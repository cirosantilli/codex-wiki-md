# Infinite-domain range-restriction index set

↑ **Parent:** [Infinite-domain index set](infinite-domain-index-set.md)

For a nonempty set $X$ of words, the property

$$
w\in\mathbf{Inf}
\quad\hbox{and}\quad
\operatorname{ran}(f_{w,1})\subseteq X
$$

is a nontrivial extensional property of unary partial computable functions: the nowhere-defined function fails it, while any total constant function with value in $X$ satisfies it. The [Rice theorem](rice-s-theorem.md) therefore makes its index set undecidable.
