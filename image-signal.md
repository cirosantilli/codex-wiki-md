# Image signal

↑ **Parent:** [Image processing](image-processing.md)

A grey-value [image signal](image-signal.md) is a scalar function on an [image signal](image-signal.md) domain or an array of pixel values. Continuous [image processing](image-processing.md) models use spaces such as $L^2$, [Sobolev spaces](sobolev-space-split.md) or the [BV space](function-of-bounded-variation-on-a-domain.md), while discrete models use finite-dimensional arrays. The chosen representation distinguishes smooth transitions, noise and [image edges](image-edge.md).
