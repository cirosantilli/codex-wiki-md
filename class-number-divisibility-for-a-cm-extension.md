# Class number divisibility for a CM extension

↑ **Parent:** [Hilbert class field](hilbert-class-field.md)

For a [CM-field](cm-field.md) $K$ over its maximal real subfield $K^+$, the ordinary [Hilbert class field](hilbert-class-field.md) $H_{K^+}$ is totally real because its real places split. Thus $H_{K^+}\cap K=K^+$. Its [compositum](field-compositum.md) with $K$ is an abelian extension of $K$ of degree $h_{K^+}$, and is everywhere unramified by [unramified extensions remain unramified under base change](unramified-extensions-remain-unramified-under-base-change.md). It lies in $H_K$, giving the divisibility. The argument does not require injectivity of extension of [ideal classes](ideal-class.md).
