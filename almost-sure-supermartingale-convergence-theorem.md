# Almost sure supermartingale convergence theorem

↑ **Parent:** [Martingale convergence theorem](martingale-convergence-theorem.md)

A nonnegative [supermartingale](supermartingale.md), or more generally a supermartingale whose negative parts have uniformly bounded expectations, converges almost surely to a finite integrable random variable.
