# Chien search

↑ **Parent:** [Error locator polynomial](error-locator-polynomial.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Chien_search)

A Chien search finds error positions by evaluating an [error locator polynomial](error-locator-polynomial.md) at every possible inverse location value $\omega^{-j}$. A zero identifies coordinate $j$. Using the recurrence between successive powers of $\omega$ avoids recomputing all monomials from scratch.
