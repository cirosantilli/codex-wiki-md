# Redundant-signals race model

↑ **Parent:** [Reaction time](reaction-time.md)

A model in which separate sensory channels can each trigger a response, and the first completed channel determines response time. Context invariance means that a channel's marginal completion distribution is unchanged between its single-signal and redundant-signal conditions. [Independence](independent-random-variables.md) is a separate, stronger assumption.
