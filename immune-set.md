# Immune set

↑ **Parent:** [Recursively enumerable set](recursively-enumerable-set.md)

An [immune set](immune-set.md) is infinite but contains no infinite [computably enumerable](recursively-enumerable-set.md) subset. Thus its infinitude cannot be witnessed by any effective infinite listing that stays entirely inside the set. Finite strings can be treated as natural-number codes for this definition.
