# Liouville vector field

↑ **Parent:** [Exact symplectic manifold](exact-symplectic-manifold.md)

For an [exact symplectic manifold](exact-symplectic-manifold.md) with $\omega=d\lambda$, the [Liouville vector field](liouville-vector-field.md) is defined by $\iota_Z\omega=\lambda$. [Cartan's magic formula](cartan-s-magic-formula.md) gives $\mathcal L_Z\omega=\omega$. On a [cotangent bundle](cotangent-bundle.md) using $\omega=-d\alpha$, take $\lambda=-\alpha$; then $Z=\sum_i p_i\partial_{p_i}$ generates the [cotangent fiber-dilation flow](cotangent-fiber-dilation-flow.md).
