# Application-layer acknowledgement

↑ **Parent:** [Communication protocol](communication-protocol.md)

An [application-layer acknowledgement](application-layer-acknowledgement.md) confirms a condition specified by an application's [communication protocol](communication-protocol.md). Receipt, successful processing and durable storage are different conditions. A [Transmission Control Protocol](transmission-control-protocol.md) acknowledgement of received bytes does not itself establish any stronger application promise; the relevant [endpoint](communication-endpoint.md) must establish that promise.[Printed p. 7: the SWALLOW example distinguishes message delivery from safe storage](end-to-end-arguments-in-system-design-by-jerome-h-saltzer-and-others.md)
