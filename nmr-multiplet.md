# NMR multiplet

↑ **Parent:** [Scalar spin-spin coupling](scalar-spin-spin-coupling.md)

A set of [resonance](resonance.md) lines arising from resolved spin coupling. Weak-coupling patterns can be assigned through coupling paths and line intensities; line count alone can be ambiguous.
