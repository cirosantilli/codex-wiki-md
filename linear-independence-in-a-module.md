# Linear independence in a module

↑ **Parent:** [Free module](free-module.md)

Elements of a [module](module-mathematics.md) are linearly independent if every finite linear relation between them has all coefficients zero. An independent finite set freely generates its span, a [finite free module](finite-free-module.md). Over an [integral domain](integral-domain.md), maximal independence within a finite generating set enables [clearing denominators relative to an independent module subset](clearing-denominators-relative-to-an-independent-module-subset.md).
