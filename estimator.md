# Estimator

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)

An estimator is a function of observed data used to estimate a parameter or a specified function of parameters. Its definition cannot involve the unknown parameter. Its [bias](bias-of-an-estimator.md), [variance](variance-split.md), and expected loss describe its performance under repeated sampling.
