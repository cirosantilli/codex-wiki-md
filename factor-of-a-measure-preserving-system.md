# Factor of a measure-preserving system

↑ **Parent:** [Measure-preserving system](measure-preserving-system.md)

A factor map $\pi$ is a measurable map satisfying $\pi\circ T=S\circ\pi$ and $\pi_*\mu=\nu$, from one [measure-preserving system](measure-preserving-system.md) to another. The target system is the factor; its observable functions pull back to observable functions of the source.
