# Generic transversality for simple holomorphic spheres

↑ **Parent:** [Regularity of a J-holomorphic curve](regularity-of-a-j-holomorphic-curve.md)

For a residual set of smooth [compatible almost complex structures](compatible-almost-complex-structure.md), all [simple J-holomorphic spheres](simple-j-holomorphic-sphere.md) in a specified countable set of spherical classes are regular. The corresponding evaluation maps at marked points are transverse to generic incidence conditions; generic paths give parameterized [transversality](transversality-of-a-map-to-a-submanifold.md). The universal linearization can vary the target structure near an [injective](injective-function.md) point of the curve, which removes its [cokernel](cokernel.md). This assertion concerns simple curves and does not ensure regularity of arbitrary multiple covers.
