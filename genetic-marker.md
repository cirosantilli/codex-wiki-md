# Genetic marker

↑ **Parent:** [Genetics](genetics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Genetic_marker)

A [genetic marker](genetic-marker.md) is an observed inherited genomic state used to track chromosomes, test [genetic association](genetic-association.md), or perform [genetic linkage](genetic-linkage.md) analysis. [Genetic marker](genetic-marker.md) [alleles](allele.md) need not themselves cause the [phenotype](phenotype.md). Several [genetic markers](genetic-marker.md) on one nonrecombining region form a single observed [haplotype](haplotype.md).
