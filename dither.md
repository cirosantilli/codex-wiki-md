# Dither

↑ **Parent:** [Analog-to-digital converter](analog-to-digital-converter.md)

[dither](dither.md) is an intentionally introduced fluctuation that makes a quantizer's output vary between codes, reducing signal-correlated quantization artifacts. A suitable distribution can make the averaged code carry information about a constant [voltage](voltage.md) smaller than one conversion step. The improvement requires filtering or averaging; extra [noise](noise-signal-processing.md) does not improve an individual conversion or repair arbitrary calibration errors.
