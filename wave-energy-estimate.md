# Wave energy estimate

↑ **Parent:** [Energy estimate](energy-estimate.md)

If $\Box u=F$ with [d'Alembert operator](d-alembert-operator.md) $\Box=-\partial_t^2+\Delta$, then $\|\partial u(t)\|_2\leq\|\partial u(0)\|_2+\int_0^t\|F(s)\|_2\,ds$, where $\partial u=(u_t,\nabla u)$. Test the [wave equation](wave-equation-split.md) against $u_t$, use [integration by parts](integration-by-parts.md), and apply the [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md). The same [energy estimate](energy-estimate.md) applies to a finite system of [wave equations](wave-equation-split.md).
