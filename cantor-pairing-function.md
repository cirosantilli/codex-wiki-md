# Cantor pairing function

↑ **Parent:** [Countable set](countable-set.md)

The Cantor pairing function is an explicit [bijection](bijection.md) between $\mathbb N^2$ and $\mathbb N$, obtained by enumerating lattice points along successive diagonals.
