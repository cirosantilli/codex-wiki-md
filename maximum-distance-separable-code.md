# Maximum distance separable code

↑ **Parent:** [Linear code](linear-code.md)

A nonzero length-$n$, dimension-$k$ [linear code](linear-code.md) is maximum distance separable if its [minimum Hamming distance](minimum-distance-of-a-code.md) equals $n-k+1$, attaining the [Singleton bound](singleton-bound.md). [Reed-Solomon codes](reed-solomon-error-correction.md) and [generalized Reed-Solomon codes](generalized-reed-solomon-code.md) provide examples because a nonzero polynomial of degree at most $k-1$ has at most $k-1$ distinct [polynomial roots](root-of-a-polynomial.md).
