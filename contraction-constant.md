# Contraction constant

↑ **Parent:** [Contraction mapping](contraction-mapping.md)

A contraction constant for a [function](function-split.md) $T$ on a [metric space](metric-space.md) is a single $q<1$ that bounds the ratio $d(Tx,Ty)/d(x,y)$ for every distinct pair. Pointwise strict inequalities $d(Tx,Ty)<d(x,y)$ do not imply such a common constant. For a [differentiable function](differentiable-function.md) on an [interval](interval-mathematics.md), the [mean value theorem](mean-value-theorem.md) shows that $|T'|\leq q<1$ supplies a contraction constant.
