# Constant diagram functor

↑ **Parent:** [Functor category](functor-category.md)

The constant diagram functor sends $C$ to the [functor](functor.md) on $J$ with constant object value $C$ and identity arrow values; a morphism $f$ becomes the [natural transformation](natural-transformation.md) with every component $f$. When all $J$-shaped [categorical limits](categorical-limit.md) exist, it is a [left adjoint](adjoint-functors.md) to the [limit functor](limit-functor.md).
