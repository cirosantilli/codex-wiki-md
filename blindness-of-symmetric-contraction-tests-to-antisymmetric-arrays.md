# Blindness of symmetric contraction tests to antisymmetric arrays

↑ **Parent:** [Scalar contraction test for a Cartesian tensor](scalar-contraction-test-for-a-cartesian-tensor.md)

The [Frobenius inner product](frobenius-inner-product.md) of a symmetric matrix and an antisymmetric matrix is zero. Thus invariant contractions of an array with all [symmetric second-rank tensors](symmetric-second-rank-tensor.md) test only its symmetric part; an arbitrary basis-dependent antisymmetric part is invisible. A nonzero antisymmetric matrix in one basis and the zero matrix in another passes all such tests with scalar zero but is not a [Cartesian second-rank tensor](cartesian-second-rank-tensor.md).
