# Algebraic generating function

↑ **Parent:** [Generating function](generating-function.md)

An algebraic generating function is a [formal power series](formal-power-series.md) $F(x)$ satisfying a nonzero [polynomial equation](polynomial-equation.md) $P(x,F(x))=0$. Over a field of characteristic zero, it is [D-finite](d-finite-power-series.md).
