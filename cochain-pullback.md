# Cochain pullback

↑ **Parent:** [Singular cochain](singular-cochain.md)

For a [continuous map](continuous-map.md) $f:X\to Y$, precomposition with the induced map on [singular chains](singular-chain.md) sends a [singular cochain](singular-cochain.md) on $Y$ to one on $X$. It commutes with the [coboundary](coboundary.md) and induces the [induced map on cohomology](induced-map-on-cohomology.md).
