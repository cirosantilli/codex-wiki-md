# Path space

↑ **Parent:** [Continuous path](continuous-path.md)

The fixed-endpoint path space $\Omega(p,q)$ consists of paths in a [manifold](topological-manifold.md) with specified initial and terminal points. Smooth, piecewise smooth and Sobolev $H^1$ versions have the same homotopy type in the usual manifold setting. Joining a path to a fixed path back from $q$ to $p$ gives a [homotopy equivalence](homotopy-equivalence.md) with the based [loop space](loop-space.md).
