# Memory address

↑ **Parent:** [Computer memory](computer-memory-split.md)

A numerical identifier for a location in [computer memory](computer-memory-split.md). In a [byte](byte.md)-addressed system, consecutive four-[byte](byte.md) [array](array-data-structure.md) elements have [memory addresses](memory-address.md) differing by four.
