# Strict partial order

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

A [strict partial order](strict-partial-order.md) is an irreflexive transitive relation. In a classical set, it corresponds to a [partial order](partially-ordered-set.md) through reflexification, but recovering the strict relation from the weak one requires inequality. In an arbitrary [topos](elementary-topos.md), this reverse operation need not be geometric or define an inverse interpretation.
