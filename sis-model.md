# SIS model

↑ **Parent:** [Compartmental models (epidemiology)](compartmental-models-epidemiology.md)

An [SIS model](sis-model.md) returns recovered hosts directly to susceptibility, so immunity does not accumulate. For homogeneous frequency-dependent transmission, a positive endemic state exists at $I_*=1-1/\mathcal R_0$ when $\mathcal R_0=\beta/\gamma>1$. This epidemiological model is distinct from the galaxy-dynamics abbreviation SIS for a singular isothermal sphere.
