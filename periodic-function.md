# Periodic function

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Periodic_function)

A function is periodic when $f(x+T)=f(x)$ for some nonzero period $T$ and every $x$ in its domain.
