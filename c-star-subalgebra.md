# C-star subalgebra

↑ **Parent:** [C-star algebra](c-star-algebra.md)

A C-star subalgebra is a norm-closed subalgebra closed under the involution, with the inherited [C-star identity](c-star-identity.md). A unital inclusion in this context uses the same identity as the ambient [C-star algebra](c-star-algebra.md). The [spectral permanence for C-star algebras](spectral-permanence-for-c-star-algebras.md) says the inclusion preserves the [spectrum of an element](spectrum-of-an-element.md).
