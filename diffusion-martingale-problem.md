# Diffusion martingale problem

↑ **Parent:** [Martingale problem](martingale-problem.md)

For bounded measurable $a,b$, with $a$ symmetric positive semidefinite, an [L-diffusion](diffusion-martingale-problem.md) is a continuous [adapted process](adapted-process.md) $X$ such that $g(X_t)-g(X_0)-\int_0^t Lg(X_s)ds$ is a true [martingale](martingale-split.md) for every $g\in C_b^2$. The general local [martingale problem](martingale-problem.md) may instead use compactly supported test functions and require only a [local martingale](local-martingale.md). Specify the test class and the true or local convention when coefficients are unbounded.
