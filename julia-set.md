# Julia set

↑ **Parent:** [Complex dynamics](complex-dynamics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Julia_set)

The Julia set is the complement of the [Fatou set](fatou-set.md). It is nonempty, closed, completely invariant, and perfect for every rational map of degree at least two.
