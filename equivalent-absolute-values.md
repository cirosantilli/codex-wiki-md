# Equivalent absolute values

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

Two nontrivial [absolute values on a field](absolute-value-algebra.md) are equivalent when they induce the same [topology](topology-split.md). Equivalently, one is a positive real power of the other.
