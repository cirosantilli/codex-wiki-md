# Edge set

↑ **Parent:** [Graph](graph-split.md)

The [set](set-split.md) of [edges](edge-of-a-graph.md) of a specified [graph](graph-split.md). In a [simple graph](simple-graph.md), an [edge](edge-of-a-graph.md) is determined by its endpoints; a [multigraph](multigraph.md) additionally distinguishes parallel [edges](edge-of-a-graph.md) with the same endpoints. A [subgraph](subgraph.md) can be specified by selecting a [vertex set](vertex-set.md) and an [edge set](edge-set.md) whose endpoints belong to it.
