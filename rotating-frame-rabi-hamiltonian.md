# Rotating-frame Rabi Hamiltonian

↑ **Parent:** [Rabi cycle](rabi-cycle.md)

A circularly driven [spin](spin.md) becomes time-independent after a rotation $R=e^{-i\omega tS_z/\hbar}$. The transformed [Hamiltonian operator](hamiltonian-quantum-mechanics.md) is $R^\dagger HR-i\hbar R^\dagger\dot R$, so the longitudinal [frequency](frequency.md) is shifted by $-\omega$. This is an exact change of frame for a circular drive. The [rotating-wave approximation](rotating-wave-approximation.md) is a separate approximation needed when a drive also contains a counterrotating component.
