# Preservation of a restrained oracle computation

↑ **Parent:** [Priority restraint](priority-restraint.md)

An oracle computation queries only finitely many positions. If the oracle remains unchanged below its use, the same computation has the same output. In a [finite-injury priority construction](finite-injury-priority-construction.md), a successful requirement imposes this bound on lower priorities; the induction that higher priorities stop acting then makes the disagreement permanent.
