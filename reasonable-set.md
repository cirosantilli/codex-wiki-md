# Reasonable set

↑ **Parent:** [Hereditarily countable set](hereditarily-countable-set.md)

A set $x$ is reasonable when every member of $\operatorname{TC}(\{x\})$ is countable. In ZFC this is equivalent to $x$ being [hereditarily countable](hereditarily-countable-set.md).
