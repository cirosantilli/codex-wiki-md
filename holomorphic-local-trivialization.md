# Holomorphic local trivialization

↑ **Parent:** [Holomorphic vector bundle](holomorphic-vector-bundle.md)

A holomorphic local trivialization of a rank-$r$ [holomorphic vector bundle](holomorphic-vector-bundle.md) $E\to X$ is a [biholomorphic](biholomorphism.md) bundle map $E|_U\to U\times\mathbb C^r$ that is complex linear on each fiber. Equivalently, it is a local frame of holomorphic sections.
