# Summability domain of a regular matrix

↑ **Parent:** [Regular matrix summability method](regular-matrix-summability-method.md)

The summability domain is the inverse image of the [convergent sequence space](convergent-sequence-space.md) under the bounded matrix operator on the [l-infinity sequence space](l-infinity-sequence-space.md). It is therefore a [closed linear subspace](closed-vector-subspace.md). The [bounded divergence for every regular summability matrix](bounded-divergence-for-every-regular-summability-matrix.md) makes it proper, so it has empty interior and is a [nowhere dense set](nowhere-dense-set.md). The [Baire category theorem](baire-category-theorem.md) then ensures that countably many regular methods miss some common bounded sequence.
