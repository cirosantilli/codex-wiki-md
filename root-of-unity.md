# Root of unity

↑ **Parent:** [Algebra](algebra-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Root_of_unity)

An $N$th root of unity is a [complex number](complex-number.md) $z$ satisfying $z^N=1$. The primitive root $e^{2\pi i/N}$ generates all $N$th roots.
