# Baire property in the Ellentuck topology

↑ **Parent:** [Ellentuck topology](ellentuck-topology.md)

A subset of the [space of infinite subsets of the natural numbers](space-of-infinite-subsets-of-the-natural-numbers.md) has this property when it differs from an [Ellentuck topology](ellentuck-topology.md) open set by a [meagre set](meagre-set.md) in the same topology. By the complete-Ramsey characterization, these are precisely the [completely Ramsey sets](completely-ramsey-set.md). Using meagreness from a different topology changes the definition.
