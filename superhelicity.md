# Superhelicity

↑ **Parent:** [Massless supermultiplet](massless-supermultiplet.md)

For a four-dimensional $\mathcal N=1$ finite-helicity [massless supermultiplet](massless-supermultiplet.md), one complex oscillator changes [helicity](helicity.md) by one-half. A lower-helicity labelling convention assigns $\kappa$ to the pair $(\kappa,\kappa+1/2)$. A symmetric midpoint convention instead uses $\kappa+1/4$; report the [helicity](helicity.md) pair when comparing conventions. [CPT completion of a supermultiplet](cpt-completion-of-a-supermultiplet.md) pairs $\kappa$ with $-\kappa-1/2$.
