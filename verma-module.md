# Verma module

↑ **Parent:** [Highest-weight representation](highest-weight-representation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Verma_module)

For a Borel subalgebra $\mathfrak b=\mathfrak t\oplus\mathfrak n^+$ and a weight $\lambda$, the Verma module is

$$
M_\lambda=U(\mathfrak g)\otimes_{U(\mathfrak b)}\mathbb C_\lambda,
$$

where $\mathfrak n^+$ kills $\mathbb C_\lambda$ and $h\in\mathfrak t$ acts by $\lambda(h)$.
