# Finite automaton emptiness test

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A [finite-state automaton](finite-state-machine.md) recognizes a nonempty [formal language](formal-language.md) exactly when some accepting [automaton state](automaton-state.md) is reachable from an initial [automaton state](automaton-state.md). [Reachability in a graph](reachability-in-a-graph.md) decides this in a finite transition graph. For an [Epsilon-NFA](epsilon-nfa.md), include its [epsilon transitions](epsilon-transition.md); the non-epsilon labels of a successful [graph path](path-in-a-graph.md) give an accepted [word](string.md).
