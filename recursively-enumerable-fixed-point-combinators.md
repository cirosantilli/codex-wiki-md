# Recursively enumerable fixed-point combinators

↑ **Parent:** [Fixed-point combinator](fixed-point-combinator.md)

The set of [fixed-point combinators](fixed-point-combinator.md) is [recursively enumerable](recursively-enumerable-set.md). Enumerate closed lambda terms and finite proofs of [beta equivalence](beta-equivalence.md), and output $Y$ whenever a proof of $Yf\equiv_\beta f(Yf)$ appears for a fresh variable $f$.
