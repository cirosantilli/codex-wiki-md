# Continuous nonalgebraic unit interval

↑ **Parent:** [Continuous directed-complete partial order](continuous-directed-complete-partial-order.md)

Give the [real interval](interval-mathematics.md) $[0,1]$ its usual [total order](total-order.md). Every nonempty [directed set](directed-set.md) has a [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) in the [real interval](interval-mathematics.md), so it is a [directed-complete partial order](directed-complete-partial-order.md). If $x<y\leq\sup D$, some $d\in D$ exceeds $x$; otherwise $x$ would be an [upper bound](upper-bound-in-a-partially-ordered-set.md) for $D$. Also $0\ll0$, since every member of a nonempty $D$ is at least zero. For $x>0$, the increasing [sequence](sequence.md) $x(1-1/n)$, $n\geq1$, has [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) $x$ but never reaches it, so $x\not\ll x$. Together with $x\ll y\Rightarrow x\leq y$, this proves the displayed [way-below relation](way-below-relation.md).

For each $y>0$, the elements [way-below](way-below-relation.md) $y$ form $[0,y)$, a [directed set](directed-set.md) with [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) $y$; for $y=0$ they form $\{0\}$. Thus this is a [continuous poset](continuous-poset.md). Its only [compact element](compact-element.md) is zero, so it is not an [algebraic partially ordered set](algebraic-partially-ordered-set.md).
