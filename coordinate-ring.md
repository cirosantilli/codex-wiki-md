# Coordinate ring

↑ **Parent:** [Affine algebraic set](affine-algebraic-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Coordinate_ring)

For an affine algebraic set $X\subseteq\mathbb A_k^n$, its coordinate ring is

$$
k[X]=k[x_1,\ldots,x_n]/I(X).
$$

The set $X$ is irreducible exactly when $k[X]$ is an [integral domain](integral-domain.md).
