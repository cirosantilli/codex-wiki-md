# No entire square root of the identity function

↑ **Parent:** [Analytic branch of a square root](analytic-branch-of-a-square-root.md)

If an [entire function](entire-function.md) $h$ satisfied $h(z)^2=z$, then $h(0)=0$. Differentiating would give $2h(0)h'(0)=1$, a contradiction. More generally, the order of every zero of a square of a [holomorphic function](holomorphic-function-split.md) is even, so a simple zero prevents a holomorphic square root on any neighborhood containing it. A square root can still exist on a slit domain avoiding the zero. The [identity theorem](identity-theorem.md) can force this obstruction from values specified only on a sequence accumulating elsewhere in a connected domain.
