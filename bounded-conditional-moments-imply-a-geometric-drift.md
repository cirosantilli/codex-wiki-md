# Bounded conditional moments imply a geometric drift

↑ **Parent:** [Geometric drift condition](geometric-drift-condition.md)

Suppose a [Markov kernel](markov-kernel.md) satisfies $PV(x)\leq M<\infty$ for a measurable $V\geq1$. For $0<\rho<1$ and $R>M/\rho$, the sublevel set $C=\{V\leq R\}$ gives $PV\leq\rho V+M\mathbf1_C$. If $C$ is a [small set](small-set.md), this is a [geometric drift condition](geometric-drift-condition.md). The hypotheses of an [irreducible Markov chain](irreducible-markov-chain.md) and an [aperiodic Markov chain](aperiodic-markov-chain.md) are also required for the usual [geometric ergodicity](geometric-ergodicity.md) theorem.
