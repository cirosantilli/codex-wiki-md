# Shape function

↑ **Parent:** [Finite element](finite-element.md)

A shape function is a local [basis](basis.md) function associated with a degree of freedom of a [finite element](finite-element.md). For nodal degrees of freedom it is one at its own node and zero at the other nodes, allowing local [interpolation](interpolation-split.md) from the nodal values. For a [bilinear square finite element](bilinear-square-finite-element.md), the four products of linear coordinate functions provide the nodal [shape functions](shape-function.md).
