# Bounded rational extension property

↑ **Parent:** [Rationally labelled Aronszajn tree construction](rationally-labelled-aronszajn-tree-construction.md)

For every earlier node and rational cap above its label, an extension at each later level remains below the cap. In the [rationally labelled Aronszajn tree construction](rationally-labelled-aronszajn-tree-construction.md) this reserves space for limit-stage unions. Choosing an intermediate rational and forcing successive values toward it ensures a rational supremum and strictly increasing labels even at limit levels.
