# Power-set equality is not upward absolute

↑ **Parent:** [Upward absolute formula](upward-absolute-formula.md)

Assume $V\ne L$. At the first cumulative stage containing a nonconstructible [set](set-split.md), the index is a successor $\beta+1$. [Rank absoluteness](set-theoretic-absoluteness.md) gives $y=V_\beta=(V_\beta)^L\in L$, not just $V_\beta\subseteq L$. Let $x$ be the [power set](power-set.md) of $y$ computed in $L$. It omits a nonconstructible [subset](subset.md) of $y$ from the next external rank stage. Thus $L$ satisfies [power-set equality](power-set-equality-is-not-upward-absolute.md) for the parameters $x,y\in L$, while $V$ does not. Both are transitive models of [ZF](zermelo-fraenkel-set-theory.md). [Subset](subset.md) inclusion itself is bounded and absolute; quantification over all possible [subsets](subset.md) causes the failure.
