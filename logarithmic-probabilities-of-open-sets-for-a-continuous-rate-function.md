# Logarithmic probabilities of open sets for a continuous rate function

↑ **Parent:** [Large deviation principle](large-deviation-principle.md)

If a [large deviation principle](large-deviation-principle.md) has a finite [continuous](continuous-function.md) [rate function](rate-function.md), then the infima on any [open set](open-set.md) and its [closure](closure-topology.md) agree. Approximate every closure point by points of the set and use continuity. The open-set lower and closed-set upper bounds consequently match, giving the displayed logarithmic limit, including the empty-set convention. A single-point event need not obey such an equality.
