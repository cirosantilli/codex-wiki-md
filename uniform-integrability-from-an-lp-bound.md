# Uniform integrability from an Lp bound

↑ **Parent:** [Uniform integrability](uniform-integrability.md)

For $p>1$, $\sup_n\mathbb E|X_n|^p=C<\infty$ gives $\sup_n\mathbb E[|X_n|\mathbf1_{|X_n|>M}]\leq C M^{1-p}\to0$. Thus an $L^p$ bound implies [uniform integrability](uniform-integrability.md); a mere $L^1$ bound does not.
