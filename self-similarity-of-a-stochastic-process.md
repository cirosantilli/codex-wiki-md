# Self-similarity of a stochastic process

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

A process $Z$ is self-similar with exponent $H$ if $Z(a\,\cdot)$ and $a^HZ$ have the same finite-dimensional distributions for every $a>0$, or the same path law when the process is considered as a random path. [Fractional Brownian motion](fractional-brownian-motion.md) has this property with its [Hurst exponent](hurst-exponent.md). It converts dilation of time to deterministic scaling of amplitude: $Z(N\,\cdot)/N\overset d=N^{H-1}Z$. Consequently a small-noise [large deviation principle](large-deviation-principle.md) with inverse-variance speed produces the [large-deviation speed](large-deviation-speed.md) $N^{2(1-H)}$ for those rescaled paths.
