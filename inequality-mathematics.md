# Inequality (mathematics)

↑ **Parent:** [Arithmetic](arithmetic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inequality_(mathematics))

An [inequality](inequality-mathematics.md) compares mathematical quantities using an ordering, such as $a<b$ or $a\leq b$ for [real numbers](real-number.md). A strict [inequality](inequality-mathematics.md) excludes equality; a non-strict [inequality](inequality-mathematics.md) allows it. For example, $4<5$ is strict, while $4\leq4$ is true because equality is allowed. Adding the same [real number](real-number.md) preserves either comparison; multiplying by a negative [real number](real-number.md) reverses its direction.
