<h1 id="deterministic-cadlag-process-is-predictable">Deterministic càdlàg process is predictable</h1>

↑ **Parent:** [Predictable sigma-algebra](predictable-sigma-algebra.md)

Every deterministic [càdlàg function](cadlag.md) is Borel measurable in time. Since the predictable sigma-algebra contains every set $\Omega\times A$ with $A$ Borel, the corresponding deterministic process is predictable.
