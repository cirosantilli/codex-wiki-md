# Multiplication of a distribution by a smooth function

↑ **Parent:** [Distribution theory](distribution-theory-split.md)

For a [distribution](distribution-mathematical-analysis.md) $u$ and a [smooth function](smooth-function.md) $a$, the product $au$ is defined by $\langle au,\varphi\rangle=\langle u,a\varphi\rangle$. It obeys the [Leibniz rule](leibniz-rule.md); in one dimension, $(au)'=a'u+au'$.
