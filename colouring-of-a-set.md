# Colouring of a set

↑ **Parent:** [Partition of a set](partition-of-a-set.md)

A colouring assigns to each member of a [set](set-split.md) $X$ a colour in another set $C$. Its nonempty fibres form a [partition of a set](partition-of-a-set.md). The colour set may be infinite; a [finite colouring](finite-coloring.md) is the special case with finitely many colours. A [homogeneous set for a colouring](homogeneous-set-for-a-colouring.md) of finite subsets has all its subsets of the specified size assigned one colour.
