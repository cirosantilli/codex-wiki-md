# Transition state theory

↑ **Parent:** [Catalyst](catalyst.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Transition_state_theory)

[Transition state theory](transition-state-theory.md) relates an [elementary reaction](elementary-reaction.md)'s [rate constant](rate-constant.md) to a [Gibbs energy of activation](gibbs-energy-of-activation.md). The Eyring expression used in the [catalyst](catalyst.md) example assumes every passage counted at the [transition state](transition-state.md) succeeds. More generally, a factor accounting for unsuccessful passage multiplies it. Comparing barriers alone gives the quoted speedup only when the remaining prefactors agree. Free-energy profiles can depend on [temperature](temperature-split.md), so the example's values at $300\,\mathrm K$ do not determine a temperature curve. See the [IUPAC Gold Book: transition state theory](https://goldbook.iupac.org/terms/view/T06470).
