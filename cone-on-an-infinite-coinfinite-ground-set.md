# Cone on an infinite coinfinite ground set

↑ **Parent:** [Ellentuck topology](ellentuck-topology.md)

For an infinite [coinfinite set](coinfinite-set.md) $A\subseteq\mathbb N$, let $E_A=[A]^\omega$ in the [space of infinite subsets of the natural numbers](space-of-infinite-subsets-of-the-natural-numbers.md). This cone is a nonempty [clopen set](clopen-set.md) in the [Ellentuck topology](ellentuck-topology.md), because it is the basic [neighbourhood](neighbourhood-mathematics.md) $[\varnothing,A]$, and any $X\notin E_A$ has a finite initial segment containing a point outside $A$ and hence a basic [neighbourhood](neighbourhood-mathematics.md) disjoint from $E_A$.

The cone is a [closed set](closed-set.md) with empty [interior](interior-topology.md) in the [ordinary topology on infinite subsets](ordinary-topology-on-infinite-subsets.md): membership of a point outside $A$ witnesses its complement as an [open set](open-set.md), while every ordinary finite-stem [neighbourhood](neighbourhood-mathematics.md) can be extended by an arbitrarily large point outside $A$. Thus $E_A$ is an ordinary [nowhere dense set](nowhere-dense-set.md), but it is neither ordinary open nor Ellentuck nowhere dense. It provides both distinctions between these two [topologies](topology-split.md).
