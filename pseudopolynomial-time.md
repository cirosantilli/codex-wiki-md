# Pseudopolynomial time

↑ **Parent:** [Time complexity](time-complexity.md)

A [time complexity](time-complexity.md) polynomial in numerical input values, which need not be polynomial in their binary encoding lengths. For example, an $O(nW)$ [knapsack](knapsack-problem.md) algorithm depends on the capacity $W$, while its input representation needs only $O(\log(W+1))$ bits for that capacity.
