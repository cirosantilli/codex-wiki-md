# Anti-symplectic map

↑ **Parent:** [Symplectic geometry](symplectic-geometry-split.md)

An anti-symplectic map between [symplectic manifolds](symplectic-manifold.md) is a [diffeomorphism](diffeomorphism.md) $f$ satisfying $f^*\omega'=-\omega$. For [symplectic vector spaces](symplectic-vector-space.md), the analogous definition uses an invertible [linear map](linear-map.md).
