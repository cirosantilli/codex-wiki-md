# Radiative transfer source function

↑ **Parent:** [Radiative transfer equation](radiative-transfer-equation.md)

The [radiative transfer](radiative-transfer.md) [source function](radiative-transfer-source-function.md) is emission per unit extinction. If $j_\nu$ is emission per unit path length and $\rho\kappa_\nu$ is extinction per unit path length, $S_\nu=j_\nu/(\rho\kappa_\nu)$ and the transfer equation is $\mu\partial_{\tau_\nu}I_\nu=I_\nu-S_\nu$. Under thermal absorption in [local thermodynamic equilibrium](local-thermodynamic-equilibrium.md) it is the [Planck function](planck-function.md); for conservative [coherent isotropic scattering](coherent-isotropic-scattering.md) it is the [mean intensity](mean-intensity.md).
