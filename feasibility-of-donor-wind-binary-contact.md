# Feasibility of donor-wind binary contact

↑ **Parent:** [Donor-wind Roche-lobe response](donor-wind-roche-lobe-response.md)

A [donor star](donor-star.md) with [stellar radius response exponent](stellar-radius-response-exponent.md) $\zeta_*$ can maintain exact contact in the [donor-wind Roche-lobe response](donor-wind-roche-lobe-response.md) model for some retained fraction $0\le f\le1$ precisely when $\zeta_*$ lies between $\zeta_0$ and $\zeta_1$. This follows because the attainable [Roche-lobe radius response exponents](roche-lobe-radius-response-exponent.md) form that closed interval. If its endpoints coincide, all fractions work when $\zeta_*$ equals the common value and none work otherwise. With negative donor mass-loss rate, $d\log(R_d/R_L)/dt=(\zeta_*-\zeta_L)\dot M_d/M_d$ distinguishes detachment from increasing overfill. [Dynamical stability of binary mass transfer](dynamical-stability-of-binary-mass-transfer.md) requires the adiabatic donor response.
