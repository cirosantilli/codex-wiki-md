# Vanishing odd complete contractions of an antisymmetric matrix

↑ **Parent:** [Antisymmetric tensor](antisymmetric-tensor.md)

For a real [antisymmetric matrix](skew-symmetric-matrix.md), [transpose](transpose.md) gives $\operatorname{tr}(A^{2j+1})=\operatorname{tr}((-A)^{2j+1})=-\operatorname{tr}(A^{2j+1})$, so this [trace](matrix-trace.md) vanishes. Every complete pairwise [tensor contraction](tensor-contraction.md) of copies of $A$, using the Euclidean [Kronecker delta](kronecker-delta.md), splits into closed index cycles. Each cycle is a trace of a power of $A$, up to a sign from index order. An odd total number of copies forces an odd-length cycle, so the whole contraction vanishes. This assertion concerns pairwise index contraction with the metric; inserting additional tensors would be a different claim.
