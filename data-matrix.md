# Data matrix

↑ **Parent:** [Matrix](matrix.md)

A [matrix](matrix.md) representing observations and their measured variables. A common convention uses observations as rows and variables as columns; stating this orientation avoids transposition ambiguities. Column centering subtracts each variable's [sample mean](sample-mean.md), and $X_c^TX_c/(n-1)$ is the [sample covariance matrix](sample-covariance-matrix.md) of centered data when $n>1$.
