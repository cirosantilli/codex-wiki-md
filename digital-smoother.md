# Digital smoother

↑ **Parent:** [Synchronous sequential circuit](synchronous-sequential-circuit.md)

A sampled [Boolean circuit](boolean-circuit.md) that suppresses short input changes using recent samples. A three-sample [majority function](majority-function.md) removes isolated one-sample changes; a stateful variant updates its stored output only after three equal input samples. These are different specifications.
