# Square-lattice Weierstrass function has a zero branch value

↑ **Parent:** [Weierstrass elliptic function](weierstrass-elliptic-function.md)

For the square [period lattice](period-lattice.md), multiplying the defining series by the lattice symmetry $z\mapsto iz$ gives $\wp(iz)=-\wp(z)$. At $h=(1+i)/2$, one has $ih=h-1$, so periodicity gives $\wp(h)=-\wp(h)$ and hence the displayed zero. This is one of the three finite branch values of the degree-two [Weierstrass elliptic function](weierstrass-elliptic-function.md) on its [torus](torus.md). The three values are always distinct but need not all be nonzero. Distinctness is enough for the nonsingularity of the associated [elliptic curve](elliptic-curve.md) $Y^2Z=4\prod_i(X-e_iZ)$.
