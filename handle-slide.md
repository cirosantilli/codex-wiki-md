# Handle slide

↑ **Parent:** [Handle decomposition](handle-decomposition.md)

A handle slide replaces the framed [attaching sphere](attaching-sphere.md) of one handle by a [band sum](band-sum.md) with a parallel copy of another handle of the same index. It changes the attaching data while preserving the diffeomorphism type of the resulting [manifold](topological-manifold.md). On the handle incidence matrix it performs an elementary row operation, or a column operation when applied to the dual decomposition.
