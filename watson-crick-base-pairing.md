# Watson-Crick base pairing

↑ **Parent:** [Base pairing](base-pairing.md)

[Watson-Crick base pairing](watson-crick-base-pairing.md) is the canonical geometry of pairing between complementary nucleic-acid bases, including adenine–thymine and guanine–cytosine in ordinary [DNA](deoxyribonucleic-acid.md). It is a particular pairing geometry, not a synonym for every possible [base pair](base-pair.md).
