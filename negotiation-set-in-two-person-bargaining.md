# Negotiation set in two-person bargaining

↑ **Parent:** [Nash bargaining problem](nash-bargaining-problem.md)

For a [compact convex set](compact-convex-set.md) of feasible [payoff](payoff.md) [vectors](vector.md) $F$ and a specified [disagreement point](disagreement-point.md) $d$, the [negotiation set](negotiation-set-in-two-person-bargaining.md) is its individually rational [Pareto frontier](pareto-frontier.md). It is the set of efficient agreements each player prefers at least weakly to disagreement. In a [maximin bargaining solution](maximin-bargaining-solution.md), $d$ is the [vector](vector.md) of the two [security level payoffs](security-level-payoff.md). This usage is distinct from objection-and-counterobjection bargaining sets in coalitional-game theory.
