# Binary constraint

↑ **Parent:** [Constraint satisfaction problem](constraint-satisfaction-problem.md)

A restriction involving two variables in a [constraint satisfaction problem](constraint-satisfaction-problem.md), represented by the allowed value pairs $R_{ij}$. Multiple restrictions on the same pair can be combined by intersection. For bundle allocation, disjointness and the two directional [envy-free allocation](envy-free-allocation.md) inequalities together define one compatibility relation.
