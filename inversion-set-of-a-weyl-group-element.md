# Inversion set of a Weyl-group element

↑ **Parent:** [Coxeter length](coxeter-length.md)

For a chosen [positive system of a root system](positive-system-of-a-root-system.md) $\Pi$, the inversion set is

$$
N(w)=\{\beta\in\Pi:w(\beta)\in-\Pi\}.
$$

For a finite [Weyl group](weyl-group.md), $|N(w)|=\ell(w)$.

Its cardinality is the [Coxeter length](coxeter-length.md); this root-sign definition should not be silently identified with an unspecified permutation inversion convention.
