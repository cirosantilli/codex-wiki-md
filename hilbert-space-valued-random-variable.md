# Hilbert-space-valued random variable

↑ **Parent:** [Random variable](random-variable-split.md)

A Hilbert-space-valued random variable is a measurable map into a [Hilbert space](hilbert-space-split.md). It is square-integrable when $\mathbb E\lVert X\rVert^2<\infty$, in which case its mean is defined by the [Bochner integral](bochner-integral.md).
