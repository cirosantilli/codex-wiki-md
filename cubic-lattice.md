# Cubic lattice

↑ **Parent:** [Graph](graph-split.md)

The [cubic lattice](cubic-lattice.md) in dimension $d$ has [graph vertex](vertex-graph-theory.md) [set](set-split.md) $\mathbb Z^d$ and an [edge](edge-of-a-graph.md) between $x,y$ exactly when $\sum_i|x_i-y_i|=1$. For $d=2$ it is the [square lattice](square-lattice.md). Every [graph vertex](vertex-graph-theory.md) has $2d$ [graph neighbours](neighbour-of-a-vertex.md), so it is a [locally finite graph](locally-finite-graph.md).
