# Approximate number system

↑ **Parent:** [Numerical cognition](numerical-cognition.md)

A system proposed to represent approximate nonsymbolic quantity. Such representations should be distinguished from exact [number](number.md)-word meanings and symbolic [arithmetic](arithmetic-split.md); causal transfer from training requires direct evidence.
