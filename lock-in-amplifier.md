# Lock-in amplifier

↑ **Parent:** [Electronic amplifier](electronic-amplifier.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lock-in_amplifier)

A [lock-in amplifier](lock-in-amplifier.md) measures the component of an input [signal](signal.md) synchronized with a reference at a chosen [frequency](frequency.md). It multiplies the input by a reference [sinusoid](sinusoid.md), then uses a [low-pass filter](low-pass-filter.md) to retain the slowly varying product. Two references in [phase quadrature](phase-quadrature.md) recover both [amplitude](wave-amplitude.md) and [phase difference](phase-difference.md). A shared timing source keeps the relative [wave phase](phase-waves.md) stable: this is coherent detection.[Model SR830 DSP Lock-In Amplifier manual, revision 2.5, printed pp. 3-1–3-2: multiplication, filtering, reference locking and dual-phase detection](model-sr830-dsp-lock-in-amplifier-manual-by-stanford-research-systems.md)

The useful trick is to move the wanted [frequency](frequency.md) to zero before averaging. An [electronic amplifier](electronic-amplifier.md) alone enlarges both the wanted [signal](signal.md) and unwanted [noise](noise-signal-processing.md); a [lock-in amplifier](lock-in-amplifier.md) instead selects a component by its timing. A [photodiode](photodiode.md)'s [electric current](electric-current.md) can first be converted to an [electric potential difference](electric-potential-difference.md), so the same calculation can measure weak modulated [light](light.md). The [chopped-light lock-in experiment](chopped-light-lock-in-experiment.md) makes this selection tangible.
