# Quantifier order and uniform witness

↑ **Parent:** [First-order logic](first-order-logic.md)

A single witness working for every object supplies a witness for each object individually. Eliminate the outer existential with a fresh witness, instantiate the universal at an arbitrary object, and introduce the required existential. Generalization can occur either before or after closing the witness scope, provided the [eigenvariable condition](eigenvariable-condition.md) holds in the corresponding contexts. The converse fails on a two-element domain with $R(x,y)$ interpreted as equality: each object has itself as a witness, but no object works for both.
