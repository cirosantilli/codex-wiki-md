# Proper extended-real function

↑ **Parent:** [Real analysis](real-analysis-split.md)

An extended-real function is proper if it never takes $-\infty$ and is finite at at least one point. It can take $+\infty$ to impose a constraint. A [convex function](convex-function.md) with this property is a [proper convex function](proper-convex-function.md).
