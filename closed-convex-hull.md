# Closed convex hull

↑ **Parent:** [Convex hull](convex-hull.md)

The smallest closed [convex set](convex-set-split.md) containing a set $C$, equivalently the closure of its [convex hull](convex-hull.md) in the specified [topology](topology-split.md). The topology must be stated: the [norm topology](norm-topology.md), [weak topology](weak-topology-split.md) and [weak-star topology](weak-star-topology.md) need not give the same closure for an arbitrary set.

Even a bounded infinite input need not have a closed [convex hull](convex-hull.md). In the real line, let $S=\{1/n:n\geq1\}$. Every finite [convex combination](convex-combination.md) of these positive points is positive, so zero is absent. Conversely, any $x\in(0,1]$ lies between some $1/n$ and $1$, and is their [convex combination](convex-combination.md). Hence

$$
\operatorname{conv}(S)=(0,1],\qquad\overline{\operatorname{conv}}(S)=[0,1].
$$

The [closed convex hull](closed-convex-hull.md) adds the missing [limit](limit-of-a-function.md) point zero. For the finite eight-point example in [convex hull](convex-hull.md), the [convex hull](convex-hull.md) is already closed, so taking the [closed convex hull](closed-convex-hull.md) adds nothing.
