# Closed convex hull

↑ **Parent:** [Convex hull](convex-hull.md)

The smallest closed [convex set](convex-set.md) containing a set $C$, equivalently the closure of its [convex hull](convex-hull.md) in the specified [topology](topology-split.md). The topology must be stated: the [norm topology](norm-topology.md), [weak topology](weak-topology-split.md) and [weak-star topology](weak-star-topology.md) need not give the same closure for an arbitrary set.
