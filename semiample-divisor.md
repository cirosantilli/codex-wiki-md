# Semiample divisor

↑ **Parent:** [Positivity of divisors](positivity-of-divisors.md)

A [Cartier divisor](cartier-divisor-split.md) is [semiample](semiample-divisor.md) if some positive multiple is a [basepoint-free divisor](basepoint-free-divisor.md), equivalently its [divisor line bundle](divisor-line-bundle.md) has a globally generated positive power. Such a power defines a [Kodaira map](kodaira-map.md) $f$ with $\mathcal O(mD)=f^*\mathcal O(1)$. [Semiampleness](semiample-divisor.md) implies nefness but need not imply [ampleness](ample-cartier-divisor.md): a fibre divisor of a morphism to a curve is a basic example.
