# Exponential memory from tensor relaxation

↑ **Parent:** [Dissipation potential](dissipation-potential.md)

The [dissipation potential](dissipation-potential.md) $\Omega=\alpha\|Q\|^{n+1}/(n+1)-\operatorname{tr}(AQ)/\tau$, with the [Frobenius norm](frobenius-norm.md), gives $\dot A+A/\tau=\alpha\|Q\|^{n-1}Q^T$. An [integrating factor](integrating-factor.md) proves the displayed memory formula. For $n>0$, its nonlinear driving term is defined continuously as zero at $Q=0$. Mechanical dissipation is $\operatorname{tr}(Q\dot A)=\alpha\|Q\|^{n+1}-\operatorname{tr}(AQ)/\tau$, which must be nonnegative on thermodynamically admissible histories.
