# String-frame metric

↑ **Parent:** [String nonlinear sigma model](string-nonlinear-sigma-model.md)

The string-frame metric is the target metric appearing directly in the kinetic term of the [string nonlinear sigma model](string-nonlinear-sigma-model.md). With conventional Euclidean [dilaton](dilaton.md) $\varphi$, its leading spacetime gravitational action contains $\sqrt{-g^{(s)}}e^{-2\varphi}(R+4|\nabla\varphi|^2)$. The dilaton-dependent Ricci coefficient distinguishes it from the [Einstein-frame metric](einstein-frame-metric.md). Frame changes are local field redefinitions where the conformal factor is finite and nonzero; the [Lorentzian dilaton coupling sign convention](lorentzian-dilaton-coupling-sign-convention.md) fixes which named field is $\varphi$.
