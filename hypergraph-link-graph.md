# Hypergraph link graph

↑ **Parent:** [Hypergraph](hypergraph-split.md)

For a three-[uniform hypergraph](uniform-hypergraph.md), the link of a vertex $v$ is the ordinary [graph](graph-split.md) on the remaining vertices in which $xy$ is an edge precisely when $vxy$ is a [hyperedge](hyperedge.md). Its edge count is the [hypergraph vertex degree](hypergraph-vertex-degree.md) of $v$.
