# Axiomatic specification

↑ **Parent:** [Formal specification](formal-specification.md)

Describe operations through laws relating their observable results, without selecting an internal representation. For an [abstract data type](abstract-data-type.md), the laws must state the operation domains and error results as well as ordinary cases. A [disjoint union](disjoint-union.md) can distinguish a successful value from an error with the same textual spelling.
