# State machine

↑ **Parent:** [Abstract machine](abstract-machine.md)

A computational model with an internal state and transition rule, together with an initial state and optional observation and stopping functions. The state space need not be finite; a [finite-state machine](finite-state-machine.md) is the special case with finitely many states. A trace records observations along transitions. An interface providing only reset, update, stopping and observation operations does not by itself provide copying or rollback; a trace [iterator](iterator.md) can revisit saved observations without reversing machine effects.
