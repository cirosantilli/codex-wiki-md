# Uniform contraction from a comparison function on a bounded set

↑ **Parent:** [Contraction mapping theorem](contraction-mapping-theorem.md)

Suppose all distances lie in $[0,D]$, $\psi$ is [continuous](continuous-function.md), $0<\psi(r)<r$ for positive $r$, and $\lim_{r\to0}\psi(r)/r<1$. The ratio is uniformly [bounded](boundedness.md) below one near zero, and its maximum on the remaining compact [scalar](scalar.md) [interval](interval-mathematics.md) is also below one. Thus one constant $q<1$ works on the entire [bounded set](bounded-set.md). If the [set](set-split.md) is complete and the map preserves it, [Banach's theorem](contraction-mapping-theorem.md) gives a unique [fixed point](fixed-point.md). [Compactness](compact-space.md) of the [set](set-split.md) itself is not required.
