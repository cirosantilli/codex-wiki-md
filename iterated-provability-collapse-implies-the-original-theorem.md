# Iterated provability collapse implies the original theorem

↑ **Parent:** [Löb's theorem](lob-s-theorem.md)

For standard provability satisfying [positive introspection](positive-introspection.md), suppose $T\vdash\Box^j A\to A$ for some positive [integer](integer-split.md) $j$. [Positive introspection](positive-introspection.md) gives $T\vdash\Box A\to\Box^j A$, hence $T\vdash\Box A\to A$. [Löb's theorem](lob-s-theorem.md) yields $T\vdash A$. The same argument applies with an already iterated [first-order sentence](first-order-sentence.md) in place of $A$.
