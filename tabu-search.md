# Tabu search

↑ **Parent:** [Heuristic optimization](heuristic-optimization.md)

[Tabu search](tabu-search.md) keeps a short-term memory of recently reversed moves or visited attributes and prohibits them temporarily, reducing cycling in [local search](local-search.md). It can select the best admissible neighbor even when that neighbor worsens the objective; an aspiration rule permits a tabu move when it improves the best known solution. For allocations, transfers and exchanges maintain feasibility and recent reverse transfers can be tabu.
