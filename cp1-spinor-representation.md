# CP1 spinor representation

↑ **Parent:** [Spin coherent-state Berry phase](spin-coherent-state-berry-phase.md)

The CP1 spinor representation writes a unit vector as $n_i=z^\dagger\sigma_i z$ with $z^\dagger z=1$. The phase redundancy $z\mapsto e^{i\alpha}z$ identifies normalized spinors that represent the same point of the [two-sphere](two-sphere.md).
