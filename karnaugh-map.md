# Karnaugh map

↑ **Parent:** [Boolean function](boolean-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Karnaugh_map)

A [truth table](truth-table.md) arranged so neighbouring cells differ in one [Boolean variable](boolean-variable.md), using [Gray code](gray-code.md) order along each multi-[bit](bit.md) axis. Opposite edges are also adjacent. A valid group contains all $2^k$ combinations of $k$ varying variables while every other variable stays fixed; it eliminates those $k$ variables and gives an [implicant](implicant.md); covering the one-cells yields a [disjunctive normal form](disjunctive-normal-form.md). The method is associated with [Maurice Karnaugh](maurice-karnaugh.md).
