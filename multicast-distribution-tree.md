# Multicast distribution tree

↑ **Parent:** [Multicast routing](multicast-routing.md)

A [multicast distribution tree](multicast-distribution-tree.md) describes the parent and outgoing branches used to distribute [packets](network-packet.md) to a group. Source-rooted and shared-group designs make different state and path choices.
