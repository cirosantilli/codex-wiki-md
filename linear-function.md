# Linear function

↑ **Parent:** [Linear map](linear-map.md)

This is a scalar-valued [linear functional](linear-functional.md), so it vanishes at the origin; an affine function with a nonzero constant term is a different notion.

A real linear function on $\mathbb R^n$ has the form $x\mapsto c^Tx$.
