# Hoare domination preorder

↑ **Parent:** [Preorder](preorder.md)

For subsets of a [preorder](preorder.md), Hoare domination means every source element has some greater or equal target element: $S\le_H T\iff\forall s\in S\;\exists t\in T\;(s\le t)$. It is reflexive and transitive. If the base is a [well-quasi-ordering](well-quasi-ordering.md), its finite subsets are [well-quasi-ordered](well-quasi-ordering.md) by this relation; arbitrary subsets need not be, as the [Rado order](rado-order.md) shows.
