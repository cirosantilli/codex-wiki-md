# Combinational logic

↑ **Parent:** [Boolean circuit](boolean-circuit.md)

A [Boolean circuit](boolean-circuit.md) whose current output depends only on its current input, with no stored state or feedback dependency. Its delay is bounded by the longest input-to-output path of [logic gates](logic-gate.md). This differs from a [synchronous sequential circuit](synchronous-sequential-circuit.md), whose output can depend on state stored at earlier [clock edges](clock-edge.md).
