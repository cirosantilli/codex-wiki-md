# Shear layer

↑ **Parent:** [Fluid mechanics](fluid-mechanics-split.md)

A shear layer is a thin region across which the tangential [velocity](velocity.md) changes rapidly. In an inviscid idealization it can collapse to a [vortex sheet](vortex-sheet.md).
