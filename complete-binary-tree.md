# Complete binary tree

↑ **Parent:** [Binary tree](binary-tree.md)

A complete binary tree is a [binary tree](binary-tree.md) whose levels are full except possibly the deepest, which is filled from left to right. A [binary heap](binary-heap.md) uses this shape to maintain logarithmic height. Completeness differs from the two-children condition of a [full binary tree](full-binary-tree.md).
