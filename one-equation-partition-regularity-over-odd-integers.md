# One-equation partition regularity over odd integers

↑ **Parent:** [Rado theorem for one equation](rado-theorem-for-one-equation.md)

A rational homogeneous equation $\sum_i a_ix_i=0$ has a [monochromatic](monochromatic-set.md) positive odd solution in every [finite colouring](finite-coloring.md) of the odd integers exactly when its full coefficient sum is zero. Sufficiency uses a constant odd vector. For necessity, clear denominators and, if the total $S$ is nonzero, colour by odd [residue classes](residue-class.md) modulo $2^K>|S|$. A common odd residue is invertible, so a solution would require $2^K\mid S$, impossible. This is stronger than the zero-sum-subset criterion for unrestricted [partition regularity](partition-regular-matrix.md).
