# Repeated game

↑ **Parent:** [Game theory](game-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Repeated_game)

A [repeated game](repeated-game.md) plays a stage game over several rounds, allowing actions to depend on earlier observations. Its [payoff](payoff.md) convention must specify a finite horizon, a discount factor or a long-time average; these need not have identical invasion properties.
