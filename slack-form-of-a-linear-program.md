# Slack form of a linear program

↑ **Parent:** [Linear programming](linear-programming-split.md)

An equality representation of a [linear program](linear-programming-split.md) in which each [basic variable](basic-variable.md) and the [objective function](objective-function.md) are expressed using [nonbasic variables](nonbasic-variable.md), and all variables are nonnegative. Introducing [slack variables](slack-variable.md) into $Ax\leq b$ gives $s=b-Ax$. Setting the [nonbasic variables](nonbasic-variable.md) to zero yields its [basic solution](basic-solution.md); nonnegative resulting basic values make this a [basic feasible solution](basic-feasible-solution.md). A [simplex algorithm](simplex-algorithm.md) pivot exchanges a basic and nonbasic index and rewrites these expressions.
