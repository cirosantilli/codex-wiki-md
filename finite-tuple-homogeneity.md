# Finite-tuple homogeneity

↑ **Parent:** [Homogeneous model](homogeneous-model.md)

A [first-order structure](first-order-structure.md) has [finite-tuple homogeneity](finite-tuple-homogeneity.md) when any two finite [tuples](finite-tuple.md) of the same parameter-free [complete type](complete-type.md) are related by an automorphism. For countably infinite [first-order structures](first-order-structure.md) this agrees with extension of finite [partial elementary maps](partial-elementary-map.md) to automorphisms. [Countable](countable-set.md) [atomic models](atomic-model.md) have this property by a [back-and-forth method](back-and-forth-method.md) using isolating [logical formulas](logical-formula.md). Uncountable [atomic models](atomic-model.md) can fail it.
