# Normally ordered density correlation

↑ **Parent:** [Normal ordering](normal-ordering.md)

This correlation counts distinct detection events without the delta-function self-counting term in an un-ordered product of densities. It is nonnegative as the expectation of $A^\dagger A$ with $A=\psi_n\cdots\psi_1$. For a single occupied bosonic mode with sharp occupation $N$, the coincident $n$-point value contains the [falling factorial](falling-factorial.md) $N(N-1)\cdots(N-n+1)$, rather than $N^n$.
