# Medial temporal lobe declarative memory system theory

↑ **Parent:** [Declarative memory](declarative-memory.md)

An account in which the [medial temporal lobe](medial-temporal-lobe.md) rapidly establishes and initially binds long-term [declarative memory](declarative-memory.md), with a changing dependence on the region during [systems consolidation](systems-consolidation.md). The original strong restriction of the region to long-term memory must be distinguished from the broader claim that it is important for declarative [learning](learning.md).[1991, anatomical system, binding and time-limited contribution](the-medial-temporal-lobe-memory-system-by-larry-squire-and-others.md)
