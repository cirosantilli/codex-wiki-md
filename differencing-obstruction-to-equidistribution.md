# Differencing obstruction to equidistribution

↑ **Parent:** [Weyl criterion](weyl-criterion.md)

If a circle-valued sequence is not an [equidistributed sequence](equidistributed-sequence.md), some positive-shift difference is not equidistributed either. The contrapositive follows by applying the [Van der Corput inequality for finite scalar sequences](van-der-corput-inequality-for-finite-scalar-sequences.md) to every nonzero integer [exponential sum](exponential-sum.md). Thus cancellation for all fixed nonzero differences implies [equidistribution](equidistributed-sequence.md) of the original sequence.
