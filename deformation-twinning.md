# Deformation twinning

↑ **Parent:** [Martensitic variant](martensitic-variant.md)

[Deformation twinning](deformation-twinning.md) joins differently oriented [crystal](crystal.md) variants across a coherent interface. In a piecewise affine nonlinear [elasticity](elasticity-physics-split.md) model the two [deformation gradients](deformation-gradient.md) must differ by $a\otimes N$, where $N$ is the reference interface [normal](normal-distribution.md). The [Hadamard jump condition](hadamard-jump-condition.md) gives this requirement from [continuity](continuous-function.md) along every interface tangent. Compatible alternating layers can then make a mixture of variants whose macroscopic shape differs from either variant alone.
