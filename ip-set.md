# IP set

↑ **Parent:** [Finite-sums set](finite-sums-set.md)

A subset $A$ of the [positive integers](positive-integer.md) is an IP set if it contains a [finite-sums set](finite-sums-set.md) generated by an infinite sequence of positive integers. Sums use distinct indices, although the generators themselves need not be distinct. An IP set is necessarily infinite, because its successive partial sums are unbounded. The [partition regularity of IP sets](partition-regularity-of-ip-sets.md) is the relative form of the [Hindman theorem](hindman-theorem.md) needed when applying that theorem inside an already specified IP set.
