# Photon fluence

↑ **Parent:** [Fluence](fluence.md)

The number of [photons](photon.md) incident per unit area in a specified geometry. It is distinct from a rate per unit time. For a monoenergetic beam, [photon energy fluence](photon-energy-fluence.md) is $\Psi=E_\gamma\Phi$.
