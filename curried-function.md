# Curried function

↑ **Parent:** [Currying](currying.md)

In [functional programming](functional-programming.md), [currying](currying.md) represents a [function](function-split.md) of several arguments as successive one-argument [functions](function-split.md). In [Haskell](haskell.md), arrows associate to the right: `a -> b -> c` means `a -> (b -> c)`. Supplying an argument of type `a` therefore returns a [function](function-split.md) of type `b -> c`, while a function of type `(a,b) -> c` expects a [tuple](finite-tuple.md). [Uncurrying](uncurrying.md) converts the first representation to the second.
