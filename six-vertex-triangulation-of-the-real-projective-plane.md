# Six-vertex triangulation of the real projective plane

↑ **Parent:** [Real projective plane](real-projective-plane.md)

On vertices $1,\ldots,6$, take the [simplicial complex](simplicial-complex.md) generated by $123,124,135,146,156,236,245,256,345,346$. Every edge occurs in two facets. The vertex links, listed cyclically, are $23564$, $13654$, $12645$, $12536$, $13426$, and $14325$, respectively. Thus each vertex link is a [cycle graph](cycle-graph.md), and the realization is a compact connected [surface](topological-surface-split.md) without boundary. Its [Euler characteristic](euler-characteristic.md) is $6-15+10=1$, so the [classification theorem for surfaces](classification-theorem-for-surfaces.md) identifies it with the [real projective plane](real-projective-plane.md). All fifteen possible edges occur, and the listed triangles are distinct three-element sets, so this is an honest abstract [simplicial complex](simplicial-complex.md), not merely a polygon presentation.
