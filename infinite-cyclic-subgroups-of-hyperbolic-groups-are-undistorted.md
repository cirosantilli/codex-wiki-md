# Infinite cyclic subgroups of hyperbolic groups are undistorted

↑ **Parent:** [Hyperbolic group](hyperbolic-group.md)

If $g$ has infinite order in a [hyperbolic group](hyperbolic-group.md), the map $n\mapsto g^n$ is a [quasi-isometric embedding](quasi-isometric-embedding.md) of the integers. Equivalently $|g^n|\geq c|n|-C$ for some $c>0$. This is the homogeneous quasigeodesic theorem: local-to-global control of [metric geodesics](metric-geodesic.md) in a hyperbolic [Cayley graph](cayley-graph.md) gives a quasigeodesic orbit for a suitable conjugate of a positive power; undoing [conjugation](conjugation.md) and passing between consecutive powers changes only uniform constants. It implies $\tau(g)>0$. The theorem and its hypotheses are given in [Löh, Theorem 6.5.9](https://loeh.app.uni-regensburg.de/teaching/ggt_ss22/lecture_notes.pdf). It is not true for arbitrary finitely generated groups, as the [Baumslag-Solitar group](baumslag-solitar-group.md) relation $ab a^{-1}=b^3$ shows.
