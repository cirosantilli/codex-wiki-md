# Atomic clock

↑ **Parent:** [Twin paradox clock experiments](twin-paradox-clock-experiments.md)  
🏷️ **Tags:** [Atomic physics](atomic-physics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Atomic_clock)

An [atomic clock](atomic-clock.md) uses an atomic transition as a [frequency](frequency.md) reference for an [oscillator](oscillator.md); counting its calibrated cycles realizes a time interval. In a passive beam implementation, the [chemical atoms](atom-physics.md) are repeatedly prepared, interrogated and detected, while [feedback control](closed-loop-control.md) corrects the continuously running [oscillator](oscillator.md). The [Ramsey separated oscillatory fields experiment](ramsey-separated-oscillatory-fields-experiment.md) explains how internal [quantum phase](quantum-phase.md) becomes a measurable population signal.

The [SI](international-system-of-units.md) [second](second.md) fixes the unperturbed [ground state](ground-state.md) [hyperfine structure](hyperfine-structure.md) transition [frequency](frequency.md) of [caesium](caesium.md)-133 to exactly $9\,192\,631\,770\,\mathrm{Hz}$. This is a defining value for the ideal transition, rather than a guarantee that an operating apparatus has no shifts.[SI base unit: second (s), defining paragraph and equivalent duration in periods of the unperturbed caesium-133 ground-state hyperfine transition](si-base-unit-second-s-by-bureau-international-des-poids-et-mesures.md)
