# Integer root

↑ **Parent:** [Root of a polynomial](root-of-a-polynomial.md)

A [polynomial root](root-of-a-polynomial.md) that is an [integer](integer-split.md). For a [polynomial](polynomial-split.md) with [integer](integer-split.md) coefficients and nonzero constant term, any integer root divides that constant term, by the [rational root theorem](rational-root-theorem.md).
