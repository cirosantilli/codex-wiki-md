# Numerical-range endpoint approximate-eigenvalue theorem

↑ **Parent:** [Numerical-range spectral enclosure](numerical-range-spectral-enclosure.md)

For bounded [self-adjoint](self-adjoint-operator.md) $T$, put $B=\beta I-T\geq0$ with $\beta=\sup W(T)$. [Unit vectors](unit-vector.md) with $\langle Bu_n,u_n\rangle\to0$ satisfy $\|Bu_n\|^2\leq\|B\|\langle Bu_n,u_n\rangle$ by positive-form [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md). Thus $\beta$ is an [approximate eigenvalue](approximate-eigenvalue.md). Applying the same argument to $T-\alpha I$ proves the result at $\alpha=\inf W(T)$.
