# RSA cycling attack

↑ **Parent:** [RSA cryptosystem](rsa-cryptosystem.md)

Repeatedly apply the public [RSA cryptosystem](rsa-cryptosystem.md) [encryption](encryption.md) map to a [ciphertext](ciphertext.md). A return to that [ciphertext](ciphertext.md) reveals its preceding iterate as the [plaintext](plaintext.md). A nontrivial [greatest common divisor](greatest-common-divisor.md) between an iterate-minus-start and the modulus instead enables [integer factorization](integer-factorization.md). Eventual return alone supplies no useful running-time bound.
