# Artin-Schreier ordering criterion

↑ **Parent:** [Formally real field](formally-real-field.md)

A [field](field.md) can be ordered compatibly with addition and multiplication if and only if it is a [formally real field](formally-real-field.md). This ordering criterion concerns real algebra, and is different from [Artin–Schreier theory](artin-schreier-theory.md) of cyclic extensions in positive characteristic.
