# Submatrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Submatrix)

A submatrix is obtained from a [matrix](matrix.md) by retaining selected rows and selected columns. A principal submatrix of a square matrix retains the same index set for its rows and columns.
