# Multiplication table

↑ **Parent:** [Multiplication](multiplication.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multiplication_table)

A [multiplication table](multiplication-table.md) lists the [products](product-of-numbers.md) of the factors labeling its rows and columns. Each cell is determined by one [multiplication](multiplication.md); the same arrangement can serve as a [spreadsheet tabular model](spreadsheet-tabular-model.md).
