# SQL NULL

↑ **Parent:** [SQL](sql.md)

SQL's marker for an unknown or absent value. [Database aggregation](database-aggregation.md) generally ignores these markers, and `AVG` returns this marker when there are no non-null inputs.[Section 9.21, general-purpose aggregate functions and empty-input behavior](aggregate-functions-in-the-postgresql-documentation.md)
