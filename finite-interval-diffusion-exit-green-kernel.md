# Finite-interval diffusion exit Green kernel

↑ **Parent:** [Speed density of a one-dimensional diffusion](speed-density-of-a-one-dimensional-diffusion.md)

The expected exit time from $(\ell,r)$ for a one-dimensional diffusion is $\int_\ell^rK(x,v)m(v)dv$ when finite. Differentiating this expression on each side of $v=x$ gives the equation $\mathcal Lu=-1$ with zero endpoint values. For the [SLE two-boundary-point ratio diffusion](sle-two-boundary-point-ratio-diffusion.md), $s(v)-s(1)$ behaves as $(v-1)^{1-4/\kappa}$ and the [speed density](speed-density-of-a-one-dimensional-diffusion.md) behaves as $(v-1)^{4/\kappa}$, so the product is integrable at $1$ for $\kappa>4$.
