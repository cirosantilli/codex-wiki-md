# Basepoint-free divisor

↑ **Parent:** [Complete linear system of a divisor](complete-linear-system-of-a-divisor.md)

A divisor is basepoint-free when its global sections have no common zero. Its complete linear system therefore defines a [Kodaira map](kodaira-map.md) everywhere.
