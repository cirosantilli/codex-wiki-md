# Electron-hydrogen normalization of the cooling function

↑ **Parent:** [Astrophysical cooling function](astrophysical-cooling-function.md)

In an [optically thin](optically-thin-medium.md) [plasma](plasma-physics.md), one convention defines the [radiative cooling](radiative-cooling.md) power per volume by $\mathcal C=n_en_H\Lambda_{eH}(T)$, where $n_H$ counts [hydrogen](hydrogen.md) nuclei. A convention $\mathcal C=n_H^2\Lambda_{HH}$ instead has $\Lambda_{HH}=(n_e/n_H)\Lambda_{eH}$. Thus the tabulated functions differ even for the same [gas](gas.md). With total particle [density](density.md) $n$, a monatomic-gas [radiative gas cooling time](optically-thin-gas-cooling-time.md) is $3nk_BT/(2\mathcal C)$ when heating is negligible.[§8: emission-measure normalization and cooling time](thermal-radiation-processes-by-jelle-s-kaastra-and-others.md)
