# End-to-end principle

↑ **Parent:** [Internet architecture](internet-architecture.md)

When fully implementing a required function needs [endpoint](communication-endpoint.md) information, a lower-layer implementation cannot replace [endpoint](communication-endpoint.md) responsibility. Lower-layer mechanisms can still improve efficiency. The principle concerns function placement, not a requirement for peer-to-peer topology. [Jerome H. Saltzer](jerry-saltzer.md), [David P. Reed](david-p-reed.md) and [David D. Clark](david-d-clark.md) articulated the argument.[Author-hosted reprint, pp. 1–3: the argument and careful file transfer](end-to-end-arguments-in-system-design-by-jerome-h-saltzer-and-others.md)
