# Doubly linked list

↑ **Parent:** [Linked list](linked-list.md)

A [linked list](linked-list.md) whose nodes store predecessor and successor references satisfying reciprocal-link consistency. A known node can be unlinked in constant pointer work without searching for its predecessor. The representation uses extra references and requires both directions to be updated on insertion and deletion.
