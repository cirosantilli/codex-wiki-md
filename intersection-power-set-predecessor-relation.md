# Intersection-power-set predecessor relation

↑ **Parent:** [Well-founded relation](well-founded-relation.md)

This relation has [well-foundedness](well-founded-relation.md) without [Axiom of foundation](axiom-of-regularity.md) or [axiom of choice](axiom-of-choice.md). If a nonempty set $S$ had no minimal member, put $b=\bigcap S$. For each $y\in S$, choose existentially an $x\in S$ with $xRy$. Since $b\subseteq x\cap y$, every subset of $b$ belongs to $y$. Thus $\mathcal P(b)\subseteq b$. But $d=\{u\in b:u\notin u\}$ is then an element of $b$, contradicting $d\in d\iff d\notin d$.
