# Shapley value of an induced subgraph game

↑ **Parent:** [Induced subgraph game](induced-subgraph-game.md)

In a uniformly random player [permutation](permutation.md), edge $\{i,j\}$ contributes $w_{ij}$ to $i$'s [marginal contribution](marginal-contribution.md) exactly when $j$ precedes $i$, which occurs with [probability](probability.md) $1/2$. Sum these expected contributions over incident [graph edges](edge-of-a-graph.md) to obtain the displayed [Shapley value](shapley-value.md). This proof works for arbitrary real edge weights; nonnegativity is not required.
