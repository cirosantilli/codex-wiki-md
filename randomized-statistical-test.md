# Randomized statistical test

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test-split.md)

A [randomized statistical test](randomized-statistical-test.md) specifies a measurable rejection [probability](probability.md) $\phi(x)$ for each possible data value. It can be implemented by rejecting when an independent [uniform random variable](uniform-random-variable.md) $U$ on $(0,1)$ satisfies $U<\phi(x)$. A deterministic test has only the values zero and one. Under a [simple hypothesis](simple-hypothesis.md) $H_j$, its rejection [probability](probability.md) is $\mathbb E_j\phi(X)$, which is its [test size](size-of-a-statistical-test.md) for $j=0$ and its [statistical power](statistical-power.md) for $j=1$.

The [Neyman-Pearson lemma](neyman-pearson-lemma.md) permits randomization on an equality set of the form $f_1(x)=kf_0(x)$ to reach a prescribed [test size](size-of-a-statistical-test.md). Continuous observations do not rule out an equality set of positive [probability](probability.md): if both hypotheses give the same [probability density function](probability-density-function.md), their [likelihood ratio](likelihood-ratio.md) is identically one. This explains why a precise statement of the lemma includes boundary randomization even for continuous data.
