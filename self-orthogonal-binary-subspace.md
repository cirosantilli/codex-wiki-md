# Self-orthogonal binary subspace

↑ **Parent:** [Binary linear code](binary-linear-code.md)

A [linear subspace](vector-subspace.md) $W\subseteq\mathbb F_2^n$ is self-orthogonal if $u\cdot v=0$ for every $u,v\in W$. The standard [bilinear form](bilinear-form.md) is [nondegenerate](nondegenerate-bilinear-form.md), whence $\dim W+\dim W^\perp=n$ and $\dim W\leq\lfloor n/2\rfloor$. The condition with $u=v$ means every vector has even [Hamming weight](hamming-weight.md). Such a [binary linear code](binary-linear-code.md) gives the [linear algebra](linear-algebra-split.md) behind the [Eventown theorem](eventown-theorem.md).
