# Optimal stopping value function

↑ **Parent:** [Optimal stopping](optimal-stopping.md)

For a [Markov process](markov-process-split.md) with reward $f$, the value starting at time $t$ in state $s$ is the supremum of expected rewards over admissible [stopping times](stopping-time.md). In finite discrete time it obeys $V(T,s)=f(s)$ and $V(t,s)=\max\{f(s),PV(t+1,\cdot)(s)\}$ for the [transition operator](transition-operator.md) $P$, wherever expectations are well-defined. Statewise absolute integrability of every remaining-horizon reward makes these values finite.
