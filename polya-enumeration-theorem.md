<h1 id="polya-enumeration-theorem">Pólya enumeration theorem</h1>

↑ **Parent:** [Combinatorics](combinatorics-split.md)

The Pólya enumeration theorem counts colourings up to a finite [group action](group-action-split.md) using the action's [cycle index](cycle-index.md). Substituting colour weights into each cycle variable groups colourings by their colour inventories.
