# Lifshitz point

↑ **Parent:** [Critical phenomenon](critical-phenomenon-split.md)

A multicritical point where disordered, spatially uniform ordered and spatially modulated phases meet. The quadratic stiffness in one or more directions vanishes, so a positive higher-derivative term stabilises the [Landau-Ginzburg theory](landau-ginzburg-theory.md). For a uniaxial case the kernel at the point has $p_\perp^2+p_\parallel^4$, with the coefficient of $p_\parallel^2$ tuned to zero.
