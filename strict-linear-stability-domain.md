# Strict linear stability domain

↑ **Parent:** [Linear stability domain](linear-stability-domain.md)

The strict decay convention for a [linear stability domain](linear-stability-domain.md) demands that every numerical mode tends to zero on the [Dahlquist test equation](dahlquist-test-equation.md). For a one-step [stability function](stability-function.md) it requires $|R(z)|<1$; for a [multistep method](linear-multistep-method.md) it requires every [amplification root](amplification-root.md) to have [modulus](modulus.md) below one. This differs from a boundedness convention that allows simple [unit-circle roots](unit-circle-root.md), and from mesh-uniform finite-time [numerical stability](stability-of-a-numerical-method.md). [Cambridge numerical analysis notes](https://www.damtp.cam.ac.uk/user/na/PartIB/Lect10.pdf) use the decay convention. Explicitly specifying the convention is essential for methods with undamped modes.
