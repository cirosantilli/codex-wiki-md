# Perfect heartbeat-counting score does not establish heartbeat detection

↑ **Parent:** [Heartbeat counting score](heartbeat-counting-score.md)

Two strategies can generate the same observations: a person detects every beat, or a person estimates the count from an expected [heart rate](heart-rate.md) and the interval. Whenever the estimate equals the actual count, both produce $C=N$ and score $1$. The score alone therefore lacks [identifiability](identifiability.md) for the latent detection strategy. This logical counterexample does not say that all high-scoring participants use estimation.
