# Production rule

↑ **Parent:** [Context-free grammar](context-free-grammar.md)

A production rule specifies a permitted replacement during a [grammar derivation](grammar-derivation.md). In a [context-free grammar](context-free-grammar.md) it has the form $A\to\alpha$, with one nonterminal $A$ on the left.
