# Parametric regularity of exchange equilibria

↑ **Parent:** [Regular exchange economy](regular-exchange-economy.md)

If zero is a [regular value](regular-value.md) of the joint smooth [aggregate excess demand](aggregate-excess-demand.md) $Z(p,t)$, almost every parameter gives a [regular economy](regular-exchange-economy.md). The [regular level set theorem](regular-level-set-theorem.md) makes the zero set a manifold. Its projection to parameter space fails to have full rank exactly where the derivative with respect to prices is singular; [Sard theorem](sard-s-theorem.md) makes these exceptional parameter values a [null set](null-set.md).
