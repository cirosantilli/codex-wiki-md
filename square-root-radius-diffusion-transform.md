# Square-root-radius diffusion transform

↑ **Parent:** [Keplerian viscous diffusion equation](keplerian-viscous-diffusion-equation.md)

For a steady zero-mass-flux background and constant [viscous transport response exponent](viscous-transport-response-exponent.md), this change removes the first derivative in the radial diffusion operator. If $\Sigma_0\propto r^{-p}$, the [kinematic viscosity](kinematic-viscosity.md) scales as $r^{p-1/2}$, so the transformed diffusivity scales as $x^{2p-3}$. It is constant at $p=3/2$.
