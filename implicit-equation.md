# Implicit equation

↑ **Parent:** [Equation](equation.md)

An [implicit equation](implicit-equation.md) specifies a relation between variables without isolating a designated output as an explicit [function](function-split.md) of the inputs. For example, $x^2+y^2=1$ specifies a [circle](circle.md). On $-1<x<1$, it determines the two real branches $y=\pm\sqrt{1-x^2}$, each an [implicit function](implicit-function.md) when one branch is selected. The [implicit function theorem](implicit-function-theorem.md) gives local conditions for a unique differentiable branch; [implicit differentiation](implicit-differentiation.md) computes its [derivative](derivative.md) without first solving explicitly.
