# Coupled inductors

↑ **Parent:** [Mutual inductance](mutual-inductance.md)

[Coupled inductors](coupled-inductors.md) are [inductors](inductor.md) whose [magnetic flux linkages](magnetic-flux-linkage.md) depend on each other's [electric currents](electric-current.md). A two-circuit linear model uses two [self-inductances](self-inductance.md) and a [mutual inductance](mutual-inductance.md).
