# Smectic C phase

↑ **Parent:** [Smectic phase](smectic-phase.md)

A smectic C phase has layered positional order with the [nematic director](nematic-director.md) tilted away from the layer normal. The tilt supplies additional orientational information beyond the density modulation of a [smectic phase](smectic-phase.md).
