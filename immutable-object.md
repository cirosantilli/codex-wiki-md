# Immutable object

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

An immutable object does not change its observable state after construction. Immutable fields prevent reassignment of their stored values, but fields containing references to mutable [software objects](software-object.md) do not automatically make the reachable [software object](software-object.md) graph immutable. Read-only generic producers can often support covariant [type parameters](type-parameter.md); publicly writable fields generally cannot.
