# Edge weight

↑ **Parent:** [Graph](graph-split.md)

The numerical label assigned to an [edge](edge-of-a-graph.md) $e$ of a [graph](graph-split.md). An [edge weight](edge-weight.md) can be negative when the model allows it. It is distinct from the [vertex degree](degree-graph-theory.md), which counts incident [edges](edge-of-a-graph.md).
