# Feature map

↑ **Parent:** [Positive-semidefinite kernel](positive-semidefinite-kernel-split.md)

A feature map sends $x$ to a vector $\phi(x)$ in a vector space with an [inner product](inner-product-split.md) so that $k(x,y)=\langle\phi(x),\phi(y)\rangle$.
