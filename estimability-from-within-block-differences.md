# Estimability from within-block differences

↑ **Parent:** [Blocks in experimental design](blocks-in-experimental-design.md)

For a [linear regression](linear-regression-split.md) model $Y_{bj}=\alpha_b+f(x_{bj})^T\beta+\epsilon_{bj}$ with one unrestricted [intercept](regression-intercept.md) per two-run [experimental block](blocks-in-experimental-design.md), differencing the responses removes all [experimental block](blocks-in-experimental-design.md) effects. The parameter vector $\beta$ is identifiable precisely when the [matrix](matrix.md) whose rows are $f(x_{b1})-f(x_{b2})$ has full column [rank](rank-one-quadratic-form.md). This criterion applies to arbitrary pairings, including nonregular [factorial designs](factorial-design.md); requiring regular [orthogonal](orthogonal-vectors.md) confounding is a stronger constraint.
