# Spindle position checkpoint

↑ **Parent:** [Cell cycle](cell-cycle-split.md)

A surveillance mechanism that restrains mitotic exit when the budding-yeast spindle is mispositioned. It is distinct from kinetochore-attachment surveillance by the [spindle checkpoint](spindle-checkpoint.md).
