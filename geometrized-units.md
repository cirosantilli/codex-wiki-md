# Geometrized units

↑ **Parent:** [General relativity](general-relativity-split.md)

[Geometrized units](geometrized-units.md) set $G=c=1$, allowing [mass](mass.md), length, and time to be expressed in common units. Restore $GM/c^2$ for a mass parameter in a radial [metric tensor](metric-tensor.md).
