# Auxiliary hypothesis

↑ **Parent:** [Scientific confirmation](scientific-confirmation.md)

An assumption used with a target scientific hypothesis to obtain a prediction, for example an apparatus calibration or an initial condition. Independent evidence for an [auxiliary hypothesis](auxiliary-hypothesis.md) helps distinguish a failure of the target from a failure of the test setup.
