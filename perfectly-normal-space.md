# Perfectly normal space

↑ **Parent:** [Normal space](normal-space.md)

A [T1 space](t1-space.md) is perfectly normal when it is normal and every closed subset is a [G-delta set](g-delta-set.md). Equivalently every closed subset is the [zero set of a continuous function](zero-set-of-a-continuous-function.md) into $[0,1]$, using the [closed G-delta set as a zero set](closed-g-delta-set-as-a-zero-set.md) theorem. If disjoint closed sets are the exact zero sets of $f,g$, then $f/(f+g)$ has those sets as its exact zero and one levels. Every subspace is normal, although the converse fails.
