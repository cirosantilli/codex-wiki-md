# Matrix with orthonormal columns

↑ **Parent:** [Orthonormal set](orthonormal-set.md)

A real $m\times k$ matrix whose columns are an [orthonormal set](orthonormal-set.md), equivalently $Q^TQ=I_k$. In the complex case use the [conjugate transpose](conjugate-transpose.md) instead. This requires $k\leq m$; only in the square case does the transpose also provide a two-sided inverse, making $Q$ an [orthogonal matrix](orthogonal-matrix.md).
