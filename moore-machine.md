# Moore machine

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A [Moore machine](moore-machine.md) is a [finite-state machine](finite-state-machine.md) whose output depends only on the current state. In a clocked implementation, a state entered at a [clock edge](clock-edge.md) determines the following period's output. Specifying an initial state is necessary to define startup behavior.
