# Quadratic program

↑ **Parent:** [Quadratic optimization](quadratic-optimization.md)

A [quadratic program](quadratic-program.md) is an optimization problem with a quadratic objective and linear equality or inequality constraints. A positive-definite objective Hessian makes it [strictly convex](strictly-convex-function.md) and coercive; on a nonempty closed feasible set its minimizer exists and is unique. Such a program resolves tied Lasso knots by constraining tangent signs of currently zero [regression coefficients](regression-coefficient.md) while allowing unrestricted tangents for nonzero ones.
