# Abstract factory pattern

↑ **Parent:** [Creational pattern](creational-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Abstract_factory_pattern)

Provide an interface for creating a family of related products while hiding their concrete [software classes](class-programming.md). Unlike a single [factory method pattern](factory-method-pattern.md) operation returning one product abstraction, an abstract factory typically exposes several related product-creation operations whose implementations coordinate a consistent family.
