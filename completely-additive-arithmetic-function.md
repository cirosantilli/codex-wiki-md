# Completely additive arithmetic function

↑ **Parent:** [Additive function (number theory)](additive-function-number-theory.md)

A [completely additive arithmetic function](completely-additive-arithmetic-function.md) satisfies $f(mn)=f(m)+f(n)$ for all positive $m,n$, equivalently $f(p^k)=k f(p)$. The [total number of prime factors](total-number-of-prime-factors.md) is an example.
