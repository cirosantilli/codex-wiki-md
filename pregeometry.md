# Pregeometry

↑ **Parent:** [Model-theoretic algebraic closure](model-theoretic-algebraic-closure.md)

A [pregeometry](pregeometry.md) is a finitary closure structure with the exchange axiom, extending the closure description of a [matroid](matroid.md) to possibly infinite underlying sets. A pregeometry is a closure operator with finite character and exchange. Algebraic closure in a strongly minimal theory is a pregeometry.
