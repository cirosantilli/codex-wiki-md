# Postfix code

↑ **Parent:** [Stack machine](stack-machine.md)

Code whose operand-producing instructions precede the instruction that consumes those operands. A [stack machine](stack-machine.md) can translate a binary [program expression](program-expression.md) by producing its left operand, producing its right operand, and then applying the operation to the two top values.
