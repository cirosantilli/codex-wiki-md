# Set-valued mapping

↑ **Parent:** [Set-valued analysis](set-valued-analysis.md)

A mapping $S:X\rightrightarrows Y$ assigns a subset $S(u)\subset Y$ to each $u$. Empty and multiple values are allowed. The [graph of a set-valued mapping](graph-of-a-set-valued-mapping.md) records the relation as a subset of $X\times Y$.
