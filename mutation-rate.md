# Mutation rate

↑ **Parent:** [Mutation](mutation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Mutation_rate)

A mutation rate measures the frequency of [mutation](mutation.md) events per specified unit, such as per chromosome segment per generation. Its units and the population-size convention must be specified. If time is measured in $N$ generations and $\theta=2Nu$, each ancestral lineage has mutation intensity $Nu=\theta/2$ per unit of coalescent time.
