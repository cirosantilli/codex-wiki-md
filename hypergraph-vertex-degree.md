# Hypergraph vertex degree

↑ **Parent:** [Hypergraph](hypergraph-split.md)

The degree of a vertex $u$ in a [hypergraph](hypergraph-split.md) is the number of hyperedges containing $u$. For a [uniform hypergraph](uniform-hypergraph.md), summing degrees counts each hyperedge once for each of its vertices, so $\sum_u d_H(u)=r e(H)$. In a [multihypergraph](multihypergraph.md), incidences are counted with multiplicity.
