# Fixed-illumination grating peak change with slit width

↑ **Parent:** [Diffraction grating](diffraction-grating.md)

For a uniformly illuminated grating of $N$ identical slits, width $w$ and pitch $p$, the amplitude is a [single-slit diffraction](single-slit-diffraction.md) factor times the coherent array sum. At integer order $m$, the array amplitude is $N$, giving the displayed peak [intensity](intensity-physics.md) at fixed incoming [intensity](intensity-physics.md). Changing $w$ can increase the central [intensity](intensity-physics.md) while suppressing a higher order through its envelope. Renormalizing both patterns to unit central [intensity](intensity-physics.md) removes the information needed for that comparison.
