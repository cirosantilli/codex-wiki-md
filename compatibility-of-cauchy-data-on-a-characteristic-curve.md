# Compatibility of Cauchy data on a characteristic curve

↑ **Parent:** [Cauchy problem](cauchy-problem.md)

For the canonical [hyperbolic partial differential equation](hyperbolic-partial-differential-equation.md) $V_{\xi\eta}=0$, every solution is $V=g(\xi)+h(\eta)$. Data on the characteristic $\eta=\eta_0$ determine $g$ up to an additive constant, but only determine $h$ at one point. If a transverse derivative is also prescribed, it must satisfy $V_\eta(\xi,\eta_0)=h'(\eta_0)$, independent of $\xi$. A varying prescribed value is incompatible; a constant compatible value still leaves the rest of $h$ arbitrary. Thus characteristic [Cauchy data](cauchy-data.md) can produce nonexistence or nonuniqueness. A derivative in original coordinates must first be transformed by the [chain rule](chain-rule.md) before applying this compatibility test.
