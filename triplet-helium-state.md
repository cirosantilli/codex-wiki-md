# Triplet helium state

↑ **Parent:** [Helium atom](helium-atom.md)

A [helium atom](helium-atom.md) electronic state with total [spin](spin.md) one. Its symmetric [spin](spin.md) function requires an antisymmetric spatial [wavefunction](wave-function-split.md), excluding two [electrons](electron.md) in the same spatial orbital. The three [spin](spin.md) projections are magnetic substates of the same [spin](spin.md) multiplet, not three separately distinguishable particles.
