# Neutron flux

↑ **Parent:** [Neutron activation](neutron-activation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Neutron_flux)

Let $n(E)\,dE$ be the number of [neutrons](neutron-split.md) per unit volume in an [energy](energy-split.md) interval. The scalar [neutron flux](neutron-flux.md) per unit [energy](energy-split.md) is $\phi(E)=v(E)n(E)$, with $v(E)$ the [speed](speed.md). Its integral has units of inverse area per unit [time](time-in-physics.md). It counts path length traversed per volume per [time](time-in-physics.md), including all directions; it is not the signed current through an oriented surface.

For a small uniform specimen containing $N_T$ target [atomic nuclei](atomic-nucleus-split.md), a reaction-specific [collision cross-section](collision-cross-section.md) $\sigma_a(E)$ gives the expected production rate

$$
R=N_T\int_0^\infty\sigma_a(E)\phi(E)\,dE.
$$

Assume the incident field is little changed within the specimen, target depletion is negligible and each counted reaction creates the product of interest. If that product has a production branching fraction below one, include it in $\sigma_a$ or as an additional factor. A single [neutron activation](neutron-activation.md) measurement supplies one weighted integral of an [energy](energy-split.md) distribution, not a unique reconstruction of that distribution.

For an original two-group example, stipulate response [collision cross-sections](collision-cross-section.md) $\sigma_s=10\sigma_f$. With the same total scalar [neutron flux](neutron-flux.md) $\Phi$, changing from all fast [neutrons](neutron-split.md) to half slow and half fast changes $R/(N_T\sigma_f\Phi)$ from $1$ to $5.5$. No additional [neutrons](neutron-split.md) need be emitted by the source. The chosen factor ten is not a historical [silver](silver.md) measurement.

For some capture reactions over a limited low-[energy](energy-split.md) interval, $\sigma_a\propto1/v$ is a useful approximation. At fixed [neutron flux](neutron-flux.md), it gives increasing reaction probability per path length as [speed](speed.md) decreases. At fixed [neutron](neutron-split.md) number density, $\sigma_a v$ is constant in this approximation, so the rate per target is unchanged. A real [neutron moderator](neutron-moderator.md) changes the local density, [energy](energy-split.md) distribution, escape and absorption together. Neither all [collision cross-sections](collision-cross-section.md) nor all [neutron activation](neutron-activation.md) rates vary monotonically as $1/v$.
