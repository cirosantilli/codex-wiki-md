# Faithfulness of a directed acyclic graph

↑ **Parent:** [Causal directed acyclic graph](causal-directed-acyclic-graph.md)

A distribution is faithful to a [Directed acyclic graph](directed-acyclic-graph.md) when, for all disjoint vertex sets $A,B,S$, $Z_A\perp Z_B\mid Z_S$ holds if and only if $A$ and $B$ are [D-separated](d-separation.md) by $S$. This includes the graph's [global Markov property of a directed acyclic graph](global-markov-property-of-a-directed-acyclic-graph.md) and excludes additional independences caused by parameter cancellations. If faithfulness is used to name only the reverse implication, the Markov property must be assumed separately.
