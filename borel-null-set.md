# Borel null set

↑ **Parent:** [Null set](null-set.md)

A [Borel set](borel-set.md) of [Lebesgue measure](lebesgue-measure.md) zero. Every Lebesgue-null [set](set-split.md) is contained in a Borel [null set](null-set.md), by outer regularity; consequently testing all [Borel null sets](borel-null-set.md) suffices in the definition of a [Sierpiński set](sierpinski-set.md).
