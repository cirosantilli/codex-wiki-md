# Dislocation core

↑ **Parent:** [Dislocation](dislocation.md)

The [dislocation core](dislocation-core.md) is the small region near a [dislocation](dislocation.md) line where the smooth linear-elastic continuum description fails. For a [screw dislocation](screw-dislocation.md), the far-field [displacement](displacement.md) [gradient](gradient.md) scales as the Burgers-vector magnitude divided by radial distance, so the predicted elastic [stress](stress.md) diverges on the axis. Atomic structure, nonlinear response or local [plastic deformation](plastic-deformation.md) replaces that singular prediction in the core.
