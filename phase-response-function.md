# Phase response function

↑ **Parent:** [Phase reduction](phase-reduction.md)

A periodic [phase response function](phase-response-function.md) describes the first-order phase shift produced by a perturbation along a [limit cycle](limit-cycle.md). With period-one orbit $U$, choose the periodic adjoint solution normalized by $\int_0^1Y\cdot U'\,ds=1$. The [Fredholm solvability condition](fredholm-solvability-condition.md) then projects forcing $p$ to $\int_0^1Y\cdot p\,ds$. For voltage-difference coupling, the averaged interaction is $h(\phi)=\int_0^1Y^1(s)U^1(s+\phi)\,ds$.
