# Nodewise regression

↑ **Parent:** [Conditional independence graph](conditional-independence-graph.md)

Fit the conditional law of each variable given all others and use its predictor support to estimate its neighbours. In a [Gaussian graphical model](gaussian-graphical-model.md), this is linear regression with coefficients given by [conditional regression coefficients from a Gaussian precision matrix](conditional-regression-coefficients-from-a-gaussian-precision-matrix.md). The [Nodewise Lasso](nodewise-lasso.md) supplies sparse fits; the [OR rule for nodewise graph selection](or-rule-for-nodewise-graph-selection.md) and [AND rule for nodewise graph selection](and-rule-for-nodewise-graph-selection.md) combine possibly disagreeing directional supports into an undirected graph.
