# Vanishing of infinitely divisible integer sequences

↑ **Parent:** [Module theory](module-theory-split.md)

If an element $w$ of the [module](module-mathematics.md) $\prod_{j\in J}\mathbb Z$ is divisible by every power of two within that [module](module-mathematics.md), then every coordinate $w(j)$ is an [integer](integer-split.md) divisible by every power of two. A nonzero [integer](integer-split.md) $a$ cannot be divisible by $2^i>|a|$, so each coordinate is zero and $w=0$. This argument applies to any index set $J$ and to powers of any fixed integer $b$ with $|b|>1$.
