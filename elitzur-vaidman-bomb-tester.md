# Elitzur-Vaidman bomb tester

↑ **Parent:** [Quantum measurement](quantum-measurement-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Elitzur–Vaidman_bomb_tester)

A [photon](photon.md) in a [quantum superposition](quantum-superposition.md) of a safe path and an absorbing path can sometimes certify a live absorber without being absorbed. Recombination is chosen so that one output is impossible if the absorber is absent. A detection at that output is then an unambiguous successful test. The measurement back-action of a surviving live-absorber trial changes the interference pattern.

In 1993, [Avshalom Elitzur](avshalom-elitzur.md) and [Lev Vaidman](lev-vaidman.md) asked how to identify a working bomb whose sensor would be triggered by even one [photon](photon.md). Their theoretical proposal places the sensor in one arm of a [Mach-Zehnder interferometer](mach-zehnder-interferometer.md), adjusted so that [destructive interference](destructive-interference.md) keeps one detector dark when both arms are unobstructed. A click there can identify a working bomb while leaving it unexploded. The motivation is to obtain information about a fragile object without destroying it; the bomb makes that operational claim explicit without committing to an interpretation of [quantum mechanics](quantum-mechanics-split.md).[1993 author preprint, §4 “How to test a bomb without exploding it?”, pp. 8–9; interferometer setup in §1, p. 3](quantum-mechanical-interaction-free-measurements-by-avshalom-c-elitzur-and-lev-vaidman.md)
