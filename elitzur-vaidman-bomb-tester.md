# Elitzur-Vaidman bomb tester

↑ **Parent:** [Measurement in quantum mechanics](quantum-measurement-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Elitzur–Vaidman_bomb_tester)

A [photon](photon.md) in a [quantum superposition](quantum-superposition.md) of a safe path and an absorbing path can sometimes certify a live absorber without being absorbed. Recombination is chosen so that one output is impossible if the absorber is absent. A detection at that output is then an unambiguous successful test. The measurement back-action of a surviving live-absorber trial changes the interference pattern.
