# Backscattering coefficient

↑ **Parent:** [Ocean colour](ocean-colour.md)

The rate per unit path length at which light is scattered into the backward hemisphere. It influences water-leaving [radiance](radiance.md) and must be distinguished from the [absorption coefficient](absorption-coefficient.md).
