# Orbital position

↑ **Parent:** [Orbit (dynamical system)](orbit-dynamical-system.md)

A body's [position](position.md) along its [orbit](orbit-dynamical-system.md), specified relative to a stated origin and time. Knowing only the shape and size of an [orbit](orbit-dynamical-system.md) does not specify where the body lies on it: an initial orbital phase or timing condition is also needed. A rendezvous requires matching [orbital positions](orbital-position.md) at the same time as well as matching [velocities](velocity.md).
