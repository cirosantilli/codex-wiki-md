# Small projective object

↑ **Parent:** [Category](category-split.md)

An object with the displayed property is called small projective; the term 0-presentable here uses this all-small-colimits convention. In a [presheaf category](presheaf-category.md), every [representable presheaf](representable-functor.md) has this property by the [Yoneda lemma](yoneda-lemma.md) and pointwise computation of [colimits](colimit.md). Conversely the [canonical colimit presentation of a presheaf](canonical-colimit-presentation-of-a-presheaf.md) shows that the identity on such an object factors through one representable, making it a retract. If the indexing category has [equalizers](equaliser.md), a representable retract is again representable by the [representable retract criterion](representable-retract-criterion.md).
