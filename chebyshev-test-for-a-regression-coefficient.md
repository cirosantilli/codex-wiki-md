# Chebyshev test for a regression coefficient

↑ **Parent:** [Chebyshev's inequality](chebyshev-s-inequality.md)

An unbiased coefficient [estimator](estimator.md) with known [variance](variance-split.md) $v$ gives a conservative level-$\alpha$ test of a zero coefficient by rejecting when its absolute value is at least $\sqrt{v/\alpha}$. [Chebyshev's inequality](chebyshev-s-inequality.md) bounds the null rejection [probability](probability.md) by $\alpha$. This test needs the [variance](variance-split.md) assumptions but no [Gaussian error](gaussian-error.md) distribution; a normal-reference test requires additional distributional justification.
