# Electronic partition function

↑ **Parent:** [Canonical partition function](canonical-partition-function.md)

The [electronic partition function](electronic-partition-function.md) includes electronic excitation energies and degeneracies $g_i$. If only an exactly degenerate ground manifold of size $g$ is populated, $q_{\rm el}=g$ and its molar [entropy](entropy-split.md) is $R\log g$. Resolved splittings require a state sum rather than replacing all components by one degeneracy.
