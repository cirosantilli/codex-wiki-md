# Inverse totient problem

↑ **Parent:** [Euler totient function](euler-totient-function.md)

Given a [positive integer](positive-integer.md) $m$, find all [positive integers](positive-integer.md) $n$ satisfying $\varphi(n)=m$. For every [prime divisor](prime-factor.md) $p$ of a solution, $p-1$ divides $m$, so the possible [primes](prime-number-split.md) lie in the finite set $\{d+1:d\mid m,\ d+1\text{ is prime}\}$. Search can then combine the [prime powers](prime-power.md) whose totient contributions multiply to $m$.
