# Weakly Mahlo cardinal

↑ **Parent:** [Weakly inaccessible cardinal](weakly-inaccessible-cardinal.md)

A [weakly inaccessible cardinal](weakly-inaccessible-cardinal.md) $\kappa$ is weakly Mahlo if $\{\alpha<\kappa:\alpha=\operatorname{cf}(\alpha)\}$ is a [stationary set](stationary-set.md). Intersecting this set with the [club set](club-set.md) of uncountable [limit cardinals](limit-cardinal.md) shows that the weakly inaccessible cardinals below $\kappa$ are stationary, hence unbounded.
