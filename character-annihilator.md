# Character annihilator

↑ **Parent:** [Additive character](additive-character.md)

For a nontrivial [additive character](additive-character.md) $\psi$ on a [local field](local-field.md), the character annihilator of an additive subgroup $H$ is $H^\perp=\{y:\psi(xy)=1\text{ for all }x\in H\}$. If $\mathcal O_F^\perp=\pi^c\mathcal O_F$, then $(\pi^n\mathcal O_F)^\perp=\pi^{c-n}\mathcal O_F$. This is a character pairing construction, distinct from the [annihilator](annihilator-ring-theory.md) of a module.
