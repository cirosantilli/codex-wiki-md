# Eta c meson

↑ **Parent:** [Quarkonium](quarkonium.md)

The ground-state [pseudoscalar meson](pseudoscalar-meson.md) with [quark model](quark-model.md) content $c\bar c$ is denoted $\eta_c(1S)$. It is a hidden-charm [quarkonium](quarkonium.md) state, with zero net charm, rather than an open-charm [D meson](d-meson.md).
