# Conjugacy class splitting in a prime-index normal subgroup

↑ **Parent:** [Conjugacy class](conjugacy-class.md)

If $N\trianglelefteq G$ has prime index $p$, a [conjugacy class](conjugacy-class.md) of $G$ lying in $N$ splits into one or $p$ [conjugacy classes](conjugacy-class.md) of $N$. [Conjugation](conjugation.md) by $G$ acts transitively on these smaller classes, while $N$ fixes every one. This factors through $G/N$, and the [orbit-stabilizer theorem](orbit-stabilizer-theorem.md) makes the number of classes a divisor of $p$.
