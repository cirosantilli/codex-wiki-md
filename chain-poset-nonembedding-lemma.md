# Chain-poset nonembedding lemma

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

If $\operatorname{Ch}(P)$ is the inclusion-ordered collection of every [chain in a partial order](chain-in-a-partial-order.md), including the empty chain, it has no [order-preserving](order-preserving-function.md) injection into $P$. Supposing $j$ exists, recursively set $p_\alpha=j(\{p_\beta:\beta<\alpha\})$ for $\alpha<h(P)$. By induction the earlier values form a chain; its proper initial chains are distinct, so monotonicity and injectivity make $p_\alpha$ strictly greater than every earlier value. This would inject the [Hartogs ordinal](hartogs-number.md) into $P$.
