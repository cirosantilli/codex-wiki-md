# Null pointer

↑ **Parent:** [Pointer (computer programming)](pointer-computer-programming.md)

A [null pointer](null-pointer.md) is a distinguished [pointer](pointer-computer-programming.md) value that designates no object or function. Pointer-linked [binary trees](binary-tree.md) commonly use it to represent an absent child. Dereferencing it is invalid; its representation is target dependent, although [AAPCS32](aapcs32.md) specifies an all-zero null representation.
