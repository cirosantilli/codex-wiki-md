# Approximable operator

↑ **Parent:** [Continuous linear operator](continuous-linear-operator.md)

A bounded [linear operator](linear-operator.md) between normed spaces is approximable if it is an [operator norm](operator-norm.md) limit of bounded [finite-rank operators](finite-rank-operator.md). If the target is a [Banach space](banach-space-split.md), every approximable operator is a [compact operator](compact-operator-split.md). For a given tolerance, approximate the operator in [norm](norm.md) by one [finite-rank operator](finite-rank-operator.md), cover that operator's bounded unit-ball image by finitely many small balls in its finite-dimensional range, and transfer the cover across the operator-norm error. This makes the original image [totally bounded](totally-bounded-space.md); its [closure](closure-topology.md) is [complete](completeness.md) in the Banach target and therefore [compact](compact-space.md). The converse on arbitrary [Banach spaces](banach-space-split.md) would require an additional approximation hypothesis and is not part of this assertion.
