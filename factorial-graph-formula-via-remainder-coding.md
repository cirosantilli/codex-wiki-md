# Factorial graph formula via remainder coding

↑ **Parent:** [Gödel beta-function sequence coding](godel-beta-function-sequence-coding.md)

The graph of the [factorial](factorial.md) function has a fixed-length [first-order formula](first-order-formula.md) in the [language of ordered rings](language-of-ordered-rings.md) interpreted on the [natural numbers](natural-number.md). A remainder code records $a_0=1$, $a_n=y$, and $a_{i+1}=(i+1)a_i$ for every $i<n$. Uniqueness of remainders proves $y=n!$; sufficiently large pairwise-coprime moduli and the [Chinese remainder theorem](chinese-remainder-theorem.md) supply a code for every input. Formula length is independent of the input variable's value, although substituting a numeral adds its encoding length.
