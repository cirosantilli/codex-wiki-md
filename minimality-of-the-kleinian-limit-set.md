# Minimality of the Kleinian limit set

↑ **Parent:** [Limit set of a Kleinian group](limit-set-of-a-kleinian-group.md)

Every nonempty closed boundary subset invariant under a [non-elementary Kleinian group](non-elementary-kleinian-group.md) contains the [Kleinian limit set](limit-set-of-a-kleinian-group.md). Such a subset cannot be a singleton. Its hyperbolic convex hull contains an interior point, whose orbit lies in the hull; in the Klein ball model the boundary of this hull is contained in the original closed boundary subset.
