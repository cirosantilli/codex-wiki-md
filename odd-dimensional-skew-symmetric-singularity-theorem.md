# Odd-dimensional skew-symmetric singularity theorem

↑ **Parent:** [Skew-symmetric matrix](skew-symmetric-matrix.md)

An [odd integer](odd-integer.md) number of rows and columns forces a real [skew-symmetric matrix](skew-symmetric-matrix.md) to be a [singular matrix](singular-matrix.md). The [determinant](determinant.md) satisfies $\det A=\det A^\top=\det(-A)=(-1)^n\det A=-\det A$, so it is zero. The argument also works over any [field](field.md) of [characteristic](characteristic-of-a-field.md) different from two.
