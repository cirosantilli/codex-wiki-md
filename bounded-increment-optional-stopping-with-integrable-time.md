# Bounded-increment optional stopping with integrable time

↑ **Parent:** [Optional sampling theorem for a supermartingale](optional-sampling-theorem-for-a-supermartingale.md)

For an integrable [supermartingale](supermartingale.md) with the displayed increment bound, $|X_{T\wedge n}|\le|X_0|+KT$. Thus the stopped values are dominated by one [integrable random variable](integrable-random-variable.md), including $X_T$. Apply [optional stopping](optional-sampling-theorem-for-a-supermartingale.md) at the bounded times $T\wedge n$ and then the [dominated convergence theorem](dominated-convergence-theorem.md). For a [martingale](martingale-split.md) the same proof gives equality.
