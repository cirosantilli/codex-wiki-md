# Isoperimetric number of a graph

↑ **Parent:** [Edge boundary in a graph](edge-boundary-in-a-graph.md)

For a finite [graph](graph-split.md) with at least two [vertices](vertex-graph-theory.md), the displayed minimum measures the fewest outgoing [edges](edge-of-a-graph.md) per vertex in a nonempty set occupying at most half the [graph](graph-split.md). It uses the [edge boundary](edge-boundary-in-a-graph.md), rather than the [external vertex boundary](external-vertex-boundary.md). For the [hypercube graph](hypercube-graph.md) $Q_n$, $n\ge1$, it equals one: edge-isoperimetry gives the lower bound and a coordinate half-cube attains it.
