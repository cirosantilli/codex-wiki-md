# Odd-order groups have no nontrivial real irreducible characters

↑ **Parent:** [Irreducible character](irreducible-character.md)

For a real-valued [irreducible character](irreducible-character.md) of a finite odd-order group, pairing $g$ with $g^{-1}$ gives $\langle\chi,1_G\rangle=(\chi(1)+2A)/|G|$, with $A$ an [algebraic integer](algebraic-integer.md). If this inner product were zero, $\chi(1)$ would be even, since a rational [algebraic integer](algebraic-integer.md) is an integer. But an [irreducible character degree divides the group order](irreducible-character-degree-divides-the-group-order.md), so it is odd. Therefore the character is trivial.
