# Projection map

↑ **Parent:** [Projection (mathematics)](projection-mathematics.md)

A projection map from a Cartesian product selects specified coordinates, for example $p_j:\prod_iX_i\to X_j$ with $p_j((x_i)_i)=x_j$.
