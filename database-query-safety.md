# Database query safety

↑ **Parent:** [Domain relational calculus](domain-relational-calculus.md)

The requirement that a [database query](database-query.md) have a finite, appropriately range-restricted answer on finite input. In the usual domain-independent interpretation, extending the ambient value domain with unused values must not change the answer. The absence of a negation symbol alone does not ensure safety.
