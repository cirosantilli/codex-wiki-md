# Gumbel auxiliary function

↑ **Parent:** [Gumbel distribution](gumbel-distribution.md)

A positive [Gumbel auxiliary function](gumbel-auxiliary-function.md) makes $\overline F(t+a(t)x)/\overline F(t)\to e^{-x}$ as $t$ approaches the [right endpoint of a distribution](right-endpoint-of-a-distribution.md), for every real $x$. Under the [Von Mises conditions for extreme values](von-mises-conditions-for-extreme-values.md), the reciprocal [hazard function](hazard-function.md) is a valid choice.
