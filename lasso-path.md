# Lasso path

↑ **Parent:** [Path in a transition system](path-in-a-transition-system.md)

An infinite [path in a transition system](path-in-a-transition-system.md) represented by a finite prefix followed by infinite repetition of a nonempty finite loop. If stored positions are $q_0,\ldots,q_k$ and $q_k\to q_\ell$, the represented [sequence](sequence.md) is $q_0\cdots q_{\ell-1}(q_\ell\cdots q_k)^\omega$. The [linear temporal logic](linear-temporal-logic.md) condition $GFp$ holds exactly when $p$ occurs on the repeated part, and $FGp$ holds exactly when $p$ holds everywhere on that part.
