# Finite probability pushforward

↑ **Parent:** [Pushforward measure](pushforward-measure.md)

Map a [finite probability distribution](finite-probability-distribution.md) through a [function](function-split.md) by summing the masses of source atoms with the same image. The image of the finite support is finite, and fibres partition the original support, so summing the output masses gives the original total one. Non-injective images require [addition](addition.md), not overwriting. A computational snapshot can evaluate each source image once and answer later mass queries by summing matching entries.
