# Fractional event imputation

↑ **Parent:** [Kaplan–Meier estimator](kaplan-meier-estimator.md)

If a censored individual is allocated event weights $q_j$ over later event times, its event-count contribution at time $t_j$ is $q_j$ and its [risk set](risk-set.md) contribution is $\sum_{k\ge j}q_k$. These fractional counts can be used in the [Kaplan–Meier estimator](kaplan-meier-estimator.md).
