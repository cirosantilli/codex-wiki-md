# Coordinate duplication for combinatorial lines

↑ **Parent:** [Combinatorial line](combinatorial-line.md)

Repeat every coordinate of a word $q$ times. A [combinatorial line](combinatorial-line.md) maps to a [combinatorial line](combinatorial-line.md) whose active-set size is multiplied by $q$. Pulling back a [finite coloring](finite-coloring.md) along this map and using the [Hales-Jewett theorem](hales-jewett-theorem.md) forces [monochromatic](monochromatic-set.md) lines with active-set size divisible by any prescribed positive integer $q$.
