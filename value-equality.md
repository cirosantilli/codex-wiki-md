# Value equality

↑ **Parent:** [Software object](software-object.md)

Equality according to the abstract content a [software class](class-programming.md) exposes, rather than [object identity](object-identity.md). Distinct [software objects](software-object.md) can be equal by value. A [Java](java-programming-language.md) `equals(Object)` override should define an [equivalence relation](equivalence-relation.md) and agree with its [hash code](hash-code.md). Equal content can have different internal subdivisions: occupied colour runs, for example, can be equal despite different brick boundaries.
