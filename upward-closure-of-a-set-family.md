# Upward closure of a set family

↑ **Parent:** [Intersecting family](intersecting-family.md)

The upward closure of $\mathcal B$ is $\overline{\mathcal B}=\{A:\text{some }B\in\mathcal B\text{ satisfies }B\subseteq A\}$.
