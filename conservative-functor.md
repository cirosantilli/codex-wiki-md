# Conservative functor

↑ **Parent:** [Functor](functor.md)

A [functor](functor.md) is conservative when it reflects [isomorphisms](isomorphism.md): if $F(f)$ is invertible then $f$ is invertible. It need not be full or [faithful functor](faithful-functor.md). The [crude monadicity theorem](crude-monadicity-theorem.md) uses this reflection property to lift invertibility of the comparison-adjunction counit from the base [category](category-split.md).
