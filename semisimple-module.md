# Semisimple module

↑ **Parent:** [Module theory](module-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Semisimple_module)

A module is semisimple, or completely reducible, when it is a [direct sum](direct-sum.md) of [simple modules](irreducible-module.md). Equivalently, every submodule has a direct-sum complement.
