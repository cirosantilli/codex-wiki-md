# Hereditary base representation

↑ **Parent:** [Positional notation](positional-notation.md)

A [hereditary base representation](hereditary-base-representation.md) expands not only the number in base $b$, but also every exponent recursively in that same base. Changing the base at every depth defines the Goodstein base-change operation; replacing it by omega defines an [ordinal rank of a Goodstein term](ordinal-rank-of-a-goodstein-term.md).
