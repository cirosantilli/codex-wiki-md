# Rank-order contest

↑ **Parent:** [Contest theory](contest-theory.md)

A rank-order contest awards a sequence of prizes according to the ranks of efforts, while every player incurs its own effort cost. With an [independent private values model](independent-private-values-model.md), an increasing symmetric bidding function orders efforts in the same way as valuations.
