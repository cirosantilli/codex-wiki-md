# Monomial matrix

↑ **Parent:** [General linear group](general-linear-group.md)

A monomial [matrix](matrix.md) has exactly one nonzero entry in each row and column. It factors as an invertible diagonal [matrix](matrix.md) times a permutation [matrix](matrix.md). Such [matrices](matrix.md) permute the coordinate axes and normalize the group of invertible diagonal [matrices](matrix.md); over very small fields that normalizer can be larger if the diagonal [subgroup](subgroup.md) fails to distinguish the axes.
