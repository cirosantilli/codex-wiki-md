# Recursive language

↑ **Parent:** [Formal language theory](formal-language-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Recursive_language)

A [formal language](formal-language.md) is decidable if a [Turing machine](turing-machine.md) halts on every input and correctly determines membership. Equivalently its encoded words form a [recursive set](computable-set.md). A [computably enumerable language](recursively-enumerable-language.md) requires only a machine that eventually accepts every member; it may run forever on nonmembers.
