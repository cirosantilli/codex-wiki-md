# Local integral domain

↑ **Parent:** [Local ring](local-ring.md)

A [local ring](local-ring.md) that is also an [integral domain](integral-domain.md). Multiplication by any nonzero element is injective. This permits cancellation in [Artin-Rees lemma](artin-rees-lemma.md) length-growth arguments.
