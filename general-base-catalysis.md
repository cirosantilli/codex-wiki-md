# General base catalysis

↑ **Parent:** [Catalysis](catalysis.md)

[General base catalysis](general-base-catalysis.md) uses a base to accept a [proton](proton.md) during the reacting pathway, for example activating [water](water.md) while it forms a bond. It need not involve an equilibrium pool of free hydroxide.
