# Finite similarity iterated function system

↑ **Parent:** [Self-similarity](self-similarity.md)

For finitely many [contracting Euclidean similarities](contracting-euclidean-similarity.md), the map $\mathcal T$ on nonempty compact subsets of $\mathbb R^n$ is a contraction in the [Hausdorff metric](hausdorff-distance.md), with contraction constant $\max_i c_i<1$. The [contraction mapping theorem](contraction-mapping-theorem.md) gives a unique nonempty compact invariant set. If the [open set condition](open-set-condition.md) holds, its [Hausdorff dimension](hausdorff-dimension.md) is the unique $s$ satisfying $\sum_i c_i^s=1$.
