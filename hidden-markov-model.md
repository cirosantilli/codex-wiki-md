# Hidden Markov model

↑ **Parent:** [Markov process](markov-process-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hidden_Markov_model)

A hidden Markov model is a [Markov process](markov-process-split.md) whose state is latent and observed only through random emissions whose conditional distribution depends on the current hidden state.
