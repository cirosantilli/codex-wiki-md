# Electron lens

↑ **Parent:** [Electron optics](electron-optics.md)

An [electron lens](electron-lens.md) uses an [electric field](electric-field-split.md) or [magnetic field](magnetic-field-split.md) to make trajectories from an object point converge towards an image point. It has no glass for the [electrons](electron.md) to pass through. In a [paraxial approximation](paraxial-approximation.md), an effective [focal length](focal-length.md) permits the same first-order image geometry used for a [thin lens](thin-lens.md); finite beam angles, energy spread and misalignment limit this approximation.
