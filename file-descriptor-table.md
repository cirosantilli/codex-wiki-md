# File descriptor table

↑ **Parent:** [File descriptor](file-descriptor.md)

A process-associated mapping from small nonnegative [integers](integer-split.md) to [open file descriptions](open-file-description.md), with descriptor-specific flags. Several [file descriptors](file-descriptor.md) can share an [open file description](open-file-description.md); their current [file offset](file-offset.md) is then shared. The traditional model has one table per process, although operating systems can support explicit sharing between processes.
