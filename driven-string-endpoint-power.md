# Driven-string endpoint power

↑ **Parent:** [Wave equation on a string](wave-equation-on-a-string.md)

For a string occupying $x>0$, its small-slope [force](force-split.md) on the endpoint is $Ty_x$. The driver [force](force-split.md) on the string has the opposite sign, so injected [power](power.md) is $-Ty_xy_t$. A right-going traveling [wave](wave-split.md) has nonnegative outgoing instantaneous [power](power.md) in this ideal model.
