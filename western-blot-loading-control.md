# Western blot loading control

↑ **Parent:** [Western blot controls](western-blot-controls.md)

A [Western blot loading control](western-blot-loading-control.md) estimates lane-to-lane sample differences. A reference [protein](protein.md), such as [actin](actin.md), must have stable abundance and detection responsive to amount. Equal saturated bands fail to establish equal loading. [McDonough and others, “Consider the Loading Controls”, Figure 4: sample doubling changes claudin detection but not the actin signal](considerations-when-quantitating-protein-abundance-by-immunoblot-by-alicia-a-mcdonough-and-others.md)
