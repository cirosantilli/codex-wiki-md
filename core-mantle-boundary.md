# Core-mantle boundary

↑ **Parent:** [Solid Earth](solid-earth.md)

The interface between [Earth](earth.md)'s metallic core and silicate [mantle](planetary-mantle.md), approximately 2890 km beneath the surface. It is a major material interface and a thermal boundary across which core heat enters the mantle. Its [temperature](temperature-split.md) is distinct from [mantle potential temperature](mantle-potential-temperature.md) because pressure and the lower thermal boundary layer matter.
