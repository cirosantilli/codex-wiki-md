# Average run length

↑ **Parent:** [CUSUM](cusum.md)

The average run length of a [CUSUM](cusum.md) is the [expectation](expected-value.md) of its first signalling time under a specified data model and initial chart state. A large in-control average run length discourages false alarms; a small out-of-control value indicates rapid detection. The mean alone does not give a finite-horizon [Type I error](type-i-and-type-ii-errors.md) probability or the complete detection-delay distribution.
