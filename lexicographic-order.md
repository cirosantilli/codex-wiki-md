# Lexicographic order

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lexicographic_order)

For equal-size subsets $A$ and $B$ of an ordered ground set, $A$ precedes $B$ in lexicographic order when the smallest element of their symmetric difference belongs to $A$.

For finite [sequences](sequence.md) over a [total order](total-order.md), [lexicographic order](lexicographic-order.md) compares the first differing [sequence terms](sequence-term.md); the smaller term determines the smaller [sequence](sequence.md). If one [sequence](sequence.md) is a proper prefix of the other, the shorter precedes its extension. For fixed-length [tuples](finite-tuple.md), this is the first-difference rule used by [radix sort key encoding](radix-sort-key-encoding.md).
