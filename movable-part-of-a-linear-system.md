# Movable part of a linear system

↑ **Parent:** [Complete linear system of a divisor](complete-linear-system-of-a-divisor.md)

The movable part is $|D-F|$, where $F$ is the [fixed part](fixed-part-of-a-linear-system.md). It has no [fixed components](fixed-component.md). On a [smooth algebraic surface](smooth-algebraic-surface.md) its associated divisor is [nef](nef-line-bundle.md): for each curve choose a member avoiding that curve and use nonnegative local [intersection multiplicities](intersection-multiplicity.md).
