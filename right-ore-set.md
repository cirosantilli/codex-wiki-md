# Right Ore set

↑ **Parent:** [Right Ore condition](right-ore-condition.md)

A multiplicative [subset](subset.md) $S$ of a [ring](ring.md) is a right Ore set if $1\in S$, $0\notin S$ and it satisfies the [right Ore condition](right-ore-condition.md). In a [noncommutative domain](noncommutative-domain.md), this condition lets nonzero denominators be used in [Ore localization](ore-localization.md).
