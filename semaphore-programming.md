# Semaphore (programming)

↑ **Parent:** [Synchronization (computing)](synchronization-computing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Semaphore_(programming))

A permit-based [synchronization](synchronization-computing.md) object. A down operation waits until it can consume a permit; an up operation supplies one. Unlike ownership-based [mutex](mutex.md) use, signalling can pass between different [software threads](thread-computing.md).
