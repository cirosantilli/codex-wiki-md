# Feasible point

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

A feasible point satisfies every constraint of an optimization problem. For a [transportation problem](transportation-problem.md) with capacity inequalities, feasibility requires nonnegative shipments, row totals no greater than factory capacities and column totals equal to shop demands. Feasibility alone does not prove minimal cost: a matching [transportation dual certificate with capacity inequalities](transportation-dual-certificate-with-capacity-inequalities.md) provides an optimality proof. The set of all feasible points can be empty, and a finite infimum need not be attained even when the set is nonempty.
