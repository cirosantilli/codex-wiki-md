# Static perfect-fluid rest-frame criterion

↑ **Parent:** [Perfect fluid in general relativity](perfect-fluid-in-general-relativity.md)

In a diagonal static metric, an ordinary [perfect fluid in general relativity](perfect-fluid-in-general-relativity.md) with a timelike [four-velocity](four-velocity.md) has $T^{0i}=(\rho+p/c^2)u^0u^i$. Since $u^0\ne0$, vanishing mixed time-space components imply a static fluid if the enthalpy is nonzero. For vacuum-like matter with $p=-\rho c^2$, the tensor is $p g^{ab}$ independently of the velocity; its rest frame cannot be recovered from that tensor.
