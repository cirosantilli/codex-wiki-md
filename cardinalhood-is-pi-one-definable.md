# Cardinalhood is Pi-one definable

↑ **Parent:** [Pi-one formula modulo ZF](pi-one-formula-modulo-zf.md)

An ordinal $\kappa$ is a [cardinal number](cardinal-number.md) precisely when no smaller ordinal has a [bijection](bijection.md) onto it. Ordinalhood and the graph predicate for a [bijection](bijection.md) are [bounded formulas in set theory](bounded-formula-in-set-theory.md), so $\operatorname{Ord}(\kappa)\land\forall f\,\forall\alpha\in\kappa\,\neg\operatorname{Bij}(f,\alpha,\kappa)$ is a [Pi-one formula modulo ZF](pi-one-formula-modulo-zf.md). This does not assert that every set can be assigned an ordinal cardinal without the [axiom of choice](axiom-of-choice.md).
