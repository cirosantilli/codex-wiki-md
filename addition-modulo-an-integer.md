# Addition modulo an integer

↑ **Parent:** [Modular arithmetic](modular-arithmetic-split.md)

For an integer $n\ge1$, add residue classes by adding their representatives and taking the class modulo $n$. This is well-defined because replacing either representative by a multiple-of-$n$ translate changes the sum by a multiple of $n$. The [associativity](associative-property.md), identity class $[0]_n$ and inverse $[-a]_n$ are inherited from integer [addition](addition.md). The result is the additive [cyclic group](cyclic-group.md) $\mathbb Z/n\mathbb Z$.
