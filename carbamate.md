# Carbamate

↑ **Parent:** [Chemical substance](chemical-substance-split.md)

A [carbamate](carbamate.md) contains the unit $\mathrm{O{-}C(O){-}N}$. The [nitrogen](nitrogen.md) [lone pair](lone-pair.md) conjugates with the [carbonyl](carbonyl-group.md); cyclic carbamates include [2-Oxazolidinone](2-oxazolidinone.md).
