# Principal nilpotent element

↑ **Parent:** [Principal sl2 subalgebra](principal-sl2-subalgebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Principal_nilpotent_element)

A principal nilpotent element of a semisimple [Lie algebra](lie-algebra-split.md) is a nilpotent element whose [centralizer](centralizer.md) has dimension equal to the rank. For nonzero simple-root vectors $e_i$, the sum $e=\sum_i e_i$ is principal nilpotent and forms the raising element of a [Principal sl2 subalgebra](principal-sl2-subalgebra.md).
