# Partition of a set

↑ **Parent:** [Set](set-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Partition_of_a_set)

A partition of a [set](set-split.md) $X$ is a family of pairwise disjoint nonempty [subsets](subset.md) whose [union](set-union.md) is $X$. Every [equivalence relation](equivalence-relation.md) defines a partition into [equivalence classes](equivalence-class.md), and conversely belonging to the same cell of a partition defines an [equivalence relation](equivalence-relation.md). The nonempty [colour classes](colour-class.md) of a [finite colouring](finite-coloring.md) form a finite partition.
