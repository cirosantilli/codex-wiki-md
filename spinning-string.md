# Spinning string

↑ **Parent:** [String theory](string-theory-split.md)

The spinning string adds [worldsheet Majorana fermions](worldsheet-majorana-fermion.md) and local [worldsheet supersymmetry](worldsheet-supersymmetry.md) to the embedding coordinates. Its gauge-fixed quantum description is the Ramond–Neveu–Schwarz formulation of the superstring.
