# Event horizon

↑ **Parent:** [Black hole](black-hole.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Event_horizon)

An event horizon is the null boundary of the causal past of future null infinity. Its global definition makes it respond teleologically to matter that falls in later.
