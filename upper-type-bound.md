# Upper type bound

↑ **Parent:** [Subtyping](subtyping.md)

An upper type bound $A<:B$ requires the [type argument](type-argument.md) assigned to $A$ to be a [subtype](subtyping.md) of $B$. Two independently bounded parameters can retain different precise component types while sharing the same upper bound. Bounds and [type variance](type-variance.md) answer different questions: admissible arguments versus [subtyping](subtyping.md) between instantiations.
