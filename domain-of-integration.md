# Domain of integration

↑ **Parent:** [Integral](integral-split.md)

The domain of integration is the set $D$ over which an [integral](integral-split.md) is taken. For a [multiple integral](multiple-integral.md), inequalities or parameter ranges specify which points belong to $D$; a [change of variables](change-of-variables-formula.md) transforms both these bounds and the integration element through its [Jacobian determinant](jacobian-determinant.md). For example, a polar region $c\leq r\leq1+\cos\phi$ exists only at angles where $1+\cos\phi\geq c$.
