# Polychoric correlation

↑ **Parent:** [Statistical association](statistical-association.md)

A model-based correlation for ordered categories, commonly estimated by treating the categories as thresholded versions of continuous jointly normal latent responses. Sparse categories and departures from that latent-response model can make estimates unreliable; using it does not remove the need for adequate data.
