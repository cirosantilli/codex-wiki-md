# Graph norm

↑ **Parent:** [Closed linear operator](closed-linear-operator.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Graph_norm)

The graph norm of $A:D(A)\subseteq X\to Y$ is $\|x\|_A=\|x\|_X+\|Ax\|_Y$. If $X$ and $Y$ are [Banach spaces](banach-space-split.md), then $A$ is a [closed linear operator](closed-linear-operator.md) exactly when its domain is complete in the graph norm.
