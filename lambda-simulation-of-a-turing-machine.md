# Lambda simulation of a Turing machine

↑ **Parent:** [Lambda representation of partial computable functions](lambda-representation-of-partial-computable-functions.md)

Represent total machine configuration transitions and tests on [Church numerals](church-numeral.md) and [Church pairs](church-pair.md), then use a [fixed-point combinator](fixed-point-combinator.md) to iterate until the halting test selects the output. Normal-order [beta reduction](beta-reduction.md) follows the computation. A nonhalting machine gives an infinite required reduction, so the [normal-order normalization theorem](normal-order-normalization-theorem.md) rules out a numeral normal form.
