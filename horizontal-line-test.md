# Horizontal line test

↑ **Parent:** [Inverse function](inverse-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Horizontal_line_test)

For a real-valued [function](function-split.md) drawn in the plane, the [horizontal line test](horizontal-line-test.md) asks whether every horizontal [line](straight-line.md) intersects its [function graph](graph-of-a-function.md) at most once. This is exactly [injectivity](injective-function.md), since two intersections at the same height mean two inputs have the same output. A missing height is compatible with [injectivity](injective-function.md), so an [inverse function](inverse-function.md) is then defined on the [image of a function](image-of-a-function.md); it is an inverse on the entire specified [codomain](codomain.md) only when [surjectivity](surjective-function.md) also holds.
