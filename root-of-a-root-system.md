# Root of a root system

↑ **Parent:** [Root system](root-system.md)

A root is an individual nonzero vector in a [root system](root-system.md). For a complex [semisimple Lie algebra](semisimple-lie-algebra-split.md), it is a nonzero [weight](weight-representation-theory.md) of the [Adjoint representation](adjoint-representation-of-a-lie-algebra.md) restricted to a [Cartan subalgebra](cartan-subalgebra.md); its [root space](root-space.md) consists of vectors $x$ satisfying $[h,x]=\alpha(h)x$ for all $h$ in that subalgebra.
