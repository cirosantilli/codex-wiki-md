# Cognitive load

↑ **Parent:** [Cognitive psychology](cognitive-psychology.md)

Demand placed on limited processing resources by a task or concurrent activity. A manipulation of [cognitive load](cognitive-load.md) may affect [attention](attention.md), [working memory](working-memory.md) and strategy together; interpreting a difference requires checking which task information remained available.
