# Total return swap

↑ **Parent:** [Credit derivative](credit-derivative.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Total_return_swap)

The total-return receiver obtains a reference asset's income and price gains, pays its price losses, and pays an agreed funding leg to the total-return payer. This supplies economic exposure without buying the reference asset outright. The transfer includes ordinary market-price risk as well as [credit risk](credit-risk.md), distinguishing it from a [credit default swap](credit-default-swap.md). Both parties can have [counterparty credit risk](counterparty-credit-risk.md) as the swap's replacement value changes.
