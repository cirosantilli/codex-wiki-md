# Analytic determinant square root for accretive symmetric matrices

↑ **Parent:** [Matrix logarithm](matrix-logarithm.md)

On complex symmetric [matrices](matrix.md) with positive-definite real part, the [determinant](determinant.md) has a nonzero analytic square root normalized positively on real positive [matrices](matrix.md). It is continued within this accretive domain. For $A=G+iB$, put $C=G^{-1/2}BG^{-1/2}$ with real [eigenvalues](eigenvalue.md) $b_j$; then $d(A)=\sqrt{\det G}\prod_j\sqrt{1+ib_j}$, using positive-real-part roots for each factor. The principal scalar square root of the product [determinant](determinant.md) need not equal this continued root: accumulated [determinant](determinant.md) arguments can cross the scalar branch cut. The principal [matrix](matrix.md) logarithm instead tracks all factors consistently.
