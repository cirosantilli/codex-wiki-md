# Activation function

↑ **Parent:** [Neural network](neural-network.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Activation_function)

An [activation function](activation-function.md) converts a unit's weighted input to its output. A [sigmoid function](sigmoid-function.md), hyperbolic tangent or rectifier can give nonlinear features. Replacing all hidden [activation functions](activation-function.md) by the identity collapses consecutive affine layers into a single affine map, removing the representational benefit of those hidden layers.
