# Entrywise matrix function

↑ **Parent:** [Matrix](matrix.md)

Applying a [scalar](scalar.md) function separately to each [matrix](matrix.md) entry: $(f[X])_{ij}=f(X_{ij})$. This differs from [spectral matrix functional calculus](spectral-matrix-functional-calculus.md). In particular, $\arcsin[Y]$ in [Gaussian hyperplane rounding](gaussian-hyperplane-rounding.md) is entrywise, and its contribution to a [matrix trace](matrix-trace.md) can be restricted to selected blocks by the support of the other [matrix](matrix.md).
