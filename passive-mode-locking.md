# Passive mode locking

↑ **Parent:** [Mode locking](mode-locking.md)

The circulating [optical pulse](optical-pulse.md) itself changes the cavity response so that a short, intense waveform is favored. A [saturable absorber](saturable-absorber.md) reduces loss at high intensity; a semiconductor saturable-absorber mirror is one implementation. No external periodic timing drive is required, although stable operation still depends on gain and loss dynamics.
