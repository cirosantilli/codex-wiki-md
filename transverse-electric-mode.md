# Transverse electric mode

↑ **Parent:** [Electromagnetic waveguide](electromagnetic-waveguide.md)

A guided [electromagnetic wave](electromagnetic-wave-split.md) whose [electric field](electric-field-split.md) has no component along the propagation axis. Its [magnetic field](magnetic-field-split.md) can have a longitudinal component. In an empty perfectly conducting rectangular [electromagnetic waveguide](electromagnetic-waveguide.md), transverse wave numbers determine a nonzero [cutoff frequency](cutoff-frequency.md). This differs from a [transverse electromagnetic mode](transverse-electromagnetic-mode.md), in which both fields are transverse.
