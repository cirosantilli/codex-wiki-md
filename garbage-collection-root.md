# Garbage collection root

↑ **Parent:** [Garbage collection](garbage-collection.md)

A garbage collection root is an initially accessible reference from which the collector traces reachable [software objects](software-object.md). Depending on the runtime, roots include active [stack](stack-data-structure.md) or register references and static references. [Software objects](software-object.md) reached transitively through reference fields must remain live. Exact root sets and collection timing are implementation details.
