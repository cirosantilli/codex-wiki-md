# Phi-irreducibility

↑ **Parent:** [Irreducible Markov chain](irreducible-markov-chain.md)

A [Markov chain](markov-chain.md) with transition kernel $P$ is $\varphi$-irreducible if $\varphi$ is a nonzero [sigma-finite measure](sigma-finite-measure.md) and every measurable set $A$ with $\varphi(A)>0$ satisfies $\sum_{n\geq1}P^n(x,A)>0$ from every starting state $x$. This is positive reachability, not certain eventual hitting.
