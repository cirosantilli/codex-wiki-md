# Triangular-channel gravity-current box model

↑ **Parent:** [Particle-laden gravity current](particle-laden-gravity-current.md)

A finite-volume [gravity-current box model](gravity-current-box-model.md) in a widening triangular channel has volume proportional to $h^2L^2$, so $hL=K$ is constant. A [gravity-current front condition](gravity-current-front-condition.md) and absorbing-bed [particle deposition flux](particle-deposition-flux.md) give

$$
\dot L=\operatorname{Fr}\sqrt{dK\phi/L},\qquad \dot\phi=-2W_sL\phi/K.
$$

Eliminating time makes $\sqrt\phi$ affine in $L^{5/2}$, producing a finite limiting [runout length of a gravity current](runout-length-of-a-gravity-current.md) despite an infinite idealized stopping time.
