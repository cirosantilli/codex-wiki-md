# Uniform closure of a function algebra

↑ **Parent:** [Uniform approximation](uniform-approximation-split.md)

For an algebra $A\subseteq C(K)$ on a compact space, its uniform closure consists of functions that are [uniform limits](uniform-limit.md) of sequences from $A$. It is a closed algebra in the [uniform norm](supremum-norm.md), because addition and multiplication preserve uniform convergence for bounded functions. If it contains every constant and separates points, the [Stone-Weierstrass theorem](stone-weierstrass-theorem.md) makes the closure all of $C(K)$.
