# Spin normalization in two-dimensional free-electron state counting

↑ **Parent:** [Two-dimensional free-electron density of states](two-dimensional-free-electron-density-of-states.md)

Each allowed [wavevector](wavevector.md) occupies area $(2\pi)^2/A$ under [periodic boundary conditions](periodic-boundary-conditions.md), for each independent spin state. For [parabolic dispersion](parabolic-band-dispersion.md), the number below [energy](energy-split.md) $\epsilon$ is $g_sAm\epsilon/(2\pi\hbar^2)$. Thus the often-quoted coefficient $Am/(2\pi\hbar^2)$ is per spin. Unpolarized [electrons](electron.md) have $g_s=2$; the same convention must be used in particle counting and the [Fermi energy](fermi-energy.md). A linear Dirac dispersion has a different [energy](energy-split.md) dependence.
