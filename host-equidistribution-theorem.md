# Host equidistribution theorem

↑ **Parent:** [Kolmogorov-Sinai entropy](kolmogorov-sinai-entropy.md)

Let $p,q\geq2$ be relatively prime integers. If $\nu$ is invariant and ergodic for the [integer multiplication map on the circle](integer-multiplication-map-on-the-circle.md) $T_p$ and $h_\nu(T_p)>0$, then for $\nu$-almost every $x$ the sequence $(T_q^nx)$ is an [equidistributed sequence](equidistributed-sequence.md) for [Lebesgue measure](lebesgue-measure.md). For a non-ergodic $T_p$ invariant measure, the same conclusion holds if almost every measure in its [ergodic decomposition](ergodic-decomposition.md) has positive entropy. Positive entropy of the whole measure alone does not suffice.
