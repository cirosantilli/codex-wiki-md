# Monadic interpreter

↑ **Parent:** [Interpreter (computing)](interpreter-computing.md)

An [interpreter](interpreter-computing.md) whose evaluator returns computations in a [computational monad](computational-monad.md). Its semantic equations specify effect order by sequencing, while [monad laws](monad-laws.md) support proofs of program equivalence independently of the particular effects.
