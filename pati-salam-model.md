# Pati-Salam model

↑ **Parent:** [Grand unified theory](grand-unified-theory.md)

A quark-lepton unification framework with conventional minimal [gauge group](gauge-group.md) $SU(4)_C\times SU(2)_L\times SU(2)_R$. [leptons](lepton.md) supply a fourth [color charge](color-charge.md), and a [right-handed neutrino](right-handed-neutrino.md) completes each family. [fermion](fermion.md) [masses](mass.md) additionally depend on symmetry breaking and [Yukawa couplings](yukawa-interaction.md).
