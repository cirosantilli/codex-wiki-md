# Ford-Fulkerson algorithm

↑ **Parent:** [Augmenting path](augmenting-path.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ford-Fulkerson_algorithm)

The Ford-Fulkerson algorithm repeatedly augments a feasible flow along an [augmenting path](augmenting-path.md). When no such path remains, the source-reachable vertices in the [residual network](residual-network.md) define a cut of capacity equal to the flow value, proving optimality by the [max-flow min-cut theorem](max-flow-min-cut-theorem.md).
