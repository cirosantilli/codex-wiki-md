# Heterotic string

↑ **Parent:** [String theory](string-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Heterotic_string)

A [string theory](string-theory-split.md) combining a bosonic left-moving system with a supersymmetric right-moving system. Ten target coordinates leave sixteen left-moving internal degrees of freedom for gauge currents. Modular consistency allows the familiar gauge algebras $\mathfrak e_8\oplus\mathfrak e_8$ and $\mathfrak{so}(32)$. Suitable compactification can produce spacetime [supersymmetry](supersymmetry-split.md) and chiral gauge matter.
