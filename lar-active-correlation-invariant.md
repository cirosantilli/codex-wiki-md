# LAR active correlation invariant

↑ **Parent:** [Least angle regression](least-angle-regression.md)

Each [least angle regression](least-angle-regression.md) segment starts with all active scores at magnitude $t$. Moving with direction $d_A=G_{AA}^{-1}s_A$ changes the score vector to $t s_A-(t-\lambda)G_{AA}d_A=\lambda s_A$. The first-hit rule bounds every inactive score in magnitude by $\lambda$. This is the key [Lasso](lasso.md) optimality link.
