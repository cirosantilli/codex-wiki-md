# False-colour composite

↑ **Parent:** [Multispectral imaging](multispectral-imaging.md)

A displayed image assigning measured bands to colour channels that differ from ordinary visual perception. Assigning [near-infrared](near-infrared.md) to red is a common way to highlight vegetation.
