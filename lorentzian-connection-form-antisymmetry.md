# Lorentzian connection-form antisymmetry

↑ **Parent:** [Connection 1-form](connection-1-form-split.md)

In an [orthonormal coframe in spacetime](orthonormal-coframe-in-spacetime.md), antisymmetry applies after lowering the first index with the Lorentzian frame metric. Thus mixed time–space [connection 1-forms](connection-1-form-split.md) are equal under index interchange, while mixed spatial forms are opposite. The same rule holds for [curvature 2-forms](curvature-2-form.md). Confusing lowered antisymmetry with ordinary mixed-index antisymmetry changes the curvature signs.
