# Exponential time

↑ **Parent:** [Time complexity](time-complexity.md)

A [time complexity](time-complexity.md) bounded by $2^{p(n)}$ for a [polynomial](polynomial-split.md) $p$, where $n$ is the encoded [input](input-computer-science.md) length. This usage includes bounds such as $2^{n^2}$; it need not mean only $2^{O(n)}$.
