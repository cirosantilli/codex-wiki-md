# Deceleration parameter from the Hubble derivative

↑ **Parent:** [Deceleration parameter](deceleration-parameter.md)

Differentiating $H=\dot a/a$ gives $\dot H=\ddot a/a-H^2$, which proves the displayed identity. A falling [Hubble parameter](hubble-parameter.md) does not by itself imply deceleration: linear growth $a\propto t$ has $H=1/t$ but $q=0$.
