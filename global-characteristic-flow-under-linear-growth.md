# Global characteristic flow under linear growth

↑ **Parent:** [Characteristic flow map](characteristic-flow-map.md)

If $F\in C^1(\mathbb R\times\mathbb R^d)$ and $|F(t,x)|\le K(1+|x|)$, every [characteristic curve](characteristic-curve.md) is defined for all real time. The [Gronwall inequality](gronwall-inequality.md) bounds $1+|X(t)|$ on each bounded time interval, so local [ordinary differential equation](ordinary-differential-equation.md) existence cannot terminate through escape to infinity. Uniqueness and the variational equation give a global $C^1$ spatial flow diffeomorphism, with Jacobian $J>0$ satisfying $J_t=(\operatorname{div}F)(t,X)J$.
