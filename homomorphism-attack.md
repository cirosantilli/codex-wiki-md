# Homomorphism attack

↑ **Parent:** [RSA cryptosystem](rsa-cryptosystem.md)

An attack exploiting preservation of an algebraic operation by [encryption](encryption.md) or signing. The textbook [RSA cryptosystem](rsa-cryptosystem.md) has $E(m_1m_2)=E(m_1)E(m_2)\pmod N$, so unprotected ciphertexts can be modified multiplicatively. Authentication must be verified before accepting a modified message.
