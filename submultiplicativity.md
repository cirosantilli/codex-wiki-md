# Submultiplicativity

↑ **Parent:** [Algebra norm](algebra-norm.md)

An [algebra norm](algebra-norm.md) is submultiplicative when it satisfies the displayed product inequality. Induction gives $\|a_1\cdots a_n\|\le\prod_j\|a_j\|$, and in particular $\|a^n\|\le\|a\|^n$. The [operator norm](operator-norm.md) has this property because $\|STv\|\le\|S\|\|T\|\|v\|$. The [supremum norm](supremum-norm.md) for bounded functions with pointwise multiplication is another example. This estimate supports the [Neumann series](neumann-series.md) and the [spectral radius formula](spectral-radius-formula.md).
