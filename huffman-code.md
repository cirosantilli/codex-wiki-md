# Huffman code

↑ **Parent:** [Huffman coding](huffman-coding.md)

A Huffman code is a [prefix code](prefix-code.md) produced by repeatedly merging the two least probable symbols or subtrees. Reversing the merges builds a [binary tree](binary-tree.md) whose leaf depths are the codeword lengths. It minimizes expected length among binary prefix codes.
