# Multiderivative multistep method

↑ **Parent:** [Linear multistep method](linear-multistep-method.md)

A multiderivative multistep method uses higher time derivatives as well as values and first derivatives from several time levels. For an autonomous [ordinary differential equation](ordinary-differential-equation.md) $y'=f(y)$, the second time derivative is $y''=f'(y)f(y)$ by the [chain rule](chain-rule.md). Its [local truncation error](local-truncation-error.md) must include the higher-derivative terms. Consequently the usual second-order barrier for [A-stable](a-stability.md) [linear multistep methods](linear-multistep-method.md), which only use first derivatives, does not apply.
