# Velocity model

↑ **Parent:** [Seismology](seismology.md)

A description of seismic [wave speed](wave-speed.md) as a function of position and, if needed, direction. It converts [travel times](travel-time.md) into geometric constraints and is distinct from a direct depth measurement.
