# Torsion module

↑ **Parent:** [Module (mathematics)](module-mathematics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Torsion_module)

A torsion module over an [integral domain](integral-domain.md) $R$ is a [module](module-mathematics.md) in which every element is a [torsion element of a module](torsion-element-of-a-module.md). Each element may require a different nonzero annihilating scalar. The [module](module-mathematics.md) $\mathbb Z/6\mathbb Z$ is torsion over $\mathbb Z$, and the [polynomial module from a linear operator](polynomial-module-from-a-linear-operator.md) $\mathbb Q[t]/(t^2)$ is torsion over $\mathbb Q[t]$.

If the [torsion module](torsion-module.md) is a [finitely generated module](finitely-generated-module.md), one common nonzero scalar kills the whole [module](module-mathematics.md): multiply annihilating scalars for a finite generating set. Without finite generation this can fail. The [quotient module](quotient-module.md) $\mathbb Q/\mathbb Z$ is torsion, since the class of $a/b$ is killed by $b$, but no nonzero [integer](integer-split.md) $n$ kills it all: the class of $1/(2|n|)$ survives multiplication by $n$. See [Keith Conrad's Modules over a PID, exercise 6.5(c)](https://kconrad.math.uconn.edu/blurbs/linmultialg/modulesoverPID.pdf).
