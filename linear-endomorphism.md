# Linear endomorphism

↑ **Parent:** [Endomorphism](endomorphism.md)

A linear endomorphism is a [linear map](linear-map.md) from a [vector space](vector-space-split.md) to itself. In a finite-dimensional [basis](basis.md) it is represented by a square [matrix](matrix.md). It need not be invertible; an invertible linear endomorphism is an [automorphism](automorphism.md) of the vector space.
