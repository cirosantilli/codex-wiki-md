# Marine cloud brightening

↑ **Parent:** [Aerosol-cloud interaction](aerosol-cloud-interaction.md)

[Marine cloud brightening](marine-cloud-brightening.md) proposes increasing suitable [cloud condensation nuclei](cloud-condensation-nucleus.md) over the ocean to increase reflected sunlight. At fixed cloud liquid-water content and thickness, the [Twomey effect](twomey-effect.md) makes more, smaller droplets increase [cloud albedo](cloud-albedo.md). Changes in cloud water, cloud fraction, entrainment and precipitation can reinforce or oppose this fixed-cloud response.
