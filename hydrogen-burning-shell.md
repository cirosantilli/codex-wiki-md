# Hydrogen-burning shell

↑ **Parent:** [Hydrogen burning](hydrogen-burning.md)

A hydrogen-burning shell converts [hydrogen](hydrogen.md) into [helium](helium.md) in a layer surrounding a hydrogen-exhausted stellar core. It moves outward in [enclosed mass](enclosed-mass.md) as it supplies fresh helium to that core; its movement in radius need not have the same sign.
