# Zariski-closed set

↑ **Parent:** [Algebraic geometry](algebraic-geometry-split.md)

A Zariski-closed set is a common zero set of [polynomials](polynomial-split.md). Arbitrary intersections and finite unions of such sets are again Zariski closed.
