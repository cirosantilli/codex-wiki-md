# Moment-map equivariance obstruction

↑ **Parent:** [Moment map](moment-map.md)

For a weakly [Hamiltonian](hamiltonian.md) left [Lie group action](lie-group-action.md) on a connected [symplectic manifold](symplectic-manifold.md), choose $\iota_{X_f}\omega=df$. [Fundamental vector fields](fundamental-vector-field.md) and [Hamiltonian vector fields](hamiltonian-vector-field.md) are both antihomomorphisms, so the displayed difference is constant. The [Jacobi identity for the Poisson bracket](jacobi-identity-for-the-poisson-bracket.md) makes it a two-cocycle. Changing $\mu_X$ by $b(X)$ changes the difference by $-b([X,Y])$. Thus its class in [Lie algebra cohomology](lie-algebra-cohomology.md) obstructs choosing an equivariant [moment map](moment-map.md). For a connected group, vanishing of this class gives infinitesimal and group equivariance.
