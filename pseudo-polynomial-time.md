# Pseudo-polynomial time

↑ **Parent:** [Time complexity](time-complexity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pseudo-polynomial_time)

An [algorithm](algorithm-split.md) has [pseudo-polynomial time](pseudo-polynomial-time.md) when its running time is bounded by a [polynomial](polynomial-split.md) in the numerical magnitudes of input quantities, rather than necessarily in their encoded length. The [dynamic programming](dynamic-programming.md) table for the [0-1 knapsack problem](0-1-knapsack-problem.md) uses $O(nW)$ arithmetic operations for $n$ items and capacity $W$. A [binary numeral system](binary-numeral-system.md) encoding needs only $O(\log(W+1))$ bits for that capacity, so the table bound can be exponential in the number of capacity bits. This distinction does not claim that every input requires exponential work.
