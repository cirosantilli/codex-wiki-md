# Reduced alternating link diagram

↑ **Parent:** [Alternating link diagram](alternating-link-diagram.md)

A reduced alternating [link](link.md) diagram is an [alternating link diagram](alternating-link-diagram.md) with no nugatory crossing. Its [Tait graph](tait-graph.md) and dual have no loops, so it is an [adequate link diagram](adequate-link-diagram.md). If connected, its [Jones polynomial](jones-polynomial.md) breadth equals its crossing count.
