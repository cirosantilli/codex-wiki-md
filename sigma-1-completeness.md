# Sigma-1 completeness

↑ **Parent:** [Sigma-1 formula](sigma-1-formula.md)

An arithmetic theory is [Sigma-1 complete](sigma-1-completeness.md) when it proves every true [Sigma-1 formula](sigma-1-formula.md) that is a sentence. A genuine finite proof gives a true existential assertion that a code is a proof; Sigma-1 completeness therefore supplies the external necessitation clause for the usual [arithmetical provability predicate](arithmetical-provability-predicate.md). Its formalized version says that, for each Sigma-1 sentence $\sigma$, $T\vdash\sigma\to\operatorname{Pr}_T(\ulcorner\sigma\urcorner)$. Applying this to a provability assertion, which is itself Sigma-1, gives the third of the [Hilbert-Bernays-Löb derivability conditions](hilbert-bernays-lob-derivability-conditions.md).
