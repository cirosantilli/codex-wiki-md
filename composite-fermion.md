# Composite fermion

↑ **Parent:** [Fractional quantum Hall effect](fractional-quantum-hall-effect.md)

An emergent description of correlated [electrons](electron.md) in which an even number of statistical flux quanta is attached to each electron. The resulting effective field can turn selected fractional electronic fillings into integer effective fillings. Flux attachment encodes correlations; it is not attachment of literal external magnetic solenoids to individual electrons.
