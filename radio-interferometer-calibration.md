# Radio interferometer calibration

↑ **Parent:** [Radio interferometry](radio-interferometry.md)

Radio interferometer calibration estimates instrumental and propagation effects that alter a [complex visibility](complex-visibility.md). A simple narrow-field model is

$$
V_{12}^{\rm obs}=g_1g_2^*V_{12}^{\rm sky}+n_{12},
$$

where $g_1,g_2$ are complex receiver gains and $n_{12}$ represents additive [noise](noise-signal-processing.md). A [point-like astronomical source](point-like-astronomical-source.md) of known position and stable strength constrains these gains: its expected [complex visibility](complex-visibility.md) has a known [wave phase](phase-waves.md) and amplitude. A resolved or variable reference source requires a better source model. Errors in the reference model can be transferred into the inferred sky.

In a proposed extension, [Martin Ryle](martin-ryle.md) described simultaneous observation of a nearby reference point source to correct atmospheric [wave phase](phase-waves.md) errors, using an additional dish at each element. He presented this as a possible extension, rather than the standard [One-Mile Telescope](one-mile-telescope.md) arrangement.[Ryle (1974), p. 202: proposed reference-source correction](radio-telescopes-of-large-resolving-power-by-martin-ryle.md)
