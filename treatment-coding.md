# Treatment coding

↑ **Parent:** [R linear-model formula](r-linear-model-formula.md)

Treatment coding sets one [reference level in a regression factor](reference-level-in-a-regression-factor.md) to zero and represents each other level by an indicator column. With two interacting factors, a main-effect coefficient compares levels at the other factor's reference level; an interaction coefficient is a difference of these contrasts. A joint [nested-model F-test](nested-model-f-test.md) can be significant even when some individual coefficient tests are not.
