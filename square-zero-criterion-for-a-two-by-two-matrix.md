# Square-zero criterion for a two-by-two matrix

↑ **Parent:** [Nilpotent matrix](nilpotent-matrix.md)

For a real or complex two-by-two [matrix](matrix.md) $A$, the [Cayley-Hamilton theorem](cayley-hamilton-theorem.md) reads $A^2-(\operatorname{tr}A)A+(\det A)I=0$. Hence $A^2=0$ exactly when $\operatorname{tr}A=\det A=0$. Conversely, if $A^m=0$ for any positive integer $m$, every [eigenvalue](eigenvalue.md) is zero and the same identity gives $A^2=0$. Thus a nonzero [nilpotent matrix](nilpotent-matrix.md) of this size has nilpotency index two.
