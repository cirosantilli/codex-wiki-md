# Jeffreys prior for a scale parameter

↑ **Parent:** [Jeffreys prior](jeffreys-prior.md)

For a differentiable [scale family](scale-family.md) with finite positive [Fisher information](fisher-information-matrix.md), the score is $-[1+u(\log f)'(u)]/\sigma$. Its squared expectation is a constant times $\sigma^{-2}$, yielding the displayed [Jeffreys prior](jeffreys-prior.md). This is an [improper prior](improper-prior.md) on the entire positive half-line.
