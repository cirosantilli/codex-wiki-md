# Flip-flop

↑ **Parent:** [Sequential logic](sequential-logic.md)

A [flip-flop](flip-flop.md) stores one [bit](bit.md) and updates it at a specified [clock edge](clock-edge.md); an [asynchronous clear](asynchronous-clear.md) can override that clocked update. Signal polarity is part of the specification, not something inferred from the name alone.
