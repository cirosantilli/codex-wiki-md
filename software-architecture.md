# Software architecture

↑ **Parent:** [Software engineering](software-engineering.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Software_architecture)

The organization of a [software](software.md) system's major components, their responsibilities and their interactions. A [software architecture](software-architecture.md) constrains which components own state and which may request or observe changes. [Model-view-controller](model-view-controller.md) is one example for interactive applications.
