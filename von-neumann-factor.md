# Von Neumann factor

↑ **Parent:** [Von Neumann algebra](von-neumann-algebra.md)

A [Von Neumann algebra](von-neumann-algebra.md) whose center consists exactly of scalar multiples of the identity. A [group von Neumann algebra](group-von-neumann-algebra.md) is a factor exactly when every nonidentity [conjugacy class](conjugacy-class.md) is infinite. A central operator has a square-summable coefficient [vector](vector.md) constant on those classes; an infinite class must therefore have coefficient zero. Conversely, the sum of left translations over a finite nonidentity class is a nonscalar central operator.
