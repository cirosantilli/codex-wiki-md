# Rough path translation

↑ **Parent:** [Geometric p-rough path](geometric-p-rough-path.md)

For $2<p<3$ and a continuous path $h$ of [bounded variation](total-variation-of-a-function.md), translate the first level by $h$ and add the mixed integrals $\int X_{s,r}\otimes dh_r$, $\int h_{s,r}\otimes dX_r$ and $\int h_{s,r}\otimes dh_r$ to the second level. [Integration by parts](integration-by-parts.md) defines the second mixed integral. The operation is continuous in the [rough path metric](rough-path-metric.md) and the variation norm of $h$. For canonical lifts it is precisely the enhancement of the sum of the paths.
