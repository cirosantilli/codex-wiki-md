# Pole-subtracted theta integral for an Epstein zeta function

↑ **Parent:** [Completed Epstein zeta function](completed-epstein-zeta-function.md)

Put $a=n/2$, $m=m(\Lambda)$ and $A_\Lambda(s)=\int_1^\infty(\Theta_\Lambda(it)-1)t^{s-1}\,dt$, which is entire. Splitting the [Mellin transform](mellin-transform.md) at one and using the [lattice theta functional equation](lattice-theta-functional-equation.md) gives $\mathcal E_\Lambda(s)=A_\Lambda(s)+m^{-1}A_{\Lambda^\vee}(a-s)+m^{-1}/(s-a)-1/s$. The two rational terms explicitly retain the contributions of the zero lattice vector.
