# Exponential forcing of a constant-coefficient differential system

↑ **Parent:** [Linear system of differential equations](linear-system-of-differential-equations.md)

For $x'-Ax=e^{\lambda t}v$, substituting an exponential particular solution reduces the differential equation to $(\lambda I-A)u=v$. The displayed solution exists whenever $\lambda$ is not an [eigenvalue](eigenvalue.md) of $A$. Resonance can require polynomial factors in time. The general solution adds $e^{tA}c$, expressed using the [matrix exponential](matrix-exponential.md).
