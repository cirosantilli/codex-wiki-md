# Intersection matrix

↑ **Parent:** [Intersection pairing](intersection-pairing.md)

The intersection matrix records an [intersection pairing](intersection-pairing.md) on chosen classes. Its nonsingularity proves [linear independence](linear-independence.md): a relation between the classes, paired with each class in turn, gives a vector in the matrix's kernel.
