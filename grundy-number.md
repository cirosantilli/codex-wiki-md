# Grundy number

↑ **Parent:** [Impartial game](impartial-game.md)

The value $g(P)=\operatorname{mex}\{g(Q):P\to Q\}$ of a game position, where [mex](minimum-excludant.md) is the smallest nonnegative [integer](integer-split.md) missing from the values of its legal successors. Terminal positions have value zero. The [Sprague-Grundy theorem](sprague-grundy-theorem.md) explains why these values combine by [exclusive or](exclusive-or.md).
