# Stochastic network

↑ **Parent:** [Queueing theory](queueing-theory-split.md)

A stochastic network combines resource constraints, routing, and random arrivals or service requirements. [Loss networks](loss-network.md) reject requests that cannot acquire all required resources; [flow-level network models](flow-level-network-model.md) let ongoing transfers share capacities.
