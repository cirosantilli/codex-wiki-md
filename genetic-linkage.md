# Genetic linkage

↑ **Parent:** [Genetics](genetics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Genetic_linkage)

Genetic linkage is dependence of transmission at loci on the same chromosome, measured in a two-locus model by a [recombination fraction](recombination-fraction.md) below $1/2$. Linkage analysis uses co-segregation within [pedigrees](pedigree.md); [genetic association](genetic-association.md) instead compares allele or genotype frequencies with phenotype.
