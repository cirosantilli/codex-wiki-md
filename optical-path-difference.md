# Optical path difference

↑ **Parent:** [Optical path length](optical-path-length.md)

An [optical path difference](optical-path-difference.md) subtracts two [optical path lengths](optical-path-length.md) at the same [frequency](frequency.md) and with specified endpoints and sign. Its [phase difference](phase-difference.md) contribution is $k_0h$, in addition to any apparatus reference [wave phase](phase-waves.md). For [wavefront error](wavefront-error.md), the comparison is usually between an actual [wavefront](wavefront.md) and an ideal reference [wavefront](wavefront.md).
