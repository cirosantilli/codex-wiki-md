# Bounded function

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bounded_function)

A real- or complex-valued function is bounded when the [moduli](modulus.md) of all its values have one finite upper bound.
