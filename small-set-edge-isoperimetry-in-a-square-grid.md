# Small-set edge isoperimetry in a square grid

↑ **Parent:** [Grid graph](grid-graph.md)

For the $n\times n$ [grid graph](grid-graph.md), if $b$ is an integer, $b<n/2$, and $(b-1)^2<a\leq b(b-1)$, the minimum [edge boundary](edge-boundary-in-a-graph.md) of an $a$-vertex set is $2b-1$. A corner $(b-1)\times(b-1)$ square with a nonempty partial adjacent column attains it. The lower bound counts occupied rows and columns; full rows or columns are treated separately because they contribute no boundary in their own direction.
