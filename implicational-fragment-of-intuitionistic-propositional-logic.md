# Implicational fragment of intuitionistic propositional logic

↑ **Parent:** [Intuitionistic propositional logic](intuitionistic-propositional-logic.md)

The implicational fragment of intuitionistic propositional logic contains formulas built from atoms using only [logical implication](logical-implication.md), with only implication introduction, implication elimination, and assumptions as proof rules.
