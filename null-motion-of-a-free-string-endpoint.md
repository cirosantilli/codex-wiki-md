# Null motion of a free string endpoint

↑ **Parent:** [Free-end string boundary condition](free-end-string-boundary-condition.md)

In a boundary-adapted [temporal gauge](temporal-gauge.md), a free [open string](open-string.md) endpoint has $X'^m=0$. The [Nambu–Goto phase-space constraints](nambu-goto-phase-space-constraints.md) then imply $P^2=0$, while $\dot X=eP$ implies $\dot X^2=0$. For $X^0=t$, its spatial speed is one. This null boundary is compatible with a timelike interior [worldsheet](worldsheet.md).
