# Repeated-root parity-check matrix

↑ **Parent:** [Repeated-root cyclic code](repeated-root-cyclic-code.md)

If the [generator polynomial of a cyclic code](generator-polynomial-of-a-cyclic-code.md) has distinct roots $\alpha_i$ with multiplicities $m_i$, a word belongs to the code exactly when $c^{[\ell]}(\alpha_i)=0$ for $0\leq\ell<m_i$, where $c^{[\ell]}$ is its [Hasse derivative](hasse-derivative.md). The corresponding rows have entries $\binom j\ell\alpha_i^{j-\ell}$ for $j\geq\ell$ and zero otherwise. Expansion in a [basis](basis.md) of the [splitting field](splitting-field.md) gives equations over the original [finite field](finite-field.md); an independent selection has [rank](rank-one-quadratic-form.md) $\sum_i m_i$.
