# Network null model

↑ **Parent:** [Graph theory](graph-theory-split.md)

A [network null model](network-null-model.md) specifies the reference network ensemble or expected connectivity against which a pattern is measured. For standard [network modularity](network-modularity.md), expected edge weight is $k_ik_j/(2m)$. The reference is part of the scientific model: choosing a different reference can change what counts as excess structure.
