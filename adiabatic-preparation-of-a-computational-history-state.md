# Adiabatic preparation of a computational history state

↑ **Parent:** [Adiabatic theorem](adiabatic-theorem.md)

A Hamiltonian path preserving the history subspace can be analysed using its restricted [spectral gap](spectral-gap.md). If this gap is $\Omega(T^{-2})$ and the derivative has [operator norm](operator-norm.md) $O(1)$, a runtime criterion proportional to $\|\dot H\|^2/(\epsilon\Delta^3)$ permits [computational history state](computational-history-state.md) preparation in time $O(T^6/\epsilon)$. Other invariant sectors do not cause leakage from a state initialized in the history subspace.
