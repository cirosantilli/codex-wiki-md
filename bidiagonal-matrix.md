# Bidiagonal matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bidiagonal_matrix)

A bidiagonal matrix has nonzero entries only on its main diagonal and one adjacent diagonal. The [upper bidiagonal matrix](upper-bidiagonal-matrix.md) uses the superdiagonal; the lower version uses the subdiagonal.
