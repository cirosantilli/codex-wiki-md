# State (computer science)

↑ **Parent:** [State machine](state-machine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/State_(computer_science))

A configuration of a system at one moment. In a [transition system](transition-system.md), a [state](state-computer-science.md) is an element of its [state space](state-space.md) $S$, and a [transition relation](transition-relation.md) specifies permitted changes of [state](state-computer-science.md).
