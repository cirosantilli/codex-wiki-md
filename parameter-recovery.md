# Parameter recovery

↑ **Parent:** [Statistical model](statistical-model-split.md)

Simulation of observations under known parameter values followed by refitting the model to assess whether those values can be recovered under the intended design. Recovery depends on information, noise and [identifiability](identifiability.md); good recovery in an assumed model does not establish that the model describes the real mechanism.
