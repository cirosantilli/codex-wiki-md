# Nondegenerate quantum error-correcting code

↑ **Parent:** [Quantum error correction](quantum-error-correction-split.md)

For a specified correctable set of distinct [Pauli operators](pauli-operator.md) modulo phase, a nondegenerate code has mutually orthogonal error images $E\mathcal X$. Equivalently, the matrix in the [Knill--Laflamme condition](knill-laflamme-condition.md) is diagonal for that Pauli error set. Each error therefore requires a separate syndrome subspace of dimension equal to the logical code dimension. Degenerate codes can have distinct errors with the same action on the code and do not satisfy this orthogonality counting argument.
