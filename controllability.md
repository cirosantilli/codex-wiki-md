# Controllability

↑ **Parent:** [Control theory](control-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Controllability)

A system is controllable on a state space if every target there is reachable from every initial state using admissible controls. Time-constrained and unconstrained-time controllability are different conditions. In [quantum control](quantum-control.md), conservation laws require choosing the relevant physical state space or orbit explicitly.
