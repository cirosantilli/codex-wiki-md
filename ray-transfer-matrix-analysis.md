# Ray transfer matrix analysis

↑ **Parent:** [Geometrical optics](geometrical-optics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ray_transfer_matrix_analysis)

[Ray transfer matrix analysis](ray-transfer-matrix-analysis.md) propagates paraxial ray height and slope with a two-by-two [matrix](matrix.md). Free propagation through $L$ uses $\left(\begin{smallmatrix}1&L\\0&1\end{smallmatrix}\right)$, a thin [optical lens](lens-optics.md) uses $\left(\begin{smallmatrix}1&0\\-1/f&1\end{smallmatrix}\right)$, and an unfolded concave-mirror reflection uses $\left(\begin{smallmatrix}1&0\\-2/R&1\end{smallmatrix}\right)$. Multiply matrices in propagation order, with the first operation at the right.
