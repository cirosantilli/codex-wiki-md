# File-system namespace

↑ **Parent:** [File system](file-system.md)

The organization of names and the rules for resolving them to [files](computer-file.md). A path such as `/notes/a` selects successive [directory entries](directory-entry.md) starting from the root [file-system directory](file-system-directory.md). Its spelling describes a route, not an immutable identity: replacing the final [directory entry](directory-entry.md) can make the same path reach a different [inode](inode.md).
