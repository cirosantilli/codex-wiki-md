# Dehn function

↑ **Parent:** [Area of a null-homotopic word](area-of-a-null-homotopic-word.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dehn_function)

The Dehn function of a finite presentation is

$$
\delta(n)=\max\{\operatorname{Area}(w):w=1,\ |w|\leq n\}.
$$

It measures the worst number of relator applications needed to prove a null word of bounded length.
