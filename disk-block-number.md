# Disk block number

↑ **Parent:** [File system](file-system-split.md)

A [disk block number](disk-block-number.md) identifies a fixed-size storage region on a volume. It locates storage rather than naming a [file](computer-file.md). A [file](computer-file.md) can occupy several numbered [file data blocks](file-data-block.md), while a disk block containing several [inodes](inode.md) can describe several [files](computer-file.md).
