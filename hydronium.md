# Hydronium

↑ **Parent:** [Ion](ion.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hydronium)

[Hydronium](hydronium.md) is the [ion](ion.md) formed when a [water](water.md) [molecule](molecule-split.md) accepts a [proton](proton.md). It provides the usual aqueous shorthand for the [hydrogen ion](hydrogen-ion.md) used in [pH](ph.md) calculations.
