# Uncentered maximal function of a finite measure

↑ **Parent:** [Hardy-Littlewood maximal function](hardy-littlewood-maximal-function.md)

The uncentered maximal function takes the supremum over all open Euclidean balls containing $x$, not only balls centred at $x$. It is an extended nonnegative [lower semicontinuous](lower-semicontinuity.md) function: each strict superlevel set is the union of the balls whose average density exceeds that level. For finite positive measures it satisfies the [uncentered maximal weak-type inequality](uncentered-maximal-weak-type-inequality.md).
