# Smooth map between manifolds

↑ **Parent:** [Smooth manifold](smooth-manifold.md)

A map between smooth manifolds is smooth when its expression in every pair of coordinate charts is a [smooth function](smooth-function.md).

A map between [smooth manifolds](smooth-manifold.md) is smooth when its coordinate expressions in compatible charts have derivatives of every order. The condition is invariant under smooth chart changes and expresses [smoothness](smoothness.md) in charts.
