# Barrier function

↑ **Parent:** [Interior-point method](interior-point-method.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Barrier_function)

A [barrier function](barrier-function.md) penalizes approaching the boundary of a [feasible set](feasible-region.md) from its interior, typically diverging to $+\infty$ there. An [interior-point method](interior-point-method.md) minimizes the original [objective function](objective-function.md) plus a positive multiple of this penalty, then reduces that multiple. The [logarithmic barrier](logarithmic-barrier.md) is the basic example for smooth inequality [optimization constraints](optimization-constraint.md).
