# One-particle-irreducible two-point vertex

↑ **Parent:** [One-particle-irreducible correlation function](one-particle-irreducible-correlation-function.md)

The second derivative of a Legendre effective action is the inverse connected two-point kernel. In a translation-invariant scalar theory it is $\widetilde\Gamma^{(2)}(p)=\widetilde G(p)^{-1}$. Its loop expansion contains the reference inverse propagator, any separately displayed counterterms, and the [self-energy](self-energy.md). A generic amputated connected higher-point function is not the same as a one-particle-irreducible vertex.
