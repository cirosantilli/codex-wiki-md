# Fluorescence spectroscopy

↑ **Parent:** [Fluorescence](fluorescence-split.md)

Spectroscopy measuring emitted light following excitation. Emission peak position and intensity can report changes of speciation, but concentration, excitation [absorption](absorption-electromagnetic-radiation.md) and photochemical loss also influence the signal.
