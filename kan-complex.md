# Kan complex

↑ **Parent:** [Simplicial set](simplicial-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kan_complex)

A Kan complex is a simplicial set in which every [simplicial horn](simplicial-horn.md), including every outer horn, has a filler.
