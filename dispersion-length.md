# Dispersion length

↑ **Parent:** [Group velocity dispersion](group-velocity-dispersion.md)

The distance over which second-order [group velocity dispersion](group-velocity-dispersion.md) substantially changes a pulse of characteristic duration $T_0$. Width conventions and initial [chirp](chirp.md) affect numerical broadening factors; the displayed definition is the standard envelope-equation scale.
