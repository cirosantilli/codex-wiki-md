# Productive set

↑ **Parent:** [Computability theory](computability-theory.md)

A set $P$ is productive when a [partial computable function](computable-function.md) returns an element of $P$ outside any [computably enumerable](recursively-enumerable-set.md) subset supplied by its index. The [function](function-split.md) must halt for every index of a subset of $P$, including finite subsets. Productive sets are not [computably enumerable](recursively-enumerable-set.md).
