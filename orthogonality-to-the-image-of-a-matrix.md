# Orthogonality to the image of a matrix

↑ **Parent:** [Image of a linear map](image-of-a-linear-map.md)

For a real [matrix](matrix.md) $A$ and a fixed [vector](vector.md) $n$, every [vector](vector.md) in the [image of a linear map](image-of-a-linear-map.md) defined by $A$ is [orthogonal](orthogonal-vectors.md) to $n$ exactly when $A^Tn=0$. Indeed, $n^TAr=(A^Tn)^Tr$. If this vanishes for every $r$, choose $r=A^Tn$ to obtain $|A^Tn|^2=0$. Equivalently each column of $A$ is [orthogonal](orthogonal-vectors.md) to $n$. Requiring the statement only for nonzero $r$ changes nothing, since the zero input already has zero [dot product](dot-product.md). This is the [orthogonal complement](orthogonal-complement.md) relation between the [image of a linear map](image-of-a-linear-map.md) and the [kernel of a linear map](kernel-of-a-linear-map-split.md) defined by its [transpose](transpose.md).
