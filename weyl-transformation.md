# Weyl transformation

↑ **Parent:** [Polyakov action](polyakov-action.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Weyl_transformation)

A [Weyl transformation](weyl-transformation.md) locally rescales a [metric tensor](metric-tensor.md), $g\mapsto e^{2\omega}g$, while retaining the same points and coordinates. Applied to a worldsheet metric, it leaves the embedding $X^\mu$ unchanged, and the classical [Polyakov action](polyakov-action.md) is invariant under these [Weyl transformations](weyl-transformation.md). Applied to a spacetime metric, a [Weyl rescaling](weyl-transformation.md) can relate different frame conventions, such as a string metric and an Einstein metric; the accompanying field normalizations must be transformed as well. It is not itself a coordinate transformation.
