# Electric polarizability

↑ **Parent:** [Electric dipole moment](electric-dipole-moment.md)

Electric polarizability relates an induced [electric dipole moment](electric-dipole-moment.md) to an applied [electric field](electric-field-split.md). In a weak-field model with [linearity](linearity.md), $\mathbf d_{\rm ind}=\boldsymbol\alpha\mathbf E$. A [tensor](tensor.md) response allows different [electric field](electric-field-split.md) directions to induce [electric dipole moments](electric-dipole-moment.md) in different directions. A response that changes with [molecular rotation](molecular-rotation.md) enables [rotational Raman spectroscopy](rotational-raman-spectroscopy.md).
