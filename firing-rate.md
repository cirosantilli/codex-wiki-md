# Firing rate

↑ **Parent:** [Neural coding](neural-coding.md)

The number of [action potentials](action-potential.md) per unit time, interpreted as an average over a stated window or as an intensity estimated from a [spike train](spike-train.md). Window size changes which temporal information remains visible.
