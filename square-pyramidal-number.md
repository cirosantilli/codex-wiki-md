# Square pyramidal number

↑ **Parent:** [Figurate number](figurate-number.md)

The [sum of squares](sum-of-squares.md) of the first $n$ [positive integers](positive-integer.md): $S_n=\sum_{k=1}^n k^2=n(n+1)(2n+1)/6$. It counts a square-based stack with layers containing $1^2,2^2,\ldots,n^2$ objects. Differences $S_b-S_{a-1}$ give sums over consecutive squares.
