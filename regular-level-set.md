# Regular level set

↑ **Parent:** [Level set](level-set.md)

A [level set](level-set.md) at a [regular value](regular-value.md) is a smooth [submanifold](submanifold.md). By the [regular level set theorem](regular-level-set-theorem.md), its codimension is the dimension of the target. For determinant-one real [symmetric matrices](symmetric-matrix.md), $D(\det)_B(C)=\operatorname{tr}(B^{-1}C)$ is nonzero because $C=B$ gives $n$, so the constraint has codimension one.
