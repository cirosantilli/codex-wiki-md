# Tikhonov filter norm bound

↑ **Parent:** [Tikhonov regularization](tikhonov-regularization.md)

For a [bounded linear operator](continuous-linear-operator.md) between [Hilbert spaces](hilbert-space-split.md), the [spectral regularization method](spectral-regularization-method.md) for quadratic [Tikhonov regularization](tikhonov-regularization.md) has scalar coefficient $s/(s^2+\alpha)$. Since $(s-\sqrt\alpha)^2\geq0$, this coefficient is at most $1/(2\sqrt\alpha)$. The [spectral theorem for normal operators](spectral-theorem-for-normal-operators.md) transfers this scalar bound to the [operator norm](operator-norm.md), providing the noise term in the [noise-bias decomposition for linear regularization](noise-bias-decomposition-for-linear-regularization.md).
