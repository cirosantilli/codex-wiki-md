# Wave function

↑ **Parent:** [Quantum mechanics](quantum-mechanics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Wave_function)

A [wavefunction](wave-function-split.md) is the position representation of a [pure state](pure-state.md). In the one-dimensional model used here, $\psi(x,t)$ takes values in the [complex numbers](complex-number.md), and the [Born rule](born-rule.md) gives

$$
\rho(x,t)=|\psi(x,t)|^2,\qquad \Pr(a<x<b)=\int_a^b\rho(x,t)\,dx.
$$

The [probability density](probability-density.md) $\rho$ has units of inverse length; the [wavefunction](wave-function-split.md) has units of inverse square root of length. A value of $\rho$ at a point is not itself a probability: probabilities come from an [integral](integral-split.md) over a region. For the [infinite square well](infinite-square-well.md) [ground state](ground-state.md), $\rho(L/2)=2/L$, whereas the probability of the exact single point $L/2$ is zero. The interesting question is how much probability a finite interval contains.

Two [wavefunctions](wave-function-split.md) differing only by a [global phase](global-phase.md) represent the same [pure state](pure-state.md). Relative [quantum phases](quantum-phase.md) between components of a [quantum superposition](quantum-superposition.md) affect [matter-wave interference](matter-wave-interference.md), so retaining the full [complex number](complex-number.md) amplitude is essential. This scalar description covers a particle without active [spin](spin.md) degrees of freedom; a general [electron](electron.md) [wavefunction](wave-function-split.md) can have two [spin](spin.md) components, with the position [probability density](probability-density.md) obtained by adding the squared [modulus](modulus.md) of each component.
