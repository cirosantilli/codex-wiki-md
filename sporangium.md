# Sporangium

↑ **Parent:** [Sporophyte](sporophyte.md)

A structure in which [spores](spore.md) are produced. One unbranched bryophyte [sporophyte](sporophyte.md) bears a single sporangium; branching sporophytes can distribute several sporangia on one body.
