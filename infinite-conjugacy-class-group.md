# Infinite conjugacy class group

↑ **Parent:** [Conjugacy class](conjugacy-class.md)

A discrete [group](group-split.md) is ICC when every nonidentity element has an infinite [conjugacy class](conjugacy-class.md). The trivial [group](group-split.md) satisfies this condition vacuously. It characterizes when the [group von Neumann algebra](group-von-neumann-algebra.md) is a [Von Neumann factor](von-neumann-factor.md).
