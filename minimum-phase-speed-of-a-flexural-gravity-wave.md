# Minimum phase speed of a flexural-gravity wave

↑ **Parent:** [Flexural-gravity wave](flexural-gravity-wave.md)

Write $\beta=D/\rho_w$ and $\alpha=m/\rho_w$ in the [dispersion relation of a floating elastic plate](dispersion-relation-of-a-floating-elastic-plate.md). A stationary point of squared [phase velocity](phase-velocity.md) satisfies $\beta k^4(3+2\alpha k)=g(1+2\alpha k)$. If plate inertia is neglected, its solution is $k=(g/(3\beta))^{1/4}$. A steadily translating load can resonate only when its speed matches a [phase velocity](phase-velocity.md); this threshold differs from the [group-velocity minimum of a flexural-gravity wave](group-velocity-minimum-of-a-flexural-gravity-wave.md).
