# Index of a Wiener-Hopf kernel

↑ **Parent:** [Wiener-Hopf kernel](wiener-hopf-kernel.md)

For a nonvanishing kernel tending to the same nonzero value at both ends, the index counts its winding as the contour is traversed from left to right. Index zero permits a continuous logarithm tending to the same normalization at both ends. Canonical bounded [Wiener-Hopf factorization](wiener-hopf-factorization.md) and a constant common entire remainder require this qualification. For example $F(z)=(z+i)/(z-i)$ has index $-1$ on the real line; the bounded half-plane functions $w_+=(z-i)/(z+i)$ and $w_-=1$ obey $Fw_+=w_-$. The analytic factors $F_+=z+i$, $F_-=z-i$ make their common product $z-i$, demonstrating why bounded input functions alone do not guarantee a constant factored remainder.
