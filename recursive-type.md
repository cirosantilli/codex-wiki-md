# Recursive type

↑ **Parent:** [Type system](type-system.md)

A [recursive type](recursive-type.md) explicitly names a type in terms of itself. Notation $\mu\alpha.\tau$ binds $\alpha$ within $\tau$. A [programming language](programming-language-split.md) must specify whether unfolding gives type equality or requires explicit operations; this is outside the finite [simple type](simple-type.md) grammar used here. See Benjamin C. Pierce's treatment of [recursive types](recursive-type.md) in chapters 20–21. [Pierce, Types and Programming Languages (2002), author-hosted contents, chapters 20–21](https://www.cis.upenn.edu/~bcpierce/tapl/contents.pdf)
