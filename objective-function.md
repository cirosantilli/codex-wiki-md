# Objective function

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

An [objective function](objective-function.md) assigns a numerical score to each admissible decision. An optimization problem seeks a [feasible solution](feasible-point.md) maximizing or minimizing this score.
