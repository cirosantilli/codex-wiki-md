# Virtual salt flux

↑ **Parent:** [Salt budget](salt-budget.md)

The salt forcing used to represent freshwater exchange while retaining a fixed reference volume. Removing freshwater at [volume flux](volumetric-flow-rate.md) $E$ is represented by a salt input $ES_0$, and adding freshwater by the opposite salt forcing, with reference [salinity](salinity.md) $S_0$. Replacing the actual salinity in a compensating-flow [salt budget](salt-budget.md) by $S_0$ is an approximation when salinity contrasts are small.
