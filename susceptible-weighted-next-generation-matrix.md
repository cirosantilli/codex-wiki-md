# Susceptible-weighted next-generation matrix

↑ **Parent:** [Next-generation matrix](next-generation-matrix.md)

For a heterogeneous [SIS model](sis-model.md) with common [recovery rate](recovery-rate.md) and a positive [endemic equilibrium](endemic-equilibrium.md) $I_*$, force balance gives $\operatorname{diag}(s_*)KI_*=I_*$. When the transmission [matrix](matrix.md) is irreducible and nonnegative, the positive [equilibrium](equilibrium-point-of-a-dynamical-system.md) vector and the [Perron–Frobenius theorem](perron-frobenius-theorem.md) imply the displayed [spectral radius](spectral-radius.md) identity. It replaces the homogeneous scalar relation $s_*=1/R_0$: different recipient types generally have different susceptible fractions.
