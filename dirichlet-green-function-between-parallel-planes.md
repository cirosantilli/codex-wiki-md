# Dirichlet Green function between parallel planes

↑ **Parent:** [Dirichlet Green function](dirichlet-green-function.md)

For a three-dimensional slab $0<x_1<L$ and source $y=(y_1,y_2,y_3)$, define image positions $y_n^+=(y_1+2nL,y_2,y_3)$ and $y_n^-=(-y_1+2nL,y_2,y_3)$. The displayed [method of images](method-of-images.md) series uses convention $\Delta_xG_D=+\delta(x-y)$. Reflection in $x_1=0$ pairs the plus image $n$ with the minus image $-n$, while reflection in $x_1=L$ pairs it with the minus image $1-n$. Both boundary values therefore vanish. Only $y_0^+=y$ lies in the slab. Each bracket is $O(n^{-2})$, giving absolute convergence of the paired series away from sources. This selects the usual [Dirichlet Green function](dirichlet-green-function.md) that decays at large transverse separation.
