# Null-state quotient of a string

↑ **Parent:** [Null string state](null-string-state.md)

The physical state space of [old covariant quantization](old-covariant-string-quantization.md) is quotiented by its physical spurious states, which are orthogonal to all physical states. In a ghost-free sector these form the radical of the semidefinite inner product. The quotient retains positive physical polarizations.
