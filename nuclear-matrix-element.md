# Nuclear matrix element

↑ **Parent:** [Atomic nucleus](atomic-nucleus-split.md)

A transition-operator [matrix element](matrix-element.md) between specified nuclear states. It combines their many-nucleon wavefunctions with the relevant interaction operator. In [double beta decay](double-beta-decay.md), different assumed mechanisms and nuclear-structure calculations give different [matrix elements](matrix-element.md), so converting a half-life bound to a neutrino-mass bound requires that input. A measured [energy](energy-split.md) endpoint alone does not determine it.
