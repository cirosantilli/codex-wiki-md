# Proper mixed state

↑ **Parent:** [Local quantum state under objective collapse](local-quantum-state-under-objective-collapse.md)

A proper mixed state represents classical uncertainty over states selected by an actual preparation or collapse. Once that selecting event lies in the readout point's past light cone, a [quantum state readout device](quantum-state-readout-device.md) returns the selected component rather than merely the ensemble average.
