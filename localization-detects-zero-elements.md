# Localization detects zero elements

↑ **Parent:** [Localization of a ring](localization-of-a-ring.md)

An element $a$ of a [commutative ring](commutative-ring.md) $R$ is zero if and only if its image in every [localization at a prime ideal](localization-at-a-prime-ideal.md) is zero. If $a\ne0$, its proper [annihilator](annihilator-ring-theory.md) lies in a [maximal ideal](maximal-ideal.md) $\mathfrak m$. No element outside $\mathfrak m$ can annihilate $a$, so $a/1\ne0$ in $R_{\mathfrak m}$. This also applies to elements of an $R$-[module](module-mathematics.md) using [localization of a module](localization-of-a-module.md).
