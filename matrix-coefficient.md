# Matrix coefficient

↑ **Parent:** [Group representation](group-representation.md)

A matrix coefficient of a finite-dimensional [group representation](group-representation.md) is a scalar function obtained by applying a [linear functional](linear-functional.md) to the translate of a fixed vector. In a chosen [basis](basis.md) these functions include $x\mapsto\rho(x)_{ij}$. For a [finite group](finite-group.md), the [Schur orthogonality relations](schur-orthogonality-relations.md) make the scaled coefficients of all inequivalent [unitary irreducible representations](unitary-irreducible-representation.md) an [orthonormal basis](orthonormal-basis.md) of its scalar functions.
