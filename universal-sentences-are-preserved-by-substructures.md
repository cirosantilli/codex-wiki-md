# Universal sentences are preserved by substructures

↑ **Parent:** [Universal first-order theory](universal-first-order-theory.md)

Quantifier-free [logical formulas](logical-formula.md) have the same [truth value](truth-value.md) in a [substructure](substructure-of-a-first-order-structure.md) and its ambient [first-order structure](first-order-structure.md) on [tuples](finite-tuple.md) from the smaller carrier. [First-order term](first-order-term.md) evaluation agrees; atomic relations agree by restriction; Boolean connectives preserve agreement. A universally quantified quantifier-free matrix true on all ambient [tuples](finite-tuple.md) is therefore true on all [substructure](substructure-of-a-first-order-structure.md) [tuples](finite-tuple.md).
