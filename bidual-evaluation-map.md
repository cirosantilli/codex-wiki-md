# Bidual evaluation map

↑ **Parent:** [Dual space](dual-space.md)

For an algebraic [dual space](dual-space.md) $X^*=\operatorname{Hom}_F(X,F)$, the [linear map](linear-map.md) $J:X\to X^{**}$ sends $x$ to evaluation at $x$. It is [injective](injective-function.md) because [linear functionals](linear-functional.md) separate nonzero vectors: extend any nonzero vector to a [basis](basis.md) and use its coordinate functional. If $X$ has a finite [basis](basis.md) $e_i$ with [dual basis](dual-basis.md) $e_i^*$, every $B\in X^{**}$ equals $J(\sum_iB(e_i^*)e_i)$, so $J$ is an [isomorphism](isomorphism.md). For infinite-dimensional spaces, [surjection](surjective-function.md) does not follow from this finite sum argument.
