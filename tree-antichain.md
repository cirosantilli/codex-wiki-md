# Tree antichain

↑ **Parent:** [Set-theoretic tree](set-theoretic-tree.md)

A set of pairwise incomparable nodes in a [set-theoretic tree](set-theoretic-tree.md). A maximal [tree antichain](tree-antichain.md) has a comparable member for every node of the tree.
