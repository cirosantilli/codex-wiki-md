# Type synonym

↑ **Parent:** [Type system](type-system.md)

A name for an existing type expression, without constructing a distinct runtime datatype. In [Haskell](haskell.md), `type Seq a = a -> [Integer]` names a function representation; an [equality test](equality-test.md) constraint can belong to an operation on that representation without belonging to the synonym itself.
