# Homogeneity

↑ **Parent:** [Homogeneous function](homogeneous-function.md)

Homogeneity of degree $k$ means that multiplying all arguments by a common positive factor $a$ multiplies the output by $a^k$. A [homogeneous function](homogeneous-function.md) is the function possessing this property. This is different from degree-one [positive homogeneity](positively-homogeneous-function-degree-one.md); investment values with [constant relative risk aversion utility](constant-relative-risk-aversion-utility.md) usually have degree $1-R$.
