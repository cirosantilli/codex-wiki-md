# Kodaira map

↑ **Parent:** [Line bundle](line-bundle.md)

A basepoint-free vector space of global sections $V\subseteq H^0(X,L)$ defines the Kodaira map $X\to\mathbb P(V^*)$ by evaluating the sections at each point.
