# Configuration model

↑ **Parent:** [Random graph](random-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Configuration_model)

For a prescribed [degree sequence](degree-sequence.md) with even sum $M=\sum_i d_i$, attach $d_i$ labelled [half-edges](half-edge-of-a-graph.md) to [vertex](vertex-graph-theory.md) $i$ and choose a uniform [perfect matching](perfect-matching.md) of the $M$ half-edges. Each pair becomes an [edge](edge-of-a-graph.md), giving a [multigraph](multigraph.md) that may have [self-loops](loop-graph-theory.md) or parallel edges. The number of pairings is $M!/[2^{M/2}(M/2)!]$. Every [simple graph](simple-graph.md) with that degree sequence has exactly $\prod_i d_i!$ pairing representations, so conditioning on simplicity produces the uniform simple-graph model.
