# Type class

↑ **Parent:** [Type (information theory)](type-information-theory.md)

The [type class](type-class.md) $T_n(q)$ contains all length-$n$ strings with [empirical distribution](type-information-theory.md) $q$. Each $nq(a)$ must be a nonnegative [integer](integer.md) and the counts must sum to $n$; otherwise the class is empty. Distinct [type classes](type-class.md) partition $\mathcal A^n$: every string belongs to exactly one class.

For four binary symbols there are five [type classes](type-class.md), indexed by the number $k$ of ones. Their [cardinalities](cardinality.md) are $1,4,6,4,1$, which sum to $16=2^4$. The balanced class contains exactly $0011,0101,0110,1001,1010,1100$. These are six different strings, not six different [empirical distributions](type-information-theory.md).
