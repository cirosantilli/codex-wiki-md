# Type class

↑ **Parent:** [Type (information theory)](type-information-theory.md)

The type class $T(P)$ is the set of all strings of a fixed length whose [type](type-information-theory.md) is $P$. Every string in one type class has the same probability under any independent identically distributed source law.
