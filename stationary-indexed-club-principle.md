# Stationary-indexed club principle

↑ **Parent:** [Club principle](club-principle.md)

For a stationary $S\subseteq\omega_1$, there are cofinal ladders $A_\delta\subset\delta$ of order type $\omega$, indexed by [limit ordinals](limit-ordinal.md) in $S$, such that every uncountable $X\subseteq\omega_1$ contains one of these ladders. This predicts a contained ladder, whereas [stationary diamond principle](stationary-diamond-principle.md) predicts a whole initial segment.
