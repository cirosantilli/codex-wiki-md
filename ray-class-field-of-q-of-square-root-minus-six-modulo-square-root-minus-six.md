# Ray class field of Q of square root minus six modulo square root minus six

↑ **Parent:** [Ray class field](ray-class-field.md)

For $K=\mathbb Q(\sqrt{-6})$, reduction of $\mathbb Z[\sqrt{-6}]$ modulo $(\sqrt{-6})$ gives $\mathbb Z/6\mathbb Z$. Its [unit group](unit-group.md) is covered by the units $\{1,-1\}$ of $K$. The [ray class exact sequence](ray-class-exact-sequence.md) therefore identifies the [ray class group](ray-class-group.md) with the ordinary [ideal class group](ideal-class-group.md), of order two. Consequently this [ray class field](ray-class-field.md) is the [Hilbert class field of Q of square root minus six](hilbert-class-field-of-q-of-square-root-minus-six.md). To verify its lack of [ramification](ramification-mathematics.md), the integral basis candidate $1,\sqrt2,b,\sqrt2b$, where $b=(1+\sqrt{-3})/2$, has [discriminant](discriminant.md) $8^2(-3)^2=576$. The relative discriminant formula also forces the field discriminant to be divisible by $(-24)^2=576$. Equality proves that the relative [discriminant ideal](discriminant-ideal.md) is trivial.
