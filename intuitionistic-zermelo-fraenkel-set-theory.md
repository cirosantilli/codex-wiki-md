<h1 id="intuitionistic-zermelo-fraenkel-set-theory">Intuitionistic Zermelo–Fraenkel set theory</h1>

↑ **Parent:** [Zermelo–Fraenkel set theory](zermelo-fraenkel-set-theory.md)

Full intuitionistic Zermelo–Fraenkel set theory uses [intuitionistic first-order logic](intuitionistic-first-order-logic.md), extensionality, pairing, union, infinity, full separation, power set, collection and [epsilon induction](epsilon-induction.md). Collection is stronger than replacement intuitionistically. This is distinct from predicative constructive ZF, which restricts separation and replaces full power set. The full theory supports a [Boolean-valued inner universe over intuitionistic set theory](boolean-valued-inner-universe-over-intuitionistic-set-theory.md), giving the relative consistency of classical [ZF](zermelo-fraenkel-set-theory.md).
