# Jacobi fields form the radical of the fixed-endpoint index form

↑ **Parent:** [Riemannian index form](riemannian-index-form.md)

On continuous piecewise smooth [vector field along a curve](vector-field-along-a-curve.md) with zero endpoints, the [radical of a bilinear form](radical-of-a-bilinear-form.md) of the [Riemannian index form](riemannian-index-form.md) is exactly the space of endpoint-vanishing [Jacobi fields](jacobi-field.md). Integration by parts against tests supported inside each smooth piece gives the [Jacobi equation](jacobi-equation.md); tests with arbitrary values at breakpoints force continuity of the covariant derivative, hence a global smooth [Jacobi field](jacobi-field.md). This characterization uses $I(V,W)=0$ for every test field $W$, not merely $I(V,V)=0$, which is insufficient for an indefinite form.
