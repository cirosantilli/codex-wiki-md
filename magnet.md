# Magnet

↑ **Parent:** [Magnetism](magnetism.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Magnet)

A [magnet](magnet.md) is a material object or current arrangement that produces a [magnetic field](magnetic-field-split.md). [Permanent magnets](permanent-magnet.md) retain [magnetization](magnetization.md), while [electromagnets](electromagnet.md) use a supplied [electric current](electric-current.md) in a winding.
