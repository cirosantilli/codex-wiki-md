# Lebesgue measurable set

↑ **Parent:** [Measure theory](measure-theory-split.md)

A [subset](subset.md) $E\subseteq\mathbb R$ is a [Lebesgue measurable set](lebesgue-measurable-set.md) when it satisfies [Carathéodory's criterion](caratheodory-s-criterion.md) for [Lebesgue outer measure](lebesgue-outer-measure.md): for every [subset](subset.md) $A\subseteq\mathbb R$,

$$
m^*(A)=m^*(A\cap E)+m^*(A\setminus E).
$$

These sets form the [Lebesgue sigma-algebra](lebesgue-sigma-algebra.md), the completion of the [Borel sigma-algebra](borel-sigma-algebra.md) with respect to [Lebesgue measure](lebesgue-measure.md). Equivalently, $E$ differs from a [Borel set](borel-set.md) by a [subset](subset.md) of a [Borel null set](borel-null-set.md).
