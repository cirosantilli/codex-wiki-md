# Lebesgue measurable set

↑ **Parent:** [Measure theory](measure-theory-split.md)

A Lebesgue measurable set is a member of the completion of the Borel sigma-algebra with respect to [Lebesgue measure](lebesgue-measure.md). In particular, it differs from a [Borel set](borel-set.md) by a null set.
