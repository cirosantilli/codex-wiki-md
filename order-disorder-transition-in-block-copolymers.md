# Order-disorder transition in block copolymers

↑ **Parent:** [Microphase separation](microphase-separation.md)

The transition between a compositionally disordered state and an ordered microdomain state as effective segregation strength increases. The parameter $\chi N$ combines unlike-segment interaction preference and chain length; its transition value depends on composition and model assumptions. A bulk [thermodynamic equilibrium](thermodynamic-equilibrium.md) boundary is not by itself an evaporation or [vitrification](vitrification.md) kinetic model.
