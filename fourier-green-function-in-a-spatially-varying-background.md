# Fourier Green function in a spatially varying background

↑ **Parent:** [Green's function](green-s-function-split.md)

A static background permits a [Fourier transform](fourier-transform-split.md) of time difference, but a spatially varying coefficient generally prevents dependence on position difference alone. A momentum-space [Green function](green-s-function-split.md) then carries an incoming and an outgoing [momentum](momentum-split.md), or equivalently one [momentum](momentum-split.md) together with the source position. Multiplication by a background field becomes a convolution, with a source-position phase when the Fourier basis is written as $e^{i\mathbf k\cdot(\mathbf r-\mathbf r')}$. A diagonal single-momentum representation is justified only with additional spatial [translation](translation-geometry.md) symmetry or an explicitly fixed source origin.
