# Goldstone current matrix element in a phase-only scalar theory

↑ **Parent:** [Goldstone theorem](goldstone-theorem.md)

For a canonically normalized massless phase [scalar field](scalar-field.md) with shift $\pi\mapsto\pi+f\alpha$, the [Noether current](noether-current.md) is $J^\mu=f\partial^\mu\pi$. With invariant one-particle normalization, the displayed [matrix](matrix.md) element follows from $\langle0|\pi(x)|\pi(p)\rangle=e^{-ipx}$. Its divergence is $-fp^2e^{-ipx}=0$ on the massless shell, despite a nonzero current [matrix](matrix.md) element. This is the elementary current [coupling](coupling.md) of a [Goldstone boson](goldstone-boson.md); conservation constrains its [momentum](momentum-split.md) contraction, not every component separately.
