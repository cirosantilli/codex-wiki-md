# Resonant argument

↑ **Parent:** [Mean-motion resonance](mean-motion-resonance.md)

A resonant argument is a slow angular combination whose libration diagnoses resonance. For an exterior $j:(j-1)$ eccentric resonance it can be $\phi=j\lambda-(j-1)\lambda_p-\varpi$.

A resonant argument is an integer combination of orbital angles whose slow variation can diagnose [mean-motion resonance](mean-motion-resonance.md). Its libration, rather than circulation through every angle, characterizes trapping in the resonance.
