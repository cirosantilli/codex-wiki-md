# Atomic model without finite-tuple homogeneity

↑ **Parent:** [Atomic model](atomic-model.md)

An equivalence-relation [first-order structure](first-order-structure.md) with exactly two infinite classes, one [countable](countable-set.md) and one uncountable, is atomic but lacks [finite-tuple homogeneity](finite-tuple-homogeneity.md). Its [first-order theory](first-order-theory.md) has [quantifier elimination](quantifier-elimination.md): a new point is either assigned a previously used class or an available unused class, and can avoid finitely many forbidden points in that infinite class. Finite equality-and-equivalence patterns therefore isolate all [tuple](finite-tuple.md) [partial types](partial-type.md). All elements have the same [complete one-type](complete-one-type.md), but no automorphism exchanges the two differently sized classes.
