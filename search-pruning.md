# Search pruning

↑ **Parent:** [Algorithm](algorithm-split.md)

Discarding a branch of a [search tree](search-tree.md) after proving that no completion can satisfy the constraints or improve the current best solution. For minimization, a [lower bound](lower-bound-in-a-partially-ordered-set.md) on every completion justifies pruning when it is at least the best value already found; this is the principle behind [branch and bound](branch-and-bound.md).
