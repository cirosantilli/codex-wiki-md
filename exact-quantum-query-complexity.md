# Exact quantum query complexity

↑ **Parent:** [Quantum query complexity](quantum-query-complexity.md)

The least worst-case number of input-oracle calls made by a [quantum circuit](quantum-circuit-split.md) that computes a [Boolean function](boolean-function.md) with zero error on every input. Known [unitary gates](quantum-logic-gate.md) and classical processing do not count toward this quantity; their runtime is a separate cost.
