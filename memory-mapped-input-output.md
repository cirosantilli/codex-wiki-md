# Memory-mapped input-output

↑ **Parent:** [Input-output](input-output.md)

[Memory-mapped input-output](memory-mapped-input-output.md) exposes device registers through addresses accessed by load and store operations. A target-specific [C programming language](c-programming-language.md) port maps the documented registers to suitably qualified objects and implements any required access barriers. Register layout, access width and acknowledgment semantics belong to the device specification; a register's name alone does not establish its numerical address.
