# String dual resonance

↑ **Parent:** [Closed-string scattering amplitude](closed-string-scattering-amplitude.md)

A single [crossing-symmetric scattering amplitude](crossing-symmetry.md) has equivalent pole expansions in different exchange channels. Its [scattering-amplitude factorization](scattering-amplitude-factorization.md) reproduces the string spectrum and couplings in each channel without adding the channel expansions again.
