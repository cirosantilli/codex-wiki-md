# Propositional compactness theorem

↑ **Parent:** [Propositional logic](propositional-logic.md)

A set of propositions has a model exactly when every finite subset has a model. Syntactically, a contradiction uses only finitely many assumptions, and every consistent set extends by [Zorn lemma](zorn-s-lemma.md) to a [maximal consistent set in propositional logic](maximal-consistent-set-in-propositional-logic.md).
