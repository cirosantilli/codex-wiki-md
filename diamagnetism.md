# Diamagnetism

↑ **Parent:** [Magnetism](magnetism.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Diamagnetism)

[Diamagnetism](diamagnetism.md) is a magnetic response in which the induced [magnetization](magnetization.md) opposes the applied [magnetic field intensity](magnetic-field-intensity.md). In a linear isotropic description, $\mathbf M=\chi\mathbf H$ with negative [magnetic susceptibility](magnetic-susceptibility.md) $\chi$.
