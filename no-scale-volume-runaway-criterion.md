# No-scale volume runaway criterion

↑ **Parent:** [Matter-logarithm no-scale potential](matter-logarithm-no-scale-potential.md)

If a [no-scale supergravity](no-scale-supergravity.md) [scalar potential](scalar-potential.md) has the displayed form with $y>0$ and nonnegative $A,B$ independent of the volume coordinate $y$, every point with $A+B>0$ has a direction of strictly decreasing potential. Thus a finite stationary vacuum requires $A=B=0$. If that common zero set is empty, the potential has infimum zero along $y\to\infty$ but no finite minimum. If the common zero set is nonempty, varying $y$ on it is a [flat direction of a scalar potential](flat-direction-of-a-scalar-potential.md). This distinguishes an attained zero-energy vacuum from a decompactification runaway.
