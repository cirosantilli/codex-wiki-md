# Entropy bound from overlap with a pure state

↑ **Parent:** [Von Neumann entropy](von-neumann-entropy-split.md)

If a [density operator](density-matrix.md) $\sigma$ on an $m\geq2$ dimensional [Hilbert space](hilbert-space-split.md) has overlap $t=\langle\psi|\sigma|\psi\rangle$ with a fixed [pure state](pure-state.md), then $S(\sigma)\leq h(t)+(1-t)\log_2(m-1)$. Dephase in a basis containing $|\psi\rangle$ and apply the [entropy bound with one prescribed probability](entropy-bound-with-one-prescribed-probability.md). The abstract state bound is attained by $\sigma=t|\psi\rangle\langle\psi|+(1-t)(I-|\psi\rangle\langle\psi|)/(m-1)$.
