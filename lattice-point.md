# Lattice point

↑ **Parent:** [Bravais lattice](bravais-lattice.md)

A lattice point is a vector $l=n_1a_1+n_2a_2+n_3a_3$ whose coefficients in a chosen primitive [basis](basis.md) are [integers](integer.md).
