# Dilaton normalization and Euler-characteristic weighting

↑ **Parent:** [Dilaton](dilaton.md)

With Euclidean curvature coupling $(4\pi)^{-1}\int\sqrt h\,\varphi R$, a constant [dilaton](dilaton.md) contributes $\varphi_0\chi$ by the [Gauss-Bonnet theorem](gauss-bonnet-theorem.md). The genus-$g$ closed-string weight is $e^{-\varphi_0\chi}=g_s^{2g-2}$ with $g_s=e^{\varphi_0}$. If the coefficient is instead written as $\int\sqrt h\,\Phi R$, then in the same convention $\varphi=4\pi\Phi$. The field normalization must be fixed before reading off the coupling.
