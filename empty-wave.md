# Empty wave

↑ **Parent:** [de Broglie-Bohm theory](de-broglie-bohm-theory.md)

A component of the [wave function](wave-function-split.md) whose configuration-space support does not contain the actual configuration. It can affect later [guidance equation](guidance-equation.md) evolution if branches overlap again; enduring environmental separation makes it dynamically irrelevant to the occupied branch to excellent approximation.
