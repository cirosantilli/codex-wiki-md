# Universal quotient bundle on a real Grassmannian

↑ **Parent:** [Quotient vector bundle](quotient-vector-bundle.md)

Over $\operatorname{Gr}_k(\mathbb R^N)$, quotient the trivial bundle by the [tautological bundle](tautological-bundle.md). The quotient is a vector bundle because it identifies continuously with the orthogonal-complement bundle via $[v]\mapsto P_{W^\perp}v$. Its rank is $N-k$.
