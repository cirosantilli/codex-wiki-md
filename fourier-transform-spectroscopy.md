# Fourier transform spectroscopy

↑ **Parent:** [Spectrometer](spectrometer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fourier_transform_spectroscopy)

Fourier transform spectroscopy measures an interferogram as a function of [optical path length](optical-path-length.md) difference. Its [Fourier transform](fourier-transform-split.md) recovers the spectrum. An imaging implementation obtains an interferogram at every detector pixel, but a scanned cube is not simultaneous at all wavelengths.
