# Wilson algorithm rooted at infinity

↑ **Parent:** [Wired uniform spanning forest](wired-uniform-spanning-forest.md)

Wilson's algorithm rooted at infinity builds the wired uniform spanning forest on a [transient graph](transient-graph.md) by successively adding [loop-erased](loop-erasure.md) random walks, run forever when they never hit the forest already constructed.
