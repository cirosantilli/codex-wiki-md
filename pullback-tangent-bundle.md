# Pullback tangent bundle

↑ **Parent:** [Pullback vector bundle](pullback-vector-bundle.md)

For a [smooth map between manifolds](smooth-map-between-manifolds.md) $f:M\to N$, the [pullback vector bundle](pullback-vector-bundle.md) $f^*TN$ has fibre $T_{f(p)}N$ at $p\in M$. A smooth section is a [vector field along a map](vector-field-along-a-map.md). It allows one to differentiate maps and curves without requiring them to be invertible.
