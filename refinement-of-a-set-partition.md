# Refinement of a set partition

↑ **Parent:** [Set partition](set-partition.md)

A [set partition](set-partition.md) $\mathcal Q$ refines $\mathcal P$ if every cell of $\mathcal Q$ is contained in a cell of $\mathcal P$. Thus $\mathcal Q$ retains every separation made by $\mathcal P$ and may make additional separations. [Refinement of a set partition](refinement-of-a-set-partition.md) is reflexive and transitive. If each partition refines the other, their cells coincide, so [refinement of a set partition](refinement-of-a-set-partition.md) is a partial order on partitions. For finite partitions the nonempty intersections of cells form their common [refinement of a set partition](refinement-of-a-set-partition.md). In [graph](graph-split.md) regularity arguments, subdividing cells and treating discarded [vertices](vertex-graph-theory.md) as singletons preserves [refinement of a set partition](refinement-of-a-set-partition.md); merging discarded [vertices](vertex-graph-theory.md) into one cell need not. The [refinement variance identity for regularity energy](refinement-variance-identity-for-regularity-energy.md) consequently proves that this singleton treatment cannot decrease the [equitable regularity energy](equitable-regularity-energy.md).
