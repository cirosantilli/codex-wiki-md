# Maximal decoding error probability

↑ **Parent:** [Channel decoder](channel-decoder.md)

The worst message's error [probability](probability.md) under a specified [channel encoder](channel-encoder.md), [communication channel](communication-channel.md), and [channel decoder](channel-decoder.md). It upper-bounds the average error [probability](probability.md) under every message [probability distribution](probability-distribution-split.md). In particular, a uniform bound on [maximal decoding error probability](maximal-decoding-error-probability.md) remains valid after restricting to any nonempty subset of messages. This distinguishes it from an average-only error guarantee in [channel coding](channel-coding.md).
