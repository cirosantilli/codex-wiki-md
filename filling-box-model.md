# Filling box model

↑ **Parent:** [Turbulent plume](turbulent-plume-split.md)

A filling box model describes a [turbulent plume](turbulent-plume-split.md) rising through a confined fluid and spreading beneath its ceiling. [Fluid entrainment](fluid-entrainment.md) transfers initially unmodified ambient fluid into the plume; the discharged fluid forms a descending [filling-box first front](filling-box-first-front.md). A maintained heat source can have negligible source [volume flux](volumetric-flow-rate.md) while maintaining nonzero [buoyancy flux](buoyancy-flux.md). A finite injected fluid flux requires an equal exhaust if the container volume is fixed.
