# Torsion element of a module

↑ **Parent:** [Torsion submodule](torsion-submodule.md)

For a [module](module-mathematics.md) over an [integral domain](integral-domain.md), a torsion element is killed by some nonzero scalar. These elements form the [torsion submodule](torsion-submodule.md): the product of nonzero annihilating scalars annihilates a sum. This scalar-annihilation definition differs from saying that an element has finite order in a [group](group-split.md).
