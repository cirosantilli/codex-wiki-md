# Tree search

↑ **Parent:** [Search algorithm](search-algorithm.md)

A [search algorithm](search-algorithm.md) that explores action histories in a [search tree](search-tree.md). Two histories ending in the same state remain distinct nodes unless an additional repetition rule identifies them. Consequently a finite [state space](state-space.md) can generate an infinite [search tree](search-tree.md): a legal stay action at a nonterminal state already suffices. A [graph search](graph-search.md) instead records explored states to control repetitions. Confusing these models changes termination and completeness claims.
