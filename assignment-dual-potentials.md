# Assignment dual potentials

↑ **Parent:** [Assignment problem](assignment-problem.md)

These feasible potentials give the lower bound $\sum_i\lambda_i-\sum_j\mu_j$ on every assignment cost. An assignment using only equality edges attains this bound and is optimal by [weak duality](weak-duality.md) and [complementary slackness](complementary-slackness.md).
