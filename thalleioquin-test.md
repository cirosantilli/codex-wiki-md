# Thalleioquin test

↑ **Parent:** [Quinine](quinine.md)

An emerald-green colour reaction obtained by treating a suitable [quinine](quinine.md) solution with chlorine or bromine followed by [Ammonia](ammonia.md). The 1867 British test specifies chlorine.
