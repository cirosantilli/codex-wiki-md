# Phase coherence length

↑ **Parent:** [Quantum transport](quantum-transport.md)

The characteristic distance over which phase-breaking processes suppress electron-path interference. For diffusion, $L_\phi\sim\sqrt{D\tau_\phi}$; ballistic phase propagation instead gives a scale $v\tau_\phi$. This differs from the elastic [mean free path](mean-free-path.md), since elastic scattering can change momentum while retaining coherence.
