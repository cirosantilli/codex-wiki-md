# Invariant measure

↑ **Parent:** [Ergodic theory](ergodic-theory.md)

For a measurable transformation $T$, a [measure](measure.md) is invariant if the [pushforward measure](pushforward-measure.md) equals the original [measure](measure.md), or equivalently $\mu(T^{-1}A)=\mu(A)$ for every measurable $A$. This is the [measure](measure.md) used in a [measure-preserving system](measure-preserving-system.md).
