# Stiction

↑ **Parent:** [Adhesion](adhesion.md)

Unwanted sticking that prevents intended relative motion. In [surface micromachining](surface-micromachining.md), a receding [liquid](liquid.md) meniscus can pull a compliant released beam onto the substrate; [adhesion](adhesion.md) can then keep it there. Avoiding a liquid-vapor drying interface addresses one route to [stiction](stiction.md), but does not remove contact [adhesion](adhesion.md) during use.
