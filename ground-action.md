# Ground action

↑ **Parent:** [Action schema](action-schema.md)

An action with no unbound object [variables](variable-mathematics.md). Its [precondition](precondition.md) and effect sets consist of fixed ground facts. [Action grounding](action-grounding.md) an [action schema](action-schema.md) over a finite object universe creates one candidate action for each type-correct parameter tuple, after any static filtering; a time-indexed encoding then creates copies or [variables](variable-mathematics.md) for individual action occurrences.
