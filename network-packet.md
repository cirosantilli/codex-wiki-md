# Network packet

↑ **Parent:** [Packet switching](packet-switching.md)

A [network packet](network-packet.md) carries a unit of data together with [protocol](communication-protocol.md) information used to interpret or deliver it. [Internet Protocol](internet-protocol.md) carries datagrams; transport and application messages can span several such [packets](network-packet.md).
