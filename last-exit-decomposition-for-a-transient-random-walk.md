# Last-exit decomposition for a transient random walk

↑ **Parent:** [Transient graph](transient-graph.md)

A last-exit decomposition partitions a transient path event according to the final visit to a finite set. Reversing the finite path before that visit and using [detailed balance](detailed-balance.md) converts last-exit probabilities into hitting probabilities weighted by an [equilibrium measure of a finite set](equilibrium-measure-of-a-finite-set.md).
