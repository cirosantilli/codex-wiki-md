# Polynomial function

↑ **Parent:** [Polynomial](polynomial-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Polynomial_function)

A polynomial function is the [function](function-split.md) obtained by evaluating a [polynomial](polynomial-split.md) on a specified [ring](ring.md) or [field](field.md). Distinct [polynomials](polynomial-split.md) can induce the same polynomial function over a [finite field](finite-field.md); for example, $x^p$ and $x$ agree on $\mathbb F_p$.

Over $\mathbb F_2$, the nonzero formal [polynomial](polynomial-split.md) $X^2-X$ evaluates to zero at both possible inputs, zero and one. It therefore induces the same [polynomial function](polynomial-function.md) as the zero [polynomial](polynomial-split.md), despite having different [coefficients](coefficient.md) and [polynomial degree](degree-of-a-polynomial.md). Over an infinite [field](field.md), equality at every input forces equality of [polynomials](polynomial-split.md) by the [root bound for a polynomial](lagrange-root-bound-over-a-field.md). The distinction matters whenever a representation is supposed to identify the function uniquely.
