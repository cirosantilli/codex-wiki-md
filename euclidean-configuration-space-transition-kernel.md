# Euclidean configuration-space transition kernel

↑ **Parent:** [Configuration-space path integral](configuration-space-path-integral.md)

For $H=p^2/(2m)+V(q)$, time slicing gives a [Euclidean path integral](euclidean-path-integral.md) over paths with the specified endpoints and action $S_E=\int[m\dot q^2/2+V(q)]dt$. Each step contributes normalization $(m/(2\pi\hbar\delta))^{1/2}$. This normalization fixes the units and endpoint factors of the kernel, which differ from amplitudes between normalized localized wavepackets.
