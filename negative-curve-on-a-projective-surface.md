# Negative curve on a projective surface

↑ **Parent:** [Smooth projective surface](smooth-projective-surface.md)

A negative curve is an irreducible [algebraic curve](algebraic-curve.md) on a smooth projective surface whose [self-intersection number](self-intersection-number.md) is negative. The negativity prevents it from moving in a nontrivial effective linear system and constrains how many curves can represent a fixed numerical class.
