# Phase vortex

↑ **Parent:** [Topological defect](topological-defect.md)

A vortex is a topological defect around which the phase of a complex [order parameter](order-parameter.md) has nonzero integer winding. In two dimensions an isolated vortex in a phase-only model has energy proportional to the logarithm of the system size.

The integer $q$ is a [winding number](winding-number.md): a counterclockwise circuit returns the same complex [order parameter](order-parameter.md) after its angle changes by $2\pi q$. Smooth changes that keep the [order parameter](order-parameter.md) nonzero on that circuit cannot change $q$. In a continuum [superfluid](superfluid.md), the core suppresses the magnitude, allowing the winding obstruction to end there; in an [XY model](xy-model.md) the microscopic core instead lies beyond the smooth-field approximation. The [vortex-antivortex binding](vortex-antivortex-binding.md) figure illustrates a locally nonzero charge with zero charge on a surrounding large circuit.
