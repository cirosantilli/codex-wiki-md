# Phase vortex

↑ **Parent:** [Topological defect](topological-defect.md)

A vortex is a topological defect around which the phase of a complex [order parameter](order-parameter.md) has nonzero integer winding. In two dimensions an isolated vortex in a phase-only model has energy proportional to the logarithm of the system size.
