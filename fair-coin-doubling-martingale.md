# Fair-coin doubling martingale

↑ **Parent:** [Martingale](martingale-split.md)

For fair [independent and identically distributed random variables](independent-and-identically-distributed-random-variables.md) $\xi_j$ with the [Bernoulli distribution](bernoulli-distribution.md), $M_n=2^n\mathbf1_{\{\xi_1=\cdots=\xi_n=1\}}$ is a nonnegative [martingale](martingale-split.md). It has [almost sure convergence](almost-sure-convergence.md) to zero but $\mathbb E M_n=1$, so it lacks [convergence in L1](convergence-in-l1.md).
