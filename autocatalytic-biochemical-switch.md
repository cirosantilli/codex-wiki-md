# Autocatalytic biochemical switch

↑ **Parent:** [Autocatalysis](autocatalysis.md)

An autocatalytic biochemical switch uses bistability and a transient input to move a system from one stable concentration to another. A [saddle-node bifurcation](saddle-node-bifurcation.md) supplies a threshold above which the low-concentration equilibrium disappears.
