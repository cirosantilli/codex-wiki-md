# Type signature

↑ **Parent:** [Type system](type-system.md)

The type-level description of a value or operation, including parameter and result types. A [type signature](type-signature.md) can rule out some invalid uses, but ordinary type annotations alone do not express every [precondition](precondition.md), [postcondition](postcondition.md) or relationship to an abstract [program state](program-state.md).
