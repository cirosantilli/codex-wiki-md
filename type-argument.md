# Type argument

↑ **Parent:** [Type parameter](type-parameter.md)

A type substituted for a [type parameter](type-parameter.md) when a generic declaration is instantiated. A type argument must satisfy the declaration's upper and lower bounds. It is distinct from an ordinary run-time argument supplied to a [function](function-split.md) call.
