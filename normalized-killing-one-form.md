# Normalized Killing one-form

↑ **Parent:** [Hypersurface orthogonality](hypersurface-orthogonality.md)

For a non-null [Killing vector field](killing-vector-field.md) $V$ of a [Levi-Civita connection](levi-civita-connection.md), [hypersurface orthogonality](hypersurface-orthogonality.md) implies that $\eta=V^\flat/F$, with $F=g(V,V)$, is a [closed differential form](closed-differential-form.md). The [Killing equation](killing-equation.md) and $V^\flat\wedge dV^\flat=0$ give $2F\nabla_\mu V_\nu=V_\nu\partial_\mu F-V_\mu\partial_\nu F$, whence $d\eta=0$. The [Poincaré lemma](poincare-lemma.md) gives $\eta=d\phi$ locally. For a timelike $V$, $\phi$ supplies local static time coordinates. This does not assert global exactness.
