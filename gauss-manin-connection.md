<h1 id="gauss-manin-connection">Gauss–Manin connection</h1>

↑ **Parent:** [Variation of Hodge structure](variation-of-hodge-structure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gauss–Manin_connection)

The flat connection on the complexified fibre-cohomology [local system](local-system.md) differentiates cohomology classes using topological parallel transport. For a smooth proper holomorphic family, relative de Rham cohomology identifies it with the connecting morphism obtained by retaining one base differential in the absolute de Rham complex.
