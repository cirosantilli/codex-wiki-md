# Logical variable

↑ **Parent:** [Logical formula](logical-formula.md)

A [logical variable](logical-variable.md) is a symbol whose value is supplied by the semantics of a [logical language](formal-language.md). A [propositional variable](propositional-variable.md) receives a [truth value](truth-value.md) under a [Boolean valuation](boolean-valuation.md). An individual [variable](logical-variable.md) of [first-order logic](first-order-logic.md) receives an element of a [structure](first-order-structure.md) under an [assignment](assignment-in-a-first-order-structure.md). These are different kinds of [variable](logical-variable.md) and should not be identified.
