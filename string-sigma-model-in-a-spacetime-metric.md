# String sigma model in a spacetime metric

↑ **Parent:** [Polyakov action](polyakov-action.md)

Replacing the flat target metric in the [Polyakov action](polyakov-action.md) by a [spacetime metric](spacetime-metric.md) $g_{\mu\nu}(X)$ gives the displayed string sigma model. The embedding fields $X^\mu$ map the [worldsheet](worldsheet.md) into target spacetime, while $h_{ab}$ is an independent [worldsheet metric](worldsheet-metric.md). Classical [worldsheet diffeomorphisms](worldsheet-diffeomorphism.md) and [Weyl transformations](weyl-transformation.md) permit [conformal gauge](conformal-gauge.md); quantum consistency additionally requires vanishing [sigma-model beta functions](sigma-model-beta-function.md).
