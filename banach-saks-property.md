# Banach-Saks property

↑ **Parent:** [Banach space](banach-space-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Banach-Saks_property)

A [Banach space](banach-space-split.md) has the Banach-Saks property if every bounded [sequence](sequence.md) contains a [subsequence](subsequence.md) whose arithmetic averages converge in [norm](norm.md). The weak Banach-Saks property requires this only for weakly convergent sequences. The [weak Banach–Saks theorem in a Hilbert space](weak-banach-saks-theorem-in-a-hilbert-space.md) establishes that weak version in [Hilbert spaces](hilbert-space-split.md).
