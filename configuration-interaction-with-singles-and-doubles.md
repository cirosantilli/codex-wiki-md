# Configuration interaction with singles and doubles

↑ **Parent:** [Configuration interaction](configuration-interaction.md)

[configuration interaction](configuration-interaction.md) retaining a reference [determinant](determinant.md) and its single and double excitations. Conventional matrix-vector iterations have leading $O(o^2v^4)$ work for occupied and virtual dimensions $o,v$, hence $O(N^6)$ when both grow with system size. Truncated [CI](configuration-interaction.md) is not generally size extensive.
