# IPC endpoint

↑ **Parent:** [Inter-process communication](inter-process-communication.md)

A communication object on which [software threads](thread-computing.md) send or receive [IPC](inter-process-communication.md) messages. In [seL4](sel4.md), an [IPC endpoint](ipc-endpoint.md) is an [operating-system kernel](kernel-operating-system.md) object with waiting senders or receivers; access requires a suitable [security capability](capability-computer-security.md).
