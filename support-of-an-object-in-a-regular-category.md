# Support of an object in a regular category

↑ **Parent:** [Regular category](regular-category.md)

The support of an object $A$ in a [regular category](regular-category.md) is the [subterminal object](subterminal-object.md) appearing as the [image of a morphism in a regular category](image-of-a-morphism-in-a-regular-category.md) of $A\to1$. A [regular functor](regular-functor.md) preserves this construction. In the [Category of sets](category-of-sets.md), the support is the empty set if $A$ is empty and a singleton otherwise.
