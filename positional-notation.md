# Positional notation

↑ **Parent:** [Integer](integer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Positional_notation)

In positional notation of base $b$, a digit string $d_nd_{n-1}\cdots d_0$ represents $\sum_{j=0}^nd_jb^j$.
