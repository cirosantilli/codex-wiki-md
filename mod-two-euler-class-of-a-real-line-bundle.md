# Mod-two Euler class of a real line bundle

↑ **Parent:** [Real line bundle](real-line-bundle.md)

For a real line bundle, the mod-two Euler class is its top [Stiefel–Whitney class](stiefel-whitney-class.md), namely $w_1(L)\in H^1(X;\mathbb F_2)$. Its evaluation on a closed curve records whether parallel transport reverses the fiber orientation.
