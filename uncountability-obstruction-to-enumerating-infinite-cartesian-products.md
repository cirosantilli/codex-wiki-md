# Uncountability obstruction to enumerating infinite Cartesian products

↑ **Parent:** [Cartesian product](cartesian-product.md)

An infinite [Cartesian product](cartesian-product.md) of finite [sets](set-split.md) need not admit any complete [list](list-abstract-data-type.md) enumeration. For the repeated binary factor, suppose the output [lists](list-abstract-data-type.md) all sequences as $z_0,z_1,\ldots$. Define a sequence by $b_i=1-z_i(i)$. It is a valid binary sequence but differs from the $i$-th output at coordinate $i$, a contradiction. This is [Cantor's diagonal argument](cantor-s-diagonal-argument.md). Consequently fair binary products can recursively enumerate the choices from finitely many possibly infinite [lists](list-abstract-data-type.md), but cannot solve the unrestricted infinite-family specification. A finite-family [algorithm](algorithm-split.md)'s restriction must be explicit.
