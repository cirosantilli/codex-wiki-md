# Rosser predicates in inconsistent theories depend on proof order

↑ **Parent:** [Rosser proof-order dependence](rosser-proof-order-dependence.md)

If a [first-order theory](first-order-theory.md) proves both $A$ and $\neg A$, the external truth of its [Rosser provability predicate](rosser-provability-predicate.md) for $A$ depends on which side has the earlier [formal proof](formal-proof.md) code. A reserved least code for a [formal proof](formal-proof.md) of $\neg A$ makes the Rosser assertion false. Reserving the least code for a [formal proof](formal-proof.md) of $A$ makes it true. These are legitimate effective renumberings of the same [formal proofs](formal-proof.md). Inconsistent [first-order theories](first-order-theory.md) therefore require an explicit proof-order convention.
