# Combinatorial explosion

↑ **Parent:** [Time complexity](time-complexity.md)

A combinatorial explosion is a rapid increase in the number of candidates generated by a search over combinations, often exponential or factorial in an input parameter. For example, listing all [subsets](subset.md) of an $n$-element [set](set-split.md) produces $2^n$ candidates, while listing all [permutations](permutation.md) produces $n!$ candidates. In contrast, listing only fixed-size $q$-element [subsets](subset.md) has [time complexity](time-complexity.md) at least $\binom nq=\Theta(n^q)$ for fixed $q$: potentially large, but polynomial rather than exponential in $n$.
