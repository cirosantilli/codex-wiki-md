# Feasible payoff set

↑ **Parent:** [Repeated game](repeated-game.md)

The [convex hull](convex-hull.md) of the stage game's attainable [payoff](payoff.md) vectors. Public randomization or deterministic sequences with prescribed limiting frequencies produce such average [payoffs](payoff.md). It can be larger than the set attainable using independent [mixed strategies](mixed-strategy.md) in a single stage.
