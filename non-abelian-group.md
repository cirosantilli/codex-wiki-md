# Non-abelian group

↑ **Parent:** [Group](group-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Non-abelian_group)

A non-abelian group is a [group](group-split.md) containing elements $a,b$ for which $ab\ne ba$.
