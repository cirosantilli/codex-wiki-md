# Irreducible scheme

↑ **Parent:** [Scheme](scheme.md)

An irreducible [scheme](scheme.md) is one whose underlying [topological space](topological-space.md) is a nonempty [irreducible topological space](irreducible-topological-space.md). It can have [nilpotent elements](nilpotent.md) in its [structure sheaf](structure-sheaf-of-a-scheme.md); irreducibility concerns only the topology. A [reduced scheme](reduced-scheme.md) is an [integral scheme](integral-scheme.md) precisely when it is irreducible.
