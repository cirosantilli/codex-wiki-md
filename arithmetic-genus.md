# Arithmetic genus

↑ **Parent:** [Algebraic curve](algebraic-curve.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Arithmetic_genus)

The [arithmetic genus](arithmetic-genus.md) of a proper curve $C$ is $p_a(C)=1-\chi(C,\mathcal O_C)$. For an integral projective curve over an algebraically closed field, $H^0(C,\mathcal O_C)=k$, so $p_a=h^1\ge0$. Its finite normalization has $p_a(C)=g(C^\nu)+\operatorname{length}(\nu_*\mathcal O_{C^\nu}/\mathcal O_C)$. Hence [arithmetic genus](arithmetic-genus.md) zero forces the curve to be smooth and rational.
