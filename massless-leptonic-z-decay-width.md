# Massless leptonic Z decay width

↑ **Parent:** [Z boson](z-boson.md)

For a vertex $(g/c_W)\gamma^\mu(c_V-c_A\gamma^5)$ into one massless color-singlet particle-antiparticle pair, the [massive-vector spin average](massive-vector-spin-average.md) and [two-body Lorentz-invariant phase space](two-body-lorentz-invariant-phase-space.md) give $\Gamma=g^2m_Z(c_V^2+c_A^2)/(12\pi c_W^2)$. With [Standard Model](standard-model-split.md) [neutral-current vector and axial couplings](neutral-current-vector-and-axial-couplings.md), one [neutrino](neutrino.md) flavor has $\Gamma_\nu=g^2m_Z/(96\pi c_W^2)$ and one charged-[lepton](lepton.md) flavor has $\Gamma_\ell=\Gamma_\nu(1-4s_W^2+8s_W^4)$. [Chiral projectors](chiral-projector.md) already remove inactive [neutrino](neutrino.md) helicities. These are tree-level massless results.
