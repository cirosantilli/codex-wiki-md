# Vector surface element of a graph

↑ **Parent:** [Surface integral](surface-integral.md)

The graph $z=g(x,y)$ has upward-oriented vector area element $d\mathbf S=(-g_x,-g_y,1)\,dx\,dy$ and scalar area element $dS=\sqrt{1+g_x^2+g_y^2}\,dx\,dy$. These follow from the [cross product](cross-product.md) of the parametrization derivatives $(1,0,g_x)$ and $(0,1,g_y)$. The vector element is used in flux [surface integrals](surface-integral.md) and [Stokes theorem](stokes-theorem.md); reversing orientation changes its sign.
