# Nondeterministic space complexity class

↑ **Parent:** [Space complexity](space-complexity.md)

Languages accepted by [Nondeterministic Turing machines](nondeterministic-turing-machine.md) using $O(s(n))$ work space on every computation path, with acceptance defined by existence of an accepting path. Bounded-space loops do not prevent the reachability interpretation in the finite [configuration graph](configuration-graph.md).
