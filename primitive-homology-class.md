# Primitive homology class

↑ **Parent:** [Homology (mathematics)](homology-split.md)

A positive-degree class whose reduced [homology](homology-split.md) diagonal vanishes. In a torsion-free [homology](homology-split.md) Hopf algebra, powers of an even primitive class have binomial diagonals. Dualizing that diagonal produces the multiplication of a [divided power algebra](divided-power-algebra.md).
