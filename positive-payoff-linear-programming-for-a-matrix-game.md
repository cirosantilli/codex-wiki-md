# Positive-payoff linear programming for a matrix game

↑ **Parent:** [Matrix game](matrix-game.md)

When every entry of a [payoff matrix](payoff-matrix.md) $B$ is positive, its game value $v$ is positive. Setting $x=p/v$ converts the row player's [probability](probability.md) vector and guaranteed value into the displayed [linear program](linear-programming.md), whose optimum is $1/v$. Conversely normalizing a feasible $x$ gives a [mixed strategy](mixed-strategy.md) guaranteeing $1/(\mathbf1^Tx)$. The dual maximizes $\mathbf1^Ty$ under $By\le\mathbf1$, $y\ge0$ and recovers the column strategy by normalization. Adding a constant to every payoff preserves [Nash equilibria](nash-equilibrium.md) and lets this positive-payoff formulation handle general finite [zero-sum games](zero-sum-game.md).
