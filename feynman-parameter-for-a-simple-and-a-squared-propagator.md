# Feynman parameter for a simple and a squared propagator

↑ **Parent:** [Feynman parameter](feynman-parameter.md)

Differentiate $1/(AB)=\int_0^1[xA+(1-x)B]^{-2}dx$ with respect to $B$ to obtain the displayed identity. The squared denominator supplies the factor $2(1-x)$. Changing the parameter to $1-x$ also changes which denominator carries each weight; its use must be consistent with the shifted [mass parameter](mass.md).
