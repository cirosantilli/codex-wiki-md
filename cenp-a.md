# CENP-A

↑ **Parent:** [Histone variant](histone-variant.md)

The centromere-associated histone-H3 variant supporting [kinetochore](kinetochore.md) assembly. Its genomic occupancy helps mark centromeric identity, which can persist without one universal underlying repeat sequence.
