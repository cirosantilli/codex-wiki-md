# Uniform private-value first-price bidding equilibrium

↑ **Parent:** [First-price sealed-bid auction](first-price-sealed-bid-auction.md)

For $n\geq2$ [risk-neutral](risk-neutrality.md) bidders with independent uniform valuations on $[0,1]$, this rule is a symmetric [Bayesian Nash equilibrium](bayesian-nash-equilibrium.md). If opponents use $\beta(v)=av$, a bid $b\in[0,a]$ has expected utility $(v-b)(b/a)^{n-1}$. Its derivative has the sign of $(n-1)v-nb$, so with $a=(n-1)/n$ the best bid is $av$. Bids above $a$ guarantee winning but only increase payment. The type-$v$ equilibrium utility is $v^n/n$.
