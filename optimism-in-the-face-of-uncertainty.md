# Optimism in the face of uncertainty

↑ **Parent:** [Online learning](online-learning.md)

A decision principle that maximizes possible reward jointly over an action and a parameter in a [confidence set](confidence-region.md). On the event that the set contains the true parameter, the reward predicted for this selected pair is at least the true optimal reward. This inequality bounds [pseudoregret](pseudoregret.md) by the width of the [confidence set](confidence-region.md) in the selected action's direction. For an $L$-[Lipschitz continuous](lipschitz-continuity.md) reward link and a radius-$\beta$ [confidence ellipsoid](confidence-ellipsoid.md), [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) and the [triangle inequality](triangle-inequality.md) bound that width by $2L\beta\sqrt{x^TV^{-1}x}$.
