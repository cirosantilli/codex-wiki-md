# Signed permutation matrix

↑ **Parent:** [Permutation matrix](permutation-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Signed_permutation_matrix)

A signed permutation matrix has exactly one nonzero entry in each row and column, and every nonzero entry is $1$ or $-1$. It is a product of a diagonal sign matrix and a [permutation matrix](permutation-matrix.md).
