# Statistical classification

↑ **Parent:** [Machine learning](machine-learning.md)

Assignment of observations to categories using measured features and a statistical rule. In geological [remote sensing](remote-sensing.md), features can be multispectral pixel values or derived [spectral reflectance](spectral-reflectance.md) ratios; known field samples provide training labels and independent observations assess errors. Classification boundaries need not coincide with [lithological contacts](lithological-contact.md) when illumination or cover dominates the signal.
