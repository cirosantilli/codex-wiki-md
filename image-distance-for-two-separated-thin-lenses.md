# Image distance for two separated thin lenses

↑ **Parent:** [Thin lens](thin-lens.md)

Use positive distances for a real incident object and a real outgoing image. The first [thin lens](thin-lens.md) makes an image at $v_1=f_1d_1/(d_1-f_1)$. The second has object distance $L-v_1$, possibly negative, and the [thin lens](thin-lens.md) equation gives the displayed expression. At $L=0$ it becomes $d_2=Fd_1/(d_1-F)$ with $F^{-1}=f_1^{-1}+f_2^{-1}$. For $d_1>0$, a real final image requires both $F>0$ and $d_1>F$; the inequality alone is insufficient when $F<0$.
