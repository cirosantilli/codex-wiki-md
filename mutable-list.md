# Mutable list

↑ **Parent:** [Linked list](linked-list.md)

A [linked list](linked-list.md) whose links are held in [ML reference type](ml-reference-type.md) cells and may be changed. Deleting a node updates the link that reaches it, including the root link when the head is removed. Aliases of links observe these mutations; no fresh list spine is needed for destructive filtering.
