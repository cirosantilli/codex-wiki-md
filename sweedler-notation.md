# Sweedler notation

↑ **Parent:** [Coalgebra](coalgebra.md)

The notation $\Delta h=\sum h_{(1)}\otimes h_{(2)}$ suppresses the summation index of a [comultiplication](comultiplication.md); iterated indices use coassociativity. For a [comodule](comodule.md), write $\rho(u)=\sum u_{(0)}\otimes u_{(1)}$.
