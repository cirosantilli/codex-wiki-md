# Polled input-output

↑ **Parent:** [Operating system](operating-system.md)

A processor checks device status explicitly, typically repeatedly, until service is possible. Frequent predictable events or very short waits can make polling cheaper than an [interrupt](interrupt.md). Infrequent or long waits waste processor time if busy polling is used.
