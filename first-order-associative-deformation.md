# First-order associative deformation

↑ **Parent:** [Formal associative deformation](formal-associative-deformation.md)

The order-$\varepsilon$ part of [associativity](associative-property.md) is $af(b,c)-f(ab,c)+f(a,bc)-f(a,b)c=0$, so $f$ is a [Hochschild cocycle](hochschild-cocycle.md). A change of coordinates $T=1+\varepsilon g$ changes $f$ to $f+\delta g$. Therefore equivalence classes of first-order associative deformations of a fixed underlying algebra are its second [Hochschild cohomology](hochschild-cohomology.md). Unital deformations use normalized cochains.
