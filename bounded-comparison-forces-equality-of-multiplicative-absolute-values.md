# Bounded comparison forces equality of multiplicative absolute values

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

If two multiplicative [absolute values on a field](absolute-value-algebra.md) satisfy a comparison with fixed positive constants $c,C$, apply it to $x^n$ and take $n$th roots. Letting $n\to\infty$ eliminates both constants. This stronger bounded comparison differs from equivalence merely as topologies: replacing an absolute value by its square generally preserves topology but not equality.
