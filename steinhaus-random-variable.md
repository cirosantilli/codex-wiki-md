# Steinhaus random variable

↑ **Parent:** [Continuous uniform distribution](continuous-uniform-distribution.md)

A Steinhaus random variable is uniformly distributed on the complex unit circle. It can be generated as $\epsilon\cos\theta+i\delta\sin\theta$ using independent signs $\epsilon,\delta$ and an independent uniform angle $\theta\in[0,\pi/2]$. This conditional sign representation transfers [Rademacher sum](rademacher-sum.md) inequalities to random complex phases.
