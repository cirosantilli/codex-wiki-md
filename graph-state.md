# Graph state

↑ **Parent:** [Stabilizer state](stabilizer-state.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Graph_state)

For an undirected graph $G=(V,E)$, the graph state is

$$
|G\rangle=\prod_{(i,j)\in E}CZ_{ij}|+\rangle^{\otimes|V|}.
$$
