# Position probability

↑ **Parent:** [Born rule](born-rule.md)

For a normalized [wavefunction](wave-function-split.md) $\psi(x)$, the probability of a [position measurement](position-measurement.md) lying in a measurable set $A$ is $\int_A|\psi(x)|^2dx$. It is a spatial-projection probability and differs from an [energy measurement](energy-measurement.md) outcome probability.
