# Compact object (mathematics)

↑ **Parent:** [Category](category-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Compact_object_(mathematics))

A [compact object (mathematics)](compact-object-mathematics.md) is an object whose represented [Hom functor](hom-functor.md) preserves filtered [colimits](colimit.md). This preservation condition differs from the extra right-adjoint property defining a [tiny object](tiny-object.md).
