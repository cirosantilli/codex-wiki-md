# Singly linked list

↑ **Parent:** [Linked list](linked-list.md)

A [linked list](linked-list.md) in which each node stores a successor reference. Forward traversal is direct, but finding a predecessor generally requires a scan unless it is retained separately. A head and tail together with a cached length support constant-time [FIFO queue](fifo-queue.md) operations.
