# Strict inequality

↑ **Parent:** [Inequality (mathematics)](inequality-mathematics.md)

An ordered comparison such as $a<b$, excluding equality. In a sorted search, strict comparisons distinguish regions that can be discarded from boundary positions that may contain an equal target.
