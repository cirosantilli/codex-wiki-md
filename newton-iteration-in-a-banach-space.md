# Newton iteration in a Banach space

↑ **Parent:** [Newton root-finding iteration](newton-root-finding-iteration.md)

For a $C^2$ map $\Phi$ on a [Banach space](banach-space-split.md), define $N(p)=p-[D\Phi(p)]^{-1}\Phi(p)$ wherever the bounded [derivative](derivative.md) is invertible. It solves the local affine approximation to $\Phi=0$. Every zero is a [fixed point](fixed-point.md) of $N$. Near a zero with invertible [derivative](derivative.md), bounded inverses and a locally Lipschitz [derivative](derivative.md) give the [quadratic Newton error bound in a Banach space](quadratic-newton-error-bound-in-a-banach-space.md).
