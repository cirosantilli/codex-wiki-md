# Globally generated line bundle

↑ **Parent:** [Line bundle](line-bundle.md)

A [line bundle](line-bundle.md) is globally generated if at each point some [global section](global-section.md) has a [germ](germ-of-a-sheaf-section.md) generating its [stalk](stalk-of-a-sheaf.md) as a module over the [local ring](local-ring.md). Equivalently its evaluation map from global sections tensored with the [structure sheaf](structure-sheaf-of-a-scheme.md) is surjective.
