# Compactness from uniformly vanishing sequence tails

↑ **Parent:** [Sequentially compact space](sequentially-compact-space.md)

Let $a_m\geq0$ and $a_m\to0$. The set $K=\{x=(x_m):x_m\in\mathbb R,\ |x_m|\leq a_m\}$ is a [compact metric space](compact-metric-space.md) for the [supremum norm](supremum-norm.md) metric. Every member is a sequence tending to zero.

For any sequence in $K$, successively extract a [convergent subsequence](convergent-subsequence.md) in each [compact interval](compact-interval.md) $[-a_m,a_m]$, then take diagonal indices. The coordinate limits define $x\in K$. For any $M$, coordinatewise differences in the tail are bounded by $2\sup_{m>M}a_m$, independently of the sequence index. This tends to zero as $M\to\infty$, while finitely many initial coordinates converge together. Hence the diagonal subsequence converges in the [supremum norm](supremum-norm.md). This proves [sequential compactness](sequentially-compact-space.md), equivalent to [compactness](compact-space.md) for [metric spaces](metric-space.md).
