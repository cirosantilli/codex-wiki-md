# Type II sum

↑ **Parent:** [Bilinear sum](bilinear-sum.md)

A Type II sum has the form $\sum_{d\sim D}\sum_{m\sim M}a_db_mf(dm)$ with two nontrivially weighted variables, both long enough for a [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) and a [large sieve](large-sieve.md) estimate. The [Vaughan identity](vaughan-s-identity.md) supplies this bilinear structure for sums weighted by the [Von Mangoldt function](von-mangoldt-function.md).
