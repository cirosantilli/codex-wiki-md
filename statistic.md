# Statistic

↑ **Parent:** [Statistical inference](statistical-inference-split.md)

A statistic is a measurable function of observed data whose definition does not involve an unknown parameter. It may be scalar or vector valued. [Sufficient statistics](sufficient-statistic.md) summarize all information about a parameter in the conditional-distribution sense.
