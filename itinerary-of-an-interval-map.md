# Itinerary of an interval map

↑ **Parent:** [Tent map](tent-map.md)

Given a finite measurable partition of an interval, the itinerary of $x$ records which partition element contains each iterate $T^n(x)$. Prescribing a finite initial word defines an itinerary cylinder. For the full [tent map](tent-map.md), every length-$N$ binary cylinder has Lebesgue measure $2^{-N}$ up to endpoint conventions, so its itinerary process is a fair i.i.d. [Bernoulli process](bernoulli-distribution.md).
