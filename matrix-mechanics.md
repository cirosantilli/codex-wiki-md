# Matrix mechanics

↑ **Parent:** [Operator formalism](operator-formalism.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Matrix_mechanics)

[Matrix mechanics](matrix-mechanics.md) represents an [observable](observable.md) by an array of [matrix elements](matrix-element.md) between chosen [quantum states](quantum-state.md). In an [orthonormal basis](orthonormal-basis.md) of [energy eigenstates](energy-eigenstate.md), each a [stationary state](stationary-state.md), the diagonal entries of the [Hamiltonian operator](hamiltonian-quantum-mechanics.md) are the [energy levels](energy-level.md); off-diagonal entries of other [observables](observable.md) describe couplings between those states. The same array can therefore answer two different questions: which values can a measurement return, and which pairs of [energy eigenstates](energy-eigenstate.md) can a specified interaction connect? The [eigenvalues](eigenvalue.md) answer the first question; the relevant [matrix elements](matrix-element.md), together with the [energy](energy-split.md) differences, answer the second.

This makes [linear algebra](linear-algebra-split.md) a practical language for [atomic physics](atomic-physics-split.md). One can calculate [energy levels](energy-level.md), [electric-dipole selection rules](electric-dipole-selection-rule.md) and [probability amplitudes](probability-amplitude.md) for transitions without assigning an [electron](electron.md) an unobserved classical [orbit](orbit-dynamical-system.md). The three-state example below separates a missing optical coupling from a missing [energy level](energy-level.md); the [finite oscillator commutator boundary defect](finite-oscillator-commutator-boundary-defect.md) explains why a finite array requires care when approximating a [quantum harmonic oscillator](quantum-harmonic-oscillator-split.md).
