# Shock filter for image enhancement

↑ **Parent:** [Image edge enhancement](image-edge-enhancement.md)

The formal shock-filter equation $u_t=-\operatorname{sign}(\Delta u)|\nabla u|$ steepens transitions around inflection boundaries. It is a Hamilton–Jacobi-type transport mechanism rather than positive diffusion. Combining it with controlled forward [image smoothing](image-smoothing.md) limits noise amplification.
