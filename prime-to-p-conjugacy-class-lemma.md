# Prime-to-p conjugacy class lemma

↑ **Parent:** [Class equation](class-equation.md)

For a [finite group](finite-group.md) with trivial [centre of a group](center-of-a-group.md) and a prime divisor $p$ of its order, some nonidentity [conjugacy class](conjugacy-class.md) has size [coprime](coprime-integers.md) to $p$. Otherwise the [class equation](class-equation.md) would give $|G|\equiv1\pmod p$. Primality is essential: in the [symmetric group](symmetric-group.md) $S_3$, neither nonidentity class size is coprime to the composite divisor $6$.
