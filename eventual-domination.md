# Eventual domination

↑ **Parent:** [Set theory](set-theory-split.md)

For functions $f,g:\omega\to\omega$, write $f\leq^*g$ when $f(n)\leq g(n)$ for all sufficiently large $n$. A [dominating family](dominating-family.md) is cofinal for this relation.
