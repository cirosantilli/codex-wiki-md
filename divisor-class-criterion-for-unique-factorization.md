# Divisor-class criterion for unique factorization

↑ **Parent:** [Divisor class group](divisor-class-group.md)

A [Noetherian ring](noetherian-ring.md) that is an [integrally closed domain](integrally-closed-domain.md) is a [unique factorization domain](unique-factorization-domain.md) exactly when its [divisor class group](divisor-class-group.md) vanishes. Indeed, vanishing says every [prime Weil divisor](prime-weil-divisor.md), equivalently every height-one prime ideal, is principal.
