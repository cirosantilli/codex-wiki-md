# Page frame

↑ **Parent:** [Paging](paging.md)

A slot in main [computer memory](computer-memory.md) that can hold one [memory page](memory-page.md) of the selected size. Physical frame number `0x07` with 256-[byte](byte.md) [page frames](page-frame.md) starts at [physical address](physical-address.md) `0x0700`.
