# Closure of a point is irreducible

↑ **Parent:** [Irreducible closed subset](irreducible-closed-subset.md)

In any [topological space](topological-space.md), the [closure](closure-topology.md) $C$ of a point $x$ is an [irreducible closed subset](irreducible-closed-subset.md). If $C=A\cup B$ with $A,B$ closed in $C$, then both are [closed subsets](closed-set.md) of the ambient [topological space](topological-space.md). One contains $x$, so it contains all of $C$ by the definition of [closure](closure-topology.md). Equivalently, $x$ is a [generic point](generic-point.md) of $C$. This does not assert that every [irreducible closed subset](irreducible-closed-subset.md) of an arbitrary [topological space](topological-space.md) has a [generic point](generic-point.md).
