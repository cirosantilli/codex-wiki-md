# Best approximation in a normed space

↑ **Parent:** [Normed vector space](normed-vector-space.md)

Given $f$ in a [normed vector space](normed-vector-space.md) and a [vector subspace](vector-subspace.md) $U$, an element $p_*\in U$ is a best approximation if $\|f-p_*\|=\inf_{p\in U}\|f-p\|$. Existence is automatic for a finite-dimensional [vector subspace](vector-subspace.md): a minimizing sequence can be bounded by the [triangle inequality](triangle-inequality.md), and a subsequence converges by [compactness](compact-space.md) in finite dimension. An arbitrary infinite-dimensional [vector subspace](vector-subspace.md) need not contain a minimizer. The norm matters: [best uniform approximation](best-uniform-approximation.md) uses the [supremum norm](supremum-norm.md), while $L^1$ approximation minimizes integrated absolute error.
