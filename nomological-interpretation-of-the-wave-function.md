# Nomological interpretation of the wave function

↑ **Parent:** [de Broglie-Bohm theory](de-broglie-bohm-theory.md)

An interpretation treating the universal [wave function](wave-function-split.md) as part of the law governing actual configurations rather than an additional material [field](field.md). The interpretation is motivated partly by the absence of reciprocal configuration-to-wave influence in [Bohmian mechanics](de-broglie-bohm-theory.md).[discussion of the universal wave function as law-like](bohmian-mechanics-and-the-meaning-of-the-wave-function-by-detlef-durr-and-others.md)
