# Metrology

↑ **Parent:** [Physics](physics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Metrology)

[Metrology](metrology.md) asks what a measurement means and how closely it can be reproduced. An instrument reading becomes useful when it is related to a reference through [measurement calibration](measurement-calibration.md), with a stated [measurement uncertainty](measurement-uncertainty.md). Measuring a changing object against a changing ruler makes the problem especially clear: an observed difference contains the responses of both.
