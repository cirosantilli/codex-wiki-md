# Parameter-free definability

↑ **Parent:** [Definable set](definable-set.md)

A [definable set](definable-set.md) has [parameter-free definability](parameter-free-definability.md) when its defining [first-order formula](first-order-formula.md) uses only the original [first-order language](first-order-language.md), with no additional constants naming elements. Constants already present in the language are allowed. Every such set is invariant under all [automorphisms of a first-order structure](automorphism-of-a-first-order-structure.md). For example, zero in the constant-free additive integers is defined by $x+x=x$, while the singleton containing one is not parameter-free definable because negation is an additive automorphism moving it. Invariance is a necessary condition in every structure, and becomes sufficient for finite sets in a countable [omega-saturated model](omega-saturated-model.md).
