# View-invariant object recognition

↑ **Parent:** [Vision](vision.md)

Recognition that preserves object or face identity despite changes in viewpoint. The aim is tolerance together with selectivity: responding identically to every object would be invariant but useless for distinguishing identity. Tolerance may be partial and differ across processing stages.
