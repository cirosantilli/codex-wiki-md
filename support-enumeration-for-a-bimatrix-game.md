# Support enumeration for a bimatrix game

↑ **Parent:** [Bimatrix game](bimatrix-game.md)

Enumerate pairs of [strategy supports](strategy-support.md), solve the equations making each supported action indifferent, then check strict positivity of supported probabilities and all omitted-action payoff inequalities. These conditions suffice for a [Nash equilibrium](nash-equilibrium.md). Under [nondegeneracy of a bimatrix game](nondegeneracy-of-a-bimatrix-game.md), only pairs of equal support size need be tested.
