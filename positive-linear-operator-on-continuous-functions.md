# Positive linear operator on continuous functions

↑ **Parent:** [Continuous linear operator](continuous-linear-operator.md)

A linear map $U:C(K,\mathbb R)\to C(K,\mathbb R)$ is positive when $f\geq0$ implies $Uf\geq0$. This is positivity for the pointwise order, not positivity of a quadratic form. On a compact space, $|Uf|\leq U|f|\leq\|f\|_\infty U1$, so $\|U\|=\|U1\|_\infty$. This makes positive maps especially useful for [uniform approximation](uniform-approximation-split.md).
