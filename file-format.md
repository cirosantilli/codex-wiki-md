# File format

↑ **Parent:** [Computer science](computer-science-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/File_format)

A [file format](file-format.md) specifies how a [binary string](binary-string.md) is interpreted: field order, field widths, permitted values and where decoding stops. A [data compression](data-compression.md) comparison must include all fields required to recover the data.
