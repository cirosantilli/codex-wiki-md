# Ternary Hamming code as a negacyclic code

↑ **Parent:** [Ternary Hamming code](ternary-hamming-code.md)

Set $n=(3^s-1)/2$ and let $\beta$ be a [primitive element of a finite field](primitive-element-of-a-finite-field.md) $\mathbb F_{3^s}$. The powers $1,\beta,\ldots,\beta^{n-1}$ represent every projective point once. Their [kernel](kernel-of-a-linear-map.md) code is a [ternary Hamming code](ternary-hamming-code.md). Since $\beta^n=-1$, its [polynomial](polynomial-split.md) description is a [negacyclic code](negacyclic-code.md), generated by the [minimal polynomial of an algebraic element](minimal-polynomial-of-an-algebraic-element.md) $\beta$ over $\mathbb F_3$.
