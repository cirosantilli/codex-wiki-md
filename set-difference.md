# Set difference

↑ **Parent:** [Set](set-split.md)

The difference consists of the elements of $A$ not belonging to $B$. In [ZF](zermelo-fraenkel-set-theory.md) it exists by [axiom schema of separation](axiom-schema-of-specification.md). It gives complements relative to a fixed tuple domain in [finite relation closure for set-theoretic coding](finite-relation-closure-for-set-theoretic-coding.md).
