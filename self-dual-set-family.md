# Self-dual set family

↑ **Parent:** [Set family](set-family.md)

A [self-dual set family](self-dual-set-family.md) on $[n]$ contains exactly one of $A,A^c$ for every subset $A$. Its relative proportions $a_j$ in complementary uniform levels satisfy $a_{n-j}=1-a_j$. In particular its measure under a uniform random subset is $1/2$.
