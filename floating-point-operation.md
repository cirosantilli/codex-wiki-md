# Floating-point operation

↑ **Parent:** [Floating-point arithmetic](floating-point-arithmetic-split.md)

A floating-point operation is one arithmetic operation on values represented in [floating-point arithmetic](floating-point-arithmetic-split.md). Algorithmic counts commonly count addition, subtraction, multiplication and division separately. A fused multiply-add can therefore count as two arithmetic operations even when executed by one hardware instruction. Such counts describe work, while elapsed time also depends on memory traffic, parallelism and the implementation.
