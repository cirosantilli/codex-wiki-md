# Nef-plus-ample ampleness lemma

↑ **Parent:** [Ample cone](ample-cone.md)

The sum of a [nef](nef-line-bundle.md) real Cartier class and an [ample](ample-line-bundle.md) real Cartier class on a [projective scheme](projective-scheme.md) is [ample](ample-line-bundle.md). By [Kleiman's criterion](kleiman-s-criterion.md), the [ample cone](ample-cone.md) is the interior of the [nef cone](nef-cone.md). If a ball about an [ample](ample-line-bundle.md) class lies in that convex cone, translating it by a [nef](nef-line-bundle.md) class still lies in the cone. The sum is consequently still an interior point.
