# POWER architecture

↑ **Parent:** [Instruction set architecture](instruction-set-architecture.md)

The POWER processor architecture family, whose shared-memory ordering uses dependency rules and barriers such as `sync`, `lwsync` and `isync`. The relevant ordering examples are documented in [Understanding POWER Multiprocessors (2011)](understanding-power-multiprocessors-2011.md).
