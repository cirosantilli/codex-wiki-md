# Sparse map with a default value

↑ **Parent:** [Associative array](associative-array.md)

Represent a total [function](function-split.md) by storing only selected entries of a finite [partial function](partial-function.md) and returning a fixed default for missing keys. A missing payment-count record can denote two zero counts. Storing an explicit default-valued record can have the same observable meaning, so the [abstraction function](abstraction-function.md) need not be injective. Update operations must preserve all unrelated keys and establish the intended change whether or not the key was previously stored.
