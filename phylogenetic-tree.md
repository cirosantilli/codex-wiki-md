# Phylogenetic tree

↑ **Parent:** [Phylogenetics](phylogenetics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Phylogenetic_tree)

A [phylogenetic tree](phylogenetic-tree.md) describes ancestral relationships. In a [probabilistic graphical model](probabilistic-graphical-model.md) on a rooted [tree](tree-graph-theory.md), [latent variables](latent-variable.md) at ancestral vertices are inferred from observations at leaves using [belief propagation](belief-propagation.md).
