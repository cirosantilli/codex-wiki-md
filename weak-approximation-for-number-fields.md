# Weak approximation for number fields

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)

Given finitely many distinct [places of a number field](place-of-a-number-field.md) $v_1,\ldots,v_r$, the diagonal image of $K$ is dense in $\prod_i K_{v_i}$. One can therefore simultaneously prescribe finite congruences and real signs. This is useful in the [ray class exact sequence](ray-class-exact-sequence.md) and in finding representatives of an [ideal class](ideal-class.md) prime to a prescribed finite set of [prime ideals](prime-ideal.md).
