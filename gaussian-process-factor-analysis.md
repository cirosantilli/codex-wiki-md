# Gaussian-process factor analysis

↑ **Parent:** [Factor analysis](factor-analysis.md)

A model combining a linear observation equation with [Gaussian process](gaussian-process-split.md) priors over latent trajectories, allowing shared neural activity and temporal smoothness to be estimated together. Observation-noise assumptions and temporal kernels are substantive choices. The original 2009 demonstration used macaque motor recordings, not episodic-memory recordings.[2009, model formulation and motor-cortex demonstration](gaussian-process-factor-analysis-for-low-dimensional-single-trial-analysis-of-neural-population-activity-by-byron-m-yu-and-others.md)
