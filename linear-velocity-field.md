# Linear velocity field

↑ **Parent:** [Affine velocity field](affine-velocity-field.md)

An [affine velocity field](affine-velocity-field.md) with zero uniform translation. It describes the relative motion about a comoving reference point even when the original [velocity field](velocity-field.md) has a nonzero spatially uniform component.
