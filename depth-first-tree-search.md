# Depth-first tree search

↑ **Parent:** [Depth-first search](depth-first-search.md)

The [tree search](tree-search.md) version of [depth-first search](depth-first-search.md) follows one action history until it ends, then returns to another choice. Repeated states do not automatically stop a branch. An infinite branch can prevent discovery of a goal on a different finite branch, so this method is not generally a [complete search algorithm](complete-search-algorithm.md). A finite [search tree](search-tree.md) restores completeness, but the first successful history need not minimize cost or maximize a terminal reward.
