# Recombination rate

↑ **Parent:** [Genetic recombination](genetic-recombination.md)

The rate of recombination events under the stated scale, for example per genomic interval per generation. It should not be silently equated with a two-marker [recombination fraction](recombination-fraction.md), which can hide multiple exchanges.
