# Microkernel

↑ **Parent:** [Kernel (operating system)](kernel-operating-system.md)

A kernel design retaining a small set of essential mechanisms in privileged code while services communicate across protection boundaries. Isolation and modularity are benefits; extra messages and address-space transitions can cost time compared with a [monolithic kernel](monolithic-kernel.md). Neither architecture alone establishes a universal performance ordering.
