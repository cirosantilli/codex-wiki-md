# Birational linear system criterion for bigness

↑ **Parent:** [Big divisor](big-divisor.md)

A [Cartier divisor](cartier-divisor-split.md) on an integral projective variety is big if and only if some multiple has a [complete linear system of a divisor](complete-linear-system-of-a-divisor.md) giving a rational map birational onto its image. [Kodaira's lemma](kodaira-s-lemma.md) embeds a very ample subsystem in a suitable multiple. Conversely, $n$ [algebraically independent elements](algebraically-independent-elements.md) among the section ratios give $\binom{q+n}{n}$ independent degree-$q$ section monomials, where $n=\dim X$. Smoothness is not necessary.
