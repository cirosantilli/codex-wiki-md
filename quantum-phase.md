# Quantum phase

↑ **Parent:** [Quantum state](quantum-state.md)

Multiplying a quantum state by one global complex phase does not change any measurement probability; relative phases between components can affect interference.

The [global phase](global-phase.md) is common to the whole state; relative phases control interference between state components.
