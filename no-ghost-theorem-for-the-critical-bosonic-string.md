# No-ghost theorem for the critical bosonic string

↑ **Parent:** [Covariant quantization of the bosonic string](covariant-quantization-of-the-bosonic-string.md)

In flat 26-dimensional [bosonic string theory](bosonic-string-theory.md), at ordinary nonzero momentum, take [physical string states](physical-string-state.md) satisfying $L_{n>0}|\psi\rangle=0$ and $(L_0-1)|\psi\rangle=0$. The [inner product](inner-product.md) restricted to these states is positive semidefinite. Quotienting by physical [null string states](null-string-state.md) removes the degeneracy; the resulting [Hilbert space](hilbert-space-split.md) is represented by the 24 transverse [string oscillators](string-oscillator.md). This is a statement about negative-norm matter states, not about removing the auxiliary [Faddeev-Popov ghosts](faddeev-popov-ghost.md). It does not remove the bosonic [tachyon](tachyon.md).
