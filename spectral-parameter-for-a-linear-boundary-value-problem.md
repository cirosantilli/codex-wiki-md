# Spectral parameter for a linear boundary value problem

↑ **Parent:** [Boundary value problem](boundary-value-problem.md)

A complex parameter labels auxiliary solutions of a linear [differential equation](differential-equation-split.md), such as exponential adjoint solutions used in a [global relation for a linear boundary value problem](global-relation-for-a-linear-boundary-value-problem.md). It need not be a discrete [eigenvalue](eigenvalue.md) or a parameter of a nonlinear [Lax pair](lax-pair.md). Analytic dependence on it allows transformed boundary identities to be sampled or inverted.
