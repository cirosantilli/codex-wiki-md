# Cartier class group

↑ **Parent:** [Cartier divisor](cartier-divisor-split.md)

The Cartier class group is the group of Cartier divisors modulo principal Cartier divisors. On an integral scheme it is naturally $H^1(X,\mathcal O_X^*)$.
