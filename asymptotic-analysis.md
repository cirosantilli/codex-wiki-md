# Asymptotic analysis

↑ **Parent:** [Real analysis](real-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Asymptotic_analysis)

Asymptotic analysis compares functions or [sequences](sequence.md) as their argument approaches a limit, using bounds such as [Big O notation](big-o-notation.md) and relations such as [asymptotic equivalence](asymptotic-equivalence.md). It records the leading behavior and the size of errors.
