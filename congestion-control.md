# Congestion control

↑ **Parent:** [Stochastic network](stochastic-network.md)

Congestion control adjusts user transmission rates in response to load signals from shared resources. A resource can compute its price from local aggregate load, while each user sums prices along its route. [Primal congestion potential](primal-congestion-potential.md) and [dual congestion potential](dual-congestion-potential.md) formulations explain equilibrium and stability for suitable monotone response functions.
