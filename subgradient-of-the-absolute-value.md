# Subgradient of the absolute value

↑ **Parent:** [Subgradient](subgradient.md)

The [absolute value function](absolute-value.md) has

$$
\partial|x|=
\begin{cases}
\{\operatorname{sgn}x\},&x\ne0,\\
[-1,1],&x=0.
\end{cases}
$$
