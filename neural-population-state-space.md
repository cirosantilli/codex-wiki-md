# Neural population state space

↑ **Parent:** [Population coding](population-coding.md)

Coordinates describing the joint activity of a neural population, often using one coordinate per cell or fitted latent variable. A trajectory connects states over time. A useful reduced description requires evidence that it retains the neural and behavioral properties relevant to the intended claim.
