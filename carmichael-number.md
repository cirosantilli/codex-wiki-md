# Carmichael number

↑ **Parent:** [Number theory](number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Carmichael_number)

A composite $N$ is Carmichael when $a^{N-1}\equiv1\pmod N$ for every $a$ coprime to $N$.
