# Subtree-size balance

↑ **Parent:** [Balanced binary tree](balanced-binary-tree.md)

The condition that each binary-tree vertex has child [subtrees](subtree.md) whose node counts differ by at most one. Recursively choosing the middle entry of an index interval establishes this condition at every vertex, with exactly one allocated node per entry. No ordering assumption on the stored values is needed for the balance property or for reproducing the input's inorder [sequence](sequence.md).
