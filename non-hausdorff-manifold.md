# Non-Hausdorff manifold

↑ **Parent:** [Topology](topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Non-Hausdorff_manifold)

A [non-Hausdorff manifold](non-hausdorff-manifold.md) is a locally Euclidean [topological space](topological-space.md) for which distinct points need not have disjoint neighborhoods. The real line with two origins is a basic example. Nonseparated algebraic schemes exhibit analogous gluing phenomena, but are not generally topological manifolds.
