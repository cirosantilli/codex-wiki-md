# Labelled combinatorial structure

↑ **Parent:** [Combinatorial structure](combinatorial-structure.md)

A [combinatorial structure](combinatorial-structure.md) whose elements carry distinct labels from a prescribed [finite set](finite-set.md). For example, a [rooted tree](rooted-tree.md) can have labelled [vertices](vertex-graph-theory.md); assigning labels is part of the structure counted by an [exponential generating function](exponential-generating-function.md).
