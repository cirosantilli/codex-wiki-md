<h1 id="huckel-s-rule">Hückel's rule</h1>

↑ **Parent:** [Aromaticity](aromaticity.md)

A monocyclic, approximately planar, continuously conjugated pi system with $4n+2$ pi [electrons](electron.md) has a closed-shell aromatic configuration in the elementary Hückel model, where $n$ is a [nonnegative integer](natural-number.md). Fused systems and [heterocycles](heterocyclic-compound.md) require a specified orbital and [resonance](resonance-chemistry.md) description rather than counting every drawn [double bond](double-bond.md) in each polygon.
