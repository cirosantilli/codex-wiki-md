# Winning-position attractor in an infinite game

↑ **Parent:** [Open determinacy](open-determinacy.md)

Start with positions whose entire extension [cylinder set](cylinder-set.md) lies in the winning [open set](open-set.md). At each successor stage add I-positions with some successor already present and II-positions with every successor already present; take unions at limit [ordinals](ordinal.md). The stable set is the least [fixed point](fixed-point.md) of this [order-preserving](order-preserving-function.md) operation. The first entry [ordinal](ordinal.md) supplies a strictly decreasing rank until the winning prefix is reached.
