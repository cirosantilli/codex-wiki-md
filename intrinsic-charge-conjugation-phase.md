# Intrinsic charge-conjugation phase

↑ **Parent:** [Charge conjugation](charge-conjugation.md)

The phase in a field transformation $\hat C V^\mu\hat C^{-1}=\eta_C V^{\mu\dagger}$. For a real vector [relativistic quantum field](relativistic-quantum-field-split.md), [Hermitian conjugation](hermitian-conjugation.md) restricts this phase to $\pm1$.
