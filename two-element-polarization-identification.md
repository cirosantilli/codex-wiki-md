# Two-element polarization identification

↑ **Parent:** [Quarter-wave plate](quarter-wave-plate.md)

Suppose the unknown ideal elements are a linear [polarizer](polarizer.md) and a [quarter-wave plate](quarter-wave-plate.md), and the two unknown sources are unpolarized and circularly polarized. Test both element orders while rotating their relative axes and monitoring output [intensity](intensity-physics.md). Only circular input followed by the [quarter-wave plate](quarter-wave-plate.md) and then the [polarizer](polarizer.md) gives complete modulation: the plate makes linear [light](light.md) and the analyzer obeys [Malus's law](malus-s-law.md). Polarizer-first output is constant half-intensity because the following lossless plate changes polarization but not [intensity](intensity-physics.md). Unpolarized input is constant in either order. This identifies both elements and both sources without comparing source brightnesses.
