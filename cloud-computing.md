# Cloud computing

↑ **Parent:** [Distributed system](distributed-system.md)

[Cloud computing](cloud-computing.md) offers remotely supplied computing resources and services through a service interface. It can make capacity easier to obtain while moving operational and state dependencies to a provider. A distributed physical implementation can remain centrally controlled.
