# Equilateral bispectrum configuration

↑ **Parent:** [Primordial bispectrum](primordial-bispectrum.md)

An equilateral [primordial bispectrum](primordial-bispectrum.md) configuration has equal external wavenumbers. For a [cubic time-derivative curvature bispectrum](cubic-time-derivative-curvature-bispectrum.md), $S\propto k_1k_2k_3/(k_1+k_2+k_3)^3$ is maximized here at fixed perimeter by the [arithmetic-geometric mean inequality](arithmetic-geometric-mean-inequality.md).
