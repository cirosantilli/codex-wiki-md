# Measurement-independence loophole

↑ **Parent:** [Measurement independence](measurement-independence.md)

A Bell-test loophole in which hidden information determining the device outputs is correlated with the chosen measurement settings. The usual local [CHSH inequality](chsh-inequality.md) averages a common hidden-variable distribution over independently selected settings. If that distribution can instead depend on the selected pair, the four counterfactual assignments need not obey the same averaging argument. An adversary controlling both the devices and their setting generators can exploit this dependence without violating the local-bound proof's actual hypotheses.
