# Group norm element

↑ **Parent:** [Group algebra](group-algebra.md)

The group norm element in the [group algebra](group-algebra.md) $kG$ is $N_G=\sum_{g\in G}g$. It spans the invariant subspace of the left regular [group representation](group-representation.md), and $N_G^2=|G|N_G$. If the [characteristic](characteristic-of-a-field.md) divides $|G|$, a projection from $kG$ onto $kN_G$ would send $N_G$ to both itself and zero, proving that $kG$ is not a [semisimple algebra](semisimple-algebra.md). Its action on indecomposable modules is described by [group norm element detects the trivial projective cover](group-norm-element-detects-the-trivial-projective-cover.md).
