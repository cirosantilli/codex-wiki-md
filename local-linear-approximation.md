# Local linear approximation

↑ **Parent:** [Derivative](derivative.md)

For a [differentiable function](differentiable-function.md), a [local linear approximation](local-linear-approximation.md) replaces nearby values by its value plus its [derivative](derivative.md) times the input change. The error divided by that change tends to zero. It uses the first-order [Taylor polynomial](taylor-polynomial.md); the statement concerns a [limit](limit-of-a-function.md) near the specified point, not a guaranteed approximation far from it.
