# Normal-order reduction

↑ **Parent:** [Lambda calculus](lambda-calculus.md)

A reduction strategy that contracts the leftmost outermost reducible expression first. If a [lambda calculus](lambda-calculus.md) expression has a [beta-normal form](beta-normal-form.md), this strategy reaches it, although the intermediate expressions can be large.
