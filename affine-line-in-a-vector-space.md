# Affine line in a vector space

↑ **Parent:** [Affine subspace](affine-subspace.md)

In a [vector space](vector-space-split.md) over a [field](field.md) $k$, an affine line is a translate of a one-dimensional [vector subspace](vector-subspace.md). Its direction is that [vector subspace](vector-subspace.md), so multiplying $v$ by a nonzero scalar preserves the direction. Over a [finite field](finite-field.md) of size $q$ it contains exactly $q$ distinct points. This usage concerns affine subsets of vector spaces, rather than the [affine line](affine-line.md) as an [affine scheme](affine-scheme.md).
