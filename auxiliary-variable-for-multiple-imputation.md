# Auxiliary variable for multiple imputation

↑ **Parent:** [Multiple imputation](multiple-imputation.md)

A recorded variable included in imputation models to help predict missing values or explain response patterns, even if it is absent from the final substantive model. Useful auxiliaries can improve precision and make [missing at random](missing-at-random.md) more plausible; they cannot establish that assumption from the observed data.
