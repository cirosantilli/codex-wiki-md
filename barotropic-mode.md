# Barotropic mode

↑ **Parent:** [Quasi-geostrophic vertical mode](quasi-geostrophic-vertical-mode.md)

A barotropic mode has horizontal velocity independent of depth. It is the zeroth [quasi-geostrophic vertical mode](quasi-geostrophic-vertical-mode.md) and usually has the largest gravity-wave speed and [Rossby deformation radius](rossby-deformation-radius.md).
