# Symbolic computation

↑ **Parent:** [Artificial intelligence](artificial-intelligence-split.md)

Computation using explicitly structured representations whose elements have identifiable roles, with rules or procedures acting on those structures. Logical [planning](planning.md) is an example. This sense concerns symbolic cognitive architectures rather than only computer algebra; it can be implemented by different physical substrates.
