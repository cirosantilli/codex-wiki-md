# Conformally flat manifold

↑ **Parent:** [General relativity](general-relativity-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Conformally_flat_manifold)

A (pseudo-)[Riemannian manifold](riemannian-manifold.md) is conformally flat if every point has a neighborhood on which the metric is $g=\Omega^2\eta$ for a flat metric $\eta$ and a positive function $\Omega$. This is a local property and does not imply global flatness.
