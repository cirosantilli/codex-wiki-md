# Separative forcing order

↑ **Parent:** [Forcing](forcing-split.md)

In [standard notation for forcing](standard-notation-for-forcing.md), an order is separative if $p\not\leq q$ implies that some $r\leq p$ is incompatible with $q$. Separativity does not imply an [atomless forcing order](atomless-forcing-order.md): the one-point order is separative and has a [forcing atom](forcing-atom.md). Its only [generic filter](generic-filter.md) is a ground-model set. Atomlessness is the hypothesis in [generic filter for an atomless order is new](generic-filter-for-an-atomless-order-is-new.md).
