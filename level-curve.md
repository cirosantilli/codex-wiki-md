# Level curve

↑ **Parent:** [Level set](level-set.md)

A [level curve](level-curve.md) is the planar [level set](level-set.md) of a scalar function. Where the gradient does not vanish, the [implicit function theorem](implicit-function-theorem.md) makes it locally a smooth curve. At a [critical point](critical-point.md), branches may cross, narrow into a cusp or shrink to a point, so a plot should be interpreted with the local critical-point analysis.
