<h1 id="sierpinski-set">Sierpiński set</h1>

↑ **Parent:** [Lebesgue measure](lebesgue-measure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sierpiński_set)

An uncountable [subset](subset.md) $S$ of the [real numbers](real-number.md) whose intersection with every [null set](null-set.md) for [Lebesgue measure](lebesgue-measure.md) is countable. Testing only [Borel sets](borel-set.md) suffices because every Lebesgue-null [set](set-split.md) has a Borel null superset. No measurability of $S$ is assumed.
