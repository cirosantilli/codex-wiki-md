# Homogeneous set for a colouring

↑ **Parent:** [Ramsey theory](ramsey-theory-split.md)

For a colouring $\chi:[S]^r\to\{0,\ldots,k-1\}$ of the $r$-element subsets of a [set](set-split.md) $S$, a subset $H\subseteq S$ is homogeneous if all its $r$-element subsets receive the same colour. The infinite [Ramsey theorem for r-sets](ramsey-s-theorem.md) guarantees an infinite homogeneous subset when $S=\mathbb N$, $r$ is positive and the number of colours is finite. This does not guarantee a [computable set](computable-set.md) when the colouring is computable.
