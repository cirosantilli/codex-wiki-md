# Linear workload rate for a local convex action

↑ **Parent:** [Workload of a queue](workload-of-a-queue.md)

For a stable input with path action $I(a)=\int_{-\infty}^0g(\dot a_s)ds$, a workload x requires some interval of length t with average input near $C+x/t$. [Jensen inequality](jensen-s-inequality.md) bounds its cost below by $tg(C+x/t)$; taking the [supremum](supremum.md) workload and then the [infimum](infimum.md) over t yields the displayed lower bound. [Constant-rate burst paths](constant-rate-burst-path.md) give the matching upper bound. At zero the typical-rate path has zero cost; negative workloads have infinite rate. If no finite-cost rate exceeds C, every positive workload has infinite rate.
