# Real projective hyperplane is not a global regular zero set

↑ **Parent:** [Regular zero hypersurfaces have disconnected complements](regular-zero-hypersurfaces-have-disconnected-complements.md)

The coordinate hyperplane is an [embedded submanifold](embedded-submanifold.md), as standard projective charts flatten its defining homogeneous coordinate. Its complement is the affine chart $\mathbb R^n$ and is connected. The lemma [regular zero hypersurfaces have disconnected complements](regular-zero-hypersurfaces-have-disconnected-complements.md) therefore excludes its being the zero set of a smooth real function with zero a [regular value](regular-value.md).
