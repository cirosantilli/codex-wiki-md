# Bochner identity for Killing vector fields

↑ **Parent:** [Killing vector field](killing-vector-field.md)

On a closed [Riemannian manifold](riemannian-manifold.md), a [Killing vector field](killing-vector-field.md) $X$ satisfies $\nabla^*\nabla X=\operatorname{Ric}^{\sharp}X$ for the nonnegative [rough Laplacian](rough-laplacian.md). This follows by differentiating $\nabla_iX_j+\nabla_jX_i=0$, contracting and commuting [covariant derivatives](covariant-derivative.md); the contraction also gives $\operatorname{div}X=0$. Taking the [inner product](inner-product.md) with $X$ and using [integration by parts](integration-by-parts.md) gives the displayed identity. If [Ricci curvature](ricci-curvature.md) is nonpositive, the nonnegative left side must vanish, so $X$ is a [parallel vector field](parallel-vector-field.md). In particular every [Killing vector field](killing-vector-field.md) on a closed [flat Riemannian manifold](flat-manifold.md) is a [parallel vector field](parallel-vector-field.md).
