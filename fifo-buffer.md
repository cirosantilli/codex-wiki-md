# FIFO buffer

↑ **Parent:** [FIFO queue](fifo-queue.md)

A communicating [FIFO queue](fifo-queue.md) that accepts values on an input channel and emits them, in the same order, on an output channel. An unbounded [FIFO buffer](fifo-buffer.md) always has room for a new input, even when its oldest pending output is also available.
