# Stationary solution

↑ **Parent:** [Differential equation](differential-equation-split.md)

A stationary solution of an evolution [differential equation](differential-equation-split.md) is independent of time. Substituting $\partial_tu=0$ leaves the spatial [boundary value problem](boundary-value-problem-split.md) that determines its profile. For an [ordinary differential equation](ordinary-differential-equation.md) this is an [equilibrium](equilibrium-point-of-a-dynamical-system.md); for a [partial differential equation](partial-differential-equation-split.md) it may vary in space. A stationary profile need not have zero [flux](flux.md), although zero [flux](flux.md) is forced in a one-dimensional conserved system with reflecting endpoints.
