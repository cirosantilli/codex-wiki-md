# Ternary prefix code

↑ **Parent:** [Prefix code](prefix-code.md)

A [prefix code](prefix-code.md) whose [codewords](codeword.md) use a three-symbol [alphabet](alphabet.md), conventionally $\{0,1,2\}$. No complete [codeword](codeword.md) is a prefix of another, permitting sequential decoding by following a [code tree](prefix-tree-of-a-code.md) to a [tree leaf](leaf-of-a-tree.md). Its [expected codeword length](expected-codeword-length.md) is $\sum_i p_i|c(i)|$ [trits](trit.md) per source symbol. For source [probabilities](probability.md) $(1/2,1/4,1/8,1/8)$, the [codewords](codeword.md) $(0,1,20,21)$ give [expected codeword length](expected-codeword-length.md) $5/4$ [trits](trit.md).
