# Holographic reference wave

↑ **Parent:** [Holography](holography.md)

A [holographic reference wave](holographic-reference-wave.md) is a known coherent comparison field at the recording surface. Its [wave phase](phase-waves.md) supplies the standard against which the [holographic object wave](holographic-object-wave.md) is encoded. In [in-line holography](in-line-holography.md), the undiffracted part of the illumination can supply this field; in [off-axis holography](off-axis-holography.md), a separate tilted beam supplies it.
