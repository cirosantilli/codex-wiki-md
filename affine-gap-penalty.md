# Affine gap penalty

↑ **Parent:** [Gap penalty](gap-penalty.md)

An [affine gap penalty](affine-gap-penalty.md) charges $o$ for the first position of a gap and $e$ for each additional position. With $o>e$, one long gap costs less than several separate gaps of the same total length. Some software instead uses $o+e\ell$; numerical settings must be interpreted with their convention.
