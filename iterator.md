# Iterator

↑ **Parent:** [Data structure](data-structure-split.md)

A stateful interface exposing a remaining [sequence](sequence.md) through an availability test and an operation returning and consuming its head. An iterator can represent an infinite sequence without materializing all elements, provided demanded steps terminate. Destructive iterators generally require exclusive ownership of their consumption state; sharing an iterator is not the same as creating a fresh independent traversal.
