# Hash table key

↑ **Parent:** [Hash table](hash-table.md)

The identifier used to select a [hash table record](hash-table-record.md). [Key equality](key-equality.md) determines whether two identifiers name the same entry, while a [hash function](hash-function.md) chooses where its lookup begins.
