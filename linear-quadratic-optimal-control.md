# Linear-quadratic optimal control

↑ **Parent:** [Hamilton-Jacobi-Bellman equation](hamilton-jacobi-bellman-equation.md)

A linear-quadratic optimal-control problem has [linear](linearity.md) state dynamics and running and terminal costs defined by [quadratic forms](quadratic-form.md). Its value function is quadratic in the state, the optimal feedback is linear, and its coefficient obeys a [Riccati equation](riccati-equation.md).
