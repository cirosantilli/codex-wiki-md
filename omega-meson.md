# Omega meson

↑ **Parent:** [Meson](meson.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Omega_meson)

The [omega meson](omega-meson.md) is an isospin-zero vector [meson](meson.md) with [charge conjugation](charge-conjugation.md) value minus one and consequently [G parity](g-parity.md) minus one. Three-pion decay is compatible with the isospin-symmetric [strong interaction](strong-interaction.md), whereas two-pion decay violates its G-parity rule.
