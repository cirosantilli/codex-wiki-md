# Spectral condition for a small discrete SIR outbreak

↑ **Parent:** [Resolvent bound for a discrete SIR epidemic](resolvent-bound-for-a-discrete-sir-epidemic.md)

The displayed condition and the [resolvent bound for a discrete SIR epidemic](resolvent-bound-for-a-discrete-sir-epidemic.md) imply $\mathbb EZ=o(n)$. The [Markov inequality](markov-inequality.md) then makes $Z/n\to0$ in probability. A sufficient special case is a sublinear initial infected count $m=o(n)$ with a fixed positive gap $1-\beta\rho\geq\eta>0$. The inequality $\beta\rho<1$ at each finite population size alone does not control a shrinking gap or an initially macroscopic outbreak.
