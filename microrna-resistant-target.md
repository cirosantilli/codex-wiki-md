# MicroRNA-resistant target

↑ **Parent:** [MicroRNA](microrna.md)

A target altered so that a tested [microRNA](microrna.md) can no longer regulate it while preserving the relevant target function. Rescue tests should control expression level and native [RNA](ribonucleic-acid.md) context.
