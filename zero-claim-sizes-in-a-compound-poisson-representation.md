# Zero claim sizes in a compound Poisson representation

↑ **Parent:** [Compound Poisson distribution](compound-poisson-distribution.md)

If zero-sized claims are allowed, a [compound Poisson distribution](compound-poisson-distribution.md) count parameter need not be unique. [Poisson thinning](poisson-thinning.md) of zero claims gives the displayed positive-claim count parameter and the conditional [claim size](claim-size.md) [probability distribution](probability-distribution.md) given $X>0$, without changing the aggregate. If no positive claims occur, the aggregate is identically zero. This matters when representing a finite weighted sum of [Poisson distribution](poisson-distribution.md) counts whose coefficients include zero.
