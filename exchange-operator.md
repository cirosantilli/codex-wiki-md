# Exchange operator

↑ **Parent:** [Indistinguishable particles](indistinguishable-particles.md)

The operator $\hat P_{12}$ interchanges all one-particle variables for particles 1 and 2. Since $\hat P_{12}^2=\hat I$, a state of definite exchange symmetry has [eigenvalue](eigenvalue.md) $+1$ or $-1$.
