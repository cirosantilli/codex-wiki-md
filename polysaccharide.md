# Polysaccharide

↑ **Parent:** [Carbohydrate](carbohydrate.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Polysaccharide)

A [polysaccharide](polysaccharide.md) is a [polymer](polymer-split.md) built from many linked [monosaccharide](monosaccharide.md) units. [Cellulose](cellulose.md) provides a structural example. See [Biology 2e: polysaccharides](https://openstax.org/books/biology-2e/pages/3-2-carbohydrates).
