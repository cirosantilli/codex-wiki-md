# Graded BRST Ward identity

↑ **Parent:** [BRST Ward identity](brst-ward-identity.md)

An invariant path-integral measure and [BRST symmetry](brst-symmetry.md) action imply this identity when every separated insertion $G_i$ is [BRST-closed](brst-closed-operator.md). The bracket is the [graded commutator](graded-commutator.md), so it becomes an anticommutator for an odd $\mathcal O$. The arbitrary operator need not itself be closed. Exact insertions therefore decouple from physical correlators.
