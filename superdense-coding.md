# Superdense coding

↑ **Parent:** [Bell state](bell-state-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Superdense_coding)

Superdense coding uses a shared [Bell state](bell-state-split.md) to communicate two classical bits by transmitting one qubit. The sender selects one of the four Bell states with a local [Pauli operation](pauli-matrices.md), and the receiver performs a Bell-basis measurement.
