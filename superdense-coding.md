# Superdense coding

↑ **Parent:** [Bell state](bell-state-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Superdense_coding)

[Superdense coding](superdense-coding.md) uses a shared [Bell state](bell-state-split.md) to communicate two classical [bits](bit.md) by transmitting one [qubit](qubit.md). The sender selects one of four orthogonal [Bell states](bell-state-split.md) with a local [Pauli operator](pauli-operator.md), and the receiver performs a [Bell-basis measurement](bell-basis-measurement.md). For an ideal shared [Bell pair](bell-pair.md), the transmitted [qubit](qubit.md) alone has a [maximally mixed state](maximally-mixed-state.md) for every message and reveals no information about the chosen encoding.
