# Static radius

↑ **Parent:** [Newtonian limit](newtonian-limit.md)

For a point mass in a positive [cosmological constant](cosmological-constant.md), the inward Newtonian acceleration $GM/r^2$ balances the outward cosmological acceleration $\Lambda r/3$ at the static radius $r_{\rm s}=(3GM/\Lambda)^{1/3}$.
