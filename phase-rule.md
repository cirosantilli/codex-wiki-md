# Phase rule

↑ **Parent:** [Phase diagram](phase-diagram.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Phase_rule)

The [phase rule](phase-rule.md) counts independent intensive controls compatible with coexistence of $P$ distinct bulk [thermodynamic phases](thermodynamic-phase.md) made from $C$ independent components:

$$
F=C-P+2.
$$

Here $P$ counts [thermodynamic phases](thermodynamic-phase.md), not [pressure](pressure-split.md), and $F$ does not count [phase fractions](phase-fraction.md). For the nonreacting one-component case, $C=1$ and $F=3-P$: a single [thermodynamic phase](thermodynamic-phase.md) occupies a region with $F=2$, two-[thermodynamic phase](thermodynamic-phase.md) coexistence a curve with $F=1$, and a [triple point](triple-point.md) an isolated point with $F=0$. Fixing [pressure](pressure-split.md) externally removes one adjustable control wherever that constraint is independent.[Gibbs Phase Rule, displayed nonreacting rule and pure-substance table](gibbs-phase-rule-mit-10-213-course-material.md)

For an elementary count without [chemical reactions](chemical-reaction-split.md), take $C$ [chemical species](chemical-species.md). Each [thermodynamic phase](thermodynamic-phase.md) has $C-1$ independent composition fractions, since they sum to one. Shared [temperature](temperature-split.md) and [pressure](pressure-split.md) add two controls, giving $2+P(C-1)$. Equality of each species' [chemical potential](chemical-potential-split.md) between one reference [thermodynamic phase](thermodynamic-phase.md) and the other $P-1$ [thermodynamic phases](thermodynamic-phase.md) supplies $C(P-1)$ constraints. Subtraction gives $2+P(C-1)-C(P-1)=C-P+2$. This argument assumes the constraints are independent and treats interfaces as negligible; [chemical reactions](chemical-reaction-split.md), external fields or critical mergers require appropriate qualifications.
