# Continuous logarithm lifting criterion

↑ **Parent:** [Winding number of a continuous closed path](winding-number-of-a-continuous-closed-path.md)

On a locally [path-connected](path-connected-space.md) space, on each path component choose a value of a [complex logarithm](complex-logarithm.md) of $f$ at a base point. Continue it along paths using local logarithms. Independence of the path is exactly vanishing of the [winding number of a continuous closed path](winding-number-of-a-continuous-closed-path.md) for all loops. This constructs a [continuous function](continuous-function.md) $g$ with $f=e^g$. The implication from a logarithm to zero winding requires no local connectivity. For applications to arbitrary planar [compact](compact-space.md) sets, apply the criterion on polygonal neighborhoods rather than assuming the [compact](compact-space.md) set is locally [path-connected](path-connected-space.md).
