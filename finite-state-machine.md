# Finite-state machine

↑ **Parent:** [Formal language theory](formal-language-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Finite-state_machine)

A [finite-state machine](finite-state-machine.md) has finitely many states and input-dependent transitions; it may also emit outputs. With designated accepting states it recognizes a [formal language](formal-language.md).

A finite-state automaton recognizes a [formal language](formal-language.md) by updating one of finitely many states as it reads each input symbol.
