# Real tree

↑ **Parent:** [Gromov-Hausdorff distance](gromov-hausdorff-distance.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Real_tree)

A real tree is a [metric space](metric-space.md) $(T,d)$ in which every pair $a,b\in T$ is joined by a unique arc and that arc is [isometric](isometry.md) to the [real interval](interval-mathematics.md) $[0,d(a,b)]$. Equivalently, it is a [geodesic metric space](geodesic-metric-space.md) with no nontrivial simple loops.
