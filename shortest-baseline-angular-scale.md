# Shortest-baseline angular scale

↑ **Parent:** [Interferometric baseline](interferometric-baseline.md)

The shortest useful projected baseline sets the lowest sampled [spatial frequency](spatial-frequency.md), of order $b_{\min}/\lambda$, and hence an angular scale $\lambda/b_{\min}$. Operational maximum recoverable source sizes also depend on source shape, coverage, weighting and [primary beam](primary-beam.md). The longest baseline sets a different scale, the synthesized [angular resolution](angular-resolution.md). The number of [antennas](antenna-radio.md) alone does not fix either limiting baseline or supply zero-spacing total power.
