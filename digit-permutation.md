# Digit permutation

↑ **Parent:** [Permutation](permutation.md)

A rearrangement of the [numerical digits](numerical-digit.md) of a numeral. Two numerals have the same [digit permutation](digit-permutation.md) class exactly when their digit [multisets](multiset.md) agree. If they represent numbers of the same length, a leading zero must be disallowed.
