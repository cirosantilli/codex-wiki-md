# Clustered database index

↑ **Parent:** [Database query plan](database-query-plan.md)

An index whose search order determines, or closely follows, the physical placement of the data records. Clustering by one [database attribute](database-attribute.md) does not give indexed access by an unrelated [database attribute](database-attribute.md).
