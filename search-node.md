# Search node

↑ **Parent:** [Search tree](search-tree.md)

An entry in a [search tree](search-tree.md) representing a particular action history. It normally stores the current state, its parent, its last action and accumulated [path cost](path-cost.md) $g$. Distinct [search nodes](search-node.md) can represent the same state; identifying them changes [tree search](tree-search.md) into a form of [graph search](graph-search.md) and requires an appropriate repeated-state policy.
