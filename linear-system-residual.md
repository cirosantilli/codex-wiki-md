# Linear-system residual

↑ **Parent:** [Conjugate gradient method](conjugate-gradient-method.md)

The residual of an approximate solution $x$ of $Ax=b$ is $r=b-Ax$. It is the unbalanced right-hand side, while the solution error is $x_*-x=A^{-1}r$. The [Conjugate gradient method](conjugate-gradient-method.md) makes residuals orthogonal to successive [Krylov subspaces](krylov-subspace.md).
