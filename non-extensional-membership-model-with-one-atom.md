# Non-extensional membership model with one atom

↑ **Parent:** [Axiom of extensionality](axiom-of-extensionality.md)

Build well-founded coded sets over a single [urelement](urelement.md) $a$ with no members, retaining a distinct empty set. Use the unmodified membership language, so both $a$ and the empty set have the same empty extension and [extensionality](axiom-of-extensionality.md) fails. Pairs, unions, separation and functional ranges have set codes, and pure natural numbers give [infinity](infinity.md). For the unrestricted [Axiom of power set](axiom-of-power-set.md), the power-set code must contain $a$ as well as all ordinary subset codes, since the atom is vacuously a subset of every object. Rank gives [foundation](axiom-of-regularity.md). Thus the other [ZF](zermelo-fraenkel-set-theory.md) axioms hold.
