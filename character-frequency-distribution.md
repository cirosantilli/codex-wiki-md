# Character-frequency distribution

↑ **Parent:** [Type (information theory)](type-information-theory.md)

For a nonempty [string](string.md), assign a character its occurrence count divided by the [string](string.md) length. Counts partition the character positions, proving normalization. Empty input has no total count to normalize and needs an explicit alternative contract or rejection. A [Scala](scala.md) Char implementation counts UTF-16 code units unless a separate code-point representation is introduced.
