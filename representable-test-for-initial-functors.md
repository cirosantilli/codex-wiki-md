# Representable test for initial functors

↑ **Parent:** [Initial functor](initial-functor.md)

A [functor](functor.md) $F:I\to J$ is initial if restriction preserves [categorical limits](categorical-limit.md) for [diagrams in a category](diagram-category-theory.md) with codomain $\mathbf{Set}^{\mathrm{op}}$. To test necessity, view $J(-,j)$ as such a diagram. Its limit is a singleton, since the [colimit](colimit.md) of the corresponding [representable presheaf](representable-functor.md) is the connected-component set of the slice $J\downarrow j$, which has a terminal object. The restricted colimit is the connected-component set of $(F\downarrow j)$. Thus that [comma category](comma-category.md) is nonempty and connected. Sufficiency follows from [cone restriction along an initial functor](cone-restriction-along-an-initial-functor.md).
