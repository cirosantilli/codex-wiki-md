# High ample twist is very ample

↑ **Parent:** [Ample line bundle](ample-line-bundle.md)

If $A$ is an [ample line bundle](ample-line-bundle.md) on a [projective variety](projective-variety.md) and $L$ is any [line bundle](line-bundle.md), then $A^{\otimes m}\otimes L$ is [very ample](very-ample-line-bundle.md) for all sufficiently large [integers](integer.md) $m$. Taking $L$ to be trivial also makes $A^{\otimes m}$ very ample.
