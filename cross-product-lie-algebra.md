# Cross-product Lie algebra

↑ **Parent:** [Lie algebra](lie-algebra-split.md)

The [vector space](vector-space-split.md) $\mathbb R^3$ with the [cross product](cross-product.md) as [Lie bracket](lie-bracket.md). The vector triple-product identity proves the [Jacobi identity](jacobi-identity.md). The map $x\mapsto-(i/2)x\cdot\sigma$ is a [Lie algebra isomorphism](lie-algebra-isomorphism.md) to the compact real [SU(2) Lie algebra](su-2-lie-algebra.md), using the [Pauli matrix commutator identity](pauli-matrix-commutator-identity.md).
