# Limits in a reflective subcategory

↑ **Parent:** [Reflective subcategory](reflective-subcategory.md)

If a [full subcategory](full-subcategory.md) is reflective in a [complete category](complete-category.md), it is complete. For an ambient limit $L$ of a diagram of reflected objects, the reflection unit $L\to JKL$ is invertible by the [hom-set](hom-set.md) characterization of reflected objects. Thus $KL$ is an internal [categorical limit](categorical-limit.md). If the subcategory is replete, $L$ itself belongs to it. The [reflector](reflector.md) need not preserve arbitrary limits.
