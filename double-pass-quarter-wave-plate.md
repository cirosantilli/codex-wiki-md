# Double-pass quarter-wave plate

↑ **Parent:** [Quarter-wave plate](quarter-wave-plate.md)

For a reciprocal ideal [quarter-wave plate](quarter-wave-plate.md) followed by a mirror at [normal incidence](normal-incidence.md), use the same fixed transverse laboratory axes for the forward and returning [Jones vectors](jones-vector.md). If the axes coincide with the plate's fast and slow axes, each pass has [Jones matrix](jones-matrix.md) $J=\operatorname{diag}(1,i)$ up to a common [phase factor](phase-factor.md). A polarization-independent mirror has scalar reflection coefficient $r_m$, so the returned [Jones vector](jones-vector.md) is $r_mJ^2\mathbf e=r_m\operatorname{diag}(1,-1)\mathbf e$. The plate acts twice as a [half-wave plate](half-wave-plate.md), rather than undoing its [phase retardation](phase-retardation.md).

For input [linear polarization](linear-polarization.md) at [angle](angle.md) $\alpha$ to the fast axis, the returned line is at $-\alpha$ modulo $\pi$. At $\alpha=45^\circ$ it is perpendicular to the original line. An axis-aligned input instead returns along the same line. General [elliptical polarization](elliptical-polarization.md) requires its full input [Jones vector](jones-vector.md); no unique returned state follows from the word “polarized” alone. The propagation direction reverses, so comparing descriptions of [circular polarization](circular-polarization.md) must also specify the viewing convention.
