# Abstract syntax tree transformation

↑ **Parent:** [Abstract syntax tree](abstract-syntax-tree.md)

An [abstract syntax tree](abstract-syntax-tree.md) transformation replaces or rearranges nodes. It can simplify a [program expression](program-expression.md), insert instrumentation, or translate a language construct into simpler constructs. When intended to preserve [programming language semantics](programming-language-semantics.md), it must preserve the relevant observable behavior, including values, [side effects](side-effect-computer-science.md), and failures. A changed tree can be structurally valid while changing the program's meaning.
