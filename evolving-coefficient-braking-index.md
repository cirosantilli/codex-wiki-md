# Evolving-coefficient braking index

↑ **Parent:** [Braking index](braking-index.md)

For $\dot\Omega=-K(t)\Omega^q$, differentiation gives the displayed [braking index](braking-index.md). Inferring the [torque](torque.md) power $q$ from a measured index therefore requires an effectively constant coefficient. Field evolution, changing inclination and moment-of-inertia changes can all contribute to the difference.
