# Radial retraction onto a closed ball

↑ **Parent:** [Closed ball](closed-ball.md)

For $R>0$ in a [normed vector space](normed-vector-space-split.md), define $P_R(0)=0$ and use the displayed formula elsewhere. This [continuous map](continuous-map.md) fixes the [closed ball](closed-ball.md) of radius $R$ and maps every point outside it to the boundary along its radial line. If a [continuous map](continuous-map.md) $T$ is defined only on that [closed ball](closed-ball.md), $T\circ P_R$ is a continuous extension to the whole space. This extension is useful when applying a theorem whose hypotheses concern a globally defined [vector field](vector-field.md).
