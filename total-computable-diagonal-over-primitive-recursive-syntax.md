# Total computable diagonal over primitive recursive syntax

↑ **Parent:** [Primitive recursive syntax and arity checking](primitive-recursive-syntax-and-arity-checking.md)

Enumerate all valid unary [primitive recursive functions in intension](primitive-recursive-function-in-intension.md) by their decidable codes $p_n$, and interpret each extension $F_{p_n}$. The [function](function-split.md) $d(n)=F_{p_n}(n)+1$ is a [total computable function](total-computable-function.md), since each finite construction terminates. If it were [primitive recursive](primitive-recursive-function.md), some $F_{p_j}$ would equal $d$, giving $d(j)=d(j)+1$. Repeated extensions in the syntax enumeration do not affect this argument.
