# Hazel model

↑ **Parent:** [Inviscid parallel shear flow](inviscid-parallel-shear-flow.md)

The [Hazel model](hazel-model.md) is a smooth stratified [shear flow](shear-flow.md) whose base [velocity](velocity.md) has a hyperbolic-tangent profile and whose squared [buoyancy frequency](buoyancy-frequency.md) has a hyperbolic-secant-squared profile. The equal-width nondimensional example is $U=\tanh z$ and $N^2=J\operatorname{sech}^2z$. For $J\geq0$, its [gradient Richardson number](gradient-richardson-number.md) is $J\cosh^2z$, with minimum $J$.
