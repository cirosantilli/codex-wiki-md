# Hypervirial distribution function

↑ **Parent:** [Hypervirial model](hypervirial-model.md)

The [hypervirial model](hypervirial-model.md) is generated self-consistently by a [constant-anisotropy distribution function](constant-anisotropy-distribution-function.md) proportional to

$$
L^{p-2}\mathcal E^{(3p+1)/2}.
$$

Its [velocity-anisotropy parameter](velocity-anisotropy-parameter.md) is $\beta=1-p/2$.
