# Existential second-order logic

↑ **Parent:** [Second-order logic](second-order-logic.md)

An existential second-order sentence consists of existentially quantified finite-arity relation symbols followed by a [first-order sentence](first-order-sentence.md). Over finite structures, witness relations have polynomial-length encodings for a fixed sentence. [Fagin's theorem](fagin-s-theorem.md) identifies the properties definable in this logic with those decidable in [NP](np-complexity.md).
