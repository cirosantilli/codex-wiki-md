# Logical derivation

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)

A [logical derivation](logical-derivation.md) is a finite application of explicitly specified [inference rules](inference-rule.md) to premises or [temporary assumptions](temporary-assumption.md). In [natural deduction](natural-deduction.md), which assumptions remain open is part of the [logical derivation](logical-derivation.md): a conclusion reached inside a temporary subproof cannot simply be used outside it.
