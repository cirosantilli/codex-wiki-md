# Falsifiability

↑ **Parent:** [Demarcation problem](demarcation-problem.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Falsifiability)

A hypothesis is falsifiable if some possible empirical outcomes conflict with it under specified testing assumptions. [Falsifiability](falsifiability.md) does not mean that an anomalous reading identifies which member of a theoretical package is false, or that a falsifiable statement is well supported.
