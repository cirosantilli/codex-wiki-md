# Connected subset of the real line

↑ **Parent:** [Connected space](connected-space.md)

A subset of the [real numbers](real-number.md) is connected exactly when it is a [real interval](interval-mathematics.md). If it contains $a<b$ but omits some $c\in(a,b)$, intersecting it with the two open half-lines separated by $c$ gives a separation.
