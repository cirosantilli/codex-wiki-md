# Metrically proper group action

↑ **Parent:** [Cubulation of a group](cubulation-of-a-group.md)

An isometric group action on a metric space is metrically proper when, for some and hence every point $x$, the set $\{g:d(x,gx)\le R\}$ is finite for every finite $R$.
