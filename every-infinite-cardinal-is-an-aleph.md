# Every infinite cardinal is an aleph

↑ **Parent:** [Aleph number](aleph-number.md)

Assuming the [axiom of choice](axiom-of-choice.md), the [well-ordering theorem](well-ordering-theorem.md) makes every set equipotent to an [initial ordinal](initial-ordinal.md). The infinite initial ordinals are exactly the $\aleph_\alpha$, so every infinite cardinal is $\aleph_\alpha$ for a unique ordinal $\alpha$.
