# Finite axiomatizability

↑ **Parent:** [First-order theory](first-order-theory.md)

A [first-order model](model-of-a-first-order-theory.md) class is [finitely axiomatizable](finite-axiomatizability.md) in a fixed language if a [finite set](finite-set.md) of sentences, equivalently one finite [conjunction](conjunction-astronomy.md), has exactly that [model](model-of-a-first-order-theory.md) class. Relative [finite axiomatizability](finite-axiomatizability.md) permits a fixed background [theory](first-order-theory.md) and asks for only finitely many additional [axioms](axiom.md). The distinction matters in an infinite [scalar](scalar-multiplication.md) language, where even vector-space structure itself needs infinitely many named-symbol constraints.
