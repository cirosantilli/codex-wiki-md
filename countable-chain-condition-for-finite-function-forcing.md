# Countable chain condition for finite-function forcing

↑ **Parent:** [Fn forcing](fn-forcing.md)

The order $\operatorname{Fn}(X,Y,\omega)$ has the [countable chain condition for forcing](countable-chain-condition-for-forcing.md) whenever $Y$ is countable. For an uncountable family of conditions, apply the [Delta-system lemma](delta-system-lemma.md) to the finite domains. On their common finite root there are only countably many assignments, so thin to an uncountable family agreeing on that root. Any two conditions now have a compatible union. For binary [Cohen forcing](cohen-forcing.md), there are only finitely many root assignments.
