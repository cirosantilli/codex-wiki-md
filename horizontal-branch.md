# Horizontal branch

↑ **Parent:** [Stellar evolution](stellar-evolution.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Horizontal_branch)

A post-helium-ignition stage of low-mass [stellar evolution](stellar-evolution.md) with core helium [nuclear fusion](nuclear-fusion.md) and usually a hydrogen-burning shell. The branch spans a broad range of [effective temperatures](effective-temperature.md) at comparatively similar [luminosities](luminosity.md), largely because envelope masses vary.
