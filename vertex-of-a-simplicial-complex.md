# Vertex of a simplicial complex

↑ **Parent:** [Simplicial complex](simplicial-complex.md)

An element of the underlying vertex set of an abstract [simplicial complex](simplicial-complex.md); a simplex is a finite subset of these vertices. In a [barycentric subdivision](barycentric-subdivision.md), the vertices are nonempty simplices of the original complex.
