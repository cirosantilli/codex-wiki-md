# Self-attention

↑ **Parent:** [Transformer model](transformer-model.md)

An attention operation in which queries, keys, and values are projections of one sequence's representations. At each position, learned similarities between its query and permitted keys determine a weighted sum of the corresponding values. [Scaled dot-product attention](scaled-dot-product-attention.md) and [multi-head attention](multi-head-attention.md) are standard implementations; [causal self-attention](causal-self-attention.md) restricts which positions can be accessed.
