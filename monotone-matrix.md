# Monotone matrix

↑ **Parent:** [Matrix](matrix.md)

A rectangular [array](array-data-structure.md) whose entries are nondecreasing in each coordinate. Every [subarray](subarray.md) obtained by restricting to a row interval and a column interval has the same property. Comparing a target with the top-right entry discards a whole row or column, giving [staircase matrix search](staircase-matrix-search.md) in time linear in the sum of the dimensions.
