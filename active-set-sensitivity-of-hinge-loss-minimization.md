# Active-set sensitivity of hinge-loss minimization

↑ **Parent:** [Active hinge set](active-hinge-set.md)

With fixed positive quadratic regularization, if all reference hinge margins are nonzero, the one-dimensional minimizer has local formula $x(a)=(\alpha n)^{-1}\sum_{i\in I}a_i$. The [active hinge set](active-hinge-set.md) is verified using continuity of this explicit candidate, then strong convexity identifies it as the optimizer. Its exact Euclidean Lipschitz modulus is $\sqrt{|I|}/(\alpha n)$.
