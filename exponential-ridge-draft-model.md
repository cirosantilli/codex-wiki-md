Here $n(H)dH$ is the expected number of ridge peaks per track length with [sea-ice draft](sea-ice-draft.md) in $[H,H+dH]$. If total line density is $\mu$ and mean peak draft is $h_m>h_0$, integration gives $b=1/(h_m-h_0)$ and $B=\mu b e^{bh_0}$. The normalized peak draft has a shifted [exponential distribution](exponential-distribution.md). This is a model over a specified draft range, not a universal description of every ridge.
