# Singular cardinal enumeration

↑ **Parent:** [Singular cardinal](singular-cardinal.md)

Write $\sigma_\alpha$ for the $\alpha$th uncountable [singular cardinal](singular-cardinal.md) in increasing order. It begins with $\sigma_0=\aleph_\omega$ and $\sigma_1=\aleph_{\omega+\omega}$. At a nonzero [limit ordinal](limit-ordinal.md) index it is continuous exactly when the supremum of its earlier values is singular. It can jump when that supremum is a [weakly inaccessible cardinal](weakly-inaccessible-cardinal.md). The first member of uncountable [cofinality](cofinality.md) occurs at index $\omega_1$, with value $\aleph_{\omega_1}$.
