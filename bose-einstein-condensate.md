# Bose-Einstein condensate

↑ **Parent:** [Bose-Einstein condensation](bose-einstein-condensation.md)

A Bose-Einstein condensate is a state with macroscopic occupation of a one-particle mode. A phase-selected mean-field description can use $\langle\psi\rangle\ne0$, while a fixed-number finite-volume state need not have a nonzero field expectation. [Bose-Einstein condensation](bose-einstein-condensation.md) and [superfluidity](superfluidity.md) are related but distinct notions; long-wavelength phase fluctuations can invalidate a uniform condensate saddle in low dimensions.
