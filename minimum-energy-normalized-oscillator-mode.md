# Minimum-energy normalized oscillator mode

↑ **Parent:** [Quantum harmonic oscillator](quantum-harmonic-oscillator.md)

For a [quantum harmonic oscillator](quantum-harmonic-oscillator.md) with $\omega>0$, a complex mode satisfying the [Wronskian normalization](wronskian-normalization.md) $q\dot q^*-\dot q q^*=i$ can be written $q=re^{is}$ with $\dot s=-1/(2r^2)$. Its [vacuum energy](vacuum-energy.md) is $\dot r^2/2+1/(8r^2)+\omega^2r^2/2$. This is at least $\omega/2$, with equality exactly when $\dot r=0$ and $r^2=1/(2\omega)$. The same argument fixes the subhorizon positive-frequency normalization in the [Bunch-Davies vacuum](bunch-davies-vacuum.md) of a canonical cosmological mode.
