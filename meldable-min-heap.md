# Meldable min-heap

↑ **Parent:** [Meldable heap](meldable-heap.md)

A [meldable heap](meldable-heap.md) satisfying the [min-heap](min-heap.md) ordering: each parent key is no greater than its children's keys. It combines efficient merging with access to the current minimum key.
