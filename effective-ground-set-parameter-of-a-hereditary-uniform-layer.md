# Effective ground-set parameter of a hereditary uniform layer

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)

For a nonempty degree-$m$ layer of a [down-set](down-set.md) in an $N$-element [Boolean lattice](boolean-lattice.md), the unique real number $x_m\geq m$ with $|\mathcal F_m|=\binom{x_m}m$ measures an effective number of available coordinates. The [Lovász shadow bound](lovasz-shadow-bound.md) and $\partial\mathcal F_{m+1}\subseteq\mathcal F_m$ imply $x_{m+1}\leq x_m$ whenever the later layer is nonempty. It is a real parameter, not the actual size of the [set family](set-family.md)'s support.
