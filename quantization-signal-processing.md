# Quantization (signal processing)

↑ **Parent:** [Image processing](image-processing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantization_(signal_processing))

[Quantization](quantization-signal-processing.md) maps numerical values to a specified discrete collection of representable values. In [lossy block averaging](lossy-block-averaging.md), $Q(m)=\lfloor m+1/2\rfloor$ maps block [arithmetic means](arithmetic-mean.md) in $[0,255]$ to eight-[bit](bit.md) [integers](integer-split.md). Thus $Q(40.25)=40$ and $Q(40.5)=41$. Different means can share a stored value, making this step irreversible.
