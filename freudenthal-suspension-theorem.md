# Freudenthal suspension theorem

↑ **Parent:** [Homotopy group](homotopy-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Freudenthal_suspension_theorem)

If $X$ is an $(n-1)$-connected based [CW complex](cw-complex.md), $n\geq2$, suspension induces an isomorphism $\pi_k(X)\to\pi_{k+1}(\Sigma X)$ for $k\leq2n-2$ and a surjection for $k=2n-1$. For a [sphere](sphere.md), $\Sigma S^n\cong S^{n+1}$, giving the stable range $\pi_k(S^n)\cong\pi_{k+1}(S^{n+1})$.
