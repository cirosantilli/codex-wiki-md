# An isometry fixed set is totally geodesic

↑ **Parent:** [Totally geodesic submanifold](totally-geodesic-submanifold.md)

A smooth [nondegenerate](nondegenerate-bilinear-form.md) component of the [fixed-point set](fixed-point-set.md) of an [isometry](isometry.md) is a [totally geodesic submanifold](totally-geodesic-submanifold.md). If a [geodesic](geodesic.md) starts tangent to the fixed component, its image under the [isometry](isometry.md) has identical position and tangent. Uniqueness of the [geodesic equation](geodesic-equation.md) makes the two [geodesics](geodesic.md) coincide throughout their common domain, so the original [geodesic](geodesic.md) stays in the fixed set.
