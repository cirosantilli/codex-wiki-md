# Array multiset

↑ **Parent:** [Multiset](multiset.md)

A [multiset](multiset.md) of keys in a fixed finite [integer](integer-split.md) range represented by one nonnegative count per key. The [abstraction function](abstraction-function.md) extends the stored [array](array-data-structure.md) counts by zero outside the range. Single-key [additions](addition.md), removals and queries use constant [array](array-data-structure.md) work, provided overflow and operation [preconditions](precondition.md) are handled. [Encapsulation](encapsulation-computer-programming.md) of the count [array](array-data-structure.md) is necessary to preserve its [representation invariant](representation-invariant.md).
