# Fibration

↑ **Parent:** [Homotopy](homotopy.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fibration)

A fibration is a map with the [homotopy lifting property](homotopy-lifting-property.md). A Hurewicz fibration has this property for every source space; a [Serre fibration](serre-fibration.md) requires it for [CW complexes](cw-complex.md). Replacing a map by a fibration gives a model for its [homotopy fiber sequence](homotopy-fiber-sequence.md).
