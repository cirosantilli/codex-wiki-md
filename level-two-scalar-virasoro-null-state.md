# Level-two scalar Virasoro null state

↑ **Parent:** [Null string state](null-string-state.md)

For $L_0|p\rangle=-|p\rangle$, the descendant $Z=(L_{-2}+\tfrac32L_{-1}^2)|p\rangle$ obeys $L_1Z=0$ and $L_2Z=(D-26)|p\rangle/2$. It becomes physical and null at 26 and supplies the scalar quotient needed for the massive spin-two [light-cone gauge in string theory](light-cone-gauge-in-string-theory.md) spectrum.
