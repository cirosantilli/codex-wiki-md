# American put option

↑ **Parent:** [Put option](put-option.md)

An American put has exercise payoff $(K-S_n)^+$. In a finite binomial market, [backward option pricing](backward-option-pricing.md) compares that payoff with the discounted risk-neutral continuation value at every node.
