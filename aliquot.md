# Aliquot

↑ **Parent:** [Pipette](pipette.md)

An [aliquot](aliquot.md) is a measured portion taken from a larger sample. For a homogeneous [chemical solution](solution-chemistry.md), it contains the corresponding fraction of each conserved component inventory. Representative sampling requires mixing; knowing only the portion's [volume](volume-thermodynamics.md) is insufficient if the sample is not homogeneous.
