# String perturbation theory

↑ **Parent:** [String coupling](string-coupling.md)

String perturbation theory expands amplitudes in powers of the [String coupling](string-coupling.md) by summing over worldsheet topologies. It is reliable where the local effective coupling $e^{\Phi(X)}$ is small.
