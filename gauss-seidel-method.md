# Gauss-Seidel method

↑ **Parent:** [Stationary iterative method for a linear system](stationary-iterative-method-for-a-linear-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gauss–Seidel_method)

With $A=D+L+U$, the [Gauss-Seidel method](gauss-seidel-method.md) solves $(D+L)x^{(k+1)}=b-Ux^{(k)}$. It uses each newly computed coordinate immediately in the remaining triangular solve. It is [successive over-relaxation](successive-over-relaxation.md) with parameter one, and converges from every start when $A$ is symmetric positive definite.
