# Implicit time-stepping method

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

An implicit time-stepping method determines a new solution value through an equation involving that same value. A small-step [contraction mapping](contraction-mapping.md) argument often establishes local solvability when the vector field is [Lipschitz continuous](lipschitz-continuity.md). Examples include the [Backward Euler method](backward-euler-method.md), [implicit Runge-Kutta methods](implicit-runge-kutta-method.md) and implicit [linear multistep methods](linear-multistep-method.md). Solvability of the update is a separate issue from [stability of a numerical method](stability-of-a-numerical-method.md).
