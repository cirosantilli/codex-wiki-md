# Phase mismatch

↑ **Parent:** [Phase matching](phase-matching.md)

The residual [wave vector](wavevector.md) difference in a wave-conversion process. For collinear [sum-frequency generation](sum-frequency-generation.md), choose $\Delta k=k_1+k_2-k_3$. Contributions separated by $z$ then differ by [wave phase](phase-waves.md) $\Delta kz$. At [phase matching](phase-matching.md) this residual is zero. The sign convention changes some amplitude phases but not the unseeded conversion factor $\operatorname{sinc}^2(\Delta kL/2)$.
