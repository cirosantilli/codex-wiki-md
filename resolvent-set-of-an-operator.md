# Resolvent set of an operator

↑ **Parent:** [Closed linear operator](closed-linear-operator.md)

The resolvent set $\rho(A)$ consists of the complex numbers $z$ for which $zI-A:D(A)\to X$ is bijective and has a bounded inverse on $X$. This inverse is the [resolvent of an operator](resolvent-of-an-operator.md) $R(z,A)=(zI-A)^{-1}$.
