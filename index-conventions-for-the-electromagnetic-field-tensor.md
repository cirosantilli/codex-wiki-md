# Index conventions for the electromagnetic field tensor

↑ **Parent:** [Electromagnetic field tensor](electromagnetic-field-tensor.md)

Choose coordinates $x^\mu=(ct,\mathbf x)$ and [Minkowski metric](minkowski-metric.md) $\eta=\operatorname{diag}(1,-1,-1,-1)$. With the convention $F^{0i}=-E_i/c$ and $F^{ij}=-\epsilon_{ijk}B_k$, lowering both [tensor](tensor.md) indices gives $F_{0i}=+E_i/c$ while leaving $F_{ij}=F^{ij}$. An array with all upper indices cannot be used unchanged as the corresponding array with all lower indices. The propagation [Lorentz four-vector](four-vector.md) $n^\mu=(1,\mathbf s)$ for unit spatial direction $\mathbf s$ similarly has $n_\mu=(1,-\mathbf s)$. These signs matter in contractions that encode [Maxwell equations](maxwell-equations-split.md).
