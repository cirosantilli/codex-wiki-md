# Standard normal random variable

↑ **Parent:** [Gaussian random variable](gaussian-random-variable.md)

A [standard normal random variable](standard-normal-random-variable.md) has the [standard normal distribution](standard-normal-distribution.md), [mean](expected-value.md) zero and [variance](variance-split.md) one. If $X\sim N(\mu,\sigma^2)$ with $\sigma>0$, the [standardization of a normal random variable](standardization-of-a-normal-random-variable.md) $(X-\mu)/\sigma$ is a [standard normal random variable](standard-normal-random-variable.md). Its values report displacement from the [mean](expected-value.md) in units of the [standard deviation](standard-deviation.md), so the result is a [dimensionless quantity](dimensionless-quantity.md).
