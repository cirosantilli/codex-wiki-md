# Standard normal random variable

↑ **Parent:** [Gaussian random variable](gaussian-random-variable.md)

A standard normal random variable has the [standard normal distribution](standard-normal-distribution.md), mean zero and [variance](variance-split.md) one. If $X\sim N(\mu,\sigma^2)$ with $\sigma>0$, the standardized variable $(X-\mu)/\sigma$ is standard normal.
