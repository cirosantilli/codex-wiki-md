# Restriction (mathematics)

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Restriction_(mathematics))

For a [function](function-split.md) $f:X\to Y$ and a [subset](subset.md) $A\subseteq X$, its [restriction](restriction-mathematics.md) $f|_A$ keeps the same values but allows only inputs in $A$. Restricting the [domain of a function](domain-of-a-function.md) can remove collisions and permit an [inverse function](inverse-function.md), as the nonnegative [quadratic function](quadratic-function.md) example shows. This changes the allowed inputs; it is different from keeping the inputs and changing the [codomain](codomain.md).
