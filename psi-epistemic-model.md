# Psi-epistemic model

↑ **Parent:** [Ontological model of a quantum system](ontological-model-of-a-quantum-system.md)

An [ontological model of a quantum system](ontological-model-of-a-quantum-system.md) is psi-epistemic if some pair of distinct [pure states](pure-state.md) has preparation measures with nonzero overlap. The same physical state can then be compatible with either preparation. This precise measure-overlap definition is stronger than merely interpreting a [wave function](wave-function.md) as information or a computational tool.
