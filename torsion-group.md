# Torsion group

↑ **Parent:** [Torsion element](torsion-element.md)

A [group](group-split.md) is a torsion group when every element is a [torsion element](torsion-element.md), meaning that each element has finite order. The orders need not have a common finite bound. A torsion group has no nontrivial [torsion-free group](torsion-free-group.md) as a subgroup; in particular it cannot contain a nonabelian [free group](free-group.md). Infinite [finitely generated groups](finitely-generated-group.md) of this kind can be constructed using a [torsion group construction by p-power relators](torsion-group-construction-by-p-power-relators.md).
