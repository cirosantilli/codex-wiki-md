# Unit-ideal identity for powers

↑ **Parent:** [Unit ideal](unit-ideal.md)

If $\sum_i g_if_i=1$, expand its power $r(N-1)+1$. By the [pigeonhole principle](pigeonhole-principle.md), each monomial contains some $f_i^N$. Collecting terms expresses $1$ as a [linear combination](linear-combination.md) of these powers. This lets one use a common denominator exponent in [localization](localization-of-a-ring.md) arguments.
