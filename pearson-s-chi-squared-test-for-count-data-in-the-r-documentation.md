Official documentation for `stats::chisq.test`. It distinguishes asymptotic [chi-squared distribution](chi-squared-distribution.md) calibration from [Monte Carlo tests](monte-carlo-test.md), and explains fixed-margin sampling for simulated [contingency table](contingency-table.md) tests. A finite simulation has limited [p-value](p-value.md) resolution.
