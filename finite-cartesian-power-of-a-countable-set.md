# Finite Cartesian power of a countable set

↑ **Parent:** [Countable set](countable-set.md)

A finite [Cartesian product](cartesian-product.md) of [countable sets](countable-set.md) is countable. For a fixed finite exponent $m$, index tuples in $\mathbb N^m$ can be listed by increasing maximum coordinate, with each group finite. If $B$ is countably infinite and $m>0$, its power $B^m$ is also countably infinite.
