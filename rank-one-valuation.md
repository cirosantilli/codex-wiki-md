# Rank-one valuation

↑ **Parent:** [Valuation](valuation.md)

A nontrivial additive [valuation](valuation.md) has rank one when its ordered value group is Archimedean and therefore embeds order-preservingly in $\mathbb R$. Exponentiating a real-valued representative gives a [Non-Archimedean absolute value](non-archimedean-absolute-value.md); changing the embedding rescales the valuation positively. Higher-rank ordered value groups cannot be represented by real-valued [absolute values on a field](absolute-value-algebra.md).
