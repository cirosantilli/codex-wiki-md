# Cayley table

↑ **Parent:** [Binary operation](binary-operation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cayley_table)

A [Cayley table](cayley-table.md) records a [binary operation](binary-operation.md) on a [finite set](finite-set.md): the cell at row $a$, column $b$ contains $a\ast b$. Every cell must contain an element of the specified [set](set-split.md). With the same ordering of row and column labels, the table is symmetric across its main diagonal exactly when the [binary operation](binary-operation.md) is [commutative](commutativity.md). Checking the [associative property](associative-property.md) instead requires comparing $(a\ast b)\ast c$ with $a\ast(b\ast c)$ for every triple; symmetry alone cannot establish it.[§1: multiplication tables](group-theory-v4-01-by-james-s-milne.md)

Read the first [input](input-computer-science.md) from the row and the second from the column. Both tables give [binary operations](binary-operation.md) on $\{0,1,2\}$. The [addition](addition.md) table is symmetric; the [subtraction](subtraction.md) table is not. The bottom calculation exhibits a failed [associative property](associative-property.md) for [subtraction](subtraction.md).
