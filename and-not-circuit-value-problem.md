# AND-NOT circuit value problem

↑ **Parent:** [Circuit value problem](circuit-value-problem.md)

The [circuit value problem](circuit-value-problem.md) restricted to AND and NOT gates remains [P-complete](p-completeness.md). Replace each OR by $\neg(\neg x\wedge\neg y)$, using a constant-size gadget. Gate indices and gadget positions can be emitted in [logarithmic space](logarithmic-space.md), and assignments are preserved. Constants, when needed, can be represented by fixed-valued input nodes.
