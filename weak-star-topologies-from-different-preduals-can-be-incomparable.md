# Weak-star topologies from different preduals can be incomparable

↑ **Parent:** [Weak-star topology](weak-star-topology.md)

The same [Banach space](banach-space-split.md) can acquire incomparable [weak-star topologies](weak-star-topology.md) from different isometric preduals. Pair $\ell^1$ with $c_0$ by $\sum\alpha_n\beta_n$ and with the space $c$ of convergent sequences by $\alpha_1\gamma_\infty+\sum_{n\geq2}\alpha_n\gamma_{n-1}$. The functional $\alpha\mapsto\alpha_1$ is continuous only for the first topology: $e_1-e_n\to0$ for the second but its values remain one. Conversely $\alpha\mapsto\sum\alpha_n$ is continuous only for the second: $e_n\to0$ for the first but its values remain one. More generally, comparable weak-star topologies arising from isometric preduals agree on the common closed [unit ball](unit-ball.md), since its identity map is a [continuous bijection](continuous-bijection.md) from a [compact space](compact-space.md) to a [Hausdorff space](hausdorff-space.md) by the [Banach-Alaoglu theorem](banach-alaoglu-theorem.md).
