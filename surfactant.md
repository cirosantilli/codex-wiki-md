# Surfactant

↑ **Parent:** [Surface tension](surface-tension.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Surfactant)

A surfactant is an interfacially active substance that changes surface tension. A concentration gradient therefore generates tangential [Marangoni stress](marangoni-effect.md).
