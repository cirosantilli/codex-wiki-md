# Organoid

↑ **Parent:** [3D cell culture](3d-cell-culture.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Organoid)

An [organoid](organoid.md) is a three-dimensional cellular model that reproduces selected organized features of a tissue or organ. Its relevance depends on which cell types, architecture and functions it actually preserves, rather than on three-dimensional shape alone.
