# Interpolant

↑ **Parent:** [Interpolation](interpolation-split.md)

An interpolant is a [function](function-split.md) satisfying the prescribed sample conditions $g(x_i)=y_i$. It agrees with the data exactly, but need not agree with an unknown underlying function between samples. The [polynomial interpolation](polynomial-interpolation.md) example shows that a family or a [polynomial degree](degree-of-a-polynomial.md) restriction can supply uniqueness; the [McShane extension theorem](mcshane-extension-theorem.md) shows a useful nonunique alternative.
