# Tafel equation

↑ **Parent:** [Electrochemical polarization](electrochemical-polarization.md)

An activation-controlled large-overpotential relation $|\eta|=b\log_{10}(|j|/j_0)$. The [Tafel slope](tafel-slope.md) $b$ uses volts per decade when the logarithm is base ten. Exchange [current density](current-density.md) and operating [current density](current-density.md) must use the same area convention.
