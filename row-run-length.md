# Row run length

↑ **Parent:** [Maximum all-true rectangle](maximum-all-true-rectangle.md)

The number of consecutive true entries ending at a specified column of one row of a [Boolean](boolean-data-type.md) [matrix](matrix.md). It is zero at a false entry and otherwise one plus the previous column's [row run length](row-run-length.md), taking the value before column zero to be zero.
