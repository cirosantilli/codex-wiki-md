# Closed convex cone

↑ **Parent:** [Convex cone](convex-cone.md)

A [convex cone](convex-cone.md) that is a [closed set](closed-set.md) in its ambient topology. In a finite-dimensional [normed vector space](normed-vector-space.md), this means it contains every limit of its convergent sequences. For example, the [positive semidefinite cone](positive-semidefinite-cone.md) is closed because each test $X\mapsto x^TXx$ is continuous.
