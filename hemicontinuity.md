# Hemicontinuity

↑ **Parent:** [Nonlinear analysis](nonlinear-analysis-split.md)

For a real [Banach space](banach-space-split.md) $X$ and a [convex set](convex-set-split.md) $K\subset X$, a map $A:K\to X^*$ is [hemicontinuous](hemicontinuity.md) if $t\mapsto\langle A(x+t(y-x)),z\rangle$ is continuous on $[0,1]$ for all $x,y\in K$ and $z\in X$. This tests [continuity](continuous-function.md) only along [line segments](line-segment.md) and only through pairings with fixed [vectors](vector.md). It is enough for the limiting step in [Minty's lemma](minty-s-lemma.md).
