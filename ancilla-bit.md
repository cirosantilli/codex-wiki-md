# Ancilla bit

↑ **Parent:** [Quantum information theory](quantum-information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ancilla_bit)

An [ancilla bit](ancilla-bit.md) is an auxiliary bit providing workspace in reversible computation. In a [quantum circuit](quantum-circuit-split.md), an [ancilla qubit](ancilla-qubit.md) provides quantum workspace; a general [quantum ancilla](quantum-ancilla.md) need not be a single bit.
