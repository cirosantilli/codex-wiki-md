# Averaged operator

↑ **Parent:** [Nonexpansive mapping](nonexpansive-mapping.md)

An operator is $\alpha$-averaged for $0<\alpha<1$ when $T=(1-\alpha)I+\alpha R$ for a [nonexpansive mapping](nonexpansive-mapping.md) $R$. Averaging controls the update residual and enables fixed-point iteration. A [firmly nonexpansive mapping](firmly-nonexpansive-mapping.md) is exactly a $1/2$-averaged operator.
