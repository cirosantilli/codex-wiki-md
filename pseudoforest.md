# Pseudoforest

↑ **Parent:** [Graph theory](graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pseudoforest)

A [pseudoforest](pseudoforest.md) is an [undirected graph](undirected-graph.md) in which every [connected component of a graph](component-graph-theory.md) contains at most one [cycle in a graph](cycle-in-a-graph.md). Thus each component is a [tree](tree-graph-theory.md) or a [unicyclic component](unicyclic-component.md). A finite tree component has one fewer edge than vertices; a finite unicyclic component has equally many edges and vertices.
