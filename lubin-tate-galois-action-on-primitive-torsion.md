<h1 id="lubin-tate-galois-action-on-primitive-torsion">Lubin–Tate Galois action on primitive torsion</h1>

↑ **Parent:** [Lubin–Tate extension](lubin-tate-extension.md)

For a primitive [Lubin–Tate torsion](lubin-tate-torsion.md) point $\lambda_n$, every Galois automorphism has $\sigma(\lambda_n)=[a_\sigma](\lambda_n)$ for a unique [unit](unit-in-a-ring.md) class $a_\sigma\pmod{\pi^n}$. All torsion points lie in $K(\lambda_n)$ because the integral endomorphism series converge there; hence the torsion field is Galois. The displayed map is an injective homomorphism. Its domain has order $(q-1)q^{n-1}$ by the primitive Eisenstein [polynomial](polynomial-split.md), equal to the number of [unit](unit-in-a-ring.md) classes, so it is an isomorphism.
