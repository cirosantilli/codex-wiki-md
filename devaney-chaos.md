# Devaney chaos

↑ **Parent:** [Dynamical systems](dynamical-systems-split.md)

A map on a metric space is chaotic in Devaney's sense when it is topologically transitive, its periodic points are dense, and it has sensitive dependence on initial conditions.

A continuous map is chaotic in Devaney's sense when it has [topological transitivity](topological-transitivity.md), a dense set of [periodic points](periodic-point.md), and [sensitive dependence on initial conditions](butterfly-effect.md).
