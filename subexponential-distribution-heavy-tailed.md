# Subexponential distribution (heavy-tailed)

↑ **Parent:** [Heavy-tailed distribution](heavy-tailed-distribution.md)

For nonnegative [independent and identically distributed random variables](independent-and-identically-distributed-random-variables.md) with unbounded support, this is the displayed two-summand tail asymptotic. The probability that the maximum exceeds $x$ is $1-F(x)^2\sim2\overline F(x)$, so the sum and maximum have asymptotically the same tail. This is the basic single-large-arrival effect relevant to [queue overflow](queue-overflow.md). The concentration-theory [sub-exponential random variable](subexponential-distribution-light-tailed.md) uses a separate light-tail convention.
