# Singular system of a periodic convolution operator

↑ **Parent:** [Singular system of a compact operator](singular-system-of-a-compact-operator.md)

The displayed [singular value system](singular-system-of-a-compact-operator.md) applies when the Fourier multipliers $c_n$ are nonzero. The phase in the left singular vector is necessary for complex kernels. If a multiplier vanishes, its mode instead belongs to the corresponding null spaces and is excluded from the positive singular system.
