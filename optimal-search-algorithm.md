# Optimal search algorithm

↑ **Parent:** [Search algorithm](search-algorithm.md)

A [search algorithm](search-algorithm.md) is optimal for a specified objective if its returned solution has the best objective value among all solutions. The objective is part of the claim: minimizing the number of actions does not generally maximize a reward assigned to terminal states. [Breadth-first tree search](breadth-first-tree-search.md) optimizes total cost when all actions have the same positive cost.
