# Non-Ramsey set from transfinite selection

↑ **Parent:** [Ramsey set of infinite subsets](ramsey-set-of-infinite-subsets.md)

Using the [axiom of choice](axiom-of-choice.md), enumerate all infinite subsets $A_\alpha$ of the [positive integers](positive-integer.md) in order type $2^{\aleph_0}$. By [transfinite recursion](transfinite-recursion.md), choose two previously unused infinite subsets $X_\alpha,Y_\alpha$ of each $A_\alpha$. This is possible because each $[A_\alpha]^\omega$ has cardinality $2^{\aleph_0}$ and fewer choices have been made at stage $\alpha$. The set $\{X_\alpha\}$ is not a [Ramsey set of infinite subsets](ramsey-set-of-infinite-subsets.md), since every $[A_\alpha]^\omega$ meets both it and its complement.
