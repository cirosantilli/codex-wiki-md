# Root vector

↑ **Parent:** [Root space](root-space.md)

A root vector is a nonzero element of a [root space](root-space.md) $\mathfrak g_\alpha$ in the [root-space decomposition](root-space-decomposition.md) of a [semisimple Lie algebra](semisimple-lie-algebra-split.md).
