# Turing reduction

↑ **Parent:** [Computability theory](computability-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Turing_reduction)

A set $A$ is Turing-reducible to $B$ when an [oracle machine](oracle-machine.md) with membership oracle $B$ computes the characteristic function of $A$. Unlike a [many-one reduction](many-one-reduction.md), it may make adaptive queries and reverse or combine oracle answers.
