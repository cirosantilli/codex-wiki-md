# Hereditarily normal space

↑ **Parent:** [Normal space](normal-space.md)

A space is hereditarily normal when every subspace is a [normal topological space](normal-space.md). This is stronger than normality: arbitrary subspaces need not be closed. Every [perfectly normal space](perfectly-normal-space.md) is hereditarily normal.
