# Independent transversal

↑ **Parent:** [Independent set (graph theory)](independent-set-graph-theory.md)

For a [graph](graph-split.md) whose vertices are partitioned into parts, an independent transversal is an [independent set](independent-set-graph-theory.md) containing exactly one vertex from each part. If a cycle's parts each have twelve vertices, choose one vertex uniformly and independently per part. A cycle edge joining distinct parts is selected at both ends with [probability](probability.md) $1/144$. Each [event](event.md) depends on at most $47$ others, since each part meets at most $24$ cycle edges. The [Lovász local lemma](lovasz-local-lemma.md) applies because $48e/144<1$, proving existence for an arbitrary such partition.
