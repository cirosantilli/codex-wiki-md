# Poisson structure

↑ **Parent:** [Poisson manifold](poisson-manifold.md)

A [Poisson structure](poisson-structure.md) is an antisymmetric smooth bivector field whose induced function bracket satisfies the [Jacobi identity](jacobi-identity.md). In coordinates its condition is the vanishing cyclic sum of $\omega^{dc}\partial_d\omega^{ab}$. Applying Jacobi to coordinate functions proves necessity; expanding arbitrary brackets cancels the second derivatives and proves sufficiency. A function bracket-commuting with every function is a [Casimir function of a Poisson manifold](casimir-function-of-a-poisson-manifold.md).
