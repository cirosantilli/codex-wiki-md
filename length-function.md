# Length function

↑ **Parent:** [Geometric group theory](geometric-group-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Length_function)

A group length function $L:G\to[0,\infty)$ satisfies $L(1)=0$, $L(g^{-1})=L(g)$ and $L(gh)\leq L(g)+L(h)$. Word length for a chosen generating set is an example; [Coxeter length](coxeter-length.md) uses the simple reflections.
