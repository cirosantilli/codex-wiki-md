# Perfect subsequence lemma

↑ **Parent:** [Well-quasi-ordering](well-quasi-ordering.md)

Every infinite [sequence](sequence.md) in a [well-quasi-ordering](well-quasi-ordering.md) has an infinite [subsequence](subsequence.md) all of whose earlier terms precede its later terms. Some term must have infinitely many later terms above it: otherwise choose each new index outside the finitely many upper-cone index [sets](set-split.md) of the terms already chosen, producing a [bad sequence](bad-sequence.md). Apply the same observation successively inside the infinite upper-cone [subsequence](subsequence.md). Each restriction preserves all earlier inequalities, proving the assertion.
