# Connected set

↑ **Parent:** [Connected space](connected-space.md)

A [subset](subset.md) of a [topological space](topological-space.md) is a connected set when its [subspace topology](subspace-topology.md) is [connected](connected-space.md). Thus connectedness is tested using relatively [open sets](open-set.md), not only subsets open in the ambient space.
