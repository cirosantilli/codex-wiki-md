# Cartan curvature forms for a static spherical metric

↑ **Parent:** [Curvature 2-form](curvature-2-form.md)

In the exterior orthonormal coframe $E^0=\sqrt Vdt$, $E^1=dr/\sqrt V$, $E^2=rd\theta$, $E^3=r\sin\theta d\phi$, use $\Omega^a{}_b=\tfrac12R^a{}_{bcd}E^c\wedge E^d$. The independent mixed-index [curvature 2-forms](curvature-2-form.md) are $\Omega^0{}_1=-V''E^0\wedge E^1/2$, $\Omega^0{}_A=-V'E^0\wedge E^A/(2r)$, $\Omega^1{}_A=-V'E^1\wedge E^A/(2r)$ for $A=2,3$, and $\Omega^2{}_3=(1-V)E^2\wedge E^3/r^2$. The orthonormal [Ricci tensor](ricci-tensor.md) is diagonal with entries $V''/2+V'/r$, $-V''/2-V'/r$, and twice $(1-V-rV')/r^2$. The [Einstein field equations](einstein-field-equations.md) with negative [cosmological constant](cosmological-constant.md) then give $V=1-2M/r+r^2/l^2$.
