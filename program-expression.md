# Program expression

↑ **Parent:** [Programming language syntax](programming-language-syntax.md)

A program construct that is evaluated to obtain a value, potentially with [side effects](side-effect-computer-science.md) or failure. An arithmetic [mathematical expression](expression-mathematics.md) is one example; its [abstract syntax tree](abstract-syntax-tree.md) records how operands and operations nest.
