# Zero derivative on a connected open set

↑ **Parent:** [Mean value inequality](mean-value-inequality.md)

A differentiable map on a connected open subset of Euclidean space whose derivative vanishes everywhere is constant. The [mean value inequality](mean-value-inequality.md) makes it constant on every ball in the domain, hence locally constant; connectedness then makes the value global.
