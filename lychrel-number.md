# Lychrel number

↑ **Parent:** [Palindromic number](palindromic-number.md)

A [positive integer](positive-integer.md) whose repeated reverse-and-add process never reaches a [palindromic number](palindromic-number.md) in the chosen base. Each step adds the current number to the number obtained by reversing its [numerical digits](numerical-digit.md). Failure to find a [palindromic number](palindromic-number.md) after a fixed iteration limit establishes only a candidate, not a proof that the process never succeeds.
