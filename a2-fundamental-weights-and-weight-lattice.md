# A2 fundamental weights and weight lattice

↑ **Parent:** [A2 root system](a2-root-system.md)

For the [A2 root system](a2-root-system.md), $\omega_1=(2\alpha_1+\alpha_2)/3$ and $\omega_2=(\alpha_1+2\alpha_2)/3$. The [weight lattice](weight-lattice.md) $P=\mathbb Z\omega_1+\mathbb Z\omega_2$ contains the [root lattice](root-lattice.md) $Q$ with index three. In fundamental coordinates $(a,b)$, root-lattice membership is $a-b\equiv0\pmod3$.
