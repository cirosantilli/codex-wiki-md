# Abstract class

↑ **Parent:** [Class (programming)](class-programming.md)

An abstract class cannot be instantiated directly and may combine concrete state or behavior with abstract operations that subclasses implement. Concrete [object methods](object-method.md) can depend on a representation convention that every subclass must maintain. An abstract declaration still has a result type: omitted result types in [Scala](scala.md) 2 procedure syntax mean Unit, not an unspecified Boolean query.
