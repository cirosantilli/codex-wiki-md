# Triangular number pair-counting identity

↑ **Parent:** [Triangular number](triangular-number.md)

For $N\geq1$ distinct objects, the number of [unordered pairs](unordered-pair.md) of different objects is

$$
\binom N2=\frac{N(N-1)}2=T_{N-1}.
$$

Ordering the objects gives $N-1$ pairs with the first object, $N-2$ new pairs with the second, and so on down to one. Alternatively, $N(N-1)$ [ordered pairs](ordered-pair.md) count every [unordered pair](unordered-pair.md) twice. The [binomial coefficient](binomial-coefficient-split.md) therefore counts the [edges](edge-of-a-graph.md) of a [complete graph](complete-graph.md) on $N$ [vertices](vertex-graph-theory.md). This is also consistent with the [handshaking lemma](degree-sum-formula.md): each [vertex](vertex-graph-theory.md) has [degree of a vertex](degree-graph-theory.md) $N-1$, and the degree sum counts every [edge](edge-of-a-graph.md) twice.
