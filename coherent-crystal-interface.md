# Coherent crystal interface

↑ **Parent:** [Crystal interface](crystal-interface.md)

An interface whose [lattice planes](lattice-plane.md) match continuously across the boundary. Elastic misfit [strain](strain.md) can accumulate when the unstrained [lattice parameters](lattice-constant.md) differ.
