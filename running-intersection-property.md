# Running intersection property

↑ **Parent:** [Junction tree](junction-tree.md)

The running intersection property says that every variable belongs to a connected subtree of a [junction tree](junction-tree.md). Equivalently, every clique along the path between two cliques contains their intersection. This ensures that eliminating variables on one side of a tree edge leaves a message depending only on its separator with the other side.
