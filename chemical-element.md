# Chemical element

↑ **Parent:** [Chemical substance](chemical-substance-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Chemical_element)

A [chemical element](chemical-element.md) is an identity shared by all [chemical atoms](atom-physics.md) whose [atomic nuclei](atomic-nucleus-split.md) contain the same number of [protons](proton.md). That number is its [atomic number](atomic-number.md), $Z$: six means [carbon](carbon.md), eleven means [sodium](sodium.md). The identity survives differences in [neutron](neutron-split.md) count, which distinguish [isotopes](isotope.md), and differences in [electron](electron.md) count, which distinguish neutral [chemical atoms](atom-physics.md) from [ions](ion.md). See the [IUPAC Gold Book, chemical element](https://goldbook.iupac.org/terms/view/C01022).

The same name can also denote a pure [chemical substance](chemical-substance-split.md) containing only that [chemical element](chemical-element.md). These two uses answer different questions. [Molecular oxygen](molecular-oxygen.md), $\mathrm O_2$, is a [chemical substance](chemical-substance-split.md) made entirely of [oxygen](oxygen.md); [water](water.md), $\mathrm H_2\mathrm O$, is a [chemical compound](chemical-compound.md) containing both [hydrogen](hydrogen.md) and [oxygen](oxygen.md). A [water](water.md) [molecule](molecule-split.md) contains three [chemical atoms](atom-physics.md) but only two [chemical elements](chemical-element.md). Joining [chemical atoms](atom-physics.md) through [chemical bonds](chemical-bond-split.md) changes their arrangement without changing their [atomic numbers](atomic-number.md).

This distinction makes [stoichiometry](stoichiometry.md) possible: ordinary [chemical reactions](chemical-reaction-split.md) rearrange [chemical atoms](atom-physics.md), so one can count each [chemical element](chemical-element.md) before and after a transformation. Changing the [proton](proton.md) count instead changes the [chemical element](chemical-element.md) and requires a [nuclear reaction](nuclear-reaction.md). The [periodic table](periodic-table.md) organizes these identities into a useful map, while [atomic number](atomic-number.md) bookkeeping keeps identity, [isotope](isotope.md), and [electric charge](electric-charge-split.md) separate.
