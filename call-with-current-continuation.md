# Call-with-current-continuation

↑ **Parent:** [First-class continuation](first-class-continuation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Call-with-current-continuation)

Supply the current [continuation](continuation-computer-science.md) to a user [function](function-split.md). A language can expose this as an escape [function](function-split.md) or as a separate [continuation](continuation-computer-science.md) value with its own invocation primitive; those interfaces need corresponding semantic definitions.
