# K3 linear system dichotomies

↑ **Parent:** [K3 surface](k3-surface.md)

For nef big systems on a complex [K3 surface](k3-surface.md), the successive alternatives distinguish a [monogonal linear system on a K3 surface](monogonal-linear-system-on-a-k3-surface.md) from a basepoint-free system; then a degree-two map from a birational map; then a projective ideal generated by quadrics from the trigonal and plane-quintic exceptions. The last alternatives must include the low-genus quartic and quadric-cubic models. The birational morphism can contract exactly the orthogonal $(-2)$-curves; it need not embed the original smooth surface.
