# Logistic model

↑ **Parent:** [Logistic regression](logistic-regression.md)

A logistic model maps a real-valued score $\eta$ to the probability $p=(1+e^{-\eta})^{-1}$, equivalently $\log(p/(1-p))=\eta$. [Logistic regression](logistic-regression.md) takes $\eta$ to be an affine function of the predictors.
