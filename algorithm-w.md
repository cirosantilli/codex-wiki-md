# Algorithm W

↑ **Parent:** [Hindley-Milner type system](hindley-milner-type-system.md)

[Algorithm W](algorithm-w.md) performs [type inference](type-inference.md) by traversing the program's [abstract syntax tree](abstract-syntax-tree.md), introducing fresh [type variables](type-variable.md), combining [type substitutions](type-substitution.md) obtained by [type unification](type-unification.md), and generalizing eligible `let` bindings. It distinguishes fresh instances of a [type scheme](type-scheme.md) from the shared monomorphic types of parameters to a [lambda abstraction](lambda-abstraction.md).
