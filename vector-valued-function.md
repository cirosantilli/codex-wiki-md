# Vector-valued function

↑ **Parent:** [Function](function-split.md)

A vector-valued function is a [function](function-split.md) with values in a [vector space](vector-space-split.md). For finite-dimensional real or complex target spaces, choosing a basis represents it by scalar coordinate functions; [continuity](continuous-function.md) and differentiability can then be checked coordinatewise.
