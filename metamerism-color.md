# Metamerism (color)

↑ **Parent:** [Optics](optics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Metamerism_(color))

Distinct spectra can give the same colour response for a specified observer and illumination. In a simplified three-[cone cell](cone-cell.md) model, equal values of $\int L(\lambda)R(\lambda)S_i(\lambda)\,d\lambda$ for $i=1,2,3$ need not imply identical [spectral reflectance](spectral-reflectance.md) functions $R$. Altering illumination or observer can break the match.
