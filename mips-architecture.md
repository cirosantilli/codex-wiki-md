# MIPS architecture

↑ **Parent:** [Instruction set architecture](instruction-set-architecture.md)

A family of reduced instruction set computer architectures. The classic 32-[bit](bit.md) [integer](integer-split.md) encoding has five-[bit](bit.md) [processor register](processor-register.md) fields, while many branch and jump instructions execute a [branch delay slot](branch-delay-slot.md). These conventions differ from later revisions and must be stated when presenting [assembly language](assembly-language.md).
