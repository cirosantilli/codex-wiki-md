# Undecidable unary languages with linear-size circuits

↑ **Parent:** [Polynomial-size circuit family](polynomial-size-circuit-family.md)

For any set of lengths $A$, choose at length $n$ a constant-zero [Boolean circuit](boolean-circuit.md) when $n\notin A$, and an AND of all inputs when $n\in A$. This uses $O(n+1)$ gates. If $A$ is [undecidable](undecidable-decision-problem.md), so is $U_A$, yet it belongs to [P/poly](p-poly.md). Since all [NP](np-complexity.md) languages are decidable by certificate enumeration, this proves [P/poly](p-poly.md) is not equal to [NP](np-complexity.md); it does not resolve containment in the other direction.
