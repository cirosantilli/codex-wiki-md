# Parity unimodality of an sl2 character

↑ **Parent:** [Classification of finite-dimensional sl2 representations](classification-of-finite-dimensional-sl2-representations.md)

For a finite-dimensional [sl2 Lie algebra](sl2-lie-algebra.md) representation, write $\chi(q)=\sum_jc_jq^j$. Each irreducible summand has character $q^m+q^{m-2}+\cdots+q^{-m}$, so $c_j=c_{-j}$ and $c_j\ge c_{j+2}$ for nonnegative $j$. Thus each parity subsequence is symmetric and unimodal. If all weights have one parity, removing the unused exponents gives an ordinarily unimodal coefficient sequence. The full sequence including every integer exponent need not be unimodal: $q+q^{-1}$ has coefficients $1,0,1$.
