# Anti-Zener model

↑ **Parent:** [Linear viscoelastic fluid](linear-viscoelastic-fluid.md)

A [Maxwell fluid](linear-maxwell-fluid.md) branch connected in parallel with a Newtonian [dashpot](dashpot.md). Branches share strain and their stresses add. With $\tau=\eta_M/G$, the displayed modulus uses the $e^{i\omega t}$ convention. Its low-frequency viscosity is $\eta_M+\eta_s$ and static shear modulus zero, so the material ultimately flows.
