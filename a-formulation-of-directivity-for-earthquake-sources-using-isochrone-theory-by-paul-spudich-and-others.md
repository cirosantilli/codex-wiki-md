# A formulation of directivity for earthquake sources using isochrone theory by Paul Spudich and others

↑ **Parent:** [Physics bibliography](physics-bibliography-split.md)  
🏷️ **Tags:** [Work by Paul Spudich](work-by-paul-spudich.md)

[https://pubs.usgs.gov/of/2004/1268/](https://pubs.usgs.gov/of/2004/1268/)

[United States Geological Survey](united-states-geological-survey.md) Open-File Report 2004-1268. [Paul Spudich](paul-spudich.md) and coauthors derive a finite-source directivity measure from the distribution of arrival times across a rupturing [fault](geological-fault.md). The explanatory discussion links apparent pulse compression to the rate at which radiation from successive patches reaches a receiver.
