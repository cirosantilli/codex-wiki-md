# Pole forward-backward asymmetry for charged leptons

↑ **Parent:** [Z boson](z-boson.md)

For a pure resonant [Z boson](z-boson.md) with negligible [fermion](fermion.md) masses, $\mathcal A_f=(|g_L^f|^2-|g_R^f|^2)/(|g_L^f|^2+|g_R^f|^2)$ and $A_{FB}=3\mathcal A_e\mathcal A_f/4$. [Lepton universality](lepton-universality.md) makes this $3\mathcal A_\ell^2/4$ for charged leptons. A nonzero value diagnoses [parity violation](parity-violation.md) within this single-resonance approximation; a general angular forward-backward asymmetry need not be parity odd.
