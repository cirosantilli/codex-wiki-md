# Atomless forcing order

↑ **Parent:** [Forcing atom](forcing-atom.md)

An order is atomless if it has no [forcing atom](forcing-atom.md), equivalently every condition has a pair of [incompatible forcing conditions](incompatible-forcing-conditions.md) below it. For a fixed order belonging to a [transitive model](transitive-model.md), this property is absolute because its quantifiers range over the unchanged [set](set-split.md) of conditions. Infinite-domain [Fn forcing](fn-forcing.md) with at least two possible values is atomless: prescribe different values at one fresh coordinate.
