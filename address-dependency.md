# Address dependency

↑ **Parent:** [Memory model](memory-model.md)

A value loaded by one instruction directly contributes, through register computation, to a later memory access's [memory address](memory-address.md). Loading a [pointer](pointer-computer-programming.md) and then reading fields through that saved [pointer](pointer-computer-programming.md) is a natural example. This differs from a [control dependency](control-dependency.md).
