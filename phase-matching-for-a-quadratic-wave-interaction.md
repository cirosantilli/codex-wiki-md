# Phase matching for a quadratic wave interaction

↑ **Parent:** [Quadratic wave interaction](quadratic-wave-interaction.md)

A resonant interaction requires matching both [wavenumber](wavenumber.md) and [angular frequency](angular-frequency.md): $k_3=k_1+k_2$ and $\omega_3=\omega_1+\omega_2$ for a sum interaction, with corresponding sign changes for differences. A common [phase velocity](phase-velocity.md) alone does not guarantee that a generated harmonic lies on the [dispersion relation](dispersion-relation.md).
