<h1 id="friedman-moschovakis-coding-lemma">Friedman–Moschovakis coding lemma</h1>

↑ **Parent:** [Descriptive set theory](descriptive-set-theory-split.md)

Assume the [axiom of determinacy](axiom-of-determinacy.md). If $\lambda$ is a surjective image of the [Baire space of sequences](baire-space-of-sequences.md) and, for every $\xi<\lambda$, the power set $\mathcal P(\xi)$ is a surjective image of that space, then $\mathcal P(\lambda)$ is also a surjective image of it.
