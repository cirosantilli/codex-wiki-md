# Compact phase sectors

↑ **Parent:** [Phase vortex](phase-vortex.md)

An [XY model](xy-model.md) orientation takes values on a circle, so a circuit around an excluded defect core can carry integer [winding number](winding-number.md). Smooth single-valued [spin waves](spin-wave.md) cannot change that integer without a core event or boundary crossing. The locally quadratic [order-parameter phase](order-parameter-phase.md) action therefore describes a sector, rather than automatically summing every compact-field configuration. Vortex-antivortex unbinding changes the large-distance [correlation function](correlation-function.md) and renormalized [phase stiffness](phase-stiffness.md), even though ordinary [long-range order](long-range-order.md) is already absent in two dimensions at positive [temperature](temperature-split.md).
