# Measurable set

↑ **Parent:** [Sigma-algebra](sigma-algebra.md)

A [subset](subset.md) of $X$ is measurable relative to a [sigma-algebra](sigma-algebra.md) $\mathcal F$ when it belongs to $\mathcal F$. A [measure](measure-split.md) defined on $\mathcal F$ assigns sizes to these sets. Measurability depends on the chosen [sigma-algebra](sigma-algebra.md); for example, a [Lebesgue measurable set](lebesgue-measurable-set.md) need not be a [Borel set](borel-set.md).
