# Tip of the red giant branch

↑ **Parent:** [Cosmic distance ladder](cosmic-distance-ladder.md)

The termination of the first-ascent [red giant](red-giant.md) [luminosity function](luminosity-function-astronomy.md) near helium ignition provides a calibrated population-II distance indicator. In suitable passbands the tip [luminosity](luminosity.md) varies relatively weakly over a useful old, metal-poor population range. Colour/composition corrections, foreground [extinction](extinction.md), photometric completeness and contamination by other evolved [stars](star.md) must be controlled; an arbitrary brightest red [star](star.md) is not a reliable tip measurement.
