# Random-cluster single-edge conditional probability

↑ **Parent:** [Random-cluster model](random-cluster-model.md)

For an edge with endpoints already connected without that edge, including any boundary wiring, the conditional open [probability](probability.md) is $p$. Otherwise opening the edge merges two components, so the [conditional probability](conditional-probability.md) is $p/(p+q(1-p))$. For $q\geq1$, this [conditional probability](conditional-probability.md) increases when more other edges are open or more boundary vertices are identified. This is the local mechanism of [boundary monotonicity of the random-cluster measure](boundary-monotonicity-of-the-random-cluster-measure.md).
