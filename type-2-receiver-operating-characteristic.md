# Type 2 receiver operating characteristic

↑ **Parent:** [Metacognitive sensitivity](metacognitive-sensitivity.md)

A [receiver operating characteristic](receiver-operating-characteristic.md) treating high confidence as a prediction that a first-order answer was correct. Varying confidence threshold $t$ traces the false-positive and true-positive probabilities in the displayed expression. Raw discrimination can depend on first-order task performance; it is not automatically a performance-independent measure of monitoring quality.
