# Rank-one Cholesky update

↑ **Parent:** [Cholesky decomposition](cholesky-decomposition.md)

Given a [Cholesky decomposition](cholesky-decomposition.md) $A=LL^T$, a rank-one Cholesky update computes a triangular factor of $A+xx^T$ in $O(n^2)$ operations without refactorizing the matrix from scratch.
