# Multiple imputation by chained equations

↑ **Parent:** [Multiple imputation](multiple-imputation.md)

Specify a [conditional distribution](conditional-distribution.md) for each incomplete variable given the others, cycle through parameter draws and missing-value draws, and retain multiple completed datasets after suitable convergence checks. Preserve observed entries. Adequate models, appropriate support and the intended analysis structure matter; arbitrary conditional models need not be compatible with one joint distribution. Standard applications assume [missing at random](missing-at-random.md) given included predictors. Use [Rubin's rules](rubin-s-rules.md) to pool estimates and uncertainty.
