# Odd-length binary self-orthogonal dual extension

↑ **Parent:** [Self-orthogonal binary subspace](self-orthogonal-binary-subspace.md)

If a [self-orthogonal binary subspace](self-orthogonal-binary-subspace.md) has odd length $n$ and [dimension](dimension-vector-space.md) $(n-1)/2$, its [dual code](dual-code.md) is obtained by adjoining the all-ones word. Self-orthogonality makes every [codeword](codeword.md) even-weight, so $\mathbf1\in C^\perp$ but $\mathbf1\notin C$. Comparing [dimensions](dimension-vector-space.md) proves the formula. The [dimension](dimension-vector-space.md) hypothesis alone is insufficient: $C=\langle100\rangle$ at length three is a counterexample.
