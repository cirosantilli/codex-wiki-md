# Transfer matrix for the one-dimensional Ising model

↑ **Parent:** [Ising model](ising-model.md)

For nearest-neighbour interactions, a two-by-two transfer matrix assigns one [Boltzmann factor](boltzmann-factor.md) to every adjacent spin pair. With periodic boundary conditions, summing all spin configurations gives the [partition function](canonical-partition-function.md) as the trace of a power of this matrix.
