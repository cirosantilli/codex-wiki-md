# Chelate ring

↑ **Parent:** [Chelation](chelation.md)

A [chelate ring](chelate-ring.md) is a closed bonded path containing the central atom and a ligand with multiple attachments to it. A tethered Cp–pyridyl ligand can close such a path when the pyridyl N coordinates.
