# Atwood number

↑ **Parent:** [Rayleigh-Taylor instability](rayleigh-taylor-instability.md)

The dimensionless density contrast $(\rho_h-\rho_l)/(\rho_h+\rho_l)$, conventionally using heavy and light densities. In the inviscid, zero-surface-tension heavy-over-light [Rayleigh-Taylor instability](rayleigh-taylor-instability.md), the [growth rate](growth-rate.md) is $s=\sqrt{\mathcal A gk}$. State the signed ordering if labels are not heavy/light.
