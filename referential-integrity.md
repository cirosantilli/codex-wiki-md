# Referential integrity

↑ **Parent:** [Data structure](data-structure-split.md)

A constraint requiring stored identifiers or references to denote valid represented entities, except for explicitly permitted absent-reference markers. For a node [set](set-split.md) $T$ with successor identifiers, integrity can require each nonnull successor identifier to equal the identifier of some node in $T$. This is separate from identifier uniqueness and from order constraints on values along edges.
