# Sequentially weakly closed set

↑ **Parent:** [Weak topology](weak-topology-split.md)

A subset $K$ of a [normed space](normed-vector-space-split.md) is sequentially weakly closed when every [weakly convergent](weak-convergence.md) sequence in $K$ has its limit in $K$. Every weakly closed [set](set-split.md) has this property. For a [convex set](convex-set-split.md) in a [Banach space](banach-space-split.md), it is equivalent to closure in the [norm topology](norm-topology.md): [Mazur lemma](mazur-s-lemma.md) produces [norm convergent](norm-convergence.md) [convex combinations](convex-combination.md) from any [weakly convergent](weak-convergence.md) sequence, and conversely [norm convergence](norm-convergence.md) implies [weak convergence](weak-convergence.md). For a [Hilbert space](hilbert-space-split.md), the [weak Banach–Saks theorem in a Hilbert space](weak-banach-saks-theorem-in-a-hilbert-space.md) supplies these [convex combinations](convex-combination.md) as subsequence averages. No equivalence with weak closedness is asserted here for arbitrary nonconvex [sets](set-split.md).
