# Schreier graph

↑ **Parent:** [Cayley graph](cayley-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Schreier_graph)

For a [group](group-split.md) $G$, a [subgroup](subgroup.md) $H$, and a generating set $S$, the Schreier graph has the left cosets $G/H$ as vertices and an edge from $gH$ to $sgH$ for each $s\in S$. Its radius-$m$ ball records the cosets met by $S^m$.
