# Coinvariant module

↑ **Parent:** [Module theory](module-theory-split.md)

For a group $G$ acting on a module $M$, the coinvariant module is

$$
M_G=M/\langle g\cdot m-m:g\in G,\ m\in M\rangle.
$$
