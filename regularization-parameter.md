# Regularization parameter

↑ **Parent:** [Regularization of an inverse problem](regularization-of-an-inverse-problem.md)

A regularization parameter controls the tradeoff between approximation bias and data-noise amplification in an [inverse problem](inverse-problem-split.md). For [early stopping of Landweber iteration](early-stopping-of-landweber-iteration.md) with fixed step $\tau$, the convention $\alpha=1/(\tau n)$ associates a smaller parameter with more iterations.
