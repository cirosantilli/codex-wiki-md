# Channel code

↑ **Parent:** [Channel coding](channel-coding.md)

A deterministic fixed-length channel code consists of a [channel encoder](channel-encoder.md) $c$ and a [channel decoder](channel-decoder.md) $d$. It represents $m$ possible messages by length-$n$ input [codewords](codeword.md) for a [communication channel](communication-channel.md), and estimates the message from the resulting output word. Its [code rate](code-rate.md) is $(\log_2m)/n$ [bits](bit.md) per [channel](communication-channel.md) use. The [maximal decoding error probability](maximal-decoding-error-probability.md) requires reliable recovery of every message, while an average error criterion depends on the chosen message [probability distribution](probability-distribution-split.md).
