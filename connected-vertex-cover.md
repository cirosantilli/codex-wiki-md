# Connected vertex cover

↑ **Parent:** [Vertex cover](vertex-cover.md)

A [vertex cover](vertex-cover.md) $C$ whose induced [subgraph](subgraph.md) $G[C]$ is connected. The optimization problem minimizes $|C|$ subject to both conditions. A [graph](graph-split.md) with edges in two distinct [connected components of a graph](component-graph-theory.md) has no connected vertex cover: covering each of these [edges](edge-of-a-graph.md) requires selected [vertices](vertex-graph-theory.md) in different components. Isolated [vertices](vertex-graph-theory.md) can be ignored when exactly one component contains all the [edges](edge-of-a-graph.md). The edge-free case depends on whether the empty solution is admitted.
