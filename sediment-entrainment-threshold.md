# Sediment entrainment threshold

↑ **Parent:** [Shields parameter](shields-parameter.md)

The [sediment entrainment threshold](sediment-entrainment-threshold.md) is the bed [shear stress](shear-stress.md) at which resting grains begin moving. An elementary [force balance](force-balance.md) using spherical grains, tangential [quadratic drag](quadratic-drag.md), and [static friction](static-friction.md) gives $\Theta_{\mathrm{th},0}=4\mu_s/(3C_D)$ when the [drag coefficient](drag-coefficient.md) is defined relative to the bed [shear velocity](shear-velocity.md).
