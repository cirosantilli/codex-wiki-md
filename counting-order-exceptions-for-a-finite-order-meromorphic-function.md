# Counting-order exceptions for a finite-order meromorphic function

↑ **Parent:** [Growth order of a meromorphic function](growth-order-of-a-meromorphic-function.md)

At most two values can have counting order smaller than a positive finite function order. Otherwise the [Nevanlinna second main theorem](nevanlinna-second-main-theorem.md) with three such values bounds the characteristic by a smaller power outside a finite-length exceptional set. Monotonicity extends this bound to all large radii by choosing a good radius in $[r,r+1]$, contradicting the original order. Order zero is immediate from nonnegativity and the first theorem.
