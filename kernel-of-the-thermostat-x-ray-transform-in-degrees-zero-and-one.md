# Kernel of the thermostat X-ray transform in degrees zero and one

↑ **Parent:** [Thermostat X-ray transform](thermostat-x-ray-transform.md)

For a smooth [Anosov flow](anosov-flow.md) generated by a [surface thermostat](generalized-thermostat-on-a-riemannian-surface.md) on a closed oriented [Riemannian surface](riemannian-surface.md), a smooth base function plus a smooth one-form is a smooth [flow coboundary](flow-coboundary.md) precisely when the base function is zero and the one-form is an [exact differential form](exact-differential-form.md). This is the nontrivial degree-zero/one kernel theorem. It does not require negative curvature or preservation of Liouville volume. The converse follows directly from $F(f\circ\pi)=df(v)$. A primary proof of the kernel theorem is [https://arxiv.org/abs/math/0601039.](https://arxiv.org/abs/math/0601039.)
