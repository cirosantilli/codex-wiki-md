# Byte-table leading-zero count

↑ **Parent:** [Count leading zeros](count-leading-zeros.md)

For [leading-zero count](count-leading-zeros.md), inspect a word's bytes from most significant to least significant. Every zero byte contributes eight; the first nonzero byte contributes its table value in the title. If all bytes are zero, a word of width $w$ contributes $w$. Defining the zero table entry explicitly makes the all-zero argument a regular case rather than an out-of-range logarithm.
