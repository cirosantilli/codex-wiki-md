# Polynomial-time algorithm

↑ **Parent:** [Polynomial time](polynomial-time.md)

An algorithm runs in polynomial time if its worst-case running time is bounded by a fixed polynomial in the input length. Arithmetic with fixed-degree algebraic numbers also needs polynomial bit cost when used in such a guarantee. The [Edmonds–Karp algorithm](edmonds-karp-algorithm.md) and the [method of conditional probabilities](method-of-conditional-probabilities.md) with efficiently computable [clause](clause-of-a-boolean-formula.md) expectations are examples.
