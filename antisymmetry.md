# Antisymmetry

↑ **Parent:** [Antisymmetric relation](antisymmetric-relation.md)

The property of a [binary relation](binary-relation.md) that opposite directed relationships between two elements can hold only when those elements are equal. It does not require every pair to be comparable and does not prohibit a longer [directed cycle](directed-cycle.md) whose reverse edges are initially absent. Taking [reflexive transitive closure](reflexive-transitive-closure.md) can therefore destroy this property.
