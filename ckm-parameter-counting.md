# CKM parameter counting

↑ **Parent:** [Cabibbo-Kobayashi-Maskawa matrix](cabibbo-kobayashi-maskawa-matrix.md)

An $N\times N$ [CKM matrix](cabibbo-kobayashi-maskawa-matrix.md) starts with $N^2$ parameters of a [unitary matrix](unitary-matrix.md). Independent quark rephasings remove $2N-1$ phases because the common phase has no effect. The remaining $(N-1)^2$ parameters consist of $N(N-1)/2$ angles and $(N-1)(N-2)/2$ [CP-violating phases](cp-violating-phase.md). Extra mass degeneracies may reduce this generic count.
