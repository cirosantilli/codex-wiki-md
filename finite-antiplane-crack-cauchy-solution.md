# Finite antiplane crack Cauchy solution

↑ **Parent:** [Hilbert problem for an antiplane crack](hilbert-problem-for-an-antiplane-crack.md)

Choose $\chi(z)=\sqrt{z^2-a^2}\sim z$ at infinity, cut on the finite crack. Its upper crack value is $i\sqrt{a^2-t^2}$, so $H=\chi G$ has jump $-2i\sqrt{a^2-t^2}p(t)$. The [Sokhotski–Plemelj theorem](sokhotski-plemelj-theorem.md) gives the displayed [Cauchy integral](cauchy-transform.md) solution. It decays as $z^{-2}$ for integrable weighted traction. A possible homogeneous term $C/\chi$ would give a logarithmic displacement period; it is removed for a dislocation-free finite crack with no extra remote loading.
