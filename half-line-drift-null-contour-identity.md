# Half-line drift null contour identity

↑ **Parent:** [Half-range Fourier transform](half-range-fourier-transform.md)

For $\alpha>0$, let $L$ be the upper branch $\operatorname{Im}k=(\alpha+\sqrt{\alpha^2+4(\operatorname{Re}k)^2})/2$, oriented left to right. Above $L$, $i\alpha-k$ lies in the lower half-plane, where a decaying half-line [Fourier transform](fourier-transform.md) is analytic. For $x>0$, closing upward proves that the displayed integral vanishes. An additional multiplier analytic above $L$ with at most polynomial growth is allowed, using exponential decay and, if needed, regularized contours. This supplies a null term in a [Fokas method](fokas-method.md) inversion formula without changing the function in the interior.
