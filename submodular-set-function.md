# Submodular set function

↑ **Parent:** [Set function](set-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Submodular_set_function)

A [set function](set-function.md) is submodular if $f(A)+f(B)\geq f(A\cup B)+f(A\cap B)$ for every pair of subsets. [Entropy submodularity](entropy-submodularity.md) is a fundamental example.
