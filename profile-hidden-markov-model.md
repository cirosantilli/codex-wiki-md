# Profile hidden Markov model

↑ **Parent:** [Hidden Markov model](hidden-markov-model.md)

A [profile hidden Markov model](profile-hidden-markov-model.md) represents the position-dependent structure of a [sequence alignment](sequence-alignment.md) using an ordered series of [match states](match-state.md) and optional [insertion states](insertion-state.md), commonly with silent deletion states as well. An emitting state chooses one character from its [probability mass function](probability-mass-function.md); transitions describe which profile position comes next. If deletion states are forbidden, an alignment column containing gaps cannot be a compulsory [match state](match-state.md).
