# Giesekus model

↑ **Parent:** [Upper-convected Maxwell model](upper-convected-maxwell-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Giesekus_model)

The Giesekus model adds the nonlinear anisotropic-drag term $\alpha\lambda\boldsymbol\tau^2/\eta$ to the [Upper-convected Maxwell model](upper-convected-maxwell-model.md). Positive dimensionless mobility factor $\alpha$ produces shear thinning and a nonzero second normal-stress difference.
