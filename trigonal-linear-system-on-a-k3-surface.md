# Trigonal linear system on a K3 surface

↑ **Parent:** [K3 surface](k3-surface.md)

For a basepoint-free nonhyperelliptic nef big divisor $D$, the trigonal condition means that its general smooth curve is a [trigonal curve](trigonal-curve.md). An [elliptic pencil on a K3 surface](elliptic-pencil-on-a-k3-surface.md) with $D\cdot E=3$ restricts to its degree-three pencil. On a smooth quartic containing a line $\Gamma$, the hyperplane class $H$ has this property for $E=H-\Gamma$.
