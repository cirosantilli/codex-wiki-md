# Recognition memory

↑ **Parent:** [Memory in animals](memory-in-animals.md)

Identifying previously encountered material when it is presented again. Recognition provides external information unavailable in unaided recall, so a recognition–recall difference is not automatically evidence for separate [memory](memory-in-animals.md) stores.
