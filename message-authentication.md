# Message authentication

↑ **Parent:** [Cryptography](cryptography.md)

Assurance of the source and integrity of a message against specified adversarial capabilities. [Digital signatures](digital-signature.md) permit public verification, whereas a [message authentication](message-authentication.md) code uses a shared secret; [encryption](encryption.md) alone need not authenticate.
