# Commutation of computational-basis dephasing and phase gates

↑ **Parent:** [Dephasing channel](dephasing-channel.md)

For a [qubit](qubit.md), [computational basis](computational-basis.md) [dephasing](dephasing-channel.md) with complex overlap $c$ maps $\rho_{01}$ to $\overline c\rho_{01}$ and preserves the diagonal entries. Conjugation by the [phase gate](phase-gate.md) $P_\varphi=\operatorname{diag}(1,e^{i\varphi})$ maps the same entry to $e^{-i\varphi}\rho_{01}$. Since these scalar factors commute, their [quantum channels](quantum-channel.md) commute on every [density matrix](density-matrix-split.md). More directly, an interaction $|j\rangle|e\rangle\mapsto|j\rangle|e_j\rangle$ and a diagonal [phase gate](phase-gate.md) give the same joint [quantum state](quantum-state.md) in either order on the specified initial environment state. This need not hold for an interaction that changes the [quantum state populations](quantum-state-population.md).
