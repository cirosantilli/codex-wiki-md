# One-tree travelling-salesman bound

↑ **Parent:** [1-tree](1-tree.md)

Deleting a vertex from a [Hamiltonian cycle](hamilton-cycle.md) leaves a spanning path, so every travelling-salesman tour is a [one-tree](1-tree.md). Minimizing the same edge cost over one-trees therefore gives a [lower bound](lower-bound-in-a-partially-ordered-set.md) for the [travelling salesman problem](travelling-salesman-problem.md). A connected [one-tree](1-tree.md) with every degree two is itself a [Hamiltonian cycle](hamilton-cycle.md), and a minimizing such [one-tree](1-tree.md) certifies the tour optimum.
