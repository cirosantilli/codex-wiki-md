# Causal filter

↑ **Parent:** [Linear filter](linear-filter.md)

A causal filter uses only present and past [input](input-computer-science.md) values to produce its current [output](output-computing.md). The trailing [moving average](moving-average.md) is causal; a centered average that uses future samples is not. Future samples can be available when processing a finished recording, but they are unavailable to a live measurement at the current time.
