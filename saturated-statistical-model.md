# Saturated statistical model

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)

A saturated model has enough independently varying mean parameters to match every observed response or response cell. In individual [Bernoulli distribution](bernoulli-distribution.md) data its fitted probabilities are $p_i=y_i$, and its maximum [log-likelihood](log-likelihood.md) is zero under $0\log0=0$. It defines the reference in a [binomial deviance](binomial-deviance.md).
