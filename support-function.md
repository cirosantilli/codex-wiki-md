# Support function

↑ **Parent:** [Convex set](convex-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Support_function)

The support function of a nonempty set $C$ is $\sigma_C(x)=\sup_{v\in C}\langle x,v\rangle$. It is convex and positively homogeneous, and for a closed convex set its [convex conjugate](convex-conjugate.md) is the [indicator function](indicator-function.md) of $C$.
