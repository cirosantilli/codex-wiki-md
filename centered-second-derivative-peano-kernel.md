# Centered second-derivative Peano kernel

↑ **Parent:** [Peano kernel](peano-kernel.md)

For $L(f)=f''(0)-f(-1)+2f(0)-f(1)$ on $C^3[-1,1]$, quadratic polynomials are annihilated. The [Peano kernel theorem](peano-kernel-theorem.md) gives $L(f)=\int_{-1}^1K(t)f'''(t)\,dt$, with the displayed kernel; its value at zero does not affect the integral. Its absolute integral is $1/3$, proving $|L(f)|\le\|f'''\|_\infty/3$. The kernel changes sign, consistent with exactness also on cubic polynomials despite the estimate using only three derivatives.
