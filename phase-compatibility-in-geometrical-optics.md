# Phase compatibility in geometrical optics

↑ **Parent:** [Eikonal equation for a variable-speed wave](eikonal-equation-for-a-variable-speed-wave.md)

A smooth phase gives $\partial_{X_i}k_j=\partial_{X_j}k_i$ and $\mathbf k_T=-\nabla\omega$. These mixed-[derivative](derivative.md) identities allow the spatially differentiated [dispersion relation](dispersion-relation.md) to be rewritten as [Hamiltonian ray equations for a local dispersion relation](hamiltonian-ray-equations-for-a-local-dispersion-relation.md). Away from phase singularities they express the curl-free character of a local wavevector.
