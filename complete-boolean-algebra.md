# Complete Boolean algebra

↑ **Parent:** [Boolean algebra](boolean-algebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Complete_Boolean_algebra)

A Boolean algebra in which every set-indexed family has a join and a meet. [Double-negation Boolean algebra](double-negation-boolean-algebra.md) is an intuitionistic example, with joins formed by regularizing unions. Completeness makes truth values for quantifiers possible in a [Boolean-valued inner universe over intuitionistic set theory](boolean-valued-inner-universe-over-intuitionistic-set-theory.md).
