# Search tree

↑ **Parent:** [Search problem](search-problem.md)

A [rooted tree](rooted-tree.md) whose nodes are partial search states and whose children are possible next choices. Leaves represent completed candidates or terminated branches. [Backtracking](backtracking.md) traverses this tree while storing the current path, and [search pruning](search-pruning.md) removes branches that cannot yield a useful completion.
