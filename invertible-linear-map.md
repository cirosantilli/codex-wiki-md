# Invertible linear map

↑ **Parent:** [Differentiable map](differentiable-map.md)

An invertible linear map is a linear bijection; its inverse is also linear.

Invertibility adds a [bijection](bijection.md) requirement to the definition of a [linear map](linear-map.md).
