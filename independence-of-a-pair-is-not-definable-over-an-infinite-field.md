# Independence of a pair is not definable over an infinite field

↑ **Parent:** [Linear independence](linear-independence.md)

In the one-sorted vector-space language naming each [scalar multiplication](scalar-multiplication.md), a [first-order formula](first-order-formula.md) reduces by [quantifier elimination](quantifier-elimination.md) to finitely many [linear equations](linear-equation.md). An independent pair satisfies only the identically zero equations among them. A dependent pair $(x,ax)$ with nonzero $x$ satisfies the same listed equations if the [scalar](scalar-multiplication.md) $a$ avoids their finitely many forbidden ratios, which is possible over an infinite [field](field.md). Thus no formula defines pair independence. The complete independent-pair type is still [consistent](consistent-first-order-theory.md) in an infinite-dimensional [model](model-of-a-first-order-theory.md); it is nonisolated.
