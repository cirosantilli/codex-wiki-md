# p-adic L-function

↑ **Parent:** [L-function](l-function.md)

A p-adic L-function is a $p$-adic analytic function or measure interpolating suitably adjusted special values of an [L-function](l-function.md). The [Kubota-Leopoldt p-adic L-function](kubota-leopoldt-p-adic-l-function.md) is the basic example attached to a [Dirichlet character](dirichlet-character.md).
