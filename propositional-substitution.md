# Propositional substitution

↑ **Parent:** [Propositional formula](propositional-formula.md)

A [propositional substitution](propositional-substitution.md) maps each atomic propositional variable to a [propositional formula](propositional-formula.md) and extends recursively through every [logical connective](logical-connective.md). Replacements are simultaneous: a variable appearing inside a replacement formula is not replaced again in the same substitution step. Since [propositional logic](propositional-logic.md) has no variable-binding [quantifiers](quantifier.md), this operation has no variable-capture problem.
