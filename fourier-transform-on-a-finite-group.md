# Fourier transform on a finite group

↑ **Parent:** [Fourier analysis on a finite group](fourier-analysis-on-a-finite-group.md)

For a scalar function on a [finite group](finite-group.md), one normalized transform convention assigns the matrix $\mathbb E_xf(x)\rho(x)$ to each chosen [unitary irreducible representation](unitary-irreducible-representation.md). This map is a weighted [Hilbert space](hilbert-space-split.md) isomorphism by the [Parseval identity on a finite group](parseval-identity-on-a-finite-group.md). Another common convention uses $\rho(x)^*$; the corresponding [convolution theorem on a finite group](convolution-theorem-on-a-finite-group.md) then reverses the matrix product order for $(f*g)(x)=\mathbb E_yf(y)g(y^{-1}x)$.
