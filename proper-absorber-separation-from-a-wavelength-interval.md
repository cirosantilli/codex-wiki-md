# Proper absorber separation from a wavelength interval

↑ **Parent:** [Cosmological wavelength-redshift relation](cosmological-wavelength-redshift-relation.md)

A local redshift spacing between absorbers corresponds to proper path length $c\Delta z/[H(z)(1+z)]$. Using the same rest-frame transition for all lines gives $\Delta z=\Delta\lambda/\lambda_{\rm rest}$. This conversion assumes [cosmological redshift](cosmological-redshift.md) dominates the line spacing and uses a local Hubble-rate approximation.
