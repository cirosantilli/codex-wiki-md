# Piecewise-linear hat function

↑ **Parent:** [Finite element method](finite-element-method.md)

A piecewise-linear hat function is one at one mesh node, zero at all other nodes, and affine on each adjacent mesh interval. Interior hat functions form the standard nodal basis for continuous piecewise-linear finite elements with homogeneous [Dirichlet boundary conditions](dirichlet-boundary-condition.md).
