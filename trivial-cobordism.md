# Trivial cobordism

↑ **Parent:** [Cobordism](cobordism.md)

A [cobordism](cobordism.md) is trivial when it is [diffeomorphic](diffeomorphism.md) to a cylinder with the prescribed incoming boundary identification. Both boundary inclusions are [homotopy equivalences](homotopy-equivalence.md) and its [relative homology](relative-homology.md) with respect to either end vanishes. It can have [critical points](critical-point.md) for a chosen [cobordism Morse function](cobordism-morse-function.md); those must form an acyclic relative [Morse chain complex](morse-chain-complex.md).
