# Kernelization

↑ **Parent:** [Parameterized complexity](parameterized-complexity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kernelization)

A [kernelization](kernelization.md) is a [polynomial-time algorithm](polynomial-time-algorithm.md) mapping a parameterized [decision problem](decision-problem.md) instance $(I,k)$ to an equivalent instance $(I',k')$ of the same problem, with both encoded length $|I'|$ and parameter $k'$ bounded by a computable [function](function-split.md) of $k$. Equivalent means that both instances have the same yes/no answer. The bound need not be a [polynomial](polynomial-split.md) in $k$; a polynomial kernel is the stronger requirement that it is. For a decidable problem, exhaustively solving the bounded output leaves only a computable dependence on $k$, so [kernelization](kernelization.md) yields [fixed-parameter tractability](fixed-parameter-tractability.md).
