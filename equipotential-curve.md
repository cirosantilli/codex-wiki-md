# Equipotential curve

↑ **Parent:** [Equipotential surface](equipotential-surface.md)

An equipotential curve is a planar level curve of a scalar potential. Where the gradient is nonzero, its tangent is perpendicular to that gradient. In [potential flow](potential-flow.md), it is therefore perpendicular to the [velocity field](velocity-field.md); this distinguishes equipotential curves from [streamlines](streamline.md).
