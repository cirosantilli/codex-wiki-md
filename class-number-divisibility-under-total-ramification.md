# Class number divisibility under total ramification

↑ **Parent:** [Hilbert class field](hilbert-class-field.md)

If $M/L$ is an extension of [number fields](number-field.md), $L$ has no real places, and one finite prime of $L$ is totally ramified in $M$, then $h_L\mid h_M$. The [Hilbert class field](hilbert-class-field.md) $H_L$ has trivial intersection with $M$: any common intermediate extension would be both unramified and totally ramified at that prime. Thus $MH_L/M$ is an unramified abelian extension of degree $h_L$, and is contained in $H_M$.
