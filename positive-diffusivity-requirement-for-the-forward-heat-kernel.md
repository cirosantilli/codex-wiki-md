# Positive diffusivity requirement for the forward heat kernel

↑ **Parent:** [Heat kernel](heat-kernel.md)

The real [Gaussian function](gaussian-function.md) [heat kernel](heat-kernel.md) $(4\pi\varepsilon z)^{-1/2}\exp[-(\phi-\theta)^2/(4\varepsilon z)]$ is integrable only when $\varepsilon z>0$. For forward time $z>0$, this requires positive diffusivity. A [Cole-Hopf transformation](cole-hopf-transformation.md) is an algebraic substitution for any nonzero coefficient, but that does not make the real forward [convolution](convolution.md) valid for negative diffusivity. Constant initial heat data already produce a divergent integral with the wrong sign.
