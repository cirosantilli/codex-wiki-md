# Relative symplectic-area independence

↑ **Parent:** [Lagrangian path-area functional](lagrangian-path-area-functional.md)

Two homotopy strips with the same endpoint paths and boundary on [Lagrangian submanifolds](lagrangian-submanifold.md) glue to a relative $2$-cycle. If that cycle is zero in $H_2(M,L_0\cup L_1)$, its [symplectic area](symplectic-area.md) vanishes: apply [Stokes theorem](stokes-theorem.md), using $d\omega=0$ and the zero restriction of $\omega$ to each Lagrangian. Thus relative homology controls the ambiguity in a [Lagrangian path-area functional](lagrangian-path-area-functional.md).
