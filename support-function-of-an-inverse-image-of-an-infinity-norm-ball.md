# Support function of an inverse image of an infinity-norm ball

↑ **Parent:** [Support function](support-function.md)

If $x\notin\operatorname{range}P^T=(\ker P)^\perp$, the [support function](support-function.md) is infinite along a kernel line. Otherwise [linear programming duality](linear-programming-duality.md) gives the displayed minimum, attained because the corresponding linear programs are feasible with finite values. Splitting $q=\alpha-\beta$ into nonnegative parts yields the equivalent minimum of $\mathbf1^T(\alpha+\beta)$. Thus worst-case revenue over a [polyhedral uncertainty set](polyhedral-uncertainty-set.md) is $r_0^Tx-\sigma_C(x)$, with value $-\infty$ off the row space.
