# Henyey track

↑ **Parent:** [Pre-main-sequence star](pre-main-sequence-star.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Henyey_track)

A [pre-main-sequence star](pre-main-sequence-star.md) with a developing [radiative core](radiative-core.md) can contract along a relatively horizontal path toward higher [effective temperature](effective-temperature.md) in the [Hertzsprung-Russell diagram](hertzsprung-russell-diagram.md). This differs from the nearly vertical fully convective [Hayashi track](hayashi-track.md).
