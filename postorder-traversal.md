# Postorder traversal

↑ **Parent:** [Depth-first traversal of a tree](depth-first-traversal-of-a-tree.md)

Visit all child [subtrees](subtree.md) before visiting their parent. A [depth-first traversal of a tree](depth-first-traversal-of-a-tree.md) produces this order by processing a node on return from its recursive calls. It lets [dynamic programming](dynamic-programming.md) use the already computed answers of every child [subtree](subtree.md).
