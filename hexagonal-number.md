# Hexagonal number

↑ **Parent:** [Polygonal number](polygonal-number.md)

The $n$th [hexagonal number](hexagonal-number.md) is $H_n=n(2n-1)$ for a [positive integer](positive-integer.md) $n$. Since $H_n=T_{2n-1}$, every [hexagonal number](hexagonal-number.md) is also a [triangular number](triangular-number.md).
