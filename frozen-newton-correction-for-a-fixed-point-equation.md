# Frozen Newton correction for a fixed-point equation

↑ **Parent:** [Newton iteration in a Banach space](newton-iteration-in-a-banach-space.md)

To solve $\Phi(p)=p$, let $J$ be a bounded approximation to $(D\Phi(p_0)-I)^{-1}$ and set $A(p)=p-J(\Phi(p)-p)$. Its [derivative](derivative.md) is $DA(p)=I-J(D\Phi(p)-I)$. Every [fixed point](fixed-point.md) of $\Phi$ is fixed by $A$; the converse holds when $J$ is injective. A good inverse approximation makes $A$ a [contraction mapping](contraction-mapping.md) even if $\Phi$ itself has an expanding direction.
