# Event (relativity)

↑ **Parent:** [Spacetime](spacetime.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Event_(relativity))

A spacetime event is an idealized occurrence at one point of [spacetime](spacetime.md), such as a [light](light.md) pulse reaching a detector. An [inertial frame](inertial-frame.md) assigns spatial coordinates and a time coordinate to it. Different frames can assign different coordinates to the same [spacetime event](event-relativity.md); the event itself is not changed by a coordinate transformation.
