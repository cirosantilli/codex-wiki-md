# Scalar-valued function

↑ **Parent:** [Function](function-split.md)

A [scalar-valued function](scalar-valued-function.md) is a [function](function-split.md) whose [codomain](codomain.md) is a [field](field.md), typically the [real numbers](real-number.md) or [complex numbers](complex-number.md). Its output is a single [scalar](scalar.md), while its input can belong to an arbitrary [set](set-split.md). For example, the square of the [norm](norm.md) of a [vector](vector.md) is real-valued. In a relativistic application, being scalar-valued alone does not establish [Lorentz invariance](lorentz-invariance.md): the transformation of the input and of the complete quantity must also be specified.
