# Relative spreadsheet reference

↑ **Parent:** [Spreadsheet cell reference](spreadsheet-cell-reference.md)

A [relative spreadsheet reference](relative-spreadsheet-reference.md), such as `A2`, allows both coordinates to change when its [spreadsheet formula](spreadsheet-formula.md) is copied. From `C2`, `A2` means two columns left, in the same row. Copy `=A2*B2` from `C2` to `C4`: the displacement is zero columns and two rows, so it becomes `=A4*B4`. The row number changes to retain the same positional relationship to the [spreadsheet formula](spreadsheet-formula.md).
