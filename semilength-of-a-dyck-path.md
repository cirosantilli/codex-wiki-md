# Semilength of a Dyck path

↑ **Parent:** [Dyck path](dyck-path.md)

Half the number of steps in a [Dyck path](dyck-path.md). A [Dyck path](dyck-path.md) with [semilength of a Dyck path](semilength-of-a-dyck-path.md) $n$ has $2n$ steps and $n$ up/down pairs; the empty [Dyck path](dyck-path.md) has $n=0$.
