# Zermelo set theory

↑ **Parent:** [Zermelo–Fraenkel set theory](zermelo-fraenkel-set-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Zermelo_set_theory)

The usual [set theory](set-theory-split.md) with [extensionality](axiom-of-extensionality.md), [empty set](empty-set.md), [pairing](axiom-of-pairing.md), [union](set-union.md), [power set](power-set.md), [infinity](infinity.md) and full [separation](axiom-schema-of-specification.md), before adjoining [replacement](axiom-schema-of-replacement.md). Modern presentations often include [foundation](axiom-of-regularity.md); the convention should be specified when comparing theories. Class-theoretic variants add classes and class comprehension, rather than treating proper classes as sets.
