# Interpolation

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Interpolation)

Interpolation constructs a [function](function-split.md) agreeing exactly with prescribed values at sample points. The resulting function is an [interpolant](interpolant.md). Choosing a family determines how missing values are filled: [polynomial interpolation](polynomial-interpolation.md) selects a [polynomial](polynomial-split.md), while [linear interpolation](linear-interpolation.md) joins adjacent samples by straight segments. The [McShane extension theorem](mcshane-extension-theorem.md) instead permits any [Lipschitz function](lipschitz-continuity.md) with a specified bound and provides envelopes controlling all allowed choices.
