# Radial escape in an inverse-radius axial magnetic field

↑ **Parent:** [Lorentz force](lorentz-force.md)

For an axial [magnetic field](magnetic-field.md) $\mathbf B=(B_0/r)\mathbf e_z$, let $L=mr^2\dot\theta$. The [Lorentz force](lorentz-force.md) gives $\dot L=-qB_0\dot r$, so $\ell=(L+qB_0r)/m$ is constant. Since [magnetic forces do no work](magnetic-forces-do-no-work.md) and $\dot z$ is constant, the transverse speed $v_\perp$ is constant and $\dot r^2=v_\perp^2-(\ell/r-c)^2$. If $c\ell>0$ and $0<v_\perp<|c|$, two finite radial [turning points](turning-point.md) confine the motion. If $v_\perp>|c|$, an outward branch escapes to infinite radius. At equality a marginal escaping branch exists when $c\ell>0$, but $\ell=0$ gives a circular orbit instead. The transverse [escape velocity](escape-velocity.md) threshold is $|qB_0|/m$; motion parallel to the [magnetic field](magnetic-field.md) cannot provide transverse escape energy.
