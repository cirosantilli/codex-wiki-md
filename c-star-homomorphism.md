# C-star homomorphism

↑ **Parent:** [C-star algebra](c-star-algebra.md)

A C-star homomorphism is a complex linear multiplicative map between [C-star algebras](c-star-algebra.md) that preserves the involution. Such maps are contractive; an injective one is an [isometry](isometry.md).
