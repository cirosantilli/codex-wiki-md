# Forward telescoping

↑ **Parent:** [Autobiographical memory](autobiographical-memory.md)

Dating a past event as more recent than its actual date. In prospective childhood-memory work, the same reported event can acquire progressively later age estimates. Shifts relative to the first interview establish dating instability, not the absolute accuracy of that first estimate.[Frontiers in Psychology 6, 2038; initial, two-year and eight-year memory dating interviews](the-fate-of-childhood-memories-by-qi-wang-and-carole-peterson.md)
