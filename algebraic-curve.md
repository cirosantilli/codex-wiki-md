# Algebraic curve

↑ **Parent:** [Algebraic variety](algebraic-variety.md)

An algebraic curve is a one-dimensional [algebraic variety](algebraic-variety.md). On a [smooth algebraic curve](smooth-algebraic-curve.md), the local ring at every closed point is a [discrete valuation ring](discrete-valuation-ring.md), which allows orders of zeros and poles to be recorded as a [divisor on an algebraic curve](divisor-on-an-algebraic-curve.md).
