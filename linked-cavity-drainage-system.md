# Linked cavity drainage system

↑ **Parent:** [Subglacial drainage](subglacial-drainage.md)

Sliding opens [water](water.md)-filled cavities behind bed obstacles and [ice](ice.md) creep closes them; narrow connections allow drainage between cavities. In a decreasing effective-[pressure](pressure-split.md)/discharge relation, a route carrying extra flux needs higher [water pressure](fluid-pressure.md). That [pressure](pressure-split.md) diverts [water](water.md) to neighboring routes, favoring a distributed network instead of [concentration](concentration.md) into one channel.
