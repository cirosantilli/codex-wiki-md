# Initial displacement

↑ **Parent:** [Initial condition](initial-condition.md)

Initial displacement specifies the configuration of a [wave equation](wave-equation-split.md) at the starting time. For a second-order evolution equation it is paired with the [initial velocity](initial-velocity.md). Specifying only the boundary forcing does not determine these initial data.
