# Generating function for Laguerre polynomials

↑ **Parent:** [Laguerre polynomial](laguerre-polynomial.md)

The [generating function](generating-function.md) holds for $|h|<1$ and fixed $x$. From [Rodrigues' formula](rodrigues-formula.md), $L_n(x)=\sum_{j=0}^n\binom nj(-x)^j/j!$. Sum first over $n\geq j$, using $\sum_{n\geq j}\binom njh^n=h^j/(1-h)^{j+1}$, and then over $j$ to obtain the [exponential function](exponential-function.md). The absolute-value double series is finite for $|h|<1$, justifying the rearrangement. Alternatively, the weighted [inner product](inner-product-split.md) and the [Laplace transform of a Laguerre polynomial](laplace-transform-of-a-laguerre-polynomial.md) extract the coefficient $h^n$.
