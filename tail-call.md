# Tail call

↑ **Parent:** [Programming language](programming-language-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tail_call)

A call whose result is returned directly, with no further computation waiting in its caller. Its caller's activation record can therefore be replaced rather than retained. A recursive tail call gives [tail recursion](tail-recursion.md); an explicit loop updating the current arguments performs the same control transfer without requiring compiler optimization.
