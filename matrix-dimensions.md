# Matrix dimensions

↑ **Parent:** [Matrix](matrix.md)

The matrix dimensions $r\times c$ specify the number of rows and columns of a [matrix](matrix.md). For [matrix multiplication](matrix-multiplication.md), an $r\times s$ [matrix](matrix.md) can multiply an $s\times t$ [matrix](matrix.md), yielding an $r\times t$ [matrix product](matrix-product.md).
