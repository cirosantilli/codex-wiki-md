# Naive height on the projective line

↑ **Parent:** [Elliptic curve](elliptic-curve.md)

For coprime integers $x,y$, the multiplicative height of $[x:y]\in\mathbb P^1(\mathbb Q)$ is $H([x:y])=\max\{|x|,|y|\}$; its logarithmic height is $h=\log H$.
