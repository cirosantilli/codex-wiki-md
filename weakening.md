# Weakening

↑ **Parent:** [Natural deduction](natural-deduction.md)

Adding unused assumptions to the context of a [logical derivation](logical-derivation.md). The original derivation still proves the same conclusion because it need not use every available assumption. When [eigenvariables](eigenvariable.md) are used, rename them first if necessary to preserve the [eigenvariable condition](eigenvariable-condition.md) for any newly added assumptions. This explains how [disjunction elimination](disjunction-elimination-rule.md) with different branch contexts can be written using a common context containing all their assumptions.
