# Parallel covector field

↑ **Parent:** [Affine connection](affine-connection.md)

A one-form $k$ with $\nabla_bk_a=0$. If $\ell=d\phi$ satisfies $\nabla_b\ell_a+\ell_a\ell_b=0$, then $k=e^\phi\ell=d(e^\phi)$ is parallel.
