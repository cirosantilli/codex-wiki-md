# Selective decay bound for magnetic helicity

↑ **Parent:** [Resistive magnetic-helicity balance](resistive-magnetic-helicity-balance.md)

With the closed-boundary assumptions of the [resistive magnetic-helicity balance](resistive-magnetic-helicity-balance.md), define the nonnegative resistive [magnetic energy](magnetic-energy.md) loss $D_B=\eta_m\int_V|\nabla\times\mathbf B|^2\,dV/\mu_0$. The [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) gives the displayed bound. Consequently, in a family of fields with bounded $E_B,D_B$ as $\eta_m\to0$, resistive [magnetic helicity](magnetic-helicity.md) loss tends to zero even when $D_B$ remains finite. This is an absolute conservation estimate; it is not a universal comparison of fractional decay times. For a single [Beltrami field](beltrami-field.md) with $\nabla\times\mathbf B=k\mathbf B$ and no motion, both $E_B$ and $H$ have the same fractional decay rate $2\eta_mk^2$.
