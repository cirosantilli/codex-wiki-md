# Finite sums theorem

↑ **Parent:** [Monochromatic m-p-c set theorem](monochromatic-m-p-c-set-theorem.md)

For every dimension $m$, every [finite coloring](finite-coloring.md) of the [positive integers](positive-integer.md) contains $x_1,\ldots,x_m$ for which all nonempty sums of distinct $x_i$ have one color. This is the case $p=c=1$ of the [monochromatic m-p-c set theorem](monochromatic-m-p-c-set-theorem.md).
