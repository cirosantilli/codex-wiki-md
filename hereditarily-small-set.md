# Hereditarily small set

↑ **Parent:** [Transitive closure](transitive-closure.md)

For an infinite [cardinal number](cardinal-number.md) $\kappa$, $H_\kappa$ consists of the sets $x$ for which $|\operatorname{tc}(\{x\})|<\kappa$, where $\operatorname{tc}$ is [transitive closure](transitive-closure.md). The entire transitive membership ancestry is bounded, not only the size of $x$. These collections are [transitive sets](transitive-set.md). At $\kappa=\omega_1$ the elements are the [hereditarily countable sets](hereditarily-countable-set.md).
