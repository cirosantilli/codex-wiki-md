# Seismic source time function

↑ **Parent:** [Finite-source rupture](finite-source-rupture.md)

The time history of a specified earthquake source quantity, commonly moment rate. It differs from recorded ground [velocity](velocity.md), which also contains radiation, propagation, instrument response and [rupture directivity](rupture-directivity.md). A measured pulse width requires those assumptions before it is called a rupture duration.
