# Extended binary Golay code

↑ **Parent:** [Binary Golay code](binary-golay-code.md)

The extended binary Golay code is the [parity extension](parity-extension.md) of the length-$23$ [binary Golay code](binary-golay-code.md). It is a [self-dual code](self-dual-code.md) and a [doubly even code](doubly-even-code.md), with [minimum Hamming distance](minimum-distance-of-a-code.md) eight. Its radius-three [Hamming balls](hamming-ball.md) are disjoint but do not cover its [Hamming space](hamming-space.md); it is not a [perfect code](perfect-code.md).
