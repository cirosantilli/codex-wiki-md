# Prime quadruplet

↑ **Parent:** [Prime number](prime-number-split.md)

A prime quadruplet is a set of four [primes](prime-number-split.md) $p,p+2,p+6,p+8$. For example, $5,7,11,13$ form a prime quadruplet. Testing candidates uses [integer congruences](integer-congruence.md) to discard starting values for which one of the four entries has a small [prime factor](prime-factor.md).
