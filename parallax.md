# Parallax

↑ **Parent:** [Astrometry](astrometry.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Parallax)

Parallax is the apparent change in the direction of an object when the observing position changes. [Stellar parallax](stellar-parallax.md) uses Earth's orbital baseline and measures half the annual angular excursion; its standard distance relation is the one displayed. A nearer object has a larger parallax for the same baseline.
