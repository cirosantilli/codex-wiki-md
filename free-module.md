# Free module

↑ **Parent:** [Module theory](module-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Free_module)

A free module is a [module](module-mathematics.md) with a [basis of a module](basis-of-a-module.md) $(e_i)_{i\in I}$: every element has exactly one expression $m=\sum_{i\in I}r_ie_i$ with $r_i\in R$ and only finitely many $r_i$ nonzero. Equivalently, the coefficient map $\bigoplus_{i\in I}R\to M$ is a [module isomorphism](module-isomorphism.md). Existence means generation; uniqueness means [linear independence in a module](linear-independence-in-a-module.md). For finite $I$ of size $n$, this says $M\cong R^n$, a [finite free module](finite-free-module.md). See [Neil Strickland's Rings, Modules and Linear Algebra, section 11](https://neilstrickland.github.io/modules/notes/modules.pdf).

The [integer lattice](integer-lattice.md) $\mathbb Z^2$ in the opening diagram is a [free module](free-module.md) over $\mathbb Z$ with [basis of a module](basis-of-a-module.md) $e_1=(1,0)$, $e_2=(0,1)$. For example, $(3,2)=3e_1+2e_2$, and comparing the two coordinates makes the coefficients unique. A different [basis of a module](basis-of-a-module.md) is $u=(1,0)$, $v=(1,1)$, because $(a,b)=(a-b)u+bv$; in particular $(3,2)=u+2v$.

By contrast, $w_1=(2,0)$ and $w_2=(0,1)$ are [linearly independent in a module](linear-independence-in-a-module.md), but generate only the [submodule](submodule.md) $2\mathbb Z\times\mathbb Z$. They miss $(1,0)$ because $2a=1$ has no [integer](integer-split.md) solution. They would form a [basis](basis.md) over the [rational numbers](rational-number.md). Even generation need not let one extract a [basis of a module](basis-of-a-module.md): the elements $2,3$ generate $\mathbb Z$, since $1=3-2$, but neither singleton generates it, and $3\cdot2-2\cdot3=0$ is a nontrivial [linear relation](linear-relation.md) between them. These are concrete failures of the usual [vector space](vector-space-split.md) argument that divides by any nonzero coefficient.

The [cyclic module](cyclic-module.md) $\mathbb Z/6\mathbb Z$ has no [basis of a module](basis-of-a-module.md) over $\mathbb Z$: every element has the nontrivial relation $6m=0$, so no nonempty subset is [linearly independent in a module](linear-independence-in-a-module.md), while the empty subset cannot generate this nonzero [module](module-mathematics.md). Specifying the scalar [ring](ring.md) is essential: over $R=\mathbb Z/6\mathbb Z$, the same additive object is a [free module](free-module.md) with the one-element [basis of a module](basis-of-a-module.md) $\{\overline1\}$, since each coefficient is itself a unique class in $R$.
