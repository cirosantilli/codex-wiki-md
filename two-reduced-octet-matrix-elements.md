# Two reduced octet matrix elements

↑ **Parent:** [Reduced matrix element](reduced-matrix-element.md)

An octet operator between [baryon octet](baryon-octet.md) states has two [reduced matrix elements](reduced-matrix-element.md), because the [tensor square of the SU(3) adjoint representation](tensor-square-of-the-su-3-adjoint-representation.md) contains two octets. The symmetric invariant $d_{ris}$ and antisymmetric invariant $f_{ris}$ give independent component tensors. Equivalently, represent baryons by traceless matrices $B$ and let the operator act as $F[t_i,B]+D(\{t_i,B\}-\tfrac23\operatorname{tr}(t_iB)I)$. Normalization choices are absorbed into $F,D$; Hermitian operators permit real coefficients in a Hermitian octet basis.
