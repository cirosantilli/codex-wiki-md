# Shifted set family

↑ **Parent:** [Elementary set shift](elementary-set-shift.md)

A [set family](set-family.md) is shifted if every [elementary set shift](elementary-set-shift.md) leaves it unchanged. For a [uniform set family](uniform-set-family.md), this is equivalent to downward closure under componentwise comparison of the increasing lists of its elements. Repeated [elementary set shifts](elementary-set-shift.md) terminate at a [shifted set family](shifted-set-family.md).
