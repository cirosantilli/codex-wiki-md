# Packet switching

↑ **Parent:** [Computer network](computer-network-split.md)

[Packet switching](packet-switching.md) carries separately represented units of data over shared communication links. Different [packets](network-packet.md) can share forwarding resources; the network service need not reserve one dedicated circuit for an entire application exchange.
