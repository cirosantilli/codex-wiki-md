# Rough path metric

↑ **Parent:** [Rough path](rough-path.md)

This inhomogeneous variation metric compares the tensor increments level by level. A common alternative is the Hölder metric $\rho_\alpha=\max_k\sup_{s<t}|X^{(k)}_{s,t}-Y^{(k)}_{s,t}|/|t-s|^{k\alpha}$. On a finite interval convergence in this metric implies $p$-variation convergence whenever $p\alpha\ge1$. Both topologies control the iterated integrals needed by the [universal limit theorem](universal-limit-theorem.md).
