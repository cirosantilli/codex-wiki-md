# Likelihood-ratio confidence interval

↑ **Parent:** [Confidence interval](confidence-interval.md)

Invert a [likelihood-ratio test](likelihood-ratio-test.md) for a scalar parameter, maximizing over nuisance parameters for each fixed candidate value. Under regularity, a level $1-\alpha$ interval includes values whose profile [log-likelihood](log-likelihood.md) is at most $\chi^2_{1,1-\alpha}/2$ below its maximum. This explains the horizontal cutoff on a [Box–Cox transformation](box-cox-transformation.md) likelihood plot.
