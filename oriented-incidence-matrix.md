# Oriented incidence matrix

↑ **Parent:** [Graph](graph-split.md)

An oriented incidence matrix records an arbitrarily chosen orientation of each [edge](edge-of-a-graph.md) of a [graph](graph-split.md). Use one row per [edge](edge-of-a-graph.md), with $+1$ and $-1$ at its endpoints and zeros elsewhere; the transpose convention is also common. The product $D\theta$ records endpoint differences. For a [connected graph](connected-graph.md), $\ker D=\operatorname{span}\{\mathbf1\}$, since zero difference propagates along every [graph path](path-in-a-graph.md).
