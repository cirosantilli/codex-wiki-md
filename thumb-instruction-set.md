# Thumb instruction set

↑ **Parent:** [ARM architecture family](arm-architecture-family.md)

A compact instruction encoding for the [ARM architecture family](arm-architecture-family.md), with sixteen-bit encodings and, in later versions, additional thirty-two-bit encodings. Operand restrictions depend on the selected architecture. The original sixteen-bit signed halfword load uses a register offset, whereas an ordinary halfword load also offers an immediate offset.[Load entries: halfword immediate/register and signed halfword register](thumb-16-bit-instruction-set-quick-reference-by-arm.md)
