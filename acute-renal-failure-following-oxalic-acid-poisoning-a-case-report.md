# Acute Renal Failure Following Oxalic Acid Poisoning: A Case Report

↑ **Parent:** [Pharmacology and toxicology bibliography](pharmacology-and-toxicology-bibliography-split.md)

[https://pmc.ncbi.nlm.nih.gov/articles/PMC3527234/](https://pmc.ncbi.nlm.nih.gov/articles/PMC3527234/)

Original case report; renal biopsy showed tubular injury with refractile [calcium oxalate](calcium-oxalate.md) crystals. The case does not establish that every exposure produces [hypocalcaemia](hypocalcaemia.md). Indexed full text was available; direct retrieval intermittently displayed a browser-verification page.
