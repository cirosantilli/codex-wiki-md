<h1 id="2/a/solution">Solution</h1>

↑ **Parent:** [A](../a.md)

A [bounded formula in set theory](../../../../bounded-formula-in-set-theory.md), or $\Sigma_0$ formula in the [Lévy hierarchy](../../../../levy-hierarchy.md), uses only [bounded quantifiers](../../../../bounded-quantifier.md) $\exists u\in v$ and $\forall u\in v$, with the usual Boolean connectives. A [Sigma-one formula in set theory](../../../../sigma-one-formula-in-set-theory.md) has the form

$$
\exists u_1\cdots\exists u_m\,\theta(\mathbf u,\mathbf x),
$$

where $\theta$ is a [bounded formula in set theory](../../../../bounded-formula-in-set-theory.md); harmless logically equivalent rearrangements are allowed. A [Pi-one formula in set theory](../../../../pi-one-formula-in-set-theory.md) is defined with a universal unbounded block instead.

A [Delta-one formula modulo ZF](../../../../delta-one-formula-modulo-zf.md) is a [first-order formula](../../../../first-order-formula.md) $\varphi(\mathbf x)$ for which there are such $\Sigma_1$ and $\Pi_1$ formulas $\sigma,\pi$ with

$$
\boxed{\mathrm{ZF}\vdash\forall\mathbf x\,(\varphi\leftrightarrow\sigma),\qquad\mathrm{ZF}\vdash\forall\mathbf x\,(\varphi\leftrightarrow\pi).}
$$

Equivalently, both $\varphi$ and $\neg\varphi$ have [Sigma-one formulas in set theory](../../../../sigma-one-formula-in-set-theory.md) provably equivalent to them in [ZF](../../../../zermelo-fraenkel-set-theory.md). These are levels of the [Lévy hierarchy](../../../../levy-hierarchy.md), with bounds by sets.
