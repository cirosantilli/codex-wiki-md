# Radio telescope

↑ **Parent:** [Radio astronomy](radio-astronomy.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Radio_telescope)

A radio telescope is an astronomical instrument that receives [radio waves](radio-wave.md) using an [antenna](antenna-radio.md) and associated receivers. A single dish measures radiation over its directional sensitivity pattern; separated elements can supply [complex visibilities](complex-visibility.md) for [aperture synthesis](aperture-synthesis.md).
