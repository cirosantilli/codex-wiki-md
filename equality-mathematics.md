# Equality (mathematics)

↑ **Parent:** [Binary relation](binary-relation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Equality_(mathematics))

Two expressions are equal when they denote the same mathematical object. An [equality test](equality-test.md) in a program implements a specified comparison of represented values; for example, approximate [floating-point arithmetic](floating-point-arithmetic-split.md) comparison is not identical to exact equality of [real numbers](real-number.md).
