# Branched covering

↑ **Parent:** [Covering space](covering-space.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Branched_covering)

A branched covering is a map that is a [covering space](covering-space.md) away from a branch set and has a specified local covering model at that set. For a smooth two-fold covering branched over a codimension-two submanifold, the local model is $(z,u)\mapsto(z^2,u)$. A [two-fold branched cover of a knot](two-fold-branched-cover-of-a-knot.md) is the basic three-dimensional example.
