# Lexicographic unranking

↑ **Parent:** [Combinatorics](combinatorics-split.md)

Lexicographic unranking constructs the object at a specified position in [lexicographic order](lexicographic-order.md). At each step it counts valid completions for each possible next symbol, skips blocks preceding the desired rank, and continues within the selected block.
