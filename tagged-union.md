# Tagged union

↑ **Parent:** [Algebraic data type](algebraic-data-type.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tagged_union)

A [data type](data-type.md) whose values belong to one of several alternatives, with a logical tag distinguishing the chosen alternative. If `Number n` and `Operator op` are its constructors, [pattern matching](pattern-matching.md) can distinguish the variants even if their payloads use similar representations. The tag need not occupy a separate physical memory field in every implementation.
