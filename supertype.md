# Supertype

↑ **Parent:** [Subtyping](subtyping.md)

A type $S$ is a supertype of $T$ when $T$ is a [subtype](subtyping.md) of $S$. A [lower type bound](lower-type-bound.md) requires an admissible [type argument](type-argument.md) to lie above a specified type in this [subtyping](subtyping.md) relation.
