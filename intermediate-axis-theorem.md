# Intermediate axis theorem

↑ **Parent:** [Euler equations for a torque-free rigid body](euler-equations-for-a-torque-free-rigid-body.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Intermediate_axis_theorem)

For $I_1<I_2<I_3$, steady torque-free rotation about the first or third principal axis is stable, while rotation about the intermediate principal axis is unstable.
