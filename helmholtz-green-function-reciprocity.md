# Helmholtz Green-function reciprocity

↑ **Parent:** [Helmholtz equation](helmholtz-equation.md)

Two [Green functions](green-s-function.md) of the same [Helmholtz equation](helmholtz-equation.md) with the same homogeneous [Robin boundary condition](robin-boundary-condition.md) satisfy the displayed reciprocity by [Green's second identity](green-second-identity.md). It is a bilinear identity without complex conjugation, so it concerns the transpose rather than the Hermitian adjoint. In an exterior problem both kernels use the same radiation convention.
