# Uniform-cost search

↑ **Parent:** [Best-first search](best-first-search.md)

[Best-first search](best-first-search.md) prioritizing accumulated [path cost](path-cost.md), equivalently [A-star search](a-star-search.md) with zero [heuristic function](heuristic-function.md). With finite [branching factor](branching-factor.md) and positive lower-bounded step costs, [tree search](tree-search.md) is complete for finite solutions and returns a least-cost goal if the [goal test](goal-test.md) is applied on removal from the [search frontier](search-frontier.md). Goal testing at generation can instead return an expensive [edge](edge-of-a-graph.md) before a cheaper multi-[edge](edge-of-a-graph.md) route is explored.
