# Diffeomorphism identity for a metric action

↑ **Parent:** [Noether identity](noether-identity.md)

For a diffeomorphism-invariant pure metric action, write $\delta S=-\int\sqrt{-g}E^{ab}\delta g_{ab}$. Substitute $\delta g_{ab}=\nabla_a\xi_b+\nabla_b\xi_a$ for an arbitrary compactly supported [vector field](vector-field.md) and integrate by parts. Symmetry of $E^{ab}$ gives $\nabla_aE^{ab}=0$ without using field equations. This [Noether identity](noether-identity.md) concerns the gravitational variational tensor alone.
