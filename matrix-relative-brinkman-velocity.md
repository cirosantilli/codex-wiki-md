# Matrix-relative Brinkman velocity

↑ **Parent:** [Brinkman equation](brinkman-equation.md)

Porous-matrix drag depends on fluid [velocity](velocity.md) relative to the matrix, so it is not invariant under adding a uniform fluid [velocity](velocity.md) while leaving the matrix fixed. In a swimmer frame with stationary laboratory matrix, the drag is proportional to $\mathbf u-U\mathbf e_x$. A constant shift can alternatively be absorbed into a linear [pressure](pressure.md) term, whose physical interpretation must then be retained.
