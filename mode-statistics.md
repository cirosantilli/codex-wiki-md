# Mode (statistics)

↑ **Parent:** [Descriptive statistics](descriptive-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Mode_(statistics))

A mode is a value at which a [probability mass function](probability-mass-function.md) or specified [probability density function](probability-density-function.md) attains its largest value. There may be more than one. For the [normal distribution](normal-distribution.md) the unique mode equals the [mean](expected-value-split.md); the [Maxwell speed distribution](maxwell-speed-distribution.md) has mode $\sqrt{2k_BT/m}$ and a larger [mean](expected-value-split.md) speed. For a [continuous probability distribution](continuous-probability-distribution-split.md), a mode maximizes density rather than the [probability](probability.md) of an exact value, which is zero. Density modes can change under a nonlinear [change of variables](change-of-variables-formula.md), as the distinction between [Maxwell-Boltzmann velocity distribution](maxwell-boltzmann-velocity-distribution.md) and [Maxwell speed distribution](maxwell-speed-distribution.md) illustrates.
