# Absolute value in a lattice-ordered group

↑ **Parent:** [Lattice-ordered group](lattice-ordered-group.md)

The displayed [join](least-upper-bound-in-a-partially-ordered-set.md) is nonnegative in a [lattice-ordered group](lattice-ordered-group.md). In an additive [Abelian group](abelian-group.md) it becomes $|g|=g\vee(-g)$. This order-theoretic absolute value need not be a real scalar.
