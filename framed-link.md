# Framed link

↑ **Parent:** [Link](link.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Framed_link)

A framed link is a link together with a homotopy class of nonzero normal vector field on every component. Relative to the [Seifert framing](seifert-framing.md), each component framing is encoded by an integer.
