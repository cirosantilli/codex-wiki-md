# Tic-tac-toe

↑ **Parent:** [Game](game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tic-tac-toe)

A two-player [game](game.md) on nine positions arranged in a three-by-three grid. Players alternate marking empty positions and stop when one has a full row, column or diagonal, or when the board is full. A game search must stop at the first win. Distinct move histories can reach the same position; canonical occupancy [sets](set-split.md) or [bitboards](bitboard.md) make that equality available to [memoization](memoization.md). Quotienting by board symmetry changes the requested output unless distinct oriented positions are subsequently restored.
