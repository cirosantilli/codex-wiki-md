# Episodic-like memory

↑ **Parent:** [Memory in animals](memory-in-animals.md)

Retention of behaviorally testable features of an event, often including integrated content, place and temporal information, without claiming to have established conscious reliving. The label separates evidence about a task from evidence about [autonoetic consciousness](autonoetic-consciousness.md).
