# Long-path projection of a magnetic correlation

↑ **Parent:** [Rotation measure](rotation-measure.md)

For constant [Electron](electron.md) density, common path length $L$, and a [solenoidal isotropic spectral tensor](solenoidal-isotropic-spectral-tensor.md), the rotation-measure [correlation](pearson-correlation-coefficient.md) contains the window $|\int_0^Le^{ik_zz}dz|^2$. As $L$ becomes large compared with the [correlation length](correlation-length.md), this window acts as $2\pi L\delta(k_z)$ within the [integral](integral.md). The transverse projector then has $zz$ component one, yielding the displayed two-dimensional [Fourier transform](fourier-transform.md). For finite $L$, the windowed integral retains longitudinal modes and endpoint corrections. The method of using such [rotation measure](rotation-measure.md) correlations to infer magnetic spectra is developed by [Enßlin and Vogt](https://arxiv.org/abs/astro-ph/0302426).
