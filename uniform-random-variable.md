# Uniform random variable

↑ **Parent:** [Continuous uniform distribution](continuous-uniform-distribution.md)

A uniform random variable has a [uniform distribution](continuous-uniform-distribution.md). Independent such variables can supply independent [inverse transform sampling](inverse-transform-sampling.md); reusing a single variable for two transforms generally creates dependence.
