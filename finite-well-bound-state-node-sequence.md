# Finite-well bound-state node sequence

↑ **Parent:** [Finite square well](finite-square-well.md)

For a symmetric one-dimensional [finite square well](finite-square-well.md), nondegenerate [bound states](bound-state.md) alternate even and odd [parity](parity.md), starting with an even [ground state](ground-state.md). The $n$th state counted from zero has $n$ interior [nodes](node-dynamical-systems.md). Outside the well, it decays with inverse [length](length.md) $\sqrt{2m(U-E_n)}/\hbar$. Matching both the [wavefunction](wave-function-split.md) and its first [derivative](derivative.md) at a finite step distinguishes it from the infinite-well approximation.
