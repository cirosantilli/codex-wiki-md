# Return period

↑ **Parent:** [Extreme value theory](extreme-value-theory.md)

For independent repeated time blocks, an event with exceedance probability $p$ has mean waiting time $1/p$ blocks by the [geometric distribution](geometric-distribution.md). The return period is a long-run average waiting time, not a deterministic recurrence interval. For annual exceedance events, it is measured in years.
