# Thermal boundary layer

↑ **Parent:** [Boundary layer](boundary-layer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Thermal_boundary_layer)

A thermal boundary layer is a thin region in which [temperature](temperature.md) changes rapidly and [thermal conduction](thermal-conduction.md) remains important. Its thickness can be estimated by balancing thermal diffusion against advection or by requiring a local [Rayleigh number](rayleigh-number.md) to be near its critical value.
