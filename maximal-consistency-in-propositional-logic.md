# Maximal consistency in propositional logic

↑ **Parent:** [Maximal consistent set in propositional logic](maximal-consistent-set-in-propositional-logic.md)

A [propositionally consistent](propositional-consistency.md) theory is maximally consistent when every proper extension by a new [propositional formula](propositional-formula.md) is inconsistent. It decides each [propositional formula](propositional-formula.md) or its [negation](negation.md).
