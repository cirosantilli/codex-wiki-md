# Uncountable set

↑ **Parent:** [Cardinal number](cardinal-number.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Uncountable_set)

An uncountable set is a set for which no [bijection](bijection.md) with a subset of the natural numbers exists.
