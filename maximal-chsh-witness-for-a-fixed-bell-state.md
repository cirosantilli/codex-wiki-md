# Maximal CHSH witness for a fixed Bell state

↑ **Parent:** [CHSH inequality](chsh-inequality.md)

The [Hermitian operator](hermitian-operator.md) $\mathcal B=\sqrt2(X\otimes X-Z\otimes Z)$ has [eigenvalues](eigenvalue.md) $2\sqrt2,0,0,-2\sqrt2$ on $\Psi^+,\Phi^+,\Psi^-,\Phi^-$, respectively. Thus any [density matrix](density-matrix-split.md) satisfying $\operatorname{Tr}(\rho\mathcal B)=2\sqrt2$ must be $|\Psi^+\rangle\langle\Psi^+|$: an average can equal the largest eigenvalue only when all weight lies in its one-dimensional [eigenspace](eigenspace.md). The [purity decouples a subsystem from its purification](purity-decouples-a-subsystem-from-its-purification.md) lemma then excludes correlations with an external environment. This argument assumes the stated measurement operators; [CHSH self-testing](chsh-self-testing.md) handles unknown representations with additional qualifications.
