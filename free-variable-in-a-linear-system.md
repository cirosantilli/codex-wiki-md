# Free variable in a linear system

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

A [free variable in a linear system](free-variable-in-a-linear-system.md) is an unknown whose coefficient column is not a [pivot column](pivot-column.md) in [row echelon form](row-echelon-form.md). When the [linear system](system-of-linear-equations.md) is consistent, it can be assigned any value in the [field](field.md); the pivot unknowns are then determined by those choices. This use of “free” differs from a [free variable](free-variable.md) in [mathematical logic](mathematical-logic-split.md).
