# Product-input classical-capacity converse

↑ **Parent:** [Holevo capacity](holevo-capacity.md)

For a code with [product state](product-state.md) inputs to $n$ uses of a memoryless [quantum channel](quantum-channel.md), [Subadditivity of Von Neumann entropy](subadditivity-of-von-neumann-entropy.md) bounds its output [Holevo quantity](holevo-quantity.md) by $n\chi^*(\Lambda)$. The [Holevo bound](holevo-s-theorem.md) and [Fano's inequality](fano-s-inequality.md) then give, for asymptotic rate $R$, average and hence maximum error at least $1-\chi^*(\Lambda)/R$ in the limit inferior. In particular, no code above that rate can have vanishing maximum error, even with a collective decoder measurement.
