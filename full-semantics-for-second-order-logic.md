# Full semantics for second-order logic

↑ **Parent:** [Second-order logic](second-order-logic.md)

Every [subset](subset.md) or relation of the appropriate arity on the object domain is allowed as a value of a second-order variable. For a domain $V_\lambda$, an external functional graph with all its individual [ordered pairs](ordered-pair.md) in $V_\lambda$ is therefore available, even if the whole graph does not belong to $V_\lambda$.
