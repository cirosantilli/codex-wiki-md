# Superharmonic function

↑ **Parent:** [Subharmonic function](subharmonic-function.md)

A locally integrable real function is superharmonic in the distributional sense if its [Laplacian](laplacian.md) is nonpositive on every nonnegative [test function](test-function.md). Equivalently its negative is a [subharmonic function](subharmonic-function.md). The canonical lower semicontinuous representative satisfies the reverse ball mean inequality. A function both subharmonic and superharmonic has zero distributional Laplacian and a smooth [harmonic function](harmonic-function.md) representative by the [Weyl lemma](weyl-lemma.md).
