# Lagrangian subspace

↑ **Parent:** [Symplectic geometry](symplectic-geometry-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lagrangian_subspace)

A Lagrangian subspace of a $2n$-dimensional [symplectic vector space](symplectic-vector-space.md) $(V,\omega)$ is an $n$-dimensional subspace $L$ on which $\omega$ vanishes.
