# Locally maximally symmetric space

↑ **Parent:** [Sectional curvature](sectional-curvature.md)

An $n$-dimensional [Riemannian manifold](riemannian-manifold.md) is locally maximally symmetric if its local [Killing vector fields](killing-vector-field-split.md) attain the [dimension bound for Killing vector fields](dimension-bound-for-killing-vector-fields.md) $n(n+1)/2$. This is equivalent to constant [sectional curvature](sectional-curvature.md). Positive, zero and negative [sectional curvature](sectional-curvature.md) give local [spherical geometry](spherical-geometry.md), [Euclidean geometry](euclidean-geometry-split.md) and [hyperbolic geometry](hyperbolic-geometry-split.md), respectively. Global identifications can reduce the number of globally defined [isometries](isometry.md) without changing this local property. The spatial slices of an [FLRW metric](friedmann-lemaitre-robertson-walker-metric.md) have this property.
