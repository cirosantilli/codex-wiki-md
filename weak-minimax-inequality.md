# Weak minimax inequality

↑ **Parent:** [Iterated extrema of an array](iterated-extrema-of-an-array.md)

For a nonempty bounded array of [real numbers](real-number.md), each column [infimum](infimum.md) is at most every row [supremum](supremum.md), because $\inf_kx_{k,n}\leq x_{m,n}\leq\sup_jx_{m,j}$ for all $m,n$. Taking the [supremum](supremum.md) over columns and then the [infimum](infimum.md) over rows proves the displayed inequality. Equality need not hold: for $x_{m,n}=\mathbf1_{\{m=n\}}$ on positive integer indices, every column [infimum](infimum.md) is zero and every row [supremum](supremum.md) is one. This elementary bound is the order-theoretic starting point for stronger [minimax theorems](minimax-theorem.md) with additional hypotheses.
