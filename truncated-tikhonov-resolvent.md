# Truncated Tikhonov resolvent

↑ **Parent:** [Tikhonov regularization](tikhonov-regularization.md)

For $B=AA^*\ge0$, the polynomial displayed here truncates the [Neumann series](neumann-series.md) for $(\alpha I+B)^{-1}$. It obeys $(\alpha I+B)R_{\alpha,2}=I+\alpha^{-3}B^3$, and is not an exact inverse. If $\|B\|/\alpha<1$, it is a controlled large-parameter expansion; its error is $\alpha^{-3}B^3(\alpha I+B)^{-1}$. At each fixed positive parameter the reconstruction $A^*R_{\alpha,2}$ is bounded. However this polynomial diverges on nonzero singular modes as $\alpha\to0$ and is not a substitute for the exact convergent Tikhonov filter in that limit.
