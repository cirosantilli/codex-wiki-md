# Minimum enclosing ball in hyperbolic space

↑ **Parent:** [Hyperbolic space](hyperbolic-space.md)

For a nonempty finite set $\{p_1,\ldots,p_m\}$ in finite-dimensional [hyperbolic space](hyperbolic-space.md), the continuous function $R(x)=\max_jd(x,p_j)$ attains its minimum. Indeed, a bounded candidate radius confines all possible improving centers to a closed bounded ball about $p_1$. Such a ball is compact in the [Poincare ball model](poincare-ball-model.md), since its points remain away from the ideal boundary. Minimizing $R$ on it supplies a [closed ball](closed-ball.md) of smallest enclosing radius. More generally this argument works for any nonempty bounded set in a [proper metric space](proper-metric-space.md) when the supremum-distance function is finite.
