# Pt100

↑ **Parent:** [Industrial platinum resistance thermometer](industrial-platinum-resistance-thermometer.md)

A [Pt100](pt100.md) has nominal [electrical resistance](electrical-resistance.md) $100\,\Omega$ at $0\,{}^\circ\mathrm C$.[Platinum Resistance Thermometers, opening explanation: conventional 100-ohm element at 0 °C](mercury-thermometer-alternatives-platinum-resistance-thermometers-prts-by-national-institute-of-standards-and-technology.md) Here $0\,{}^\circ\mathrm C$ is the reference for the nominal element designation; it is distinct from the $0.01\,{}^\circ\mathrm C$ water [triple point](triple-point.md) used in [SPRT](standard-platinum-resistance-thermometer.md) calibration. The following [Pt100 local linear model](pt100-local-linear-model.md) deliberately stipulates one approximate response for calculations.
