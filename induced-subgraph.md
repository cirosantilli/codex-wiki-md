# Induced subgraph

↑ **Parent:** [Subgraph](subgraph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Induced_subgraph)

The subgraph induced by a vertex set $W$ contains every edge of the original graph whose two endpoints lie in $W$.
