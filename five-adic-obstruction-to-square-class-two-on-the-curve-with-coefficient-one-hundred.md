# Five-adic obstruction to square class two on the curve with coefficient one hundred

↑ **Parent:** [Quartic covering in a two-isogeny descent](quartic-covering-in-a-two-isogeny-descent.md)

This quartic has no primitive integral solution. If $5\nmid U$, reduction modulo five makes $W^2\equiv2$, impossible. If $5\mid U$, coprimality gives $5\nmid V$ and $5\mid W$; dividing by twenty-five then gives $(W/5)^2\equiv2V^4\equiv2\pmod5$, again impossible. It excludes the square class two in [two-isogeny descent](two-isogeny-descent.md) on $Y^2=X^3+100X$. The point $(5,25)$ supplies class five, so the subgroup property excludes class ten as well.
