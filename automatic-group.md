# Automatic group

↑ **Parent:** [Geometric group theory](geometric-group-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Automatic_group)

An [automatic group](automatic-group.md) admits an [automatic structure for a group](automatic-structure-for-a-group.md): a [regular language](regular-language.md) of representatives and synchronous [group multiplier automata](group-multiplier-automaton.md) recognizing right multiplication by each generator and equality of representatives. Representatives need not be unique. This finite-state description yields effective algorithms for the [word problem for a group](word-problem-for-groups.md).
