# Pi donation

↑ **Parent:** [Coordinate covalent bond](coordinate-covalent-bond.md)

Donation from an occupied ligand orbital into a [metal](metal.md) orbital of pi symmetry relative to the [metal](metal.md)–ligand axis. It differs from metal-to-ligand [pi backbonding](pi-backbonding.md).
