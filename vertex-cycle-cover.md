# Vertex cycle cover

↑ **Parent:** [Graph theory](graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Vertex_cycle_cover)

A [vertex cycle cover](vertex-cycle-cover.md) is a collection of cycles whose union contains every vertex of a [graph](graph-split.md); its cycles can overlap. A [cycle cover of a directed graph](cycle-cover-of-a-directed-graph.md) additionally requires directed, vertex-disjoint cycles, and a [spanning circuit family](spanning-circuit-family.md) can allow overlaps.
