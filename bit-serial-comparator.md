# Bit-serial comparator

↑ **Parent:** [Digital comparator](digital-comparator.md)

A [digital comparator](digital-comparator.md) processes one pair of [bits](bit.md) per [clock cycle](clock-cycle.md), storing a comparison result in a [finite-state machine](finite-state-machine.md). For least-significant-first unsigned input, a new unequal pair overrides the stored result, while equal [bits](bit.md) preserve it: the newest unequal pair has the greatest place value seen so far.
