# Base change action on quiver representations

↑ **Parent:** [Quiver representation space](quiver-representation-space.md)

The group $\operatorname{GL}(\mathbf n)=\prod_i\operatorname{GL}_{n_i}(k)$ acts by $(g\cdot f)_\rho=g_{t(\rho)}f_\rho g_{s(\rho)}^{-1}$. Inverse entries are regular on a [general linear group](general-linear-group.md), so this is an [algebraic group action](algebraic-group-action.md). Its stabilizer is the [automorphism group of a quiver representation](automorphism-group-of-a-quiver-representation.md).
