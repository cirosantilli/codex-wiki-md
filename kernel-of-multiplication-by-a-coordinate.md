# Kernel of multiplication by a coordinate

↑ **Parent:** [Distribution annihilated by a function with simple zeros](distribution-annihilated-by-a-function-with-simple-zeros.md)

In one dimension, $xw=0$ if and only if $w=c\delta_0$. Choose a [cutoff function](cutoff-function.md) $\eta=1$ near zero and write every [test function](test-function.md) as $\varphi=\varphi(0)\eta+x\psi$. The pairing with $x\psi$ vanishes, leaving $\langle w,\varphi\rangle=\varphi(0)\langle w,\eta\rangle$.
