# Left-invariant group metric

↑ **Parent:** [Topological group](topological-group-split.md)

This is a distance function satisfying the displayed identity, rather than a [Riemannian metric](riemannian-metric.md) tensor. When it induces the group's given topology, it is a compatible left-invariant group metric. Left translations are isometries.
