# Neuronal firing threshold

↑ **Parent:** [Synaptic integration](synaptic-integration.md)

A [neuronal firing threshold](neuronal-firing-threshold.md) specifies the condition for initiating an [action potential](action-potential.md). The [leaky integrate-and-fire model](leaky-integrate-and-fire-model.md) uses a prescribed [membrane potential](membrane-potential.md) $\vartheta$; real initiation involves active [voltage-gated ion channels](voltage-gated-ion-channel.md) and depends on recent activity and recording site. A threshold drawn on a passive voltage trace is a comparison criterion, not a simulated [action potential](action-potential.md).
