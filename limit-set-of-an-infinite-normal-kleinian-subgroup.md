# Limit set of an infinite normal Kleinian subgroup

↑ **Parent:** [Minimality of the Kleinian limit set](minimality-of-the-kleinian-limit-set.md)

The [Kleinian limit set](limit-set-of-a-kleinian-group.md) of an infinite subgroup is nonempty. If it is normal, its limit set is invariant under the ambient group by base-point independence and conjugation. [Minimality of the Kleinian limit set](minimality-of-the-kleinian-limit-set.md) gives one inclusion, and subgroup containment gives the other. Neither properness nor finite generation of the subgroup is needed.
