# Homologous temperature

↑ **Parent:** [Creep (deformation)](creep-deformation.md)

The absolute [temperature](temperature-split.md) divided by an appropriate melting [temperature](temperature-split.md), $T/T_m$. It is a useful scale for comparing thermally activated deformation; Celsius [temperatures](temperature-split.md) cannot be used directly in the ratio.
