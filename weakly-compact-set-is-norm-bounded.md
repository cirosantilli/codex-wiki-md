# Weakly compact set is norm bounded

↑ **Parent:** [Weakly compact set](weakly-compact-set.md)

Every [weakly compact set](weakly-compact-set.md) in a [normed vector space](normed-vector-space.md) is norm bounded, even if the space is incomplete. Its [canonical embedding into the bidual](canonical-embedding-into-the-bidual.md) is pointwise bounded on the [continuous dual space](continuous-dual-space-split.md); the [Uniform boundedness principle](uniform-boundedness-principle.md) on that Banach dual gives the norm bound.
