# Log-uniform distribution

↑ **Parent:** [Continuous probability distribution](continuous-probability-distribution-split.md)

For $0<A<B<\infty$, this density makes $\log X$ uniform between $\log A$ and $\log B$. It is a proper finite-interval version of the [scale-invariant prior](scale-invariant-prior.md). The chosen logarithm base changes only the endpoint coordinates.
