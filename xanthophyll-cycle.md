# Xanthophyll cycle

↑ **Parent:** [Photosynthesis](photosynthesis.md)

The [xanthophyll cycle](xanthophyll-cycle.md) reversibly changes antenna-associated xanthophyll composition with light conditions. Lumen-acidification-dependent de-epoxidation towards zeaxanthin can support photoprotective quenching in plants.
