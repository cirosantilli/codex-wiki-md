# G-parity selection rule for pion multiplicities

↑ **Parent:** [G-parity of an isospin multiplet](g-parity-of-an-isospin-multiplet.md)

Each [pion](pion.md) has [G parity](g-parity.md) minus one, so an $n$-pion state has $G=(-1)^n$. In the isospin-symmetric [strong interaction](strong-interaction.md), a parent with positive G parity can decay only to an even pion multiplicity, and a negative parent only to an odd multiplicity. The rule does not forbid small isospin-breaking or electromagnetic amplitudes.
