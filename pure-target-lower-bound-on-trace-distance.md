# Pure-target lower bound on trace distance

↑ **Parent:** [Trace distance](trace-distance.md)

For a [density operator](density-matrix.md) $\rho$ and [pure state](pure-state.md) $P=|\psi\rangle\langle\psi|$, the [diagonal absolute-sum bound for the trace norm](diagonal-absolute-sum-bound-for-the-trace-norm.md) in a basis containing $|\psi\rangle$ gives $D(\rho,P)\geq1-\langle\psi|\rho|\psi\rangle=1-F(\rho,P)^2$. The [quantum fidelity](fidelity-of-quantum-states.md) is unsquared. Block-diagonal states with respect to the target and its complement attain equality.
