# Clifford gate

↑ **Parent:** [Pauli group](pauli-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Clifford_gate)

A Clifford gate is a unitary operation that normalizes the [Pauli group](pauli-group.md): conjugating any Pauli operator by it produces another Pauli operator. Hadamard, phase, and controlled-$Z$ gates generate the Clifford operations.
