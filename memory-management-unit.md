# Memory management unit

↑ **Parent:** [Virtual memory](virtual-memory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Memory_management_unit)

The hardware that performs [address translation](address-translation.md) and access checks. Whether a [TLB miss](tlb-miss.md) is resolved entirely by hardware or with [operating system](operating-system.md) assistance depends on the architecture.
