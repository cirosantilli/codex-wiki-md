# Witness constant

↑ **Parent:** [Henkin construction](henkin-construction.md)

A [witness constant](witness-constant.md) is a fresh [constant symbol](constant-symbol.md) added to a first-order language so that an existential assertion has a named witness. In a [Henkin construction](henkin-construction.md) one adds $\exists x\theta(x)\to\theta(c_\theta)$, with $c_\theta$ absent from the previous language. Freshness preserves [consistency](consistent-first-order-theory.md). Repeating the construction for the successively enlarged languages supplies the witness property used in a [term model](term-model.md).
