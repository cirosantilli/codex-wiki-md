# Conjugate-basis steering of a Bell pair

↑ **Parent:** [Quantum steering](quantum-steering.md)

For a [Bell pair](bell-pair.md) $|\phi_+\rangle=(|00\rangle+|11\rangle)/\sqrt2$, Alice's [basic measurement](basic-measurement.md) in the entrywise [complex conjugate](complex-conjugate.md) of any desired Bob [orthonormal basis](orthonormal-basis.md) prepares each Bob [pure state](pure-state.md) with [probability](probability.md) $1/2$. Indeed, if $|u\rangle=\sum_{j=0}^1u_j|j\rangle$, then $\langle\overline u|j\rangle=u_j$, which proves the displayed contraction identity. The undisclosed-outcome [density matrix](density-matrix-split.md) stays $I/2$; [quantum steering](quantum-steering.md) changes the conditional [quantum state ensemble](quantum-state-ensemble.md) without violating the [no-communication theorem](no-communication-theorem.md).
