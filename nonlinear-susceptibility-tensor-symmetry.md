# Nonlinear-susceptibility tensor symmetry

↑ **Parent:** [Nonlinear optical susceptibility](nonlinear-optical-susceptibility.md)

The order-$n$ response has one output vector index and $n$ input vector indices. Material point-group invariance, permutation of input index-frequency pairs, and reality of the [electric polarization](polarization-density.md) impose different constraints. They must not be conflated with the stronger dispersion-neglecting [Kleinman symmetry](kleinman-symmetry.md).
