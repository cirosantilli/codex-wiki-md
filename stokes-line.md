# Stokes line

↑ **Parent:** [Stokes phenomenon](stokes-phenomenon.md)

With the convention used here, a Stokes line is a ray where competing exponential actions have the same imaginary part. A subdominant exponential can acquire a rapidly changing multiplier there. For $e^{\pm x^2/\varepsilon}$, these rays have $\arg x=m\pi/2$. The [anti-Stokes lines](anti-stokes-line.md) instead have equal exponential magnitudes.
