# Program state

↑ **Parent:** [Programming language semantics](programming-language-semantics.md)

A description of the information needed to determine a program's next permitted step. In the [summation loop verification](summation-loop-verification.md), this includes the current [variable](variable-mathematics.md) values and the position in the instructions.
