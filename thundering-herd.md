# Thundering herd

↑ **Parent:** [Synchronization (computing)](synchronization-computing.md)

Many waiting [software threads](thread-computing.md) wake for a state change that can benefit only one or a few of them. Repeated [monitor](monitor-synchronization.md) reacquisition, failed predicate checks and [context switches](context-switch.md) add overhead; selective notification can reduce it.
