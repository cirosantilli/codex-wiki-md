# Use-after-free

↑ **Parent:** [Memory reclamation](memory-reclamation.md)

An access through a [pointer](pointer-computer-programming.md) after its storage has been released. Reusing the same [memory address](memory-address.md) for a different object can make this failure silently return unrelated data instead of immediately crashing.
