# Barkai-Leibler model

↑ **Parent:** [Chemotaxis feedback regulation](chemotaxis-feedback-regulation.md)

A conceptual [chemotaxis](chemotaxis.md) adaptation model in which saturated [CheR](cher.md) action supplies [receptor methylation](receptor-methylation.md) while [CheB](cheb.md) preferentially demethylates active [receptors](receptor-biochemistry.md). If $\dot M=r-bA/(K+A)$, the [steady state](steady-state.md) output is $A_*=Kr/(b-r)$, independent of ligand whenever a physically accessible stable [steady state](steady-state.md) exists. Changing [enzyme](enzyme-split.md) abundance can change this baseline without destroying adaptation to a subsequent ligand step.[Figure 1b and equation 1](robustness-in-simple-biochemical-networks-by-naama-barkai-and-stanislas-leibler.md)
