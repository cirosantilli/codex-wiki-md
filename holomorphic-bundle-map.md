# Holomorphic bundle map

↑ **Parent:** [Vector bundle morphism](vector-bundle-morphism.md)

A holomorphic bundle map is a [holomorphic map](holomorphic-map.md) between total spaces of [holomorphic vector bundles](holomorphic-vector-bundle.md) that covers a holomorphic base map and is complex-linear on each fibre. Over a fixed base, its matrix in [holomorphic local frames](holomorphic-local-trivialization.md) has holomorphic entries.
