# Fine ultrafilter

↑ **Parent:** [Ultrafilter](ultrafilter.md)

An [ultrafilter](ultrafilter.md) on $P_\kappa(\lambda)$ is fine when it contains the set of small subsets containing $\alpha$, for each $\alpha<\lambda$. Fineness makes every coordinate of $\lambda$ represented in the corresponding [ultrapower](ultrapower.md), though no one small subset is required to contain every coordinate.
