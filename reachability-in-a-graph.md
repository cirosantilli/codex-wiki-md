# Reachability in a graph

↑ **Parent:** [Graph](graph-split.md)

A vertex $v$ is reachable from $u$ if a finite path leads from $u$ to $v$, respecting edge directions in a directed [graph](graph-split.md). For a finite graph, [graph search](graph-search.md) decides [reachability](reachability-in-a-graph.md) by maintaining the [set](set-split.md) of discovered vertices; every step discovers a new vertex or examines an edge, so the procedure terminates.
