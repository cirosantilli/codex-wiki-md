# S wave

↑ **Parent:** [Elastic wave](elastic-wave.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/S_wave)

An S-wave is transverse, carries rotation without dilatation, and has speed $c_S=\sqrt{\mu/\rho}$.
