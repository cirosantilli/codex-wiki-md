# Cluster in cluster analysis

↑ **Parent:** [Cluster analysis](cluster-analysis.md)

A cluster in [cluster analysis](cluster-analysis.md) is a nonempty group of observations treated as similar under the chosen representation and dissimilarity. A partition assigns each observation to exactly one cluster; [agglomerative hierarchical clustering](agglomerative-hierarchical-clustering.md) supplies a nested sequence of such partitions. An algorithmic cluster need not correspond to a distinct probabilistic population.
