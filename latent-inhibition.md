# Latent inhibition

↑ **Parent:** [Classical conditioning](classical-conditioning.md)

Retarded conditioning to a previously nonreinforced cue relative to an appropriately matched novel cue. Changes in [attention](attention.md), retrieval and context can contribute, so it is not uniquely diagnostic of one mechanism.
