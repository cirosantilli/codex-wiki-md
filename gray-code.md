# Gray code

↑ **Parent:** [Hypercube graph](hypercube-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gray_code)

A Gray code orders binary strings so that successive strings differ in exactly one bit. Consequently it describes a path in a [hypercube graph](hypercube-graph.md); a cyclic Gray code describes a cycle.
