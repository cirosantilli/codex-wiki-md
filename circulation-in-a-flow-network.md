# Circulation in a flow network

↑ **Parent:** [Flow network](flow-network.md)

A [network circulation](circulation-in-a-flow-network.md) is a [flow](flow.md) with zero net supply at every vertex. A feasible residual [network circulation](circulation-in-a-flow-network.md) changes one feasible flow into another with the same prescribed supplies. It decomposes into directed cycles, giving the negative-cycle optimality test for [minimum-cost flow](minimum-cost-flow-problem.md).
