# Fixed component

↑ **Parent:** [Fixed part of a linear system](fixed-part-of-a-linear-system.md)

A fixed component is a prime divisor appearing in every member of a [complete linear system of a divisor](complete-linear-system-of-a-divisor.md). This concerns divisorial components; a linear system can have isolated basepoints even when it has no fixed component.
