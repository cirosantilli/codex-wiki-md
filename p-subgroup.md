# p-subgroup

↑ **Parent:** [Finite p-group](finite-p-group.md)

A p-subgroup is a [subgroup](subgroup.md) which is a [finite p-group](finite-p-group.md), for a specified prime $p$. Every p-subgroup lies in a [Sylow subgroup](sylow-subgroup.md).
