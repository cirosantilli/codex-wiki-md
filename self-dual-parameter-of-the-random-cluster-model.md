# Self-dual parameter of the random-cluster model

↑ **Parent:** [Random-cluster model](random-cluster-model.md)

Planar random-cluster duality relates edge odds by $[p/(1-p)][p^*/(1-p^*)]=q$. The fixed point $p=p^*$ has odds $\sqrt q$, giving the displayed parameter. A self-dual parameter does not by itself establish a critical threshold on an arbitrary [planar graph](planar-graph.md). At this parameter the [symmetric cluster weight at the self-dual parameter](symmetric-cluster-weight-at-the-self-dual-parameter.md) makes the primal-dual cluster counts explicit.
