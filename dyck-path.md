# Dyck path

↑ **Parent:** [Lattice path](lattice-path.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dyck_path)

A Dyck path of semilength $n$ starts at $(0,0)$, ends at $(2n,0)$, uses steps $(1,1)$ and $(1,-1)$, and never passes below the horizontal axis.
