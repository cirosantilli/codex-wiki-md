# Support widening for the wave equation

↑ **Parent:** [Finite propagation speed](finite-propagation-speed.md)

For whole-line [Cauchy data](cauchy-data.md) with [support](support.md) contained in $[-a,a]$, the displayed inclusion holds at $t\geq0$. A short check uses [D'Alembert's formula](d-alembert-s-formula.md): if $x>a+ct$, both sampled endpoints and the whole [interval](interval-mathematics.md) of [integration](integral-split.md) lie to the right of $a$, so all contributions vanish; the argument for $x<-a-ct$ is identical. The inclusion can be strict, and a nonzero response at the first permitted arrival is not guaranteed.
