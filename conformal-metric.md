# Conformal metric

↑ **Parent:** [Riemann surfaces](riemann-surfaces.md)

In a [holomorphic coordinate](holomorphic-coordinate.md), a length element $\rho(z)|dz|$. [Smooth](smooth-function.md) positive densities define ordinary [Riemannian metrics](riemannian-metric.md); [extremal length](extremal-length.md) also permits nonnegative measurable densities with finite positive area $\int\rho^2\,dx\,dy$.
