# Definable set

↑ **Parent:** [First-order structure](first-order-structure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Definable_set)

A [definable set](definable-set.md) in a [first-order structure](first-order-structure.md) $M$ is the set of tuples satisfying one [first-order formula](first-order-formula.md), possibly with a specified finite tuple of parameters $\mathbf b$ from the structure. A set definable over $B\subseteq M$ uses parameters from $B$. [Parameter-free definability](parameter-free-definability.md) uses no extra named elements. The distinction matters: any singleton becomes definable if its own element is allowed as a parameter, while many singletons are not definable without parameters. Finite Boolean combinations of definable sets are definable, using [logical conjunction](logical-conjunction.md), [logical disjunction](logical-disjunction.md) and [logical negation](negation.md).
