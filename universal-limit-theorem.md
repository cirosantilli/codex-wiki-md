# Universal limit theorem

↑ **Parent:** [Rough differential equation](rough-differential-equation.md)

For sufficiently regular vector fields, for example bounded fields with bounded derivatives through order three when $2<p<3$, the solution map of a [rough differential equation](rough-differential-equation.md) exists uniquely and is locally continuous in the [rough path metric](rough-path-metric.md). [Ordinary differential equations](ordinary-differential-equation.md) driven by smooth approximations therefore converge whenever their enhanced drivers converge. The theorem makes the enhancement, rather than just the original path, the correct input for a continuous solution map.
