# Constant-one arithmetic function

↑ **Parent:** [Dirichlet convolution](dirichlet-convolution.md)

The constant-one arithmetic function has $\mathbf 1(n)=1$ for every [positive integer](positive-integer.md) $n$. Its [Dirichlet convolution](dirichlet-convolution.md) with $f$ is the [divisor sum](divisor-sum.md) $(\mathbf 1*f)(n)=\sum_{d\mid n}f(d)$.
