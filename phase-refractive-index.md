# Phase refractive index

↑ **Parent:** [Refractive index](refractive-index.md)

The ratio $n=c/v_{\rm ph}$ compares vacuum light speed with the [phase velocity](phase-velocity.md) at a specified [frequency](frequency.md). In a dispersive material it differs from the group index; the [Cherenkov radiation](cherenkov-radiation.md) cone uses the phase index.
