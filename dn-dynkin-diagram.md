# Dn Dynkin diagram

↑ **Parent:** [Dynkin diagram](dynkin-diagram.md)

For $n\ge4$, the finite [Dynkin diagram](dynkin-diagram.md) $D_n$ is a simply laced tree with one trivalent vertex and three arms containing $1,1,n-3$ edges. All its [roots](root-of-a-root-system.md) have the same length.
