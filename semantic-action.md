# Semantic action

↑ **Parent:** [Context-free grammar](context-free-grammar.md)

An operation associated with a [context-free grammar](context-free-grammar.md) production, performed when that production is recognized. [Semantic actions](semantic-action.md) can construct an [abstract syntax tree](abstract-syntax-tree.md) by combining the trees attached to its child [nonterminal symbols](nonterminal-symbol.md).
