# Single parity-check code

↑ **Parent:** [Binary linear code](binary-linear-code.md)

The code consisting of all even-weight binary words. For $n\geq1$ its dimension is $n-1$, and its [weight enumerator](weight-enumerator.md) is $[(t+s)^n+(t-s)^n]/2$, by selecting the even terms of the [binomial theorem](binomial-theorem.md). The length-one code contains only zero.
