# Type I migration

↑ **Parent:** [Planetary migration](planetary-migration.md)

Orbital migration of a low-[mass](mass.md) embedded [planet](planet.md) driven by its interaction with disk [gas](gas.md), without a deep gap. Spiral wave torques and corotation-region torques exchange orbital [angular momentum](angular-momentum.md). The sign depends on the disk gradients and thermodynamics; this regime is not restricted to inward migration.
