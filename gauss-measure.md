# Gauss measure

↑ **Parent:** [Gauss continued-fraction map](gauss-continued-fraction-map.md)

The [invariant measure](invariant-measure.md) for the [Gauss continued-fraction map](gauss-continued-fraction-map.md) with density $1/[(\log2)(1+x)]$ on $[0,1]$. Inverse branches $x=1/(n+y)$ give transformed density $(\log2)^{-1}\sum_{n\geq1}[(n+y)^{-1}-(n+y+1)^{-1}]$, which telescopes to the same density.
