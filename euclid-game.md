# Euclid game

↑ **Parent:** [Impartial game](impartial-game.md)

A game on two positive [integers](integer-split.md) in which a move subtracts a positive multiple of the smaller from the larger without making it negative. The position is then reordered. This is an [impartial game](impartial-game.md) related to the [Euclidean algorithm](euclidean-algorithm.md); the exact terminal and winning convention must be stated.
