# Clutching function

↑ **Parent:** [Clutching construction](clutching-construction.md)

A clutching function is the equatorial transition map used in the [clutching construction](clutching-construction.md). For an oriented real [vector bundle](vector-bundle.md) one may choose a [fiber metric](fiber-metric.md) and orthonormal trivializations, so its clutching function takes values in the [special orthogonal group](special-orthogonal-group.md).
