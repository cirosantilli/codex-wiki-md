# Conjugate subset

↑ **Parent:** [Conjugation](conjugation.md)

For a subset $S$ of a [group](group-split.md) and an element $g$, its conjugate subset is

$$
gSg^{-1}=\{gsg^{-1}:s\in S\}.
$$

Conjugation is a [bijection](bijection.md) and a [group automorphism](group-automorphism.md), so it preserves cardinality and every property expressed using the group operation.
