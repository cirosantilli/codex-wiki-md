# SLE two-boundary-point ratio diffusion

↑ **Parent:** [Boundary-point Bessel flow for SLE](boundary-point-bessel-flow-for-sle.md)

For $0<x<y$, let $D_t=g_t(y)-g_t(x)$. Before the first [boundary-point swallowing time for a Loewner chain](boundary-point-swallowing-time-for-a-loewner-chain.md), the ratio obeys

$$
dZ_t=-\frac{\sqrt\kappa}{D_t}d\beta_t+\frac2{D_t^2}\left(\frac1{Z_t}+\frac1{Z_t-1}\right)dt.
$$

The clock $u=\int D_t^{-2}dt$ removes the denominator. An increasing [scale function of a one-dimensional diffusion](scale-function-stochastic-processes.md) is $s_\kappa(z)=\int_1^z[v(v-1)]^{-4/\kappa}dv$. For $\kappa>4$ the endpoint $1$ represents strict swallowing; escape at infinite clock represents simultaneous swallowing.
