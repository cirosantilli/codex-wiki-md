# Isocline

↑ **Parent:** [Differential equation](differential-equation-split.md)

For a first-order [differential equation](differential-equation-split.md) $y'=f(x,y)$, an isocline is a [level set](level-set.md) on which the slope of each solution is the same constant $k$. These curves organize a [direction field](direction-field.md): draw tangent vectors proportional to $(1,k)$ along each isocline. Points where the right-hand side is undefined must be excluded.
