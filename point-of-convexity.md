# Point of convexity

↑ **Parent:** [Convex function](convex-function.md)

For a differentiable real [function](function-split.md) $g$, a point of [convexity](convex-function.md) is a point $v_0$ whose tangent line lies below the entire graph. The [function](function-split.md) need not be [convex](convex-function.md) at other points. The [Weierstrass excess function](weierstrass-excess-function.md) is exactly the difference between the function and this tangent line when applied to a variational integrand as a function of slope.
