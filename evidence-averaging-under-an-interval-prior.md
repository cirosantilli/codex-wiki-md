# Evidence averaging under an interval prior

↑ **Parent:** [Bayesian model evidence](bayesian-model-evidence.md)

For a normalized [uniform prior](uniform-prior.md) on $[a,b]$, [Bayesian model evidence](bayesian-model-evidence.md) is $Z=(b-a)^{-1}\int_a^b\mathcal L(\theta)d\theta$. It averages the [likelihood](likelihood-function.md) over the prior range. Extending a well-placed interval into low-likelihood regions reduces that average, but moving or widening a poorly placed interval can improve it. A model prior is separate: posterior model odds equal the evidence ratio multiplied by prior model odds.
