# Conformal map from a parabolic domain to the unit disc

↑ **Parent:** [Conformal map](conformal-map.md)

The map $C(z)=\tan^2(\pi\sqrt z/4)$ is a [conformal map](conformal-map.md) from $\{x+iy:y^2<4(1-x)\}$ onto the [unit disc](unit-disc.md). A [principal square root](principal-square-root-of-a-complex-number.md) first maps the slit parabolic region to a vertical strip, and a scaled [tangent](tangent.md) followed by squaring maps the strip to a slit disc. Evenness in the square-root variable gives a [holomorphic](complex-differentiability-at-a-point.md) extension across the removed axis, filling the target slit.
