# Axiom of pairing

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Axiom_of_pairing)

For any two [sets](set-split.md) there is a set containing exactly those two members. Together with other [ZFC](zermelo-fraenkel-set-theory-with-choice.md) axioms it permits ordinary ordered-pair coding. [Countable-subset closure](countable-subset-closure.md) implies this axiom for the structure of [hereditarily countable sets](hereditarily-countable-set.md).
