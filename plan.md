# Plan

↑ **Parent:** [Automated planning](automated-planning.md)

In deterministic [classical planning](classical-planning.md), a finite sequence of actions applicable successively from the initial state and ending in a state satisfying the goal. A [STRIPS](strips.md) [plan](plan.md) must respect every action's [precondition](precondition.md) set and both add and delete effects. A numerical bound on a possible [plan](plan.md)'s cost does not itself specify the action sequence.
