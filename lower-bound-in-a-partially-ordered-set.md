# Lower bound in a partially ordered set

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

A [lower bound](lower-bound-in-a-partially-ordered-set.md) of a subset $S$ of a [partially ordered set](partially-ordered-set.md) is an element $\ell$ no greater than every member of $S$. For minimization, a number below every feasible objective value is therefore a [lower bound](lower-bound-in-a-partially-ordered-set.md) on the optimum; a relaxation often provides such a certificate.
