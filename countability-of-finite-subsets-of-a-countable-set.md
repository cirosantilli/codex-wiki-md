# Countability of finite subsets of a countable set

↑ **Parent:** [Countable set](countable-set.md)

A finite [subset](subset.md) $A$ of the [natural numbers](natural-number.md), numbered from one, has the binary code $\sum_{j\in A}2^{j-1}$. Distinct finite [subsets](subset.md) give distinct codes, because the largest differing exponent exceeds the sum of all smaller powers of two. Thus the finite [subsets](subset.md) form a [countable set](countable-set.md), although the entire [power set](power-set.md) is an [uncountable set](uncountable-set.md) by the [Cantor diagonal argument](cantor-diagonal-argument.md). An enumeration transfers this coding to any [countable set](countable-set.md).
