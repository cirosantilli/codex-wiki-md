# Generalized Reed-Solomon code

↑ **Parent:** [Reed-Solomon error correction](reed-solomon-error-correction.md)

A generalized Reed-Solomon code consists of $(v_i f(a_i))_{i=1}^n$, where the evaluation points are distinct, all coordinate multipliers $v_i$ are nonzero, and $\deg f<k$. It remains a [maximum distance separable code](maximum-distance-separable-code.md). Its [dual code](dual-code.md) is another generalized Reed-Solomon code with dimension $n-k$ and multipliers proportional to $v_i^{-1}\prod_{j\ne i}(a_i-a_j)^{-1}$.
