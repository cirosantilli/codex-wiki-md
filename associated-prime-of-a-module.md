# Associated prime of a module

↑ **Parent:** [Annihilator (ring theory)](annihilator-ring-theory.md)

An associated prime of an $R$-[module](module-mathematics.md) $M$ is a [prime ideal](prime-ideal.md) equal to the [annihilator](annihilator-ring-theory.md) $\operatorname{Ann}_R(m)$ of some nonzero $m\in M$. The set of these primes is denoted $\operatorname{Ass}_R(M)$. Over a [Noetherian ring](noetherian-ring.md), any maximal member among the [annihilators](annihilator-ring-theory.md) of nonzero elements is prime: if $abm=0$ and $bm\ne0$, maximality forces $\operatorname{Ann}_R(bm)=\operatorname{Ann}_R(m)$, so $am=0$. Hence every nonzero [module](module-mathematics.md) has an associated prime.
