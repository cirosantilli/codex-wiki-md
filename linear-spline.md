# Linear spline

↑ **Parent:** [Spline (mathematics)](spline-mathematics.md)

A [linear spline](linear-spline.md) is a continuous [piecewise linear function](piecewise-linear-function.md) on a specified [spline knot sequence](spline-knot-sequence.md). For uniform integer [spline knots](spline-knot.md), the hat basis in the displayed representation interpolates the data $s(i)=c_i$. The [derivative](derivative.md) is constant on each open span and can jump at a knot. Coinciding neighboring slopes remove a particular jump, but generic data give only $C^0$ regularity.
