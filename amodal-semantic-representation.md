# Amodal semantic representation

↑ **Parent:** [Semantic memory](semantic-memory.md)

A representation of conceptual information not restricted to a single sensory input or verbal output format. Converging cross-modal deficits can support this hypothesis without proving that all features are stored in one homogeneous site.
