# Intermediate representation

↑ **Parent:** [Compiler](compiler.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Intermediate_representation)

A program representation used between input and final output, convenient for analysis, transformation or execution. An [abstract syntax tree](abstract-syntax-tree.md) and [bytecode](bytecode.md) can each serve this role.
