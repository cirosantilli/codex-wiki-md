# Polynomial residual

↑ **Parent:** [Polynomial evaluation](polynomial-evaluation.md)

The residual of a proposed [polynomial root](root-of-a-polynomial.md) $\widehat z$ is the value $p(\widehat z)$, which is zero for an exact root. Its size alone does not bound the root error without information about the scaling and [derivative](derivative.md) of the [polynomial](polynomial-split.md).
