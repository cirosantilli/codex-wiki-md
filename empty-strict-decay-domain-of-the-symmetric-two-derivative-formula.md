# Empty strict decay domain of the symmetric two-derivative formula

↑ **Parent:** [Symmetric two-step two-derivative formula](symmetric-two-step-two-derivative-formula.md)

On the [Dahlquist test equation](dahlquist-test-equation.md), write the [amplification polynomial](amplification-polynomial-of-a-multistep-method.md) as $D\xi^2-16z\xi-A$, where $D=z^2-7z+15$ and $A=z^2+7z+15$. The identity $|A|^2-|D|^2=28\operatorname{Re}z(|z|^2+15)$ shows that both [roots of a polynomial](root-of-a-polynomial.md) can lie inside the open [unit disk](unit-disk.md) only if $\operatorname{Re}z<0$. But the [complex quadratic Schur criterion](complex-quadratic-schur-criterion.md) would then require $32|\operatorname{Re}z|(|z|^2+15)<28|\operatorname{Re}z|(|z|^2+15)$, which is impossible. Thus the [strict linear stability domain](strict-linear-stability-domain.md) is empty. This concerns robust damping of all modes, rather than convergence on fixed time intervals or the [bounded-root stability set of the symmetric two-derivative formula](bounded-root-stability-set-of-the-symmetric-two-derivative-formula.md).
