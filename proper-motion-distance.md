# Proper-motion distance

↑ **Parent:** [Cosmological distance measure](cosmological-distance-measure.md)

A source-frame transverse physical speed $v$ produces an observed angular rate $\dot\theta$. [cosmological time dilation](cosmological-time-dilation.md) converts source time to observer time, so this operational distance equals $(1+z)$ times the [angular diameter distance](angular-diameter-distance.md). In an FLRW geometry it is the [transverse comoving distance](transverse-comoving-distance.md) $R_0S(\chi)$. It should be derived with the time convention stated, rather than interpreting the source speed and angular rate as measurements made by the same clock.
