# Jacobi theta function

↑ **Parent:** [Theta function](theta-function.md)

The Jacobi theta function

$$
\theta(\tau)=\sum_{n\in\mathbb Z}e^{\pi in^2\tau}
$$

satisfies $\theta(\tau+2)=\theta(\tau)$ and $\theta(-1/\tau)=(-i\tau)^{1/2}\theta(\tau)$.
