# Trace-overlap gate fidelity

↑ **Parent:** [Quantum logic gate](quantum-logic-gate.md)

For two $d$-dimensional [unitary matrices](unitary-matrix.md), this normalized absolute trace lies in $[0,1]$ and equals one exactly when $V=e^{i\gamma}U$. The triangle inequality on the eigenphases of $U^\dagger V$ proves both statements. It ignores an overall [global phase](global-phase.md) and compares complete propagators. It is not the same definition as average gate fidelity; for unitary implementations that latter quantity is $(d\mathcal F^2+1)/(d+1)$.
