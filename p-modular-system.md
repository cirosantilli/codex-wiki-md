# p-modular system

↑ **Parent:** [Modular representation theory](modular-representation-theory.md)

A p-modular system consists of a characteristic-zero field $K$, a [discrete valuation ring](discrete-valuation-ring.md) $\mathcal O\subset K$, and its residue field $k$ of characteristic $p$. It is a splitting system for a finite group when both $K$ and $k$ split the relevant group representations.
