# String length constraint

↑ **Parent:** [Constraint (mechanics)](constraint-mechanics.md)

The [holonomic constraint](holonomic-constraint.md) obtained by summing the straight and curved segment lengths of a taut [massless inextensible string](massless-inextensible-string.md) and setting the result equal to its fixed length $l$. [Differentiation](differentiation.md) gives $\sum_i(\partial L/\partial q_i)\dot q_i=0$, a relation between the permitted [velocities](velocity.md). A slack string does not impose this equality on endpoint separation.
