# Principal submatrix

↑ **Parent:** [Matrix](matrix.md)

The square [matrix](matrix.md) obtained by retaining the same index set $I$ of rows and columns of a square [matrix](matrix.md) $A$. Its [determinant](determinant.md) is a [principal minor](principal-minor.md). A leading [principal submatrix](principal-submatrix.md) uses the first $k$ indices.
