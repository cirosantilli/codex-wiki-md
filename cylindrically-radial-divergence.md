# Cylindrically radial divergence

↑ **Parent:** [Divergence](divergence.md)

For a [vector field](vector-field.md) directed radially from a fixed axis and depending only on distance $\rho$ from that axis, [cylindrical coordinates](cylindrical-coordinate-system.md) give $\nabla\cdot[f(\rho)\mathbf e_\rho]=f\prime+f/\rho$. Zero [divergence](divergence.md) gives $f=A/\rho$ on any positive radial interval. Unless $A=0$, this field is singular on the axis, so applications of the [divergence theorem](divergence-theorem.md) must use a domain avoiding it or account separately for that singularity.
