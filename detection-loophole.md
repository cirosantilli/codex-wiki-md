# Detection loophole

↑ **Parent:** [Bell test](bell-test.md)

The [detection loophole](detection-loophole.md) arises when missed events allow the retained sample to depend on settings and hidden variables. For example, a [local hidden-variable theory](local-hidden-variable-theory.md) may retain different underlying pairs at different [polarizer](polarizer.md) angles. Applying the [CHSH inequality](chsh-inequality.md) to that selected sample does not test the original setting-independent ensemble. A valid protocol specifies outcomes and trials, including failures, or justifies an appropriate [fair sampling](fair-sampling.md) assumption. Subtracting [accidental coincidences](accidental-coincidence.md) addresses background contamination; it does not by itself repair this selection problem.
