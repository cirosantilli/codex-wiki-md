# Rank test

↑ **Parent:** [Nonparametric statistics](nonparametric-statistics-split.md)

A rank test is a [hypothesis test](statistical-hypothesis-test.md) whose statistic is a function of the [ranks of observations](rank-of-an-observation.md), possibly together with fixed sample labels. Under independent observations from a common continuous [probability distribution](probability-distribution.md), exchangeable rank allocations give its exact null law without specifying that distribution. The [Wilcoxon rank sum test](mann-whitney-u-test.md) is an example. Invariance under common increasing transformations follows because ranks do not change.
