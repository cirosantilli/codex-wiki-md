# Computer network

↑ **Parent:** [Computer science](computer-science-split.md)

A [computer network](computer-network-split.md) connects computing devices so they can exchange data using [communication protocols](communication-protocol.md). [Packet switching](packet-switching.md) shares communication links among many exchanges; [routers](router.md) forward [network packets](network-packet.md) between connected networks. The arrangement of machines and links need not coincide with the arrangement of administrative control.
