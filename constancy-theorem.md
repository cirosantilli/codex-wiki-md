# Constancy theorem

↑ **Parent:** [Mean value theorem](mean-value-theorem.md)

A [differentiable function](differentiable-function.md) on an [interval](interval-mathematics.md) whose [derivative](derivative.md) is identically zero is a [constant function](constant-function.md). Indeed, for any two arguments $x<y$, the [mean value theorem](mean-value-theorem.md) on $[x,y]$ gives $f(y)-f(x)=f'(c)(y-x)=0$. For an [interval](interval-mathematics.md) with endpoints included, [continuity](continuous-function.md) at those endpoints is required. A disconnected [domain](domain-mathematical-analysis.md) may have different constants on different components.
