# Homotopy type

↑ **Parent:** [Homotopy equivalence](homotopy-equivalence.md)

Two spaces have the same homotopy type when there is a [homotopy equivalence](homotopy-equivalence.md) between them. Their [homology](homology-split.md) and [homotopy groups](homotopy-group.md) are then isomorphic. In [Morse theory](morse-theory.md), attaching a cell records a change in the homotopy type of a sublevel set.
