# Dimensional interband threshold shapes

↑ **Parent:** [Joint density of states](joint-density-of-states.md)

Parabolic electron-hole continua with $d$ unconfined directions have cumulative state count proportional to $(E-E_{\rm th})^{d/2}$. Differentiating gives the threshold joint density proportional to $(E-E_{\rm th})^{d/2-1}$: a square root for bulk, a step for a well, and an inverse square root for a wire. A fully confined dot instead has discrete lines. Optical matrix elements, occupations, [excitons](exciton.md) and broadening determine the actual absorption beyond this counting argument.
