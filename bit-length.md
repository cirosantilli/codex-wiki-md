# Bit length

↑ **Parent:** [Binary number](binary-number.md)

The number of [binary digits](binary-digit.md) in the usual representation of a positive [integer](integer-split.md) $n$: $\lfloor\log_2 n\rfloor+1$. The bit length of zero is conventionally zero in integer programming interfaces.
