# Planning state invariant

↑ **Parent:** [Formal specification](formal-specification.md)

A property true initially and preserved by every applicable action in an [automated planning](automated-planning.md) model. [Mathematical induction](mathematical-induction.md) on the plan length then proves it for every reachable state. Typical examples are unique object locations, a capacity bound, and exactly one occupancy marker being true. An invariant is a consequence to prove from the action rules; merely declaring the intended capacity in prose does not enforce it.
