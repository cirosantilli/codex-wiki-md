# Simplex ratio test

↑ **Parent:** [Simplex method](simplex-method.md)

In a feasible [simplex basis](simplex-basis.md), increasing a nonbasic variable by $\theta$ changes basic coordinates to $x-\theta d$. Nonnegativity limits $\theta$ by the smallest ratio $x_i/d_i$ with $d_i>0$; a minimizing coordinate leaves the basis. Ties can leave zero-valued basic variables. This pivot test is distinct from the analytic [ratio test](ratio-test.md) for series convergence.
