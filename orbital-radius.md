# Orbital radius

↑ **Parent:** [Orbit (dynamical system)](orbit-dynamical-system.md)

The instantaneous [distance](distance.md) from an attracting centre to an orbiting body. It is constant on a [circular orbit](circular-orbit.md) but varies along an [elliptic orbit](elliptic-orbit.md). For [Kepler's third law](kepler-s-third-law.md) the relevant size is the [semi-major axis](semi-major-axis.md), which equals the orbital radius only for a [circular orbit](circular-orbit.md).
