# Mercurinium ion

↑ **Parent:** [Ion](ion.md)

A bridged cationic intermediate formed when an [alkene](alkene.md) coordinates an [electrophilic](electrophilicity.md) [mercury](mercury-element.md) species. Unequal [carbon](carbon.md) substitution can produce unequal positive-charge character and control nucleophilic opening.
