# Hungarian algorithm

↑ **Parent:** [Assignment problem](assignment-problem.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hungarian_algorithm)

The Hungarian algorithm maintains feasible [assignment dual potentials](assignment-dual-potentials.md) and a matching of equality edges. If the alternating search cannot augment, adjust reachable job and agent potentials by the smallest [reduced cost](reduced-cost.md) leaving the search set. This preserves feasibility and existing matching equalities while exposing a new equality edge. A resulting [perfect matching](perfect-matching.md) attains the dual lower bound.
