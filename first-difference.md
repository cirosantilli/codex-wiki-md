# First difference

↑ **Parent:** [Finite difference](finite-difference-split.md)

The first difference of a [sequence](sequence.md) records the change between consecutive terms. Its partial sums telescope: $u_n=u_0+\sum_{j=0}^{n-1}\Delta u_j$. Thus a compact description of the differences can give an efficient way to reconstruct distant terms of the original [sequence](sequence.md).
