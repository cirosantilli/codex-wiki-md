# Confirmatory factor analysis

↑ **Parent:** [Factor analysis](factor-analysis.md)

A [factor analysis](factor-analysis.md) evaluating prespecified loading patterns and other measurement restrictions. Testing a model in new data is stronger evidence than selecting it and evaluating its apparent fit using the same data. Model fit alone does not establish [construct validity](construct-validity.md).
