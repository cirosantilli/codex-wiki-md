# Conditional logistic model for longitudinal binary data

↑ **Parent:** [Logistic regression](logistic-regression.md)

A [logistic regression](logistic-regression.md) can specify each binary response conditionally on recorded past outcomes and baseline [covariates](covariate.md). A [chain rule for probabilities](chain-rule-for-probabilities.md) gives the path [likelihood](likelihood-function.md) as the product of the conditional [Bernoulli distribution](bernoulli-distribution.md) masses. This permits dependence within a person's history without treating their outcomes as unconditionally independent. The model must specify the initial history and which past features enter its conditional mean.
