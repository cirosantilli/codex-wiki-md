# Radius stabilization

↑ **Parent:** [Radion](radion.md)

[Radius stabilization](radius-stabilization.md) fixes the size of a [compactification](compactification-physics.md) dynamically rather than choosing it as an undetermined parameter. If the four-dimensional [low-energy effective action](low-energy-effective-action.md) contains a [radion](radion.md) $R$ with positive kinetic coefficient $Z(R)$ and [scalar potential](scalar-potential.md) $V(R)$, a stable radius $R_0$ requires $V'(R_0)=0$ and $m_R^2=V''(R_0)/Z(R_0)>0$. This matters for the [hierarchy problem](hierarchy-problem.md): the volume or warp factor explains a hierarchy only if a consistent dynamics selects and maintains the required geometry.
