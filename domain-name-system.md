# Domain Name System

↑ **Parent:** [Internet](internet.md)

The [Domain Name System](domain-name-system.md) provides a hierarchical namespace with delegated administration and distributed [servers](network-server.md). Caching and replication help supply its service. A consistent namespace is compatible with distribution of responsibility across organisations.[§2.2, §3 and §4.2: goals, namespace and zones](domain-names-concepts-and-facilities-rfc-1034.md)
