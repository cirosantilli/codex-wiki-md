# Multiple-acceptor FRET efficiency

↑ **Parent:** [FRET efficiency](fret-efficiency.md)

For n identical independent available [FRET acceptors](fret-acceptor.md), transfer rates add. With single-pair [FRET efficiency](fret-efficiency.md) E, the donor exit probability is $E_n=nE/[1+(n-1)E]$. It is not nE; competition with the donor's other decay routes must be retained.
