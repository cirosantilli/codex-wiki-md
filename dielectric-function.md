# Dielectric function

↑ **Parent:** [Relative permittivity](relative-permittivity.md)

The generally complex, frequency- and wavevector-dependent [relative permittivity](relative-permittivity.md) describing linear [polarization](polarization-waves.md) response. Its imaginary part represents dissipative response with the sign fixed by the time convention; optical prefactors connect it to an absorption coefficient.
