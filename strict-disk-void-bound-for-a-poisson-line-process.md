# Strict disk-void bound for a Poisson line process

↑ **Parent:** [Intersection point process of a Poisson line process](intersection-point-process-of-a-poisson-line-process.md)

For $c,r>0$, an intersection inside a disk requires at least two lines to meet that disk. The latter count is [Poisson](poisson-distribution.md) with [mean](expected-value.md) $2\pi cr$, giving the non-strict bound first. It is strict because two lines with nearby normal angles but separated perpendicular distances can both hit the disk while intersecting outside. Choose two positive-measure parameter boxes forcing this configuration; the event of exactly one line in each box and no other disk-hitting line has positive [probability](probability.md). This also yields a void [probability](probability.md) too large to equal that of a [Poisson point process](poisson-point-process.md) with the intersection process's [intensity measure](intensity-measure-of-a-point-process.md).
