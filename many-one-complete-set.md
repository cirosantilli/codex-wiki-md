# Many-one complete set

↑ **Parent:** [Many-one reduction](many-one-reduction.md)

A set $A$ is complete for a class $\mathcal C$ under many-one reductions when $A\in\mathcal C$ and every $B\in\mathcal C$ satisfies $B\leq_mA$.
