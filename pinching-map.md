# Pinching map

↑ **Parent:** [Nonselective projective measurement](nonselective-projective-measurement.md)

For mutually orthogonal projectors summing to the identity, a pinching map discards coherences between their ranges while preserving each diagonal block. It is a [quantum channel](quantum-channel.md) with [Kraus operators](kraus-operator.md) $P_i$, and a [unital quantum channel](unital-quantum-channel.md). A state is fixed by pinching exactly when it commutes with every projector.
