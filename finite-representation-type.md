# Finite representation type

↑ **Parent:** [Module theory](module-theory-split.md)

A finite-dimensional [algebra](algebra-split.md) has finite representation type when there are only finitely many isomorphism classes of finite-dimensional [indecomposable modules](indecomposable-module.md). This counts module types, not the dimensions or the number of direct sums formed from them. For a [block of a group algebra](block-of-a-group-algebra.md), finite representation type is equivalent to a cyclic [defect group of a block](defect-group-of-a-block.md).
