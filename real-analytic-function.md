# Real analytic function

↑ **Parent:** [Analysis](analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Real_analytic_function)

A function $f$ is real analytic at $y$ when its [Taylor series](taylor-series.md)

$$
\sum_{\alpha\in\mathbb N^n}\frac{D^\alpha f(y)}{\alpha!}(x-y)^\alpha
$$

converges to $f(x)$ throughout some [neighborhood](neighbourhood-mathematics.md) of $y$.
