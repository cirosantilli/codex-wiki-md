# Principal idele

↑ **Parent:** [Idele group](idele-group.md)

An [idele](idele.md) obtained by mapping the same nonzero element of a [number field](number-field.md) into every completion. Only finitely many local valuations are nonzero, so this diagonal tuple belongs to the [idele group](idele-group.md).
