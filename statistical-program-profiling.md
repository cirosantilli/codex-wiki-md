# Statistical program profiling

↑ **Parent:** [Algorithm](algorithm.md)

Periodically sample an executing program's [instruction pointer](instruction-pointer.md) and accumulate an address histogram. Samples approximate time spent in address regions, rather than exact instruction execution counts. Jittering the sampling interval reduces accidental synchronization with periodic code.
