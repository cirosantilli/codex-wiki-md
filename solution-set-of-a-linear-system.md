# Solution set of a linear system

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

For a consistent [linear system](system-of-linear-equations.md) $Ax=b$, choose one solution $x_0$. By [linearity](linearity.md), $Ax=b$ if and only if $A(x-x_0)=0$, so its solution set is the translate $x_0+\ker A$ of the [kernel](kernel-of-a-linear-map-split.md). Over the [real numbers](real-number.md), this gives exactly one solution when the [kernel](kernel-of-a-linear-map-split.md) is zero and infinitely many when the [kernel](kernel-of-a-linear-map-split.md) contains a nonzero [vector](vector.md): $x_0+tz$ is a distinct solution for each real $t$ if $z\ne0$ lies in the [kernel](kernel-of-a-linear-map-split.md). An inconsistent [linear system](system-of-linear-equations.md) has an empty solution set. The [dimension](dimension-vector-space.md) of a nonempty solution set, regarded as an [affine space](affine-space.md), is the [nullity](nullity-of-a-linear-map.md) of $A$.
