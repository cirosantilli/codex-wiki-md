# Connected correlation function

↑ **Parent:** [Correlation function](correlation-function.md)

The connected correlation of two observables is $\langle AB\rangle_c=\langle AB\rangle-\langle A\rangle\langle B\rangle$. It vanishes in a [product state](product-state.md) when $A$ and $B$ act on disjoint factors.
