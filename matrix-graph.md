# Matrix graph

↑ **Parent:** [Sparse Gaussian elimination](sparse-gaussian-elimination.md)

For a symmetric [sparse matrix](sparse-matrix.md), its [matrix graph](matrix-graph.md) has one vertex per unknown and an edge $i-j$ whenever the off-diagonal entry $a_{ij}$ is structurally nonzero. Simultaneous row and column permutation relabels this [graph](graph-split.md). Nonsymmetric patterns are instead represented by directed or bipartite [graphs](graph-split.md) when row and column roles must be distinguished.
