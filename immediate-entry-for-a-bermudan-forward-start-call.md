# Immediate entry for a Bermudan forward-start call

↑ **Parent:** [Forward start option](forward-start-option.md)

Let $c(u)$ be the [Black-Scholes formula](black-scholes-formula.md) value divided by stock price for an at-the-money call of duration $u$. On a discrete set of possible entry dates, [homogeneous function](homogeneous-function.md) and the discounted stock [martingale](martingale-split.md) reduce the [Snell envelope](snell-envelope.md) to $b_i=\max(c(T-T_i),b_{i+1})$, with zero terminal value. Thus the displayed maximum is exact. When $r>0$ and [volatility](financial-volatility.md) is positive, $c$ increases with maturity, so immediate entry is optimal and the initial value equals the ordinary at-the-money [European call option](european-call-option.md). The maximum recursion remains useful if a different parameter regime loses that monotonicity.
