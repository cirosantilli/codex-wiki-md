# Diagonalizable nilpotent matrix

↑ **Parent:** [Nilpotent matrix](nilpotent-matrix.md)

The only [diagonalizable](diagonalizable-matrix.md) [nilpotent matrix](nilpotent-matrix.md) is the zero matrix. Indeed, if $A^p=0$ and $Av=\lambda v$ with $v\ne0$, then $\lambda^p=0$, so $\lambda=0$. A basis of [eigenvectors](eigenvector.md) would make every diagonal entry zero and therefore $A=0$. Nonzero nilpotent matrices require nontrivial [Jordan blocks](jordan-block.md), even if their characteristic polynomial has only one distinct root.
