# Normalized Banzhaf index

↑ **Parent:** [Probabilistic Banzhaf index](probabilistic-banzhaf-index.md)

The [normalized Banzhaf index](normalized-banzhaf-index.md) rescales the [probabilistic Banzhaf indices](probabilistic-banzhaf-index.md) to sum to the grand-[coalition](coalition-game-theory.md) value, whenever the denominator is nonzero. It preserves [cooperative-game symmetry](symmetry-of-a-cooperative-game-value.md) and assigns zero to a [null player](null-player.md), but generally fails [cooperative-game additivity](additivity-of-a-cooperative-game-value.md). For example, add the three-player majority game to a dictatorship of player one. Their normalized indices are $(1/3,1/3,1/3)$ and $(1,0,0)$, whereas the sum game has normalized index $(6/5,2/5,2/5)$, not their vector [sum](sum.md). The sum game has grand-[coalition](coalition-game-theory.md) value two, which must be retained in the normalization.
