# Exponential of a skew-Hermitian matrix

↑ **Parent:** [Matrix exponential](matrix-exponential.md)

If $A$ is [Skew-Hermitian](skew-hermitian-matrix.md), then $-iA$ is a [Hermitian matrix](hermitian-operator.md). The [finite-dimensional spectral theorem](finite-dimensional-spectral-theorem.md) gives $A=Q\operatorname{diag}(i\theta_j)Q^\dagger$, with real $\theta_j$ and a [unitary matrix](unitary-matrix.md) $Q$. Since the [matrix exponential respects similarity](matrix-exponential-respects-similarity.md), $e^A=Q\operatorname{diag}(e^{i\theta_j})Q^\dagger$. Each diagonal entry has modulus one, so $e^A$ is a [unitary matrix](unitary-matrix.md). Thus a [skew-Hermitian matrix](skew-hermitian-matrix.md) generates norm-preserving linear evolution.
