# Local extension of a vector field along a submanifold

↑ **Parent:** [Vector field along a map](vector-field-along-a-map.md)

For an embedded [submanifold](submanifold.md) $i:M\hookrightarrow N$, a smooth [section of a vector bundle](section-of-a-vector-bundle.md) $X\in\Gamma(i^*TN)$ locally extends to an ambient [vector field](vector-field.md). In an adapted chart $M=\{y=0\}$, extend each component $X^a(x)$ independently of the transverse coordinates $y$. If $X$ takes values in $TM$, the extension criterion is $(\widetilde XF)|_M=X(F|_M)$ for every local smooth function $F$ on $N$. Testing coordinate functions suffices. For tangent fields $X,Y$, this criterion also proves $[\widetilde X,\widetilde Y]|_M=[X,Y]$. General fields with normal components have no extension-independent ambient [Lie bracket](lie-bracket.md).
