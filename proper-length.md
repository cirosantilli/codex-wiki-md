# Proper length

↑ **Parent:** [Special relativity](special-relativity-split.md)

Proper length is spatial length measured using the [induced metric](induced-metric.md) on a specified spacelike slice. For a moving extended object, specify the simultaneity convention; local rest lengths need not coincide with a coordinate length.
