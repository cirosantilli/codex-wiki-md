# Cayley graph

↑ **Parent:** [Geometric group theory](geometric-group-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cayley_graph)

For a group $G$ with generating set $S$, the Cayley graph $\operatorname{Cay}_S(G)$ has vertex set $G$ and an edge from $g$ to $gs$ for each $s\in S$.
