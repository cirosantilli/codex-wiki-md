# Diagonalizability criterion using the minimal polynomial

↑ **Parent:** [Diagonalizable matrix](diagonalizable-matrix.md)

A finite-dimensional [linear operator](linear-operator.md) over a [field](field.md) is diagonalizable exactly when its [minimal polynomial](minimal-polynomial.md) splits into distinct linear factors. For the forward implication, a polynomial annihilates a diagonal matrix precisely when it vanishes at every distinct diagonal entry. Conversely, if $m_T=\prod_j(t-\lambda_j)$ with distinct roots, the [Chinese remainder theorem](chinese-remainder-theorem.md) yields a direct sum of the kernels of $T-\lambda_jI$. Each kernel is an [eigenspace](eigenspace.md), so concatenating their [bases](basis.md) diagonalizes $T$.
