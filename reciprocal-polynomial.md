# Reciprocal polynomial

↑ **Parent:** [Polynomial](polynomial-split.md)

The reciprocal polynomial reverses the coefficients of a polynomial with nonzero constant term. For a binary cyclic code with generator $g$ and canonical check polynomial $h$, the reciprocal $h^*$ generates the [dual of a cyclic code](dual-of-a-cyclic-code.md).
