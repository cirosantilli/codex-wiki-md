# Sidorenko inequality for trees

↑ **Parent:** [Sidorenko conjecture](sidorenko-conjecture.md)

Every [tree](tree-graph-theory.md) $T$ satisfies the [Sidorenko conjecture](sidorenko-conjecture.md). If a bipartite host graph has edge density $\alpha$, then a uniformly random bipartition-respecting map from a $k$-vertex tree into the host is a [graph homomorphism](graph-homomorphism.md) with probability at least $\alpha^{k-1}$.
