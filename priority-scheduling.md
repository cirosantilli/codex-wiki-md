# Priority scheduling

↑ **Parent:** [Process scheduling](process-scheduling.md)

A [process scheduling](process-scheduling.md) policy that prefers runnable [operating-system processes](process-computing.md) with higher assigned priority. With [scheduling preemption](scheduling-preemption.md), urgent service work can displace a running background task. Bounded response still requires bounded higher-priority work and adequate CPU capacity; continuously runnable high-priority work can deny lower-priority work progress.
