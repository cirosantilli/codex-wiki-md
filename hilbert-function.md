# Hilbert function

↑ **Parent:** [Hilbert series](hilbert-series.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hilbert_function)

The Hilbert function of a graded module $M=\bigoplus_nM_n$ over a field is $n\mapsto\dim_kM_n$. Its generating function is the [Hilbert series](hilbert-series.md).
