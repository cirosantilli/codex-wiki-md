# Duality gap

↑ **Parent:** [Weak duality](weak-duality.md)

For finite primal and dual optimal values in a [minimization problem](minimization-problem.md), the [duality gap](duality-gap.md) is $p_*-d_*\geq0$. [Strong duality](strong-duality.md) means this difference is zero.
