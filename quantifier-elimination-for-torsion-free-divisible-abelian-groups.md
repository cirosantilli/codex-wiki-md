# Quantifier elimination for torsion-free divisible Abelian groups

↑ **Parent:** [Theory of nontrivial torsion-free divisible Abelian groups](theory-of-nontrivial-torsion-free-divisible-abelian-groups.md)

In a [torsion-free](torsion-free-connection.md) divisible [Abelian group](abelian-group.md), division by a nonzero integer is unique. The rational scalar operations are therefore a definitional expansion. Formulas reduce to Boolean combinations of rational [linear equations](linear-equation.md): eliminate an existential variable in a conjunction by solving any equation with nonzero coefficient; if none fixes the variable, the finitely many nontrivial disequalities exclude only finitely many choices in an infinite group. Equations with zero coefficient reduce to parameter conditions.

Thus over a finite parameter set a complete one-variable type either specifies an element of its [linear span](linear-span.md), or excludes every element of that span. An [uncountable](uncountable-set.md) rational [vector space](vector-space-split.md) realizes the latter type because a finite-parameter span is [countable](countable-set.md). It is consequently an [omega-saturated model](omega-saturated-model.md) in the additive language.
