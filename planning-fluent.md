# Planning fluent

↑ **Parent:** [Artificial intelligence](artificial-intelligence-split.md)

A fact whose truth can change as actions execute in [automated planning](automated-planning.md). Ground location facts and an empty-container marker are examples. In [STRIPS](strips.md), static facts such as an object's fixed type are never added or deleted, while [planning fluents](planning-fluent.md) can appear in action effects.
