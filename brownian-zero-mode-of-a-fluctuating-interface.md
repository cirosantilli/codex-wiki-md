# Brownian zero mode of a fluctuating interface

↑ **Parent:** [Linear fluctuating interface](linear-fluctuating-interface.md)

An unpinned uniform height driven by [Gaussian white noise](gaussian-white-noise.md) is [Brownian motion](brownian-motion-split.md). Its [variance](variance-split.md) grows as $\sigma^2t$ and it has no [stationary distribution](stationary-distribution.md) on the real height axis for $\sigma>0$. Indeed, a stationary [characteristic function](characteristic-function.md) would obey $\widehat\mu(k)=\widehat\mu(k)e^{-\sigma^2k^2t/2}$, incompatible with continuity at zero. Quotienting out the uniform height can still leave stationary shape fluctuations.
