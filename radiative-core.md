# Radiative core

↑ **Parent:** [Radiative stellar structure](radiative-stellar-structure.md)

A stellar core in which [radiative diffusion in a star](radiative-diffusion-in-a-star.md) carries most of the energy, rather than [convection](convection.md). Its formation in a [pre-main-sequence star](pre-main-sequence-star.md) breaks the fully convective assumption behind an idealized [Hayashi track](hayashi-track.md).
