# Elementary lower bound for the Chebyshev theta function

↑ **Parent:** [Chebyshev theta function](chebyshev-theta-function.md)

The [central binomial coefficient](central-binomial-coefficient.md) and [Legendre formula](legendre-s-formula.md) imply

$$
\vartheta(x)\geq\frac{x}{12}
$$

for every sufficiently large real number $x$.
