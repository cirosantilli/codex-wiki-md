# Irreducible object in a topos

↑ **Parent:** [Elementary topos](elementary-topos.md)

A noninitial object is irreducible, or supercompact, when every family of subobjects with union the whole object contains the whole object as one member. This concerns unions of subobjects rather than disjoint coproduct decompositions. [Irreducible representable sheaves for the regular coverage](irreducible-representable-sheaf-for-the-regular-coverage.md) follow from the one-arrow nature of that coverage.
