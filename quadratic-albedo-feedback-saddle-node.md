# Quadratic albedo feedback saddle-node

↑ **Parent:** [Climate feedback](climate-feedback.md)

A perturbation [energy balance](energy-balance.md) $\dot T\propto F-AT+BT^2$ with positive $A,B$ has a stable lower-temperature root and an unstable upper root for $F<A^2/(4B)$. They merge at $T=A/(2B)$; equality is marginal. Extrapolation of this local model is not an empirical runaway threshold for a real planet.
