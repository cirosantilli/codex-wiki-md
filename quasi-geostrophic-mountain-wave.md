# Quasi-geostrophic mountain wave

↑ **Parent:** [Three-dimensional quasi-geostrophic potential vorticity](three-dimensional-quasi-geostrophic-potential-vorticity.md)

A quasi-geostrophic mountain wave is a stationary [Rossby wave](rossby-wave.md) forced when a geostrophic basic flow crosses topography. Its vertical wavenumber is real only when the intrinsic Rossby-wave phase speed permits vertical propagation.
