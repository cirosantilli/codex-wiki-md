# Fatou set

↑ **Parent:** [Complex dynamics](complex-dynamics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fatou_set)

The Fatou set of a rational map is the largest open subset of the Riemann sphere on which its iterates form a [normal family](normal-family.md). Its complement is the [Julia set](julia-set.md).
