# Odd maps pull back the real tautological line bundle

↑ **Parent:** [Odd map between spheres](odd-map-between-spheres.md)

For an [odd map between spheres](odd-map-between-spheres.md) $f:S^n\to S^m$ and its quotient $\bar f$, there is an [isomorphism](isomorphism.md) $\gamma_n\cong\bar f^*\gamma_m$ of [real tautological line bundles](real-tautological-line-bundle.md). With $x$ a unit vector, send $t x$ to $t f(x)$; replacing $x$ by $-x$ and $t$ by $-t$ gives the same vector. This proves both linearity on fibers and well-definedness. Therefore $\bar f^*w_1(\gamma_m)=w_1(\gamma_n)$. The [mod-two cohomology ring of real projective space](mod-two-cohomology-ring-of-real-projective-space.md) then implies $n\leq m$, since a vanishing $(m+1)$st power must pull back to a vanishing power.
