# Finite-function collapse to countable size

↑ **Parent:** [Forcing](forcing-split.md)

For an infinite ground-model [cardinal number](cardinal-number.md) $\kappa$, use finite [partial functions](partial-function.md) from $\omega$ to $\kappa$, ordered by reverse inclusion. The union of a [generic filter](generic-filter.md) is a surjection $\omega\to\kappa$. The order has size $\kappa$, hence the $\kappa^+$-chain condition, and preserves cardinals at least $\kappa^+$.
