# Mirror segment phasing

↑ **Parent:** [Segmented mirror](segmented-mirror.md)

Phasing adjusts relative piston and tilt so adjacent segments form a continuous optical wavefront. Near normal reflection a surface piston changes [optical path length](optical-path-length.md) by twice that displacement.
