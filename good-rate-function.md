# Good rate function

↑ **Parent:** [Rate function](rate-function.md)

A [rate function](rate-function.md) is a [lower semicontinuous](lower-semicontinuity.md) map $I:E\to[0,\infty]$. It is good if every sublevel set $\{I\leq M\}$ is a [compact set](compact-space.md). This property controls escapes to infinity and makes the minimizations in the [contraction principle for large deviations](contraction-principle-for-large-deviations.md) attain their finite infima. On $\mathbb R^d$, a [lower semicontinuous](lower-semicontinuity.md) [rate function](rate-function.md) tending to infinity with the norm is good.
