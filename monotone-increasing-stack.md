# Monotone increasing stack

↑ **Parent:** [Monotone stack](monotone-stack.md)

A [monotone stack](monotone-stack.md) whose stored values are kept in increasing order from bottom to top. An implementation specifies whether equality is allowed; popping values greater than or equal to a new value leaves strictly increasing stored values.
