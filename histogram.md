# Histogram

↑ **Parent:** [Descriptive statistics](descriptive-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Histogram)

A histogram groups observations into bins and displays the bin counts or frequencies. For a [probability density function](probability-density-function.md) estimate, the height in a bin of width $\delta$ is its sample count divided by $n\delta$, so each bar's area is the observed relative frequency. This scaling ensures that the histogram integrates to one.
