# Level surface

↑ **Parent:** [Level set](level-set.md)

A [level set](level-set.md) of a real-valued function on three-dimensional space. Where the function is continuously differentiable and its [gradient](gradient.md) is nonzero, the [regular level set theorem](regular-level-set-theorem.md) makes this a smooth surface with [normal vector](normal-vector.md) parallel to the gradient. The equation alone can also have singular points, or fail to describe a two-dimensional surface at all.
