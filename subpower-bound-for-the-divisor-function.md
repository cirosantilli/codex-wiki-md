# Subpower bound for the divisor function

↑ **Parent:** [Divisor function](divisor-function.md)

For each $\eta>0$, the [divisor function](divisor-function.md) satisfies the displayed bound. Write $n=\prod p^{a_p}$, so $\tau(n)=\prod(a_p+1)$. For all sufficiently large [primes](prime-number.md), $a+1\le2^a\le p^{\eta a}$ for every $a\ge0$. For each of the finitely many smaller [primes](prime-number.md), $\sup_{a\ge0}(a+1)p^{-\eta a}$ is finite. Multiplying these finitely many constants proves the bound. Products of a fixed number of divisor functions obey the same conclusion after reducing $\eta$.
