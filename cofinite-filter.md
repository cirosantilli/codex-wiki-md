# Cofinite filter

↑ **Parent:** [Filter (set theory)](filter-set-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cofinite_filter)

The cofinite filter on an infinite set consists of all subsets whose complements are finite.
