# Auction

↑ **Parent:** [Mechanism design](mechanism-design.md)

An auction allocates goods using submitted messages and a specified payment rule. [Private-value auctions](private-value-auction.md) model each bidder's valuation as its own private information. Equilibrium bids depend on the allocation and payment rules, not only on valuations.
