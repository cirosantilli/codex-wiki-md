# Generalized phi coefficient

↑ **Parent:** [Contingency table](contingency-table.md)

For a [contingency table](contingency-table.md) with [Pearson chi-squared statistic](pearson-chi-squared-statistic.md) $X^2$ and [sample size](sample-size.md) $n>0$, the nonnegative magnitude $\phi=\sqrt{X^2/n}$ is sometimes reported as generalized phi. It does not encode an ordinal direction. In a two-row or two-column table it coincides with [Cramér's V](cramer-s-v.md); in larger tables it can exceed one, so the normalization in [Cramér's V](cramer-s-v.md) matters. In a two-by-two table it is the absolute value of the Pearson correlation coefficient of binary category indicators; a signed binary phi requires a stated coding convention.
