# No information without disturbance

↑ **Parent:** [Measurement in quantum mechanics](quantum-measurement-split.md)

If a [quantum instrument](quantum-instrument.md) leaves every input state unchanged even after conditioning on its classical output, then its output distribution is independent of the input state. Thus an ordinary quantum process cannot learn arbitrary state information while preserving every state.
