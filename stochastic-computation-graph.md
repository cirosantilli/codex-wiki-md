# Stochastic computation graph

↑ **Parent:** [Probabilistic programming](probabilistic-programming.md)

A [stochastic computation graph](stochastic-computation-graph.md) is a [Directed acyclic graph](directed-acyclic-graph.md) combining deterministic transformations, random choices and costs. The changing [probabilities](probability.md) of random choices contribute [score-function gradient estimators](score-function-gradient-estimator.md), while differentiable deterministic paths contribute [pathwise gradients](reparameterization-gradient.md). This accounts for both sources of a parameter's effect on an expected cost.[Sections 2–3](gradient-estimation-using-stochastic-computation-graphs-by-john-schulman-and-others.md)
