# Phi meson

↑ **Parent:** [Vector meson](vector-meson.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Phi_meson)

A neutral [vector meson](vector-meson.md) of spin-parity $1^-$, predominantly $s\bar s$ in the ideal quark-flavour description. A pseudoscalar decaying to this meson and a [pion](pion.md) requires relative orbital angular momentum one if total angular momentum is zero.
