# Matrix bandwidth

↑ **Parent:** [Sparse matrix](sparse-matrix.md)

The bandwidth in this convention is the largest distance from the main diagonal of a nonzero [matrix](matrix.md) entry. A symmetric positive-definite [matrix](matrix.md) of bandwidth $b$ can be factored using $O(Nb^2)$ operations and $O(Nb)$ storage; its [Cholesky decomposition](cholesky-decomposition.md) does not introduce entries outside that band. A variable permutation changes bandwidth, so it is a property of both the sparsity pattern and its ordering.
