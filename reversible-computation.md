# Reversible computation

↑ **Parent:** [Turing machine](turing-machine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reversible_computation)

A reversible computation has an injective transition function, so its preceding configuration can be recovered from its current configuration. Any finite classical computation can be simulated reversibly while retaining enough workspace to [uncompute](uncomputation.md) its temporary results.
