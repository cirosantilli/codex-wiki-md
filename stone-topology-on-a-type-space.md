# Stone topology on a type space

↑ **Parent:** [Type space](type-space.md)

For a [type space](type-space.md) $S_n^M(A)$, the basic open set $[\varphi]$ consists of complete types containing the formula $\varphi$. These sets are clopen, satisfy $[\varphi]\cap[\psi]=[\varphi\wedge\psi]$, and distinguish distinct types. The [compactness theorem](compactness-theorem.md) makes this topology compact; it is Hausdorff and has a basis of clopen sets.
