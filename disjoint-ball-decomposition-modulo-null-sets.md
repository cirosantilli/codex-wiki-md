# Disjoint ball decomposition modulo null sets

↑ **Parent:** [Wiener covering lemma](wiener-covering-lemma.md)

Every open set of finite [Lebesgue measure](lebesgue-measure.md) in Euclidean space is covered, up to a [null set](null-set.md), by countably many pairwise disjoint open balls contained in it. At each stage cover a compact subset of the open remainder, choose a packing with the [Wiener covering lemma](wiener-covering-lemma.md), and remove its closed balls. A fixed positive fraction of the remaining measure is removed each time, while sphere boundaries are null.
