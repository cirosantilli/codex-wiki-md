# Path in a transition system

↑ **Parent:** [Transition system](transition-system.md)

A finite or infinite [sequence](sequence.md) of [states](state-computer-science.md) in which $s_i\to s_{i+1}$ for each consecutive pair. In infinite-path [linear temporal logic](linear-temporal-logic.md) semantics, paths are infinite; an initial path must also start in the specified initial [set](set-split.md). Repeated [states](state-computer-science.md) are allowed, unlike conventions for a simple [path in a graph](path-in-a-graph.md).
