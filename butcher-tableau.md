# Butcher tableau

↑ **Parent:** [Runge-Kutta method](runge-kutta-method.md)

A Butcher tableau records a Runge-Kutta method's stage matrix $A$, nodes $c$, and output weights $b$ in the block array

$$
\begin{array}{c|c}c&A\\\hline&b^T\end{array}.
$$
