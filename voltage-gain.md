# Voltage gain

↑ **Parent:** [Electronic amplifier](electronic-amplifier.md)

The ratio of output to input [signal](signal.md) [electric potential difference](electric-potential-difference.md) for specified source and load conditions. A signed [voltage gain](voltage-gain.md) records whether the output reverses polarity; its value can depend on [frequency](frequency.md).
