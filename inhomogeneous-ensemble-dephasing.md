# Inhomogeneous ensemble dephasing

↑ **Parent:** [Dephasing channel](dephasing-channel.md)

Different ensemble members accumulating different deterministic [phases](phase-waves.md) can shorten their averaged [Bloch vector](bloch-vector.md) even when each member remains in a [pure state](pure-state.md). Averaging static [frequency](frequency.md) offsets gives an effective [dephasing channel](dephasing-channel.md). It need not represent irreversible [phase](phase-waves.md) loss in each individual system; an appropriate refocusing pulse can reverse static offsets. Changing offsets during the sequence requires a temporal noise model.
