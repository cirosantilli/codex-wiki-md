# Absoluteness of well-foundedness

↑ **Parent:** [Set-theoretic absoluteness](set-theoretic-absoluteness.md)

For a set relation in nested transitive models of [ZFC](zermelo-fraenkel-set-theory-with-choice.md), well-foundedness is absolute. An inner-model ordinal rank function witnesses upward absoluteness, and a fixed nonempty subset without a minimal member witnesses failure in both models.
