# Graph (topology)

↑ **Parent:** [CW complex](cw-complex.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Graph_(topology))

A topological graph is a [CW complex](cw-complex.md) with only zero-cells and one-cells, called vertices and edges. Edge endpoints attach to vertices; loops, multiple edges and infinitely many edges are allowed. A [subgraph](subgraph.md) in this setting is a [CW subcomplex](cw-subcomplex.md). A connected acyclic graph is a [tree](tree-graph-theory.md) and is a [contractible space](contractible-space.md).
