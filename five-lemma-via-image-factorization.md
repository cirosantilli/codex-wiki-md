# Five lemma via image factorization

↑ **Parent:** [Five lemma](five-lemma.md)

For commuting five-term [exact sequences](exact-sequence.md) in an [abelian category](abelian-category.md), the first vertical map being epic and the second invertible give an invertible induced map on the images entering the middle objects, because these images are the cokernels of the first horizontal maps. The fourth vertical map being invertible and the fifth monic similarly give an invertible map on the images leaving the middle objects, because these are the kernels of the last horizontal maps. The [image factorization in an abelian category](image-factorization-in-an-abelian-category.md) packages each middle object between these two images in a [short exact sequence](short-exact-sequence.md). The [short five lemma](short-five-lemma.md) then makes the middle vertical map invertible. The proof is categorical and does not require an embedding into a category of modules.
