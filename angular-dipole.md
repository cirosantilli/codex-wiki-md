# Angular dipole

↑ **Parent:** [Spherical harmonic](spherical-harmonic.md)

The angular dipole is the degree-one [spherical harmonic](spherical-harmonic.md) component. A real angular dipole is a function $\mathbf d\cdot\widehat{\mathbf n}$ for a fixed vector $\mathbf d$. Direction-dependent observer velocity and gravitational endpoint terms can therefore be discarded from higher-multipole calculations when they have this form.
