# Cayley transform of a Hermitian matrix

↑ **Parent:** [Operator theory](linear-operator-theory-split.md)

If $A$ is a [Hermitian matrix](hermitian-operator.md), then $(I+iA)^{-1}(I-iA)$ is [unitary](unitary-matrix.md). This Cayley transform maps each real eigenvalue $\lambda$ to the unit-modulus number $(1-i\lambda)/(1+i\lambda)$.
