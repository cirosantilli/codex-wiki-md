# Loop (topology)

↑ **Parent:** [Algebraic topology](algebraic-topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Loop_(topology))

A loop in a [topological space](topological-space.md) is a continuous map $\gamma:[0,1]\to X$ with $\gamma(0)=\gamma(1)$. Equivalently it is a map from the circle. A [based loop](based-loop.md) also specifies the common endpoint as a chosen base point.
