# Signed edge weights can prevent a shortest-path tree

↑ **Parent:** [Shortest-path tree](shortest-path-tree.md)

In a triangle with root $v$, assign $w(va)=w(vb)=2$ and $w(ab)=-1$. Among [graph paths](path-in-a-graph.md), the unique [shortest path](shortest-path.md) from $v$ to $a$ is $v,b,a$, and that from $v$ to $b$ is $v,a,b$, both of weight one. A [shortest-path tree](shortest-path-tree.md) would have to contain all three edges, impossible for a [tree](tree-graph-theory-split.md). The example uses shortest simple paths; arbitrary walks can have unboundedly negative weight by repeatedly traversing the negative edge.
