# Teleportation fidelity

↑ **Parent:** [Quantum teleportation](quantum-teleportation.md)

For a pure input target $|\psi\rangle$ and normalized output [density operator](density-matrix-split.md) $\rho_{\rm out}$, the displayed squared [quantum fidelity](fidelity-of-quantum-states.md) measures how well a teleportation channel reproduces that target. A mean value additionally specifies the input ensemble and whether it is conditioned on success. Detection efficiency, conditional fidelity, heralding and overall success [probability](probability.md) are distinct experimental quantities.
