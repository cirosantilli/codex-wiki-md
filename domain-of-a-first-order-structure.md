# Domain of a first-order structure

↑ **Parent:** [First-order structure](first-order-structure.md)

The underlying [set](set-split.md) of elements over which the [quantifiers](quantifier.md) of a [first-order structure](first-order-structure.md) range. Relation symbols are interpreted as [finitary relations](finitary-relation.md) on this [set](set-split.md), and function symbols as [functions](function-split.md) on it.
