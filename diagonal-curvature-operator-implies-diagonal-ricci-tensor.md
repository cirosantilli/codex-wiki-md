# Diagonal curvature operator implies diagonal Ricci tensor

↑ **Parent:** [Diagonal curvature operator](diagonal-curvature-operator.md)

If $\mathcal R^{ab}$ is proportional to $e^a\wedge e^b$ for every pair, then a curvature component can be nonzero only when its two index pairs describe the same coordinate two-plane. The contraction $R_{bd}=R^a{}_{bad}$ therefore vanishes for $b\ne d$, so the [Ricci tensor](ricci-tensor.md) is diagonal in the same frame.
