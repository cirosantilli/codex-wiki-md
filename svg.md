# SVG

↑ **Parent:** [Vector graphics](vector-graphics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/SVG)

[SVG](svg.md), short for [Scalable Vector Graphics](svg.md), is a markup [file format](file-format.md) for two-dimensional graphics, specified by the W3C SVG Working Group. It describes [vector graphics](vector-graphics.md) shapes, text and image objects, with grouping and transformations; it can therefore contain both geometric objects and [raster images](raster-graphics.md). The small command strings in [vector graphics](vector-graphics.md) are path data within this format, not complete standalone documents.[W3C SVG Working Group, SVG 2, section 1.1: scope, graphical objects and transformations](https://www.w3.org/TR/SVG2/intro.html#AboutSVG)
