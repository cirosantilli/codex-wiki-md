# Memory access trace

↑ **Parent:** [Memory reference](memory-reference.md)

An ordered [sequence](sequence.md) of [memory references](memory-reference.md), recording repetitions as well as addresses. The example under [memory cache](cache-computing.md) records twelve reads in decimal [physical addresses](physical-address.md); the trace itself does not determine [cache hits](cache-hit.md) until [cache line](cache-line.md) size, capacity, initial contents, placement and replacement are specified.
