# Shortest path

↑ **Parent:** [Shortest path problem](shortest-path-problem-split.md)

A [graph path](path-in-a-graph.md) of minimum total edge weight between its endpoints, among the permitted paths. In an unweighted graph, its weight is the number of edges. A shortest path need not be unique.
