# Repeated-root cosmological density mode

↑ **Parent:** [Linear density modes with polytropic pressure](linear-density-modes-with-polytropic-pressure.md)

When the characteristic exponents of the density-mode [Euler-Cauchy equation](euler-cauchy-equation.md) coincide, the second independent solution gains a logarithm. In the polytropic matter-era example the complete solution at this threshold is $t^{-1/6}(A+B\log t)$.
