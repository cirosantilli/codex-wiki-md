# FM modulation index

↑ **Parent:** [Frequency modulation](frequency-modulation.md)

For a message consisting of a single [sinusoid](sinusoid.md) with [frequency](frequency.md) $f_m>0$, the FM modulation index is $\beta=\Delta f/f_m$. It is dimensionless and equals the peak [wave phase](phase-waves.md) excursion in [radians](radian.md) in the chosen sine-phase convention. Keeping $\Delta f=5\,\mathrm{Hz}$ while changing $f_m$ from $1$ to $2\,\mathrm{Hz}$ reduces $\beta$ from $5$ to $2.5$: the same [frequency deviation](frequency-deviation.md) acts for a shorter portion of each message cycle. A general message containing many [frequencies](frequency.md) does not have a single $f_m$ with this meaning.
