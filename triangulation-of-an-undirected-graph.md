# Triangulation of an undirected graph

↑ **Parent:** [Chordal graph](chordal-graph.md)

Triangulation adds fill edges to an undirected [graph](graph-split.md) to make it a [chordal graph](chordal-graph.md). Given an elimination ordering, join all remaining neighbors of each removed vertex. The completed graph has that [perfect elimination ordering](perfect-elimination-ordering.md). Fill edges can enlarge the [cliques](clique-graph-theory.md) used for exact [probabilistic graphical model](probabilistic-graphical-model.md) inference, without changing the original probability factors; they do not assert new biological relationships.
