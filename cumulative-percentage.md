# Cumulative percentage

↑ **Parent:** [Frequency table](frequency-table.md)

The sum of category percentages up to a specified position in an ordering. It has a substantive interpretation for an [ordinal categorical variable](ordinal-categorical-variable.md); the cumulative percentage of an arbitrarily ordered [nominal categorical variable](nominal-categorical-variable.md) changes when the labels are reordered.
