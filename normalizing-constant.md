# Normalizing constant

↑ **Parent:** [Probability density function](probability-density-function.md)

A [normalizing constant](normalizing-constant.md) makes a nonnegative integrable [function](function-split.md) into a [probability density function](probability-density-function.md): if $0<Z=\int h<\infty$, then $h/Z$ is a [probability density function](probability-density-function.md).
