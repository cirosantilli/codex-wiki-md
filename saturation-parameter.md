# Saturation parameter

↑ **Parent:** [Two-level system](two-level-system.md)

For a specified optical transition, the on-resonance [saturation parameter](saturation-parameter.md) is the [light intensity](light-intensity.md) divided by the [saturation intensity](saturation-intensity.md). The independent-beam [Doppler cooling force](doppler-cooling-force.md) model assumes weak total excitation and defines $s$ separately for each beam.
