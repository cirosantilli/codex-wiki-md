# Metacognitive monitoring

↑ **Parent:** [Metacognition](metacognition.md)

Estimating aspects of one's own [cognition](cognition.md), such as whether an answer is correct or whether material can later be recalled. [Metacognitive monitoring](metacognitive-monitoring.md) should be distinguished from [metacognitive control](metacognitive-control.md), which changes behaviour in response to such estimates.
