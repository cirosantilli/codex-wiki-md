# Goodstein function

↑ **Parent:** [Goodstein sequence](goodstein-sequence.md)

The [Goodstein function](goodstein-function.md) records the least step at which the [Goodstein sequence](goodstein-sequence.md) from a given initial number reaches zero. With the initial step numbered zero, its values on $0,1,2,3$ are $0,1,3,5$. [Goodstein's theorem](goodstein-s-theorem.md) makes this effective termination-time [function](function-split.md) total.
