# Junction-tree sum-product message

↑ **Parent:** [Junction tree](junction-tree.md)

Assign each factor exactly once to a containing [clique](clique-graph-theory.md) and multiply the factors there into $\psi_i$. The displayed [sum-product belief propagation](sum-product-belief-propagation.md) message sums out variables of $C_i$ outside the separator $S_{ij}=C_i\cap C_j$. By the [running intersection property](running-intersection-property.md), eliminating all variables in the subtree on the $i$ side creates precisely this function of the separator. An inward pass computes the [normalizing constant](normalizing-constant.md) at the root; an outward pass produces [marginal distributions](marginal-distribution.md). For [pedigree likelihoods](pedigree-likelihood.md), observed genotypes and [penetrance](penetrance.md) factors simply multiply the relevant potentials.
