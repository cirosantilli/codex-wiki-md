# Thermally damped quasi-geostrophic mountain wave

↑ **Parent:** [Quasi-geostrophic mountain wave](quasi-geostrophic-mountain-wave.md)

Thermal damping makes the vertical wavenumber of a stationary topographic [Rossby wave](rossby-wave.md) complex. A vertically propagating wave then decays while oscillating, whereas an inviscidly evanescent disturbance acquires both decay and phase tilt; both can exert wave drag.
