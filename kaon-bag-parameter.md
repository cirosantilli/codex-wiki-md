# Kaon bag parameter

↑ **Parent:** [Charged weak box contribution to kaon mixing](charged-weak-box-contribution-to-kaon-mixing.md)

For relativistically normalized [kaon](kaon.md) states and $Q=(\bar s\gamma_\mu(1-\gamma^5)d)(\bar s\gamma^\mu(1-\gamma^5)d)$, define $\langle\bar K^0|Q|K^0\rangle=(8/3)f_K^2m_K^2B_K$. The dimensionless kaon bag parameter measures [strong interaction](strong-interaction.md) corrections to the vacuum-insertion normalization. The coefficient and [matrix element](matrix-element.md) must be defined in the same [renormalization scheme](renormalization-scheme.md) and at the same scale. Dividing by $2m_K$ gives the corresponding two-state mixing-Hamiltonian normalization.
