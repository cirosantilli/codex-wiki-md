# Dirichlet spectrum with inverse-square weight

↑ **Parent:** [Logarithmic change of variable in a Sturm-Liouville problem](logarithmic-change-of-variable-in-a-sturm-liouville-problem.md)

For $-y''=\lambda x^{-2}y$ on $1<x<e^\ell$ with zero endpoint values, the natural [weighted inner product](weighted-inner-product.md) has measure $dx/x^2$. Set $v=\ln x$ and $y(x)=\sqrt x\,Z(v)$. The [chain rule](chain-rule.md) gives $x^2y''=\sqrt x(Z''-Z/4)$, so $-Z''+Z/4=\lambda Z$ with zero endpoints on $(0,\ell)$. Moreover $|y|^2dx/x^2=|Z|^2dv$, so the transformation preserves the norm. The ordinary sine [orthonormal eigenbasis](orthonormal-eigenbasis.md) therefore gives exactly the displayed spectrum and eigenfunctions for $n\geq1$. The factor $\sqrt x$ and the additive $1/4$ distinguish this problem from the operator $-x^2y''-xy'$ with measure $dx/x$.
