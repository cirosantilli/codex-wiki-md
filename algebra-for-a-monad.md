# Algebra for a monad

↑ **Parent:** [Monad](monad.md)

An algebra for a monad $(T,\eta,\mu)$ is an object $A$ with a morphism $a:TA\to A$ satisfying $a\eta_A=1_A$ and $aT(a)=a\mu_A$.
