# Leading principal minor

↑ **Parent:** [Principal minor](principal-minor.md)

A [leading principal minor](leading-principal-minor.md) is a [principal minor](principal-minor.md) using the first $k$ rows and columns of a square [matrix](matrix.md) in a specified ordering. [Sylvester's criterion](sylvester-s-criterion.md) uses these minors to characterize [positive-definite matrices](positive-definite-matrix.md).
