# Intrusive memory

↑ **Parent:** [Memory retrieval](memory-retrieval.md)

An involuntarily occurring [memory](memory-in-animals.md) or memory-like impression. Frequency, sensory content, [distress](distress.md) and sense of present occurrence should be assessed separately; an intrusion is not automatically a literal replay.
