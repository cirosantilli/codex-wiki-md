# Penning trap

↑ **Parent:** [Ion trap](ion-trap.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Penning_trap)

A Penning trap uses a static [electric quadrupole](electric-quadrupole.md) field for axial confinement and a static axial [magnetic field](magnetic-field-split.md) for transverse confinement. The [Lorentz force](lorentz-force.md) bends a moving [electric charge](electric-charge-split.md)'s trajectory without doing work. An RF probe may interrogate a trapped particle, but an RF confining voltage is unnecessary in this ideal model. This makes the [Penning trap](penning-trap.md) useful for relating [cyclotron frequencies](cyclotron-frequency.md) and [spin](spin.md) precession to a common [magnetic field](magnetic-field-split.md).
