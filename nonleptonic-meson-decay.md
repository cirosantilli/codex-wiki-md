# Nonleptonic meson decay

↑ **Parent:** [Particle decay](particle-decay.md)

A [nonleptonic meson decay](nonleptonic-meson-decay.md) contains final [hadrons](hadron.md) and no final [leptons](lepton.md). Weak quark transitions set flavour factors, but strong [hadronization](hadronization.md) and additional hadronic matrix elements are needed to determine exclusive rates.
