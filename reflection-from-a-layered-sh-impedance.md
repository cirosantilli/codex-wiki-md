# Reflection from a layered SH impedance

↑ **Parent:** [Uniform-layer SH impedance update](uniform-layer-sh-impedance-update.md)

Set the lower [half-space](half-space.md) load to $q_b=\mu_bp_{\beta,b}$ using the [causal vertical wavenumber branch](causal-vertical-wavenumber-branch.md), which excludes a wave arriving from depth infinity. Apply the [uniform-layer SH impedance update](uniform-layer-sh-impedance-update.md) upwards through every layer, keeping particle [velocity](velocity.md) and [traction](traction.md) continuous. For upper [half-space](half-space.md) impedance $q_a$, incident [velocity](velocity.md) $V_0$ and reflected [velocity](velocity.md) $RV_0$, the top values are $V=V_0(1+R)$ and $T=-q_aV_0(1-R)$. Their ratio gives the displayed [reflection coefficient](reflection-coefficient.md), incorporating every underlying interface and multiple reflection.
