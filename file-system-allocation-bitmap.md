# File-system allocation bitmap

↑ **Parent:** [File system](file-system.md)

A [data structure](data-structure.md) using a [bit](bit.md) per allocation unit to mark whether it is available. Its agreement with ownership references is a [file-system crash consistency](file-system-crash-consistency.md) requirement; changing just this structure does not install the owner's update.
