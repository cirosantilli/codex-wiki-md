# Derivative of a map into a level set

↑ **Parent:** [Differentiable map](differentiable-map.md)

If a [differentiable map](differentiable-map.md) $F$ takes values in a level set of a differentiable scalar function $H$, the [chain rule](chain-rule.md) gives $DH_{F(x)}DF_x=0$. At a regular point, the image of the [derivative](derivative.md) lies in the kernel of the nonzero covector $DH$: the tangent space of the level set. For a map into the unit circle this forces rank at most one.
