# Epidemic extinction

↑ **Parent:** [Stochastic SIR model](stochastic-sir-model.md)

An epidemic reaches an absorbing state when no infected individuals remain and there is no external source of infection. Extinction time differs from a simulation horizon at which infected individuals are still present.
