# Residual maximum flow is the remaining optimality gap

↑ **Parent:** [Residual network](residual-network.md)

For an undirected capacitated network, write the net edge flow as $y_{ij}=-y_{ji}$, and the directed residual capacity as $c_{ij}-y_{ij}$. On every source–sink cut, residual capacity is the original cut capacity minus the current net flow value $f$. Taking the minimum over cuts and applying the [max-flow min-cut theorem](max-flow-min-cut-theorem.md) to each network gives the displayed remaining-flow identity.
