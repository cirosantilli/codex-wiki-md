# Hamiltonian group action

↑ **Parent:** [Symplectic geometry](symplectic-geometry-split.md)

A Hamiltonian group action is a [Lie group action](lie-group-action.md) on a [symplectic manifold](symplectic-manifold.md) with an equivariant [moment map](moment-map.md) $\mu:M\to\mathfrak g^*$. In the sign convention $\iota_{X_H}\omega=dH$, each component satisfies $d\langle\mu,X\rangle=\iota_{X_M}\omega$, where $X_M$ is the [fundamental vector field](fundamental-vector-field.md). The opposite [Hamiltonian vector field](hamiltonian-vector-field.md) convention reverses the sign.
