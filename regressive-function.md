# Regressive function

↑ **Parent:** [Stationary set](stationary-set.md)

A function on a set of ordinals with $f(\alpha)<\alpha$ at every nonzero point of its domain. On a stationary subset of a regular uncountable cardinal, [Fodor lemma](fodor-lemma.md) makes it constant on a stationary subset.
