# Stack invariant

↑ **Parent:** [Stack (data structure)](stack-data-structure.md)

A property of the evaluation [stack](stack-data-structure.md) at a specified program point. For expression [compilation](compilation.md), a useful contract is that generated code transforms any incoming [stack](stack-data-structure.md) $\sigma$ into $\sigma,v$, leaving all pre-existing values unchanged. For a statement, a useful contract is preservation of $\sigma$.
