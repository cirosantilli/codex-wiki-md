# Hardware timer

↑ **Parent:** [Digital counter](digital-counter.md)

A [hardware timer](hardware-timer.md) uses a [clock signal](clock-signal.md) to measure intervals, commonly by a [digital counter](digital-counter.md) with capture or comparison facilities. A comparison event can request an [interrupt](interrupt.md) or change an output directly. Counter resolution, wraparound, [interrupt](interrupt.md) latency and the hardware's comparison semantics determine the timing guarantees available to software.
