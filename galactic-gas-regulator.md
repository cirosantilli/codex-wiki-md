# Galactic gas regulator

↑ **Parent:** [Galaxy evolution](galaxy-evolution.md)

A gas-budget model in which inflow competes with [star formation](star-formation.md), gas return and outflows. A zero instantaneous gas derivative defines a balance [nullcline](nullcline.md); it need not define a [fixed point](fixed-point.md) of the evolving stellar and black-hole masses.
