# Countable infinitary logic

↑ **Parent:** [Infinitary language](infinitary-language.md)

The logic $L_{\omega_1,\omega}$ extends [first-order logic](first-order-logic.md) by countable [logical conjunctions](logical-conjunction.md) and [logical disjunctions](logical-disjunction.md). Each formula has finitely many [free variables](free-variable.md), and quantifier strings are finite. In a countable [first-order language](first-order-language.md), every countable structure has a [Scott sentence](scott-sentence.md) in this logic that characterizes its [isomorphism](isomorphism.md) class among countable structures.
