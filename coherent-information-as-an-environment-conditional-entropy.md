# Coherent information as an environment conditional entropy

↑ **Parent:** [Coherent information](coherent-information.md)

Purify the input on $RA$ and dilate a channel by $A\to BE$. The joint state $RBE$ is pure, so complementary entropies obey $S(B)=S(RE)$ and $S(RB)=S(E)$. Therefore [coherent information](coherent-information.md) is $I_c=S(B)-S(RB)=S(R\mid E)=-S(R\mid B)$. The positive environment conditional entropy and negative receiving-system conditional entropy are two equivalent forms.
