# Sliding-window algorithm

↑ **Parent:** [Algorithm](algorithm-split.md)

An [algorithm](algorithm-split.md) that maintains information about a contiguous part of a [sequence](sequence.md) while moving its endpoints. Updating a fixed-length window [sum](sum.md) needs subtraction of the outgoing term and [addition](addition.md) of the incoming term. A window [product](product-of-numbers.md) can be updated by [division](division-mathematics.md) only when the outgoing factor is nonzero; zero counts or zero-free segments handle that exception.
