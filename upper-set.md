# Upper set

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Upper_set)

A [subset](subset.md) $U$ of a [partially ordered set](partially-ordered-set.md) is an [upper set](upper-set.md) when $x\in U$ and $x\leq y$ imply $y\in U$. The upward closure $\uparrow A=\{y:\exists a\in A,\ a\leq y\}$ is the smallest [upper set](upper-set.md) containing $A$. Both [union](set-union.md) and [intersection](set-intersection.md) preserve this property.
