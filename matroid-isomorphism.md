# Matroid isomorphism

↑ **Parent:** [Matroid](matroid.md)

A [matroid isomorphism](matroid-isomorphism.md) between $(E,\mathcal I)$ and $(E',\mathcal I')$ is a [bijection](bijection.md) $\phi$ such that $I\in\mathcal I$ if and only if $\phi(I)\in\mathcal I'$. It relabels the [ground set](ground-set.md) without changing independence. The number of labelled [matroids](matroid.md) therefore differs from the number of types up to [matroid isomorphism](matroid-isomorphism.md).
