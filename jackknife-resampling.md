# Jackknife resampling

↑ **Parent:** [Statistical inference](statistical-inference-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Jackknife_resampling)

[Jackknife resampling](jackknife-resampling.md) recalculates a [statistic](statistic.md) after removing each observation in turn. Comparing these leave-one-out values estimates the sensitivity of the [statistic](statistic.md), leading to [Jackknife bias correction](jackknife-bias-correction.md) and a [Jackknife variance estimator](jackknife-variance-estimator.md).
