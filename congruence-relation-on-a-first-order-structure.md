# Congruence relation on a first-order structure

↑ **Parent:** [Equivalence relation](equivalence-relation.md)

A [congruence relation on a first-order structure](congruence-relation-on-a-first-order-structure.md) is an [equivalence relation](equivalence-relation.md) compatible with each interpreted [function](function-split.md) and relation. Equivalent input [tuples](finite-tuple.md) give equivalent [function](function-split.md) outputs, and an [atomic relation](atomic-formula.md) has the same [truth value](truth-value.md) on equivalent input [tuples](finite-tuple.md). This compatibility makes the [functions](function-split.md) and relations well-defined on the [quotient set](quotient-set.md). In a Henkin [term model](term-model.md) with [equality](logical-equality.md), membership of a formal [equality](logical-equality.md) in the maximal [consistent](consistent-first-order-theory.md) theory gives precisely the [equivalence relation](equivalence-relation.md) used for this [quotient](quotient-set.md).
