# Deformable mirror

↑ **Parent:** [Adaptive optics](adaptive-optics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Deformable_mirror)

A deformable mirror changes its optical surface using an array of actuators. For reflection near normal incidence, surface displacement changes [optical path length](optical-path-length.md) by twice that displacement.
