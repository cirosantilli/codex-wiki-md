# Autonomous third-order reduction using the dependent variable

↑ **Parent:** [Ordinary differential equation](ordinary-differential-equation.md)

An [autonomous differential equation](autonomous-system-mathematics.md) for $f(\eta)$ can be reduced by one order on a monotone solution branch by using $f$ as the new independent variable. Setting $G(f)=df/d\eta$ and applying the [chain rule](chain-rule.md) gives the displayed [derivative](derivative.md) identities. The absence of explicit $\eta$ dependence makes the resulting equation involve only $f,G$ and [derivatives](derivative.md) of $G$. A point with $G=0$ is singular for this coordinate change; for example $f\sim b\eta^2/2$ gives $G\sim\sqrt{2bf}$ on an appropriate branch, so $G_f$ need not remain finite there.
