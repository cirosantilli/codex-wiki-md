# Superfluid velocity

↑ **Parent:** [Superfluid](superfluid.md)

For a condensate $\psi=\sqrt n e^{iS}$ with kinetic operator $-\hbar^2\nabla^2/(2m)$, its particle current is $n\mathbf u$ with the displayed [velocity](velocity.md). This follows by subtracting the [Gross–Pitaevskii equation](gross-pitaevskii-equation.md) from its [complex conjugate](complex-conjugate.md). More generally, in units where the kinetic operator is $-D\nabla^2$, the current [velocity](velocity.md) is $2D\nabla S$. The [complex argument](argument-complex-analysis.md) [gradient](gradient.md) and current [velocity](velocity.md) coincide only when $D=1/2$.
