# Acceptance by final state

↑ **Parent:** [Pushdown automaton](pushdown-automaton.md)

A [pushdown automaton](pushdown-automaton.md) accepts a [word](string.md) if some finite run consumes all its input and reaches a designated final control state, regardless of the remaining [stack](stack-data-structure.md) contents. Reaching a final control state while leaving unread input is insufficient.
