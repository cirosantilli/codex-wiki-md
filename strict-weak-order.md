# Strict weak order

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

An irreflexive transitive comparison whose induced incomparability relation is transitive. Incomparability is then an [equivalence relation](equivalence-relation.md), and its classes are totally ordered by the comparison. A comparison-based [sorting algorithm](sorting-algorithm.md) can treat incomparable elements as ties; a [merge algorithm](merge-algorithm.md) that takes from the left input on ties preserves [stable sorting](stable-sorting.md). Ordinary ordering on [real numbers](real-number.md) is an example; machine NaN values require separate handling.
