# Silent substitution

↑ **Parent:** [Colorimetry](colorimetry.md)

A stimulus manipulation designed to vary one receptor class while holding others approximately fixed. With a calibrated primary-to-receptor [matrix](matrix.md) $B$, solve for primary changes producing a specified catch change, respecting baseline and [gamut](gamut.md) constraints. Observer variation, calibration error and unintended receptor inputs can limit isolation.
