# Supernova calibration and population tests

↑ **Parent:** [Type Ia supernova cosmology](type-ia-supernova-cosmology.md)

The [High-Z Supernova Search Team](high-z-supernova-search-team.md) analysis fitted multicolour [light curves](light-curve.md) and [interstellar extinction](interstellar-extinction.md), and compared a second decline-rate method. Similar local and distant [spectroscopy](spectroscopy.md) supported, but did not establish, population stability. Nearly colourless attenuation remained a qualified alternative.[Sections 3.2, 5.1–5.2: multicolour fits, evolution, grey dust](observational-evidence-from-supernovae-for-an-accelerating-universe-and-a-cosmological-constant-by-adam-riess-and-others.md)

The [Supernova Cosmology Project](supernova-cosmology-project.md) compared low- and high-[redshift](redshift.md) colours, removed red outliers in its primary fit, and tested [Malmquist bias](malmquist-bias.md) with artificial-source recovery.[Sections 4.1–4.2: colours, subsamples, artificial-source selection tests](measurements-of-omega-and-lambda-from-42-high-redshift-supernovae-by-saul-perlmutter-and-others.md)

The inference can be organized as a chain of independently testable failure modes. A [magnitude zero point](magnitude-zero-point.md) offset between nearby and distant observations imitates a [distance modulus](distance-modulus.md) offset; a common offset instead changes the intercept. An erroneous [photometric passband](photometric-passband.md) response changes a [K correction](k-correction.md) in a [redshift](redshift.md)-dependent way because different emitted [wavelengths](wavelength.md) cross the detector band. Residual host-[galaxy](galaxy-split.md) light changes the recovered [radiative flux](radiative-flux.md). [Color excess](color-excess.md) constrains wavelength-dependent [interstellar extinction](interstellar-extinction.md) only after intrinsic colour is modeled; grey attenuation is not bounded by colour alone. Changes in [stellar population](stellar-population.md) or [metallicity](metallicity.md) could shift standardized [absolute magnitude](absolute-magnitude.md) without large changes in the chosen shape parameter. These are logical degeneracies, so increasing the sample size alone cannot remove them.

A useful control strategy therefore compares subsets with different host environments, fits consistent rest-frame [photometric passbands](photometric-passband.md), and checks artificial-source recovery through the same image processing and selection. A [Malmquist bias](malmquist-bias.md) tends to select brighter detectable sources, but the relative bias between the nearby and distant samples is what matters. [Peculiar velocity](peculiar-velocity.md) mainly perturbs the nearby [redshift](redshift.md) anchor; [weak gravitational lensing](weak-gravitational-lensing.md) changes individual brightnesses and the selection distribution. Neither can be replaced by an arbitrary extra scatter term when its mean or selection dependence is uncertain.
