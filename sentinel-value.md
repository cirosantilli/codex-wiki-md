# Sentinel value

↑ **Parent:** [Data structure](data-structure-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sentinel_value)

A distinguished value marking a boundary or special condition, such as the end of an input [sequence](sequence.md). It must be distinguishable from every ordinary data value.
