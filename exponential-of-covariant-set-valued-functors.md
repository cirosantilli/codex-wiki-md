# Exponential of covariant set-valued functors

↑ **Parent:** [Exponential object](exponential-object.md)

For a [small category](small-category.md), this formula defines the [exponential object](exponential-object.md) in its covariant set-valued [functor category](functor-category.md). An arrow $c\to d$ acts by precomposition with $\mathcal C(d,-)\to\mathcal C(c,-)$. Evaluation applies a natural transformation to $(1_c,z)$; currying a map $P\times G\to H$ sends $p\in P(c)$ to the transformation $(f,z)\mapsto\theta(P(f)p,z)$. The formulas prove the universal property directly, without an adjoint existence theorem.
