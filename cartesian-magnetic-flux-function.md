# Cartesian magnetic flux function

↑ **Parent:** [Ideal magnetohydrodynamic induction equation](ideal-magnetohydrodynamic-induction-equation.md)

For a $y$-independent solenoidal [magnetic field](magnetic-field.md), the transverse components can be written $B_x=-\psi_z$ and $B_z=\psi_x$. Contours of $\psi$ are transverse [magnetic field lines](magnetic-field-line.md). The independent axial component $B_y$ can twist the [flux tube](flux-tube.md). Under the [MHD induction equation](ideal-magnetohydrodynamic-induction-equation.md), an additive time-dependent gauge can be chosen so that $D\psi/Dt=0$.
