# Scaling invariance of SLE

↑ **Parent:** [Schramm–Loewner evolution](schramm-loewner-evolution.md)

For every $a>0$, if $(K_t)$ is $\operatorname{SLE}_\kappa$, then $(a^{-1}K_{a^2t})$ has the same law. Its driving function is $a^{-1}U_{a^2t}$, which has the same law as $U_t$ by [Brownian scaling](brownian-scaling.md).
