# Removable node of a Young diagram

↑ **Parent:** [Young diagram](young-diagram.md)

A removable node is a cell whose deletion leaves a [Young diagram](young-diagram.md). The set $\lambda^-$ consists of the distinct partitions obtained by deleting one removable node from $\lambda$.
