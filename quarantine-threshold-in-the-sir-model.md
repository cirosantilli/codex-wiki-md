# Quarantine threshold in the SIR model

↑ **Parent:** [Quarantine](quarantine.md)

Before isolation, the closed [SIR model](sir-model.md) has [first integral](first-integral-of-an-ordinary-differential-equation.md) $I+S-(a/r)\log S$. If [quarantine](quarantine.md) occurs at the first crossing $I=I_*$, the corresponding [susceptible](susceptible-individual.md) count $S_*$ is the [root](root-of-a-polynomial.md) on the outbreak branch of $I_*+S_*-(a/r)\log S_*=I_0+S_0-(a/r)\log S_0$. Immediate prevention of further transmission makes the number [infected](infectious-disease.md) among the initial [susceptible](susceptible-individual.md) class equal to $S_0-S_*$.
