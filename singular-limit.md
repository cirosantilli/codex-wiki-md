# Singular limit

↑ **Parent:** [Singular perturbation](singular-perturbation-split.md)

A [singular limit](singular-limit.md) is a parameter limit in which the governing problem loses an order, changes type, or otherwise changes its qualitative solution structure. For $\varepsilon\dot x=F(x,y)$, setting $\varepsilon=0$ produces the algebraic constraint $F(x,y)=0$ and can omit fast transients required by the initial data.
