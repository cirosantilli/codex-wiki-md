# Ramp reference signal

↑ **Parent:** [Reference signal](reference-signal.md)

A [ramp reference signal](ramp-reference-signal.md) changes at a constant rate $v$ from $t=0$ onward. Its [derivative](derivative.md) is $v$ for $t>0$. A [ramp reference signal](ramp-reference-signal.md) tests whether a [controller](controller-control-theory.md) can keep following a moving goal, rather than merely reaching a fixed one; a finite [steady-state tracking error](steady-state-tracking-error.md) can coexist with an unbounded [reference signal](reference-signal.md).
