# Noncongruent primes congruent to three modulo eight

↑ **Parent:** [Congruent number](congruent-number.md)

For a [prime](prime-number.md) $p\equiv3\pmod8$, apply [two-isogeny descent](two-isogeny-descent.md) to the [congruent number elliptic curve](congruent-number-elliptic-curve.md) $y^2=x^3-p^2x$ and its companion $y^2=x^3+4p^2x$. The first square-class image is exactly $\{1,-1,p,-p\}$, already supplied by [2-torsion](2-torsion.md). The second has only positive candidates $1,2,p,2p$. The [quartic covering in a two-isogeny descent](quartic-covering-in-a-two-isogeny-descent.md) equations for $p$ and $2p$ are impossible modulo $p$, because $-1$ is not a [quadratic residue](quadratic-residue.md). For $2$ the equation is $W^2=2U^4+2p^2V^4$. Coprimality forces $U,V$ odd and $W=2Z$; modulo sixteen this gives $2Z^2=1+9=10$, which is impossible. Thus the second image is trivial and the [square-class index formula for two-isogeny descent](square-class-index-formula-for-two-isogeny-descent.md) gives rank zero. The same prime-reduction argument bounds its rational torsion by four, and it already has four rational [2-torsion](2-torsion.md) points, so it has no [rational point](rational-point.md) corresponding to a [right triangle](right-triangle.md) of area $p$.
