# Bers pants decomposition theorem

↑ **Parent:** [Pants decomposition](pants-decomposition.md)

For fixed $g\geq2$, a constant $B_g$ bounds all cuff lengths in some [pants decomposition](pants-decomposition.md) of every closed [genus](genus-of-a-surface.md)-$g$ [hyperbolic surface](hyperbolic-surface.md). Together with [Fenchel–Nielsen coordinates](fenchel-nielsen-coordinates.md) this implies [Mumford's compactness theorem](mumford-s-compactness-theorem.md).
