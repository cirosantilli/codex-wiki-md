# Reconstructing Vaidya mass from a radial null geodesic

↑ **Parent:** [Radial null geodesics of the Vaidya metric](radial-null-geodesics-of-the-vaidya-metric.md)

An outgoing [radial null geodesic of the Vaidya metric](radial-null-geodesics-of-the-vaidya-metric.md) prescribed as $r=r_0(v)$ determines the mass along that curve by $M(v)=r_0(v)(1-2r'_0(v))/2$. This inverse relation comes from the radial [null condition](null-condition.md). It determines a function of advanced time wherever the prescribed curve is differentiable and has positive radius.
