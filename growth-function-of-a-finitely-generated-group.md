# Growth function of a finitely generated group

↑ **Parent:** [Growth function of a discrete metric space](growth-function-of-a-discrete-metric-space.md)

For a [finitely generated group](finitely-generated-group.md) $G$ with finite generating set $S$, the growth function $\beta_{G,S}(r)$ is the number of group elements of [word metric](word-metric.md) distance at most $r$ from the identity. Different finite generating sets change its scale only by multiplicative constants.
