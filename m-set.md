# M-set

↑ **Parent:** [Monoid action](monoid-action.md)

An M-set is a set carrying a [monoid action](monoid-action.md). This terminology here uses left actions. Morphisms are [equivariant maps of monoid sets](equivariant-map-of-monoid-sets.md), and the resulting [functor category](functor-category.md) $[M,\mathbf{Set}]$ is an [elementary topos](elementary-topos.md).
