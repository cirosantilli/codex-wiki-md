# Compatibility constant

↑ **Parent:** [Compatibility condition for the Lasso](compatibility-condition-for-the-lasso.md)

For a positive-semidefinite matrix $\Sigma$, an active set $S$ of size $s$, and cone factor three, one compatibility constant is defined by

$$
\phi_\Sigma^2
=s\inf_{\|\delta_S\|_1=1,\,\|\delta_{S^c}\|_1\leq3}
\delta^T\Sigma\delta.
$$

It measures how strongly the quadratic form controls active-coordinate $\ell^1$ error on the [Lasso cone condition](lasso-cone-condition.md).
