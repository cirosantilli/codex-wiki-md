# What-where-when memory

↑ **Parent:** [Episodic-like memory](episodic-like-memory.md)

Retention of which event occurred at which place and at which time or temporal position. Separate success on content, location and timing tests does not establish that their particular conjunction was retained; [episodic binding](episodic-binding.md) is a stronger requirement.
