# Off-diagonal matrix entry

↑ **Parent:** [Matrix entry](matrix-entry.md)

A [matrix entry](matrix-entry.md) whose row and column indices differ. These entries lie outside the [diagonal matrix entries](diagonal-matrix-entry.md). A [diagonal matrix](diagonal-matrix.md) has all its [off-diagonal entries](off-diagonal-matrix-entry.md) equal to zero. Cancellation of these entries when averaging [density matrices](density-matrix-split.md) does not require the individual preparations to have zero entries there.
