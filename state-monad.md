# State monad

↑ **Parent:** [Computational monad](computational-monad.md)

A computation represented by a [function](function-split.md) from an initial [program state](program-state.md) to a result and a final [program state](program-state.md). Its sequencing passes each output [program state](program-state.md) to the next computation.
