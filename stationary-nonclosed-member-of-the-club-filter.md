# Stationary nonclosed member of the club filter

↑ **Parent:** [Club filter](club-filter.md)

For any regular uncountable [cardinal number](cardinal-number.md) $\kappa$, the set $\kappa\setminus\{\omega\}$ contains the final-segment [club set](club-set.md) $[\omega+1,\kappa)$, so belongs to the [club filter](club-filter.md) and is a [stationary set](stationary-set.md). It is not closed, since its finite ordinals have supremum $\omega$, which is missing.
