# CDK-activating kinase

↑ **Parent:** [CDK1 phosphorylation state](cdk1-phosphorylation-state.md)

A [CDK-activating kinase](cdk-activating-kinase.md) is a [protein kinase](protein-kinase.md) supplying activating [phosphorylation](phosphorylation.md) to a [cyclin-dependent kinase 1](cyclin-dependent-kinase-1.md) preparation. The [Xenopus laevis](xenopus-laevis.md) experiment above distinguished this activity from the catalytic activity of [Cdc2](cyclin-dependent-kinase-1.md) itself. [CAK](cdk-activating-kinase.md) names that function here, without asserting that every [species](species.md) uses the same [protein](protein-split.md) assembly.
