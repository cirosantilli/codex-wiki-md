# Stable I-filtration

↑ **Parent:** [I-adic filtration](i-adic-filtration.md)

An $I$-filtration $(M_n)$ is stable when $IM_n=M_{n+1}$ for all sufficiently large $n$. Every stable $I$-filtration is equivalent to the $I$-adic filtration.
