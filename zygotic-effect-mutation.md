# Zygotic-effect mutation

↑ **Parent:** [Mutation](mutation.md)

In an embryonic genetic analysis, a mutation whose developmental effect is assigned to the embryo's own [genotype](genotype.md), in contrast to a [maternal-effect mutation](maternal-effect-mutation.md). This usage does not assert when the sequence change first arose.
