# Unary constraint

↑ **Parent:** [Constraint satisfaction problem](constraint-satisfaction-problem.md)

A restriction on the value of one [variable](variable-mathematics.md). In a finite-domain [constraint satisfaction problem](constraint-satisfaction-problem.md), it can be applied by deleting disallowed values from that [variable](variable-mathematics.md)'s [constraint domain](constraint-domain.md) before search. It introduces no [edge](edge-of-a-graph.md) in the binary [constraint graph](constraint-graph.md).
