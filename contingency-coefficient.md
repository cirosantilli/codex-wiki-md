# Contingency coefficient

↑ **Parent:** [Contingency table](contingency-table.md)

The [contingency coefficient](contingency-coefficient.md) transforms the [Pearson chi-squared statistic](pearson-chi-squared-statistic.md) as $C=\sqrt{X^2/(X^2+n)}$. It is an unsigned measure of [statistical association](statistical-association.md), not a [p-value](p-value.md) or a direction of an ordinal relationship. Writing $\phi^2=X^2/n$ gives $C=\phi/\sqrt{1+\phi^2}$. Unlike [Cramér's V](cramer-s-v.md), its attainable maximum depends on table dimensions, so comparisons between differently sized tables need care.
