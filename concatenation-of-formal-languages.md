# Concatenation of formal languages

↑ **Parent:** [Formal language](formal-language.md)

For [formal languages](formal-language.md) $L,M$ over the same [alphabet](alphabet.md), concatenate each [word over an alphabet](string.md) in $L$ with each [word over an alphabet](string.md) in $M$. This operation is associative, has identity $\{\varepsilon\}$ and absorbing element the [empty language](empty-language.md).
