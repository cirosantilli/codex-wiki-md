# Spectrum of a finite-dimensional commutative algebra

↑ **Parent:** [Artinian ring](artinian-ring.md)

If $C$ is a commutative algebra of finite dimension over a [field](field.md) $K$, every [prime ideal](prime-ideal.md) is maximal and $|\operatorname{Spec}C|\leq\dim_KC$. Indeed, the quotient by a prime is a finite-dimensional [integral domain](integral-domain.md). Multiplication by any nonzero element is an [injective](injective-function.md) linear [endomorphism](endomorphism.md), hence [surjective](surjective-function.md), so the quotient is a [field](field.md). Distinct [maximal ideals](maximal-ideal.md) are pairwise comaximal. For any finite list $\mathfrak m_1,\ldots,\mathfrak m_r$, construct $e_i\equiv1\pmod{\mathfrak m_i}$ and $e_i\equiv0\pmod{\mathfrak m_j}$ for $j\ne i$ by multiplying elements in $\mathfrak m_j$ congruent to one modulo $\mathfrak m_i$. These give a [surjection](surjective-function.md) $C\to\prod_iC/\mathfrak m_i$. Each factor has positive $K$-dimension, so $r\leq\dim_KC$, excluding an infinite list.
