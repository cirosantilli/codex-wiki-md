# Minimum locus of a squared function

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

If a real-valued [function](function-split.md) $g$ has a zero in the feasible region, then $g^2-c\geq-c$, with equality precisely on that zero set. The minimum can therefore occur along a curve or a higher-dimensional set rather than at isolated [critical points](critical-point.md). To maximize it on a compact feasible region, maximize $|g|$: both the largest and the smallest values of $g$ must be considered, since a large negative value also has a large square.
