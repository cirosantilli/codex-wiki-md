# Compact measure-preserving system

↑ **Parent:** [Almost periodic observable](almost-periodic-observable.md)

A probability [measure-preserving system](measure-preserving-system.md) is compact if every $L^2$ observable has a relatively compact [Koopman operator](koopman-operator.md) orbit in the global $L^2$ norm. For an invertible system one may use all integer times; for a general transformation use nonnegative times. This is a measure-theoretic definition, stronger than compactness of the underlying topological space.
