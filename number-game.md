# Number game

↑ **Parent:** [Partizan game](partizan-game.md)

A number game is a recursively defined normal-play [partizan game](partizan-game.md) whose options are number games and every left option is smaller than every right option. Its value is the simplest [surreal number](surreal-number.md) between those options. Finite number games have [dyadic rational](dyadic-rational.md) values.
