# Object constructor

↑ **Parent:** [Class (programming)](class-programming.md)

An operation used when creating and initializing a [software class](class-programming.md) instance. Construction should establish the [representation invariant](representation-invariant.md) before ordinary clients can access the [software object](software-object.md). [Class inheritance](class-inheritance.md) and initialization order require care if construction invokes overridable [object methods](object-method.md) before subclass fields are initialized.
