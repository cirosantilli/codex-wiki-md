# Topographic buoyancy boundary condition for quasi-geostrophic flow

↑ **Parent:** [Quasi-geostrophic potential-vorticity equation](quasi-geostrophic-potential-vorticity-equation.md)

For a small steady lower-boundary height $b(x,y)$, impermeability gives $w=\mathbf u_g\cdot\nabla b$ at the reference plane. Substitution in the [buoyancy](buoyancy.md) equation $D_g(f_0\psi_z)+N^2w=0$ yields the displayed [boundary condition](boundary-condition.md). For nonzero Fourier modes in a uniform crossing current, this fixes $\psi_z(0)=-N^2b/f_0$. An upper [radiation condition](radiation-condition.md) or decay condition is still needed to select the physical response.
