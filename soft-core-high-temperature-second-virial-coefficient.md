# Soft-core high-temperature second virial coefficient

↑ **Parent:** [Second virial coefficient](second-virial-coefficient.md)

For a steep soft repulsion, the effective excluded radius decreases with [temperature](temperature-split.md). An inverse-twelfth-power core gives a positive second-virial contribution proportional to $T^{-1/4}$. A hard core instead has a fixed positive excluded-volume limit. These asymptotics explain why different inert-gas model sketches have different high-temperature tails.
