# Small-data existence for a nonlinear elliptic Dirichlet problem

↑ **Parent:** [Nonlinear elliptic boundary value problem](nonlinear-elliptic-boundary-value-problem.md)

Suppose the inverse $S:C^{0,\alpha}\to C^{2,\alpha}_0$ of a linear [elliptic boundary value problem](elliptic-boundary-value-problem-split.md) is bounded by $K$, and a nonlinear map satisfies

$$
\|Q(v)\|_{C^{0,\alpha}}\leq C\|v\|_{C^{2,\alpha}}^2+\delta,\qquad
\|Q(v)-Q(w)\|_{C^{0,\alpha}}\leq[C(\|v\|+\|w\|)+\delta]\|v-w\|.
$$

Then $T(v)=S(Q(v)+f)$ maps a sufficiently small closed ball into itself and is a [contraction mapping](contraction-mapping.md) when $\delta$ and $\|f\|_{C^{0,\alpha}}$ are sufficiently small. The [Banach fixed-point theorem](contraction-mapping-theorem.md) gives a solution of $Lu=Q(u)+f$ with zero [Dirichlet boundary condition](dirichlet-boundary-condition.md), unique within that ball. Invertibility follows from the [Fredholm alternative for an elliptic Dirichlet problem](fredholm-alternative-for-an-elliptic-dirichlet-problem.md) when the homogeneous [null space](kernel-of-a-linear-map.md) is zero.
