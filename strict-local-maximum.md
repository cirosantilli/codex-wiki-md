# Strict local maximum

↑ **Parent:** [Local maximum](local-maximum.md)

A [function](function-split.md) has a strict [local maximum](local-maximum.md) at $t$ if some neighbourhood contains no other point $s$ with $f(s)\geq f(t)$. Unlike a non-strict [local maximum](local-maximum.md), equality at another sufficiently nearby point is excluded. Use neighbourhoods relative to the domain, including when $t$ is an endpoint.
