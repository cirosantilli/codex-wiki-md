# Probit model

↑ **Parent:** [Generalized linear model](generalized-linear-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Probit_model)

Binary probit regression sets $p_i=\Phi(\beta_0+x_i^T\beta)$, where $\Phi$ is the [standard normal distribution](standard-normal-distribution.md) function. Its intercept score is a weighted sum of residuals, so an intercept does not generally force $\sum_i\widehat p_i=\sum_i y_i$.
