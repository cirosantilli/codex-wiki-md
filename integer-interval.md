# Integer interval

↑ **Parent:** [Integer](integer.md)

A finite [integer interval](integer-interval.md) is a set $\{a,a+1,\ldots,b\}$ with [integers](integer.md) $a\leq b$. Its length is $b-a+1$. Infinite [integer intervals](integer-interval.md) can also be defined by allowing one or both endpoints to be infinite; a bounded-gaps condition on words always quantifies over finite [integer intervals](integer-interval.md).
