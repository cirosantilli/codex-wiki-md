# Maximum modulus principle on a bounded domain

↑ **Parent:** [Maximum modulus principle](maximum-modulus-principle.md)

If a function is continuous on the closure of a bounded plane domain and holomorphic inside, the compact closure supplies a point of maximum modulus. Unless the function is constant, the [maximum modulus principle](maximum-modulus-principle.md) places every maximum on the boundary.
