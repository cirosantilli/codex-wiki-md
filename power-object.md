# Power object

↑ **Parent:** [Elementary topos](elementary-topos.md)

A power object $PA$ represents parameterized [subobjects](subobject.md) of $A$: $\mathcal E(X,PA)\cong\operatorname{Sub}(X\times A)$. In an [elementary topos](elementary-topos.md), it is $\Omega^A$, with the membership subobject supplied by evaluation at the [subobject classifier](subobject-classifier.md).
