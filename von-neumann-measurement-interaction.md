# von Neumann measurement interaction

↑ **Parent:** [Measurement interaction](measurement-interaction.md)

A coupling between system [observable](observable.md) $A$ and meter [momentum](momentum-split.md) $p$ that translates a pointer coordinate by $ga$ for an $A$ eigenvalue $a$. For a [weak measurement](weak-measurement.md), these translations are small compared with the initial pointer width. Larger separated pointer distributions instead support a sharp readout of the coupled observable.
