# Full-cycle phase-plate invisibility

↑ **Parent:** [Optical path difference](optical-path-difference.md)

In a monochromatic two-path interferometer, an ideal [phase plate](phase-plate.md) of thickness $t$ and [refractive index](refractive-index.md) $n$ adds [phase](phase-waves.md) $2\pi(n-1)t/\lambda$ at normal incidence. The [interference](interference-wave-propagation.md) pattern is unchanged when $(n-1)t=m\lambda$ for integer $m$, provided transmitted [amplitudes](wave-amplitude.md) and alignment are unchanged. Calling the smallest index requires specifying the admissible range; $n>1$ excludes the optically null $n=1$ solution.
