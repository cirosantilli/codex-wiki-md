# Software module

↑ **Parent:** [Computer science](computer-science-split.md)

A [software module](software-module.md) groups responsibilities behind an [application programming interface](application-programming-interface.md). Its boundary can be maintained by procedures and hidden storage; it need not be a [class in object-oriented programming](class-programming.md). [Information hiding](information-hiding.md) guides which implementation decisions belong inside that boundary.
