# Bounded subfunctor solution set for precomposition

↑ **Parent:** [Left Kan extension](left-kan-extension.md)

For [small categories](small-category.md) $\mathcal C,\mathcal D$, a [functor](functor.md) $F:\mathcal C\to\mathcal D$ and $Q:\mathcal C\to\mathbf{Set}$, choose an infinite [cardinal number](cardinal-number.md) $\kappa$ bounding the number of [morphisms](morphism.md) of $\mathcal D$ and the total number of elements of $Q$. Given a [natural transformation](natural-transformation.md) $\eta:Q\to GF$, generate a subfunctor $G'\subseteq G$ from all $\eta_c(x)$ by applying every outgoing $\mathcal D$-[morphism](morphism.md). Each $G'(d)$ has at most $\kappa$ elements. Label bounded values by subsets of $\kappa$; only a [set](set-split.md) of such [functors](functor.md) and transformations exists. These factorizations give the [solution-set condition](solution-set-condition.md) for precomposition, whose [left adjoint](adjoint-functors.md) is the [left Kan extension](left-kan-extension.md).
