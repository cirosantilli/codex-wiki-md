# Acoustic Doppler measurement

↑ **Parent:** [Doppler effect](doppler-effect.md)

UNSW School of Physics documents a [Doppler effect](doppler-effect.md) experiment using a buzzer based on [piezoelectricity](piezoelectricity.md), powered by a taped-on $9\,\mathrm V$ [battery](electric-battery.md), and a computer's built-in [microphone](microphone.md). Audacity records the [acoustic wave](acoustic-wave.md). First record the stationary source to establish its baseline [frequency](frequency.md); then attach it to a bicycle passing the stationary [microphone](microphone.md). The published [spectrogram](spectrogram.md) shows a rapid decrease in [frequency](frequency.md) during passage.[UNSW, Measuring velocities using the Doppler Shift: Introduction, Figs. 1–2; Circular Motion, Measurements (2)–(3); Linear Motion:Bicycle, Moving Source](measuring-velocities-using-the-doppler-shift-at-unsw-school-of-physics.md)

For numerical readout, select an approaching or receding interval, display its [frequency spectrum](frequency-spectrum.md) using Plot Spectrum, and read the interpolated Peak [frequency](frequency.md). The protocol recommends repeating with slightly different selections to test stability, and working outdoors to reduce reflections and [standing waves](standing-wave.md). Longer windows refine [frequency](frequency.md) spacing while averaging over more motion. The baseline controls for the source's actual tone; repeated selections expose analysis-window sensitivity.[UNSW, Introduction, final paragraph; Circular Motion, spectrogram resolution discussion; Linear Motion:Bicycle, Plot Spectrum and Peak instructions](measuring-velocities-using-the-doppler-shift-at-unsw-school-of-physics.md)

Under nearly collinear constant-speed approach, infer $v=c(1-f_s/f_o)$ from the [classical Doppler effect for sound](classical-doppler-effect-for-sound.md). For recession the positive speed is $v=c(f_s/f_o-1)$. These inversions need a specified [speed of sound](speed-of-sound.md). An offset path changes the projection, as in [Doppler frequency along a trajectory](doppler-frequency-along-a-trajectory.md); neither inversion measures the full speed near closest passage. The protocol's controls cannot remove arbitrary [acceleration](acceleration.md), background [measurement noise](measurement-noise.md) or unresolved reflected paths. No new measurements are claimed here.
