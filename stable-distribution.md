# Stable distribution

↑ **Parent:** [Cauchy distribution](cauchy-distribution.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stable_distribution)

A probability distribution is stable when every linear combination of independent copies has the same distribution up to a location and scale change. The [Cauchy distribution](cauchy-distribution.md) is stable with stability parameter one.
