# Merton consumption-investment problem

↑ **Parent:** [Investment-consumption problem](investment-consumption-problem.md)

For a constant-coefficient single-asset [investment-consumption problem](investment-consumption-problem.md) with [constant relative risk aversion utility](constant-relative-risk-aversion-utility.md), put $\kappa=(\mu-r)/\sigma$ and $\delta=[\rho-(1-R)(r+\kappa^2/(2R))]/R$. When $\delta>0$, the infinite-horizon value is $\delta^{-R}w^{1-R}/(1-R)$ and the optimal controls are $c^*=\delta w$ and $\theta^*=(\mu-r)w/(R\sigma^2)$. The case $R=1$ uses logarithmic utility.
