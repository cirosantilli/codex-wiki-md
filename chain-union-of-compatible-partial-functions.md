# Chain union of compatible partial functions

↑ **Parent:** [Partial function](partial-function.md)

The [union](set-union.md) of a [chain](chain-in-a-partial-order.md) of partial-function graphs is a [partial function](partial-function.md): two values at the same input occur together in a larger [chain](chain-in-a-partial-order.md) member and therefore agree. Any closure or algebraic identity involving finitely many inputs passes to the [union](set-union.md) if it holds in every [chain](chain-in-a-partial-order.md) member, because one member contains all those inputs.
