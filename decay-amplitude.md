# Decay amplitude

↑ **Parent:** [Decay width](decay-width.md)

The invariant decay amplitude is the transition matrix element for one incoming particle and a specified on-shell final state, with the overall momentum delta function factored out. For covariantly normalized states, write the connected [S-matrix](s-matrix.md) element as $i(2\pi)^4\delta^4(p_i-p_f)\mathcal M(i\to f)$. Its overall phase does not affect the [decay width](decay-width.md). The rate is $\Gamma=(2M_i)^{-1}\sum_{\rm spins}\int d\Phi_f|\mathcal M|^2$, with the initial spin average included when the initial state is unpolarized. For a spin-zero parent and an angle-independent two-body amplitude, the [two-body Lorentz-invariant phase space](two-body-lorentz-invariant-phase-space.md) gives $\Gamma=|\mathbf k|\sum|\mathcal M|^2/(8\pi M_i^2)$. In [leptonic pion decay](leptonic-pion-decay.md), contracting the axial hadronic matrix element with the chiral [weak charged current](charged-current.md) makes this amplitude proportional to the charged-lepton mass, proving [helicity suppression](helicity-suppression.md).
