# Value of a zero-sum game

↑ **Parent:** [Zero-sum game](zero-sum-game.md)

For a finite matrix [zero-sum game](zero-sum-game.md), the value is the payoff that the maximizing player can guarantee and the minimizing player can prevent the payoff from exceeding, using [mixed strategies](mixed-strategy.md). The common value of the two displayed optimizations exists by the [minimax theorem](minimax-theorem.md). A pair of strategies can be verified directly by checking that every pure column pays the row mixture at least $v$ and every pure row earns at most $v$ against the column mixture.
