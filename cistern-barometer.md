# Cistern barometer

↑ **Parent:** [Mercury barometer](mercury-barometer.md)

A mercury [barometer](barometer.md) with its lower end in a reservoir exposed to atmospheric [pressure](pressure-split.md). A fixed-cistern scale must allow for the changing reservoir level, while an adjustable cistern can restore a fixed lower reference before each reading.
