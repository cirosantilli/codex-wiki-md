# Blocks in experimental design

↑ **Parent:** [Design of experiments](design-of-experiments.md)

A block groups [experimental units](experimental-unit.md) expected to have similar background responses. Comparing [treatments](treatment.md) within blocks can reduce the [variance of an estimator](variance-of-an-estimator.md). Block allocation must be specified before responses are used to evaluate treatment effects.
