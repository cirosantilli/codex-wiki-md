# Inverse function

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inverse_function)

If a function $f:X\to Y$ is bijective, its inverse function $f^{-1}:Y\to X$ is characterized by $f^{-1}(f(x))=x$ and $f(f^{-1}(y))=y$.
