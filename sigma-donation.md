# Sigma donation

↑ **Parent:** [Coordinate covalent bond](coordinate-covalent-bond.md)

[Sigma donation](sigma-donation.md) transfers [electron](electron.md) density from an occupied ligand orbital into a metal acceptor orbital with the appropriate [symmetry](symmetry-physics.md) along the bond axis. CO uses an occupied carbon-centered $5\sigma$ orbital. Backdonation can occur simultaneously.
