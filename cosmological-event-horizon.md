# Cosmological event horizon

↑ **Parent:** [Observer event horizon](observer-event-horizon.md)

For a comoving observer in a spatially flat [Friedmann-Lemaître-Robertson-Walker metric](friedmann-lemaitre-robertson-walker-metric.md), a finite future [conformal time](conformal-time.md) interval gives an event horizon at the displayed comoving radius. Its physical radius at time $t$ is $a(t)\chi_{\mathrm{eh}}(t)$.
