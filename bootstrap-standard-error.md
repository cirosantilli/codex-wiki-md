# Bootstrap standard error

↑ **Parent:** [Bootstrapping (statistics)](bootstrapping-statistics.md)

Replace the unknown sampling distribution by the [empirical distribution](type-information-theory.md), generate independent [bootstrap samples](bootstrap-sample.md), and recompute the statistic. The sample standard deviation of those recomputed values estimates the conditional bootstrap standard deviation, which approximates the statistic's sampling [standard error](standard-error.md) when the bootstrap is consistent. It is different from the Monte Carlo standard error of the estimated bootstrap mean.
