# Nonautonomous abstract Cauchy problem

↑ **Parent:** [Abstract Cauchy problem](abstract-cauchy-problem.md)

A nonautonomous abstract Cauchy problem has the form $u'(t)=A(t)u(t)$, with a time-dependent generally [closed linear operator](closed-linear-operator.md). Under stability, common-domain, and regularity hypotheses, it is propagated by an [evolution family](evolution-family.md).
