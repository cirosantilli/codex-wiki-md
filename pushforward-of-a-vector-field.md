# Pushforward of a vector field

↑ **Parent:** [Differential of a smooth map](differential-of-a-smooth-map.md)

For a [vector field](vector-field.md) $X$ on $M$, its pushforward by a [smooth map between manifolds](smooth-map-between-manifolds.md) $f:M\to N$ is the [vector field along a map](vector-field-along-a-map.md) defined by $(f_*X)_p=df_p(X_p)$. Acting on a function $h$ on $N$, it satisfies $(f_*X)_p(h)=X_p(h\circ f)$. For a [diffeomorphism](diffeomorphism.md) this defines a vector field on $N$ by evaluation at $p=f^{-1}(q)$. For a general map there need not be a single vector at each image point: $f(x)=x^2$, $X=\partial_x$ gives $2x\partial_y$, with opposite values over $y>0$.
