# Cellular reprogramming

↑ **Parent:** [Cellular differentiation](cellular-differentiation.md)

[Cellular reprogramming](cellular-reprogramming.md) changes an established [cell state](cell-state.md) so that a different developmental program becomes accessible. Experimentally induced [cellular reprogramming](cellular-reprogramming.md) must be distinguished from the ordinary progression of [cell differentiation](cellular-differentiation.md). An [ovum](ovum.md)'s [cytoplasm](cytoplasm.md) can reset aspects of a transferred [cell nucleus](cell-nucleus.md); this does not mean that a specialized donor normally returns to an early developmental state in its original surroundings.
