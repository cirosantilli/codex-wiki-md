# Continuation-ratio logits

↑ **Parent:** [Multinomial logistic regression](multinomial-logistic-regression.md)

For ordered response categories, model each displayed conditional probability by a [grouped-binomial logistic regression](grouped-binomial-logistic-regression.md). The [multinomial likelihood](multinomial-likelihood.md) factors exactly into successive conditional [binomial likelihoods](binomial-likelihood.md), using the remaining category total as each stage's denominator. This is a different regression parameterization from baseline-category logits or cumulative odds. Separate cumulative binary indicators from the same person are dependent and cannot be treated as independent likelihood contributions.
