# Minimal polynomial of an invertible matrix

↑ **Parent:** [Minimal polynomial](minimal-polynomial.md)

A square matrix $A$ is [invertible](invertible-matrix.md) exactly when its [minimal polynomial](minimal-polynomial.md) has nonzero constant term. If $m_A(t)=tq(t)$, then $Aq(A)=0$, and invertibility would contradict the minimality of $m_A$. Conversely, if $m_A(t)=tq(t)+c$ with $c\ne0$, then $A[-q(A)/c]=I$.
