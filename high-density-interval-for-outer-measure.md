# High-density interval for outer measure

↑ **Parent:** [Lebesgue outer measure](lebesgue-outer-measure.md)

For any $E\subseteq\mathbb R$ with positive [Lebesgue outer measure](lebesgue-outer-measure.md) and any $0<\lambda<1$, some bounded nonempty open [interval](interval-mathematics.md) $I$ satisfies the displayed inequality. The set $E$ need not be a [Lebesgue measurable set](lebesgue-measurable-set.md).

To prove this, first choose a bounded portion $F=E\cap[-N,N]$ with $0<a=m^*(F)<\infty$, using [countable subadditivity](countable-subadditivity-of-a-measure.md). Choose a countable open-interval cover $(I_j)$ of $F$ with $\sum_j|I_j|<a/\lambda$. If $m^*(E\cap I_j)\leq\lambda|I_j|$ for every $j$, then

$$
a\leq\sum_jm^*(F\cap I_j)\leq\lambda\sum_j|I_j|<a,
$$

a contradiction. For measurable $E$ this gives the [high-density interval in a positive-measure subset of the real line](high-density-interval-in-a-positive-measure-subset-of-the-real-line.md) without requiring the full [Lebesgue density theorem](lebesgue-s-density-theorem.md).
