# Constraint domain

↑ **Parent:** [Constraint satisfaction problem](constraint-satisfaction-problem.md)

The [set](set-split.md) of values permitted for a variable $X_i$ in a [constraint satisfaction problem](constraint-satisfaction-problem.md). All assignments before relational constraints form the [Cartesian product](cartesian-product.md) $\prod_iD_i$, whose [cardinality](cardinality.md) is $\prod_i|D_i|$ for finite domains. Unary restrictions can be incorporated directly into the [constraint domain](constraint-domain.md) by deleting forbidden values.
