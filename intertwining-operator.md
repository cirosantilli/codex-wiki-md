# Intertwining operator

↑ **Parent:** [Representation theory](representation-theory-split.md)

An intertwining operator between representations $\rho$ and $\sigma$ is a linear [equivariant map](equivariant-map.md) $T$ satisfying $T\rho(g)=\sigma(g)T$ for every group element $g$.
