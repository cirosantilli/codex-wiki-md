# Black-Scholes value equation needs delta-compatible holdings

↑ **Parent:** [Black-Scholes equation](black-scholes-equation.md)

A smooth value function satisfying the [Black-Scholes equation](black-scholes-equation.md) admits a [self-financing portfolio](self-financing-portfolio.md) with the displayed [delta hedge](delta-hedge.md). An arbitrary decomposition $p=xg+Bh$ need not be self-financing. For example $p=0$, $g=1$, $h=-x/B$ solves the value equation but has portfolio gains $dS-\rho S\,dt$, which are not zero when volatility is positive. For specified holdings, self-financing is equivalent to the value equation together with $g=p_x$.
