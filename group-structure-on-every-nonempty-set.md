# Group structure on every nonempty set

↑ **Parent:** [Group](group-split.md)

Assuming choice, every nonempty [set](set-split.md) admits a [group operation](group-operation.md). A [finite set](finite-set.md) receives a [cyclic group](cyclic-group.md) structure. For an [infinite set](infinite-set.md), a maximal partial [group](group-split.md) obtained by Zorn has infinite carrier $A$ with smaller complement; infinite-cardinal doubling implies the whole [set](set-split.md) is equipotent with $A$. Transport its operation along a [bijection](bijection.md) $j$. This final [group](group-split.md) need not extend a previously chosen partial [group](group-split.md) on its original [subset](subset.md); transport changes labels and only asserts existence.
