# Thumb 16-bit instruction set quick reference by Arm

↑ **Parent:** [Computer science bibliography](computer-science-bibliography-split.md)

[https://documentation-service.arm.com/static/5ed67dc7ca06a95ce53f9334](https://documentation-service.arm.com/static/5ed67dc7ca06a95ce53f9334)

Page 1 lists the compact logical and shift instruction forms. [Left bit shifts](left-bit-shift.md) have immediate counts $0$–$31$, while [logical right shifts](logical-right-shift.md) and [arithmetic right shifts](arithmetic-right-shift.md) have immediate counts $1$–$32$. The logical [bitwise AND](bitwise-and.md) entry uses a [processor register](processor-register.md) operand. These encoding details explain why extracting low [bits](bit.md) with two immediate shifts can avoid materializing a [bit mask](bit-mask.md).
