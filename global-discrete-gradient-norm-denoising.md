# Global discrete gradient-norm denoising

↑ **Parent:** [Variational regularization](variational-regularization.md)

For a discrete [image signal](image-signal.md) operator $A$, minimize $\alpha\|Au\|_2+\tfrac12\|u-g\|_2^2$ with one [Euclidean norm](euclidean-norm.md) on the full [gradient](gradient.md) array. This differs from [discrete isotropic total variation](discrete-isotropic-total-variation.md), which sums pixelwise Euclidean lengths. The global [norm](norm.md)'s dual ball is a single ball; its [convex projection](euclidean-projection-onto-a-convex-set.md) normalizes the whole vector array.
