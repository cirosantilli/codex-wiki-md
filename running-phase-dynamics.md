# Running phase dynamics

↑ **Parent:** [Adler phase equation](adler-phase-equation.md)

A phase that continues winding rather than tending to a locked value. In the noise-free [Adler phase equation](adler-phase-equation.md), $\omega>\epsilon>0$ makes the drift positive at every phase, so there are no [equilibrium points](equilibrium-point-of-a-dynamical-system.md). The associated [tilted washboard potential](tilted-washboard-potential.md) decreases monotonically; wells vanish at the locking threshold.
