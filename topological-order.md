# Topological order

↑ **Parent:** [Topological sorting](topological-sorting.md)

A [topological order](topological-order.md) is an ordering of a directed graph's vertices in which every arc points from an earlier vertex to a later one. A finite directed graph admits such an ordering exactly when it is a [Directed acyclic graph](directed-acyclic-graph.md).
