# Phase margin

↑ **Parent:** [Loop gain](loop-gain.md)

The [phase margin](phase-margin.md) measures the remaining phase lag before a negative-feedback loop reaches the critical phase $-\pi$ at unity loop magnitude, using a continuous phase convention. Positive adequate margin is a useful stability and transient-response design diagnostic for standard single-crossover amplifier loops. More general unstable open-loop systems and multiple crossovers require the full stability criterion.
