# Cloud droplet

↑ **Parent:** [Cloud](cloud.md)

A liquid-water particle suspended in a [cloud](cloud.md). Number, size distribution and liquid-water content are separate properties; increasing number at fixed total [water](water.md) shifts the characteristic radius downward.
