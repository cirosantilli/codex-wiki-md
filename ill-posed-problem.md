# Ill-posed problem

↑ **Parent:** [Partial differential equation](partial-differential-equation-split.md)

An ill-posed problem fails existence, uniqueness or continuous dependence in the specified function spaces. Backward [heat equation](heat-equation.md) evolution is unstable because its [Fourier modes](fourier-mode.md) grow like $e^{t|\xi|^2}$, making arbitrarily small high-frequency errors grow without a uniform bound.
