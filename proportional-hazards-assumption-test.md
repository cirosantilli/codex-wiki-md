# Proportional hazards assumption test

↑ **Parent:** [Cox proportional-hazards model](cox-proportional-hazards-model.md)

A proportional hazards assumption test assesses whether fitted covariate coefficients remain constant over time. A common implementation uses trends in [scaled Schoenfeld residuals](scaled-schoenfeld-residual.md), with separate covariate tests and a joint global test. Failure to reject is compatible with proportional hazards, but does not establish the correct covariate functional form or [independent censoring](independent-censoring.md).
