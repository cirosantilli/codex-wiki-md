# Quotient by an irreducible polynomial is a field

↑ **Parent:** [Irreducible polynomial](irreducible-polynomial.md)

If $f$ is an [irreducible polynomial](irreducible-polynomial.md) over a [field](field.md) $F$, then a nonzero residue $[g]$ modulo $(f)$ has $\gcd(f,g)=1$. The [Euclidean algorithm](euclidean-algorithm.md) supplies $uf+vg=1$, giving inverse $[v]$ for $[g]$. Thus the [quotient ring](quotient-ring.md) $F[X]/(f)$ is a field. If $\deg f=d$ and $F$ has $q$ elements, polynomial division supplies exactly $q^d$ residue classes.
