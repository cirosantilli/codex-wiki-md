# Phased array

↑ **Parent:** [Antenna (radio)](antenna-radio.md)

A [phased array](phased-array.md) combines radiation from spatially separated [antennas](antenna-radio.md) with controlled relative [phases](phase-waves.md). Changing those [phases](phase-waves.md) steers the direction of [constructive interference](constructive-interference.md) without moving the elements. For an equally spaced linear array with spacing $d$, free-space [wavenumber](wavenumber.md) $k$ and phase increment $\psi$, a principal beam at angle $\theta_0$ from the array normal satisfies $\psi=kd\sin\theta_0$ when the time dependence is $e^{-i\omega t}$ and the element drives are $e^{ij\psi}$.
