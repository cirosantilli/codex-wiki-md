# Optical coherence length

↑ **Parent:** [Optical coherence time](optical-coherence-time.md)

In this temporal sense, the [optical coherence length](optical-coherence-length.md) is $L_c=c\tau_c$, where $c$ is the [vacuum](vacuum.md) [speed of light](speed-of-light.md) and $\tau_c$ is an explicitly chosen [optical coherence time](optical-coherence-time.md). It measures a delay as a vacuum-equivalent path difference; it does not measure transverse [spatial optical coherence](spatial-optical-coherence.md). [Rüdiger Paschotta, RP Photonics Encyclopedia, Coherence Length: temporal definition and path difference](https://www.rp-photonics.com/coherence_length.html).

For the stipulated $1\,\mathrm{GHz}$ profiles, the $1/e$ convention gives $L_c\approx9.54269\,\mathrm{cm}$ for the Lorentzian and $15.8896\,\mathrm{cm}$ for the Gaussian. In a [vacuum](vacuum.md) [Michelson interferometer](michelson-interferometer.md), changing one mirror position by $x$ changes the round-trip delay by $2x/c$, so the mirror travel to either of these delays is $L_c/2$. In a medium, convert physical travel using the actual group delay, which can depend on [frequency](frequency.md). For a narrow line centered at [vacuum](vacuum.md) [wavelength](wavelength.md) $\lambda_0$, differentiating $\nu=c/\lambda$ gives $\Delta\nu\approx c\Delta\lambda/\lambda_0^2$; this small-width approximation must use consistently defined spectral widths.
