# Nevanlinna integrated counting function

↑ **Parent:** [Nevanlinna theory](nevanlinna-theory.md)

The number $n(t,f)$ counts [poles](pole.md) in $|z|<t$ with [multiplicity](multiplicity-mathematics.md), and $n(0,f)$ is the pole order at zero. Thus $N(r,f)=n(0,f)\log r+\sum_{0<|p|<r}\log(r/|p|)$. Applying this to $1/(f-a)$ counts occurrences of the value $a$.
