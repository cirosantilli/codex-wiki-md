# Scattering phase function

↑ **Parent:** [Radiative transfer](radiative-transfer.md)

A [scattering phase function](scattering-phase-function.md) describes the angular distribution of single-scattered power. One common convention is $\int P\,d\Omega=4\pi$, so that $P/(4\pi)$ is a probability density over outgoing [solid angle](solid-angle.md). For unpolarized [Rayleigh scattering](rayleigh-scattering.md), $P=3(1+\cos^2\Theta)/4$. It is distinct from the oscillatory-integral meaning of phase function.
