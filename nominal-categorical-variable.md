# Nominal categorical variable

↑ **Parent:** [Categorical variable](categorical-variable.md)

A [categorical variable](categorical-variable.md) whose labels have no intrinsic ordering. Relabelling its categories does not change the underlying classification. An [ordinal categorical variable](ordinal-categorical-variable.md) additionally records an order; neither type automatically supplies equal numerical distances between categories.
