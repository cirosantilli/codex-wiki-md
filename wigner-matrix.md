# Wigner matrix

↑ **Parent:** [Random matrix](random-matrix.md)

A real Wigner [matrix](matrix.md) is a real [symmetric matrix](symmetric-matrix.md) whose upper off-diagonal entries are independent centered copies of a fixed [random variable](random-variable-split.md), scaled to have [variance](variance-split.md) of order $1/N$. Diagonal conventions may vary and should be specified separately. A common version has variance-one unscaled off-diagonal entries and either zero diagonal entries or independent diagonal entries with a bounded second moment.
