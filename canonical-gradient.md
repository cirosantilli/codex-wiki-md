# Canonical gradient

↑ **Parent:** [Influence-function representer](influence-function-representer.md)

The canonical gradient is the [influence-function representer](influence-function-representer.md) in the [statistical tangent space](statistical-tangent-space.md) $\mathcal T$. It equals the [orthogonal projection](orthogonal-projection.md) onto $\mathcal T$ of any representer. Every other representer differs from it by an element of $\mathcal T^\perp$, so the [Pythagorean theorem in an inner-product space](pythagorean-theorem-in-an-inner-product-space.md) gives it minimum [variance](variance-split.md). For $\psi(P)=Pa$ in an unrestricted density model with bounded $a$, it is $a-Pa$.
