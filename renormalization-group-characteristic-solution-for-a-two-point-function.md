# Renormalization-group characteristic solution for a two-point function

↑ **Parent:** [Callan-Symanzik equation](callan-symanzik-equation.md)

For $t=\log(|p|/\mu)$ and $d\bar g/dt=\beta(\bar g)$, the displayed characteristic solution follows from $(-\partial_t+\beta\partial_g+2\gamma_\phi)d=0$. It separates the [running coupling](running-coupling.md) from the accumulated [field-renormalization anomalous dimension](field-renormalization-anomalous-dimension.md). The exponent sign is determined by the precise [Callan-Symanzik equation](callan-symanzik-equation.md) convention.
