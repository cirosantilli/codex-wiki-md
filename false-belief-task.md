# False-belief task

↑ **Parent:** [False-belief understanding](false-belief-understanding.md)

A task testing how an agent will act or respond when its representation differs from the actual state of affairs. Unexpected-transfer tasks contrast the location an agent witnessed with a subsequent displacement it did not witness; comprehension controls and response demands affect interpretation.[Cognition 13, 103–128; unexpected-transfer stories](beliefs-about-beliefs-by-heinz-wimmer-and-josef-perner.md)
