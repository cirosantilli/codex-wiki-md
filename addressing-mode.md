# Addressing mode

↑ **Parent:** [Instruction set architecture](instruction-set-architecture.md)

An [addressing mode](addressing-mode.md) specifies how an instruction obtains an operand or forms an effective memory address. Examples include [immediate operands](immediate-operand.md), [processor register](processor-register.md) operands, base-plus-displacement memory access and scaled [processor register](processor-register.md) indexing.
