# Formal character of a weight module

↑ **Parent:** [Highest-weight representation](highest-weight-representation.md)

For a module with finite-dimensional [weight spaces](weight-space.md), its formal character is $\operatorname{ch}V=\sum_\mu(\dim V_\mu)e^\mu$ in the completed group algebra of the [weight lattice](weight-lattice.md).
