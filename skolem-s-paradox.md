<h1 id="skolem-s-paradox">Skolem's paradox</h1>

↑ **Parent:** [Löwenheim-Skolem theorem](lowenheim-skolem-theorem.md)

A [countable](countable-set.md) model of [set theory](set-theory-split.md) can internally assert that an [uncountable](uncountable-set.md) set exists. There is no contradiction because “there is a [bijection](bijection.md)” ranges only over functions in the model. An external enumeration of its domain need not itself be an element of that domain. [Löwenheim-Skolem theorem](lowenheim-skolem-theorem.md) controls external [cardinality](cardinality.md); [Cantor's theorem](cantor-s-theorem.md) remains valid for the sets and functions that the model contains.
