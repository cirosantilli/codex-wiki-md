# Signed area

↑ **Parent:** [Surface area](surface-area.md)

The [area](surface-area.md) of a planar oriented region with a sign determined by orientation. For a [triangle](triangle.md) with cyclically ordered points $A,B,C$, it is $\tfrac12((B-A)\times(C-A))$, using the [two-dimensional cross product](two-dimensional-cross-product.md); reversing the order reverses the sign.
