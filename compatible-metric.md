# Compatible metric

↑ **Parent:** [Metric](metric.md)

A [metric](metric.md) is compatible with a given topology when its open balls generate exactly that topology. [Compatible metrics](compatible-metric.md) on a compact [topological space](topological-space.md) are uniformly equivalent: the identity maps between the resulting compact [metric spaces](metric-space.md) are [uniformly continuous](uniform-continuity.md). Consequently they define the same [proximality](proximality.md) and the same asymptotic-pair relation for a fixed [continuous map](continuous-map.md).
