# Fundamental string

↑ **Parent:** [String theory](string-theory-split.md)

A fundamental string is the perturbative string of a string-theory description. Its [string tension](string-tension.md) is the displayed expression in the string metric. It couples to the [Neveu–Schwarz two-form](neveu-schwarz-two-form.md).
