# Sharp-k smoothing filter

↑ **Parent:** [Press-Schechter formalism](press-schechter-formalism.md)

A sharp-k filter includes every Fourier mode below a cutoff with unit weight and excludes all modes above it. For a [Gaussian random field](gaussian-random-field.md), increasing the cutoff adds independent Fourier shells, so the smoothed [density contrast](density-contrast.md) is a [Brownian motion](brownian-motion-split.md) when parameterized by its variance. The real-space window is not a localized spherical top-hat, so its halo mass assignment needs a specified convention.
