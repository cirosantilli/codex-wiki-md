# Factorial bound for a Volterra iterate

↑ **Parent:** [Volterra integral equation](volterra-integral-equation.md)

If $\|\tau f(t)\|\leq C\int_0^t\|f(s)\|ds$, repeated integration produces the time-ordered simplex of volume $t^n/n!$. Thus the [Neumann series](neumann-series.md) $\sum_{n\geq0}\tau^n$ converges on every finite interval, without requiring the single-step [operator norm](operator-norm.md) to be less than one.
