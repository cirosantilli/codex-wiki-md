# Asymmetric planar gluing return map

↑ **Parent:** [Homoclinic orbit](homoclinic-orbit.md)

Near two [homoclinic orbits](homoclinic-orbit.md) of a planar [saddle equilibrium](saddle-equilibrium.md) with contracting ratio $\delta>1$, the signed [Poincaré return map](poincare-map.md) has separate offsets $\mu,\nu$. Two single-lobe [periodic orbits](periodic-orbit.md) exist for $\mu<0$ and $\nu<0$, respectively. A two-lobe [periodic orbit](periodic-orbit.md) is represented by positive $p,q$ solving the displayed equations. Its boundary consists of the compound [homoclinic orbit](homoclinic-orbit.md) curves $\mu=-A\nu^\delta$ for $\nu>0$ and $\nu=-B\mu^\delta$ for $\mu>0$, with $A,B>0$. In a sufficiently small return domain the derivatives tend to zero, so each admissible symbolic branch has at most one attracting [periodic orbit](periodic-orbit.md). Restricting to $\mu=\nu$, $A=B$ gives the usual [symmetric homoclinic gluing bifurcation](symmetric-homoclinic-gluing-bifurcation.md).
