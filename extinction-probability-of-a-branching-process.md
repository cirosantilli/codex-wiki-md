# Extinction probability of a branching process

↑ **Parent:** [Galton-Watson extinction fixed point](galton-watson-extinction-fixed-point.md)

For a [Galton-Watson process](galton-watson-process.md) with one ancestor this is the probability that some generation is empty. It is the smallest fixed point of the offspring [probability generating function](probability-generating-function.md) in $[0,1]$; the complementary survival probability is $1-q$. A [branching process conditioned on extinction](branching-process-conditioned-on-extinction.md) reweights reproduction using this fixed point.
