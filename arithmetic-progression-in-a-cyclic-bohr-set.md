# Arithmetic progression in a cyclic Bohr set

↑ **Parent:** [Bohr set](bohr-set.md)

When $N$ is prime, simultaneous approximation of the frequencies shows that $B(\Gamma,\rho)\subseteq\mathbb Z/N\mathbb Z$ contains a centered [arithmetic progression](arithmetic-progression.md) of length at least

$$
\frac18\rho N^{1/|\Gamma|}.
$$
