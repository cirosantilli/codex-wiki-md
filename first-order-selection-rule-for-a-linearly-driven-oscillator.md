# First-order selection rule for a linearly driven oscillator

↑ **Parent:** [Shaken harmonic trap](shaken-harmonic-trap.md)

The ladder identity $x=\sqrt{\hbar/(2m\omega)}(a+a^\dagger)$ proves the matrix element in the title. In [time-dependent perturbation theory](time-dependent-perturbation-theory.md), a linear force excites only $n=1$ directly from $n=0$. [Parity](parity.md) alone rules out even excited states; the ladder identity also rules out odd $n>1$. Higher-order evolution can reach other levels, so the driven oscillator is not an exact [two-level system](two-level-system.md).
