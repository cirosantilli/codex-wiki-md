# Inverse Galois problem

↑ **Parent:** [Galois theory](galois-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inverse_Galois_problem)

The inverse Galois problem asks which finite groups occur as [Galois groups](galois-group.md) over a given [field](field.md), with the classical problem taking the base [field](field.md) to be $\mathbb Q$. A regular realization over $K(T)$ and [Galois-preserving Hilbert specialization](galois-preserving-hilbert-specialization.md) solve an instance over a [Hilbertian field](hilbertian-field.md). Realization over an algebraically closed constant [field](field.md)'s [rational function field](rational-function-field.md) alone does not supply descent to $\mathbb Q$.
