# Extensional flow

↑ **Parent:** [Rheology](rheology-split.md)

An [extensional flow](extensional-flow.md) stretches material along one or more directions while contracting it along others. A local ideal model of planar extension has [velocity](velocity.md) $\mathbf u=(\dot\epsilon x,-\dot\epsilon y,0)$: its [rate-of-strain tensor](strain-rate-tensor.md) is $\operatorname{diag}(\dot\epsilon,-\dot\epsilon,0)$ and it is an [incompressible flow](incompressible-flow.md). [Uniaxial extensional flow](uniaxial-extensional-flow.md) instead contracts both transverse directions. These geometries probe [extensional viscosity](extensional-viscosity.md) and can stretch [polymers](polymer-split.md).
