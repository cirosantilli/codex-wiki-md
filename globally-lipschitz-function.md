# Globally Lipschitz function

↑ **Parent:** [Lipschitz continuity](lipschitz-continuity.md)

A [function](function-split.md) is globally Lipschitz when one finite [Lipschitz bound](lipschitz-bound.md) holds for every pair in its entire specified [domain of a function](domain-of-a-function.md). The [sine](sine.md) and the [absolute value](absolute-value.md) have this property on the [real line](real-line.md). For any reference point $x_0$, a globally [Lipschitz continuous](lipschitz-continuity.md) real function obeys $|f(x)|\leq|f(x_0)|+L|x-x_0|$, so its size grows at most linearly in the distance from $x_0$.

The [function](function-split.md) $f(x)=x^2$ is a [locally Lipschitz function](locally-lipschitz-function.md) on the [real line](real-line.md), but is not globally Lipschitz there: pairs $x=n+1$, $y=n$ have ratio $2n+1$, which is unbounded. Restricting the domain to $[-R,R]$ does give a global bound $2R$. Global and local describe where one bound must work, rather than two intrinsic labels independent of the domain.
