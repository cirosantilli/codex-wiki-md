# Globally Lipschitz function

↑ **Parent:** [Lipschitz continuity](lipschitz-continuity.md)

A function is globally Lipschitz when one [Lipschitz bound](lipschitz-bound.md) holds for every pair of points in its domain. Unlike local Lipschitz continuity, this condition gives a uniform growth control over the whole domain.
