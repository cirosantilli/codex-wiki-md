# Information confidentiality

↑ **Parent:** [Computer security](computer-security.md)

[Access control](access-control.md) can prevent a subject from reading a file, while [cryptographic confidentiality](cryptographic-confidentiality.md) protects message contents against specified adversaries using [cryptography](cryptography.md).
