# Lorentz index

↑ **Parent:** [Lorentz transformation](lorentz-transformation.md)

An index labeling components that transform under a spacetime [Lorentz transformation](lorentz-transformation.md). For example, the four components $p^\mu$ form a [Lorentz four-vector](four-vector.md). Repeated upper and lower indices are contracted using the [Minkowski metric](minkowski-metric.md).
