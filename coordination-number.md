# Coordination number

↑ **Parent:** [Ionic crystal](ionic-crystal.md)

In this structural use, the [coordination number](coordination-number.md) counts nearest neighbouring constituents. State which neighbours are counted and which [ionic crystal](ionic-crystal.md) structure is being described; it is not an [ion](ion.md)'s [electric charge](electric-charge-split.md) number.
