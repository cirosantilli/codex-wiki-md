# Abelian quotient

↑ **Parent:** [Quotient group](quotient-group.md)

An abelian quotient is a [quotient group](quotient-group.md) $G/N$ that is an [abelian group](abelian-group.md). It exists only for a [normal subgroup](normal-subgroup.md) $N$, and it is abelian exactly when $N$ contains the [commutator subgroup](commutator-subgroup.md). Thus every abelian quotient factors through the [abelianization](abelianization.md) $G/[G,G]$.
