# Haskell type class

↑ **Parent:** [Type system](type-system.md)

A class specifies overloaded methods and a constraint supplies the applicable instance operations for a type. This programming-language concept is distinct from an information-theoretic type class. A method signature does not enforce algebraic laws such as a lawful [total order](total-order.md).
