# Clique decision problem

↑ **Parent:** [Clique problem](clique-problem.md)

Given an explicitly represented finite [simple graph](simple-graph.md) $G$ and a nonnegative [integer](integer-split.md) $k$, decide whether $G$ contains a [clique](clique-graph-theory.md) of size $k$. The problem is [NP-complete](np-completeness.md). A [polynomial-time many-one reduction](polynomial-time-many-one-reduction.md) from [SAT](boolean-satisfiability-problem.md) first obtains [conjunctive normal form](conjunctive-normal-form.md) by a [Tseitin transformation](tseytin-transformation.md), makes one [vertex](vertex-graph-theory.md) per [Boolean literal](boolean-literal.md) occurrence, and joins noncontradictory occurrences from different [Boolean clauses](clause-of-a-boolean-formula.md). A [clique](clique-graph-theory.md) as large as the [Boolean clause](clause-of-a-boolean-formula.md) count is equivalent to a [satisfying assignment](satisfying-assignment.md).
