# Pauli matrix commutator identity

↑ **Parent:** [Pauli matrix multiplication law](pauli-matrix-multiplication-law.md)

For vectors $\mathbf a,\mathbf b\in\mathbb R^3$, the [Pauli matrix multiplication law](pauli-matrix-multiplication-law.md) gives

$$
[\mathbf a\mathbin\cdot\boldsymbol\sigma,\mathbf b\mathbin\cdot\boldsymbol\sigma]
=2i(\mathbf a\times\mathbf b)\mathbin\cdot\boldsymbol\sigma.
$$
