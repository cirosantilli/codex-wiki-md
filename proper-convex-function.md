# Proper convex function

↑ **Parent:** [Convex function](convex-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Proper_convex_function)

A proper convex function is both a [convex function](convex-function.md) and a [proper extended-real function](proper-extended-real-function.md). For example, the [total variation seminorm on a domain](total-variation-seminorm-on-a-domain.md) is nonnegative, finite at zero, and a supremum of linear functionals, making it proper and convex.
