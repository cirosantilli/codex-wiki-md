# Stefan problem

↑ **Parent:** [Planetary ice shell](planetary-ice-shell.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stefan_problem)

A Stefan problem is a [moving-boundary problem](moving-boundary-problem.md) in which a phase boundary moves as [latent heat](latent-heat.md) is released or absorbed. Temperature satisfies a [heat equation](heat-equation.md) in each phase and the [Stefan condition](stefan-condition.md) supplies the interfacial energy balance.
