# Read-only memory

↑ **Parent:** [Computer memory](computer-memory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Read-only_memory)

A memory read through an address whose contents are fixed during ordinary operation. Used as a [Boolean function](boolean-function.md) lookup table, $a$ address [bits](bit.md) select one of $2^a$ words, each holding $b$ output bits, so the logical table capacity is $2^a b$ bits. A [finite-state machine](finite-state-machine.md) can store its [next-state function](next-state-function.md) in such a table while separate [flip-flops](flip-flop.md) store the current state.
