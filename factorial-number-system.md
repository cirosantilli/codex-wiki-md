# Factorial number system

↑ **Parent:** [Positional notation](positional-notation.md)

A mixed-radix [positional notation](positional-notation.md) using [factorials](factorial.md) as place values: $n=\sum_{i\ge1} a_i i!$ with $0\le a_i\le i$. For [lexicographic order](lexicographic-order.md) on [permutations](permutation.md), division by $(k-1)!$ selects the next symbol when $k$ symbols remain; the [remainder](remainder.md) gives the rank within that block.
