# Burrows-Wheeler transform

↑ **Parent:** [String-searching algorithm](string-searching-algorithm.md)

The [Burrows-Wheeler transform](burrows-wheeler-transform.md) appends a unique smallest terminator to a [string](string.md), sorts its [cyclic rotations](cyclic-rotation.md) in [lexicographic order](lexicographic-order.md), and records the last column. It is reversible because the first and last columns contain the same characters and the [last-to-first mapping](last-to-first-mapping.md) preserves the occurrence order of each character. The resulting letter arrangement supports both compression and [backward search](backward-search.md).[§2, Background: sorted cyclic shifts and inversion](opportunistic-data-structures-with-applications-by-paolo-ferragina-and-others.md)
