# First-order consistency

↑ **Parent:** [Consistent first-order theory](consistent-first-order-theory.md)

A [first-order theory](first-order-theory.md) is consistent when it has no [formal proof](formal-proof.md) of a [contradiction](contradiction.md). This syntactic property concerns the specified calculus; its equivalence with having a [first-order model](model-of-a-first-order-theory.md) uses the completeness theorem.
