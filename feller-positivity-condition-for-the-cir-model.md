# Feller positivity condition for the CIR model

↑ **Parent:** [Cox–Ingersoll–Ross model](cox-ingersoll-ross-model.md)

For a [CIR model](cox-ingersoll-ross-model.md) started at a positive rate, this condition makes the zero boundary inaccessible. Below the threshold, zero can be reached, but the usual nonnegative solution does not cross into negative rates. Thus nonnegativity and strict positivity are different properties.
