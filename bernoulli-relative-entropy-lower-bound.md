# Bernoulli relative entropy lower bound

↑ **Parent:** [Binary partition bound for relative entropy](binary-partition-bound-for-relative-entropy.md)

For $d(a,b)=a\log(a/b)+(1-a)\log((1-a)/(1-b))$, the [second derivative](second-derivative.md) with respect to $a$ is $1/[a(1-a)]\geq4$. Its value and first derivative at $a=b$ vanish, so $d(a,b)\geq2(a-b)^2$. Boundary values follow by continuity or the infinite-divergence convention. Together with the [binary partition bound for relative entropy](binary-partition-bound-for-relative-entropy.md), this gives [Pinsker's inequality](pinsker-s-inequality.md) with the natural-logarithm constant.
