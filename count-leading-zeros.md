# Count leading zeros

↑ **Parent:** [Combinational logic](combinational-logic.md)

The number of zero [bits](bit.md) before the first one, reading a fixed-width [binary representation](binary-number.md) from its [most significant bit](most-significant-bit.md). The all-zero $n$-[bit](bit.md) input has count $n$. Thus $\operatorname{clz}_8(00000101)=5$, and $\operatorname{clz}_8(00000000)=8$; the width is part of the definition.
