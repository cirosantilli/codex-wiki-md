# Non-null hypersurface projection

↑ **Parent:** [Hypersurface](hypersurface.md)

A [non-null hypersurface projection](non-null-hypersurface-projection.md) annihilates the unit [normal vector](normal-vector.md) and fixes tangent vectors to the [hypersurface](hypersurface.md). It obeys $P^2=P$. Apply it to every tensor index to remove normal components, with the metric used to lower or raise the index pair for covariant slots. For a timelike unit normal in mostly-plus signature it is the [spatial projection tensor](spatial-projection-tensor.md). A null normal cannot be normalized this way, and a null hypersurface requires additional choices for a corresponding projection.
