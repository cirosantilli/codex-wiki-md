# Isothermal-isobaric partition function

↑ **Parent:** [Isothermal-isobaric ensemble](isothermal-isobaric-ensemble.md)

Integrating a [canonical partition function](canonical-partition-function.md) over [volume](volume.md) gives the displayed continuous-volume normalization. For a temperature-independent measure and Hamiltonian, $-\partial_\beta\ln\Delta=\langle E+PV\rangle$. Multiplying by a volume-independent prefactor leaves normalized volume probabilities unchanged, but a temperature-dependent prefactor changes this derivative.
