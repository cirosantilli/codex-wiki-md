# Term-generated model

↑ **Parent:** [First-order structure](first-order-structure.md)

A term-generated model has every element denoted by a [closed term](closed-term.md) of its original language. Each element is then parameter-free definable by an equation $x=t$. A [term model](term-model.md) of a complete Henkin theory is a syntactic construction with this property, but “term-generated” can be stated for an arbitrary structure without choosing such a construction.
