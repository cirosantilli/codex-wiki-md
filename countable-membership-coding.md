# Countable membership coding

↑ **Parent:** [Hereditarily countable set](hereditarily-countable-set.md)

A countable [well-founded relation](well-founded-relation.md) that is an [extensional relation](extensional-relation.md) codes a transitive set through the [Mostowski collapse theorem](mostowski-collapse-theorem.md). Adding a distinguished point selects one decoded set. Every [hereditarily countable set](hereditarily-countable-set.md) has such a code by enumerating its transitive membership ancestry. There are only continuum many codes. In [ZFC](zermelo-fraenkel-set-theory-with-choice.md), selecting least codes in a well-order gives an injection of the hereditarily countable sets into a set of size $2^{\aleph_0}$.
