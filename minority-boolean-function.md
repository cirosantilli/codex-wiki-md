# Minority Boolean function

↑ **Parent:** [Boolean function](boolean-function.md)

For an [odd number](odd-number.md) of input [bits](bit.md), this [Boolean function](boolean-function.md) is one exactly when fewer than half of the inputs are one. For three inputs, $m(a,b,c)=\neg a\neg b\lor\neg a\neg c\lor\neg b\neg c$. Each term says that a specified pair of inputs is zero; at most one input can then be one. This proves both directions of the formula.
