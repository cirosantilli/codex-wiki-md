# Principal Weil divisor

↑ **Parent:** [Weil divisor](weil-divisor.md)

On a normal integral Noetherian scheme, a nonzero rational function defines the displayed [Weil divisor](weil-divisor.md), with the sum over codimension-one prime divisors. The [local ring](local-ring.md) at each such divisor is a [discrete valuation ring](discrete-valuation-ring.md), so the order is well defined. The [divisor class group](divisor-class-group.md) is the group of [Weil divisors](weil-divisor.md) modulo principal Weil divisors. On a smooth curve this agrees with a [principal divisor on an algebraic curve](principal-divisor-on-an-algebraic-curve.md).
