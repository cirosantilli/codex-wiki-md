# Sparse matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sparse_matrix)

A sparse matrix has few nonzero [matrix elements](matrix-element.md) in each row or column compared with its dimension. Algorithms normally require an efficient oracle that lists the positions and values of those entries.
