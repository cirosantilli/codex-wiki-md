# End (topology)

↑ **Parent:** [Topology](topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/End_(topology))

An end of a noncompact [topological space](topological-space.md) describes a coherent way to escape every compact subset. For a cofinal compact exhaustion, when one exists, $K_1\subseteq K_2\subseteq\cdots$, it is represented by nested connected components of the complements. A connected noncompact manifold is [disconnected at infinity](disconnected-at-infinity.md) when it has more than one end.
