# Galaxy stellar mass function

↑ **Parent:** [Galaxy stellar mass](galaxy-stellar-mass.md)

The [galaxy stellar mass function](galaxy-stellar-mass-function.md) counts galaxies per stellar-mass interval and volume, often using [comoving volume](comoving-volume.md). Its stellar-mass moment gives the [cosmic stellar mass density](cosmic-stellar-mass-density.md), while its number moment counts galaxies only if the low-mass population is integrable or truncated. It differs from the initial mass function of individual stars.
