# Integer string oscillator level

↑ **Parent:** [String level operator](string-level-operator.md)

The [canonical commutation relations](canonical-commutation-relation.md) imply $[N,\alpha_{-k}^i]=k\alpha_{-k}^i$ for $N=\sum_{k>0}\alpha_{-k}\cdot\alpha_k$. With zero level assigned to the [oscillator vacuum](oscillator-vacuum.md), a [Fock space](fock-space.md) basis state containing $r_{ki}$ [creation operators](creation-operator.md) of each mode has level $\sum_{k,i}kr_{ki}$. The level is therefore a nonnegative integer; it counts oscillator excitation weighted by frequency, not simply the number of creation operators.
