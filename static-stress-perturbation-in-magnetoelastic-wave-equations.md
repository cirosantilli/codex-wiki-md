# Static stress perturbation in magnetoelastic wave equations

↑ **Parent:** [Magnetoelastic wave in an isotropic magnetic tangle](magnetoelastic-wave-in-an-isotropic-magnetic-tangle.md)

The linear system $\partial_tv_i=-\partial_i\pi+\partial_jm_{ij}$, $\partial_tm_{ij}=v_A^2(\partial_iv_j+\partial_jv_i)$ and $\nabla\cdot\mathbf v=0$ admits stationary [stress](stress.md) as well as propagating [waves](wave-split.md). For instance, $\mathbf v=0$, $m_{ij}=f(\mathbf r)\delta_{ij}$ and $\pi=f(\mathbf r)$ solve it for any sufficiently small smooth $f$. Thus arbitrary initial [magnetic second-moment tensor](magnetic-second-moment-tensor.md) perturbations need not be oscillatory.
