# Gradient constraint for unbounded consumption

↑ **Parent:** [Consumption satisfaction stock](consumption-satisfaction-stock.md)

If [consumption](consumption.md) contributes $c(V_\xi-V_w)$ to the [Hamilton-Jacobi-Bellman equation](hamilton-jacobi-bellman-equation.md) and has no finite upper bound, finite value requires $V_\xi\leq V_w$. Strict inequality makes zero [consumption](consumption.md) optimal locally. Equality describes an active transfer boundary, often reached through [singular consumption control](singular-consumption-control.md).
