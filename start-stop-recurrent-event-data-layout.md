# Start-stop recurrent-event data layout

↑ **Parent:** [Survival analysis](survival-analysis-split.md)

Represent each person's successive eligible episodes by separate left-open, right-closed intervals, retaining a common patient identifier and event-order information. A recurrence ends an interval and can be followed by another one; administrative censoring ends the final interval without an event. The row's entry time determines [risk set](risk-set.md) membership. Multiple rows remain one patient history, with possible [within-patient recurrent-event dependence](within-patient-recurrent-event-dependence.md).
