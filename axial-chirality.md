# Axial chirality

↑ **Parent:** [Chirality (chemistry)](chirality-chemistry.md)

An [allene](allene.md) has a $\mathrm{C=C=C}$ unit whose terminal [substituents](substituent.md) lie in perpendicular planes. In $\mathrm{abC=C=Ccd}$, with $a\ne b$ and $c\ne d$, the two terminal pairs can define [enantiomers](enantiomer.md) without any tetrahedral [carbon](carbon.md) [stereocenter](stereocenter.md). The groups need be different within each end pair, not all four mutually different. This is [axial chirality](axial-chirality.md).[Basic Terminology of Stereochemistry, entry Axial Chirality: nonplanar pairs about an axis, including allenes](basic-terminology-of-stereochemistry-by-g-p-moss/axial-chirality.md)
