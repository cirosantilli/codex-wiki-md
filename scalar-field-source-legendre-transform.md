# Scalar-field source Legendre transform

↑ **Parent:** [Landau-Ginzburg theory](landau-ginzburg-theory.md)

For a real statistical source convention $Z[h]=\int\mathcal D\phi\,e^{-H_0[\phi]+\int h\phi}$, define $F=-\log Z$ and the displayed [Legendre transform](convex-conjugate.md). On a differentiable stable branch, $\delta\Gamma/\delta m=h$. In the [Landau approximation](landau-approximation.md), the branch expression is $\Gamma_{\rm L}[m]=H_0[m]$. The exact Legendre effective [free energy](thermodynamic-free-energy.md) is convex; a bare nonconvex [Landau free energy](landau-free-energy.md) is a local approximation and requires branch or coexistence interpretation.
