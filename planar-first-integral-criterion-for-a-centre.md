# Planar first integral criterion for a centre

↑ **Parent:** [Center equilibrium](center-equilibrium.md)

Let $F$ be a continuously differentiable planar [vector field](vector-field.md) with an isolated [equilibrium point](equilibrium-point-of-a-dynamical-system.md) $p$, and let the twice continuously differentiable [first integral](first-integral.md) $H$ satisfy $F\cdot\nabla H=0$ and $\nabla H(p)=0$. If the [Hessian matrix](hessian-matrix.md) $D^2H(p)$ is positive or negative definite, then $p$ is a [centre equilibrium](center-equilibrium.md).

For a [positive-definite matrix](positive-definite-matrix.md), sufficiently short rays from $p$ have strictly increasing $H$ with radial [derivative](derivative.md) bounded below by a positive constant times distance. Every sufficiently small positive level difference therefore meets each ray exactly once, and the [implicit function theorem](implicit-function-theorem.md) makes these intersections a [simple closed curve](simple-closed-curve.md). These [regular level sets](regular-level-set.md) shrink to $p$; use $-H$ in the negative-definite case. The [vector field](vector-field.md) is tangent and nonzero on each such compact curve. Its speed is bounded away from zero, so a traversal takes finite time and each curve is a [periodic orbit](periodic-orbit.md). An arbitrary strict [local extremum](local-extremum.md) without these regularity and nondegeneracy conditions does not by itself supply this argument.
