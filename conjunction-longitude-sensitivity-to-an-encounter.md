# Conjunction-longitude sensitivity to an encounter

↑ **Parent:** [Conjunction-pattern precession near a mean-motion resonance](conjunction-pattern-precession-near-a-mean-motion-resonance.md)

For an exterior circular grain with [radiation-pressure coefficient](radiation-pressure-coefficient.md) $\beta$, set $q=\sqrt{1-\beta}$ and $\epsilon=a/a_p-1$. Its next [conjunction](conjunction-astronomy.md) occurs after the [synodic period](synodic-period.md), during which the planet's unwrapped [mean longitude](mean-longitude.md) advances by $\Lambda=2\pi/[1-q(1+\epsilon)^{-3/2}]$. A weak [planetary scattering](planetary-scattering.md) encounter changes this by $\delta\Lambda\simeq-3\pi q(1+\epsilon)^{-5/2}\delta\epsilon/[1-q(1+\epsilon)^{-3/2}]^2$. Unwrapped longitude counts turns; reducing it modulo $2\pi$ before comparison would erase this measure of timing sensitivity.
