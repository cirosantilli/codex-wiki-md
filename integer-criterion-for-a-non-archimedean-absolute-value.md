# Integer criterion for a non-Archimedean absolute value

↑ **Parent:** [Non-Archimedean absolute value](non-archimedean-absolute-value.md)

An [absolute value on a field](absolute-value-algebra.md) is non-Archimedean if and only if $|n\cdot1|\le1$ for every positive integer $n$. Necessity follows from the [ultrametric inequality](ultrametric-inequality.md). Conversely the binomial theorem gives $|x+y|^m\le(m+1)\max(|x|,|y|)^m$, since every binomial coefficient has absolute value at most one. Take $m$th roots and let $m\to\infty$. In particular an [extension of an absolute value](extension-of-an-absolute-value.md) that is non-Archimedean stays non-Archimedean.
