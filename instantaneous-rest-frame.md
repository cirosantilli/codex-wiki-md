# Instantaneous rest frame

↑ **Parent:** [Rest frame](rest-frame.md)

An inertial frame in which a selected body's velocity vanishes at one event on its worldline. For an accelerated body it is a local construction: rest frames at different events need not coincide, and simultaneity slices chosen at one event do not equal laboratory equal-time slices.
