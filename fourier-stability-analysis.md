# Fourier stability analysis

↑ **Parent:** [Finite difference method](finite-difference-method.md)

Fourier stability analysis transforms a translation-invariant finite-difference scheme into scalar or matrix recurrences indexed by wavenumber. The [Parseval identity](parseval-identity.md) then converts uniform multiplier bounds into discrete $2$-norm bounds.
