# Bjorken scaling

↑ **Parent:** [Parton model](parton-model.md)

At leading order in the naive [parton model](parton-model.md), dimensionless [deep-inelastic structure functions](deep-inelastic-structure-function.md) depend only on [Bjorken x](bjorken-x.md). [Quantum chromodynamics](quantum-chromodynamics.md) evolution introduces scale dependence.
