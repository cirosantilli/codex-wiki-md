# Model-based reinforcement learning

↑ **Parent:** [Reinforcement learning](reinforcement-learning.md)

Learning or using a model of transitions and outcomes to evaluate possible actions. It can support flexible replanning when the value of an outcome changes, but depends on the learned model and computational resources. Behavioural experiments must distinguish it from alternative strategies with similar observable predictions.
