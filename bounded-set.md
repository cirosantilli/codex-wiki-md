# Bounded set

↑ **Parent:** [Metric space](metric-space.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bounded_set)

A subset $A$ of a [metric space](metric-space.md) is bounded if it lies in some finite-radius ball: there are $x$ and $R<\infty$ such that $d(x,a)\leq R$ for every $a\in A$.
