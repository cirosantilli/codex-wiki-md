# Chain cycle

↑ **Parent:** [Chain complex](chain-complex.md)

An element of a [chain group](chain-group.md) is a cycle when its [boundary operator](boundary-operator.md) kills it. A cycle need not itself be a [chain boundary](chain-boundary.md). The [homology group](homology-group.md) $H_n(C)$ identifies cycles whose difference is a [chain boundary](chain-boundary.md).
