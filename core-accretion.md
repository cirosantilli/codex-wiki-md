# Core accretion

↑ **Parent:** [Planet formation](planet-formation.md)

Core accretion forms a planet by building a solid core through growth and accretion of solid material. A sufficiently massive core can then bind a gaseous envelope. It is distinct from direct fragmentation through [gravitational instability of an astrophysical disk](gravitational-instability-of-an-astrophysical-disk-split.md).
