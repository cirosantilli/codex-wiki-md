# Conjugacy-class generating function for finite general linear groups

↑ **Parent:** [General linear group over a finite field](general-linear-group-over-a-finite-field.md)

If $k_n(q)$ counts [conjugacy classes](conjugacy-class.md) in $GL_n(q)$, then $\sum_{n\ge0}k_n(q)t^n=\prod_{i\ge1}(1-t^i)/(1-qt^i)$. Associate a partition to each irreducible polynomial other than t. The Euler product over those polynomials counts monic polynomials with nonzero constant term and is $(1-u)/(1-qu)$.
