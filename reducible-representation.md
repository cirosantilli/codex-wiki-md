# Reducible representation

↑ **Parent:** [Invariant subspace](invariant-subspace.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reducible_representation)

A nonzero representation is reducible when it has a nonzero proper [invariant subspace](invariant-subspace.md); otherwise it is an [irreducible representation](irreducible-representation.md).
