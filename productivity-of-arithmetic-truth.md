# Productivity of arithmetic truth

↑ **Parent:** [Productive set](productive-set.md)

Uniformly diagonalize against the formula expressing membership in $W_e$ to obtain a sentence saying that its own code is not in $W_e$. If every enumerated sentence is true, this new sentence cannot be enumerated, and hence is true. Its code is a computable new element of [arithmetic truth](true-arithmetic.md) outside $W_e$.
