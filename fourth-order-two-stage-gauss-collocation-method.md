# Fourth-order two-stage Gauss collocation method

↑ **Parent:** [Gauss-Legendre method](gauss-legendre-method.md)

The two-stage [Gauss--Legendre Runge-Kutta method](gauss-legendre-method.md) uses nodes $c_{1,2}=1/2\mp\sqrt3/6$, weights $b_1=b_2=1/2$ and coefficients $a_{11}=a_{22}=1/4$, $a_{12}=1/4-\sqrt3/6$, $a_{21}=1/4+\sqrt3/6$. The [Butcher order conditions](butcher-order-condition.md) give order four. Its [stability function](stability-function.md) is the displayed rational function, which is [A-stable](a-stability.md). The [algebraic stability](algebraic-stability-of-a-runge-kutta-method.md) matrix is zero, so positive weights also give nonlinear contractivity for dissipative vector fields.
