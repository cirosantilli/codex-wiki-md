# Logical biconditional

↑ **Parent:** [Logical connective](logical-connective.md)

A binary [logical connective](logical-connective.md) true exactly when its two arguments have the same [truth value](truth-value.md). It is [logically equivalent](logical-equivalence.md) to $(P\to Q)\land(Q\to P)$, and hence to $(\neg P\lor Q)\land(\neg Q\lor P)$. Its [truth table](truth-table.md) has value one on input pairs $(0,0)$ and $(1,1)$, and zero on $(0,1)$ and $(1,0)$.
