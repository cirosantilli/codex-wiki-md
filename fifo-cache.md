# FIFO cache

↑ **Parent:** [FIFO page replacement](fifo-page-replacement.md)

A finite-capacity cache that evicts the oldest inserted item when full. A hit leaves the insertion order unchanged, so its behavior differs from an [LRU cache](lru-cache.md).
