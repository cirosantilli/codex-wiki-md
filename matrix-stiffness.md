# Matrix stiffness

↑ **Parent:** [Extracellular matrix](extracellular-matrix.md)

[Matrix stiffness](matrix-stiffness.md) describes resistance of an [extracellular matrix](extracellular-matrix.md) to deformation under a specified loading geometry and timescale. It differs from pore size, ligand density and fibre alignment, although changing a matrix formulation can alter all of them.
