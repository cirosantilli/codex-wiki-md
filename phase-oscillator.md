# Phase oscillator

↑ **Parent:** [Dynamical system](dynamical-system.md)

A model retaining an oscillation's phase while neglecting amplitude dynamics. Interactions can synchronize relative phases through [phase locking](phase-locking.md); noise can cause [phase slips](phase-slip.md). The [Adler phase equation](adler-phase-equation.md) is a simple example for a coupled relative phase.
