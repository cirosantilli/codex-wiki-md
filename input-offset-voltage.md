# Input offset voltage

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

The [input offset voltage](input-offset-voltage.md) of an [operational amplifier](operational-amplifier.md) is the differential direct-current input voltage needed to make its output zero at a specified operating point. Its effect resembles a small unwanted input signal and can cause sustained output drift in an [op amp integrator](op-amp-integrator.md).
