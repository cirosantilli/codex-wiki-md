# Standardization of a normal random variable

↑ **Parent:** [Standard normal distribution](standard-normal-distribution.md)

If $X\sim N(\mu,\sigma^2)$ with $\sigma>0$, then $(X-\mu)/\sigma$ has the [standard normal distribution](standard-normal-distribution.md).
