# Ergodicity criterion for a circle rotation

↑ **Parent:** [Irrational rotation](irrational-rotation.md)

The rotation $x\mapsto x+a$ of a circle of circumference $2\pi$ is ergodic exactly when $a/\pi$ is irrational. In the [Fourier basis](fourier-basis.md), an invariant function can have a nonzero $k$th coefficient only when $e^{ika}=1$.
