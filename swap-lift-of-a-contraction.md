# Swap lift of a contraction

↑ **Parent:** [Contraction mapping](contraction-mapping.md)

On the [maximum product metric](maximum-product-metric.md), the displayed map is nonexpansive when $f$ is a [contraction mapping](contraction-mapping.md). If the space has two distinct points, changing only the second input coordinate shows that one step preserves some nonzero distance exactly, so it is not itself a strict contraction. Two iterations apply $f$ to both coordinates and therefore contract with the same constant as $f$. This provides a direct example of a map whose iterate is contractive although the map is not.
