# Point spread function normalization

↑ **Parent:** [Point spread function](point-spread-function.md)

[Point spread function normalization](point-spread-function-normalization.md) specifies how the response is scaled. Unit-[integral](integral.md) scaling separates image shape from total [radiant flux](radiant-flux.md); unit-peak scaling compares shapes but does not make their total [radiant fluxes](radiant-flux.md) equal.
