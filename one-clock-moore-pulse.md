# One-clock Moore pulse

↑ **Parent:** [Moore machine](moore-machine.md)

Enter a distinguished [Moore machine](moore-machine.md) state whose output is active, and ensure that every outgoing transition leaves that state for an inactive-output state. The output then lasts one [clock period](clock-period.md). Its outgoing transitions may simultaneously recognize the start of the next event, avoiding an unnecessary idle cycle. The one-period statement refers to the synchronous logical model, with ordinary propagation delay after each [clock edge](clock-edge.md).
