# Generic filter

↑ **Parent:** [Forcing](forcing-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generic_filter)

A filter $G\subseteq\mathbb P$ is generic over a model $M$ when it meets every dense subset of $\mathbb P$ belonging to $M$.
