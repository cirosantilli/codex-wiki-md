# Permutation graph

↑ **Parent:** [Circle graph](circle-graph.md)

The [intersection graph](intersection-graph.md) of the segments in a [permutation diagram](permutation-diagram.md). Two segments cross exactly when their endpoint orders disagree. A set of mutually noncrossing segments corresponds to a monotone subsequence of the endpoint [permutation](permutation.md).
