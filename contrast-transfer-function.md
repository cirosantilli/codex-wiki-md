# Contrast transfer function

↑ **Parent:** [Electron microscope](electron-microscope.md)

The [contrast transfer function](contrast-transfer-function.md) describes how an imaging system transfers object information at different [spatial frequencies](spatial-frequency.md). In phase-contrast [electron microscopy](electron-microscopy.md), defocus and aberrations can suppress or reverse particular components, requiring calibrated correction and complementary data.
