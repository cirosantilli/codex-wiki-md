# Symmetric closure

↑ **Parent:** [Symmetric relation](symmetric-relation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Symmetric_closure)

The symmetric closure of a [binary relation](binary-relation.md) $R$ is $R\cup R^{-1}$, where $(x,y)\in R^{-1}$ means $(y,x)\in R$. Every [symmetric relation](symmetric-relation.md) containing $R$ contains all these reversed pairs, proving minimality.
