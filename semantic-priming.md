# Semantic priming

↑ **Parent:** [Cognitive psychology](cognitive-psychology.md)

A change in processing caused by a preceding meaning-related cue. Contrasting related and unrelated cues can reveal how representations influence later performance, but task expectations and response strategies must be controlled. Category-name cues can test whether [category typicality](category-typicality.md) affects processing beyond explicit ratings.
