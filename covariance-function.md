# Covariance function

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

The covariance function of a second-order [stochastic process](stochastic-process-split.md) $(X_t)$ is

$$
C(s,t)=\operatorname{Cov}(X_s,X_t).
$$

It is a [positive-semidefinite kernel](positive-semidefinite-kernel.md) and determines the [finite-dimensional distributions](finite-dimensional-distribution.md) of a centered [Gaussian process](gaussian-process.md).
