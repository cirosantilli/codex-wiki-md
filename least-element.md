# Least element

↑ **Parent:** [Greatest element and least element](greatest-element-and-least-element.md)

An element $\bot$ of a [partially ordered set](partially-ordered-set.md) $P$ is a least element if $\bot\leq x$ for every $x\in P$. A least element is unique: two such elements are below each other, so [antisymmetry](antisymmetry.md) makes them equal.
