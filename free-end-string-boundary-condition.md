# Free-end string boundary condition

↑ **Parent:** [Open-string endpoint momentum flux](open-string-endpoint-momentum-flux.md)

Free endpoint variations set the [open string](open-string.md) flux $eT^2X'_m+uP_m$ to zero. In a boundary-adapted temporal gauge, freedom to vary time forces $u=0$ at the end. Nonzero lapse then gives $X'^m=0$, a [Neumann boundary condition](neumann-boundary-condition.md).
