# Monomorphic type

↑ **Parent:** [Type system](type-system.md)

A [data type](data-type.md) without universally quantified type variables. During [Hindley-Milner type inference](hindley-milner-type-inference.md), every use of a lambda-bound parameter shares one type, even if that type initially contains unknowns to be unified. In contrast, suitable let-bound definitions may admit [let polymorphism](let-polymorphism.md).
