# Maslov map

↑ **Parent:** [Maslov index](maslov-index.md)

The Maslov map is well defined because every matrix in $O(n)$ has determinant $\pm1$. The loop

$$
t\longmapsto e^{\pi it}\mathbb R\oplus\mathbb R^{n-1}
$$

maps to $e^{2\pi it}$ and therefore has Maslov index one.
