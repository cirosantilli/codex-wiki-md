# Expected generation size in a Galton-Watson process

↑ **Parent:** [Galton-Watson process](galton-watson-process.md)

If a [Galton-Watson process](galton-watson-process.md) starts from one individual and has offspring mean $m$, conditioning on generation $n$ gives $\mathbb E[Z_{n+1}\mid Z_n]=mZ_n$. Induction therefore gives $\mathbb E[Z_n]=m^n$.
