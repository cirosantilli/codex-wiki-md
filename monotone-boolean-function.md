# Monotone Boolean function

↑ **Parent:** [Boolean function](boolean-function.md)

A Boolean function $f:\{0,1\}^n\to\{0,1\}$ is a [monotone function](monotonic-function.md) when $x_i\leq y_i$ for every $i$ implies $f(x)\leq f(y)$.
