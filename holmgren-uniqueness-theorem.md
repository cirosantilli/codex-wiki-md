# Holmgren uniqueness theorem

↑ **Parent:** [Cauchy-Kovalevskaya theorem](cauchy-kovalevskaya-theorem.md)

For a linear differential operator with [real analytic](real-analytic-function.md) coefficients, a classical solution with zero [Cauchy data](cauchy-data.md) on a [real analytic](real-analytic-function.md) [non-characteristic hypersurface](non-characteristic-hypersurface.md) vanishes locally near that [hypersurface](hypersurface.md). The solution itself need not be [real analytic](real-analytic-function.md). A proof solves the [real analytic](real-analytic-function.md) inhomogeneous [formal adjoint](formal-adjoint.md) problem against [polynomial](polynomial-split.md) sources, annihilates all [polynomial](polynomial-split.md) moments using boundary jets, and uses [polynomial](polynomial-split.md) density to force the solution to vanish.
