# Address bus

↑ **Parent:** [Shared computer bus](shared-computer-bus.md)

The [computer bus](computer-bus.md) path identifying the destination or location of a [bus transaction](bus-transaction.md). An initiator supplies an address; decoding selects the intended target. Address width describes the available address encodings, whereas [data bus](data-bus.md) width describes how many [bits](bit.md) can be carried at once.[AMBA Specification, revision 2.0, section 1.5, pp. 1-7–1-8: master, slave and address decoder](amba-specification-rev-2-0-by-arm-limited.md)
