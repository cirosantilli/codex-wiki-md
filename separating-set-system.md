# Separating set system

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)

A [set family](set-family.md) on a finite [set](set-split.md) separates ordered pairs if each ordered pair of distinct points has a member containing the first point and omitting the second. If its members are $A_1,\ldots,A_m$, assign each point the [characteristic vector](characteristic-vector-of-a-set.md) of its incidences, or equivalently $T_i=\{a:i\in A_a\}$. Separation in both directions says precisely that the $T_i$ form an [antichain](antichain.md) in the [Boolean lattice](boolean-lattice.md) on $m$ coordinates. Thus the [Sperner theorem](sperner-s-theorem.md) gives $n\leq\binom m{\lfloor m/2\rfloor}$. Conversely, any [antichain](antichain.md) of $n$ distinct subsets of $[m]$ supplies such a [set family](set-family.md) by transposing its incidence table.
