# Derived inference rule

↑ **Parent:** [Inference rule](inference-rule.md)

A [derived inference rule](derived-inference-rule.md) abbreviates a [logical derivation](logical-derivation.md) from the primitive [inference rules](inference-rule.md). Its use retains the assumptions and side conditions required by that [logical derivation](logical-derivation.md); proving the abbreviation once allows subsequent [proofs](mathematical-proof.md) to use the rule without expanding every intermediate line.
