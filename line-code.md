# Line code

↑ **Parent:** [Computer network](computer-network-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Line_code)

A [line code](line-code.md) maps data to a sequence of physical signal levels or transitions for transmission. Timing, polarity and the length of runs of equal levels affect the choice.
