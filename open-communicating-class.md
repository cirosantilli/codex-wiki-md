# Open communicating class

↑ **Parent:** [Communicating class](communicating-class.md)

A [communicating class](communicating-class.md) of a [Markov chain](markov-chain.md) is open when a state in the class has positive probability of transitioning to a state outside it. Once a path leaves, it cannot return to the class: a return path would make the outside state communicate with the class. Every open class consists of [transient states](transient-state.md). Conversely, a finite transient [communicating class](communicating-class.md) is open; an infinite [closed communicating class](closed-communicating-class.md) can be transient.
