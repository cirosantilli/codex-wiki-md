# Dependent set of a matroid

↑ **Parent:** [Matroid](matroid.md)

A [matroid dependent set](dependent-set-of-a-matroid.md) is a [subset](subset.md) of the [ground set](ground-set.md) that is not a [matroid independent set](independent-set-of-a-matroid.md). By heredity, every [subset](subset.md) containing a [matroid dependent set](dependent-set-of-a-matroid.md) is also dependent. Distinct [nonloops](nonloop-of-a-matroid.md) are [parallel elements of a matroid](parallel-elements-of-a-matroid.md) exactly when their pair is a [matroid dependent set](dependent-set-of-a-matroid.md).
