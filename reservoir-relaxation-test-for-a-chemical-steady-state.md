# Reservoir relaxation test for a chemical steady state

↑ **Parent:** [Steady-state approximation](steady-state-approximation.md)

For $dX/dt=P-kX$ with locally fixed coefficients, $X(t)=P/k+(X_0-P/k)e^{-kt}$. Setting $dX/dt\simeq0$ requires $1/k$ to be short compared with changes in production, loss and transport. A major reservoir can fail this test even when nearby [radicals](radical-chemistry.md) rapidly adjust.
