# Cylinder function on a product space

↑ **Parent:** [Product topology](product-topology.md)

A function on a [Cartesian product](cartesian-product.md) is a cylinder function if it depends on only finitely many coordinates. With finite discrete coordinate spaces it is a [continuous function](continuous-function.md) in the [product topology](product-topology.md). These functions determine finite-dimensional laws and provide a natural domain for local generators of [interacting particle systems](interacting-particle-system.md).
