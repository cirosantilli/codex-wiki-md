# Integral first-order Taylor formula for a vector map

↑ **Parent:** [Taylor theorem](taylor-theorem.md)

For a continuously differentiable [vector-valued function](vector-valued-function.md) whose domain contains the segment from $x$ to $x+h$, apply the [fundamental theorem of calculus](fundamental-theorem-of-calculus.md) componentwise to $t\mapsto F(x+th)$. The resulting integral matrix is valid even when there is no common intermediate point giving a vector mean-value formula. For a [score function](informant-function.md), it integrates the [Hessian matrix](hessian-matrix.md) along the segment to a candidate estimate.
