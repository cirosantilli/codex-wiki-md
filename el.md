# EL

↑ **Parent:** [Description logic](description-logic.md)

The [description logic](description-logic.md) generated by atomic concepts, $\top$, conjunction and existential restrictions. Some conventions also allow $\bot$; that extension is distinguished here as [EL with bottom](el-with-bottom.md). Without $\bot$, every concept is satisfiable with respect to every [EL](el.md) [TBox](tbox.md).
