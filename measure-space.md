# Measure space

↑ **Parent:** [Measure](measure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Measure_space)

A measure space is a set $X$, a [sigma-algebra](sigma-algebra.md) $\mathcal M$ on it, and a [measure](measure.md) $\mu$ defined on $\mathcal M$.
