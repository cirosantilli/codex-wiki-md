# Interferometry

↑ **Parent:** [Interference (wave propagation)](interference-wave-propagation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Interferometry)

Measurement using [wave interference](interference-wave-propagation.md): relative path or phase changes are inferred from the resulting signal. The interacting fields must have sufficient [optical coherence](optical-coherence.md) in the measured modes for the intended interference signal.
