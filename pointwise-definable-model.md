# Pointwise definable model

↑ **Parent:** [Definable element of a first-order structure](definable-element-of-a-first-order-structure.md)

Every element of a pointwise definable model is uniquely specified by a formula with no added parameters. Finite tuples are then uniquely specified by conjunctions of their defining formulas. For a [complete theory](complete-theory.md) these formulas isolate the tuple types, so such a model is an [atomic model](atomic-model.md). The converse fails: a [countable](countable-set.md) [dense linear order without endpoints](dense-linear-order-without-endpoints.md) with a named point is atomic, while its other points are moved by [structure automorphisms](automorphism-of-a-first-order-structure.md) fixing that point.
