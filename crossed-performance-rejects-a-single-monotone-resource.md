# Crossed performance rejects a single monotone resource

↑ **Parent:** [Double dissociation](double-dissociation.md)

Suppose performances on fixed tasks $A$ and $B$ are $f_A(r)$ and $f_B(r)$, where both [functions](function-split.md) are [nondecreasing](nondecreasing-function.md) in the same [scalar](scalar.md) resource $r$. If patient $P$ performs strictly better than $Q$ on $A$, then $r_P>r_Q$: the reverse ordering would contradict monotonicity. If $Q$ performs strictly better on $B$, the same argument gives $r_Q>r_P$, a contradiction. Thus a genuine crossover rejects this single-resource model.

The conclusion depends on the fixed mappings and task comparability. It does not prove isolated anatomical stores, and it need not apply when patients differ in strategy, sensory access or other task parameters.
