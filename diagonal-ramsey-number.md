# Diagonal Ramsey number

↑ **Parent:** [Ramsey theorem](ramsey-theorem.md)

The diagonal Ramsey number $R(t)$ is the least $n$ such that every red-blue edge-colouring of $K_n$ contains a monochromatic $K_t$.
