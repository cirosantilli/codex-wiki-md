# Multi-head attention

↑ **Parent:** [Self-attention](self-attention.md)

Several independently learned query, key, and value projections apply [scaled dot-product attention](scaled-dot-product-attention.md) in parallel. Concatenating their outputs and applying a learned output projection allows different heads to mix sequence information using different learned representations.
