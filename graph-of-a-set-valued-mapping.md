# Graph of a set-valued mapping

↑ **Parent:** [Set-valued mapping](set-valued-mapping.md)

The graph is $\operatorname{gph}S=\{(u,v):v\in S(u)\}$. Local graph normals encode the [Mordukhovich coderivative](limiting-coderivative.md) and hence the [Aubin property](aubin-property.md). Graph closedness is a local hypothesis in the sensitivity criterion.
