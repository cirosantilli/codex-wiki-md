# Decidability in a set-valued functor category

↑ **Parent:** [Decidable object in a topos](decidable-object-in-a-topos.md)

A covariant set-valued functor $F$ is a decidable object precisely when every transition map $F(u)$ is injective. The pointwise complement of its diagonal consists of unequal pairs; it is a subfunctor exactly when transition maps preserve inequality. For left [M-sets](m-set.md), this says that every action map is injective.
