# Einstein-de Sitter cumulative number counts

↑ **Parent:** [Comoving number density](comoving-number-density.md)

For constant [comoving number density](comoving-number-density.md) and complete selection in a spatially flat [Einstein-de Sitter universe](einstein-de-sitter-universe.md), integrate the present-epoch shell volume up to the population's formation [redshift](redshift.md). The radial distance is $D_M=2c[1-(1+z)^{-1/2}]/H_0$, so the count per unit [solid angle](solid-angle.md) is $n_0D_M^3(z_f)/3$. It tends to a finite value as $z_f$ tends to infinity because this model's present comoving particle-horizon radius is $2c/H_0$. Formation, mergers or an incomplete observed sample change this ideal count.
