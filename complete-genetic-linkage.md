# Complete genetic linkage

↑ **Parent:** [Genetic linkage](genetic-linkage.md)

[Complete linkage](complete-genetic-linkage.md) in a two-locus model means [recombination fraction](recombination-fraction.md) zero: only parental [haplotype](haplotype.md) combinations are transmitted. Multiple [genetic markers](genetic-marker.md) in a nonrecombining block represent one [haplotype](haplotype.md) segregation observation.
