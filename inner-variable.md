# Inner variable

↑ **Parent:** [Inner expansion](inner-expansion.md)

An inner variable is a stretched coordinate such as $\xi=(x-x_0)/\delta(\epsilon)$ that remains order one inside a thin region of width $\delta(\epsilon)$.
