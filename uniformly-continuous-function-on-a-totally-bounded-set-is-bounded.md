# Uniformly continuous function on a totally bounded set is bounded

↑ **Parent:** [Uniform continuity](uniform-continuity.md)

Choose the [uniform continuity](uniform-continuity.md) input tolerance corresponding to output tolerance one. A [totally bounded](totally-bounded-space.md) domain is covered by finitely many balls of smaller radius centred in the domain. Every function value differs by less than one from the value at one of their finitely many centres. Taking the largest centre value bounds the whole function. Compactness or closedness of the domain is unnecessary.
