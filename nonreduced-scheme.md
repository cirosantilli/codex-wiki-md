# Nonreduced scheme

↑ **Parent:** [Scheme](scheme.md)

A scheme is nonreduced when its structure sheaf contains a nonzero [nilpotent element](nilpotent.md). For an affine scheme $\operatorname{Spec}(A/I)$, this is equivalent to the ideal $I$ not being radical.
