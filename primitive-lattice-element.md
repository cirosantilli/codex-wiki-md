# Primitive lattice element

↑ **Parent:** [Free abelian group](free-abelian-group.md)

A nonzero element of a [free abelian group](free-abelian-group.md) is primitive when it is part of an integral basis, equivalently when some homomorphism to $\mathbb Z$ takes it to one. Its coordinates have [greatest common divisor](greatest-common-divisor.md) one. This lattice meaning differs from a [primitive homology class](primitive-homology-class.md) in the coalgebra sense.
