# Every proper orthochronous Lorentz transformation is an exponential

↑ **Parent:** [Proper orthochronous Lorentz group](proper-orthochronous-lorentz-group.md)

Use the [Lorentz spinor double cover](lorentz-spinor-double-cover.md) $SL(2,\mathbb C)\to SO^+(1,3)$. For a lift with distinct eigenvalues $\lambda,\lambda^{-1}$, diagonalize and choose logarithms $z,-z$; this gives a traceless matrix logarithm. For a repeated eigenvalue, choose the sign of the lift so it is $I+N$, where $N^2=0$, and use $\log(I+N)=N$. The two lifts have the same Lorentz image. Exponentiating the differential of the covering map therefore expresses every proper orthochronous transformation as the exponential of a real element of the [Lie algebra of the Lorentz group](lie-algebra-of-the-lorentz-group.md). This argument does not assert that every element of $SL(2,\mathbb C)$ itself has a traceless logarithm.
