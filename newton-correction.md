# Newton correction

↑ **Parent:** [Newton system](newton-system.md)

The correction is the vector obtained by solving the [Newton system](newton-system.md), added to the current point to give $x_{\mathrm{new}}=x+\delta$. The inverse notation specifies the solution; a numerical implementation normally solves a [linear system](system-of-linear-equations.md) rather than forming a [matrix inverse](matrix-inverse-split.md).
