# X unit

↑ **Parent:** [Relative X-ray wavelength calibration](relative-x-ray-wavelength-calibration.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/X_unit)

The historical [X unit](x-unit.md) was a practical [X-ray](x-ray.md) [wavelength](wavelength.md) unit, approximately $10^{-13}\,\mathrm m$. Its scale used an assigned calcite spacing; relative [wavelength](wavelength.md) measurements could be more precise than absolute determinations. Variation between crystal specimens led to calibration using reference [spectral lines](spectral-line.md). An [X unit](x-unit.md) value therefore cannot simply be read as an exact multiple of $10^{-13}\,\mathrm m$.[IUPAC, Nomenclature system for X-ray spectroscopy, §5.1 Units, printed p. 745](nomenclature-system-for-x-ray-spectroscopy-prepared-by-r-jenkins-and-others.md)

An angular-scale check determines how an indicated rotation corresponds to an angle. A reference line transfers a [wavelength](wavelength.md) scale. An absolute determination ties that scale to an independently established [length](length.md) standard. These are different calibration tasks. Repeating measurements can reduce random scatter without correcting the common scale: if every inferred $d$ is too large by a chosen $0.1\%$, all inferred absolute [wavelengths](wavelength.md) are too large by $0.1\%$, while ratios using that same $d$ are unchanged.
