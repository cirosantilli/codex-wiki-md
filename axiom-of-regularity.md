# Axiom of regularity

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Axiom_of_regularity)

Every nonempty set $A$ has an element $x\in A$ such that $x\cap A=\varnothing$.
