# Out-of-order execution

↑ **Parent:** [Central processing unit](central-processing-unit.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Out-of-order_execution)

Executing ready instructions before older instructions whose operands or resources are unavailable, while preserving the specified architectural behavior. [Reservation stations](reservation-station.md), [register renaming](register-renaming.md) and a [reorder buffer](reorder-buffer.md) support different parts of this organization.
