# Client-server model

↑ **Parent:** [Distributed system](distributed-system.md)

In the [client-server model](client-server-model.md), a [network client](network-client.md) requests a service supplied by a [network server](network-server.md). It can be used within a federated deployment or a centralised one; it does not by itself determine whether an application respects the [end-to-end principle](end-to-end-principle.md).
