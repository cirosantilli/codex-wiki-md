# CP-conjugate decay-amplitude ratio

↑ **Parent:** [Neutral meson mixing](neutral-meson-mixing.md)

For $\lambda_f=(q/p)\bar A_f/A_f$, exchanging both initial [flavour](flavor-eigenstate.md) and final-state labels defines $\bar\lambda_{\bar f}=(p/q)A_{\bar f}/\bar A_{\bar f}$. It equals $\lambda_f^{-1}$ exactly when $A_{\bar f}/\bar A_{\bar f}=A_f/\bar A_f$. This holds for a common [CP eigenstate](cp-eigenstate.md) final ray. [CP symmetry](cp-symmetry.md) of paired amplitudes alone does not imply it for distinct final states: $p=q$, $A_f=\bar A_{\bar f}=2$, $\bar A_f=A_{\bar f}=1$ gives both ratios $1/2$.
