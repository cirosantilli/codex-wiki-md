# Declustering of extremes

↑ **Parent:** [Peaks-over-threshold method](peaks-over-threshold-method.md)

Declustering groups dependent threshold exceedances into extreme-event clusters and retains a representative, commonly the cluster maximum. It aims to make the events used in a [peaks-over-threshold method](peaks-over-threshold-method.md) approximately independent. The event rate must be estimated consistently with the retained clusters when computing [return levels](return-level.md).
