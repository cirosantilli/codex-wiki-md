# Protein interaction network

↑ **Parent:** [Protein](protein-split.md)

A [protein interaction network](protein-interaction-network.md) represents [proteins](protein-split.md) as nodes and supported associations as edges. Edges should retain evidence type, because copurification, direct [protein-protein interaction](protein-protein-interaction.md) and [proximity labeling](proximity-labeling.md) answer different questions.
