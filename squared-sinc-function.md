# Squared sinc function

↑ **Parent:** [Fourier transform of a triangular function](fourier-transform-of-a-triangular-function.md)

The squared sinc function is nonnegative and integrable; it occurs as the Fourier transform of a triangular function.

It is the pointwise square of the [sinc function](sinc-function.md), with its normalization inherited from that function.
