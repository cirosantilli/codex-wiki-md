# Type parameter

↑ **Parent:** [Parametric polymorphism](parametric-polymorphism.md)

A type parameter is a named variable ranging over admissible types in a generic definition. Instantiation substitutes a particular [type argument](type-argument.md), allowing one declaration to retain type information across uses. An [upper type bound](upper-type-bound.md) restricts the admissible arguments; a variance annotation instead describes how instantiated types participate in [subtyping](subtyping.md).
