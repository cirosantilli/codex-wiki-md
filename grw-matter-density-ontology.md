# GRW matter-density ontology

↑ **Parent:** [Ghirardi-Rimini-Weber theory](ghirardi-rimini-weber-theory.md)

A version of the [GRW model](ghirardi-rimini-weber-theory.md) in which matter is the ordinary-space density $m(x,t)=\sum_i m_i\int dq\,\delta^{(3)}(x-q_i)|\Psi(q,t)|^2$. This density is proposed as physical matter, rather than ignorance over hidden point positions. A dominant localized density supplies approximate object locations.
