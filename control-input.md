# Control input

↑ **Parent:** [Control theory](control-theory-split.md)

A chosen input to a dynamical system, commonly written $u(t)$ in the state equation $\dot x=f(t,x,u)$. An [optimal control](optimal-control.md) problem specifies both the admissible input set and any information or regularity constraints on the choice.
