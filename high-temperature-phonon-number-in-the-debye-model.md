# High-temperature phonon number in the Debye model

↑ **Parent:** [Debye model](debye-model.md)

For three-dimensional [Debye model](debye-model.md) mode density $D(\omega)=9N\omega^2/\omega_D^3$, the [Bose-Einstein distribution](bose-einstein-distribution.md) becomes $n_\omega\simeq k_BT/(\hbar\omega)$ when $T\gg\Theta_D$. Integrating the occupations gives $N_{\mathrm{ph}}\simeq(9/2)NT/\Theta_D$. The number of [phonon](phonon.md) quanta is not the number $3N$ of vibrational modes and need not be bounded by it. If a stipulated [electron-phonon scattering](electron-phonon-scattering.md) model makes resistivity proportional to this [phonon](phonon.md) number with a temperature-independent coefficient, the high-temperature [electrical resistivity](electrical-resistivity.md) is proportional to $T$.
