# Matrix addition

↑ **Parent:** [Matrix](matrix.md)

Matrices of the same shape are added entry by entry. For fixed dimensions over a field, this operation and scalar multiplication make the matrices a [vector space](vector-space-split.md). A [matrix product](matrix-product.md) has a different dimension-matching rule: its inner dimensions must agree, whereas addition requires the entire shapes to agree.
