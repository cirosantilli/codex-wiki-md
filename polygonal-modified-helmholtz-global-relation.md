# Polygonal modified Helmholtz global relation

↑ **Parent:** [Global relation for a linear boundary value problem](global-relation-for-a-linear-boundary-value-problem.md)

For $u_{z\bar z}=\beta^2u$, pull back its spectral [closed differential one-form](closed-differential-one-form.md) along each straight side $z=m_j+sh_j$. Under counterclockwise traversal and outward [normal derivatives](normal-derivative.md) $q_j$, the side density is $i e^{-i\beta(\lambda z-\bar z/\lambda)}[|h_j|q_j+\beta(\lambda h_j+\bar h_j/\lambda)g_j]$, where $g_j$ is the [Dirichlet boundary data](dirichlet-boundary-data.md). The [Generalized Stokes theorem](generalized-stokes-theorem.md) gives the displayed [global relation](global-relation-for-a-linear-boundary-value-problem.md). Clockwise traversal reverses the normal-derivative coefficient; all orientations must be changed consistently.
