# Shift-invariant graph groups encode arbitrary sets

↑ **Parent:** [Word problem for groups](word-problem-for-groups.md)

For $S\subseteq\mathbb N_{>0}$, form the [Right-angled Artin group](right-angled-artin-group.md) on generators $b_i$ indexed by $i\in\mathbb Z$, imposing $[b_i,b_j]=1$ precisely when $|i-j|\in S$. Translation $b_i\mapsto b_{i+1}$ is an automorphism. Its [semidirect product](semidirect-product.md) with an infinite cyclic group generated by $t$ is countable and generated by $b_0,t$. If $n\notin S$, killing all $b_i$ except $b_0,b_n$ retracts the graph group onto the rank-two [free group](free-group.md), so their commutator is nonidentity. This proves the displayed equivalence. For non-recursively-enumerable $S$, [enumerable identities of finitely generated subgroups](enumerable-identities-of-finitely-generated-subgroups.md) rules out an embedding of this two-generated group in any finitely presented group.
