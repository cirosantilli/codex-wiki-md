# Fixed-interior-point avoidance of SLE4

↑ **Parent:** [Logarithmic martingale for SLE4](logarithmic-martingale-for-sle4.md)

Every fixed $z\in\mathbb H$ has infinite [interior-point swallowing time for a Loewner chain](interior-point-swallowing-time-for-a-loewner-chain.md) under [Schramm–Loewner evolution](schramm-loewner-evolution.md) at $\kappa=4$. The centered flow is bounded on any finite horizon, making $\log|Z_t|$ bounded above. The [one-sided bound criterion for a martingale clock](one-sided-bound-criterion-for-a-martingale-clock.md) gives a finite logarithmic limit at any putative finite swallowing time. Thus $|Z_t|$ stays away from zero and the imaginary coordinate remains positive, so the differential equation extends, a contradiction. In particular the trace misses each fixed interior point almost surely.
