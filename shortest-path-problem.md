# Shortest path problem

↑ **Parent:** [Graph theory](graph-theory-split.md)

A shortest path minimizes the sum of edge lengths between two vertices. With nonnegative lengths, a shortest walk can be reduced to a simple path by removing cycles, so exponentially many candidate paths can be searched implicitly. The [Dijkstra algorithm](dijkstra-algorithm.md) solves this problem in [polynomial time](polynomial-time.md).
