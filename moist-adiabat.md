# Moist adiabat

↑ **Parent:** [Adiabatic process](adiabatic-process.md)

A thermodynamic path for saturated adiabatic displacement including latent heating from condensation. A pseudoadiabatic model removes condensate, while a reversible model retains it; they need not have the same [heat capacity](heat-capacity.md) or condensate loading.
