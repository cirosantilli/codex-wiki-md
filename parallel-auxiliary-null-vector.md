# Parallel auxiliary null vector

↑ **Parent:** [Null geodesic congruence](null-geodesic-congruence.md)

For an affine [null geodesic congruence](null-geodesic-congruence.md) with future tangent $U$, choose a future unit [timelike vector](timelike-vector.md) $T$ on a transverse section, put $E=-U\cdot T$, and set $N=T/E-U/(2E^2)$ there. It has $N^2=0$ and $U\cdot N=-1$. [Parallel transport](parallel-transport.md) along each generator preserves these contractions by metric compatibility and $\nabla_UU=0$. The construction is local up to caustics and supplies the auxiliary normal for a [screen-space projector](screen-space-projector.md).
