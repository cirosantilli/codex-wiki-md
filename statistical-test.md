# Statistical test

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test.md)

A statistical test is a measurable rule for deciding whether to reject a [null hypothesis](null-hypothesis.md). Allowing randomisation, it is represented by a function $\varphi(x)\in[0,1]$ giving the conditional rejection [probability](probability.md) after observing $x$. A deterministic test takes only values zero and one. Under a simple null, $E_0\varphi$ is its [size of a statistical test](size-of-a-statistical-test.md); under an alternative, $E_1\varphi$ is its [statistical power](statistical-power.md). Randomisation on a [likelihood ratio](likelihood-ratio.md) equality set allows a [Neyman-Pearson lemma](neyman-pearson-lemma.md) threshold test to attain a prescribed size even for discrete data.
