# Von Mangoldt function

↑ **Parent:** [Arithmetic function](arithmetic-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Von_Mangoldt_function)

The Von Mangoldt function is $\Lambda(n)=\log p$ when $n$ is a positive power of a [prime number](prime-number.md) $p$, and is zero otherwise.
