# Thermodynamic linkage

↑ **Parent:** [Allostery](allostery.md)

Coupling between equilibria such that favouring one state changes another measured equilibrium. For example, preferential [ligand](ligand-biochemistry.md) binding to an assembled state can shift an assembly equilibrium; the coupling follows from consistent free-energy differences around the thermodynamic cycle.
