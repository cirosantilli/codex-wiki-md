# Working memory capacity

↑ **Parent:** [Working memory](working-memory.md)

The amount of information that can be retained under specified task and measurement conditions. Behavioral estimates depend on stimulus complexity, interference and the assumed response model; a physiological plateau does not alone establish a universal fixed slot count.
