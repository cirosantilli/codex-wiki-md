# Missing common-neighbour count in a binomial random graph

↑ **Parent:** [Binomial random graph](binomial-random-graph.md)

Let $X$ count unordered [vertex](vertex-graph-theory.md) pairs with no [common neighbour](common-neighbour.md) in a [binomial random graph](binomial-random-graph.md). Each other [vertex](vertex-graph-theory.md) provides the required pair of [edges](edge-of-a-graph.md) independently, with success probability $p^2$. A fixed pair has no common neighbour with probability $(1-p^2)^{n-2}$. Summing its indicators gives the displayed [expectation](expected-value.md).
