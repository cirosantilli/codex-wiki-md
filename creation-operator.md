# Creation operator

↑ **Parent:** [Creation and annihilation operators](creation-and-annihilation-operators.md)

A creation operator raises the occupation [number operator](number-operator.md) eigenvalue of a [quantum harmonic oscillator](quantum-harmonic-oscillator.md) by one. Repeated application builds [Fock states](fock-state.md).
