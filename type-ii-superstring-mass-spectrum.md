# Type II superstring mass spectrum

↑ **Parent:** [Type II string theory](type-ii-string-theory.md)

The four-point tree amplitude exposes poles at $M_n^2=4n/\alpha'$ for $n=0,1,2,\ldots$. The $n=0$ level is massless, and positive $n$ form an infinite tower of massive string excitations.
