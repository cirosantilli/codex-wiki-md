# Thermally activated phase slip

↑ **Parent:** [Phase slip](phase-slip.md)

A noise-driven barrier crossing between adjacent phase-locked wells. The [Kramers escape rate](kramers-escape-rate.md) is proportional to $e^{-\Delta V/T_{\rm eff}}$ when a mobility-one [Langevin equation](langevin-dynamics.md) has white-noise [covariance](covariance.md) $2T_{\rm eff}\delta(t-t')$. Both the barrier and local relaxation time determine whether an [intrawell phase autocorrelation](intrawell-phase-autocorrelation.md) approximation is appropriate.
