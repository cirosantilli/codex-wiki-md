# Remote state invariance under a local trace-preserving operation

↑ **Parent:** [No-communication theorem](no-communication-theorem.md)

For local [Kraus operators](kraus-operator.md) $A_i$ with $\sum_iA_i^\dagger A_i=I$, let $\rho'_{AB}=\sum_i(A_i\otimes I)\rho_{AB}(A_i^\dagger\otimes I)$. For every remote operator $B$, cyclicity of the [trace](matrix-trace.md) gives $\operatorname{Tr}[(I\otimes B)\rho'_{AB}]=\sum_i\operatorname{Tr}[(A_i^\dagger A_i\otimes B)\rho_{AB}]=\operatorname{Tr}[(I\otimes B)\rho_{AB}]$. Hence the remote [reduced density matrix](reduced-density-matrix.md) is unchanged. In particular every remote [POVM](positive-operator-valued-measure.md) has the same outcome probabilities, proving the [no-communication theorem](no-communication-theorem.md) from the measurement rule rather than assuming it as a physical postulate.
