# AND gate

↑ **Parent:** [Logical conjunction](logical-conjunction.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/AND_gate)

An [AND gate](and-gate.md) computes $a\land b=ab$ for bits $a,b$. It is irreversible when only its one-bit output is retained. The [Toffoli gate](toffoli-gate.md) embeds the operation reversibly as $(a,b,c)\mapsto(a,b,c\oplus ab)$; setting $c=0$ preserves the inputs while recording their [logical conjunction](logical-conjunction.md).
