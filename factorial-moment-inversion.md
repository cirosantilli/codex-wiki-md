# Factorial-moment inversion

↑ **Parent:** [Factorial moment](factorial-moment.md)

For a nonnegative integer-valued [random variable](random-variable-split.md), the displayed inversion is valid when $\mathbb E(X)_s s^k/s!\to0$. Indeed the gap between consecutive [Jordan-Bonferroni exact-occurrence inequalities](jordan-bonferroni-exact-occurrence-inequalities.md) is $\mathbb E(X)_{k+m+1}/[k!(m+1)!]$, which tends to zero under this hypothesis. No exchange of an infinite signed sum with an [expectation](expected-value.md) is needed.
