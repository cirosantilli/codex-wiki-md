# Variable ordering of a binary decision diagram

↑ **Parent:** [Ordered binary decision diagram](ordered-binary-decision-diagram.md)

A fixed order in which [Boolean variables](boolean-variable.md) may be tested along each branch of an ordered [binary decision diagram](binary-decision-diagram.md). Branches may skip a test, but cannot reverse the order. The order can change the number of distinct remaining [Boolean cofactors](boolean-cofactor.md) and therefore the size of the representation.
