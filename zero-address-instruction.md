# Zero-address instruction

↑ **Parent:** [Instruction set architecture](instruction-set-architecture.md)

An instruction whose encoding contains no explicit operand addresses. A [stack machine](stack-machine.md) obtains operands implicitly from its operand [stack](stack-data-structure.md), but absence of explicit addresses does not logically force that design: fixed implicit [processor registers](processor-register.md) are another possibility. A zero-address indirect-load instruction can still obtain an arbitrary [memory address](memory-address.md) from the [stack](stack-data-structure.md); “zero-address” describes the instruction's encoding, not the absence of address-valued data.
