# Nonconstant function

↑ **Parent:** [Function](function-split.md)

A [function](function-split.md) is nonconstant when two inputs in its [domain of a function](domain-of-a-function.md) have different outputs. For example, $f(x)=x^2$ on the [real line](real-line.md) is nonconstant, whereas the same rule restricted to $\{-1,1\}$ is a [constant function](constant-function.md).
