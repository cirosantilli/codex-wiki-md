# Stefan number

↑ **Parent:** [Latent heat](latent-heat.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stefan_number)

The Stefan number compares sensible heat $c_p\Delta T$ with [latent heat](latent-heat.md) $L$ per unit mass. Some solidification literature uses its reciprocal as the Stefan parameter, so the defining formula must accompany the convention.
