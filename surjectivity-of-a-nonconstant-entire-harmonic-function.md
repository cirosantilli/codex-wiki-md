# Surjectivity of a nonconstant entire harmonic function

↑ **Parent:** [Harmonic Liouville theorem](harmonic-liouville-theorem.md)

Every nonconstant harmonic function $u:\mathbb C\to\mathbb R$ is unbounded above and below by the [harmonic Liouville theorem](harmonic-liouville-theorem.md). The [intermediate value theorem](intermediate-value-theorem.md) then gives $u(\mathbb C)=\mathbb R$.
