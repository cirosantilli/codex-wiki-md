# Word metric

↑ **Parent:** [Cayley graph](cayley-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Word_metric)

The word metric associated with a generating set $S$ is the path metric on $\operatorname{Cay}_S(G)$, equivalently $d_S(g,h)=|g^{-1}h|_S$.
