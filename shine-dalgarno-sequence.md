# Shine-Dalgarno sequence

↑ **Parent:** [Translation (biology)](translation-biology.md)

A [Shine-Dalgarno sequence](shine-dalgarno-sequence.md) is a bacterial messenger-RNA element that can pair with the anti-Shine-Dalgarno region of small-subunit ribosomal RNA to position initiation. Base pairing within the messenger RNA can make the element unavailable.
