# Classical path

↑ **Parent:** [Configuration-space path integral](configuration-space-path-integral.md)

A [classical path](classical-path.md) joining prescribed endpoints is a stationary point of the [action](action.md), satisfying the [Euler-Lagrange equation](euler-lagrange-equation.md) and the endpoint [boundary conditions](boundary-condition.md). Expanding the [path integral](path-integral.md) about each such path separates its classical phase from its quadratic fluctuation determinant. There may be multiple classical paths or none within a chosen real saddle class; the [semiclassical propagator](semiclassical-propagator.md) must respect that saddle structure rather than assuming a unique trajectory for every potential.
