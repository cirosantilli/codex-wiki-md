# Binary period invariant for a constant wind angular-momentum factor

↑ **Parent:** [Nonconservative binary mass transfer](nonconservative-binary-mass-transfer.md)

If an escaping [stellar wind](stellar-wind.md) carries specific [orbital angular momentum](orbital-angular-momentum.md) $\lambda J/M$ with constant $\lambda$, then $\dot J/J=\lambda\dot M/M$ and $J\propto M^\lambda$. Combining this with [circular-binary orbital angular momentum](circular-binary-orbital-angular-momentum.md) gives the displayed period invariant. It is a different prescription from [donor-wind angular-momentum loss](donor-wind-angular-momentum-loss.md), whose specific angular momentum generally varies with mass ratio.
