# Psychophysical threshold

↑ **Parent:** [Psychometric function](psychometric-function.md)

A stimulus value corresponding to a specified performance criterion in a specified task. It is a summary of a [psychometric function](psychometric-function.md), not a claim that every trial below that value has no sensory response. State the response definition, chance level, lapse convention and performance criterion.
