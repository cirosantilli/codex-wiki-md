# Unit root

↑ **Parent:** [Autoregressive polynomial](autoregressive-polynomial.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Unit_root)

A unit root is a zero of an [autoregressive polynomial](autoregressive-polynomial.md) on the unit circle. A zero at $1$ is removed by first [differencing](differencing.md). A conjugate pair $e^{\pm i\omega}$ corresponds to the real factor $1-2\cos\omega\,B+B^2$. Nonzero white-noise excitation at an uncancelled unit root prevents a finite-variance stationary solution.
