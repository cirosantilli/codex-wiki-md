# Discrete-time expected-utility portfolio problem

↑ **Parent:** [Mathematical finance](mathematical-finance-split.md)

For independent return innovations $\xi_n$ and a [predictable process](predictable-process.md) of holdings $\theta_n$, wealth obeys

$$
X_n=(1+r)X_{n-1}+\theta_n^T\xi_n.
$$

The investor chooses the holdings to maximize expected utility of terminal wealth.
