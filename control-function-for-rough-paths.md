# Control function for rough paths

↑ **Parent:** [Rough path](rough-path.md)

A control is a continuous nonnegative function on ordered pairs of times, zero on the diagonal and superadditive as displayed. It measures the size of increments of a [rough path](rough-path.md), typically through $|X^{(k)}_{s,t}|\leq\omega(s,t)^{k/p}$. Continuous finite variation gives suitable controls, which let local estimates be stated without tying them to a particular time parametrization.
