# Hybrid orbital

↑ **Parent:** [Orbital hybridization](orbital-hybridization.md)

A linear combination of [atomic orbitals](atomic-orbital.md) used in a localized description of directional bonding or [lone pairs](lone-pair.md). Hybrid labels are models rather than directly observable fixed atomic states.
