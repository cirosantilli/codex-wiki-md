# Quadratic class number formula

↑ **Parent:** [Analytic class number formula](analytic-class-number-formula.md)

For an imaginary quadratic field of fundamental discriminant $D<-4$,

$$
h(D)=\frac{\sqrt{|D|}}{\pi}L(1,\chi_D).
$$

Equivalent finite character-sum forms follow by evaluating the odd quadratic [Dirichlet L-function](dirichlet-l-function.md) at one.
