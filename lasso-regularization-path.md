# Lasso regularization path

↑ **Parent:** [Lasso](lasso.md)

The [Lasso](lasso.md) regularization path follows its coefficients as the penalty or constraint radius changes. Under the usual least-angle construction, the coefficient path is piecewise linear between knots, and variables can enter or leave the active set. Reading support at a selected [cross-validation](cross-validation.md) fraction requires checking which coefficients are actually zero at that fraction, rather than retaining only visibly large traces.
