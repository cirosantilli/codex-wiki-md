# Visual cortex

↑ **Parent:** [Cerebral cortex](cerebral-cortex.md)

Cortical systems processing visual information, including [primary visual cortex](primary-visual-cortex.md) and extrastriate regions. Delay-period information in these systems can be consistent with [sensory recruitment](sensory-recruitment.md) without proving that a single local region independently maintains the memory.
