# Ghost Virasoro zero-mode convention

↑ **Parent:** [Worldsheet ghost field](worldsheet-ghost-field.md)

With the [ghost oscillator vacuum](ghost-oscillator-vacuum.md), one can define $L_0^{\mathrm{gh}}=\sum_{k>0}k(b_{-k}c_k+c_{-k}b_k)$ with vacuum eigenvalue zero. The corresponding [Virasoro algebra](virasoro-algebra.md) contains a linear shift: $[L_m^{\mathrm{gh}},L_n^{\mathrm{gh}}]=(m-n)(L_{m+n}^{\mathrm{gh}}-\delta_{m+n,0})-\tfrac{26}{12}(m^3-m)\delta_{m+n,0}$. Shifting the zero mode by minus one removes the linear term but changes the stated vacuum eigenvalue. A [BRST charge](brst-charge.md) must use a consistent choice throughout.
