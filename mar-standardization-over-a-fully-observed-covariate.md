# MAR standardization over a fully observed covariate

↑ **Parent:** [Missing at random](missing-at-random.md)

When a response $Y$ is [missing at random](missing-at-random.md) conditional on a fully observed category $X$, estimate its [conditional probabilities](conditional-probability.md) using respondents within each category and average them with the category frequencies from all patients. For a binary response, $\widehat P(Y=1)=\sum_x\widehat P(X=x)\widehat P(Y=1\mid X=x,R=1)$. The weighting uses the full cohort rather than only complete cases.
