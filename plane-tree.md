# Plane tree

↑ **Parent:** [Tree (graph theory)](tree-graph-theory-split.md)

A [tree](tree-graph-theory-split.md) together with an embedding in an oriented plane, considered up to deformation preserving the cyclic order of incident edges. For a rooted plane tree, the embedding orders the children of each vertex.
