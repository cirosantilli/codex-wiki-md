# Variance component

↑ **Parent:** [Gaussian linear mixed model](gaussian-linear-mixed-model.md)

A variance component is a nonnegative parameter multiplying a specified covariance contribution. In a [Gaussian linear mixed model](gaussian-linear-mixed-model.md) with independent standardized group effects, $\tau_k^2Z_kZ_k^T$ describes the covariance induced by one set of [random effects](random-effect.md). Testing whether a component is zero is a [variance-component likelihood-ratio test at a boundary](variance-component-likelihood-ratio-test-at-a-boundary.md); ordinary regular chi-squared likelihood-ratio calibration need not apply.
