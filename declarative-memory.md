# Declarative memory

↑ **Parent:** [Memory in animals](memory-in-animals.md)

Memory accessible to flexible report or use concerning facts and events. It includes [semantic memory](semantic-memory.md) and [episodic memory](episodic-memory.md); it is distinguished from preserved performance-based learning such as [procedural memory](procedural-memory.md).
