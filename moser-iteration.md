# Moser iteration

↑ **Parent:** [De Giorgi-Nash-Moser theorem](de-giorgi-nash-moser-theorem.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Moser_iteration)

Moser iteration combines a [Caccioppoli inequality](caccioppoli-inequality.md) with the [Sobolev embedding theorem](sobolev-embedding-theorem.md) to raise an integrability exponent geometrically. On nested balls it turns an $L^p$ bound for a nonnegative subsolution of a uniformly elliptic divergence-form equation into a local supremum bound.
