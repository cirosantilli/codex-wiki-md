# Kind (type theory)

↑ **Parent:** [Type system](type-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kind_(type_theory))

A classification of type-level expressions. In the traditional [Haskell](haskell.md) notation, ordinary types have kind `*`, while a unary [type constructor](type-constructor.md) such as `Tree` has kind `* -> *`. Applying it to a suitable [type argument](type-argument.md) produces an ordinary type. This distinguishes the type-level application from applying a value with a [function type](function-type.md).
