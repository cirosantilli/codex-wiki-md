# Hypergraph codegree

↑ **Parent:** [Hypergraph vertex degree](hypergraph-vertex-degree.md)

The codegree of a vertex set $\sigma$ in a [hypergraph](hypergraph-split.md) is the number of hyperedges containing every vertex in $\sigma$. For a singleton this is the [hypergraph vertex degree](hypergraph-vertex-degree.md); for two vertices it measures how often those vertices occur together. Subset codegrees of all sizes control the overlap relevant to the [hypergraph container theorem](hypergraph-container-theorem.md).
