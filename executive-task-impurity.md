# Executive task impurity

↑ **Parent:** [Executive function](executive-function.md)

An [executive function](executive-function.md) task necessarily recruits nonexecutive processes as well as its intended control demand. A verbal [inhibition](inhibitory-control.md) task, for example, requires word comprehension and a response. Multiple indicators with different incidental demands can help separate common executive [variance](variance-split.md), but only under a defensible measurement model.[Cognitive Psychology 41, 49–100; latent-variable analyses](the-unity-and-diversity-of-executive-functions-and-their-contributions-to-complex-frontal-lobe-tasks-by-akira-miyake-and-others.md)
