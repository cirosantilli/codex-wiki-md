# Four-term progression hypergraph encoding

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)

Use four parts indexed by $0,1,2,3$ in a [cyclic group](cyclic-group.md) $G$, and include the triple missing part $i$ when $L_i\in A$. A transversal [three-uniform tetrahedron](three-uniform-tetrahedron.md) then has the four values $S_1-iS_0$, where $S_0=\sum_jx_j$ and $S_1=\sum_jjx_j$, so it encodes a four-term [arithmetic progression](arithmetic-progression.md). Constant progressions give $|A||G|^2$ edge-disjoint tetrahedra. This is the bridge from the [tetrahedron removal lemma](tetrahedron-removal-lemma.md) to the [Szemerédi theorem](szemeredi-s-theorem.md).
