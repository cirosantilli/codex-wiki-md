# Tableau algorithm for ALC

↑ **Parent:** [ALC](alc.md)

A [concept satisfiability](concept-satisfiability.md) procedure that expands concept labels into a graph, branches on disjunctions, creates witnesses for existential restrictions, propagates universal restrictions along existing edges, and tests for a [tableau clash](tableau-clash.md). General [TBoxes](tbox.md) require global constraints and a termination device such as [direct blocking in description logic](direct-blocking-in-description-logic.md).
