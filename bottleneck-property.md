# Bottleneck property

↑ **Parent:** [Quasi-tree](quasi-tree.md)

A geodesic metric space has the bottleneck property if every path joining the endpoints of a geodesic passes within one uniform distance of that geodesic's midpoint. A geodesic metric space is a quasi-tree exactly when it has this property.
