# Creational pattern

↑ **Parent:** [Software design pattern](software-design-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Creational_pattern)

A [software design pattern](software-design-pattern.md) organizing how [software objects](software-object.md) are created. A [prototype pattern](prototype-pattern.md) creates an object by asking an existing example to copy itself, letting a client choose a concrete configuration at runtime through an [object interface](object-interface.md).
