# Array index

↑ **Parent:** [Array (data structure)](array-data-structure.md)

An [integer](integer-split.md) identifying a position in an [array](array-data-structure.md). With zero-based indexing and capacity $m$, valid [array indices](array-index.md) are $0,\ldots,m-1$. An [array index](array-index.md) identifies the slot rather than its stored value.
