# Positive matrix semigroup

↑ **Parent:** [Matrix exponential](matrix-exponential.md)

A [matrix exponential](matrix-exponential.md) defines a [positive matrix semigroup](positive-matrix-semigroup.md) if $e^{tA}$ maps nonnegative [vectors](vector.md) to nonnegative [vectors](vector.md) for all $t\ge0$. Here the inequality means entrywise nonnegativity, with zero entries allowed. In finite dimensions this holds exactly when the real [matrix](matrix.md) $A$ has nonnegative off-diagonal entries: if $A+\gamma I\ge0$, expand $e^{tA}=e^{-\gamma t}\sum_{k\ge0}t^k(A+\gamma I)^k/k!$; conversely, the off-diagonal entries of $e^{tA}=I+tA+O(t^2)$ force $a_{ij}\ge0$ for $i\ne j$. Zero column sums additionally preserve $\mathbf1^Tc$ under $c'=Ac$.
