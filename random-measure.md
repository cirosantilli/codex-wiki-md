# Random measure

↑ **Parent:** [Measure theory](measure-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Random_measure)

A random measure assigns a [measure](measure-split.md) $\mu_\omega$ to each outcome so that $\omega\mapsto\mu_\omega(A)$ is a [random variable](random-variable-split.md) for every measurable $A$. A [finite-variation process](finite-variation-process.md) gives pathwise signed random measures through [Lebesgue–Stieltjes integration](lebesgue-stieltjes-integration.md).
