# Equal-length crystallographic root configurations in a plane

↑ **Parent:** [Crystallographic root system](crystallographic-root-system.md)

Let $\Phi$ be a nonempty set of [unit vectors](unit-vector.md) in a real Euclidean plane, closed under the reflections $s_v(u)=u-2\langle u,v\rangle v$ and satisfying $2\langle u,v\rangle\in\mathbb Z$ for every pair. Then it consists of an antipodal pair, a [square](square.md), or a [regular hexagon](regular-hexagon.md). Relative to any fixed member, the inner products can only be $0,\pm1/2,\pm1$, so only eight angles are initially possible. [Reflection](reflection-mathematics.md) gives every negative vector. If a perpendicular pair occurs, it and its negatives exhaust the set, since any extra sixty-degree direction would have forbidden [inner product](inner-product-split.md) $\pm\sqrt3/2$ with one of them. Otherwise any noncollinear pair gives, after negation, a sixty-degree angle; [reflection](reflection-mathematics.md) supplies the third direction and negation supplies the other three hexagon vertices. If no such pair occurs, only the antipodal pair remains. Each configuration directly satisfies the conditions.

These are the equal-length cases of the [classification of rank-two root systems](classification-of-rank-two-root-systems.md), with the antipodal case having rank one. The [square](square.md) is the [orthogonal](orthogonal-vectors.md) sum of two [A1 root systems](rank-one-root-system.md), and the hexagon is an [A2 root system](a2-root-system.md). The [root system](root-system.md) is considered in the span of its vectors when the ambient plane is not spanned.
