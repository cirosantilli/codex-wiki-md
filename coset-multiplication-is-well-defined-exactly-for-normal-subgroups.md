# Coset multiplication is well-defined exactly for normal subgroups

↑ **Parent:** [Quotient group](quotient-group.md)

If $N$ is a [normal subgroup](normal-subgroup.md), changing representatives to $gn$ and $hm$, where $n,m\in N$, gives

$$
(gn)(hm)=gh(h^{-1}nh)m\in ghN.
$$

The chosen representatives therefore give the same [coset](coset.md). Conversely, suppose the rule defines an operation on left [cosets](coset.md). Since $nN=N$ for $n\in N$, multiplying by $gN$ gives $ngN=gN$, hence $g^{-1}ng\in N$. Applying this inclusion for every $g$ and $g^{-1}$ proves $g^{-1}Ng=N$, so $N$ is a [normal subgroup](normal-subgroup.md). This makes normality exactly the condition needed to carry [group operation](group-operation.md) to these classes.
