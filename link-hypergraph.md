# Link hypergraph

↑ **Parent:** [Uniform hypergraph](uniform-hypergraph.md)

The link at a fixed vertex $v$ of an $r$-[uniform hypergraph](uniform-hypergraph.md) has vertex set $V(H)\setminus\{v\}$ and the displayed $(r-1)$-element [hyperedges](hyperedge.md). For a [universal countable uniform hypergraph](universal-countable-uniform-hypergraph.md), its link has the [hypergraph extension property](hypergraph-extension-property.md): include $v$ in the finite set of vertices and prescribe only those $r$-edges containing $v$, completing the remaining prescription arbitrarily. Thus the link is a universal countable $(r-1)$-[uniform hypergraph](uniform-hypergraph.md). In particular the link at a fixed vertex in the three-uniform case is the [Rado graph](rado-graph.md). This operation retains a specified vertex; deleting the maximum from every edge is a different operation.
