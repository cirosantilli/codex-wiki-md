# Thom class in a generalized cohomology theory

↑ **Parent:** [Thom class](thom-class.md)

For an $h$-oriented rank-$r$ real [vector bundle](vector-bundle.md), its [Thom class](thom-class.md) restricts on each fiber to the suspension of the coefficient unit under the oriented identification $h^r(D^r,S^{r-1})\cong h^0(\mathrm{pt})$. [Cup product](cup-product.md) with this class gives the Thom isomorphism. The associated [Euler class in a generalized cohomology theory](euler-class-in-a-generalized-cohomology-theory.md) is the pullback along the [zero section](zero-section-of-a-vector-bundle.md) after forgetting relative supports.
