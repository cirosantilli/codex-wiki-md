# Decisive number

↑ **Parent:** [Number theory](number-theory-split.md)

A positive [integer](integer.md) $n$ is decisive when every [integer](integer.md) $a$ satisfying $1<a<n$ and $\gcd(a,n)=1$ is a [prime number](prime-number.md). There are only finitely many decisive numbers: every prime $p<\sqrt n$ must divide a decisive $n$, so the [Chebyshev theta function](chebyshev-theta-function.md) gives $\log n\geq\vartheta(\sqrt n)$, which eventually contradicts the linear lower bound for $\vartheta(\sqrt n)$.
