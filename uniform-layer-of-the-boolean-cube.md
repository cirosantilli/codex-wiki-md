# Uniform layer of the Boolean cube

↑ **Parent:** [Uniform set family](uniform-set-family.md)

The uniform layer consists of the [characteristic vectors of sets](characteristic-vector-of-a-set.md) of size $r$ in $[n]$. It has size $\binom nr$, a [binomial coefficient](binomial-coefficient.md). Restricting [polynomials](polynomial-split.md) to a uniform layer introduces identities absent on the entire [Boolean lattice](boolean-lattice.md), since the coordinate sum is fixed. In particular, [homogenisation on a uniform layer](homogenisation-on-a-uniform-layer.md) spans all restricted [multilinear polynomials](multilinear-polynomial.md) of degree at most $s\leq r$ using just the degree-$s$ [monomials](monomial.md).
