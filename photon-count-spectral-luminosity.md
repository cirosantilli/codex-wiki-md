# Photon count spectral luminosity

↑ **Parent:** [Spectral luminosity](spectral-luminosity.md)

For [photon](photon.md) [energy](energy-split.md) $\varepsilon=h\nu$, equating radiated [energy](energy-split.md) in corresponding spectral intervals gives $L_\nu\,d\nu=\varepsilon L_\varepsilon^N\,d\varepsilon$. Thus $L_\varepsilon^N=L_\nu/(h\varepsilon)$. A quoted rate per joule must be multiplied by the number of joules per [electronvolt](electronvolt.md) or per $\mathrm{keV}$ to express it in that spectral unit. For homogeneous [optically thin](optically-thin-medium.md) emission, $L_\nu=4\pi Vj_\nu$ if $j_\nu$ is defined per [solid angle](solid-angle.md).
