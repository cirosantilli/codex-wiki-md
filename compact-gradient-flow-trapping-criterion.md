# Compact gradient-flow trapping criterion

↑ **Parent:** [Invariant sublevel set](invariant-sublevel-set.md)

A smooth [gradient flow](gradient-flow.md) confined to a compact [invariant sublevel set](invariant-sublevel-set.md) has finite total integral of $\|\nabla V\|^2$ when $V$ is bounded below. Compactness supplies uniform continuity of that squared norm along the trajectory, so it tends to zero. Every accumulation point is a [critical point](critical-point.md). If the trapped component contains exactly one [critical point](critical-point.md), the trajectory converges to it. This supplies a direct convergence proof in place of an inference solely from an energy-contour picture.
