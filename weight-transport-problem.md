# Weight transport problem

↑ **Parent:** [Backpropagation](backpropagation.md)

Exact [backpropagation](backpropagation.md) computes hidden teaching signals using the transpose of the current forward weight matrix. Explaining how a biological feedback pathway could know or maintain those weights is the [weight transport problem](weight-transport-problem.md). Useful approximate error correction need not satisfy exact reciprocal weight equality.[Results, Figure 1 and Figure 2; Discussion: random feedback, learning performance and biological limitations](random-synaptic-feedback-weights-support-error-backpropagation-for-deep-learning-by-timothy-p-lillicrap-and-others.md)
