# Uniform metric

↑ **Parent:** [Metric space](metric-space.md)

The supremum of pointwise distances defines a metric on maps when it is finite, for example if the target [metric space](metric-space.md) is bounded. Convergence in this metric is [uniform convergence](uniform-convergence.md). If the target is complete, Cauchy sequences have pointwise limits and the Cauchy estimate makes convergence uniform.
