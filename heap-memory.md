# Heap memory

↑ **Parent:** [Computer memory](computer-memory-split.md)

Storage used for [heap allocation](heap-allocation.md), with [software object](software-object.md) lifetimes not necessarily nested like procedure calls on a call [stack](stack-data-structure.md). [Garbage collection](garbage-collection.md) can reclaim unreachable [software objects](software-object.md); keeping references to every allocated [software object](software-object.md) prevents that reclamation regardless of how little of each [software object](software-object.md)'s data a program still needs.
