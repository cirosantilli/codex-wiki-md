# Hitting set

↑ **Parent:** [Set family](set-family.md)

A [set](set-split.md) $H$ is a hitting set for a [set family](set-family.md) $\mathcal F$ if $H\cap A\ne\varnothing$ for every $A\in\mathcal F$. Every [set](set-split.md) is a hitting set for an empty [set family](set-family.md); none is a hitting set for a family containing the empty [set](set-split.md). Bounded hitting sets permit finite certificates for some infinite [set families](set-family.md), as in the [bounded-size transversal kernel](bounded-size-transversal-kernel.md).
