# Hypergraph chromatic number

↑ **Parent:** [Hypergraph colouring](hypergraph-colouring.md)

The [hypergraph chromatic number](hypergraph-chromatic-number.md) is the minimum number of colours in a proper [hypergraph colouring](hypergraph-colouring.md). If $H$ has $N$ vertices and maximum [hypergraph independent set](hypergraph-independent-set.md) size $a$, then $\chi(H)\geq N/a$, since the [colour classes](colour-class.md) partition its [vertex set](vertex-set.md) into [hypergraph independent sets](hypergraph-independent-set.md).
