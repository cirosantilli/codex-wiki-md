# Closure of normal monomorphisms forces abelianness

↑ **Parent:** [Normal monomorphism](normal-monomorphism.md)

In an [additive category](additive-category.md) with finite [categorical limits](categorical-limit.md) and [colimits](colimit.md) in which every [epimorphism](epimorphism.md) is a [conormal epimorphism](conormal-epimorphism.md), closure of [normal monomorphisms](normal-monomorphism.md) under composition forces every [monomorphism](monomorphism.md) to be normal. To prove this, write a monomorphism $m$ as $kg$, where $k=\ker\operatorname{coker}m$, and put $l=\ker\operatorname{coker}g$. If $kl=\ker t$ were normal, $tm=0$ would force $tk=0$, hence $l$ would be an [isomorphism](isomorphism.md). This makes $\operatorname{coker}g=0$, so $g$ is epic as well as monic. An epic monomorphism which is a cokernel is invertible, forcing $m$ to be normal. Contrapositively, any failure of normality provides two normal monomorphisms whose composite is not normal.
