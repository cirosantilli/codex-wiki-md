# Label-correcting shortest-path algorithm

↑ **Parent:** [Shortest path problem](shortest-path-problem.md)

An algorithm whose tentative distance labels may be revised repeatedly until all relevant [Bellman inequalities](bellman-inequalities.md) hold. [Bellman-Ford algorithm](bellman-ford-algorithm.md) uses this approach: a label is an upper bound supplied by a discovered [directed path](directed-path.md), and relaxing an [directed edge](directed-edge.md) can replace it with a shorter discovered [directed path](directed-path.md). A finite label is not declared permanent merely because it has been processed.
