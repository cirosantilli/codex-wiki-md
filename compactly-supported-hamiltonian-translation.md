# Compactly supported Hamiltonian translation

↑ **Parent:** [Hamiltonian flow preserves the symplectic form](hamiltonian-flow-preserves-the-symplectic-form.md)

Given a bounded set in the symplectic plane and a translation vector $v=(a,b)$, the linear Hamiltonian $H(x,y)=bx-ay$ generates translation by $v$. Multiplying it by a cutoff that equals one on the entire swept region produces a compactly supported [Hamiltonian diffeomorphism](hamiltonian-isotopy.md) that agrees with the translation on the set.
