# Iterated function

↑ **Parent:** [Discrete dynamical system](discrete-dynamical-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Iterated_function)

For a [map](function-class.md) $F:X\to X$, its iterates are defined by $F^0$ equal to the [identity map](identity-function.md) and $F^{n+1}=F\circ F^n$.
