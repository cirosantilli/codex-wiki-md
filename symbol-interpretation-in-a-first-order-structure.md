# Symbol interpretation in a first-order structure

↑ **Parent:** [First-order structure](first-order-structure.md)

In a [first-order structure](first-order-structure.md), an interpretation assigns a relation of the specified arity to each [predicate symbol](predicate-symbol.md), a total [function](function-split.md) of the specified arity to each [function symbol](function-symbol.md), and an element to each [constant symbol](constant-symbol.md). Evaluation of [first-order terms](first-order-term.md) and truth of [logical formulas](logical-formula.md) are then defined recursively. This specifies how symbols acquire their meanings on the underlying [set](set-split.md).
