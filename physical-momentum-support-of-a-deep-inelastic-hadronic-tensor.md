# Physical momentum support of a deep-inelastic hadronic tensor

↑ **Parent:** [Hadronic tensor](hadronic-tensor.md)

For an absorbed spacelike photon, use $q^2=-Q^2<0$, $\nu=P\cdot q>0$, $x=Q^2/(2\nu)$ and the physical momentum delta function $\delta^{(4)}(P+q-p_X)$. The displayed invariant final mass is compatible with [deep inelastic scattering](deep-inelastic-scattering.md) for $0<x<1$. Using $P-q$ with the same positive-$x$ definition instead gives $M^2-Q^2(1+1/x)$, which becomes negative in the [Bjorken scaling](bjorken-scaling.md) limit and has no physical hadronic spectral support. Reversing the photon convention requires reversing the associated scalar-product and scaling-variable conventions too.
