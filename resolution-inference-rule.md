# Resolution inference rule

↑ **Parent:** [Propositional logic](propositional-logic.md)

From [Boolean clauses](clause-of-a-boolean-formula.md) containing complementary [Boolean literals](boolean-literal.md), derive the [Boolean clause](clause-of-a-boolean-formula.md) formed by removing that complementary pair and taking the remaining [Boolean literals](boolean-literal.md). For example, resolving $p\lor\neg q$ with $\neg p\lor\neg r$ gives $\neg q\lor\neg r$. Backward proof search with a positive-headed [Horn clause](horn-clause.md) and an all-negative query is a restricted use of this rule.
