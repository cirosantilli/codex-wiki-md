# Photon count inside a relativistic beaming cone

↑ **Parent:** [Relativistic beaming](relativistic-beaming.md)

For isotropic photon emission in a source rest frame, aberration maps its forward hemisphere into a laboratory cone of half-angle $\arccos\beta$. The cone contains half the emitted photons. Direction-dependent Doppler energies mean that this count statement is not an identical half-power statement.
