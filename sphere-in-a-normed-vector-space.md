# Sphere in a normed vector space

↑ **Parent:** [Normed vector space](normed-vector-space.md)

In a [normed vector space](normed-vector-space.md), this set consists of all points at a fixed positive [norm](norm.md) distance $r$ from $x_0$. It also makes sense in an infinite-dimensional [Hilbert space](hilbert-space-split.md), unlike a specifically Euclidean [sphere](sphere.md). In a real [Hilbert space](hilbert-space-split.md), the [sphere in a normed vector space](sphere-in-a-normed-vector-space.md) $\|u\|^2=2E_0>0$ has tangent variations $v$ satisfying $(u,v)=0$; this follows by differentiating the fixed squared [norm](norm.md). This is the geometric constraint used in [fixed-energy initial-condition optimality](fixed-energy-initial-condition-optimality.md).
