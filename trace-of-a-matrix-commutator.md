# Trace of a matrix commutator

↑ **Parent:** [Commutator](commutator.md)

The [matrix trace](matrix-trace.md) of $[A,B]=AB-BA$ is zero, since $\operatorname{tr}(AB)=\sum_{i,j}A_{ij}B_{ji}=\operatorname{tr}(BA)$. This obstructs a matrix with nonzero trace from being a single [commutator](commutator.md).
