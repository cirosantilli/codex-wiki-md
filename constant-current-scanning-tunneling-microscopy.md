# Constant-current scanning tunneling microscopy

↑ **Parent:** [Scanning tunneling microscopy](scanning-tunneling-microscopy.md)

Choose a fixed tip-sample [electric potential difference](electric-potential-difference.md) and a positive target [electric current](electric-current.md) magnitude $I_0$. At each lateral position $(x,y)$, [feedback control](closed-loop-control.md) adjusts $z$ until the measured [electric current](electric-current.md) approaches $I_0$. Since increasing the gap reduces [quantum tunnelling](quantum-tunnelling.md), excessive [electric current](electric-current.md) calls for retraction; insufficient [electric current](electric-current.md) calls for approach. The image is the calibrated vertical displacement $z(x,y)$, while the residual [electric current](electric-current.md) error tests how closely the loop followed its target.

This is a contour of equal [electric current](electric-current.md), not necessarily a contour of equal separation. The [electronic contrast in scanning tunneling microscopy](electronic-contrast-in-scanning-tunneling-microscopy.md) model below shows why. It also explains the value of [vibration isolation](vibration-isolation.md): an unintended displacement changes the same sensitive gap as the feature being measured. A scan must be slow enough for the finite [bandwidth](bandwidth-signal-processing.md) of [feedback control](closed-loop-control.md); otherwise $z(x,y)$ lags the desired contour.
