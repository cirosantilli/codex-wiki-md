# Replay attack

↑ **Parent:** [Computer security](computer-security.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Replay_attack)

Reuse of previously observed valid messages to obtain an acceptance or action in a different context. [Cryptographic nonces](cryptographic-nonce.md), fresh [session keys](session-key.md) and explicit context binding can prevent particular replay patterns.
