# Local search

↑ **Parent:** [Heuristic optimization](heuristic-optimization.md)

[Local search](local-search.md) repeatedly improves a feasible solution within a specified neighborhood until no improving move remains. For an allocation, neighbors can transfer an item or exchange items between bidders while preserving the partition. A local optimum need not be a global optimum; restarting from several initial solutions can explore different basins.
