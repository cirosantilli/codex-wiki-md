# Statistical tangent set

↑ **Parent:** [Statistical path](statistical-path.md)

A statistical tangent set is the collection of [score functions](informant-function.md) attained by a specified family of [differentiable-in-quadratic-mean paths](differentiability-in-quadratic-mean.md) through $P$. The choice of paths is part of the definition. Its elements lie in the [mean-zero L2 space](mean-zero-l2-space.md), but the set need not already be a closed [vector subspace](vector-subspace.md).
