# Characteristic speed

↑ **Parent:** [Flux Jacobian](flux-jacobian.md)

A characteristic speed is an [eigenvalue](eigenvalue.md) of the [flux Jacobian](flux-jacobian.md). Along a corresponding [characteristic curve](characteristic-curve.md), an associated wave variable obeys an [ordinary differential equation](ordinary-differential-equation.md) obtained by projecting the governing system onto the matching left [eigenvector](eigenvector.md).
