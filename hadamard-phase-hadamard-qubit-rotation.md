# Hadamard-phase-Hadamard qubit rotation

↑ **Parent:** [Hadamard gate](hadamard-gate.md)

For $P_\alpha=\operatorname{diag}(1,e^{i\alpha})$, conjugation by the [Hadamard gate](hadamard-gate.md) turns a relative [quantum phase](quantum-phase.md) into an $x$-axis [Bloch vector](bloch-vector.md) [rotation](rotation-mathematics.md). In the convention $\rho=(I+\mathbf P\cdot\boldsymbol\sigma)/2$, the map is $(P_x,P_y,P_z)\mapsto(P_x,P_y\cos\alpha-P_z\sin\alpha,P_y\sin\alpha+P_z\cos\alpha)$. An $x$-polarized input is unchanged, whereas a $z$-polarized input gives a sinusoidal population difference. A maximally mixed input remains maximally mixed under every [unitary time evolution](unitary-time-evolution.md).
