# Comoving coordinate

↑ **Parent:** [Scale factor (cosmology)](scale-factor-cosmology.md)

A comoving coordinate remains fixed for an observer following the homogeneous cosmological expansion.

A [comoving coordinate](comoving-coordinate.md) provides labels for the [comoving and proper distances](comoving-and-proper-distances.md) comparison; proper separation additionally contains the cosmological scale factor.
