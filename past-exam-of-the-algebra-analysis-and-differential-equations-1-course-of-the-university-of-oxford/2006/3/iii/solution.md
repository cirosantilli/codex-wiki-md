<h1 id="3/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

The conditions set the constant and linear [coefficients](../../../../coefficient.md) to zero, so $\boxed{J_3=(X^2)}$. This is a [principal ideal](../../../../principal-ideal.md), but it is **not maximal**: there is a strict chain $(X^2)\subsetneq(X)\subsetneq\mathbb R[X]$. In the [quotient ring](../../../../quotient-ring.md), the nonzero class of $X$ has square zero, so the quotient is not a [field](../../../../field.md).
