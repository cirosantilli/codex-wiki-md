# Metric net

↑ **Parent:** [Metric space](metric-space.md)

An $\varepsilon$-net of a [metric space](metric-space.md) $(T,d)$ is a subset $U\subseteq T$ such that every $x\in T$ has $d(x,u)\leq\varepsilon$ for some $u\in U$. Its least possible finite size is the [metric covering number](metric-covering-number.md) with closed balls. A maximal set with pairwise distances greater than $\varepsilon$ is an $\varepsilon$-net.
