# Powerfully embedded subgroup

↑ **Parent:** [Powerful p-group](powerful-p-group.md)

A [normal subgroup](normal-subgroup.md) $N$ is powerfully embedded in a [finite p-group](finite-p-group.md) or [pro-p group](pro-p-group.md) $G$ if $[N,G]\leq N^p$ for odd $p$, or $[N,G]\leq N^4$ for $p=2$; use closed generated [subgroups](subgroup.md) in the [pro-p group](pro-p-group.md) case. The condition implies that $N$ is a [powerful p-group](powerful-p-group.md). For odd $p$, both $[N,G]$ and $N^p$ remain powerfully embedded.
