# Strong NP-completeness

↑ **Parent:** [NP-completeness](np-completeness.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Strong_NP-completeness)

An [NP](np-complexity.md) [decision problem](decision-problem.md) is strongly [NP-complete](np-completeness.md) when its [NP-hardness](np-hardness.md) persists with numerical parameters written in the [unary numeral system](unary-numeral-system.md). An important proof method bounds every relevant numerical value by a [polynomial](polynomial-split.md) in the remaining explicit [input](input-computer-science.md) size. For the [clique decision problem](clique-decision-problem.md), values $k>|V(G)|$ can be mapped to one fixed no-instance; otherwise writing $1^k$ takes only [polynomial time](polynomial-time.md). The distinction is representation-sensitive, so an explicit [graph](graph-split.md) encoding must be specified.
