# Normalised set function

↑ **Parent:** [Set function](set-function.md)

A [set function](set-function.md) is normalised when its value at the [empty set](empty-set.md) is zero. Subtracting the constant $f(\varnothing)$ normalises any real-valued [set function](set-function.md) and preserves [submodularity](submodular-set-function.md) and the [monotone set function](monotone-set-function.md) property.
