# Ore theorem

↑ **Parent:** [Ore condition](ore-condition.md)

A multiplicative set $S$ of [regular elements of a ring](regular-element-of-a-ring.md) admits a right ring of fractions exactly when it satisfies the [right Ore condition](right-ore-condition.md). The resulting localization embeds the original [ring](ring.md), inverts $S$, and expresses every element as $as^{-1}$. For denominators that can be [zero divisors](zero-divisor.md), an additional denominator reversibility condition is required.
