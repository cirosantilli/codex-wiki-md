# State transition table

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A table specifying the next state for each present state and input combination, together with the output if needed. For a [Moore machine](moore-machine.md), output depends only on the state; for a [Mealy machine](mealy-machine.md), it may also depend on the current input. A [state-transition diagram](state-transition-diagram.md) gives the same transitions as labelled [directed edges](directed-edge.md).
