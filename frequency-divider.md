# Frequency divider

↑ **Parent:** [Digital electronics](digital-electronics.md)

A circuit producing a periodic output at an [integer](integer-split.md) fraction of the input [frequency](frequency.md). Each toggle stage divides the triggering [frequency](frequency.md) by two, so stage $n-1$ in an $n$-stage binary [ripple counter](ripple-counter.md) has ideal output [frequency](frequency.md) $f_{\mathrm{in}}/2^n$.
