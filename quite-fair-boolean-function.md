# Quite fair Boolean function

↑ **Parent:** [Boolean function](boolean-function.md)

Under uniform independent input bits, a zero-one [Boolean function](boolean-function.md) is quite fair when its mean lies between one quarter and three quarters. This convention excludes functions whose output is nearly constant; it does not require exact balance or equal coordinate influences.
