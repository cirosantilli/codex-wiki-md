# Nonseparating curve

↑ **Parent:** [Simple closed curve](simple-closed-curve.md)

A simple closed curve in a connected oriented [surface](topological-surface.md) is nonseparating when cutting along it leaves a connected [surface](topological-surface.md). A separating curve bounds a subsurface and represents zero in first [homology](homology-split.md). For a nonseparating curve, an arc between the two new boundary components closes to a curve meeting it once. Its [algebraic intersection number of curves on an oriented surface](algebraic-intersection-number-of-curves-on-an-oriented-surface.md) is $\pm1$, proving that the original curve represents a [primitive homology class](primitive-homology-class.md).
