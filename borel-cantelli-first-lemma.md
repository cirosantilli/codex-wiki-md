# Borel-Cantelli first lemma

↑ **Parent:** [Borel-Cantelli lemmas](borel-cantelli-lemmas.md)

For arbitrary events $A_n$, if $\sum_n\mathbb P(A_n)<\infty$, then $\mathbb P(\limsup_n A_n)=0$. The [union bound](boole-s-inequality.md) gives $\mathbb P(\limsup A_n)\le\sum_{n\ge m}\mathbb P(A_n)\to0$. No [independence](independent-random-variables.md) is required.
