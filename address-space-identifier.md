# Address space identifier

↑ **Parent:** [Translation lookaside buffer](translation-lookaside-buffer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Address_space_identifier)

A tag distinguishing cached [address translations](address-translation.md) belonging to different [address spaces](address-space.md). Tags can be reused, but reusing a tag for a different mapping context requires appropriate invalidation.
