# Cube root

↑ **Parent:** [Real number](real-number.md)

For a [real number](real-number.md) $x$, its cube root is the unique [real number](real-number.md) $y$ satisfying $y^3=x$. The function $y\mapsto y^3$ is [strictly increasing](strictly-increasing-function.md), so negative inputs also have a unique real cube root.
