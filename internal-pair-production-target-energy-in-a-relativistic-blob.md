# Internal pair-production target energy in a relativistic blob

↑ **Parent:** [Gamma-ray compactness problem](gamma-ray-compactness-problem.md)

Let the relevant rest-frame [photon-photon pair production](photon-photon-pair-production.md) [energy](energy-split.md) product be $K=\epsilon'_1\epsilon'_2$ for a specified collision-angle prescription. For fixed observed high-energy [photon](photon.md) [energy](energy-split.md), $\epsilon'_1=\epsilon_{1,\rm obs}/D$, so the target has $\epsilon'_2=DK/\epsilon_{1,\rm obs}$. Observing the same internally produced target population supplies a second [Doppler factor](doppler-factor.md), giving the displayed result. An external stationary [radiation](radiation.md) field requires its own angular transformation instead.
