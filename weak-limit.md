# Weak limit

↑ **Parent:** [Weak convergence](weak-convergence.md)

The weak limit of a sequence in a [normed vector space](normed-vector-space-split.md) is an element at which every continuous [linear functional](linear-functional.md) has the limit of its values along the sequence. Thus the definition is precisely [weak convergence](weak-convergence.md) to that element.
