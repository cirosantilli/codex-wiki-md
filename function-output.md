# Function output

↑ **Parent:** [Function](function-split.md)

A [function output](function-output.md) is the value $f(x)$ assigned by a [function](function-split.md) $f:X\to Y$ to a [function input](function-input.md) $x$. It belongs to the [codomain](codomain.md) $Y$; all such [function outputs](function-output.md) together form the [image of a function](image-of-a-function.md) $f(X)$.
