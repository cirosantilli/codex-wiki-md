# GHZ preparation with Hadamard and controlled-Z gates

↑ **Parent:** [Greenberger–Horne–Zeilinger state](greenberger-horne-zeilinger-state.md)

For $n\geq2$, apply a [Hadamard gate](hadamard-gate.md) to one [qubit](qubit.md), then controlled-NOTs from it to all others. Replacing each [controlled-NOT gate](controlled-not-gate.md) by a target Hadamard, a [Controlled-Z gate](controlled-z-gate.md), and another target Hadamard uses $1+3(n-1)$ allowed gates. Each one-qubit reduced state is $I/2$, proving entanglement across each qubit-versus-rest bipartition.
