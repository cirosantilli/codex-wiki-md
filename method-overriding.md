# Method overriding

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

A subclass or composed trait supplies an implementation of an inherited method signature. Ordinary instance calls use [dynamic dispatch](dynamic-dispatch.md) to choose the effective implementation for the receiver, after any overload selection. In [Scala](scala.md), overriding a concrete inherited member requires the `override` modifier; a qualified `super` invocation selects the corresponding inherited implementation.
