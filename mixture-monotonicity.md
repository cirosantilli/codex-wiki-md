# Mixture monotonicity

↑ **Parent:** [Independence axiom for lottery preferences](independence-axiom-for-lottery-preferences.md)

Assume $0\le q<p\le1$ and write $L_q=qA+(1-q)B$. The [independence axiom for lottery preferences](independence-axiom-for-lottery-preferences.md) gives $A\succ L_q$ because $1-q>0$. Set $\lambda=(p-q)/(1-q)>0$; then $L_p=\lambda A+(1-\lambda)L_q$. A second use of the same axiom gives $L_p\succ L_q$. Thus a higher [probability](probability.md) of the strictly preferred outcome strictly improves a two-outcome [lottery](lottery.md).
