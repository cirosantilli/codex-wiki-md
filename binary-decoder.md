# Binary decoder

↑ **Parent:** [Combinational logic](combinational-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Binary_decoder)

A [combinational logic](combinational-logic.md) circuit mapping a binary input code to selected output lines. In a one-of-$k$ register-address decoder, line $i$ is asserted exactly when the address equals $i$, optionally combined with an enable. This selects which [processor register](processor-register.md) may capture a common write-data word.
