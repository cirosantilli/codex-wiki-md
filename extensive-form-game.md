# Extensive-form game

↑ **Parent:** [Game theory](game-theory-split.md)

A game described by a [game tree](game-tree.md), with the acting player and available actions specified at each decision node, [payoffs](payoff.md) at terminal nodes, and [information sets](information-set.md) indicating which decision nodes a player can distinguish. A [pure strategy](pure-strategy.md) specifies an action at every information set belonging to that player, including ones not reached during realized play.
