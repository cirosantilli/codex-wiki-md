# Microscopic reversibility

↑ **Parent:** [Local detailed balance](local-detailed-balance.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Microscopic_reversibility)

For an equilibrium process, a path and its physically time-reversed path have equal probability after including their equilibrium starting weights. Conditional on their endpoints, this means

$$
\frac{P_F}{P_B}=\exp[-(F_2-F_1)/(k_BT)].
$$

This is the path version of [detailed balance](detailed-balance.md). A time-even [order parameter](order-parameter.md) is read backward without changing sign, while a transport flux changes sign. The [Onsager--Machlup path probability](onsager-machlup-path-probability.md) implements this reversal in a coarse-grained stochastic description.
