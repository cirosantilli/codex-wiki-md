# File-system backup

↑ **Parent:** [File system](file-system-split.md)

A separately retained copy intended to recover [files](computer-file.md) after loss or unwanted changes. A journal can be overwritten after a [journal checkpoint](journal-checkpoint.md) and can faithfully commit an unwanted deletion; it does not supply that historical copy or protect against loss of the device holding the only copy.
