# Simplex dictionary

↑ **Parent:** [Simplex algorithm](simplex-algorithm.md)

A simplex dictionary expresses the basic variables and the objective as affine functions of the nonbasic variables in a [linear program](linear-programming.md). Setting the nonbasic variables to zero gives a [basic feasible solution](basic-feasible-solution.md) when all basic values are nonnegative. A [simplex algorithm](simplex-algorithm.md) pivot exchanges one basic and one nonbasic variable. For maximization, a feasible dictionary with all nonbasic objective coefficients nonpositive certifies optimality.
