# Convex roof extension

↑ **Parent:** [Quantum state ensemble](quantum-state-ensemble.md)

A convex roof extension extends a function $\mu$ on [pure states](pure-state.md) to arbitrary [density operators](density-matrix.md) by minimizing its ensemble average over all [pure state](pure-state.md) decompositions. It agrees with $\mu$ on [pure states](pure-state.md): every positive-weight state in a decomposition of a rank-one [density operator](density-matrix.md) has the same one-dimensional support. Concatenating nearly minimizing ensembles proves that $F$ is a [convex function](convex-function.md). Moreover, every [convex function](convex-function.md) that is no larger than $\mu$ on [pure states](pure-state.md) is no larger than $F$, by applying convexity to each decomposition. Infima need not be attained; an arbitrarily small additive error suffices when $F$ is finite.
