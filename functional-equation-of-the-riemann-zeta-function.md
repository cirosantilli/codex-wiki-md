# Functional equation of the Riemann zeta function

↑ **Parent:** [Riemann zeta function](riemann-zeta-function.md)

The completed zeta function

$$
\xi(s)=\frac12s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)
$$

is an [entire function](entire-function.md) satisfying $\xi(s)=\xi(1-s)$. Thus every nontrivial zero $\rho$ is accompanied by $1-\rho$, $\overline\rho$, and $1-\overline\rho$.
