# Cosmological visibility function

↑ **Parent:** [Cosmological optical depth](cosmological-optical-depth.md)

The visibility function

$$
g(\eta)=\partial_\eta e^{-\tau(\eta)}
=\Gamma(\eta)e^{-\tau(\eta)}
$$

is the probability density for the conformal time of a CMB photon's last scattering.

This probability density describes last scattering during [cosmological recombination](recombination-cosmology.md) and is built from the optical depth, rather than naming the recombination process itself.
