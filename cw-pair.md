# CW pair

↑ **Parent:** [CW complex](cw-complex.md)

A CW pair consists of a [CW complex](cw-complex.md) $X$ and a subcomplex $A$. Its inclusion is a [cofibration](cofibration.md), so homotopies on $A$ extend across $X$. The relative lifting property of a [Serre fibration](serre-fibration.md) for such pairs allows specified boundary lifts to be retained while lifting a homotopy.
