# Inverse-matrix verification test

↑ **Parent:** [Matrix inverse](matrix-inverse-split.md)

A claimed [inverse matrix](matrix-inverse-split.md) C for a finite square [matrix](matrix.md) A must satisfy $AC=CA=I$. A single product entry differing from the [identity matrix](identity-matrix.md) disproves the claim. Conversely, in finite dimension one exact identity such as $AC=I$ already implies that A has full [rank](rank-one-quadratic-form.md), so A is invertible and $C=A^{-1}$; the other product then equals I as well. Checking the product is useful before using a supplied inverse in a [similarity transformation](similarity-transformation.md).
