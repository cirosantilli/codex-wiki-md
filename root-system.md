# Root system

↑ **Parent:** [Root-space decomposition](root-space-decomposition.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Root_system)

A root system is a finite set of nonzero vectors closed under the reflections they define and satisfying the crystallographic integrality condition when it arises from a semisimple [Lie algebra](lie-algebra-split.md).
