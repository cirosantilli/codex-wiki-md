# Acoustic waveguide cutoff

↑ **Parent:** [Acoustic waveguide mode](acoustic-waveguide-mode.md)

For an [acoustic waveguide mode](acoustic-waveguide-mode.md) with transverse index $n\geq1$, the [dispersion relation](dispersion-relation-split.md) $\omega^2=c^2[q^2+(n\pi/H)^2]$ permits a propagating axial [wavenumber](wavenumber.md) only above the displayed [angular frequency](angular-frequency.md). Below it the outgoing bounded response decays as $e^{-\alpha x}$, with $\alpha=\sqrt{(n\pi/H)^2-\omega^2/c^2}$. The $n=0$ mode has no positive cutoff. At cutoff, a nonzero imposed axial derivative requires $\Phi=A+Bx$, so no bounded periodic solution exists on a semi-infinite channel. Near cutoff, fixed wall-velocity forcing gives amplitudes proportional to $1/|q|$, which can invalidate [linearization](linearization.md).
