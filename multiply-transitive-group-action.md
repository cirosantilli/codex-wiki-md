# Multiply transitive group action

↑ **Parent:** [Group action](group-action.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multiply_transitive_group_action)

A [group action](group-action.md) is $t$-transitive if it acts transitively on ordered $t$-tuples of distinct points. In degree $n\ge t$ this implies $n(n-1)\cdots(n-t+1)\mid |G|$. It is [sharply t-transitive](sharp-t-transitivity.md) when each such ordered tuple has trivial [stabilizer subgroup](stabilizer-subgroup.md).
