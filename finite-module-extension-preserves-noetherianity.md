# Finite-module extension preserves Noetherianity

↑ **Parent:** [Right Noetherian ring](right-noetherian-ring.md)

Suppose $A\subseteq B$ are unital [rings](ring.md) and $B$ is a [finitely generated module](finitely-generated-module.md) over $A$ on the right. If $A$ is a [right Noetherian ring](right-noetherian-ring.md), then $B_A$ is a [Noetherian module](noetherian-module.md). Every [right ideal](right-ideal.md) of $B$ is an $A$-[submodule](submodule.md), hence has finitely many generators over $A$; these also generate it over $B$. Thus $B$ is a [right Noetherian ring](right-noetherian-ring.md). The same argument works on the left under the corresponding hypotheses. Finite-index [group ring](group-ring.md) extensions give an important example, using coset representatives as a finite module basis.
