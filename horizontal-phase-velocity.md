# Horizontal phase velocity

↑ **Parent:** [Phase velocity](phase-velocity.md)

For phase $kx+mz-\omega t$ with $k\ne0$, hold $z$ fixed: a contour of constant [wave phase](phase-waves.md) advances in $x$ at $\omega/k$. This is the speed at which a tilted [wavefront](wavefront.md) crosses a horizontal line. It differs from the horizontal component of the vector [phase velocity](phase-velocity.md), $\omega k/(k^2+m^2)$, which is defined along the [wavevector](wavevector.md).
