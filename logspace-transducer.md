# Logspace transducer

↑ **Parent:** [Logarithmic space](logarithmic-space.md)

A deterministic [Turing machine](turing-machine.md) with read-only [input](input-computer-science.md), $O(\log(n+2))$ work space, and successive write-only output whose contents it cannot inspect. A transducer for a total function halts on every [input](input-computer-science.md). It has a [polynomial](polynomial-split.md) number of internal [Turing machine configurations](instantaneous-description-of-a-turing-machine.md), so a halting run emits only a [polynomial](polynomial-split.md) number of symbols. The unreadable output position does not affect subsequent transitions.
