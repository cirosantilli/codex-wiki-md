# Midpoint line decision

↑ **Parent:** [Bresenham's line algorithm](bresenham-s-line-algorithm.md)

For the [implicit equation](implicit-equation.md) $f(X,Y)=\Delta y(X-x_0)-\Delta x(Y-y_0)$, the sign of $d$ compares the exact [line](straight-line.md) with the midpoint between candidate [pixel](pixel.md) centres $(x+1,y)$ and $(x+1,y+1)$. Multiplication by two makes the test integral. A consistent equality rule specifies which tied [pixel](pixel.md) is selected.
