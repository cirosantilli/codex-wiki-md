# Relation module

↑ **Parent:** [Free presentation](free-presentation.md)

For a [free presentation](free-presentation.md) $G\cong F/R$, the relation module is the abelianization $R/[R,R]$ equipped with the $G$-action induced by conjugation in $F$.
