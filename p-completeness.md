# P-completeness

↑ **Parent:** [P (complexity)](p-complexity.md)

A language in [P](p-complexity.md) to which every P language has a [logspace many-one reduction](logspace-many-one-reduction.md). The reduction strength matters: using arbitrary polynomial-time reductions instead would make completeness trivial for nontrivial P decision problems.
