# Ground-state probability

↑ **Parent:** [Ground state](ground-state.md)

The probability that an [energy measurement](energy-measurement.md) selects a [ground state](ground-state.md). For a nondegenerate normalized mode $\phi_1$, it is $|\langle\phi_1,\psi\rangle|^2$; for a degenerate ground eigenspace, use its full orthogonal projection.
