# Discrete-time multi-state model

↑ **Parent:** [Markov chain](markov-chain.md)

A discrete-time model describes individual transitions between states at successive steps. State occupancy counts, first-entry counts and transition counts are distinct quantities, especially when a state has a self-loop. With independent individuals and fixed transition probabilities, destination counts conditional on the source count have a [multinomial distribution](multinomial-distribution.md).
