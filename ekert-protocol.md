# Ekert protocol

↑ **Parent:** [Quantum key distribution](quantum-key-distribution.md)

Entanglement-based key distribution that tests correlations with a [Bell inequality](bell-inequality.md). Equal measurement axes generate correlated key data; other settings test the quantum channel. Authentication, statistical parameter estimation, information reconciliation and [privacy amplification](privacy-amplification.md) are needed to turn observed correlations into a secure shared key under specified assumptions.[1991 primary proposal](quantum-cryptography-based-on-bell-s-theorem-by-artur-k-ekert.md)
