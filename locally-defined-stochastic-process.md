# Locally defined stochastic process

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

A continuous locally defined process is a pair $(X,T)$ specified on the [stochastic interval](stochastic-interval.md) $[0,T)$, with a lifetime [stopping time](stopping-time.md) $T$ approached by an [announcing sequence for a stopping time](announcing-sequence-for-a-stopping-time.md) $T_n$. Each stopped process is an ordinary continuous [adapted process](adapted-process.md). This is the convention used for continuous local differential equations; no value at $T$ is required. Restricting a globally defined process gives examples, but finite lifetimes also allow approach to a domain boundary or explosion.
