# Coordinate-shift shadow containment

↑ **Parent:** [Coordinate shifts of a set family](coordinate-shifts-of-a-set-family.md)

For a [uniform set family](uniform-set-family.md), the [lower shadow](lower-shadow.md) of its shifted [set family](set-family.md) is contained in the shifted [lower shadow](lower-shadow.md). Check the witness in the four patterns of membership in coordinates $i,j$. A surviving shadow member containing only $j$ must have both old shadow partners; a member containing only $i$ needs either old partner. Taking complements exchanges $C_{ij}$ with $C_{ji}$ and gives the same containment for the [upper shadow](upper-shadow.md). Thus [coordinate shifts of a set family](coordinate-shifts-of-a-set-family.md) cannot increase either shadow or their disjoint union, the [external vertex boundary](external-vertex-boundary.md) of a [uniform set family](uniform-set-family.md).
