# Type space

↑ **Parent:** [Complete type](complete-type.md)

With its standard topology, this [type space](type-space.md) is a [Stone space](stone-space.md). The type space $S_n^M(A)$ is the set of complete $n$-types over a parameter set $A$ that are consistent with the complete theory of $M$ together with its diagram over $A$.
