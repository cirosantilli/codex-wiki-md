# Immunity of incompressible strings

↑ **Parent:** [Incompressible string](incompressible-string.md)

If an infinite [computably enumerable](recursively-enumerable-set.md) family contained only [incompressible strings](incompressible-string.md), select its first enumerated string of length at least $n$. This is a total computable selection rule, and its selected string has a description of length $O(\log n)$ encoding the threshold. For large $n$ that is shorter than the selected string. This contradiction proves immunity.
