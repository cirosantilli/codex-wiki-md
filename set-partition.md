# Set partition

↑ **Parent:** [Combinatorics](combinatorics-split.md)

A set partition is a collection of nonempty, pairwise disjoint subsets called blocks whose union is the original set.

A set partition is a [partition of a set](partition-of-a-set.md) into its disjoint nonempty blocks.
