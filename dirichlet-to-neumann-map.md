# Dirichlet-to-Neumann map

↑ **Parent:** [Boundary value problem](boundary-value-problem.md)

Given a uniquely solvable [Dirichlet problem](dirichlet-problem.md), this map sends prescribed [Dirichlet boundary data](dirichlet-boundary-data.md) to the solution's outward [normal derivative](normal-derivative.md). It depends on the differential operator and domain. Spectral [global relations](global-relation-for-a-linear-boundary-value-problem.md) offer one way to compute it numerically from boundary traces, while a finite collocation scheme still requires a rank and conditioning check.
