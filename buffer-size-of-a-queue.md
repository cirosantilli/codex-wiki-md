# Buffer size of a queue

↑ **Parent:** [Queue (queueing theory)](queue-queueing-theory.md)

The maximum stored work or number of waiting jobs, according to the model's convention. A [bufferless queue](bufferless-queue.md) has no room to retain excess input for a later slot.
