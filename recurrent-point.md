# Recurrent point

↑ **Parent:** [Topological dynamics](topological-dynamics.md)

A point of a [dynamical system](dynamical-system.md) is recurrent if some sequence of positive times tending to infinity returns its [orbit](orbit-dynamical-system.md) arbitrarily close to the point. In a compact [metric space](metric-space.md), this is equivalent to the displayed condition. A periodic point is recurrent, but a recurrent point need not be periodic.
