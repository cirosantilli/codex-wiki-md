# Passive cavity input-output transfer function

↑ **Parent:** [Coherent quantum feedback](coherent-quantum-feedback.md)

For $\dot a=-\gamma a/2-\sqrt\gamma\,b_0$ and $b_1=\sqrt\gamma\,a+b_0$, zero-initial-data [Laplace transforms](laplace-transform.md) give the displayed [transfer function](transfer-function.md). For $\gamma>0$ its pole is in the open left half-plane, while $|G(i\omega)|=1$ and its zero lies in the right half-plane. Passing through $-1$ in this plant's frequency plot is not evidence of an unstable open cavity: a [Nyquist stability criterion](nyquist-stability-criterion.md) needs an explicitly specified feedback return ratio.
