# Deterministic evolution

↑ **Parent:** [Dynamical system](dynamical-system.md)

Evolution is deterministic when a specified [initial condition](initial-condition.md) and evolution rule select a unique future [orbit](orbit-dynamical-system.md). For a [discrete dynamical system](discrete-dynamical-system-split.md), applying the same [map](function-class.md) to the same state gives the same next state. For an [ordinary differential equation](ordinary-differential-equation.md), uniqueness of the [initial value problem](initial-value-problem.md) is required; merely writing a [differential equation](differential-equation-split.md) does not guarantee it.

Determinism permits both [asymptotic stability](asymptotic-stability.md) and [sensitive dependence on initial conditions](butterfly-effect.md). It does not by itself imply reliable prediction from approximate measurements, and sensitivity does not introduce a random choice into the evolution rule.
