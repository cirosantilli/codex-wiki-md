# Tangential boundary derivative

↑ **Parent:** [Boundary condition](boundary-condition.md)

A tangential boundary derivative differentiates the boundary restriction of a [function](function-split.md) along a [tangent vector](tangent-vector.md). Prescribing it fixes the boundary value only up to a constant on each connected boundary component. This differs from a [Neumann boundary condition](neumann-boundary-condition.md), which specifies a normal [derivative](derivative.md).
