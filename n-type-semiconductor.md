# N-type semiconductor

↑ **Parent:** [Semiconductor doping](semiconductor-doping.md)

An [n-type semiconductor](n-type-semiconductor.md) has more mobile [electrons](electron.md) than [electron holes](electron-hole.md). The letter describes the predominant mobile [charge carriers](charge-carrier.md), not a net negative [electric charge](electric-charge-split.md) of the whole material.
