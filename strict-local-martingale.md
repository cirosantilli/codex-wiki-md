# Strict local martingale

↑ **Parent:** [Local martingale](local-martingale.md)

A strict local martingale is a [local martingale](local-martingale.md) that is not a true [martingale](martingale-split.md). The reciprocal of a three-dimensional [Bessel process](bessel-process.md) is an example: it is a nonnegative [continuous local martingale](continuous-local-martingale.md) whose [expectation](expected-value.md) decreases strictly.
