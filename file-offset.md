# File offset

↑ **Parent:** [Computer file](computer-file.md)

A [byte](byte.md) position measured from the start of a [file](computer-file.md), beginning at zero. A [memory-mapped file](memory-mapped-file.md) combines a starting [file offset](file-offset.md) with a displacement inside its mapping; this is distinct from an [open file description](open-file-description.md)'s current read/write position.
