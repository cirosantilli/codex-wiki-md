# Homolysis

↑ **Parent:** [Chemical bond](chemical-bond-split.md)

[Homolysis](homolysis.md) splits a [covalent bond](covalent-bond-split.md) with one bonding [electron](electron.md) assigned to each fragment. A neutral closed-shell [molecule](molecule-split.md) thereby produces fragments with unpaired [electrons](electron.md), each a [radical](radical-chemistry.md). The usual [bond-dissociation enthalpy](bond-dissociation-enthalpy.md) uses this product convention.
