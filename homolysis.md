# Homolysis

↑ **Parent:** [Chemical bond](chemical-bond.md)

[Homolysis](homolysis.md) splits a [covalent bond](covalent-bond.md) with one bonding [Electron](electron.md) assigned to each fragment. A neutral closed-shell [molecule](molecule.md) thereby produces fragments with unpaired [Electrons](electron.md), each a [radical](radical-chemistry.md). The usual [bond-dissociation enthalpy](bond-dissociation-enthalpy.md) uses this product convention.
