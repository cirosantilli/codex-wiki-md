# T-forward measure

↑ **Parent:** [Forward measure](forward-measure.md)

For a maturity $T$, the T-forward measure uses the zero-coupon bond maturing at $T$ as [numéraire](numeraire.md). If $B_t^T$ is its time-$t$ price, an attainable payoff $X_T$ has value $B_t^T\mathbb E_{Q^T}[X_T\mid\mathcal F_t]$.
