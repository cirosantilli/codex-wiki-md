# Instanton

↑ **Parent:** [Euclidean path integral](euclidean-path-integral.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Instanton)

An [instanton](instanton.md) is a localized finite-action classical solution in Euclidean spacetime, used in a semiclassical description of [quantum tunnelling](quantum-tunnelling.md) and other nonperturbative effects. In one-dimensional quantum mechanics it can connect distinct degenerate potential minima over infinite Euclidean time. A [quartic double-well instanton](quartic-double-well-instanton.md) is an elementary example; a [Yang-Mills instanton](yang-mills-instanton.md) is a gauge-field example with different geometric structure.
