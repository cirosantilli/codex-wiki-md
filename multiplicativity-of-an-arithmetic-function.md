# Multiplicativity of an arithmetic function

↑ **Parent:** [Multiplicative function](multiplicative-function.md)

Multiplicativity means $f(mn)=f(m)f(n)$ whenever $m,n$ are [coprime integers](coprime-integers.md). It allows values of an [arithmetic function](arithmetic-function.md) to be assembled from its values on [prime powers](prime-power.md).
