# Multiplicativity of an arithmetic function

↑ **Parent:** [Multiplicative function](multiplicative-function.md)

For an [arithmetic function](arithmetic-function-split.md), [multiplicativity](multiplicativity-of-an-arithmetic-function.md) means $f(1)=1$ and $f(mn)=f(m)f(n)$ whenever $m,n$ are positive [coprime integers](coprime-integers.md). It allows values of an [arithmetic function](arithmetic-function-split.md) to be assembled from its values on [prime powers](prime-power.md), as explained under [multiplicative function](multiplicative-function.md).
