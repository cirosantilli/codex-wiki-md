# Dyadic occupancy approximation of a simple point measure

↑ **Parent:** [Simple locally finite point measure](simple-locally-finite-point-measure.md)

For a fixed bounded interval with no atoms at its endpoints, the occupation count of fully contained half-open [dyadic intervals](dyadic-interval.md) increases to the true count of a [simple locally finite point measure](simple-locally-finite-point-measure.md). Refinement cannot reduce occupancy. Finitely many distinct atoms in a bounding interval have positive minimum separation; for fine enough cells each atom lies alone, and every interior atom's cell is contained in the target interval. Thus the counts eventually agree, path by path.
