# Gaussian score event for the Lasso

↑ **Parent:** [Lasso](lasso.md)

Let $0<c<1$, $A>0$, $\sigma>0$ and $p\geq2$. For [design matrix](design-matrix.md) columns of norm $\sqrt n$ and $\varepsilon\sim N_n(0,\sigma^2I)$, the event $\|X^T\varepsilon\|_\infty/n\leq c\lambda$ has probability at least $1-p^{1-A^2c^2/2}$ when $\lambda=A\sigma\sqrt{\log(p)/n}$. Apply the [sharp two-sided Gaussian tail bound](sharp-two-sided-gaussian-tail-bound.md) to each standardized score and then the [union bound](boole-s-inequality.md); independence of the scores is not required.
