# Nice forcing name

↑ **Parent:** [Forcing name](forcing-name.md)

A name for a subset of a ground-model set, given coordinatewise by [antichains in a forcing order](antichain-in-a-forcing-order.md). For countable-chain-condition forcing, each coordinate uses a countable antichain, which bounds the number of names for reals.
