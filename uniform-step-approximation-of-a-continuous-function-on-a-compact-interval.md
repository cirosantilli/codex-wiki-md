# Uniform step approximation of a continuous function on a compact interval

↑ **Parent:** [Step function](step-function.md)

A [continuous function](continuous-function.md) on a [compact interval](compact-interval.md) is [uniformly continuous](uniform-continuity.md) by the [Heine-Cantor theorem](heine-cantor-theorem.md). Choose a [partition of an interval](partition-of-an-interval.md) whose widths lie below the input tolerance for a desired output error $\varepsilon$. On each half-open partition subinterval, use the value of the [function](function-split.md) at its left endpoint, and assign the rightmost endpoint its own value. This defines a [step function](step-function.md) whose error is strictly below $\varepsilon$ at every input. Finitely assigned partition-point values are allowed and do not alter the [Riemann integral](riemann-integral.md).
