# Membership induction theorem

↑ **Parent:** [Axiom of regularity](axiom-of-regularity.md)

Membership induction is the schema displayed, with set parameters permitted in $\varphi$. The [Axiom of foundation](axiom-of-regularity.md) proves it by choosing a minimal counterexample in the [transitive closure](transitive-closure.md) $\operatorname{TC}(\{x\})$ of the singleton containing a counterexample $x$. Conversely, if a nonempty set $a$ had no membership-minimal element, the property $x\notin a$ would be progressive, so induction would force $a$ to be empty. Thus over ZF without [Axiom of foundation](axiom-of-regularity.md), this schema implies [Axiom of foundation](axiom-of-regularity.md). It also implies that every set lies in the [cumulative hierarchy](cumulative-hierarchy.md): bound the stage indices of all members of a set by replacement, then place that set in the next power-set stage.
