# Pooling layer

↑ **Parent:** [Convolutional neural network](convolutional-neural-network.md)

A network layer aggregating nearby activations, for example by a maximum or mean. Pooling can reduce spatial size but does not by itself guarantee arbitrary [translation invariance](translation-invariance.md).
