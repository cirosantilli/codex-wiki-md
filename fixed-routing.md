# Fixed routing

↑ **Parent:** [Loss network](loss-network.md)

Under fixed routing, each call type always requests the same collection of resources. The [link-route incidence matrix](link-route-incidence-matrix.md) records those requirements. This differs from [alternative routing](alternative-routing.md), in which a rejected direct request can try another route.
