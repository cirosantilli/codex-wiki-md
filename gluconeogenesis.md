# Gluconeogenesis

↑ **Parent:** [Metabolism](metabolism.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gluconeogenesis)

[Gluconeogenesis](gluconeogenesis.md) synthesizes [glucose](glucose.md) from non-[carbohydrate](carbohydrate.md) precursors. It is distinct from [glycogenolysis](glycogenolysis.md), which mobilizes an existing [glycogen](glycogen.md) store.
