# Handle decomposition

↑ **Parent:** [Handle attachment](handle-attachment.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Handle_decomposition)

A handle decomposition builds an $n$-dimensional [manifold](topological-manifold.md) by successively adjoining $D^h\times D^{n-h}$ along $S^{h-1}\times D^{n-h}$. The attaching data comprise an [attaching sphere](attaching-sphere.md) and its [framing of an embedded sphere](framing-of-an-embedded-sphere.md). Reading a decomposition backwards replaces index $h$ by index $n-h$ and interchanges its [attaching spheres](attaching-sphere.md) and [belt spheres](belt-sphere.md).
