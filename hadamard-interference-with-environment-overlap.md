# Hadamard interference with environment overlap

↑ **Parent:** [Complex environment overlap in qubit dephasing](complex-environment-overlap-in-qubit-dephasing.md)

In a [Hadamard gate](hadamard-gate.md), [phase gate](phase-gate.md), [Hadamard gate](hadamard-gate.md) sequence starting from $|0\rangle$, let a population-preserving interaction correlate $|j\rangle$ with a normalized environment state $|e_j\rangle$ between the two [Hadamard gates](hadamard-gate.md). Use $P_\varphi=\operatorname{diag}(1,e^{i\varphi})$ and $\langle e_0|e_1\rangle=ve^{i\alpha}$. The environment-valued output-zero coefficient is $(|e_0\rangle+e^{i\varphi}|e_1\rangle)/2$, whose squared [norm](norm.md) is the displayed [probability](probability.md). The modulus $v$ controls contrast, while $\alpha$ shifts the [quantum interference](quantum-interference.md) fringe. For $v=1$ there is no mixing; a deterministic relative [quantum phase](quantum-phase.md) accounts for the shift.
