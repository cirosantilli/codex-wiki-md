# Cache tag

↑ **Parent:** [Cache slot](cache-slot.md)

Metadata identifying which eligible backing [cache block](cache-line.md) a valid [cache slot](cache-slot.md) currently holds. In the [fully associative cache](fully-associative-cache.md) example, the [cache tag](cache-tag.md) is the full [cache block](cache-line.md) number $q$; in the two-slot [direct-mapped cache](direct-mapped-cache.md) example, the slot supplies $q\bmod2$ and the [cache tag](cache-tag.md) can store $\lfloor q/2\rfloor$ using the [floor function](floor-function.md).
