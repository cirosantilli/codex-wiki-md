# Polynomial regression

↑ **Parent:** [Linear regression](linear-regression-split.md)

A [linear regression](linear-regression-split.md) in the coefficients with a polynomial mean function $\mathbb E(Y\mid t)=\sum_{j=0}^d\beta_jt^j$. Successive degrees define nested models that can be compared by an [F-test](f-test.md).
