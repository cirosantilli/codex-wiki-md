# Polynomial interactions as source differential operators

↑ **Parent:** [Generating functional](generating-functional.md)

In a finite-dimensional integral, $u_i e^{b\cdot u}=\partial_{b_i}e^{b\cdot u}$. Expand $e^{V(u)}$ as a formal perturbation series to obtain $\int du\,e^{-u^TAu/2+b\cdot u+V(u)}=e^{V(\partial_b)}I_0(b)$. With a finite-mode regulator, a Minkowski source insertion satisfies $\phi(x)e^{i\int J\phi}=(1/i)\delta e^{i\int J\phi}/\delta J(x)$; this gives the displayed interacting [generating functional](generating-functional.md). The substitution is a perturbative differential-operator identity, not an assertion that the interaction exponential defines a convergent series. Divide the resulting functional by $Z[0]$ for normalized [correlation functions](correlation-function.md).
