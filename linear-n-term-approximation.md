# Linear N-term approximation

↑ **Parent:** [N-term approximation](n-term-approximation.md)

A linear N-term approximation fixes its index set independently of the approximated function. Wavelet approximation normally orders by increasing resolution, whereas [Fourier series](fourier-series-split.md) approximation normally keeps the lowest frequencies. An arbitrary reordering can change or destroy a claimed convergence rate.
