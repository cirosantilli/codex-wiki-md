# Jump discontinuity

↑ **Parent:** [Discontinuity of a function](discontinuity-of-a-function.md)

A jump occurs when both finite one-sided limits of a function exist but differ. Unlike an isolated change in value, a jump changes limiting values on whole one-sided neighbourhoods. [One-sided Fourier spectrum excludes jumps](one-sided-fourier-spectrum-excludes-jumps.md) explains an obstruction to jumps for functions with only nonnegative [Fourier coefficients](fourier-coefficient.md).
