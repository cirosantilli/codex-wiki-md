# Stationary points under an increasing outer function

↑ **Parent:** [Stationary point](stationary-point.md)

Suppose $h$ is differentiable and $F'>0$ on its range. The [multivariable chain rule](multivariable-chain-rule.md) shows that $F\circ h$ has exactly the same [stationary points](stationary-point.md) as $h$. Since $F$ is strictly increasing, the type of every [local maximum](local-maximum.md), [local minimum](local-minimum.md), and [saddle point](saddle-point.md) is preserved. If both functions are twice differentiable, then at a stationary point

$$
\operatorname{Hess}(F\circ h)=F'(h)\operatorname{Hess}h,
$$

so the [Hessian matrix](hessian-matrix.md) signature is unchanged. The hypothesis $F'>0$ matters for the converse about stationary points: a strictly increasing function such as $F(s)=s^3$ can have a zero [derivative](derivative.md) and create new stationary points in a composition.
