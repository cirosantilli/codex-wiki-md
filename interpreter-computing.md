# Interpreter (computing)

↑ **Parent:** [Programming language](programming-language.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Interpreter_(computing))

An implementation that executes a program's operations. An [interpreter](interpreter-computing.md) can work from an [abstract syntax tree](abstract-syntax-tree.md) or another representation rather than requiring the whole program to be translated into [machine code](machine-code.md) in advance.
