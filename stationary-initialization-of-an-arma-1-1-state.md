↑ **Parent:** [Three-coordinate state realization of an ARMA(1,1) process](three-coordinate-state-realization-of-an-arma-1-1-process.md)

For $|\phi|<1$ and centered [independent](independent-random-variables.md) [white noise](white-noise.md) values, the state above has [expected value](expected-value.md) zero and this stationary [covariance matrix](covariance-matrix.md), where $\gamma_0=\sigma^2(1+\theta^2+2\phi\theta)/(1-\phi^2)$. The cross-covariance with the future [white noise](white-noise.md) value is zero and that with the contemporaneous [white noise](white-noise.md) value is $\sigma^2$. Direct multiplication verifies $P=GPG^\top+Q$.
