# Density-gradient centrifugation

↑ **Parent:** [Centrifugation](centrifugation.md)

[Density-gradient centrifugation](density-gradient-centrifugation.md) uses a liquid whose [density](density.md) varies along the separation direction. A band does not by itself establish which mechanism produced it: [rate-zonal centrifugation](rate-zonal-centrifugation.md) separates by migration rate before equilibrium, whereas [isopycnic centrifugation](isopycnic-centrifugation.md) uses equilibrium positions set by [buoyant density](buoyant-density.md).
