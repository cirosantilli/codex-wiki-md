# Atomic proposition

↑ **Parent:** [Propositional logic](propositional-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Atomic_proposition)

An indivisible statement treated as either true or false. In a labelled [transition system](transition-system.md), an [atomic proposition](atomic-proposition.md) $p$ holds at [state](state-computer-science.md) $s$ exactly when $p\in L(s)$.
