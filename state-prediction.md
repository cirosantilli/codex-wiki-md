# State prediction

↑ **Parent:** [State estimation](state-estimation.md)

[State prediction](state-prediction.md) estimates a future state of a [dynamical system](dynamical-system.md) using observations already available. A [state-space model](state-space-model-time-series.md) supplies the transition law. Unlike [causal state filtering](causal-state-filtering.md) at the next time, the prediction has not yet incorporated that next observation; a [Kalman prediction step](kalman-prediction-step.md) therefore includes uncertainty from new [process noise](process-noise.md).
