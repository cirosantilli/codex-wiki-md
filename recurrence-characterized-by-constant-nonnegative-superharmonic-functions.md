# Recurrence characterized by constant nonnegative superharmonic functions

↑ **Parent:** [Nonnegative superharmonic function for a Markov chain](nonnegative-superharmonic-function-for-a-markov-chain.md)

An irreducible [Markov chain](markov-chain.md) is recurrent exactly when every [nonnegative superharmonic function for a Markov chain](nonnegative-superharmonic-function-for-a-markov-chain.md) is constant. In the recurrent case, absorb the chain at $j$. The inequality $g_i\ge(\widetilde P^{\,n}g)_i\ge g_j\mathbb P_i(\tau_j\le n)$ and almost-sure hitting give $g_i\ge g_j$; exchange $i,j$. In the transient case, the [hitting probability](hitting-probability.md) of a state $j$ is one there and satisfies the superharmonic inequality, but its one-step average at $j$ is the strictly smaller return probability. It is a nonconstant example.
