# Koszul homotopy for multiplication by a generator

↑ **Parent:** [Koszul homology](koszul-homology.md)

Exterior multiplication $h_j(u)=e_j\wedge u$ is a [chain homotopy](chain-homotopy.md) between multiplication by $f_j$ and zero on a [Koszul complex](koszul-complex.md). A linear combination of these homotopies is a [contracting homotopy](contracting-homotopy.md) when the generators span the unit ideal.
