# Catalytic hydrogenation

↑ **Parent:** [Hydrogenation](hydrogenation.md)

Reduction using [hydrogen](hydrogen.md) and a catalyst. Selectivity depends on the catalyst, pressure, solvent and functional groups: reducing an [alkene](alkene.md) while retaining a [ketone](ketone.md) is a distinct requirement from reducing a [nitrile](nitrile.md) while retaining an [ester](ester.md).
