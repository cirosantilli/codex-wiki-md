# Initial-state dependence of Ramsey contrast

↑ **Parent:** [Ramsey interferometry](ramsey-interferometry.md)

The contrast of a phase-sensitive pulse sequence depends on the state _during_ phase accumulation. Coherent preparation can create two populated paths whose [relative quantum phase](relative-quantum-phase.md) is converted to a population by readout; preparation into one path gives no such signal. For the [Hadamard-phase-Hadamard qubit rotation](hadamard-phase-hadamard-qubit-rotation.md), a pure $z$-polarized input yields full contrast, a pure $x$-polarized input yields none, and an unpolarized input also yields none. The last two cases have different [purity](purity-of-a-density-operator.md) despite identical measured populations. [Purity](purity-of-a-density-operator.md) alone is therefore not a phase-sensitivity criterion.
