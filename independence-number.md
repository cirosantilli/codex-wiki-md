# Independence number

↑ **Parent:** [Independent set (graph theory)](independent-set-graph-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Independence_number)

The independence number is the largest cardinality of an [independent set](independent-set-graph-theory.md) in a graph. Since every colour class is independent,

$$
\chi(G)\geq\frac{|V(G)|}{\alpha(G)}.
$$
