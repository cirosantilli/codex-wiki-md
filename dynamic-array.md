# Dynamic array

↑ **Parent:** [Array (data structure)](array-data-structure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dynamic_array)

A [dynamic array](dynamic-array.md) is an [array](array-data-structure.md) whose backing storage can grow as entries are appended. [Dynamic array doubling](dynamic-array-doubling.md) is one growth policy with a deterministic [amortized analysis](amortized-analysis.md).
