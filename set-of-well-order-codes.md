# Set of well-order codes

↑ **Parent:** [Descriptive set theory](descriptive-set-theory-split.md)

The set $\mathrm{WF}\subseteq\omega^\omega$ consists of the reals coding [well-orders](well-order.md) of $\omega$. For $x\in\mathrm{WF}$, the norm $\lVert x\rVert$ is the [order type](order-type.md) of the well-order coded by $x$.
