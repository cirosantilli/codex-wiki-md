# Inner model

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inner_model)

An inner model is a transitive class containing every [ordinal](ordinal.md) and satisfying the specified axioms of set theory with the inherited membership relation.
