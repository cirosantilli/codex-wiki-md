# Entangling gate

↑ **Parent:** [Quantum logic gate](quantum-logic-gate.md)

A [unitary gate](quantum-logic-gate.md) on two [quantum systems](quantum-system-split.md) is entangling if it maps at least one [pure state](pure-state.md) that is a [product state](product-state.md) to an [entangled state](entangled-state.md). The [controlled-NOT gate](controlled-not-gate.md) qualifies because it maps $|+\rangle|0\rangle$ to a [Bell state](bell-state-split.md). A gate that merely exchanges the two systems need not be a [local unitary operation](local-unitary-operation.md), but cannot create [quantum entanglement](entangled-state.md) from a [product state](product-state.md).
