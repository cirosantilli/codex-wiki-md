# Multilinear map

↑ **Parent:** [Multilinear algebra](multilinear-algebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multilinear_map)

A [multilinear map](multilinear-map.md) $F:V_1\times\cdots\times V_r\to W$ is a map between [vector spaces](vector-space-split.md) that is linear in each argument when all other arguments are fixed. For example the evaluation $(\omega,v)\mapsto\omega(v)$ is bilinear, and the [determinant](determinant.md) is multilinear in its columns. The [universal property of a tensor product](universal-property-of-a-tensor-product.md) replaces this separate linearity by a single [linear map](linear-map.md) from $V_1\otimes\cdots\otimes V_r$.
