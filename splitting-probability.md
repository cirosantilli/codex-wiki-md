# Splitting probability

↑ **Parent:** [Hitting probability](hitting-probability.md)

A splitting probability is the probability that a stochastic process reaches one target before competing targets. For a diffusion it is harmonic for the [Kolmogorov backward equation](kolmogorov-backward-equation.md), with boundary values one on the selected target and zero on the others.
