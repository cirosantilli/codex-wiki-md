# Kolmogorov complexity

↑ **Parent:** [Computability theory](computability-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kolmogorov_complexity)

[Kolmogorov complexity](kolmogorov-complexity.md) measures the length of a shortest effective description of an object. Fixing an [optimal description machine](optimal-description-machine.md) gives an invariant quantity up to an additive machine-dependent constant. [Plain Kolmogorov complexity](plain-kolmogorov-complexity.md) is especially convenient for counting descriptions shorter than a [binary string](binary-string.md).
