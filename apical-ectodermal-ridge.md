# Apical ectodermal ridge

↑ **Parent:** [Limb bud](limb-bud.md)

A specialized distal ectodermal structure that supplies signals supporting limb outgrowth and patterning. Removing it simultaneously alters several processes, so truncation alone does not uniquely identify a timing mechanism.
