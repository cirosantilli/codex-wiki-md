# Uncountable-language proof of propositional completeness

↑ **Parent:** [Completeness theorem for propositional logic](completeness-theorem-for-propositional-logic.md)

When the primitive propositions are not countable, replace sequential enumeration of the formulae by [Zorn lemma](zorn-s-lemma.md). The union of a chain of consistent extensions is consistent because every formal proof is finite, so every consistent theory extends to a [maximal consistent set in propositional logic](maximal-consistent-set-in-propositional-logic.md). Declaring an atom true exactly when it belongs to that maximal set and proving the truth lemma by structural induction produces a model.
