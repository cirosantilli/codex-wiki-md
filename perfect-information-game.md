# Perfect-information game

↑ **Parent:** [Game theory](game-theory-split.md)

An [extensive-form game](extensive-form-game.md) in which each [information set](information-set.md) contains a single decision node. Each acting player knows the entire preceding sequence of moves. Finite games with this property can be solved for a [subgame perfect equilibrium](subgame-perfect-equilibrium.md) by [backward induction](backward-induction.md).
