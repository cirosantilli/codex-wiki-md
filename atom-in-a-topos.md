# Atom in a topos

↑ **Parent:** [Elementary topos](elementary-topos.md)

An atom is a noninitial object with only the empty and whole subobject. In the [atomic finite-surjection site](atomic-finite-surjection-site.md), the sheaf component generated by one primitive class is an atom: membership of one descendant in a subobject descends to its primitive ancestor and then propagates to all descendants. A decomposition into atoms makes subobjects selections of components.
