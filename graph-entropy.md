# Graph entropy

↑ **Parent:** [Information entropy](information-entropy.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Graph_entropy)

For a vertex law $P$ on a graph, choose $X\sim P$ and an [independent set](independent-set-graph-theory.md) valued random variable $Y$ containing $X$ almost surely. Minimize their [mutual information](mutual-information.md) over all such joint laws. This defines graph entropy. It differs from the entropy of a proper coloring, because the random independent set need not be a deterministic color class.
