# I1 incoherent feed-forward loop

↑ **Parent:** [Incoherent feed-forward loop](incoherent-feed-forward-loop.md)

In the I1 [incoherent feed-forward loop](incoherent-feed-forward-loop.md), an input activates both an intermediate regulator and the output, while the intermediate represses the output. Delayed accumulation of the intermediate can therefore interrupt an initial output pulse. The precise [steady state](steady-state.md) depends on the actual [gene regulation](regulation-of-gene-expression.md) rule and thresholds.
