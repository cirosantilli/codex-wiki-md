# Dual root system

↑ **Parent:** [Coroot](coroot.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dual_root_system)

The dual root system of $\Phi$ is $\Phi^\vee=\{\alpha^\vee:\alpha\in\Phi\}$. It has the transposed [Cartan matrix](cartan-matrix.md), so its [Dynkin diagram](dynkin-diagram.md) reverses every multiple-edge arrow; in particular, $B_n$ and $C_n$ are dual.
