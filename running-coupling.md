# Running coupling

↑ **Parent:** [Renormalization scale](renormalization-scale.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Running_coupling)

A running coupling is a renormalized coupling regarded as a function of the [renormalization scale](renormalization-scale.md). Its scale derivative is its [beta function](beta-function-physics.md).
