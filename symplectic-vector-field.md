# Symplectic vector field

↑ **Parent:** [Symplectic manifold](symplectic-manifold.md)

A [vector field](vector-field.md) on a [symplectic manifold](symplectic-manifold.md) is symplectic when its flow preserves the [symplectic form](symplectic-form.md). Infinitesimally this is $\mathcal L_X\omega=0$. By [Cartan's magic formula](cartan-s-magic-formula.md) it is equivalent to $d(\iota_X\omega)=0$. A [Hamiltonian vector field](hamiltonian-vector-field.md) has an exact contraction with the form, so is symplectic. On the standard two-dimensional [torus](torus.md), $\partial_x$ contracts to the closed but nonexact form $dy$, providing a symplectic non-Hamiltonian example.
