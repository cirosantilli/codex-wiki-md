# Convolution kernel

↑ **Parent:** [Convolution](convolution.md)

A convolution kernel is the fixed [function](function-split.md) $h$ in an operator $T_hf=f*h$. It specifies how shifted input values are weighted. The averaging kernel $k_\varepsilon$ above has nonnegative values and [integral](integral-split.md) one; arbitrary [convolution kernels](convolution-kernel.md) need not have either property. A [linear time-invariant system](linear-time-invariant-system.md) uses its [impulse response](impulse-response.md) as a kernel when its output admits this representation.
