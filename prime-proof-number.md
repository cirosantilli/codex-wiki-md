# Prime-proof number

↑ **Parent:** [Primality testing](primality-testing.md)

An [integer](integer-split.md) for which replacing any one decimal [numerical digit](numerical-digit.md) by a different digit never produces a [prime number](prime-number-split.md). The convention must specify whether changes creating a leading zero are permitted. An exact test enumerates the allowed substitutions and applies [primality testing](primality-testing.md) to each result.
