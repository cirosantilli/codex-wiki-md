# Pooling selected slopes in a Poisson regression

↑ **Parent:** [Poisson regression](poisson-regression.md)

A categorical covariate can be grouped in an interaction term while retaining its original main effect. This shares selected slopes but keeps separate intercepts. Nested [Poisson deviance](poisson-deviance.md) differences test slope pooling and intercept pooling separately.
