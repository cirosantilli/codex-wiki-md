# Trace distance

↑ **Parent:** [Density matrix](density-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Trace_distance)

The trace distance between [density operators](density-matrix.md) is

$$
D(\rho,\sigma)=\frac12\lVert\rho-\sigma\rVert_1.
$$

Every [quantum channel](quantum-channel.md), including the [partial trace](partial-trace.md), contracts trace distance.
