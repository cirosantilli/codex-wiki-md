# Binary categorical variable

↑ **Parent:** [Categorical variable](categorical-variable.md)

A [categorical variable](categorical-variable.md) with two possible categories. Coding an event as one and its complement as zero makes the [sample mean](sample-mean.md) of that [indicator variable](indicator-variable.md) equal to the event's [sample proportion](sample-proportion.md).
