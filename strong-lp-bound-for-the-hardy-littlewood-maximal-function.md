# Strong Lp bound for the Hardy-Littlewood maximal function

↑ **Parent:** [Hardy-Littlewood maximal inequality](hardy-littlewood-maximal-inequality.md)

For $1<p\leq\infty$, the [Hardy-Littlewood maximal function](hardy-littlewood-maximal-function.md) is bounded on $L^p(\mathbb R^n)$. A direct proof for finite $p$ applies the weak $(1,1)$ estimate to $f\mathbf1_{\{|f|>s/2\}}$, integrates the resulting distribution-function bound against $ps^{p-1}$, and uses [Tonelli theorem](tonelli-theorem.md).
