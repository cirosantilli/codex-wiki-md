# Infrared spin-wave correlations of the XY model

↑ **Parent:** [Phase-difference variance](phase-difference-variance.md)

For the [Gaussian functional integral](gaussian-functional-integral.md) with dimensionless [phase stiffness](phase-stiffness.md) $K$ and a microscopic cutoff $a$, the [Gaussian phase averaging](gaussian-phase-averaging.md) identity gives the displayed [correlation function](correlation-function.md). In two dimensions the [phase-difference variance](phase-difference-variance.md) is $(\pi K)^{-1}\log(r/a)+O(1)$, so the [XY model](xy-model.md) has algebraic [spin wave](spin-wave.md) correlations with exponent $1/(2\pi K)$. In one dimension the variance is $r/K$, giving exponential decay. Above two dimensions the variance has a finite large-distance limit within the low-temperature [spin wave](spin-wave.md) approximation. The [Laplacian](laplacian.md) Green function solves $-K\nabla^2G=\delta$; integration over a sphere fixes $G(r)=r^{2-d}/[(d-2)S_dK]+C$ for $d\ne2$ and $G(r)=-(2\pi K)^{-1}\log(r/a)+C$ for $d=2$. A fixed uniform phase and ultraviolet regularization are required to define $G$ itself; phase differences eliminate the constant.
