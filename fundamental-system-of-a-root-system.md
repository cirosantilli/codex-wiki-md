# Fundamental system of a root system

↑ **Parent:** [Root system](root-system.md)

A fundamental system $\Delta$ is a basis made of roots such that every root is a linear combination of $\Delta$ whose nonzero coefficients all have the same sign. Its members are the [simple roots](simple-root.md).
