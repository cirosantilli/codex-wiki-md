# Radial stellar pulsation equation

↑ **Parent:** [Linear adiabatic stellar oscillation equations](linear-adiabatic-stellar-oscillation-equations.md)

For a radial [stellar oscillation](stellar-oscillation.md), put $\xi_r=r\eta$. The self-gravitating adiabatic equation is $(\Gamma_1Pr^4\eta^{\prime})^{\prime}+r^3[(3\Gamma_1-4)P]^{\prime}\eta+\rho r^4\omega^2\eta=0$. It is a [Sturm-Liouville problem](sturm-liouville-problem.md) whose [Rayleigh quotient](rayleigh-quotient.md) tests radial stability. The familiar constant-exponent threshold is $\Gamma_1=4/3$; a variable exponent requires the full integral test.
