# Integral kernel

↑ **Parent:** [Integral operator](integral-operator.md)

An integral kernel is a [function](function-split.md) or [distribution](distribution-mathematical-analysis.md) specifying an [integral operator](integral-operator.md) through $(Tf)(x)=\int K(x,y)f(y)dy$. A [Green function](green-s-function-split.md) is an integral kernel that inverts a [differential operator](differential-operator.md) under specified [boundary conditions](boundary-condition.md).
