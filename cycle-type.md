# Cycle type

↑ **Parent:** [Permutation cycle](permutation-cycle.md)

The cycle type of a [permutation](permutation.md) is the multiset of lengths in its decomposition into [disjoint permutation cycles](disjoint-permutation-cycles.md), including one-cycles for fixed points. Two permutations in the same [symmetric group](symmetric-group.md) are conjugate exactly when they have the same cycle type.
