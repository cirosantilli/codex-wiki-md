# Reachable set

↑ **Parent:** [Reachability in control theory](reachability-in-control-theory.md)

The [reachable set](reachable-set.md) collects the targets attainable from one initial state by allowed [control inputs](control-input.md), at a specified time or over allowed durations. [Controllability](controllability.md) compares these sets with the declared state space. In closed [quantum control](quantum-control.md), a [density operator](density-matrix.md) [reachable set](reachable-set.md) lies inside its [unitary orbit of a density operator](unitary-orbit-of-a-density-operator.md), since coherent evolution preserves the [spectrum](spectrum-functional-analysis.md).
