# Code rate

↑ **Parent:** [Linear code](linear-code.md)

For a linear code of length $n$ and dimension $k$ over $\mathbb F_q$, the code rate is $R=k/n$. There are $q^k$ possible messages represented by $q^k$ [codewords](codeword.md) of length $n$. More generally a block code $C\subseteq\mathbb F_q^n$ has rate $\log_q|C|/n$. This is a dimensionless redundancy measure, distinct from information transmitted per unit physical time.
