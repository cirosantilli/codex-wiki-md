# L-function

↑ **Parent:** [Analytic number theory](analytic-number-theory-split.md)

An L-function is an arithmetic function given initially by a [Dirichlet series](dirichlet-series.md) and often an [Euler product](euler-product.md), with analytic continuation and a functional equation in important cases. [Dirichlet L-functions](dirichlet-l-function.md) and [L-functions of cusp forms](l-function-of-a-cusp-form.md) are basic examples; [p-adic L-functions](p-adic-l-function.md) interpolate suitably modified special values.
