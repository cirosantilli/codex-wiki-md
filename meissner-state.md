# Meissner state

↑ **Parent:** [Meissner effect](meissner-effect.md)

A [Meissner state](meissner-state.md) is an equilibrium state of [superconductivity](superconductivity.md) without [quantum vortex](quantum-vortex.md) penetration, with screening [electric currents](electric-current.md) responding to the applied [magnetic field](magnetic-field.md). In a solid, [simply connected](simply-connected-space.md) sample much thicker than the [London penetration depth](london-penetration-depth.md), the deep interior [magnetic field](magnetic-field.md) is approximately zero. This is a statement about a phase and a geometry, not a rule that every sample exhibiting [superconductivity](superconductivity.md) always has $\mathbf B=0$. In particular, the [Meissner state](meissner-state.md) exists for sufficiently weak [magnetic fields](magnetic-field.md) in both [type-I superconductors](type-i-superconductor.md) and [type-II superconductors](type-ii-superconductor.md).
