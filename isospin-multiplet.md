# Isospin multiplet

↑ **Parent:** [Isospin](isospin.md)

An [isospin multiplet](isospin-multiplet.md) is an irreducible finite-dimensional [SU(2) representation](representation-theory-of-su-2.md) with labels $I,M$, where $I\ge0$, $2I$ is an integer and $M=I,I-1,\ldots,-I$. With Hermitian generators, the lowering coefficient is $\sqrt{(I+M)(I-M+1)}$. The [quadratic Casimir operator](quadratic-casimir-operator.md) has value $I(I+1)$, fixing all ladder norms and the termination at $M=-I$.
