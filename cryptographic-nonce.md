# Cryptographic nonce

↑ **Parent:** [Cryptography](cryptography.md)

A protocol value intended to be used only once under a specified key. In the [ElGamal signature scheme](elgamal-signature-scheme.md) the signing nonce must also be secret and invertible modulo the group order; mere distinctness does not imply unpredictability.
