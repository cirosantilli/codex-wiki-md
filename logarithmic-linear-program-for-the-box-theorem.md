# Logarithmic linear program for the box theorem

↑ **Parent:** [Box theorem](box-theorem.md)

Set $x_i=\log b_i$ for candidate [axis-parallel box](axis-parallel-box.md) side lengths. Its coordinate-projection constraints are the displayed [linear program](linear-programming.md). The dual feasible weights are [fractional uniform covers](fractional-uniform-cover.md). Its optimal extreme point is rational, so the [uniform covers theorem](uniform-covers-theorem.md) forces its objective to be at least $\log|S|$. Weight one on the full coordinate set attains that value. [Strong duality](strong-duality.md) therefore supplies box side lengths with volume $|S|$ and no larger coordinate projections.
