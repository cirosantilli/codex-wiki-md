# Biquadratic residue

↑ **Parent:** [Modular arithmetic](modular-arithmetic-split.md)

A nonzero residue class $a$ modulo an odd [prime number](prime-number-split.md) $p$ is a [biquadratic residue](biquadratic-residue.md) if $x^4\equiv a\pmod p$ for some [integer](integer-split.md) $x$.
