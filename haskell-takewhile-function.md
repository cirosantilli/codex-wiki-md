# Haskell takeWhile function

↑ **Parent:** [Haskell](haskell.md)

The [higher-order function](higher-order-function.md) `takeWhile :: (a -> Bool) -> [a] -> [a]` retains the longest initial segment whose elements all satisfy its predicate. It stops at the first failure and does not resume later. Thus it differs from a [list filter](list-filter.md), which tests later elements as well.
