# Path probability

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

A path probability is a [probability measure](probability-measure.md), or a density relative to a specified reference measure, on histories of a [stochastic process](stochastic-process-split.md). A formal [Onsager--Machlup path probability](onsager-machlup-path-probability.md) must be interpreted with its discretization and initial-state conditioning specified; conditioning on both endpoints produces a separately normalized bridge measure.
