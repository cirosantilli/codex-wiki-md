# Corrsin scalar microscale

↑ **Parent:** [Inertial-diffusive scalar range](inertial-diffusive-scalar-range.md)

In the large-diffusivity regime, equate diffusion rate $\alpha/r^2$ with inertial eddy rate $\epsilon^{1/3}r^{-2/3}$. This gives the Corrsin scalar microscale, which exceeds the [Kolmogorov length scale](kolmogorov-length-scale.md) when $\alpha\gg\nu$.
