# Circular orbital speed

↑ **Parent:** [Circular speed](circular-speed.md)

For a test body on a [circular Kepler orbit](circular-kepler-orbit.md) about a point [mass](mass.md) $M$, the [centripetal acceleration](centripetal-acceleration.md) $v_c^2/r$ equals $GM/r^2$, so $v_c=\sqrt{GM/r}$. For a spherical extended source use the enclosed [mass](mass.md) $M(<r)$ instead. The formula is not valid for an arbitrary nonspherical [gravitational potential](newtonian-potential-of-a-point-mass.md).
