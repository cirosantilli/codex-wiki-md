# Length-two criterion for a very ample linear system

↑ **Parent:** [Very ample linear system](very-ample-linear-system.md)

For a finite generating space $V\subseteq H^0(X,\mathcal L)$ on a projective scheme, its map to [projective space](projective-space-split.md) is a [closed immersion](closed-immersion.md) exactly when, after algebraic closure of the ground field, the displayed evaluation is surjective for every length-two [closed subscheme](closed-subscheme.md) $E$. Two distinct points test point separation; a double point tests a direction in the [Zariski tangent space](zariski-tangent-space.md). For the complete section space, this characterizes a [very ample line bundle](very-ample-line-bundle.md).
