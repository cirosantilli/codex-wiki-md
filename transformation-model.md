# Transformation model

↑ **Parent:** [Statistical model](statistical-model-split.md)

A [group action](group-action.md) on the sample space induces a compatible action on the parameter space, preserving the family of [probability laws](probability-distribution.md). In a transitive model every law arises by transforming a fixed reference law. A [location-scale model](location-scale-family.md) is generated by $y\mapsto a+by$, $b>0$, with parameter action $(\mu,\sigma)\mapsto(a+b\mu,b\sigma)$.
