# Linear combination

↑ **Parent:** [Vector space](vector-space-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linear_combination)

A linear combination of vectors $v_1,\ldots,v_n$ is a sum $a_1v_1+\cdots+a_nv_n$ with scalar coefficients $a_i$.
