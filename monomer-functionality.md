# Monomer functionality

↑ **Parent:** [Polymerization](polymerization.md)

The number of reactive connections available on a [monomer](monomer.md) under a specified [polymerization](polymerization.md) [chemistry](chemistry-split.md). One-functional units can terminate chains, two-functional units can build chains, and higher functionality can produce branching and networks.
