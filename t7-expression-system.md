# T7 expression system

↑ **Parent:** [Gene expression](gene-expression.md)

A [T7 expression system](t7-expression-system.md) uses bacteriophage T7 [RNA polymerase](rna-polymerase.md) to transcribe an insert from a recognized promoter. Regulating the supply or activity of that polymerase can control expression. High transcript production can still yield insoluble or inactive protein.
