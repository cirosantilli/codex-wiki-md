# Abstract data type invariant

↑ **Parent:** [Abstract data type](abstract-data-type.md)

A condition describing legal abstract states, independently of their concrete storage. A bounded-key [multiset](multiset.md) has nonnegative counts and zero counts outside its allowed range. A [representation invariant](representation-invariant.md) instead constrains implementation states; an [abstraction function](abstraction-function.md) connects a valid representation to its abstract state. The two kinds of [invariant](invariant-mathematics.md) should not be conflated.
