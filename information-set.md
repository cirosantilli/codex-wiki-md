# Information set

↑ **Parent:** [Game theory](game-theory-split.md)

A collection of decision nodes that the acting player cannot distinguish when choosing an action in an [extensive-form game](extensive-form-game.md). All nodes in an [information set](information-set.md) have the same acting player and available actions. A [behavioural strategy](behavioural-strategy.md) assigns the same action probabilities throughout that set.
