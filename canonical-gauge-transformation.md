# Canonical gauge transformation

↑ **Parent:** [First-class constraint](first-class-constraint.md)

A [first-class constraint](first-class-constraint.md) generates an infinitesimal [canonical transformation](canonical-transformation.md) $\delta F=\{F,\epsilon^i\varphi_i\}$. For the [phase-space action](phase-space-action.md) $I=\int(p\dot q-\lambda^i\varphi_i)dt$, the multiplier transformation $\delta\lambda^k=\dot\epsilon^k-\lambda^i\epsilon^jC_{ij}{}^k$ cancels the bulk variation when $\{\varphi_i,\varphi_j\}=C_{ij}{}^k\varphi_k$. The remaining temporal boundary term vanishes for parameters that vanish at the endpoints.
