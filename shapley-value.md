# Shapley value

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Shapley_value)

The [Shapley value](shapley-value.md) averages each player's [marginal contribution](marginal-contribution.md) over uniformly random player orderings. Exactly $|S|!(n-|S|-1)!$ orderings have $S$ immediately before player $i$, giving the formula. The values sum to $v(N)$ by telescoping each ordering. In a [simple cooperative game](simple-cooperative-game.md) this is the [probability](probability.md) of being pivotal. For a [convex cooperative game](convex-cooperative-game.md), [Shapley value belongs to the core of a convex game](shapley-value-belongs-to-the-core-of-a-convex-game.md) guarantees a stable allocation as well.
