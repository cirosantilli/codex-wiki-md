# Hodge metric

↑ **Parent:** [Kähler metric](kahler-metric.md)

A Hodge metric is a [Kähler metric](kahler-metric.md) whose [Kähler form](kahler-form.md) represents an [integral cohomology](integral-cohomology.md) class in real [de Rham cohomology](de-rham-cohomology.md). Equivalently, its periods over integral two-cycles are integers. Some conventions require the class of $\omega/(2\pi)$ to be integral instead; this changes the normalization but not existence.
