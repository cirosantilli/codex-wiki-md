# Lebesgue-measure-preserving map

↑ **Parent:** [Measure-preserving transformation](measure-preserving-transformation.md)

Such a measurable self-map preserves [Lebesgue measure](lebesgue-measure.md). On the unit interval examples include the identity, reflection $t\mapsto1-t$, and $t\mapsto2t\pmod1$. Invertibility is not required.
