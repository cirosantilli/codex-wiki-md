# Object interface

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

The operations and behavioral contract exposed by a [software object](software-object.md) to its clients. Different classes can implement a common interface while hiding different state representations. Correct substitution requires agreement with the contract, not only matching [object method](object-method.md) names.
