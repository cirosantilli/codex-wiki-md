# Well-founded model of set theory

↑ **Parent:** [Transitive model](transitive-model.md)

A model of set theory is well-founded when its internally interpreted membership relation is a [well-founded relation](well-founded-relation.md) externally. By the [Mostowski collapse theorem](mostowski-collapse-theorem.md), every well-founded extensional set model is isomorphic to a transitive model.
