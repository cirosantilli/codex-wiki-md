# Lithium beryllium diatomic molecule

↑ **Parent:** [Diatomic molecule](diatomic-molecule.md)

A heteronuclear three-valence-electron diatomic. A simple bonding/antibonding two-orbital description predicts [bond order](bond-order.md) one-half and one [unpaired electron](unpaired-electron.md). More electronegative [beryllium](beryllium.md) carries the negative end of the bond dipole.
