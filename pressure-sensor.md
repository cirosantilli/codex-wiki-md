# Pressure sensor

↑ **Parent:** [Pressure](pressure-split.md)

A pressure sensor converts a [pressure](pressure-split.md) into a recorded signal. An [absolute pressure](absolute-pressure.md) sensor uses a [vacuum](vacuum.md) reference; a [gauge pressure](gauge-pressure.md) sensor uses a specified reference [pressure](pressure-split.md). A closed [gas](gas.md) syringe and an [absolute pressure](absolute-pressure.md) sensor can test [Boyle's law](boyle-s-law.md) after allowing the [temperature](temperature-split.md) to stabilize.
