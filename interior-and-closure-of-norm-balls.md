# Interior and closure of norm balls

↑ **Parent:** [Normed vector space](normed-vector-space.md)

In a nonzero [normed vector space](normed-vector-space.md), a unit vector $x$ is approached from outside the unit ball by $(1+\varepsilon)x$, so no boundary point is [interior](interior-topology.md). It is approached from inside by $(1-\varepsilon)x$, so every boundary point is in the [closure](closure-topology.md) of the open ball. The zero space satisfies the same identities trivially. These statements need the radial structure of a normed space; a two-point discrete [metric space](metric-space.md) with interpoint distance one disproves both analogous claims for general metric balls.
