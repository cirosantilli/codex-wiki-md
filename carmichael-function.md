# Carmichael function

↑ **Parent:** [Number theory](number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Carmichael_function)

The Carmichael function $\lambda(n)$ is the exponent of $(\mathbb Z/n\mathbb Z)^\times$, equivalently the least positive $m$ such that every unit $a$ satisfies $a^m\equiv1\pmod n$.
