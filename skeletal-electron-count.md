# Skeletal electron count

↑ **Parent:** [Polyhedral skeletal electron pair theory](polyhedral-skeletal-electron-pair-theory.md)

The number of electrons allocated to the connected cluster framework after separating external bonds and appropriate [lone pairs](lone-pair.md). For $\mathrm{B_nH_m^{q-}}$ with one terminal B–H bond per vertex it is $n+m+q$.
