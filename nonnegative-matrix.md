# Nonnegative matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nonnegative_matrix)

A real [matrix](matrix.md) is nonnegative when every entry is nonnegative. This entrywise condition differs from being a [positive semidefinite matrix](positive-semidefinite-matrix.md): the [symmetric matrix](symmetric-matrix.md) $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ is nonnegative but has [eigenvalues](eigenvalue.md) $1$ and $-1$.
