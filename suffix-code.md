# Suffix code

↑ **Parent:** [Decipherable code](decipherable-code.md)

A [decipherable code](decipherable-code.md) is suffix-free when no codeword is a proper suffix of another. Reversing all its words gives a [prefix code](prefix-code.md). Consequently it is uniquely decipherable: read a concatenation from the right, where the last codeword is determined uniquely, and continue by induction.
