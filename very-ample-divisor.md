# Very ample divisor

↑ **Parent:** [Complete linear system of a divisor](complete-linear-system-of-a-divisor.md)

A [very ample divisor](very-ample-divisor.md) is a divisor whose associated [line bundle](line-bundle.md) is a [very ample line bundle](very-ample-line-bundle.md). A divisor is very ample when its complete linear system defines a closed embedding into projective space.
