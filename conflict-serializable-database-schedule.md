# Conflict-serializable database schedule

↑ **Parent:** [Database schedule](database-schedule.md)

A [database schedule](database-schedule.md) that can be turned into a [serial database schedule](serial-database-schedule.md) by swapping adjacent operations of different [database transactions](database-transaction.md) that do not conflict. Reads and writes of the same object conflict when at least one is a write.
