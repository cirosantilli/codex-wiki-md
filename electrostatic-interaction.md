# Electrostatic interaction

↑ **Parent:** [Electrostatics](electrostatics-split.md)

An interaction between [electric charges](electric-charge-split.md) mediated by an [electric field](electric-field-split.md). In a uniform dielectric the pair [potential energy](potential-energy.md) is $q_1q_2/(4\pi\epsilon r)$; mobile [ions](ion.md) can modify it through [electrostatic screening](electrostatic-screening.md).
