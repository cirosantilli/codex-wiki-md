# Lenslet array

↑ **Parent:** [Optical instrument](optical-instrument.md)

A lenslet array is a set of small lenses that divides a field or a pupil into many optical samples. In an [integral field spectrograph](integral-field-spectrograph.md) each field sample generates a microspectrum or feeds an [optical fiber](optical-fiber.md).
