# Commutation vector field for the wave equation

↑ **Parent:** [Vector field method for wave equations](vector-field-method-for-wave-equations.md)

A first-order [vector field](vector-field.md) $Z$ is a commutation field for the flat [wave equation](wave-equation-split.md) when $[\Box,Z]$ is zero or a controlled multiple of $\Box$. Translations, spatial rotations and [Lorentz boost vector fields](lorentz-boost-vector-field.md) commute with $\Box$; the [scaling vector field](scaling-vector-field.md) satisfies $[\Box,S]=2\Box$. Repeated commutation preserves the differential order of a [semilinear wave equation](semilinear-wave-equation.md).
