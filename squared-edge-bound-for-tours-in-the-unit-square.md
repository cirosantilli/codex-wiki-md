# Squared edge bound for tours in the unit square

↑ **Parent:** [Euclidean travelling salesman tour](euclidean-travelling-salesman-tour.md)

Every finite point set in the unit square admits a cyclic visiting order with $\sum_i\lVert x_{i+1}-x_i\rVert^2\leq4$. Split the square into two [right triangles](right-triangle.md), apply the [quadratic path bound in a right triangle](quadratic-path-bound-in-a-right-triangle.md), and remove auxiliary corners using the [law of cosines](law-of-cosines.md). The [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) then gives $\operatorname{TS}(X)\leq2\sqrt{|X|}$. The tour minimizing ordinary length need not minimize the sum of squared lengths.
