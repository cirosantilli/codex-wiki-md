# Hyperphantom map of spectra

↑ **Parent:** [Phantom map of spectra](phantom-map-of-spectra.md)

A [hyperphantom map of spectra](hyperphantom-map-of-spectra.md) is a stable map $p:D\to E$ such that $pu=0$ for every $u:\Sigma^{-j}\Sigma^\infty X\to D$, for arbitrary [based spaces](based-space.md) $X$ and all nonnegative $j$. Equivalently it induces zero on the entire [represented cohomology theory](represented-cohomology-theory.md). This is a stronger condition than being a [phantom map of spectra](phantom-map-of-spectra.md), which tests only [finite spectra](finite-spectrum.md).
