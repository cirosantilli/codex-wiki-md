# Revenue-optimal public-project auction

↑ **Parent:** [Virtual-surplus revenue identity](virtual-surplus-revenue-identity.md)

In a public-project [single-parameter mechanism](single-parameter-mechanism.md), all players receive the same binary allocation. For independent [regular priors](regular-distribution-economics.md) and voluntary participation with zero outside utility, maximizing [virtual surplus](virtual-surplus.md) means providing the project exactly when $\sum_i\phi_i(v_i)\geq0$. The allocation is monotone in each value, so [critical-value payments](critical-value-payment.md) implement it with [dominant-strategy incentive compatibility](dominant-strategy-incentive-compatibility.md) and [ex post individual rationality](ex-post-individual-rationality.md). For independent uniform values on $[0,1]$, the condition is $\sum_i v_i\geq n/2$, with winning payment $\max\{0,n/2-\sum_{j\ne i}v_j\}$.
