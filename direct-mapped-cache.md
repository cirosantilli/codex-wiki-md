# Direct-mapped cache

↑ **Parent:** [Cache (computing)](cache-computing.md)

A [memory cache](cache-computing.md) in which each backing [cache block](cache-line.md) has exactly one eligible [cache slot](cache-slot.md). The example under [cache miss](cache-miss.md) maps [cache block](cache-line.md) $q$ to slot $q\bmod2$: [cache blocks](cache-line.md) 0 and 2 compete for slot 0 despite free space in slot 1.
