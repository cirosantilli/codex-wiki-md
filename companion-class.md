# Companion class

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

In [Scala](scala.md), a class paired with a same-named companion object in the appropriate source context. They can access each other's private members. This permits a companion object to hide implementation-node definitions while the corresponding class creates and manipulates those nodes.[Private modifier and companion access](scala-2-13-classes-and-objects-specification.md)
