# Multistart optimization

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

Run a local optimization method from multiple initial points and compare the feasible solutions it returns. This can explore different attraction regions, but a finite set of starts does not generally certify a [global minimum](global-minimum.md).
