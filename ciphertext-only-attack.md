# Ciphertext-only attack

↑ **Parent:** [Cryptography](cryptography.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ciphertext-only_attack)

An attack using observed [ciphertexts](ciphertext.md) without supplied corresponding [plaintexts](plaintext.md). Recognisable message redundancy or publicly testable relations can sometimes provide key-testing predicates.
