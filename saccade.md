# Saccade

↑ **Parent:** [Vision](vision.md)

A rapid eye movement between fixation positions. In a memory-guided [saccade](saccade.md) task, the endpoint provides a behavioral report of a previously presented location; sensory retention and prospective movement coding can therefore covary.
