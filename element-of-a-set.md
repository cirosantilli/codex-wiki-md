# Element of a set

↑ **Parent:** [Set](set-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Element_of_a_set)

A set element is an object belonging to a [set](set-split.md). The statement $a\in A$ asserts membership; $a\notin A$ denies it. Membership differs from inclusion: $a\in A$ concerns one member, whereas $B\subseteq A$ asserts that every [set element](element-of-a-set.md) of $B$ belongs to $A$.
