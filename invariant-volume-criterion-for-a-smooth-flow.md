# Invariant volume criterion for a smooth flow

↑ **Parent:** [Flow coboundary](flow-coboundary.md)

For a [volume form](volume-form.md) $\Omega$, define divergence by $\mathcal L_F\Omega=(\operatorname{div}_{\Omega}F)\Omega$. The product rule for the [Lie derivative](lie-derivative-of-a-differential-form.md) gives $\operatorname{div}_{e^h\Omega}F=\operatorname{div}_{\Omega}F+Fh$. Consequently the flow preserves a smooth positive volume precisely when its divergence in any reference volume is a smooth [flow coboundary](flow-coboundary.md). The displayed density has the minus sign dictated by this product rule.
