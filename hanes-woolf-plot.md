# Hanes-Woolf plot

↑ **Parent:** [Michaelis-Menten kinetics](michaelis-menten-kinetics.md)

A plot of $[S]/v$ against $[S]$ for a reaction modeled by [Michaelis-Menten kinetics](michaelis-menten-kinetics.md). The slope is $1/V_{\max}$, the vertical intercept $K_m/V_{\max}$ and the horizontal intercept $-K_m$; graphical transformation changes how measurement errors are weighted.
