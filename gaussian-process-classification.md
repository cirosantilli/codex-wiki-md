# Gaussian process classification

↑ **Parent:** [Gaussian process](gaussian-process.md)

[Gaussian process classification](gaussian-process-classification.md) links [latent variables](latent-variable.md) from a [Gaussian process](gaussian-process.md) to class [probabilities](probability.md). A binary [probit regression](probit-model.md) likelihood is $\prod_i\Phi((2y_i-1)f_i)$ under [conditional independence](conditional-independence.md). The [posterior distribution](bayesian-posterior.md) of the latent values is not a [normal distribution](normal-distribution.md).
