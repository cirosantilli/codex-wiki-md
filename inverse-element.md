# Inverse element

↑ **Parent:** [Monoid](monoid.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inverse_element)

An [inverse element](inverse-element.md) of $a$ in a [monoid](monoid.md) is an element $b$ satisfying $a\ast b=b\ast a=e$, where $e$ is the [identity element](identity-element.md). Its notation is $a^{-1}$. Some elements of a [monoid](monoid.md) can lack an [inverse element](inverse-element.md); a [group](group-split.md) requires one for every element. [Associativity](associative-property.md) makes a two-sided [inverse element](inverse-element.md) unique: if $b,c$ both invert $a$, then $b=b\ast(a\ast c)=(b\ast a)\ast c=c$.

For the [full transformation monoid](full-transformation-monoid.md), a [self-map](self-map.md) has an [inverse element](inverse-element.md) exactly when it is a [bijection](bijection.md); that element is its [inverse function](inverse-function.md). On $\{0,1\}$, the swap $s(0)=1,s(1)=0$ is its own [inverse element](inverse-element.md), while a [constant function](constant-function.md) has none because it merges the two [inputs](input-computer-science.md).
