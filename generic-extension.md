# Generic extension

↑ **Parent:** [Generic filter](generic-filter.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generic_extension)

If $G$ is a [generic filter](generic-filter.md) over a [countable transitive model](countable-transitive-model.md) $M$, the generic extension $M[G]$ consists of the interpretations by $G$ of all forcing names in $M$.
