# Magnetic domain-wall pinning

↑ **Parent:** [Magnetic domain wall](magnetic-domain-wall.md)

Spatial variations in [energy](energy-split.md), including [crystal defects](crystallographic-defect.md), can trap a [magnetic domain wall](magnetic-domain-wall.md). This is [magnetic domain-wall pinning](magnetic-domain-wall-pinning.md). Increasing the applied [magnetic field](magnetic-field-split.md) can release the wall into a collective jump.
