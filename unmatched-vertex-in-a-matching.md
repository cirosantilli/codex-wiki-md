# Unmatched vertex in a matching

↑ **Parent:** [Matching (graph theory)](matching-graph-theory-split.md)

A [vertex](vertex-graph-theory.md) is an [unmatched vertex in a matching](unmatched-vertex-in-a-matching.md) $M$ if no [edge](edge-of-a-graph.md) of $M$ is incident to it. It is also called free or exposed, always relative to the specified [matching in a graph](matching-graph-theory-split.md): changing $M$ can change which [vertices](vertex-graph-theory.md) are free. The endpoints of an [augmenting path in a matching](augmenting-path-in-a-matching.md) must be distinct [unmatched vertices in a matching](unmatched-vertex-in-a-matching.md) before the change.
