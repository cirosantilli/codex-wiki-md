# Baseline covariate

↑ **Parent:** [Covariate](covariate.md)

A baseline covariate is measured before treatment assignment or exposure. A prognostic baseline covariate predicts the outcome. Adjusting for such variables in a [randomized controlled trial](randomized-controlled-trial.md) can improve [statistical efficiency](efficiency-statistics.md) without conditioning on a treatment consequence. For example, if $Y=\tau Z+\gamma X+\varepsilon$ with randomized $Z$ independent of $X$, adjustment for $X$ reduces the unexplained [variance](variance-split.md) from $\gamma^2\operatorname{Var}(X)+\operatorname{Var}(\varepsilon)$ to $\operatorname{Var}(\varepsilon)$. This precision role of prognostic baseline adjustment is described in [the FDA statistical guidance on covariate adjustment](https://www.fda.gov/media/148910/download).
