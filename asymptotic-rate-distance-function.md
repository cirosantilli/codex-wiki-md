# Asymptotic rate-distance function

↑ **Parent:** [Code rate](code-rate.md)

The asymptotic rate-distance function is $\alpha_q(\delta)=\limsup_{n\to\infty}n^{-1}\log_q A_q(n,\max\{1,\lceil\delta n\rceil\})$. It is the best asymptotic [code rate](code-rate.md) available at the specified [relative minimum distance](relative-minimum-distance-of-a-code.md). A limsup is used because the definition does not assume an ordinary limit exists.
