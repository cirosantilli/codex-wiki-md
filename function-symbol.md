# Function symbol

↑ **Parent:** [First-order language](first-order-language.md)

A [function symbol](function-symbol.md) is part of the syntax of a [first-order language](first-order-language.md), with a specified finite arity. In a [first-order structure](first-order-structure.md) it is interpreted as a function from the corresponding finite power of the domain into the domain. Applying it to the appropriate number of [first-order terms](first-order-term.md) forms another term. The symbol itself is distinguished from its interpretation in a particular structure.
