# Constraint satisfaction problem

↑ **Parent:** [Search problem](search-problem.md)

Assign values from specified domains to variables so that all stated constraints hold simultaneously. A partial assignment can be rejected when it violates a constraint or leaves an unassigned variable with no permissible value. [Backtracking](backtracking.md) applies this test during a [depth-first search](depth-first-search.md).
