# Pure-state norm distance

↑ **Parent:** [Pure state](pure-state.md)

The [Euclidean norm](euclidean-norm.md) distance between normalized [pure state](pure-state.md) vector representatives in a common [Hilbert space](hilbert-space-split.md). Its square is $2-2\operatorname{Re}\langle\psi|\phi\rangle$. If vectors differing by a [global phase](global-phase.md) are identified, minimize over that phase to obtain $\sqrt{2-2|\langle\psi|\phi\rangle|}$. This is a different distance convention from [trace distance](trace-distance.md) or one minus [squared quantum fidelity](squared-quantum-fidelity.md); stating the convention is necessary when defining $\varepsilon$-closeness.
