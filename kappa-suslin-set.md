# Kappa-Suslin set

↑ **Parent:** [X-Suslin set](x-suslin-set.md)

A $\kappa$-Suslin set is an $X$-Suslin set with $X=\kappa$. If $X$ injects into $Y$, relabelling a [Suslin representation](suslin-representation.md) shows that every $X$-Suslin set is $Y$-Suslin.
