# Vertex cover

↑ **Parent:** [Graph theory](graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Vertex_cover)

A vertex cover is a set of [vertices](vertex-graph-theory.md) meeting every [edge](edge-of-a-graph.md) of a [graph](graph-split.md). The endpoints of any [maximal matching](maximal-matching.md) form a vertex cover: an [edge](edge-of-a-graph.md) avoiding all endpoints would enlarge that [matching in a graph](matching-graph-theory.md). Consequently a [graph](graph-split.md) with no [matching in a graph](matching-graph-theory.md) of size $s$ has a vertex cover of size at most $2(s-1)$.
