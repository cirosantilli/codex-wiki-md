# Parity-consistent filling of a free-fermion band

↑ **Parent:** [Fermion parity](fermion-parity.md)

When a quadratic [fermion](fermion.md) spectrum was derived in a fixed [fermion parity](fermion-parity.md) sector, filling all negative-energy modes is permitted only if the resulting particle number has that parity. If it does not, toggle the occupation of a mode with smallest absolute [energy](energy-split.md). Compare the minimum energies of the physical sectors. Zero-energy modes can create degeneracy without [energy](energy-split.md) cost.
