# Stratified randomization

↑ **Parent:** [Randomization](randomization.md)

Divide participants into strata defined by prespecified baseline prognostic variables and randomize independently within each [stratum](stratum.md). Permuted blocks can keep treatment counts close throughout recruitment. This balances the stratification variable between arms by design, while [allocation concealment](allocation-concealment.md) keeps upcoming assignments hidden. Analyses should account for important design strata where appropriate.
