For a [set function](../../../../../set-function.md) $f:2^V\to\mathbb R$, the four properties are:

- A [normalised set function](../../../../../normalised-set-function.md) satisfies **$f(\varnothing)=0$**.
- A [nonnegative function](../../../../../nonnegative-function.md) satisfies **$f(S)\geq0$ for every $S\subseteq V$**.
- A [monotone set function](../../../../../monotone-set-function.md) satisfies **$f(A)\leq f(B)$ whenever $A\subseteq B\subseteq V$**.
- A [symmetric set function](../../../../../symmetric-set-function.md) satisfies **$f(S)=f(V\setminus S)$ for every $S\subseteq V$**.

Here [monotone set function](../../../../../monotone-set-function.md) means nondecreasing under inclusion; it does not require strict increase.
