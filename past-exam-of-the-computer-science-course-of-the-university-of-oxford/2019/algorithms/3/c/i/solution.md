<h1 id="3/c/i/solution">Solution</h1>

↑ **Parent:** [I](../i.md)

If the basis has $r\leq k$ members, it has $2^r$ [subsets](../../../../../../subset.md), each specifying a possible [union](../../../../../../set-union.md). Different [subsets](../../../../../../subset.md) can produce the same [union](../../../../../../set-union.md), so the number of distinct generated [sets](../../../../../../set-split.md) is at most $2^r$. Consequently,

$$
\boxed{|\mathcal F|\leq2^k.}
$$

Here $\mathcal F$ is a [set family](../../../../../../set-family.md) of distinct [sets](../../../../../../set-split.md). If a representation lists duplicate input [sets](../../../../../../set-split.md), discard those duplicates before applying this bound. The empty [union](../../../../../../set-union.md) is included.
