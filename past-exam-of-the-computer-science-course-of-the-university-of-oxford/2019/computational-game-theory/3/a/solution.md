<h1 id="3/a/solution">Solution</h1>

↑ **Parent:** [A](../a.md)

For a fixed finite player [set](../../../../../set-split.md) $N$ and characteristic [function](../../../../../function-split.md) $v$ with $v(\varnothing)=0$, let $\psi(v)$ be the allocated [payoff](../../../../../payoff.md) [vector](../../../../../vector.md). A standard four-axiom characterization is:

**[Cooperative-game efficiency](../../../../../efficiency-of-a-cooperative-game-value.md):** $\sum_{i\in N}\psi_i(v)=v(N)$.

**[Cooperative-game symmetry](../../../../../symmetry-of-a-cooperative-game-value.md):** if $v(S\cup\{i\})=v(S\cup\{j\})$ for every $S\subseteq N\setminus\{i,j\}$, then $\psi_i(v)=\psi_j(v)$.

**The [null player](../../../../../null-player.md) axiom:** if $v(S\cup\{i\})=v(S)$ for every $S\subseteq N\setminus\{i\}$, then $\psi_i(v)=0$.

**[Cooperative-game additivity](../../../../../additivity-of-a-cooperative-game-value.md):** for games $v,w$ on the same $N$, $\psi_i(v+w)=\psi_i(v)+\psi_i(w)$, where $(v+w)(S)=v(S)+w(S)$.

These axioms uniquely specify the [Shapley value](../../../../../shapley-value.md). This is the zero-marginal null-player convention. The original work combines some requirements into an equivalent formulation.[RAND P-295, 1952, abstract identifies an axiomatic construction; the four-part formulation and proof are given in Shapley value axioms](../../../../../a-value-for-n-person-games-by-lloyd-shapley-rand-paper.md)
