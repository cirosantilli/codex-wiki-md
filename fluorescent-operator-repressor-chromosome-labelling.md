# Fluorescent operator-repressor chromosome labelling

↑ **Parent:** [Chromatin organization](chromatin-organization.md)

A bacterial DNA-recognition pair marks an integrated operator array with a fluorescent repressor. It enables live tracking of a chosen [genetic locus](genetic-locus.md), while the array and bound [protein](protein-split.md) can perturb that locus.
