# Symmetric matrix

↑ **Parent:** [Linear algebra](linear-algebra-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Symmetric_matrix)

A real matrix is symmetric when $A^T=A$. It represents a [self-adjoint operator](self-adjoint-operator.md) in the standard Euclidean [inner product](inner-product.md).
