# Simple turning point of a variable-speed wave

↑ **Parent:** [Hamiltonian ray equations for a local dispersion relation](hamiltonian-ray-equations-for-a-local-dispersion-relation.md)

A simple turning point for a stratified [wavespeed](wave-speed.md) occurs at $c(Y_s)=\omega/k$, where $Q=\omega^2/c^2-k^2$ has a nonzero derivative. If $c_Y(Y_s)>0$, write $q=-Q'(Y_s)>0$; then $\ell\sim[q(Y_s-Y)]^{1/2}$ below it. The vertical [group velocity](group-velocity.md) vanishes and the [stationary wave amplitude in a stratified wavespeed](stationary-wave-amplitude-in-a-stratified-wavespeed.md) diverges as $(Y_s-Y)^{-1/4}$.
