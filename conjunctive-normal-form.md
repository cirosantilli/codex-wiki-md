# Conjunctive normal form

↑ **Parent:** [Boolean formula](boolean-formula.md)

A [Boolean formula](boolean-formula.md) is in [conjunctive normal form](conjunctive-normal-form.md) when it is a [logical conjunction](logical-conjunction.md) of [Boolean clauses](clause-of-a-boolean-formula.md). It is true precisely when every [Boolean clause](clause-of-a-boolean-formula.md) is true under the same [Boolean valuation](boolean-valuation.md); an empty [logical conjunction](logical-conjunction.md) is true. For example, $(x\lor\neg y)\land(z)$ has two [Boolean clauses](clause-of-a-boolean-formula.md) with widths two and one. Width counts [Boolean literal](boolean-literal.md) occurrences within a [Boolean clause](clause-of-a-boolean-formula.md), whereas the [Boolean clause](clause-of-a-boolean-formula.md) count counts the conjuncts. [2-SAT](2-satisfiability.md) bounds width by two, and [3-SAT](3-sat.md) bounds width by three. A [Boolean formula](boolean-formula.md) with an empty [Boolean clause](clause-of-a-boolean-formula.md) is an [unsatisfiable Boolean formula](unsatisfiable-boolean-formula.md).
