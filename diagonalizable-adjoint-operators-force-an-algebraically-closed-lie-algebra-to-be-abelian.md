# Diagonalizable adjoint operators force an algebraically closed Lie algebra to be abelian

↑ **Parent:** [Abelian Lie algebra](abelian-lie-algebra.md)

Let $\mathfrak g$ be a finite-dimensional [Lie algebra](lie-algebra-split.md) over an [algebraically closed field](algebraically-closed-field.md). If every operator $\operatorname{ad}(x)$ of the [Adjoint representation of a Lie algebra](adjoint-representation-of-a-lie-algebra.md) is [diagonalizable](diagonalizable-matrix.md), then $\mathfrak g$ is abelian. For if $[x,y]=\lambda y$ with $\lambda\ne0$, then $\operatorname{ad}(y)x=-\lambda y\ne0$ but $(\operatorname{ad}y)^2x=0$. This contradicts $\ker T^2=\ker T$ for a diagonalizable endomorphism $T$. Therefore every adjoint operator has only the eigenvalue zero and is diagonalizable, so every adjoint operator is zero. Hence every [Lie bracket](lie-bracket.md) vanishes.
