# Quadratic branch parity criterion

↑ **Parent:** [Branch-cycle conjugacy class](branch-cycle-conjugacy-class.md)

In [characteristic zero](characteristic-zero.md) with algebraically closed constants, a local unit has a square root. Thus $K(T)(\sqrt a)$ near a point is equivalent to adjoining the square root of the local parameter to the power $v_p(a)$. Even order is unramified; odd order gives [ramification index](ramification-index.md) two. For a [polynomial](polynomial-split.md) $a$, its order at infinity is minus its degree, so infinity branches exactly for odd degree.
