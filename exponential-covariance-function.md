# Exponential covariance function

↑ **Parent:** [Gaussian process](gaussian-process.md)

The stationary exponential covariance function is

$$
k(s,t)=R\exp(-|t-s|/\tau).
$$

The corresponding [Gaussian process](gaussian-process.md) is Markov and is a stationary [Ornstein-Uhlenbeck process](ornstein-uhlenbeck-process.md).
