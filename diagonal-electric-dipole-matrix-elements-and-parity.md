# Diagonal electric-dipole matrix elements and parity

↑ **Parent:** [Electric dipole operator](electric-dipole-operator.md)

A [parity](parity.md) eigenstate has zero expectation of an odd coordinate, hence no diagonal electric-dipole coupling to a uniform oscillatory field. Stationarity alone does not prove this: an oscillator displaced by $x_c$ has $\langle x\rangle=x_c$. Degenerate subspaces or a parity-breaking static field require a separate symmetry analysis.
