# Logic gate

↑ **Parent:** [Boolean circuit](boolean-circuit.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Logic_gate)

A physical or idealized component implementing a fixed [Boolean function](boolean-function.md) on one or more input [bits](bit.md). For example, an [AND gate](and-gate.md) outputs one exactly when both input [bits](bit.md) are one. A [Boolean circuit](boolean-circuit.md) connects [logic gates](logic-gate.md); [circuit size](circuit-size.md) counts components and [circuit depth](depth-of-a-boolean-circuit.md) measures the longest chain of dependencies.
