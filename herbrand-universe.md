# Herbrand universe

↑ **Parent:** [First-order logic](first-order-logic.md)

The set of all [ground terms](ground-term.md) over a [first-order signature](first-order-signature.md) $\sigma$. Add a fresh constant if the [first-order signature](first-order-signature.md) has none, so that this domain is nonempty. A constant $a$ and unary function $f$ give the [Herbrand universe](herbrand-universe.md) $\{a,f(a),f(f(a)),\ldots\}$.
