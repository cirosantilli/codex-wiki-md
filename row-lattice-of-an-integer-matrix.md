# Row lattice of an integer matrix

↑ **Parent:** [Hermite normal form](hermite-normal-form.md)

The row lattice of an integer [matrix](matrix.md) with $m$ rows is the set of their integer linear combinations. It is an [Euclidean lattice](euclidean-lattice.md) in its real span, since it is contained in the discrete set $\mathbb Z^n$ and spans that real vector space. For a nonsingular two-by-two integer [matrix](matrix.md), the [row Hermite normal form in rank two](row-hermite-normal-form-in-rank-two.md) gives a canonical [basis](basis.md) and proves that its index in $\mathbb Z^2$ is the absolute value of its [determinant](determinant.md).
