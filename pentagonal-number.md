# Pentagonal number

↑ **Parent:** [Polygonal number](polygonal-number.md)

The $n$th [pentagonal number](pentagonal-number.md) is $P_n=n(3n-1)/2$ for a [positive integer](positive-integer.md) $n$, giving $1,5,12,22,\ldots$. A [positive integer](positive-integer.md) $x$ is pentagonal exactly when $24x+1$ is a [perfect square](square-number.md) and $(1+\sqrt{24x+1})/6$ is an [integer](integer-split.md), by the defining [quadratic equation](quadratic-equation.md).
