# Lusin set construction under CH

↑ **Parent:** [Lusin set](lusin-set.md)

Under the [Continuum hypothesis](continuum-hypothesis.md), enumerate the meagre $F_\sigma$ covers by $\omega_1$. At stage $\alpha$ choose a new real outside all earlier covers and the previous choices. The excluded union is meagre, so the [Baire category theorem](baire-category-theorem.md) makes the choice possible. Each cover then contains only countably many selected points. Arbitrary [meagre sets](meagre-set.md) need not themselves have only continuum many possible choices; the coded covers are what is enumerated.
