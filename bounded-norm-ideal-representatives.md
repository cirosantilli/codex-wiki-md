# Bounded-norm ideal representatives

↑ **Parent:** [Ideal class group](ideal-class-group.md)

If every integral ideal $I$ contains nonzero $\alpha$ with $|N(\alpha)|\leq C N(I)$, then $(\alpha)I^{-1}$ is an integral representative of $[I]^{-1}$ with norm at most $C$.
