# Agrammatism

↑ **Parent:** [Syntax](syntax.md)

An impairment in grammatical structure in production or comprehension. It is not equivalent to reduced [speech](speech.md) rate, dysarthria or all forms of [aphasia](aphasia.md); task design must separate grammatical dependencies from lexical and memory demands.
