# Single-slip tensile-axis rotation

↑ **Parent:** [Schmid's law](schmid-s-law.md)

In an ideal single-slip tensile test neglecting elastic stretch, the specimen end-to-end vector expressed in crystal coordinates changes as $\mathbf r=\mathbf r_0+\gamma(\mathbf n\cdot\mathbf r_0)\mathbf s$, with unit slip direction $\mathbf s$ and slip-plane normal $\mathbf n$. It moves towards the slip direction along a great circle. The perpendicular component is unchanged, so $L\sin\lambda=L_0\sin\lambda_0$. Secondary slip changes this kinematics; equal [Schmid factors](schmid-factor.md) determine onset only if the systems have equal current critical [stresses](stress.md).
