# Bounded minimization

↑ **Parent:** [Primitive recursive function](primitive-recursive-function.md)

Search over the finite interval $0\leq y\leq b$ for the least witness to a [primitive recursive](primitive-recursive-function.md) predicate, with an explicitly chosen default if there is none. The result is a [primitive recursive function](primitive-recursive-function.md), by scanning this finite interval using [primitive recursion](primitive-recursion.md). This differs from [unbounded minimization](mu-operator.md), which may fail to terminate.
