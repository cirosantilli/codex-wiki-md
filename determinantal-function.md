# Determinantal function

↑ **Parent:** [Determinant](determinant.md)

A [determinantal function](determinantal-function.md) on $M_n(F)$ is an [alternating multilinear map](alternating-multilinear-map.md) of the $n$ columns, normalized to take value one at the [identity matrix](identity-matrix.md). It is uniquely the [determinant](determinant.md). Indeed, expand each column in the [standard basis](standard-basis.md). Terms with a repeated [basis vector](basis-vector.md) vanish, and all remaining terms differ from the value on the [standard basis](standard-basis.md) only by the sign of a [permutation](permutation.md). Thus an [alternating multilinear map](alternating-multilinear-map.md) of $n$ columns is determined by its value on the [identity matrix](identity-matrix.md).
