# Object method

↑ **Parent:** [Software object](software-object.md)

An operation invoked on a [software object](software-object.md) that can read or modify that receiver's state. Its contract specifies accepted inputs and effects. [Dynamic dispatch](dynamic-dispatch.md) can select an overriding implementation according to the receiver's concrete [software class](class-programming.md); [method overloading](method-overloading.md) instead selects among different signatures using static type information.
