# Finite model property

↑ **Parent:** [Model theory](model-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Finite_model_property)

A logic or fragment has the [finite model property](finite-model-property.md) if every satisfiable sentence has a finite model. This does not require every model to be finite, or a uniform bound on all finite model sizes.
