# Maximum of element weights

↑ **Parent:** [Set function](set-function.md)

On nonempty [subsets](subset.md) of a nonempty [finite set](finite-set.md) $V$, take the [maximum](maximum-of-a-subset-of-a-total-order.md) of the contained element weights. Setting $f(\varnothing)=\min_{v\in V}w(v)$ extends this to a [monotone set function](monotone-set-function.md) and a [submodular set function](submodular-set-function.md). More generally any value at the [empty set](empty-set.md) at most every element weight works, because $\Delta_x f(S)=\max\{0,w(x)-f(S)\}$ satisfies [diminishing returns](diminishing-returns-characterization-of-submodularity.md).
