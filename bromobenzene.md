# Bromobenzene

↑ **Parent:** [Aryl halide](aryl-halide.md)

$\mathrm{C_6H_5Br}$, an aryl bromide that can be converted to an aryl [grignard reagent](grignard-reagent.md). Bromine directs electrophilic aromatic substitution preferentially to the ortho and para positions while deactivating the ring overall.
