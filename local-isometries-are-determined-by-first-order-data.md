# Local isometries are determined by first-order data

↑ **Parent:** [Local isometry](local-isometry.md)

Two [local isometries](local-isometry.md) from a connected [Riemannian manifold](riemannian-manifold.md) that have the same value and [differential](differential-of-a-smooth-map.md) at one point agree everywhere. They preserve [geodesics](geodesic.md), so their equality follows on a [normal neighborhood](normal-neighbourhood.md) from $f(\exp_pv)=\exp_{f(p)}(df_pv)$. The set of points where both value and differential agree is consequently open, and continuity makes it closed. [Connectedness](connected-space.md) completes the argument.
