# Basic variable

↑ **Parent:** [Simplex basis](simplex-basis.md)

A [basic variable](basic-variable.md) corresponds to a column of the current [simplex basis](simplex-basis.md). Given the nonbasic variables, the invertible basis matrix determines the basic variables from the equality constraints.
