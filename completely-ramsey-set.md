# Completely Ramsey set

↑ **Parent:** [Ramsey set of infinite subsets](ramsey-set-of-infinite-subsets.md)

A set $E\subseteq[\mathbb N]^\omega$ is completely Ramsey if every basic [Ellentuck topology](ellentuck-topology.md) neighborhood $[s,A]$ admits an infinite $B\subseteq A$ with $[s,B]\subseteq E$ or $[s,B]\cap E=\varnothing$. Keeping the finite stem $s$ makes this stronger than being a [Ramsey set of infinite subsets](ramsey-set-of-infinite-subsets.md).
