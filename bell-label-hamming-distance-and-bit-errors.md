# Bell-label Hamming distance and bit errors

↑ **Parent:** [Two-component Bell resource in dense coding](two-component-bell-resource-in-dense-coding.md)

If a wrong Bell-label partner occurs with probability $\epsilon$ and differs from the intended two-bit label in $w$ positions, its contribution to the error probability of a uniformly selected bit is $\epsilon w/2$. Relabeling the [Bell states](bell-state-split.md) can change $w$ while preserving the physical wrong-state probability. Thus symbol error probability and bit error probability are different quantities.
