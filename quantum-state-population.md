# Quantum state population

↑ **Parent:** [Density matrix](density-matrix.md)

For a chosen normalized level state $|k\rangle$, its population is the [probability](probability.md) $\langle k|\rho|k\rangle=\operatorname{Tr}(|k\rangle\langle k|\rho)$ of finding the system in that state. In an orthonormal level basis these diagonal entries are nonnegative and sum to one. Off-diagonal [quantum coherence](quantum-coherence-in-a-specified-basis.md) contains information absent from the population vector, so matching all level populations need not prepare a specified coherent superposition.
