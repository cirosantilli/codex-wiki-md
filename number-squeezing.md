# Number squeezing

↑ **Parent:** [Photon statistics](photon-statistics.md)

Sub-Poissonian number [variance](variance-split.md) in a specified mode or detection gate. It concerns [photon counting](photon-counting.md), not an [optical quadrature](optical-quadrature.md). An [optical squeezed vacuum](optical-squeezed-vacuum.md) has [quadrature squeezing](quadrature-squeezing.md) but fails this number-variance condition.
