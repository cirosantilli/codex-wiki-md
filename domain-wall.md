# Domain wall

↑ **Parent:** [Topological defect](topological-defect.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Domain_wall)

A domain wall is a codimension-one configuration interpolating between disconnected components of a [vacuum manifold](vacuum-manifold.md). In a one-dimensional system with broken discrete symmetry it is a point defect of finite energy, so positional entropy produces a nonzero density at every positive temperature.
