# Depth-first quantum circuit path summation

↑ **Parent:** [Quantum circuit](quantum-circuit-split.md)

Expand a [quantum circuit](quantum-circuit-split.md) [matrix element](matrix-element.md) by inserting [computational basis](computational-basis.md) resolutions between gates, then enumerate the intermediate strings depth first. The active stack stores one basis label and accumulator per [quantum circuit](quantum-circuit-split.md) layer, using polynomial space for polynomially many qubits and gates. Recompute entries rather than storing an exponential matrix or state vector. The output probability requires the [Born rule](born-rule.md) sum of squared amplitude moduli.
