# Weakly holomorphic Banach-valued function

↑ **Parent:** [Holomorphic function](holomorphic-function-split.md)

A map from an open subset of $\mathbb C$ into a complex [Banach space](banach-space-split.md) is weakly holomorphic when every composition with a bounded complex-[linear functional](linear-functional.md) is a scalar [holomorphic function](holomorphic-function-split.md). [Norm](norm.md) holomorphy requires its difference quotients to converge in the Banach [norm](norm.md). Weak holomorphy is initially a condition on scalar observations; the [weak holomorphy implies norm holomorphy](weak-holomorphy-implies-norm-holomorphy.md) argument recovers an actual vector derivative. A closed target subspace containing values on a sequence with an interior accumulation point contains every value on the connected domain: annihilate the subspace, apply the scalar [identity theorem](identity-theorem.md), and use [Hahn-Banach separation](hahn-banach-separation-theorem.md).
