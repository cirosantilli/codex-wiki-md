# Entropy increase under nonselective projective measurement

↑ **Parent:** [Von Neumann entropy](von-neumann-entropy-split.md)

If $\sigma=\sum_iP_i\rho P_i$ is a [nonselective projective measurement](nonselective-projective-measurement.md), then $S(\sigma)\geq S(\rho)$. Equality holds exactly when $\rho$ is already block diagonal in the measurement decomposition, equivalently $[\rho,P_i]=0$ for every $i$.
