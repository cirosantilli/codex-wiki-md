# Finite-box comparison for percolation parameters

↑ **Parent:** [Monotone coupling of Bernoulli percolation](monotone-coupling-of-bernoulli-percolation.md)

If an [increasing event](increasing-event.md) $A$ depends on $m$ sites or [edges](edge-of-a-graph.md), the uniform-label [monotone coupling of Bernoulli percolation](monotone-coupling-of-bernoulli-percolation.md) and the [union bound](boole-s-inequality.md) give $0\leq\mathbb P_q(A)-\mathbb P_p(A)\leq m(q-p)$ for $p\leq q$. A change of the event requires a coordinate with label in $(p,q]$. For [bond percolation](bond-percolation-split.md) from the origin to the boundary of $[-n,n]^2$, first-hit [graph paths](path-in-a-graph.md) use the $4n(2n+1)$ internal [edges](edge-of-a-graph.md), so the same count bounds the parameter sensitivity.
