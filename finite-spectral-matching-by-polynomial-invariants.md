# Finite spectral matching by polynomial invariants

↑ **Parent:** [Buser finite length spectrum theorem](buser-finite-length-spectrum-theorem.md)

Suppose a compact parameter set carries a locally finite countable multiset of positive quantities, and a fixed injective transform of each labelled quantity is a [polynomial](polynomial-split.md) in finitely many ambient coordinates. Assume only finitely many labels can have bounded value anywhere in the compact set. Then a uniform finite initial multiset determines the entire multiset. For each source label there are finitely many possible matching labels. Equality for finitely many labels in both directions is a finite union of [algebraic sets](algebraic-set.md), obtained from injective matchings and polynomial equalities. These algebraic sets decrease as more labels are included, so they stabilize by the [Hilbert basis theorem](hilbert-basis-theorem.md). A compatible infinite matching in each direction follows by the [König infinity lemma](konig-s-lemma.md), and local finiteness makes multiplicities equal. Squared traces of [hyperbolic holonomy representations](hyperbolic-holonomy-representation.md) give the application to the [Buser finite length spectrum theorem](buser-finite-length-spectrum-theorem.md).
