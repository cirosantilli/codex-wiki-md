# Spectral-radius Liouville theorem

↑ **Parent:** [Spectral-radius three-circle inequality](spectral-radius-three-circle-inequality.md)

If an entire [Banach algebra](banach-algebra-split.md)-valued function has bounded [spectral radius](spectral-radius.md), that spectral radius is constant. The [spectral-radius three-circle inequality](spectral-radius-three-circle-inequality.md) on circles about an arbitrary point, with the outer radius tending to infinity, bounds every interior value by the maximum on any smaller circle. Upper semicontinuity of the spectral radius then lets the smaller radius tend to zero. Every value is bounded by the value at the arbitrary center; exchanging centers gives equality. The algebra-valued function itself can be nonconstant, for example $zN$ for a fixed nonzero square-zero matrix $N$.
