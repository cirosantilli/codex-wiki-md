# Automaton state

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

An [automaton state](automaton-state.md) is one possible memory configuration of a [finite-state machine](finite-state-machine.md). The initial [automaton state](automaton-state.md) is the starting configuration; accepting [automaton states](automaton-state.md) indicate successful recognition when the whole [word](string.md) has been read.
