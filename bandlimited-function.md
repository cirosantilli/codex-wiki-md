# Bandlimited function

↑ **Parent:** [Fourier transform](fourier-transform.md)

A [bandlimited function](bandlimited-function.md) has [Fourier transform](fourier-transform.md) supported in a bounded frequency interval. An integrable bandlimited function has a bounded continuous representative when its [Fourier transform](fourier-transform.md) is integrable, and that representative extends analytically using the compact-frequency integral. Scaling arguments scales its frequency support inversely, while multiplying two such functions adds their support intervals through convolution.
