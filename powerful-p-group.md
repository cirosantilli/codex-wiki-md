# Powerful p-group

↑ **Parent:** [Finite p-group](finite-p-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Powerful_p-group)

A [finite p-group](finite-p-group.md) is powerful if $[G,G]\leq G^p$ for odd $p$, or $[G,G]\leq G^4$ for $p=2$. Here powers denote generated [subgroups](subgroup.md). The same definition applies to [pro-p groups](pro-p-group.md) using closed power and [commutator subgroups](commutator-subgroup.md). Its [Frattini subgroup](frattini-subgroup.md) is $G^p$. For odd $p$, successive power layers admit linear correction of roots, which makes every element of $G^p$ an actual $p$th power.
