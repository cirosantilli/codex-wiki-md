# Overtone

↑ **Parent:** [Normal mode](normal-mode.md)

An [overtone](overtone.md) is an oscillatory mode above the [fundamental mode](fundamental-mode.md) in the same mode family. [Waveguide](waveguide.md) branches are compared at fixed horizontal [wavenumber](wavenumber.md). Their [frequencies](frequency.md) need not be integer multiples of the fundamental [frequency](frequency.md). In a scalar layered guide, additional vertical nodes distinguish successive [overtones](overtone.md).
