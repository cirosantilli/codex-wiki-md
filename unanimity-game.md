# Unanimity game

↑ **Parent:** [Simple cooperative game](simple-cooperative-game.md)

For a fixed nonempty [coalition](coalition-game-theory.md) $K$, the [simple cooperative game](simple-cooperative-game.md) in which a [coalition](coalition-game-theory.md) wins exactly when it contains $K$. Members of $K$ are exactly the [veto players](veto-player.md). It is a [convex cooperative game](convex-cooperative-game.md): intersections of [winning coalitions](winning-coalition.md) still contain $K$, and checking the remaining zero-one cases establishes the [supermodular](supermodular-set-function.md) inequality. Full [symmetry of players in a cooperative game](symmetry-of-players-in-a-cooperative-game.md) forces $K=N$.
