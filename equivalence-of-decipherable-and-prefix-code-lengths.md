# Equivalence of decipherable and prefix code lengths

↑ **Parent:** [Kraft–McMillan inequality](kraft-mcmillan-inequality.md)

Prescribed positive word lengths admit a [decipherable code](decipherable-code.md) if and only if they admit a [prefix code](prefix-code.md). Counting length-$L$ concatenations of $m$ words proves the [Kraft inequality](kraft-mcmillan-inequality.md) for any [decipherable code](decipherable-code.md); choosing free vertices of the ordered $D$-ary [tree](tree-graph-theory.md) constructs a [prefix code](prefix-code.md) whenever this inequality holds. Each [prefix code](prefix-code.md) has [unique decodability](unique-decodability.md).
