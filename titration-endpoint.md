# Titration endpoint

↑ **Parent:** [Acid-base titration](acid-base-titration.md)

A [titration endpoint](titration-endpoint.md) is the experimentally assigned point indicated by a specified signal: for example, a persistent color of a [pH indicator](ph-indicator.md), or a feature extracted from a [potentiometric titration](potentiometric-titration.md). An [equivalence point](equivalence-point.md) is defined by [stoichiometry](stoichiometry.md); an endpoint estimates its location. State the signal rule and its repeatability. A fleeting local color where a drop enters an unmixed sample need not satisfy the rule for the mixed sample.

Define the endpoint offset $\Delta V=V_{\mathrm{end}}-V_{\mathrm{eq}}$. For one-to-one [neutralization](neutralization.md), using the endpoint without correction gives inferred acid inventory $\widehat n_A=c_BV_{\mathrm{end}}$ and

$$
\frac{\widehat n_A-n_A}{n_A}=\frac{\Delta V}{V_{\mathrm{eq}}}.
$$

Thus an illustrative $0.05\,\mathrm{mL}$ overshoot at $V_{\mathrm{eq}}=10.00\,\mathrm{mL}$ overestimates the inventory by $0.5\%$. Repeatedly reaching the same color can reduce scatter while retaining this systematic offset. This example stipulates an offset; it is not a measured drop size.
