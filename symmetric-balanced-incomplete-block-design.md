# Symmetric balanced incomplete block design

↑ **Parent:** [Balanced incomplete block design](balanced-incomplete-block-design.md)

A [balanced incomplete block design](balanced-incomplete-block-design.md) is symmetric when its number of blocks equals its number of treatments. The identity $bk=tr$ then gives $r=k$. Its square [incidence matrix of a set system](incidence-matrix-of-a-set-system.md) $N$ obeys $NN^T=(r-\lambda)I+\lambda J$, with eigenvalues $r-\lambda$ of multiplicity $t-1$ and $r^2$ of multiplicity one.
