# Solvability condition

↑ **Parent:** [Operator theory](linear-operator-theory-split.md)

A solvability condition is a compatibility requirement on data for an equation to admit a solution in a specified function space or with specified boundary behavior. For a bounded [linear operator](linear-operator.md) between [Hilbert spaces](hilbert-space-split.md), the equation $Lu=f$ requires $f$ to be orthogonal to the kernel of the adjoint. A closed range makes that requirement sufficient; the [Fredholm alternative for a compact operator](fredholm-alternative.md) applies this principle to $I-K$ with compact $K$. in an asymptotic inner problem, exclusion of a growing homogeneous mode can impose an analogous weighted-integral condition.
