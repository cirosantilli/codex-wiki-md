# Skew Schur function

↑ **Parent:** [Schur polynomial](schur-polynomial.md)

Sum the weight [monomials](monomial.md) of all [Semistandard Young tableaux](semistandard-young-tableau.md) on the [skew Young diagram](skew-young-diagram.md) $\lambda/\mu$, with weak rows and strict columns. A [Bender-Knuth involution](bender-knuth-involution.md) interchanges the counts of adjacent letters without changing the shape, so the sum is a [symmetric function](symmetric-function.md). Taking $\mu$ empty gives the [Schur function](schur-polynomial.md).
