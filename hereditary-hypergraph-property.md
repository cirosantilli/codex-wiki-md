# Hereditary hypergraph property

↑ **Parent:** [Uniform hypergraph](uniform-hypergraph.md)

A property of [uniform hypergraphs](uniform-hypergraph.md) is hereditary if every [induced subhypergraph](induced-subhypergraph.md) of a hypergraph with that property also has the property. It is understood to be invariant under relabelling the [vertex set](vertex-set.md). For example, excluding a specified induced [hypergraph](hypergraph-split.md) is hereditary. This permits counting restrictions to smaller vertex sets using the same counting function.
