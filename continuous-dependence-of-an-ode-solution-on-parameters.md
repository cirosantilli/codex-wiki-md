# Continuous dependence of an ODE solution on parameters

↑ **Parent:** [Ordinary differential equation](ordinary-differential-equation.md)

On a common compact solution domain, a right-hand side continuous in parameters and uniformly Lipschitz in the state yields continuous dependence of the solution on those parameters. The [Gronwall inequality](gronwall-inequality.md) controls the difference of two solutions. A transverse zero of an event function persists under a small parameter change, which allows a simple stellar surface in the [Newtonian limit](newtonian-limit.md) to persist in relativistic models.
