# Heat kernel trace formula

↑ **Parent:** [Heat kernel](heat-kernel.md)

On a [closed manifold](closed-manifold.md), the [positive Laplace-Beltrami operator](positive-laplace-beltrami-operator.md) has a smooth [heat kernel](heat-kernel.md) and its [heat semigroup](heat-semigroup.md) is a [trace-class operator](trace-class-operator.md) for positive time. Expanding in a smooth [orthonormal eigenbasis](orthonormal-eigenbasis.md) gives $K_t(x,y)=\sum_je^{-t\lambda_j}\phi_j(x)\overline{\phi_j(y)}$. [Elliptic regularity](elliptic-regularity.md) bounds each derivative of $\phi_j$ polynomially in $\lambda_j$, while the exponential dominates those powers, so the expansion converges with all derivatives. Integrating the diagonal and using the unit norm of each [eigenfunction](eigenfunction.md) proves the formula. For a bundle operator, insert the fibre [matrix trace](matrix-trace.md) inside the integral.
