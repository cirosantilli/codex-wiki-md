# Hausdorff dimension of a connected set

↑ **Parent:** [Hausdorff dimension](hausdorff-dimension.md)

A [connected](connected-space.md) subset $C$ of [Euclidean space](euclidean-norm.md) containing distinct points $a,b$ has [Hausdorff dimension](hausdorff-dimension.md) at least one. The [Lipschitz](lipschitz-continuity.md) map $x\mapsto|x-a|$ maps $C$ onto a set containing $[0,|b-a|]$, since [continuous images of connected spaces](continuous-image-of-a-connected-space.md) are [connected](connected-space.md). A [Lipschitz map](lipschitz-continuity.md) cannot increase [Hausdorff dimension](hausdorff-dimension.md), whereas an interval has [Hausdorff dimension](hausdorff-dimension.md) one. Consequently any set of [Hausdorff dimension](hausdorff-dimension.md) less than one is [totally disconnected](totally-disconnected-space.md).
