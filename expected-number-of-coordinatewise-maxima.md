# Expected number of coordinatewise maxima

↑ **Parent:** [Maximal external point](maximal-external-point.md)

For $n$ independent uniform points in a rectangle, condition on one point with normalized coordinates $(x,y)$. It is a [maximal external point](maximal-external-point.md) if all others avoid the upper-right rectangle of area $(1-x)(1-y)$, giving conditional probability $[1-(1-x)(1-y)]^{n-1}$. Integrating gives $H_n/n$, where $H_n$ is a [harmonic number](harmonic-number.md). [Linearity of expectation](linearity-of-expectation.md) over the $n$ [indicator random variables](indicator-random-variable.md) gives $\mathbb E K_n=H_n$. The same answer holds for independent continuous coordinate distributions, by transforming each coordinate with its distribution function.
