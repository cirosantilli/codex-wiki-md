# Pandigital number

↑ **Parent:** [Numerical digit](numerical-digit.md)

A number whose representation contains every [numerical digit](numerical-digit.md) from a specified alphabet. The convention must specify the base, whether zero is required, and whether repetitions are allowed. In many counting problems, “0-to-9 pandigital” means that all ten decimal [numerical digits](numerical-digit.md) occur exactly once; other problems require only that each occur at least once.
