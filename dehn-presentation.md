# Dehn presentation

↑ **Parent:** [Group presentation](group-presentation.md)

A finite [group presentation](group-presentation.md) with cyclically reduced symmetrized [relators](relator.md) is a [Dehn presentation](dehn-presentation.md) if every nonempty freely reduced null word contains a [relator](relator.md) segment longer than half that [relator](relator.md). Replacing the segment by the inverse complementary segment strictly shortens the word. Finiteness of both the alphabet and the [relator](relator.md) set is part of this definition; merely permitting all null words as an infinite [relator](relator.md) set would make the shortening property vacuous as a finiteness criterion.
