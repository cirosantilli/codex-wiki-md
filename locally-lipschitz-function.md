# Locally Lipschitz function

↑ **Parent:** [Lipschitz continuity](lipschitz-continuity.md)

A function is locally Lipschitz when every point has a neighborhood on which the function satisfies a [Lipschitz bound](lipschitz-bound.md). Continuously differentiable functions are locally Lipschitz.
