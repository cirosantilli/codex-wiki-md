# Lexicographic initial segments preserve ordinary intersection

↑ **Parent:** [Intersecting family](intersecting-family.md)

For $1\le r\le n/2$, the [Erdős-Ko-Rado theorem](erdos-ko-rado-theorem.md) bounds an [intersecting family](intersecting-family.md) by the displayed size. The first that many rank-$r$ sets in [lexicographic order](lexicographic-order.md) all contain coordinate one. Therefore the lexicographic [initial segment](initial-segment.md) of the same size as any [intersecting family](intersecting-family.md) is also intersecting. This statement concerns ordinary one-element intersection and does not extend to higher intersection requirements.
