# Weak approximation for inequivalent absolute values

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

For finitely many pairwise inequivalent nontrivial [absolute values on a field](absolute-value-algebra.md), an element of the field can approximate independently prescribed targets in the associated [completion of a valued field](completion-of-a-valued-field.md) at each place to arbitrary positive accuracies. Equivalently the diagonal map has dense image in the finite product. Requiring finitely many inequivalent places is essential; the conclusion controls finitely many inequalities, not infinitely many independently prescribed bounds at once, or incompatible targets at one place. [Weak approximation for number fields](weak-approximation-for-number-fields.md) is the class-field-theoretic instance.
