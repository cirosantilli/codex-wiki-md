# Bounded harmonic function theorem on a recurrent graph

↑ **Parent:** [Discrete harmonic function](discrete-harmonic-function.md)

Every bounded [harmonic function on a graph](discrete-harmonic-function.md) is constant if the connected [locally finite graph](locally-finite-graph.md) is recurrent. Along its [random walk on a graph](random-walk-on-a-graph.md), the harmonic values form a bounded [martingale](martingale-split.md) and converge almost surely. Recurrence visits each vertex infinitely often, making every vertex value a subsequential limit of the same convergent sequence. Thus every value agrees.
