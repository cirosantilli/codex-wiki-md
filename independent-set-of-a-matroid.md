# Independent set of a matroid

↑ **Parent:** [Matroid](matroid.md)

A [matroid independent set](independent-set-of-a-matroid.md) is a [subset](subset.md) belonging to the family $\mathcal I$. Independence refers to the chosen [matroid](matroid.md): for a [linear matroid](linear-matroid.md) it means [linear independence](linear-independence.md), and for a [graphic matroid](graphic-matroid.md) it means that the chosen [edges](edge-of-a-graph.md) contain no [graph cycle](cycle-in-a-graph.md). It is different from an [independent set](independent-set-graph-theory.md), which selects [vertices](vertex-graph-theory.md) with no [edge](edge-of-a-graph.md) between them.
