# Fixed-size clique appearance threshold

↑ **Parent:** [Clique count in a binomial random graph](clique-count-in-a-binomial-random-graph.md)

For fixed $k\ge2$, a [binomial random graph](binomial-random-graph.md) has no $k$-[cliques](clique-graph-theory.md) with probability tending to one if $\mu_n\to0$, and has at least one with probability tending to one if $\mu_n\to\infty$. The first assertion uses the [first moment method](first-moment-method.md). The second uses the [overlap formula for the variance of a clique count](overlap-formula-for-the-variance-of-a-clique-count.md): overlapping $k$-sets with $l\ge2$ contribute $O(n^{-l}p^{-\binom l2})$, and each contribution tends to zero above this threshold. The fixed-size qualification matters.
