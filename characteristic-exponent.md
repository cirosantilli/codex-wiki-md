# Characteristic exponent

↑ **Parent:** [Linear ordinary differential equation](linear-ordinary-differential-equation-split.md)

A [characteristic exponent](characteristic-exponent.md) is a value $\lambda$ for which an exponential mode $e^{\lambda t}$ solves the homogeneous constant-coefficient linear equation or system. Repeated exponents can give polynomial factors multiplying that exponential.
