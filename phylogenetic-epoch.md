# Phylogenetic epoch

↑ **Parent:** [Phylogenetic tree](phylogenetic-tree.md)

A [phylogenetic epoch](phylogenetic-epoch.md) is an interval between successive branching or merging events during which the number of extant ancestral branches is constant. Its expected duration with $k$ branches is denoted $E_k$.
