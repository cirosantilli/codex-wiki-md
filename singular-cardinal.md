# Singular cardinal

↑ **Parent:** [Cofinality](cofinality.md)

An infinite [cardinal number](cardinal-number.md) $\kappa$ is singular when $\operatorname{cf}(\kappa)<\kappa$. Thus a short [cofinal function](cofinal-function.md) reaches arbitrarily high ordinals below $\kappa$. For example, $\aleph_\omega$ has [cofinality](cofinality.md) $\omega$. The complementary case is a [regular cardinal](regular-cardinal.md).
