# Positive system of a root system

↑ **Parent:** [Fundamental system of a root system](fundamental-system-of-a-root-system.md)

The positive system associated with a [fundamental system of a root system](fundamental-system-of-a-root-system.md) $\Delta$ consists of the roots whose coordinates in the basis $\Delta$ are nonnegative.
