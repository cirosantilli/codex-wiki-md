# Heawood torus map

↑ **Parent:** [Heawood graph](heawood-graph.md)

Triangulate a [torus](torus.md) using the seven vertices of the [complete graph](complete-graph.md) $K_7$ and oriented triangles $(i,i+1,i+3)$ and $(i,i+3,i+2)$, with indices modulo seven. Every edge occurs twice with opposite orientations; each vertex has a cyclic link. The [Euler characteristic](euler-characteristic.md) is $7-21+14=0$. Its [dual graph](dual-graph.md) is the [Heawood graph](heawood-graph.md). This dual map has seven disc faces, each adjacent to all the others, so it needs seven face colors although its edges have a [Tait coloring](tait-coloring.md).
