# Majority function

↑ **Parent:** [Threshold function](threshold-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Majority_function)

A majority [Boolean function](boolean-function.md) outputs one when more than half its input bits are one. An odd number of inputs avoids a tie convention. For three bits its unique [multilinear polynomial](multilinear-polynomial.md) is $x_1x_2+x_1x_3+x_2x_3-2x_1x_2x_3$, so the [polynomial method for quantum query lower bounds](polynomial-method-for-quantum-query-lower-bounds.md) requires at least two exact queries.
