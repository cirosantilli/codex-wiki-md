# Software prefetch

↑ **Parent:** [Cache prefetching](cache-prefetching.md)

A program-directed hint to fetch a [cache line](cache-line.md) early. A useful nonblocking hint produces no destination [processor register](processor-register.md) value and allows execution to continue before the transfer completes. Fault and dropping behavior depend on the specified instruction contract.
