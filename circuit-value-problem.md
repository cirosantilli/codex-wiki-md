# Circuit value problem

↑ **Parent:** [Boolean circuit](boolean-circuit.md)

Given a finite acyclic [Boolean circuit](boolean-circuit.md) and its input assignment, determine the output bit. Topological gate evaluation places the problem in [P](p-complexity.md); it is a standard [P-complete](p-completeness.md) problem under [logspace many-one reductions](logspace-many-one-reduction.md). [Boolean circuit](boolean-circuit.md) evaluation is different from [Circuit satisfiability problem](circuit-satisfiability-problem.md), which asks whether some assignment succeeds.
