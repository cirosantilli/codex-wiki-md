# Block code

↑ **Parent:** [Coding theory](coding-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Block_code)

A [block code](block-code.md) assigns source messages to words of a fixed length over an [alphabet](alphabet.md). Its codewords form a subset of that fixed-length word space; a [binary block code](binary-block-code.md) uses the two-symbol [finite field](finite-field.md) $\mathbb F_2$.
