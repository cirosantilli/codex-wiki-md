# Alpha element

↑ **Parent:** [Galactic chemical evolution](galactic-chemical-evolution.md)

An alpha element is an element such as oxygen, neon or magnesium associated with nucleosynthesis involving helium nuclei and massive-star burning. [Core-collapse supernovae](core-collapse-supernova.md) promptly return substantial abundances of these elements. Their abundance relative to iron can distinguish a rapid enrichment history from one with substantial delayed [Type Ia supernova](type-ia-supernova.md) enrichment.
