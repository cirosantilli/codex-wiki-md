# Negative-definite matrix

↑ **Parent:** [Definite matrix](definite-matrix.md)

A real symmetric matrix $A$ is negative definite when $x^TAx<0$ for every nonzero real [vector](vector.md) $x$. Equivalently, $-A$ is a [positive-definite matrix](positive-definite-matrix.md) and every [eigenvalue](eigenvalue.md) of $A$ is negative.
