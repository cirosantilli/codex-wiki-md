# Virtual hopping

↑ **Parent:** [Hopping integral](hopping-integral.md)

A hopping process through an intermediate configuration of different unperturbed [energy](energy-split.md), contributing to a low-[energy](energy-split.md) effective description through [perturbation theory](perturbation-theory.md). If an intermediate state costs $\Delta>0$, [second-order nondegenerate perturbation theory](second-order-nondegenerate-perturbation-theory.md) gives a contribution $-|\langle a|T|0\rangle|^2/\Delta$. Its amplitude is of order $t/\Delta$ and its [energy](energy-split.md) correction of order $-t^2/\Delta$; a degenerate low-[energy](energy-split.md) sector requires the corresponding [degenerate perturbation theory](degenerate-perturbation-theory.md) before identifying the [ground state](ground-state.md).
