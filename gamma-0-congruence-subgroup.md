# Gamma 0 congruence subgroup

↑ **Parent:** [Congruence subgroup](congruence-subgroup.md)

The Gamma 0 congruence subgroup is

$$
\Gamma_0(N)=\left\{\begin{pmatrix}a&b\\c&d\end{pmatrix}\in SL_2(\mathbb Z):c\equiv0\pmod N\right\}.
$$
