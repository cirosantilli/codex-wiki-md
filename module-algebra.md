# Module algebra

↑ **Parent:** [Hopf algebra](hopf-algebra.md)

An [algebra over a field](algebra-over-a-field.md) acted on by a [bialgebra](bialgebra.md) is a module algebra when multiplication and unit are [module](module-mathematics.md) maps: the displayed product identity holds and $h1=\varepsilon(h)1$. This expresses the product rule determined by [comultiplication](comultiplication.md).
