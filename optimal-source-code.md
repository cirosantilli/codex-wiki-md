# Optimal source code

↑ **Parent:** [Decipherable code](decipherable-code.md)

For a fixed source distribution and code alphabet, an optimal [uniquely decodable code](decipherable-code.md) minimizes expected codeword length. [Huffman coding](huffman-coding.md) gives an optimal binary [prefix code](prefix-code.md), and the equivalence of attainable uniquely-decodable and prefix-code lengths gives the same minimum for both classes.
