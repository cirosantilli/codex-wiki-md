# Nonprincipal propositional type

↑ **Parent:** [Propositional type](propositional-type.md)

Relative to a consistent [propositional theory](propositional-theory.md) $T$, a [nonprincipal propositional type](nonprincipal-propositional-type.md) has no formula consistent with $T$ that implies every member modulo $T$. Equivalently, for each finite condition $\theta$ consistent with $T$, some member $\sigma$ leaves $T\cup\{\theta,\neg\sigma\}$ consistent. This is the local omission condition for the [extended omitting types theorem for propositional logic](extended-omitting-types-theorem-for-propositional-logic.md).
