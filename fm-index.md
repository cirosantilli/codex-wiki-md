# FM-index

↑ **Parent:** [String-searching algorithm](string-searching-algorithm.md)

An [FM-index](fm-index.md) is a compressed text index supporting [backward search](backward-search.md) through the [Burrows-Wheeler transform](burrows-wheeler-transform.md) and occurrence counts. Character [rank queries](rank-query.md) locate a matching interval; sampled [suffix array](suffix-array.md) positions then allow the actual text positions to be recovered. Query length, number of matches and the chosen sampling density control different parts of the search cost.[§§3.1–3.2, counting and locating occurrences](opportunistic-data-structures-with-applications-by-paolo-ferragina-and-others.md)
