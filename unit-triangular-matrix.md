# Unit triangular matrix

↑ **Parent:** [LU decomposition](lu-decomposition.md)

A [unit triangular matrix](unit-triangular-matrix.md) is a [triangular matrix](triangular-matrix.md) whose diagonal entries are all one. It is an [invertible matrix](invertible-matrix.md) with [determinant](determinant.md) one. In the convention used for [LU decomposition](lu-decomposition.md), $L$ is a unit [lower triangular matrix](lower-triangular-matrix.md), so [forward substitution](forward-substitution.md) needs no division by its diagonal entries.
