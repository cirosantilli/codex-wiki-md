# Precise exception

↑ **Parent:** [Synchronous processor exception](synchronous-processor-exception.md)

An exception presented with architectural state corresponding to a program-order boundary: older instructions have taken effect and younger ones have not. Private results in a [reorder buffer](reorder-buffer.md) can be discarded to recover this state.
