# Edge path

↑ **Parent:** [Simplicial complex](simplicial-complex.md)

An edge path in a [simplicial complex](simplicial-complex.md) is a finite sequence of [vertices of a simplicial complex](vertex-of-a-simplicial-complex.md) such that $\{v_i,v_{i+1}\}$ is a [simplex](simplex.md) for each consecutive pair. Repeated consecutive vertices are allowed. Its [geometric realization](geometric-realization-of-a-simplicial-complex.md) is a [continuous path](continuous-path.md) formed by traversing the corresponding [line segments](line-segment.md), with constant pieces for repetitions.

A [connected](connected-space.md) [geometric realization](geometric-realization-of-a-simplicial-complex.md) has an edge path between any two vertices. For a fixed vertex, the reachable vertices form a union of whole [simplexes](simplex.md): all vertices of a [simplex](simplex.md) are pairwise joined by edges. The reachable and unreachable geometric parts therefore intersect each [simplex](simplex.md) in either the whole [simplex](simplex.md) or the [empty set](empty-set.md). Both parts are [closed](closed-set.md) in the realization [topology](topology-split.md) and are complements, so both are [open](open-set.md). [Connectedness](connected-space.md) forces the unreachable part to be empty. Conversely, edge paths between vertices and straight segments inside [simplexes](simplex.md) join arbitrary points, so the realization is [path-connected](path-connected-space.md).
