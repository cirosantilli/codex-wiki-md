<h1 id="dalen-light">Dalén light</h1>

↑ **Parent:** [Lighthouse](lighthouse.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dalén_light)

An automatic gas-lighting system associated with [Gustaf Dalén](gustaf-dalen.md). The [sun valve](sun-valve.md) decides whether daylight permits the main supply; a separate flashing mechanism determines the repeated light pattern. Keeping those functions distinct is useful when identifying what an apparatus actually controls.
