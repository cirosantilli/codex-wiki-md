# Functionally independent functions

↑ **Parent:** [Differentiable map](differentiable-map.md)

Functions whose [differentials](differential-of-a-smooth-map.md) are [linearly independent](linear-independence.md) at the point in question. For $F=(F_1,\ldots,F_r)$ this means the derivative has rank $r$, so $F$ is a [submersion](submersion.md) there. The condition is open. It is distinct from global [algebraic independence](algebraic-independence.md) of functions.
