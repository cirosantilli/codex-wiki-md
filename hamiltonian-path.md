# Hamiltonian path

↑ **Parent:** [Path in a graph](path-in-a-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hamiltonian_path)

A [Hamiltonian path](hamiltonian-path.md) is a [path in a graph](path-in-a-graph.md) that visits every [graph vertex](vertex-graph-theory.md) exactly once. Removing any [edge](edge-of-a-graph.md) from a [Hamilton cycle](hamilton-cycle.md) produces a [Hamiltonian path](hamiltonian-path.md). Conversely, a [Hamiltonian path](hamiltonian-path.md) closes to a [Hamilton cycle](hamilton-cycle.md) exactly when its endpoints are joined by an [edge](edge-of-a-graph.md).
