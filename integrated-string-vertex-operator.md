# Integrated string vertex operator

↑ **Parent:** [String vertex operator](string-vertex-operator.md)

An integrated closed-string vertex is inserted as $\int d^2z\,V(z,\bar z)$. In conformal gauge its matter operator must have [conformal weights](conformal-weight.md) $(1,1)$ so that the insertion is invariant under worldsheet coordinate changes.
