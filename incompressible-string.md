# Incompressible string

↑ **Parent:** [Plain Kolmogorov complexity](plain-kolmogorov-complexity.md)

A [binary string](binary-string.md) is incompressible relative to a fixed [optimal description machine](optimal-description-machine.md) when its [plain Kolmogorov complexity](plain-kolmogorov-complexity.md) is at least its length. A counting argument gives at least one such string at each length, and their set is immune.
