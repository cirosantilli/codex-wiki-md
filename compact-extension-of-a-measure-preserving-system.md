# Compact extension of a measure-preserving system

↑ **Parent:** [Factor map between measure-preserving systems](factor-map-between-measure-preserving-systems.md)

An extension for which the [relatively almost periodic observables](relatively-almost-periodic-observable.md) are dense in global $L^2$. Density does not assert that every $L^2$ function already meets the uniform finite-net condition on fibers. Localization yields the [positive-measure almost periodic indicator in a compact extension](positive-measure-almost-periodic-indicator-in-a-compact-extension.md).
