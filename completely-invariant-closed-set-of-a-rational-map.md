# Completely invariant closed set of a rational map

↑ **Parent:** [Julia set](julia-set.md)

If a closed set $E$ satisfies $f^{-1}(E)=E$ for a rational map of degree at least two, then either $E$ has at most two points and lies in the [Fatou set](fatou-set.md), or $J(f)\subseteq E$. The complement omits every point of $E$, so [Montel theorem](montel-s-theorem.md) proves normality when $|E|\geq3$.
