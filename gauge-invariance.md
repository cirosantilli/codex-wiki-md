# Gauge invariance

↑ **Parent:** [Gauge field](gauge-field.md)

Gauge invariance is invariance under local changes of gauge representative. Gauge-invariant observables depend only on the physical gauge orbit.

A [gauge theory](gauge-theory.md) uses this redundancy to describe the same physical state by different field representatives.
