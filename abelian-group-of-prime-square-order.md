# Abelian group of prime-square order

↑ **Parent:** [Abelian group](abelian-group.md)

An [abelian group](abelian-group.md) of order $p^2$ is cyclic if it has an element of order $p^2$. Otherwise [Lagrange's theorem](lagrange-s-theorem.md) makes every nonidentity element have order $p$. Choose $a\ne1$ and $b\notin\langle a\rangle$. The [group homomorphism](group-homomorphism.md) $(i,j)\mapsto a^ib^j$ from $C_p\times C_p$ is injective: $b^j\in\langle a\rangle$ with $j\ne0$ would imply $b\in\langle a\rangle$, using the inverse of $j$ modulo $p$. Equal finite orders then make this an isomorphism.
