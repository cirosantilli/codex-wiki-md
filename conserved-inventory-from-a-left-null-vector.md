# Conserved inventory from a left null vector

↑ **Parent:** [Left null space](left-null-space.md)

For the [linear ordinary differential equation](linear-ordinary-differential-equation-split.md) $c'=Ac-b$, a fixed [left null space](left-null-space.md) [vector](vector.md) gives $(w^Tc)'=-w^Tb$. Thus $w^Tc$ is a [conserved quantity](conserved-quantity.md) when $w^Tb=0$. In a [box model](box-model.md) written for [concentrations](concentration.md) per unit [volume](volume.md), physical tracer inventory uses the box [volumes](volume.md) as weights. Zero column sums make $w=\mathbf1$ possible, but that property must be checked rather than assumed.
