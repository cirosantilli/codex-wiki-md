# Shell crossing

↑ **Parent:** [Zeldovich approximation](zeldovich-approximation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Shell_crossing)

Shell crossing occurs when the Lagrangian-to-Eulerian map ceases to be one-to-one. Its Jacobian determinant vanishes, the pressureless single-stream density formally diverges, and several streams subsequently occupy the same position.
