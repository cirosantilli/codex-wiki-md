# Translating accelerated reference frame

↑ **Parent:** [Reference frame](reference-frame.md)

If the origin of a nonrotating [reference frame](reference-frame.md) has inertial [position](position.md) $\mathbf a(t)$ and a particle has relative [position](position.md) $\mathbf R$, then $\mathbf r=\mathbf R+\mathbf a$. [Newton's second law](newton-s-second-law.md) becomes $m\ddot{\mathbf R}=\mathbf F-m\ddot{\mathbf a}$. The effective inertial [force](force.md) is therefore $-m\ddot{\mathbf a}$. No rotation-dependent terms arise because the coordinate axes remain parallel to the inertial axes.
