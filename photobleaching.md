# Photobleaching

↑ **Parent:** [Fluorescence](fluorescence-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Photobleaching)

[Photobleaching](photobleaching.md) is an irreversible loss of fluorescent capacity caused by illumination. It changes the number of active [fluorophores](fluorophore.md) over experimental [time](time-in-physics.md); [fluorescence lifetime](fluorescence-lifetime.md) concerns the delay after an individual excitation. Reversible dark states and ordinary return to the [ground state](ground-state.md) are different processes.

In a stipulated population-loss model, let $T$ denote elapsed illumination [time](time-in-physics.md) and $t$ denote delay after a pulse. If active population declines as $e^{-k_{\rm b}T}$ while surviving [fluorophores](fluorophore.md) retain the same decay rates, then $I(t;T)=A_0e^{-k_{\rm b}T}e^{-t/\tau}$. Brightness falls while $\tau$ stays fixed. This example does not assert that all bleaching follows [exponential decay](exponential-decay.md): chemical changes and selective loss from a mixture can also change the observed decay shape. The existing [FRET photobleaching controls](fret-photobleaching-controls.md) illustrate why deliberate bleaching requires careful interpretation.
