# X-ray fluorescence

↑ **Parent:** [Characteristic X-ray](characteristic-x-ray.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/X-ray_fluorescence)

[X-ray fluorescence](x-ray-fluorescence.md) is [Characteristic X-ray](characteristic-x-ray.md) emission following excitation by incident [photons](photon.md). In a simple initially unexcited [chemical atom](atom-physics.md), [photoionization](photoionization.md) can eject an inner [electron](electron.md) if the incident [photon](photon.md) supplies its [binding energy](binding-energy.md). An outer [electron](electron.md) can then fill the vacancy, releasing an emitted [photon](photon.md) with the difference of shell [binding energies](binding-energy.md). Nonradiative relaxation competes with this route, so one absorbed incident [photon](photon.md) need not yield one escaping characteristic [photon](photon.md).

Choose a separate stipulated [electron shell](electron-shell.md) model with values $B_K=10.0$, $B_L=1.5$ and $B_M=0.3$, all in $\mathrm{keV}$. Ignore subshell splitting, recoil and changes of [binding energy](binding-energy.md) during relaxation. The possible shell differences are

$$
E_{K\alpha}=B_K-B_L=8.5\,\mathrm{keV},\qquad
E_{K\beta}=B_K-B_M=9.7\,\mathrm{keV},\qquad
E_{L\alpha}=B_L-B_M=1.2\,\mathrm{keV}.
$$

These labels denote simplified shell groups, not resolved subshell [electronic transitions](electronic-transition.md). With $hc=1.23984\,\mathrm{keV\,nm}$, their calculated [wavelengths](wavelength.md) are respectively $0.145864$, $0.127819$ and $1.03320\,\mathrm{nm}$. An incident $9.8\,\mathrm{keV}$ [photon](photon.md) exceeds both K-line [energies](energy-split.md) but cannot directly create the K vacancy in this initially unexcited model. A $12.0\,\mathrm{keV}$ [photon](photon.md) can, leaving approximately $2.0\,\mathrm{keV}$ of [photoelectron](photoelectron.md) [kinetic energy](kinetic-energy.md). This comparison fixes neither the excitation probability nor the radiative branching probability.
