# Inductance matrix

↑ **Parent:** [Coupled inductors](coupled-inductors.md)

An [inductance matrix](inductance-matrix.md) relates [magnetic flux linkages](magnetic-flux-linkage.md) to [electric currents](electric-current.md) in a linear model of [coupled inductors](coupled-inductors.md). For reciprocal two-coil coupling, $\mathbf L=\left(\begin{smallmatrix}L_1&M\\M&L_2\end{smallmatrix}\right)$. Its stored [magnetic energy](magnetic-energy.md) is $\mathbf i^T\mathbf L\mathbf i/2$. With $L_1,L_2>0$, it is a [positive-definite matrix](positive-definite-matrix.md) exactly when $M^2<L_1L_2$. Equality is a singular limiting model requiring separate treatment.
