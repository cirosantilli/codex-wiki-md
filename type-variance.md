# Type variance

↑ **Parent:** [Parametric polymorphism](parametric-polymorphism.md)

How [subtyping](subtyping.md) between parameter types affects [subtyping](subtyping.md) between instances of a parameterized type. A [covariant type parameter](covariant-type-parameter.md) preserves the direction, a [contravariant type parameter](contravariant-type-parameter.md) reverses it, and [generic type invariance](generic-type-invariance.md) permits neither conversion solely from the parameter relationship. Safe variance depends on how a type is consumed, produced and stored.
