# Bounded-complete partially ordered set

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

Every subset having an [upper bound](upper-bound-in-a-partially-ordered-set.md) has a [least upper bound](least-upper-bound-in-a-partially-ordered-set.md). If the empty subset is included, a nonempty such [partially ordered set](partially-ordered-set.md) has a [least element](least-element.md). This condition differs from a [directed-complete partial order](directed-complete-partial-order.md): a [directed set](directed-set.md) need not have an [upper bound](upper-bound-in-a-partially-ordered-set.md).
