# Baryon-minus-lepton number

↑ **Parent:** [Baryon number](baryon-number.md)

The difference between [baryon number](baryon-number.md) and [lepton number](lepton-number.md). Standard electroweak [sphalerons](sphaleron.md) violate $B+L$ while conserving $B-L$. Consequently an early [baryon asymmetry](baryon-asymmetry.md) with zero $B-L$ need not survive equilibration; a surviving nonzero $B-L$ can be redistributed between [baryons](baryon.md) and [leptons](lepton.md). Additional lepton-number-violating interactions can change this conclusion.
