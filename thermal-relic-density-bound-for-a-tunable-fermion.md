# Thermal relic density bound for a tunable fermion

↑ **Parent:** [Mass-dependent fermion freeze-out](mass-dependent-fermion-freeze-out.md)

For a stable nonrelativistic [thermal relic](thermal-relic.md), compare [energy](energy.md) densities rather than number densities. If $m_Y=m_{\rm nr}/x^3$ and $Y_Y=Cx^{3/2}e^{-x}$, its [density](density.md) relative to [baryons](baryon.md) is $(Cm_{\rm nr}/m_BY_B)x^{-3/2}e^{-x}$. Requiring this ratio below an allowed dark-matter-to-baryon ratio $R$ means $x+\tfrac32\log x\ge\log[Cm_{\rm nr}/(Rm_BY_B)]$. With fixed rate parameters this excludes the weakly interacting large-mass branch, while the sufficiently Boltzmann-suppressed smaller-mass branch can satisfy the [density](density.md) bound. Decay or a nonthermal initial abundance requires a different constraint.
