# Circular orbit condition for a radial kinetic Lagrangian

↑ **Parent:** [Circular orbit](circular-orbit.md)

Let a planar [Lagrangian](lagrangian.md) have the form $L=a(r)\dot r^2+b(r)\dot\theta^2+c(r)$, with smooth coefficients and $b(r)>0$. Its [cyclic coordinate](cyclic-coordinate.md) $\theta$ has constant [conjugate momentum](canonical-momentum.md) $p_\theta=2b(r)\dot\theta$. For a [circular orbit](circular-orbit.md) $r=R$, the radial [Euler-Lagrange equation](euler-lagrange-equation.md) reduces to $b'(R)\dot\theta^2+c'(R)=0$. If $b'(R)\ne0$, eliminating $\dot\theta$ gives the displayed condition. A real orbit requires $-c'(R)/b'(R)\geq0$; the radial kinetic coefficient $a$ does not enter this constant-radius condition, although it affects radial perturbations. If $b'(R)=0$, the original condition must be used rather than divided by zero.
