# Bernoulli function (hypercube)

↑ **Parent:** [Rademacher distribution](rademacher-distribution.md)

On the [Boolean hypercube](boolean-hypercube.md) $\{-1,1\}^d$ with uniform measure, each coordinate is a [Rademacher random variable](rademacher-distribution.md). Products of these sign coordinate functions are [Walsh characters](walsh-character.md). This use of Bernoulli function is distinct from the fluid-mechanical [Bernoulli function](bernoulli-function.md).
