# Nonnegative state prices need not exclude arbitrage

↑ **Parent:** [Arrow–Debreu state price](arrow-debreu-state-price.md)

If a traded payoff matrix $A$ has initial price vector $q=A^Tp$ with $p\ge0$, there cannot be a negative-cost [portfolio](investment-portfolio.md) with nonnegative terminal payoff. Nevertheless a nonzero nonnegative attainable payoff supported only in zero-price states can cost zero and give an [arbitrage](arbitrage.md). When every state has positive physical [probability](probability.md), excluding this possibility requires strictly positive [Arrow state prices](arrow-debreu-state-price.md), not merely a nonnegative supporting vector.
