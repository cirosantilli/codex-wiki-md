# Programming language polymorphism

↑ **Parent:** [Type system](type-system.md)

Using an interface or definition across multiple types. [Subtype polymorphism](subtype-polymorphism.md) dispatches through a common supertype; [parametric polymorphism](parametric-polymorphism.md) uses a type parameter uniformly; [method overloading](method-overloading.md) selects among signatures by [static types](static-type.md) in languages such as [Scala](scala.md). These mechanisms should be distinguished from genetic or materials-science polymorphism.
