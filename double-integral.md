# Double integral

↑ **Parent:** [Integral](integral-split.md)

A double integral integrates a function over a two-dimensional region. A [change of variables formula](change-of-variables-formula.md) can replace the region and area element using a [Jacobian determinant](jacobian-determinant.md).

It is a [multiple integral](multiple-integral.md) with two integration variables.
