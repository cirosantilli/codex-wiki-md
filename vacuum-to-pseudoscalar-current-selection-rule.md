# Vacuum-to-pseudoscalar current selection rule

↑ **Parent:** [Leptonic pion decay](leptonic-pion-decay.md)

[Lorentz covariance](lorentz-covariance.md) allows only a multiple of $p^\mu$ for a vacuum-to-[spin](spin.md)-zero one-particle current. In its rest frame only the temporal component can remain. A parity-even temporal [vector current](vector-current.md) between a parity-even vacuum and parity-odd particle changes sign, forcing that component to vanish. A temporal [axial current](axial-current.md) is parity-odd and is allowed. This explains why the [pion decay constant](pion-decay-constant.md) enters the axial, rather than vector, part of the [weak charged current](charged-current.md).
