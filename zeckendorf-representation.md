# Zeckendorf representation

↑ **Parent:** [Fibonacci number](fibonacci-number.md)

The Zeckendorf representation expresses a [nonnegative integer](natural-number.md) as a sum of nonconsecutive [Fibonacci numbers](fibonacci-number.md), using the sequence that starts $1,2,3,5,\ldots$. Every nonnegative integer has exactly one such representation; repeatedly taking the largest available Fibonacci number constructs it.
