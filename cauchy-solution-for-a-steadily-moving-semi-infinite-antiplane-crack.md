# Cauchy solution for a steadily moving semi-infinite antiplane crack

↑ **Parent:** [Hilbert problem for an antiplane crack](hilbert-problem-for-an-antiplane-crack.md)

For the moving semi-infinite crack, take the [branch cut](branch-cut.md) of $\sqrt z$ on the negative real axis and $\sqrt x>0$ ahead of the tip. With [steadily moving antiplane shear](steadily-moving-antiplane-shear.md), face [tractions](traction.md) $\sigma_{23}^{\pm}=-f(x)$ imply $\operatorname{Im}F'^{\pm}=f/\mu$. The antisymmetric [displacement](displacement.md) response gives $F'^-=-\overline{F'^+}$. Hence $G=\sqrt zF'$ has jump $G^+-G^-=-2\sqrt{-x}f(x)/\mu$. The [Sokhotski–Plemelj theorem](sokhotski-plemelj-theorem.md) gives the displayed [Cauchy integral](cauchy-transform.md), assuming convergence and no extra remote homogeneous loading. For $x>0$ it is purely imaginary, so $\sigma_{23}=\int_{-\infty}^0\sqrt{-s}f(s)/(x-s)\,ds/(\pi\sqrt x)$. At fixed co-moving loading this ahead-of-tip [stress](stress.md) is independent of speed; the [displacement](displacement.md) still has the factor $1/\beta$.
