# Local coefficient system

↑ **Parent:** [Singular homology](singular-homology.md)

A local coefficient system assigns an Abelian group or module to each point, with compatible transport isomorphisms along paths depending only on homotopy relative endpoints. Equivalently it is a functor from the fundamental groupoid. On a connected manifold it is described by a representation of the [fundamental group](fundamental-group.md) after fixing one fiber.
