# Factorial cosine iterated limit detects rationality

↑ **Parent:** [Pointwise convergence](pointwise-convergence.md)

For fixed $m$, the inner [limit](limit-of-a-function.md) is one precisely when $m!x$ is an [integer](integer.md), and zero otherwise, because $|\cos(\pi y)|=1$ exactly at integers and powers of a number with modulus below one tend to zero. If $x=p/q$ is a [rational number](rational-number.md), $q$ divides $m!$ for every $m\geq q$, making the inner limit eventually one. If $x$ is an [irrational number](irrational-number.md), multiplication by a nonzero integer cannot make it integral, making every inner limit zero. The order of the two limits is essential to this argument.
