# Hermitian metric on a holomorphic vector bundle

↑ **Parent:** [Holomorphic vector bundle](holomorphic-vector-bundle.md)

A Hermitian metric on a [holomorphic vector bundle](holomorphic-vector-bundle.md) $E\to X$ is a smoothly varying positive-definite [Hermitian form](hermitian-form.md) $h_x$ on every complex fiber $E_x$.

Such a metric makes the underlying smooth bundle a [Hermitian vector bundle](hermitian-vector-bundle.md).
