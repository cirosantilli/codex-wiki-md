# Generic point for an invariant measure

↑ **Parent:** [Ergodic theory](ergodic-theory.md)

A point is generic for an [invariant measure](invariant-measure.md) $\mu$ of a [continuous map](continuous-map.md) on a [compact metric space](compact-metric-space.md) if the displayed convergence holds for every [continuous function](continuous-function.md) $\varphi$. Its empirical [probability measures](probability-measure.md) converge against continuous test functions to $\mu$. The same test-function condition may be used before invariance is known: the telescoping identity for $\varphi\circ f-\varphi$ then proves that the limiting [Borel probability measure](borel-probability-measure.md) must be invariant. If almost every point is generic for the same measure, continuous approximation of invariant-set indicators proves that this measure is [ergodic](ergodicity.md).
