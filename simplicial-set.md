# Simplicial set

↑ **Parent:** [Simplicial homotopy theory](simplicial-homotopy-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Simplicial_set)

A simplicial set is a [functor](functor.md) from the opposite of the [simplex category](simplex-category.md) to sets. Its face and degeneracy maps satisfy the simplicial identities.
