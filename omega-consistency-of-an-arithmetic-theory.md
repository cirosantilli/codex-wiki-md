# Omega-consistency of an arithmetic theory

↑ **Parent:** [Soundness of an arithmetic theory](soundness-of-an-arithmetic-theory.md)

A [first-order theory](first-order-theory.md) is omega-consistent when it never proves $\exists x\phi(x)$ while proving $\neg\phi(\bar n)$ for every standard [natural number](natural-number.md) $n$. Restricting the matrix to [arithmetic](arithmetic-split.md) [bounded arithmetic formulas](arithmetic-bounded-formula.md) gives [one-consistency](one-consistency.md). This condition concerns standard instances and is stronger tha [first-order consistency](first-order-consistency.md).
