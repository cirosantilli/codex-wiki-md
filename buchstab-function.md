# Buchstab function

↑ **Parent:** [Sieve theory](sieve-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Buchstab_function)

The continuous [Buchstab function](buchstab-function.md) satisfies $w(u)=1/u$ for $1\le u\le2$ and $\frac{d}{du}(u w(u))=w(u-1)$ for $u>2$. It describes the density of [rough numbers](rough-number.md).
