# Prenucleolus

↑ **Parent:** [Nucleolus](nucleolus.md)

The [prenucleolus](prenucleolus.md) uses the same sorted [excesses of a coalition](excess-of-a-coalition.md) but minimizes over all efficient payoff vectors, without imposing individual rationality. It can differ from the [nucleolus](nucleolus.md) when [coalition](coalition-game-theory.md) values are not superadditive. Any computation must state which domain is used rather than silently relaxing [imputation](imputation-in-a-coalitional-game.md) inequalities.
