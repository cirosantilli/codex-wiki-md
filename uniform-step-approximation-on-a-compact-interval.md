# Uniform step approximation on a compact interval

↑ **Parent:** [Uniform approximation](uniform-approximation-split.md)

A [uniformly continuous](uniform-continuity.md) real [function](function-split.md) on a closed bounded interval can be approximated uniformly by finite [step functions](step-function.md). Given $\varepsilon>0$, choose a mesh smaller than the uniform-continuity distance and set the approximant equal to a sampled value on each interval. Then the [supremum norm](supremum-norm.md) of the approximation error is at most $\varepsilon$. If the function has a [Lipschitz bound](lipschitz-bound.md) $L$, a mesh of maximum length $h$ gives the explicit error bound $\|f-g\|_\infty\le Lh$.
