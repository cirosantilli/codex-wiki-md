# Bit-flip repetition code

↑ **Parent:** [Stabilizer code](stabilizer-code.md)

The $m$-qubit bit-flip repetition code is obtained from the [phase-flip repetition code](phase-flip-repetition-code.md) by interchanging $X$ and $Z$. It is stabilized by $Z_jZ_{j+1}$ and has logical operators $\overline X=X_1\cdots X_m$ and $\overline Z=Z_1$.
