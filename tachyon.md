# Tachyon

↑ **Parent:** [Subatomic particle](subatomic-particle.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tachyon)

A negative squared [mass](mass.md) in a relativistic field spectrum signals instability of the background about which the field is expanded. The [bosonic string mass spectrum](bosonic-string-mass-spectrum.md) contains such an unexcited state.
