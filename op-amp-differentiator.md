# Op amp differentiator

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

For an [ideal operational amplifier](ideal-operational-amplifier.md) with grounded non-inverting input, connect an input [capacitor](capacitor.md) $C$ to the inverting input and a feedback [resistor](resistor.md) $R$ from output to that input. The [virtual ground](virtual-ground.md) and [Kirchhoff's current law](kirchhoff-node-law.md) give $C\dot V_{\rm in}=-V_{\rm out}/R$. The ideal response amplifies high-frequency noise, so practical differentiators restrict its operating band and maintain feedback stability.
