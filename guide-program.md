# Guide program

↑ **Parent:** [Variational inference](variational-inference.md)

A [guide program](guide-program.md) is a [probabilistic program](probabilistic-program.md) whose generated [probability distribution](probability-distribution-split.md) approximates a model's [posterior distribution](bayesian-posterior.md). Its adjustable parameters are fitted by [variational inference](variational-inference.md). The guide must assign [probability](probability.md) only where the target allows it when minimizing $D_{\rm KL}(q\Vert p)$, but a tractable guide can still miss important target regions.
