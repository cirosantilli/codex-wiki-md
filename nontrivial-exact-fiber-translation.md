# Nontrivial exact fiber translation

↑ **Parent:** [Cotangent fiber translation](cotangent-fiber-translation.md)

If $dh$ is not identically zero, translating cotangent fibers by $dh$ preserves the canonical [symplectic form](symplectic-form.md) but changes the [Liouville one-form](canonical-one-form-on-a-cotangent-bundle.md) by $\pi^*dh$. Any positive-dimensional [smooth manifold](smooth-manifold.md) has a suitable nonconstant bump function in a chart. In dimension zero every [differential one-form](one-form.md) is zero, so this distinction cannot occur.
