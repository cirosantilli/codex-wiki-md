# Holley inequality

↑ **Parent:** [Stochastic domination of probability measures](stochastic-domination-of-probability-measures.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Holley_inequality)

On a finite distributive configuration lattice, [probability](probability.md) weights satisfying $\mu_1(\omega\vee\eta)\mu_2(\omega\wedge\eta)\ge\mu_1(\omega)\mu_2(\eta)$ for all pairs give [stochastic domination](stochastic-domination-of-probability-measures.md) $\mu_1\ge\mu_2$. The result holds for nonnegative weights as well: apply the [four functions theorem](ahlswede-daykin-inequality.md) to $\mu_1\mathbf1_{A^c},\mu_2\mathbf1_A,\mu_1\mathbf1_A,\mu_2\mathbf1_{A^c}$ for an [increasing event](increasing-event.md) $A$, obtaining $\mu_1(A^c)\mu_2(A)\le\mu_1(A)\mu_2(A^c)$.
