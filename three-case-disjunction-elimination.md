# Three-case disjunction elimination

↑ **Parent:** [Disjunction elimination rule](disjunction-elimination-rule.md)

If each of $A$, $B$ and $C$ separately yields the same conclusion $K$, then $A\lor B\lor C$ yields $K$, with the three case assumptions discharged. For $(A\lor B)\lor C$, first eliminate the outer [logical disjunction](logical-disjunction.md), using a nested applications of the [disjunction elimination rule](disjunction-elimination-rule.md) on the $A\lor B$ branch. For $A\lor(B\lor C)$, nest the second elimination in the other branch. Common surrounding assumptions remain open.
