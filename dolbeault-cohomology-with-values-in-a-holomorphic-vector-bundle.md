# Dolbeault cohomology with values in a holomorphic vector bundle

↑ **Parent:** [Dolbeault cohomology](dolbeault-cohomology.md)

This is the cohomology of $\mathcal A^{p,\bullet}(X,E)$ with the bundle [Dolbeault operator](dolbeault-operator.md). The [Dolbeault theorem](dolbeault-theorem.md) identifies it with $H^q(X,\Omega_X^p\otimes\mathcal O(E))$. For compact Hermitian $X$, [Dolbeault Hodge decomposition](dolbeault-hodge-decomposition-on-a-compact-hermitian-manifold.md) gives unique harmonic representatives.
