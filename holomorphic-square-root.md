# Holomorphic square root

↑ **Parent:** [Complex analysis](complex-analysis-split.md)

A [holomorphic square root](holomorphic-square-root.md) of a nonvanishing [holomorphic function](holomorphic-function.md) $f$ is a [holomorphic function](holomorphic-function.md) $g$ satisfying $g^2=f$. It exists locally. On a connected open domain it exists globally exactly when the [winding number](winding-number.md) of $f\circ\gamma$ around zero is even for every closed path $\gamma$ in the domain. Continuing a local square root once along such a path multiplies it by $(-1)^m$, where $m$ is that [winding number](winding-number.md). Thus the obstruction concerns parity, whereas a [holomorphic logarithm](holomorphic-logarithm.md) needs every such winding number to be zero.

On $\mathbb C\setminus\{0\}$, the function $f(z)=z$ has no global [holomorphic square root](holomorphic-square-root.md): its value winds once on the [unit circle](complex-unit-circle.md), and the lift shown under [monodromy](monodromy.md) changes sign. In contrast, $f(z)=z^2$ winds twice there and has global square roots $g(z)=z$ and $g(z)=-z$. It still has no [holomorphic logarithm](holomorphic-logarithm.md) on that domain. This distinguishes the two global continuation conditions.
