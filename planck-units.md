# Planck units

↑ **Parent:** [Natural units](natural-units.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Planck_units)

Planck units use fundamental constants to set natural units of [mass](mass.md), [length](length.md) and [time](time-in-physics.md). The displayed convention sets the ordinary [Planck mass](planck-mass.md) to one. The related [reduced Planck units](reduced-planck-units.md) convention instead normalizes the [reduced Planck mass](reduced-planck-mass.md).
