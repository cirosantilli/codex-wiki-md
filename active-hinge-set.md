# Active hinge set

↑ **Parent:** [Hinge loss](hinge-loss.md)

For a sample term $\max\{0,1-a_ix\}$, the active hinge set contains indices with $1-a_ix>0$. At strict negative margins the hinge is inactive, while zero margins allow fractional [hinge-loss optimality weights](hinge-loss-optimality-weight.md). Away from zero margins, the active set stays fixed on a sufficiently small candidate solution neighborhood.
