# Metric path length

↑ **Parent:** [Metric space](metric-space.md)

For a [continuous path](continuous-path.md) $\gamma:[a,b]\to X$ in a [metric space](metric-space.md), take the [supremum](supremum.md) over finite partitions $a=t_0<\cdots<t_n=b$ of $\sum_{i=1}^n d(\gamma(t_i),\gamma(t_{i-1}))$. This definition allows $+\infty$ and needs no [derivative](derivative.md). A [metric geodesic](metric-geodesic.md) parametrized on $[a,b]$ has length $b-a$. In a [Riemannian manifold](riemannian-manifold.md), it agrees with the usual [arc length](arc-length.md) integral for a [smooth](smooth-function.md) curve.
