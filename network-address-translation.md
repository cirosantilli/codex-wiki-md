# Network address translation

↑ **Parent:** [Middlebox](middlebox.md)

[Network address translation](network-address-translation.md) maps [IP addresses](ip-address.md) between address realms. State and path constraints can affect sessions. [Network address and port translation](network-address-and-port-translation.md) additionally maps transport ports. Translation does not itself require decryption of application payloads.[Abstract and §§1–2: address and port translation, state and limitations](traditional-ip-network-address-translator-traditional-nat-rfc-3022.md)
