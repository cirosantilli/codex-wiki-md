# Class equation

↑ **Parent:** [Conjugacy class](conjugacy-class.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Class_equation)

For a finite group,

$$
|G|=|Z(G)|+\sum_i[G:C_G(x_i)],
$$

where the $x_i$ represent the noncentral conjugacy classes.
