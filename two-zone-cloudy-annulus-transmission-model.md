# Two-zone cloudy annulus transmission model

↑ **Parent:** [Annulus model for transmission spectroscopy](annulus-model-for-transmission-spectroscopy.md)

An [exoplanet cloud deck](exoplanet-cloud-deck.md) divides the projected atmospheric annulus into cloudy and clear radial zones. Their contributions to the [exoplanet transmission spectrum](exoplanet-transmission-spectrum.md) add as projected areas multiplied by $1-e^{-\tau_\lambda}$ for each zone's slant [optical depth](optical-depth.md).
