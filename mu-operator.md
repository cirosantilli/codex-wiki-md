# Mu operator

↑ **Parent:** [Computable function](computable-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Mu_operator)

For a partial function $g(\mathbf x,y)$, unbounded minimization defines

$$
f(\mathbf x)=\mu y\,[g(\mathbf x,y)=0]
$$

as the least $y$ at which $g$ is zero, provided the preceding required computations are defined. If no such $y$ is found, $f(\mathbf x)$ is undefined. Closing the [primitive recursive functions](primitive-recursive-function.md) under this operation gives the partial recursive functions.
