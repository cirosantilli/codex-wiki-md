# Adiabatic tensor mode

↑ **Parent:** [Primordial tensor power spectrum](primordial-tensor-power-spectrum.md)

An adiabatic tensor mode is a long-wavelength transverse-traceless metric perturbation whose leading local effect can be produced by a [large spatial diffeomorphism](large-spatial-diffeomorphism.md). Its effect on short modes is therefore constrained by a Ward identity.
