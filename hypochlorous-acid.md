# Hypochlorous acid

↑ **Parent:** [Chemical substance](chemical-substance-split.md)

The [chlorine](chlorine.md) oxyacid $\mathrm{HOCl}$. In polar heterogeneous chemistry it can react with [hydrogen chloride](hydrogen-chloride.md) to release molecular [chlorine](chlorine.md) and [water](water.md), helping convert reservoir [chlorine](chlorine.md) into photolabile forms.
