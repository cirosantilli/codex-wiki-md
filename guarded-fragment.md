# Guarded fragment

↑ **Parent:** [First-order logic](first-order-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Guarded_fragment)

A relational fragment of [first-order logic](first-order-logic.md) in which each quantification is guarded by an atom containing all the variables that must remain together in its scope. The usual fragment excludes nonconstant function symbols.
