# Section compression in binary order

↑ **Parent:** [Binary order on the discrete cube](binary-order-on-the-discrete-cube.md)

Fix a coordinate of the [Boolean hypercube](boolean-hypercube.md), delete it in each of the two sections, and replace each section by a [binary initial segment](binary-initial-segment.md) of the same size. This preserves the total size. [Mathematical induction](mathematical-induction.md) on dimension proves that it does not decrease contained edge counts; the crossing contribution is the size of the section intersection, maximized by nested initial segments.
