# Division ring

↑ **Parent:** [Ring](ring.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Division_ring)

A division ring is a nonzero [ring](ring.md) in which every nonzero element has a multiplicative inverse. Its multiplication need not be [commutative](commutative-ring.md).
