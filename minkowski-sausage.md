# Minkowski sausage

↑ **Parent:** [Finite similarity iterated function system](finite-similarity-iterated-function-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Minkowski_sausage)

The [Minkowski sausage](minkowski-sausage.md) replaces a segment by eight directed unit segments whose endpoint displacement is four units. A middle straight run of length two represents two collinear unit segments. After normalizing the displacement to one, the eight [contracting Euclidean similarities](contracting-euclidean-similarity.md) all have ratio $1/4$. The open diamond $\{|x-1/2|+|y|<1/2\}$ is an [open set condition](open-set-condition.md) witness: its eight image diamonds have disjoint interiors and lie within it. Hence $8(1/4)^s=1$, giving [Hausdorff dimension](hausdorff-dimension.md) $3/2$. Treating the middle run as a single similarity of ratio $1/2$ instead defines a different iterated scheme.
