# Evolutionary game theory

↑ **Parent:** [Game theory](game-theory-split.md)

[Evolutionary game theory](evolutionary-game-theory.md) models changes in strategy frequencies when reproductive success or imitation depends on a game's [payoff](payoff.md). An [evolutionarily stable strategy](evolutionarily-stable-strategy.md) is an invasion criterion; a [replicator equation](replicator-equation.md) is a particular deterministic frequency dynamic.
