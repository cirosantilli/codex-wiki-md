# False-twin class

↑ **Parent:** [False twin](false-twin.md)

A false-twin class is an equivalence class of [vertices](vertex-graph-theory.md) with identical open neighbourhoods. In [edge-triangle symmetrization](edge-triangle-symmetrization.md), merging nonadjacent false-twin classes by cloning the better local score never decreases the objective. A secondary maximization of squared class sizes forces all distinct classes to be adjacent, giving a [complete multipartite graph](complete-multipartite-graph.md).
