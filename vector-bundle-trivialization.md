# Vector bundle trivialization

↑ **Parent:** [Vector bundle](vector-bundle.md)

A local trivialization of a rank-$r$ [vector bundle](vector-bundle.md) $\pi:E\to M$ is a bundle isomorphism $\pi^{-1}(U)\cong U\times\mathbb R^r$ over an open set $U$, linear on each fiber. Overlapping trivializations differ by $(p,v)\mapsto(p,g(p)v)$ for a smooth $GL_r(\mathbb R)$-valued function $g$. A [tangent bundle](tangent-bundle.md) chart uses the derivative of its base [manifold chart](manifold-chart.md) for this fiber identification.
