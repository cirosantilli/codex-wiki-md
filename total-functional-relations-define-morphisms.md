# Total functional relations define morphisms

↑ **Parent:** [Category of relations](category-of-relations.md)

In a [regular category](regular-category.md), a relation $R\hookrightarrow A\times B$ is total if its projection to $A$ is a [regular epimorphism](regular-epimorphism.md), and single-valued if two pairs with the same first component have the same second component. The latter makes that projection a [monomorphism](monomorphism.md). A regular epimorphism that is monic is invertible, so $f=\pi_B\pi_A^{-1}$ has graph exactly $R$. No axiom of choice or set-based element selection is used.
