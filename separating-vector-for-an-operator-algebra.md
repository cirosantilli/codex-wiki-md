# Separating vector for an operator algebra

↑ **Parent:** [Cyclic vector for an operator algebra](cyclic-vector-for-an-operator-algebra.md)

A [vector](vector.md) is separating for an [operator algebra](operator-algebra.md) when evaluation at that [vector](vector.md) is injective. A cyclic [vector](vector.md) for the [commutant of an operator algebra](commutant-of-an-operator-algebra.md) is separating for the original algebra: if $a\Omega=0$, then $a$ vanishes on its dense commutant orbit.
