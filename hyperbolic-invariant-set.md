# Hyperbolic invariant set

↑ **Parent:** [Dynamical systems](dynamical-systems-split.md)

A compact [invariant set](invariant-set-of-a-measure-preserving-transformation.md) $K$ of a smooth invertible map $f$ is uniformly hyperbolic when its tangent spaces split continuously as $E^s\oplus E^u$, the [derivative](derivative.md) preserves this splitting, and constants $C>0$, $0<\rho<1$ satisfy $\|Df^n v_s\|\le C\rho^n\|v_s\|$ and $\|Df^{-n}v_u\|\le C\rho^n\|v_u\|$ for every $n\ge0$. Thus the stable direction contracts forward and the unstable direction contracts backward. A [Smale horseshoe](smale-horseshoe.md) is an example with nontrivial symbolic dynamics; such a set can contain infinitely many saddle [periodic orbits](periodic-orbit.md) without attracting an open neighborhood.
