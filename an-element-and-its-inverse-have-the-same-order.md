# An element and its inverse have the same order

↑ **Parent:** [Order of a group element](order-of-a-group-element.md)

For every positive integer $m$, $(g^{-1})^m=(g^m)^{-1}$, hence $g^m=e$ if and only if $(g^{-1})^m=e$. The sets of positive powers returning to the [identity element](identity-element.md) are therefore equal. Taking the least positive exponent therefore gives the same finite [order of a group element](order-of-a-group-element.md) for $g$ and $g^{-1}$; if the sets are empty, both elements have infinite order. Equivalently, $g$ and $g^{-1}$ generate the same [cyclic subgroup](cyclic-subgroup.md).
