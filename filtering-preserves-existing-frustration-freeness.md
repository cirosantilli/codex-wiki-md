# Filtering preserves existing frustration freeness

↑ **Parent:** [Spectral filtering of Hamiltonian terms](spectral-filtering-of-hamiltonian-terms.md)

If each local term is already minimized by the global [ground state](ground-state.md), subtract its minimum $a_Z$ to obtain a [positive operator](positive-operator.md). Nonnegative normalized [spectral filtering of Hamiltonian terms](spectral-filtering-of-hamiltonian-terms.md) preserves positivity and leaves the ground eigenvalue $a_Z$ unchanged. Thus the same state minimizes every filtered term. This preserves [frustration freeness](frustration-freeness.md) but does not create it for an initially frustrated decomposition.
