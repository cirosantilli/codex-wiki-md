# Commuting-current obstruction in a two-dimensional Skyrme model

↑ **Parent:** [Derrick dimension test for the Skyrme model](derrick-dimension-test-for-the-skyrme-model.md)

For a smooth finite-energy static planar [Skyrme model](skyrme-model.md) field, [Derrick scaling](derrick-scaling.md) gives zero quartic energy, hence $[R_1,R_2]=0$ pointwise. The quartic first variation then vanishes, leaving the sigma-model equation $\partial_iR_i=0$. The right-current [Maurer-Cartan equation](maurer-cartan-equation.md) gives $\partial_1R_2-\partial_2R_1=[R_1,R_2]=0$. Each current component is therefore harmonic on the plane and square-integrable. The mean-value estimate on expanding disks makes each component zero, so $U$ is constant. This excludes smooth finite-energy planar static solutions of this potential-free SU(2) model, without misapplying the same conclusion to a pure curved-target sigma model.
