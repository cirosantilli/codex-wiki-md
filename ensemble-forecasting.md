# Ensemble forecasting

↑ **Parent:** [Weather forecasting](weather-forecasting.md)

An ensemble runs multiple forecasts with perturbed initial states, model parameters or physical formulations to represent uncertainty. Its distribution can indicate probabilities and sensitivity, but finite sampling or shared model errors can make the ensemble underdispersive. Growing initial perturbations can be selected using [right singular vectors](right-singular-vector.md) of a finite-time propagator.
