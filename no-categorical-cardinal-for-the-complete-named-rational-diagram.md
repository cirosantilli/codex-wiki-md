# No categorical cardinal for the complete named rational diagram

↑ **Parent:** [Categorical theory](categorical-theory.md)

For any infinite cardinal $\kappa$, insert a dense order without endpoints of size $\kappa$ into an irrational cut of the named rationals. Compare it with an order of the same size having a dense tail above every named rational. Both [models](model-of-a-first-order-theory.md) satisfy the complete named rational diagram by [quantifier elimination](quantifier-elimination.md), but only the second realizes the type of being above every named rational. This is an [isomorphism](structure-isomorphism.md) invariant over the constants, even though it is an infinite type rather than one defining sentence. Thus the diagram is categorical in no cardinal with a [model](model-of-a-first-order-theory.md).
