# Plane-wave string mode frequency

↑ **Parent:** [String sigma model in an isotropic plane wave](string-sigma-model-in-an-isotropic-plane-wave.md)

For a [closed string](closed-string.md) in a [string sigma model in an isotropic plane wave](string-sigma-model-in-an-isotropic-plane-wave.md), insert $e^{-i\omega_n\tau+2\pi in\sigma/L}$ into the transverse [wave equation](wave-equation-split.md). Periodicity requires integer $n$, giving the displayed [dispersion relation](dispersion-relation.md). The zero spatial mode is an oscillator of frequency $|m\kappa|$; when this mass vanishes it becomes a free particle mode and needs the position-plus-linear-time expansion.
