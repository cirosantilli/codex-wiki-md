# Hash code

↑ **Parent:** [Hash function](hash-function.md)

A bounded value used to organize entries in a [hash table](hash-table.md). An equality-based collection requires equal keys to have equal hash codes, while unequal keys may collide. A [Java](java-programming-language.md) `hashCode()` override must therefore use information invariant under the chosen [value equality](value-equality.md). Hashing internal subdivisions is invalid when those subdivisions are deliberately ignored by equality.[equals(Object) and hashCode() contracts](java-8-object-api-documentation.md)
