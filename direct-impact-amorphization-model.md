# Direct-impact amorphization model

↑ **Parent:** [Radiation-induced amorphization](radiation-induced-amorphization.md)

A random-overlap model in which each independent [radioactive decay](radioactive-decay.md) damages a fixed volume. At constant event rate density $R$ and damaged volume $v$, the surviving crystalline fraction is $e^{-Rvt}$ and the amorphous fraction is $1-e^{-Rvt}$.
