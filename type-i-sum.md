# Type I sum

↑ **Parent:** [Bilinear sum](bilinear-sum.md)

A Type I sum in [analytic number theory](analytic-number-theory-split.md) has the form $\sum_{d\leq U}a_d\sum_{m\in I_d}f(dm)$, with a short weighted variable and a relatively long inner sum whose coefficients are simple. The [Vaughan identity](vaughan-s-identity.md) produces these sums when the [Möbius function](mobius-function.md) is truncated.
