# Indicator variable

↑ **Parent:** [Categorical variable](categorical-variable.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Indicator_variable)

An indicator variable of an event $A$ is one on $A$ and zero outside $A$. Indicator columns encode categorical levels in a [design matrix](design-matrix.md).
