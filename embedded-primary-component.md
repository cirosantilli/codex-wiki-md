# Embedded primary component

↑ **Parent:** [Minimal primary decomposition](minimal-primary-decomposition.md)

A component in a [minimal primary decomposition](minimal-primary-decomposition.md) is embedded if its [radical of an ideal](radical-of-an-ideal.md) strictly contains another radical occurring in that decomposition. Such components need not be unique. For example,

$$
(x^2,xy)=(x)\cap(x^2,y)=(x)\cap(x^2,y-x)
$$

in $k[x,y]$ gives different $(x,y)$-[primary ideals](primary-ideal.md) as embedded components, with the same isolated component $(x)$.
