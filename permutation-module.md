# Permutation module

↑ **Parent:** [Permutation representation](permutation-representation.md)

For a finite [group action](group-action.md) on a finite set $X$, $R[X]$ is the free $R$-module with basis $X$, with the group permuting that basis. For a transitive set $G/H$ it is $\operatorname{Ind}_H^G R$. Disjoint unions of sets give [direct sums](direct-sum.md) of permutation modules.
