# Sidon set

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sidon_set)

A Sidon set in an [abelian group](abelian-group.md) is a subset $A$ for which an equality $a+b=c+d$ with $a,b,c,d\in A$ forces the unordered pairs $\{a,b\}$ and $\{c,d\}$ to be equal. Equivalently, the ordered nonzero differences $a-b$ with $a\ne b$ are all distinct.
