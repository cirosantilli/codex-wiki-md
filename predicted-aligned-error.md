# Predicted aligned error

↑ **Parent:** [AlphaFold](alphafold.md)

Expected positional error at one residue after predicted and true structures are aligned on another residue. Low within-domain values with high between-domain values support more confident internal geometry than relative domain placement. PAE is not a physical residue–residue distance and need not be symmetric.[Formal definition and interpretation of inter-domain confidence](pae-a-measure-of-global-confidence-in-alphafold2-predictions-by-embl-ebi.md)
