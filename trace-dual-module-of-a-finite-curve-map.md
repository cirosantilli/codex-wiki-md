# Trace-dual module of a finite curve map

↑ **Parent:** [Finite morphism](finite-morphism.md)

For a finite generically separable morphism between [smooth projective curves](smooth-projective-curve.md), the [field trace](field-trace.md) on [rational differentials](rational-differential-on-an-algebraic-curve.md) identifies the differential sheaf with the trace-dual module. Locally, for $A=k[[s]]\subset B=k[[u]]$ with $s=f(u)$, the trace-dual fractional ideal is $f'(u)^{-1}B$. Multiplying it by $ds=f'(u)du$ gives $Bdu$. For a monogenic finite extension with monic polynomial $P$, the identity $\operatorname{Tr}(g(u)/P'(u))=[T^{e-1}](g(T)\bmod P(T))$ proves the dual-module formula: the top-coefficient pairing on the basis $1,u,\ldots,u^{e-1}$ has invertible antitriangular matrix. Tensoring locally with an [invertible sheaf](line-bundle.md) yields $\pi_*(\mathcal M^\vee\otimes\Omega^1_C)\cong\mathcal H om(\pi_*\mathcal M,\Omega^1_D)$.
