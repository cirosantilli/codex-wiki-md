# Odd-extension solution for a semi-infinite fixed string

↑ **Parent:** [Wave equation on a string](wave-equation-on-a-string.md)

For zero initial [velocity](velocity.md) and initial [displacement](displacement.md) $h(x)$ on $x\geq0$ with $h(0)=0$, let $H$ be its [odd extension](odd-extension.md) to the real line. The displayed [D'Alembert's formula](d-alembert-s-formula.md) solves the [wave equation](wave-equation-split.md) with $y(0,t)=0$, since $H(-ct)+H(ct)=0$. A pulse travelling toward the endpoint reflects with reversed [displacement](displacement.md). For piecewise linear data the equation holds classically between moving corners and in the sense of [weak derivatives](weak-derivative.md) globally.
