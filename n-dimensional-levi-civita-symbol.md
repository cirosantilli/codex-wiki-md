# N-dimensional Levi-Civita symbol

↑ **Parent:** [Levi-Civita symbol](levi-civita-symbol.md)

For indices in $\{1,\ldots,n\}$, this [Levi-Civita symbol](levi-civita-symbol.md) is zero when any indices repeat, and otherwise is the [sign of a permutation](sign-of-a-permutation.md) taking $(1,\ldots,n)$ to $(i_1,\ldots,i_n)$. Thus $\epsilon_{1\cdots n}=1$ and exchanging any two index slots changes the sign. It expresses a [determinant](determinant.md) as $\det M=\epsilon_{i_1\cdots i_n}M_{i_1,1}\cdots M_{i_n,n}$ with repeated indices summed. Exactly $n!$ components are nonzero, so $\sum\epsilon_{i_1\cdots i_n}^2=n!$.
