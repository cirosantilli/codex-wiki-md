# Successor-state axiom

↑ **Parent:** [Classical planning](classical-planning.md)

A logical equivalence characterizing exactly when a [planning fluent](planning-fluent.md) is true after one step. Here $\operatorname{Add}_F$ and $\operatorname{Delete}_F$ are disjunctions of selected actions with the respective effects, under a suitable action-conflict policy. The persistence term excludes spontaneous changes and captures the relevant [frame axiom](frame-axiom.md). An implication from add effects alone would not constrain all other state changes.
