# Exactly one infinite equivalence class is not first-order axiomatizable

↑ **Parent:** [Compactness theorem](compactness-theorem.md)

Suppose a [first-order theory](first-order-theory.md) characterized [equivalence relations](equivalence-relation.md) with exactly one infinite class. Name two inequivalent points and require each named class to have at least $n$ elements for every positive [integer](integer-split.md) $n$. Every finite [subset](subset.md) is satisfied with one infinite class and a sufficiently large finite class. [Compactness theorem](compactness-theorem.md) would produce a [first-order model](model-of-a-first-order-theory.md) with two infinite classes, a [contradiction](contradiction.md).
