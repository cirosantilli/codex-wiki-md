# Finite-measure set

↑ **Parent:** [Finite measure](finite-measure.md)

A finite-measure set is a [measurable set](measurable-set.md) on which the ambient [measure](measure.md) is finite. Restricting to such a set makes its [indicator function](indicator-function.md) belong to every [Lp space](lp-space.md) with finite exponent, enabling local [Radon-Nikodym theorem](radon-nikodym-theorem.md) arguments even when the whole [measure space](measure-space.md) is not sigma-finite.
