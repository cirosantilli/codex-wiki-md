# Image processing

↑ **Parent:** [Computer science](computer-science-split.md)

[Image processing](image-processing.md) transforms recorded [image signal](image-signal.md) data to remove noise, recover detail or extract structure. [Variational image processing](variational-image-processing.md) describes desired reconstructions through energies, while [diffusion image processing](diffusion-image-processing.md) describes filtering through evolution equations.
