# Computable binary tree

↑ **Parent:** [Binary tree of finite strings](binary-tree-of-finite-strings.md)

A [binary tree of finite strings](binary-tree-of-finite-strings.md) is computable when membership of a finite [binary string](binary-string.md) is decidable. An infinite computable tree need not have any computable infinite path. Removing all nodes without infinite extensions need not preserve decidability.
