# Teleportation as an identity channel on a reference

↑ **Parent:** [Quantum teleportation](quantum-teleportation.md)

Ideal corrected [quantum teleportation](quantum-teleportation.md) transfers an input system to the receiver while preserving its entire joint [density operator](density-matrix.md) with an arbitrary reference. Expand a joint [pure state](pure-state.md) as $\sum_j|j\rangle|r_j\rangle$. Every teleportation branch acts with the same known correction on each system basis vector and does nothing to the reference vectors; undoing that correction restores the complete sum. Linearity extends the result to mixed states. The sender's measured carrier no longer retains the original reference correlations.
