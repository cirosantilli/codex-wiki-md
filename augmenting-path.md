# Augmenting path

↑ **Parent:** [Residual network](residual-network.md)

An augmenting path is a source-to-sink path of positive capacities in the [residual network](residual-network.md). Increasing the flow by the smallest residual capacity on the path gives another feasible flow of strictly greater value.
