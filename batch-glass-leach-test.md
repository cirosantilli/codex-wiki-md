# Batch glass leach test

↑ **Parent:** [Waste-glass corrosion](waste-glass-corrosion.md)

A glass-durability test with a finite initially specified leachant inventory. Dissolved products, [pH](ph.md) and alteration layers evolve, so the test does not maintain the same conditions as continuous fresh-water flow.
