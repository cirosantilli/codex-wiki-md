# Inorder traversal

↑ **Parent:** [Binary tree](binary-tree.md)

An [inorder traversal](inorder-traversal.md) of a [binary tree](binary-tree.md) uses [recursion](recursion-computer-science.md) to visit the left [subtree](subtree.md), output the current [vertex](vertex-graph-theory.md), and visit the right [subtree](subtree.md); an empty [subtree](subtree.md) outputs nothing. This is a [depth-first traversal of a tree](depth-first-traversal-of-a-tree.md) with output between the two recursive calls. It produces sorted keys for a [binary search tree](binary-search-tree.md), but arbitrary labels in a [binary tree](binary-tree.md) need not appear in [total order](total-order.md).
