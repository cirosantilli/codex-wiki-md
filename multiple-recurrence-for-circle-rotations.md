# Multiple recurrence for circle rotations

↑ **Parent:** [Furstenberg multiple recurrence theorem](furstenberg-multiple-recurrence-theorem.md)

Every circle rotation has the [Furstenberg multiple recurrence theorem](furstenberg-multiple-recurrence-theorem.md) property for normalized [Lebesgue measure](lebesgue-measure.md). For a rational angle, use a period. For an irrational angle, choose a positive return time with angle close to zero; [translation continuity in L1 on the circle](translation-continuity-in-l1-on-the-circle.md) then makes finitely many translates of a given positive-measure set simultaneously close to that set, and the [union bound](boole-s-inequality.md) leaves a positive-measure intersection.
