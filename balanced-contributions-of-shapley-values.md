# Balanced contributions of Shapley values

↑ **Parent:** [Shapley value](shapley-value.md)

For a [coalitional game](transferable-utility-game.md), restriction to the remaining players preserves coalition values. Remove player $j$ from a uniformly random ordering when comparing player $i$'s [Shapley value](shapley-value.md). The marginal contribution changes only when $j$ precedes $i$. If $S$ is the set of other predecessors, the change is $v(S\cup\{i,j\})-v(S\cup\{i\})-v(S\cup\{j\})+v(S)$, with coefficient $(|S|+1)!(n-|S|-2)!/n!$. The same expression and coefficient arise after interchanging $i,j$, proving balanced contributions.
