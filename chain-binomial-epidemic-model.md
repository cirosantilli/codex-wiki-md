# Chain-binomial epidemic model

↑ **Parent:** [Stochastic SIR model](stochastic-sir-model.md)

A [chain-binomial epidemic model](chain-binomial-epidemic-model.md) uses discrete time, with conditionally independent [binomial distributions](binomial-distribution.md) for infection and recovery counts given the current compartments. It requires valid probability parameters; replacing $1-e^{-\beta I\delta t}$ by $\beta I\delta t$ is a small-step approximation.
