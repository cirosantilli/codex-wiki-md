# First integral for a variational integrand independent of the function value

↑ **Parent:** [Euler-Lagrange equation](euler-lagrange-equation.md)

If a smooth [functional](functional.md) has integrand $f(x,v)$ independent of the [function](function-split.md) value, a weak local minimizer satisfies the displayed first [integral](integral-split.md) [almost everywhere](almost-everywhere.md). Its [first variation](first-variation.md) gives $\int f_v(x,u')\varphi'=0$ for every compactly supported [test function](test-function.md). Thus the [distributional derivative](distributional-derivative.md) of $f_v(x,u')$ vanishes, making it constant on the interval. Equivalently, any smooth compactly supported [function](function-split.md) with [integral](integral-split.md) zero is the [derivative](derivative.md) of such a [test function](test-function.md), so the first-variation identity says that $f_v(x,u')$ agrees with a single constant against all tests. This reduces the [Euler-Lagrange equation](euler-lagrange-equation.md) from a second-order equation to an algebraic relation in $u'$.
