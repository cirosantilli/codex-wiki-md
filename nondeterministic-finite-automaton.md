# Nondeterministic finite automaton

↑ **Parent:** [Finite-state machine](finite-state-machine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nondeterministic_finite_automaton)

A nondeterministic finite automaton assigns a set of possible successor states to each state-symbol pair and accepts when at least one run ends in a final state.
