# Pointed set

↑ **Parent:** [Set](set-split.md)

A pointed set is a [set](set-split.md) $X$ with a distinguished element $x_0\in X$. A morphism of pointed sets is a [function](function-split.md) carrying the distinguished element to the distinguished element. The resulting [category of pointed sets](category-of-pointed-sets.md) has every singleton as a [zero object](zero-object.md).
