# Orthogonal matrix

↑ **Parent:** [Orthogonal group](orthogonal-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Orthogonal_matrix)

A real square matrix is orthogonal when $R^TR=I$, equivalently when its columns form an orthonormal basis.
