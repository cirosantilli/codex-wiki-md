# Completely multiplicative function

↑ **Parent:** [Multiplicative function](multiplicative-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Completely_multiplicative_function)

An arithmetic function $f$ is completely multiplicative when $f(mn)=f(m)f(n)$ for every pair of positive integers $m,n$, without a coprimality condition.
