# Completely multiplicative function

↑ **Parent:** [Multiplicative function](multiplicative-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Completely_multiplicative_function)

An [arithmetic function](arithmetic-function.md) $f$ is a [completely multiplicative function](completely-multiplicative-function.md) when $f(1)=1$ and $f(mn)=f(m)f(n)$ for every pair of [positive integers](positive-integer.md) $m,n$. In particular $f(p^a)=f(p)^a$ for every [prime number](prime-number.md) $p$ and every nonnegative exponent $a$. Both the [constant-one arithmetic function](constant-one-arithmetic-function.md) and the [identity arithmetic function](identity-arithmetic-function.md) are [completely multiplicative functions](completely-multiplicative-function.md): $\mathbf1(mn)=1=1\cdot1$ and $\operatorname{id}(mn)=mn=\operatorname{id}(m)\operatorname{id}(n)$. The [divisor function](divisor-function.md) fails this stronger condition at $m=n=2$.
