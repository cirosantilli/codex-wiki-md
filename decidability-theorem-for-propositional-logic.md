# Decidability theorem for propositional logic

↑ **Parent:** [Propositional logic](propositional-logic.md)

There is an algorithm deciding whether any finite propositional formula is a theorem. A formula contains only finitely many atoms, so a finite [truth table](truth-table.md) decides whether it is valid; the [completeness theorem for propositional logic](completeness-theorem-for-propositional-logic.md) identifies validity with provability.

The finite valuation space of [propositional logic](propositional-logic.md) gives the decision procedure; this theorem is a property of that logic rather than an alternative name for it.
