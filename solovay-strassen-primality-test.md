# Solovay-Strassen primality test

↑ **Parent:** [Euler witness](euler-witness.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Solovay–Strassen_primality_test)

The Solovay-Strassen primality test samples unit bases and rejects an odd candidate as composite when it finds an [Euler witness](euler-witness.md). Every prime passes every base by [Euler's criterion](euler-s-criterion.md), while an odd composite passes a random base with probability at most one half.
