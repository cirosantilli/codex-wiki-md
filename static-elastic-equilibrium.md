# Static elastic equilibrium

↑ **Parent:** [Elasticity (physics)](elasticity-physics.md)

A symmetric [stress tensor](cauchy-stress-tensor.md) is in [static elastic equilibrium](static-elastic-equilibrium.md) when its divergence balances the prescribed [body force](body-force.md). Its boundary [traction](traction.md) is $t_i=\sigma_{ij}n_j$. With zero [body force](body-force.md), [integration by parts](integration-by-parts.md) gives $\int_\Omega\sigma:\operatorname{sym}\nabla v=\int_{\partial\Omega}t\cdot v$. This is the weak [principle of virtual work](virtual-work.md) for a static elastic body.
