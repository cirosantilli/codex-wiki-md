# Quadratic-form criterion for a skew-symmetric matrix

↑ **Parent:** [Skew-symmetric matrix](skew-symmetric-matrix.md)

**Proof.** For a [skew-symmetric matrix](skew-symmetric-matrix.md), the scalar $x^\top Ax$ equals its [transpose](transpose.md) $x^\top A^\top x=-x^\top Ax$, so it vanishes. Conversely, substituting [standard basis](standard-basis.md) [vectors](vector.md) $e_i$ into the vanishing [quadratic form](quadratic-form-split.md) gives $a_{ii}=0$. Substituting $e_i+e_j$ gives $a_{ij}+a_{ji}=0$. Thus $A^\top=-A$. In particular, a real [quadratic form](quadratic-form-split.md) depends only on a [matrix](matrix.md)'s [symmetric part](symmetric-part-of-a-matrix.md).
