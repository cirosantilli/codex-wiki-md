# One-particle-irreducible correlation function

↑ **Parent:** [One-particle-irreducible Feynman diagram](one-particle-irreducible-feynman-diagram.md)

An $n$-point one-particle-irreducible correlation function is obtained by differentiating the [quantum effective action](effective-action.md) $n$ times. Its diagrammatic expansion contains the amputated one-particle-irreducible diagrams with $n$ external legs.
