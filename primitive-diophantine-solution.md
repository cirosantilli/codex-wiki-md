# Primitive Diophantine solution

↑ **Parent:** [Diophantine equation](diophantine-equation.md)

A primitive Diophantine solution is an integer tuple satisfying the equation whose coordinates have [greatest common divisor](greatest-common-divisor.md) one. For homogeneous equations, this removes common integer scale factors.
