# Classifying topos of linear orders

↑ **Parent:** [Classifying topos](classifying-topos.md)

With empty objects allowed, finite [totally ordered sets](totally-ordered-set.md) and all weak [order-preserving functions](order-preserving-function.md) give a presheaf classifier for weak total orders. Finite tuples in a model can locally be merged into a sorted tuple using finitely many totality disjunctions. Equalizing two maps between finite chains amounts to collapsing the convex intervals forced equal. These two constructions give the flatness conditions without assuming decidable equality.
