# Accumulation below an unattained supremum

↑ **Parent:** [Supremum](supremum.md)

If a nonempty real set $A$ has finite [supremum](supremum.md) $s$ and $s\notin A$, then every interval $(s-\varepsilon,s)$ contains infinitely many elements of $A$. Otherwise its finitely many elements have a largest value $m<s$; all remaining elements are at most $s-\varepsilon$, making $\max(m,s-\varepsilon)<s$ an [upper bound](upper-bound-in-a-partially-ordered-set.md). The interval cannot be empty either, by the defining approximation property of a [supremum](supremum.md). Thus failure to attain a finite [supremum](supremum.md) forces accumulation from below.
