# Full functor

↑ **Parent:** [Functor](functor.md)

A [functor](functor.md) $F:\mathcal C\to\mathcal D$ is full when each function $\mathcal C(A,B)\to\mathcal D(FA,FB)$ is surjective. It is a [faithful functor](faithful-functor.md) when each is injective. A [full and faithful functor](full-and-faithful-functor.md) identifies its source, up to equivalence, with a [full subcategory](full-subcategory.md) of the target. Fullness only concerns morphisms between image objects; it does not require every target object to lie in the image.
