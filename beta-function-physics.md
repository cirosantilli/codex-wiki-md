# Beta function (physics)

↑ **Parent:** [Running coupling](running-coupling.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Beta_function_(physics))

The beta function of a coupling $g$ is

$$
\beta(g)=\mu\frac{dg}{d\mu}=\frac{dg}{d\log\mu}.
$$

It describes how the [running coupling](running-coupling.md) changes when the [renormalization scale](renormalization-scale.md) changes.
