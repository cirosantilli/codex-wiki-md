# Scale height

↑ **Parent:** [Hydrostatic equilibrium](hydrostatic-equilibrium.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Scale_height)

A scale height is a characteristic distance over which a vertically stratified physical quantity varies. For a decreasing exponential $q(z)=q_0e^{-z/H}$, it is $H=-(d\log q/dz)^{-1}$. The local [pressure scale height](pressure-scale-height.md) applies this logarithmic measure to [pressure](pressure.md); density and pressure scale heights need not coincide when [temperature](temperature.md) varies.
