# Autonomic emotion classification

↑ **Parent:** [Psychophysiology](psychophysiology.md)

[Statistical classification](statistical-classification.md) of [emotion](emotion.md) categories using measurements of the [autonomic nervous system](autonomic-nervous-system.md). It requires an independently justified target label, appropriate [cross-validation](cross-validation.md), and evaluation in the population and context where the [classifier](classifier.md) will be used. Predictive success does not imply that every instance of a category has one invariant physiological pattern.
