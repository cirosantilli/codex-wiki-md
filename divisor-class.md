# Divisor class

↑ **Parent:** [Linear equivalence of divisors](linear-equivalence-of-divisors.md)

A divisor class is an equivalence class of divisors under [linear equivalence](linear-equivalence-of-divisors.md). Degree descends to divisor classes because every principal divisor has degree zero.
