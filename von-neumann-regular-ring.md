# Von Neumann regular ring

↑ **Parent:** [Ring](ring.md)

A ring is von Neumann regular if every element $a$ has an element $b$ with $a=aba$. In a [commutative ring](commutative-ring.md), this is $a=a^2b$. An arbitrary [direct product of rings](direct-product-of-rings.md) whose factors are [fields](field.md) has this property by taking inverses in each nonzero coordinate. Every [localization at a prime ideal](localization-at-a-prime-ideal.md) of a commutative von Neumann regular ring is a [field](field.md).
