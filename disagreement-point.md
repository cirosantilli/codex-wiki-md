# Disagreement point

↑ **Parent:** [Nash bargaining problem](nash-bargaining-problem.md)

The disagreement point specifies each player's payoff if bargaining fails. It supplies the baseline from which the [Nash product](nash-product.md) measures gains. In a game-based example it may be set to the vector of [security level payoffs](security-level-payoff.md); this choice must be recomputed when the underlying payoff matrices change.
