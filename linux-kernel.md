# Linux kernel

↑ **Parent:** [Kernel (operating system)](kernel-operating-system.md)

A concrete [operating-system kernel](kernel-operating-system.md) whose documented [file system](file-system-split.md) interface distinguishes a name-associated `dentry`, an object-associated `inode`, and a `file` object created for an open instance. An [inode](inode.md) can have several name-associated objects. This illustrates the distinction among [directory entries](directory-entry.md), [inodes](inode.md) and [open file descriptions](open-file-description.md); it does not imply identical structures in every [operating system](operating-system-split.md). [Linux kernel documentation, Overview of the Linux Virtual File System: directory entries, inode objects and file objects](https://docs.kernel.org/filesystems/vfs.html)
