# Square-integrable function

↑ **Parent:** [Lp space](lp-space.md)

A [measurable function](measurable-function.md) is square-integrable when the [integral](integral.md) of its squared absolute value is finite. Its equivalence class belongs to the [L2 space](l2-space-is-a-hilbert-space.md); on a [probability space](probability-space.md), this means a finite second [moment](moment.md).
