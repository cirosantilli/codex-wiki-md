# Phase-sensitive test of d-wave pairing

↑ **Parent:** [Phase-sensitive superconducting gap experiment](phase-sensitive-superconducting-gap-experiment.md)

Compare superconducting phase information from different crystal directions rather than only measuring the gap magnitude. Orthogonal-face junctions and a [tricrystal half-flux experiment](tricrystal-half-flux-experiment.md) can test sign changes of a candidate d-wave gap. Junction properties, trapped flux and loop inductance must be controlled; a measured half-flux signal needs its actual device model.
