# Summing amplifier

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

An inverting [operational amplifier](operational-amplifier.md) can combine currents from several input [resistors](resistor.md) at one [virtual ground](virtual-ground.md). [Kirchhoff's current law](kirchhoff-node-law.md) and negligible amplifier input current give the displayed weighted sum. Replacing the feedback resistance by a [capacitor](capacitor.md) gives a weighted [op amp integrator](op-amp-integrator.md). The formulas assume stable [negative feedback](negative-feedback.md) and operation within the amplifier's linear output range.
