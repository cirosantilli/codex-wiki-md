# Fundamental cycle

↑ **Parent:** [Spanning tree](spanning-tree.md)

Adding a non-tree edge to a [spanning tree](spanning-tree.md) creates exactly one [graph cycle](cycle-in-a-graph.md), its [fundamental cycle](fundamental-cycle.md). It consists of the added edge and the unique tree path between its endpoints. In the [network simplex algorithm](network-simplex-algorithm.md), modifying flow around this cycle preserves [flow conservation](flow-conservation.md).
