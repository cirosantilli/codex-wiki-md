# Option delta

↑ **Parent:** [Greeks (finance)](greeks-finance.md)

The option delta is the derivative of an option value with respect to the underlying asset price. In a smooth complete diffusion model, it is also the number of underlying units in the replicating [delta hedge](delta-hedge.md).
