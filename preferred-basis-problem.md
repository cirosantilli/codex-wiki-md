# Preferred-basis problem

↑ **Parent:** [Measurement problem](measurement-problem.md)

The problem of explaining which basis represents stable measurement records. A maximally entangled [quantum premeasurement](quantum-premeasurement.md) state can have several equally weighted [Schmidt decompositions](schmidt-decomposition.md). Choosing a different decomposition does not alter that pure state, but declaring a projection in a different basis generally changes the resulting mixture. [Environment-induced pointer-basis selection](environment-induced-pointer-basis-selection.md) supplies a dynamical account of robust records, while leaving the further question of a single realized outcome distinct.
