# CSP alphabetized parallel composition

↑ **Parent:** [CSP parallel composition](csp-parallel-composition.md)

The alphabets assigned to participants determine their shared [CSP events](csp-event.md). An event in both assigned alphabets requires both participants; one assigned only to a single participant advances that participant. Replicated composition synchronizes all participants whose assigned alphabets contain the event.
