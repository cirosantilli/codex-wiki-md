# Running-maximum boundary for a lookback option

↑ **Parent:** [Lookback option](lookback-option.md)

For running maximum $M_t=\max_{u\le t}S_u$, a smooth price $v(t,S_t,M_t)$ has an [Itô formula](ito-s-lemma.md) term $v_m\,dM_t$. The maximum increases only when $S_t=M_t$. A [self-financing portfolio](self-financing-portfolio.md) in stock and bank account cannot supply an extra singular finite-variation term there, so the smooth price must satisfy the displayed boundary condition. Inside $0<s<m$, it obeys the [Black-Scholes equation](black-scholes-equation.md) in the price variable. The condition need only hold before maturity, where terminal corners may destroy differentiability.
