# Real matrix

↑ **Parent:** [Matrix](matrix.md)

A [real matrix](real-matrix.md) is a [matrix](matrix.md) whose entries are [real numbers](real-number.md). The [vector space](vector-space-split.md) of $m\times n$ [real matrices](real-matrix.md) is denoted $M_{m,n}(\mathbb R)$.
