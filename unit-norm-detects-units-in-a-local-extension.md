# Unit norm detects units in a local extension

↑ **Parent:** [Field norm](field-norm.md)

For a finite extension of [local fields](local-field.md) with normalized [discrete valuations](discrete-valuation.md), the [field norm](field-norm.md) satisfies the displayed equality. The extended [absolute values on a field](absolute-value-algebra.md) of all conjugates agree, so $|N(x)|_K=|x|_L^{[L:K]}$. Using $[L:K]=e(L/K)f(L/K)$ and $v_L|_K=e(L/K)v_K$ gives the equality. Thus the [field norm](field-norm.md) is a unit precisely when the original element is a unit.
