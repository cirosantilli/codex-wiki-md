# Residual mass-shell action in light-cone string gauge

↑ **Parent:** [Light-cone gauge in string theory](light-cone-gauge-in-string-theory.md)

Fixing nonzero longitudinal oscillators leaves the center-of-mass symplectic term, transverse oscillator terms, and a zero-mode multiplier imposing the [mass-shell condition](string-mass-shell-condition.md). On a patch with $p^+\ne0$, further choosing $x^+$ as time solves that [constraint](constraint-mechanics.md) for $p^-=[p_\perp^2+(N-a)/\alpha']/(2p^+)$. This distinguishes partial oscillator gauge fixing from the subsequent time choice.
