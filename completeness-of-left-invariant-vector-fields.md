# Completeness of left-invariant vector fields

↑ **Parent:** [Left-invariant vector field](left-invariant-vector-field.md)

Every smooth [left-invariant vector field](left-invariant-vector-field.md) on a [Lie group](lie-group.md) is a [complete vector field](complete-vector-field.md). Translate a local [integral curve of a vector field](integral-curve-of-a-vector-field.md) through the identity to every other point. The same positive local existence interval works at every initial point, so no maximal [integral curve of a vector field](integral-curve-of-a-vector-field.md) can have a finite endpoint. Uniqueness then makes the curve through the identity a [one-parameter subgroup](one-parameter-subgroup.md).
