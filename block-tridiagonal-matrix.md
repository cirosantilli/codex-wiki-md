# Block tridiagonal matrix

↑ **Parent:** [Block matrix](block-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Block_tridiagonal_matrix)

A block tridiagonal matrix has nonzero blocks only on its main block diagonal and the two adjacent block diagonals. It is the block analogue of a [tridiagonal matrix](tridiagonal-matrix.md).
