# Stack bottom marker

↑ **Parent:** [Stack (data structure)](stack-data-structure.md)

A designated [stack](stack-data-structure.md) symbol marking its bottom. A [pushdown automaton](pushdown-automaton.md) can use it to detect that all symbols above the bottom have been removed, then enter a final control state. The marker must be distinct from the other [stack alphabet](stack-alphabet.md) symbols.
