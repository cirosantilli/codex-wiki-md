# Core helium burning

↑ **Parent:** [Stellar nuclear fusion](stellar-nuclear-fusion.md)

Core helium burning begins when a hydrogen-exhausted stellar core becomes hot enough for the [Triple-alpha process](triple-alpha-process.md). Subsequent alpha capture on carbon produces oxygen, leaving a carbon-oxygen core after central helium exhaustion.
