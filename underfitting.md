# Underfitting

↑ **Parent:** [Overfitting](overfitting.md)

Underfitting occurs when a prediction rule fails to capture useful structure in the target relation. A straight-line [polynomial regression](polynomial-regression.md) fitted to a genuinely quadratic noiseless target illustrates a representational limitation. Poor prediction alone does not identify the cause: compare candidate rules using [cross-validation](cross-validation.md) or a [validation set](validation-set.md), while keeping the final [test set](test-set.md) reserved for assessment.
