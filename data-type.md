# Data type

↑ **Parent:** [Type system](type-system.md)

A classification of program values together with the operations permitted on them. An [algebraic data type](algebraic-data-type.md) describes values by [data constructors](data-constructor.md); a [function type](function-type.md) describes acceptable arguments and produced results.
