# WinBUGS

↑ **Parent:** [Gibbs sampler](gibbs-sampler.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/WinBUGS)

Software for [Bayesian inference](bayesian-statistics.md) through [Markov chain Monte Carlo](markov-chain-monte-carlo.md) in directed statistical models. Its model language uses `dnorm(mean, precision)`, so the second argument is inverse [variance](variance-split.md); `dcat` indexes a supplied probability vector, and `dbern` introduces a binary [latent variable](latent-variable.md). The model is declarative, so the order of deterministic node definitions does not impose procedural evaluation order.
