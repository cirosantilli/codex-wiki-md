# Fully polynomial randomized approximation scheme

↑ **Parent:** [Approximation algorithm](approximation-algorithm.md)

For a nonnegative counting quantity $Z$, an FPRAS is a [randomized algorithm](randomized-algorithm.md) with the displayed guarantee, running in time polynomial in encoded input length, $\varepsilon^{-1}$ and $\log(\delta^{-1})$. The usual constant-success definition is equivalent by independent repetition and a median. This counting notion differs from a deterministic [fully polynomial-time approximation scheme](fully-polynomial-time-approximation-scheme.md) for optimization.
