# Extreme point

↑ **Parent:** [Convex set](convex-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Extreme_point)

An extreme point of a convex set $C$ is a point $x\in C$ for which

$$
x=(1-t)y+tz,\qquad y,z\in C,\quad0<t<1
$$

implies $x=y=z$.
