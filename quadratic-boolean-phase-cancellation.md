# Quadratic Boolean phase cancellation

↑ **Parent:** [Phase kickback](phase-kickback.md)

For a two-variable [Boolean quantum oracle](boolean-quantum-oracle.md), [quantum phase kickback](phase-kickback.md) produces the phase $(-1)^{axy+bx+cy+d}$ on $|xy\rangle$. If the quadratic coefficient $a$ is known, apply the [Controlled-Z gate](controlled-z-gate.md) to the power $a$: its phase $(-1)^{axy}$ cancels the quadratic term. A [Walsh-Hadamard transform](walsh-hadamard-transform.md) then maps the remaining phase state to $(-1)^d|bc\rangle$. The constant term is only a [global phase](global-phase.md), and both linear coefficients are read in one [quantum measurement in the computational basis](quantum-measurement-in-the-computational-basis.md).
