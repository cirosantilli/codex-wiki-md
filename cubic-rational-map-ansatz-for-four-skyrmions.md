# Cubic rational-map ansatz for four Skyrmions

↑ **Parent:** [Rational map approximation for Skyrmions](rational-map-approximation-for-skyrmions.md)

This degree-four [rational map](rational-map-complex-analysis.md) obeys $R(iz)=1/R(z)$ and $R((iz+1)/(1-iz))=e^{2\pi i/3}R(z)$. These pair the generators of the [rotational symmetry group of a cube](rotational-symmetry-group-of-a-cube.md) with target rotations, giving combined spatial-isospin symmetry in the [Skyrme model](skyrme-model.md). Its spatial half-turn kernel is a [Klein four-group](klein-four-group.md). The map gives a [cubic four-Skyrmion](cubic-four-skyrmion.md) approximation; preserving only its Wronskian zero set does not guarantee the same rotational symmetry.
