# Bell-LaPadula star property

↑ **Parent:** [Bell-LaPadula model](bell-lapadula-model.md)

The [Bell-LaPadula model](bell-lapadula-model.md) restriction that a subject operating at its current level reads only at or below that level and writes only at or above it. An access combining both operations therefore requires equal levels. Safe changes of current level must also control retained information.
