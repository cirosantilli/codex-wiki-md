# Linear partial differential operator

↑ **Parent:** [Partial differential equation](partial-differential-equation-split.md)

A linear partial differential operator sends a function to a linear combination of its partial derivatives. If its coefficients are constant, the [Fourier transform of a derivative](fourier-transform-of-a-derivative.md) turns it into multiplication by its polynomial symbol $P(\xi)$.
