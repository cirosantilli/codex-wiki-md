# Weighted binary-sequence metric

↑ **Parent:** [Cantor space](cantor-space.md)

On $\{0,1\}^{\mathbb N}$ this sum is a [metric](metric.md), since each summand obeys the [triangle inequality](triangle-inequality.md) and a zero sum forces coordinatewise equality. A prefix [cylinder set](cylinder-set.md) fixing the first $n$ coordinates contains the [open ball](open-ball.md) of radius $2^{-n}$ about each of its points and has [diameter](diameter.md) at most $2^{-n}$. These bounds show that the [metric topology](metric-topology.md) equals the prefix [cylinder set](cylinder-set.md) topology, the usual [Cantor space](cantor-space.md) topology.
