# Private key

↑ **Parent:** [Public-key cryptography](public-key-cryptography.md)

The secret member of a public-key cryptographic key pair, used for decryption or signing according to the scheme. In the [RSA cryptosystem](rsa-cryptosystem.md) the private exponent is not interchangeable with a security proof for textbook signing.
