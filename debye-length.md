# Debye length

↑ **Parent:** [Plasma screening](plasma-screening.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Debye_length)

For mobile thermal [electrons](electron.md) with a fixed neutralizing background, the Debye length is the characteristic distance over which [plasma screening](plasma-screening.md) suppresses an electrostatic perturbation. Linearizing the Boltzmann density response and using [Poisson's equation](poisson-s-equation.md) gives the displayed scale. Other mobile species contribute additively to $\lambda_D^{-2}$ through $n_s q_s^2/(\epsilon_0k_BT_s)$.
