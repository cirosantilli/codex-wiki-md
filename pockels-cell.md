# Pockels cell

↑ **Parent:** [Optical instrument](optical-instrument-split.md)

An electro-optic element whose birefringent retardance changes approximately linearly with applied voltage. Combined with a [polarizer](polarizer.md), it converts voltage-controlled [polarization](polarization-waves.md) changes into variable optical loss for active [Q-switching](q-switching.md).
