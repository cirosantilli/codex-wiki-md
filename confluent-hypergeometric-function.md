# Confluent hypergeometric function

↑ **Parent:** [Kummer differential equation](kummer-differential-equation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Confluent_hypergeometric_function)

Confluent hypergeometric functions solve the [Kummer differential equation](kummer-differential-equation.md) $zy''+(b-z)y'-ay=0$. The regular solution is the [confluent hypergeometric function of the first kind](confluent-hypergeometric-function-of-the-first-kind.md); a second standard solution is conventionally denoted $U(a,b,z)$. The family arises by coalescing singular points of the [Gauss hypergeometric equation](gauss-hypergeometric-equation.md).
