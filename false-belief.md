# False belief

↑ **Parent:** [Belief](belief.md)

A [belief](belief.md) whose content differs from the actual state of affairs. A [false belief](false-belief.md) is distinct from ignorance: an ignorant agent need not have any particular mistaken representation. [False-belief understanding](false-belief-understanding.md) is the capacity to represent and reason about this difference.
