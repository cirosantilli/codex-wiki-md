# Rotation about the x-axis

↑ **Parent:** [Rotation gate](rotation-gate.md)

The [rotation gate](rotation-gate.md) about the [Pauli X gate](pauli-x-gate.md) axis commutes with $X$. The [J gate](j-gate-in-measurement-based-quantum-computation.md) convention gives $J(\alpha)J(0)=H\operatorname{diag}(1,e^{i\alpha})H=e^{i\alpha/2}R_x(\alpha)$, differing from the standard axis rotation only by [global phase](global-phase.md).
