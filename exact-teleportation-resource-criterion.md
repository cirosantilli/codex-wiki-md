# Exact teleportation resource criterion

↑ **Parent:** [Quantum teleportation](quantum-teleportation.md)

A shared resource enables deterministic exact transmission of an arbitrary unknown [qubit](qubit.md) using only [local operations and classical communication](local-operations-and-classical-communication.md) if and only if it can produce a shared [Bell pair](bell-pair.md) deterministically by such operations. Sufficiency follows from [quantum teleportation](quantum-teleportation.md). For necessity, prepare a Bell pair locally at the sender and apply the purported transmission protocol to one half: exact identity-channel action leaves a shared Bell pair between the retained reference and the receiver. A separable shared resource cannot satisfy this condition because local operations and classical communication preserve separability.
