# Positively homogeneous function (degree one)

↑ **Parent:** [Homogeneous function](homogeneous-function.md)

A [function](function-split.md) on a cone is positively homogeneous of degree one when $f(tX)=t f(X)$ for every $t>0$. If such a function is [concave](concave-function.md), then

$$
f(X+tY)\geq f(X)+t f(Y),
$$

because homogeneity rewrites the left-hand side as $(1+t)f((X+tY)/(1+t))$ before [concavity](concave-function.md) is applied.
