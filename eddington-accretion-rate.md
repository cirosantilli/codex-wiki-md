# Eddington accretion rate

↑ **Parent:** [Eddington ratio](eddington-ratio.md)

An Eddington accretion rate converts the [Eddington luminosity](eddington-luminosity.md) into a mass supply rate using an adopted reference efficiency $\eta_0$: $\dot M_{\rm Edd}=L_{\rm Edd}/(\eta_0c^2)$. The common choice $\eta_0=0.1$ gives $\dot M_{\rm Edd}=10L_{\rm Edd}/c^2$.
