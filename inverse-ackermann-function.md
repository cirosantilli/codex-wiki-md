# Inverse Ackermann function

↑ **Parent:** [Ackermann function](ackermann-function.md)

For the displayed [Ackermann function](ackermann-function.md) convention, one possible inverse-growth scale is $\alpha(n)=\min\{m\geq1:A(m,m)\geq n\}$ for positive [integers](integer-split.md) $n$. It gives $\alpha(n)=1$ through $3$, $2$ from $4$ through $7$, and $3$ from $8$ through $61$. Several [inverse Ackermann function](inverse-ackermann-function.md) conventions occur in [algorithm](algorithm-split.md) analysis; changing convention can shift these small values without changing the very slow growth relevant to the [disjoint-set data structure](disjoint-set-data-structure.md). This inverse-growth definition does not invert a two-variable [function](function-split.md) as an ordinary one-variable [inverse function](inverse-function.md).
