# Reverse inference

↑ **Parent:** [Cognitive neuroscience](cognitive-neuroscience.md)

Inferring a particular mental process from a neural response associated with it. The inference is weak when the same response occurs during many other processes; task contrasts, functional selectivity and intervention evidence can constrain alternatives.
