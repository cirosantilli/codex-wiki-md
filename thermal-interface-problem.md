# Thermal interface problem

↑ **Parent:** [Heat equation](heat-equation.md)

A [heat equation](heat-equation.md) problem in adjacent materials with separate [thermal conductivities](thermal-conductivity.md) and [volumetric heat capacities](volumetric-heat-capacity.md). Perfect [thermal contact](thermal-contact.md) imposes continuous [temperature](temperature-split.md) and continuous normal [heat flux](heat-flux-density.md) at the interface. Multiplying each material's [heat equation](heat-equation.md) by its [temperature](temperature-split.md) cancels the interface [boundary terms](boundary-term.md) in a weighted [energy estimate](energy-estimate.md).
