# Limit-reflecting functor

↑ **Parent:** [Functor](functor.md)

For a specified diagram shape, a [functor](functor.md) reflects [categorical limits](categorical-limit.md) when a [cone over a diagram](cone-over-a-diagram.md) is limiting whenever its image is limiting. This condition tests an existing [categorical cone](cone-over-a-diagram.md). It does not assert that every limiting [categorical cone](cone-over-a-diagram.md) in the codomain has a lift.
