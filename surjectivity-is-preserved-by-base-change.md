# Surjectivity is preserved by base change

↑ **Parent:** [Base change of a morphism of schemes](base-change-of-a-morphism-of-schemes.md)

If $X\to Y$ is a surjective [morphism of schemes](morphism-of-schemes.md), the projection $X\times_YY^{\prime}\to Y^{\prime}$ is surjective for every $Y^{\prime}\to Y$. For a point $y\prime$, choose a point $x$ over its base image and apply the [point-lifting property of a scheme fibre product](point-lifting-property-of-a-scheme-fibre-product.md). No flatness assumption is necessary.
