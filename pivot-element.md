# Pivot element

↑ **Parent:** [Gaussian elimination](gaussian-elimination.md)

A [pivot element](pivot-element.md) is the current diagonal entry used to eliminate entries below it in [Gaussian elimination](gaussian-elimination.md), after any row interchange. At step $k$ it is $a_{kk}^{(k-1)}$, where $A^{(k-1)}$ is the current reduced [matrix](matrix.md). Computing [elimination multipliers](elimination-multiplier.md) requires this entry to be nonzero. A zero [pivot element](pivot-element.md) can reflect an unsuitable row order even for an [invertible matrix](invertible-matrix.md), as [Pivoted LU decomposition](pivoted-lu-decomposition.md) illustrates.
