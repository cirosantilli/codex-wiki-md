# Resistive load line

↑ **Parent:** [Electrical load](electrical-load.md)

The straight terminal relation of a resistive [electrical load](electrical-load.md) satisfying [Ohm's law](ohm-s-law.md). Its intersection with the [Thévenin terminal response](thevenin-terminal-response.md) determines the shared terminal voltage and [electric current](electric-current.md).
