# Disjoint stationary subsets of omega-one

↑ **Parent:** [Ulam matrix on omega-one](ulam-matrix-on-omega-one.md)

There are $\aleph_1$ pairwise disjoint stationary subsets of the nonzero countable limit ordinals. In a [Ulam matrix on omega-one](ulam-matrix-on-omega-one.md), each row partitions a stationary tail into countably many cells, so some cell is stationary. One column contains stationary cells in uncountably many rows, and the column cells are disjoint. Unions indexed by different subsets of $\omega_1$ then differ on a stationary set.
