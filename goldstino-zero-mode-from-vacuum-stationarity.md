# Goldstino zero mode from vacuum stationarity

↑ **Parent:** [Goldstino](goldstino.md)

Stationarity of a canonical global [F-term scalar potential](f-term-scalar-potential.md) gives $\partial_iV=\sum_jW_{ij}\overline{W_j}=0$. If some $F_j=-\overline{W_j}$ is nonzero, this vector is in the [kernel](kernel-of-a-linear-map.md) of the [chiral-superfield fermion mass matrix](chiral-superfield-fermion-mass-matrix.md). It supplies the massless [goldstino](goldstino.md) direction. If every $F_j$ vanishes, this argument gives no broken-symmetry mode.
