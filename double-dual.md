# Double dual

↑ **Parent:** [Dual space](dual-space-split.md)

The algebraic double dual of a [vector space](vector-space-split.md) is the [dual space](dual-space-split.md) of its [algebraic dual](dual-space-split.md). An element assigns a [scalar](scalar.md) linearly to each [linear functional](linear-functional.md) on the original space. The [bidual evaluation map](bidual-evaluation-map.md) sends $v$ to the rule $\ell\mapsto\ell(v)$. It is a canonical [linear isomorphism](linear-isomorphism.md) in finite [dimension](dimension-vector-space.md), unlike an identification of $V$ with $V^*$, which generally requires an additional choice. For spaces with topology, using the [continuous dual space](continuous-dual-space-split.md) instead defines the topological bidual; that is a distinct construction in infinite [dimension](dimension-vector-space.md).
