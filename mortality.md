# Mortality

↑ **Parent:** [Biology](biology-split.md)

Mortality describes deaths in a defined population during a specified observation window. A cumulative death [probability](probability.md) is distinct from a death rate per person-time. Comparing treatments requires the same endpoint definition, time origin and ascertainment in both arms.
