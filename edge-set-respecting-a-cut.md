# Edge set respecting a cut

↑ **Parent:** [Cut (graph theory)](cut-graph-theory.md)

An [edge set](edge-set.md) respects a [cut of a graph](cut-graph-theory.md) when none of its [edges](edge-of-a-graph.md) crosses that cut. In the [minimum spanning tree cut property](minimum-spanning-tree-cut-property.md), this guarantees that exchanging a crossing tree edge cannot remove an edge already committed to the partial solution.
