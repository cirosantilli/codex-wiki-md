# Band matrix

↑ **Parent:** [Sparse matrix](sparse-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Band_matrix)

A [band matrix](band-matrix.md) has nonzero entries confined to a band around its main diagonal. The nonnegative integers $p,q$ in the displayed condition are its lower and upper bandwidths. A [tridiagonal matrix](tridiagonal-matrix.md) has $p=q=1$. Storing only the band reduces memory use; [banded Gaussian elimination](banded-gaussian-elimination.md) can exploit the same structure when the pivoting assumptions permit it.
