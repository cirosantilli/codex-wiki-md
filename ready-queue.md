# Ready queue

↑ **Parent:** [Process scheduling](process-scheduling.md)

A collection of runnable [operating-system processes](process-computing.md) or [software threads](thread-computing.md) waiting for a [CPU](central-processing-unit.md). A running task is not waiting in the [ready queue](ready-queue.md), and a task waiting for [input-output](input-output.md) is not runnable. [FCFS](first-come-first-served.md) and [round-robin scheduling](round-robin-scheduling.md) can use a [FIFO queue](fifo-queue.md); other policies can organize eligible work differently, for example with a [priority queue](priority-queue.md).
