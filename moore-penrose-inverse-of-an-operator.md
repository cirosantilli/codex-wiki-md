<h1 id="moore-penrose-inverse-of-an-operator">Moore–Penrose inverse of an operator</h1>

↑ **Parent:** [Normal equation for a linear inverse problem](normal-equation-for-a-linear-inverse-problem.md)

For a bounded operator $A:X\to Y$ between Hilbert spaces, the Moore–Penrose inverse maps admissible data to the unique minimum-norm least-squares solution. If $(\sigma_j,u_j,v_j)$ is a [singular system of a compact operator](singular-system-of-a-compact-operator.md), then

$$
A^\dagger y
=\sum_j\frac{\langle y,u_j\rangle}{\sigma_j}v_j
$$

on the data for which this series converges.

More precisely, its domain is $\operatorname{ran}A\oplus(\operatorname{ran}A)^\perp$. It vanishes on $(\operatorname{ran}A)^\perp$ and takes values in $(\ker A)^\perp$. An infinite-rank [compact operator](compact-operator-split.md) on infinite-dimensional spaces has singular values approaching zero, so its inverse on its range is generally unbounded; [Picard criterion](picard-criterion.md) specifies admissible data.
