# Uniform random orientation out-cluster comparison

↑ **Parent:** [Bond percolation](bond-percolation-split.md)

If independent [edges](edge-of-a-graph.md) of a [locally finite graph](locally-finite-graph.md) receive fair orientations, exploring outward from a root tests each fresh reached-to-unreached boundary [edge](edge-of-a-graph.md) with success [probability](probability.md) $1/2$. Deferred decisions give exactly the exploration law of the root cluster in [bond percolation](bond-percolation-split.md) of density $1/2$. Thus the two reachable [graph vertex](vertex-graph-theory.md) sets have the same distribution. An infinite out-cluster contains an infinite simple directed ray by the [König infinity lemma](konig-s-lemma.md). Geometrically biased orientations do not generally give the same uniform edge-success law.
