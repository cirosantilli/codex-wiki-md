# Doob-Dynkin lemma

↑ **Parent:** [Measurable function](measurable-function.md)

For real [random variables](random-variable-split.md) $X,Z$, if $Z$ is [measurable](measurability.md) with respect to the [sigma-algebra generated by a random variable](sigma-algebra-generated-by-a-random-variable.md) $X$, there is a [Borel measurable function](borel-measurable-function.md) $g:\mathbb R\to\mathbb R$ with $Z=g(X)$. To prove the bounded case, approximate $Z$ pointwise by finite-valued [simple functions](simple-function.md) $Z_m$. Each level [set](set-split.md) is $X^{-1}(B)$ for a [Borel set](borel-set.md) $B$, so each approximation factors as $Z_m=g_m(X)$ with $g_m$ a [Borel measurable function](borel-measurable-function.md). Apply [scalar clipping](scalar-clipping.md) to $g_m$ with a common bounded interval and use its [limit superior](limit-superior.md) to obtain $g$. For unbounded finite $Z$, apply the bounded case to the one-to-one bounded [continuous function](continuous-function.md) $t\mapsto\arctan t$, then invert on $(-\pi/2,\pi/2)$ and assign arbitrary values elsewhere. Exact [measurability](measurability.md) gives exact factorization; assumptions after adjoining [null sets](null-set.md) give an [almost surely](almost-sure-convergence.md) equal version.
