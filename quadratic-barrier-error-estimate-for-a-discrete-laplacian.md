# Quadratic-barrier error estimate for a discrete Laplacian

↑ **Parent:** [Discrete elliptic barrier](discrete-elliptic-barrier.md)

For a normalized two-dimensional [discrete Laplacian](discrete-laplacian.md) satisfying the [discrete maximum principle](discrete-maximum-principle.md), suppose quadratic functions are differentiated exactly and $L_h1=0$. In a domain of diameter $D$, choose $x_0$ in the domain and $\phi(x)=|x-x_0|^2$. Then $0\leq\phi\leq D^2$ and $L_h\phi=4$. Applying the [discrete elliptic barrier](discrete-elliptic-barrier.md) argument to zero-boundary error $L_he=\tau$ gives the displayed bound. A mere sign pattern of the stencil does not determine this constant: rescaling the whole operator changes the error-to-residual ratio without changing the domain diameter.
