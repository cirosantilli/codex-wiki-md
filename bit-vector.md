# Bit vector

↑ **Parent:** [Bit](bit.md)

A [bit vector](bit-vector.md) is a fixed-length sequence of [bits](bit.md). An [unsigned interpretation of a bit string](unsigned-interpretation-of-a-bit-string.md) assigns positional weights $1,2,4,\ldots$; the [vector](vector.md) itself need not represent an [integer](integer-split.md), since its coordinates can instead encode independent [Boolean](boolean-data-type.md) conditions.
