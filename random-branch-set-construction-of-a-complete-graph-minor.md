# Random branch-set construction of a complete graph minor

↑ **Parent:** [Branch set of a graph minor](branch-set-of-a-graph-minor.md)

In a dense [graph](graph-split.md) with many [common neighbours](common-neighbour.md) for every pair of [vertices](vertex-graph-theory.md), choose disjoint random small sets. A set is good if few [vertices](vertex-graph-theory.md) have no neighbour in it. The [Markov inequality](markov-inequality.md) controls the number of bad sets, and random sampling makes almost every pair of good sets adjacent. Add unused [common neighbours](common-neighbour.md) to connect each set and to repair the remaining missing adjacencies. If the number of used [vertices](vertex-graph-theory.md) stays below every common-neighbour count, this constructs disjoint [branch sets of a graph minor](branch-set-of-a-graph-minor.md) representing a large [complete graph](complete-graph.md).
