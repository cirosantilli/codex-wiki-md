# Cauchy condensation test

↑ **Parent:** [Series (mathematics)](series-mathematics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cauchy_condensation_test)

If $(a_n)$ is a nonnegative decreasing [sequence](sequence.md), then $\sum_{n\geq1}a_n$ converges if and only if the condensed series $\sum_{k\geq0}2^ka_{2^k}$ converges. Comparing each dyadic block with its first and last terms proves both directions.
