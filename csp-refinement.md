# CSP refinement

↑ **Parent:** [CSP semantic model](csp-semantic-model.md)

Implementation $I$ has only behaviours permitted by specification $S$ in [CSP semantic model](csp-semantic-model.md) $M$. In particular, [CSP traces model](csp-traces-model.md) refinement means $\operatorname{traces}(I)\subseteq\operatorname{traces}(S)$; the other models additionally constrain [CSP stable failures](csp-stable-failure.md) or [CSP divergences](csp-divergence.md).
