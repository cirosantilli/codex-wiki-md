# Radial-path approximation for a cracked toroid

↑ **Parent:** [Inductance of a rectangular-section toroid](inductance-of-a-rectangular-section-toroid.md)

In this [magnetic circuit](magnetic-circuit.md) approximation, each circular path has air-gap [length](length.md) $d$, core [length](length.md) $2\pi r-d$, and the same normal [magnetic flux density](magnetic-field-split.md) in air and core. [Ampère's law](ampere-s-circuital-law.md) then gives $B(r)\simeq\mu_0\mu_rNI/[2\pi r+(\mu_r-1)d]$; integrating across the section gives the displayed [mutual inductance](mutual-inductance.md). Even $d\ll a$ can strongly reduce inductance when $\mu_rd/a$ is appreciable. This is a path estimate, not an exact local field solution in the slit geometry. It neglects [magnetic fringing](magnetic-fringing.md) and redistribution between paths. In particular, a literal field proportional to $\widehat{\boldsymbol\phi}/(r+q)$ everywhere in a current-free core is not curl-free; transverse corrections are required. Narrow-gap circuit approximations and their limitations are discussed in [§9.7, Example 9.7.1; paragraph following the example](electromagnetic-fields-and-energy-by-hermann-a-haus-and-james-r-melcher/magnetic-circuits.md).
