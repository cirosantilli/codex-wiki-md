# Spectrogram

↑ **Parent:** [Frequency spectrum](frequency-spectrum.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Spectrogram)

A [spectrogram](spectrogram.md) displays how a local [frequency spectrum](frequency-spectrum.md) changes over [time](time-in-physics.md), usually using colour for squared [Fourier transform](fourier-transform-split.md) magnitude. Longer analysis windows give finer [frequency](frequency.md) spacing while averaging over a longer [time](time-in-physics.md) interval.
