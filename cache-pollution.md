# Cache pollution

↑ **Parent:** [Cache (computing)](cache-computing.md)

Loss of useful cached data because less useful data occupy the limited [memory cache](cache-computing.md). Excessive [cache prefetching](cache-prefetching.md) can increase later demand [cache misses](cache-miss.md) by evicting useful [cache lines](cache-line.md).
