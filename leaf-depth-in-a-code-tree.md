# Leaf depth in a code tree

↑ **Parent:** [Optimal prefix code](optimal-prefix-code.md)

The number of [edges](edge-of-a-graph.md) on the [graph path](path-in-a-graph.md) from the [root of a tree](root-of-a-tree.md) to the leaf for symbol $x$ in a [code tree](prefix-tree-of-a-code.md). The [root of a tree](root-of-a-tree.md) has depth zero. Each [edge](edge-of-a-graph.md) contributes one [bit](bit.md) to a binary [codeword](codeword.md), so this depth equals the [codeword length](codeword-length.md); weighting these depths by [probabilities](probability.md) gives [expected codeword length](expected-codeword-length.md).
