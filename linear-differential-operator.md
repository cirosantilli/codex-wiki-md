# Linear differential operator

↑ **Parent:** [Differential operator](differential-operator.md)

A linear [differential operator](differential-operator.md) is a finite linear combination of [derivatives](derivative.md) with specified coefficient [functions](function-split.md). It obeys $L(\alpha f+\beta g)=\alpha Lf+\beta Lg$ for scalar constants $\alpha,\beta$. Variable coefficients need not commute with [differentiation](differentiation.md): $D(af)=a'f+af'$.
