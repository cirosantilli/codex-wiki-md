# Relativistic normalization of a one-particle state

↑ **Parent:** [Fock state](fock-state.md)

If creation operators obey $[a_{\mathbf p},a^\dagger_{\mathbf q}]=(2\pi)^3\delta^3(\mathbf p-\mathbf q)$, set $|\mathbf p\rangle=\sqrt{2E_{\mathbf p}}a^\dagger_{\mathbf p}|0\rangle$. Their [inner product](inner-product.md) then has the displayed value. The associated completeness measure is $d^3p/((2\pi)^3 2E_{\mathbf p})$, the invariant positive-energy [mass shell](mass-shell.md) measure. Specifying this normalization prevents hidden external energy factors in a [scattering amplitude](scattering-amplitude.md).
