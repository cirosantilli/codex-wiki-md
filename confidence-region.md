# Confidence region

↑ **Parent:** [Statistical inference](statistical-inference-split.md)

A random set of parameter values with specified repeated-sampling coverage: $\mathbb P_\theta\{\theta\in C(X)\}\geq1-\alpha$ for every permitted $\theta$. Exact coverage, asymptotic coverage and pointwise versus uniform validity must be distinguished. A [confidence interval](confidence-interval.md) is the scalar interval case.
