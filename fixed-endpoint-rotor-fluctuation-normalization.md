# Fixed-endpoint rotor fluctuation normalization

↑ **Parent:** [Rotor winding-sector path integral](rotor-winding-sector-path-integral.md)

In a temporal winding sector of a [quantum rotor](quantum-rotor.md), decompose the lifted angle into a straight winding path and a fluctuation vanishing at both endpoints. The cross term in the kinetic [action](action.md) vanishes, so all sectors have the same [Gaussian path integral](gaussian-path-integral.md). With inverse-energy imaginary time its value is the displayed diagonal free-particle kernel on the line. Integrating the initial angle separately supplies $2\pi$. Thus this fixed-endpoint factor is an amplitude density, not an additional rotor partition function or an uncounted angular zero mode.
