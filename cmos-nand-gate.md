# CMOS NAND gate

↑ **Parent:** [CMOS](cmos.md)

A static [CMOS](cmos.md) implementation of a [NAND gate](nand-gate.md) has a [pull-down network](pull-down-network.md) of [NMOS transistors](nmos-transistor.md) in series and a [pull-up network](pull-up-network.md) of [PMOS transistors](pmos-transistor.md) in parallel. With $k$ inputs it uses $k$ devices of each kind. All inputs high connect the output to ground; any low input breaks the pull-down path and connects the output to the positive supply through its corresponding p-channel device.
