# Repolarization

↑ **Parent:** [Membrane potential](membrane-potential-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Repolarization)

Return of a depolarized [membrane potential](membrane-potential-split.md) toward a more negative value. During an [action potential](action-potential.md), reduced inward current and increased outward current commonly contribute. It is distinct from [hyperpolarization](hyperpolarization.md), which takes the membrane beyond its reference resting value.
