# Embedding

↑ **Parent:** [Geometry and topology](geometry-and-topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Embedding)

An [embedding](embedding.md) identifies one mathematical structure with a structure-preserving copy inside another. In [topology](topology-split.md) it is a [homeomorphism](homeomorphism.md) onto its image with the [subspace topology](subspace-topology.md); an algebraic [embedding](embedding.md) is an injective [homomorphism](homomorphism.md). A [smooth embedding](smooth-embedding.md) additionally has injective [differential](differential-of-a-smooth-map.md) everywhere, so its image is an [embedded submanifold](embedded-submanifold.md).
