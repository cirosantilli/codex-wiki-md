# Expected absorption time in an illness-death model

↑ **Parent:** [Illness-death model](illness-death-model.md)

With initial exit rates $a$ to the advanced living state and $b$ directly to death, and death rate $c>0$ from the advanced state, the expected time to death from state 1 is $1/(a+b)+a/((a+b)c)$. The first term is initial [holding time](holding-time.md); the second weights the advanced-state [holding time](holding-time.md) by the [probability](probability.md) of reaching it.
