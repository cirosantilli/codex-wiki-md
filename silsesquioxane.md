# Silsesquioxane

↑ **Parent:** [Organosilicon compound](organosilicon-compound.md)

A [silicon](silicon.md)–[oxygen](oxygen.md) framework with ideal fully condensed composition $\mathrm{(RSiO_{3/2})_n}$. Each [silicon](silicon.md) has one organic [substituent](substituent.md) and three [siloxane](siloxane.md) bridges. Incompletely condensed cages retain [silanol](silanol.md) groups.
