# Boson-pair Casimir operator

↑ **Parent:** [Boson-pair realization of SU(1,1)](boson-pair-realization-of-su-1-1.md)

The identities $K_+K_-=N_aN_b$ and $K_-K_+=(N_a+1)(N_b+1)$ give the displayed quadratic [Casimir operator](casimir-element.md). It commutes with all generators because the number difference does. A fixed number-difference sector therefore has a fixed Casimir value even though pair creation changes its total occupation.
