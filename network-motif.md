# Network motif

↑ **Parent:** [Graph theory](graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Network_motif)

A small interaction pattern occurring unusually often relative to a specified [network null model](network-null-model.md). A circuit's wiring and proposed dynamical function should be distinguished from the statistical evidence that its pattern is enriched in a network.
