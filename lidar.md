# Lidar

↑ **Parent:** [Remote sensing](remote-sensing.md)

Range measurement using transmitted [laser](laser-split.md) light and its returned signal. For a pulse traveling a round trip in air, the elementary range is $r\simeq c\Delta t/2$, where $c$ is the propagation speed and $\Delta t$ the measured travel time. Sensor position, pointing and time synchronization place returns in a three-dimensional point cloud. Scanning [lidar](lidar.md) can record multiple returns from vegetation and the ground; a return is an observation of a reflecting surface, not automatically bare-earth elevation.
