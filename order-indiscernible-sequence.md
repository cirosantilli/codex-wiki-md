# Order-indiscernible sequence

↑ **Parent:** [Ehrenfeucht-Mostowski model](ehrenfeucht-mostowski-model.md)

A sequence $(a_i)_{i\in I}$ indexed by a [total order](total-order.md) is order-indiscernible when any two increasing finite subsequences of the same length satisfy the same first-order formulas.
