# Neutrality between Tit for tat and unconditional cooperation

↑ **Parent:** [Tit for tat](tit-for-tat.md)

Under cooperative initial memories, matches involving only [Tit for tat](tit-for-tat.md) and [always cooperate](always-cooperate.md) contain only cooperation, so all four [payoffs](payoff.md) equal $R$. The [two-condition criterion for evolutionary stability](two-condition-criterion-for-evolutionary-stability.md) has both differences zero. Thus [Tit for tat](tit-for-tat.md) is not an [evolutionarily stable strategy](evolutionarily-stable-strategy.md) against a strategy space containing unconditional cooperation, even if it is a [Nash equilibrium](nash-equilibrium.md). This counterexample is valid for finite horizons and discounting as well as infinite averages.
