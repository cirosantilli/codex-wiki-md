# Virtual state

↑ **Parent:** [Scattering amplitude](scattering-amplitude.md)

A pole reached on an unphysical sheet of the [scattering amplitude](scattering-amplitude.md), often on the negative imaginary [momentum](momentum-split.md) axis for a short-range one-dimensional potential. Unlike a positive-imaginary-momentum bound-state pole, it does not give a [normalizable](normalizable-wavefunction.md) exponentially decaying state on both sides.
