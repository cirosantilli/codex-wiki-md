# Regular polygon is a Euclidean Ramsey set

↑ **Parent:** [Euclidean Ramsey set](euclidean-ramsey-set.md)

Every [regular polygon](regular-polygon.md) is a [Euclidean Ramsey set](euclidean-ramsey-set.md). Its cyclic rotation acts transitively on the vertices, so this is a special case of the [Kriz theorem for cyclic transitive point sets](kriz-theorem-for-cyclic-transitive-point-sets.md).
