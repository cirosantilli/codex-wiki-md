# Finite repetition-free sequence

↑ **Parent:** [Sequence](sequence.md)

A [finite repetition-free sequence](finite-repetition-free-sequence.md) in a [set](set-split.md) $X$ is an [injective function](injective-function.md) from an initial segment $\{0,\ldots,k-1\}$ of the [natural numbers](natural-number.md) into $X$, including the empty [sequence](sequence.md) for $k=0$. For a [finite set](finite-set.md) of size $m$, the number of these [sequences](sequence.md) is

$$
\sum_{k=0}^m\frac{m!}{(m-k)!}.
$$

The order of each list is part of the data, so it can be enumerated without choosing an order on its underlying support.
