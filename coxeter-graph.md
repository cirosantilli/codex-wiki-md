# Coxeter graph

↑ **Parent:** [Coxeter matrix](coxeter-matrix.md)

The Coxeter graph has vertex set $I$, joins $i$ and $j$ when $m_{ij}\geq3$, and labels the edge by $m_{ij}$ when $m_{ij}>3$. A [Coxeter system](coxeter-system.md) is [irreducible](irreducible-coxeter-system.md) exactly when this graph is connected.
