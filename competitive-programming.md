# Competitive programming

↑ **Parent:** [Computer science](computer-science-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Competitive_programming)

Competitive programming asks participants to design and implement [algorithms](algorithm-split.md) for specified [computational problems](computational-problem.md), usually with constraints on [time complexity](time-complexity.md) and [space complexity](space-complexity.md). A successful solution combines a correctness argument with an implementation that fits the available resources.
