# Right-continuous function

↑ **Parent:** [Continuous function](continuous-function.md)

A function $f$ on the real line is right-continuous at $t$ when $f(s)\to f(t)$ as $s\downarrow t$.

Two-sided [continuity](continuous-function.md) requires both the right and left limits to equal the function value.
