# Type Ic supernova

↑ **Parent:** [Core-collapse supernova](core-collapse-supernova.md)

A [type Ic supernova](type-ic-supernova.md) lacks prominent [hydrogen](hydrogen.md) and helium features and is associated with a strongly stripped core-collapse progenitor. Line visibility depends on excitation and transfer as well as composition, so spectral classification is not an exact inventory of every element present.
