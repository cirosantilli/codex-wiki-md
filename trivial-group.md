# Trivial group

↑ **Parent:** [Group](group-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Trivial_group)

The trivial group has exactly one element, its identity. Every [group homomorphism](group-homomorphism.md) to it is trivial, and a [group](group-split.md) is trivial precisely when all elements in a generating set equal the identity.
