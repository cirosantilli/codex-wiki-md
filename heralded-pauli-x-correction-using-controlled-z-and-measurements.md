# Heralded Pauli X correction using controlled-Z and measurements

↑ **Parent:** [One-bit teleportation](one-bit-teleportation.md)

Two angle-zero [one-bit teleportations](one-bit-teleportation.md) with outcomes $p,q$ implement $X^qH X^pH=X^qZ^p$ on an arbitrary input, up to [global phase](global-phase.md). A [Controlled-Z gate](controlled-z-gate.md) with a fixed $|1\rangle$ [quantum ancilla](quantum-ancilla.md) implements $Z$, so $Z^p$ removes the known $Z$ factor. The result is $X^q$ up to phase. With probability one half the desired [Pauli X gate](pauli-x-gate.md) is applied; otherwise the input is unchanged. Repeating until $q=1$ gives an exact heralded correction with two attempts on average and almost-sure termination. It has no finite worst-case measurement count. A [Pauli frame](pauli-frame.md) avoids this repeat-until-success procedure when only logical action or classical output statistics are required.
