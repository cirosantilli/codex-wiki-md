# Derivative coupling to a conserved current

↑ **Parent:** [Dirac current](dirac-current.md)

An interaction $-\lambda j^\mu\partial_\mu\phi$ with an exactly [conserved current](conserved-current.md) is redundant: integration by parts gives $\lambda\phi\,\partial_\mu j^\mu$ up to a boundary term. For the [Dirac current](dirac-current.md), the local phase redefinition $\psi=e^{-i\lambda\phi}\chi$ removes the coupling, so its on-shell scattering amplitudes vanish.
