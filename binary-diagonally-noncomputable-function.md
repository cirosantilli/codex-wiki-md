# Binary diagonally noncomputable function

↑ **Parent:** [Computability theory](computability-theory.md)

A total binary-valued [function](function-split.md) is diagonally noncomputable if it differs from each defined diagonal value in an effective enumeration of [partial computable functions](computable-function.md). Nonbinary diagonal outputs are automatically different. No such [function](function-split.md) is computable: its own program index would contradict the defining condition. Choosing the opposite bit at every defined binary diagonal value proves existence without supplying a computable procedure.
