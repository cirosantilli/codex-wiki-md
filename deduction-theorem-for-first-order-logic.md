# Deduction theorem for first-order logic

↑ **Parent:** [Deduction theorem for propositional logic](deduction-theorem-for-propositional-logic.md)

In the usual first-order Hilbert system, [logical implication](logical-implication.md) discharge requires the appropriate generalization restriction: a variable generalized in the derivation must not be free in the assumption being discharged. Equivalently use a proof system whose generalization rule already forbids variables free in open assumptions. One can first discharge a temporary assumption and then generalize if the quantified variable is not free in the remaining assumptions. Ignoring this side condition would allow deriving universal conclusions from a single arbitrary instance as an open hypothesis.
