# Cauchy matrix

↑ **Parent:** [Matrix](matrix.md)

A [Cauchy matrix](cauchy-matrix.md) has entries $1/(x_i+y_j)$ with nonzero denominators. If $x_i=y_i>0$ are distinct, it is positive definite: $C_{ij}=\int_0^\infty e^{-x_is}e^{-x_js}ds$ is the Gram matrix of linearly independent exponential functions. This form occurs in finite-rank [inverse scattering transform](inverse-scattering-transform.md) reconstructions.
