# Certifiable function

↑ **Parent:** [Concentration inequality](concentration-inequality.md)

An integer-valued [function](function-split.md) $f$ is $g$-certifiable when every input $x$ with $f(x)=k$ has a set of at most $g(k)$ coordinates whose values alone guarantee that $f\geq k$.
