# Fixed point

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fixed_point)

A fixed point of a function $f:X\to X$ is an element $x\in X$ satisfying $f(x)=x$.
