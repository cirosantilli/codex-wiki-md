# Row-major order

↑ **Parent:** [Array (data structure)](array-data-structure.md)

Storage of a multidimensional [array](array-data-structure.md) with the last index varying fastest in consecutive positions. In a two-dimensional [array](array-data-structure.md), each row is contiguous. [Row-major order](row-major-order.md) is a layout convention; a program can traverse that [array](array-data-structure.md) by rows or by columns. See the explicit address calculation in [spatial locality](spatial-locality.md).
