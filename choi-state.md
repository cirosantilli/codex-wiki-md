# Choi state

↑ **Parent:** [Choi matrix](choi-matrix.md)

A channel's Choi state is its normalized [Choi matrix](choi-matrix.md),

$$
C_\Lambda=(\Lambda\otimes\operatorname{id})(|\Phi_d\rangle\langle\Phi_d|),\qquad
|\Phi_d\rangle=\frac1{\sqrt d}\sum_i|ii\rangle.
$$

It is a [density operator](density-matrix.md) and satisfies $\operatorname{Tr}_{\rm out}C_\Lambda=I_{\rm in}/d$. Some authors use an unnormalized [Choi matrix](choi-matrix.md) of trace $d$, so reconstruction factors depend on the convention.
