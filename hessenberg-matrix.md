# Hessenberg matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hessenberg_matrix)

An upper Hessenberg matrix has zero entries below the first subdiagonal; the lower version has zero entries above the first superdiagonal. The [upper Hessenberg matrix](upper-hessenberg-matrix.md) is one of these two forms.
