# Block diagonal matrix

↑ **Parent:** [Block matrix](block-matrix.md)

A [block matrix](block-matrix.md) is block diagonal if all off-diagonal blocks vanish. It represents independent actions on a [direct sum](direct-sum.md) of [vector spaces](vector-space-split.md). Its [determinant](determinant.md) is the product of the diagonal-block [determinants](determinant.md).
