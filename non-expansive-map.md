# Non-expansive map

↑ **Parent:** [Category of metric spaces and non-expansive maps](category-of-metric-spaces-and-non-expansive-maps.md)

A non-expansive map between [metric spaces](metric-space.md) is a function $f$ such that $d(fx,fy)\leq d(x,y)$.
