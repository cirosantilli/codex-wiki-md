# Partial residual

↑ **Parent:** [Regression residual](regression-residual.md)

In an additive mean model, the partial residual for component $j$ subtracts every fitted term except that component. It equals the full [regression residual](regression-residual.md) plus the fitted component. Plotting it against that component's predictor shows the conditional pattern after accounting for other fitted effects, and supplies the response for a [backfitting](backfitting-algorithm.md) update.
