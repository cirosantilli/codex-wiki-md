# Pairwise independent events

↑ **Parent:** [Probability theory](probability-theory-split.md)

[Pairwise independent events](pairwise-independent-events.md) have factorizable two-event intersections. [Independent events](independent-events.md) require the corresponding factorization for every finite subfamily, which is stronger. If three events have common probability $s$ and every pair and triple intersect in the same event of probability $q$, pairwise independence requires $q=s^2$, while full independence additionally requires $q=s^3$. Both hold only for $s=0$ or $s=1$.
