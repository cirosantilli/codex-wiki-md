# Common-arm phase cancellation in a balanced interferometer

↑ **Parent:** [Michelson interferometer](michelson-interferometer.md)

Changing both arms of a balanced [Michelson interferometer](michelson-interferometer.md) by the same length changes the common phase of both returning fields. Their relative phase and detector [intensity](intensity-physics.md) remain unchanged at every frequency. Thus balanced interference cannot select a minimum positive common arm length.
