# Continuous transformation learning

↑ **Parent:** [Unsupervised learning](unsupervised-learning.md)

Learning transformation-tolerant representations by combining input-feature overlap, current-activity [Hebbian learning](hebbian-learning.md) and [synaptic competition](synaptic-competition.md). A new view partly activates an output already learned for an overlapping view, then strengthens its new features onto that output. Chains of overlapping views can link more distant transformations without an explicit temporal trace; dense enough overlap and suitable competition remain conditions.[Abstract and Introduction, pp. 128–131; experiments 3–4 distinguish spatial overlap from temporal ordering](learning-invariant-object-recognition-in-the-visual-system-with-continuous-transformations-by-simon-m-stringer-and-others.md)
