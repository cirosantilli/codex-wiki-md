# Source fixed point of a map

↑ **Parent:** [Fixed point stability for an iteration](fixed-point-stability-for-an-iteration.md)

A hyperbolic source [fixed point](fixed-point.md) of a smooth finite-dimensional map has every Jacobian [eigenvalue](eigenvalue.md) outside the [unit circle](complex-unit-circle.md). Forward iteration repels nearby states. For an ordinary differential equation the analogous test instead uses positive real parts, so a source equilibrium criterion should not be substituted into a discrete map calculation.
