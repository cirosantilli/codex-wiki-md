# Facial Action Coding System

↑ **Parent:** [Facial expression](facial-expression.md)

A system for describing visible facial actions in terms of anatomically grounded action units. Coding an action unit documents a movement; assigning an [emotion](emotion.md) to the movement is a separate inference.
