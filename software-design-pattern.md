# Software design pattern

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

A reusable organization of responsibilities and interactions for a recurring software-design problem. The [Memento pattern](memento-pattern.md) separates snapshot creation/restoration from history management, while the [Decorator pattern](decorator-pattern.md) composes independent responsibilities behind one interface. A pattern specifies an arrangement rather than one mandatory class naming scheme.
