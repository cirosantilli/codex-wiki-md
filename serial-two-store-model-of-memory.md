# Serial two-store model of memory

↑ **Parent:** [Human memory](human-memory.md)

A [human memory](human-memory.md) architecture in which new information must pass through a short-term store to reach a long-term store. A strong version is challenged if the specific short-term mechanism claimed to be obligatory is severely impaired while relevant long-term learning remains relatively preserved. Residual or alternative routes must be considered.
