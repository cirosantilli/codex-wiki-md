# Datapath

↑ **Parent:** [Central processing unit](central-processing-unit.md)

A [datapath](datapath.md) comprises the [processor registers](processor-register.md), functional units and connections through which instruction operands and results move. Control signals select operand sources, operations, memory access and [processor register](processor-register.md) writeback. Connecting a [barrel shifter](barrel-shifter.md) before an [arithmetic logic unit](arithmetic-logic-unit.md) permits shift-and-add operations in one pass, but puts their delays in series.
