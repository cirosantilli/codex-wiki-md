# Abbe number

↑ **Parent:** [Dispersion (optics)](dispersion-optics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Abbe_number)

The Abbe number compares refractive strength with visible [optical dispersion](dispersion-optics.md). The traditional $C,F,d$ reference lines are near $656.3,486.1,587.6$ nm, respectively. A large $V_d$ means weak relative dispersion.
