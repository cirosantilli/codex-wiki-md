# Synchronous sequential circuit

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A [synchronous sequential circuit](synchronous-sequential-circuit.md) stores a finite collection of [bits](bit.md) $s$, reads inputs $a$, and updates all stored [bits](bit.md) at each [clock edge](clock-edge.md) according to a specified next-state function $F$. A combinational output is $G(s,a)$; an output that is itself stored is included among the state [bits](bit.md). An initial state is part of a complete design. These equations provide a precise implementation-level description of a [finite-state machine](finite-state-machine.md) without requiring a particular gate drawing.
