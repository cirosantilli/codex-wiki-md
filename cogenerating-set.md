# Cogenerating set

↑ **Parent:** [Coseparator](coseparator.md)

A cogenerating set is a set-indexed family $(Q_i)_{i\in I}$ such that whenever $f\ne g:A\to B$, there is a [morphism](morphism.md) $q:B\to Q_i$ with $qf\ne qg$. It generalizes a single [coseparator](coseparator.md). In a [locally small category](locally-small-category.md) with the needed [products in a category](product-category-theory.md), it gives an [evaluation embedding into cogenerator products](evaluation-embedding-into-cogenerator-products.md).
