# Supporting hyperplane

↑ **Parent:** [Convex set](convex-set-split.md)

For a [convex set](convex-set-split.md) $C$ and $x_0\in C$, a [supporting hyperplane](supporting-hyperplane.md) has a nonzero [normal vector](normal-vector.md) $a$ such that $a^Tx\le a^Tx_0$ for all $x\in C$. It touches $C$ while containing the set on one side.
