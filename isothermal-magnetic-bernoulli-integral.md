# Isothermal magnetic Bernoulli integral

↑ **Parent:** [Magnetohydrodynamic Bernoulli invariant](magnetohydrodynamic-bernoulli-invariant.md)

In aligned steady ideal flow with $p=c_s^2\rho$ and constant [isothermal sound speed](isothermal-sound-speed.md), the [Lorentz force density](lorentz-force-density.md) has no field-parallel component. Projecting momentum along the [magnetic field](magnetic-field.md) makes $u^2/2+\Phi+c_s^2\ln(\rho/\rho_0)$ constant on each connected magnetic surface. The arbitrary reference density changes only the additive constant.
