# Ordinal described by a first-order formula

↑ **Parent:** [Lévy reflection theorem](levy-reflection-theorem.md)

A [first-order formula](first-order-formula.md) $\varphi$ describes an ordinal $\alpha$ when $\alpha$ is the least ordinal such that $V_\alpha\models\varphi$. No [strongly inaccessible cardinal](strongly-inaccessible-cardinal.md) can be described: if $V_\kappa\models\varphi$, the [Lévy reflection theorem](levy-reflection-theorem.md) produces some $\alpha<\kappa$ with $V_\alpha\models\varphi$.
