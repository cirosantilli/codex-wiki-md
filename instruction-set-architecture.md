# Instruction set architecture

↑ **Parent:** [Computer science](computer-science-split.md)

The programmer-visible machine instruction repertoire and its semantics, including accessible [processor registers](processor-register.md) and permitted operand forms. Different processors can implement the same [instruction set architecture](instruction-set-architecture.md) using different internal designs.
