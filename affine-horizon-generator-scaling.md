# Affine horizon-generator scaling

↑ **Parent:** [Surface gravity](surface-gravity.md)

If a [Killing horizon](killing-horizon.md) generator $\xi$ has constant nonzero [surface gravity](surface-gravity.md) $\kappa$, write $\xi=F(\lambda)k$ with $k=d/d\lambda$ affine. The equation $\nabla_\xi\xi=\kappa\xi$ implies $dF/d\lambda=\kappa$, so shifting the affine origin gives $\xi=\kappa\lambda k$.
