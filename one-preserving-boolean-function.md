# One-preserving Boolean function

↑ **Parent:** [Boolean function](boolean-function.md)

A [Boolean function](boolean-function.md) satisfying the displayed condition. Composition of [one-preserving Boolean functions](one-preserving-boolean-function.md) is one-preserving, since each inner output is one on an all-one input. Consequently [structural induction](structural-induction.md) shows that a variable-built [propositional formula](propositional-formula.md) using only one-preserving [logical connectives](logical-connective.md), such as $\land,\lor,\to$, is true under the all-one [Boolean valuation](boolean-valuation.md).
