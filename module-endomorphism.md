# Module endomorphism

↑ **Parent:** [Module homomorphism](module-homomorphism.md)

A module endomorphism is a [module homomorphism](module-homomorphism.md) from a [module](module-mathematics.md) to itself. These maps form the [endomorphism ring](endomorphism-ring.md) $\operatorname{End}_R(M)$ under pointwise addition and composition. An invertible module endomorphism is a [module automorphism](module-automorphism.md).
