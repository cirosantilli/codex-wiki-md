# Zero Fourier mode

↑ **Parent:** [Fourier mode](fourier-mode.md)

The spatially constant [Fourier mode](fourier-mode.md). On a periodic domain its coefficient represents the spatial mean, up to the chosen [Fourier transform](fourier-transform-split.md) normalization. Derivatives annihilate this mode, so homogeneous periodic diffusion preserves it.
