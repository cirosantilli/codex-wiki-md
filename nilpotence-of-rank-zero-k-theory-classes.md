# Nilpotence of rank-zero K-theory classes

↑ **Parent:** [Rank map in topological K-theory](rank-map-in-topological-k-theory.md)

For a [finite CW complex](finite-cw-complex.md), every element in the kernel of the [rank map in topological K-theory](rank-map-in-topological-k-theory.md) is a [nilpotent element](nilpotent.md). One proof adjoins one positive-dimensional cell at a time: the restriction kernel is square-zero by the [relative product in topological K-theory](relative-product-in-topological-k-theory.md). For [connected](connected-space.md) spaces the rank-zero kernel is [Reduced topological K-theory](reduced-topological-k-theory.md); for disconnected spaces the kernel of restriction to just one basepoint can contain nonzero [idempotents](idempotent.md).
