# Coincidence line of response

↑ **Parent:** [Positron emission tomography](positron-emission-tomography.md)

A line defined by an approximately coincident detector pair in annihilation-photon [tomography](tomography.md). An event constrains a possible annihilation location to that line within instrumental and physical uncertainties. Time-of-flight data can add a [position](position.md) constraint along it; attenuation, scattering and random coincidences change the forward model.
