# Surface-code decoding as a random-bond Ising model

↑ **Parent:** [Surface code](surface-code.md)

For independent bit flips, summing the probabilities of all error chains in one syndrome and logical class equals, up to a class-independent factor, the partition function of a random-bond [Ising model](ising-model.md). A reference error fixes bond signs and products of star stabilizers become Ising spin configurations.
