# String-loop effective action expansion

↑ **Parent:** [String genus expansion](string-genus-expansion.md)

Connected oriented [closed string](closed-string.md) worldsheets of genus $g$ give the spacetime effective-action term $g_s^{2g-2}S_g$. Each $S_g$ has a separate low-energy derivative expansion in $\alpha'$. The [string coupling](string-coupling.md) orders quantum string loops, while $\alpha'$ orders effects of finite string size.
