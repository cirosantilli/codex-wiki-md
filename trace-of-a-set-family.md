# Trace of a set family

↑ **Parent:** [Set family](set-family.md)

For a set family $\mathcal A\subseteq\mathcal P([n])$ and $F\subseteq[n]$, its trace on $F$ is

$$
T_F(\mathcal A)=\{A\cap F:A\in\mathcal A\}.
$$
