# Bad barrier array for the Rado order

↑ **Parent:** [Rado order](rado-order.md)

The [barrier in better-quasi-order theory](barrier-in-better-quasi-order-theory.md) $[\omega]^2$ has shifts $\{m,n\}\triangleleft\{n,l\}$ for $m<n<l$. Map each pair to the corresponding element of the [Rado order](rado-order.md). Neither clause of $(m,n)\le_R(n,l)$ holds: the first coordinates differ, and the second coordinate of the first pair equals, rather than precedes, the first coordinate of the second. Thus this array is bad, although the [Rado order](rado-order.md) is a [well-quasi-ordering](well-quasi-ordering.md). It separates [better-quasi-ordering](better-quasi-ordering.md) from [well-quasi-ordering](well-quasi-ordering.md).
