# Frobenius cycle type

↑ **Parent:** [Galois theory](galois-theory-split.md)

Over $\mathbb F_q$, Frobenius acts on roots of an irreducible degree-$n$ polynomial as an $n$-cycle. Factor degrees therefore give its cycle type.
