# Global cloning fidelity

↑ **Parent:** [Quantum cloning](quantum-cloning.md)

For a [quantum cloning](quantum-cloning.md) device with [pure state](pure-state.md) output $U|\phi,0\rangle$, the global cloning fidelity is its [squared quantum fidelity](squared-quantum-fidelity.md) with the desired joint two-copy [pure state](pure-state.md). It is the [probability](probability.md) that a joint projector test for two ideal copies accepts the actual output. It differs from a one-clone marginal fidelity: correlations between the output [qubits](qubit.md) affect the joint overlap. For a [controlled-NOT gate](controlled-not-gate.md) with input $|+\rangle|0\rangle$, the output is a [Bell state](bell-state-split.md) and its global cloning fidelity with $|++\rangle$ is $1/2$; for input $|0\rangle|0\rangle$ it is one.
