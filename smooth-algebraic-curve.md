# Smooth algebraic curve

↑ **Parent:** [Algebraic variety](algebraic-variety.md)

A smooth algebraic curve is a one-dimensional [algebraic variety](algebraic-variety.md) whose [local ring](local-ring.md) at every point is regular.

This is the nonsingular subclass of [algebraic curves](algebraic-curve.md).
