# Spectrum equals character values in a commutative Banach algebra

↑ **Parent:** [Gelfand representation](gelfand-representation.md)

For a commutative complex unital [Banach algebra](banach-algebra-split.md), a [character of an algebra](character-of-an-algebra.md) annihilates $a-\phi(a)1$, so this element cannot be invertible. Conversely a noninvertible $a-\lambda1$ generates a proper [ideal](ideal.md), which lies in a [maximal ideal](maximal-ideal.md). The corresponding character then has value $\lambda$ at $a$. Thus the [Gelfand transform](gelfand-representation.md) determines every element's spectrum even when the algebra is not semisimple.
