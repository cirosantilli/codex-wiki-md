# Bessel turning-point asymptotic

↑ **Parent:** [Cubic stationary endpoint](cubic-stationary-endpoint.md)

At equal argument and large integer order, the [Bessel function of the first kind](bessel-function-of-the-first-kind.md) has phase $n(\sin t-t)=-nt^3/6+\cdots$ near the endpoint. The [cubic stationary endpoint](cubic-stationary-endpoint.md) yields the displayed positive constant. It is also the zero-argument value of the [Airy function](airy-function.md) in the uniform Bessel turning-point approximation.
