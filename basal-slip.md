# Basal slip

↑ **Parent:** [Slip system](slip-system.md)

[Dislocation glide](dislocation-glide.md) in a hexagonal crystal on its basal $(0001)$ plane, ordinarily along a close-packed basal direction in the $\langle11\overline20\rangle$ family. Direction indices must be converted using the actual hexagonal metric, including the ratio $c/a$.
