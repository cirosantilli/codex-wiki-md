# Volatile memory access

↑ **Parent:** [Computer memory](computer-memory-split.md)

A memory access whose execution is observable under the source language or machine rules, so that replacing repeated accesses by a saved value can change behavior. The precise guarantees depend on the [programming language](programming-language-split.md); volatile access alone does not provide thread synchronization.
