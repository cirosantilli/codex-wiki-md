# Residues of the Gamma function

↑ **Parent:** [Gamma function](gamma-function.md)

The [Gamma function recurrence](gamma-function-recurrence.md) gives $\Gamma(s)=\Gamma(s+j+1)/(s(s+1)\cdots(s+j))$. Its numerator equals one at $s=-j$, so the [residue](residue.md) there is $(-1)^j/j!$ for every nonnegative integer $j$.
