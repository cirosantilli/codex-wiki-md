# Orbit averaging

↑ **Parent:** [Secular perturbation](secular-perturbation.md)

For a quantity on a periodic [Kepler orbit](kepler-orbit.md), its orbit average is $\langle x\rangle=P^{-1}\int_0^P x(t)\,dt$. Equal increments of [true anomaly](true-anomaly.md) are not equal increments of time. [Eccentric anomaly](eccentric-anomaly.md) gives the weight $dt=(1-e\cos E)dE/n$, which yields $\langle\cos f\rangle=-e$. Slow orbital perturbations can be averaged using elements held fixed over a single [orbital period](orbital-period.md).
