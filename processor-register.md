# Processor register

↑ **Parent:** [Central processing unit](central-processing-unit.md)

A small storage location within a [CPU](central-processing-unit.md) used by its instructions. Some hold data; others describe control state, such as the [program counter](instruction-pointer.md) or [stack pointer](stack-pointer.md). Saving and restoring [processor registers](processor-register.md) lets different [software threads](thread-computing.md) reuse the same [CPU](central-processing-unit.md) while retaining separate [execution contexts](execution-context.md).
