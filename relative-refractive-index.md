# Relative refractive index

↑ **Parent:** [Refractive index](refractive-index.md)

The [relative refractive index](relative-refractive-index.md) of medium two with respect to medium one is $n_{21}=n_2/n_1$, using their absolute [refractive indices](refractive-index.md) at the same [frequency](frequency.md). For transparent media with [isotropy](isotropy.md) and positive [refractive indices](refractive-index.md), [Snell's law](snell-s-law.md) gives $n_{21}=\sin i/\sin r$, with the [angles](angle.md) measured from the interface normal. Thus a [refraction](refraction.md) measurement in air directly determines an index relative to air. Converting it to an absolute [refractive index](refractive-index.md) requires the [refractive index](refractive-index.md) of that air; replacing it by one is an approximation.
