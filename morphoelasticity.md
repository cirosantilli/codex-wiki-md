# Morphoelasticity

↑ **Parent:** [Mathematical biology](mathematical-biology-split.md)

The mathematical description of elastic bodies whose stress-free material state changes through growth or remodelling. A [multiplicative decomposition of the deformation gradient](multiplicative-decomposition-of-the-deformation-gradient.md) separates the [growth tensor](growth-tensor.md) $\mathbf G$ from the elastic accommodation $\mathbf A$. The relaxed grown configuration need not be globally compatible, so even an unloaded body can develop internal [stress](stress.md).
