# Residual spectrum

↑ **Parent:** [Spectrum (functional analysis)](spectrum-functional-analysis.md)

In the disjoint convention for a [bounded linear operator](continuous-linear-operator.md) $T$, the [residual spectrum](residual-spectrum.md) consists of $\lambda$ for which $T-\lambda I$ is injective but has nondense range. Together with the [point spectrum](point-spectrum.md) and [continuous spectrum](continuous-spectrum.md) it partitions the [spectrum of a bounded operator](spectrum-of-a-bounded-operator.md). Some conventions also include noninjective operators with nondense range, so the convention must be stated.
