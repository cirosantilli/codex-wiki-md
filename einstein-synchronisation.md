# Einstein synchronisation

↑ **Parent:** [Einstein's principle of relativity](einstein-s-principle-of-relativity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Einstein_synchronisation)

Einstein synchronisation sets clocks at rest in one [inertial frame](inertial-frame.md) using exchanged [light](light.md) signals. If the sending clock records departure at $t_A$ and return at $t_A'$, the distant clock's reflection reading is set to $t_B=(t_A+t_A')/2$. This convention assigns equal outgoing and incoming travel times and defines the frame's distant simultaneity. It does not set the arrival time of an image equal to the time of the remote [spacetime event](event-relativity.md).
