# Word problem for groups

↑ **Parent:** [Group presentation](group-presentation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Word_problem_for_groups)

For a fixed finitely generated [group](group-split.md) with specified generators, its word problem asks for an algorithm deciding whether an input word represents the identity. For a finitely presented group, positive answers can be enumerated from the relators, but there need not be an algorithm deciding both positive and negative answers. An effective reduction from a nonrecursive [halting set](halting-set.md) proves unsolvability.
