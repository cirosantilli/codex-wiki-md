# Density level sets separate a singular measure

↑ **Parent:** [Mutually singular measures](mutually-singular-measures.md)

Suppose a finite nonnegative [measure](measure.md) has finite-level densities $Y_n$ with respect to a [probability](probability.md) [measure](measure.md) $\lambda$. The event $\{Y_n\leq\varepsilon\}$ belongs to that level's [sigma-algebra](sigma-algebra.md), so its [measure](measure.md) is $\int\mathbf1_{\{Y_n\leq\varepsilon\}}Y_n\,d\lambda\leq\varepsilon$. The set where nonnegative $Y_n$ tends to zero is contained in the eventual occurrence of every such level event; it therefore has [measure](measure.md) at most $\varepsilon$ for every $\varepsilon>0$, hence zero. If the same limit set has full $\lambda$-measure, the two [measures](measure.md) are singular.
