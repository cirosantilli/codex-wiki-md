# Girsanov density for a stopped Bessel process

↑ **Parent:** [Girsanov theorem](girsanov-theorem.md)

For reference [Brownian motion](brownian-motion-split.md) $R=x+W$, stopped at $T=t\wedge\tau_{(a,b)}$ with $0<a<x<b$, this expression is the [Radon-Nikodym derivative](radon-nikodym-derivative.md) of the stopped [Bessel process](bessel-process.md) law of dimension $\delta$. The bounded stopped drift verifies the [Novikov condition](novikov-s-condition.md). The comparison laws must have the same initial value and the same stopping rule.
