# Triangular function

↑ **Parent:** [Fourier transform of a triangular function](fourier-transform-of-a-triangular-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Triangular_function)

The triangular function

$$
\operatorname{tri}(x)=(1-|x|)\mathbf1_{[-1,1]}(x)
$$

has angular-frequency Fourier transform $4\sin^2(\xi/2)/\xi^2$.

Equivalently, this is the [convolution](convolution.md) of two unit-width [rectangular functions](rectangular-function.md): the overlap length is $1-|x|$ when $|x|<1$, and zero otherwise. Time rescaling and amplitude changes give [triangular pulses](triangular-function.md) with different widths and heights. The [convolution theorem](convolution-theorem.md) also obtains the displayed transform by squaring $\sin(\xi/2)/(\xi/2)$, with continuous value one at zero.
