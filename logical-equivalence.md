# Logical equivalence

↑ **Parent:** [Propositional logic](propositional-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Logical_equivalence)

Two [propositional formulas](propositional-formula.md) are logically equivalent in [classical propositional logic](classical-propositional-logic.md) when they have the same [truth value](truth-value.md) under every [Boolean valuation](boolean-valuation.md). Identical output columns in a [truth table](truth-table.md) prove [logical equivalence](logical-equivalence.md); one differing row refutes it. [De Morgan's laws](de-morgan-s-laws.md) give useful examples.
