# Factor base

↑ **Parent:** [Integer factorization](integer-factorization.md)

A factor base is a finite set of small primes, often with the sign factor $-1$ included, over which selected integer residues are completely factored. A [smooth number](smooth-number.md) supported on this set gives an exponent vector. Linear dependence of such vectors modulo two produces a product that is a square, enabling congruence-of-squares [integer factorization](integer-factorization.md).
