# Deductive-nomological model

↑ **Parent:** [Covering-law model](covering-law-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Deductive-nomological_model)

An explanation derives an event description from laws and circumstances, with valid [deduction](deductive-reasoning.md), essential use of a law, empirical content and true premises. These requirements do not by themselves settle explanatory direction or eliminate irrelevant additions.[section 3](studies-in-the-logic-of-explanation-by-carl-hempel-and-paul-oppenheim.md)
