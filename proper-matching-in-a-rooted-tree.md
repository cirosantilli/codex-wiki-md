# Proper matching in a rooted tree

↑ **Parent:** [Matching (graph theory)](matching-graph-theory-split.md)

A [matching in a graph](matching-graph-theory-split.md) on a [rooted tree](rooted-tree.md) has the sibling-support condition if every unmatched non-root [vertex](vertex-graph-theory.md) has its parent matched to one of its [siblings in a rooted tree](sibling-in-a-rooted-tree.md). This is the properness condition used here. The root has no parent, so either exempt an unmatched root or require it to be matched in a nontrivial instance; the [unmatched-vertex bound for a proper tree matching](unmatched-vertex-bound-for-a-proper-tree-matching.md) holds under either convention. Properness is stronger than being maximal: on the path $r-a-b-c$ rooted at $r$, selecting only $ab$ gives a maximal [matching in a graph](matching-graph-theory-split.md), but unmatched $c$ has parent $b$ matched upward rather than to a sibling of $c$.
