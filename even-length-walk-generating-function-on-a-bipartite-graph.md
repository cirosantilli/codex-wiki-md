# Even-length walk generating function on a bipartite graph

↑ **Parent:** [Self-avoiding walk generating function](self-avoiding-walk-generating-function.md)

In a [bipartite graph](bipartite-graph.md), a [self-avoiding walk](self-avoiding-walk.md) ends in its starting class exactly when it has even length. If degrees are bounded by $\Delta$, deleting the last [edge](edge-of-a-graph.md) gives $\sigma_{2k+1}\leq\Delta\sigma_{2k}$ and hence $Z_G^0(x)\leq Z_G(x)\leq(1+\Delta x)Z_G^0(x)$ for $x\geq0$. Thus these [generating functions](generating-function.md) have the same [radius of convergence](radius-of-convergence.md).
