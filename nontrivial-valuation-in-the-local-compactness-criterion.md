# Nontrivial valuation in the local compactness criterion

↑ **Parent:** [Local compactness criterion for a complete non-Archimedean field](local-compactness-criterion-for-a-complete-non-archimedean-field.md)

An infinite field with the trivial [absolute value on a field](absolute-value-algebra.md) is discrete, hence locally compact, but its [residue field](residue-field.md) is the original infinite field. Thus local compactness forces a finite [residue field](residue-field.md) and a discrete nontrivial value group only when the [valuation](valuation.md) is assumed nontrivial.
