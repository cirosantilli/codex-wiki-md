# Finitely generated soluble torsion groups are finite

↑ **Parent:** [Solvable group](solvable-group.md)

A finitely generated [abelian group](abelian-group.md) whose elements all have finite order is finite. Induct on derived length for a finitely generated [soluble group](solvable-group.md) with this property. Its [abelianization](abelianization.md) is finite, so its [commutator subgroup](commutator-subgroup.md) has finite index and is finitely generated by [Schreier's lemma](schreier-s-lemma.md). That subgroup is soluble of smaller derived length and is still a [torsion group](torsion-group.md), hence finite by induction. The ambient group is a finite extension of it and is finite.
