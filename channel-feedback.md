# Channel feedback

↑ **Parent:** [Communication channel](communication-channel.md)

Information about earlier received outputs made available to the [channel encoder](channel-encoder.md) while choosing subsequent inputs. For [repeat-until-success coding over an erasure channel](repeat-until-success-coding-over-an-erasure-channel.md), an erasure report tells the sender to repeat the current [bit](bit.md), while a success report tells it to advance. A forward [code rate](code-rate.md) calculation must specify whether this return communication is supplied freely or included in the resource count.
