# Encryption

↑ **Parent:** [Cryptography](cryptography.md)

The transformation of a message into a ciphertext using a key, with decryption recovering the message using an appropriate key. Confidentiality and [message authentication](message-authentication.md) are separate properties; an [encryption](encryption.md) scheme needs explicit security hypotheses.
