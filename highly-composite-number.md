# Highly composite number

↑ **Parent:** [Divisor function](divisor-function.md)

A [positive integer](positive-integer.md) whose [divisor](divisor.md) count strictly exceeds that of every smaller [positive integer](positive-integer.md). A record scan maintains the largest earlier value of the [divisor function](divisor-function.md) and emits exactly candidates exceeding it. Equality does not create a new record; the first candidate is handled by a zero initial record.
