# Exponential stability

↑ **Parent:** [Asymptotic stability](asymptotic-stability.md)

An equilibrium has [exponential stability](exponential-stability.md) when sufficiently small displacements satisfy an estimate $\|x(t)-x_*\|\le C e^{-\alpha t}\|x(0)-x_*\|$ for some $C,\alpha>0$.
