# Inertial dam-break current in a triangular valley

↑ **Parent:** [Gravity-current box model](gravity-current-box-model.md)

In a horizontal prismatic V-shaped valley with section area $A=\lambda h^2$, a fixed-volume high-Reynolds-number [gravity-current box model](gravity-current-box-model.md) has $h=(W/(\lambda X))^{1/2}$ and front speed $\dot X=\operatorname{Fr}\sqrt{gh}$. Integrating gives $X=[5\operatorname{Fr}\sqrt g(W/\lambda)^{1/4}t/4]^{4/5}$ after the initial release scale is neglected. This is an inertial closure, distinct from the viscous [V-shaped channel gravity current](v-shaped-channel-gravity-current.md), whose exponent is different.
