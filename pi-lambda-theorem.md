# Pi-lambda theorem

↑ **Parent:** [Product measure](product-measure.md)

If a [Dynkin system](dynkin-system.md) contains a [pi-system](pi-system.md), then it contains the sigma-algebra generated by that pi-system. This proves uniqueness of finite measures from agreement on a generating pi-system.
