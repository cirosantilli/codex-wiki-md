# Tree unfold

↑ **Parent:** [Functional programming](functional-programming.md)

Expand a seed by a function returning either no node or a left seed, root label and right seed. Recursively expanding the two seeds produces a binary tree. A finite ascending [list](list-abstract-data-type.md) split about its midpoint supplies an unfold into a [balanced binary tree](balanced-binary-tree.md) that is a [binary search tree](binary-search-tree.md).
