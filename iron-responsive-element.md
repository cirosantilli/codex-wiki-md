# Iron-responsive element

↑ **Parent:** [RNA secondary structure](rna-secondary-structure.md)

A structured [RNA](ribonucleic-acid.md) recognition element bound by [iron regulatory proteins](iron-regulatory-protein.md). In suitable 5′ contexts it controls [biological translation](translation-biology.md), whereas a 3′ stability-control context can regulate [RNA decay](rna-decay.md). It is not an autonomous iron-sensing riboswitch.
