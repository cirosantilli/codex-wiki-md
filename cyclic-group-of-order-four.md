# Cyclic group of order four

↑ **Parent:** [Finite cyclic group](finite-cyclic-group.md)

The [cyclic group](cyclic-group.md) generated by $r$ with $r^4=e$ and $r^2\ne e$ has elements $e,r,r^2,r^3$. It is realized by quarter-turn [rotations](rotation-mathematics.md) of a plane. The [cyclic group of order four and Klein four-group](cyclic-group-of-order-four-and-klein-four-group.md) have the same order but different element orders: the latter has no element of order four.
