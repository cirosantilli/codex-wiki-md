# First true null argument for Holm control

↑ **Parent:** [Holm–Bonferroni method](holm-bonferroni-method.md)

If the [Holm step-down procedure](holm-bonferroni-method.md) makes a false rejection, it must reject the first true null in the ordered list. All $m_0$ true nulls remain at that step, so its cutoff is at most $\alpha/m_0$. The [union bound](boole-s-inequality.md) on their marginally valid [p-values](p-value.md) gives [familywise error rate](familywise-error-rate.md) at most $\alpha$. This proves strong control under arbitrary dependence, and super-uniformity suffices.
