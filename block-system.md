# Block system

↑ **Parent:** [Group action](group-action.md)

A block system for a [group action](group-action.md) is a partition of the acted-on set such that every [group](group-split.md) element permutes its parts. For a transitive action, a nontrivial block system has more than one part and more than one element per part. The full [symmetric group](symmetric-group.md) preserves no such partition: a [transposition](transposition-permutation.md) exchanging one point in each of two parts breaks it.
