# Word length

↑ **Parent:** [Word metric](word-metric.md)

The [word length](word-length.md) $|g|_S$ is the least number of letters from a symmetric [generating set of a group](generating-set-of-a-group.md) $S$ whose product is $g$. The empty word has length zero. It obeys $|gh|_S\leq|g|_S+|h|_S$, $|g^{-1}|_S=|g|_S$ and $d_S(g,h)=|g^{-1}h|_S$. The generating set may be infinite; finiteness is needed only for additional conclusions such as finite metric balls.
