# Geometrization of the Lorentz force by an affine connection

↑ **Parent:** [Lorentz force](lorentz-force.md)

For smooth stationary fields on $\mathbb R^3$, set $\Gamma^i{}_{tt}=-E^i$ and $\Gamma^i{}_{tj}=\Gamma^i{}_{jt}=\epsilon^i{}_{jk}B^k$, with all other [Christoffel symbols](christoffel-symbol.md) zero. This [torsion-free connection](torsion-free-connection.md) makes the equation $\ddot{\mathbf x}=\mathbf E+2\mathbf B\times\dot{\mathbf x}$ a [geodesic equation](geodesic-equation.md) with time as [affine parameter](affine-parameter.md). Arbitrary smooth fields suffice; a metric realization imposes additional potential conditions.
