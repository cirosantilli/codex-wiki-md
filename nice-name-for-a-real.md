# Nice name for a real

↑ **Parent:** [Forcing](forcing-split.md)

For a forcing order with the [countable chain condition for forcing](countable-chain-condition-for-forcing.md), a real can be represented by a nice name determined by a countable [antichain in a forcing order](antichain-in-a-forcing-order.md) for each natural-number coordinate. This bounds the number of reals in the extension in terms of the size of the forcing order.
