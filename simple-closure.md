# Simple closure

↑ **Parent:** [Substructure of a first-order structure](substructure-of-a-first-order-structure.md)

A [substructure](substructure-of-a-first-order-structure.md) $M\subseteq N$ is simply closed when each existential [quantifier-free formula](quantifier-free-formula.md) over $M$ realized in $N$ is already realized in $M$. A single quantified variable suffices in the definition; iterating covers finite tuples. This property is also called existential closure in this specified extension. It is weaker than being an [elementary substructure](elementary-substructure.md).
