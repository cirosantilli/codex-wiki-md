# Kirby diagram

↑ **Parent:** [Kirby calculus](kirby-calculus.md)

A Kirby diagram depicts a [handle decomposition](handle-decomposition.md) of a four-dimensional [manifold](topological-manifold.md) using a [framed link](framed-link.md) for the two-handles and dotted circles for the one-handles. The framing specifies the attaching normal directions; it controls the resulting [intersection form](intersection-form.md) and the boundary [Dehn surgery](dehn-surgery.md).
