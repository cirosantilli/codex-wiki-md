# Chi c meson

↑ **Parent:** [Charmonium](charmonium.md)

The spin-triplet P-wave [charmonium](charmonium.md) multiplet $1\,{}^3P_J$, with $J=0,1,2$ and $J^{PC}=0^{++},1^{++},2^{++}$. Radiative cascades between S-wave [vector mesons](vector-meson.md) and these states generate bands in three-body [Dalitz plots](dalitz-plot.md).
