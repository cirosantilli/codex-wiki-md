# Isomorphic embedding

↑ **Parent:** [Continuous linear operator](continuous-linear-operator.md)

An isomorphic embedding of [normed vector spaces](normed-vector-space-split.md) is an [injective](injective-function.md) [bounded linear operator](continuous-linear-operator.md) whose inverse on its [image](image-of-a-function.md) is bounded. Equivalently $\|Tx\|\geq c\|x\|$ for some $c>0$. The two-sided bounds make the domain and its [image](image-of-a-function.md) carry equivalent [norms](norm.md). If the domain is a [Banach space](banach-space-split.md), a convergent sequence $Tx_n$ has a [Cauchy sequence](cauchy-sequence.md) of preimages, so its limit remains in the [image](image-of-a-function.md); thus the [image](image-of-a-function.md) is closed.
