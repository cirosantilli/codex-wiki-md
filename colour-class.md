# Colour class

↑ **Parent:** [Finite coloring](finite-coloring.md)

A [colour class](colour-class.md) of a [finite colouring](finite-coloring.md) $c:X\to\{1,\ldots,r\}$ is a fibre $c^{-1}(i)$. Each [colour class](colour-class.md) is a [monochromatic set](monochromatic-set.md), and these fibres give a finite [set partition](set-partition.md) of $X$ after empty fibres are omitted.
