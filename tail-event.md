# Tail event

↑ **Parent:** [Tail sigma-algebra](tail-sigma-algebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tail_event)

A tail event is measurable with respect to a [tail sigma-algebra](tail-sigma-algebra.md), so changing finitely many coordinates does not affect whether it occurs.
