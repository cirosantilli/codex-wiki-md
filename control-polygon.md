# Control polygon

↑ **Parent:** [Control point](control-point.md)

A [control polygon](control-polygon.md) joins successive [control points](control-point.md) by [line segments](line-segment.md). It gives an editable geometric skeleton, not usually the exact [curve](curve.md). An open [control polygon](control-polygon.md) has two ends; a closed [control polygon](control-polygon.md) also joins the last [control point](control-point.md) to the first. Store the first [control point](control-point.md) only once when using cyclic indices, so the closing edge is counted exactly once. Positive [partition of unity](partition-of-unity.md) basis functions place the [curve](curve.md) inside the [convex hull](convex-hull.md) of its active [control points](control-point.md); a convergent [subdivision curve](subdivision-curve.md) rule refines the [control polygon](control-polygon.md) toward its limit, with a certified error when an appropriate bound is available.
