# Equalizer preservation by pullback-preserving functors

↑ **Parent:** [Limit-preserving functor](limit-preserving-functor.md)

If $\mathcal C$ has finite [categorical limits](categorical-limit.md), every [functor](functor.md) $F:\mathcal C\to\mathcal D$ preserving [pullbacks in a category](pullback-category-theory.md) also preserves [equalizers](equaliser.md), even when it does not preserve a [terminal object](terminal-object.md). Factor it through the [slice category](slice-category.md) $\mathcal D/F1$ by sending $A$ to $F(A\to1)$. This lifted functor preserves pullbacks because the slice [forgetful functor](forgetful-functor.md) reflects them; it also preserves the terminal object, so it preserves finite limits. The slice forgetful functor preserves equalizers, completing the proof.
