# Program identifier

↑ **Parent:** [Programming language syntax](programming-language-syntax.md)

A name used by a program, such as `x` in a [variable assignment](variable-assignment.md). An [abstract syntax tree](abstract-syntax-tree.md) can record the name without determining which value it denotes.
