# Controlled-Z update in the binary phase representation

↑ **Parent:** [Binary phase representation of a Pauli string](binary-phase-representation-of-a-pauli-string.md)

Conjugation by a [Controlled-Z gate](controlled-z-gate.md) leaves the $a$ bits unchanged and updates the displayed $b$ bits and phase, using the old bits. The phase occurs when the extra $Z$ from one line is moved past $X$ on the other line. These constant-size updates support [Heisenberg propagation of a Pauli observable through a Clifford circuit](heisenberg-propagation-of-a-pauli-observable-through-a-clifford-circuit.md).
