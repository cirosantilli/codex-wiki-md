# Comodule

↑ **Parent:** [Coalgebra](coalgebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Comodule)

A right comodule is an object $M$ with a [coaction](coaction.md) $\rho:M\to M\otimes C$ satisfying the coassociativity and [counit](counit.md) laws. This definition extends from [coalgebras](coalgebra.md) to [comonoids](comonoid.md) in a [monoidal category](monoidal-category.md).
