# Conduction aphasia

↑ **Parent:** [Aphasia](aphasia.md)

An aphasic pattern featuring disproportionately impaired repetition relative to some other [language](language.md) abilities. It can involve dorsal temporoparietal network dysfunction and is not proof of one isolated tract lesion in every case.
