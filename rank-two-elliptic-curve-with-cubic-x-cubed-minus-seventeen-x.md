# Rank-two elliptic curve with cubic x cubed minus seventeen x

↑ **Parent:** [Two-isogeny descent](two-isogeny-descent.md)

The [two-torsion square-class homomorphism](two-torsion-square-class-homomorphism.md) on $E$ has candidate classes $\{1,-1,17,-17\}$ by the [prime-support bound in two-isogeny descent](prime-support-bound-in-two-isogeny-descent.md). The identity, $(0,0)$ and $(-1,4)$ realize $1,-17,-1$, so multiplicativity gives all four. The [two-isogeny formula](two-isogeny-formula.md) companion $E':y^2=x^3+68x$ has only positive candidate classes $\{1,2,17,34\}$; $(0,0)$ realizes $[68]=17$ and $(2,12)$ realizes $2$. Thus both images have order four, and the [two-isogeny rank formula](square-class-index-formula-for-two-isogeny-descent.md) gives $2^r=4\cdot4/4=4$. The [rank of an elliptic curve](rank-of-an-elliptic-curve.md) is therefore two, without any unresolved covering class.
