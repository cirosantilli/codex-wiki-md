# Cross-link density inferred from rubber elasticity

↑ **Parent:** [Rubber elasticity](rubber-elasticity.md)

The ideal [rubber elasticity](rubber-elasticity.md) relation infers active strand [number density](number-density.md) from the [shear modulus](shear-modulus.md). If a quoted modulus is instead [Young's modulus](young-s-modulus.md), nearly incompressible behavior gives $\nu_s\simeq E/(3k_BT)$. This is not automatically the junction density: for junction functionality $f$ and no dangling ends or loops, counting strand ends gives $\nu_s=f\nu_j/2$. Network fluctuations and inactive strands modify the modulus, so converting it into a chemical [cross-link](cross-link.md) count requires a network model.
