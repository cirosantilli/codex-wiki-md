# Strike price

↑ **Parent:** [Financial asset](financial-asset.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Strike_price)

The fixed price parameter at which an option permits an underlying trade. A [European call option](european-call-option.md) pays $(S_T-K)^+$ at maturity; a [European put option](european-put-option.md) pays $(K-S_T)^+$. Specifying $K$ therefore determines how terminal prices translate into the [financial payoff](contingent-claim-payoff.md).
