# Mineral endmember

↑ **Parent:** [Mineral](mineral.md)

A specified limiting composition used to describe a [solid solution](solid-solution.md) in a [mineral](mineral.md). Its [thermodynamic activity](thermodynamic-activity.md) depends on the chosen [standard state](standard-state.md) and activity model. For example, [pyrope](pyrope.md) is a magnesian [garnet](garnet.md) endmember, while [phlogopite](phlogopite.md) is a magnesian [biotite](biotite.md) endmember.
