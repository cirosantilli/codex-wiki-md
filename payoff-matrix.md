# Payoff matrix

↑ **Parent:** [Matrix game](matrix-game.md)

A payoff matrix records the row player's gains when row $i$ meets column $j$. In a [zero-sum game](zero-sum-game.md) the other player's payoff is the negative. For [mixed strategies](mixed-strategy.md) $p,q$, the expected row payoff is $p^TAq$.
