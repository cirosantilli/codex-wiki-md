# Adsorption-site grand partition function

↑ **Parent:** [Langmuir adsorption model](langmuir-adsorption-model.md)

An independent site has one empty state and an occupied set with [binding energy](binding-energy.md) $-\epsilon$ and vibrational [partition function](canonical-partition-function.md) $z_s$. Its occupied probability is $\theta=z_s e^{\beta(\mu+\epsilon)}/[1+z_s e^{\beta(\mu+\epsilon)}]$. The denominator enforces the one-molecule-per-site constraint even though the vapour may obey classical statistics. Multiple occupancy or lateral interactions require a different model.
