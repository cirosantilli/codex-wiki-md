# Return probability from effective resistance

↑ **Parent:** [Effective resistance](effective-resistance.md)

For the conductance-weighted [random walk on a graph](random-walk-on-a-graph.md), set $d(x)=\sum_vc_{xv}$. The voltage $h(u)=P_u(T_x<T_y)$ has boundary values one and zero. The total [electric current](electric-current.md) is $\sum_vc_{xv}(1-h(v))=1/R(x,y)$. The [first-step analysis](first-step-analysis.md) therefore gives the displayed positive-return-time formula. Wiring the exterior of finite sets and taking limits gives $P_x(T_x^+=\infty)=1/(d(x)R(x,\infty))$.
