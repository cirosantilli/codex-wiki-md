# Longitudinal velocity structure function

↑ **Parent:** [Longitudinal velocity correlation](longitudinal-velocity-correlation.md)

The order-$p$ [longitudinal velocity structure function](longitudinal-velocity-structure-function.md) is $S_p(r)=\langle[u_L(\mathbf x+r\mathbf n)-u_L(\mathbf x)]^p\rangle$; absolute increments are used for noninteger orders. At second order $S_2=2u^2[1-f(r)]$. It suppresses a smooth common velocity but does not exactly remove all contributions from motions larger than the separation.
