<h1 id="21h/b/solution">Solution</h1>

↑ **Parent:** [B](../b.md)

For a real [antisymmetric matrix](../../../../../../skew-symmetric-matrix.md) $A$, $p^TAp=0$ for every real vector $p$. Thus for each row strategy $p$, the column player could choose $q=p$, giving $\min_qp^TAq\le0$. Hence the row security value is at most zero. Conversely, for each column strategy $q$, the row choice $p=q$ gives $\max_pp^TAq\ge0$, so the column security value is at least zero. The [minimax theorem](../../../../../../minimax-theorem.md) equates these values, proving

$$
\boxed{v=0.}
$$

The choices matching the opponent in this proof establish inequalities for security levels; they do not by themselves specify a single universal optimal strategy.
