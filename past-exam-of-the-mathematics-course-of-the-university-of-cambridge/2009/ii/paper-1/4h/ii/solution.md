<h1 id="4h/ii/solution">Solution</h1>

↑ **Parent:** [Ii](../ii.md)

**There is a genuinely different optimal procedure.** Exchange the codewords assigned to items three and four. Both have code length four, so each item's length, and hence the expected number of tests $173/55$, remains unchanged. The first tested subset now contains item three instead of item four, so this changes the tested groups rather than merely reversing the names of the two test outcomes. The new [prefix code](../../../../../../prefix-code.md) still identifies every item uniquely and retains the minimum [Huffman coding](../../../../../../huffman-coding.md) expectation.
