<h1 id="2/c/solution">Solution</h1>

↑ **Parent:** [C](../c.md)

**c1 is true for density-state controllability.** Every qubit [density operator](../../../../../../density-matrix.md) can be written $\rho=\lambda_2I+(\lambda_1-\lambda_2)|\psi\rangle\langle\psi|$ using its [eigenvalues](../../../../../../eigenvalue.md). A control taking one pure [orthogonal projector](../../../../../../orthogonal-projection.md) to any other therefore also connects every pair of qubit [density operators](../../../../../../density-matrix.md) with the same [spectrum](../../../../../../spectrum-functional-analysis.md). In Lie-algebra language, $\mathfrak{sp}(1)=\mathfrak{su}(2)$; there is no larger-dimensional symplectic exception. This does not supply arbitrary [global phase](../../../../../../global-phase.md): $SU(2)$ alone is already a counterexample to an implication involving strict operator controllability.

**c2 is false.** For every even $N=2\ell\ge4$, the defining $Sp(\ell)$ action is transitive on unit vectors, so a system generating this algebra is pure-state controllable. It still preserves additional mixed-state invariants and lacks [density operator controllability](../../../../../../density-operator-controllability.md), as the preceding explicit four-dimensional example demonstrates. [pure states](../../../../../../pure-state.md) have fewer orbit requirements than general [mixed states](../../../../../../mixed-state.md).
