Allocate a rectangular [Java array](../../../../../../java-array.md):
```
java
boolean[][] board = new boolean[1000][1000];
```
[Java](../../../../../../java-programming-language.md) initializes every new boolean array element to `false`, so **all cells are initially dead without a filling loop**. This allocates a top-level array of row references and a distinct boolean array for every row.
