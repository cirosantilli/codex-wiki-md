<h1 id="7/a/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

**Choose CLOCK for page replacement in a conventional operating system.** Good [temporal locality](../../../../../../../temporal-locality.md) makes recency valuable, and [CLOCK page replacement](../../../../../../../clock-page-replacement.md) captures it reasonably well using cheap reference flags. [FIFO page replacement](../../../../../../../fifo-page-replacement.md) ignores accesses after a page arrives, so it can evict a hot page. Exact [LRU replacement](../../../../../../../lru-replacement.md) has a stronger recency rule but recording and maintaining the order on every ordinary memory access is usually too costly. This is a practical cost-versus-hit-rate choice, not a theorem that [CLOCK page replacement](../../../../../../../clock-page-replacement.md) minimizes faults on every reference sequence.
