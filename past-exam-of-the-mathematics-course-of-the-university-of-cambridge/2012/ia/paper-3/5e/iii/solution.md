<h1 id="5e/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

Every nontrivial [subgroup](../../../../../../subgroup.md) of the [quaternion group](../../../../../../quaternion-group.md) contains $-1$. Indeed, it either contains $-1$ directly, or contains one of $\pm i,\pm j,\pm k$, whose square is $-1$.

Suppose $Q_8$ acts on an $n$-point set with $n<8$. Every [group orbit](../../../../../../orbit-of-a-group-action.md) has size at most $n<8$. By the [orbit-stabilizer theorem](../../../../../../orbit-stabilizer-theorem.md), each point's [stabilizer subgroup](../../../../../../stabilizer-subgroup.md) has order $8/|Q_8x|>1$, so it contains $-1$. Consequently $-1$ fixes every point, and the [group action](../../../../../../group-action.md) is not faithful. An embedding in $S_n$ would give a [faithful group action](../../../../../../faithful-group-action.md) on $n$ letters, which is impossible. Thus

$$
\boxed{Q_8\not\hookrightarrow S_n\quad(n<8).}
$$

The left-regular [group action](../../../../../../group-action.md) on eight points is faithful by [Cayley theorem](../../../../../../cayley-s-theorem.md), so the [minimal faithful permutation degree of the quaternion group](../../../../../../minimal-faithful-permutation-degree-of-the-quaternion-group.md) is exactly eight. The proof allows multiple [group orbits](../../../../../../orbit-of-a-group-action.md); restricting only to transitive actions would not suffice.
