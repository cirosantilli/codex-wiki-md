<h1 id="11e/b/solution">Solution</h1>

↑ **Parent:** [B](../b.md)

The set is the [ideal quotient](../../../../../../ideal-quotient.md) $K=(I:J)$. It contains zero. If $r,s\in K$, then $(r-s)J\subseteq I$, since $I$ is an [subgroup](../../../../../../subgroup.md). If $a\in R$ and $r\in K$, then $(ar)J=a(rJ)\subseteq I$ because $I$ is an [ideal](../../../../../../ideal.md). Thus $K$ is an [ideal](../../../../../../ideal.md).

Write $J=(a)$ and $K=(b)$. Because $I\subseteq J$, each $x\in I$ has the form $ar$. Then $rJ=r(aR)=xR\subseteq I$, so $r\in K$, and $x\in aK$. Conversely $aK\subseteq I$ by the definition of $K$. Therefore

$$
 \boxed{I=aK=(ab),}
$$

so $I$ is a [principal ideal](../../../../../../principal-ideal.md). This argument uses only the commutative ring convention, not cancellation or an [integral domain](../../../../../../integral-domain.md) hypothesis.
