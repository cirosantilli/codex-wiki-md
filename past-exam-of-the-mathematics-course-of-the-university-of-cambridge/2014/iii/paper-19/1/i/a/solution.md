In the [Lévy hierarchy](../../../../../../../levy-hierarchy.md), a [bounded formula in set theory](../../../../../../../bounded-formula-in-set-theory.md) has only quantifiers of the forms $\forall x\in y$ and $\exists x\in y$. A [Sigma-one formula in set theory](../../../../../../../sigma-one-formula-in-set-theory.md) is an existential unbounded quantifier block followed by a [bounded formula in set theory](../../../../../../../bounded-formula-in-set-theory.md), and a [Pi-one formula in set theory](../../../../../../../pi-one-formula-in-set-theory.md) has a universal unbounded block. **A formula is a [Delta-one formula modulo ZFC](../../../../../../../delta-one-formula-modulo-zfc.md) if [ZFC](../../../../../../../zermelo-fraenkel-set-theory-with-choice.md) proves it equivalent, with the same free variables, both to a $\Sigma_1$ formula and to a $\Pi_1$ formula.** Equivalence modulo the specified theory is part of the definition; it is not necessary that the original string have both syntactic forms. Such formulas satisfy the usual [Delta-one absoluteness](../../../../../../../delta-one-absoluteness.md) between [transitive models](../../../../../../../transitive-model.md) satisfying the relevant axioms. The modulo-ZF analogue is a [Delta-one formula in set theory](../../../../../../../delta-one-formula-in-set-theory.md).
