<h1 id="2/ii/solution">Solution</h1>

↑ **Parent:** [Ii](../ii.md)

Use one label for each member of $A$. More explicitly, set

$$
T_A=\{((a,\ldots,a),a\mathbin{\upharpoonright}n):a\in A,\ n<\omega\}
\subseteq(A\times\omega)^{<\omega}.
$$

An infinite branch through this [tree](../../../../../../tree-graph-theory.md) has a constant first coordinate $a\in A$ and second coordinate $a$, so $p[T_A]=A$. Thus $A$ is $A$-Suslin. Since $A\subseteq\omega^\omega$ injects into a set of [cardinality](../../../../../../cardinal-number.md) $2^{\aleph_0}$, part i makes $A$ a $2^{\aleph_0}$-[Suslin set](../../../../../../kappa-suslin-set.md). This proves that [Every set of reals is continuum-Suslin](../../../../../../every-set-of-reals-is-continuum-suslin.md).
