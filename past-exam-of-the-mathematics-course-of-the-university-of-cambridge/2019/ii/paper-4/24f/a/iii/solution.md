<h1 id="24f/a/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

For any smooth projective curve of [genus](../../../../../../../genus-of-a-surface.md) $g$, a [canonical divisor](../../../../../../../canonical-divisor.md) has degree $2g-2$. If this plane curve had genus two, part (ii) would imply

$$
d(d-3)=2,
$$

so $d^2-3d-2=0$. The [quadratic discriminant](../../../../../../../quadratic-discriminant.md) is $17$, which is not a [perfect square](../../../../../../../square-number.md), so the equation has no integral solution. Thus **a smooth projective plane curve cannot have genus two**, as recorded by [no smooth plane curve has genus two](../../../../../../../no-smooth-plane-curve-has-genus-two.md).
