<h1 id="5e/ii/solution">Solution</h1>

↑ **Parent:** [Ii](../ii.md)

The [empty-set cases for Cartesian projections](../../../../../../empty-set-cases-for-cartesian-projections.md) matter here. For $p_i$, write $X_j$ for the other factor. If $X_j$ is nonempty, any $x_i\in X_i$ can be paired with an element of $X_j$, so $p_i$ is [surjective](../../../../../../surjective-function.md). If $X_j$ is empty, the [Cartesian product](../../../../../../cartesian-product.md) is empty and its image is empty. Consequently

$$
\boxed{p_i\text{ is surjective}\iff X_i=\varnothing
\ \text{or}\ X_j\ne\varnothing.}
$$

The possibility $X_i=\varnothing$ is included because the empty [function](../../../../../../function-split.md) onto the empty set is [surjective](../../../../../../surjective-function.md).

If $X_i$ is empty, $p_i$ has empty domain and is [injective](../../../../../../injective-function.md). If $X_j$ has at most one element, an ordered pair is determined by its $i$th coordinate, so $p_i$ is also [injective](../../../../../../injective-function.md). Conversely, when $X_i$ is nonempty and $X_j$ contains two different elements, pairing those two elements with one fixed $x_i$ gives distinct ordered pairs with the same [projection map](../../../../../../projection-map.md). Therefore

$$
\boxed{p_i\text{ is injective}\iff X_i=\varnothing
\ \text{or}\ |X_j|\leq1.}
$$
