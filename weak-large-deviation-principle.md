# Weak large deviation principle

↑ **Parent:** [Large deviation principle](large-deviation-principle.md)

A weak [large deviation principle](large-deviation-principle.md) has the usual lower bound on every [open set](open-set.md), but requires the upper bound only on [compact sets](compact-space.md). It does not by itself control probabilities escaping every [compact set](compact-space.md). [Exponential tightness](exponential-tightness.md) provides that missing control.
