# Superspace integration

↑ **Parent:** [Superspace](superspace.md)

Superspace integration uses the [Berezin integral](berezin-integral.md) over [Grassmann variables](grassmann-variable.md). A chiral $d^2\theta$ integral extracts an [F-term](f-term.md), while a full $d^4\theta$ integral extracts a [D-term](d-term.md).
