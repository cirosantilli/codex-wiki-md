# Zero set

↑ **Parent:** [Zero of a function](zero-of-a-function.md)

The zero set of a [function](function-split.md) $f$ is the [preimage](preimage.md) $f^{-1}(\{0\})$, consisting of all its [zeros of a function](zero-of-a-function.md). For a real- or complex-valued [continuous function](continuous-function.md), it is a [closed set](closed-set.md), because the preimage of the closed singleton $\{0\}$ under a [continuous function](continuous-function.md) is closed. A nonzero [holomorphic function](holomorphic-function.md) on a connected open set has isolated zeros by the [identity theorem for holomorphic functions](identity-theorem.md).
