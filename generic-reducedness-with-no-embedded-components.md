# Generic reducedness with no embedded components

↑ **Parent:** [Reduced scheme](reduced-scheme.md)

A Noetherian scheme with no embedded [associated primes](associated-prime-of-a-module.md) is reduced if it is reduced at all its generic points. Locally, a nonzero nilpotent ideal would have an [associated prime](associated-prime-of-a-module.md), necessarily a minimal prime. Its localization there would be nonzero, contradicting generic reducedness. This is useful with the [unmixedness of a complete intersection](unmixedness-of-a-complete-intersection.md).
