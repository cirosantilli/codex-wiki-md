# Context-sensitive Hilbert weakening

↑ **Parent:** [Weakening](weakening.md)

Thinning enlarges the assumptions without changing a conclusion. In a predicate-calculus presentation with context-sensitive [generalization](universal-generalization-rule.md), a [generalization](universal-generalization-rule.md) valid before adding an unused assumption may not be replayable with that assumption open. An explicit [weakening](weakening.md) step nevertheless imports the already proved conclusion. In propositional calculus with only axiom schemes and [modus ponens](implication-elimination-rule.md), [weakening](weakening.md) is admissible by replaying the proof. The need for a separately stated rule depends on how proof dependencies are represented.
