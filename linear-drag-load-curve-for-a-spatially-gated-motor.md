# Linear-drag load curve for a spatially gated motor

↑ **Parent:** [Constant-force spatially gated motor](constant-force-spatially-gated-motor.md)

With positive opposing load magnitude $L$ and positive [viscous drag coefficient](viscous-drag-coefficient.md) $\gamma$, steady contraction requires $L=N\langle f\rangle-\gamma u$. A decreasing motor [force](force-split.md) curve and an increasing drag-magnitude line have a unique intersection for each load below the limiting stall [force](force-split.md). Using $+\gamma u$ as the signed drag would instead make drag assist forward motion, reversing its physical role.
