# Schreier index-rank inequality

↑ **Parent:** [Nielsen–Schreier theorem](nielsen-schreier-theorem.md)

If $H$ has finite index $d$ in a [finitely generated group](finitely-generated-group.md) $G$, then [Schreier's lemma](schreier-s-lemma.md) gives

$$
\boxed{d(H)\leq 1+d\bigl(d(G)-1\bigr).}
$$

Equality holds when $G$ is a [free group](free-group.md) of finite rank.
