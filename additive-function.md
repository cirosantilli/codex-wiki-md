# Additive function

↑ **Parent:** [Cauchy's functional equation](cauchy-s-functional-equation.md)

An additive function on an [additive semigroup](additive-semigroup.md) satisfies $f(x+y)=f(x)+f(y)$ whenever $x$, $y$, and $x+y$ belong to its domain.

For [real numbers](real-number.md), an [additive function](additive-function.md) is a [group homomorphism](group-homomorphism.md) from $(\mathbb R,+)$ to itself. It preserves [scalar multiplication](scalar-multiplication.md) by every [rational number](rational-number.md), so it is a [linear map](linear-map.md) when domain and codomain are viewed as [vector spaces over the rational numbers](vector-space-over-the-rational-numbers.md). Being a [linear map](linear-map.md) over the [real numbers](real-number.md) additionally requires $f(tx)=tf(x)$ for every [real number](real-number.md) $t$. On the [real line](real-line.md) this stronger condition is equivalent to $f(x)=xf(1)$. Additivity alone does not imply it.
