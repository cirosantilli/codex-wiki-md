# Quasi-projective algebraic set

↑ **Parent:** [Algebraic variety](algebraic-variety.md)

A locally closed [affine algebraic set](affine-algebraic-set.md) in a [projective space](projective-space-split.md), equivalently an [open subset](open-set.md) of a closed subset of [projective space](projective-space-split.md) cut out by homogeneous polynomials. Reducibility is allowed for an algebraic set; an [irreducible variety](irreducible-variety.md) with such an embedding is a [quasi-projective variety](quasi-projective-variety.md).
