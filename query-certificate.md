# Query certificate

↑ **Parent:** [Certificate complexity of a Boolean function](certificate-complexity-of-a-boolean-function.md)

For a [Boolean function](boolean-function.md) $f$ and a chosen input $x$, a set of coordinates $S$ is a [query certificate](query-certificate.md) if every $y$ agreeing with $x$ on $S$ has $f(y)=f(x)$. It fixes actual input bits rather than supplying an independently guessed [certificate](certificate-complexity.md) to an NP verifier. Minimizing its size at each input and then maximizing gives [query certificate complexity](certificate-complexity-of-a-boolean-function.md).
