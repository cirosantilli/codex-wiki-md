# Prime number theorem error from a fixed zero-free strip

↑ **Parent:** [Prime number theorem](prime-number-theorem.md)

If all nontrivial zeta zeros satisfy $\Re\rho\leq1-c$ with fixed $0<c<1/2$, the [Riemann–von Mangoldt formula](riemann-von-mangoldt-formula.md) gives $\sum_{|\rho|<T}|\rho|^{-1}\ll\log^2T$. The [truncated explicit formula for the second Chebyshev function](truncated-explicit-formula-for-the-second-chebyshev-function.md) then bounds the error by $O(x^{1-c}\log^2T+x\log^2x/T)$. Choosing $T=x^c$ gives the displayed bound and, for every positive $\varepsilon$, $O_\varepsilon(x^{1-c+\varepsilon})$.
