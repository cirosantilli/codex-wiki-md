<h1 id="don-t-care-term">Don't-care term</h1>

↑ **Parent:** [Boolean function](boolean-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Don't-care_term)

An input combination at which a [Boolean function](boolean-function.md)'s specification imposes no required output value. [Karnaugh map](karnaugh-map.md) minimization may assign either value independently to simplify the implemented [Boolean circuit](boolean-circuit.md). The resulting circuit still assigns a definite output to every input. An unused [finite-state machine](finite-state-machine.md) encoding is therefore an optimization opportunity, but its eventual transitions must be checked if recovery from that encoding matters.
