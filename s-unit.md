# S-unit

↑ **Parent:** [S-unit group](s-unit-group.md)

An S-unit in a [number field](number-field.md) $K$ is an element $u\in K^*$ whose valuations outside the finite set $S$ vanish. Equivalently, it is a unit of the ring of S-integers $\mathcal O_{K,S}$. The [S-unit group](s-unit-group.md) is finitely generated by the [Dirichlet unit theorem](dirichlet-s-unit-theorem.md) together with generators arising from the inverted primes.
