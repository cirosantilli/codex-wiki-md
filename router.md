# Router

↑ **Parent:** [Computer network](computer-network-split.md)

A [router](router.md) forwards [network packets](network-packet.md) between networks using forwarding information. Ordinary [Internet Protocol](internet-protocol.md) forwarding is distinct from a [middlebox](middlebox.md) function that translates addresses, terminates a transport connection or applies an application-specific transformation.
