# Infinitely many reciprocal-logarithmic gaps between zeta zeros

↑ **Parent:** [Riemann–von Mangoldt formula](riemann-von-mangoldt-formula.md)

List positive ordinates of [Nontrivial zeros of the Riemann zeta function](nontrivial-zero-of-the-riemann-zeta-function.md) in nondecreasing order, including [multiplicity](multiplicity-mathematics.md). If all sufficiently late gaps were at most $c/\log n$, summing would give $\gamma_n\le(c+o(1))n/\log n$, since $\sum_{j\le n}1/\log j\sim n/\log n$ with the sum starting at two. The [Riemann–von Mangoldt formula](riemann-von-mangoldt-formula.md) would then give $n\le N(\gamma_n)\le(c/(2\pi)+o(1))n$, a contradiction when $c<2\pi$. The same argument applies when only distinct ordinates are listed, because $n\le N(\gamma_n)$ still holds.
