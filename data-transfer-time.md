# Data transfer time

↑ **Parent:** [Latency (engineering)](latency-engineering.md)

At constant transfer rate $v$ bytes per second, moving $B$ bytes takes $B/v$ seconds. The size and rate must use compatible units. This term alone does not include [seek time](seek-time.md), [rotational latency](rotational-latency.md) or controller setup costs.
