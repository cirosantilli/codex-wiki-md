# Shortest conjugacy representative

↑ **Parent:** [Conjugacy class](conjugacy-class.md)

A [shortest conjugacy representative](shortest-conjugacy-representative.md) is a word having the fewest written letters among all words representing elements of a fixed [conjugacy class](conjugacy-class.md). This minimum equals the least group [word length](word-length.md) of an element in the class; a longer spelling of that element is not itself a shortest representative. Such a word exists because lengths are nonnegative integers. It is freely and cyclically reduced: free cancellation shortens the same representative, while removing mutually inverse first and last letters shortens a conjugate. Every cyclic rotation has the same minimal length.
