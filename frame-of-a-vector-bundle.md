# Frame of a vector bundle

↑ **Parent:** [Vector bundle trivialization](vector-bundle-trivialization.md)

A frame over an open set $U$ is a list of smooth sections $e_1,\ldots,e_r$ of a rank-$r$ [vector bundle](vector-bundle.md) whose values form a basis in every fibre over $U$. It is equivalent to a [vector bundle trivialization](vector-bundle-trivialization.md) by $(x,v)\mapsto\sum_a e_a(x)v^a$. Two local frames differ by a smooth map $g:U\to\mathrm{GL}(r)$, written $e'=eg$.
