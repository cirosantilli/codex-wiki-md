# Comeagre set

↑ **Parent:** [Meagre set](meagre-set.md)

The complement of a comeagre set is a [meagre set](meagre-set.md), a countable union of nowhere dense sets. A dense [G-delta set](g-delta-set.md) is comeagre. The [Baire category theorem](baire-category-theorem.md) ensures that two comeagre subsets of a nonempty complete [metric](metric.md) space cannot be disjoint.
