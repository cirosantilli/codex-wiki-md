# Time-zero correction for a half-point dyadic spike martingale

↑ **Parent:** [Dyadic filtration](dyadic-filtration.md)

On $(0,1]$ with Lebesgue probability and the usual [dyadic filtration](dyadic-filtration.md), each displayed support is a dyadic atom. Its next split has one child of doubled height and one of zero height, preserving the conditional average. Hence the sequence is a [martingale](martingale-split.md) from time one. To extend it to the trivial time-zero [sigma-algebra](sigma-algebra.md) one must set $X_0=1$: applying the same displayed formula at zero instead gives $\mathbf1_{(0,1/2]}$, which is not adapted and has the wrong [expected value](expected-value-split.md). The repaired [martingale](martingale-split.md) tends to zero almost surely while its [expected values](expected-value-split.md) remain one, so it is not uniformly integrable.
