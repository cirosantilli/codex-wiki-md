# Sallen-Key low-pass filter

↑ **Parent:** [Low-pass filter](low-pass-filter.md)

A second-order active low-pass architecture using a non-inverting amplifier and a resistor-capacitor network with output feedback into the network. For the convention with $R_1$ from source to A, $R_2$ from A to the non-inverting input, $C_2$ from that input to ground and $C_1$ from A to output, $a=C_1R_1(1-K)+C_2(R_1+R_2)$ and $b=R_1R_2C_1C_2$. The [poles](pole.md), not merely finite values of $G(i\omega)$, determine whether a settled sinusoidal response exists.[Section 3, low-pass transfer-function derivation](analysis-of-the-sallen-key-architecture-by-james-karki.md)
