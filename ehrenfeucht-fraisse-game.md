<h1 id="ehrenfeucht-fraisse-game">Ehrenfeucht-Fraïssé game</h1>

↑ **Parent:** [Model theory](model-theory.md)

In each round the Spoiler selects an element from either structure and the Duplicator responds in the other. The paired selected elements must preserve all atomic information and equality, giving a [partial isomorphism of structures](partial-embedding.md). In the infinite game the Duplicator wins by avoiding failure at every finite stage. In a timed game the Spoiler first announces the number of rounds, allowing a different response strategy for each horizon.
