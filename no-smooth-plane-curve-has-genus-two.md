# No smooth plane curve has genus two

↑ **Parent:** [Genus of a smooth plane curve](genus-of-a-smooth-plane-curve.md)

If a smooth degree-$d$ [projective plane curve](projective-plane-curve.md) had genus two, the [genus-degree formula](genus-degree-formula.md) would give $(d-1)(d-2)=4$, equivalently $d^2-3d-2=0$. Its discriminant is $17$, so it has no integral solution for the degree $d$.
