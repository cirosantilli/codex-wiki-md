# Terminal finite-coproduct-preserving set endofunctor

↑ **Parent:** [Ultrafilter functor](ultrafilter-functor.md)

The [ultrafilter functor](ultrafilter-functor.md) is terminal among endofunctors of $\mathbf{Set}$ that preserve finite coproducts. For such an endofunctor $F$ and $x\in F(A)$, the unique natural map sends $x$ to

$$
\{B\subseteq A:x\in\operatorname{im}(F(B)\to F(A))\}.
$$
