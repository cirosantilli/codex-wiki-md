# Particular solution

↑ **Parent:** [Linear ordinary differential equation](linear-ordinary-differential-equation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Particular_solution)

A particular solution is any one solution of a forced linear differential equation. Every solution is the sum of that particular solution and an arbitrary [homogeneous solution](homogeneous-solution.md).
