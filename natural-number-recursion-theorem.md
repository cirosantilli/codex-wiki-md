# Natural-number recursion theorem

↑ **Parent:** [Transfinite recursion](transfinite-recursion.md)

Given an initial value $a$ and a rule $G$, there is a unique function $F$ on $\omega$ satisfying $F(0)=a$ and $F(n+1)=G(F(n))$.
