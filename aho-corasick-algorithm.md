# Aho-Corasick algorithm

↑ **Parent:** [Algorithm](algorithm-split.md)

The Aho-Corasick algorithm matches multiple patterns in a [string](string.md) using a [trie](trie.md) equipped with failure links. After preprocessing the patterns, it scans the input while reporting every pattern ending at each position.
