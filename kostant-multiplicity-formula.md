# Kostant multiplicity formula

↑ **Parent:** [Weight multiplicity](weight-multiplicity.md)

Multiply the [Weyl character formula](weyl-character-formula.md) by the [generating series of the Kostant partition function](generating-series-of-the-kostant-partition-function.md). In each numerator summand, the coefficient of $e^\mu$ occurs when $\nu=w(\lambda+\rho)-(\mu+\rho)$. Summing those coefficients with the [Weyl group](weyl-group.md) signs proves the displayed [weight multiplicity](weight-multiplicity.md) formula. Although $\rho$ need not itself be an integral [group](group-split.md) [weight](weight-representation-theory.md), $w\rho-\rho$ is in the [root lattice](root-lattice.md), so each partition-function argument is an integral [weight](weight-representation-theory.md).
