# Network latency

↑ **Parent:** [Computer network](computer-network-split.md)

[Network latency](network-latency.md) is the delay associated with communication over a network, distinguished from the rate at which data can be transferred. Moving a delivery [endpoint](communication-endpoint.md) closer to demand can reduce some path delay, but does not by itself establish application correctness or independent control.
