# Slam-dunk move

↑ **Parent:** [Kirby calculus](kirby-calculus.md)

If a [meridian of a knot](meridian-of-a-knot.md) component in a surgery [link](link.md) links only one other component, filling it with coefficient $b\ne0$ removes it and replaces the other coefficient $a$ by $a-1/b$. This gives the negative continued-fraction chain description of rational [Dehn filling](dehn-filling.md).
