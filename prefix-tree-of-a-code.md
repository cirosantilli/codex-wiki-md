# Prefix tree of a code

↑ **Parent:** [Prefix code](prefix-code.md)

The prefix tree of a code has vertices corresponding to prefixes of codewords, with one edge for each next symbol. The root represents the empty word. In a prefix code, complete codewords are leaves, and their depths are their [codeword lengths](codeword-length.md).
