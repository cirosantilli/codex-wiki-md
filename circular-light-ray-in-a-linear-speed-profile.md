# Circular light ray in a linear speed profile

↑ **Parent:** [Light ray](light-ray.md)

For speed $c(y)=y+c_0>0$, [Fermat principle](fermat-principle.md) and the [Beltrami identity](beltrami-identity.md) yield circular [light rays](light-ray.md) whose centres lie on $y=-c_0$. The ray between $(\pm a,0)$ in the upper half-plane is $y=\sqrt{a^2+c_0^2-x^2}-c_0$.
