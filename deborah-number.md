# Deborah number

↑ **Parent:** [Viscoelasticity](viscoelasticity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Deborah_number)

The Deborah number compares a material's [viscoelastic relaxation time](viscoelastic-relaxation-time.md) with the time scale of an imposed process. A small value allows substantial [stress relaxation](stress-relaxation.md) during that process; a large value can reveal stored [elasticity](elasticity-physics.md). In [small-amplitude oscillatory shear](small-amplitude-oscillatory-shear.md), one commonly uses $\mathrm{De}=\omega\tau$. Large frequency does not by itself invalidate a [linear viscoelastic fluid](linear-viscoelastic-fluid.md) approximation if the deformation amplitude remains sufficiently small.
