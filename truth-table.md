# Truth table

↑ **Parent:** [Boolean valuation](boolean-valuation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Truth_table)

A truth table lists a finite formula's value for every Boolean valuation of the finitely many primitive propositions that occur in it.
