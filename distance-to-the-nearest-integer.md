# Distance to the nearest integer

↑ **Parent:** [Diophantine approximation](diophantine-approximation.md)

For a [real number](real-number.md) $x$, define $\|x\|_{\mathbb R/\mathbb Z}=\min_{k\in\mathbb Z}|x-k|$. It lies in $[0,1/2]$ and obeys $\|\ell x\|\leq|\ell|\|x\|$ for an [integer](integer.md) $\ell$. It is a distance on the circle, rather than a [norm](norm.md) on the real vector space.
