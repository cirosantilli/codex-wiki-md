# Binary self-dual code contains the all-ones word

↑ **Parent:** [Self-dual code](self-dual-code.md)

For a binary [self-dual code](self-dual-code.md), every word $c$ satisfies $c\cdot c=0$. In characteristic two this is $\sum_i c_i=0$, so the all-ones word is orthogonal to every [codeword](codeword.md) and lies in the [dual code](dual-code.md), hence the code itself. The [dual code](dual-code.md) [dimension](dimension-vector-space.md) identity gives even length and half-length [dimension](dimension-vector-space.md).
