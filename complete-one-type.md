# Complete one-type

↑ **Parent:** [Complete type](complete-type.md)

A [complete one-type](complete-one-type.md) is a [complete type](complete-type.md) in one [free variable](free-variable.md). It chooses exactly one of each [first-order formula](first-order-formula.md) and its [negation](negation.md) consistently with the [first-order theory](first-order-theory.md) and the named parameters.
