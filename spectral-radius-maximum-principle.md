# Spectral-radius maximum principle

↑ **Parent:** [Banach-space-valued holomorphic function](banach-space-valued-holomorphic-function.md)

For a [Banach algebra](banach-algebra-split.md)-valued [holomorphic function](holomorphic-function.md), set $p_n(w)=\|f(w)^{2^n}\|^{1/2^n}$. These [continuous](continuous-function.md) functions decrease to the [spectral radius](spectral-radius.md) by the [spectral radius formula](spectral-radius-formula.md). If $M=\sup_{\partial K}r(f(w))$, the [continuous](continuous-function.md) functions $\max\{p_n,M\}$ on $\partial K$ decrease to the [continuous](continuous-function.md) constant $M$. The [Dini theorem](dini-s-theorem.md) gives [uniform convergence](uniform-convergence.md). Apply the [norm maximum principle for a Banach-space-valued holomorphic function](norm-maximum-principle-for-a-banach-space-valued-holomorphic-function.md) to each power, and then let $n\to\infty$. This proof does not assume [continuity](continuous-function.md) of [spectral radius](spectral-radius.md).
