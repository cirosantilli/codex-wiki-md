# Simple cooperative game

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

A simple cooperative game is a monotone [transferable utility game](transferable-utility-game.md) in which each [coalition](coalition-game-theory.md) either loses, with value zero, or wins, with value one. In the usual nontrivial convention the empty [coalition](coalition-game-theory.md) loses and the grand [coalition](coalition-game-theory.md) wins. The [Shapley value](shapley-value.md) is then the [probability](probability.md) that a player changes a losing [coalition](coalition-game-theory.md) into a winning one when players enter in uniformly random order.
