# Next-time operator

↑ **Parent:** [Temporal operator](temporal-operator.md)

The [linear temporal logic](linear-temporal-logic.md) operator $X\alpha$, true at position $i$ of a [path in a transition system](path-in-a-transition-system.md) exactly when $\alpha$ is true at position $i+1$. Thus $XX\alpha$ tests two positions ahead.
