# Poisson exponential tilting for a loss network

↑ **Parent:** [Entropy maximization for loss-network occupancy](entropy-maximization-for-loss-network-occupancy.md)

Substituting the optimizer relation $\nu_r=x_r^*e^{(A^Tz)_r}$ into the [product-form stationary distribution of a loss network](product-form-stationary-distribution-of-a-loss-network.md) proves the displayed exact identity. The independent [Poisson random variables](poisson-distribution.md) give a reference law centered at the optimized occupancies, while the constraint and exponential factor account for saturated resources. An unconstrained [Gaussian approximation](normal-approximation.md) can miss these boundary effects.
