# Portfolio wealth

↑ **Parent:** [Investment portfolio](investment-portfolio.md)

The value of an [investment portfolio](investment-portfolio.md), obtained by summing each holding times its current asset price. [Consumption](consumption.md) removes money from [portfolio wealth](portfolio-wealth.md); a [self-financing portfolio](self-financing-portfolio.md) changes its value only through asset gains. Nonnegative [portfolio wealth](portfolio-wealth.md) is a common admissibility restriction in an [investment-consumption problem](investment-consumption-problem.md).
