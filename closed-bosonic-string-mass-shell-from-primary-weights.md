# Closed-bosonic-string mass shell from primary weights

↑ **Parent:** [Bosonic string mass spectrum](bosonic-string-mass-spectrum.md)

A matter vertex with left and right oscillator levels $N,\widetilde N$ and momentum $k$ has weights $N+\alpha'k^2/4,\widetilde N+\alpha'k^2/4$. An [integrated string vertex operator](integrated-string-vertex-operator.md) must have weights $(1,1)$, giving the displayed mass shell and level matching with $M^2=-k^2$. Physical states are further identified modulo [null string states](null-string-state.md), equivalently through [BRST cohomology](brst-cohomology.md); merely counting all weight-one primaries would include gauge redundancies.
