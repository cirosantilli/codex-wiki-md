# Half-line drift global relation

↑ **Parent:** [Global relation for a linear boundary value problem](global-relation-for-a-linear-boundary-value-problem.md)

For the [advection-diffusion equation](advection-diffusion-equation.md) $u_t=u_{xx}+\alpha u_x$ on $x>0$, the spectral [divergence form](divergence-form.md) uses $\omega=k^2-i\alpha k$ and factor $e^{-ikx+\omega t}$. With negative-exponential [Half-range Fourier transforms](half-range-fourier-transform.md), integration gives the displayed [global relation](global-relation-for-a-linear-boundary-value-problem.md) for $\operatorname{Im}k\le0$. The boundary transform $G_1$ refers to $u_x(0,t)$, the negative of the outward [normal derivative](normal-derivative.md).
