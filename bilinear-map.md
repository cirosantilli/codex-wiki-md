# Bilinear map

↑ **Parent:** [Multilinear map](multilinear-map.md)

A bilinear map is a map $B:V\times W\to U$ between [vector spaces](vector-space-split.md) that is [linear](linearity.md) in each argument when the other is fixed. The nonlinear [temperature](temperature.md) [advection](advection.md) can be written as the diagonal of a bilinear map, $\mathcal N(\phi,\chi)=-\mathbf u[\phi]\cdot\nabla\chi$, when [velocity](velocity.md) depends linearly on [temperature](temperature.md). Unlike a [bilinear form](bilinear-form.md), its output need not be a scalar.
