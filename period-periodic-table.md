# Period (periodic table)

↑ **Parent:** [Periodic table](periodic-table.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Period_(periodic_table))

A [periodic table period](period-periodic-table.md) is a horizontal row of the [periodic table](periodic-table.md), read in increasing [atomic number](atomic-number.md). [Periodic table period](period-periodic-table.md) 2 runs from [lithium](lithium.md), $Z=3$, to [neon](neon.md), $Z=10$: $10-3+1=8$ [chemical elements](chemical-element.md). In these neutral [ground states](ground-state.md), the second [electron shell](electron-shell.md) gains [electrons](electron.md) while the first retains two.
