# Cohomological injectivity of a degree-one map

↑ **Parent:** [Poincare duality](poincare-duality.md)

A degree-one map $f:M\to N$ between closed connected oriented manifolds of the same dimension induces an injection $f^*:H^*(N;R)\to H^*(M;R)$. The wrong-way map defined using [Poincare duality](poincare-duality.md) is a left inverse by the projection formula and $f_*[M]=[N]$.
