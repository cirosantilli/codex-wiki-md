# Anisotropic stress

↑ **Parent:** [Stress-energy tensor](stress-energy-tensor.md)

In a local [orthonormal tetrad](orthonormal-frame-in-spacetime.md), [anisotropic stress](anisotropic-stress.md) is the trace-free spatial part of the [stress-energy tensor](stress-energy-tensor.md), conventionally denoted $\pi^{ij}$. Some [linear cosmological perturbation theory](linear-cosmological-perturbation-theory-split.md) conventions instead use $\Pi^{ij}=-\pi^{ij}$ and write $T^{ij}=P\delta^{ij}-\Pi^{ij}$. The sign must be specified before using a [photon Euler equation](photon-euler-equation.md). The [photon quadrupole](photon-quadrupole.md) determines the linear [photon](photon.md) [anisotropic stress](anisotropic-stress.md).
