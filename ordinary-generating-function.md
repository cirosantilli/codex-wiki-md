# Ordinary generating function

↑ **Parent:** [Formal power series](formal-power-series.md)

This is the power-series specialization of a [generating function](generating-function.md).

The ordinary generating function of a sequence $(a_n)_{n\geq0}$ is the [formal power series](formal-power-series.md) $A(z)=\sum_{n\geq0}a_nz^n$. Algebraic identities for $A$ encode recurrences and counting constructions for the coefficients.
