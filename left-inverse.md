# Left inverse

↑ **Parent:** [Inverse function](inverse-function.md)

A left inverse of a [function](function-split.md) $f:X\to Y$ is a function $g:Y\to X$ satisfying $g\circ f=\operatorname{id}_X$. It forces $f$ to be [injective](injective-function.md), since equal images can be mapped back to equal original elements.
