# Unipotent matrix

↑ **Parent:** [Unipotent element of an affine algebraic group](unipotent-element-of-an-affine-algebraic-group.md)

A square [matrix](matrix.md) $U$ is unipotent when $U-I$ is nilpotent. Over an [algebraically closed field](algebraically-closed-field.md), this is equivalent to all [eigenvalues](eigenvalue.md) being one. If $j$ belongs to a [nilpotent ideal](nilpotent-ideal.md) of an operator algebra, $I+j$ is a unipotent matrix. This realizes the radical factor in the [Levi decomposition of a quiver automorphism group](levi-decomposition-of-a-quiver-automorphism-group.md).
