# Principal component function

↑ **Parent:** [Functional principal component analysis](functional-principal-component-analysis.md)

A principal component function is a normalized [eigenfunction](eigenfunction.md) $\phi_k$ of a [covariance operator](covariance-operator.md), ordered by decreasing eigenvalue $\lambda_k$.
