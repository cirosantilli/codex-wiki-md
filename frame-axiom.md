# Frame axiom

↑ **Parent:** [Classical planning](classical-planning.md)

A condition specifying when a fact remains unchanged by an action. In [STRIPS](strips.md), facts outside the add and delete lists persist. A [successor-state axiom](successor-state-axiom.md) combines these persistence conditions with all action effects that can change the fact.
