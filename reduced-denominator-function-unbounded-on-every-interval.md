# Reduced-denominator function unbounded on every interval

↑ **Parent:** [Thomae function](thomae-function.md)

On $[0,1]$, use reduced representations of [rational numbers](rational-number.md) with positive denominator. This reverses the nonzero values of the [Thomae function](thomae-function.md), while leaving its values at [irrational numbers](irrational-number.md) zero. Every interval of positive length contains [rational numbers](rational-number.md) of arbitrarily large reduced denominator: there are only finitely many fractions in $[0,1]$ with denominator at most a fixed $M$, whereas any open interval contains infinitely many [rational numbers](rational-number.md). Thus this [function](function-split.md) taking finite [real number](real-number.md) values is unbounded on every nondegenerate subinterval.
