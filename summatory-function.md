# Summatory function

↑ **Parent:** [Arithmetic function](arithmetic-function-split.md)

The summatory function of an [arithmetic function](arithmetic-function-split.md) $a$ is $A(x)=\sum_{1\le n\le x}a(n)$. For example, the [prime-counting function](prime-counting-function.md) sums the indicator of the [prime numbers](prime-number-split.md), while the [divisor summatory function](divisor-summatory-function.md) sums the [divisor function](divisor-function.md). Grouping equal values of $\lfloor x/d\rfloor$ often speeds up identities involving summatory functions.
