# Connected component of a category

↑ **Parent:** [Connected category](connected-category.md)

Two objects of a [category](category-split.md) lie in the same connected component if a finite zigzag of [morphisms](morphism.md), with either orientation allowed, joins them. This is an [equivalence relation](equivalence-relation.md); its classes give full [subcategories](subcategory.md), each a [connected category](connected-category.md). For a [small category](small-category.md), the collection of components is a [set](set-split.md) denoted $\pi_0(\mathcal C)$. A [functor](functor.md) induces a function on components. Empty categories have no components.
