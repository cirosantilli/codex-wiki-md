# CP transformation of a non-Abelian gauge connection

↑ **Parent:** [Gauge field](gauge-field.md)

For vector coupling to a Dirac [fermion](fermion.md), write the Hermitian color connection $\mathcal A_\mu=A_\mu^aT^a$. [Charge conjugation](charge-conjugation.md) reverses the vector current and transposes its color matrix, requiring $\mathcal A_\mu^C=-\mathcal A_\mu^T$. Combining with [parity](parity.md) gives $\mathcal A_\mu^{CP}(x)=-P_\mu{}^\nu\mathcal A_\nu^T(x_P)$, where $P=\operatorname{diag}(1,-1,-1,-1)$. The transpose acts only on color indices; intrinsic [fermion](fermion.md) phases cancel in the bilinear.
