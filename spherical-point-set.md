# Spherical point set

↑ **Parent:** [Euclidean Ramsey set](euclidean-ramsey-set.md)

A finite point set is spherical when it lies on a [sphere](sphere.md). Every [Euclidean Ramsey set](euclidean-ramsey-set.md) is spherical. Whether every finite spherical point set is Euclidean Ramsey is open.
