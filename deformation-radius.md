# Deformation radius

↑ **Parent:** [Geophysical fluid dynamics](geophysical-fluid-dynamics-split.md)

A horizontal scale comparing gravitational or buoyancy restoring forces with rotation. For a shallow-water gravity mode with propagation speed $c$, the [deformation radius](deformation-radius.md) is $c/|f|$. The [barotropic deformation radius](barotropic-deformation-radius.md) uses $c=\sqrt{gH}$; internal layered modes use a speed set by [reduced gravity](reduced-gravity-split.md) and layer depths.
