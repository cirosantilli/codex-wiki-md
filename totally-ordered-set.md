# Totally ordered set

↑ **Parent:** [Total order](total-order.md)

A [totally ordered set](totally-ordered-set.md) is a set equipped with a [total order](total-order.md). Internally in a [topos](elementary-topos.md), weak totality does not imply decidable equality. The empty ordered set is allowed unless an inhabitation axiom is explicitly imposed.
