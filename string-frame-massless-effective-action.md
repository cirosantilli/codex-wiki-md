# String-frame massless effective action

↑ **Parent:** [String nonlinear sigma model](string-nonlinear-sigma-model.md)

The leading massless-sector spacetime action is proportional to $\int\sqrt{-G}e^{-2\Phi}[R+4(\nabla\Phi)^2-H^2/12]$, with $H=dB$. The backgrounds are the [string-frame metric](string-frame-metric.md), [dilaton](dilaton.md), and [Kalb–Ramond field](kalb-ramond-field.md). Massive string exchange generates higher-derivative corrections ordered by $\alpha'$. This perturbative bosonic massless-sector truncation does not remove the [tachyon](tachyon.md) instability.
