# Query complexity

↑ **Parent:** [Computational complexity theory](computational-complexity-theory.md)

The number of accesses to an unknown input needed to solve a specified task. The input might be a string with individually readable entries, or an implicitly supplied function. A complete statement specifies deterministic, randomized, or quantum access, the accepted error, and worst-case or expected cost. [Quantum query complexity](quantum-query-complexity.md) permits coherent input access through a [quantum oracle](quantum-oracle.md).
