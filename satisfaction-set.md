# Satisfaction set

↑ **Parent:** [Model checking](model-checking.md)

For a [state](state-computer-science.md) formula $\varphi$ in a fixed labelled [transition system](transition-system.md), its satisfaction set is $\{s\in S:s\models\varphi\}$. This is a [set](set-split.md) of [states](state-computer-science.md); it is distinct from the assertion that every initial [state](state-computer-science.md) satisfies the formula.
