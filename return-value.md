# Return value

↑ **Parent:** [Calling convention](calling-convention.md)

The result a called procedure supplies to its caller on returning. A [calling convention](calling-convention.md) specifies the [processor register](processor-register.md) or memory location carrying it, separately from the [return address](return-address.md), which identifies where execution resumes. In the elementary [MIPS architecture](mips-architecture.md) convention, an integer result is placed in `$v0`, while `$ra` carries the [return address](return-address.md).
