# Characteristic vector of a set

↑ **Parent:** [Set family](set-family.md)

For $A\subseteq[n]$, the characteristic vector $\mathbf1_A\in\{0,1\}^n$ has coordinate $i$ equal to one exactly when $i\in A$. Under this identification, [set union](set-union.md) becomes coordinatewise Boolean OR.
