# Embedding a finitely generated torsion-free module in a finite free module

↑ **Parent:** [Torsion-free module](torsion-free-module.md)

Apply [clearing denominators relative to an independent module subset](clearing-denominators-relative-to-an-independent-module-subset.md) to find $0\ne a$ with $aM$ lying in a [finite free module](finite-free-module.md). Multiplication by $a$ is injective on a [torsion-free module](torsion-free-module.md), giving the required embedding. A submodule need not itself be free over a general [integral domain](integral-domain.md).
