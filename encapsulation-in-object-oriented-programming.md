# Encapsulation in object-oriented programming

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

In [object-oriented programming](object-oriented-programming.md), encapsulation packages an object's state with the operations that act on it and can restrict direct access to its implementation. It is the object-oriented use of [encapsulation](encapsulation-computer-programming.md).
