# Weakly terminal set

↑ **Parent:** [Terminal object](terminal-object.md)

A weakly terminal set is a [set](set-split.md) of objects $(W_i)$ of a [category](category-split.md) such that every object admits at least one [morphism](morphism.md) into some $W_i$. It is the dual of a [weakly initial set](weakly-initial-set.md).
