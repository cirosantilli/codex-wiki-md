# Sudoku

↑ **Parent:** [Constraint satisfaction problem](constraint-satisfaction-problem.md)

A finite [constraint satisfaction problem](constraint-satisfaction-problem.md) on a $9\times9$ [array](array-data-structure.md). Each entry must be one of the [integers](integer-split.md) $1,\ldots,9$, and every row, column, and designated $3\times3$ box must contain each value once. Given entries constrain the possible completions; [backtracking](backtracking.md) searches those completions.
