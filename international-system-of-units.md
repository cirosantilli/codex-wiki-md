# International System of Units

↑ **Parent:** [System of units](system-of-units.md)

The International System of Units defines a common system for expressing [physical quantities](physical-quantity.md). Its base units include the [kelvin](kelvin.md) for [thermodynamic temperature](thermodynamic-temperature.md); derived units combine them to describe quantities such as [force](force.md) and [energy](energy.md).[The International System of Units (SI), ninth edition, SI Brochure](the-international-system-of-units-si-ninth-edition-si-brochure.md)
