# Doppler extrema for a circularly moving source

↑ **Parent:** [Relativistic Doppler effect](relativistic-doppler-effect.md)

A source of fixed proper [frequency](frequency.md) and [speed](speed.md) $v$ on a circle has instantaneous [frequency](frequency.md) extrema $\nu_0\sqrt{(1\pm\beta)/(1\mp\beta)}$ for a stationary coplanar receiver outside the circle. The extrema occur when the emission ray is tangent to the source circle, so line-of-sight [speed](speed.md) reaches $\pm v$.
