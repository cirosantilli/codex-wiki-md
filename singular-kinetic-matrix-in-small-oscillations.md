# Singular kinetic matrix in small oscillations

↑ **Parent:** [Small oscillation](small-oscillation.md)

If the quadratic [kinetic energy](kinetic-energy.md) has a singular coefficient matrix, some [generalized coordinates](generalized-coordinate.md) have no independent linearized inertia. The [small oscillation](small-oscillation.md) equations can then contain algebraic constraints, and the number of finite [normal mode](normal-mode.md) frequencies can be smaller than the number of coordinates. One should use the polynomial $\det(\mathsf K-\omega^2\mathsf M)$ without dividing by $\det\mathsf M$. Giving a nominally massless component a small mass can restore a high-frequency mode whose frequency diverges as that mass tends to zero.
