# Finite completeness of slice categories

↑ **Parent:** [Slice category](slice-category.md)

If a [category](category-split.md) has [pullbacks in a category](pullback-category-theory.md), each [slice category](slice-category.md) is finitely complete. The identity of the base object is terminal in the slice. Ambient [pullbacks in a category](pullback-category-theory.md) inherit a unique common structure map to the base and satisfy the same universal property over that base. A [terminal object](terminal-object.md) and [pullbacks in a category](pullback-category-theory.md) construct finite [products in a category](product-category-theory.md) and [equalizers](equaliser.md), hence all [finite limits](finite-limit.md).
