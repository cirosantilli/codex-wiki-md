# Fermat witness

↑ **Parent:** [Fermat little theorem](fermat-little-theorem.md)

A [Fermat witness](fermat-witness.md) for an [integer](integer-split.md) $n>1$ is a nonzero [residue class](residue-class.md) represented by $1\leq a<n$ for which $a^{n-1}\not\equiv1\pmod n$. It proves that $n$ is a [composite number](composite-number.md) by [Fermat's little theorem](fermat-little-theorem.md). Here the definition includes [nonunits](nonunit.md); some conventions restrict [Fermat witnesses](fermat-witness.md) to bases [coprime](coprime-integers.md) to $n$. The [Fermat primality test](fermat-primality-test.md) can first compute the [greatest common divisor](greatest-common-divisor.md): if $1<\gcd(a,n)<n$, it already has a proper factor. A zero [residue class](residue-class.md) is excluded. [Keith Conrad, Fermat's Test, p. 2, Definition 2.4 and footnote 3 on the two witness conventions](fermat-s-test-by-keith-conrad.md)
