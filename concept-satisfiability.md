# Concept satisfiability

↑ **Parent:** [Description logic](description-logic.md)

A [description logic concept](description-logic-concept.md) is satisfiable with respect to a [TBox](tbox.md) if some model of that [TBox](tbox.md) interprets the concept as a nonempty set.
