# Zero object

↑ **Parent:** [Pointed category](pointed-category.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Zero_object)

A zero object is both an [initial object](initial-object.md) and a [terminal object](terminal-object.md). In a pointed category, the composite through the zero object is the zero morphism $0_{A,B}:A\to B$.
