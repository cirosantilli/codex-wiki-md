# Linkage-disequilibrium marker tagging

↑ **Parent:** [Association mapping](association-mapping.md)

An observed [genetic marker](genetic-marker.md) tags an unobserved causal [genetic variant](genetic-variant.md) when [linkage disequilibrium](linkage-disequilibrium.md) correlates their allele indicators. Their squared [allelic correlation](allelic-correlation.md) $r^2$ measures prediction strength. Under standard local-alternative score-test approximations, using the marker rather than the causal allele reduces the noncentrality parameter by roughly $r^2$, suggesting a sample-size multiplier about $1/r^2$. This is an approximation requiring the same disease model and sampling design, not a universal power identity.
