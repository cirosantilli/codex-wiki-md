# Bit

↑ **Parent:** [Information theory](information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bit)

A [bit](bit.md) is a binary classical symbol with two distinguishable values, zero and one. A uniform random [bit](bit.md) has one [bit](bit.md) of [information entropy](information-entropy.md), while a biased binary symbol has less. Sending one [bit](bit.md) means transmitting one symbol from this binary alphabet; the [mutual information](mutual-information.md) it carries about a particular input need not be one.
