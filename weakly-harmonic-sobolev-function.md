# Weakly harmonic Sobolev function

↑ **Parent:** [Harmonic function](harmonic-function.md)

An element $h\in H^1_{\mathrm{loc}}(U)$ is weakly harmonic on an [open set](open-set.md) $U$ when $\int_U\nabla h\cdot\nabla\phi=0$ for every [test function](test-function.md) $\phi\in C_c^\infty(U)$. This is the statement $\Delta h=0$ in [distributions](distribution-mathematical-analysis.md). It requires no regularity of the [domain boundary](boundary-of-a-domain.md). The [Weyl lemma](weyl-lemma.md), a form of [elliptic regularity](elliptic-regularity.md), identifies such an element with a [smooth](smooth-function.md) [harmonic function](harmonic-function.md).
