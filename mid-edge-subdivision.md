# Mid-edge subdivision

↑ **Parent:** [Subdivision surface](subdivision-surface.md)

Mid-edge subdivision replaces each mesh edge by its midpoint, joins successive midpoints around every old face, and joins successive midpoints around every old vertex. For an interior [manifold](topological-manifold.md) mesh, each new vertex has valence four. Each geometric update is a [convex combination](convex-combination.md), so every refined control point remains in the [convex hull](convex-hull.md) of the original control mesh. The regular limit is associated with the [quadratic four-direction box spline](quadratic-four-direction-box-spline.md).
