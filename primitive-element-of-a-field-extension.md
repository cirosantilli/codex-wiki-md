# Primitive element of a field extension

↑ **Parent:** [Galois theory](galois-theory-split.md)

A primitive element of a finite extension $L/K$ is an element $\alpha\in L$ such that $L=K(\alpha)$.

The [primitive element theorem](primitive-element-theorem.md) proves existence under finite separability; the [primitive element of a field extension](primitive-element-of-a-field-extension.md) is the generator whose existence the theorem asserts.
