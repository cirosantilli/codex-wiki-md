# Adjacent pair in a linear order

↑ **Parent:** [Total order](total-order.md)

Two elements $u<v$ of a [totally ordered set](totally-ordered-set.md) form an adjacent pair when no domain element lies strictly between them. Every pair of consecutive [integers](integer-split.md) is adjacent, while a [dense order](dense-order.md) has no adjacent pair. A gap in a subset of the [real numbers](real-number.md) matters here only through which points belong to the domain: $1,2$ are adjacent in $[0,1]\cup[2,3]$.
