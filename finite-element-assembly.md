# Finite element assembly

↑ **Parent:** [Finite element method](finite-element-method-split.md)

Finite element assembly adds local element [matrices](matrix.md) and load vectors into a global [linear system](system-of-linear-equations.md) according to the correspondence between local and global degrees of freedom. A shared node receives contributions from every incident [finite element](finite-element.md). Boundary integrals, such as those in a [Robin boundary condition](robin-boundary-condition.md), are assembled from local boundary-edge matrices in the same way.
