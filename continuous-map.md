# Continuous map

↑ **Parent:** [Topological space](topological-space.md)

A map $f:X\to Y$ between [topological spaces](topological-space.md) is continuous when every [open set](open-set.md) $V\subseteq Y$ has an [inverse image](preimage.md) $f^{-1}(V)=\{x\in X:f(x)\in V\}$ that is an [open set](open-set.md) in $X$. The notation denotes a [subset](subset.md), so $f$ need not have an inverse [function](function-split.md).

For the [continuous map](continuous-map.md) $f:\mathbb R\to\mathbb R$, $f(x)=x^2$, with the usual [metric topology](metric-topology.md),

$$
f^{-1}((1,4))=(-2,-1)\cup(1,2).
$$

The two [open intervals](open-interval.md) form an [open set](open-set.md); an [inverse image](preimage.md) can split into separate pieces without violating [continuity](continuous-function.md). The defining condition concerns [inverse images](preimage.md), rather than images: here $f((-1,1))=[0,1)$ is not an [open set](open-set.md) in the [real line](real-line.md). Checking this one [inverse image](preimage.md) illustrates the definition; it alone does not prove [continuity](continuous-function.md) for all target [open sets](open-set.md).
