# Pipeline stall

↑ **Parent:** [Instruction pipelining](instruction-pipelining.md)

An interval in which some stage cannot advance its instruction. A [data hazard](data-hazard.md), occupied resource or unresolved [cache miss](cache-miss.md) can cause a [pipeline stall](pipeline-stall.md).
