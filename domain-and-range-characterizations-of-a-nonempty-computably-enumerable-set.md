# Domain and range characterizations of a nonempty computably enumerable set

↑ **Parent:** [Recursively enumerable set](recursively-enumerable-set.md)

For a nonempty set $A$ of words, the following are equivalent: $A$ is [computably enumerable](recursively-enumerable-set.md), $A$ is the domain of a [partial computable function](computable-function.md), $A$ is the range of a partial computable function, and $A$ is the range of a [total computable function](total-computable-function.md). The nonempty hypothesis is needed only for the last formulation, since the range of a total function cannot be empty.
