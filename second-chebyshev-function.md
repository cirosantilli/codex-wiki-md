# Second Chebyshev function

↑ **Parent:** [Chebyshev function](chebyshev-function.md)

The second Chebyshev function is the summatory [Von Mangoldt function](von-mangoldt-function.md), $\psi(x)=\sum_{n\leq x}\Lambda(n)$.
