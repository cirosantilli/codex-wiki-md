# Transition function of a finite automaton

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

For a [deterministic finite automaton](deterministic-finite-automaton.md) with [automaton state](automaton-state.md) [set](set-split.md) $Q$ and input [alphabet](alphabet.md) $\Sigma$, the [function](function-split.md) $\delta:Q\times\Sigma\to Q$ specifies the next [automaton state](automaton-state.md) after reading one input symbol. A [nondeterministic finite automaton](nondeterministic-finite-automaton.md) instead allows a [set](set-split.md) of possible next [automaton states](automaton-state.md).
