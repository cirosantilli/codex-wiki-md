# Difference set

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Difference_set)

For subsets $A,B$ of an additive group, their difference set is $A-B=\{a-b:a\in A,b\in B\}$.
