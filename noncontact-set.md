# Noncontact set

↑ **Parent:** [Obstacle problem](obstacle-problem.md)

The [noncontact set](noncontact-set.md) is where the unknown function is strictly above its obstacle. For [continuous functions](continuous-function.md) it is open. Every smooth variation with [compact support](compact-support.md) in this set remains feasible with either sign when its amplitude is small enough. The [first variation](first-variation.md) therefore vanishes there, yielding the unconstrained [Euler-Lagrange equation](euler-lagrange-equation.md). On the complementary [contact set of an obstacle problem](contact-set-of-an-obstacle-problem.md), only the appropriate one-sided [variational inequality](variational-inequality.md) is available globally.
