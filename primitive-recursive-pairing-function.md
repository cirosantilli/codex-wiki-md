# Primitive recursive pairing function

↑ **Parent:** [Pairing function](pairing-function.md)

A [pairing function](pairing-function.md) whose forward map and two inverse coordinate functions are [primitive recursive functions](primitive-recursive-function.md). For example, the Cantor pairing function $\langle x,y\rangle=(x+y)(x+y+1)/2+y$ has such inverses: find the diagonal index by [bounded minimization](bounded-minimization.md) over integers at most the encoded value, then recover $x,y$ by subtraction. It enables finite tuples to be decoded within a [primitive recursive](primitive-recursive-function.md) construction.
