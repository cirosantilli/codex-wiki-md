# von Klitzing constant

↑ **Parent:** [Integer quantum Hall effect](integer-quantum-hall-effect.md)

The [von Klitzing constant](von-klitzing-constant.md) is $R_K=h/e^2=25812.807459\ldots\,\Omega$. The current [SI](international-system-of-units.md) fixes the [Planck constant](planck-constant.md) $h=6.62607015\times10^{-34}\,\mathrm{J\,s}$ and [elementary charge](elementary-charge.md) $e=1.602176634\times10^{-19}\,\mathrm C$ exactly, so $R_K$ is exact; the displayed decimal is truncated. It differs from the historical conventional value $R_{K\text{-}90}=25812.807\,\Omega$.[2022 CODATA adjustment: Planck constant, elementary charge, von Klitzing constant and conventional-value rows](fundamental-physical-constants-complete-listing-by-national-institute-of-standards-and-technology-and-others.md)

As an original ideal example, $N=2$ and [electric current](electric-current.md) $I=1\,\mu\mathrm A$ give $|V_H|=IR_K/2\simeq12.9064\,\mathrm{mV}$. Changing the [Hall bar](hall-bar.md)'s width changes the transverse [electric field](electric-field-split.md) required for this [electric potential difference](electric-potential-difference.md), while the ideal ratio $|V_H|/I$ remains $R_K/2$.
