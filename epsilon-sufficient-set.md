# Epsilon-sufficient set

↑ **Parent:** [Information entropy](information-entropy.md)

For a finite-valued [random variable](random-variable-split.md), an epsilon-sufficient set $S$ retains probability at least $1-\epsilon$. This notion is about covering probability mass and is unrelated to a [sufficient statistic](sufficient-statistic.md). For an [IID random variable](independent-and-identically-distributed-random-variables.md) source, any such set of words with fixed $\epsilon<1$ requires exponentially many words at a rate approaching the [Shannon entropy](information-entropy.md).
