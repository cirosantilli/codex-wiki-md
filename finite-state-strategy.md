# Finite-state strategy

↑ **Parent:** [Repeated game](repeated-game.md)

A history-dependent [pure strategy](pure-strategy.md) represented by a [finite-state machine](finite-state-machine.md) with an initial [automaton state](automaton-state.md), an action output for each state, and an [automaton transition](automaton-transition.md) after each observed completed joint action. A [grim trigger strategy](grim-trigger.md) uses a following state and an absorbing punishment state. Two such deterministic machines jointly form a finite deterministic state system, so their action path is eventually periodic. Its [long-run average payoffs](long-run-average-payoff.md) are the averages over the eventual cycle; a finite initial prefix has vanishing weight.
