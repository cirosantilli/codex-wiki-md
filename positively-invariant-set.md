# Positively invariant set

↑ **Parent:** [Dynamical systems](dynamical-systems-split.md)

A set is positively invariant when every forward trajectory starting in it remains in it.

This is a dynamical example of an [invariant](invariant-mathematics.md); forward invariance and strict inward trapping are additional conditions.
