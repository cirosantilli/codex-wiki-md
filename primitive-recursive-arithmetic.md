# Primitive recursive arithmetic

↑ **Parent:** [Peano arithmetic](peano-arithmetic.md)

Primitive recursive arithmetic formalizes [primitive recursive functions](primitive-recursive-function.md), their defining equations, and quantifier-free induction. It is a weak arithmetic base for coding finite syntax and checking effective proof reductions. Assertions that a combinatorial principle implies [formal consistency statement](formal-consistency-statement.md) must specify such a base or another arithmetic metatheory.
