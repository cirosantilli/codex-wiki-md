# Approximate discontinuity set

↑ **Parent:** [Function of bounded variation on a domain](function-of-bounded-variation-on-a-domain.md)

For a [BV space](function-of-bounded-variation-on-a-domain.md) function, this is the set where no finite [approximate mean limit of a function](approximate-mean-limit-of-a-function.md) exists. Its difference from the [jump set of a bounded-variation function](jump-set-of-a-bounded-variation-function.md) has zero $(n-1)$-dimensional [Hausdorff measure](hausdorff-measure.md).
