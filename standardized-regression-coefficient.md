# Standardized regression coefficient

↑ **Parent:** [Regression coefficient](regression-coefficient.md)

In an ordinary [linear regression](linear-regression-split.md) with nonzero response and predictor [standard deviations](standard-deviation.md), the coefficient after rescaling predictor $j$ and the response to standard-deviation units is the displayed quantity. An unstandardized coefficient table does not automatically report it. Standardization and reference coding must be explicit.
