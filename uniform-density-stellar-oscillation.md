# Uniform-density stellar oscillation

↑ **Parent:** [Self-gravitating adiabatic displacement equations](self-gravitating-adiabatic-displacement-equations.md)

A constant-density gas sphere in [hydrostatic equilibrium](hydrostatic-equilibrium.md) has $g=\omega_d^2r$ and $p=\rho\omega_d^2(R^2-r^2)/2$. Its [stellar oscillations](stellar-oscillation.md) can be expanded using [regular solid harmonics](regular-solid-harmonic.md) and radial displacement amplitudes. Uniform density does not imply uniform [specific entropy](specific-entropy.md), so this equilibrium can be radially stable and still exhibit [convective instability](stellar-convective-instability.md).
