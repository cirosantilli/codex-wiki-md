# Relaxation-time approximation

↑ **Parent:** [Boltzmann equation](boltzmann-equation-split.md)

Approximation in which a small departure from a specified equilibrium distribution relaxes exponentially with time constant $\tau$. Different observables can have different effective relaxation times; momentum relaxation is not automatically the same as every microscopic scattering lifetime.
