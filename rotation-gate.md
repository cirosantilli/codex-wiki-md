# Rotation gate

↑ **Parent:** [Quantum circuit](quantum-circuit-split.md)

A one-qubit rotation gate is $R_\alpha(\theta)=e^{-i\theta\sigma_\alpha/2}$, where $\sigma_\alpha$ is a [Pauli matrix](pauli-matrices.md). It rotates the [Bloch vector](bloch-vector.md) by angle $\theta$ about the corresponding axis.
