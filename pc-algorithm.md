# PC algorithm

↑ **Parent:** [Causal directed acyclic graph](causal-directed-acyclic-graph.md)

The PC algorithm starts with a candidate undirected graph, removes edges using [conditional independence](conditional-independence.md) tests over increasing conditioning-set sizes, records separating sets, then orients unshielded colliders and propagates orientations. Under oracle tests and [faithfulness of a directed acyclic graph](faithfulness-of-a-directed-acyclic-graph.md), it estimates the graph's Markov equivalence class.
