# Conditionally unbiased estimator

↑ **Parent:** [Unbiased estimator](unbiased-estimator.md)

An estimator is conditionally unbiased for a parameter if its [expectation](expected-value.md), conditional on the specified observation or selection event, equals that parameter. Unconditional unbiasedness does not imply this property after selection. Independent new-stage data and the [Rao-Blackwell theorem](rao-blackwell-theorem.md) can provide useful constructions.
