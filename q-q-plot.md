# Q-Q plot

↑ **Parent:** [Probability and statistics](probability-and-statistics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Q–Q_plot)

A quantile-quantile plot compares ordered observations with quantiles of a reference distribution, or with quantiles of another sample. Approximate linearity supports agreement up to location and scale. A regression normal [Q-Q plot](q-q-plot.md) compares ordered [standardized regression residuals](standardized-regression-residual.md) with [standard normal distribution](standard-normal-distribution.md) quantiles.
