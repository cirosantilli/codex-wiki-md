# Linear fluctuating interface

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

A linear fluctuating interface smooths height gradients by diffusion and receives additive [Gaussian white noise](gaussian-white-noise.md). With periodic or [Neumann boundary conditions](neumann-boundary-condition.md), its nonzero [Fourier modes](fourier-mode.md) are independent [Ornstein-Uhlenbeck processes](ornstein-uhlenbeck-process.md) if the noise is diagonal in that basis. The unconstrained uniform height is a [Brownian zero mode of a fluctuating interface](brownian-zero-mode-of-a-fluctuating-interface.md).
