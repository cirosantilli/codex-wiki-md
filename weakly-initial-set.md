# Weakly initial set

↑ **Parent:** [Initial object](initial-object.md)

A weakly initial set is a [set](set-split.md) of objects $(W_i)$ of a [category](category-split.md) such that every object receives at least one [morphism](morphism.md) from some $W_i$. No uniqueness is required. A [solution-set condition](solution-set-condition.md) asserts this property in suitable [comma categories](comma-category.md).
