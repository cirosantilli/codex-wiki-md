# Five values force infinitely many simple preimages

↑ **Parent:** [Nevanlinna second main theorem](nevanlinna-second-main-theorem.md)

If a transcendental [meromorphic function](meromorphic-function.md) had only finitely many simple preimages over each of five distinct finite values, their simple counting functions would be $O(\log r)$. The displayed [multiplicity](multiplicity-mathematics.md) inequality and the [Nevanlinna first main theorem](nevanlinna-first-main-theorem.md) would bound the truncated sum by $5T_f/2+O(\log r)$. The [Nevanlinna second main theorem](nevanlinna-second-main-theorem.md) requires at least $3T_f$ up to its $o(T_f)$ error, a contradiction. Thus at least one value has infinitely many simple preimages; four other values can remain totally ramified.
