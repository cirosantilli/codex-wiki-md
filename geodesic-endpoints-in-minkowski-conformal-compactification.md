# Geodesic endpoints in Minkowski conformal compactification

↑ **Parent:** [Minkowski conformal compactification](minkowski-conformal-compactification.md)

A complete inertial [timelike geodesic](timelike-geodesic.md) in [Minkowski spacetime](minkowski-spacetime.md) has $\mathbf x=\mathbf b+\mathbf vt$ with $|\mathbf v|<1$. Under $p=\arctan(t-r)$, $q=\arctan(t+r)$, both $p,q$ tend to the same endpoint, giving [past timelike infinity](past-timelike-infinity.md) and [future timelike infinity](future-timelike-infinity.md). A complete [null geodesic](null-geodesic.md) has one finite limiting null coordinate at each end and reaches [past null infinity](past-null-infinity.md) and [future null infinity](future-null-infinity.md). Complete [spacelike geodesics](spacelike-geodesic.md) have $r>|t|$ asymptotically and both ends approach [spacelike infinity](spacelike-infinity.md). The endpoints have finite compactified coordinates but occur at infinite physical [affine parameter](affine-parameter.md). A [conformal transformation](conformal-map.md) preserves null paths as unparametrized geodesics; it does not generally preserve timelike or spacelike geodesic paths.
