# Distance of a quantum error-correcting code

↑ **Parent:** [Quantum error correction](quantum-error-correction-split.md)

An $[[n,k,d]]$ [quantum error correction](quantum-error-correction-split.md) code is a $2^k$-dimensional subspace of $n$ [qubits](qubit.md). Its distance $d$ is the minimum weight of a [Pauli operator](pauli-operator.md) $E$ for which $PEP$ is not a scalar multiple of the code projector $P$. Thus every operator supported on fewer than $d$ qubits has scalar compression to the code, by expansion in the Pauli basis. This definition includes degenerate codes; a low-weight operator acting as a scalar does not reduce the distance.
