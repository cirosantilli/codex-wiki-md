# Signal

↑ **Parent:** [Signal processing](signal-processing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Signal)

A signal is a [function](function-split.md) or [sequence](sequence.md) representing a quantity that carries information. An [electric potential difference](electric-potential-difference.md) measured over time can be written $x(t)$; regularly recorded values give a [discrete-time signal](discrete-time-signal.md) $x[n]$. The meaning includes the measured quantity, units, time reference and sampling interval. The same list of numbers sampled once per second or once per millisecond describes different physical [frequencies](frequency.md).
