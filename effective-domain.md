# Effective domain

↑ **Parent:** [Proper extended-real function](proper-extended-real-function.md)

The [effective domain](effective-domain.md) of an extended-real [function](function-split.md) is $\operatorname{dom}E=\{u:E(u)<+\infty\}$. An infinite value can impose a hard constraint through an [indicator functional of a constraint set](indicator-functional-of-a-constraint-set.md).
