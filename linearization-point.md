# Linearization point

↑ **Parent:** [Linearizability](linearizability.md)

The instant used to identify an operation's abstract effect in a proof of [linearizability](linearizability.md). Loading the published [pointer](pointer-computer-programming.md) can be the [linearization point](linearization-point.md) of an immutable snapshot read, with suitable ordering and lifetime guarantees.
