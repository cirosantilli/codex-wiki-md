# Functional graph

↑ **Parent:** [Directed graph](directed-graph.md)

A functional graph has exactly one outgoing [edge of a graph](edge-of-a-graph.md) at every [vertex of a graph](vertex-graph-theory.md), representing a [function](function-split.md) from its [vertex of a graph](vertex-graph-theory.md) set to itself. In a finite functional graph, each weakly connected component contains one [directed cycle](directed-cycle.md), with directed trees feeding into it. Iterating the represented [function](function-split.md) eventually reaches that [directed cycle](directed-cycle.md).
