# Channel coding

↑ **Parent:** [Coding theory](coding-theory-split.md)

Channel coding represents messages with [codewords](codeword.md) chosen to withstand transmission errors. An [error-correcting code](error-correcting-code.md) deliberately supplies redundancy, so a receiver can distinguish nearby corrupted outputs and recover the message. [Lossless source coding](lossless-source-coding.md) instead removes predictable redundancy; practical communication can use both operations. The [Shannon second coding theorem](noisy-channel-coding-theorem.md) relates achievable rates on a [discrete memoryless channel](discrete-memoryless-channel.md) to its [channel capacity](channel-capacity.md).
