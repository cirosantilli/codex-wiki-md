# Coherent information upper bound by input entropy

↑ **Parent:** [Coherent information](coherent-information.md)

In a purified [Stinespring dilation](stinespring-dilation.md), [coherent information](coherent-information.md) satisfies $I_c=S(RE)-S(E)=S(\rho)-I(R:E)$. Nonnegativity of [quantum mutual information](quantum-mutual-information.md) implies $I_c\leq S(\rho)$. Equality means that the reference and environment are uncorrelated, so the environment learns nothing about the purified input reference.
