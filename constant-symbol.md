# Constant symbol

↑ **Parent:** [Function symbol](function-symbol.md)

A [constant symbol](constant-symbol.md) is a zero-ary [function symbol](function-symbol.md). Its interpretation in a [first-order structure](first-order-structure.md) names one fixed domain element, and the symbol is a [closed term](closed-term.md). A language can contain no [constant symbols](constant-symbol.md) unless a construction explicitly adds them.
