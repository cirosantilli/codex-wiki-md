#### Outline font

↑ **Parent:** [Computer font](#computer-font)

An outline font stores [glyph](#glyph) shapes as geometric boundaries that can be scaled before drawing. [Bézier curves](computer-aided-geometric-design.md#bezier-curve) provide editable segments of these boundaries. TrueType outlines use quadratic [Bézier curves](computer-aided-geometric-design.md#bezier-curve); Type 2 charstrings used in Compact Font Format outlines use cubic [Bézier curves](computer-aided-geometric-design.md#bezier-curve). [OpenType specification, TrueType fundamentals: outlines](https://learn.microsoft.com/en-us/typography/opentype/spec/ttch01) [Adobe, The Type 2 Charstring Format, section 4.1](https://adobe-type-tools.github.io/font-tech-notes/pdfs/5177.Type2.pdf)
