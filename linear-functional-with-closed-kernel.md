# Linear functional with closed kernel

↑ **Parent:** [Continuous linear functional](continuous-linear-functional.md)

A [linear functional](linear-functional.md) on a [normed vector space](normed-vector-space.md) is continuous exactly when its kernel is closed. The forward direction follows because zero is closed in the scalar field. Conversely, if $l\ne0$, choose $v$ with $l(v)=1$ and write $M=\ker l$. Closedness gives $d=\operatorname{dist}(v,M)>0$. Since $x/l(x)-v\in M$ when $l(x)\ne0$, $|l(x)|\leq\|x\|/d$. The zero functional is continuous separately. Thus the criterion does not require completeness or the [closed graph theorem](closed-graph-theorem.md).
