# Necessity of the Knill-Laflamme condition

↑ **Parent:** [Knill--Laflamme condition](knill-laflamme-condition.md)

If a common recovery [quantum channel](quantum-channel.md) with [Kraus operators](kraus-operator.md) $R_\mu$ restores every pure code state after each error $E_a$, then each vector $R_\mu E_a|\psi\rangle$ is parallel to $|\psi\rangle$. [Linearity](linearity.md) on basis vectors and their pairwise superpositions forces $R_\mu E_aP=c_{\mu a}P$, with the scalar independent of the logical state. Insert $\sum_\mu R_\mu^\dagger R_\mu=I$ between two error operators to obtain the displayed [Knill--Laflamme condition](knill-laflamme-condition.md). This proves necessity without presuming an orthogonal syndrome description of recovery.
