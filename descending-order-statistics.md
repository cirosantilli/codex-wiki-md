# Descending order statistics

↑ **Parent:** [Order statistic](order-statistic.md)

Descending order statistics list a sample from greatest to least. If $V_{(1)}\leq\cdots\leq V_{(n)}$ uses the usual increasing convention, then $V_{[k]}=V_{(n-k+1)}$. This notation distinguishes the next-highest value used by [revenue equivalence](revenue-equivalence.md) from the second-smallest sample value.
