# Branch weight

↑ **Parent:** [Many-worlds interpretation](many-worlds-interpretation.md)

For an orthogonal decomposition $\Psi=\sum_i\Psi_i$, the squared norms add to the total norm. Refining one component into orthogonal subcomponents preserves its total weight by the [Pythagorean theorem](pythagorean-theorem.md). In an Everettian account these weights are candidates for governing probabilities, rational credences or decisions; the algebra alone does not select which interpretive role is justified. Counting arbitrarily refined components is not the same measure.[sections 4–5](quantum-probability-and-decision-theory-revisited-by-david-wallace.md)
