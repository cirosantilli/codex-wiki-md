# Integrable-supremum martingale criterion

↑ **Parent:** [Continuous local martingale](continuous-local-martingale.md)

If a [local martingale](local-martingale.md) has an integrable running absolute supremum on each fixed finite horizon, localization and conditional dominated convergence make it a true [martingale](martingale-split.md). This upgrades polynomial Itô local martingales when maximal moments and bracket moments control all terms.
