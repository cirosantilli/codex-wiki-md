# First integrals in involution

↑ **Parent:** [Integrable Hamiltonian system](integrable-hamiltonian-system.md)

First integrals are in involution when every pair has zero [Poisson bracket](poisson-bracket.md). An $n$-degree-of-freedom Hamiltonian system is [Liouville integrable](integrable-hamiltonian-system.md) when it has $n$ almost-everywhere independent first integrals in involution.
