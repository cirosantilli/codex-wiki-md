<h1 id="weak-type-1-1">Weak type (1,1)</h1>

↑ **Parent:** [Weak-type operator](weak-type-operator.md)

For a nonnegative [sublinear operator](sublinear-operator.md), weak type $(1,1)$ is the displayed level-set bound for all integrable inputs and positive thresholds. It supplies an exceptional-set estimate for approximation errors; the [uncentered maximal weak-type inequality](uncentered-maximal-weak-type-inequality.md) is a central example.
