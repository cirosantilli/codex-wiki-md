# Empty sum

↑ **Parent:** [Sum](sum.md)

An empty sum has no terms and is defined to be zero, the [identity element](identity-element.md) for [addition](addition.md). This keeps the rule for combining [sums](sum.md) valid when one index set is empty. In a [Galton-Watson process](galton-watson-process.md), an empty generation contributes an [empty sum](empty-sum.md) of offspring counts, so the next generation is empty too. The corresponding convention for [multiplication](multiplication.md) is the [empty product](empty-product.md), which equals one.
