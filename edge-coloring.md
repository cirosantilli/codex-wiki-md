# Edge coloring

↑ **Parent:** [Graph coloring](graph-coloring-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Edge_coloring)

An [edge colouring](edge-coloring.md) assigns a label called a colour to every [edge of a graph](edge-of-a-graph.md): it is a [function](function-split.md) $c:E(G)\to\{1,\ldots,k\}$. Here this definition allows arbitrary assignments. Two [edges](edge-of-a-graph.md) sharing a [vertex](vertex-graph-theory.md) may receive the same colour. A [proper edge colouring](proper-edge-coloring.md) imposes the additional condition that such [edges](edge-of-a-graph.md) receive different colours. Some textbooks use "[edge colouring](edge-coloring.md)" as shorthand for this proper version; check the convention before applying a theorem.[Line graphs and edge coloring, slide 1: arbitrary labeling versus proper edge coloring](line-graphs-and-edge-coloring.md)

The distinction matters in [Ramsey theory](ramsey-theory-split.md). In a red-blue [edge colouring](edge-coloring.md) of a [complete graph](complete-graph.md), a [triangle in a graph](triangle-in-a-graph.md) is monochromatic when its three [edges](edge-of-a-graph.md) have the same colour. These are arbitrary [edge colourings](edge-coloring.md): forbidding equal colours on [edges](edge-of-a-graph.md) sharing a [vertex](vertex-graph-theory.md) would forbid the very monochromatic [triangles in a graph](triangle-in-a-graph.md) being sought. For example, assigning red to every [edge](edge-of-a-graph.md) of $K_3$ is a valid arbitrary [edge colouring](edge-coloring.md), although it is not a [proper edge colouring](proper-edge-coloring.md). Colour labels can also stand for time slots: then [proper edge colouring](proper-edge-coloring.md) turns incompatible jobs into separate rounds.
