# Closed migration process

↑ **Parent:** [Stochastic network](stochastic-network.md)

A closed migration process is a [continuous-time Markov chain](continuous-time-markov-chain.md) of populations moving between colonies with a conserved total number of individuals. A colony containing $k$ individuals has departure rate $\phi_j(k)$, with $\phi_j(0)=0$, and each departure chooses its next colony using a fixed routing [matrix](matrix.md). Its colony populations can represent stages of a service system, including an idle stage.
