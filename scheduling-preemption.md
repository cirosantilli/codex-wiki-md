# Scheduling preemption

↑ **Parent:** [Process scheduling](process-scheduling.md)

Taking the [CPU](central-processing-unit.md) away from a still-runnable task before it voluntarily yields or finishes. [Round-robin scheduling](round-robin-scheduling.md) uses [scheduling preemption](scheduling-preemption.md) when a [scheduling quantum](scheduling-quantum.md) expires, commonly using a timer [interrupt](interrupt.md) to regain control. [Kernel preemption](kernel-preemption.md) is the more specific question of whether an execution already within the [operating-system kernel](kernel-operating-system.md) can be suspended for another runnable context.
