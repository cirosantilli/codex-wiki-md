# Characteristic line for the one-dimensional wave equation

↑ **Parent:** [One-dimensional wave equation](one-dimensional-wave-equation.md)

These [characteristic curves](characteristic-curve.md) are straight when [wave speed](wave-speed.md) $c$ is constant. A right-moving component is constant on $x-ct=s$, and a left-moving component on $x+ct=s$. The full [superposition](superposition-principle.md) generally is not constant on either family, because the other component can vary along it. Their backwards intersections with the initial line select the endpoints used in [D'Alembert's formula](d-alembert-s-formula.md).
