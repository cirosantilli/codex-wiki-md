# Exponential order

↑ **Parent:** [Laplace transform](laplace-transform.md)

A [function](function-split.md) has exponential order $a\in\mathbb R$ if some $M>0$ and $T\geq0$ give the displayed bound. Bounded [functions](function-split.md), including [sine](sine.md), have exponential order zero; $e^{-2t}$ has exponential order $-2$. The bound need not use the smallest possible $a$. Together with [piecewise continuity](piecewise-continuous-function.md), it guarantees a [Laplace transform](laplace-transform.md) for $\operatorname{Re}s>a$.
