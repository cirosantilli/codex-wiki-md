# Lattice-ordered group

↑ **Parent:** [Partially ordered group](partially-ordered-group-split.md)

An [ordered group](partially-ordered-group-split.md) whose [partial order](partially-ordered-set.md) is a [lattice](lattice.md). Each pair has a [join](least-upper-bound-in-a-partially-ordered-set.md) $f\vee g$ and a [meet](greatest-lower-bound-in-a-partially-ordered-set.md) $f\wedge g$. Translations preserve these operations, for example $a(f\vee g)b=afb\vee agb$. Pointwise [maximum](maximum-of-a-subset-of-a-total-order.md) and [minimum](minimum-of-a-subset-of-a-total-order.md) make the [order automorphisms](order-automorphism.md) of a chain into a lattice-ordered group.
