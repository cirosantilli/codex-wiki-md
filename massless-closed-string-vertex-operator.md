# Massless closed-string vertex operator

↑ **Parent:** [Integrated string vertex operator](integrated-string-vertex-operator.md)

At the first massless closed-string level, the matter vertex has the form $\epsilon_{\mu\nu}:\!\partial X^\mu\bar\partial X^\nu e^{ik\cdot X}\!:$, with null momentum and a polarization tensor transverse in both indices. Its symmetric trace-free, antisymmetric and trace sectors describe the graviton, [Kalb–Ramond field](kalb-ramond-field.md) and [dilaton](dilaton.md).
