# Well-supported object

↑ **Parent:** [Support of an object in a regular category](support-of-an-object-in-a-regular-category.md)

An object of a [regular category](regular-category.md) is well-supported when its [support of an object in a regular category](support-of-an-object-in-a-regular-category.md) is the [terminal object](terminal-object.md), equivalently when $A\to1$ is a [regular epimorphism](regular-epimorphism.md). Finite products of well-supported objects are well-supported, by pullback and composition stability of regular epimorphisms. A regular epimorphism has the same support as its codomain, and an object with a point $1\to A$ is well-supported.
