# Counting irreducible sl2 summands using weights zero and one

↑ **Parent:** [Classification of finite-dimensional sl2 representations](classification-of-finite-dimensional-sl2-representations.md)

For a finite-dimensional complex [sl2 Lie algebra](sl2-lie-algebra.md) module $V$, the number of simple summands, counted with multiplicity, is $\dim V_0+\dim V_1$. Indeed, the simple module of [highest weight](highest-weight-of-a-representation.md) $m\ge0$ has weights $m,m-2,\ldots,-m$, each once. Exactly one of zero and one appears: zero when $m$ is even, one when $m$ is odd. The [classification of finite-dimensional sl2 representations](classification-of-finite-dimensional-sl2-representations.md) decomposes $V$ into these modules, and dimensions of [weight spaces](weight-space.md) add over the direct sum.
