# Inverting amplifier

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

A voltage-feedback [operational amplifier](operational-amplifier.md) with its noninverting input grounded and input and feedback resistances $R_i,R_f$ has ideal gain $-R_f/R_i$. [Virtual short](virtual-short.md) and negligible input current give the result by node-current balance.
