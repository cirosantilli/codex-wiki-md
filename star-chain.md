# Star chain

↑ **Parent:** [Addition chain](addition-chain.md)

An [addition chain](addition-chain.md) restricted to updates $a_{t+1}=a_t+a_i$ with $0\le i\le t$. Each new power uses the most recently computed power as one factor. This restriction reduces the search space, but a shortest [star chain](star-chain.md) need not be a shortest unrestricted [addition chain](addition-chain.md) for every target.
