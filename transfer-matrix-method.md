# Transfer matrix method

↑ **Parent:** [Dynamic programming](dynamic-programming.md)

A method for counting or weighting configurations by processing successive slices and recording only the information that crosses the current boundary. Compatible boundary states define a [matrix](matrix.md) of transitions, so repeated slices can be handled by [matrix](matrix.md) powers. It is especially useful when the boundary is much smaller than the whole configuration.
