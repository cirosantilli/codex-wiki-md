# Language of ordered rings

↑ **Parent:** [First-order language](first-order-language.md)

For coding [arithmetic](arithmetic-split.md) computations, the signature in use is $0,1,+,\times,<,=$. Bounded remainder tests and polynomial equations use only these symbols. This is a statement about the language: interpretation in the [natural numbers](natural-number.md) does not impose the axioms of a ring.
