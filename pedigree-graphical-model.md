# Pedigree graphical model

↑ **Parent:** [Pedigree likelihood](pedigree-likelihood.md)

Assign one [genotype](genotype.md) [random variable](random-variable-split.md) to each person in a [pedigree](pedigree.md). Independent [founders in a pedigree](founder-in-a-pedigree.md) carry population genotype laws, and each other genotype has its [conditional distribution](conditional-distribution.md) given its two parents from [Mendelian segregation](mendelian-segregation.md). The ancestry [Directed acyclic graph](directed-acyclic-graph.md) is a [Bayesian network](bayesian-network.md) for the joint genotype law. Its [moral graph](moral-graph.md) contains each parent-child edge and each coparent edge. Each founder factor and each child-with-parents factor belongs to a [clique](clique-graph-theory.md), giving an undirected graphical representation. The graph is an independence representation; equality with the minimal [conditional independence graph](conditional-independence-graph.md) needs additional faithfulness assumptions, particularly because inheritance can produce zero probabilities.
