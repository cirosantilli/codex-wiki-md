# Gradient Richardson number

↑ **Parent:** [Richardson number](richardson-number.md)

For a stratified parallel [shear flow](shear-flow.md), the gradient Richardson number compares the squared [buoyancy frequency](buoyancy-frequency.md) with squared vertical shear. The [Miles–Howard theorem](miles-howard-theorem.md) excludes exponentially growing inviscid [normal modes](normal-mode.md) when this ratio is at least $1/4$ everywhere. Where $U'=0$, the equivalent criterion is written directly as $N^2\geq(U')^2/4$.
