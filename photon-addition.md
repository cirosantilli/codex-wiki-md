# Photon addition

↑ **Parent:** [Quantum optics](quantum-optics-split.md)

Ideal conditional application of a [creation operator](creation-operator.md), followed by normalization. It reweights the input number distribution as well as raising each occupied number by one. A heralded physical implementation has a success [probability](probability.md); the algebraic [creation operator](creation-operator.md) alone is not a trace-preserving deterministic [quantum operation](quantum-operation.md).
