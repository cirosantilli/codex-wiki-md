# Coresilience

↑ **Parent:** [Euler totient function](euler-totient-function.md)

For an [integer](integer-split.md) $n>1$, define $C(n)=(n-\varphi(n))/(n-1)$, the complementary proportion to the [resilience of a denominator](resilience-of-a-denominator.md). For [composite numbers](composite-number.md), asking when this is a unit fraction is equivalent to the [divisibility](divisibility-split.md) condition $n-\varphi(n)\mid n-1$.
