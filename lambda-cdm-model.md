# Lambda-CDM model

↑ **Parent:** [Cosmology](cosmology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lambda-CDM_model)

The Lambda-CDM model combines a [cosmological constant](cosmological-constant.md) with [cold dark matter](cold-dark-matter.md) and the standard baryonic and radiation components in an expanding [Friedmann-Lemaître-Robertson-Walker metric](friedmann-lemaitre-robertson-walker-metric.md).
