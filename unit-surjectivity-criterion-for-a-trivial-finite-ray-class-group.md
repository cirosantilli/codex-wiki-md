# Unit-surjectivity criterion for a trivial finite ray class group

↑ **Parent:** [Ray class exact sequence](ray-class-exact-sequence.md)

For a modulus with no infinite component, suppose the ordinary [ideal class group](ideal-class-group.md) is trivial. Then the [ray class group](ray-class-group.md) is trivial exactly when the global [unit group](unit-group.md) maps surjectively onto the product of local unit residue groups at the finite modulus. Negative real units are allowed: positivity restrictions occur only when the modulus includes the corresponding real places.
