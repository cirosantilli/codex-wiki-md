# Cardinal exponentiation

↑ **Parent:** [Cardinal arithmetic](cardinal-arithmetic.md)

Cardinal exponentiation counts functions from a set of size $\lambda$ to one of size $\kappa$. The [currying law for cardinal exponentiation](currying-law-for-cardinal-exponentiation.md) gives $(\kappa^\lambda)^\mu=\kappa^{\lambda\cdot\mu}$. These are cardinal operations, distinct from [ordinal](ordinal-split.md) exponentiation. For example the [Generalized continuum hypothesis](generalized-continuum-hypothesis.md) specifies $2^\kappa=\kappa^+$ at infinite cardinals.
