# Dulac function

↑ **Parent:** [Bendixson-Dulac theorem](bendixson-dulac-theorem.md)

A multiplier $B(x,y)$ whose rescaled planar vector field has divergence of one strict sign can exclude [periodic orbits](periodic-orbit.md) in a simply connected region. For a system $\dot x=xF$, $\dot y=yG$ in the positive quadrant, $B=1/(xy)$ is often effective.
