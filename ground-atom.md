# Ground atom

↑ **Parent:** [Atomic formula](atomic-formula.md)

An [atomic formula](atomic-formula.md) containing no [variables](variable-mathematics.md). In [STRIPS](strips.md), a state records true [ground atoms](ground-atom.md), and the [closed-world assumption](closed-world-assumption.md) treats unlisted [ground atoms](ground-atom.md) as false. Object names may occur as arguments: $\operatorname{OnTop}(c_1,c_2)$ is a [ground atom](ground-atom.md) when $c_1,c_2$ are object constants.
