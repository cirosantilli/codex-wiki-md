# Primitive cyclic Reed-Solomon code

↑ **Parent:** [Reed-Solomon error correction](reed-solomon-error-correction.md)

Let $n=q-1$ and let $\omega$ be a [primitive root of unity](primitive-root-of-unity.md) in $\mathbb F_q$. The length-$n$ [cyclic code](cyclic-code.md) with consecutive [zeros of a cyclic code](zero-of-a-cyclic-code.md) $\omega^b,\ldots,\omega^{b+n-k-1}$ has dimension $k$. It equals the [generalized Reed-Solomon code](generalized-reed-solomon-code.md) of vectors $(\omega^{j(1-b)}f(\omega^j))_{j=0}^{n-1}$, $\deg f<k$. The choice $b=1$ is the unweighted [Reed-Solomon code](reed-solomon-error-correction.md) on these evaluation points; allowing other offsets makes this family closed under [dual codes](dual-code.md).
