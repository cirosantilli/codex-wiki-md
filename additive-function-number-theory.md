# Additive function (number theory)

↑ **Parent:** [Arithmetic function](arithmetic-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Additive_function)

An [arithmetic function](arithmetic-function.md) $f$ is additive when $f(mn)=f(m)+f(n)$ for [coprime integers](coprime-integers.md) $m,n$. Equivalently, $f(n)=\sum_{p^k\parallel n}f(p^k)$. This concerns multiplication of integers, and differs from an [additive function](additive-function.md) on a vector space.
