# Main-sequence mass-luminosity relation

↑ **Parent:** [Mass-luminosity relation](mass-luminosity-relation.md)

For [main-sequence stars](main-sequence-star.md), [luminosity](luminosity.md) increases steeply with [mass](mass.md). A local power-law approximation uses an exponent that varies with the stellar mass range and composition; $\alpha\simeq4$ is a useful rough near-solar estimate. Evolved stars need not follow that same calibration.
