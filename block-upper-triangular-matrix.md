# Block upper triangular matrix

↑ **Parent:** [Linear algebra](linear-algebra-split.md)

A block upper triangular matrix is a [block matrix](block-matrix.md) with square diagonal blocks and zero blocks below them. Its determinant is the product of the determinants of its diagonal blocks.
