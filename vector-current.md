# Vector current

↑ **Parent:** [Fermion bilinear](fermion-bilinear.md)

A [fermion bilinear](fermion-bilinear.md) transforming as a [Lorentz four-vector](four-vector.md). For a single [Dirac field](dirac-field.md) this is the [Dirac current](dirac-current.md); distinct flavours can give a charged or flavour-changing current.
