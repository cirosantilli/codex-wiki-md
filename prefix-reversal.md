# Prefix reversal

↑ **Parent:** [Permutation](permutation.md)

Reverse the first $k$ entries of a [sequence](sequence.md) and leave its suffix unchanged. On a [permutation](permutation.md), this is a bijection on positions and is its own inverse: performing the same reversal twice restores the state. The nontrivial moves have $2\leq k\leq n$. With unit-cost moves, the resulting state graph supports a [breadth-first search](breadth-first-search.md) for a minimum-move solution.
