# Statistical hypothesis

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test.md)

A [statistical hypothesis](statistical-hypothesis.md) is a specified set of possible data-generating [probability distributions](probability-distribution.md), usually expressed as a restriction on model parameters. A simple [statistical hypothesis](statistical-hypothesis.md) specifies one distribution; a composite [statistical hypothesis](statistical-hypothesis.md) permits several. A [hypothesis test](statistical-hypothesis-test.md) compares a [null hypothesis](null-hypothesis.md) with an [alternative hypothesis](alternative-hypothesis.md) using a statistic calibrated under the null.
