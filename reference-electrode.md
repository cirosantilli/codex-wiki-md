# Reference electrode

↑ **Parent:** [Weak acid dissociation measurement](weak-acid-dissociation-measurement.md)

A [reference electrode](reference-electrode.md) supplies the comparison [electric potential](electric-potential.md) for the [glass electrode](glass-electrode.md) measurement. A combination probe incorporates both [electrodes](electrode.md); changes at its junction can contribute measurement error.
