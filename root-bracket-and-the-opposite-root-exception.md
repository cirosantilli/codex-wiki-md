# Root bracket and the opposite-root exception

↑ **Parent:** [Root space](root-space.md)

For [root spaces](root-space.md) $\mathfrak g_\alpha,\mathfrak g_\beta$, the [Jacobi identity](jacobi-identity.md) gives $[\mathfrak g_\alpha,\mathfrak g_\beta]\subset\mathfrak g_{\alpha+\beta}$ when $\alpha+\beta\ne0$. If the bracket is nonzero, that nonzero weight must be a root. When $\beta=-\alpha$, the bracket instead lies in the [Cartan subalgebra](cartan-subalgebra.md) and can be nonzero; zero is not a root. Thus the common nonzero-bracket implication requires the opposite-root exception.
