# Function space

↑ **Parent:** [Functional analysis](functional-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Function_space)

A function space is a collection of [functions](function-split.md) with common domain and codomain, often supplied with a [vector space](vector-space-split.md) structure and a [norm](norm.md) or [topology](topology-split.md). Examples include [L2 spaces](l2-space-is-a-hilbert-space.md) and [Sobolev spaces](sobolev-space-split.md).
