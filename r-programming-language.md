# R (programming language)

↑ **Parent:** [Programming language](programming-language-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/R_(programming_language))

[R](r-programming-language.md) is a [programming language](programming-language-split.md) and environment for [statistics](statistics.md), data analysis and graphics. For [matrix](matrix.md) algorithms, `drop = FALSE` preserves dimensions when extracting submatrices. To choose an element uniformly from a possibly singleton numeric vector `indices`, use `indices[sample.int(length(indices), 1L)]`: `sample(indices, 1L)` has a special interpretation when its first argument is a single positive number. Official documentation: [Extraction and the drop argument](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Extract.html) and [Sampling, including the singleton numeric argument rule](https://stat.ethz.ch/R-manual/R-devel/library/base/html/sample.html).
