# Freezing degree-day

↑ **Parent:** [Sea ice thermodynamics](sea-ice-thermodynamics.md)

A freezing degree-day accumulates air temperature below a declared reference freezing temperature, with time in days and temperature difference in degrees Celsius or kelvins. The reference temperature and averaging convention must match the empirical [sea ice thermodynamics](sea-ice-thermodynamics.md) formula using it. Warming by a constant $\Delta T$ subtracts $\Delta T$ times the number of days only if those days remain below the reference threshold.
