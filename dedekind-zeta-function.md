# Dedekind zeta function

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dedekind_zeta_function)

For a number field $K$, the Dedekind zeta function is formally

$$
\zeta_K(s)=\sum_{0\ne\mathfrak a\subseteq\mathcal O_K}N(\mathfrak a)^{-s}.
$$
