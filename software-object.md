# Software object

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

An object combines an identity, state and operations exposed through an [object interface](object-interface.md). Distinct [software objects](software-object.md) can hold equal data while remaining different by [object identity](object-identity.md). [Reference aliasing](reference-aliasing.md) occurs when multiple references designate the same object, so a state update through one reference can affect observations through another.
