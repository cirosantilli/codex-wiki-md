# Nonparametric linkage analysis

↑ **Parent:** [Genetic linkage](genetic-linkage.md)

Nonparametric linkage analysis tests excess [identity by descent](identity-by-descent.md) among relatives with a shared [phenotype](phenotype.md), without specifying its complete [penetrance](penetrance.md) model or disease-allele frequency. Its null still uses [Mendelian segregation](mendelian-segregation.md) and the specified [pedigree](pedigree.md).
