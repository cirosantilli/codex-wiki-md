# Stationary iterative method for a linear system

↑ **Parent:** [Numerical linear algebra](numerical-linear-algebra.md)

A stationary iteration has the form

$$
x^{(k+1)}=Hx^{(k)}+v,
$$

with a fixed iteration matrix $H$. It converges for every initial vector exactly when the [spectral radius](spectral-radius.md) satisfies $\rho(H)<1$.

This is an [iterative method](iterative-method.md) whose update matrix remains fixed.
