# Directed covering graph of an interval map

↑ **Parent:** [Interval covering relation](interval-covering-relation.md)

Given finitely many intervals $J_1,\ldots,J_r$, their directed covering graph has an [directed edge](directed-edge.md) $J_i\to J_j$ whenever $F(J_i)\supseteq J_j$.
