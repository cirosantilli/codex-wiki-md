# Disc diagram shell

↑ **Parent:** [Disc diagram](disc-diagram.md)

A shell is an exposed two-cell in a [disc diagram](disc-diagram.md), with perimeter split as an exterior boundary arc $Q$ and an interior path $P$. An $i$-shell has $P$ consisting of $i$ interior pieces. Under $C'(1/6)$, an $i$-shell with $i\leq3$ has $|P|<|\partial R|/2<|Q|$, so removal replaces a long exterior path by a strictly shorter path.
