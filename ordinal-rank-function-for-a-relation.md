# Ordinal rank function for a relation

↑ **Parent:** [Well-founded recursion](well-founded-recursion.md)

An ordinal-valued function strictly increasing along a relation. For a well-founded set relation, or a [set-like](set-like-relation.md) class relation, the canonical rank is $\rho(y)=\sup\{\rho(x)+1:xRy\}$.
