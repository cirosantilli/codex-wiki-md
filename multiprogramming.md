# Multiprogramming

↑ **Parent:** [Operating system](operating-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multiprogramming)

Keeping several [operating-system processes](process-computing.md) available so [process scheduling](process-scheduling.md) can run another when one waits. Increasing their number can increase the combined [working set](working-set.md) demand beyond the available [page frames](page-frame.md), producing [memory thrashing](thrashing-computer-science.md) rather than more useful [CPU](central-processing-unit.md) work.
