# Compare-and-swap

↑ **Parent:** [Atomic read-modify-write](atomic-read-modify-write.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Compare-and-swap)

An [atomic read-modify-write](atomic-read-modify-write.md) that replaces a location only if its current value matches an expected value. An update based on an old version can retry after a failed [compare-and-swap](compare-and-swap.md) instead of blindly overwriting a competing writer's change.
