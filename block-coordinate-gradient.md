# Block coordinate gradient

↑ **Parent:** [Coordinate descent](coordinate-descent.md)

The [orthogonal projection](orthogonal-projection.md) of the [gradient](gradient.md) onto the [coordinate subspace](coordinate-subspace.md) indexed by $\mathcal B$. It is kept as a [vector](vector.md) in the original [Euclidean space](euclidean-norm.md), with zero coordinates outside the block. For a singleton block it is $\partial_i f(x)e_i$; for the full block it is $\nabla f(x)$.
