# Primal problem

↑ **Parent:** [Lagrangian duality](lagrangian-duality.md)

The original [mathematical optimization](mathematical-optimization-split.md) problem relative to a chosen [Lagrangian dual problem](lagrangian-dual-problem.md). In [convex perturbation duality](convex-perturbation-duality.md), its objective is $\varphi(x)=f(x,0)$ and its value is $p(0)$. [Strong duality](strong-duality.md) concerns optimal values; primal attainment additionally requires an actual minimizing point.
