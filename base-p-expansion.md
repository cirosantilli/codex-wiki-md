# Base-p expansion

↑ **Parent:** [Positional notation](positional-notation.md)

For an integer base $p\ge2$, a nonnegative [integer](integer-split.md) has a finite positional representation with digits $k_i\in\{0,\ldots,p-1\}$. Repeated [Euclidean division](euclidean-division.md) gives the digits uniquely; appending zero high-place digits has no effect. The base need not be prime for uniqueness, but a prime base is useful in [Lucas theorem](lucas-s-theorem.md) and modular [binomial coefficients](binomial-coefficient-split.md).
