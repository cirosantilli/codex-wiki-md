<h1 id="ieee-arithmetic-in-oracle-s-numerical-computation-guide">IEEE arithmetic in Oracle's Numerical Computation Guide</h1>

↑ **Parent:** [Mathematics bibliography](mathematics-bibliography-split.md)

Official technical manual: [IEEE Arithmetic](https://docs.oracle.com/cd/E19957-01/806-3568/ncg_math.html).

Relevant locators: IEEE Arithmetic Model, significand precision and overall bit count; Double Format, field layout and Table 2-5; and Ranges and Precisions in Decimal Representation. The source describes the traditional IEEE double format, now called binary64. It supports the precision and storage calculations for the [double-precision floating-point format](double-precision-floating-point-format.md); no claim about a current processor's execution speed is inferred.
