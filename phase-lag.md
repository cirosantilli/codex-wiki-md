# Phase lag

↑ **Parent:** [Phase difference](phase-difference.md)

For an oscillation written $A\cos(\omega t-\phi)$ relative to $A\cos(\omega t)$, a positive $\phi$ represents delayed maxima. The corresponding unwrapped delay is $\phi/\omega$, while a single periodic observation determines the [phase difference](phase-difference.md) only modulo $2\pi$.
