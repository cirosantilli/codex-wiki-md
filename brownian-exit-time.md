# Brownian exit time

↑ **Parent:** [Brownian motion](brownian-motion-split.md)

For a domain $D$, the Brownian exit time is $T_D=\inf\{t\geq0:B_t\notin D\}$. It is a [stopping time](stopping-time.md), and it has finite expectation when $D$ is bounded.
