# Middlebox

↑ **Parent:** [Internet architecture](internet-architecture.md)

A [middlebox](middlebox.md) performs a function on a communication path beyond ordinary [Internet Protocol](internet-protocol.md) forwarding, such as address translation, traffic filtering or proxying. The function can be embedded in a device rather than implemented in a separate physical box. Its state and assumptions can affect failure recovery and [protocol](communication-protocol.md) evolution.[§1.1 and §4: definition and architectural issues](middleboxes-taxonomy-and-issues-rfc-3234.md)
