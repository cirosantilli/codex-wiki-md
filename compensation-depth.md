# Compensation depth

↑ **Parent:** [Isostasy](isostasy.md)

A common reference depth at which lateral [pressure](pressure-split.md) differences are assumed relaxed in an isostatic model. It must lie below relevant lateral [density](density.md) anomalies; it need not be a sharp material interface.
