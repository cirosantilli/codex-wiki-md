# Algol variable

↑ **Parent:** [Eclipsing binary](eclipsing-binary.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algol_variable)

An Algol variable is an [eclipsing binary](eclipsing-binary.md) with well-separated eclipse minima and relatively little variation between eclipses. This light-curve classification includes detached systems as well as interacting [Algol binaries](algol-binary.md); it does not by itself imply [Roche-lobe overflow](roche-lobe-overflow.md).
