# Delta-one formula modulo ZF

↑ **Parent:** [Lévy hierarchy](levy-hierarchy.md)

A [first-order formula](first-order-formula.md) is Delta-one modulo [ZF](zermelo-fraenkel-set-theory.md) if that theory proves it equivalent both to a [Sigma-one formula in set theory](sigma-one-formula-in-set-theory.md) and to a [Pi-one formula in set theory](pi-one-formula-in-set-theory.md), with the same free variables. Equivalently its assertion and negation each have existential-bounded definitions over [ZF](zermelo-fraenkel-set-theory.md). A witness gives upward absoluteness for the first definition; the universal form gives downward absoluteness. Thus the formula has [Delta-one absoluteness](delta-one-absoluteness.md) between nested [transitive models](transitive-model.md) of [ZF](zermelo-fraenkel-set-theory.md).
