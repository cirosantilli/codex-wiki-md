# Control dependency

↑ **Parent:** [Memory model](memory-model.md)

A memory operation's execution is conditional on a preceding value. A [control dependency](control-dependency.md) alone does not generally order two reads on [POWER architecture](power-architecture.md) or the relevant ARM [memory models](memory-model.md); it must not be substituted for an [address dependency](address-dependency.md) in pointer-publication reasoning.
