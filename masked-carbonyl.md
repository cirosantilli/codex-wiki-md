# Masked carbonyl

↑ **Parent:** [Protecting group](protecting-group.md)

A functional group that can later be converted into a [carbonyl](carbonyl-group.md) at a mapped [carbon](carbon.md). A secondary nitro group is a useful example when it also enables [carbon](carbon.md)–[carbon](carbon.md) bond formation before unmasking.
