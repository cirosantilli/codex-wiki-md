# Gamma prime phase

↑ **Parent:** [Nickel-based superalloy](nickel-based-superalloy.md)

The ordered $L1_2$ phase based on $\mathrm{Ni_3Al}$ in many [nickel-based superalloys](nickel-based-superalloy.md). A matrix [translation](translation-geometry.md) $a\langle110\rangle/2$ disrupts its order and can create an [antiphase boundary](antiphase-boundary.md).
