# Minimal point

↑ **Parent:** [Minimal dynamical system](minimal-dynamical-system.md)

A point is minimal when its forward [orbit closure](orbit-closure.md) is a [minimal dynamical system](minimal-dynamical-system.md). This does not require the point to be a [fixed point](fixed-point.md). In a finite-alphabet [full shift](full-shift.md), [minimal points](minimal-point.md) are exactly the [uniformly recurrent](uniform-recurrence.md) [sequences](sequence.md).
