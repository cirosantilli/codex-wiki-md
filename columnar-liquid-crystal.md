# Columnar liquid crystal

↑ **Parent:** [Liquid crystal](liquid-crystal.md)

A columnar liquid crystal has columns arranged with two-dimensional positional order transverse to the column axes and relatively fluid positional order along them. Orientational order alone, as in a [nematic liquid crystal](nematic-liquid-crystal.md), does not specify this structure.
