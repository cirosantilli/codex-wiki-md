# Fixed-effect meta-analysis

↑ **Parent:** [Meta-analysis](meta-analysis.md)

A common-effect synthesis treats study estimates as estimates of one shared effect. For [independent](independent-random-variables.md) approximately unbiased estimates $y_i$ with [variances](variance-split.md) $v_i$, use $\widehat\mu=\sum_iw_iy_i/\sum_iw_i$ with $w_i=v_i^{-1}$. This model does not accommodate additional [between-study heterogeneity](between-study-heterogeneity.md).
