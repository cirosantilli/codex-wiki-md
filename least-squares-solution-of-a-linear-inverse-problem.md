# Least-squares solution of a linear inverse problem

↑ **Parent:** [Normal equation for a linear inverse problem](normal-equation-for-a-linear-inverse-problem.md)

A [least-squares solution](least-squares-solution-of-a-linear-inverse-problem.md) minimizes $\|Ku-f\|$ over the source [Hilbert space](hilbert-space-split.md). It exists exactly when $f\in\mathcal R(K)\oplus\mathcal R(K)^\perp$, and then the solutions form a closed [affine subspace](affine-subspace.md) with direction $\mathcal N(K)$.
