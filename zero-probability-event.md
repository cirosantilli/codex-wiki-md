# Zero-probability event

↑ **Parent:** [Probability measure](probability-measure.md)

A zero-probability event has [probability measure](probability-measure.md) zero. It need not be empty: for a continuously distributed [random variable](random-variable-split.md), equality with a specified value is such an event. The complementary event occurs [almost surely](almost-sure-convergence.md).
