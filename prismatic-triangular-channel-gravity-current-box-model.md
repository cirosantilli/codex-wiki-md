# Prismatic triangular-channel gravity-current box model

↑ **Parent:** [Gravity-current box model](gravity-current-box-model.md)

A uniform-depth [particle-laden gravity current](particle-laden-gravity-current.md) in fixed triangular cross section has conserved [volume](volume.md) proportional to $h^2X$. A [gravity-current front condition](gravity-current-front-condition.md) and absorbing-boundary [particle deposition flux](particle-deposition-flux.md) give $\dot X=\operatorname{Fr}\sqrt{G\phi h}$ and $\dot\phi=-2w(\phi)\phi/h$. The box describes late-time bulk evolution; it does not resolve the nose or immediate dam-break flow.
