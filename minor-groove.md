# Minor groove

↑ **Parent:** [Deoxyribonucleic acid](deoxyribonucleic-acid.md)

The [minor groove](minor-groove.md) of duplex DNA exposes a different set of base edges from the [major groove](major-groove.md). Similar chemical patterns for some oriented base-pair alternatives limit simple direct readout, but groove shape, hydration and electrostatics can still contribute to specificity.
