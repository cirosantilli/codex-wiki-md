# Radical of an ideal is the intersection of the prime ideals containing it

↑ **Parent:** [Radical of an ideal](radical-of-an-ideal.md)

For any [ideal](ideal.md) $I$ in a [commutative ring](commutative-ring.md), every [prime ideal](prime-ideal.md) containing $I$ contains $\sqrt I$, because $a^n\in P$ implies $a\in P$. Conversely, if $a\notin\sqrt I$, the [multiplicatively closed set](multiplicatively-closed-set.md) $T=\{1,a,a^2,\ldots\}$ is disjoint from $I$. By [Zorn's lemma](zorn-s-lemma.md), there is an [ideal](ideal.md) $P\supseteq I$ maximal among those disjoint from $T$.

This $P$ is a [prime ideal](prime-ideal.md): if $bc\in P$ but $b,c\notin P$, maximality makes both $P+(b)$ and $P+(c)$ meet $T$. Multiplication of representatives from these two intersections puts an element of $T$ in $P$, a contradiction. Thus there is a [prime ideal](prime-ideal.md) containing $I$ but avoiding $a$, establishing the identity. For $I=R$, the intersection is empty and means $R$. It follows that an [ideal](ideal.md) is a [radical ideal](radical-ideal.md) exactly when it is an [intersection of ideals](intersection-of-ideals.md) that are all [prime ideals](prime-ideal.md).
