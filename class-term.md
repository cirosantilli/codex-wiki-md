# Class term

↑ **Parent:** [Class (set theory)](class-set-theory.md)

A [class term](class-term.md) abbreviates a definable collection in first-order [set](set-split.md) theory. The expression $\{x:\theta(x,\vec p)\}$ can be eliminated from [logical formulas](logical-formula.md) by replacing [class in set theory](class-set-theory.md) membership with its defining condition. It does not turn a [proper class](proper-class.md) into a [set](set-split.md) or add unrestricted [class in set theory](class-set-theory.md) [quantifiers](quantifier.md).
