# Affine Euler-Lagrange solution from finite derivative fibers

↑ **Parent:** [Euler-Lagrange equation](euler-lagrange-equation.md)

For an autonomous scalar integral $\int f(u')$, the [first variation](first-variation.md) gives the integrated [Euler-Lagrange equation](euler-lagrange-equation.md) $f'(u')=c$. If $u$ is $C^1$ and each fiber of $f'$ is finite, the connected image of the interval under the continuous derivative $u'$ lies in a finite set and is therefore a singleton. The fixed endpoints then determine exactly one affine solution. If $f$ is strictly convex, the strict [Jensen's inequality](jensen-s-inequality.md) applied to $u'$ additionally makes this solution the unique [global minimizer](global-minimizer.md) among fixed-endpoint [Lipschitz functions](lipschitz-continuity.md). Without [convexity](convex-function.md) the same unique smooth stationary solution can be a maximizer, for example at zero for $f(v)=1/(1+v^{2008})$ and zero endpoint values.
