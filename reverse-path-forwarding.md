# Reverse path forwarding

↑ **Parent:** [Multicast routing](multicast-routing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reverse_path_forwarding)

[Reverse path forwarding](reverse-path-forwarding.md) accepts a source's [multicast](multicast.md) traffic only on the interface selected for the reverse route to that source. With consistent loop-free routing, those parent choices define a source-rooted [tree](tree-graph-theory-split.md). Membership pruning can then remove unneeded branches.
