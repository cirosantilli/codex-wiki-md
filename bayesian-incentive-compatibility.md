# Bayesian incentive compatibility

↑ **Parent:** [Incentive compatibility](incentive-compatibility.md)

Truthful reporting is Bayesian incentive compatible when every type maximizes its expected utility over the other players' types by reporting truthfully. In an [independent private values model](independent-private-values-model.md), the displayed inequality uses the same interim allocation and payment functions for every possible true type.
