# Automated planning

↑ **Parent:** [Artificial intelligence](artificial-intelligence-split.md)

Constructing a sequence of actions whose successive applications transform a specified initial state into one satisfying a goal. The formal model must specify action [preconditions](precondition.md), state changes and the meaning of facts absent from a state. [STRIPS](strips.md) represents changes by add and delete lists; [planning state invariants](planning-state-invariant.md) explain which physical properties the action definitions preserve.
