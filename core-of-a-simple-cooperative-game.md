# Core of a simple cooperative game

↑ **Parent:** [Core (game theory)](core-game-theory.md)

For a monotone [simple cooperative game](simple-cooperative-game.md) with empty value $0$ and grand-[coalition](coalition-game-theory.md) value $1$, the [core of a cooperative game](core-game-theory.md) consists exactly of the nonnegative unit-total [payoff](payoff.md) [vector](vector.md)s supported on [veto players](veto-player.md).

For the proof, singleton [core](core-game-theory.md) conditions give $x_i\ge0$. Every [winning coalition](winning-coalition.md) must receive at least $1$, the full available total, so all players outside it receive zero. A positively paid player therefore belongs to every [winning coalition](winning-coalition.md) and is a [veto player](veto-player.md). Conversely, a unit-total nonnegative allocation supported on [veto players](veto-player.md) gives every [winning coalition](winning-coalition.md) exactly $1$ and every losing [coalition](coalition-game-theory.md) at least $0$. These are precisely the [core](core-game-theory.md) inequalities. The [core](core-game-theory.md) is thus nonempty if and only if a [veto player](veto-player.md) exists.
