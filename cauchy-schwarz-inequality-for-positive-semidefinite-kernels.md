# Cauchy-Schwarz inequality for positive-semidefinite kernels

↑ **Parent:** [Positive-semidefinite kernel](positive-semidefinite-kernel.md)

A real [positive-semidefinite kernel](positive-semidefinite-kernel.md) satisfies $|k(x,y)|^2\leq k(x,x)k(y,y)$. This follows from positivity of its two-point [kernel matrix](kernel-matrix.md). If a diagonal value is zero, the corresponding off-diagonal values must also vanish.
