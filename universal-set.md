# Universal set

↑ **Parent:** [Complement of a set](complement-of-a-set.md)

A universal set $U$ fixes the objects under consideration in a particular discussion; each [set](set-split.md) under consideration is a [subset](subset.md) of $U$. For example, $U=\{1,2,3,4,5,6\}$ makes the [complement](complement-of-a-set.md) of $\{1,2,3\}$ equal to $\{4,5,6\}$. This use of “universal” is local to the discussion: it does not assert the existence of a [set](set-split.md) containing every [set](set-split.md). Stating $U$ makes exclusion rules precise.
