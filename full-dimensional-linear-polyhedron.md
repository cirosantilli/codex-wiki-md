# Full-dimensional linear polyhedron

↑ **Parent:** [Linear polyhedron](linear-polyhedron.md)

A [linear polyhedron](linear-polyhedron.md) in $\mathbb R^n$ is full-dimensional when its [affine hull](affine-hull.md) is all of $\mathbb R^n$. Equivalently, it contains an open [Euclidean ball](euclidean-ball.md). An open [Euclidean ball](euclidean-ball.md) spans the ambient space. Conversely, a full-dimensional [convex set](convex-set.md) contains $n+1$ affinely independent points; their [convex hull](convex-hull.md) is a simplex with nonempty interior, so the set contains an open [Euclidean ball](euclidean-ball.md).
