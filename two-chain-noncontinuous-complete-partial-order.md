# Two-chain noncontinuous complete partial order

↑ **Parent:** [Directed-complete partial order](directed-complete-partial-order.md)

Take two increasing countable [chains](chain-in-a-partial-order.md) sharing a [least element](least-element.md) $\bot$ and a [greatest element](greatest-element.md) $\top$, with interiors $a_1<a_2<\cdots$ and $b_1<b_2<\cdots$ and no comparisons between branches. Each entire interior [chain](chain-in-a-partial-order.md) has $\top$ as its [least upper bound](least-upper-bound-in-a-partially-ordered-set.md). A [directed set](directed-set.md) meeting both interiors must contain $\top$. Otherwise it lies within one branch, where it has either a greatest member or [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) $\top$. This proves that the [partially ordered set](partially-ordered-set.md) is a [directed-complete partial order](directed-complete-partial-order.md).

The only element [way-below](way-below-relation.md) $a_n$ is $\bot$. Indeed, an element [way-below](way-below-relation.md) $a_n$ must be below $a_n$, but every positive $a_m\leq a_n$ fails the [way-below relation](way-below-relation.md) when tested against $\{b_1,b_2,\ldots\}$: its [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) is $\top\geq a_n$, yet it has no member above $a_m$. Nonempty [directed sets](directed-set.md) always contain an element above $\bot$, so $\bot\ll a_n$. Thus the elements [way-below](way-below-relation.md) $a_n$ have [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) $\bot\ne a_n$, and this is not a [continuous poset](continuous-poset.md).
