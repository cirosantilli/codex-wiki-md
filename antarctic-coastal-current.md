# Antarctic Coastal Current

↑ **Parent:** [Ocean circulation](ocean-circulation.md)

The Antarctic Coastal Current is a mainly westward flow near the Antarctic coast. It can transport [icebergs](iceberg.md) along the continental margin; coastal geometry, winds and regional circulation make trajectories variable.
