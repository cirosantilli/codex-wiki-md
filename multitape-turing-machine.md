# Multitape Turing machine

↑ **Parent:** [Turing machine](turing-machine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multitape_Turing_machine)

A [Turing machine](turing-machine.md) with a fixed finite number of tapes and a head for each tape. One transition reads the scanned symbols, updates them and moves the heads. This model accepts the same [computably enumerable languages](recursively-enumerable-language.md) as a [single-tape Turing machine](single-tape-turing-machine.md), but step counts can differ.
