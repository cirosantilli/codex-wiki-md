# Fourier transform of a triangular function

↑ **Parent:** [Fourier analysis](fourier-analysis-split.md)

For $\theta_n(x)=(1-|x|/n)_+$,

$$
\widehat\theta_n(\xi)
=\frac{2(1-\cos(n\xi))}{n\xi^2}
=n\left(\frac{\sin(n\xi/2)}{n\xi/2}\right)^2,
$$

with value $n$ at zero.
