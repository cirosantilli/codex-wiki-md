# Relator exponent-sum matrix

↑ **Parent:** [Balanced presentation](balanced-presentation.md)

For a finite [group presentation](group-presentation.md), the relator exponent-sum matrix records in row $i$ the total exponent of each generator in relator $r_i$. It presents the [abelianization](abelianization.md) of the group. For a balanced presentation of a [perfect group](perfect-group.md), it is a [unimodular matrix](unimodular-matrix.md).
