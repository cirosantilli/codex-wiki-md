# Strong lumpability

↑ **Parent:** [Markov chain](markov-chain.md)

A partition of a [Markov chain](markov-chain.md) state space is strongly lumpable when, for every target block $C$, the sum $\sum_{j\in C}p_{ij}$ is identical for all source states $i$ in a given source block. These sums define the [transition matrix](stochastic-matrix.md) of the block-valued [Markov chain](markov-chain.md), independently of the initial law. Failure of this condition means the projection is not guaranteed to be a homogeneous Markov chain for every initial law, although special initial laws may still produce a Markov process.
