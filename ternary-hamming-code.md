# Ternary Hamming code

↑ **Parent:** [Hamming code](hamming-code.md)

For $s\geq2$, use one nonzero representative from each one-dimensional subspace of $\mathbb F_3^s$ as a [parity-check matrix](parity-check-matrix.md) column. The [rank](rank-one-quadratic-form.md) is $s$; no zero or proportional columns imply [minimum Hamming distance](minimum-distance-of-a-code.md) at least three. Two independent columns and the representative of their sum give a weight-three relation, proving equality. Every nonzero [syndrome](syndrome.md) uniquely identifies one column and one nonzero error value.
