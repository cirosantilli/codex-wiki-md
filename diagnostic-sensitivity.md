# Diagnostic sensitivity

↑ **Parent:** [Binary classification](binary-classification.md)

[Diagnostic sensitivity](diagnostic-sensitivity.md) is the probability that a test is positive in a person who has the target condition. For past-infection assays, the target is prior infection rather than current disease. Estimate it from suitable independently characterized positive samples; using the same assay to define truth would make the assessment circular.
