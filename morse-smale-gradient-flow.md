# Morse-Smale gradient flow

↑ **Parent:** [Gradient flow](gradient-flow.md)

For a [Morse function](morse-function.md), a downward [gradient flow](gradient-flow.md) is Morse-Smale if every [unstable manifold](unstable-manifold.md) meets every [stable manifold](stable-manifold.md) transversely. An intersection between points whose indices differ by one has dimension one; quotienting by time translation gives isolated connecting trajectories. Choosing orientations of the unstable [manifolds](topological-manifold.md) assigns signs to these trajectories and defines the differential of the [Morse-Smale complex](morse-smale-complex.md).
