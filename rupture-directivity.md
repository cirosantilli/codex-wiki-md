# Rupture directivity

↑ **Parent:** [Finite-source rupture](finite-source-rupture.md)

Azimuth-dependent compression or stretching of observed source radiation because later-rupturing patches have different source-to-receiver travel times. A unilateral rupture generally yields shorter apparent duration in its forward direction. Pulse width also contains local slip rise time, instrument response and path effects, so directivity requires controlled comparisons.
