# Optimal stopping time

↑ **Parent:** [Snell envelope](snell-envelope.md)

An optimal stopping time attains the supremum of the expected reward over an admissible class of [stopping times](stopping-time.md). For a finite-horizon [Snell envelope](snell-envelope.md), the first time at which its value equals the current reward is optimal.
