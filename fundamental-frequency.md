# Fundamental frequency

↑ **Parent:** [Eigenfrequency](eigenfrequency.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fundamental_frequency)

The lowest positive [normal mode frequency](eigenfrequency.md) of an oscillating system is its [fundamental frequency](fundamental-frequency.md). For an ideal uniform string of length $L$ with fixed ends and [phase speed](phase-speed.md) $c$, $f_1=c/(2L)$. A spatial [finite difference](finite-difference-split.md) approximation has its own lowest positive [normal mode frequency](eigenfrequency.md), approaching this continuous value as the grid is refined.
