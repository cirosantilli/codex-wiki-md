# Dirichlet gauge transform for constant drift

↑ **Parent:** [Advection-diffusion equation](advection-diffusion-equation.md)

For the [advection-diffusion equation](advection-diffusion-equation.md) $u_t=u_{xx}+2au_x$, the multiplication $w=e^{ax}u$ gives $w_t=w_{xx}-a^2w$. A [Dirichlet boundary condition](dirichlet-boundary-condition.md) remains a prescribed value, multiplied by $e^{ax}$ at the endpoint. This real exponential conjugation removes the first [derivative](derivative.md) without changing a bounded spatial interval.
