# Infeasibility certificate from an unbounded Lagrangian dual

↑ **Parent:** [Lagrangian duality](lagrangian-duality.md)

For a maximization problem, every [feasible point](feasible-point.md)'s finite objective is bounded above by every valid [Lagrangian relaxation](lagrangian-relaxation.md) value. If a sequence of nonnegative multipliers makes those upper bounds tend to minus infinity, no [feasible point](feasible-point.md) can exist. Thus a minimization [Lagrangian dual problem](lagrangian-dual-problem.md) unbounded below certifies primal infeasibility. Finite dual value alone does not certify primal feasibility.
