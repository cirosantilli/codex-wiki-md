# Pi-one formula in set theory

↑ **Parent:** [Lévy hierarchy](levy-hierarchy.md)

A syntactically $\Pi_1$ [first-order formula](first-order-formula.md) has an unbounded universal quantifier block followed by a [bounded formula in set theory](bounded-formula-in-set-theory.md). Universal quantification makes it downward absolute between [transitive models](transitive-model.md). A [Pi-one formula modulo ZF](pi-one-formula-modulo-zf.md) may have another syntax but has such an equivalent provable in [ZF](zermelo-fraenkel-set-theory.md).
