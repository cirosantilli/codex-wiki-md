# Ideal quotient

↑ **Parent:** [Ideal](ideal.md)

For [ideals](ideal.md) $I,J$ in a commutative [ring](ring.md), the ideal quotient is $(I:J)=\{r\in R:rJ\subseteq I\}$. Closure under subtraction and multiplication by arbitrary ring elements proves it is an [ideal](ideal.md). If $I\subseteq J=(a)$, then $I=a(I:J)$: write $x=ar\in I$ and observe that $rJ=xR\subseteq I$. Consequently, if also $(I:J)=(b)$, then $I=(ab)$ is a [principal ideal](principal-ideal.md).
