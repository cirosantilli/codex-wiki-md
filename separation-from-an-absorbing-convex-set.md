# Separation from an absorbing convex set

↑ **Parent:** [Hahn-Banach separation theorem](hahn-banach-separation-theorem.md)

If a [convex set](convex-set.md) $E$ in a real [normed vector space](normed-vector-space.md) contains $B(0,\epsilon)$, every $x\notin E$ admits a [continuous linear functional](continuous-linear-functional.md) $T$ with $Tx\geq1\geq Te$ for all $e\in E$, even if $E$ is not closed. Its [Minkowski functional](minkowski-functional.md) $p(v)=\inf\{t>0:v\in tE\}$ is [sublinear functional](sublinear-function.md), satisfies $p(v)\leq\|v\|/\epsilon$, $p(e)\leq1$, and $p(x)\geq1$. Extend $tx\mapsto tp(x)$ by the dominated [Hahn-Banach theorem](hahn-banach-theorem.md). The resulting domination $T\leq p$ applied to $v$ and $-v$ makes $T$ continuous and supplies the separation inequalities.
