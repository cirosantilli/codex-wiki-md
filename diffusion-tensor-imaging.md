# Diffusion tensor imaging

↑ **Parent:** [Magnetic resonance imaging](magnetic-resonance-imaging.md)

An imaging approach describing direction-dependent water diffusion using a tensor model. In [white matter](white-matter.md) it provides indirect information about tissue organisation; crossing fibres, motion and model limitations affect interpretation.
