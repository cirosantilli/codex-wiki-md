# Entringer number

↑ **Parent:** [Combinatorics](combinatorics-split.md)

Entringer numbers refine counts of alternating [permutations](permutation.md). One standard convention uses $E(0,0)=1$, $E(n,0)=0$ for $n>0$, and $E(n,k)=E(n,k-1)+E(n-1,n-k)$ for $1\le k\le n$. Reversed-row [prefix sums](prefix-sum.md) generate the triangle.
