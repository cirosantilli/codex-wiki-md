# Least-upper-bound property

↑ **Parent:** [Completeness of the real numbers](completeness-of-the-real-numbers.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Least-upper-bound_property)

The least-upper-bound property states that every nonempty set of [real numbers](real-number.md) that has an [upper bound](upper-bound-in-a-partially-ordered-set.md) has a [supremum](supremum.md) in the real numbers. It is an order-theoretic formulation of the [completeness of the real numbers](completeness-of-the-real-numbers.md).
