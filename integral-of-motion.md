# Integral of motion

↑ **Parent:** [Hamiltonian mechanics](hamiltonian-mechanics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Integral_of_motion)

An integral of motion is a function on [phase space](phase-space.md) that remains constant along every trajectory. If it has no explicit time dependence, $I(q,p)$ is an integral exactly when its [Poisson bracket](poisson-bracket.md) with the [Hamiltonian](hamiltonian.md) vanishes: $\{I,H\}=0$.
