# Hilbert class field of Q of square root minus thirty-one

↑ **Parent:** [Hilbert class field](hilbert-class-field.md)

The [splitting field](splitting-field.md) of $T^3+T-1$ has discriminant square class $-31$ and [Galois group](galois-group.md) $S_3$. It is the [Hilbert class field](hilbert-class-field.md) of $K=\mathbb Q(\sqrt{-31})$: the relative extension is unramified cyclic cubic, and the [ideal class group of Q of square root minus thirty-one](ideal-class-group-of-q-of-square-root-minus-thirty-one.md) has order three. Locally at $31$, the simple residue root $28$ lifts and the remaining quadratic splits over $\mathbb Q_{31}(\sqrt{-31})$, so the prime of $K$ above $31$ splits completely in its [Hilbert class field](hilbert-class-field.md). The inverse generator satisfies $T^3-T^2-1=0$.
