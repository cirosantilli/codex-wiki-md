# Dilate of a Bohr set

↑ **Parent:** [Bohr set](bohr-set.md)

If $B=B(\Gamma,\rho)$ is a [Bohr set](bohr-set.md), its $\delta$-dilate is $B_\delta=B(\Gamma,\delta\rho)$. The triangle inequality on the unit circle gives $B_\delta+B_\eta\subseteq B_{\delta+\eta}$.
