# Smooth atlas

↑ **Parent:** [Manifold chart](manifold-chart.md)

A smooth atlas is a collection of [manifold charts](manifold-chart.md) covering a [topological manifold](topological-manifold.md) whose coordinate changes are [smooth transition maps](smooth-transition-map.md). It determines a [smooth manifold](smooth-manifold.md) structure by adjoining every compatible chart.
