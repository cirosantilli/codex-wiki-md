# Compact metrizable convex set

↑ **Parent:** [Locally convex space](locally-convex-space.md)

Here the set is a nonempty compact metrizable convex subset of a Hausdorff locally convex space. The ambient space can be infinite-dimensional. Continuous affine [functions](function-split.md) separate its points, and weak-star compact dual balls with separable preduals provide examples. This general setting is needed for [Choquet theorem](choquet-theorem.md).
