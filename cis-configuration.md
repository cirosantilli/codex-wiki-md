# Cis configuration

↑ **Parent:** [Stereochemistry](stereochemistry-split.md)

A [cis configuration](cis-configuration.md) places the specified substituents on the same side of a restricted structural element. A cis double bond in a fatty-acyl chain commonly disrupts close chain packing relative to the comparable trans arrangement.
