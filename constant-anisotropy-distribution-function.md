# Constant-anisotropy distribution function

↑ **Parent:** [Galactic distribution function](galactic-distribution-function.md)

A spherical constant-anisotropy distribution function has

$$
f(\mathcal E,L)=L^{-2\beta}f_E(\mathcal E).
$$

Its velocity moments have the radius-independent [velocity-anisotropy parameter](velocity-anisotropy-parameter.md) $\beta$.
