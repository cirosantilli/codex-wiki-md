# Integrated second-order kernel bias bound

↑ **Parent:** [Bias of a kernel density estimator](bias-of-a-kernel-density-estimator.md)

For a nonnegative symmetric unit-integral [kernel for density estimation](kernel-for-density-estimation.md) and $f\in H^2(\mathbb R)$, the integral [Taylor remainder](taylor-remainder.md) and [Minkowski inequality](minkowski-inequality.md) give $\|K_h*f-f\|_2\le h^2\mu_2(K)\|f^{\prime\prime}\|_2/2$. Translation preserves the [L2 norm](l2-norm.md). For a signed kernel the same proof requires the absolute moment $\int u^2|K(u)|\,du$.
