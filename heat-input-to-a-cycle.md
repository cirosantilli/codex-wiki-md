# Heat input to a cycle

↑ **Parent:** [Heat engine](heat-engine.md)

The [heat input to a cycle](heat-input-to-a-cycle.md) sums positive transfers of [heat](heat-split.md) into its working substance. It is not the net [heat](heat-split.md) over the entire cycle, which equals net [work](work.md). A single geometric branch can contain both heat absorption and rejection, so grouping the branch into one net transfer can overestimate a [heat engine](heat-engine.md)'s [thermal efficiency](thermal-efficiency.md).
