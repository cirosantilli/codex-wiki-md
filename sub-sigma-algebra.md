# Sub-sigma-algebra

↑ **Parent:** [Sigma-algebra](sigma-algebra.md)

A [sigma-algebra](sigma-algebra.md) $\mathcal G$ on the same underlying [set](set-split.md) as $\mathcal F$, with $\mathcal G\subseteq\mathcal F$. In [probability theory](probability-theory-split.md) it represents information retained from the original [probability space](probability-space-split.md) and is a possible conditioning collection for a [conditional expectation](conditional-expectation.md).
