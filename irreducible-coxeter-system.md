# Irreducible Coxeter system

↑ **Parent:** [Coxeter graph](coxeter-graph.md)

An irreducible Coxeter system is one whose [Coxeter graph](coxeter-graph.md) is connected. The connected components of a Coxeter graph give the direct-product decomposition of its Coxeter group.
