# Irreducible three-manifold

↑ **Parent:** [3-manifold](3-manifold.md)

An orientable [three-manifold](3-manifold.md) is irreducible if every embedded two-sphere bounds a three-ball. This makes innermost-disk simplifications of embedded [topological surfaces](topological-surface.md) possible without changing the ambient [three-manifold](3-manifold.md).
