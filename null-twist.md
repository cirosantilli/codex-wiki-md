# Null twist

↑ **Parent:** [Optical tensor](optical-tensor.md)

The null twist is $\widehat\omega_{ab}=\widehat B_{[ab]}$. It vanishes for null generators orthogonal to a hypersurface by the [Frobenius theorem](frobenius-theorem.md).
