# Finite residual contains surjective endomorphism kernels

↑ **Parent:** [Finite residual](finite-residual.md)

Let $G$ be a [finitely generated group](finitely-generated-group.md) and $\theta:G\to G$ a surjective [endomorphism](endomorphism.md). Pullback by $\theta$ permutes the finite set of normal subgroups of any prescribed finite index. For each such $N$, some iterate satisfies $\theta^{-m}(N)=N$, so $\ker\theta\subseteq\ker\theta^m\subseteq N$. Intersecting proves the inclusion. Consequently every finitely generated [residually finite group](residually-finite-group.md) is a [Hopfian group](hopfian-group.md).
