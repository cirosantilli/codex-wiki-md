# Skew-Hermitian matrix

↑ **Parent:** [Operator theory](linear-operator-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Skew-Hermitian_matrix)

A complex matrix $A$ is skew-Hermitian when $A^\dagger=-A$. Its [matrix exponential](matrix-exponential.md) $e^{tA}$ is [unitary](unitary-matrix.md) for every real $t$.
