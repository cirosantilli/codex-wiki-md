# Orthogonal block design

↑ **Parent:** [Block design](block-design.md)

An [orthogonal block design](orthogonal-block-design.md) has centered treatment-indicator vectors [orthogonal](orthogonal-vectors.md) to centered block-indicator vectors on the [experimental units](experimental-unit.md). With treatment replication $r_i$, block size $k_j$ and total $n$, this is equivalent to $n_{ij}=r_i k_j/n$. It permits additive block adjustment without changing treatment estimates.
