# Bitwise AND

↑ **Parent:** [Bitwise operation](bitwise-operation.md)

Bitwise AND combines binary representations position by position, setting a bit exactly when it is set in every operand. For [bit masks](bit-mask.md) representing sets, it computes intersection.
