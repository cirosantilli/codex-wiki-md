# Chordal SLE in a specified scale

↑ **Parent:** [Conformal invariance of SLE](conformal-invariance-of-sle.md)

A scale is a [conformal bijection](biholomorphism.md) sending a marked starting boundary point to zero and target boundary point to infinity in the [complex upper half-plane](upper-half-plane-complex-analysis.md). A curve is [SLE](schramm-loewner-evolution.md) in that scale when its image is ordinary [SLE](schramm-loewner-evolution.md) using the [half-plane-capacity parameterization](half-plane-capacity-parameterization.md) of that image.
