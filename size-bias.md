# Size bias

↑ **Parent:** [Size-biased distribution](size-biased-distribution.md)

Reweight probabilities proportionally to the nonnegative value being observed, then divide by its positive finite [expected value](expected-value-split.md). This produces a [size-biased distribution](size-biased-distribution.md). Values twice as large receive twice the original relative weight; this is a change in the sampling law rather than a deterministic multiplication of the sampled value.
