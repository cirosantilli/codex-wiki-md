# Union by size

↑ **Parent:** [Disjoint-set data structure](disjoint-set-data-structure.md)

When merging two components in a [disjoint-set data structure](disjoint-set-data-structure.md), attach the representative of the smaller component to that of the larger one. Each time an element's depth increases its component size at least doubles, so its depth is logarithmically bounded even before [path compression](path-compression.md) is applied.
