# Mean-zero function

↑ **Parent:** [Expected value](expected-value.md)

A mean-zero function has [expectation](expected-value.md) zero with respect to the specified [probability measure](probability-measure.md). On a [finite set](finite-set.md) with uniform measure this means $\sum_xf(x)=0$. A [balanced subset indicator](balanced-indicator-function-of-a-finite-subset.md) is an example. In [Fourier analysis on a finite group](fourier-analysis-on-a-finite-group.md), this is equivalent to vanishing of the component at the [trivial representation](trivial-representation.md).
