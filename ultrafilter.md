# Ultrafilter

↑ **Parent:** [Filter (set theory)](filter-set-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ultrafilter)

An ultrafilter on a set $X$ is a proper [filter on a set](filter-set-theory.md) that contains exactly one of $A$ and $X\setminus A$ for every $A\subseteq X$.
