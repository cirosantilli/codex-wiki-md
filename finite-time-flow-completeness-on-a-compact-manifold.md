# Finite-time flow completeness on a compact manifold

↑ **Parent:** [Time-dependent vector field](time-dependent-vector-field.md)

A smooth [time-dependent vector field](time-dependent-vector-field.md) on a compact manifold without boundary has [flow maps](flow-map.md) throughout each compact time interval on which the field is defined. Finite-time escape is impossible on the compact state space. Uniqueness and the backward-time equation supply smooth inverses, so the flow is a [smooth isotopy](smooth-isotopy.md).
