# Central-commutator differentiation rule

↑ **Parent:** [Commutator](commutator.md)

If $D=[A,B]$ commutes with $A$, then $[A^n,B]=nDA^{n-1}$. A convergent [power series](power-series.md) therefore gives $[F(A),B]=DF'(A)$ on a common domain where termwise operations are justified. For unbounded [linear operators](linear-operator.md), the domain condition is essential.
