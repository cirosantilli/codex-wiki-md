# Littrow configuration

↑ **Parent:** [Diffraction grating](diffraction-grating.md)

In the Littrow configuration the selected diffracted ray retraces the incident ray, so $\alpha=\beta$ and the [grating equation](grating-equation.md) becomes $m\lambda=2d\sin\alpha$.
