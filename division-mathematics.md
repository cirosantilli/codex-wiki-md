# Division (mathematics)

↑ **Parent:** [Arithmetic](arithmetic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Division_(mathematics))

For [real numbers](real-number.md) $a$ and $b\ne0$, [division](division-mathematics.md) $a/b$ asks for the unique [number](number.md) $x$ satisfying $bx=a$. Equivalently, $a/b=a b^{-1}$ uses the [multiplicative inverse](multiplicative-inverse.md) of $b$. This description separates the role of the [denominator](denominator.md) from the result: the [quotient](quotient.md) undoes a specified [multiplication](multiplication.md).

For example, $3/2$ is the [number](number.md) whose double is three, so it is exactly $1.5$. A second interpretation asks how many portions of size $2$ fit into an amount $3$; the answer is one and a half portions. Equal sharing and measuring with a specified portion size lead to the same [quotient](quotient.md), although the units assigned to the result can differ.

In the [natural numbers](natural-number.md), exact [division](division-mathematics.md) need not be possible. [Euclidean division](euclidean-division.md) instead keeps a [remainder](remainder.md): $17=5\cdot3+2$, with $0\leq2<5$. Thus seventeen objects form three complete groups of five with two left over. As a [rational number](rational-number.md), the same [quotient](quotient.md) is $17/5=3+2/5=3.4$. The [remainder](remainder.md) and the [fractional part](fractional-part.md) describe the same unfinished group in different ways.

[Division](division-mathematics.md) by zero cannot retain the unique-solution rule. For $a\ne0$, the equation $0x=a$ has no solution; for $a=0$, every [real number](real-number.md) $x$ solves $0x=0$, so there is no unique [quotient](quotient.md). This explains both failures through [multiplication](multiplication.md), rather than assigning $a/0$ a value that would contradict ordinary [arithmetic](arithmetic-split.md).
