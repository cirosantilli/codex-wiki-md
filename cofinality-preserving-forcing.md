# Cofinality-preserving forcing

↑ **Parent:** [Forcing](forcing-split.md)

A [forcing](forcing-split.md) is cofinality-preserving over a [transitive model](transitive-model.md) $M$ if every [generic extension](generic-extension.md) has the same [cofinality](cofinality.md) for every ground [ordinal](ordinal.md). The values are compared as [ordinals](ordinal.md), which [forcing](forcing-split.md) preserves.
