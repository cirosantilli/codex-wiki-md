# Bus cycle

↑ **Parent:** [Bus transaction](bus-transaction.md)

One clock period in a synchronous [computer bus](computer-bus.md). A [bus transaction](bus-transaction.md) can occupy several [bus cycles](bus-cycle.md). An asynchronous [computer bus](computer-bus.md) instead coordinates progress through acknowledgments, so a clock-based count requires an additional timing model.[CS152 lecture 21, slides 32–33: synchronous and asynchronous sequencing](cs152-computer-architecture-and-engineering-fall-1999/lecture-21-buses-and-i-and-o.md)
