# Implicit function

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Implicit_function)

An [implicit function](implicit-function.md) is a [function](function-split.md) specified through a relation between its input and output, rather than an explicit output formula. Locally, an [equation](equation.md) $F(x,y)=0$ may specify $y=g(x)$ if one output $y$ is selected for each input $x$ in a suitable domain. Different branches can define different [functions](function-split.md); the relation itself need not give a unique output globally. For example, $x^2+y^2=1$ gives the two branches $y=\pm\sqrt{1-x^2}$ on $-1<x<1$.

The [implicit function theorem](implicit-function-theorem.md) gives sufficient conditions for a unique local differentiable branch, while [implicit differentiation](implicit-differentiation.md) computes its [derivative](derivative.md) by the [chain rule](chain-rule.md). If $F$ is continuously differentiable and $F_y\ne0$, that [derivative](derivative.md) is $g'(x)=-F_x/F_y$ along the branch.
