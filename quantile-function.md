# Quantile function

↑ **Parent:** [Probability distribution](probability-distribution.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantile_function)

For a distribution function $F$, its generalized inverse or quantile function is

$$
F^{-1}(p)=\inf\{t:F(t)\geq p\}.
$$
