# Mathieu characteristic value

↑ **Parent:** [Mathieu equation](mathieu-equation.md)

The Mathieu characteristic values are the parameter values $a$ for which the [Mathieu equation](mathieu-equation.md) has the even periodic mode traditionally denoted $\operatorname{ce}_n$, or the odd periodic mode $\operatorname{se}_n$. They are [eigenvalues](eigenvalue.md) of $-d^2/dt^2+2q\cos2t$ with the corresponding periodic or antiperiodic [boundary conditions](boundary-condition.md). Their small-$q$ expansions can be derived by projecting onto a [Fourier series](fourier-series-split.md) and perturbing the resulting tridiagonal [matrix](matrix.md).
