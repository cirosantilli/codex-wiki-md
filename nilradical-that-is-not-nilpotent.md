# Nilradical that is not nilpotent

↑ **Parent:** [Nilradical](nilradical.md)

In $R=k[t_1,t_2,\ldots]/(t_1^2,t_2^2,\ldots)$, the [nilradical](nilradical.md) is generated by all $\bar t_i$. Every element uses finitely many variables and is nilpotent, while each square-free product $\bar t_1\cdots\bar t_j$ is nonzero. Thus this [nilradical](nilradical.md) is not a [nilpotent ideal](nilpotent-ideal.md). A [Noetherian ring](noetherian-ring.md) cannot have this behavior: finitely many nilpotent generators give a nilpotent [ideal](ideal.md).
