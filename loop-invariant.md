# Loop invariant

↑ **Parent:** [Algorithm correctness](algorithm-correctness.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Loop_invariant)

A statement true whenever execution reaches a chosen point in a loop, usually immediately before its condition is tested. Establish it initially, preserve it through each iteration, and combine it with the exit condition to establish [algorithm correctness](algorithm-correctness.md). Termination needs a separate argument.[Cornell CS 2112: loop invariants](https://www.cs.cornell.edu/courses/cs2112/2019fa/lectures/loopinv/)
