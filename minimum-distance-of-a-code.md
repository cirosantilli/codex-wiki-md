# Minimum distance of a code

↑ **Parent:** [Hamming distance](hamming-distance.md)

The minimum distance of a code $C$ is the least [Hamming distance](hamming-distance.md) between distinct codewords. For a [linear code](linear-code.md), translation invariance makes this equal to the least [Hamming weight](hamming-weight.md) of a nonzero codeword.
