# Uniform module

↑ **Parent:** [Module theory](module-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Uniform_module)

A nonzero [module](module-mathematics.md) is uniform if every pair of nonzero [submodules](submodule.md) has nonzero intersection. Equivalently, every nonzero [submodule](submodule.md) is an [essential submodule](essential-submodule.md). A [right Noetherian domain](right-noetherian-domain.md) is uniform as a right [module](module-mathematics.md): if $aA\cap bA=0$ for nonzero $a,b$, the [right ideals](right-ideal.md) $b^iaA$, $i\geq0$, form an infinite [direct sum](direct-sum.md), contradicting the [ascending chain condition](ascending-chain-condition.md).
