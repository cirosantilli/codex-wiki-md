# Identity function

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Identity_function)

The [identity function](identity-function.md) on a [set](set-split.md) $X$ maps each $x\in X$ to itself: $\operatorname{id}_X(x)=x$. It changes no information. For every [function](function-split.md) $f:X\to Y$, [function composition](function-composition.md) satisfies $f\circ\operatorname{id}_X=f$ and $\operatorname{id}_Y\circ f=f$. The subscripts specify the appropriate source or target [set](set-split.md). An [inverse function](inverse-function.md) reverses a [bijection](bijection.md) exactly when the two possible compositions are these [identity functions](identity-function.md).
