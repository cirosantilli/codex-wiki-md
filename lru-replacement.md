# LRU replacement

↑ **Parent:** [Page replacement](page-replacement.md)

Evict the least recently accessed eligible item. Exact recency tracking on every memory reference can be expensive, whereas accesses to a [buffer cache](buffer-cache.md) already pass through software. Recency captures [temporal locality](temporal-locality.md) but can be defeated by a one-pass scan.
