# Gyrotactic focusing in a downward pipe flow

↑ **Parent:** [Gyrotaxis](gyrotaxis.md)

For a bottom-heavy spherical swimmer in axial flow $u_z=W_0(-1+r^2+w)$, the [bottom-heavy spherical-cell orientation dynamics](bottom-heavy-spherical-cell-orientation-dynamics.md) with aligning rate $1/B$ gives $\sin\theta=-\lambda(2r+w')$, $\lambda=BW_0/(2R)$. On the upward-stable branch $\cos\theta>0$, the cells tilt inward in a downward [Poiseuille flow](hagen-poiseuille-equation.md). Zero radial cell flux with scalar [diffusivity](diffusion-coefficient.md) gives $n'=\chi n\sin\theta$, $\chi=V_cR/D$. For $w=0$, integration and the average normalization $2\int_0^1nr\,dr=1$ give the displayed concentration. A steady deterministic orientation requires $|\lambda(2r+w')|<1$; beyond this shear threshold the stationary orientation closure fails.
