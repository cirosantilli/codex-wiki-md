# Model companion

↑ **Parent:** [Model-complete theory](model-complete-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Model_companion)

A model companion of $T$ is a [model-complete theory](model-complete-theory.md) $T^*$ in the same language with $T^*_\forall=T_\forall$. Equivalently each model of either theory embeds into a model of the other. Alternating these embeddings and using the [elementary chain theorem](elementary-chain-theorem.md) proves uniqueness up to logical equivalence. A model companion need not be a syntactic extension of its original theory.
