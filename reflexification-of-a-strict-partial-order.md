# Reflexification of a strict partial order

↑ **Parent:** [Strict partial order](strict-partial-order.md)

Reflexification turns a [strict partial order](strict-partial-order.md) into a [partial order](partially-ordered-set.md). Reflexivity is immediate, transitivity follows by the four disjunction cases, and antisymmetry follows because two opposed strict comparisons imply a forbidden self-comparison. The construction uses only [coherent logic](coherent-logic.md), so is preserved by [inverse image functors of geometric morphisms](inverse-image-functor-of-a-geometric-morphism.md).
