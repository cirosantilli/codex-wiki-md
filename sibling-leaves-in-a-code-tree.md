# Sibling leaves in a code tree

↑ **Parent:** [Huffman sibling property](huffman-sibling-property.md)

Two leaves of a [code tree](prefix-tree-of-a-code.md) with the same [parent in a rooted tree](parent-in-a-rooted-tree.md). Their [codewords](codeword.md) have a common initial segment $u$ and differ only in the final [bit](bit.md): $u0,u1$. Their [leaf depth in a code tree](leaf-depth-in-a-code-tree.md) is equal. The [Huffman sibling property](huffman-sibling-property.md) places two chosen least weights at such leaves in some [optimal prefix code](optimal-prefix-code.md).
