# Borazine dearomatization

↑ **Parent:** [Borazine](borazine.md)

[Borazine dearomatization](borazine-dearomatization.md) interrupts the planar pi system, for example when a [nucleophile](nucleophile.md) makes one boron tetrahedral. In a [metal](metal.md) pi complex, this can change ring [hapticity](hapticity.md) and produce a charged ligand with a different donor count.
