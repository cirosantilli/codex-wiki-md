# Wave dispersion

↑ **Parent:** [Dispersion relation](dispersion-relation-split.md)

Wave dispersion means that [phase velocity](phase-velocity.md) depends on [wavenumber](wavenumber.md) or, equivalently, [wavelength](wavelength.md). [Wave packets](wave-packet.md) generally travel with [group velocity](group-velocity.md), which need not equal [phase velocity](phase-velocity.md). The [linear rotating shallow-water dispersion relation](linear-rotating-shallow-water-dispersion-relation.md) $\omega^2=f^2+c^2k^2$ has faster long-wave phase motion but slower long-[wave packet](wave-packet.md) motion when $f\ne0$.
