# Upper triangular matrix

↑ **Parent:** [Triangular matrix](triangular-matrix.md)

An upper triangular matrix has zero entries below its main diagonal. Its [determinant](determinant.md) is the product of its diagonal entries, and an invertible upper triangular linear system is solved by backward substitution.
