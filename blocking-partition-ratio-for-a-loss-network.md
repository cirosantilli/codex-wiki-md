# Blocking partition ratio for a loss network

↑ **Parent:** [Product-form stationary distribution of a loss network](product-form-stationary-distribution-of-a-loss-network.md)

Let $Z(C)$ sum the unnormalized occupancy weights $\prod_r\rho_r^{n_r}/n_r!$ over feasible counts. The states admitting another type-$r$ call are exactly those feasible under capacities $C-A_r$. [Poisson arrivals see time averages](poisson-arrivals-see-time-averages.md) therefore gives the displayed blocking probability. Take $Z$ to be zero when the reduced capacities make its feasible set empty.
