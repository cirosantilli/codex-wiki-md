# Rationality indicator is not Baire class one

↑ **Parent:** [Baire class one function](baire-class-one-function.md)

The indicator of the [rational numbers](rational-number.md) in the [real numbers](real-number.md) is discontinuous everywhere because both the rationals and irrationals are dense. The discontinuity theorem for [Baire class one functions](baire-class-one-function.md) therefore shows that it is not Baire class one.
