# Closed-fibre lower bound by finite normalization

↑ **Parent:** [Fiber dimension theorem](fiber-dimension-theorem.md)

For a surjective morphism of irreducible varieties, choose an affine neighborhood of the target point and a finite [Noether normalization](noether-normalization.md) to affine space of target dimension $r$. On an affine source neighborhood the composite fibre is cut out by $r$ functions, so repeated [principal hypersurface dimension lemma](principal-hypersurface-dimension-lemma.md) gives dimension at least source dimension minus $r$ on every component. The normalization fibre is finite. The original fibre is therefore an open-and-closed union of components of that composite fibre, proving the bound without assuming target smoothness. For a reducible source the bound must instead be applied using the dimension of each source component.
