# Classical-path factorization of a quadratic path integral

↑ **Parent:** [Gaussian path integral](gaussian-path-integral.md)

For a quadratic [potential energy](potential-energy.md), shifting a path to its classical solution leaves an exactly quadratic fluctuation [action](action.md) with homogeneous [Dirichlet boundary conditions](dirichlet-boundary-condition.md). The first variation vanishes by the [Euler-Lagrange equation](euler-lagrange-equation.md). The [Gaussian path integral](gaussian-path-integral.md) prefactor is an inverse square root of a regulated [functional determinant](functional-determinant.md) and does not depend on the endpoints. At conjugate times the ordinary formula must instead be read by distributional continuation.
