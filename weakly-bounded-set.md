# Weakly bounded set

↑ **Parent:** [Weak topology](weak-topology-split.md)

A subset $D$ of a [normed vector space](normed-vector-space.md) is weakly bounded when $\sup_{x\in D}|f(x)|<\infty$ for every $f\in X^*$. It is norm bounded: its [canonical embedding into the bidual](canonical-embedding-into-the-bidual.md) is a pointwise bounded family of functionals on the complete [continuous dual space](continuous-dual-space-split.md), so the [Uniform boundedness principle](uniform-boundedness-principle.md) applies. The converse is immediate. A [weakly compact set](weakly-compact-set.md) is weakly bounded because each scalar evaluation has compact image.
