# Fermat number

↑ **Parent:** [Number theory](number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fermat_number)

A Fermat number is $F_n=2^{2^n}+1$ for $n\geq0$. Distinct [Fermat numbers](fermat-number.md) are [coprime integers](coprime-integers.md). Their prime divisors are constrained by the [multiplicative order](multiplicative-order.md) of $2$ modulo that prime; this remains useful whether or not the Fermat number itself is prime. The initial value $F_0=3$ must be distinguished when a statement restricts to positive indices.
