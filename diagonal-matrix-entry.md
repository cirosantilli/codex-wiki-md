# Diagonal matrix entry

↑ **Parent:** [Matrix entry](matrix-entry.md)

A [diagonal matrix entry](diagonal-matrix-entry.md) uses the same row and column index. The diagonal entries of a [lower triangular matrix](lower-triangular-matrix.md) determine its [determinant](determinant.md) by their product.
