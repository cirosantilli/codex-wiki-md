# Pseudolikelihood

↑ **Parent:** [Statistical inference](statistical-inference-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pseudolikelihood)

A [pseudolikelihood](pseudolikelihood.md) multiplies conditional probabilities rather than the full joint [likelihood function](likelihood-function.md). It can be useful for fitting a [Markov random field](markov-random-field.md), but using the product itself as a probability density defines a different model unless an additional equivalence is established.
