# Hilbert-Schmidt factorization of a trace-class operator

↑ **Parent:** [Trace-class operator](trace-class-operator.md)

An operator is trace class exactly when it factors as $T=AB$ with $A$ and $B$ Hilbert--Schmidt. The factors can be chosen so that $\|T\|_1=\|A\|_{\mathrm{HS}}\|B\|_{\mathrm{HS}}$ by using the [polar decomposition of a bounded operator](polar-decomposition-of-a-bounded-operator.md).
