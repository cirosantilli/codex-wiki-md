<h1 id="b/4/c/solution">Solution</h1>

↑ **Parent:** [C](../c.md)

**The axiom of infinity fails.** First prove $L_n=V_n$ for every [finite ordinal](../../../../../finite-ordinal.md) $n$. The base stage is empty in both hierarchies. If $L_n=V_n$, that stage is a finite set. Every one of its subsets is definable over it with finitely many parameters, by a disjunction of equalities to the selected elements; the empty subset is defined by a false formula. Hence

$$
\operatorname{Def}(L_n)=\mathcal P(V_n)=V_{n+1}.
$$

Induction and the limit-stage definitions give

$$
\boxed{L_\omega=V_\omega,}
$$

the set of all [hereditarily finite sets](../../../../../hereditarily-finite-set.md). Every member of this set is finite externally.

If this transitive structure satisfied the [axiom of infinity](../../../../../axiom-of-infinity.md), it would contain an inductive set $I$: zero belongs to $I$, and whenever $x\in I$, its successor $x\cup\{x\}$ belongs to $I$. These operations are the actual [empty set](../../../../../empty-set.md) and actual set successor, since they are absolute for this transitive structure and all relevant finite-rank sets lie in it. External induction would then place every [finite ordinal](../../../../../finite-ordinal.md) in $I$, contradicting the finiteness of $I$.

Every individual [finite ordinal](../../../../../finite-ordinal.md) does belong to $L_\omega$, but the set $\omega$ of all finite [ordinals](../../../../../ordinal-split.md) does not. The distinction between containing each [finite ordinal](../../../../../finite-ordinal.md) and containing one inductive set is precisely the issue.
