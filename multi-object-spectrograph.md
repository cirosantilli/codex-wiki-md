# Multi-object spectrograph

↑ **Parent:** [Spectrograph](spectrograph.md)

A multi-object spectrograph records [optical spectra](optical-spectrum.md) of many selected objects simultaneously. The main designs are [multi-slit spectrographs](multi-slit-spectrograph.md) and [fiber-fed spectrographs](fiber-fed-spectrograph.md). The [ESO instrumentation overview](https://www.eso.org/sci/facilities/paranal/instruments/multiobject.html) describes both arrangements.
