# Section obstruction for a clutched vector bundle

↑ **Parent:** [Clutching function](clutching-function.md)

For an oriented rank-$k$ bundle over $S^n$, with $k\ge2$, normalize its [clutching function](clutching-function.md) to be based at the identity. A [nowhere-zero section](nowhere-zero-section.md) exists precisely when the displayed [homotopy class](homotopy-class.md) vanishes. If it vanishes, extend $\gamma e_k$ across one hemisphere and use the constant section $e_k$ on the other. Conversely normalize any [nowhere-zero section](nowhere-zero-section.md) using the [fiber metric](fiber-metric.md). Its two hemisphere maps satisfy $\sigma_-=\gamma\sigma_+$ on the boundary. The first hemisphere makes $\sigma_+$ homotopic to a constant; the second makes $\gamma\sigma_+$ null-homotopic. Thus $\gamma e_k$ is [null-homotopic](null-homotopic-map.md). If $k>n$, the lower [homotopy group](homotopy-group.md) of the [sphere](sphere.md) vanishes and a section always exists. Rank one is already trivial because $SO(1)$ is trivial.
