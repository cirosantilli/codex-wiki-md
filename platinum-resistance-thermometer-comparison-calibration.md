# Platinum resistance thermometer comparison calibration

↑ **Parent:** [Platinum resistance thermometer](platinum-resistance-thermometer.md)

A 1998 NIST account describes stirred comparison baths, a reference [SPRT](standard-platinum-resistance-thermometer.md) with a 30 Hz [resistance bridge](resistance-bridge.md), and a temperature-controlled $100\,\Omega$ reference [resistor](resistor.md). The test [IPRTs](industrial-platinum-resistance-thermometer.md) used a $1\,\mathrm{mA}$ [current source](current-source.md), a scanner, and an 8½-digit [voltmeter](voltmeter.md). Separate current and voltage leads made each test probe a four-terminal device; readings in both current directions supplied voltage ratios to the reference [resistor](resistor.md).[A New NIST Automated Calibration System for Industrial-Grade Platinum Resistance Thermometers, §§3.1, 3.3 and 4.2, printed pp. 2–6: baths, readout, four-terminal devices and reversed current](a-new-nist-automated-calibration-system-for-industrial-grade-platinum-resistance-thermometers-by-gregory-f-strouse-and-others.md)

Its program bracketed test readings with reference [SPRT](standard-platinum-resistance-thermometer.md) readings and repeated a block if bath drift was excessive. A check [SPRT](standard-platinum-resistance-thermometer.md) monitored the system; reference water-[triple point](triple-point.md) measurements checked stability. Sensor depths were matched, and unfamiliar probes underwent immersion tests. Ice and water-[triple point](triple-point.md) readings before and after calibration checked changes. Additional points could test the fitted curve. Reported calibration uncertainties excluded transport, subsequent drift, [hysteresis](hysteresis.md), and the user's measurement system. These are controls and limits of that documented apparatus, not an accuracy promise for all [platinum resistance thermometers](platinum-resistance-thermometer.md).[§1, printed p. 2; §4.2, printed pp. 5–6; §5.4, printed p. 9: excluded effects, drift rejection, check thermometer, immersion and extra fit checks](a-new-nist-automated-calibration-system-for-industrial-grade-platinum-resistance-thermometers-by-gregory-f-strouse-and-others.md)

The inference is a pair: reference [temperature](temperature-split.md) from the [SPRT](standard-platinum-resistance-thermometer.md), test [electrical resistance](electrical-resistance.md) from the electrical readout. Record measuring [electric current](electric-current.md), wiring, immersion, and the stated reference scale with each pair. A bath controller's setpoint is not itself the calibrated reference [temperature](temperature-split.md). Returning to a reference and checking intermediate points distinguishes a fitted relation from a reproducible calibration over the intended interval.
