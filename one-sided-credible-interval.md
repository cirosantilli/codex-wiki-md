# One-sided credible interval

↑ **Parent:** [Credible interval](credible-interval.md)

A [one-sided credible interval](one-sided-credible-interval.md) puts all excluded [posterior probability](posterior-probability.md) in one tail. For a continuous [posterior distribution](bayesian-posterior.md), an upper bound $u=F^{-1}(1-\alpha)$ satisfies $\mathbb P(\Theta\leq u\mid D=d)=1-\alpha$; a lower bound uses $F^{-1}(\alpha)$. Intersecting with the parameter's allowed range removes points of zero [posterior probability](posterior-probability.md). For the [beta distribution](beta-distribution.md) $\operatorname{Beta}(10,4)$, the upper 95% bound is $u\approx0.887334219$, so $[0,u]$ is the alternative [credible interval](credible-interval.md) shown above.
