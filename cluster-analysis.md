# Cluster analysis

↑ **Parent:** [Statistical learning](statistical-learning-split.md)

Cluster analysis groups observations using similarities or dissimilarities without supplied class labels. A distance choice specifies which features and scales matter. [Agglomerative hierarchical clustering](agglomerative-hierarchical-clustering.md) merges groups recursively, producing partitions at different resolutions rather than one intrinsically determined number of groups.
