# Hadronic matrix element

↑ **Parent:** [Matrix element](matrix-element.md)

A [matrix element](matrix-element.md) of an interaction operator between [hadron](hadron.md) states. It contains [strong interaction](strong-interaction.md) dynamics beyond the explicit [CKM matrix](cabibbo-kobayashi-maskawa-matrix.md) factors of a [weak interaction](weak-interaction.md) decay; its magnitude and [strong phase](strong-phase.md) need not be identical for two different channels.
