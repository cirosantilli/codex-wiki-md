# Positive-measure almost periodic indicator in a compact extension

↑ **Parent:** [Compact extension of a measure-preserving system](compact-extension-of-a-measure-preserving-system.md)

Approximate $\mathbf1_A$ by relative almost periodic functions with summable squared global errors. [Tonelli theorem](tonelli-theorem.md) makes their conditional errors tend to zero almost everywhere. Choose a positive base set on which the conditional mass of $A$ is bounded below, then use the [Egorov theorem](egorov-s-theorem.md) to make those errors uniform on a smaller positive set $C$. [Localization of relative almost periodicity to base sets](localization-of-relative-almost-periodicity-to-base-sets.md) and conditional-norm closure prove $\mathbf1_B$ is relatively almost periodic and $\mu(B)>0$.
