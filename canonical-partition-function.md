# Canonical partition function

↑ **Parent:** [Canonical ensemble](canonical-ensemble.md)

The canonical partition function

$$
Z(\beta)=\sum_s e^{-\beta E_s}
$$

normalizes Boltzmann probabilities and generates equilibrium thermodynamic quantities.
