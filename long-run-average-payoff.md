# Long-run average payoff

↑ **Parent:** [Repeated game](repeated-game.md)

A [repeated game](repeated-game.md) criterion evaluating the average stage [payoff](payoff.md) over increasingly long horizons. State how paths without a limit are treated, for example by using a lower limit. Changing a finite prefix does not change a convergent [long-run average payoff](long-run-average-payoff.md). Thus a one-time gain can be outweighed by permanent future punishment without specifying a discount factor.
