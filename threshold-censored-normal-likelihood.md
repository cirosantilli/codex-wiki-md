# Threshold-censored normal likelihood

↑ **Parent:** [Censoring (statistics)](censoring-statistics.md)

Suppose conditionally independent latent values have [normal distribution](normal-distribution.md) $N(\mu,\sigma^2)$, with $\sigma>0$, but the observation only says which side of a known threshold $c_i$ contains each value. With $s_i=1$ for a value above the threshold and $s_i=-1$ for a value below, the [likelihood](likelihood-function.md) is the displayed product, where $\Phi$ is the [standard normal distribution function](standard-normal-distribution-function.md). Repeated thresholds give corresponding powers. These factors are tail [probabilities](probability.md), not [probability densities](probability-density.md) evaluated at the thresholds. Multiplying normal densities at $c_i$ would describe a different observation process. The thresholds must be treated as fixed or otherwise modelled appropriately; informative selection of thresholds can change the [likelihood](likelihood-function.md).
