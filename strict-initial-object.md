# Strict initial object

↑ **Parent:** [Initial object](initial-object.md)

An [initial object](initial-object.md) $0$ is strict when every [morphism](morphism.md) into $0$ is invertible. Adjoining a new strict initial object to a [category](category-split.md) means adding one map from it to every object and no map to it from any old object. Its only endomorphism is the identity.
