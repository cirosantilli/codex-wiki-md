# Binary simplex code

↑ **Parent:** [Hamming code](hamming-code.md)

The binary simplex code is the dual of the binary Hamming code. For redundancy $r$ it has parameters $[2^r-1,r,2^{r-1}]$.

Its relation to the [Hamming code](hamming-code.md) is duality, not equality of the code families.
