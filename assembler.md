# Assembler

↑ **Parent:** [Assembly language](assembly-language.md)

A program that translates [assembly language](assembly-language.md) into [machine code](machine-code.md). A pseudo-instruction can expand into several instructions, for example to construct a constant that cannot fit one [immediate operand](immediate-operand.md).
