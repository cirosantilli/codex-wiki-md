# Number-based dissociation equilibrium ratio

↑ **Parent:** [Chemical equilibrium](chemical-equilibrium.md)

For ideal-gas single-particle functions $Z_1^{(i)}=C_iVT^{3/2}$ and reaction $A\rightleftharpoons2B$, equilibrium gives $K_N=N_B^2/N_A=(C_B^2/C_A)VT^{3/2}$. This particle-number ratio contains a [volume](volume.md) factor; the concentration ratio $n_B^2/n_A=K_N/V$ does not.
