# Trivial absolute value

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

The trivial [absolute value on a field](absolute-value-algebra.md) is zero at zero and one elsewhere. Its metric [topology](topology-split.md) is discrete. Its [valuation ring](valuation-ring.md) and [residue field](residue-field.md) are both the field itself. This is why rational absolute-value classification and nontrivial discrete-value compactness criteria need a nontriviality hypothesis.
