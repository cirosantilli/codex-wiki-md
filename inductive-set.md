# Inductive set

↑ **Parent:** [Axiom of infinity](axiom-of-infinity.md)

A [set](set-split.md) $I$ is inductive if it contains the [empty set](empty-set.md) and contains $x\cup\{x\}$ whenever it contains $x$. The [axiom of infinity](axiom-of-infinity.md) asserts that an [inductive set](inductive-set.md) exists. The [natural numbers](natural-number.md) form the least [inductive set](inductive-set.md): intersect one [inductive set](inductive-set.md) with the class of objects belonging to every [inductive set](inductive-set.md). This use of [separation](axiom-schema-of-specification.md) gives a [set](set-split.md), and the defining class is closed under successor.
