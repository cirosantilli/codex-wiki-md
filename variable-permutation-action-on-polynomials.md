# Variable-permutation action on polynomials

↑ **Parent:** [Group action](group-action.md)

The [symmetric group](symmetric-group.md) acts on [multivariate polynomials](multivariate-polynomial.md) by replacing each variable $x_i$ by $x_{\sigma(i)}$. With $(\sigma\tau)(i)=\sigma(\tau(i))$, substitution gives $\sigma\cdot(\tau\cdot f)=(\sigma\tau)\cdot f$. Thus it is a left [group action](group-action.md). A polynomial encoding a combinatorial partition has a [group orbit](orbit-of-a-group-action.md) encoding all relabelings and a [stabiliser subgroup](stabilizer-subgroup.md) encoding its label symmetries.
