# Alternative hypothesis

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test-split.md)

The [alternative hypothesis](alternative-hypothesis.md) specifies the parameter values or distributions against which a [null hypothesis](null-hypothesis.md) is tested. If the null is $\theta\in\Theta_0$, the alternative is $\theta\in\Theta_1$ with $\Theta_0\cap\Theta_1=\varnothing$. For example an upper one-sided comparison uses $\theta>\theta_0$, while a two-sided comparison uses $\theta\ne\theta_0$. The alternative determines the relevant rejection tail. A [p-value](p-value.md) is computed under the null; it is not the probability that the alternative is false.
