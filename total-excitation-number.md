# Total excitation number

↑ **Parent:** [Jaynes-Cummings model](jaynes-cummings-model.md)

For the rotating-wave coupling in the [Jaynes-Cummings model](jaynes-cummings-model.md), one atomic excitation is exchanged for one [photon](photon.md), so the displayed operator commutes with the [Hamiltonian](hamiltonian.md). Its [eigenvalue](eigenvalue.md) zero labels $|g,0\rangle$ alone, and each [eigenvalue](eigenvalue.md) $n+1\geq1$ labels the paired sector $|e,n\rangle,|g,n+1\rangle$.
