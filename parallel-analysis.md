# Parallel analysis

↑ **Parent:** [Exploratory factor analysis](exploratory-factor-analysis.md)

An approach to selecting factor or component count by comparing observed [eigenvalues](eigenvalue.md) with reference values obtained from uncorrelated random data of matching dimensions. The reference must match the intended extraction and correlation approach. [John L. Horn](john-l-horn.md) proposed a random-variable procedure to assess sampling contributions to the roots.[1965, abstract](a-rationale-and-test-for-the-number-of-factors-in-factor-analysis-by-john-l-horn.md) Use it with substantive interpretation and model assessment rather than as a universal guarantee of a correct factor count.
