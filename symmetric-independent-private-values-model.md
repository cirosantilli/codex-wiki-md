# Symmetric independent private values model

↑ **Parent:** [Independent private values model](independent-private-values-model.md)

The [independent private values model](independent-private-values-model.md) is symmetric when bidders have identical roles and draw their valuations independently from the same distribution. For [revenue equivalence](revenue-equivalence.md) in the usual single-object setting, bidders additionally have [risk neutrality](risk-neutrality.md) and [quasilinear utility](quasilinear-utility.md). Under a strictly increasing symmetric equilibrium bidding rule, a type $v$ wins with probability $F(v)^{n-1}$.
