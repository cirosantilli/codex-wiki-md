# Arrhenius plot

↑ **Parent:** [Arrhenius equation](arrhenius-equation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Arrhenius_plot)

An [Arrhenius plot](arrhenius-plot.md) places $\ln(k/k_{\mathrm{ref}})$ against $1/T$, using a fixed reference [rate constant](rate-constant.md) with the same units as $k$. Under the constant-parameter [Arrhenius equation](arrhenius-equation.md),

$$
\ln\frac{k(T)}{k_{\mathrm{ref}}}
=\ln\frac{A}{k_{\mathrm{ref}}}-\frac{E_a}{R}\frac1T.
$$

The slope is $-E_a/R$ and the intercept is $\ln(A/k_{\mathrm{ref}})$. Changing the reference units shifts the intercept but leaves the slope unchanged. If the horizontal coordinate is displayed in $10^{-3}\,\mathrm{K^{-1}}$, its numerical slope must be rescaled before multiplying by $-R$. A temperature-dependent [pre-exponential factor](pre-exponential-factor.md) or [activation energy](activation-energy.md) can make the plot curved.
