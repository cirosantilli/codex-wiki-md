# Fault zone

↑ **Parent:** [Geological fault](geological-fault.md)

A finite-width region containing the main slip surface, subsidiary fractures and mechanically or chemically modified [rock](rock-geology.md) associated with a [fault](geological-fault.md). It can include a comminuted core and a surrounding damaged region. [Porous permeability](permeability-of-a-porous-medium.md) can be enhanced along connected fractures while fine [fault gouge](fault-gouge.md) reduces cross-fault flow.
