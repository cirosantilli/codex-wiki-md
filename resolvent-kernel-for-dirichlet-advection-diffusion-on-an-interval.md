# Resolvent kernel for Dirichlet advection-diffusion on an interval

↑ **Parent:** [Dirichlet gauge transform for constant drift](dirichlet-gauge-transform-for-constant-drift.md)

After the [Dirichlet gauge transform for constant drift](dirichlet-gauge-transform-for-constant-drift.md), put $q=\sqrt{p+a^2}$. The [Dirichlet Green function](dirichlet-green-function.md) of $p-\partial_x^2+a^2$ is

$$
R_q(x,y)=\frac{\sinh(q\min(x,y))\sinh(q[L-\max(x,y)])}{q\sinh(qL)}.
$$

The original unweighted resolvent kernel is $e^{-ax}R_q(x,y)e^{ay}$. Its poles are $p=-a^2-(n\pi/L)^2$. The kernel is even in $q$, so the apparent square-root branch point is removable.
