# Inviscid parallel shear flow

↑ **Parent:** [Rayleigh equation for inviscid shear flow](rayleigh-equation-for-inviscid-shear-flow.md)

An inviscid parallel shear flow has base velocity $\mathbf u=U(y)\mathbf e_x$. Two-dimensional normal-mode perturbations satisfy the [Rayleigh equation for inviscid shear flow](rayleigh-equation-for-inviscid-shear-flow.md).
