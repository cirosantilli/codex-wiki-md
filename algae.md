# Algae

↑ **Parent:** [Eukaryote](eukaryote.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algae)

[Algae](algae.md) is a broad name for several photosynthetic [eukaryotic](eukaryote.md) groups, rather than one exclusive [clade](clade.md). The older name blue-green algae for [cyanobacteria](cyanobacteria.md) is misleading in a comparison of cellular organization: [cyanobacteria](cyanobacteria.md) are [bacteria](bacteria.md), with neither [chloroplasts](chloroplast.md) nor a [cell nucleus](cell-nucleus.md).
