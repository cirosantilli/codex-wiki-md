# Lexicographic rank

↑ **Parent:** [Lexicographic order](lexicographic-order.md)

The lexicographic rank of an object is its position among the admissible objects in [lexicographic order](lexicographic-order.md). The rank convention must specify whether the first object has rank zero or one.
