# Partition atom

↑ **Parent:** [Measurable partition](measurable-partition.md)

A partition atom is a member of a [measurable partition](measurable-partition.md). For a finite or countable partition, each cell is an [atom of a sigma-algebra](atom-of-a-sigma-algebra.md) generated by that partition, whose measurable sets are unions of cells. A partition atom need not be an [atom of a measure](atom-measure-theory.md): an interval cell with positive [Lebesgue measure](lebesgue-measure.md) can be split into smaller positive-measure sets that lie outside the generated partition sigma-algebra.
