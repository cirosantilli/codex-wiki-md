# Lithological contact

↑ **Parent:** [Structural geology](structural-geology.md)

A boundary between bodies with different [lithologies](lithology.md). It can be depositional, intrusive or created by [faulting](faulting.md). A remotely observed colour change is evidence for a candidate [lithological contact](lithological-contact.md), but illumination, soil and vegetation changes require independent checks.
