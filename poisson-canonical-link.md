# Poisson canonical link

↑ **Parent:** [Canonical link function](canonical-link-function.md)

For a Poisson mean $\mu$, the natural parameter is $\theta=\log\mu$, so the canonical link is the logarithmic link $g(\mu)=\log\mu$.
