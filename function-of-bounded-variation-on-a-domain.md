# Function of bounded variation on a domain

↑ **Parent:** [Total variation seminorm on a domain](total-variation-seminorm-on-a-domain.md)

A function $u\in L^1(\Omega)$ has bounded variation when $\operatorname{TV}(u)<\infty$. The space $BV(\Omega)$ is a [Banach space](banach-space-split.md) with norm $\|u\|_{L^1}+\operatorname{TV}(u)$.
