# Mean of an additive arithmetic function

↑ **Parent:** [Additive function (number theory)](additive-function-number-theory.md)

For an [additive arithmetic function](additive-function-number-theory.md), the model mean is $A_f(x)=\sum_{p^k\le x}f(p^k)(1-1/p)/p^k$. The exact uniform [expectation](expected-value.md) differs by $O(x^{-1}\sum_{p^k\le x}|f(p^k)|)$.
