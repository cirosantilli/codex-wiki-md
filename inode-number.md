# Inode number

↑ **Parent:** [Inode](inode.md)

An [inode number](inode-number.md) identifies an allocated [inode](inode.md) within one [file system](file-system-split.md). A [directory entry](directory-entry.md) stores a name and this number; it does not normally store the [file data block](file-data-block.md) addresses. Different volumes can reuse the same number for unrelated [files](computer-file.md), and a reclaimed number can later be reused on the same volume. This is therefore a local, current identity, rather than a permanent identifier.
