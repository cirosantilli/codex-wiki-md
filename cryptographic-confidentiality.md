# Cryptographic confidentiality

↑ **Parent:** [Cryptography](cryptography.md)

[Cryptographic confidentiality](cryptographic-confidentiality.md) protects the content of a message against specified adversaries. The security claim must identify which participants are excluded from learning the protected content and what side information or metadata is outside the claim. A provider that receives plaintext is not excluded merely because its incoming connection uses [encryption](encryption.md).
