# Fermat pseudoprime

↑ **Parent:** [Number theory](number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fermat_pseudoprime)

An odd composite number $N$ is a Fermat pseudoprime to a coprime base $b$ when

$$
b^{N-1}\equiv1\pmod N.
$$
