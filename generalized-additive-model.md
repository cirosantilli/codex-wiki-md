# Generalized additive model

↑ **Parent:** [Generalized linear model](generalized-linear-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generalized_additive_model)

A generalized additive model has [linear predictor](linear-predictor.md) $g(\mu_i)=\alpha+\sum_j s_j(x_{ij})$. Centering the smooth functions identifies the intercept. The response family and [link function](link-function.md) remain part of the model; an unspecified software family must not be inferred from the response name.
