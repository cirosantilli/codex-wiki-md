# Memory protection

↑ **Parent:** [Virtual memory](virtual-memory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Memory_protection)

Rules controlling access to [computer memory](computer-memory.md). In [paging](paging.md), [page table entries](page-table-entry.md) and the [memory management unit](memory-management-unit.md) enforce permissions; [copy-on-write](copy-on-write.md) temporarily denies writes to logically writable private [memory pages](memory-page.md) so a write enters [copy-on-write fault handling](copy-on-write-fault-handling.md).
