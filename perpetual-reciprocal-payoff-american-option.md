# Perpetual reciprocal-payoff American option

↑ **Parent:** [American option](american-option.md)

For payoff $g(s)=(1+s)^{-1}$ and $\alpha=2r/\sigma^2\in(0,1)$, the exercise boundary is $b=\alpha/(1-\alpha)$. The value equals $g$ below $b$ and $(1+b)^{-1}(s/b)^{-\alpha}$ above it. Value matching, [smooth fit](smooth-pasting.md), and the [obstacle problem](obstacle-problem.md) verify the first down-crossing policy.
