# Kinematic wave

↑ **Parent:** [Characteristic speed](characteristic-speed.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kinematic_wave)

A kinematic wave is a disturbance whose propagation speed is determined by the local relation between a conserved density and its flux. In a [scalar conservation law](scalar-conservation-law.md) $u_t+f(u)_x=0$, smooth values travel at speed $f'(u)$.
