# Artinian ring

↑ **Parent:** [Noetherian ring](noetherian-ring.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Artinian_ring)

An Artinian ring satisfies the descending chain condition on ideals. A commutative ring is Artinian exactly when it is Noetherian and has [Krull dimension](krull-dimension.md) zero.
