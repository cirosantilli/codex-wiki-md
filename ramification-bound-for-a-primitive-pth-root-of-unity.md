# Ramification bound for a primitive pth root of unity

↑ **Parent:** [Roots of unity in a p-adic field](roots-of-unity-in-a-p-adic-field.md)

If a finite extension of the [P-adic numbers](p-adic-number.md) contains a primitive $p$th [root of unity](root-of-unity.md) $\zeta$, the identity $p=\prod_{j=1}^{p-1}(1-\zeta^j)$ gives $e=(p-1)v_L(1-\zeta)\geq p-1$. The ratios of these factors reduce to the nonzero integers $j$ in the [residue field](residue-field.md). Thus an extension with $e<p-1$ has only roots of unity of order prime to $p$.
