# Transcription start site

↑ **Parent:** [Gene expression](gene-expression.md)

The [DNA](deoxyribonucleic-acid.md) position corresponding to the first incorporated [ribonucleotide](ribonucleotide.md) in a primary transcript. A processed $5'$ end need not identify a [transcription start site](transcription-start-site.md).
