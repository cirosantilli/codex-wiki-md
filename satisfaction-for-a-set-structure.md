# Satisfaction for a set structure

↑ **Parent:** [First-order structure](first-order-structure.md)

The satisfaction relation says that the finite code $e$ of a [first-order formula](first-order-formula.md) is true in a set-sized [first-order structure](first-order-structure.md) $A$ at assignment $\vec a$. It is defined uniformly in set theory by recursion on the finite syntax tree: evaluate atomic relations, Boolean operations and quantifiers over the given domain. A code includes only finitely many subformulas, and their truth relations are [sets](set-split.md). This does not define a truth predicate for the ambient universe, whose domain is not a [set](set-split.md). [Finite relation closure for set-theoretic coding](finite-relation-closure-for-set-theoretic-coding.md) gives an explicit closure criterion ensuring that these truth relations are computed correctly in a [transitive set](transitive-set.md).
