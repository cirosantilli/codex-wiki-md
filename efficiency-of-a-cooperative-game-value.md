# Efficiency of a cooperative-game value

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

A value assigning a [vector](vector.md) of [payoffs](payoff.md) $\psi(v)$ to a [transferable utility game](transferable-utility-game.md) has [cooperative-game efficiency](efficiency-of-a-cooperative-game-value.md) when it distributes exactly the grand-[coalition](coalition-game-theory.md) value. This is a budget-total condition; it does not assert membership in the [core of a cooperative game](core-game-theory.md).
