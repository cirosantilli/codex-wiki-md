# Callan-Symanzik equation with additive renormalization

↑ **Parent:** [Callan-Symanzik equation](callan-symanzik-equation.md)

An additive subtraction can produce a source in the renormalization-group equation. If $G_R=G_B-a\log(\Lambda_0/\Lambda)$ and the bare correlator is invariant under $\mathcal D=\Lambda\partial_\Lambda+\beta(g)\partial_g$, then $\mathcal D G_R=a$. A vanishing operator [anomalous dimension](anomalous-dimension.md) does not remove this source.
