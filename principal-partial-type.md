# Principal partial type

↑ **Parent:** [Partial type](partial-type.md)

A [partial type](partial-type.md) $p(\mathbf x)$ is principal over $T$ if some formula $\theta(\mathbf x)$ with $T\cup\{\exists\mathbf x\,\theta\}$ consistent implies each formula of $p$ modulo $T$. For complete types this is the usual notion of an [isolated type](isolated-type.md). For an incomplete type, the isolating formula need not belong to the type itself.
