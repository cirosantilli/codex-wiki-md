# Soundness theorem for first-order logic

↑ **Parent:** [First-order logic](first-order-logic.md)

Every sentence derivable from a first-order theory is true in every model of that theory.

This is [soundness](soundness.md) of the first-order deduction system relative to its structure semantics.
