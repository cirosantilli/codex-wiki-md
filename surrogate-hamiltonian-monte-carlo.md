# Surrogate Hamiltonian Monte Carlo

↑ **Parent:** [Hamiltonian Monte Carlo](hamiltonian-monte-carlo.md)

[Surrogate Hamiltonian Monte Carlo](surrogate-hamiltonian-monte-carlo.md) uses an auxiliary smooth [probability density function](probability-density-function.md) $\nu$ to generate trajectories but applies a [Metropolis–Hastings acceptance probability](metropolis-hastings-acceptance-probability.md) using the intended target $\mu$. For Gaussian momenta and an [involutive Metropolis proposal](involutive-metropolis-proposal.md) generated by flipped [leapfrog integration](leapfrog-integration.md), the acceptance probability is $\min(1,\mu(x')e^{-\|p'\|^2/2}/[\mu(x)e^{-\|p\|^2/2}])$. Only the surrogate [gradient](gradient.md) is required during the trajectory; target density evaluations are still required at the endpoints.
