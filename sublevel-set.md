# Sublevel set

↑ **Parent:** [Sequential lower semicontinuity](sequential-lower-semicontinuity.md)

A [sublevel set](sublevel-set.md) consists of points whose objective value is at most a chosen threshold. [Coercivity](coercive-function.md) makes finite [sublevel sets](sublevel-set.md) bounded, while [sequential lower semicontinuity](sequential-lower-semicontinuity.md) makes them [sequentially closed sets](sequentially-closed-set.md) in the selected [topology](topology-split.md).
