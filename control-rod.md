# Control rod

↑ **Parent:** [Nuclear reactor](nuclear-reactor.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Control_rod)

A movable neutron-absorbing component used to change reactor [reactivity](reactivity-nuclear-engineering.md). Insertion can make the fission chain reaction subcritical; residual radioactive-decay heat still requires cooling.
