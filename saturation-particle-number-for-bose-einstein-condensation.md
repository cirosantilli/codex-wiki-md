# Saturation particle number for Bose-Einstein condensation

↑ **Parent:** [Bose-Einstein condensation](bose-einstein-condensation.md)

With the ground-state [energy](energy-split.md) set to zero, the [chemical potential](chemical-potential-split.md) of an ideal [Bose gas](bose-gas.md) cannot exceed zero. The limiting population of excited states as it approaches zero is the saturation [particle number](particle-number.md), provided the integral converges. Additional particles occupy the ground state macroscopically. For a three-dimensional uniform box, $N_c=\zeta(3/2)V/\lambda^3$ with [thermal wavelength](thermal-de-broglie-wavelength.md) $\lambda=h/\sqrt{2\pi mk_BT}$.
