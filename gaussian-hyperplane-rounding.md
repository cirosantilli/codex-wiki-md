# Gaussian hyperplane rounding

↑ **Parent:** [Randomized rounding](randomized-rounding.md)

Given a real unit-vector [Gram matrix](gram-matrix.md) $Y_{ij}=\langle v_i,v_j\rangle$, draw a [standard Gaussian random vector](standard-gaussian-random-vector.md) $Z$ and set $y_i=\operatorname{sign}\langle v_i,Z\rangle$. Each coordinate is [almost surely](almost-sure-convergence.md) a sign; zero projections have [probability](probability.md) zero. The same random separating hyperplane is used for every coordinate, so the signs need not be [independent](independent-random-variables.md). Their pair expectations follow the [Gaussian sign-correlation identity](gaussian-sign-correlation-identity.md).
