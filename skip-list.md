# Skip list

↑ **Parent:** [Data structure](data-structure-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Skip_list)

A [skip list](skip-list.md) stores an ordered [sequence](sequence.md) in a bottom [linked list](linked-list.md), with successively sparser [linked lists](linked-list.md) above it. Searching moves right while the next key is too small, then down a level. Randomly chosen node heights give logarithmic expected search and update [time complexity](time-complexity.md) with a suitable height policy. Repeated keys require distinguishing equal-valued nodes by identity when removing their links.
