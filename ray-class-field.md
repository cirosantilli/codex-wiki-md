# Ray class field

↑ **Parent:** [Existence theorem of global class field theory](existence-theorem-of-global-class-field-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ray_class_field)

The ray class field modulo $\mathfrak m$ is the maximal abelian extension whose Artin map factors through the ray class group; its degree is the ray class number.
