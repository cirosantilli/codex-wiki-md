# Bunch-Davies mode normalization in a finite comoving volume

↑ **Parent:** [Bunch-Davies vacuum](bunch-davies-vacuum.md)

For a [minimally coupled massless scalar field](minimally-coupled-massless-scalar-field.md) in flat [de Sitter spacetime](de-sitter-spacetime.md), $a=-1/(H\tau)$ and the [Canonically rescaled de Sitter scalar mode](canonically-rescaled-de-sitter-scalar-mode.md) is $u_k=af_k$. The equation $u_k''+(k^2-2/\tau^2)u_k=0$ and the positive-frequency condition $u_k\sim e^{-ik\tau}/\sqrt{2k\mathcal V}$ select the displayed mode. Direct differentiation verifies its [Wronskian](wronskian.md) normalization, which ensures the equal-time [canonical commutation relations](canonical-commutation-relation.md) with box-normalized creation and annihilation operators. A conformally coupled massless scalar has a different mode equation.
