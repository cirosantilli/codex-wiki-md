# Polymorphic type

↑ **Parent:** [Parametric polymorphism](parametric-polymorphism.md)

A [type scheme](type-scheme.md) describing a family of instances through [type variables](type-variable.md). In [Hindley-Milner type inference](hindley-milner-type-inference.md), a principal type describes the most general valid instance pattern; concrete types arise by consistently substituting for the quantified variables. Reusing one variable constrains the corresponding positions to the same type, whereas distinct variables can vary independently.
