# CSP event renaming

↑ **Parent:** [CSP process](csp-process.md)

Relabel visible [CSP events](csp-event.md) according to a function or relation, preserving [CSP internal actions](csp-internal-action.md). An [injective](injective-function.md) relabelling preserves event identity; a non-injective one can merge distinct actions. In relational renaming, an original event with no image is disabled. Thus partial relational renaming can also restrict an interface.
