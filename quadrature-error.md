# Quadrature error

↑ **Parent:** [Riemann integration](riemann-integration.md)

The difference between a weighted integral and a discrete approximation is a quadrature error. For a [Hölder continuous function](holder-condition.md) on a [partition of an interval](partition-of-an-interval.md) with mesh $\Delta$, a left endpoint approximation has error of order $\Delta^\alpha$. For a normalized window [indicator function](indicator-function.md), only the two endpoint cells contribute and the error is bounded by a constant times $\Delta/h$.
