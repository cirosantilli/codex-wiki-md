# Random Fourier features

↑ **Parent:** [Random feature map](random-feature-map.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Random_Fourier_features)

Random Fourier features represent a translation-invariant [positive-semidefinite kernel](positive-semidefinite-kernel.md) by sampling frequencies from its spectral distribution and using sine and cosine features. They replace an implicit infinite-dimensional [feature map](feature-map.md) by a finite random approximation.
