# Eigenvalue addition in a common eigenbasis

↑ **Parent:** [Simultaneous diagonalization](simultaneous-diagonalization.md)

If [linear operators](linear-operator.md) $A,B$ have a common [eigenbasis](eigenbasis.md) $(v_i)$, then $A+B$ has the corresponding [eigenvalues](eigenvalue.md) $\alpha_i+\beta_i$, counting [algebraic multiplicity](algebraic-multiplicity.md). This follows directly from [linearity](linearity.md) on each [basis vector](basis-vector.md). The pairing is determined by the common [eigenvectors](eigenvector.md); it is not the collection of all pairwise sums of arbitrary [eigenvalues](eigenvalue.md).
