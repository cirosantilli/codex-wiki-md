# Proof of work

↑ **Parent:** [Computer security](computer-security.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Proof_of_work)

A moderately expensive computation whose result can be checked cheaply. Request-specific puzzles can mitigate a computational [denial-of-service attack](denial-of-service-attack.md) if verification precedes expensive service and solved puzzles cannot be reused indefinitely.
