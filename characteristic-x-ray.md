# Characteristic X-ray

↑ **Parent:** [X-ray tube](x-ray-tube.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Characteristic_X-ray)

A [Characteristic X-ray](characteristic-x-ray.md) comes from an [electronic transition](electronic-transition.md) filling an inner [electron shell](electron-shell.md) vacancy. The emitted [photon](photon.md) carries the difference between atomic [energies](energy-split.md). Vacancy creation by direct [electron](electron.md) impact requires [kinetic energy](kinetic-energy.md) above the shell's [binding energy](binding-energy.md), exceeding the line [energy](energy-split.md). Higher tube [voltage](voltage.md) need not move the [spectral line](spectral-line.md).[Diagnostic Radiology Physics: A Handbook for Teachers and Students; IAEA Chapter 5, §§5.2.2–5.2.3: shell vacancy, binding-energy threshold and characteristic radiation](diagnostic-radiology-physics-a-handbook-for-teachers-and-students/chapter-5-x-ray-production-teaching-slides-by-k-p-maher.md)

An original stipulated shell model illustrates the distinction without using measured atomic data. Let positive [binding energies](binding-energy.md) be $B_K=9.0\,\mathrm{keV}$ and $B_L=1.2\,\mathrm{keV}$, ignoring relaxation corrections. Filling a K-shell vacancy from the L shell releases

$$
E_{KL}=B_K-B_L=7.8\,\mathrm{keV},\qquad
\lambda_{KL}=\frac{hc}{E_{KL}}\simeq0.159\,\mathrm{nm}.
$$

An $8.5\,\mathrm{kV}$ tube can energetically emit a $7.8\,\mathrm{keV}$ [bremsstrahlung](bremsstrahlung.md) [photon](photon.md), yet cannot directly remove this K-shell [electron](electron.md). A $12\,\mathrm{kV}$ tube can create that vacancy by [electron](electron.md) impact; if radiative filling occurs, the line is still $7.8\,\mathrm{keV}$, not $12\,\mathrm{keV}$. This argument concerns direct [electron](electron.md) impact and an initially unexcited target; it does not describe every possible excitation route.
