# Planck-constant loop counting with source normalization

↑ **Parent:** [Loop order](loop-order.md)

In a [scalar field path integral](scalar-field-path-integral.md) with weight $\exp[i(S+\int J\phi)/\hbar]$, each internal [propagator](propagator.md) contributes $\hbar$, each interaction vertex contributes $\hbar^{-1}$, and each source insertion contributes $\hbar^{-1}$. A connected graph with $I$ internal lines and $V$ interaction vertices has [loop order](loop-order.md) $L=I-V+1$. Its amputated amplitude, or its coefficient in $\log Z[J]$ with the source insertions included, is proportional to $\hbar^{I-V}=\hbar^{L-1}$. An ordinary unamputated connected $n$-field [correlation function](correlation-function.md) instead has the additional $n$ external propagator factors and scales as $\hbar^{L+n-1}$. Multiplication by $-i\hbar$ to form the [connected generating functional](connected-generating-functional.md) shifts the source-kernel counting to $\hbar^L$. These are compatible normalization conventions.
