# Closed term

↑ **Parent:** [First-order term](first-order-term.md)

A closed term contains no variables, so its value in a [first-order structure](first-order-structure.md) does not depend on an assignment. In a language containing only relations and the constant zero, zero is the only closed term. A [term-generated model](term-generated-model.md) has every element denoted by such a term.
