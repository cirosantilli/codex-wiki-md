# Total-calcium fast fibres

↑ **Parent:** [Two-pool calcium model](two-pool-calcium-model.md)

For $\dot u=\mu-u-\gamma f/\epsilon$ and $\dot v=f/\epsilon$, total scaled [calcium](calcium.md) $w$ changes only on the external-input/extrusion [time](time-in-physics.md) scale. Fast motion therefore follows lines $u+\gamma v=\mathrm{constant}$. The fast normal [eigenvalue](eigenvalue.md) on $f=0$ is $f_v-\gamma f_u$, so $f_v<0$ alone does not establish attraction. If $v=V(u)$, the slow [equation](equation.md) is $\dot u=(\mu-u)/(1+\gamma V'(u))$. Folds of this reduced description satisfy $V'=-1/\gamma$.
