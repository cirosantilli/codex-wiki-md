# Fourier stability of a linear configuration count

↑ **Parent:** [Linear configuration count](linear-configuration-count.md)

Suppose a linear configuration count has a Fourier-integral representation with $k$ factors. If one has a uniform Fourier bound for the difference between two weights and compatible $L^{k-1}$ bounds for each weight, expanding the difference one factor at a time and applying [Hölder's inequality](holder-s-inequality.md) bounds the change in the count.
