# Emotion

↑ **Parent:** [Psychology](psychology-split.md)

A coordinated, context-sensitive pattern involving appraisal, subjective feeling, bodily changes and action tendencies. These components can dissociate; a [facial expression](facial-expression.md) is evidence about [emotion](emotion.md) rather than an infallible definition of it.
