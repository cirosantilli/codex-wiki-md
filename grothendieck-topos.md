# Grothendieck topos

↑ **Parent:** [Elementary topos](elementary-topos.md)

A Grothendieck topos is a category equivalent to the [sheaves on a site](sheaf-on-a-site.md) for a small [Grothendieck topology](grothendieck-topology.md). It is an [elementary topos](elementary-topos.md) with all small colimits and a small generating family. Small disjoint coproducts, effective quotients and the set of subobjects of any fixed object allow many constructions by unions.
