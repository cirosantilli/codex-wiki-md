# Tree with unique limits

↑ **Parent:** [Set-theoretic tree](set-theoretic-tree.md)

At a limit level, two nodes with the same predecessor at every smaller level must be equal. This is a uniqueness condition; it need not provide an upper node for every [cofinal branch](cofinal-branch.md) through the lower levels.
