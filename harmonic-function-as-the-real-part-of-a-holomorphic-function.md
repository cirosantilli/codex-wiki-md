# Harmonic function as the real part of a holomorphic function

↑ **Parent:** [Harmonic function](harmonic-function.md)

A real-valued function $u$ on a [simply connected domain](simply-connected-domain.md) is [harmonic](harmonic-function.md) exactly when

$$
u=\operatorname{Re}f
$$

for some [holomorphic function](holomorphic-function.md) $f$. One construction observes that $u_x-iu_y$ is holomorphic and takes its [holomorphic primitive](primitive-of-a-holomorphic-function-on-a-simply-connected-domain.md).
