# Companion object

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

In [Scala](scala.md), a singleton object associated with a same-named [companion class](companion-class.md) in the required source context. Object members and instance members are distinct: `B.g(x)` invokes a member of object `B`, while `b.g(x)` invokes an instance member through `b`. Both can use [method overloading](method-overloading.md), but the instance's members are not automatically part of the companion's overload set.[Object Definitions](scala-2-11-classes-and-objects-specification.md)
