# Cartan curvature matrix equation

↑ **Parent:** [Curvature form](curvature-form.md)

For a [connection on a vector bundle](connection-vector-bundle.md) written $D=d+A\wedge$ in a local frame, its [curvature form of a connection](curvature-form.md) is represented by $\Theta=dA+A\wedge A$. The products combine matrix multiplication with the [exterior product](exterior-product.md). The formula follows by squaring $D$ and using the graded [Leibniz rule](leibniz-rule.md).
