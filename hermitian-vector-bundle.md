# Hermitian vector bundle

↑ **Parent:** [Vector bundle](vector-bundle.md)

A Hermitian vector bundle is a complex [vector bundle](vector-bundle.md) with a smoothly varying positive definite [Hermitian form](hermitian-form.md) on each fibre. When the bundle is holomorphic, this is a [Hermitian metric on a holomorphic vector bundle](hermitian-metric-on-a-holomorphic-vector-bundle.md). Orthogonal projection to a smooth subbundle produces its induced metric and the [quotient Hermitian metric](quotient-hermitian-metric.md).
