# Field with four elements

↑ **Parent:** [Finite field](finite-field.md)

The [quotient by an irreducible polynomial is a field](quotient-by-an-irreducible-polynomial-is-a-field.md) construction gives $\mathbb F_4=\mathbb F_2[X]/(X^2+X+1)$. The quadratic has no root in $\mathbb F_2$. With $\alpha=[X]$, the four elements are $0,1,\alpha,\alpha+1$, and $\alpha^2=\alpha+1$, $\alpha(\alpha+1)=1$, $(\alpha+1)^2=\alpha$. These relations determine the full multiplication table.
