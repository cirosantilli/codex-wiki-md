# Ionic configuration in a two-site molecule

↑ **Parent:** [Two-site Hubbard dimer](two-site-hubbard-dimer.md)

A configuration with both [electrons](electron.md) on one center, such as $aa$ or $bb$, in a two-center electronic basis. A coherent superposition of such configurations in a neutral molecule represents charge fluctuations; it does not imply a permanent classical ionic charge assignment.
