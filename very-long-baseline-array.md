# Very Long Baseline Array

↑ **Parent:** [Radio interferometry](radio-interferometry.md)

The [Very Long Baseline Array](very-long-baseline-array.md) is a radio-telescope array used for [very-long-baseline interferometry](very-long-baseline-interferometry.md). In a solar-deflection experiment, differential [astrometry](astrometry.md) of nearby compact sources compares their apparent directions as their angular separation from the [Sun](sun.md) changes. Measurements at several frequencies can distinguish dispersive [refraction](refraction.md) in the [solar corona](solar-corona.md) from achromatic gravitational deflection.[2009, §§II–III](progress-in-measurements-of-the-gravitational-bending-of-radio-waves-using-the-vlba-by-edward-fomalont-and-others.md)
