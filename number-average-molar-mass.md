# Number-average molar mass

↑ **Parent:** [Molar mass](molar-mass.md)

The [number-average molar mass](number-average-molar-mass.md) weights each [molecule](molecule-split.md) equally. For counts $n_i$ with [molar masses](molar-mass.md) $M_i$,

$$
M_n=\frac{\sum_i n_iM_i}{\sum_i n_i}.
$$

A mass-proportional [SEC detector response](sec-detector-response.md) requires conversion to counts before determining this average.
