# Rotational isomeric state model

↑ **Parent:** [Polymer physics](polymer-physics.md)

A [polymer](polymer-split.md) conformation model assigning allowed torsional states and statistical weights to successive backbone bonds. Correlations between torsional states can represent local stiffness beyond the fixed-angle, uniformly rotating [freely rotating chain](freely-rotating-chain.md).
