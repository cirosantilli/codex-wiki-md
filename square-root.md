# Square root

↑ **Parent:** [Algebra](algebra-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Square_root)

A square root of an element $x$ is an element $y$ such that $y^2=x$. The notation $\sqrt{x}$ denotes the nonnegative square root when $x$ is a [nonnegative real number](real-number.md).
