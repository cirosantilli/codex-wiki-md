Official historical API documentation for the mutable [stack](stack-data-structure.md): the empty constructor, `push`, `pop` and `nonEmpty` support an explicit [inorder traversal](inorder-traversal.md) stack. The API's deprecation notices concern later collection choices; they do not remove these documented operations from the cited version.
