# Electron biprism

↑ **Parent:** [Electron optics](electron-optics.md)

An [electron biprism](electron-biprism.md) uses the [electric field](electric-field-split.md) around a biased fine wire to overlap coherent [electron](electron.md) waves for [interference](interference-wave-propagation.md). It provides object–reference overlap in [electron holography](electron-holography.md).[Electron biprism: electrode arrangement and wave overlap](electron-biprism-by-jeol-ltd.md)
