# Device independence

↑ **Parent:** [Input-output](input-output.md)

A device-independent interface expresses requests without exposing each peripheral's control registers or protocol to the client. A [device driver](device-driver.md) translates these requests into device-specific operations. This lets an application retain its interface when the supported hardware changes.
