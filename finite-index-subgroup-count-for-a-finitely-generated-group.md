# Finite-index subgroup count for a finitely generated group

↑ **Parent:** [Finitely generated group](finitely-generated-group.md)

If $G$ has $d$ generators, there are at most $(n!)^d$ [group homomorphisms](group-homomorphism.md) $G\to S_n$. Each [subgroup](subgroup.md) of index $n$ is a point stabilizer in a transitive coset [group action](group-action.md), so there are at most $n(n!)^d$ such subgroups. Consequently finitely many subgroups have index at most any fixed bound. Intersecting them gives a finite-index [characteristic subgroup](characteristic-subgroup.md), useful in proving [residual finiteness of semidirect products](residual-finiteness-of-semidirect-products.md).
