# Coherent feed-forward loop

↑ **Parent:** [Feed-forward loop](feed-forward-loop.md)

The direct path and the indirect path of a [coherent feed-forward loop](coherent-feed-forward-loop.md) have matching overall signs. The all-activating case with an AND rule can delay activation while allowing rapid removal of the production signal when the direct input disappears.
