# Factor-level pooling test

↑ **Parent:** [Two-factor normal linear model](two-factor-normal-linear-model.md)

To pool factor levels in a [normal linear model](normal-linear-model.md), impose equality of their fitted means while retaining any needed [interaction terms](interaction-term.md). Compare the resulting nested model with the full model using a [nested-model F-test](nested-model-f-test.md). For two cells each of size $m$, pooling their fitted means adds $(m/2)(\overline Y_1-\overline Y_2)^2$ to the [residual sum of squares](residual-sum-of-squares.md). If pooling two pairs separately within two other-factor levels, there are four restrictions.
