# Operator monotonicity of the square root

↑ **Parent:** [Löwner order](lowner-order.md)

For bounded positive [self-adjoint operators](self-adjoint-operator.md), $0\leq A\leq B$ implies $A^{1/2}\leq B^{1/2}$. Thus the nonnegative square-root function is operator monotone.
