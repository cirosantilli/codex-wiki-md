# Radial null geodesics of the Vaidya metric

↑ **Parent:** [Vaidya metric](vaidya-metric.md)

The two radial [null geodesic](null-geodesic.md) families are $v=\text{constant}$ and $dr/dv=(1-2M(v)/r)/2$. The first has affine radius, while the second has tangent $k=\partial_v+(f/2)\partial_r$ obeying $\nabla_kk=(M/r^2)k$, so advanced time is generally a nonaffine parameter. An [affine parameter](affine-parameter.md) $\lambda$ for the outgoing family satisfies $d\log(dv/d\lambda)/dv=-M/r^2$.
