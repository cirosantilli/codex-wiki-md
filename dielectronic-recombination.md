# Dielectronic recombination

↑ **Parent:** [Ionization](ionization.md)

A free [Electron](electron.md) is resonantly captured while exciting the ionic core, producing a doubly excited state above the parent-ion threshold. Capture becomes permanent recombination only if the state undergoes [radiative stabilization](radiative-stabilization.md) rather than [autoionization](autoionization.md). For resonance $d$, entrance ion $i$, and Maxwellian electrons, $\alpha_d=(g_d/(2g_i))(h^2/(2\pi mkT))^{3/2}e^{-E_d/kT}A^a_{di}A^r_{\rm stab}/(A^a_{\rm tot}+A^r_{\rm tot})$. Detailed balance determines the capture rate; a steady population balance determines the survival factor. The rate coefficient has dimensions volume per time.
