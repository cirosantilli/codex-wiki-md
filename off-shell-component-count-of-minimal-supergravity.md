# Off-shell component count of minimal supergravity

↑ **Parent:** [Minimal four-dimensional supergravity](minimal-four-dimensional-supergravity.md)

A four-dimensional [Majorana spinor](majorana-spinor.md) [gravitino](gravitino.md) has $4\times4=16$ real components, minus four local [supersymmetry](supersymmetry-split.md) gauge functions, leaving twelve before using any [Euler-Lagrange field equation](euler-lagrange-field-equation.md). A [vierbein](orthonormal-coframe-in-spacetime.md) has sixteen real components, minus six local [Lorentz transformation](lorentz-transformation.md) and four [diffeomorphism](diffeomorphism.md) gauge functions, leaving six. Equivalently, a symmetric [metric tensor](metric-tensor.md) has $10-4=6$. The propagating [graviton](graviton.md) and massless [gravitino](gravitino.md) each have two states [on shell](on-shell.md). Six bosonic [auxiliary field](auxiliary-field.md) components complete an off-shell [supergravity multiplet](supergravity-multiplet.md).
