# Subtype polymorphism

↑ **Parent:** [Subtyping](subtyping.md)

Subtype polymorphism lets a value implementing a more specific type be used through a common supertype [object interface](object-interface.md). Calls to overridable [instance methods](object-method.md) can select implementations by [dynamic dispatch](dynamic-dispatch.md). [Behavioral subtyping](behavioral-subtyping.md) additionally requires the concrete implementation to honor the common contract, including [preconditions](precondition.md), [postconditions](postcondition.md) and state invariants; structural access to [object method](object-method.md) names alone does not establish that guarantee.
