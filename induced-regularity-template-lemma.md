# Induced regularity template lemma

↑ **Parent:** [Szemerédi regularity lemma](szemeredi-regularity-lemma.md)

For fixed forbidden induced patterns, a regularity and Ramsey refinement uses internal [clique](clique-graph-theory.md)/independent types and sparse, almost-complete, or intermediate cross pairs. A [clique](clique-graph-theory.md) of intermediate pairs realizes every bounded induced pattern consistent with those internal types, using both [edge](edge-of-a-graph.md) and nonedge regularity. This is the induced embedding consequence used in [hereditary graph enumeration theorem](hereditary-graph-enumeration-theorem.md); the exceptional-pair budget can be arbitrarily small.
