# Memory barrier

↑ **Parent:** [Memory model](memory-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Memory_barrier)

An operation constraining specified memory-access orderings. The strength and scope of a [memory barrier](memory-barrier.md) matter; it does not by itself provide [mutual exclusion](mutual-exclusion.md) or safe [memory reclamation](memory-reclamation.md).
