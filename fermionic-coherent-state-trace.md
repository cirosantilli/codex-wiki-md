# Fermionic coherent-state trace

↑ **Parent:** [Fermionic coherent state](fermionic-coherent-state.md)

The ordinary trace of an even fermionic operator requires $-\psi$ in the bra of its [fermionic coherent state](fermionic-coherent-state.md) kernel. In one mode the diagonal matrix elements give $\langle-\psi|A|\psi\rangle=A_{00}-\bar\psi\psi A_{11}$, whose Gaussian [Berezin integral](berezin-integral.md) is $A_{00}+A_{11}$. An untwisted bra gives $A_{00}-A_{11}$, the [supertrace](supertrace.md). This distinction produces the antiperiodic [coherent-state thermal boundary conditions](coherent-state-thermal-boundary-conditions.md).
