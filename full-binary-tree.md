# Full binary tree

↑ **Parent:** [Binary tree](binary-tree.md)

A full binary tree is a binary tree in which every nonleaf has exactly two children. A binary [Huffman code](huffman-code.md) with at least two positive-probability symbols has a full code tree: a vertex with only one child could be suppressed to shorten all codewords below it.
