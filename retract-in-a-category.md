# Retract in a category

↑ **Parent:** [Split monomorphism](split-monomorphism.md)

An object $A$ is a retract of $B$ when there are morphisms $s:A\to B$ and $r:B\to A$ with $rs=1_A$. The map $s$ is a [split monomorphism](split-monomorphism.md) and $r$ is a [split epimorphism](split-epimorphism.md).
