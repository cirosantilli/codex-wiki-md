# String vertex operator

↑ **Parent:** [Polyakov path integral](polyakov-path-integral.md)

A string vertex operator inserts an asymptotic string state at a point of the worldsheet. Its conformal weights encode the physical-state and mass-shell conditions.

These insertions are described by the state-field correspondence of a [vertex operator algebra](vertex-operator-algebra.md); an individual insertion is not the whole algebra.
