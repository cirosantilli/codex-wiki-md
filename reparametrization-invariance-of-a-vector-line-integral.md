# Reparametrization invariance of a vector line integral

↑ **Parent:** [Line integral](line-integral.md)

If $h:[\alpha,\beta]\to[a,b]$ is an increasing piecewise smooth change of parameter, with endpoints mapped to endpoints, the [chain rule](chain-rule.md) gives $(\gamma\circ h)'=(\gamma'\circ h)h'$. [Change of variables](change-of-variables-formula.md) in the defining [line integral](line-integral.md) proves the displayed identity. A decreasing change of parameter reverses the endpoints and the sign. The result concerns the same traversal with the same multiplicity; retracing a loop additional times changes the integral in general.
