# Plane wave

↑ **Parent:** [Wave function](wave-function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Plane_wave)

A plane wave has constant amplitude and a phase linear in space and time. It is a [momentum eigenstate](momentum-eigenstate.md) and is not spatially normalizable.
