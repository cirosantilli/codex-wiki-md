# Linear probability score

↑ **Parent:** [Scoring rule](scoring-rule.md)

For a binary outcome, rewarding the reported probability of the realized outcome gives expected score $1-q+(2q-1)p$ under genuine probability $q$. The optimal report is an endpoint whenever $q\ne1/2$, so this is not a [proper scoring rule](proper-scoring-rule.md).
