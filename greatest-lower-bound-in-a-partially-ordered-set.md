# Greatest lower bound in a partially ordered set

↑ **Parent:** [Lower bound in a partially ordered set](lower-bound-in-a-partially-ordered-set.md)

A [lower bound in a partially ordered set](lower-bound-in-a-partially-ordered-set.md) which is greater than or equal to every other lower bound. For a pair it is written $a\wedge b$; an empty meet, when it exists, is the greatest element. In a [complete lattice](complete-lattice.md), every subset has a meet. In the [open-set frame](open-set-frame.md), this is the interior of the intersection, with finite meets given by the intersections themselves.
