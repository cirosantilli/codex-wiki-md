# Local-to-global gap in isogeny descent

↑ **Parent:** [Isogeny Selmer group](isogeny-selmer-group.md)

Coverings surviving all [local solubility](local-solubility.md) tests need not have [rational points](rational-point.md). The quotient of an [isogeny Selmer group](isogeny-selmer-group.md) by the rational-point image is a kernel in the [Tate–Shafarevich group](tate-shafarevich-group.md). A nonzero class therefore passes every local test but contributes no rational point to a search. This explains why [two-isogeny descent](two-isogeny-descent.md) can leave a gap between a certified upper bound and found lower bound for the [rank of an elliptic curve](rank-of-an-elliptic-curve.md). Higher descents address finer obstructions; see [Tom Fisher's paper on higher descents with rational two-torsion](https://arxiv.org/abs/1509.03234).
