# Zero-rest-length spring

↑ **Parent:** [Spring](spring.md)

A [zero-rest-length spring](zero-rest-length-spring.md) has quadratic [potential energy](potential-energy.md) in its actual length $s$, with no subtracted natural length. It is a useful idealization, not an ordinary unstretched [spring](spring.md) of arbitrary length. For an end-to-end [spring](spring.md) on a two-link pendulum, changing the natural length changes the quadratic bending stiffness about the straight configuration.
