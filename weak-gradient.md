# Weak gradient

↑ **Parent:** [Weak derivative](weak-derivative.md)

The weak gradient is the [vector](vector.md) of first-order [weak derivatives](weak-derivative.md) of a [function](function-split.md). Its $i$th component is specified by $\int u\partial_i\varphi=-\int(\partial_i u)\varphi$ for compactly supported [test functions](test-function.md). For a differentiable function with appropriate local integrability it agrees with the classical [gradient](gradient.md).
