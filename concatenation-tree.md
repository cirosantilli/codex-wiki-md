# Concatenation tree

↑ **Parent:** [List (abstract data type)](list-abstract-data-type.md)

A [tree](tree-graph-theory-split.md) representation of a [list](list-abstract-data-type.md) with empty nodes, single-element nodes and binary concatenation nodes. Concatenation constructs one node without traversing either operand. The representation need not be unique: adding empty branches changes its size without changing the denoted [list](list-abstract-data-type.md). An accumulator-based traversal gives [linear flattening of a binary tree](linear-flattening-of-a-binary-tree.md) in the representation's size rather than merely the output length.
