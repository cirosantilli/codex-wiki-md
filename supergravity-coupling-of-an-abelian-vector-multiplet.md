# Supergravity coupling of an Abelian vector multiplet

↑ **Parent:** [Minimal four-dimensional supergravity](minimal-four-dimensional-supergravity.md)

An Abelian [vector multiplet](supersymmetric-vector-multiplet.md) contains a [Maxwell field](electromagnetic-field.md) and a Majorana [gaugino](gaugino.md). With the doubled [gravitino](gravitino.md) normalization, add $e[-F^2/4-\bar\lambda\not\nabla\lambda/2-(\kappa/2)\bar\psi_\mu F_{ab}\gamma^{ab}\gamma^\mu\lambda]$. The leading transformations are $\delta A_\mu=\bar\epsilon\gamma_\mu\lambda$ and $\delta\lambda=-F_{ab}\gamma^{ab}\epsilon/2$. Promoting the rigid parameter to a function produces the current $(F_{ab}/2)\gamma^{ab}\gamma^\mu\lambda$ multiplying $\nabla_\mu\bar\epsilon$; the gravitino-current term cancels it. The Clifford identity $(F_{ab}\gamma^{ab})\gamma^\mu(F_{cd}\gamma^{cd})=8T_{\rm EM}^{\mu\nu}\gamma_\nu$ cancels the Maxwell stress variation. Supercovariant field strengths and quartic [fermions](fermion.md) complete the transformations beyond this order.
