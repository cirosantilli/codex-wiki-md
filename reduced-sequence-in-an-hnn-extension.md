# Reduced sequence in an HNN extension

↑ **Parent:** [Normal form theorem for an HNN extension](normal-form-theorem-for-an-hnn-extension.md)

A reduced sequence is a word $g_0t^{\epsilon_1}g_1\cdots t^{\epsilon_k}g_k$ with no [pinch in an HNN extension](pinch-in-an-hnn-extension.md). If $k>0$, [Britton's lemma](britton-s-lemma.md) makes it nontrivial and prevents it from representing a base-group element. Reduced sequences need not be unique; uniqueness requires the fixed coset representatives in the [normal form theorem for an HNN extension](normal-form-theorem-for-an-hnn-extension.md).
