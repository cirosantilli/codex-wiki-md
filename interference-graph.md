# Interference graph

↑ **Parent:** [Random access network](random-access-network.md)

An interference graph has one [graph vertex](vertex-graph-theory.md) for each station and an [edge](edge-of-a-graph.md) for every pair that cannot transmit simultaneously. Feasible activation schedules are the graph's [independent sets](independent-set-graph-theory.md).
