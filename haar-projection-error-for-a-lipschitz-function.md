# Haar projection error for a Lipschitz function

↑ **Parent:** [Haar projection](haar-projection.md)

The [Haar projection](haar-projection.md) replaces a [function](function-split.md) by its mean on each [dyadic interval](dyadic-interval.md) of length $2^{-j}$. For a function satisfying [Lipschitz continuity](lipschitz-continuity.md) with constant $L$, every value in a cell differs from its cell mean by at most $L2^{-j}$. This bound holds for all points with a consistent endpoint convention, and requires no global [L2 norm](l2-norm.md) assumption when the projection is defined by local averages.
