# Ultrafilter limit map for a dense continuous image

↑ **Parent:** [Convergence of a filter](convergence-of-a-filter.md)

A [continuous](continuous-function.md) [dense](dense-set.md) map into a [compact](compact-space.md) [Hausdorff space](hausdorff-space.md) assigns to each [ultrafilter](ultrafilter.md) on its domain the unique limit of its pushforward. This limit map is [surjective](surjective-function.md) by the [ultrafilter](ultrafilter.md) characterization of image [closure](closure-topology.md). It is [injective](injective-function.md) exactly when disjoint domain [subsets](subset.md) have disjoint image [closures](closure-topology.md).
