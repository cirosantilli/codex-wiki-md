# Current element

↑ **Parent:** [Biot-Savart law](biot-savart-law.md)

A [current element](current-element.md) is the oriented infinitesimal wire contribution $I\,d\boldsymbol\ell'$ inside the [Biot-Savart law](biot-savart-law.md). For uniform axial [current density](current-density.md) across [wire cross-sectional area](wire-cross-sectional-area.md) $A$, $I=JA$ and $d^3r'=A\,d\ell'$ imply $\mathbf J\,d^3r'=I\,d\boldsymbol\ell'$. This reduces a [volume integral](volume-integral.md) to a [line integral](line-integral.md) in the thin-wire approximation. It is an integration contribution, not an isolated steady source. [Conventional current](conventional-current.md) runs opposite the drift of negatively charged [electrons](electron.md).
