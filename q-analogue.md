# q-analogue

↑ **Parent:** [Enumerative combinatorics](enumerative-combinatorics.md)

A parameter-dependent generalization which recovers a familiar object at a specified value or [limit](limit-of-a-function.md) of the parameter. In [enumerative combinatorics](enumerative-combinatorics.md), a [generating function](generating-function.md) can refine an ordinary count by retaining a statistic; [Gaussian binomial coefficients](gaussian-binomial-coefficient.md) are one example.
