# Normal surface coordinates

↑ **Parent:** [Normal surface](normal-surface.md)

For $t$ [tetrahedra](tetrahedron.md), count the seven [disk](disk-mathematics.md) types in each [tetrahedron](tetrahedron.md). Across each glued face the counts of each of its three normal arc types must agree. These are homogeneous [linear equations](linear-equation.md) with integer coefficients. An admissible solution also has at most one nonzero quadrilateral type in each [tetrahedron](tetrahedron.md). Matching the arcs in their [boundary](boundary-of-a-set.md) order reconstructs the [normal surface](normal-surface.md) up to an [isotopy](isotopy.md) preserving the [tetrahedra](tetrahedron.md).
