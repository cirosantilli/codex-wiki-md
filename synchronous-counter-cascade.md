# Synchronous counter cascade

↑ **Parent:** [Digital counter](digital-counter.md)

Coupled [digital counters](digital-counter.md) sharing one clock, with a slower stage enabled by a terminal-state decode of a faster stage. Both stages sample the old state at the same [clock edge](clock-edge.md). An enable changes whether a stage advances; it does not create a separate clock from a combinational decode.
