# Automaton transition

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

An [automaton transition](automaton-transition.md) changes an [automaton state](automaton-state.md) on reading a symbol. A [DFA](deterministic-finite-automaton.md) specifies one destination; an [NFA](nondeterministic-finite-automaton.md) may specify several or none.
