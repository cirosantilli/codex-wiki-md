# Volume element

↑ **Parent:** [Multiple integral](multiple-integral.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Volume_element)

Under a smooth locally invertible coordinate map $\Phi$ into Euclidean space, the positive [volume element](volume-element.md) in a [multiple integral](multiple-integral.md) is multiplied by the absolute [Jacobian determinant](jacobian-determinant.md). In three-dimensional [spherical coordinates](spherical-coordinate-system.md), $dV=r^2\sin\theta\,dr\,d\theta\,d\varphi$; in [cylindrical coordinates](cylindrical-coordinate-system.md), $dV=r\,dr\,d\theta\,dz$. The absolute value distinguishes positive integration measure from a signed orientation convention.
