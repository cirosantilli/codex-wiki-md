# Normal-order normalization theorem

↑ **Parent:** [Normal-order beta reduction](normal-order-beta-reduction.md)

If an untyped [lambda term](lambda-term.md) has a [beta-normal form](beta-normal-form.md), leftmost outermost [beta reduction](beta-reduction.md) reaches a normal form. Thus an infinite normal-order computation certifies the absence of a [beta-normal form](beta-normal-form.md). This is the normalization result needed to make a lambda simulation respect undefined outputs.
