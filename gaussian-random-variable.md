# Gaussian random variable

↑ **Parent:** [Normal distribution](normal-distribution.md)

A [Gaussian random variable](gaussian-random-variable.md) is a [random variable](random-variable-split.md) whose [probability distribution](probability-distribution-split.md) is a [normal distribution](normal-distribution.md). For $\sigma>0$, write $X=\mu+\sigma Z$ with a [standard normal random variable](standard-normal-random-variable.md) $Z$; conversely, [standardization of a normal random variable](standardization-of-a-normal-random-variable.md) recovers $Z=(X-\mu)/\sigma$. For example, $X\sim N(100,15^2)$ has [mean](expected-value-split.md) $100$, [standard deviation](standard-deviation.md) $15$, and [variance](variance-split.md) $225$. The outcome $x=115$ corresponds to [standard score](standard-score.md) $z=1$, one [standard deviation](standard-deviation.md) above the [mean](expected-value-split.md).

Some definitions also allow a [Gaussian random variable](gaussian-random-variable.md) with $\sigma=0$. This means $X=\mu$ [almost surely](almost-sure-convergence.md), with [variance](variance-split.md) zero and [probability distribution](probability-distribution-split.md) equal to the [Dirac measure](dirac-measure.md) $\delta_\mu$. It has no [probability density function](probability-density-function.md) with respect to [Lebesgue measure](lebesgue-measure.md): $\mathbb P(X=\mu)=1$. The positive-scale density formula and division by $\sigma$ apply only when $\sigma>0$. MIT's constructive definition explicitly includes the constant case. [MIT 6.436, Lecture 14, §2: degenerate normal distributions](https://ocw.mit.edu/courses/6-436j-fundamentals-of-probability-fall-2018/ceb423b6a703abd60429367b733f45bf_MIT6_436JF18_lec14.pdf).
