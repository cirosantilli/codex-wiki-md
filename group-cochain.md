# Group cochain

↑ **Parent:** [Group cohomology](group-cohomology.md)

An inhomogeneous group $n$-cochain with values in a $G$-module $M$ is a function $G^n\to M$. The standard alternating [group coboundary](group-coboundary.md) turns these groups into the cochain complex whose cohomology is $H^n(G,M)$.
