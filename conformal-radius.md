# Conformal radius

↑ **Parent:** [Conformal map](conformal-map.md)

For a [simply connected domain](simply-connected-domain.md) $D\ne\mathbb C$ and $z\in D$, the conformal radius is $|\phi'(0)|$, where $\phi$ maps the unit disc conformally onto $D$ with $\phi(0)=z$. Disc automorphisms fixing zero are rotations, so the value is independent of the chosen map.
