# Granule cell

↑ **Parent:** [Neuron](neuron-split.md)

A small [neuron](neuron-split.md) found in several brain regions. Cerebellar [granule cells](granule-cell.md) supply [parallel fibers](parallel-fiber.md); dentate [granule cells](granule-cell.md) participate in sparse [hippocampal](hippocampus.md) input coding. These are anatomically distinct populations, so a shared descriptive name does not imply an identical circuit role.
