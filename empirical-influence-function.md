# Empirical influence function

↑ **Parent:** [Influence function](influence-function.md)

This plugs the [empirical distribution](type-information-theory.md) into the population [influence function](influence-function.md). For an [M-estimator](m-estimator.md) it is $-[n^{-1}\sum_i\partial_\theta\psi(y_i,T(F_n))]^{-1}\psi(z,T(F_n))$, when this denominator is well-defined and nonzero. For functionals involving a density at a quantile, an unsmoothed empirical measure may not permit this derivative, so smoothing or an actual [sensitivity curve](sensitivity-curve.md) is required.
