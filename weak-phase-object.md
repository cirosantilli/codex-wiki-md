# Weak phase object

↑ **Parent:** [Phase object](phase-object.md)

A [phase object](phase-object.md) for which the relevant relative [phase](phase-waves.md) variations are much smaller than one radian. The [Taylor expansion](taylor-expansion.md) $e^{i\phi}=1+i\phi+O(\phi^2)$ separates a direct reference term from a small specimen term. A constant overall [phase](phase-waves.md) can be removed before making this approximation: [phase-contrast microscopy](phase-contrast-microscopy.md) measures spatial variations, not an absolute common [phase](phase-waves.md).
