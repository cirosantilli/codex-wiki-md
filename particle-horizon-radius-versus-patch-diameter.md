# Particle-horizon radius versus patch diameter

↑ **Parent:** [Angular particle-horizon size in a power-law universe](angular-particle-horizon-size-in-a-power-law-universe.md)

The proper radial [particle horizon](particle-horizon.md) is the distance travelled by a null [signal](signal.md) since the initial boundary, measured on the current [time](time-in-physics.md) slice. A spherical patch with that radius has twice that physical diameter. Dividing one or the other by an [angular diameter distance](angular-diameter-distance.md) therefore differs by a factor of two. A question using horizon size should state which linear extent is intended.
