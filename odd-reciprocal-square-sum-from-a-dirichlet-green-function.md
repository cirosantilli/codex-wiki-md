# Odd reciprocal-square sum from a Dirichlet Green function

↑ **Parent:** [Spectral Green function of a regular Sturm-Liouville problem](spectral-green-function-of-a-regular-sturm-liouville-problem.md)

For $L=d^2/dx^2$ on $(0,\pi)$ with zero endpoints, the zero-parameter [Green function](green-s-function.md) is $-x_<(\pi-x_>)/\pi$. Its [eigenfunctions](eigenfunction.md) are $\sqrt{2/\pi}\sin(nx)$ with eigenvalues $-n^2$. At $x=\xi=\pi/2$, the kernel is $-\pi/4$ and its expansion contains precisely the odd reciprocal squares, giving the displayed identity.
