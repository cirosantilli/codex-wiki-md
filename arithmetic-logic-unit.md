# Arithmetic logic unit

↑ **Parent:** [Central processing unit](central-processing-unit.md)

An [arithmetic logic unit](arithmetic-logic-unit.md) is a [combinational logic](combinational-logic.md) component that performs selected arithmetic or bitwise operations on its input [machine words](machine-word.md). Its result and status outputs, such as a [carry flag](carry-flag.md), depend on the operation control. A [datapath](datapath.md) may require a pass-through operation as well as addition, particularly when a [barrel shifter](barrel-shifter.md) feeds an operand.
