# Projected electron operator

↑ **Parent:** [t-J model](t-j-model.md)

An [electron](electron.md) annihilation operator restricted to the no-double-occupancy sector of the [t-J model](t-j-model.md). It removes a spin-$\sigma$ [electron](electron.md) only when the opposite-spin site occupation vanishes. The corresponding creation operator cannot create a doubly occupied site. These projected operators do not obey the unrestricted canonical on-site [fermion](fermion.md) algebra on all states.
