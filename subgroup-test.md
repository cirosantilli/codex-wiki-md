# Subgroup test

↑ **Parent:** [Subgroup](subgroup.md)

A nonempty subset $H$ of a [group](group-split.md) $G$ is a [subgroup](subgroup.md) if and only if $gh^{-1}\in H$ for every $g,h\in H$. Necessity follows from [closure](closure-topology.md) and the existence of [inverse elements](inverse-element.md) in a [subgroup](subgroup.md).

Conversely, choose $a\in H$. Setting $g=h=a$ gives the [identity element](identity-element.md) $e=aa^{-1}\in H$. Taking $g=e$ then gives $h^{-1}\in H$ for every $h\in H$. Finally, using $h^{-1}$ as the second element gives $g(h^{-1})^{-1}=gh\in H$, proving [closure](closure-topology.md). The inherited multiplication is [associative](associative-property.md), so these properties establish the [group](group-split.md) axioms on $H$.
