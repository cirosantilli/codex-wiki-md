# Thermodynamic process

↑ **Parent:** [Thermodynamic system](thermodynamic-system.md)

A [thermodynamic process](thermodynamic-process.md) changes a [thermodynamic system](thermodynamic-system.md) between states. A [quasistatic process](quasistatic-process.md) supplies equilibrium intermediate states and therefore a path on equilibrium coordinates. An irreversible [thermodynamic process](thermodynamic-process.md) can have equilibrium endpoints while lacking a uniform intermediate [temperature](temperature-split.md) or [pressure](pressure-split.md). Endpoint values still determine changes in a [state function](state-function.md); computing [heat](heat-split.md) and [work](work.md) requires the actual interaction history.
