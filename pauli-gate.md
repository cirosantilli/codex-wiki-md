# Pauli gate

↑ **Parent:** [Pauli operator](pauli-operator.md)

A Pauli gate applies a [Pauli matrix](pauli-matrices.md) as a [unitary operator](unitary-operator.md) to a [qubit](qubit.md). The [Pauli X gate](pauli-x-gate.md), [Pauli Y gate](pauli-y-gate.md) and [Pauli Z gate](pauli-z-gate.md) are common correction operations in [quantum teleportation](quantum-teleportation.md).
