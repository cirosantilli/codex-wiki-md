# Node of a wavefunction

↑ **Parent:** [Wave function](wave-function-split.md)

A position or set of positions where a [wavefunction](wave-function-split.md) vanishes. Its [Born rule](born-rule.md) position [probability density](probability-density.md) is also zero there. For a one-dimensional bound state, counting interior nodes distinguishes successive [energy eigenfunctions](energy-eigenfunction.md); hard-wall endpoint zeros are usually counted separately.
