# List-based set representation

↑ **Parent:** [Data structure](data-structure-split.md)

Represent a [finite set](finite-set.md) by a [list](list-abstract-data-type.md) of its elements. Allowing repeated elements makes [set union](set-union.md) cheap by [list concatenation](list-concatenation.md); imposing uniqueness requires membership checks. A representation sorted by a [total order](total-order.md) and containing no duplicates permits [set union](set-union.md) and [set intersection](set-intersection.md) by a simultaneous scan in [linear time](linear-time.md). These are different [representation invariants](representation-invariant.md) for the same abstract [set](set-split.md).
