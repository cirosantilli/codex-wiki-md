# Nido cluster

↑ **Parent:** [Polyhedral cluster](polyhedral-cluster.md)

An open cluster framework formally obtained by removing one vertex from a [closo](closo-cluster.md) parent. In the usual electron-counting model, an $n$-vertex [nido](nido-cluster.md) framework has $n+2$ skeletal pairs.
