# Tangent line to a projective plane curve

↑ **Parent:** [Nonsingular point of an algebraic curve](nonsingular-point-of-an-algebraic-curve.md)

For a [projective plane curve](projective-plane-curve.md) $C=V(F)$ and a nonsingular [projective point](projective-point.md) $p$, the tangent is the line $F_x(p)x+F_y(p)y+F_z(p)z=0$. The coefficients are not all zero, and the [Euler theorem for homogeneous functions](euler-theorem-for-homogeneous-functions.md) makes this line pass through $p$. On an affine chart this is precisely the first-order part of a local defining equation, so the definition agrees with the usual [tangent line](tangent-line.md) and is invariant under [projective transformations](projective-linear-transformation.md).
