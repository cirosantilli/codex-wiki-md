# Path-constraint separation by shortest paths

↑ **Parent:** [Separation oracle](separation-oracle.md)

After testing nonnegative edge coordinates and any explicit box or budget inequalities, treat those coordinates as lengths. A shortest path of length below one supplies a violated path inequality; a minimum length at least one certifies all path inequalities. If no source-to-target path exists, all those inequalities are vacuous. Thus a [polynomial time](polynomial-time.md) [shortest path problem](shortest-path-problem.md) calculation separates an exponentially constrained [linear program](linear-programming.md).
