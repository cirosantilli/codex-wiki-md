# Physical-state Virasoro conditions for an open string

↑ **Parent:** [Virasoro constraint](virasoro-constraint.md)

The covariant physical-state conditions impose positive-mode [Virasoro constraints](virasoro-constraint.md) on kets and the adjoint conditions on bras, with intercept $a$ in the zero mode. They are a string version of [Gupta-Bleuler quantization](gupta-bleuler-formalism.md). Imposing every positive and negative matter mode on the same state would conflict with the [Virasoro central extension](virasoro-central-extension.md). In critical [bosonic string theory](bosonic-string-theory.md), $a=1$ and the matter [central charge](central-charge.md) is $26$, canceled by the reparameterization ghosts.
