# Wallspace

↑ **Parent:** [Cubical complex](cubical-complex.md)

A wallspace $(S,\mathcal W)$ is a set $S$ with walls $W=\{W^+,W^-\}$, each a partition into two halfspaces, such that only finitely many walls separate any two points of $S$.

Such wall partitions encode separation data used to construct a dual [cube complex](cubical-complex.md).
