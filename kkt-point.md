# KKT point

↑ **Parent:** [Karush-Kuhn-Tucker conditions](karush-kuhn-tucker-conditions.md)

A [KKT point](kkt-point.md) is a [feasible point](feasible-point.md) admitting [Lagrange multipliers](lagrange-multiplier.md) that satisfy the [Karush-Kuhn-Tucker conditions](karush-kuhn-tucker-conditions.md). Some authors use the name for the full primal and multiplier pair; specify the multipliers when this distinction matters. For a [convex optimization](convex-optimization-split.md) problem with a [differentiable](differentiable-function.md) [convex function](convex-function.md) as its [objective function](objective-function.md), convex inequality functions and affine equality constraints, the [KKT conditions](karush-kuhn-tucker-conditions.md) certify a [global minimizer](global-minimizer.md). Their necessity requires an appropriate [constraint qualification](constraint-qualification.md).
