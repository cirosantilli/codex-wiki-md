# Pseudo-prior augmentation for model comparison

↑ **Parent:** [Pseudo-prior](pseudo-prior.md)

A [pseudo-prior](pseudo-prior.md) can make model parameter vectors have equal dimensions, allowing identity-matched [RJ-MCMC](reversible-jump-markov-chain-monte-carlo.md) moves. If active and inactive coordinates share the same prior density in the two augmented targets, these factors cancel in model-switch ratios. Within-model updates must preserve the augmented target, including the inactive coordinate's pseudo-prior law.
