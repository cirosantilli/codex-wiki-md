# Bufferless queue output

↑ **Parent:** [Bufferless queue](bufferless-queue.md)

The work served in one slot is capped at the [service rate of a queue](service-rate-of-a-queue.md). The remainder is lost, so output is input minus its [positive part](positive-part-of-a-real-valued-function.md) above capacity. Every downstream threshold below the cap has exactly the same overflow event for input and output; thresholds at or above the cap cannot be exceeded by the output.
