# Sum-of-divisors function

↑ **Parent:** [Divisor sum](divisor-sum.md)

The sum-of-divisors function is

$$
\sigma_1(n)=\sum_{d\mid n}d.
$$

It is the [divisor sum](divisor-sum.md) of the identity arithmetic function $n\mapsto n$.
