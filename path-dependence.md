# Path dependence

↑ **Parent:** [Line integral](line-integral.md)

A [line integral](line-integral.md) is path dependent when two admissible paths with the same starting and ending points give different values. This disproves [path independence](path-independence.md) and, for a [vector field](vector-field.md), shows that it is not a [conservative vector field](conservative-vector-field.md) on the relevant domain.
