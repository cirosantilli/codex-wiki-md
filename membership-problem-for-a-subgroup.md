# Membership problem for a subgroup

↑ **Parent:** [Subgroup](subgroup.md)

For a specified subgroup $H\le G$ and a chosen alphabet for $G$, the membership problem asks whether an input word represents an element of $H$. Solubility of the ordinary [word problem for a group](word-problem-for-groups.md) does not imply solubility of this problem, even for finitely generated subgroups: a [Mihailova subgroup](mihailova-subgroup.md) of a product of finite-rank [free groups](free-group.md) can have undecidable membership.
