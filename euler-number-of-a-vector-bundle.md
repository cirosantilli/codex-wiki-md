# Euler number of a vector bundle

↑ **Parent:** [Euler class of a vector bundle](euler-class-of-a-vector-bundle.md)

When an oriented rank-$d$ vector bundle $E$ has a closed oriented $d$-dimensional base $B$, its Euler number is the integer obtained by evaluating the [Euler class of a vector bundle](euler-class-of-a-vector-bundle.md) on the [fundamental class](fundamental-class.md) of $B$. A nonzero Euler number obstructs a nowhere-zero section and therefore obstructs a framing.
