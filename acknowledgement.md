# Acknowledgement

↑ **Parent:** [Transport protocol](transport-protocol.md)

An [acknowledgement](acknowledgement.md) reports receipt according to the [protocol](communication-protocol.md)'s rules. A [TCP](transmission-control-protocol.md) cumulative [acknowledgement](acknowledgement.md) names the next expected [byte](byte.md); it does not establish that the application has durably acted on all preceding data.
