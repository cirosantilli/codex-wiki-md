# Class inheritance

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

Class inheritance defines a [software class](class-programming.md) using another [software class](class-programming.md)'s implementation and may add or override behavior. When it also establishes [subtyping](subtyping.md), the derived [software class](class-programming.md) must satisfy the base [software class](class-programming.md)'s behavioral contract for clients to substitute it safely. Code reuse alone is not sufficient justification for an inheritance relationship. [Object composition](object-composition.md) often better represents a [software object](software-object.md) containing a replaceable component.
