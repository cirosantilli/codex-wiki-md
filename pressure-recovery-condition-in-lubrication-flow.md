# Pressure recovery condition in lubrication flow

↑ **Parent:** [Lubrication theory](lubrication-theory.md)

If pressure approaches the same ambient value at both ends of a lubrication region, then $\int_{-\infty}^{\infty}p_x\,dx=0$, which determines the conserved flux.
