# Conditional class probability

↑ **Parent:** [Classification in statistical learning](classification-in-statistical-learning.md)

The conditional class probability for class $k$ is

$$
p_k(x)=\mathbb P(Y=k\mid X=x).
$$

A [Bayes classifier](bayes-classifier.md) selects a class maximizing this probability.
