# Functional data analysis

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Functional_data_analysis)

Functional data analysis treats each observation as a function or another infinite-dimensional object. Means, [covariance operators](covariance-operator.md), spectral coordinates, and regression operators replace their finite-dimensional vector and matrix counterparts.
