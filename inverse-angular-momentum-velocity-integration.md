# Inverse-angular-momentum velocity integration

↑ **Parent:** [Constant-anisotropy distribution function](constant-anisotropy-distribution-function.md)

In a spherical [galactic distribution function](galactic-distribution-function.md) with $F=L^{-1}f_E(E)$, write $L=rv_T$ and $d^3v=dv_r\,v_Tdv_T\,d\psi$. The velocity Jacobian cancels the apparent singularity at $v_T=0$. Integration of Gaussian energy components then reduces to one full-line and one half-line [Gaussian integral](gaussian-integral.md). The angular average makes each tangential [velocity dispersion](velocity-dispersion.md) half the radial one, so the [velocity-anisotropy parameter](velocity-anisotropy-parameter.md) is $1/2$.
