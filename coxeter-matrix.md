# Coxeter matrix

↑ **Parent:** [Coxeter system](coxeter-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Coxeter_matrix)

The Coxeter matrix of a [Coxeter system](coxeter-system.md) is the symmetric matrix whose entry $m_{ij}$ is the order of $x_ix_j$.
