# Abstract data type

↑ **Parent:** [Encapsulation (computer programming)](encapsulation-computer-programming.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Abstract_data_type)

An [abstract data type](abstract-data-type.md) specifies values and operations independently of their storage. A [FIFO queue](fifo-queue.md) has ordered [sequences](sequence.md) as its abstract values; an [array](array-data-structure.md) and a [linked list](linked-list.md) can represent those same values. A [representation invariant](representation-invariant.md) identifies valid storage states, and an [abstraction function](abstraction-function.md) says what each valid state means.[Reading 13, Rep Invariant and Abstraction Function: representation values, abstract values, AF and RI](6-005-software-construction-spring-2016/reading-13-abstraction-functions-and-rep-invariants.md)
