# Block code for line coding

↑ **Parent:** [Line code](line-code.md)

A [block code for line coding](block-code-for-line-coding.md) maps fixed-size groups of data [bits](bit.md) to fixed-size transmitted [codewords](codeword.md), chosen to meet signal constraints as well as to distinguish inputs. Constraints on long runs must also be checked across word boundaries.
