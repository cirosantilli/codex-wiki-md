↑ **Parent:** [Computer science bibliography](computer-science-bibliography-split.md)

[https://www.scala-lang.org/api/2.12.20/scala/collection/immutable/Stream.html](https://www.scala-lang.org/api/2.12.20/scala/collection/immutable/Stream.html)

The official archived API documents lazy lists, memoization of their evaluated values, and retention of cached tails while earlier cells remain reachable. The companion object supplies `Stream.iterate` for repeated function application. This source documents the Scala 2.12 API family; it does not establish the exact compiler patch release used for a historical examination.
