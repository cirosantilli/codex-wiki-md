# Inside-out patch

↑ **Parent:** [Patch clamp](patch-clamp.md)

An [inside-out patch](inside-out-patch.md) is an excised membrane patch whose [cytosol](cytosol.md) side faces the bath. Bath changes can therefore test effects on the intracellular face of an [ion channel](ion-channel.md), with the extracellular face exposed to pipette solution.
