# Local convex path action

↑ **Parent:** [Rate function](rate-function.md)

A local path action integrates a nonnegative convex cost g of the path's instantaneous input rate, assigning infinity to paths that are not absolutely continuous. When $g(\mu)=0$, the typical-rate path has zero cost. On any interval with prescribed total input, [Jensen inequality](jensen-s-inequality.md) makes a constant derivative minimize its cost. With a [queue workload](workload-of-a-queue.md) constraint this leads to [constant-rate burst paths](constant-rate-burst-path.md) and the [linear workload rate for a local convex action](linear-workload-rate-for-a-local-convex-action.md). Such a formula alone does not establish goodness in an unspecified path topology; goodness must be checked or assumed as part of the input large-deviation principle.
