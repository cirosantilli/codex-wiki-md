# Euclidean body

↑ **Parent:** [Geometric combinatorics](geometric-combinatorics.md)

A Euclidean body is a nonempty bounded [Lebesgue measurable set](lebesgue-measurable-set.md) in $\mathbb R^n$ of positive [Lebesgue measure](lebesgue-measure.md). Projection inequalities require measurable coordinate projections, as for a [compact set](compact-space.md) or a bounded [Borel set](borel-set.md). Modifying a body on a set of volume zero can change its coordinate-projection measures, so the actual projection sets matter. Geometric equality statements commonly impose additional regularity.
