# Dawson function

↑ **Parent:** [Gaussian integral](gaussian-integral.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dawson_function)

The Dawson function obeys $F_D'+2zF_D=1$ by [differentiation](differentiation.md). Its large-real-argument [asymptotic expansion](asymptotic-expansion.md) begins $F_D(z)=1/(2z)+1/(4z^3)+O(z^{-5})$. This inverse-power behavior contrasts with the separate exponentially growing factors in its definition.
