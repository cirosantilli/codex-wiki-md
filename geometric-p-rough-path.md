# Geometric p-rough path

↑ **Parent:** [Rough path](rough-path.md)

A geometric $p$-rough path is a limit, in the [rough path metric](rough-path-metric.md), of [path signatures](signature-of-a-bounded-variation-path.md) of sufficiently regular paths. It is a [weak geometric p-rough path](weak-geometric-p-rough-path.md). At the same exponent these definitions need not coincide; weak geometric paths can be approximated after slightly weakening the variation exponent. The Brownian enhancement is geometric for every $p>2$.
