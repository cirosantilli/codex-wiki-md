# Smooth character

↑ **Parent:** [Smooth representation of a locally profinite group](smooth-representation-of-a-locally-profinite-group.md)

A smooth [linear character](linear-character.md) is a one-dimensional [smooth representation](smooth-representation-of-a-locally-profinite-group.md), equivalently a homomorphism whose kernel is open. On a local multiplicative group, each smooth [linear character](linear-character.md) is trivial on some sufficiently deep principal-unit subgroup. Its inverse has the same kernel.
