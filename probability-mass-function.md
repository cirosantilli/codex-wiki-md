# Probability mass function

↑ **Parent:** [Probability distribution](probability-distribution.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Probability_mass_function)

For a discrete [random variable](random-variable-split.md) $X$, its probability mass function is

$$
p_X(x)=\mathbb P(X=x).
$$

It is nonnegative and sums to one over the possible values of $X$.
