# Rotational angular momentum

↑ **Parent:** [Rotational energy](rotational-energy.md)

The [angular momentum](angular-momentum.md) associated with end-over-end [molecular rotation](molecular-rotation.md). In an open-shell [diatomic molecule](diatomic-molecule.md) it is useful to distinguish $\mathbf N$ from the total $\mathbf J=\mathbf N+\mathbf S$, which also contains the electronic [spin angular momentum](spin.md).
