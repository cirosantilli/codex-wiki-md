# Ehrenfest urn model

↑ **Parent:** [Ehrenfest model](ehrenfest-model.md)

The Ehrenfest urn model moves one uniformly chosen ball between two boxes at each step. For $k\geq1$ balls, the count in one box is a [Markov chain](markov-chain-split.md) on $\{0,\ldots,k\}$. Its [stationary distribution](stationary-distribution.md) is $2^{-k}\binom ki$, and [detailed balance](detailed-balance.md) makes it a [reversible Markov chain](reversible-markov-chain.md). The chain has period two, but its [mean recurrence time](mean-recurrence-time.md) to the all-in-one-box state is still $2^k$.
