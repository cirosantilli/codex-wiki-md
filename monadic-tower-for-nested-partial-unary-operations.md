# Monadic tower for nested partial unary operations

↑ **Parent:** [Monadic length](monadic-length.md)

For the [nested partial unary operation category](nested-partial-unary-operation-category.md) tower, each one-step forgetful [functor](functor.md) is a [monadic adjunction](monadic-adjunction.md) right adjoint: it reflects [isomorphisms](isomorphism.md) and creates its split [coequalizers](coequalizer.md). The [Beck monadicity theorem](beck-s-monadicity-theorem.md) identifies the first [Eilenberg-Moore category](eilenberg-moore-category.md) with the next category in the tower. A long composite has that same first [monad](monad.md) because [free extension of nested partial unary operations](free-extension-of-nested-partial-unary-operations.md) leaves no new top fixed points. Repeating the comparison forgets one fewer operation at each step. The remaining forgetful functor is not full until no operation remains to forget, giving [monadic length](monadic-length.md) $m-n$.
