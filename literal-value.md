# Literal value

↑ **Parent:** [Programming language syntax](programming-language-syntax.md)

A value written directly in program text, such as an [integer](integer-split.md) numeral or a quoted string, rather than obtained through a [program identifier](program-identifier.md). Distinct spellings can denote the same value.
