# Bump function

↑ **Parent:** [Smooth function](smooth-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bump_function)

A bump function is a [smooth function](smooth-function.md) with [compact support](compact-support.md). Rescaled and translated bump functions provide local cutoffs.
