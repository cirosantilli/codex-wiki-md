# Maximum a posteriori estimation

↑ **Parent:** [Bayesian statistics](bayesian-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Maximum_a_posteriori_estimation)

[Maximum a posteriori estimation](maximum-a-posteriori-estimation.md) selects a parameter value maximizing its posterior density relative to a specified reference measure. Its output is a [maximum a posteriori estimate](maximum-a-posteriori-estimate.md). The maximizing value need not be invariant under a nonlinear reparameterization, because a density transforms with a Jacobian.
