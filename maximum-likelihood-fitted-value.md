# Maximum-likelihood fitted value

↑ **Parent:** [Maximum-likelihood estimator](maximum-likelihood-estimator.md)

A maximum-likelihood fitted value is a response mean or probability evaluated at a [maximum-likelihood estimate](maximum-likelihood-estimator.md). In a parametric mean model $\mu_i(\theta)$ it is $\widehat\mu_i=\mu_i(\widehat\theta)$.
