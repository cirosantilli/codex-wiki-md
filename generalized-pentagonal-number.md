# Generalized pentagonal number

↑ **Parent:** [Pentagonal number](pentagonal-number.md)

A value $k(3k-1)/2$ with $k$ any [integer](integer-split.md), including negative values and zero. For $k=\pm1,\pm2,\ldots$, positive values occur as pairs $j(3j-1)/2$ and $j(3j+1)/2$. These are the indices in the [Euler pentagonal identity](euler-pentagonal-identity.md).
