# Half-wave and quarter-wave achromatic circularizer

↑ **Parent:** [Quarter-wave plate](quarter-wave-plate.md)

Take a [half-wave plate](half-wave-plate.md) with fast axis at $15^\circ$ to a linearly polarized input, followed by a [quarter-wave plate](quarter-wave-plate.md) at a further $60^\circ$, so the second axis is at $75^\circ$ to the input. With shared quarter-wave [retardance](retardance.md) error $\epsilon$ and half-wave error $2\epsilon$, use $Q=\operatorname{diag}(1,ie^{i\epsilon})$ and $H=\operatorname{diag}(1,-e^{2i\epsilon})$. Rotating each matrix into the input axes and multiplying gives $\mathbf J(0)=e^{i75^\circ}(1,-i)^{\mathsf T}/\sqrt2$ and the title expansion. Its first-order change is common [phase](phase-waves.md) only, so the output remains circular to first order. This input-specific local compensation does not prove a frequency-independent quarter-wave operator for arbitrary input across a finite spectral band.
