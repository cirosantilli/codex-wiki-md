# Conjugate permutation

↑ **Parent:** [Conjugate group elements](conjugate-group-elements.md)

Two [permutations](permutation.md) in the same [symmetric group](symmetric-group.md) are conjugate if $\tau=\pi\sigma\pi^{-1}$ for some permutation $\pi$. Conjugation relabels every [permutation cycle](permutation-cycle.md), so it preserves [cycle type](cycle-type.md). Conversely, equal cycle types permit a relabelling between corresponding cycles, establishing conjugacy.
