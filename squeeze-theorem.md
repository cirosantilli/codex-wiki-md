# Squeeze theorem

↑ **Parent:** [Limit of a function](limit-of-a-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Squeeze_theorem)

If two functions with the same limit bound a third nearby, the bounded function has that limit too.
