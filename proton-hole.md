# Proton hole

↑ **Parent:** [Nuclear shell model](nuclear-shell-model.md)

A missing [proton](proton.md) relative to a filled [nuclear shell](nuclear-shell.md). In a closed-core approximation a single hole in a $j$ orbital has the same total [angular momentum](angular-momentum.md) $j$ and orbital [parity](parity.md) as the removed particle. For example, removing a $p_{1/2}$ [proton](proton.md) from a spin-zero closed core gives $J^P=1/2^-$.
