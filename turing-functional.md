# Turing functional

↑ **Parent:** [Turing reduction](turing-reduction.md)

A Turing functional is a partial computation performed by an [oracle machine](oracle-machine.md), viewed as a function of both the oracle $B$ and input $x$. Oracle programs admit an effective enumeration. Every convergent computation inspects only a finite part of its oracle, recorded by its [oracle use](oracle-use.md).
