# Phase shifter

↑ **Parent:** [Optical instrument](optical-instrument-split.md)

An optical element that adds a controlled [wave phase](phase-waves.md) to one path. On two path states, an ideal lossless phase shifter has the displayed [unitary matrix](unitary-matrix.md). It changes their relative phase while leaving individual path [probabilities](probability.md) unchanged; subsequent [interference](interference-wave-propagation.md) can turn that phase into an output-intensity change.
