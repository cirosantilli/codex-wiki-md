# Lambda application

↑ **Parent:** [Lambda term](lambda-term.md)

Application $MN$ applies the [lambda term](lambda-term.md) $M$ to the [lambda term](lambda-term.md) $N$. It associates to the left: $MNP=(MN)P$. Together with variables and [lambda abstraction](lambda-abstraction.md), it generates all [lambda terms](lambda-term.md).
