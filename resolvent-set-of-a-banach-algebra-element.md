# Resolvent set of a Banach algebra element

↑ **Parent:** [Spectrum of an element](spectrum-of-an-element.md)

The [algebra resolvent set](resolvent-set-of-a-banach-algebra-element.md) consists of those scalars for which $\lambda1-x$ is invertible in the algebra. It is [open](open-set.md) by the [Neumann series](neumann-series.md), and the inverse-valued map is the [resolvent of an element](resolvent-of-an-element.md). A [closed](closed-set.md) [subalgebra](subalgebra.md) can have a smaller [algebra resolvent set](resolvent-set-of-a-banach-algebra-element.md) because an ambient inverse need not lie in it.
