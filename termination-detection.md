# Termination detection

↑ **Parent:** [Distributed system](distributed-system.md)

A [protocol](communication-protocol.md) for detecting that a distributed computation has completed. Merely observing each participant idle at different instants need not establish a simultaneous idle state; the [protocol](communication-protocol.md) must account for intervening changes and communications.
