# Expected latency

↑ **Parent:** [Latency (engineering)](latency-engineering.md)

The [expected value](expected-value-split.md) of a latency random variable. If a [cache hit](cache-hit.md) takes total time $t_h$, a [cache miss](cache-miss.md) takes total time $t_m$, and the [cache hit rate](cache-hit-rate.md) is $h$, conditioning gives $\mathbb E[T]=ht_h+(1-h)t_m$. An overhead already included in either total should not be charged again.
