# Sigma-0 soundness

↑ **Parent:** [Soundness of an arithmetic theory](soundness-of-an-arithmetic-theory.md)

A [first-order theory](first-order-theory.md) is Sigma-0 [sound](soundness.md) when every [arithmetic](arithmetic-split.md) [bounded arithmetic sentence](bounded-arithmetic-sentence.md) it proves is true in the standard [natural numbers](natural-number.md). For a [first-order theory](first-order-theory.md) proving every true [bounded arithmetic sentence](bounded-arithmetic-sentence.md), this is equivalent to [first-order consistency](first-order-consistency.md): a false bounded theorem would have a provable bounded [negation](negation.md), and an inconsistent [first-order theory](first-order-theory.md) proves the false [bounded arithmetic sentence](bounded-arithmetic-sentence.md) $0=1$.
