# Cyclic Bogolyubov lemma with explicit phase radius

↑ **Parent:** [Bogolyubov lemma](bogolyubov-lemma.md)

For a set of density $\alpha$ in a finite cyclic group, select frequencies whose normalized [Fourier coefficients on a finite abelian group](fourier-coefficient-on-a-finite-abelian-group.md) have magnitude at least $\alpha^{3/2}/2$. [Parseval identity](parseval-identity.md) bounds their number by $4\alpha^{-2}$. [Fourier inversion](fourier-inversion-theorem.md) of the fourfold [convolution](convolution.md) shows it is positive on the [Bohr set in phase-distance convention](bohr-set-in-phase-distance-convention.md) of radius $1/6$. This is an explicit form of the [Bogolyubov lemma](bogolyubov-lemma.md).
