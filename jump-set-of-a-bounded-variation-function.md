# Jump set of a bounded-variation function

↑ **Parent:** [Function of bounded variation on a domain](function-of-bounded-variation-on-a-domain.md)

The jump set consists of points where a [BV space](function-of-bounded-variation-on-a-domain.md) function has distinct one-sided approximate values across an approximate normal. In the plane its [derivative](derivative.md) contribution is $[u]\nu_u\mathcal H^1\!\lfloor J_u$. The [Mumford–Shah functional](mumford-shah-functional.md) penalizes its length rather than the jump amplitude.
