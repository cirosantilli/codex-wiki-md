# Entorhinal cortex

↑ **Parent:** [Cerebral cortex](cerebral-cortex.md)

Cortex linking widespread cortical processing with the [hippocampus](hippocampus.md). Its pathways convey information about events and space; models must state how this information is encoded rather than treating it as an already solved world-coordinate representation.
