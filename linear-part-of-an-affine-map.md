# Linear part of an affine map

↑ **Parent:** [Affine map](affine-map.md)

The map $A$ associated with an [affine map](affine-map.md) $x\mapsto Ax+b$; it is independent of the translation $b$. An affine [Euclidean isometry](euclidean-isometry.md) has an orthogonal linear part, and an [isometry](isometry.md) between [flat tori](flat-torus.md) has a lift whose linear part carries one [Euclidean lattice](euclidean-lattice.md) onto the other.
