# Chow class

↑ **Parent:** [Chow group](chow-group.md)

The equivalence class of an [algebraic cycle](algebraic-cycle.md) modulo [rational equivalence](rational-equivalence.md). The [Chow group](chow-group.md) consists of these classes with addition induced by adding cycles.
