# Exact false discovery rate under independent null p-values

↑ **Parent:** [Benjamini-Hochberg leave-one-out identity](benjamini-hochberg-leave-one-out-identity.md)

For the [Benjamini-Hochberg procedure](benjamini-hochberg-procedure.md), replace a true-null [p-value](p-value.md) $P_i$ by zero and call the new rejection count $R^{(i)}$. The [Benjamini-Hochberg leave-one-out identity](benjamini-hochberg-leave-one-out-identity.md) identifies rejection with $R=r$ with the event $P_i\leq\alpha r/m$ and $R^{(i)}=r$. If $P_i$ is uniform and independent of all the other [p-values](p-value.md), each possible rejection count contributes $\alpha\mathbb P(R^{(i)}=r)/m$ to its expected false-discovery fraction. Summation gives $\alpha/m$ per true null and the displayed exact [false discovery rate](false-discovery-rate.md). Super-uniform independent nulls yield the corresponding upper bound.
