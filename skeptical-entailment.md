# Skeptical entailment

↑ **Parent:** [Stable model semantics](stable-model-semantics.md)

A consequence holds skeptically if it is true in every admitted model, in particular every [stable model](stable-model.md) when using [stable model semantics](stable-model-semantics.md). Exhibiting one supporting [stable model](stable-model.md) establishes only existence of support, not [skeptical entailment](skeptical-entailment.md).
