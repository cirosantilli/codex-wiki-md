# Insertion state

↑ **Parent:** [Hidden Markov model](hidden-markov-model.md)

An [insertion state](insertion-state.md) in a [profile hidden Markov model](profile-hidden-markov-model.md) emits characters between successive [match states](match-state.md). A bypass allows zero inserted characters and a self-transition allows several. Under a fixed loop probability $r<1$, the length of an insertion run conditional on entering has a [geometric distribution](geometric-distribution.md) on positive integers with exit probability $1-r$.
