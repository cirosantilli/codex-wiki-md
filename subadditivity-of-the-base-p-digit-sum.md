# Subadditivity of the base-p digit sum

↑ **Parent:** [Base-p digit sum](base-p-digit-sum.md)

For [nonnegative integers](natural-number.md) $x,y$ and an [integer](integer-split.md) base $p\geq2$,

$$
d_p(x+y)\leq d_p(x)+d_p(y).
$$

In column [addition](addition.md), every [arithmetic carry](carry-arithmetic.md) replaces $p$ units in one [numeral digit](numerical-digit.md) by one unit in the next position and therefore decreases the [base-p digit sum](base-p-digit-sum.md) by $p-1$. Count each outgoing carry separately, including each step of a chain. There is equality precisely when there are no carries. For [prime number](prime-number-split.md) bases, [Kummer's theorem](kummer-s-theorem.md) turns this digit-sum deficit into a [prime exponent](p-adic-valuation.md).
