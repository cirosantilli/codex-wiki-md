# Equivalence partitioning

↑ **Parent:** [Software testing](software-testing.md)

Select tests by dividing an input domain into classes expected to exercise the same relevant behavior, then choosing representatives, including boundaries. [Integer](integer-split.md)-only and point-containing inputs can exercise different paths in a positional-number parser. The classes are part of the test design, not a proof that one representative detects every possible defect in its class. Invalid-format classes need an explicit validation contract before an expected rejection can be asserted.
