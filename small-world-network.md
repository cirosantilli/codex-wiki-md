# Small-world network

↑ **Parent:** [Graph theory](graph-theory-split.md)

A [small-world network](small-world-network.md) combines elevated local [clustering coefficients](clustering-coefficient.md) with mean [graph distance](distance-graph-theory.md) comparable to a chosen reference ensemble of [random graphs](random-graph-split.md). Both the reference ensemble and the clustering convention must be specified. A network can have these properties without having a power-law [degree distribution](degree-distribution.md).
