# Laplace transform of a periodic function

↑ **Parent:** [Laplace transform](laplace-transform.md)

If $g$ has period $T$, then

$$
\mathcal L\{g\}(s)=\frac{\int_0^T e^{-st}g(t)dt}{1-e^{-sT}}.
$$
