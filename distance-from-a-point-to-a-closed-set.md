# Distance from a point to a closed set

↑ **Parent:** [Metric space](metric-space.md)

For a point $x$ and a nonempty [closed set](closed-set.md) $A$ in a [metric space](metric-space.md), the distance

$$
d(x,A)=\inf_{a\in A}d(x,a)
$$

is a continuous function of $x$. It vanishes exactly on $A$.
