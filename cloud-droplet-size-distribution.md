# Cloud-droplet size distribution

↑ **Parent:** [Cloud droplet](cloud-droplet.md)

The number of cloud droplets per volume in each radius interval, often represented by $n(r)dr$. Its width controls differential terminal speeds and collection opportunities; condensational growth with a common $d(r^2)/dt$ narrows relative radius differences.
