# Concurrence

↑ **Parent:** [Entangled state](entangled-state.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Concurrence)

For a normalized pure state of two qubits with coefficient matrix $C$, the concurrence is $2|\det C|$. It ranges from zero for a [product state](product-state.md) to one for a [maximally entangled state](maximally-entangled-state.md).
