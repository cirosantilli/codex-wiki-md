# Angular spectrum

↑ **Parent:** [Wave](wave.md)

The angular spectrum is the transverse [Fourier transform](fourier-transform.md) of a monochromatic field on a reference plane. In a uniform medium, each transverse [wavevector](wavevector.md) component propagates with a longitudinal wavenumber satisfying the [Helmholtz equation](helmholtz-equation.md). Components beyond the propagating wavenumber range are [evanescent waves](evanescent-wave.md). The [outgoing angular spectrum](outgoing-angular-spectrum.md) chooses the longitudinal branch that propagates or decays away from the plane.
