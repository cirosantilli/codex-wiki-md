# Binary expression tree

↑ **Parent:** [Binary tree](binary-tree.md)

A [binary tree](binary-tree.md) representing a [mathematical expression](expression-mathematics.md), with values at its leaves and binary operations at internal nodes. The tree records which pair of intermediate values is combined at each step.
