# Deadlock freedom

↑ **Parent:** [Deadlock](deadlock.md)

Absence of a reachable [deadlock](deadlock.md). In the finite acquisition model under [deadlock](deadlock.md), reaching a nonterminal state with no enabled operation is a finite witness to failure, so this formulation is a [safety property](safety-property.md). Sometimes the phrase is used for eventual acquisition by some requester, a [liveness property](liveness-property.md); the intended requirement must be stated. Neither formulation by itself promises [starvation freedom](starvation-freedom.md) for every requester.
