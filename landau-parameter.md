# Landau parameter

↑ **Parent:** [Landau quasiparticle energy functional](landau-quasiparticle-energy-functional.md)

For a three-dimensional isotropic unpolarized spin-one-half [Fermi liquid](fermi-liquid-split.md), define $f^s=(f_{\uparrow\uparrow}+f_{\uparrow\downarrow})/2$ and $f^a=(f_{\uparrow\uparrow}-f_{\uparrow\downarrow})/2$. Dimensionless [Landau parameters](landau-parameter.md) use the [spin-summed density of states](spin-summed-density-of-states.md) per [volume](volume.md):

$$
N^*(0)=\frac{m^*p_F}{\pi^2\hbar^3},\qquad N^*(0)f^{s,a}(\cos\theta)=\sum_{\ell=0}^{\infty}F_\ell^{s,a}P_\ell(\cos\theta).
$$

$P_\ell$ is a [Legendre polynomial](legendre-polynomial.md); $s,a$ label spin symmetry. No extra $(2\ell+1)$ multiplies this expansion.[Section VIII, angular interaction function; normalization stated explicitly here](renormalization-group-approach-to-interacting-fermions-by-ramamurti-shankar.md) The superscript $s$ on $F_0^s$ is unrelated to the dimensionless wave speed $s$ below.
