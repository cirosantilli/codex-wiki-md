# Vector-boson fusion

↑ **Parent:** [Higgs boson](higgs-boson.md)

Production through exchange of weak [gauge bosons](gauge-boson.md) emitted by incoming fermions. A characteristic [Higgs boson](higgs-boson.md) process at a hadron collider has two outgoing quark jets and tests the Higgs coupling to weak vectors. Predictions for a specified measured final state must include the consistent set of interfering amplitudes rather than treating a diagram label as a separately measurable event.
