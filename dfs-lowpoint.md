# DFS lowpoint

↑ **Parent:** [Cut vertex](cut-vertex.md)

For a finite [simple graph](simple-graph.md) that is an [undirected graph](undirected-graph.md), the [DFS lowpoint](dfs-lowpoint.md) of $v$ is the smallest [DFS discovery time](dfs-discovery-time.md) reachable by following zero or more discovery [edges](edge-of-a-graph.md) down its [rooted tree](rooted-tree.md), then at most one non-discovery [edge](edge-of-a-graph.md) to an ancestor. Staying at $v$ is allowed. Ignore the reverse traversal of the discovery [edge](edge-of-a-graph.md) to the [parent in a rooted tree](parent-in-a-rooted-tree.md): it is the same [edge](edge-of-a-graph.md), not an escape route. Start with $\operatorname{low}(v)=\operatorname{disc}(v)$. On returning from a [child in a rooted tree](child-in-a-rooted-tree.md) $w$, replace $\operatorname{low}(v)$ by $\min\{\operatorname{low}(v),\operatorname{low}(w)\}$. For a non-discovery [edge](edge-of-a-graph.md) from $v$ to an earlier ancestor $a$, replace it by $\min\{\operatorname{low}(v),\operatorname{disc}(a)\}$. This summarizes how far upward the explored branch can reconnect. [Tarjan (1972), §3, LOWPT recurrence, pp. 151–153](https://sites.cs.ucsb.edu/~gilbert/cs240a/notes/TarjanDFS.pdf)

The [cut vertex](cut-vertex.md) criterion has a separate case for each [root of a tree](root-of-a-tree.md) in the discovery [forest](forest.md):
- A nonroot [vertex](vertex-graph-theory.md) $u$ is a [cut vertex](cut-vertex.md) exactly when some [child in a rooted tree](child-in-a-rooted-tree.md) $w$ satisfies $\operatorname{low}(w)\geq\operatorname{disc}(u)$.
- A [root of a tree](root-of-a-tree.md) is a [cut vertex](cut-vertex.md) exactly when it has at least two [children in a rooted tree](child-in-a-rooted-tree.md), counting discovery [edges](edge-of-a-graph.md), rather than all [graph neighbours](neighbour-of-a-vertex.md).
- A discovery [edge](edge-of-a-graph.md) $uw$ is a [bridge in a graph](bridge-graph-theory.md) exactly when $\operatorname{low}(w)>\operatorname{disc}(u)$. A non-discovery [edge](edge-of-a-graph.md) is never a [bridge in a graph](bridge-graph-theory.md).

Why does equality matter? If $\operatorname{low}(w)=\operatorname{disc}(u)$, the branch below $w$ can reconnect to $u$, so the discovery [edge](edge-of-a-graph.md) $uw$ lies on a [graph cycle](cycle-in-a-graph.md) and is not a [bridge in a graph](bridge-graph-theory.md). Deleting the [vertex](vertex-graph-theory.md) $u$ destroys that reconnection too. If $u$ has a [parent in a rooted tree](parent-in-a-rooted-tree.md), the branch is then separated from that [parent in a rooted tree](parent-in-a-rooted-tree.md), explaining the non-strict [cut vertex](cut-vertex.md) test. For a [root of a tree](root-of-a-tree.md), there is no earlier side to separate from; distinct discovery branches cannot have an [edge](edge-of-a-graph.md) between them, since [depth-first search](depth-first-search.md) would have explored them as one branch. This gives the two-[children in a rooted tree](child-in-a-rooted-tree.md) rule. These are proof outlines of the criteria. [Sedgewick and Wayne, Biconnected.java: discovery, lowpoint and root tests](https://algs4.cs.princeton.edu/41graph/Biconnected.java.html)[Sedgewick and Wayne, Algorithms, §4.1: bridge detection](https://algs4.cs.princeton.edu/41graph/)

In the joined-$CD$ example with [DFS discovery times](dfs-discovery-time.md) $1,2,3,4,5,6$, the [DFS lowpoints](dfs-lowpoint.md) in label order are $1,1,1,4,4,4$. For $C$ and its [child in a rooted tree](child-in-a-rooted-tree.md) $D$, $4>3$: $CD$ is a [bridge in a graph](bridge-graph-theory.md), and $C$ is a [cut vertex](cut-vertex.md). For $D$ and its [child in a rooted tree](child-in-a-rooted-tree.md) $E$, $4=4$: $D$ is a [cut vertex](cut-vertex.md), although $DE$ is not a [bridge in a graph](bridge-graph-theory.md). The [root of a tree](root-of-a-tree.md) $A$ has only one [child in a rooted tree](child-in-a-rooted-tree.md), $B$, so it is not a [cut vertex](cut-vertex.md). In the shared-$A$ example, the [root of a tree](root-of-a-tree.md) $A$ has two [children in a rooted tree](child-in-a-rooted-tree.md), $B$ and $D$, and is a [cut vertex](cut-vertex.md), while every [DFS lowpoint](dfs-lowpoint.md) is $1$ and no [edge](edge-of-a-graph.md) passes the strict [bridge in a graph](bridge-graph-theory.md) test.

Restart [depth-first search](depth-first-search.md) at every undiscovered [vertex](vertex-graph-theory.md) to cover a disconnected [graph](graph-split.md), applying the [root of a tree](root-of-a-tree.md) rule separately in each [connected component of a graph](component-graph-theory.md). With [adjacency lists](adjacency-list.md) and constant-cost label operations, computing all [DFS lowpoints](dfs-lowpoint.md), [cut vertices](cut-vertex.md) and [bridges in a graph](bridge-graph-theory.md) has [time complexity](time-complexity.md) $O(|V|+|E|)$ in [Big O notation](big-o-notation.md), because each [vertex](vertex-graph-theory.md) is discovered once and each [edge](edge-of-a-graph.md) is inspected twice. The simple parent-skipping rule assumes a [simple graph](simple-graph.md). In a [multigraph](multigraph.md), skip only the actual parent [edge](edge-of-a-graph.md), identified individually: a parallel [edge](edge-of-a-graph.md) to the same [parent in a rooted tree](parent-in-a-rooted-tree.md) is a valid reconnection and can prevent the first [edge](edge-of-a-graph.md) from being a [bridge in a graph](bridge-graph-theory.md). The criteria here concern [undirected graphs](undirected-graph.md); a [directed graph](directed-graph.md) requires a different connectivity analysis.
