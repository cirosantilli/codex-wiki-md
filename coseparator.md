# Coseparator

↑ **Parent:** [Category](category-split.md)

A coseparator $S$ in a [category](category-split.md) distinguishes parallel arrows by postcomposition: if $u\ne v:X\to B$, some $t:B\to S$ satisfies $tu\ne tv$. Equivalently, the contravariant [functor](functor.md) $\mathcal C(-,S)$ is faithful. In a [complete category](complete-category.md) that is a [locally small category](locally-small-category.md), the evaluation arrow $B\to\prod_{t\in\mathcal C(B,S)}S$ is a [monomorphism](monomorphism.md).
