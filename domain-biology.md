# Domain (biology)

↑ **Parent:** [Taxonomy (biology)](taxonomy-biology.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Domain_(biology))

A biological [domain](domain-biology.md) is a high-level rank used to classify [organisms](organism-split.md) in the [three-domain system](three-domain-system.md). Distinguish a taxonomic rank from a primary branch in an inferred [phylogenetic tree](phylogenetic-tree.md): retaining familiar names does not settle the branching relationships.
