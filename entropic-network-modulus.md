# Entropic network modulus

↑ **Parent:** [Rubber elasticity](rubber-elasticity.md)

A network of flexible thermally fluctuating strands stores an order-$k_BT$ elastic free-energy change per active strand under an order-one deformation. For active-strand [number density](number-density.md) $n$, its [shear modulus](shear-modulus.md) is therefore of order $nk_BT$. If one active element occupies a mesh [volume](volume.md) $m^3$, this becomes $k_BT/m^3$. The numerical coefficient depends on network connectivity, defects and the deformation model. A mesh size alone does not fix the modulus of a general athermal or bending-dominated network; strand stiffness is then additional input.
