# Spike count

↑ **Parent:** [Neural coding](neural-coding.md)

The number of recorded [action potentials](action-potential.md) in a specified interval. A count is a nonnegative integer; a fitted [firing rate](firing-rate.md) or an expected count need not be an integer.
