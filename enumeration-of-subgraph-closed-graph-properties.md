For the upper bound, a regularity reduced [graph](graph-split.md) is clique-free, so its dense pairs have the [Turan theorem](turan-s-theorem.md) [edge](edge-of-a-graph.md) bound; sparse pairs contribute only small binary entropy and the bounded partition description costs only a linear number of bits.
