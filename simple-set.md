# Simple set

↑ **Parent:** [Recursively enumerable set](recursively-enumerable-set.md)

A [computably enumerable set](recursively-enumerable-set.md) is simple when its [complement of a set](complement-of-a-set.md) is an [immune set](immune-set.md): the complement is infinite and contains no infinite [computably enumerable](recursively-enumerable-set.md) subset. Equivalently, it is coinfinite and meets every infinite [computably enumerable set](recursively-enumerable-set.md). A simple set is not decidable.
