# Maximal-primary ideal criterion

↑ **Parent:** [Primary ideal](primary-ideal.md)

In a [Noetherian ring](noetherian-ring.md), an [ideal](ideal.md) $Q$ is $\mathfrak m$-[primary](primary-ideal.md) for a [maximal ideal](maximal-ideal.md) $\mathfrak m$ if and only if $\mathfrak m^n\subseteq Q\subseteq\mathfrak m$ for some $n\geq1$. For necessity, choose generators $x_1,\ldots,x_d$ of $\mathfrak m$ and exponents $e_i\geq1$ with $x_i^{e_i}\in Q$. Every product of $1+\sum_i(e_i-1)$ generators lies in $Q$. If $\mathfrak m=0$, take $n=1$. Conversely the inclusions imply $\sqrt Q=\mathfrak m$, so $R/Q$ is a [local ring](local-ring.md) with [maximal ideal](maximal-ideal.md) $\mathfrak m/Q$. Every element outside this [maximal ideal](maximal-ideal.md) is a [unit](unit-in-a-ring.md), while every element inside is [nilpotent](nilpotent.md). Therefore every [zero divisor](zero-divisor.md) is [nilpotent](nilpotent.md), which is the [primary ideal](primary-ideal.md) condition. The reverse implication works for any [commutative ring](commutative-ring.md).
