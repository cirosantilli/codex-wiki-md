# Path-dependent type

↑ **Parent:** [Type system](type-system.md)

A type selected through a stable object path, allowing an object's nested type to retain its association with that instance. In [Scala](scala.md), `editor.Snapshot` can differ from `otherEditor.Snapshot` even when both objects have the same outer class. This is useful for originator-specific mementos and other values that must not be mixed across owners.[Paths and type selections](scala-2-13-types-specification.md)
