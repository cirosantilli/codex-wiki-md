# Source counts on an FLRW past light cone

↑ **Parent:** [Comoving number density](comoving-number-density.md)

For proper [number density](number-density.md) $n(t)$ in an [FLRW metric](friedmann-lemaitre-robertson-walker-metric.md) $ds^2=dt^2-a^2[dr^2/(1-kr^2)+r^2d\Omega^2]$, a radial shell has proper volume $4\pi a^3r^2|dr|/\sqrt{1-kr^2}$. A radial [null geodesic](null-geodesic.md) obeys $|dr|=\sqrt{1-kr^2}\,dt/a$. Multiplication gives the displayed shell count on a local radial branch of the [past light cone](past-light-cone.md). Spatially uniform [number density](number-density.md) need not be time independent or have conserved [comoving number density](comoving-number-density.md).
