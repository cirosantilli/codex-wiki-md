# Generating set in a category

↑ **Parent:** [Category](category-split.md)

A generating set is a set-indexed family $(P_i)$ such that unequal parallel [morphisms](morphism.md) $f,g:A\to B$ are distinguished by some $h:P_i\to A$, with $fh\ne gh$. It is dual to a [cogenerating set](cogenerating-set.md).
