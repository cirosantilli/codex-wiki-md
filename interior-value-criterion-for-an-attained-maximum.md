# Interior-value criterion for an attained maximum

↑ **Parent:** [Extreme value theorem](extreme-value-theorem.md)

Let $f$ be continuous on $(a,b]$, bounded above, and suppose its [limit superior](limit-superior.md) at $a$ from the right is at most $L$. If some $c\in(a,b]$ has $f(c)>\max\{L,f(a)\}$, then $f$ attains its maximum on $[a,b]$. A sufficiently short initial interval has all values below $f(c)$. On the remaining closed interval, the [extreme value theorem](extreme-value-theorem.md) supplies a maximum, which is consequently global. This can prove attainment despite an oscillatory discontinuity at one endpoint.
