# Absolutely normal number

↑ **Parent:** [Normal number](normal-number.md)

An absolutely normal number is a [normal number](normal-number.md) in every [integer](integer.md) base $K\geq2$. This requires every finite [word](string.md) in every such [positional notation](positional-notation.md) to have its appropriate limiting [digit block frequency](digit-block-frequency.md). Knowing base-ten normality alone does not establish [absolute normality](absolutely-normal-number.md); the base is part of the statement.

Borel's 1909 result says that [absolute normality](absolutely-normal-number.md) holds [almost everywhere](almost-everywhere.md) for [Lebesgue measure](lebesgue-measure.md): within $[0,1)$ the exceptions form a [Lebesgue null set](lebesgue-null-set.md). In particular, the [set](set-split.md) of [absolutely normal numbers](absolutely-normal-number.md) has [Lebesgue measure](lebesgue-measure.md) one there. This is a statement about the size of an exceptional [set](set-split.md), not a test for a specified constant. [Émile Borel, Les probabilités dénombrables et leurs applications arithmétiques, 1909](https://doi.org/10.1007/BF03019651) [Bailey and Borwein, Normal Numbers and Pseudorandom Generators, 2011, introduction: simultaneous normality in all integer bases](https://www.davidhbailey.com/dhbpapers/normal-pseudo.pdf)

A modern route uses the [Birkhoff ergodic theorem](birkhoff-ergodic-theorem.md) and [ergodicity of integer multiplication on the circle](ergodicity-of-integer-multiplication-on-the-circle.md). For each fixed base and digit [interval](interval-mathematics.md), the time proportion equals its [Lebesgue measure](lebesgue-measure.md) [almost everywhere](almost-everywhere.md). The bases and finite [words](string.md) form [countable sets](countable-set.md), so a [countable intersection](countable-intersection.md) of these measure-one [sets](set-split.md) still has [Lebesgue measure](lebesgue-measure.md) one. For an [absolutely normal number](absolutely-normal-number.md), the [word](string.md) $11$ therefore has frequency $1/4$ in base two, $1/9$ in base three, and $1/100$ in base ten. The same symbols represent different [intervals](interval-mathematics.md) in different bases.
