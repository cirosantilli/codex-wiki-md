# MICROSCOPE (satellite)

↑ **Parent:** [Weak equivalence principle](weak-equivalence-principle.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/MICROSCOPE)

A satellite experiment testing the universality of [free fall](free-fall.md). Electrostatic control keeps test masses made from titanium and platinum alloys on matched orbital motion; the required differential [forces](force-split.md) constrain composition dependence. A reference sensor uses masses of the same composition. The experiment tests the [weak equivalence principle](weak-equivalence-principle.md), rather than the full [strong equivalence principle](strong-equivalence-principle.md).[2017 paper: differential electrostatic measurement and reference instrument](the-microscope-mission-first-results-of-a-space-test-of-the-equivalence-principle-by-pierre-touboul-and-others.md)
