# Pullback of a smooth function

↑ **Parent:** [Smooth map between manifolds](smooth-map-between-manifolds.md)

A [pullback of a smooth function](pullback-of-a-smooth-function.md) composes a function on the target with a [smooth map between manifolds](smooth-map-between-manifolds.md), producing a function on the source. It needs no inverse map. Acting on the pulled-back function defines the [differential of a smooth map](differential-of-a-smooth-map.md) intrinsically as a map of derivations.
