# Weak localization

↑ **Parent:** [Anderson localization](anderson-localization.md)

Interference of time-reversed multiple-scattering paths can enhance return probability and reduce conductance in a coherent disordered conductor with the appropriate symmetries. Magnetic fields, spin-orbit coupling and dephasing alter or suppress the correction; some symmetry classes exhibit antilocalization. This small-correction regime must be distinguished from strong [Anderson localization](anderson-localization.md).
