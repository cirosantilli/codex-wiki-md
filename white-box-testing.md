# White-box testing

↑ **Parent:** [Software testing](software-testing.md)

Choose tests using knowledge of internal structure, such as branches, paths or representation cases. Covering all branches is still not generally a proof of correctness for every input. This selection criterion can be combined with specification-based tests within [test-driven development](test-driven-development.md).
