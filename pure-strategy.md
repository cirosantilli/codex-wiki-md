# Pure strategy

↑ **Parent:** [Game theory](game-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pure_strategy)

A [pure strategy](pure-strategy.md) is a definite, complete plan for a player's choices. In a game with one simultaneous choice, it selects one available action with certainty: heads or tails in [matching pennies](matching-pennies.md), for example. In a sequential game it specifies an action at every situation where that player could be called upon to move, including situations never reached when the plan is followed. The plan can use only information available to the player: indistinguishable decision situations must prescribe the same action. An action at one such situation is only part of the plan.

If $S_i$ is player $i$'s [set](set-split.md) of [pure strategies](pure-strategy.md), the [payoff](payoff.md) $u_i(s_i,s_{-i})$ depends on the whole [strategy profile](strategy-profile.md). Thus the same [pure strategy](pure-strategy.md) can be a [best response](best-response.md) against one opposing choice and perform poorly against another. A [dominant strategy](dominant-strategy.md) is the stronger case in which it is a [best response](best-response.md) against every opposing [strategy profile](strategy-profile.md).
