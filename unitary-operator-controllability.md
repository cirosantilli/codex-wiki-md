# Unitary operator controllability

↑ **Parent:** [Quantum controllability](quantum-controllability.md)

A finite-dimensional closed-system control model is unitarily operator controllable when its reachable propagators include every [unitary operator](unitary-operator.md). For the usual real Hamiltonian controls and freely chosen duration, this requires the [Dynamical Lie algebra](dynamical-lie-algebra.md) to be $\mathfrak u(N)$. If global phase is ignored, $\mathfrak{su}(N)$ also suffices; exact access to all of $U(N)$ still requires the central phase direction.
