# Slowly varying function

↑ **Parent:** [Regular variation](regular-variation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Slowly_varying_function)

A [slowly varying function](slowly-varying-function.md) has [regular variation](regular-variation.md) with index zero: $\ell(tu)/\ell(t)\to1$ for every $u>0$. A power of $\log t$ is an example.
