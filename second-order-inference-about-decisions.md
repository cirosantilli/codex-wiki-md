# Second-order inference about decisions

↑ **Parent:** [Subjective confidence](subjective-confidence.md)

A computation that evaluates an action using partially shared evidence about the action-producing system. First-order decisions and confidence need not have identical internal samples; calling the computation second order does not imply conscious verbal reasoning.[2017, model architecture](self-evaluation-of-decision-making-a-general-bayesian-framework-for-metacognitive-computation-by-stephen-m-fleming-and-nathaniel-d-daw.md)
