# Cyclotomic Milnor square

↑ **Parent:** [Milnor square](milnor-square.md)

Evaluation of the cyclic generator at $1$ and at a primitive $p$th root gives the displayed [pullback](pullback-category-theory.md). The maps to the common [field](field.md) reduce integers modulo $p$ and set $\zeta_p=1$. If a representative [polynomial](polynomial-split.md) for the second component has value $c$ at one, adding an integer multiple of $\Phi_p$ adjusts that value by a multiple of $p$ without changing the second component. This proves surjectivity onto compatible pairs.
