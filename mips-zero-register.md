# MIPS zero register

↑ **Parent:** [Register file](register-file.md)

Register zero in the [MIPS architecture](mips-architecture.md) reads as zero and discards writes. An implementation can omit its data storage, hardwire its read output to zero and suppress its write selection. This property permits using zero as a [write-suppression destination](write-suppression-destination.md) without changing the visible register values.
