# Smooth vector

↑ **Parent:** [Smooth representation of a locally profinite group](smooth-representation-of-a-locally-profinite-group.md)

A [smooth vector](smooth-vector.md) in any abstract group representation of a [locally profinite group](locally-profinite-group.md) has an open stabilizer, equivalently is fixed by some [compact-open subgroup](compact-open-subgroup.md). [Smooth vectors](smooth-vector.md) form an invariant linear subspace: use intersections for addition and conjugation for translation. A [smooth representation](smooth-representation-of-a-locally-profinite-group.md) is one in which every vector has this property.
