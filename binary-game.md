# Binary game

↑ **Parent:** [Normal-form game](normal-form-game.md)

A [binary game](binary-game.md) is a finite [normal-form game](normal-form-game.md) in which each player's [payoff](payoff.md) at every pure [strategy profile](strategy-profile.md) is either zero or one. This describes the numerical [payoffs](payoff.md), not the number of players or available actions. A [mixed strategy](mixed-strategy.md) can have an intermediate [expected payoff](expected-payoff.md). If a weighted average of binary [payoffs](payoff.md) is at least one, every positive-weight term must equal one; this observation makes pure-by-mixed domination unusually simple in [binary games](binary-game.md).
