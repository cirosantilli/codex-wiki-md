# Canonical height of an elliptic curve

↑ **Parent:** [Naive height on the projective line](naive-height-on-the-projective-line.md)

This is the elliptic-curve specialization of the [Néron–Tate height](neron-tate-height.md). For an associated logarithmic projective height $h$, one normalization is $\widehat h(P)=\lim_{n	o\infty}4^{-n}h([2^n]P)$.

The canonical height is

$$
\widehat h(P)=\frac12\lim_{r\to\infty}4^{-r}h(x(2^rP)).
$$

It is a quadratic form, vanishes on torsion points, and satisfies $\widehat h(\phi P)=\deg(\phi)\widehat h(P)$ for every isogeny $\phi$.
