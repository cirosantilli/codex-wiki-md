# Naive height contraction in elliptic halving descent

↑ **Parent:** [Height descent lemma](height-descent-lemma.md)

For a fixed rational point $R$ on an [elliptic curve](elliptic-curve.md) over a [number field](number-field.md), the addition formula gives $h_x(P-R)\leq2h_x(P)+O_R(1)$. The duplication map has degree four, so $h_x(2Q)=4h_x(Q)+O(1)$. Combining them gives the displayed contraction. A finite set of representatives modulo twice the point group makes the constants uniform. Points above a fixed height threshold descend by a definite amount; [Northcott theorem](northcott-theorem.md) makes the terminal bounded-height set finite. This converts the [Weak Mordell-Weil theorem](weak-mordell-weil-theorem.md) into the full finite-generation theorem.
