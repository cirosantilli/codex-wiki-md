# Geodesic intersection from reflection symmetry

↑ **Parent:** [Geodesic](geodesic.md)

Suppose reflection in a plane is an [isometry](isometry.md) of a smooth [surface](topological-surface-split.md), and its intersection with the plane is a regular curve. That curve is a [geodesic](geodesic.md) when parametrized by arclength. At any intersection point, reflection fixes both the point and every tangent vector to the intersection. It carries the [geodesic](geodesic.md) with these initial data to one with the same data. Local uniqueness of the [geodesic equations](geodesic-equation.md) forces it to remain in the fixed plane. This is the one-dimensional instance of fixed-point sets of Riemannian isometries being totally [geodesic](geodesic.md).
