# Straight-rod resistance in a linear flow

↑ **Parent:** [Slender-body theory](slender-body-theory.md)

For a straight rod $\mathbf X=s\mathbf p$, $-L<s<L$, leading [slender-body theory](slender-body-theory.md) uses $\mathbf f=C(I-\mathbf p\mathbf p/2)[\Delta\mathbf U+s(\Delta\boldsymbol\Omega\times\mathbf p-E\mathbf p)]$. Integration gives $\mathbf F=2CL(I-\mathbf p\mathbf p/2)\Delta\mathbf U$ and $\mathbf G=(2CL^3/3)[(I-\mathbf p\mathbf p)\Delta\boldsymbol\Omega-\mathbf p\times E\mathbf p]$. Axial spin is outside this centreline approximation.
