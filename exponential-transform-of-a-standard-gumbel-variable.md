# Exponential transform of a standard Gumbel variable

↑ **Parent:** [Gumbel distribution](gumbel-distribution.md)

If $Y$ has [cumulative distribution function](cumulative-distribution-function.md) $F(y)=\exp(-e^{-y})$, put $Z=e^{-Y}$. For $z>0$, the decreasing transformation gives $\mathbb P(Z\le z)=1-F(-\ln z)=1-e^{-z}$, while this [probability](probability.md) is zero for $z\le0$. Hence $Z$ has the rate-one [exponential distribution](exponential-distribution.md). Conversely, if $Z$ has that [exponential distribution](exponential-distribution.md), then $-\ln Z$ has the standard [Gumbel distribution](gumbel-distribution.md).
