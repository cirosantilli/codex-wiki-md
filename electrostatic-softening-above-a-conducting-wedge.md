# Electrostatic softening above a conducting wedge

↑ **Parent:** [Image charges in a right-angle conducting wedge](image-charges-in-a-right-angle-conducting-wedge.md)

For an attractive [force](force-split.md) $-\beta/y^2$ and an otherwise linear vertical [spring](spring.md), differentiation about the charged [equilibrium](equilibrium-point-of-a-dynamical-system.md) $y_e$ reduces the [spring](spring.md) stiffness by $2\beta/y_e^3$. If the uncharged height is $y_0$ and the shift is small, the fractional [frequency](frequency.md) change is $-\beta/(ky_0^3)$. Using only the [force](force-split.md) value, without its [derivative](derivative.md), would miss this [frequency](frequency.md) shift.
