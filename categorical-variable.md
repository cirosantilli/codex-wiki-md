# Categorical variable

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Categorical_variable)

A categorical variable takes values in a finite or countable set of labels. A regression model usually represents an unordered categorical predictor by [indicator variables](indicator-variable.md) relative to a [reference level in a regression factor](reference-level-in-a-regression-factor.md).
