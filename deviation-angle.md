# Deviation angle

↑ **Parent:** [Geometrical optics](geometrical-optics-split.md)

The [angle](angle.md) through which an optical element changes a [light ray](light-ray.md)'s propagation direction, with the chosen branch and convention specified. For the one-internal-reflection branch through a spherical drop, entry [refraction](refraction.md), internal [specular reflection](specular-reflection.md), and exit [refraction](refraction.md) give $\delta=\pi+2\alpha-4\beta$, with $\sin\alpha=n\sin\beta$. The corresponding primary [rainbow](rainbow.md) radius about the antisolar direction is $\pi-\delta$.
