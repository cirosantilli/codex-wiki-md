# Interim individual rationality

↑ **Parent:** [Individual rationality](individual-rationality.md)

Interim individual rationality requires a nonnegative expected participation utility for each private type, averaging over the other types with the player's conditional beliefs. It differs from requiring nonnegative utility at each realized profile, which is [ex post individual rationality](ex-post-individual-rationality.md).
