# Natural parameter space

↑ **Parent:** [Natural parameter of an exponential family](natural-parameter-of-an-exponential-family.md)

The natural parameter space is the set of $\theta$ for which the normalizing integral $\int h(y)e^{\theta^TT(y)}\,dy$ is finite. Interior points permit the usual [exponential-family derivative identities](exponential-family-derivative-identities.md) when differentiation and integration can be interchanged.
