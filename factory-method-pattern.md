# Factory method pattern

↑ **Parent:** [Creational pattern](creational-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Factory_method_pattern)

Declare a creation operation returning an abstract product interface and let concrete creators specialize how products are built. Clients call the creator interface rather than hard-coding construction of each concrete product. For example two regional manufacturers can implement `build(carType): Car` to select a concrete car and apply regional settings; optional wrappers can then be composed independently using the [decorator pattern](decorator-pattern.md).
