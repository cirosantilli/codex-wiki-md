# Autoassociative memory

↑ **Parent:** [Associative memory in neural networks](associative-memory-in-neural-networks.md)

A memory retrieves a stored pattern from a partial or corrupted version of that pattern. A recurrent [Hopfield network](hopfield-network.md) supplies a precise idealization through stored attractors and their [basins of attraction](basin-of-attraction.md). Retrieval can fail through interference, ambiguous cues or spurious stable states.
