# Existence

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)

A solution exists when at least one object satisfies all the stated conditions. In [first-order logic](first-order-logic.md), this is expressed by [existential quantification](existential-quantification.md). [Uniqueness](uniqueness.md) additionally requires that any two solutions are equal.
