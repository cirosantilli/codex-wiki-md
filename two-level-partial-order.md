# Two-level partial order

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

Take disjoint [antichains](antichain.md) $P,C$ and place every element of $P$ below every element of $C$. Together with equality these comparisons define a [partial order](partially-ordered-set.md): a strict step always moves from $P$ to $C$, so there cannot be a strict two-step path or a reverse comparison.

If both levels have at least two elements, a [subset](subset.md) $S$ has an [upper bound](upper-bound-in-a-partially-ordered-set.md) exactly when it contains at most one element of $C$. When it contains one such element $c$, that element is its [maximum](maximum-of-a-subset-of-a-total-order.md) and its only [upper bound](upper-bound-in-a-partially-ordered-set.md). A singleton $\{p\}\subseteq P$ has [maximum](maximum-of-a-subset-of-a-total-order.md) and [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) $p$. A [subset](subset.md) of $P$ with at least two elements has all of $C$ as [upper bounds](upper-bound-in-a-partially-ordered-set.md) and has no [least upper bound](least-upper-bound-in-a-partially-ordered-set.md), because these elements are incomparable. The empty [subset](subset.md) has all of $P\sqcup C$ as [upper bounds](upper-bound-in-a-partially-ordered-set.md) and has no [least upper bound](least-upper-bound-in-a-partially-ordered-set.md). These cases prove the complete classification.
