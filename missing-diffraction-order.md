# Missing diffraction order

↑ **Parent:** [Diffraction order](diffraction-order.md)

A [missing diffraction order](missing-diffraction-order.md) occurs when a principal maximum of an array factor coincides with a zero of the individual aperture's [diffraction](diffraction.md) envelope. For identical slits of width $a$ and centre spacing $D$, order $m$ has $\sin\theta_m=m\lambda/D$. It is missing if $ma/D$ is a nonzero integer. This is cancellation of field contributions, not loss of the incident [wavelength](wavelength.md) or a failure of the [grating equation](grating-equation.md).
