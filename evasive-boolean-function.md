# Evasive Boolean function

↑ **Parent:** [Decision-tree depth](decision-tree-depth.md)

A [Boolean function](boolean-function.md) is evasive when every deterministic [decision tree](decision-tree.md) computing it has a worst-case path that queries all input bits. The [alternating-sum criterion for decision-tree evasiveness](alternating-sum-criterion-for-decision-tree-evasiveness.md) is one sufficient method for proving this lower bound.
