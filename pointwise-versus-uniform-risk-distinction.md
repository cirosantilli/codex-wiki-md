# Pointwise versus uniform risk distinction

↑ **Parent:** [Minimax risk](minimax-risk.md)

A [risk function](risk-function.md) can decay rapidly for each fixed [regression function](regression-function.md) while its [supremum](supremum.md) over a function class decays more slowly or fails to decay. Bounds depending on each function's local [differentiability](differentiability.md) remainder need not be uniform. In [fixed-design nonparametric regression](fixed-design-nonparametric-regression.md), a class with no common smoothness bound permits [smooth bump functions](smooth-bump-function.md) whose supports shrink between design points. Such sequences obstruct uniform estimation without contradicting fixed-function [mean squared error](mean-squared-error.md) bounds.
