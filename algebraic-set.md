# Algebraic set

↑ **Parent:** [Algebraic geometry](algebraic-geometry-split.md)

An algebraic set is a zero locus of polynomial equations, allowing reducible sets. An [affine algebraic set](affine-algebraic-set.md) uses ordinary polynomial equations; a projective algebraic set uses homogeneous equations in projective coordinates. On affine or projective space, closed sets in the [Zariski topology](zariski-topology.md) are algebraic sets, and an irreducible algebraic set is an [algebraic variety](algebraic-variety.md) in the classical convention.
