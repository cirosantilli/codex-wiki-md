# Abstract machine

↑ **Parent:** [Theoretical computer science](theoretical-computer-science-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Abstract_machine)

An [abstract machine](abstract-machine.md) specifies a computational state and rules for advancing that state without requiring one particular physical implementation. A [Turing machine](turing-machine.md) and a [stack machine](stack-machine.md) give different ways to organize the state and its transitions.
