# Speculative execution

↑ **Parent:** [Central processing unit](central-processing-unit.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Speculative_execution)

Executing work before a condition validating it is resolved. Correctness requires suppressing or recovering its architectural effects if the condition fails. A [reorder buffer](reorder-buffer.md) supports controlled [instruction retirement](instruction-retirement.md) of such work.
