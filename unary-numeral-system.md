# Unary numeral system

↑ **Parent:** [Numeral system](numeral-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Unary_numeral_system)

Represent a nonnegative [integer](integer-split.md) $k$ by $1^k$, using delimiters when several quantities are encoded. The length is $k$, rather than the $O(\log(k+1))$ length of a [binary numeral system](binary-numeral-system.md) representation. Despite the parent category for numerical notation, this is not a positional base-one place-value system.
