# Hall condition

↑ **Parent:** [Hall's marriage theorem](hall-s-marriage-theorem.md)

The [Hall condition](hall-condition.md) requires enough distinct [neighbours](neighbour-of-a-vertex.md) for **every** [subset](subset.md) of the specified left [vertex set](vertex-set.md) in a finite [bipartite graph](bipartite-graph-split.md). Checking the whole left [set](set-split.md) establishes only one inequality. Checking singleton [sets](set-split.md) establishes only that each left [vertex](vertex-graph-theory.md) has positive [degree of a vertex](degree-graph-theory.md). Overlapping lists can pass both tests and still fail to admit [matching saturation](matching-saturation.md) of the left side.
