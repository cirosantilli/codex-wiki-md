# Adiabatic invariance of the action

↑ **Parent:** [Action variable](action-variable.md)

When a Hamiltonian parameter varies slowly compared with the orbital period and no separatrix is crossed, the action changes only at higher adiabatic order.

The action is an [adiabatic invariant](adiabatic-invariant.md) under these assumptions; other slowly varying systems can have different adiabatic invariants.
