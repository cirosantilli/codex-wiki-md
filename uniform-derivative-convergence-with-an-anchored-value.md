# Uniform derivative convergence with an anchored value

↑ **Parent:** [Uniform convergence](uniform-convergence.md)

If continuously differentiable functions have uniformly convergent [derivatives](derivative.md) on an interval and their values converge at one point, the functions converge locally uniformly to a continuously differentiable limit whose [derivative](derivative.md) is the [derivative](derivative.md) limit. The proof integrates from the anchored point using the [fundamental theorem of calculus](fundamental-theorem-of-calculus.md). [Uniform convergence](uniform-convergence.md) of the functions on the entire interval follows when the interval is bounded; it need not follow on an unbounded interval.
