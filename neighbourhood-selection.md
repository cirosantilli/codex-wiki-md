# Neighbourhood selection

↑ **Parent:** [Conditional independence graph](conditional-independence-graph.md)

For Gaussian data, regress each variable on all remaining variables using [Lasso](lasso.md). Nonzero coefficients estimate its neighbours in the [conditional independence graph](conditional-independence-graph.md). Symmetrize the separate regressions using either the union or the intersection of their selected directed neighbourhoods.
