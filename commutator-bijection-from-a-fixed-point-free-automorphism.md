# Commutator bijection from a fixed-point-free automorphism

↑ **Parent:** [Frobenius kernel](frobenius-kernel.md)

Let $N$ be a [finite group](finite-group.md) and $\alpha$ an [automorphism](automorphism.md) whose only fixed element is the identity. If $\alpha(a)^{-1}a=\alpha(b)^{-1}b$, then $\alpha(ba^{-1})=ba^{-1}$, so $a=b$. The displayed map is therefore a bijection. For conjugation by a nonidentity element of a [Frobenius complement](frobenius-complement.md), it gives the commutator map $y\mapsto h^{-1}y^{-1}hy$.
