# Stress intensity factor

↑ **Parent:** [Fracture toughness](fracture-toughness.md)

An amplitude characterizing a near-tip linear-elastic crack field for a specified loading mode. The mode-I opening factor scales as the displayed expression for a suitable crack geometry factor $Y$. It is not itself the local [stress](stress.md), and large-scale plasticity can invalidate a linear-elastic characterization.
