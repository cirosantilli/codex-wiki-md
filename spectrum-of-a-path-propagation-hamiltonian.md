# Spectrum of a path propagation Hamiltonian

↑ **Parent:** [History-subspace propagation Hamiltonian](history-subspace-propagation-hamiltonian.md)

For a path with $T+1$ vertices and edge weight $1/2$, the [eigenvalues](eigenvalue.md) are $1-\cos[\pi k/(T+1)]$, $k=0,\ldots,T$. The corresponding coefficients are proportional to $\cos[\pi k(t+1/2)/(T+1)]$. The zero mode is uniform, and the [spectral gap](spectral-gap.md) is at least $2/(T+1)^2$. The endpoint difference equations use reflecting ghost values, not periodic ones.
