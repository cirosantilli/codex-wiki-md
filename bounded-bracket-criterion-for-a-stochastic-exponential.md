# Bounded-bracket criterion for a stochastic exponential

↑ **Parent:** [Novikov's condition](novikov-s-condition.md)

For a zero-start [continuous local martingale](continuous-local-martingale.md) $M$ with $[M]_\infty\leq C$ deterministically, its [stochastic exponential](doleans-dade-exponential.md) is a [uniformly integrable](uniform-integrability.md) [martingale](martingale-split.md). For each $p>1$, $\sup_t\mathbb E\mathcal E(M)_t^p\leq e^{p(p-1)C/2}$. Its terminal value is strictly positive, so it defines an equivalent infinite-horizon [change of measure](change-of-measure.md) by the [Girsanov theorem](girsanov-theorem.md).
