# Closed convex set

↑ **Parent:** [Convex set](convex-set-split.md)

A [convex set](convex-set-split.md) that is also a [closed subset](closed-set.md) in the specified topology. In a [Hilbert space](hilbert-space-split.md) with its [norm topology](norm-topology.md), every nonempty closed convex set has a unique nearest point to every ambient [vector](vector.md), by the [Hilbert projection theorem](hilbert-projection-theorem.md).
