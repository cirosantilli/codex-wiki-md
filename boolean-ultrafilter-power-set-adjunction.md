# Boolean ultrafilter-power-set adjunction

↑ **Parent:** [Adjoint functors](adjoint-functors.md)

A [Boolean algebra](boolean-algebra.md) homomorphism $B\to\mathcal P(A)$ is equivalent to a function assigning to every $a\in A$ an [ultrafilter](ultrafilter.md) on $B$: test membership of $a$ in every image subset. This gives a left adjoint valued in the [opposite category](opposite-category.md) of sets. Its unit sends an algebra element $b$ to the set of ultrafilters containing $b$. On an infinite power-set algebra this map is not surjective, because the subset consisting of the [principal ultrafilters](principal-ultrafilter.md) cannot arise this way in the presence of a [nonprincipal ultrafilter](nonprincipal-ultrafilter.md).
