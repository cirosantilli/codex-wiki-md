# Distributed system

↑ **Parent:** [Computer science](computer-science-split.md)

A [distributed system](distributed-system.md) contains communicating computing components whose coordination crosses machine boundaries. Distribution can improve capacity or [fault tolerance](fault-tolerance.md), but it introduces communication and partial-failure problems. The physical placement of components does not by itself determine who controls them.
