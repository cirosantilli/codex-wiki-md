# Way-below relation

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

In a [partially ordered set](partially-ordered-set.md), $x\ll y$ means that every nonempty [directed set](directed-set.md) $D$ whose [least upper bound](least-upper-bound-in-a-partially-ordered-set.md) exists and satisfies $y\leq\sup D$ contains some $d$ with $x\leq d$. Taking $D=\{y\}$ shows that $x\ll y$ implies $x\leq y$; the converse need not hold. Some formulations quantify over the empty [directed set](directed-set.md) as well; this changes the behaviour at the least element and must be specified.
