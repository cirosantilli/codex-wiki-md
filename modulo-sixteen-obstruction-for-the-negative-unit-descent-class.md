# Modulo-sixteen obstruction for the negative unit descent class

↑ **Parent:** [Quartic covering in a two-isogeny descent](quartic-covering-in-a-two-isogeny-descent.md)

For $y^2=x^3+ax^2+bx$ with $a\equiv8$ and $b\equiv9\pmod{16}$, the [square class](square-class.md) $-1$ in a [two-isogeny descent](two-isogeny-descent.md) would require [coprime integers](coprime-integers.md) $u,v$ and an [integer](integer.md) $N$ with $N^2=-u^4+au^2v^2-bv^4$. If $u$ is odd and $v$ even, the right side is $15$ modulo $16$; if $u$ is even and $v$ odd, it is $7$; if both are odd, it is $14$. None is a square modulo $16$. Therefore $-1$ does not occur in the [two-torsion square-class homomorphism](two-torsion-square-class-homomorphism.md) image.
