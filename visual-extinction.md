# Visual extinction

↑ **Parent:** [Attention](attention.md)

Failure to report a contralesional visual event during simultaneous bilateral stimulation despite better detection when it appears alone. The contrast points to competition and selection, while sensory imbalance and task demands remain possible contributors.
