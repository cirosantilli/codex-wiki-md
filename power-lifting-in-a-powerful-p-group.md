# Power lifting in a powerful p-group

↑ **Parent:** [Powerful p-group](powerful-p-group.md)

For odd $p$, set $P_0=G$ and $P_{i+1}=P_i^p$. Powerful embedding gives $[P_i,G]\leq P_{i+1}$. Modulo $P_{i+2}$, commutators with $P_i$ are central and have exponent dividing $p$, so $(xy)^p\equiv x^py^p$ when $y\in P_i$. Also the power map $P_i/P_{i+1}\to P_{i+1}/P_{i+2}$ is a surjective [homomorphism](homomorphism.md). First find a root modulo $P_2$, then multiply it by successive corrections in $P_i$. The process terminates for a [finite p-group](finite-p-group.md), and converges for a [pro-p group](pro-p-group.md) with separated power filtration. This proves that the generated power [subgroup](subgroup.md) consists of actual powers.
