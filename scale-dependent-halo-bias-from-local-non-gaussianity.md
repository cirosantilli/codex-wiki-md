# Scale-dependent halo bias from local non-Gaussianity

↑ **Parent:** [Peak-background split](peak-background-split.md)

For a universal abundance depending on [halo peak height](halo-peak-height.md), the [peak-background split](peak-background-split.md) gives a potential-response coefficient $b_\varphi=2f_{\rm NL}\delta_c b_L$, with $b_L$ the [linear Lagrangian halo bias](linear-lagrangian-halo-bias.md). If $\delta=\alpha(k)\varphi$, the corresponding deterministic [galaxy bias](galaxy-bias.md) correction is $\Delta b=b_\varphi/\alpha(k)$, proportional to $k^{-2}$ on sufficiently large scales. For a physical Eulerian tracer, $b_E=1+b_L$, so $b_\varphi=2f_{\rm NL}\delta_c(b_E-1)$. The deterministic tracer [power spectrum](power-spectrum.md) is $(b_E+\Delta b)^2P_m$; it remains nonnegative even if a negative correction changes the sign of the tracer-matter correlation.
