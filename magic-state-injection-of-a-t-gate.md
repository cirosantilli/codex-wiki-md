# Magic-state injection of a T gate

↑ **Parent:** [Magic state injection](magic-state-injection.md)

Apply a [controlled-NOT gate](controlled-not-gate.md) from data $a|0\rangle+b|1\rangle$ to the resource $|A\rangle$, then measure the resource in the standard basis. Outcome zero leaves data $T|\psi\rangle$; outcome one leaves $e^{i\pi/4}T^\dagger|\psi\rangle$. Both outcomes have [probability](probability.md) $1/2$. Correct outcome one with $S$, using $ST^\dagger=T$, so the data has undergone the [T gate](t-gate.md) irrespective of the measurement result. The resource is consumed, and its [Bloch vector](bloch-vector.md) lies outside the [stabilizer octahedron](stabilizer-octahedron.md).
