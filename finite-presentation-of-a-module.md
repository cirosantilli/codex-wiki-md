# Finite presentation of a module

↑ **Parent:** [Module (mathematics)](module-mathematics.md)

A [module](module-mathematics.md) is finitely presented when it admits the displayed [exact sequence](exact-sequence.md) for finite integers $r,s$. Thus it has finitely many generators and finitely many relations. On a [Noetherian ring](noetherian-ring.md), every finitely generated module has a finite presentation.
