# Predictable-coefficient localization of a martingale transform

↑ **Parent:** [Martingale transform](martingale-transform.md)

For a finite-valued [predictable process](predictable-process.md) $K$, this is a [stopping time](stopping-time.md) and increases to infinity. The stopped [martingale transform](martingale-transform.md) uses coefficients $K_s\mathbf1_{\{s\leq\sigma_j\}}$, which are [predictable](predictable-process.md) and bounded by $j$. Thus a transform of a discrete-time [martingale](martingale-split.md) is a [local martingale](local-martingale.md) without a global boundedness assumption. The stop is before, not after, the first large coefficient is used.
