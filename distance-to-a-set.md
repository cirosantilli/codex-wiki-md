# Distance to a set

↑ **Parent:** [Metric space](metric-space.md)

For a nonempty [subset](subset.md) $F$ of a [metric space](metric-space.md), the [distance to a set](distance-to-a-set.md) is $d(x,F)=\inf_{y\in F}d(x,y)$. The [triangle inequality](triangle-inequality.md) gives $d(x,F)\leq d(x,z)+d(z,F)$; swapping $x,z$ proves $|d(x,F)-d(z,F)|\leq d(x,z)$. Thus it is one-[Lipschitz](lipschitz-continuity.md). Its zero set is exactly the [closure](closure-topology.md) of $F$: every [neighbourhood](neighbourhood-mathematics.md) of $x$ meets $F$ precisely when this infimum vanishes. For a [closed set](closed-set.md), zero distance therefore implies membership. When the empty set is allowed, use the convention $d(x,\varnothing)=+\infty$; the finite-valued Lipschitz assertion applies to nonempty sets.
