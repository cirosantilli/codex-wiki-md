# Solution branch

↑ **Parent:** [Continuation method](continuation-method.md)

A [solution branch](solution-branch.md) is a portion of a solution set followed continuously as a [curve](curve.md). For $F(u,\lambda)=0$ with $u\in\mathbb R^n$, a full [Jacobian matrix](jacobian-matrix.md) $[F_u\ F_\lambda]$ of [rank](rank-one-quadratic-form.md) $n$ makes the nearby solution set a one-dimensional [regular level set](regular-level-set.md). It need not be a [graph of a function](graph-of-a-function.md) $u(\lambda)$: a [continuation fold](fold-of-a-solution-branch.md) can obstruct that particular choice of parameter while leaving the [solution branch](solution-branch.md) regular.
