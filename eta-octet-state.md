# Eta octet state

↑ **Parent:** [Meson octet](meson-octet.md)

The zero-[isospin](isospin.md), zero-[flavor hypercharge](flavor-hypercharge.md) state $\eta_8=(u\bar u+d\bar d-2s\bar s)/\sqrt6$ in the pseudoscalar [meson octet](meson-octet.md). It is a pure octet basis state; the physical eta may mix it with the flavor-singlet state.
