# Binary string

↑ **Parent:** [Formal language](formal-language.md)

A [binary string](binary-string.md) is a finite word over the alphabet $\{0,1\}$. There are $2^n$ strings of length $n$. Finite [binary strings](binary-string.md) have an effective [bijection](bijection.md) with [natural numbers](natural-number.md), so computable enumerability and immunity apply to sets of strings.
