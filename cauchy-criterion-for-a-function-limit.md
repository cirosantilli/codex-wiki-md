# Cauchy criterion for a function limit

↑ **Parent:** [Complete metric space](complete-metric-space.md)

For a [function](function-split.md) $F:(0,1)\to Z$ into a [complete metric space](complete-metric-space.md), the displayed pairwise condition is equivalent to existence of a limit as $h\to0^+$. Necessity follows from the [triangle inequality](triangle-inequality.md). For sufficiency, the values $F(1/(n+1))$ form a [Cauchy sequence](cauchy-sequence.md), hence converge to some $z\in Z$. Given $\varepsilon>0$, use the pairwise condition with $\varepsilon/2$ and then send $n\to\infty$ in $d(F(h),F(1/(n+1)))<\varepsilon/2$. This gives $d(F(h),z)\leq\varepsilon/2<\varepsilon$ for every sufficiently small positive $h$.
