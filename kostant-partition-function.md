# Kostant partition function

↑ **Parent:** [Root lattice](root-lattice.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kostant_partition_function)

The Kostant partition function $P(\nu)$ counts the ways to express a weight $\nu$ as a nonnegative integer combination of positive roots. By the [Poincaré-Birkhoff-Witt theorem](poincare-birkhoff-witt-theorem.md), $P(\lambda-\mu)$ is the multiplicity of the weight $\mu$ in the [Verma module](verma-module.md) $M(\lambda)$.
