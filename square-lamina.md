# Square lamina

↑ **Parent:** [Square](square.md)

A square frame formed by removing a concentric square hole from a larger [square](square.md). If outer and inner sides are [positive integers](positive-integer.md) $a>b$ with the same [integer parity](parity-mathematics.md), the border has [integer](integer-split.md) thickness $t=(a-b)/2$ and contains $a^2-b^2=4t(b+t)$ unit tiles.
