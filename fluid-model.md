# Fluid model

↑ **Parent:** [Stochastic network](stochastic-network.md)

A fluid model replaces discrete counts by continuous quantities whose evolution follows averaged large-scale drifts. A heuristic drift calculation motivates such a model; proving a [fluid limit](fluid-limit.md) requires a separate convergence argument.
