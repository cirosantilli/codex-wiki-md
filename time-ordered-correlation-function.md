# Time-ordered correlation function

↑ **Parent:** [Correlation function](correlation-function.md)

The vacuum expectation value of a [time ordering](time-ordering.md) of [quantum field](quantum-field.md) insertions, for example $\langle0|T\{\phi(x)\phi(y)\}|0\rangle$. The vacuum [path integral](path-integral.md) with the [Feynman i-epsilon prescription](feynman-i-epsilon-prescription.md) computes these functions. For [fermion](fermion.md) fields the ordering includes a minus sign for each odd permutation. Differentiating a [time-ordered correlation function](time-ordered-correlation-function.md) can differentiate its ordering step functions and produce [Ward identity contact terms](ward-identity-contact-terms.md).
