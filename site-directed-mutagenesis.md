# Site-directed mutagenesis

↑ **Parent:** [Molecular genetics](molecular-genetics-split.md)

[site-directed mutagenesis](site-directed-mutagenesis.md) deliberately changes a specified sequence position. Functional interpretation requires distinguishing a local mechanistic effect from altered abundance, localization or [protein folding](protein-folding.md).
