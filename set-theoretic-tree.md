# Set-theoretic tree

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

A [partial order](partially-ordered-set.md) in which the strict predecessors of each node form a [well-order](well-order.md). The height of a node is the [order type](order-type.md) of its predecessors; nodes of a common height form a level. This order-theoretic meaning is distinct from a graph-theoretic [tree](tree-graph-theory.md).
