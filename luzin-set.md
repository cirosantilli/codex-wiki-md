# Luzin set

↑ **Parent:** [Meagre set](meagre-set.md)

An uncountable [subset](subset.md) of the [real numbers](real-number.md) with countable intersection with every [meagre set](meagre-set.md). This is the category counterpart of a [Sierpiński set](sierpinski-set.md).
