# Square class

↑ **Parent:** [Square-class group of a field](square-class-group-of-a-field.md)

The square class of $a\in K^*$ is its image in the [square-class group of a field](square-class-group-of-a-field.md) $K^*/K^{*2}$. Two nonzero elements have the same square class exactly when their quotient is a square. Every element of this quotient has order dividing $2$. Over the [rational numbers](rational-number.md), a square class has a unique signed squarefree integer representative.
