# Pointwise order on real polynomials

↑ **Parent:** [Polynomial](polynomial-split.md)

This is a [partial order](partially-ordered-set.md): the real inequalities supply [reflexivity](reflexive-relation.md) and [transitivity](transitive-relation.md), while inequalities in both directions give equality of the [polynomials](polynomial-split.md) as functions. It is not a [total order](total-order.md), since the [polynomials](polynomial-split.md) $x$ and $0$ are incomparable on all of $\mathbb R$. Restricting the test domain can change the relation; testing only at finitely many points need not distinguish different [polynomials](polynomial-split.md).
