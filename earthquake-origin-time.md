# Earthquake origin time

↑ **Parent:** [Earthquake location by arrival times](earthquake-location-by-arrival-times.md)

An [earthquake origin time](earthquake-origin-time.md) is the estimated onset time of rupture. Predicted arrivals add this time to a propagation [travel time](travel-time.md); an uncertain origin time therefore couples to uncertain source depth in some station geometries.
