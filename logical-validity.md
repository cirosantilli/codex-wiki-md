# Logical validity

↑ **Parent:** [Classical propositional logic](classical-propositional-logic.md)

An argument has [logical validity](logical-validity.md) in [classical propositional logic](classical-propositional-logic.md) when no [Boolean valuation](boolean-valuation.md) makes all premises $\Gamma$ true and the conclusion $A$ false: $\Gamma\models A$. With no premises, $\models A$ says that $A$ is a [tautology](tautology.md). See [forall x: Calgary, sections 12.4–12.6](https://forallx.openlogicproject.org/html/Ch12.html).
