# Zero of a cyclic code

↑ **Parent:** [Cyclic code](cyclic-code.md)

A zero of a [cyclic code](cyclic-code.md) is a [polynomial root](root-of-a-polynomial.md) of its [generator polynomial](generator-polynomial-of-a-cyclic-code.md), taken in a [splitting field](splitting-field.md). Every [codeword](codeword.md), represented as a [polynomial](polynomial-split.md), vanishes there. For a [repeated-root cyclic code](repeated-root-cyclic-code.md), the [multiplicity of a root](multiplicity-of-a-root.md) must also be retained: ordinary evaluations alone need not determine the code.
