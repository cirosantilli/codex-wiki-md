# Condensate density in a shifted-parabola triplon model

↑ **Parent:** [Field-induced triplon condensation](field-induced-triplon-condensation.md)

If the phenomenological single-density shift is continued into the condensed [phase](phase-waves.md) and the thermal population remains saturated at $n_T(T)$, the zero minimum requires $\nu[n_0+n_T]=\eta(H-H_g)$. At fixed [temperature](temperature-split.md), $n_0=(\eta/\nu)[H-H_c(T)]$ above onset and zero below it. This prefactor belongs to that closure; a microscopic interaction model can distinguish normal and condensed self-energies. Continuing the normal [parabola](parabola.md) into negative energies without changing the state is not a consistent Bose distribution.
