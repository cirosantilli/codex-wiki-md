# Negative semidefinite matrix

↑ **Parent:** [Hessian matrix](hessian-matrix.md)

A symmetric matrix $A$ is negative semidefinite when $v^TAv\leq0$ for every vector $v$. Equivalently, all its [eigenvalues](eigenvalue.md) are nonpositive.
