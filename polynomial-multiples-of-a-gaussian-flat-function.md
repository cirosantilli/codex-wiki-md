# Polynomial multiples of a Gaussian flat function

↑ **Parent:** [Flat function](flat-function.md)

Extend this expression by zero at zero. [Gaussian decay dominates every power](gaussian-decay-dominates-every-power.md), so the resulting function and its derivative difference quotients vanish to every order at zero. Away from zero, differentiation replaces $p(t)$ by $2t^3p(t)-t^2p'(t)$, another [polynomial](polynomial-split.md). Induction therefore gives a [smooth function](smooth-function.md) flat at zero. If $p$ is nonzero, its [Taylor series](taylor-series.md) is zero while the function is nonzero at every sufficiently small nonzero argument, so it is not [real analytic](real-analytic-function.md) there.
