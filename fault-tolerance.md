# Fault tolerance

↑ **Parent:** [Distributed system](distributed-system.md)

[Fault tolerance](fault-tolerance.md) is the ability to continue satisfying a specified service property despite a stated class of component failures. The failure model and the property matter: preserving stored bytes, accepting new connections and finishing an operation are different requirements.
