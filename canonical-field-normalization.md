# Canonical field normalization

↑ **Parent:** [Wave-function renormalization](wave-function-renormalization.md)

Canonical field normalization rescales a field so that its kinetic term has unit coefficient. For a [chiral superfield](chiral-superfield.md) with $K=Z\Phi^\dagger\Phi$, the change $\Phi_c=Z^{1/2}\Phi$ turns holomorphic [superpotential](superpotential.md) parameters into canonical parameters $m_c=m/Z$ and $g_c=g/Z^{3/2}$.
