# Tridiagonal matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tridiagonal_matrix)

A tridiagonal matrix has zero entries outside its main diagonal and the two adjacent diagonals. Linear systems with a nonsingular tridiagonal coefficient matrix can be solved in linear time by the [Thomas algorithm](tridiagonal-matrix-algorithm.md).
