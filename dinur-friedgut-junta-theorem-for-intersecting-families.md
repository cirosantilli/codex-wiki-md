# Dinur-Friedgut junta theorem for intersecting families

↑ **Parent:** [Intersecting family](intersecting-family.md)

For $0<p<1/2$ and $\varepsilon>0$, every intersecting family is, up to $\mu_p$-measure $\varepsilon$, contained in the [upward closure of a set family](upward-closure-of-a-set-family.md) generated by an intersecting family on a bounded set of coordinates.
