# Conditional probability mass function

↑ **Parent:** [Conditional distribution](conditional-distribution.md)

The [probability mass function](probability-mass-function.md) of a discrete [conditional distribution](conditional-distribution.md). The elementary ratio requires $p_X(x)>0$; a value of zero gives no event-conditioning definition through this ratio.
