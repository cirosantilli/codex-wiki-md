# Idempotent element of a semigroup

↑ **Parent:** [Semigroup](semigroup.md)

An element of a [semigroup](semigroup.md) is idempotent when multiplying it by itself leaves it unchanged. Every element of a left-zero or right-zero semigroup is idempotent, whereas a [group](group-split.md) has only its identity as an idempotent. The [Ellis–Numakura lemma](ellis-numakura-lemma.md) guarantees such an element in a nonempty compact one-sided topological semigroup. Additive idempotence on ultrafilters gives the [idempotent ultrafilter](idempotent-ultrafilter.md) relation $p+p=p$.
