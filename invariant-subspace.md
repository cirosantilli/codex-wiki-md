# Invariant subspace

↑ **Parent:** [Group representation](group-representation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Invariant_subspace)

An invariant subspace of a [linear map](linear-map.md) $A:V\to V$ is a [vector subspace](vector-subspace.md) $W\subseteq V$ satisfying $A(W)\subseteq W$. For a [group representation](group-representation.md), invariance means $\rho(g)W\subseteq W$ for every represented group element $g$.
