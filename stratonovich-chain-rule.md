# Stratonovich chain rule

↑ **Parent:** [Stratonovich integral](stratonovich-integral.md)

For a continuous [semimartingale](semimartingale.md) $X$ and a sufficiently smooth $f$, the [Stratonovich integral](stratonovich-integral.md) obeys $f(X_t)-f(X_0)=\int_0^tf'(X_s)\circ dX_s$. In general $f'(X)$ is a [semimartingale](semimartingale.md), so the definition must allow this larger class of integrands.
