# Indefinite matrix

↑ **Parent:** [Indefinite quadratic form](indefinite-quadratic-form.md)

A real [symmetric matrix](symmetric-matrix.md) $A$ is indefinite when $x^TAx$ is an [indefinite quadratic form](indefinite-quadratic-form.md). Equivalently, $A$ has both a positive and a negative [eigenvalue](eigenvalue.md), by the [spectral theorem](spectral-theorem.md). A zero [eigenvalue](eigenvalue.md) is permitted, so an [indefinite matrix](indefinite-matrix.md) need not be an [invertible matrix](invertible-matrix.md).
