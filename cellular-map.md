# Cellular map

↑ **Parent:** [CW complex](cw-complex.md)

A cellular map $f:X\to Y$ between [CW complexes](cw-complex.md) satisfies $f(X^q)\subseteq Y^q$ for every skeleton. It induces a [chain map](chain-map.md) $f_\#:C_*^{\mathrm{cell}}(X)\to C_*^{\mathrm{cell}}(Y)$.
