# Complete search algorithm

↑ **Parent:** [Search algorithm](search-algorithm.md)

A [search algorithm](search-algorithm.md) is complete for a specified class of problems if it finds a solution whenever a solution exists in that class. This definition need not require termination on unsolvable instances; an additional termination guarantee should be stated separately. A finite [branching factor](branching-factor.md) makes [breadth-first tree search](breadth-first-tree-search.md) complete for finite-depth solutions, while [depth-first tree search](depth-first-tree-search.md) additionally needs a reason it cannot be trapped on an infinite branch.
