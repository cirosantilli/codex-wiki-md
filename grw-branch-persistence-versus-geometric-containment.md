# GRW branch persistence versus geometric containment

↑ **Parent:** [GRW amplification mechanism](grw-amplification-mechanism.md)

A first localization near one macroscopically separated branch suppresses the other branch through the Gaussian [GRW localization operator](grw-localization-operator.md). This selects a correlated pointer alternative. However, if a region contains only packet centres and excludes substantial packet mass, the next centre need not lie in that region's small enlargement. Probabilities $|\alpha|^2$ for the first event and approximately one for the next require regions containing essentially all corresponding branch mass. The general [GRW collapse-centre event probabilities](grw-collapse-centre-event-probabilities.md) retain the geometry exactly.
