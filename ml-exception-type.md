# ML exception type

↑ **Parent:** [Exception handling](exception-handling.md)

In [Standard ML](standard-ml.md), `exn` is an extensible datatype of exception packets. Fresh declarations introduce constructors, optionally with payloads; rebinding can alias an existing constructor; `raise` propagates a packet and `handle` performs dynamic pattern-based recovery.
