# Arbitrary-precision arithmetic

↑ **Parent:** [Integer arithmetic](integer-arithmetic.md)

[Integer arithmetic](integer-arithmetic.md) in which storage grows with the number of [numerical digits](numerical-digit.md) needed, instead of imposing a fixed word size. It allows exact [addition](addition.md), [multiplication](multiplication.md), and [exponentiation](exponentiation.md) on large [integers](integer-split.md), subject to available memory; operation costs grow with operand length.
