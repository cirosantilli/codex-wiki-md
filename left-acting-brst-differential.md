# Left-acting BRST differential

↑ **Parent:** [BRST symmetry](brst-symmetry.md)

Writing a transformation as $\delta\Phi=\epsilon s\Phi$ with the odd parameter on the left defines this graded derivation convention. For Yang-Mills fields, $sA=Dc$, $sc=-[c,c]/2$, $sb=h$, and $sh=0$. The [Jacobi identity](jacobi-identity.md) supplies nilpotence; the placement of the odd parameter controls signs in a [Noether current](noether-current.md).
