# Linear capacity rigidity

↑ **Parent:** [Symplectic capacity](symplectic-capacity.md)

An invertible real linear map preserving [symplectic capacities](symplectic-capacity.md) of all [solid ellipsoids](solid-ellipsoid.md) is symplectic or [anti-symplectic](anti-symplectic-map.md). For a pair with $\omega(u,v)=1$, if $0<|\omega(T^Tu,T^Tv)|<1$, complete this pair and its normalized transformed pair to [symplectic bases](symplectic-basis.md). The resulting transpose matrix sends a unit ball into a [symplectic cylinder](symplectic-cylinder.md) of radius less than one, contradicting the capacity axioms after iterating the resulting linear map: its first coordinate pair contracts geometrically, while the image ellipsoid retains positive capacity. Perturbation handles a zero pairing; using $T^{-1}$ handles absolute value greater than one. Thus the absolute bilinear pairings agree. Their squares agree as polynomials, and the polynomial ring being an [integral domain](integral-domain.md) forces one global sign.
