# Static mode lost by cancelling frequency

↑ **Parent:** [Dispersion relation](dispersion-relation-split.md)

When a [dispersion relation](dispersion-relation-split.md) factors as $\omega P(\omega,k)=0$, dividing by $\omega$ discards a possible time-independent [Fourier mode](fourier-mode.md). This can remove a necessary [stationary solution](stationary-solution.md) from an [initial value problem](initial-value-problem.md). For instance, a constant-coefficient temporal equation $T^{(3)}+iaT''+bT'=0$ has a constant solution as well as the two exponential solutions from its quadratic factor. Three initial conditions generally require all three modes. Cancellation is valid only when a nonzero frequency has already been required.
