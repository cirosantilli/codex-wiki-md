# Quotient theorem for Cartesian tensors

↑ **Parent:** [Tensor](tensor.md)

Suppose an array $T_{ij}$ is specified in each right-handed [orthonormal basis](orthonormal-basis.md). If $w_i=T_{ij}v_j$ transforms as a [vector](vector.md) for every [vector](vector.md) $v$, then $T$ is a second-order Cartesian [tensor](tensor.md) under those [basis](basis.md) changes. Indeed $v'=Rv$, $w'=Rw$ imply $T'Rv=RTv$ for every $v$, hence $T'=RTR^T$. The condition on every test [vector](vector.md) is essential; one contraction is insufficient.
