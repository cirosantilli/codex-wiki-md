# Logarithmic branch point

↑ **Parent:** [Branch point](branch-point.md)

The [complex logarithm](complex-logarithm.md) has infinite-sheeted branching: continuing once around its zero changes its value by $2\pi i$. Multiplication by a function vanishing at that point need not remove the branching. For example $z^m\log z$ with positive integer $m$ tends to zero but changes by $2\pi iz^m$ after continuation around zero. This remains a [branch point](branch-point.md), rather than a [removable singularity](removable-singularity.md), because no single-valued holomorphic function exists on a full punctured neighbourhood. The coordinate $w=1/z$ tests logarithmic branching at infinity in the same way.
