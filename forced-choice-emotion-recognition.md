# Forced-choice emotion recognition

↑ **Parent:** [Emotion recognition](emotion-recognition.md)

A procedure in which an observer selects an [emotion](emotion.md) interpretation from specified alternatives. Above-chance performance supports [discrimination](discrimination.md) among those alternatives under that task; it does not establish that the same categories would be produced spontaneously without prompting.
