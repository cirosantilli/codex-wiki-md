# Critical points escaping to infinity in a Gaussian-weighted bilinear function

↑ **Parent:** [Second-derivative test](second-derivative-test.md)

The origin is a [saddle point of a scalar function](saddle-point-of-a-scalar-function.md) for every real parameter. For $\alpha>0$ four further [critical points](critical-point.md) have $x^2=y^2=1/(2\alpha)$. Equal-sign coordinates give global maxima and opposite-sign coordinates give [global minima](global-minimum.md), with values $\pm1/(2e\alpha)$. The [Hessian matrix](hessian-matrix.md) there is $-4\alpha xy e^{-1}I$. Their distance from the origin is $\alpha^{-1/2}$, so as $\alpha\downarrow0$ they escape every compact region. At nonpositive $\alpha$ the origin is the only [critical point](critical-point.md). This illustrates why the number of [critical points](critical-point.md) on an unbounded domain can change without a finite degenerate [critical point](critical-point.md) appearing.
