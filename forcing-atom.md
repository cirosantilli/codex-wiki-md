# Forcing atom

↑ **Parent:** [Forcing](forcing-split.md)

A condition is an atom if every two stronger conditions are [compatible forcing conditions](compatible-forcing-conditions.md). This is a compatibility definition, not necessarily minimality in an arbitrary [partial order](partially-ordered-set.md). An [atomless forcing order](atomless-forcing-order.md) is one in which every condition has two incompatible strengthenings.
