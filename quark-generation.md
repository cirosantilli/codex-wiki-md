# Quark generation

↑ **Parent:** [Fermion generation](fermion-generation.md)

The three [quark](quark.md) generations pair $(u,d)$, $(c,s)$ and $(t,b)$, each containing one charge-$2/3$ and one charge-$-1/3$ quark. The number of generations controls the number of physical mixing angles and [CP-violating phases](cp-violating-phase.md) in the [CKM matrix](cabibbo-kobayashi-maskawa-matrix.md).
