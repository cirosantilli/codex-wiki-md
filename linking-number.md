# Linking number

↑ **Parent:** [Link](link.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linking_number)

The linking number of two disjoint oriented closed curves in $S^3$ is the signed intersection number of one curve with a [Seifert surface](seifert-surface.md) for the other. In an oriented diagram it is half the signed sum of crossings between the two components.
