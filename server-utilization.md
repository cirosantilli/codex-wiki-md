# Server utilization

↑ **Parent:** [Queueing theory](queueing-theory-split.md)

The long-run fraction of time a work-conserving server is busy. Applying [Little's law](little-s-law.md) to the server alone gives utilization equal to admitted [queue throughput](queue-throughput.md) times mean [service time](service-time.md). In a finite-buffer queue, the blocking probability must be included in that throughput.
