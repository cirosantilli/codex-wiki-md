# Lorentz boost vector field

↑ **Parent:** [Commutation vector field for the wave equation](commutation-vector-field-for-the-wave-equation.md)

For [Minkowski spacetime](minkowski-spacetime.md) with unit light speed, $L_i=t\partial_i+x_i\partial_t$ generates a [Lorentz boost](lorentz-boost.md). It commutes with the [d'Alembert operator](d-alembert-operator.md) and controls derivatives transverse to time slices in the [vector field method for wave equations](vector-field-method-for-wave-equations.md).
