# Hapticity

↑ **Parent:** [Ligand in coordination chemistry](ligand-in-coordination-chemistry.md)

[Hapticity](hapticity.md), written $\eta^n$, specifies the number of contiguous ligand atoms involved in attachment to a metal. It differs from denticity, which counts donor sites in a chelate.
