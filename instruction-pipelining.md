# Instruction pipelining

↑ **Parent:** [Central processing unit](central-processing-unit.md)

[Instruction pipelining](instruction-pipelining.md) divides execution into stages with stored intermediate state, allowing different instructions to occupy different stages simultaneously. The [processor clock period](processor-clock-period.md) is constrained by stage timing; moving a [barrel shifter](barrel-shifter.md) and [arithmetic logic unit](arithmetic-logic-unit.md) into the same stage can lengthen that stage's [combinational critical path](combinational-critical-path.md).
