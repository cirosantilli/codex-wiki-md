# Shapley wages in an entrepreneur-worker game

↑ **Parent:** [Shapley value](shapley-value.md)

An entrepreneur is indispensable and a [coalition](coalition-game-theory.md) containing the entrepreneur and $k$ of $n$ workers earns $p(k)$; a [coalition](coalition-game-theory.md) without the entrepreneur earns zero. A worker's [marginal contribution](marginal-contribution.md) is nonzero only when the entrepreneur precedes them. The [probability](probability.md) that the entrepreneur and exactly $k$ other workers precede that worker is $(k+1)/(n(n+1))$, giving the displayed common [Shapley value](shapley-value.md) wage. The entrepreneur receives $p(n)-nw$. Convex nondecreasing $p$ makes all [marginal contributions](marginal-contribution.md) increase with predecessor sets, so the whole [Shapley value](shapley-value.md) allocation belongs to the [core](core-game-theory.md).
