# Mapping class

↑ **Parent:** [Mapping class group](mapping-class-group.md)

A mapping class is an [isotopy](isotopy.md) class of self-homeomorphisms of a surface. Orientation-preserving classes form the [mapping class group](mapping-class-group.md). Acting on markings changes a point of [Teichmüller space](teichmuller-space.md) while preserving the underlying unmarked [Riemann surface](riemann-surfaces.md).
