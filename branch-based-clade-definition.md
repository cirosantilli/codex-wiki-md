# Branch-based clade definition

↑ **Parent:** [Phylogenetic nomenclature](phylogenetic-nomenclature.md)

A definition selecting the largest [clade](clade.md) containing specified internal reference taxa but excluding specified external reference taxa. With one of each, it includes organisms more closely related to the internal than to the external specifier.
