# Newton iteration for formal power series exponential

↑ **Parent:** [Formal power series exponential](formal-power-series-exponential.md)

To solve $\log G=A$ with $A(0)=0$, start with $G=1$ and update $G\gets G(1+A-\log G)$ at successively doubled truncation precision. The correction removes the current logarithmic error to first order. This is Newton iteration applied to the [formal power series exponential](formal-power-series-exponential.md), using a [formal power series logarithm](logarithm-of-a-formal-power-series.md).
