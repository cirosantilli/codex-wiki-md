# Arithmetic bounded formula

↑ **Parent:** [Bounded quantifier](bounded-quantifier.md)

An [arithmetic bounded formula](arithmetic-bounded-formula.md) uses only quantifiers bounded by [arithmetic](arithmetic-split.md) terms, such as $\exists u<t$ and $\forall u<t$, with the bound not containing the quantified variable. Existential bounded representation of a [primitive recursive function](primitive-recursive-function.md) places all unrestricted existential variables in a single outer block.
