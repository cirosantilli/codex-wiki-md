# Metric

↑ **Parent:** [Metric space](metric-space.md)

A metric on a [set](set-split.md) $X$ is a function $d:X\times X\to[0,\infty)$ that is symmetric, satisfies the [triangle inequality](triangle-inequality.md), and obeys $d(x,y)=0$ exactly when $x=y$.

A metric equips its underlying [set](set-split.md) with a [metric space](metric-space.md) structure; the distance function and the space carrying it are distinct concepts.
