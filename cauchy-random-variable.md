# Cauchy random variable

↑ **Parent:** [Cauchy distribution](cauchy-distribution.md)

A Cauchy random variable is a [random variable](random-variable-split.md) having a [Cauchy distribution](cauchy-distribution.md). For a standard Cauchy random variable $V$,

$$
\mathbb E e^{itV}=e^{-|t|}.
$$
