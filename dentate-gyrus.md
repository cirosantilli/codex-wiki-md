# Dentate gyrus

↑ **Parent:** [Hippocampus](hippocampus.md)

A [hippocampal](hippocampus.md) input structure with sparse granule-cell activity. Expansion and [synaptic competition](synaptic-competition.md) can reduce overlap between similar inputs, motivating its role in [pattern separation](pattern-separation.md). Input and output population comparisons test that computation more directly than firing-rate differences alone.
