# Poisson spike-train likelihood fitting

↑ **Parent:** [Linear-nonlinear-Poisson cascade model](linear-nonlinear-poisson-cascade-model.md)

For a stimulus-conditioned [Inhomogeneous Poisson process](inhomogeneous-poisson-process.md), the event log-likelihood is the displayed expression. A causal filter expansion $\lambda(t)=\exp[b+\sum_aw_a(s*b_a)(t)]$ can be fitted by [maximum likelihood estimation](maximum-likelihood-estimation.md), with a smoothness or size penalty and held-out validation. The integral term penalizes predicted spikes that did not occur; fitting only stimulus values at observed spikes omits this essential part.
