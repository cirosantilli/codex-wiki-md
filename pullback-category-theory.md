# Pullback (category theory)

↑ **Parent:** [Finite limit](finite-limit.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pullback_(category_theory))

The pullback of $X\to Z\leftarrow Y$ is a universal commutative square with an object mapping to $X$ and $Y$. In the [Category of sets](category-of-sets.md), it is the set of pairs with equal images in $Z$.
