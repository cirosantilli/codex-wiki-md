# Resolvent of an operator

↑ **Parent:** [Resolvent formalism](resolvent-formalism.md)

For a [closed linear operator](closed-linear-operator.md) $A$, the resolvent is the bounded inverse $(zI-A)^{-1}$ when $z$ lies in the [resolvent set of an operator](resolvent-set-of-an-operator.md). This definition includes unbounded $A$. It specializes to the [resolvent of an element](resolvent-of-an-element.md) when $A$ is an element of a [Banach algebra](banach-algebra-split.md).
