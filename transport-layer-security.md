# Transport Layer Security

↑ **Parent:** [Cryptography](cryptography.md)

[Transport Layer Security](transport-layer-security.md) creates a protected channel between [protocol](communication-protocol.md) peers. The application determines the intended peer and how its authentication is interpreted; a provider-authorised [CDN edge](cdn-edge.md) can be such a peer. Channel protection does not make that peer unable to read data delivered to it.[§1: channel properties and application authentication interpretation](the-transport-layer-security-protocol-version-1-3-rfc-8446.md)
