# Color multiplicity in a decay width

↑ **Parent:** [Color charge](color-charge.md)

For a colorless parent decaying through a color-diagonal interaction into a [quark](quark.md) and [antiquark](antiquark.md), the three orthogonal matching-color states add incoherently. The inclusive flavor [decay width](decay-width.md) is $N_c=3$ times the one-color width. In a parton scattering rate, an initial color average instead cancels the matching final color sum.
