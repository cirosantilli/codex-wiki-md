# Algebraic integer

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algebraic_integer)

An algebraic number is an algebraic integer when it satisfies a monic polynomial with integer coefficients. Algebraic integers are closed under addition and multiplication.
