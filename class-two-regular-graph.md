# Class two regular graph

↑ **Parent:** [Regular graph](regular-graph.md)

An $r$-[regular graph](regular-graph.md) is class two when its [edge chromatic number](edge-chromatic-number.md) exceeds $r$. For a finite [simple graph](simple-graph.md), [Vizing's theorem](vizing-s-theorem.md) makes that [edge chromatic number](edge-chromatic-number.md) exactly $r+1$. An $r$-colour [proper edge colouring](proper-edge-coloring.md) of an $r$-[regular graph](regular-graph.md) would partition its [edges](edge-of-a-graph.md) into $r$ [perfect matchings](perfect-matching.md), since every [vertex](vertex-graph-theory.md) would see each colour exactly once.
