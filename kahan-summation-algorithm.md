# Kahan summation algorithm

↑ **Parent:** [Compensated summation](compensated-summation.md)

A [summation](summation.md) [algorithm](algorithm-split.md) that keeps a correction for low-order information lost when adding [floating-point numbers](floating-point-number.md). Feeding that correction into subsequent additions can greatly reduce accumulated rounding error compared with straightforward summation.
