# Pareto improvement

↑ **Parent:** [Pareto efficiency](pareto-efficiency.md)

A feasible change weakly increasing every participant's [utility](utility.md) and strictly increasing at least one. An assignment is [Pareto optimal](pareto-efficiency.md) exactly when no [Pareto improvement](pareto-improvement.md) exists. This comparison permits coordinated changes by several participants; it is different from a profitable [unilateral deviation](unilateral-deviation.md) used to test a [Nash equilibrium](nash-equilibrium.md).
