# Equivalent probability measure

↑ **Parent:** [Mutually absolutely continuous measures](mutually-absolutely-continuous-measures.md)

Two [probability measures](probability-measure.md) are equivalent when each is [absolutely continuous](absolute-continuity-of-measures.md) with respect to the other, or equivalently when they have the same null events.
