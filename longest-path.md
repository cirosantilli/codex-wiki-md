# Longest path

↑ **Parent:** [Path in a graph](path-in-a-graph.md)

A [longest path](longest-path.md) maximizes path length, either the number of [edges](edge-of-a-graph.md) or the sum of specified [edge](edge-of-a-graph.md) weights, under the stated endpoints and simple-path convention. In a general [graph](graph-split.md), imposing [vertex](vertex-graph-theory.md) simplicity makes the optimization computationally difficult; a [Directed acyclic graph](directed-acyclic-graph.md) admits a direct [dynamic programming](dynamic-programming.md) solution. Allowing arbitrary walks instead requires care with reachable positive cycles. The convention permitting a zero-edge path gives a possible value zero even when all nonempty paths have negative weight.
