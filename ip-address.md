# IP address

↑ **Parent:** [Internet Protocol](internet-protocol.md)

An [IP address](ip-address.md) identifies an interface or destination according to the relevant [Internet Protocol](internet-protocol.md) addressing rules. It is not inherently the identity of a person, and address translation can change the address visible across a boundary.
