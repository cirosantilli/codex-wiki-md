# Stagnant mushy-layer model

↑ **Parent:** [Mushy layer](mushy-layer.md)

A stagnant mushy-layer model has no bulk advection, equal phase [mass densities](density.md), pure solid, and local equilibrium on the [liquidus](liquidus.md). With [liquid fraction](liquid-fraction.md) $\phi$, [specific enthalpy](specific-enthalpy.md) $E=c_pT+L\phi$ and bulk solute [concentration](concentration.md) $B=\phi C$, neglecting solute [diffusion](diffusion.md) inside the [mushy layer](mushy-layer.md) gives $T_t+(L/c_p)\phi_t=\kappa T_{zz}$ and $(\phi C)_t=0$. The latter fixes composition at each stationary material level; it does not automatically set every level to the initial liquid [concentration](concentration.md) when solute can diffuse ahead of the growing mush.
