# Complementary factorial congruence

↑ **Parent:** [Wilson's theorem](wilson-s-theorem.md)

For a [prime number](prime-number.md) $p$ and nonnegative [integers](integer.md) $h+k=p-1$, [Wilson theorem](wilson-s-theorem.md) gives $(-1)^k h!k!\equiv-1\pmod p$ by replacing the last $k$ factors of $(p-1)!$ with $-1,-2,\ldots,-k$. For odd $p$, $h,k$ have the same parity; for $p=2$, both signs have the same [residue class](residue-class.md). Thus $h!k!+(-1)^h\equiv0\pmod p$, including the endpoint cases $0!=1$.
