# Null set

↑ **Parent:** [Measure theory](measure-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Null_set)

A [measurable set](measurable-set.md) $N$ is a null set for a [measure](measure-split.md) $\mu$ when $\mu(N)=0$. A property holds [almost everywhere](almost-everywhere.md) when its exceptions lie in a null set. With a [complete measure](complete-measure.md), every [subset](subset.md) of a null set is measurable and is itself a null set.
