# Simplex optimality criterion

↑ **Parent:** [Simplex method](simplex-method.md)

In a feasible minimization [simplex dictionary](simplex-dictionary.md), the nonbasic variables are nonnegative. If every [reduced cost](reduced-cost.md) $\bar c_j\ge0$, the displayed objective identity proves $z\ge z_0$ for every feasible point. Thus the current [basic feasible solution](basic-feasible-solution.md) is globally optimal. If all [reduced costs](reduced-cost.md) are strictly positive, equality forces every nonbasic variable to vanish and gives a unique basic solution, provided the dictionary determines all basic variables.
