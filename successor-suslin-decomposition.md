# Successor-Suslin decomposition

↑ **Parent:** [Kappa-Suslin set](kappa-suslin-set.md)

For an infinite [cardinal number](cardinal-number.md) $\kappa$, every $\kappa^+$-Suslin set is a union of $\kappa^+$ many $\kappa$-Suslin sets. A countable sequence of ordinals below the [successor cardinal](successor-cardinal.md) $\kappa^+$ is bounded there, so restrict the representing tree successively to labels below each $\alpha<\kappa^+$.
