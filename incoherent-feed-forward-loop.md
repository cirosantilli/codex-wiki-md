# Incoherent feed-forward loop

↑ **Parent:** [Feed-forward loop](feed-forward-loop.md)

In an incoherent [feed-forward loop](feed-forward-loop.md), the direct path from an input to an output and the indirect path through a second [transcription factor](transcription-factor.md) have opposite net signs. Their different response times can generate a pulse or adaptation. A nonzero basal production rate makes the final adapted output nonzero, so its logic and response time must be calculated from the actual [gene regulation](regulation-of-gene-expression.md) rule rather than assumed from a Boolean label.
