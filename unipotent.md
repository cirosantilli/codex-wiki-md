# Unipotent

↑ **Parent:** [Linear algebraic group](linear-algebraic-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Unipotent)

An element $u$ of a [ring](ring.md) is [unipotent](unipotent.md) when $u-1$ is [nilpotent](nilpotent.md). For a matrix, this says that every [eigenvalue](eigenvalue.md) is one. A [unipotent algebraic group](unipotent-algebraic-group.md) consists of unipotent elements in a faithful linear representation.
