# Rank-raising monotonicity lemma

↑ **Parent:** [Strategyproofness](strategyproofness.md)

If a [strategyproof](strategyproofness.md) [social choice function](social-choice-function.md) selects $a$, raising $a$ in one agent's order without moving any formerly lower alternative above it preserves the outcome. A different outcome would make one of the changes between the old and new reports a profitable deviation. Arbitrary changes among alternatives wholly above or wholly below $a$ are allowed.
