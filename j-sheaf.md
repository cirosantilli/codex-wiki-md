# j-sheaf

↑ **Parent:** [Lawvere-Tierney topology](lawvere-tierney-topology.md)

An object $X$ is a $j$-sheaf when every map $A'\to X$ defined on the domain of a [j-dense monomorphism](j-dense-monomorphism.md) $A'\hookrightarrow A$ extends uniquely to a map $A\to X$.
