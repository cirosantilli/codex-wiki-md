# Existential axiomatization from extension closure

↑ **Parent:** [Łoś-Tarski preservation theorem](los-tarski-preservation-theorem.md)

A [first-order model](model-of-a-first-order-theory.md) class axiomatized by a [theory](first-order-theory.md) is closed under extensions exactly when it has an existential axiomatization. If $A$ satisfies all existential consequences of $T$, then $T$ is jointly satisfiable with the universal [theory](first-order-theory.md) of $A$: any finite obstruction would negate a universal [conjunction](conjunction-astronomy.md) and produce a violated existential consequence. Embed a [model](model-of-a-first-order-theory.md) of $T$ into a [model](model-of-a-first-order-theory.md) [elementarily equivalent](elementary-equivalence.md) to $A$, apply extension closure, and transfer truth back to $A$.
