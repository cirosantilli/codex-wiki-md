# Inclusion-maximal separated set

↑ **Parent:** [Separated subset of a metric space](separated-subset-of-a-metric-space.md)

An inclusion-maximal [separated set](separated-subset-of-a-metric-space.md) is one to which no further point of the ambient [metric space](metric-space.md) can be added while keeping the same separation. It need not have the largest possible cardinality. In a finite space it can be obtained by repeatedly adding an admissible point.
