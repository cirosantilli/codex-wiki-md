# Inverse-square-root singularity

↑ **Parent:** [Integrable singularity](integrable-singularity.md)

An endpoint [integrable singularity](integrable-singularity.md) with $f(x)\sim C/\sqrt{x-x_0}$ as $x\downarrow x_0$, for finite nonzero $C$. It is an [integrable singularity](integrable-singularity.md) because $\int_{x_0}^{x_0+\epsilon}(x-x_0)^{-1/2}\,dx=2\sqrt\epsilon$. One common origin is a stationary [change of variables](change-of-variables-formula.md): if $y-y_0=bz^2+O(z^4)$ with $b>0$ and a smooth nonzero [probability density](probability-density.md) for $z$ at zero, the two inverse branches give a [probability density](probability-density.md) for $y$ proportional to $(y-y_0)^{-1/2}$.
