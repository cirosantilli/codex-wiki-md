# Radiation boundary condition for linearized gravity

↑ **Parent:** [Linearized Einstein equations](linearized-einstein-equations.md)

The retarded source solution of the [Linearized Einstein equations](linearized-einstein-equations.md) is selected by excluding added incoming or freely specified homogeneous [gravitational waves](gravitational-wave.md). A homogeneous wave can satisfy [Lorenz gauge in linearized gravity](lorenz-gauge-in-linearized-gravity.md) while having no source [mass quadrupole moment](mass-quadrupole-moment.md). Thus a formula for the retarded source field is not an identity for every solution of the sourced wave equation.
