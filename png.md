# PNG

↑ **Parent:** [Image compression](image-compression.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/PNG)

[PNG](png.md) is a [file format](file-format.md) for [raster images](raster-graphics.md) with [lossless source coding](lossless-source-coding.md) of the encoded image data. Its first W3C Recommendation, dated 1 October 1996, described a portable replacement for earlier image formats; this situates the design in exchanging images reliably between systems.[W3C, PNG (Portable Network Graphics) Specification, 1 October 1996, status and abstract](https://www.w3.org/TR/REC-png-961001)
