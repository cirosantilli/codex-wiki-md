# Box norm singular-value identity

↑ **Parent:** [Box norm](box-norm.md)

For a [real-valued function](real-valued-function.md) $H$ on a nonempty finite [Cartesian product](cartesian-product.md), let $T_Hv(x)=\mathbb E_yH(x,y)v(y)$ with uniform [inner products](inner-product.md). The [box norm](box-norm.md) obeys $\|H\|_\square^4=\operatorname{Tr}((T_HT_H^*)^2)=\sum_j\sigma_j^4$, where $\sigma_j$ are its [singular values](singular-value.md). For a [biregular graph](biregular-graph.md) this separates the constant component $\gamma^4$ from the other fourth powers.
