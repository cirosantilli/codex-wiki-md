# Temporal order memory

↑ **Parent:** [Memory in animals](memory-in-animals.md)

Retention of the relative order of events. It need not involve knowing a calendar date or measuring elapsed duration. Tests should distinguish an ordered relation from judgments based only on the recency or strength of individual item traces.
