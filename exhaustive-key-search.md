# Exhaustive key search

↑ **Parent:** [Cryptography](cryptography.md)

Trying candidate keys and testing them against known [plaintext](plaintext.md)–[ciphertext](ciphertext.md) pairs or another available verification condition. A uniformly selected key in a space of size $2^m$ appears at average position $(2^m+1)/2$ in a fixed enumeration.
