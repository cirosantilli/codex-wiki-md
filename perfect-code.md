# Perfect code

↑ **Parent:** [Binary block code](binary-block-code.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Perfect_code)

A code of minimum distance $d$ is perfect if its [Hamming balls](hamming-ball.md) of radius $\lfloor(d-1)/2\rfloor$ partition the ambient word space. Every word then has a unique nearest codeword within the code's error-correction radius.
