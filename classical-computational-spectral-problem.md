# Classical computational spectral problem

↑ **Parent:** [Solvability complexity index](solvability-complexity-index.md)

The classical computational spectral problem takes $\Omega=\mathcal B(\ell^2(\mathbb N))$, reads the matrix entries $\langle Ae_j,e_i\rangle$, and asks for $\operatorname{Sp}(A)$ in the [Hausdorff distance](hausdorff-distance.md) or [Attouch--Wets topology](attouch-wets-topology.md). Its [Solvability complexity index](solvability-complexity-index.md) is three for general bounded operators.
