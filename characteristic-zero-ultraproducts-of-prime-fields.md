# Characteristic-zero ultraproducts of prime fields

↑ **Parent:** [Ultraproduct](ultraproduct.md)

For a [nonprincipal ultrafilter](nonprincipal-ultrafilter.md) on the primes, the [ultraproduct](ultraproduct.md) of the prime fields $\mathbb F_p$ is a field of characteristic zero. Each fixed sentence $n\cdot1\ne0$, $n\geq1$, fails at only finitely many prime divisors of $n$; its cofinite truth set belongs to the ultrafilter, so [Łoś theorem](los-theorem.md) transfers it to the product. Every sentence eventually true in the prime fields also transfers. However, the sentence asserting that minus one is a square splits along the two infinite prime classes modulo four. Ultrafilters concentrating on these two classes yield different characteristic-zero fields satisfying the same eventual-truth theory, showing that this common theory is incomplete.
