# Primitive of a holomorphic function on a simply connected domain

↑ **Parent:** [Simply connected domain](simply-connected-domain.md)

Every [holomorphic function](holomorphic-function.md) $f$ on a [simply connected domain](simply-connected-domain.md) has a single-valued [antiderivative](antiderivative.md). Fixing $z_0$ and setting

$$
F(z)=\int_{z_0}^z f(t)\,dt
$$

gives a path-independent function with $F'=f$, because the [Cauchy integral theorem](cauchy-s-integral-theorem.md) makes the integral around every closed path zero.
