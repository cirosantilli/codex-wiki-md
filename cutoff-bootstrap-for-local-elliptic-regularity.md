# Cutoff bootstrap for local elliptic regularity

↑ **Parent:** [Elliptic regularity](elliptic-regularity.md)

For a constant-coefficient [elliptic differential operator](elliptic-differential-operator.md) $P(D)$ of order $N\geq1$, localizing the equation gives $P(D)(\chi u)=\chi P(D)u+[P(D),\chi]u$. The [commutator](commutator.md) has order at most $N-1$, so a global [Fourier transform](fourier-transform.md) estimate raises the known [Local Sobolev space](local-sobolev-space.md) index by one until the forcing index plus $N$ is reached.
