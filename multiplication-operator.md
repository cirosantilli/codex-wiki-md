# Multiplication operator

↑ **Parent:** [Linear operator](linear-operator.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multiplication_operator)

For a finite almost-everywhere measurable function $f$, the multiplication operator on [L2 space](l2-space-is-a-hilbert-space.md) has maximal [operator domain](operator-domain.md) $D(M_f)=\{u\in L^2:fu\in L^2\}$. It is a [closed operator](closed-linear-operator.md): if $u_n\to u$ and $fu_n\to v$ in [L2 space](l2-space-is-a-hilbert-space.md), subsequences converge almost everywhere, giving $v=fu$. Its domain is dense, since truncating a function to the sets $|f|\leq n$ approximates it in [L2 space](l2-space-is-a-hilbert-space.md). If $f$ is bounded, this is a bounded [linear operator](linear-operator.md) of norm equal to the essential supremum of $|f|$.
