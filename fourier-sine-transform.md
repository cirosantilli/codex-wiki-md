# Fourier sine transform

↑ **Parent:** [Fourier transform](fourier-transform.md)

The Fourier sine transform is a half-line transform adapted to a homogeneous [Dirichlet boundary condition](dirichlet-boundary-condition.md). With the displayed normalization, inversion is $f(x)=(2/\pi)\int_0^\infty\sin(kx)S(k)dk$. It is equivalent to the [Fourier transform](fourier-transform.md) of an odd extension. If $f(0)=0$ and boundary terms vanish, two [integrations by parts](integration-by-parts.md) give the transform of $f''$ as $-k^2S(k)$.
