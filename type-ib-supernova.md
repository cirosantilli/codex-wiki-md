# Type Ib supernova

↑ **Parent:** [Core-collapse supernova](core-collapse-supernova.md)

A [type Ib supernova](type-ib-supernova.md) is a stripped-envelope event with no strong [hydrogen](hydrogen.md) lines but identifiable helium features. The hydrogen-poor spectrum does not make it a thermonuclear Type Ia event.
