# Separating subspace of an algebraic dual

↑ **Parent:** [Dual space](dual-space.md)

A [linear subspace](vector-subspace.md) $W\subseteq X^*$ is separating if every nonzero $x\in X$ has $T(x)\ne0$ for some $T\in W$. For finite-dimensional $X$, an evaluation map $X\to F^{\dim W}$ is [injective](injective-function.md), so the [rank-nullity theorem](rank-nullity-theorem.md) forces $\dim W\geq\dim X=\dim X^*$ and $W=X^*$. For the infinite-dimensional [polynomial](polynomial-split.md) space, the span of its coefficient functionals is a proper separating [linear subspace](vector-subspace.md) of the [dual space](dual-space.md), which contains all sequences of coefficients, not just finitely supported ones.
