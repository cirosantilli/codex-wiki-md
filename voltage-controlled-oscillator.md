# Voltage-controlled oscillator

↑ **Parent:** [Electrical engineering](electrical-engineering-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Voltage-controlled_oscillator)

An [oscillator](oscillator.md) whose [frequency](frequency.md) is adjusted by an input [electric potential difference](electric-potential-difference.md). An approximately linear control characteristic provides a model for [frequency modulation](frequency-modulation.md).
