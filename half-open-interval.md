# Half-open interval

↑ **Parent:** [Interval (mathematics)](interval-mathematics.md)

An [interval](interval-mathematics.md) that includes exactly one endpoint, such as $[a,b)=\{x:a\leq x<b\}$. Adjacent [half-open intervals](half-open-interval.md) $[a,b)$ and $[b,c)$ are disjoint while covering $[a,c)$, which is useful for representing adjoining occupied cells without treating shared boundaries as overlaps.
