# Barrier digital put

↑ **Parent:** [Binary option](binary-option.md)

A [contingent claim](contingent-claim.md) paying one at maturity if a specified price path has remained below an upper barrier, and zero otherwise. This survival payoff differs from a terminal [digital put option](digital-put-option.md), which tests only the terminal price. In the dividend-free [Black-Scholes model](black-scholes-model.md), its value is the [discount factor](discount-factor.md) times the [risk-neutral probability](risk-neutral-probability.md) of avoiding the barrier, obtainable from the [linear-boundary Brownian first-passage distribution](linear-boundary-brownian-first-passage-distribution.md).
