# Space of continuous compactly supported functions

↑ **Parent:** [Function space](function-space.md)

For a locally compact Hausdorff space $X$, $C_c(X)$ consists of continuous functions whose [support](support.md) is compact. A [positive linear functional](positive-linear-functional.md) on this space, bounded on each fixed compact support, is represented by a [Radon measure](radon-measure.md). For a locally compact group with [Haar measure](haar-measure.md), these functions are dense in $L^p$ for $1\leq p<\infty$.
