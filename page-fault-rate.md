# Page fault rate

↑ **Parent:** [Page fault](page-fault.md)

For a specified interval of [memory references](memory-reference.md), the number causing a [page fault](page-fault.md) divided by the total number of [memory references](memory-reference.md). In the nonresident-only toy model in [memory thrashing](thrashing-computer-science.md), this equals the miss fraction used as [probability](probability.md) $p$ in the [expected value](expected-value-split.md) calculation. Startup and later intervals can have very different [page fault rates](page-fault-rate.md).
