# Current bottleneck in an inhomogeneous condensate

↑ **Parent:** [Superfluid velocity](superfluid-velocity.md)

Stationary one-dimensional flow has constant particle current $j=\rho v$. A lower-density segment must flow faster at the same current and also has smaller local [speed of sound](speed-of-sound.md) $\sqrt{g\rho/m}$. It can therefore lose local [phonon](phonon.md) energetic stability before a denser segment.
