# Fixed coordinate subspace

↑ **Parent:** [Vector subspace](vector-subspace.md)

The [fixed coordinate subspace](fixed-coordinate-subspace.md) of dimension $k$ in $\mathbb R^p$ consists of vectors whose coordinates after the first $k$ vanish. Restricting a [quadratic form](quadratic-form.md) to it uses only the leading $k$ by $k$ matrix block. It specifies one fixed support; allowing every support of size $k$ would introduce another combinatorial counting step.
