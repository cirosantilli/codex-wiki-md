# Measured output

↑ **Parent:** [Output (control theory)](output-control-theory.md)

The [measured output](measured-output.md) is the information about the [plant output](output-control-theory.md) available to the [controller](controller-control-theory.md). It may differ from the actual [plant output](output-control-theory.md) because of [measurement noise](measurement-noise.md) or [feedback delay](feedback-delay.md). In the ideal examples $y_m=y=x$, so the [controller](controller-control-theory.md) observes the actual current state exactly.
