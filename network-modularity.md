# Network modularity

↑ **Parent:** [Graph theory](graph-theory-split.md)

[Network modularity](network-modularity.md) measures excess within-community edge weight relative to a [network null model](network-null-model.md) based on [degrees of vertices](degree-graph-theory.md). For an undirected unweighted [graph](graph-split.md), its standard form is $Q=(2m)^{-1}\sum_{ij}(A_{ij}-k_ik_j/(2m))\mathbf1\{c_i=c_j\}$. A single community containing every [vertex](vertex-graph-theory.md) has $Q=0$; a partition with more internal connectivity than expected can have positive $Q$.
