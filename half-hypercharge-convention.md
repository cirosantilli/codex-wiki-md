# Half-hypercharge convention

↑ **Parent:** [Flavor hypercharge](flavor-hypercharge.md)

Some formulas write $Q=I_3+Y$ rather than $Q=I_3+Y_{\rm usual}/2$. Then $Y=(B+S)/2$, where $B$ is [baryon number](baryon-number.md) and $S$ is [strangeness](strangeness.md). The light-quark weights are $u:(1/2,1/6)$, $d:(-1/2,1/6)$, $s:(0,-1/3)$. Baryon weight rows therefore have half the usual vertical coordinates. This is a flavour convention, distinct from [weak hypercharge](hypercharge.md).
