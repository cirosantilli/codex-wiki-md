# Group of exponent two is abelian

↑ **Parent:** [Group](group-split.md)

If every element of a [group](group-split.md) squares to the identity, every element equals its inverse. Then $ab=(ab)^{-1}=b^{-1}a^{-1}=ba$, so the [group](group-split.md) is an [abelian group](abelian-group.md). The argument does not require a finite group.
