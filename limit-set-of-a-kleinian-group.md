# Limit set of a Kleinian group

↑ **Parent:** [Kleinian group](kleinian-group.md)

For a discrete isometry group of [hyperbolic space](hyperbolic-space.md), its limit set is the boundary accumulation set of one interior orbit. All interior base points give the same set: corresponding orbit points stay a fixed hyperbolic distance apart, and bounded-distance sequences approaching the boundary have the same endpoint. This definition does not require finite generation.
