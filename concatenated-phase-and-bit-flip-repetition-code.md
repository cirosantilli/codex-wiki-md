# Concatenated phase-and-bit-flip repetition code

↑ **Parent:** [Stabilizer code](stabilizer-code.md)

Replacing every qubit of an $n$-qubit [phase-flip repetition code](phase-flip-repetition-code.md) by an $m$-qubit [bit-flip repetition code](bit-flip-repetition-code.md) gives a code with logical $Z$- and $X$-operator weights $m$ and $n$, respectively, and hence distance $\min(m,n)$.
