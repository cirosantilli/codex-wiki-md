# Hormone response element

↑ **Parent:** [Cis-regulatory element](cis-regulatory-element.md)

A [DNA](deoxyribonucleic-acid.md) sequence recognized by an activated hormone-regulated [transcription factor](transcription-factor.md). It connects ligand-dependent regulator activity to a particular target [gene](gene.md).
