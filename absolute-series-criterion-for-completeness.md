# Absolute-series criterion for completeness

↑ **Parent:** [Banach space](banach-space-split.md)

A [normed vector space](normed-vector-space-split.md) is a [Banach space](banach-space-split.md) exactly when every absolutely convergent [series](series-mathematics.md) converges in the space. Completeness implies the assertion because the [triangle inequality](triangle-inequality.md) makes the partial sums a [Cauchy sequence](cauchy-sequence.md). Conversely, select from any [Cauchy sequence](cauchy-sequence.md) a subsequence whose consecutive differences have [norm](norm.md) at most $2^{-k}$. The [series](series-mathematics.md) of these differences converges by hypothesis, so the subsequence converges. The original [Cauchy sequence](cauchy-sequence.md) then has the same limit. This provides a useful way to demonstrate incompleteness by a summable-norm [series](series-mathematics.md) whose candidate sum lies outside the space.
