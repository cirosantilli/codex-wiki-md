# Photogravitational restricted three-body problem

↑ **Parent:** [Circular restricted three-body problem](circular-restricted-three-body-problem.md)

The photogravitational restricted three-body problem adds radial [radiation pressure](radiation-pressure.md) from one or both luminous primaries. If the pressure-to-gravity ratio of primary $i$ is $\beta_i$, its effective attraction on the test particle is multiplied by $1-\beta_i$.
