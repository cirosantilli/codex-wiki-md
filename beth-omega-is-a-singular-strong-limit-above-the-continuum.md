# Beth omega is a singular strong limit above the continuum

↑ **Parent:** [Beth number](beth-number.md)

The [Beth numbers](beth-number.md) $\beth_0=\aleph_0$, $\beth_{n+1}=2^{\beth_n}$ form a strictly increasing countable sequence by [Cantor's theorem](cantor-s-theorem.md). Their supremum $\beth_\omega$ has [cofinality](cofinality.md) $\omega$ because no finite subset is cofinal. It exceeds $2^{\aleph_0}=\beth_1$. It is also a [strong limit cardinal](strong-limit-cardinal.md): if $\rho<\beth_\omega$, some $n$ has $\rho<\beth_n$, so $2^\rho\leq\beth_{n+1}<\beth_\omega$. Thus the [singular cardinal](singular-cardinal.md) example needs no [Continuum hypothesis](continuum-hypothesis.md).
