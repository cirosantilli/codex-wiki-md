# One-dimensional total variation denoising

↑ **Parent:** [Fused Lasso](fused-lasso.md)

This version of the [fused Lasso](fused-lasso.md) penalizes only adjacent differences. It estimates a piecewise-constant signal while preserving an unpenalized constant level. Larger penalties generally favour fewer fitted changes.
