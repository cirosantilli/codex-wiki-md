# Dry adiabat

↑ **Parent:** [Adiabatic process](adiabatic-process.md)

For an [ideal gas](ideal-gas-split.md) of constant specific heat, an isentrope without phase changes satisfies $T=T_0(p/p_0)^{R_a/c_p}$. A dilute saturated atmosphere approximates this path only when both vapour sensible heat and latent-heating corrections are small.
