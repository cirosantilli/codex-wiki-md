# Gravity-current box model

↑ **Parent:** [Gravity current](gravity-current.md)

A gravity-current box model replaces the current by a well-mixed region with uniform depth and density. Integral volume, scalar, and front-speed balances then reduce the spreading problem to [ordinary differential equations](ordinary-differential-equation.md).
