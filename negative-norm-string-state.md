# Negative-norm string state

↑ **Parent:** [Covariant quantization of the bosonic string](covariant-quantization-of-the-bosonic-string.md)

Time-coordinate oscillators produce negative norms in the covariant indefinite [Fock space](fock-space.md). A physical negative-norm state would violate probabilistic unitarity. Such ghosts differ from the anticommuting [worldsheet ghost fields](worldsheet-ghost-field.md) introduced by [gauge fixing](gauge-fixing.md).
