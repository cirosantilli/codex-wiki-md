# Regularization of an inverse problem

↑ **Parent:** [Inverse problem](inverse-problem-split.md)

A regularization is a family of continuous maps $R_\alpha$ such that $R_\alpha f\to A^\dagger f$ as $\alpha\downarrow0$ for every datum in the domain of the [Moore–Penrose inverse of an operator](moore-penrose-inverse-of-an-operator.md). A linear regularization uses bounded [linear operators](linear-operator.md); nonlinear [variational regularization](variational-regularization.md) can use nonquadratic penalties. A parameter rule that also ensures stability as the data noise tends to zero makes it a [convergent regularization of an inverse problem](convergent-regularization-of-an-inverse-problem.md).
