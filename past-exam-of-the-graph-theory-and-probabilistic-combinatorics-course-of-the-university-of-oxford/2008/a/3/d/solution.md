<h1 id="a/3/d/solution">Solution</h1>

↑ **Parent:** [D](../d.md)

Assume the usual nontrivial case $\chi(G)\ge2$ and $|H|\ge2$. On $(\chi(G)-1)(|H|-1)$ vertices partition into $\chi(G)-1$ equal classes of size $|H|-1$. Color all edges between distinct classes red and all edges within a class blue. The red [graph](../../../../../graph-split.md) is $(\chi(G)-1)$-colorable, so it contains no copy of $G$. Every blue [connected](../../../../../connected-space.md) component has only $|H|-1$ vertices, so [connectedness](../../../../../connected-space.md) prevents a blue copy of $H$. Therefore one more vertex is necessary:

$$
\boxed{R(G,H)\ge(\chi(G)-1)(|H|-1)+1}.
$$

If $G$ is edgeless or $H$ has one vertex, the displayed lower bound is just one and holds directly.
