# Code smell

↑ **Parent:** [Refactoring](refactoring.md)

An observable feature of source code suggesting a possible underlying design problem. It prompts investigation rather than proving a defect. [Duplicate code](duplicate-code.md), [feature envy](feature-envy.md) and a [long method](long-method.md) suggest potential transformations, and context can justify leaving an apparent smell unchanged.[Definition and warning that smells are not automatically bad](code-smell-by-martin-fowler.md)
