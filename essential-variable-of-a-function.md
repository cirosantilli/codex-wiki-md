# Essential variable of a function

↑ **Parent:** [Function](function-split.md)

A coordinate of a [function](function-split.md) on a finite [Cartesian product](cartesian-product.md) is essential if changing that coordinate, with all the others fixed suitably, can change the output. A coordinate is inessential precisely when such a change never affects the output in any context. If only coordinate $i$ is essential, changing the other coordinates one at a time proves that the output is $g(x_i)$ for a nonconstant unary [function](function-split.md) $g$. This deterministic dependence definition is not by itself a probabilistic or experimental notion of [causal inference](causal-inference-split.md).
