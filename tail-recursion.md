# Tail recursion

↑ **Parent:** [Recursion (computer science)](recursion-computer-science.md)

[Recursion](recursion-computer-science.md) in which the recursive call is the last operation required to obtain the current call's result. An accumulator can encode the state that would otherwise be updated by a loop. A suitable [compiler](compiler.md) can replace the call by a jump, avoiding growing [call stack](call-stack.md) storage. In [Scala](scala.md), a tail-recursion annotation requests a check that the recursive method is eligible for this transformation.
