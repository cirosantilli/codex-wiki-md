# Phase-insensitive unitary gate error

↑ **Parent:** [Quantum optimal control](quantum-optimal-control.md)

The [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) for the [Hilbert-Schmidt inner product](hilbert-schmidt-inner-product.md) gives $0\leq J\leq1$ for $n$-dimensional [unitary operators](unitary-operator.md). Equality $J=0$ holds exactly when $U=e^{i\phi}U_T$. When absolute gate phase matters, use the phase-sensitive [Hilbert-Schmidt distance](hilbert-schmidt-distance.md) $\|U-U_T\|^2/(2n)=1-\operatorname{Re}\operatorname{Tr}(U_T^\dagger U)/n$ instead.
