# Poisson mapping theorem

↑ **Parent:** [Poisson point process](poisson-point-process.md)

For a [measurable](measurability.md) map $f$ and a [Poisson random measure](poisson-random-measure.md) of intensity $\nu$, image counts in disjoint sets equal original counts in their disjoint preimages. They are therefore [independent](independent-random-variables.md) Poisson variables with the pushforward intensity. The result is a [Poisson random measure](poisson-random-measure.md) even if images collide; diffuse pushforward intensity gives a simple point process.
