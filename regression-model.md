# Regression model

↑ **Parent:** [Statistical model](statistical-model-split.md)

A regression model specifies features of the [conditional distribution](conditional-distribution.md) of a response given predictor [covariates](covariate.md), often a conditional mean or a full parametric density. [Linear regression](linear-regression-split.md) specifies a linear conditional mean; [logistic regression](logistic-regression.md) specifies a logit-linear conditional probability for a binary response. The conditional comparison represented by a coefficient depends on which covariates are included.
