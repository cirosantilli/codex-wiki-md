# First-order variable assignment

↑ **Parent:** [First-order logic](first-order-logic.md)

For a [first-order structure](first-order-structure.md) with domain $A$, an assignment maps every individual variable to an element of $A$. It extends recursively to [first-order terms](first-order-term.md) using the interpreted functions. To evaluate $\forall x\varphi$, vary only the value of $x$ over $A$, holding the other values fixed. The [truth value](truth-value.md) of a [first-order formula](first-order-formula.md) depends only on its [free variables](free-variable.md); a [first-order sentence](first-order-sentence.md) is therefore independent of the assignment.
