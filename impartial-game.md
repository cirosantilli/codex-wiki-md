# Impartial game

↑ **Parent:** [Game theory](game-theory-split.md)

An impartial game is a [game](game.md) in which both players have the same legal moves from any given position. Under the [normal-play convention](normal-play-convention.md), a player with no legal move loses. For finite games without draws, [Grundy numbers](grundy-number.md) encode positions for the [Sprague-Grundy theorem](sprague-grundy-theorem.md).
