# Astronomical selection function

↑ **Parent:** [Observational astronomy](observational-astronomy.md)

An [astronomical selection function](astronomical-selection-function.md) specifies the probability that an object or its measured data enter a catalogue. It can depend on sky position, flux, colour, angular extent, time sampling and follow-up success. A generative calculation combines the parent population, instrument response, measurement noise and inclusion rule. A selection cut on latent properties must be propagated through the measurement [likelihood](likelihood-function.md) rather than substituted for a cut on observed quantities.
