# Pair of partitions for a generalized Specht module

↑ **Parent:** [Generalized Specht module](generalized-specht-module.md)

The first component is a proper partition marking an initial segment of each row of the second component. The second component may be a composition rather than a decreasing partition. This convention specifies a [generalized Specht module](generalized-specht-module.md) and differs from specifying a [skew shape](skew-young-diagram.md) by two nested proper partitions.
