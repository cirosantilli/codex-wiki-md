# Regression analysis

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Regression_analysis)

Regression analysis studies how a [response variable](response-variable.md) depends on explanatory variables through a [regression model](regression-model.md). It estimates that dependence and assesses uncertainty in fitted [regression coefficients](regression-coefficient.md), predictions and model comparisons. [Linear regression](linear-regression-split.md) is one important case.
