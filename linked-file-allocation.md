# Linked file allocation

↑ **Parent:** [File system](file-system-split.md)

A [file system](file-system-split.md) organization in which each [file data block](file-data-block.md) identifies its successor. It supports sequential traversal and growth without a fixed per-file index tree, but arbitrary [file offsets](file-offset.md) require following the chain. Adding predecessor links permits reverse traversal.
