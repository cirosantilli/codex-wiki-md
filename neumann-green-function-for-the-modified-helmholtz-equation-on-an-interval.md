# Neumann Green function for the modified Helmholtz equation on an interval

↑ **Parent:** [Neumann Green function for a second-order ordinary differential equation](neumann-green-function-for-a-second-order-ordinary-differential-equation.md)

For real $\kappa\ne0$, this [Green function](green-s-function-split.md) inverts $d^2/dx^2-\kappa^2$ on $[0,1]$ with homogeneous [Neumann boundary conditions](neumann-boundary-condition.md). It is continuous and its first [derivative](derivative.md) has jump one at $x=\xi$. At $\kappa=0$, a Green function with the same unit [Dirac delta](dirac-delta-function.md) source and zero boundary derivatives does not exist: integrating its defining equation would give zero equal to one. The equation $y''=f$ with these boundary conditions instead requires $\int_0^1f(x)\,dx=0$ and determines $y$ only up to a constant.
