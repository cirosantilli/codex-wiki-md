# Geometric intersection number

↑ **Parent:** [Mapping class group](mapping-class-group.md)

The geometric intersection number $i(\alpha,\beta)$ is the minimum number of transverse intersection points among representatives of the isotopy classes of $\alpha$ and $\beta$. Representatives in [minimal position](minimal-position-of-curves-or-arcs.md) realize it.
