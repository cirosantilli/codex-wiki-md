# Metric geodesic

↑ **Parent:** [Geodesic metric space](geodesic-metric-space.md)

A unit-speed metric geodesic in a [metric space](metric-space.md) is an [isometric embedding](isometric-embedding.md) $\gamma:I\to X$ of a [real interval](interval-mathematics.md). Every restricted segment realizes the distance between its endpoints. A one-point interval permits a constant segment. In a unit-edge graph, shortest edge paths parametrized by [metric path length](metric-path-length.md) are metric geodesics; no smooth structure is required. This is stronger than the differential definition of a [geodesic](geodesic.md) in a [Riemannian manifold](riemannian-manifold.md), which need only minimize locally: on a unit circle, an arc of angle $3\pi/2$ is a Riemannian geodesic but its endpoint distance is only $\pi/2$.
