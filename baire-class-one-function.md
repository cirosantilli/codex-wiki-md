# Baire class one function

↑ **Parent:** [Baire function](baire-function.md)

A Baire class one function is a pointwise limit of [continuous functions](continuous-function.md). On a complete metric domain, its set of discontinuities is meagre; in particular, it has a point of continuity on every nonempty perfect closed subset.
