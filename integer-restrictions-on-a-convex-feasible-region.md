# Integer restrictions on a convex feasible region

↑ **Parent:** [Convex feasible region for a resource budget](convex-feasible-region-for-a-resource-budget.md)

If the amounts in the budget example must be [integers](integer.md), the actual [feasible region](feasible-region.md) is $C\cap\mathbb Z^2$. Both $(0,0)$ and $(1,0)$ are feasible, but their [midpoint](midpoint.md) $(1/2,0)$ is not. Thus the continuous [feasible region](feasible-region.md) is a convex set while the integer-restricted choices are not. Averaging two manufacturing plans may specify half an indivisible item. [Integer programming](integer-programming.md) must respect that restriction; using the surrounding convex set is a relaxation, not a proof that its averages are admissible integer plans.
