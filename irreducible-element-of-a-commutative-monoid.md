# Irreducible element of a commutative monoid

↑ **Parent:** [Cancellative commutative monoid](cancellative-commutative-monoid.md)

A nonunit element of a [commutative monoid](commutative-monoid.md) is irreducible if each factorization has a unit factor. In a submonoid of the positive integers under multiplication, the only unit is one. Irreducibility is relative to the allowed factors: a composite integer can be irreducible in a smaller monoid even though it is not a [prime number](prime-number.md).
