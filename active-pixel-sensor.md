# Active-pixel sensor

↑ **Parent:** [Photodetector](photodetector.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Active-pixel_sensor)

An image sensor with active circuitry at its [optical detector pixels](optical-detector-pixel.md) to buffer or amplify collected signals. [CMOS](cmos.md) implementations can select pixel signals without transporting every charge packet through the entire image.
