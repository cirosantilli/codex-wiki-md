# Lipschitz gradient

↑ **Parent:** [Gradient descent](gradient-descent.md)

A differentiable function has a $\beta$-Lipschitz gradient when

$$
\|\nabla f(x)-\nabla f(y)\|\leq\beta\|x-y\|.
$$
