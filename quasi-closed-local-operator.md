# Quasi-closed local operator

↑ **Parent:** [Lawvere-Tierney topology](lawvere-tierney-topology.md)

For a subterminal truth value $u$, the quasi-closed local operator is relative double negation $q(U)(p)=((p\Rightarrow u)\Rightarrow u)$. It has bottom value $q(U)(0)=u$. Its fixed truth values are Boolean with relative bottom $u$, inherited meet, join closed by $q(U)$ and complement $p\Rightarrow u$. Therefore its sheaf topos is a [Boolean topos](boolean-topos.md).
