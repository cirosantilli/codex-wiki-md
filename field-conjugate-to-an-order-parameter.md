# Field conjugate to an order parameter

↑ **Parent:** [Order parameter](order-parameter.md)

A field conjugate to a scalar [order parameter](order-parameter.md) $m$ contributes $-hm$ to its [free-energy density](free-energy-density.md). Differentiating the equilibrium [free energy](thermodynamic-free-energy.md) with respect to $h$ gives $-m$, with density or extensive normalization stated consistently. In a ferromagnet the [conjugate field](field-conjugate-to-an-order-parameter.md) is magnetic; for a fluid-density [order parameter](order-parameter.md) it is related to a chemical-potential difference. It can explicitly break the symmetry whose spontaneous breaking defines the ordered phase.
