# Static predicate

↑ **Parent:** [STRIPS](strips.md)

A predicate whose ground facts are unchanged by every action in a [planning](planning.md) model. Object types and a fixed adjacency relation are common examples. Static conditions can filter [ground actions](ground-action.md) before search; they need not acquire a separate truth [variable](variable-mathematics.md) at every time layer. A [planning fluent](planning-fluent.md) can instead be added or deleted by actions.
