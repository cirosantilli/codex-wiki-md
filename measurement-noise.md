# Measurement noise

↑ **Parent:** [Measurement error](measurement-error.md)

[Measurement noise](measurement-noise.md) is a fluctuating contribution to [measurement error](measurement-error.md). An additive model for a [measured output](measured-output.md) is $y_m(t)=y(t)+n(t)$, where $y$ is the actual [plant output](output-control-theory.md). A [controller](controller-control-theory.md) using [feedback control](closed-loop-control.md) can react to $n$ as though it were a change in the [plant output](output-control-theory.md). This effect is absent from the ideal noiseless examples under [control theory](control-theory-split.md); an [errors-in-variables model](errors-in-variables-model.md) represents a related distinction between latent quantities and their noisy observations.
