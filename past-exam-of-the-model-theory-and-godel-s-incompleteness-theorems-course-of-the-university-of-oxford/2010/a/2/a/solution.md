<h1 id="a/2/a/solution">Solution</h1>

↑ **Parent:** [A](../a.md)

Write $\operatorname{Prf}(n,m)$ for the specified proof relation and $R(n)$ for its [Rosser provability predicate](../../../../../rosser-provability-predicate.md). If $R(\overline n)$ is true in the standard [natural numbers](../../../../../natural-number.md), its existential witness $m$ is the code of an actual proof of the expression with code $n$. Thus that expression is provable.

Conversely, suppose an actual proof has code $m$. If [Peano arithmetic](../../../../../peano-arithmetic.md) is consistent, there is no proof of the [negation](../../../../../negation.md) at all, in particular none with code at most $m$. The same $m$ therefore witnesses the bounded proof-order condition as well as the positive proof condition. Hence

$$
\boxed{\mathbb N\models R(\overline n)\ \Longleftrightarrow\ PA\vdash E_n}
$$

under consistency. For numbers that do not code well-formed expressions, neither side holds under the usual proof coding. This is an external equivalence of theoremhood; it does not establish every internal [derivability conditions](../../../../../hilbert-bernays-lob-derivability-conditions.md) for $R$.
