<h1 id="b/5/a/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

An [atomic model](../../../../../../atomic-model.md) is a model in which every finite tuple realizes an isolated [complete type](../../../../../../complete-type.md) over the empty set. For a [complete theory](../../../../../../complete-theory.md) in a [countable](../../../../../../countable-set.md) language, every [countable](../../../../../../countable-set.md) atomic model is prime. The underlying argument is a [back-and-forth method](../../../../../../back-and-forth-method.md) in the one-sided form needed for an embedding: enumerate the atomic model, and extend a finite partial elementary map one element at a time using an isolating formula for the enlarged tuple. The target model has the required witness because the already matched tuple has the same [complete type](../../../../../../complete-type.md).

Thus property (iii) implies property (iv). It need not imply pointwise definability or term-generation. The [countable](../../../../../../countable-set.md) [dense linear order without endpoints](../../../../../../dense-linear-order-without-endpoints.md) with a single named point, for example $(\mathbb Q,<,0)$, is atomic: [quantifier elimination for dense linear orders without endpoints](../../../../../../quantifier-elimination-for-dense-linear-orders-without-endpoints.md) isolates a tuple by its finite order-and-equality pattern relative to zero. But order [structure automorphisms](../../../../../../automorphism-of-a-first-order-structure.md) fixing zero move every nonzero rational. Such elements are not parameter-free definable, and no [closed term](../../../../../../closed-term.md) names them. This supplies the failed implications (iii)$\not\Rightarrow$(ii) and (iii)$\not\Rightarrow$(i).
