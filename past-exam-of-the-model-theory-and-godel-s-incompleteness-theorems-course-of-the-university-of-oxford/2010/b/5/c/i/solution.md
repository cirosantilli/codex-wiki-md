↑ **Parent:** [I](../i.md)

**Yes.** The pure order on the reals is a [dense linear order without endpoints](../../../../../../dense-linear-order-without-endpoints.md) and has [quantifier elimination for dense linear orders without endpoints](../../../../../../quantifier-elimination-for-dense-linear-orders-without-endpoints.md). Over a finite parameter set $a_1<\cdots<a_m$, a complete one-variable type either specifies equality to one of these points or specifies one of the open intervals and exterior rays they determine.

Each such interval or ray contains a real number. Hence every complete one-variable type over a finite parameter set is realized. The successive-coordinate characterization gives [saturation](../../../../../../homogeneity-plus-realization-of-empty-set-types-implies-saturation.md) for all finite tuples. This uses finite parameter sets; it does not say that arbitrary types over a countably [infinite set](../../../../../../infinite-set.md) of parameters are realized.
