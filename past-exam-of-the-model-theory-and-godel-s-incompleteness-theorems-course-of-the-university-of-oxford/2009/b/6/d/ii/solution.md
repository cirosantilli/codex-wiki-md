<h1 id="b/6/d/ii/solution">Solution</h1>

↑ **Parent:** [Ii](../ii.md)

**No infinite cardinal is categorical for this [theory](../../../../../../first-order-theory.md)**, as described by [no categorical cardinal for the complete named rational diagram](../../../../../../no-categorical-cardinal-for-the-complete-named-rational-diagram.md). For an arbitrary infinite $\kappa$, choose a dense linear order $I_\kappa$ without endpoints of size $\kappa$; for example the [lexicographic order](../../../../../../lexicographic-order.md) on $\kappa\times\mathbb Q$ works, since every rational block is dense and has no endpoints.

Construct one order by inserting $I_\kappa$ into a fixed irrational cut of the named rational order. Every element of this order is bounded above by some named rational. Construct a second order by putting an $I_\kappa$ tail above all named rationals, as the ordered sum $\mathbb Q+I_\kappa$. Both are dense linear orders without endpoints, both have [cardinality](../../../../../../cardinality.md) $\kappa$, and both contain the named rational copy as an [elementary substructure](../../../../../../elementary-substructure.md) by [quantifier elimination](../../../../../../quantifier-elimination.md). Hence both satisfy its [complete diagram](../../../../../../elementary-diagram-of-a-structure.md) $T$.

They are not isomorphic over the named constants: the second has an element greater than every named rational, and the first has none. This property need not be expressible by a single sentence in the infinite language to be an [isomorphism](../../../../../../structure-isomorphism.md) invariant. Finite cardinalities have no [models](../../../../../../model-of-a-first-order-theory.md) at all because the constants name infinitely many distinct [Elements](../../../../../../euclid-s-elements.md), so the existence clause excludes categoricity there too.
