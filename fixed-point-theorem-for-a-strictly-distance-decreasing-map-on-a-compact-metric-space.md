# Fixed point theorem for a strictly distance-decreasing map on a compact metric space

↑ **Parent:** [Metric space](metric-space.md)

Let $X$ be a nonempty [compact](compact-space.md) [metric space](metric-space.md) and let $f:X\to X$ satisfy $d(f(x),f(y))<d(x,y)$ whenever $x\neq y$. Then $f$ has exactly one [fixed point](fixed-point.md). The distance condition implies [continuity](continuous-function.md), and $x\mapsto d(f(x),x)$ attains a minimum by [compactness](compact-space.md). If a minimizer $p$ were not a [fixed point](fixed-point.md), then $d(f^2(p),f(p))<d(f(p),p)$ would contradict minimality. Two distinct [fixed points](fixed-point.md) would contradict the same strict distance inequality directly. A uniform [Lipschitz](lipschitz-continuity.md) constant below $1$ is unnecessary; [compactness](compact-space.md) replaces the quantitative hypothesis of the [contraction mapping theorem](contraction-mapping-theorem.md).
