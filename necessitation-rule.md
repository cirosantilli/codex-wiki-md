# Necessitation rule

↑ **Parent:** [Modal logic](modal-logic.md)

The [necessitation rule](necessitation-rule.md) permits boxing a theorem in a modal proof system. It does not permit boxing an arbitrary temporary assumption. Under an arithmetic interpretation, it uses the external first of the [derivability conditions](hilbert-bernays-lob-derivability-conditions.md): an actual proof of $A$ supplies a proof that $A$ has a proof. This distinction matters when proving the [Internal form of Löb's theorem](internal-form-of-lob-s-theorem.md).
