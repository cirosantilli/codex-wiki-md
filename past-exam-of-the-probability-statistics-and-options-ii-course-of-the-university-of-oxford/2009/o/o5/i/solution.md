↑ **Parent:** [I](../i.md)

For the specified parameter there is no fitted parameter, so the null reference has $10-1=9$ [degrees of freedom](../../../../../degree-of-freedom.md). The given deviance is $15.59$, below the supplied five-percent critical value $16.92$. Hence **do not reject the fixed log-series model at level five percent**. The parameter is fixed in this test, so subtracting an additional [degree of freedom](../../../../../degree-of-freedom.md) would be inappropriate.
