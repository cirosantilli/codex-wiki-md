# Projector phase rotation

↑ **Parent:** [Reflection operator](reflection-operator.md)

For an [orthogonal projection](orthogonal-projection.md), $P^k=P$ for $k\geq1$. Summing the exponential series proves the displayed identity. At $\theta=\pi$, the operator is $I-2P$, which changes the sign on the range and fixes its orthogonal complement. In [Grover search algorithm](grover-s-algorithm.md), the marked-state reflection and the uniform-state reflection compose to the search iterate up to an irrelevant [global phase](global-phase.md).
