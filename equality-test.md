# Equality test

↑ **Parent:** [Algorithm](algorithm-split.md)

A terminating check returning whether two values match under a specified relation. Mathematical equality is one such relation; a chosen [equivalence relation](equivalence-relation.md) can instead express matching keys. [Linear search](linear-search.md) only needs this check, whereas [binary search](binary-search.md) also uses relative order. The cost of an [equality test](equality-test.md) depends on the representation and implementation of its operands.
