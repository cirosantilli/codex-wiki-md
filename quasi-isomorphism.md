# Quasi-isomorphism

↑ **Parent:** [Chain map](chain-map.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quasi-isomorphism)

A [chain map](chain-map.md) inducing isomorphisms on all [homology groups](homology-group.md). The same definition applies to a map of [cochain complexes](cochain-complex.md) using [cohomology groups](cohomology-group.md). A quasi-isomorphism need not be an isomorphism in each degree.
