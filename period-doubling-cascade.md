# Period-doubling cascade

↑ **Parent:** [Period-doubling bifurcation](period-doubling-bifurcation.md)

A [period-doubling cascade](period-doubling-cascade.md) is a succession of [period-doubling bifurcations](period-doubling-bifurcation.md) creating attracting periods $1,2,4,8,\ldots$, with bifurcation parameters tending to an accumulation value. [Superstable periodic orbits](superstable-periodic-orbit.md) inside successive stability intervals give a second parameter sequence with the same limiting parameter-scaling ratio in a quadratic universality class.
