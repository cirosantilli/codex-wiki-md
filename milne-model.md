# Milne model

↑ **Parent:** [Friedmann-Lemaître-Robertson-Walker metric](friedmann-lemaitre-robertson-walker-metric.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Milne_model)

The Milne universe is the empty $k=-1$, $\Lambda=0$ FLRW model with scale factor proportional to proper time. It is a hyperbolic-coordinate description of the interior of a future light cone in [Minkowski spacetime](minkowski-spacetime.md).
