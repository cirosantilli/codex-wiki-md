# Eigenline

↑ **Parent:** [Eigenspace](eigenspace.md)

An eigenline is a one-dimensional [vector subspace](vector-subspace.md) spanned by an [eigenvector](eigenvector.md). If $Av=\lambda v$ with $v\ne0$, then $A(av)=\lambda av$ for every [scalar](scalar.md) $a$, so the line is an [invariant subspace](invariant-subspace.md). It can be contained in an [eigenspace](eigenspace.md) of larger [dimension](dimension-vector-space.md); an eigenline need not be the whole [eigenspace](eigenspace.md).
