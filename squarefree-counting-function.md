# Squarefree counting function

↑ **Parent:** [Square-free integer](square-free-integer.md)

The squarefree counting function is $Q(x)=\#\{n\le x:n\text{ is squarefree}\}$. The [Möbius function](mobius-function.md) gives $Q(x)=\sum_{d\le\sqrt{x}}\mu(d)\lfloor x/d^2\rfloor$, because $\sum_{d^2\mid n}\mu(d)$ is the indicator of a [square-free integer](square-free-integer.md).
