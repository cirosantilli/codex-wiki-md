# Odd function

↑ **Parent:** [Calculus](calculus-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Odd_function)

An odd function satisfies $f(-x)=-f(x)$; its [Laurent series](laurent-series.md) or [taylor series](taylor-series.md) contains only odd powers.
