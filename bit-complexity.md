# Bit complexity

↑ **Parent:** [Computational complexity theory](computational-complexity-theory.md)

The number of elementary operations on [bits](bit.md) required by an [algorithm](algorithm-split.md). Arithmetic-operation counts treat operations on entire [integers](integer-split.md) as units, whereas [bit complexity](bit-complexity.md) charges for the sizes of their operands. An [algorithm](algorithm-split.md) using few multiplications can therefore require substantially more bit operations when the operands grow. State the model when comparing bounds for [repeated squaring](exponentiation-by-squaring.md) or [dynamic programming](dynamic-programming.md) counts.
