# Overlap multiplicity bound for piecewise difference operators

↑ **Parent:** [Linear regularization](linear-regularization.md)

Suppose a piecewise [finite difference](finite-difference-split.md) uses two translated evaluations divided by $\alpha$. If the pulled-back evaluation intervals cover almost every input point at most $m$ times, then $|a-b|^2\leq2(|a|^2+|b|^2)$ gives $\|R_\alpha f\|_2^2\leq2m\|f\|_2^2/\alpha^2$. This converts an interval-overlap count into an [operator norm](operator-norm.md) estimate without requiring pointwise values of an [L2 space](l2-space-is-a-hilbert-space.md) equivalence class outside the almost-everywhere evaluation rule.
