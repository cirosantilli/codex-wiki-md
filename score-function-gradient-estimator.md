# Score-function gradient estimator

↑ **Parent:** [Informant function](informant-function.md)

For a parameter-independent integrand $h$, the displayed [score-function gradient estimator](score-function-gradient-estimator.md) follows by differentiating the sampling [probability density function](probability-density-function.md) or [probability mass function](probability-mass-function.md), using $\nabla q=q\nabla\log q$. It requires conditions permitting [differentiation under the integral sign](differentiation-under-the-integral-sign.md), or the corresponding sum, and control of support changes. It applies to discrete choices without pretending that their sampled values are differentiable paths. If $h=h_\lambda$, add $\mathbb E_{q_\lambda}[\nabla_\lambda h_\lambda]$.
