# Unit modulo n

↑ **Parent:** [Modular congruence](modular-congruence.md)

A residue class modulo $n$ is a unit exactly when it is represented by an integer coprime to $n$. The units form the multiplicative group $(\mathbb Z/n\mathbb Z)^\times$.
