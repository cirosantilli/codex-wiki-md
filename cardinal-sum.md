# Cardinal sum

↑ **Parent:** [Cardinal arithmetic](cardinal-arithmetic.md)

The cardinal sum is the [cardinality](cardinality.md) of the disjoint [union](set-union.md) of sets of the specified sizes. Using [initial ordinals](initial-ordinal.md), this is $|\{(i,\xi):i\in I,\ \xi<\kappa_i\}|$. The tags distinguish overlapping summands. The empty sum is zero.
