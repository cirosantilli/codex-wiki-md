# Cooper shell projection

↑ **Parent:** [Cooper problem](cooper-problem.md)

The pairing Hamiltonian is projected onto empty states in a specified shell above the inert [Fermi sea](fermi-sea.md). A state restricted to that shell is an eigenstate of this projected model, not necessarily of a contact interaction that remains unrestricted at all momenta.
