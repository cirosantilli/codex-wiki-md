# Partial atomic charge

↑ **Parent:** [Chemical bond](chemical-bond-split.md)

A partial atomic charge assigns an [electric charge](electric-charge-split.md) to a [chemical atom](atom-physics.md) by partitioning the actual [electron density](electron-density.md). The result depends on the partitioning convention and need not be an integer. It differs from [formal charge](formal-charge.md), which divides bonding [electrons](electron.md) equally in a specified [Lewis structure](lewis-structure.md).
