# Mathematical model

↑ **Parent:** [Mathematics](mathematics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Mathematical_model)

A mathematical model represents selected features of a system with mathematical objects and relations so that its behavior can be analyzed or predicted. Choosing the representation is part of the work: specify the quantities tracked, the equations or [probability distributions](probability-distribution-split.md) connecting them, and the conditions under which those connections are expected to apply. A [mathematical proof](mathematical-proof.md) can establish a consequence of the model; comparing that consequence with observations tests its suitability for the intended use.

For a [simple pendulum](simple-pendulum-split.md), the angle $\theta(t)$ and [gravitational acceleration](gravitational-acceleration.md) $g$ give the ideal equation $\ddot\theta+(g/\ell)\sin\theta=0$. Its assumptions include a point mass, fixed [length](length.md) $\ell$, uniform [gravitational acceleration](gravitational-acceleration.md), and no [damping](damping.md). The [small-angle approximation](small-angle-approximation.md) gives the simpler [harmonic oscillator equation](simple-harmonic-motion.md) and [oscillation period](period-of-an-oscillation.md) $T_0=2\pi\sqrt{\ell/g}$. A larger [amplitude](wave-amplitude.md) changes the full model's period; drag requires a [damped pendulum](damped-pendulum.md). The simpler model remains useful when its omitted effects are small for the question being asked.

A model need not track every detail. A [Bernoulli process](bernoulli-process.md) models repeated success/failure observations using one [probability](probability.md) and an independence assumption; a [Gaussian process](gaussian-process-split.md) specifies a [mean](expected-value-split.md) and a [covariance function](covariance-function.md) to model related measurements. Each representation enables calculations by retaining some distinctions and omitting others. Useful simplification therefore comes with a stated domain of use and quantities against which its predictions can be checked.
