# Vector measure

↑ **Parent:** [Measure theory](measure-theory-split.md)

A finite-dimensional [vector measure](vector-measure.md) has scalar [measures](measure.md) as components and a [total variation norm of a measure](total-variation-norm-of-a-measure.md) defined using their joint vector [norm](norm.md). Finite variation controls every pairing with a bounded continuous vector test. [Derivatives](derivative.md) in the [bounded-variation space](function-of-bounded-variation-on-a-domain.md) are examples.
