# Block confounding in a factorial design

↑ **Parent:** [Blocks in experimental design](blocks-in-experimental-design.md)

Partition a regular [factorial design](factorial-design.md) by fixed signs of independent [factorial contrasts](factorial-contrast.md). Products of those block-generating columns span the block effects. A treatment contrast that is constant on each block is therefore confounded with block differences. Select generators so that only scientifically dispensable treatment effects enter this space; randomize the assignment of blocks and the run order within each block.
