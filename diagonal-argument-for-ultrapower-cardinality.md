# Diagonal argument for ultrapower cardinality

↑ **Parent:** [Ultrapower](ultrapower.md)

If $U$ is a [kappa-complete](kappa-complete-filter.md) [nonprincipal ultrafilter](nonprincipal-ultrafilter.md) on $\kappa$ and $|M|\geq\kappa$, then $|M^\kappa/U|>\kappa$. Otherwise enumerate representatives $f_\alpha$ for its classes and choose $g(i)\notin\{f_\alpha(i):\alpha<i\}$. Every tail of $\kappa$ belongs to $U$, so $g$ differs modulo $U$ from every representative. The [small set is absent from a complete nonprincipal ultrafilter](small-set-is-absent-from-a-complete-nonprincipal-ultrafilter.md) lemma supplies the tail property.
