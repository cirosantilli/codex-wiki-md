# Multipartite graph

↑ **Parent:** [Graph](graph-split.md)

A graph is $r$-partite when its vertices can be partitioned into $r$ classes, each an [independent set](independent-set-graph-theory.md). Edges may be missing between different classes. If all possible edges between different classes occur, it is a [complete multipartite graph](complete-multipartite-graph.md).
