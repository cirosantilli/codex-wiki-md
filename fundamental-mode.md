# Fundamental mode

↑ **Parent:** [Normal mode](normal-mode.md)

The [fundamental mode](fundamental-mode.md) is the lowest-frequency oscillatory mode for the specified geometry, constraints and, in a propagation problem, horizontal [wavenumber](wavenumber.md). Its [frequency](frequency.md) need not be a universal constant of the material. In a [waveguide](waveguide.md) it forms the lowest [dispersion](wave-dispersion.md) branch; rigid zero-frequency motions, when present, must be distinguished from oscillations.
