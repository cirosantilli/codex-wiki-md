# Divisor class group of a plane-curve complement

↑ **Parent:** [Divisor class group](divisor-class-group.md)

If $C$ is an irreducible plane curve of degree $d$, the [localization sequence for the divisor class group](localization-sequence-for-the-divisor-class-group.md) quotients $\operatorname{Cl}(\mathbb P^2)=\mathbb Z[H]$ by the class $[C]=d[H]$. Nonsingularity of the removed curve is not required; irreducibility makes it a single removed [prime Weil divisor](prime-weil-divisor.md).
