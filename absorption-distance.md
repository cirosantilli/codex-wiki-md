# Absorption distance

↑ **Parent:** [Absorber incidence and comoving number density](absorber-incidence-and-comoving-number-density.md)

Absorption distance is a dimensionless path variable chosen so a non-evolving comoving absorber population with fixed proper cross-section has constant $d\mathcal N/dX$. It absorbs the geometrical factor in [absorber incidence and comoving number density](absorber-incidence-and-comoving-number-density.md). A distribution per $dN\,dX$ and one per $dN\,dz$ therefore differ by $dX/dz$.
