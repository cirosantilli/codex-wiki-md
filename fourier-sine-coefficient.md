# Fourier sine coefficient

↑ **Parent:** [Fourier coefficient](fourier-coefficient.md)

For an integrable [function](function-split.md) on $[-L,L]$, with $L>0$ and [integer](integer-split.md) $n\geq1$, the displayed [Fourier coefficient](fourier-coefficient.md) multiplies the mode $\sin(n\pi x/L)$ in its real [Fourier series](fourier-series-split.md). [Fourier orthogonality](fourier-orthogonality.md) fixes the normalization because the squared mode has [integral](integral-split.md) $L$. If $f$ is [odd](odd-function.md), the product with the sine is [even](even-function.md), so $b_n=(2/L)\int_0^Lf(x)\sin(n\pi x/L)dx$. These are also the coefficients of the [Fourier sine series](fourier-sine-series.md) of the restriction to $(0,L)$.
