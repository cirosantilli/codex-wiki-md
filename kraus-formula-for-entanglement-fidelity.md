# Kraus formula for entanglement fidelity

↑ **Parent:** [Entanglement fidelity](entanglement-fidelity.md)

If $\{K_a\}$ is any [Kraus representation](kraus-representation.md) of a [quantum channel](quantum-channel.md) $\Lambda$, then

$$
F_e(\rho,\Lambda)=\sum_a|\operatorname{Tr}(\rho K_a)|^2.
$$

For a [purification of a density operator](purification-of-a-density-operator.md), each branch overlap is $\langle\Psi_\rho|(I\otimes K_a)|\Psi_\rho\rangle=\operatorname{Tr}(\rho K_a)$. Summing the squared branch overlaps gives [entanglement fidelity](entanglement-fidelity.md).
