# Quadratic discriminant analysis

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quadratic_discriminant_analysis)

Quadratic discriminant analysis uses class-conditional [Gaussian distributions](multivariate-normal-distribution.md) with class-dependent covariance matrices. Their log density ratio is a quadratic polynomial in the observation.
