# Evanescent transverse electric mode in a rectangular waveguide

↑ **Parent:** [Transverse electric mode of a rectangular waveguide](transverse-electric-mode-of-a-rectangular-waveguide.md)

Below the lowest [waveguide cutoff frequency](waveguide-cutoff-frequency.md), the axial wave number of the $\mathrm{TE}_{10}$ mode is $i\kappa$, with $\kappa>0$. For a real peak scale $E_0$ and time convention $e^{-i\omega t}$, $E_y=E_0\sin(\pi x/a)e^{-\kappa z}$, $B_x=-i\kappa E_y/\omega$ and $B_z=-iE_0(\pi/a)\cos(\pi x/a)e^{-\kappa z}/\omega$. The [electric field](electric-field-split.md) and [magnetic field](magnetic-field-split.md) are in quadrature. A single decaying mode in a lossless semi-infinite guide consequently has zero time-averaged [Poynting vector](poynting-vector.md), although its instantaneous field stores [energy](energy-split.md).
