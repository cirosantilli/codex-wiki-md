# Randomized experiment

↑ **Parent:** [Design of experiments](design-of-experiments-split.md)

An experiment using [randomization](randomization.md) to allocate the comparison conditions. With valid implementation and analysis it can support [causal inference](causal-inference-split.md) within the studied setting; it does not by itself establish [external validity](external-validity.md).
