# Fixed-particle-number Gibbs minimum

↑ **Parent:** [Gibbs free energy](gibbs-free-energy.md)

At imposed [temperature](temperature-split.md) and [pressure](pressure-split.md), with fixed species amounts and only pressure-volume work, increasing total system-plus-reservoir [entropy](entropy-split.md) is equivalent to decreasing $G=U-TS+pV$. Unconstrained particle exchange requires the reservoir [chemical potentials](chemical-potential-split.md) to be included; minimizing $G$ over arbitrary particle number is a different problem.
