# Hamming code as a cyclic code

↑ **Parent:** [Hamming code](hamming-code.md)

Let $\omega$ generate $\mathbb F_{2^s}^{\times}$, $s\geq2$, and set $n=2^s-1$. The binary [cyclic code](cyclic-code.md) defined by $c(\omega)=0$ has a [parity-check matrix](parity-check-matrix.md) consisting of every nonzero vector of $\mathbb F_2^s$ once, after choosing a [basis](basis.md) and ordering its columns. It is therefore a [Hamming code](hamming-code.md). Its [generator polynomial](generator-polynomial-of-a-cyclic-code.md) is the [minimal polynomial of an algebraic element](minimal-polynomial-of-an-algebraic-element.md) $m_\omega(x)=\prod_{j=0}^{s-1}(x-\omega^{2^j})$, of degree $s$.
