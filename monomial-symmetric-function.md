# Monomial symmetric function

↑ **Parent:** [Symmetric function](symmetric-function.md)

For an [integer partition](integer-partition.md) $\lambda$, $m_\lambda$ sums the distinct [monomials](monomial.md) whose positive exponent multiset is $\lambda$. No multiplicity is attached to repeated parts. The functions of fixed total degree form a [basis](basis.md) of the [symmetric functions](symmetric-function.md) of that degree, since finite variable [permutations](permutation.md) identify precisely these [monomial](monomial.md) orbits.
