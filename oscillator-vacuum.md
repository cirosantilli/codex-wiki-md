# Oscillator vacuum

↑ **Parent:** [String oscillator](string-oscillator.md)

An oscillator vacuum is annihilated by all positive-frequency oscillator annihilation operators. For a [Ramond sector](ramond-sector.md) string this leaves a degenerate space on which the fermionic zero modes act through the [Ramond zero-mode Clifford algebra](ramond-zero-mode-clifford-algebra.md). Vacuum annihilation therefore does not select a unique spinor state.
