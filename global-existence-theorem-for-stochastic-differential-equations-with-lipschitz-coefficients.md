# Global existence theorem for stochastic differential equations with Lipschitz coefficients

↑ **Parent:** [Stochastic differential equation](stochastic-differential-equation.md)

Globally Lipschitz drift and diffusion coefficients have linear growth and give a nonexplosive [strong stochastic solution](strong-solution-of-a-stochastic-differential-equation.md) for a prescribed initial state and [Brownian motion](brownian-motion-split.md). The solution satisfies [pathwise uniqueness](pathwise-uniqueness.md). Local versions apply after stopping inside compact regions.
