# Search transition model

↑ **Parent:** [Search problem](search-problem.md)

The rule giving the successor state of each permitted state-action pair in a [search problem](search-problem.md). A compound action may include deterministic environmental responses. If a game state is sampled at full-turn boundaries, its [search transition model](search-transition-model.md) must still detect terminal events occurring inside the turn. Otherwise an intermediate failure can be incorrectly hidden by the final position. All information needed for future successors and the [goal test](goal-test.md) must be encoded in the state or supplied as fixed problem data.
