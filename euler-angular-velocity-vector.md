# Euler angular velocity vector

↑ **Parent:** [Euler pole](euler-pole.md)

Relative [angular velocities](angular-velocity.md) add as [vectors](vector.md): $\boldsymbol\omega_{B/C}=\boldsymbol\omega_{B/A}+\boldsymbol\omega_{A/C}$. Geographic pole [latitudes](geographical-latitude.md) and [longitudes](longitude.md) must first be converted into Cartesian [vector](vector.md) directions.
