# Proper-time gauge for a massive worldline einbein

↑ **Parent:** [Worldline einbein](worldline-einbein.md)

For the [relativistic particle](relativistic-particle.md) action $S=(m/2)\int[g_{\mu\nu}\dot x^\mu\dot x^\nu/e-e]d\lambda$, varying the [worldline einbein](worldline-einbein.md) gives $g_{\mu\nu}\dot x^\mu\dot x^\nu=-e^2$. On the positive-einbein branch the [proper time](proper-time.md) satisfies $ds=e\,d\lambda$. A [reparametrization](reparametrization.md) with $\lambda'=s$ sets the transformed einbein to one, making the [geodesic equation](geodesic-equation.md) affinely parametrized. This gauge choice is made after retaining the einbein [mass shell](mass-shell.md) constraint; fixing the action first would discard that equation. If the parameter interval is held fixed at both ends, its integrated [proper length](proper-length.md) is a modulus and cannot be arbitrarily changed by endpoint-preserving transformations.
