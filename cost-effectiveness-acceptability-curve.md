# Cost-effectiveness acceptability curve

↑ **Parent:** [Incremental net monetary benefit](incremental-net-monetary-benefit.md)

A [cost-effectiveness acceptability curve](cost-effectiveness-acceptability-curve.md) displays the probability of positive [incremental net monetary benefit](incremental-net-monetary-benefit.md) as a function of the willingness-to-pay threshold. Under a [posterior distribution](bayesian-posterior.md) this is a posterior probability. A frequentist paired [bootstrap](bootstrapping-statistics.md) version displays the fraction of replicates for which the net benefit is positive, a resampling measure of uncertainty rather than literally a probability that a fixed true parameter is positive. Using the sign of net benefit handles all quadrants of the [cost-effectiveness plane](cost-effectiveness-plane.md); counting only replicates whose ratio is below the threshold does not.
