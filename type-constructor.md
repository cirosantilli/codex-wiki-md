# Type constructor

↑ **Parent:** [Type system](type-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Type_constructor)

A type-level constructor accepting the number and kinds of [type arguments](type-argument.md) specified by its [kind of a type](kind-type-theory.md). For example, `Tree` accepts one ordinary type and produces `Tree a`; it has kind `* -> *`. A [data constructor](data-constructor.md) such as `One` operates at the value level instead. The two levels can use separate namespaces in a [programming language](programming-language-split.md).
