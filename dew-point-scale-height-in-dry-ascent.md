# Dew-point scale height in dry ascent

↑ **Parent:** [Dew point](dew-point.md)

Fixed [water vapor](water-vapor.md) [mole fraction](mole-fraction.md) gives $d\ln e_v=d\ln p$. Combining [hydrostatic balance](hydrostatic-balance.md) with the [Clausius-Clapeyron relation](clausius-clapeyron-relation.md) yields $d\ln T_D/dz=-(gR_v/L_vR_d)(T_D/T)$. If $T_D/T\simeq1$, then $T_D(z)\simeq T_D(0)e^{-z/H}$. All ratios use absolute [temperature](temperature-split.md); constant [latent heat](latent-heat.md), fixed composition and approximate parcel–environment [temperature](temperature-split.md) equality are required.
