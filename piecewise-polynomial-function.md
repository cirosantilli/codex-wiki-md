# Piecewise polynomial function

↑ **Parent:** [Polynomial function](polynomial-function.md)

A piecewise polynomial function agrees with a [polynomial](polynomial-split.md) on each member of a partition. Approximation claims usually require finitely many pieces with controlled interfaces. In one dimension, finitely many partition points and localized [wavelets](wavelet.md) with more [vanishing moments](vanishing-moment.md) than the polynomial degree leave only a bounded number of nonzero coefficients per scale, yielding exponential squared [best N-term approximation](best-n-term-approximation.md) error.
