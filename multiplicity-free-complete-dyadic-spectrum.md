# Multiplicity-free complete dyadic spectrum

↑ **Parent:** [Finite-dimensional spectral theorem](finite-dimensional-spectral-theorem.md)

A [Hermitian operator](hermitian-operator.md) on a $2^n$-dimensional [Hilbert space](hilbert-space-split.md), with $2^n$ distinct [eigenvalues](eigenvalue.md) all belonging to $\{c/2^n:0\leq c<2^n\}$, must occupy this entire grid. This follows from the [pigeonhole principle](pigeonhole-principle.md): the set of possible values and the set of distinct [eigenvalues](eigenvalue.md) have the same [cardinality](cardinality.md). Its minimum [eigenvalue](eigenvalue.md) is zero, so the operator is necessarily singular. Distinctness therefore does not imply invertibility; it forces a one-dimensional [kernel](kernel-of-a-linear-map.md) in this specific complete-grid setting.
