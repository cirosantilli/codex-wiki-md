# Airy function

↑ **Parent:** [Airy ordinary differential equation](airy-ordinary-differential-equation.md)

The standard Airy functions solve the [Airy ordinary differential equation](airy-ordinary-differential-equation.md). Their [Wronskian](wronskian.md) is $\operatorname{Ai}(Z)\operatorname{Bi}'(Z)-\operatorname{Ai}'(Z)\operatorname{Bi}(Z)=1/\pi$, so they form a fundamental solution pair, including for complex $Z$.
