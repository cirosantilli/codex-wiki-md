# Formative pluripotency

↑ **Parent:** [Pluripotency](pluripotency.md)

A transitional pluripotent state in which naive circuitry has been dismantled while competence for later lineage induction is being acquired. This is a state transition, not an additional [germ layer](germ-layer.md).
