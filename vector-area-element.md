# Vector area element

↑ **Parent:** [Area element of a surface](area-element-of-a-surface.md)

For an oriented parametrized surface $\mathbf r(u,v)$,

$$
d\mathbf S=(\mathbf r_u\times\mathbf r_v)\,du\,dv
=\mathbf n\,dA.
$$
