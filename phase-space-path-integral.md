# Phase-space path integral

↑ **Parent:** [Path integral](path-integral.md)

A [phase-space path integral](phase-space-path-integral.md) represents a quantum transition kernel by integrating both coordinates and conjugate momenta with action $\int(p\dot q-H)dt$. It follows from inserting position and momentum completeness relations between short-time evolution operators. For a quadratic momentum dependence the momentum variables can be integrated by a [Gaussian integral](gaussian-integral.md).
