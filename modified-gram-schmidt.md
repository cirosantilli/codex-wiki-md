# Modified Gram-Schmidt

↑ **Parent:** [Gram-Schmidt process](gram-schmidt-process.md)

[Modified Gram-Schmidt](modified-gram-schmidt.md) starts with $w=v_j$ and, for each retained [orthonormal](orthonormal-set.md) [vector](vector.md) $q_i$ in order, replaces $w$ by $w-\langle w,q_i\rangle q_i$. Each [orthogonal projection](orthogonal-projection.md) [coefficient](coefficient.md) uses the current remainder. In exact arithmetic, subtracting earlier [orthogonal](orthogonal-vectors.md) directions does not change the [inner product](inner-product.md) with $q_i$, so the final $w$ equals the [Classical Gram-Schmidt](classical-gram-schmidt.md) remainder $u_j$; then divide by $\|w\|$ if it is nonzero.
