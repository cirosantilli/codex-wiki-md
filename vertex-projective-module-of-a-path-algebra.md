# Vertex projective module of a path algebra

↑ **Parent:** [Path algebra](path-algebra.md)

The [vertex projective module of a path algebra](vertex-projective-module-of-a-path-algebra.md) $P(i)=kQe_i$ has at vertex $j$ the span of paths from $i$ to $j$. Each arrow appends itself to such paths. It is a [projective module](projective-module.md) because it is a summand of the free module $kQ$. Its [endomorphism ring](endomorphism-ring.md) is $(e_ikQe_i)^{\mathrm{op}}$, acting by right multiplication. The [closed-path corner of a path algebra is a domain](closed-path-corner-of-a-path-algebra-is-a-domain.md), so this ring has no nontrivial [idempotents](idempotent.md) and $P(i)$ is indecomposable. Directed cycles may make these projectives infinite-dimensional.
