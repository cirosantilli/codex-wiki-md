# Skeleton of a category

↑ **Parent:** [Skeletal category](skeletal-category.md)

A skeleton of $\mathcal C$ is a full [subcategory](subcategory.md) with exactly one object from each isomorphism class. The [axiom of choice](axiom-of-choice.md) supplies skeletons of [small categories](small-category.md). Conversely, if every small category has a skeletal equivalent, apply this to the [groupoid](groupoid.md) on $\coprod_i A_i$ with exactly one [morphism](morphism.md) between objects in the same nonempty fibre. A quasi-inverse from the skeletal category selects one object per fibre, giving a choice function. This converse uses an [equivalence of categories](equivalence-of-categories.md) with specified quasi-inverse functors, not just the existence of a full essentially surjective functor in one direction.
