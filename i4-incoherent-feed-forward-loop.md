# I4 incoherent feed-forward loop

↑ **Parent:** [Incoherent feed-forward loop](incoherent-feed-forward-loop.md)

In the I4 [incoherent feed-forward loop](incoherent-feed-forward-loop.md), an input activates the output but represses an intermediate activator of that output. Decay of the intermediate can interrupt an initial output pulse. Residual production and signal dependence must be retained when specifying the [gene regulation](regulation-of-gene-expression.md) rule.
