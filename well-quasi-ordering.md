# Well-quasi-ordering

↑ **Parent:** [Preorder](preorder.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Well-quasi-ordering)

A [preorder](preorder.md) is a [well-quasi-ordering](well-quasi-ordering.md) if every infinite [sequence](sequence.md) has indices $i<j$ with $x_i\leq x_j$. An infinite [sequence](sequence.md) with no such pair is a bad [sequence](sequence.md). This formulation handles combinatorial embedding relations that need not be antisymmetric on syntactic codes.
