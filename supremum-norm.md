# Supremum norm

↑ **Parent:** [Normed vector space](normed-vector-space.md)

The supremum norm of a bounded real- or complex-valued [function](function-split.md) on a set $X$ is

$$
\lVert f\rVert_\infty=\sup_{x\in X}|f(x)|.
$$

For a [continuous function](continuous-function.md) on a [compact space](compact-space.md), the [extreme value theorem](extreme-value-theorem.md) makes this supremum a maximum.
