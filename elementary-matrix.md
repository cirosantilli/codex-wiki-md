# Elementary matrix

↑ **Parent:** [Elementary row operation](elementary-row-operation.md)

An elementary matrix is obtained by applying one [elementary row operation](elementary-row-operation.md) to the [identity matrix](identity-matrix.md). Multiplying $A$ by it on the left performs the same row operation on $A$. Such a [matrix](matrix.md) is invertible: reverse a row swap, reverse a nonzero row scaling by its reciprocal, or reverse adding a multiple of another row by adding its negative. Right multiplication gives an [elementary column operation](elementary-column-operation.md). In particular these operations preserve [matrix rank](matrix-rank.md).
