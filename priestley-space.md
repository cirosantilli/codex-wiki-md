# Priestley space

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Priestley_space)

A [Priestley space](priestley-space.md) is a compact topological [partially ordered set](partially-ordered-set.md) that is totally order-disconnected: if $x\not\leq y$, a clopen upward-closed set contains $x$ and omits $y$. A [Priestley dual space](priestley-dual-space.md) is a space of this kind constructed from the prime filters of a bounded distributive lattice.
