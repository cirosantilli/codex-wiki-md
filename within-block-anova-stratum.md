# Within-block ANOVA stratum

↑ **Parent:** [ANOVA stratum](anova-stratum.md)

The [within-block ANOVA stratum](within-block-anova-stratum.md) contains response vectors whose coordinates sum to zero separately in every block. For $b$ blocks of size $k$ its dimension is $b(k-1)$. A shared additive block effect cancels in every vector in this subspace.
