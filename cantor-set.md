# Cantor set

↑ **Parent:** [Self-similarity](self-similarity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cantor_set)

The Cantor set is obtained from $[0,1]$ by repeatedly deleting the open middle third of every remaining interval. Equivalently, it consists of the numbers that admit a base-three expansion using only the digits zero and two.
