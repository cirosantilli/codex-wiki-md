# Collatz sequence

↑ **Parent:** [Sequence](sequence.md)

For a [positive integer](positive-integer.md) $a_0$, define $a_{k+1}=a_k/2$ when $a_k$ is an [even number](even-number.md), and $a_{k+1}=3a_k+1$ when $a_k$ is an [odd number](odd-number.md). Starting at $6$ gives $6,3,10,5,16,8,4,2,1$. Computing many trajectories benefits from [memoization](memoization.md), since trajectories that reach the same value have identical continuations.
