# Coasting cosmic-string universe

↑ **Parent:** [Cosmic string network](cosmic-string-network.md)

An isotropic [cosmic string network](cosmic-string-network.md) with $\rho=C/a^2$ has [equation-of-state parameter](equation-of-state-parameter.md) $w=-1/3$. The [Friedmann equation](friedmann-equations.md) gives $\dot a^2=8\pi GC/3-K$. On the expanding branch with positive right side, $a=B(t-t_B)$, the [comoving Hubble radius](comoving-hubble-radius.md) is constant, and the [cosmological density parameter](cosmological-density-parameter.md) is constant. There is no growing [flatness problem](flatness-problem.md), but flatness is not an attractor. If this exact coasting solution extends all the way to $t_B$, then $\int_{t_B}^t dt'/a(t')$ diverges and there is no finite [particle horizon](particle-horizon.md). A finite starting time changes that global conclusion.
