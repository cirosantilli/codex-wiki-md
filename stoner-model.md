# Stoner model

↑ **Parent:** [Ferromagnetism](ferromagnetism.md)

An itinerant mean-field model in which exchange splitting competes with the kinetic cost of unequal spin populations. Its instability condition is a suitably normalized interaction parameter times the Fermi-level density of states exceeding unity. It is distinct from a localized-spin exchange Hamiltonian for an insulator.
