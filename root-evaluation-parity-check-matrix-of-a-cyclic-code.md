# Root-evaluation parity-check matrix of a cyclic code

↑ **Parent:** [Parity-check matrix](parity-check-matrix.md)

For a [cyclic code](cyclic-code.md) whose [generator polynomial](generator-polynomial-of-a-cyclic-code.md) has distinct roots $\alpha_1,\ldots,\alpha_r$ in a [splitting field](splitting-field.md) $E$, the rows $(1,\alpha_i,\ldots,\alpha_i^{n-1})$ impose precisely the codeword conditions $c(\alpha_i)=0$. Expanding each value in a [basis](basis.md) of $E$ over the original [finite field](finite-field.md), then discarding dependent equations, gives a [parity-check matrix](parity-check-matrix.md) over that field of [rank](rank-one-quadratic-form.md) $r$. Alternatively choose one root from each [Frobenius conjugate](frobenius-conjugate.md) orbit and expand its value in the field it generates.
