# Local omission of a partial type

↑ **Parent:** [Nonprincipal partial type](nonprincipal-partial-type.md)

A [first-order theory](first-order-theory.md) locally omits a family $\Gamma(\mathbf x)$ if every formula $\theta(\mathbf x)$ consistent with it has a consistent refinement $\theta\land\neg\gamma$ for some $\gamma\in\Gamma$. Equivalently no consistent formula implies all of $\Gamma$. In a countable language the [omitting types theorem](omitting-types-theorem.md) converts this local condition into a countable model with no realization of the family.
