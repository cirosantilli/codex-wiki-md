# Stable letter

↑ **Parent:** [HNN extension](hnn-extension.md)

A stable letter is the new generator of an [HNN extension](hnn-extension.md) which implements an [isomorphism](isomorphism.md) between two specified subgroups by conjugation. In the convention $tat^{-1}=\phi(a)$, it moves elements of the source subgroup $A$ to the target subgroup $B$; using $t^{-1}at=\phi(a)$ reverses the naming convention.
