# Herglotz wave function

↑ **Parent:** [Inverse scattering problem](inverse-scattering-problem.md)

A Herglotz wave function is a superposition of incident [plane waves](plane-wave.md),

$$
v_g(\mathbf r)=\int_{S^2}e^{ik\widehat{\mathbf d}\cdot\mathbf r}g(\widehat{\mathbf d})\,dS(\widehat{\mathbf d}),\qquad g\in L^2(S^2).
$$

It solves the [Helmholtz equation](helmholtz-equation.md) everywhere and is [real analytic](real-analytic-function.md). The finite sphere area makes the density integrable, so each spatial [derivative](derivative.md) can be taken under the integral.
