# Rank of a set

↑ **Parent:** [Von Neumann hierarchy](von-neumann-hierarchy.md)

The rank is defined by

$$
\operatorname{rank}(x)
=\sup_{y\in x}(\operatorname{rank}(y)+1).
$$

It is the least ordinal $\alpha$ for which $x\subseteq V_\alpha$.
