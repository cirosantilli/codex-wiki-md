# Parallel vector field along a curve

↑ **Parent:** [Parallel transport](parallel-transport.md)

A [vector field](vector-field.md) along a smooth curve is parallel if its [covariant derivative](covariant-derivative.md) along that curve is zero. Its value is the [parallel transport](parallel-transport.md) of its initial value. A [Levi-Civita connection](levi-civita-connection.md) preserves inner products under this transport, so the length of a parallel field is constant. Along a unit-speed curvature-one [geodesic](geodesic.md), the normal [Jacobi field](jacobi-field.md) with zero initial value and initial derivative $a$ is $\sin t$ times the parallel transport of $a$.
