# Power-set failure in an increasing union of generic extensions

↑ **Parent:** [Generic extension](generic-extension.md)

Let $M_{n+1}=M_n[G_n]$ for a fixed [atomless forcing order](atomless-forcing-order.md) $\mathbb P$, and $N=\bigcup_{n<\omega}M_n$. If a [set](set-split.md) $A\in N$ were its internal [power set](power-set.md) of $\mathbb P$, choose $n$ with $A\in M_n$. The next [generic filter](generic-filter.md) $G_n$ belongs to $N$, so $G_n\in A$; transitivity of $M_n$ implies $G_n\in M_n$, contradicting [generic filter for an atomless order is new](generic-filter-for-an-atomless-order-is-new.md). The chain is increasing but need not be an elementary chain.
