<h1 id="hormander-integral-kernel-condition">Hörmander integral kernel condition</h1>

↑ **Parent:** [Convolution](convolution.md)

This integral smoothness condition on a [convolution](convolution.md) kernel controls how translations change the kernel away from the translation scale. It need not imply differentiability. Coupled with an $L^2$ operator bound, it yields a [weak type (1,1)](weak-type-1-1.md) bound through the [Calderón–Zygmund decomposition](calderon-zygmund-decomposition.md). It is distinct from the bracket-generating condition for differential operators also named after Hörmander.
