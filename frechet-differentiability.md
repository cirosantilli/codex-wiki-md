<h1 id="frechet-differentiability">Fréchet differentiability</h1>

↑ **Parent:** [Fréchet derivative](frechet-derivative.md)

A map is [Fréchet differentiable](frechet-differentiability.md) at $x$ if it admits a bounded linear first-order approximation: $f(x+h)=f(x)+Ah+o(\|h\|)$ for a [continuous linear map](continuous-linear-operator.md) $A$.
