# Bose condensation temperature from a fermionic density scale

↑ **Parent:** [Bose-Einstein condensation](bose-einstein-condensation.md)

Compare uniform three-dimensional [ideal gases](ideal-gas-split.md) at the same [number density](number-density.md) n, with [fermion](fermion.md) [mass](mass.md) $m_F$, [spin degeneracy](spin-degeneracy.md) $g_F$, [boson](boson.md) [mass](mass.md) $m_B$ and a single [boson](boson.md) [spin](spin.md) component. The [Fermi temperature](fermi-temperature.md) has $k_BT_F=\hbar^2(6\pi^2n/g_F)^{2/3}/(2m_F)$, while Bose saturation gives $k_BT_B=2\pi\hbar^2[n/\zeta(3/2)]^{2/3}/m_B$. Eliminating [density](density.md) yields

$$
\frac{T_B}{T_F}=\frac{4\pi}{(6\pi^2/g_F)^{2/3}\zeta(3/2)^{2/3}}\frac{m_F}{m_B}.
$$

The degeneracy is essential; using a spinless Fermi sea changes the numerical estimate. This is an ideal-gas comparison and does not remove interaction effects in a dense liquid.
