# Directory entry

↑ **Parent:** [File-system directory](file-system-directory.md)

An association between a name in a [file-system directory](file-system-directory.md) and a [file](computer-file.md). In the toy [file system](file-system-split.md), the pairs are `(a, 42)` and `(b, 42)`: each name resolves to the same [inode](inode.md). The name belongs to the [directory entry](directory-entry.md), rather than being the single authoritative name stored in that [inode](inode.md).
