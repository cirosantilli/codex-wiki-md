# Incomplete beta function

↑ **Parent:** [Beta function](beta-function.md)

For real $p,q>0$ and $0\leq z\leq1$, the displayed integral is the incomplete [beta function](beta-function.md). The regularized version is $I_z(p,q)=B_z(p,q)/B_1(p,q)$, the [cumulative distribution function](cumulative-distribution-function.md) of the [Beta distribution](beta-distribution.md). It has endpoint values zero and one and derivative $z^{p-1}(1-z)^{q-1}/B_1(p,q)$. This is a useful explicit [scale function of a one-dimensional diffusion](scale-function-stochastic-processes.md) when the scale density has two power-law endpoint singularities.
