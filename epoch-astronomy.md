# Epoch (astronomy)

↑ **Parent:** [Equatorial coordinate system](equatorial-coordinate-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Epoch_(astronomy))

An [astronomical epoch](epoch-astronomy.md) is a reference instant for astronomical data. A catalogue's position [astronomical epoch](epoch-astronomy.md) says when the listed source direction applies; [proper motion](proper-motion.md) advances that direction to another instant. The reference date for an [equatorial coordinate system](equatorial-coordinate-system.md)'s axes need not equal the position [astronomical epoch](epoch-astronomy.md). ESA's Gaia documentation explicitly associates both [right ascension](right-ascension.md) and [declination](declination.md) with its reference-epoch field. [ESA Gaia DR3: Reference epoch and its associated coordinate and proper-motion fields](https://gea.esac.esa.int/archive/documentation/GDR3/Gaia_archive/chap_datamodel/sec_dm_main_source_catalogue/ssec_dm_gaia_source.html).
