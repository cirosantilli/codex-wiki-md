# Random access network

↑ **Parent:** [Stochastic network](stochastic-network.md)

A random access network lets stations make transmission attempts independently using a shared medium. A collision can prevent all attempted packets from being delivered; [slotted ALOHA](slotted-aloha.md) adjusts attempt probabilities using slot feedback.
