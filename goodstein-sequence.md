# Goodstein sequence

↑ **Parent:** [Hereditary base representation](hereditary-base-representation.md)

Start at base two. At each nonzero step, change every base occurrence in the [hereditary base representation](hereditary-base-representation.md) to the next base and subtract one. Although the natural-number terms can grow, their [ordinal ranks of a Goodstein term](ordinal-rank-of-a-goodstein-term.md) decrease strictly. Keep zero fixed once it is reached.
