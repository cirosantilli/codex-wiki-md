# File-system directory

↑ **Parent:** [File system](file-system-split.md)

A [file](computer-file.md) containing [directory entries](directory-entry.md). Each entry supplies a name in that [file-system directory](file-system-directory.md); two entries in the same [file-system directory](file-system-directory.md) cannot have the same name. In an [inode](inode.md)-based [file system](file-system-split.md), a [file-system directory](file-system-directory.md) has its own [inode](inode.md), and its contents describe names of other objects. [The Open Group, POSIX.1-2024, sections 3.103–3.104: directory and directory entry](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap03.html#tag_03_103)
