# Extension of an absolute value

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

For a [field extension](field-extension.md) $L/K$, an extension of an absolute value $|\cdot|$ on $K$ is an absolute value on $L$ whose restriction to $K$ is $|\cdot|$.
