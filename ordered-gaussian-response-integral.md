# Ordered Gaussian response integral

↑ **Parent:** [Gaussian integral](gaussian-integral.md)

For $g(t)=e^{-(t-t_0)^2/(2\tau^2)}$, the real integrand is symmetric under $t\leftrightarrow s$, so the ordered domain contributes half the full plane. The result is $\tfrac12|\int g(t)e^{-i\omega t}\,dt|^2=\pi\tau^2e^{-\omega^2\tau^2}$, using the [Fourier transform](fourier-transform-split.md) of a [Gaussian function](gaussian-function.md). The imaginary part is not generally zero and must not be discarded before pairing conjugate harmonics in a real response.
