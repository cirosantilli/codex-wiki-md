# Root correction criterion for uniformity

↑ **Parent:** [Uniform pro-p group](uniform-pro-p-group.md)

For odd $p$ and a finitely generated [powerful pro-p group](powerful-pro-p-group.md), put $U_j=G^{p^j}$. The displayed [group homomorphisms](group-homomorphism.md) are surjective. If one has a nonzero [kernel](kernel-of-a-linear-map.md), choose $x\in U_j\setminus U_{j+1}$ with $x^p\in U_{j+2}$. Successive corrections $x\mapsto xu_r$, with $u_r\in U_r$, cancel its $p$-th power one layer at a time, using $(xu_r)^p\equiv x^pu_r^p\pmod {U_{r+2}}$. [Compactness](compact-space.md) and the separated power filtration give a nonidentity limit of order $p$. Thus a [torsion-free group](torsion-free-group.md) has constant layer indices and is a [uniform pro-p group](uniform-pro-p-group.md). Conversely constant indices make every displayed map injective; comparison at the first differing power layer proves that $x\mapsto x^p$ is injective, so there is no nontrivial torsion.
