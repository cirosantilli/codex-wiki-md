# Fourier extension estimate

↑ **Parent:** [Fourier extension operator](fourier-extension-operator.md)

An extension estimate is a [norm](norm.md) bound for the [Fourier extension operator](fourier-extension-operator.md), uniform over its input. The exponents encode the curvature and scale of the frequency surface. For normalized circle measure, a cap of angular width $\delta$ produces size comparable to $\delta$ on a rectangle of dimensions $\delta^{-2}\times\delta^{-1}$. This single-cap example forces $p\ge4$ for a finite diagonal estimate with the same exponent $p$ on both sides.
