# Antithetic Cauchy-tail integration on a finite interval

↑ **Parent:** [Antithetic variates](antithetic-variates.md)

For standard [Cauchy distribution](cauchy-distribution.md) [probability density function](probability-density-function.md) $f$ and $k>0$, this estimates its upper-tail [probability](probability.md) without sampling a heavy tail. The function $f(ku)$ decreases on $[0,1]$, while $f(k(1-u))$ increases, so their [covariance](covariance.md) is nonpositive. The paired estimator is unbiased and has no larger [variance](variance-split.md) than an estimator using the same number $2r$ of [independent](independent-random-variables.md) [probability density function](probability-density-function.md) evaluations.
