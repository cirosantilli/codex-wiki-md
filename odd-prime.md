# Odd prime

↑ **Parent:** [Prime number](prime-number.md)

An odd prime is a [prime number](prime-number.md) that is an [odd integer](odd-integer.md). The only [even number](even-number.md) that is a [prime number](prime-number.md) is $2$, since every other positive [even number](even-number.md) has $2$ as a proper [divisor](divisor.md). Thus every [prime number](prime-number.md) greater than $2$ is an odd prime. There are infinitely many odd primes, by [Euclid's theorem](euclid-s-theorem.md).
