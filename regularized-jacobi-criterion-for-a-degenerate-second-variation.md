# Regularized Jacobi criterion for a degenerate second variation

↑ **Parent:** [Jacobi positivity criterion](jacobi-positivity-criterion.md)

For continuous $P\geq0,Q$, a scalar [second variation](second-variation.md) $q=\int(P\varphi'^2+Q\varphi^2)$ is strictly positive on nonzero fixed-endpoint [Lipschitz](lipschitz-continuity.md) variations if and only if every regularized form $q_\eta$ for $\eta>0$ has no [conjugate point](conjugate-point.md) in $(a,b]$, and the original weak Jacobi boundary problem has no nonzero [Lipschitz](lipschitz-continuity.md) solution. The [Jacobi positivity criterion](jacobi-positivity-criterion.md) applies to each regularized coefficient $P+\eta>0$. Letting $\eta$ decrease to zero gives $q\geq0$. For a nonnegative [quadratic form](quadratic-form-split.md), $q(\varphi)=0$ forces its mixed [bilinear form](bilinear-form-split.md) with every [test function](test-function.md) to vanish, by considering $q(\varphi+t\psi)$ for both signs of $t$. This is the weak [Jacobi equation](jacobi-equation.md), so the kernel condition gives strict positivity. Necessity follows by the same argument in reverse. It distinguishes strict positivity from a uniform coercive estimate when the [derivative](derivative.md) coefficient degenerates.
