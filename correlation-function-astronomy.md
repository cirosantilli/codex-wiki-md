# Correlation function (astronomy)

↑ **Parent:** [Large-scale structure of the universe](large-scale-structure-of-the-universe-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Correlation_function_(astronomy))

The [cosmological two-point correlation function](correlation-function-astronomy.md) measures excess pairing or correlated density fluctuations at a separation. For a statistically homogeneous and isotropic mean-zero [density contrast](density-contrast.md), $\xi(r)=\langle\delta(\mathbf x)\delta(\mathbf x+\mathbf r)\rangle$. For distinct points in a discrete galaxy population it instead specifies the factorial pair density, $\bar n^2[1+\xi(r)]$. The latter excludes self-pairs; an unsmoothed discrete-density covariance also contains a [Dirac delta](dirac-delta-function.md) at zero separation. These definitions connect large-scale galaxy clustering with the [matter power spectrum](matter-power-spectrum.md) while keeping [galaxy power spectrum shot noise](galaxy-power-spectrum-shot-noise.md) separate.
