# Nonlinear regression

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nonlinear_regression)

Nonlinear regression fits a conditional mean whose dependence on its parameters is nonlinear. In a [normal distribution](normal-distribution.md) observation model, the likelihood is based on residuals $y_i-m(x_i,\theta)$. Nonlinearity can create parameter trade-offs, asymmetric uncertainty and several posterior regions, so [prior predictive checks](prior-predictive-check.md) and [Markov chain Monte Carlo convergence diagnostics](markov-chain-monte-carlo-convergence-diagnostics.md) can be especially useful.
