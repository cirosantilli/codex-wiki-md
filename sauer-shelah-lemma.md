# Sauer-Shelah lemma

↑ **Parent:** [VC dimension](vc-dimension.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sauer–Shelah_lemma)

If $VC(H)=D<\infty$, then $s(H,n)\leq\sum_{j=0}^D\binom nj$.
