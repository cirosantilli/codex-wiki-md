# Cauchy mean value theorem

↑ **Parent:** [Mean value theorem](mean-value-theorem.md)

For real functions continuous on $[a,b]$ and differentiable on $(a,b)$, there exists $\xi\in(a,b)$ with

$$
[f(b)-f(a)]g'(\xi)=[g(b)-g(a)]f'(\xi).
$$

Apply [Rolle's theorem](rolle-theorem.md) to a linear combination of the functions with equal endpoint values. If $g'$ never vanishes, $g(b)\ne g(a)$ and the equality can be divided into a ratio. This form directly proves the zero-over-zero endpoint case of [L'Hôpital's rule](l-hopital-s-rule.md), without continuity of the derivatives.
