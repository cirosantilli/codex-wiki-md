# Global relation for a linear boundary value problem

↑ **Parent:** [Boundary value problem](boundary-value-problem.md)

A global relation is an identity connecting transforms or integrals of the boundary traces of a solution. For a formally self-adjoint operator $L=\Delta-k^2$, [Green second identity](green-second-identity.md) gives

$$
\int_{\partial\Omega}(v\partial_nu-u\partial_nv)\,ds=0
$$

for every homogeneous adjoint solution $Lv=0$. Exponential adjoint families turn this into a spectral identity between the [Dirichlet boundary condition](dirichlet-boundary-condition.md) and unknown [normal derivative](normal-derivative.md).
