# Connection matrix in an orthonormal frame is skew-symmetric

↑ **Parent:** [Metric connection](metric-connection.md)

In a local [orthonormal frame](orthonormal-frame-in-spacetime.md) $(e_i)$, write $\nabla e_j=A^i{}_j e_i$. [Metric compatibility](metric-compatibility.md) and $d\langle e_i,e_j\rangle=0$ give

$$
A^i{}_j+A^j{}_i=0.
$$

Thus the connection one-form of a real metric connection takes values in the [skew-symmetric matrices](skew-symmetric-matrix.md).
