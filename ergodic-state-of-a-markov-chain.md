# Ergodic state of a Markov chain

↑ **Parent:** [Positive recurrent state](positive-recurrent-state.md)

In the standard discrete-time state terminology, an ergodic state is a [positive recurrent state](positive-recurrent-state.md) with [aperiodicity](aperiodic-markov-chain.md). Return occurs almost surely, the mean strictly positive return time is finite, and the greatest common divisor of possible return lengths is one. An irreducible chain shares these properties among all its states.
