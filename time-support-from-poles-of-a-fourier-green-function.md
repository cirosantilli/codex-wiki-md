# Time support from poles of a Fourier Green function

↑ **Parent:** [Green's function](green-s-function-split.md)

For the inverse transform $G(\tau)=\int d\omega\,e^{-i\omega\tau}g(\omega)/(2\pi)$, positive $\tau$ requires closing a decaying contour below the real axis, clockwise; negative $\tau$ requires closing above, counterclockwise. [Poles](pole.md) strictly below give a [retarded Green function](retarded-green-function.md), while [poles](pole.md) strictly above give an [advanced Green function](advanced-green-function.md). Real-axis [poles](pole.md) need a prescription. The sign convention in the Fourier exponential is essential.
