# Set

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Set_(mathematics))

A set is a collection of distinct objects regarded as its [set elements](element-of-a-set.md). Membership, written $a\in A$, is the basic question: is $a$ one of the objects in $A$? For example, $\{1,2,2\}=\{1,2\}=\{2,1\}$: repeated entries and their written order do not change a [set](set-split.md). A [multiset](multiset.md) retains multiplicities, while a [tuple](finite-tuple.md) retains positions as well. Choosing the right object therefore determines which distinctions the mathematics remembers.

A [set](set-split.md) can collect possible outcomes of a [probability space](probability-space-split.md), vertices of a [graph](graph-split.md), or allowed inputs of a [function](function-split.md). The [empty set](empty-set.md) contains none; a [subset](subset.md) selects members of a previously given [set](set-split.md); the [power set](power-set.md) collects every such selection. These constructions are useful because they can be stated once and reused regardless of what the members represent. In an axiomatic account, rules such as the [axiom schema of separation](axiom-schema-of-specification.md) specify which collections exist as [sets](set-split.md).
