# Smoothing parameter

↑ **Parent:** [Nonparametric regression](nonparametric-regression.md)

A smoothing parameter controls the amount of averaging or regularization in a fitted function. Increasing the penalty multiplier $\lambda$ in a [cubic smoothing spline](cubic-smoothing-spline.md) discourages curvature and generally reduces [effective degrees of freedom](effective-degrees-of-freedom.md). Increasing a [smoothing bandwidth](smoothing-bandwidth.md) enlarges local averaging neighbourhoods. Software may use a monotone transformed parameter such as `spar`, so its numerical value should not be confused with the raw penalty multiplier.
