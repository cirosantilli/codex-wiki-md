# Associated graded module

↑ **Parent:** [Associated graded ring](associated-graded-ring.md)

For an increasing [filtration of a module](filtration-of-a-module.md) $M_n$ compatible with a [filtered algebra](filtered-algebra.md) $A$, set $\operatorname{gr}M=\bigoplus_n M_n/M_{n-1}$. Multiplication on the quotients makes it a graded [module](module-mathematics.md) over $\operatorname{gr}A$. Its cumulative homogeneous dimensions equal $\dim M_n$ for a finite-dimensional exhaustive nonnegative [filtration of a module](filtration-of-a-module.md).
