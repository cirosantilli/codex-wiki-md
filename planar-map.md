# Planar map

↑ **Parent:** [Planar graph](planar-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Planar_map)

A planar map is a [planar graph](planar-graph.md) together with a fixed embedding in the [sphere](sphere.md), considered up to orientation-preserving homeomorphism. A rooted planar map has a distinguished oriented edge, which removes most embedding symmetries.
