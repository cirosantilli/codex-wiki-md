# State space

↑ **Parent:** [Dynamical system](dynamical-system.md)

The state space of a [dynamical system](dynamical-system.md) is the set of all states that the system may occupy. An evolution rule traces an [orbit](orbit-dynamical-system.md) through this space from each admissible initial state.
