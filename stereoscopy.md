# Stereoscopy

↑ **Parent:** [Photography](photography-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stereoscopy)

Using images from different viewpoints to convey or recover depth. In scientific [photography](photography-split.md), comparing corresponding features in calibrated views can help reconstruct their three-dimensional positions; a single image generally leaves depth ambiguous.
