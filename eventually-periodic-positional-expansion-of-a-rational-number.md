# Eventually periodic positional expansion of a rational number

↑ **Parent:** [Rational number](rational-number.md)

A positional expansion in an integer base represents a rational number exactly when its digit sequence is eventually periodic. Long division proves the forward implication because only finitely many remainders occur; summing a periodic tail as a [geometric series](geometric-series.md) proves the converse.
