# Block copolymer

↑ **Parent:** [Polymer](polymer-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Block_copolymer)

A [polymer](polymer-split.md) composed of connected blocks with different repeat-unit chemistry. Incompatible blocks can form spatially distinct domains while remaining covalently connected.
