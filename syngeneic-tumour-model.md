# Syngeneic tumour model

↑ **Parent:** [Cancer](cancer.md)

A tumour-graft model using a genetically compatible host and donor, enabling investigation in an immune-competent setting. It generally uses mouse rather than human [tumour](tumour.md) [biological cells](biological-cell-split.md).
