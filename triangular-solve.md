# Triangular solve

↑ **Parent:** [Triangular system](triangular-system.md)

A [triangular solve](triangular-solve.md) computes the unique [solution of a linear system](solution-of-a-linear-system.md) for an invertible [triangular system](triangular-system.md) using [forward substitution](forward-substitution.md) for a [lower triangular matrix](lower-triangular-matrix.md) or [backward substitution in a triangular system](backward-substitution-in-a-triangular-system.md) for an [upper triangular matrix](upper-triangular-matrix.md).
