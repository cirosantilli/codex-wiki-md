# Associative memory in neural networks

↑ **Parent:** [Neural network](neural-network.md)

An [associative memory](associative-memory-in-neural-networks.md) retrieves a stored pattern from a related cue. An incomplete cue supplies only some coordinates; a corrupted cue supplies some wrong coordinates. A [Hopfield network](hopfield-network.md) implements retrieval by making intended patterns stable states with surrounding [basins of attraction](basin-of-attraction.md). This turns correction into a collective computation: no unit needs to know the entire desired answer. A cue outside the appropriate [basin of attraction](basin-of-attraction.md) can retrieve another pattern or an unintended stable state.
