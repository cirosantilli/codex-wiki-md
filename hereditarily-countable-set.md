# Hereditarily countable set

↑ **Parent:** [Transitive closure](transitive-closure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hereditarily_countable_set)

A set is hereditarily countable when its [transitive closure](transitive-closure.md) is [countable](countable-set.md). These sets form the transitive set $H_{\omega_1}$ and all have rank below $\omega_1$.
