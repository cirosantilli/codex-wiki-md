# Nevanlinna class

↑ **Parent:** [Holomorphic function](holomorphic-function.md)

The analytic Nevanlinna class consists of [holomorphic functions](holomorphic-function.md) on the [unit disc](unit-disc.md) with uniformly bounded means of their positive logarithmic modulus. Here $m$ is normalized angular measure. A bounded [holomorphic function](holomorphic-function.md) belongs to this class, but the class also permits unbounded functions. It is the analytic version of [bounded characteristic](bounded-characteristic.md).
