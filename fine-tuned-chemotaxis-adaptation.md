# Fine-tuned chemotaxis adaptation

↑ **Parent:** [Perfect adaptation](perfect-adaptation.md)

For $\dot m=r-bm/(K+m)$ with activity $a=fm$, preserving the original output after f changes from one requires $b'=fb+(1-f)r$. This relation depends on modification capacities and is generally disrupted by changing [enzyme](enzyme-split.md) abundance. It differs from output-dependent reverse modification in the [Barkai-Leibler model](barkai-leibler-model.md).
