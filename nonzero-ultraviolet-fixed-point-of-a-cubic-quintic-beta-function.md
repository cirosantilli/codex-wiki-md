# Nonzero ultraviolet fixed point of a cubic-quintic beta function

↑ **Parent:** [Beta function (physics)](beta-function-physics.md)

For $A,B>0$, the nonzero zero of the [renormalization-group beta function](beta-function-physics.md) has slope $\beta^{\prime}(g_*)=-2B^2/A<0$ and is ultraviolet attractive. The origin is infrared attractive. A fixed-point [field-renormalization anomalous dimension](field-renormalization-anomalous-dimension.md) gives a power-law [quantum field theory propagator](propagator.md) factor $d(z)\sim Cz^{\gamma_\phi(g_*)}$. A weak fixed point is needed for control by a perturbative truncation.
