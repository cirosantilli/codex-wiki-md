# Complete set of commuting observables

↑ **Parent:** [Observable](observable.md)

A [complete set of commuting observables](complete-set-of-commuting-observables.md) consists of mutually commuting [quantum observables](observable.md) whose joint [eigenvalues](eigenvalue.md) distinguish all vectors of a simultaneous [eigenbasis](eigenbasis.md), up to phase. For a finite-dimensional [Hilbert space](hilbert-space-split.md), commuting [self-adjoint operators](self-adjoint-operator.md) admit a simultaneous [orthonormal basis](orthonormal-basis.md) of [eigenvectors](eigenvector.md); completeness means that every joint [eigenspace](eigenspace.md) is one-dimensional. An additional [quantum observable](observable.md) that is already a function of the others supplies no independent [quantum number](quantum-number.md).

For the [addition of angular momentum](addition-of-angular-momentum.md), the uncoupled labels $(j_1,j_2,m_1,m_2)$ correspond to $\{J_1^2,J_2^2,J_{1z},J_{2z}\}$, whereas the coupled labels $(j_1,j_2,j,m)$ correspond to $\{J_1^2,J_2^2,J^2,J_z\}$. Within a fixed pair of irreducible [angular momentum](angular-momentum.md) spaces each choice gives a natural [eigenbasis](eigenbasis.md). The [Clebsch-Gordan coefficients](clebsch-gordan-coefficients.md) implement the change between them.
