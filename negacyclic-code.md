# Negacyclic code

↑ **Parent:** [Cyclic code](cyclic-code.md)

A [linear code](linear-code.md) is negacyclic if $(c_0,\ldots,c_{n-1})$ being a [codeword](codeword.md) implies that $(-c_{n-1},c_0,\ldots,c_{n-2})$ is a [codeword](codeword.md). [Polynomial](polynomial-split.md) identification makes it an [ideal](ideal.md) modulo $X^n+1$. For odd $n$, the substitution $X\mapsto-X$ gives a [monomial equivalence of linear codes](monomial-equivalence-of-linear-codes.md) between negacyclic and [cyclic codes](cyclic-code.md).
