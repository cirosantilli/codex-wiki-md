# Top-hat plume model

↑ **Parent:** [Turbulent plume](turbulent-plume-split.md)

A top-hat plume model takes velocity and reduced gravity to be uniform across the plume and zero outside it. Integral volume, momentum, and [buoyancy fluxes](buoyancy-flux.md) then depend only on plume width and these uniform values.
