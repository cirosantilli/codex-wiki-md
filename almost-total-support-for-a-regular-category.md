# Almost total support for a regular category

↑ **Parent:** [Support of an object in a regular category](support-of-an-object-in-a-regular-category.md)

A [regular category](regular-category.md) is almost totally supported if every object is a [well-supported object](well-supported-object.md) or a [strict initial object](strict-initial-object.md). The case in which every object is well-supported is allowed. There can be at most one strict initial object up to isomorphism. In the [Category of sets](category-of-sets.md), these two cases distinguish nonempty sets from the empty set. A meet-semilattice regarded as a category satisfies the condition precisely when it has at most two objects up to isomorphism.
