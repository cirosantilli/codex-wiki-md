# Rank-zero elliptic curve with cubic x cubed plus x

↑ **Parent:** [Two-isogeny descent](two-isogeny-descent.md)

For $E:y^2=x^3+x$, the [two-torsion square-class homomorphism](two-torsion-square-class-homomorphism.md) has image $\{1\}$: prime-support bounds allow only $\pm1$, and every nonzero affine $x$ is positive. Its [two-isogeny formula](two-isogeny-formula.md) companion $E':y^2=x^3-4x$ has possible image classes $\{1,-1,2,-2\}$, all realized by its rational two-torsion. The [two-isogeny rank formula](square-class-index-formula-for-two-isogeny-descent.md) gives $2^r=1\cdot4/4=1$, so the rank is zero.
