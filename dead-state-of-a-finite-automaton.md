# Dead state of a finite automaton

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A [dead state of a finite automaton](dead-state-of-a-finite-automaton.md) has no path to an accepting state. In a complete [deterministic finite automaton](deterministic-finite-automaton.md), all dead states may be merged into one rejecting sink without changing the accepted [formal language](formal-language.md).
