# Bogoliubov quasiparticle

↑ **Parent:** [Quasiparticle](quasiparticle.md)

A Bogoliubov [quasiparticle](quasiparticle.md) is an excitation created by the diagonal mode operator obtained through a [Bogoliubov transformation](bogoliubov-transformation.md). Its vacuum can contain particles in the original modes because creation and [annihilation operators](annihilation-operator.md) mix. Examples include [antiferromagnetic spin waves](antiferromagnetic-spin-wave.md), Bose-gas [phonons](phonon.md) and paired-fermion excitations.
