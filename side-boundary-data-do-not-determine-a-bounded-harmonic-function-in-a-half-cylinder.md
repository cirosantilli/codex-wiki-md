# Side boundary data do not determine a bounded harmonic function in a half-cylinder

↑ **Parent:** [Laplace equation in cylindrical coordinates](laplace-equation-in-cylindrical-coordinates.md)

In the unit half-cylinder $z\ge0$, specifying only the curved-side boundary values does not determine a bounded [harmonic function](harmonic-function.md). The displayed nonzero function, where $j_{0,1}$ is a positive zero of the [Bessel function of the first kind](bessel-function-of-the-first-kind.md) $J_0$, is regular at the axis, bounded, harmonic, and zero on $r=1$. It may be added to any particular solution without changing the side data, and even decays at infinity. Boundary information at the base $z=0$ is still required for uniqueness.
