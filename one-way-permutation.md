# One-way permutation

↑ **Parent:** [One-way function](one-way-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/One-way_permutation)

A [one-way permutation](one-way-permutation.md) is a bijective [one-way function](one-way-function.md) on its input domain. Injectivity is useful for binding in [bit commitment](bit-commitment.md), because an output has only one possible preimage even if a dishonest sender has unlimited computation.
