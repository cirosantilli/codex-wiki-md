# Capture-safe equality replacement

↑ **Parent:** [Logical equality](logical-equality.md)

Equal variables can replace selected free occurrences in a [first-order formula](first-order-formula.md) if the inserted variable is not captured. Starting with atomic equality replacement, derive symmetry, then prove both replacement directions together by [structural induction](structural-induction.md). [Negation](negation.md) uses the reverse induction implication; implication uses both directions; a [universal quantifier](universal-quantification.md) is handled by instantiation, replacement and [generalization](universal-generalization-rule.md) with a variable fresh for the equality assumptions. Bound occurrences are not replaced as free ones.
