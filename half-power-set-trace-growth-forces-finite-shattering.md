# Half-power-set trace growth forces finite shattering

↑ **Parent:** [Sauer-Shelah lemma](sauer-shelah-lemma.md)

If no $k$-set were shattered, the [Sauer-Shelah lemma](sauer-shelah-lemma.md) would bound the number of traces by $\sum_{i<k}\binom{2k}{i}=(2^{2k}-\binom{2k}{k})/2<2^{2k-1}$. This strict middle-layer gap contradicts the displayed lower bound. Therefore a family with such traces at every even size has unbounded finite [VC dimension](vc-dimension.md).
