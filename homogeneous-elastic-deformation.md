# Homogeneous elastic deformation

↑ **Parent:** [Deformation gradient](deformation-gradient.md)

An elastic [deformation map](deformation-map.md) whose [deformation gradient](deformation-gradient.md) is independent of position at each time. Its spatial [material acceleration](material-acceleration.md) is $\mathbf a=\ddot F F^{-1}(\mathbf x-\mathbf c)+\ddot{\mathbf c}$. [Incompressibility](incompressible-flow.md) requires $\det F=1$.
