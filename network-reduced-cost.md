# Network reduced cost

↑ **Parent:** [Network dual potential](network-dual-potential.md)

With the tail-positive incidence convention, a network edge's reduced cost is $r_{ij}=c_{ij}-\pi_i+\pi_j$. For [uncapacitated minimum-cost flow](uncapacitated-minimum-cost-flow.md), dual feasibility requires $r_{ij}\geq0$ and [complementary slackness](complementary-slackness.md) requires $f_{ij}r_{ij}=0$. A negative non-tree reduced cost identifies an improving [graph cycle](cycle-in-a-graph.md) pivot in the [network simplex algorithm](network-simplex-algorithm.md). This sign convention differs from the row-column potentials of a [transportation problem](transportation-problem.md).
