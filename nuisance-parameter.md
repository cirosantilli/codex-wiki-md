# Nuisance parameter

↑ **Parent:** [Statistical parameter](statistical-parameter.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nuisance_parameter)

A [nuisance parameter](nuisance-parameter.md) is a [statistical parameter](statistical-parameter.md) required to specify the distribution of observations but not itself the target of inference. A [profile likelihood](profile-likelihood.md) maximizes over it; [Bayesian model evidence](bayesian-model-evidence.md) integrates over it using a proper [prior distribution](prior-probability.md). These operations differ and need not give the same inference. A [baseline hazard](baseline-hazard.md) in a [Cox proportional-hazards model](cox-proportional-hazards-model.md) is an infinite-dimensional example.
