# Hypersurface

↑ **Parent:** [Smooth manifold](smooth-manifold.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hypersurface)

A hypersurface in an $n$-dimensional [smooth manifold](smooth-manifold.md) is a smooth submanifold of dimension $n-1$. Locally, a regular level set $\{\phi=0\}$ with $\nabla\phi\ne0$ is a hypersurface whose [normal vector](normal-vector.md) is $\nabla\phi$.
