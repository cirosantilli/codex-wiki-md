# Nuclide

↑ **Parent:** [Chemical element](chemical-element.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nuclide)

A nuclear species specified by [atomic number](atomic-number.md), [mass number](mass-number.md), and nuclear [energy](energy-split.md) state. [Isotopes](isotope.md) compare [nuclides](nuclide.md) with the same [atomic number](atomic-number.md); changing only the nuclear [energy](energy-split.md) state does not create a different [isotope](isotope.md).
