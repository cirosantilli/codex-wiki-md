# Campbell first-moment formula

↑ **Parent:** [Campbell's theorem](campbell-s-theorem.md)

For a [Poisson random measure](poisson-random-measure.md) $\Pi$ with intensity $\mu$ and measurable nonnegative $h$, $\mathbb E\int h\,d\Pi=\int h\,d\mu$, allowing both sides to be infinite. For signed $h$, the same identity holds if $\int|h|d\mu<\infty$. This first-moment statement does not require square integrability. Applying it to a nonnegative [volume](volume.md) mark gives the expected total [volume](volume.md) in a marked Poisson model.
