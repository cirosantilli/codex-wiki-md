# Vector field along a map

↑ **Parent:** [Pullback tangent bundle](pullback-tangent-bundle.md)

A vector field along a [smooth map between manifolds](smooth-map-between-manifolds.md) $f:M\to N$ assigns $Y_p\in T_{f(p)}N$ smoothly to each $p$. It is a section of the [pullback tangent bundle](pullback-tangent-bundle.md), not necessarily a vector field on $N$. Along a curve $\gamma$, the velocity $\dot\gamma$ is such a section.
