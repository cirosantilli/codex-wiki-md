# Unnormalized sinc function

↑ **Parent:** [Sinc function](sinc-function.md)

The [sinc function](sinc-function.md) $\sin z/z$ for $z\ne0$, extended by value one at zero. The displayed [power series](power-series.md) has infinite [radius of convergence](radius-of-convergence.md), so the extension is [entire](entire-function.md). Its removable value follows from the first coefficient or from the sine limit. This convention differs by the argument scaling $z\mapsto\pi z$ from the normalized sinc convention.
