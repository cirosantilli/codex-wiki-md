# Scala

↑ **Parent:** [Programming language](programming-language-split.md)

A [programming language](programming-language-split.md) supporting [object-oriented programming](object-oriented-programming.md) and [functional programming](functional-programming.md). Its [traits](trait.md) support reusable [mixin](mixin.md) behavior, while [type variance](type-variance.md) controls how parameterized types participate in [subtyping](subtyping.md). The Scala 2 and Scala 3 language versions differ in some syntax and typing details; examples should state the version relevant to a particular claim. Official documentation: [https://docs.scala-lang.org](https://docs.scala-lang.org)
