# Density process

↑ **Parent:** [Change of measure](change-of-measure.md)

For a [Radon-Nikodym derivative](radon-nikodym-derivative.md) $L_T\geq0$ with $\mathbb EL_T=1$, its conditional-expectation process is a nonnegative [martingale](martingale-split.md). If $L_T>0$ [almost surely](almost-sure-convergence.md), it defines an [equivalent probability measure](equivalent-probability-measure.md). A [stochastic exponential](doleans-dade-exponential.md) satisfying the [Novikov condition](novikov-s-condition.md) is a common positive density process.
