# Eigenvalue problem

↑ **Parent:** [Eigenvalue](eigenvalue.md)

An eigenvalue problem asks for the [eigenvalues](eigenvalue.md) and corresponding [eigenvectors](eigenvector.md) or [eigenfunctions](eigenfunction.md) of a [linear operator](linear-operator.md). It is commonly written as the [eigenvalue equation](eigenvalue-equation.md) $Av=\lambda v$.
