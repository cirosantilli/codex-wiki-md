# Phase winding of a condensate

↑ **Parent:** [Quantized circulation](quantized-circulation.md)

If a condensate order parameter stays nonzero along a closed loop, its phase changes by an integer multiple of $2\pi$. Broken [rotational symmetry](rotational-symmetry.md) does not destroy this single-valuedness constraint. In an inhomogeneous ring the winding integer need not label an angular-momentum [eigenstate](eigenstate.md).
