# Functional localizer

↑ **Parent:** [Neuroscientific methods](neuroscientific-methods.md)

An independently specified task contrast used to identify a region for subsequent analysis. Individual localisation can distinguish neighbouring language-selective and domain-general regions, while independent data reduce circularity.[Current Biology 22, 2059–2062; individual functional localization and cross-domain response profiles](language-selective-and-domain-general-regions-lie-side-by-side-within-broca-s-area-by-evelina-fedorenko-and-others.md)
