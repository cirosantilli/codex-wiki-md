# Restricted sumset

↑ **Parent:** [Sumset](sumset.md)

For finite sets in an [abelian group](abelian-group.md) and a [bipartite graph](bipartite-graph.md) $\Gamma\subseteq A\times B$, the restricted [sumset](sumset.md) is $\{a+b:(a,b)\in\Gamma\}$. It retains only sums corresponding to graph edges.
