# Discrete Riccati recurrence

↑ **Parent:** [Linear-quadratic optimal control](linear-quadratic-optimal-control.md)

A backward scalar or matrix recurrence for the quadratic coefficients in a value function for a [linear-quadratic optimal control](linear-quadratic-optimal-control.md) problem. It results from completing the control square in the [Bellman equation](bellman-equation.md). Multiplicative noise modifies the quadratic coefficients through its second moments.
