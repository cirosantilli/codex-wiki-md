# Common neighbourhood from bipartite density

↑ **Parent:** [Complete bipartite graph](complete-bipartite-graph.md)

If a [bipartite graph](bipartite-graph.md) with class sizes $m,N$ has at least $\beta mN$ [edges](edge-of-a-graph.md), double count pairs consisting of an $s$-set in the first class and a common neighbour in the second. Convexity of binomial coefficients gives some $S$ with $|N(S)|\ge N\binom{\lfloor\beta m\rfloor}s/\binom ms$. When $s\le\beta m/2$, the quotient is at least $(\beta/2)^s$. This turns density into a large complete bipartite subgraph.
