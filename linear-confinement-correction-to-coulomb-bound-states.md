# Linear confinement correction to Coulomb bound states

↑ **Parent:** [Time-independent perturbation theory](time-independent-perturbation-theory.md)

For [reduced mass](reduced-mass.md) $\mu$ and Coulomb strength $a$, put $a_q=\hbar^2/(\mu a)$. The perturbation $br$ shifts the $1s,2s,2p$ energies by $3ba_q/2,6ba_q,5ba_q$, respectively. These values follow by integrating $r^3|R_{nl}|^2$. Because the perturbation is central, angular [orthogonality](orthogonal-vectors.md) makes its [matrix](matrix.md) diagonal inside each Coulomb [energy](energy-split.md) [eigenspace](eigenspace.md). It splits the accidental degeneracy between different orbital angular momenta while preserving magnetic degeneracy.
