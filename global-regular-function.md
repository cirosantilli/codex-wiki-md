# Global regular function

↑ **Parent:** [Regular function](regular-function.md)

A global regular function is a [global section](global-section.md) of the [structure sheaf](structure-sheaf-of-a-scheme.md) of a [scheme](scheme.md), defined on the entire scheme. These functions form its ring $H^0(X,\mathcal O_X)$. On an [affine scheme](affine-scheme.md) this recovers the defining ring; on a positive-dimensional [projective complete intersection](projective-complete-intersection.md) it consists only of constants over the base [field](field.md).
