# Algebraic integer module criterion

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)

An element $x$ is integral over $\mathbb Z$ exactly when it acts stably on some faithful nonzero finitely generated $\mathbb Z$-module containing one.
