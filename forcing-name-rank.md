# Forcing name rank

↑ **Parent:** [Forcing name](forcing-name.md)

The [ordinal](ordinal.md) assigned recursively by $\operatorname{nrk}(\tau)=\sup\{\operatorname{nrk}(\sigma)+1:(\sigma,p)\in\tau\}$. It measures dependency on subnames and justifies generic evaluation by recursion. The ordinary [rank of a set](rank-of-a-set.md) also accounts for the coding of the [ordered pairs](ordered-pair.md) and the [forcing](forcing-split.md) conditions; it need not equal this dependency [rank of a set](rank-of-a-set.md).
