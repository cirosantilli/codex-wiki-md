# Tonelli-Shanks algorithm

↑ **Parent:** [Algorithm](algorithm-split.md)

The Tonelli-Shanks algorithm finds a [square root](square-root.md) of a [quadratic residue](quadratic-residue-split.md) [modulo](modulo-operation.md) an [odd prime](odd-prime.md). It uses the decomposition of the prime minus one into an odd part and a [power of two](power-of-two.md) to successively correct a candidate root.
