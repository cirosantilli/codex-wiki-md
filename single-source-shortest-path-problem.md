# Single-source shortest-path problem

↑ **Parent:** [Shortest path problem](shortest-path-problem-split.md)

Compute [shortest-path distances](shortest-path-distance.md) from one fixed source to every vertex, together with predecessor information when shortest paths exist. [Dijkstra's algorithm](dijkstra-algorithm.md) handles nonnegative weights; the [Bellman-Ford algorithm](bellman-ford-algorithm.md) admits negative weights and detects reachable [negative cycles](negative-cycle.md). A [Directed acyclic graph](directed-acyclic-graph.md) instead permits one pass in [topological order](topological-order.md).
