# co-NP

↑ **Parent:** [Computational complexity theory](computational-complexity-theory.md)

The class of [decision problems](decision-problem.md) whose complements belong to [NP](np-complexity.md). Equivalently, negative instances admit polynomially bounded witnesses verifiable in [polynomial time](polynomial-time.md). A problem is [co-NP](co-np.md)-complete when it is in [co-NP](co-np.md) and every problem in [co-NP](co-np.md) has a [polynomial-time reduction](polynomial-time-reduction.md) to it. Unsatisfiability of a [propositional formula](propositional-formula.md) is a basic example: its complement is the [NP](np-complexity.md)-complete [Boolean satisfiability problem](boolean-satisfiability-problem.md).
