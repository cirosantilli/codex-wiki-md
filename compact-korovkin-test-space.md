# Compact Korovkin test space

↑ **Parent:** [Korovkin theorem](korovkin-theorem.md)

Let $K$ be a [compact Hausdorff space](compact-hausdorff-space.md). A test subspace $H\subset C(K,\mathbb R)$ containing a strictly positive function is sufficient for [uniform convergence](uniform-convergence.md) of [positive linear operators on continuous functions](positive-linear-operator-on-continuous-functions.md) if, for each $x\in K$, the only [positive linear functional](positive-linear-functional.md) agreeing with point evaluation on $H$ is that evaluation itself. By the [Riesz-Markov-Kakutani representation theorem](riesz-markov-kakutani-representation-theorem.md), this is uniqueness of the positive measure with the prescribed moments. Boundedness from the positive test function and the [Banach-Alaoglu theorem](banach-alaoglu-theorem.md) prove the assertion by compactness. When $1\in H$, nonnegative tests with a unique zero at each prescribed $x$ give a convenient sufficient condition.
