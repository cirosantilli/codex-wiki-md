# Schwartz function

↑ **Parent:** [Schwartz space](schwartz-space.md)

A Schwartz function is an element of the [Schwartz space](schwartz-space.md): it is a [smooth function](smooth-function.md) and every derivative decreases faster than every inverse polynomial. Equivalently, $x^\alpha D^\beta f(x)$ defines a [bounded function](bounded-function.md) for every pair of [multi-indices](multi-index-notation.md) $\alpha,\beta$.
