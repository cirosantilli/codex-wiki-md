# Opponent color processing

↑ **Parent:** [Color vision](color-vision.md)

A class of post-receptoral computations comparing signals from different cone populations, for example a gain-weighted L–M difference and an S versus L+M comparison. Such comparisons distinguish spectral differences from shared changes in illumination [intensity](intensity-physics.md). Receptor counts, signal gains and later appearance judgments need not vary proportionally.
