# Square matrix

↑ **Parent:** [Matrix](matrix.md)

A [matrix](matrix.md) with the same number of rows and columns represents an [endomorphism](endomorphism.md) of a finite-dimensional [vector space](vector-space-split.md) after choosing a [basis](basis.md). Square matrices support [trace](matrix-trace.md), [determinant](determinant.md), powers and the [matrix exponential](matrix-exponential.md).
