# Material-arm winding in a differentially rotating galaxy

↑ **Parent:** [Spiral density wave](spiral-density-wave.md)

Two radii with different orbital frequencies develop a relative angular displacement $\Delta\phi=\Delta\Omega\,t$. A spiral made of a fixed set of stars therefore winds increasingly tightly. A [density](density.md) pattern need not follow that material winding because matter can pass through it.
