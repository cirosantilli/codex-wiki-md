# Open bosonic string mass spectrum

↑ **Parent:** [Bosonic string mass spectrum](bosonic-string-mass-spectrum.md)

The [string level operator](string-level-operator.md) for a free-ended [open string](open-string.md) is $N=\sum_{k>0}\alpha_{-k}\cdot\alpha_k$. The quantum condition is $\alpha'M^2=N-a$, where $a$ is the [normal-ordering constant of a string](normal-ordering-constant-of-a-string.md). Lorentz-consistent [bosonic string theory](bosonic-string-theory.md) has $a=1$.
