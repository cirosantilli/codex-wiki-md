# Keplerian disk

↑ **Parent:** [Astrophysical disk](astrophysical-disk.md)

A Keplerian disk rotates with angular frequency $\Omega_K=\sqrt{GM/r^3}$ set mainly by a central mass, so $\Omega_K\propto r^{-3/2}$.
