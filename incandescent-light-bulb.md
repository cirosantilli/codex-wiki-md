# Incandescent light bulb

↑ **Parent:** [Electrical engineering](electrical-engineering-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Incandescent_light_bulb)

An electric lamp whose current heats a filament until it emits visible [thermal radiation](thermal-radiation.md). [Joule heating](joule-heating.md) converts electrical input into thermal energy and radiation. Its [electrical resistance](electrical-resistance.md) changes with [temperature](temperature-split.md), so one fixed resistor value need not describe different operating voltages.
