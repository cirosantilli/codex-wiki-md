# Simple locally finite point measure

↑ **Parent:** [Point process](point-process.md)

A point [measure](measure.md) is a countable sum of [Dirac measures](dirac-measure.md). It is simple if all its atoms have mass one, and locally finite if every bounded set has finite mass. Simplicity lets fine enough cells count individual points, whereas occupation indicators would lose multiplicities in a nonsimple [measure](measure.md).
