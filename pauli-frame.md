# Pauli frame

↑ **Parent:** [Pauli group](pauli-group.md)

A Pauli frame is a classical record of known [Pauli operator](pauli-operator.md) byproducts rather than their physical correction. A one-[qubit](qubit.md) frame $X^aZ^b$ changes a [computational basis](computational-basis.md) measurement label by $a$; $b$ changes only a phase. Conjugation by [Clifford gates](clifford-gate.md) maps [Pauli operators](pauli-operator.md) to [Pauli operators](pauli-operator.md), so the frame can be updated by classical binary arithmetic throughout a [Clifford circuit](clifford-circuit.md).
