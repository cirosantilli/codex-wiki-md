# Ray asymptotics of a clamped elastic waveguide mode

↑ **Parent:** [Rigid elastic waveguide mode](rigid-elastic-waveguide-mode.md)

A [shear-horizontal wave](shear-horizontal-wave.md) mode has $\omega_n(k)=c_s\sqrt{k^2+(n\pi/h)^2}$. At $x=Vt$ with $0<|V|<c_s$, a nondegenerate stationary Fourier phase gives generic $t^{-1/2}$ decay. Faster rays have no [stationary point](stationary-point.md); compactly supported data give eventual zero by [finite propagation speed](finite-propagation-speed.md).
