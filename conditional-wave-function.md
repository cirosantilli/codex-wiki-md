# Conditional wave function

↑ **Parent:** [de Broglie-Bohm theory](de-broglie-bohm-theory.md)

In the spinless version of [Bohmian mechanics](de-broglie-bohm-theory.md), insert the actual environment configuration $Y(t)$ into a total [wave function](wave-function-split.md) $\Psi(x,y,t)$ to obtain a subsystem's conditional wave function, when that slice is nonzero. It encodes the actual environment relevant to the subsystem's guiding dynamics. It need not satisfy an autonomous subsystem [Schrödinger equation](schrodinger-equation.md); further separation conditions are needed for an effective wave function.[section 2.2](quantum-equilibrium-and-the-role-of-operators-as-observables-in-quantum-theory-by-detlef-durr-and-others.md)
