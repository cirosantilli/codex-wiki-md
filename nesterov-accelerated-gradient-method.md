# Nesterov accelerated gradient method

↑ **Parent:** [Convex optimization](convex-optimization-split.md)

For a convex objective with an $L$-Lipschitz [gradient](gradient.md), Nesterov's accelerated gradient method reaches objective error $\delta$ in $O(\sqrt{LR^2/\delta})$ iterations when a minimizer lies within distance $R$ of the initial point.

This is an accelerated variant of [gradient descent](gradient-descent.md); it should not be identified with every first-order or proximal gradient method.
