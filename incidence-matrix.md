# Incidence matrix

↑ **Parent:** [Graph](graph-split.md)

A vertex-edge incidence matrix records which [vertices](vertex-graph-theory.md) are endpoints of each [edge](edge-of-a-graph.md) of a [graph](graph-split.md). The unsigned convention uses entries one at the endpoints, with a convention for loops. Choosing an orientation gives the [oriented incidence matrix](oriented-incidence-matrix.md), with minus one at the initial endpoint and plus one at the terminal endpoint. These are different conventions and should be specified when using the matrix in a computation.
