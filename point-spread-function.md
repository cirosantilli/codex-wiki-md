# Point spread function

↑ **Parent:** [Physical optics](physical-optics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Point_spread_function)

The point spread function is the image of an unresolved point source. It describes blurring from [diffraction](diffraction.md), [optical aberrations](optical-aberration.md), and [astronomical seeing](astronomical-seeing.md).
