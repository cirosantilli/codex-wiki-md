# Channel encoder

↑ **Parent:** [Discrete memoryless channel](discrete-memoryless-channel.md)

For deterministic block transmission without feedback, a [channel encoder](channel-encoder.md) maps each message label to an input word of length $n$ over an [alphabet](alphabet.md) $\mathcal X$. These words are the [codewords](codeword.md) of a [block code](block-code.md). Distinct messages should have distinct [codewords](codeword.md): if two labels give the same word, even a noiseless [communication channel](communication-channel.md) cannot tell them apart. The [channel encoder](channel-encoder.md) may add redundancy, so the transmitted word can be longer than the message representation.
