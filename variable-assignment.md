# Variable assignment

↑ **Parent:** [Programming language syntax](programming-language-syntax.md)

A program action that associates a value with a target name. For [Python](python-programming-language.md) `x=2+3*4`, evaluate the right-hand [program expression](program-expression.md) and bind `x` to its result. [Python language reference, section 7.2: assignment to an identifier and evaluation of the right-hand side](https://docs.python.org/3.14/reference/simple_stmts.html#assignment-statements)
