# Multiple edges

↑ **Parent:** [Undirected graph](undirected-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multiple_edges)

[Multiple edges](multiple-edges.md) are distinct [edges](edge-of-a-graph.md) with the same pair of endpoint [vertices](vertex-graph-theory.md) in an [undirected graph](undirected-graph.md). A [multigraph](multigraph.md) permits them; a [simple graph](simple-graph.md) does not. In an [orientation of a graph](orientation-of-a-graph.md) of a [multigraph](multigraph.md), each such [edge](edge-of-a-graph.md) receives its own direction, so two of them can supply opposite [directed edges](directed-edge.md) between the same [vertices](vertex-graph-theory.md).
