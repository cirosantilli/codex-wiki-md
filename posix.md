# POSIX

↑ **Parent:** [Operating system](operating-system-split.md)

The Portable Operating System Interface standards specify interfaces and observable behaviour for portable programs, including [file descriptors](file-descriptor.md), [hard links](hard-link.md) and [unlinking an open file](unlinking-an-open-file.md). Their requirements do not prescribe one on-storage [inode](inode.md) layout. The worked examples below use [POSIX](posix.md) [Unix](unix.md) semantics for ordinary [files](computer-file.md). [The Open Group, POSIX.1-2024, definitions of files, directories and file descriptors](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap03.html)
