# Empty function

↑ **Parent:** [Function](function-split.md)

The empty function has empty domain and empty graph. For any specified codomain there is exactly one function from the empty set into it. This explains why a [cardinal product](cardinal-product.md) over an empty index set is one, including the convention $0^0=1$ in [cardinal exponentiation](cardinal-exponentiation.md).
