# Loop momentum

↑ **Parent:** [Loop order](loop-order.md)

A loop momentum is an independent momentum integrated over in a [Feynman diagram](feynman-diagram.md). Momentum conservation leaves one independent loop momentum for each cycle counted by the [loop order](loop-order.md).
