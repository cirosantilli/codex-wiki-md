# Hindley-Milner type inference

↑ **Parent:** [Hindley-Milner type system](hindley-milner-type-system.md)

Inference of a [principal type](principal-type.md) in the [Hindley-Milner type system](hindley-milner-type-system.md) uses fresh [type variables](type-variable.md) and [type unification](type-unification.md) to satisfy the constraints imposed by expressions. A successful result describes every valid monomorphic instance through [type substitution](type-substitution.md); generalization at suitable bindings forms a [type scheme](type-scheme.md) for later instantiation.
