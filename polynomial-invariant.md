# Polynomial invariant

↑ **Parent:** [Polynomial invariant ring](polynomial-invariant-ring.md)

For a [group representation](group-representation.md) on $V$, a polynomial invariant is a [polynomial](polynomial-split.md) $p$ satisfying $p(gv)=p(v)$ for every $g\in G$. Homogeneous degree-$d$ invariants form $(\operatorname{Sym}^d V^*)^G$. Using the [symmetric power](symmetric-power.md) matters: an alternating [invariant tensor](invariant-tensor.md) contracted with repeated copies of the same commuting vector can vanish.
