# Full second-order replacement rank obstruction

↑ **Parent:** [Axiom schema of replacement](axiom-schema-of-replacement.md)

If $V_\lambda$, for an infinite [cardinal number](cardinal-number.md) $\lambda$, satisfies [Axiom schema of replacement](axiom-schema-of-replacement.md) for every external functional class, then an external cofinal [function](function-split.md) from an [ordinal](ordinal.md) below $\lambda$ cannot exist: its range would have [rank of a set](rank-of-a-set.md) $\lambda$ and would have to belong to $V_\lambda$. Similarly, a [surjection](surjective-function.md) $\mathcal P(\theta)\to\lambda$ with $\theta<\lambda$ is impossible. Infinity therefore makes $\lambda$ an uncountable [regular cardinal](regular-cardinal.md) and a [strong limit cardinal](strong-limit-cardinal.md). [Full semantics for second-order logic](full-semantics-for-second-order-logic.md), allowing arbitrary external functional relations, is essential.
