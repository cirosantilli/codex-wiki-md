# Drawdown (economics)

↑ **Parent:** [Mathematical finance](mathematical-finance-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Drawdown_(economics))

The absolute decline from a previous running peak of a cumulative-value process. For positive peak values a relative decline can also be defined, but that is a different unit convention. Flat intervals do not end a drawdown, and a brief recovery that stays below the previous peak does not necessarily end it either. A maximum consecutive strictly negative run is therefore not generally a maximum drawdown.
