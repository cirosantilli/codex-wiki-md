# Rate function under scalar clipping

↑ **Parent:** [Contraction principle for large deviations](contraction-principle-for-large-deviations.md)

For $a<b$, the [contraction principle for large deviations](contraction-principle-for-large-deviations.md) under [scalar clipping](scalar-clipping.md) gives $K(z)=I(z)$ in $(a,b)$, the displayed endpoint costs, and infinite cost outside $[a,b]$. The endpoint costs can differ from $I(a)$ and $I(b)$ because clipping collects a whole input tail into a single output atom.
