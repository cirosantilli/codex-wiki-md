# Recursion invariant

↑ **Parent:** [Algorithm correctness](algorithm-correctness.md)

A relationship between a recursive procedure's arguments, accumulated state and original input that holds at every reachable [recursive call](recursive-call.md). For accumulator-based [exponentiation by squaring](exponentiation-by-squaring.md), $acc\,base^{remaining}=x^n$ is a [recursion invariant](recursion-invariant.md) under exact arithmetic. The base case converts it into the desired result, while the recursive step and a decreasing argument justify preservation and termination.
