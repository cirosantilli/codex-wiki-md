# Uniformly convex space

↑ **Parent:** [Normed vector space](normed-vector-space.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Uniformly_convex_space)

A [normed vector space](normed-vector-space.md) is uniformly convex if, for each $\varepsilon>0$, there is $\delta>0$ such that unit-ball vectors $x,y$ with $\lVert x-y\rVert\geq\varepsilon$ satisfy $\lVert(x+y)/2\rVert\leq1-\delta$. Completeness is not part of this definition; a complete example is a [uniformly convex Banach space](uniformly-convex-banach-space.md).
