# Random effect

↑ **Parent:** [Latent variable](latent-variable.md)

A random effect is a [latent variable](latent-variable.md) used to describe variation between observational units or dependence among related observations. Its distribution supplements the fixed effects used in [statistical modelling](statistical-modelling-split.md). Independent random effects produce extra variability; correlated random effects can produce serial dependence.
