# Polynomial-time many-one reduction

↑ **Parent:** [Polynomial-time reduction](polynomial-time-reduction.md)

A polynomial-time many-one reduction from a [decision problem](decision-problem.md) $A$ to a decision problem $B$ is a polynomial-time computable function $r$ satisfying $x\in A$ exactly when $r(x)\in B$.
