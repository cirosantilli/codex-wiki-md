# T1 space

↑ **Parent:** [Separation axiom](separation-axiom.md)

A [topological space](topological-space.md) is T1 when every point is a [closed point](closed-point.md). Equivalently, for distinct $x,y$ there is an open set containing $x$ but not $y$, and an open set containing $y$ but not $x$. These open sets need not be disjoint. Every [Hausdorff space](hausdorff-space.md) is T1, but an infinite set with its [cofinite topology](cofinite-topology.md) is T1 without being Hausdorff.
