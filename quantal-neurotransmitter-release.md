# Quantal neurotransmitter release

↑ **Parent:** [Synaptic vesicle](synaptic-vesicle.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantal_neurotransmitter_release)

[Quantal neurotransmitter release](quantal-neurotransmitter-release.md) is release of [neurotransmitter](neurotransmitter.md) in discrete packets associated with individual [synaptic vesicles](synaptic-vesicle.md). Packet count and postsynaptic packet response are different quantities; see the [binomial distribution](binomial-distribution.md) example under [synaptic vesicle](synaptic-vesicle.md).
