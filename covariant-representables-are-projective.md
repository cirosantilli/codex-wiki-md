# Covariant representables are projective

↑ **Parent:** [Projective object](projective-object.md)

For a [locally small category](locally-small-category.md) $\mathcal C$, every [representable functor](representable-functor.md) $\mathcal C(A,-)$ is a [projective object in a category](projective-object.md) in $[\mathcal C,\mathbf{Set}]$. The [Yoneda lemma](yoneda-lemma.md) identifies maps from this functor with elements at $A$, and the [pointwise epimorphism in a functor category](pointwise-epimorphism-in-a-functor-category.md) criterion lets such an element be lifted through any epimorphism.
