# Neutron diffusion coefficient

↑ **Parent:** [One-group neutron diffusion equation](one-group-neutron-diffusion-equation.md)

The coefficient in $\mathbf J=-D\nabla\phi$ for the scalar [neutron flux](neutron-flux.md) convention. It has dimensions of length, unlike a particle-density [diffusion coefficient](diffusion-coefficient.md) with dimensions length squared per time. For a single fixed speed $v$, the corresponding density [diffusion coefficient](diffusion-coefficient.md) is $vD$.
