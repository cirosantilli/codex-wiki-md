# Callee-saved register

↑ **Parent:** [Calling convention](calling-convention.md)

A [processor register](processor-register.md) whose incoming value a called subroutine must restore before returning if it modifies it. This lets a caller retain live values across calls, but the caller must in turn preserve its own caller's values when using these [processor registers](processor-register.md).
