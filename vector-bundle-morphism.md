# Vector bundle morphism

↑ **Parent:** [Vector bundle](vector-bundle.md)

A morphism of [vector bundles](vector-bundle.md) over one base is a smooth map between their total spaces that commutes with projection to the base and is linear on each fiber. In local [vector bundle trivializations](vector-bundle-trivialization.md) it is multiplication by a smoothly varying [matrix](matrix.md).
