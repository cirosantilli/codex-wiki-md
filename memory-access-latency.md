# Memory access latency

↑ **Parent:** [Cache (computing)](cache-computing.md)

The time from a [memory reference](memory-reference.md)'s request until the requested data become available. [Average memory access time](average-memory-access-time.md) averages this delay in the stated serial model; it does not directly measure whole-program runtime.
