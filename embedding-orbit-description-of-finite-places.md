# Embedding orbit description of finite places

↑ **Parent:** [Embedding of a number field into a p-adic algebraic closure](embedding-of-a-number-field-into-a-p-adic-algebraic-closure.md)

Finite [places of a number field](place-of-a-number-field.md) above $p$ correspond to absolute [Galois group](galois-group.md) orbits of [embeddings of a number field into a p-adic algebraic closure](embedding-of-a-number-field-into-a-p-adic-algebraic-closure.md). The absolute value is invariant under the group. Conversely, embeddings inducing the same place extend to embeddings of the same local completion and are conjugate.
