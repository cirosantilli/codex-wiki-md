# Single-valued wavefunction

↑ **Parent:** [Wave function](wave-function-split.md)

An ordinary scalar [wavefunction](wave-function-split.md) assigns one complex amplitude to each physical configuration. In [polar coordinates](polar-coordinates.md) without an additional twisted boundary condition, the points $(r,\phi)$ and $(r,\phi+2\pi)$ are identical, so the angular factor must be periodic. An angular [eigenfunction](eigenfunction.md) $e^{im\phi}$ therefore requires integer $m$. This scalar orbital condition does not rule out half-integer intrinsic [spin](spin.md).
