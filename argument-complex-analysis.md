# Argument (complex analysis)

↑ **Parent:** [Complex number](complex-number.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Argument_(complex_analysis))

An argument of a nonzero [complex number](complex-number.md) $z$ is any angle $\theta$ for which $z=|z|e^{i\theta}$. Arguments differ by integer multiples of $2\pi$; choosing one representative defines a branch of the argument.
