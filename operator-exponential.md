# Operator exponential

↑ **Parent:** [Operator theory](linear-operator-theory-split.md)

For a bounded [linear operator](linear-operator.md), the series $e^A=\sum_{n=0}^\infty A^n/n!$ converges in [operator norm](operator-norm.md). For an unbounded [self-adjoint operator](self-adjoint-operator.md) $H$, the [spectral theorem](spectral-theorem.md) instead defines the bounded [unitary operator](unitary-operator.md) $e^{-iHt/\hbar}$ by applying the scalar function $e^{-iEt/\hbar}$ to its [projection-valued measure](projection-valued-measure.md). This yields [unitary time evolution](unitary-time-evolution.md) without assuming that every vector lies in the domain of every power of $H$. In finite dimensions it is the [matrix exponential](matrix-exponential.md).
