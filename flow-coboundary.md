# Flow coboundary

↑ **Parent:** [Smooth flow](smooth-flow.md)

A smooth function $h$ is a flow coboundary if $h=Fu$ for some smooth function $u$, where $F$ is the flow generator. Equivalently $u(\phi_t x)-u(x)=\int_0^t h(\phi_sx)\,ds$. Thus its integral over every periodic orbit is zero. For a transitive [Anosov flow](anosov-flow.md), the [Livsic theorem](livsic-theorem.md) supplies the converse and smooth regularity.
