# Algebraic extension

↑ **Parent:** [Field extension](field-extension.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algebraic_extension)

A [field extension](field-extension.md) $L/K$ is algebraic if every element of $L$ is an [algebraic element](algebraic-element.md) over $K$. Every [finite field extension](finite-field-extension.md) is algebraic, but algebraic extensions can have infinite degree.
