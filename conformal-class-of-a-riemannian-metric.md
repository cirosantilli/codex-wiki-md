# Conformal class of a Riemannian metric

↑ **Parent:** [Conformal rescaling of a Riemannian metric](conformal-rescaling-of-a-riemannian-metric.md)

Two [Riemannian metrics](riemannian-metric-split.md) lie in the same conformal class when one is a positive smooth scalar multiple of the other. They measure the same [angles](angle.md), while [lengths](length.md) may change from point to point. On an oriented [Riemannian surface](riemannian-surface.md), rotation of each [tangent plane](tangent-plane.md) through $\pi/2$ determines a [complex structure](complex-structure.md) which depends only on this conformal class.
