# Elementary abelian group

↑ **Parent:** [Finite abelian group](finite-abelian-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Elementary_abelian_group)

An elementary abelian $p$-group is a finite [abelian group](abelian-group.md) in which every nonidentity element has order $p$. It is equivalently a finite-dimensional [vector space](vector-space-split.md) over $\mathbb F_p$ under addition.
