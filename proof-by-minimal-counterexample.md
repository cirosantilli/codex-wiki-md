# Proof by minimal counterexample

↑ **Parent:** [Well-ordering principle for the natural numbers](well-ordering-principle-for-the-natural-numbers.md)

Assume that a proposed statement fails for some [natural number](natural-number.md), and choose the least failing index using the [well-ordering principle](well-ordering-principle-for-the-natural-numbers.md). Prove the necessary base cases and reduce the least failure to a smaller index that must satisfy the statement. If that smaller case implies the alleged failure also satisfies it, there is a [contradiction](contradiction.md). Reductions by a step larger than one require enough consecutive base cases to cover every possible residue class.
