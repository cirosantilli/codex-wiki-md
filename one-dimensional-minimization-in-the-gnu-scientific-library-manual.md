# One dimensional minimization in the GNU Scientific Library manual

↑ **Parent:** [Mathematics bibliography](mathematics-bibliography-split.md)

Official manual: [One Dimensional Minimization](https://www.gnu.org/software/gsl/doc/html/min.html).

The “Caveats” subsection derives the loss of position accuracy proportional to the square root of [function](function-split.md)-value relative accuracy near a nonzero minimum with positive [second derivative](second-derivative.md). “Minimization Algorithms” describes [golden-section search](golden-section-search.md) and its linear contraction. The claims concern standard mathematical precision effects, not an assertion that later software releases were available for a historical examination.
