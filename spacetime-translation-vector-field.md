# Spacetime translation vector field

↑ **Parent:** [Commutation vector field for the wave equation](commutation-vector-field-for-the-wave-equation.md)

The [vector fields](vector-field.md) $\partial_t$ and $\partial_i$ generate time and space translations and commute with the flat [d'Alembert operator](d-alembert-operator.md). They form the unweighted part of the [commutation vector fields for the wave equation](commutation-vector-field-for-the-wave-equation.md).
