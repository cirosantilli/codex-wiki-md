# Vacuum expectation value

↑ **Parent:** [Spontaneous symmetry breaking](spontaneous-symmetry-breaking.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Vacuum_expectation_value)

A vacuum expectation value is the expectation of a field or operator in the vacuum state. A nonzero value that is not invariant under the full symmetry group can select a point of the [vacuum manifold](vacuum-manifold.md) and spontaneously break the symmetry.
