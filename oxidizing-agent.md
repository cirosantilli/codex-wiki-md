# Oxidizing agent

↑ **Parent:** [Redox](redox.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Oxidizing_agent)

An [oxidizing agent](oxidizing-agent.md) undergoes [reduction](reduction-chemistry.md) by accepting the formal [electron](electron.md) inventory. In the [zinc-copper displacement experiment](zinc-copper-displacement-experiment.md), $\mathrm{Cu}^{2+}$ plays this role.[§4.2, “Oxidation-Reduction Reactions”: oxidizing agent is the species reduced](chemistry-2e-by-paul-flowers-and-others.md)
