# Spherical magnetospheric pressure balance

↑ **Parent:** [Magnetospheric truncation radius](magnetospheric-truncation-radius.md)

A dipole's [magnetic pressure](magnetic-pressure.md) scales as $B_*^2R_*^6/(\mu_0r^6)$. Spherical [free fall](free-fall.md) with $\rho=\dot M/(4\pi r^2v)$ and $v\propto(GM/r)^{1/2}$ has [ram pressure](ram-pressure.md) proportional to $\dot M(GM)^{1/2}r^{-5/2}$. Equating them gives the seventh-root scaling. Disc geometry changes the coefficient; the estimate ceases to describe an exterior magnetosphere if the resulting radius lies inside the star.
