# Finiteness of the projective Clifford group

↑ **Parent:** [Clifford group (quantum computing)](clifford-group-quantum-computing.md)

For fixed $n$, a [Clifford gate](clifford-gate.md) permutes the finite [Pauli group](pauli-group.md) by [conjugation](conjugation.md). Its action is determined by the images of $X_j,Z_j$, so there are finitely many possible such actions. If two [unitary operators](unitary-operator.md) induce the same action, their quotient commutes with every $Z_j$ and is diagonal in the [computational basis](computational-basis.md). Commutation with every $X_j$ equates diagonal entries at bit strings differing in one position; those flips connect all strings, so the quotient is a scalar. A unitary scalar is a [global phase](global-phase.md). Thus the [Clifford group](clifford-group-quantum-computing.md) modulo [global phase](global-phase.md) is finite and cannot approximate every unitary arbitrarily well. This proves the obstruction for any fixed number of wires, rather than relying solely on a one-qubit picture.[Section 3 and Table 1, Pauli normalizer and Clifford generators](the-heisenberg-representation-of-quantum-computers-by-daniel-gottesman.md)
