# Markov information source

↑ **Parent:** [Information theory](information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Markov_information_source)

A [Markov information source](markov-information-source.md) uses a stationary [finite Markov chain](finite-markov-chain.md) to emit symbols. The emitted symbol can be a [function](function-split.md) of the state. If it does not identify that state, the observed sequence need not itself be a [Markov chain](markov-chain.md). The examples here use a [fully observed Markov source](fully-observed-markov-source.md), which makes the next-symbol uncertainty directly computable from the [transition matrix](stochastic-matrix.md).
