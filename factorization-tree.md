# Factorization tree

↑ **Parent:** [Fundamental theorem of arithmetic](fundamental-theorem-of-arithmetic.md)

A [factorization tree](factorization-tree.md) is a [rooted tree](rooted-tree.md) whose root is an [integer](integer.md) $n>1$. Each nonleaf label is a [composite number](composite-number.md) split into two factors greater than one whose [product](product-of-numbers.md) equals that label; the leaves are [prime numbers](prime-number.md). Multiplying the leaves recovers $n$. Many [factorization trees](factorization-tree.md) can have the same root, but the [fundamental theorem of arithmetic](fundamental-theorem-of-arithmetic.md) gives them the same leaf [multiset](multiset.md).
