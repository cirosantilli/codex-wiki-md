# Strong c-monotonicity

↑ **Parent:** [C-cyclical monotonicity](c-cyclical-monotonicity.md)

A [transport plan](transport-plan.md) is strongly c-monotone if Borel [Kantorovich potentials](kantorovich-potential.md) satisfy the displayed feasible inequality everywhere and equality almost everywhere for the plan. Extended values $-\infty$ away from the full marginal-[measure](measure.md) sets may be permitted. This is a potential certificate, not a strict version of every cyclic inequality. A finite continuous cost allows the [transport potential path construction](transport-potential-path-construction.md).
