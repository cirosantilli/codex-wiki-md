# Fermat primality test

↑ **Parent:** [Primality testing](primality-testing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fermat_primality_test)

The Fermat test looks for a coprime base $a$ with $a^{N-1}\not\equiv1\pmod N$. Such a witness proves compositeness by the [Fermat little theorem](fermat-little-theorem.md), but [Carmichael numbers](carmichael-number.md) pass for every coprime base.
