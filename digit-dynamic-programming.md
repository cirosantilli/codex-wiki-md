# Digit dynamic programming

↑ **Parent:** [Dynamic programming](dynamic-programming.md)

Count or sum [integers](integer-split.md) by processing their [numerical digits](numerical-digit.md) and merging prefixes that have the same possible continuations. Typical state records include the current position, whether the prefix still equals an upper limit, a [remainder](remainder.md), or a [bit mask](bit-mask.md) of digits already used. The final answer comes from accepting exactly those states satisfying the desired digit constraints.
