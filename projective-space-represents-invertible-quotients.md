# Projective space represents invertible quotients

↑ **Parent:** [Projective space](projective-space-split.md)

With the quotient convention, [projective space](projective-space-split.md) represents the [functor](functor.md) of surjections from a rank-$n+1$ [free sheaf](free-sheaf.md) to a [line bundle](line-bundle.md), modulo isomorphisms of the target compatible with the map. On an affine base the target may be a nontrivial rank-one [projective module](projective-module.md), so a tuple of elements generating the unit ideal is only the description when that target is trivial. Where the image of the $i$th basis vector generates the target, divide the other images by it to get the usual affine coordinates. Infinitesimal variations of the quotient form $\mathcal H om(\ker q,\mathcal L)$ and give the [Euler sequence](euler-sequence.md).
