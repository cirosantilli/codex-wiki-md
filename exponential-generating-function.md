# Exponential generating function

↑ **Parent:** [Generating function](generating-function.md)

An exponential [generating function](generating-function.md) encodes a [sequence](sequence.md) using the displayed [factorial](factorial.md) denominators. It is especially useful for counting labelled combinatorial structures: taking an unordered set of structures with positive size corresponds to exponentiating their exponential generating function. The [rooted-tree generating function](rooted-tree-generating-function.md) illustrates this through $T=z e^T$.
