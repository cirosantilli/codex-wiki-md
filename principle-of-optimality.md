# Principle of optimality

↑ **Parent:** [Dynamic programming](dynamic-programming.md)

After fixing an initial decision in an optimal solution, the remaining decisions must solve the resulting residual problem optimally, with the relevant state and constraints retained. Otherwise substituting a better continuation would improve the original solution. This replacement argument justifies [dynamic programming recurrences](dynamic-programming-recurrence.md) when the chosen [dynamic programming state](dynamic-programming-state.md) contains all information needed by future decisions.
