# Monotone subsequence

↑ **Parent:** [Subsequence](subsequence.md)

A monotone subsequence is a [subsequence](subsequence.md) which is a [monotone sequence](monotone-sequence.md). The indices always increase strictly, but equal selected values are permitted. The [monotone subsequence theorem](monotone-subsequence-theorem.md) guarantees one for every [sequence](sequence.md) of [real numbers](real-number.md).
