# Grouped Bernoulli failure counts

↑ **Parent:** [Binomial proportion](binomial-proportion.md)

With $m$ groups of $q$ trials and common marginal failure [probability](probability.md) $p$, each count $X_j$ has [expectation](expected-value.md) $qp$, so the displayed estimate is unbiased without assuming independence within groups. Independent individual trials give [variance](variance-split.md) $p(1-p)/(mq)$. If only groups are independent, estimate the [variance](variance-split.md) instead by $s_X^2/(mq^2)$, retaining within-group dependence. Equal marginal probabilities alone do not justify a binomial [confidence interval](confidence-interval.md).
