# Backing file

↑ **Parent:** [Memory-mapped file](memory-mapped-file.md)

The [file](computer-file.md) supplying a [memory-mapped file](memory-mapped-file.md)'s initial contents. Its logical [file offsets](file-offset.md) identify data independently of the [virtual addresses](virtual-address.md) chosen by different [operating-system processes](process-computing.md). Modified [private file mapping](private-file-mapping.md) contents have private storage; they are not updates waiting to be written to the [backing file](backing-file.md).
