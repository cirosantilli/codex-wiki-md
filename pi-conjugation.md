# Pi conjugation

↑ **Parent:** [Conjugated system](conjugated-system.md)

Overlap between adjacent p-type [atomic orbitals](atomic-orbital.md) permits delocalized electronic states across more than one [chemical bond](chemical-bond-split.md). A cyclic path with suitable occupancy can support [aromaticity](aromaticity.md); an external [lone pair](lone-pair.md) can act as a donor without contributing an extra independent pair to every ring count.
