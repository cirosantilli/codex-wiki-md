# Freiman 2-isomorphism

↑ **Parent:** [Freiman s-isomorphism](freiman-s-isomorphism.md)

A [Freiman 2-isomorphism](freiman-2-isomorphism.md) is a [bijection](bijection.md) between subsets of [abelian groups](abelian-group.md) preserving additive quadruple relations in both directions. It need not extend to an ambient group homomorphism. Multiplication by a nonzero [scalar](scalar.md) in a [finite field](finite-field.md) and [translation](translation-geometry.md) are examples; reduction of an [integer](integer.md) set modulo a prime is an example only when it creates no new additive relations.
