# Speed of a graph property

↑ **Parent:** [Graph property](graph-property.md)

The speed counts the labelled [graphs](graph-split.md) with a given property on [vertex](vertex-graph-theory.md) set $[n]$. For proper unbounded [hereditary graph properties](hereditary-graph-property.md), its base-two logarithm has leading term $(1-1/r)\binom n2$, where $r$ is the property's colouring number.
