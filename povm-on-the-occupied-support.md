# POVM on the occupied support

↑ **Parent:** [Positive operator-valued measure](positive-operator-valued-measure.md)

If every allowed input [density operator](density-matrix-split.md) has [support of a positive operator](support-of-a-positive-operator.md) inside a subspace with [orthogonal projector](orthogonal-projection.md) $P$, completeness need only equal $P$ on that subspace. To define a measurement on the full [Hilbert space](hilbert-space-split.md), one can append $M_\perp=I-P$ when the original operators act only on the subspace. The added outcome has zero probability on supported inputs. The effects $M_r^\dagger M_r$ form a [POVM](positive-operator-valued-measure.md); the operators themselves additionally specify state updates.
