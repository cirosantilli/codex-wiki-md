# Hofer metric

↑ **Parent:** [Compactly supported Hamiltonian diffeomorphism group](compactly-supported-hamiltonian-diffeomorphism-group.md)

The displayed distance uses the oscillation length of a compactly supported [Hamiltonian isotopy](hamiltonian-isotopy.md). On a closed manifold one may normalize each Hamiltonian to have zero mean. Additive time-dependent constants do not change the flow or its oscillation. Pullback by a [symplectomorphism](symplectomorphism.md) preserves extrema, so this distance is bi-invariant. Nondegeneracy requires an additional geometric argument; it does not follow merely from the definition as an infimum of path lengths.
