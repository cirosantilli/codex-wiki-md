# Linear extension

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linear_extension)

A linear extension is a total ordering of the elements of a [partially ordered set](partially-ordered-set.md) that preserves all its comparisons. For a finite set it can be recorded as a list. If two adjacent elements in that list are incomparable, their interchange is again a linear extension.
