# Canonical models of complete theories are prime

↑ **Parent:** [Prime model](prime-model.md)

Let two [first-order models](model-of-a-first-order-theory.md) satisfy a [complete theory](complete-theory.md) and suppose every element of the first is the value of a [closed term](closed-term.md). Send each such value to the value of the same [first-order term](first-order-term.md) in the second [first-order model](model-of-a-first-order-theory.md). Completeness decides all [logical equality](logical-equality.md) [first-order sentences](first-order-sentence.md), making this map well-defined and [injective](injective-function.md). It also decides every [logical formula](logical-formula.md) with [closed terms](closed-term.md) substituted, making the map elementary. Thus the first [first-order model](model-of-a-first-order-theory.md) is prime.
