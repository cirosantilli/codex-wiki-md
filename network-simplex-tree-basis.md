# Network simplex tree basis

↑ **Parent:** [Network simplex algorithm](network-simplex-algorithm.md)

For a connected capacitated [minimum-cost flow](minimum-cost-flow-problem.md) network, a [spanning tree](spanning-tree.md) supplies basic flow variables. Every non-tree edge is fixed at its lower or upper bound. [Flow balance](flow-balance.md) determines the tree flows; these must also obey [capacity constraints](capacity-constraint.md). An entering edge creates one cycle, and adjusting flow on that cycle preserves balance until a bound is hit and an edge leaves the tree.
