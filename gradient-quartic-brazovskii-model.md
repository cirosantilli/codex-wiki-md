# Gradient-quartic Brazovskii model

↑ **Parent:** [Brazovskii model](brazovskii-model.md)

A gradient-quartic Brazovskii model stabilizes a negative quadratic gradient coefficient with $\gamma(\nabla^2\phi)^2/2$ and uses the quartic interaction $B\phi^2|\nabla\phi|^2$. For $\gamma,B>0$ and a zero-average [compositional order parameter](compositional-order-parameter.md), its nonzero-wavevector instability is a candidate for [smectic phase](smectic-phase.md) ordering. The [Gaussian variational kernel for a gradient quartic interaction](gaussian-variational-kernel-for-a-gradient-quartic-interaction.md) shifts both the quadratic coefficients.
