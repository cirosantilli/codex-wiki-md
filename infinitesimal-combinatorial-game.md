# Infinitesimal combinatorial game

↑ **Parent:** [Partizan game](partizan-game.md)

A game value lying strictly between $-r$ and $r$ for every positive [rational number](rational-number.md) $r$, in the ordering of [partizan games](partizan-game.md). Infinitesimal values can determine a sum whose numerical part is zero, while they cannot overturn a nonzero integer advantage.
