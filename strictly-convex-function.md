# Strictly convex function

↑ **Parent:** [Convex function](convex-function.md)

A function $f$ on a [convex set](convex-set-split.md) is strictly convex when

$$
f(tx+(1-t)y)<tf(x)+(1-t)f(y)
$$

whenever $x\ne y$ and $0<t<1$.
