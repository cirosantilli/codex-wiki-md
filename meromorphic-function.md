# Meromorphic function

↑ **Parent:** [Pole](pole.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Meromorphic_function)

A meromorphic function is [holomorphic](holomorphic-function.md) except at isolated [poles](pole.md). Equivalently, it is locally a quotient of two holomorphic functions whose denominator is not identically zero.
