# Filter base

↑ **Parent:** [Filter (set theory)](filter-set-theory.md)

A [filter base](filter-base.md) is a nonempty family of nonempty [subsets](subset.md) directed under reverse inclusion. Its upward closure is a [proper filter](filter-set-theory.md). Every [finite intersection](finite-intersection.md) contains a base member, so it has the [finite intersection property](finite-intersection-property.md).
