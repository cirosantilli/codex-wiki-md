# Shortest path on a circular cylinder

↑ **Parent:** [Geodesics on a circular cylinder](geodesics-on-a-circular-cylinder.md)

Unroll a [circular cylinder](circular-cylinder.md) of radius $R>0$ using the coordinate $u=R\phi$. Its [line element](line-element.md) becomes $ds^2=du^2+dz^2$, so a [geodesic](geodesic.md) lifts to a [straight line](straight-line.md) in the [plane](plane.md). An endpoint has infinitely many lifts differing by $2\pi Rk$. Minimize the ordinary [Euclidean distance](euclidean-distance.md) over those lifts to obtain the unrestricted shortest path. A fixed lift instead specifies a winding class and need not give the global shortest path.

For angular difference $0\leq\delta\leq2\pi$, put $m=\min(\delta,2\pi-\delta)$. Then $d=\sqrt{R^2m^2+(z_1-z_0)^2}$. At $\delta=\pi$, two different [geodesics](geodesic.md) have the same shortest [length](length.md). This is the source of the corner in the distance-versus-angle graph at the opposite generator of the [circular cylinder](circular-cylinder.md).
