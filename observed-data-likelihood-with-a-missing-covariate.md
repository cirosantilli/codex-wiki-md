# Observed-data likelihood with a missing covariate

↑ **Parent:** [Ignorable missingness mechanism](ignorable-missingness-mechanism.md)

If a regression response $Y$ is observed but covariate $X$ is sometimes missing, [likelihood](likelihood-function.md) inference requires a joint model: for example $f_\beta(y\mid x)g_\eta(x)$. An incomplete record contributes $\int f_\beta(y\mid x)g_\eta(x)\,dx$ to the [observed-data likelihood](observed-data-likelihood.md). [Missing at random](missing-at-random.md) with distinct parameters allows the missingness mechanism to be omitted; it does not remove the need to integrate over $X$.
