# Postnikov tower

↑ **Parent:** [Homotopy group](homotopy-group.md)

A [Postnikov tower](postnikov-tower.md) of a connected [CW complex](cw-complex.md) $X$ consists of spaces $P_nX$ with $\pi_i(P_nX)=\pi_i(X)$ for $i\le n$ and zero for $i>n$, together with compatible maps $X\to P_nX\to P_{n-1}X$. For [simply connected](simply-connected-space.md) $X$, each stage is a [principal Eilenberg–MacLane fibration](principal-eilenberg-maclane-fibration.md) with fibre $K(\pi_nX,n)$, classified by a [Postnikov invariant](postnikov-invariant.md). The canonical map $X\to\operatorname{holim}_nP_nX$ is a weak equivalence: in each [homotopy](homotopy.md) degree the tower is eventually constant, so the derived inverse-limit obstruction vanishes.
