# Number size distribution

↑ **Parent:** [Aerosol](aerosol.md)

A particle count per stated volume and logarithmic size interval. Its [integral](integral-split.md) over $d\ln D$ gives a [number density](number-density.md), unlike an [aerosol](aerosol.md) mass distribution. In a [cloud-droplet activation](cloud-droplet-activation.md) estimate, integrating the dry-size distribution above the size-dependent [Köhler theory](kohler-theory.md) threshold gives activated number for a specified peak [atmospheric supersaturation](atmospheric-supersaturation.md) and composition.
