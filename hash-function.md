# Hash function

↑ **Parent:** [Computer science](computer-science-split.md)

A function mapping a large input set to a smaller set of hash values. It is used to index data or summarize an input; its required properties depend on the task. A [cryptographic hash function](cryptographic-hash-function.md) is designed for computational security properties, whereas a [universal hash family](universal-hash-family.md) controls collision probabilities under random choice of the function.
