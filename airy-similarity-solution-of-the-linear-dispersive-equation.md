# Airy similarity solution of the linear dispersive equation

↑ **Parent:** [Airy equation](airy-equation.md)

Let $y$ solve the [Airy ordinary differential equation](airy-ordinary-differential-equation.md) $y''(s)=sy(s)$. For $t>0$, set $s=x/(3t)^{1/3}$ and define the displayed [similarity solution](similarity-solution.md). Differentiating the profile equation gives $y'''=y+sy'$, so the [chain rule](chain-rule.md) yields

$$
u_t=-\frac13t^{-4/3}(y+sy'),\qquad
u_{xxx}=\frac13t^{-4/3}y'''=\frac13t^{-4/3}(y+sy').
$$

Their sum is zero, proving the [Airy equation](airy-equation.md) $u_t+u_{xxx}=0$. Every real linear combination of the two standard [Airy functions](airy-function.md) gives such a solution. This is a solution of the linear dispersive equation; the nonlinear [Korteweg-De Vries equation](korteweg-de-vries-equation.md) includes an extra term and does not follow from the same arbitrary profile construction.
