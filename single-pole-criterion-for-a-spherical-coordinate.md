# Single-pole criterion for a spherical coordinate

↑ **Parent:** [Meromorphic function as a holomorphic map to the Riemann sphere](meromorphic-function-as-a-holomorphic-map-to-the-riemann-sphere.md)

A nonconstant [meromorphic function](meromorphic-function.md) on a compact [Riemann surface](riemann-surfaces.md) with exactly one [simple pole](simple-pole.md) gives a degree-one holomorphic map to the sphere. A degree-one map is a [biholomorphism](biholomorphism.md). The surface therefore has genus zero and the function is a global rational coordinate.
