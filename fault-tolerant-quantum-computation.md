# Fault-tolerant quantum computation

↑ **Parent:** [Quantum error correction](quantum-error-correction-split.md)

[Quantum computation](quantum-computing.md) organized so that the spread of physical errors can be controlled by [quantum error correction](quantum-error-correction-split.md). Error thresholds depend on the noise model, code, operations and architecture. A correct ideal gate decomposition alone does not establish fault tolerance.
