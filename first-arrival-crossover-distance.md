# First-arrival crossover distance

↑ **Parent:** [Seismic head wave](seismic-head-wave.md)

In a two-layer [P wave](p-wave.md) model, the head-wave branch overtakes the direct upper-layer arrival at $X_c=2H\sqrt{(\alpha_2+\alpha_1)/(\alpha_2-\alpha_1)}$. It differs from the smaller minimum offset needed for the critical-ray construction.
