# Arithmetic absoluteness for a rank-initial model

↑ **Parent:** [Worldly cardinal](worldly-cardinal.md)

If $V_\kappa\models\mathrm{ZFC}$, it has the standard natural numbers and standard finite proofs. Every arithmetical sentence, including a [formal consistency statement](formal-consistency-statement.md), therefore has the same truth value in $V_\kappa$ and the universe.
