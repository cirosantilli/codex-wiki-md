# Quotient Hermitian metric

↑ **Parent:** [Hermitian metric on a holomorphic vector bundle](hermitian-metric-on-a-holomorphic-vector-bundle.md)

For a smooth subbundle $S$ of a [Hermitian vector bundle](hermitian-vector-bundle.md) $E$, [orthogonal projection](orthogonal-projection.md) identifies $E/S$ smoothly with $S^\perp$. The quotient metric is $h_Q([v],[w])=h_E((I-\pi_S)v,(I-\pi_S)w)$. It is independent of representatives and positive definite. For a holomorphic subbundle the resulting smooth quotient metric is defined on the holomorphic quotient, but the orthogonal identification itself need not be holomorphic.
