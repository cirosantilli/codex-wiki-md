# Parity-check extension of a linear code

↑ **Parent:** [Linear code](linear-code.md)

The parity-check extension of a binary [linear code](linear-code.md) appends to each codeword the sum of its coordinates in $\mathbb F_2$, making every extended word have even [Hamming weight](hamming-weight.md).
