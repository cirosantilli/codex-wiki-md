# Gaussian momentum integration in a phase-space path integral

↑ **Parent:** [Phase-space path integral](phase-space-path-integral.md)

Integrating each momentum in a quadratic [Hamiltonian](hamiltonian.md) yields the configuration-space kinetic action and its time-slice normalization. A raw $dp$ measure gives $\sqrt{2\pi m/\Delta t}$; the normalized Fourier measure $dp/(2\pi)$ gives $\sqrt{m/(2\pi\Delta t)}$. Dropping the time dependence changes the [quantum-mechanical propagator](quantum-mechanical-propagator.md).
