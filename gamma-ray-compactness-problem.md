# Gamma-ray compactness problem

↑ **Parent:** [Relativistic jet](relativistic-jet.md)

Rapidly varying high-energy sources can appear too dense in target [photons](photon.md) to transmit their observed [gamma rays](gamma-ray.md). For an approximately isotropic stationary region with target-band [luminosity](luminosity.md) $L_2$, radius $R$ and target [photon](photon.md) [energy](energy-split.md) $\epsilon_2$, the target [number density](number-density.md) is $n\sim L_2/(4\pi R^2c\epsilon_2)$. [photon-photon pair production](photon-photon-pair-production.md) then gives [optical depth](optical-depth.md) $\tau\sim n\sigma R$. A [luminosity variability size bound](luminosity-variability-size-bound.md) can make this very large. [relativistic beaming](relativistic-beaming.md) both increases the inferred rest-frame size and reduces the inferred rest-frame [radiation](radiation.md) density, allowing escape. This radiation-opacity argument is distinct from gravitational stellar compactness and topological compactness.
