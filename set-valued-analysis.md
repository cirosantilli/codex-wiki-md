# Set-valued analysis

↑ **Parent:** [Variational analysis](variational-analysis.md)

Set-valued analysis studies relations whose output at one input is a set. Solution maps, [subdifferentials](subdifferential.md) and generalized normal mappings are important examples. Graph geometry provides definitions of continuity, local stability and differentiation.
