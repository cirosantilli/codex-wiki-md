# Percolation cluster

↑ **Parent:** [Bond percolation](bond-percolation-split.md)

In [bond percolation](bond-percolation-split.md), a [percolation cluster](percolation-cluster.md) is a [connected component of a graph](component-graph-theory.md) formed by the open [edges](edge-of-a-graph.md), with every [graph vertex](vertex-graph-theory.md) retained. In [site percolation](site-percolation-split.md), it is a [connected component of a graph](component-graph-theory.md) of the subgraph induced by the open [graph vertices](vertex-graph-theory.md). Write $C(x)$ for the cluster containing $x$; for [site percolation](site-percolation-split.md) set $C(x)=\varnothing$ when $x$ is closed.
