# Order automorphism

↑ **Parent:** [Total order](total-order.md)

An [order automorphism](order-automorphism.md) of a [total order](total-order.md) $(I,<)$ is a [bijection](bijection.md) $\pi:I\to I$ such that $i<j$ if and only if $\pi(i)<\pi(j)$. Composition and inverses are again [order automorphisms](order-automorphism.md). Transporting the indices of an [order-indiscernible sequence](order-indiscernible-sequence.md) by such a map preserves every [first-order formula](first-order-formula.md) on increasing finite tuples.
