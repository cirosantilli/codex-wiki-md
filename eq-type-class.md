# Eq type class

↑ **Parent:** [Haskell type class](haskell-type-class.md)

The [Haskell type class](haskell-type-class.md) providing the overloaded operations `==` and `/=`. A signature `Eq a => [a] -> [a] -> Bool` requires the corresponding operations for the element type. Correctness arguments treating them as mathematical equality additionally assume that the instance supplies the intended equality relation.
