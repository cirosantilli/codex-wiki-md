# Error bound

↑ **Parent:** [Approximation error](approximation-error.md)

An [error bound](error-bound.md) is an established [upper bound](upper-bound-in-a-partially-ordered-set.md) on a specified [approximation error](approximation-error.md), on a stated domain and under stated assumptions. A numerical comparison at selected points can test an approximation but does not by itself establish a bound throughout that domain. An [absolute error](absolute-error.md) bound controls $|\widetilde f-f|$; a [relative error](relative-error.md) bound additionally specifies the reference scale.
