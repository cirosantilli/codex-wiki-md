# L2 initial condition

↑ **Parent:** [Initial value problem](initial-value-problem.md)

An L2 initial condition specifies a square-integrable initial function up to equality almost everywhere. It need not have pointwise nodal values or classical derivatives. [L2-compatible initialization of grid data](l2-compatible-initialization-of-grid-data.md) uses bounded averaging or projection, and evolution estimates use the relevant [L2 norm](l2-norm.md).
