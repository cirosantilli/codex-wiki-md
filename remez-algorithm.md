# Remez algorithm

↑ **Parent:** [Best uniform approximation](best-uniform-approximation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Remez_algorithm)

The Remez algorithm searches for a [best uniform approximation](best-uniform-approximation.md) by solving alternation equations on a reference set, finding extrema of the error, and exchanging reference points. For real degree-at-most-$n$ [polynomials](polynomial-split.md), the [equioscillation theorem](equioscillation-theorem.md) characterizes success by $n+2$ ordered alternating maximal errors. The [alternating-reference error bound](alternating-reference-error-bound.md) supplies a certified lower bound at each step, while the largest absolute error supplies an upper bound. Their gap measures how close the current [polynomial](polynomial-split.md) is to optimal, provided the upper bound is established globally rather than only on a finite grid.
