# Hox cluster

↑ **Parent:** [Hox gene](hox-gene.md)

A genomic grouping of related [Hox genes](hox-gene.md) whose organization can support shared and sequential developmental regulation. Clustering is widespread but is not a universal requirement for positional Hox expression.
