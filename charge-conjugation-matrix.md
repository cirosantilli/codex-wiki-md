# Charge-conjugation matrix

↑ **Parent:** [Charge conjugation](charge-conjugation.md)

For a [Dirac field](dirac-field.md), the charge-conjugation matrix implements $\psi^c=C\bar\psi^T$. In the standard [gamma matrix](gamma-matrices.md) representation one can take $C=i\gamma^2\gamma^0$. An overall phase is conventional. The transpose intertwining relation is different from the entrywise [complex conjugation](complex-conjugation.md) involved in an [antiunitary operator](antiunitary-operator.md).
