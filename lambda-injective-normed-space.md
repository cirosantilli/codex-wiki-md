# Lambda-injective normed space

↑ **Parent:** [Normed vector space](normed-vector-space.md)

For $\lambda\ge1$, a [normed vector space](normed-vector-space.md) $X$ is lambda-injective when every [bounded linear operator](continuous-linear-operator.md) from a subspace $Y$ of any normed space $Z$ into $X$ extends to $Z$ with the displayed norm bound. The space of [bounded scalar functions on an index set](bounded-scalar-functions-on-an-index-set.md) is 1-injective: extend each coordinate functional by the [Hahn-Banach theorem](hahn-banach-theorem.md) and reassemble it using the [coordinate functional representation of an operator into bounded indexed functions](coordinate-functional-representation-of-an-operator-into-bounded-indexed-functions.md).
