# Quality factor from ringdown

↑ **Parent:** [Q factor](q-factor.md)

For an isolated weakly damped [resonator](resonator.md) mode, $Q=\omega E/P_{\rm loss}$. If $E(t)=E(0)e^{-t/\tau_E}$, differentiating gives $P_{\rm loss}=E/\tau_E$, so $Q=\omega\tau_E$. Since [energy](energy-split.md) is quadratic in [wave amplitude](wave-amplitude.md), the [wave amplitude](wave-amplitude.md) [exponential relaxation time](exponential-relaxation-time.md) is $\tau_A=2\tau_E$. A decay by an [energy](energy-split.md) factor $D$ in a measured interval $t_d$ gives $Q=\omega t_d/\ln D$. For a conventional [reverberation time](reverberation-time.md), $Q=2\pi fT_{60}/[6\ln(10)]$ under this exponential single-rate approximation.
