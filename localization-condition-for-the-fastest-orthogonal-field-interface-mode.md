# Localization condition for the fastest orthogonal-field interface mode

↑ **Parent:** [Orthogonal-field magnetic Rayleigh-Taylor dispersion relation](orthogonal-field-magnetic-rayleigh-taylor-dispersion-relation.md)

For the density jump of a [magnetic pressure discontinuity in an isothermal atmosphere](magnetic-pressure-discontinuity-in-an-isothermal-atmosphere.md), with $0<|B_+|<|B_-|$, the fastest [Rayleigh-Taylor instability](rayleigh-taylor-instability.md) has $m=0$ and $|k|=K_*=(B_-^2-B_+^2)/(4B_+^2H)$. Its vertical decay length is $K_*^{-1}$. Hence localization relative to both common [scale heights](scale-height.md) requires $4B_+^2\ll B_-^2-B_+^2$. This also makes its growth speed small compared with the isothermal sound speed. If $B_+=0$, the ideal sharp-interface [dispersion relation](dispersion-relation.md) instead has unbounded growth as $|k|\to\infty$: there is no finite maximizing mode.
