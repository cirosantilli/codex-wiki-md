# Stack pointer

↑ **Parent:** [Processor register](processor-register.md)

A [processor register](processor-register.md) identifying the current position in a stack, commonly a [call stack](call-stack.md); the exact convention depends on the architecture. Restoring a [stack pointer](stack-pointer.md) selects the saved stack position, rather than copying the whole [call stack](call-stack.md).
