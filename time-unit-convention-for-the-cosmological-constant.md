# Time-unit convention for the cosmological constant

↑ **Parent:** [Cosmological constant](cosmological-constant.md)

In a [Friedmann equation](friedmann-equations.md) written $H^2=8\pi G\rho/3+\Lambda/3-kc^2/a^2$, the symbol $\Lambda$ has units of inverse time squared. If $\Lambda_{\rm geom}$ is the geometrical constant measured in inverse length squared, $\Lambda=c^2\Lambda_{\rm geom}$. [Natural units](natural-units.md) hide this distinction.
