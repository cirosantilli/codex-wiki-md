# Proxy server

↑ **Parent:** [Middlebox](middlebox.md)

A [proxy server](proxy-server.md) performs communication operations on behalf of another participant. Whether it can inspect plaintext depends on the [protocols](communication-protocol.md) and keys it uses: relaying opaque encrypted bytes differs from authorised [TLS termination](tls-termination.md).
