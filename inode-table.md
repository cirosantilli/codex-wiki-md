# Inode table

↑ **Parent:** [Inode](inode.md)

A persistent collection of [inodes](inode.md) indexed by [inode numbers](inode-number.md) in an [inode](inode.md)-based [file system](file-system-split.md). The same term can also denote an operating system's in-memory collection of active [inodes](inode.md); these must be distinguished. A persistent table belongs to a particular volume, while the system-wide active collection keys entries by both volume identity and [inode number](inode-number.md).
