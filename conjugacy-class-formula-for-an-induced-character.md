# Conjugacy-class formula for an induced character

↑ **Parent:** [Induced character](induced-character.md)

For a [finite group](finite-group.md) $G$, a [subgroup](subgroup.md) $H$, and a [character](character-of-a-representation.md) $\chi$ of $H$, each element $h$ of $g^G\cap H$ has exactly $|C_G(g)|$ preimages under $x\mapsto x^{-1}gx$. This follows because one such preimage $x_0$ has full fiber $C_G(g)x_0$. Grouping the [character formula for an induced representation](character-formula-for-an-induced-representation.md) by these fibers proves the formula. Grouping again by [conjugacy classes](conjugacy-class.md) of $H$ replaces each class by its size times its [character](character-of-a-representation.md) value.
