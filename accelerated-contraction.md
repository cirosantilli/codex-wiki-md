# Accelerated contraction

↑ **Parent:** [Deceleration parameter](deceleration-parameter.md)

Accelerated contraction has $H<0$ and $\ddot a<0$, so the magnitude $|\dot a|$ increases. Since $\ddot a/a=H^2(1-\epsilon)$, it corresponds to a first Hubble slow-roll parameter $\epsilon>1$.
