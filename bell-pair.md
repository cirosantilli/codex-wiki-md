# Bell pair

↑ **Parent:** [Bell state](bell-state-split.md)

A Bell pair consists of two [qubits](qubit.md) prepared jointly in a [Bell state](bell-state-split.md). It is a maximally entangled two-qubit resource with [Schmidt rank](schmidt-rank.md) two. Two independent [Bell pairs](bell-pair.md) have resource [Schmidt rank](schmidt-rank.md) four across the same party partition.
