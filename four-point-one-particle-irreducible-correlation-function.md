# Four-point one-particle-irreducible correlation function

↑ **Parent:** [One-particle-irreducible correlation function](one-particle-irreducible-correlation-function.md)

The four-point one-particle-irreducible correlation function is the fourth functional derivative of the [quantum effective action](effective-action.md). It defines a renormalized quartic coupling after evaluation at the kinematic point specified by a [renormalization condition](renormalization-condition.md).
