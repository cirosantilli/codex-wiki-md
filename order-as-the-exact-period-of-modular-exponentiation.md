# Order as the exact period of modular exponentiation

↑ **Parent:** [Periodic modular exponentiation](periodic-modular-exponentiation.md)

Equality $a^x\equiv a^y\pmod N$ holds exactly when the multiplicative order divides $x-y$, so one period contains no repeated values.
