# Force field (physics)

↑ **Parent:** [Force](force-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Force_field_(physics))

A force field specifies a [force](force-split.md) [vector](vector.md) as a function of [position](position.md) and, when necessary, time, for a specified test body. It is a [vector field](vector-field.md). A time-independent [conservative vector field](conservative-vector-field.md) has $\mathbf F=-\nabla V$, where $V$ is the body's [potential energy](potential-energy.md); its [work](work.md) along a path equals the decrease in $V$. Position-dependent forces can have nonzero [curl](curl.md), so a [scalar potential](scalar-potential.md) need not exist.
