# Monoprotic acid

↑ **Parent:** [Weak acid](weak-acid.md)

A [monoprotic acid](monoprotic-acid.md) supplies one [proton](proton.md) per acid unit in the [acid-base chemistry](acid-base-chemistry-split.md) model under consideration. [Acetic acid](acetic-acid.md) is an example. Several successive proton transfers require several [acid dissociation constants](acid-dissociation-constant.md) and a larger set of [chemical species](chemical-species.md).
