# Breadth-first tree search

↑ **Parent:** [Breadth-first search](breadth-first-search.md)

The [tree search](tree-search.md) version of [breadth-first search](breadth-first-search.md) explores action histories in nondecreasing length without automatically removing repeated states. A finite [branching factor](branching-factor.md) ensures that every finite depth contains finitely many histories, so the method is a [complete search algorithm](complete-search-algorithm.md) for goals reachable at finite depth. With equal positive action costs it is an [optimal search algorithm](optimal-search-algorithm.md) for total action cost. It need not terminate on an unsolvable instance with an infinite [search tree](search-tree.md), and it need not optimize a terminal reward unrelated to depth.
