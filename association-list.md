# Association list

↑ **Parent:** [Associative array](associative-array.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Association_list)

An [associative array](associative-array.md) represented by a [list](list-abstract-data-type.md) of key-value pairs. Looking up a key scans entries until a matching key is found, giving linear worst-case search cost in the number of entries when key comparisons have unit cost.
