# Harmonic Liouville theorem

↑ **Parent:** [Harmonic function](harmonic-function.md)

A bounded [harmonic function](harmonic-function.md) on the [complex plane](complex-plane.md) is constant. More generally, an entire harmonic function bounded on either side is constant: write it as $\operatorname{Re}f$ by [harmonic function as the real part of a holomorphic function](harmonic-function-as-the-real-part-of-a-holomorphic-function.md), then apply the [Liouville theorem](liouville-theorem.md) to $e^f$ or $e^{-f}$.
