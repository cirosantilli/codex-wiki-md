# String coupling

↑ **Parent:** [String theory](string-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/String_coupling)

The string coupling controls topology change and string splitting and joining. A constant background [dilaton](dilaton.md) $\Phi_0$ sets $g_s=e^{\Phi_0}$.
