# Weighted Bernoulli majority bound

↑ **Parent:** [Complementary-layer bound for biased measure](complementary-layer-bound-for-biased-measure.md)

Let $c_i\ge0$ sum to one, with no subset sum equal to $1/2$, and let independent [Bernoulli random variables](bernoulli-distribution.md) $Z_i$ all have parameter $p\ge1/2$. The subsets of weight greater than $1/2$ form an intersecting [self-dual set family](self-dual-set-family.md). The [complementary-layer bound for biased measure](complementary-layer-bound-for-biased-measure.md) proves $\mathbb P(\sum_ic_iZ_i\ge1/2)\ge p$. Nonnegative weights ensure that disjoint sets cannot both have weight greater than $1/2$; the no-tie condition supplies self-duality.
