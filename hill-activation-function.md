# Hill activation function

↑ **Parent:** [Hill equation](hill-equation.md)

A [Hill activation function](hill-activation-function.md) is an increasing saturating input function for phenomenological [regulation of gene expression](regulation-of-gene-expression.md). For positive $K,n$, its value is one-half at $u=K$. The [Hill coefficient](hill-coefficient.md) controls steepness; it need not equal a literal molecular binding-site count.
