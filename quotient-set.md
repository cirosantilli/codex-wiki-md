# Quotient set

↑ **Parent:** [Equivalence relation](equivalence-relation.md)

The quotient set $X/{\sim}$ of a [set](set-split.md) $X$ by an [equivalence relation](equivalence-relation.md) $\sim$ is the set of its equivalence classes.
