# Sedimentation-Brownian crossover radius

↑ **Parent:** [Gravitational Peclet number](gravitational-peclet-number.md)

Setting the gravitational Péclet number to one gives the displayed particle-scale estimate. A macroscopic sample instead requires its height to be small compared with the [sedimentation scale height](sedimentation-scale-height.md). These different observational criteria give different size thresholds; “no sedimentation” is not an exact universal cutoff.
