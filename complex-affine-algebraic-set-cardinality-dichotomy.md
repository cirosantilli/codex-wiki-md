# Complex affine algebraic set cardinality dichotomy

↑ **Parent:** [Hilbert Nullstellensatz](hilbert-nullstellensatz.md)

A complex affine algebraic set is either finite or has the cardinality of $\mathbb C$. One proof takes a positive-dimensional irreducible component and applies [Noether normalization](noether-normalization.md): the resulting finite dominant map to a positive-dimensional affine space has a point above every closed point.
