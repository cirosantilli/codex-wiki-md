# Function input

↑ **Parent:** [Function](function-split.md)

A [function input](function-input.md) to a [function](function-split.md) $f:X\to Y$ is an element $x$ of its [domain of a function](domain-of-a-function.md) $X$, also called its argument. The corresponding [function output](function-output.md) is $f(x)$.
