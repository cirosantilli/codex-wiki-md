# Herbrand function

↑ **Parent:** [Lower ramification numbering](lower-ramification-numbering.md)

The Herbrand function is a continuous strictly increasing piecewise linear function on the nonnegative reals. Its inverse is denoted $\psi_{L/K}$. It reparametrizes the [lower ramification numbering](lower-ramification-numbering.md) to the [upper ramification numbering](upper-ramification-numbering.md).
