# Jaccard index

↑ **Parent:** [Cluster analysis](cluster-analysis.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Jaccard_index)

The index measures similarity of finite sets by shared presence relative to total presence. For binary profiles it ignores joint absences, unlike the [simple matching coefficient](simple-matching-coefficient.md). When both sets are empty, define the similarity to be one. The complementary [Jaccard distance](jaccard-distance.md) measures dissimilarity.
