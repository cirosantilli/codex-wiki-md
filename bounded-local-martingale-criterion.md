# Bounded local martingale criterion

↑ **Parent:** [Local martingale](local-martingale.md)

A uniformly bounded [local martingale](local-martingale.md) is a true [uniformly integrable martingale](uniformly-integrable-martingale.md): a [localizing sequence](localizing-sequence.md) gives uniformly dominated stopped values, so their conditional identities pass to the limit. A deterministic bound on each compact time interval gives a true [martingale](martingale-split.md) on each such interval, even when the bound grows with time.
