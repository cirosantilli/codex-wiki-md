# Seismic network

↑ **Parent:** [Seismology](seismology.md)

A coordinated collection of recording stations with known positions and time bases. Distributed source–receiver paths constrain [earthquake](earthquake.md) locations and internal wave speeds more effectively than one station. Geometry, noise, synchronization and instrument response determine which structures can be resolved; adding stations without crossing ray paths need not remove an inversion trade-off.
