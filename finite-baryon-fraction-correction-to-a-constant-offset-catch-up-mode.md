# Finite-baryon-fraction correction to a constant-offset catch-up mode

↑ **Parent:** [Baryon catch-up approximation after recombination](baryon-catch-up-approximation-after-recombination.md)

With growing total matter mode, constant relative offset, initial $\Delta_B=0$, and $x=R/R_r$, the exact ratio is $\Delta_B/\Delta_D=f_D(x-1)/(f_Dx+f_B)$. It reduces to $1-x^{-1}$ only in the dark-matter-dominated limit.
