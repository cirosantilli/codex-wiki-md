# Quantum error-correcting code

↑ **Parent:** [Quantum error correction](quantum-error-correction-split.md)

A quantum error-correcting code is a subspace encoding a logical [Hilbert space](hilbert-space-split.md), together with a specified family of noise operators that a common recovery [quantum channel](quantum-channel.md) reverses on every encoded state. A K-dimensional code carries $\log_2K$ logical qubits. For a code projector $P$, correctability is characterized by the [Knill--Laflamme condition](knill-laflamme-condition.md); code distance is defined by the smallest undetectable operator weight, not merely by the number of generators.
