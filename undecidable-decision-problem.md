# Undecidable decision problem

↑ **Parent:** [Computability theory](computability-theory.md)

A decision problem for which no [algorithm](algorithm.md) terminates with the correct yes-or-no answer on every input. For example, if the [diagonal halting set](diagonal-halting-set.md) had a decision algorithm, a program could halt on its own code exactly when that algorithm says it does not halt, producing a contradiction. An [undecidable decision problem](undecidable-decision-problem.md) may still admit a partial procedure that terminates on every yes-instance.
