# Suffix array

↑ **Parent:** [Data structure](data-structure-split.md)

A [suffix array](suffix-array.md) stores starting positions of a [string](string.md)'s [suffixes](string-suffix.md) in [lexicographic order](lexicographic-order.md). All [suffixes](string-suffix.md) starting with a fixed query occupy a consecutive interval. This permits [string-searching algorithms](string-searching-algorithm.md) to search a compact list of positions instead of storing every suffix explicitly.
