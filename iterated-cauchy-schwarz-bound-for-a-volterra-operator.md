# Iterated Cauchy-Schwarz bound for a Volterra operator

↑ **Parent:** [Volterra integral equation](volterra-integral-equation.md)

Starting from $\|\tau g(t)\|^2\leq C^2t\int_0^t\|g(s)\|^2ds$, induction integrates $s^{2n-2}$ at the $n$th step. Its denominator accumulates the odd integers $1,3,\ldots,2n-1$. The [factorial bound for a Volterra iterate](factorial-bound-for-a-volterra-iterate.md) is stronger because $(n!)^2\geq(2n-1)!!$.
