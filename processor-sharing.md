# Processor sharing

↑ **Parent:** [Service discipline](service-discipline.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Processor_sharing)

A nonempty server divides its capacity equally among all customers present. With class-$r$ exponential service parameter $\mu_r$, population $n_r$, and total population $n$, the class departure rate is $\mu_r n_r/n$. The resulting class-count process is a [continuous-time Markov chain](continuous-time-markov-chain.md).
