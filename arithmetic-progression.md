# Arithmetic progression

↑ **Parent:** [Arithmetic](arithmetic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Arithmetic_progression)

An arithmetic progression is a sequence $a,a+r,\ldots,a+(m-1)r$ with constant successive difference $r$. It is nonconstant when $r\ne0$.
