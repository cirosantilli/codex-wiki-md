# Palindromic number

↑ **Parent:** [Positional notation](positional-notation.md)

A [nonnegative integer](natural-number.md) whose [positional notation](positional-notation.md) reads the same forwards and backwards, with no leading zeros. This property depends on the base: $585$ is a [palindromic number](palindromic-number.md) in both [decimal representation](decimal-representation.md) and [binary representation](binary-number.md), since $585=(1001001001)_2$.
