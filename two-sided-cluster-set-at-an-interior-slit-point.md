# Two-sided cluster set at an interior slit point

↑ **Parent:** [Explicit disk map of a slit half disk](explicit-disk-map-of-a-slit-half-disk.md)

In the explicit slit map, right-side approach to $i/2$ gives the positive root, and left-side approach gives the negative root. The corresponding lower-half-plane [boundary](boundary-of-a-set.md) values are $\pm25/(2\sqrt{21})$, so the two unit-circle image values are distinct. Every other [conformal bijection](biholomorphism.md) onto the disk differs by a [disk automorphism](automorphism-of-the-unit-disk.md), which extends bijectively to the unit [circle](circle.md). Thus a sequence approaching that slit point has exactly one or both of two [boundary](boundary-of-a-set.md) cluster values, according to which sides occur infinitely often.
