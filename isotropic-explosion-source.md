# Isotropic explosion source

↑ **Parent:** [Seismic moment tensor](seismic-moment-tensor.md)

An ideal compact volume source has $M_{ij}(t)=M(t)\delta_{ij}$. In an unbounded homogeneous [isotropic](isotropy.md) solid its far-field body radiation is P only. Boundaries and heterogeneity can create converted SV and surface-wave [energy](energy-split.md); a real explosion can have nonisotropic components.
