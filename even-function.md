# Even function

↑ **Parent:** [Calculus](calculus-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Even_function)

An even function satisfies $f(-x)=f(x)$; its [Laurent series](laurent-series.md) or [Taylor series](taylor-series.md) contains only even powers.
