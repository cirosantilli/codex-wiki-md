# Gimel function

↑ **Parent:** [Cardinal arithmetic](cardinal-arithmetic.md)

For an infinite [cardinal number](cardinal-number.md), $\gimel(\kappa)=\kappa^{\operatorname{cf}(\kappa)}$. The [singular cardinals hypothesis](singular-cardinals-hypothesis.md) predicts its value when $\kappa$ is a [singular cardinal](singular-cardinal.md) and $2^{\operatorname{cf}(\kappa)}<\kappa$. For a [regular cardinal](regular-cardinal.md), its value is $2^\kappa$.
