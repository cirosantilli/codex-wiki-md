# Highest occupied molecular orbital

↑ **Parent:** [Molecular orbital](molecular-orbital.md)

The occupied [molecular orbital](molecular-orbital.md) of greatest [energy](energy-split.md) in a specified reference [electron configuration](electron-configuration.md). A fixed-orbital model removes an [electron](electron.md) from this level first; relaxation and [electron correlation](electron-correlation.md) can modify the resulting energy.
