# Stable model semantics

↑ **Parent:** [Datalog with negation](datalog-with-negation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stable_model_semantics)

A semantics in which an interpretation must equal the [least Herbrand model](least-herbrand-model.md) of its own [stable model reduct](stable-model-reduct.md). Some programs have no [stable model](stable-model.md), and others have several.
