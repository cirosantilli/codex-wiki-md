# Kernel ridge regression

↑ **Parent:** [Kernel method](kernel-method.md)

Kernel ridge regression minimizes empirical squared error plus the squared norm in a [Reproducing kernel Hilbert space](reproducing-kernel-hilbert-space.md). The [representer theorem](representer-theorem.md) reduces it to [ridge regression](ridge-regression.md) with the [kernel matrix](kernel-matrix.md) as its feature Gram matrix.
