# Computable set

↑ **Parent:** [Recursively enumerable set](recursively-enumerable-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Computable_set)

A set is computable when an algorithm decides membership for every input and always halts. Equivalently, both the set and its complement are [computably enumerable](recursively-enumerable-set.md).
