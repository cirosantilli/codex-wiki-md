# Bump attractor

↑ **Parent:** [Attractor network](attractor-network.md)

A localized population-activity pattern in a network with a continuous family of possible represented positions. Noise can shift the pattern's center, producing drift in a remembered continuous variable while the pattern remains present. This yields testable relationships between delay activity and report errors.
