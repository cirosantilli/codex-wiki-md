# Large-order asymptotic of the modified Bessel function of the second kind

↑ **Parent:** [Modified Bessel function of the second kind](modified-bessel-function-of-the-second-kind.md)

For fixed $x>0$,

$$
K_\nu(x)\sim\left(\frac\pi{2\nu}\right)^{1/2}
\left(\frac{2\nu}{ex}\right)^\nu
$$

as $\nu\to+\infty$. Applying [Laplace's method](laplace-s-method.md) to the [integral representation of the modified Bessel function of the second kind](integral-representation-of-the-modified-bessel-function-of-the-second-kind.md) proves the formula.
