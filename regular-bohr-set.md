# Regular Bohr set

↑ **Parent:** [Bohr set](bohr-set.md)

A rank-$d$ [Bohr set](bohr-set.md) $B$ is regular when small changes of its width produce proportionally small changes of its size: for $|\kappa|\leq c/d$,

$$
|B_{1+\kappa}|=(1+O(d|\kappa|))|B|.
$$

Every Bohr set has a regular dilate $B_\lambda$ with $1/2\leq\lambda\leq1$.
