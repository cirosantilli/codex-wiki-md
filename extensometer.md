# Extensometer

↑ **Parent:** [Tensile testing](tensile-testing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Extensometer)

An [extensometer](extensometer.md) measures the change in distance between two specimen points. Its [gauge length](gauge-length.md) defines the reference length used to calculate [engineering strain](engineering-strain.md).
