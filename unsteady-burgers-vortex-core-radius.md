# Unsteady Burgers-vortex core radius

↑ **Parent:** [Burgers vortex](burgers-vortex.md)

An axisymmetric Gaussian [Burgers vortex](burgers-vortex.md) with constant [circulation](circulation-physics.md) in axial strain $\alpha$ has core area parameter $s=\delta^2$ satisfying $\dot s+\alpha s=4\nu$. Thus $s=4\nu/\alpha+(s_0-4\nu/\alpha)e^{-\alpha t}$, an attracting balance of transverse compression and viscous diffusion for every positive finite initial radius.
