# Finitely generated cone

↑ **Parent:** [Conic hull](conic-hull.md)

A [finitely generated cone](finitely-generated-cone.md) is a [conic hull](conic-hull.md) of a finite set of vectors. Every point admits a representation using linearly independent active generators, by eliminating dependence while keeping coefficients nonnegative.
