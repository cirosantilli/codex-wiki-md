# Interpolation node

↑ **Parent:** [Polynomial interpolation](polynomial-interpolation.md)

An [interpolation node](interpolation-node.md) is an argument value $x_i$ at which an [interpolation polynomial](interpolation-polynomial.md) must take a prescribed value $y_i$. The [interpolation nodes](interpolation-node.md) specify where the constraints apply; the values specify how high the graph must pass there. In the three-point example, the [interpolation nodes](interpolation-node.md) are $0,1,2$, while the prescribed values are $1,2,5$. Changing the [interpolation nodes](interpolation-node.md) changes the [Lagrange cardinal polynomials](lagrange-cardinal-polynomial.md) and the [polynomial interpolation error](polynomial-interpolation-error.md), even if their number stays fixed.
