# Secular equation (linear algebra)

↑ **Parent:** [Eigenvalue](eigenvalue.md)

The equation requiring a homogeneous matrix system for an [eigenvector](eigenvector.md) to have a nonzero solution. In an orthonormal basis, $(H-EI)c=0$ requires $\det(H-EI)=0$. For a nonorthonormal basis with overlap matrix $S$, it becomes $\det(H-ES)=0$, a [generalized eigenvalue problem](generalized-eigenvalue-problem.md). The [nearly-free electron model](nearly-free-electron-model.md) uses this condition on a resonant [plane wave](plane-wave.md) subspace.
