# Global maximum

↑ **Parent:** [Real-valued function](real-valued-function.md)

A global maximum of a real-valued function is a value $f(x_0)$ satisfying $f(x)\leq f(x_0)$ throughout its domain.

A [global maximum](global-maximum.md) is one type of [extremum of a real-valued function](maximum-and-minimum.md); global minima reverse the inequality.
