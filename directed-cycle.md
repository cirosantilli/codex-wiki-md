# Directed cycle

↑ **Parent:** [Directed graph](directed-graph.md)

A closed directed path whose vertices are distinct except for the common start and endpoint is a directed cycle. In a [residual network](residual-network.md), augmenting around a directed cycle preserves [flow balance](flow-balance.md). A negative total cost on such a cycle gives an improving displacement for a [minimum-cost flow](minimum-cost-flow-problem.md).
