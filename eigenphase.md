# Eigenphase

↑ **Parent:** [Unitary operator](unitary-operator.md)

An eigenphase of a [unitary operator](unitary-operator.md) is a real number $\theta$ modulo one specifying an [eigenvalue](eigenvalue.md) $e^{2\pi i\theta}$. Every unitary eigenvalue has [modulus](modulus.md) one. [Quantum phase estimation](quantum-phase-estimation.md) records the eigenphase corresponding to an input [eigenvector](eigenvector.md); a superposition retains the corresponding labels coherently before measurement.
