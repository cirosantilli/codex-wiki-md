# Convex hole

↑ **Parent:** [Convex polygon](convex-polygon.md)

For a finite point set in the plane, a [convex polygon](convex-polygon.md) whose [vertices of a polygon](vertex-of-a-polygon.md) belong to the set and whose interior contains no point of the set. The convention must specify whether additional points on the boundary are allowed. A fan triangulation reduces emptiness to tests on constituent [triangles](triangle.md), together with checks that internal diagonals contain no forbidden points.
