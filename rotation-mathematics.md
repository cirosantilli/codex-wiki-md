# Rotation (mathematics)

↑ **Parent:** [Euclidean isometry](euclidean-isometry.md)

In [Euclidean geometry](euclidean-geometry-split.md), a rotation about the origin is an orientation-preserving orthogonal [linear map](linear-map.md), represented by an element of the [special orthogonal group](special-orthogonal-group.md). About another center $a$, the map has form $x\mapsto a+R(x-a)$. In three dimensions a nonidentity rotation fixes an axis.
