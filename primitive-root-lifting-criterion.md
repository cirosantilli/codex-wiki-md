# Primitive-root lifting criterion

↑ **Parent:** [Number theory](number-theory-split.md)

If $g$ is primitive modulo an odd prime $p$ and $g^{p-1}\not\equiv1\pmod{p^2}$, then $g$ is primitive modulo every $p^k$.
