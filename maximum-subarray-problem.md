# Maximum subarray problem

↑ **Parent:** [Algorithm](algorithm-split.md)

Given a finite sequence of [real numbers](real-number.md), find a nonempty contiguous block with maximum sum. Its restriction to contiguous blocks distinguishes it from choosing an arbitrary [subset](subset.md). The problem admits a linear-time solution using [Kadane's algorithm](kadane-s-algorithm.md).
