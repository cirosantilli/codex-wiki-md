# A-alpha stability

↑ **Parent:** [Linear stability domain](linear-stability-domain.md)

A numerical time-stepping method is $A(\alpha)$-stable if its [absolute stability](linear-stability-domain.md) region contains the negative-axis sector $\{z:|\arg(-z)|\leq\alpha\}$, for $0<\alpha\leq\pi/2$. With a [stability function](stability-function.md) $R$, this requires $|R(z)|\leq1$ throughout that sector. At $\alpha=\pi/2$, this is [A-stability](a-stability.md).
