# Root-embedding correspondence

↑ **Parent:** [Splitting field](splitting-field.md)

A root of an irreducible [polynomial](polynomial-split.md) in an extension field defines a base-field embedding of the [polynomial](polynomial-split.md) quotient by evaluation. Conversely the image of the residue class of the variable determines the embedding and is a root. This counts embeddings through separable minimal [polynomials](polynomial-split.md).
