# First-class continuation

↑ **Parent:** [Continuation (computer science)](continuation-computer-science.md)

A [continuation](continuation-computer-science.md) represented as an ordinary language value that can be stored and later invoked. Whether it may be invoked once or repeatedly, and whether mutable [program state](program-state.md) is restored, are separate semantic choices.
