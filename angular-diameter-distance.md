# Angular diameter distance

↑ **Parent:** [Cosmological distance measure](cosmological-distance-measure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Angular_diameter_distance)

The angular diameter distance is defined by $d_A=x/\theta$ for a small transverse physical size $x$ subtending angle $\theta$. In a spatially flat [Friedmann-Lemaître-Robertson-Walker metric](friedmann-lemaitre-robertson-walker-metric.md),

$$
d_A(z)=\frac{\chi(z)}{1+z},
$$

where $\chi$ is the [comoving radial distance](comoving-radial-distance.md).
