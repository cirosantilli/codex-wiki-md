# Canonical first-order structure

↑ **Parent:** [First-order structure](first-order-structure.md)

A [canonical first-order structure](canonical-first-order-structure.md) is generated by closed-term names: each element is the interpretation of a [closed term](closed-term.md). In a [first-order language](first-order-language.md) without [function symbols](function-symbol.md) this says each element is named by a constant. The constant-name convention for [canonical first-order structures](canonical-first-order-structure.md) agrees with this one in the function-free setting. [Logical equality](logical-equality.md) identifies different names for the same element.
