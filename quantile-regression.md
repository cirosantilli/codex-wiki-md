# Quantile regression

↑ **Parent:** [Statistical modelling](statistical-modelling-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantile_regression)

[Quantile regression](quantile-regression.md) models a conditional [quantile](quantile-function.md) of a response, rather than its conditional mean. Fitting by the [check loss](check-loss.md) uses an asymmetric absolute-error penalty, so different values of $\tau$ describe different parts of the response distribution. Nonlinear models may use any identifiable continuous regression function, not only a linear predictor.
