# Gaussian error linear unit

↑ **Parent:** [Neural network](neural-network.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gaussian_error_linear_unit)

The Gaussian error linear unit activation is $\operatorname{GELU}(x)=x\Phi(x)$, where $\Phi$ is the [standard normal distribution function](standard-normal-distribution-function.md).
