# Logarithm of an element near the identity

↑ **Parent:** [Holomorphic functional calculus](holomorphic-functional-calculus.md)

The displayed series converges absolutely in a [Banach algebra](banach-algebra-split.md). It is the [holomorphic functional calculus](holomorphic-functional-calculus.md) value of the analytic branch $z\mapsto\log(1-z)$ on the unit disk. The [composition rule for holomorphic functional calculus](composition-rule-for-holomorphic-functional-calculus.md) and $\exp(\log(1-z))=1-z$ give $\exp(\log(1-x))=1-x$. Thus every sufficiently small norm perturbation of the identity is an exponential.
