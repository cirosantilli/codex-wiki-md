# Saddle-point matrix

↑ **Parent:** [Block matrix](block-matrix.md)

A common symmetric saddle-point system couples primal unknowns with constraint multipliers through the displayed [block matrix](block-matrix.md), with symmetric $H,C$. At $C=0$, full row rank of $A$ and a nonsingular [reduced Hessian](reduced-hessian.md) are exactly the nonsingularity conditions. Such matrices arise from equality-constrained quadratic models and mixed [finite element methods](finite-element-method-split.md). A regularized block $C=\mu I$ also arises when an augmented linear system replaces a badly scaled quadratic-penalty [Newton system](newton-system.md).
