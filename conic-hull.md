# Conic hull

↑ **Parent:** [Convex cone](convex-cone.md)

The set of all finite [conic combinations](conic-combination.md) of elements of $S$, including zero. It is the smallest [convex cone](convex-cone.md) containing $S$. It need not be closed even when $S$ is closed: the [closed set](closed-set.md) $S=\{(t,1):t\geq1\}$ generates [vectors](vector.md) converging to $(1,0)$ via $(t,1)/t$, but no nonzero generated [vector](vector.md) has second coordinate zero.
