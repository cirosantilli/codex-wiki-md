# Classical planning

↑ **Parent:** [Automated planning](automated-planning.md)

[Automated planning](automated-planning.md) with a completely specified initial state, deterministic actions and a goal condition. A finite [STRIPS](strips.md) model is a common representation. A plan is an action sequence applicable from the initial state, ending in a goal state. Unknown facts about the initial world require an epistemic representation such as a [belief state](belief-state.md), rather than silently interpreting every unlisted fact as false.
