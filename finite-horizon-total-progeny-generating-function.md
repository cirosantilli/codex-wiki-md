# Finite-horizon total progeny generating function

↑ **Parent:** [Total progeny of a branching process](total-progeny-of-a-branching-process.md)

Count the ancestor and the next $n-1$ generations of a [Galton-Watson process](galton-watson-process.md). Conditioning on the ancestor's offspring, their independent descendant trees each have the preceding finite-horizon [probability generating function](probability-generating-function.md), proving the displayed recursion. If the count instead excludes the ancestor, the recursion is $\widehat H_{n+1}(s)=G(s\widehat H_n(s))$ with $\widehat H_0=1$. The indexing convention must be specified.
