# Work function

↑ **Parent:** [Tunnel junction](tunnel-junction.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Work_function)

The [work function](work-function.md) is the minimum [energy](energy-split.md) needed to remove an [electron](electron.md) from a [solid](solid.md) to the nearby [vacuum](vacuum.md) level. A junction's effective barrier need not equal either electrode's isolated [work function](work-function.md).
