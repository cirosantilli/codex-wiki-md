# Prime-valued sum

↑ **Parent:** [Summation](summation.md)

A sum whose resulting value is a [prime number](prime-number-split.md). This is a condition on the value, rather than a requirement that the summation index run over [prime numbers](prime-number-split.md). Counting subsets with a prime-valued sum can use [subset sum](subset-sum-problem.md) counts followed by a [primality](primality.md) filter on the possible totals.
