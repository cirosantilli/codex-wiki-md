# Arithmetic function

↑ **Parent:** [Number theory](number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Arithmetic_function)

An [arithmetic function](arithmetic-function-split.md) is a [function](function-split.md) whose [domain of a function](domain-of-a-function.md) is the [positive integers](positive-integer.md), usually taking values in the [complex numbers](complex-number.md). Thus $f(1),f(2),\ldots$ are its values; $f(0)$ is outside this [domain of a function](domain-of-a-function.md). Examples include the [divisor function](divisor-function.md), with $\tau(12)=6$, and the [sum-of-divisors function](sum-of-divisors-function.md), with $\sigma_1(12)=28$. Studying an [arithmetic function](arithmetic-function-split.md) packages a question about each [positive integer](positive-integer.md) into one object whose values can be combined using [Dirichlet convolution](dirichlet-convolution.md). [Darij Grinberg, MIT 18.781 lecture notes, Section 2.1: arithmetic functions](https://darijgrinberg.gitlab.io/floor.pdf)
