# Sentence-picture matching

↑ **Parent:** [Sentence comprehension](sentence-comprehension.md)

A task in which a person selects a picture corresponding to a sentence. Reversing [thematic roles](thematic-role.md) while preserving the pictured participants can test syntactic interpretation, but visual analysis and response selection remain additional requirements.
