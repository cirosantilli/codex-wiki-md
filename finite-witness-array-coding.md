# Finite witness array coding

↑ **Parent:** [Gödel beta-function sequence coding](godel-beta-function-sequence-coding.md)

In a [primitive recursion](primitive-recursion.md), an existential representation of the step [function](function-split.md) may need a different witness tuple at every time. Code each coordinate of the finite witness array by a separate beta-function code pair. All row witnesses then have bounded remainder quantifiers under the bounded time quantifier, while the finitely many code pairs remain in the outer unrestricted existential block.
