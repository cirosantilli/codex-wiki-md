# Bootstrap-t confidence interval

↑ **Parent:** [Bootstrap confidence interval](bootstrap-confidence-interval.md)

For each [bootstrap sample](bootstrap-sample.md), form $T^*=(\widehat\theta^*-\widehat\theta)/\widehat s^*$, using that sample's estimated [standard error](standard-error.md), possibly from a nested bootstrap. If $q_p$ are conditional quantiles of $T^*$ and $\widehat s$ is the original estimated standard error, invert the studentized inequalities to obtain the displayed interval. The quantile order is reversed by subtraction. Its coverage is approximate and requires a nondegenerate statistic and suitable bootstrap regularity.
