# Heegaard splitting

↑ **Parent:** [3-manifold](3-manifold.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Heegaard_splitting)

A Heegaard splitting divides a closed [three-manifold](3-manifold.md) into two [handlebodies](handlebody.md) with common boundary. For a [three-manifold](3-manifold.md) with boundary, one uses compression bodies, which can retain negative boundary components.
