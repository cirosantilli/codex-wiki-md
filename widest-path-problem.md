# Widest path problem

↑ **Parent:** [Path in a graph](path-in-a-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Widest_path_problem)

Find a [graph path](path-in-a-graph.md) whose least [edge weight](edge-weight.md) is as large as possible. In a connected [undirected graph](undirected-graph.md), use the unique route in a [maximum spanning tree](maximum-spanning-tree.md). Deleting a least-weight [edge](edge-of-a-graph.md) on that route gives a separating [cut of a graph](cut-graph-theory.md); a heavier crossing [edge](edge-of-a-graph.md) would improve the tree's total weight, so every competing route contains an [edge](edge-of-a-graph.md) no heavier than the deleted one. This proves the bottleneck optimum without assuming distinct weights.
