# Device register

↑ **Parent:** [Input-output](input-output.md)

A [device register](device-register.md) exposes a device's status, control or data to software. Its access semantics can include side effects: a status flag may need an explicit acknowledgement operation before another event is detectable. A [device register](device-register.md) is not necessarily a [processor register](processor-register.md). [Memory-mapped input-output](memory-mapped-input-output.md) input-output is one way to access it.
