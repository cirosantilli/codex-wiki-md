# Terminal node

↑ **Parent:** [Binary decision diagram](binary-decision-diagram.md)

A [vertex](vertex-graph-theory.md) that returns a final output rather than performing another test. In a [binary decision diagram](binary-decision-diagram.md) the two possible outputs are the [Boolean](boolean-data-type.md) constants zero and one.
