# Left Ore set

↑ **Parent:** [Ore condition](ore-condition.md)

A multiplicative subset $S$ is left Ore when, for every $s\in S$ and $r\in R$, there are $s'\in S$ and $r'\in R$ such that $s'r=r's$.
