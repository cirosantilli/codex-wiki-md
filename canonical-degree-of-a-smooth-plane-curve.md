# Canonical degree of a smooth plane curve

↑ **Parent:** [Canonical bundle of a smooth projective hypersurface](canonical-bundle-of-a-smooth-projective-hypersurface.md)

For a smooth degree-$d$ [projective plane curve](projective-plane-curve.md) $X$, the [adjunction formula](adjunction-formula.md) gives $K_X\cong\mathcal O_X(d-3)$. A [hyperplane section](hyperplane-section.md) has degree $d$, so

$$
\deg K_X=d(d-3).
$$
