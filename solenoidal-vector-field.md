# Solenoidal vector field

↑ **Parent:** [Vector field](vector-field.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Solenoidal_vector_field)

A solenoidal vector field has zero [divergence](divergence.md). Magnetic fields are solenoidal because $\nabla\mathbin\cdot\mathbf B=0$.
