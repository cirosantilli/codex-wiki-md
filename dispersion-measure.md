# Dispersion measure

↑ **Parent:** [Pulsar dispersion delay](pulsar-dispersion-delay.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dispersion_measure)

The integrated [electron](electron.md) number density along the line of sight, conventionally quoted in $\mathrm{pc\,cm^{-3}}$. A [dispersion measure](dispersion-measure.md) is a column, not a unique distance: converting it into distance requires a model of the [interstellar medium](interstellar-medium.md). A clumpy nearby column and a longer dilute column can give the same [pulsar dispersion delay](pulsar-dispersion-delay.md).
