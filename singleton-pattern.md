# Singleton pattern

↑ **Parent:** [Creational pattern](creational-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Singleton_pattern)

Provide a shared unique instance of a service or state holder. A [Scala](scala.md) `object` supplies one instance of that object definition; a top-level object can therefore centralize shared state such as a registry of current scores. A singleton does not by itself implement [thread safety](thread-safety.md), remove stale entries, or define the lifetime of registered objects. Those remain separate design responsibilities.
