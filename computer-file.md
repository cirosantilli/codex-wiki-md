# Computer file

↑ **Parent:** [File system](file-system.md)

An object whose contents and attributes can be accessed through [operating system](operating-system.md) interfaces. Here an ordinary [file](computer-file.md) means a [byte](byte.md) sequence with [file metadata](file-metadata.md), distinct from a [file-system directory](file-system-directory.md) or a [symbolic link](symbolic-link.md). Its contents need not disappear when the creating [operating-system process](process-computing.md) ends.
