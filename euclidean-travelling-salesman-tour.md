# Euclidean travelling salesman tour

↑ **Parent:** [Travelling salesman problem](travelling-salesman-problem.md)

A closed polygonal tour through a finite point set, measured using [Euclidean distance](euclidean-distance.md). Write $\operatorname{TS}(X)$ for the minimum length over cyclic visiting orders. A two-point tour traverses its segment twice; a one-point tour has length zero. The [triangle inequality](triangle-inequality.md) allows repeated visits to be shortcut when estimating this minimum.
