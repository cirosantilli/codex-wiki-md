# Inductive step

↑ **Parent:** [Mathematical induction](mathematical-induction.md)

Assuming the [induction hypothesis](induction-hypothesis.md) for a fixed integer, establish the next instance. Together with the [induction base case](induction-base-case.md), this proves every succeeding instance by [mathematical induction](mathematical-induction.md). The hypothesis is conditional within this argument, rather than an unsupported assumption that the desired theorem is already true.
