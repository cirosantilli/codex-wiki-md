# Linear configuration count

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)

A linear configuration count is a weighted sum over tuples satisfying prescribed [linear equations](linear-equation.md). [Orthogonality of complex exponentials](orthogonality-of-complex-exponentials.md) often rewrites such a count as an integral of [Fourier transforms](fourier-transform.md).
