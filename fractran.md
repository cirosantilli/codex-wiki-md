# FRACTRAN

↑ **Parent:** [Programming language](programming-language-split.md)

A programming language whose program is an ordered list of positive [rational numbers](rational-number.md). Starting with a [positive integer](positive-integer.md), multiply by the first listed [fraction](fraction.md) that produces an [integer](integer-split.md), then repeat; halt if none applies. Encoding registers as [prime](prime-number-split.md) exponents relates this operation to a [register machine](register-machine.md).
