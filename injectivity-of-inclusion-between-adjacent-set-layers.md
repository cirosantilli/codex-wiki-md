# Injectivity of inclusion between adjacent set layers

↑ **Parent:** [Boolean lattice](boolean-lattice.md)

If $n\geq2d+1$ and the [field characteristic](characteristic-of-a-field.md) is zero or greater than $d+1$, the matrix recording inclusion of $d$-sets in $(d+1)$-sets has full row [rank](rank-one-quadratic-form.md). Subtracting equations on sets differing in one coordinate reduces the kernel problem to degree $d-1$ on $n-2$ coordinates. [Mathematical induction](mathematical-induction.md) then makes all coefficients equal, and the factor $d+1$ forces them to vanish. This gives the auxiliary-polynomial independence used in the uniform [Frankl-Wilson theorem](frankl-wilson-theorem.md).
