# Auditory object

↑ **Parent:** [Perception](perception.md)

A perceptual grouping of acoustic components treated as belonging to a source or event. Harmonic relations, temporal coherence, location and learned expectations can contribute. A perceptual grouping need not correspond uniquely to one physical source.
