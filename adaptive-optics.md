# Adaptive optics

↑ **Parent:** [Optical instrument](optical-instrument-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Adaptive_optics)

Adaptive optics measures changing [wavefront errors](wavefront-error.md) and corrects them using a [deformable mirror](deformable-mirror.md). A [wavefront sensor](wavefront-sensor.md) supplies measurements to a fast feedback controller; a [guide star](guide-star-adaptive-optics.md) provides the reference. It improves [astronomical seeing](astronomical-seeing.md) toward [diffraction-limited resolution](diffraction-limited-resolution.md).
