# Class number one for Q square root of fourteen

↑ **Parent:** [Class number](class-number.md)

Every [ideal class](ideal-class.md) of this real quadratic [number field](number-field.md) contains an [integral ideal](integral-ideal.md) of [ideal norm](ideal-norm.md) at most $\sqrt{14}<4$, by the diamond form of the [Minkowski convex body theorem](minkowski-s-theorem.md). The only possible norms are one, two and three. The sole [prime ideal](prime-ideal.md) above two has norm two and is principal, generated by $4+\sqrt{14}$, whose [field norm](field-norm.md) is two. The prime three is inert, since $X^2-14$ is irreducible modulo three, so there is no ideal of norm three. Every class therefore has a principal small representative, and the [ideal class group](ideal-class-group.md) is trivial.

This illustrates why the small-ideal bound can prove a class number without listing arbitrary ideals: only prime ideals of a few possible norms need to be tested. Real quadratic fields require the absolute [field norm](field-norm.md); the generator here happens to have positive norm.
