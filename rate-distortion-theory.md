# Rate-distortion theory

↑ **Parent:** [Information theory](information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Rate–distortion_theory)

[Rate-distortion theory](rate-distortion-theory.md) asks how much [mutual information](mutual-information.md) must survive when a representation may lose detail. [Lossy compression](lossy-compression.md) groups different inputs into one reconstruction; a [distortion measure](distortion-measure-information-theory.md) specifies which differences matter. The [rate-distortion function](rate-distortion-function.md) then gives a quantitative tradeoff between allowed [expected distortion](expected-distortion.md) and the required number of [bits](bit.md). A smaller file is useful only if its reconstruction retains the distinctions that the application needs.
