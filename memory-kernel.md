# Memory kernel

↑ **Parent:** [Volterra integral equation](volterra-integral-equation.md)

A function weighting the influence of past values in a history-dependent equation. In a [Volterra integral equation](volterra-integral-equation.md) its [convolution](convolution.md) with the history is causal: only earlier times appear. For an integrable kernel, $\widetilde\kappa(0)=\int_0^\infty\kappa(u)\,du$ measures its response to a constant input. In a [generalized Langevin equation](generalized-langevin-equation.md), the friction [memory kernel](memory-kernel.md) records delayed resistance to the [velocity](velocity.md).
