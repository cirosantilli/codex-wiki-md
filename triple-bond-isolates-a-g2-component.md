# Triple bond isolates a G2 component

↑ **Parent:** [G2 root system](g2-root-system.md)

If two [simple roots](simple-root.md) have angle $5\pi/6$, normalize them to unit vectors $u,v$ with $(u,v)=-\sqrt3/2$. For any other unit [simple root](simple-root.md) $w$, set $r=(u,w)\le0$, $s=(v,w)\le0$. Its three-root [Gram matrix](gram-matrix.md) has determinant $1/4-r^2-s^2-\sqrt3rs$. Any nonzero $r$ or $s$ has absolute value at least $1/2$, contradicting positive definiteness. Thus all other [simple roots](simple-root.md) are orthogonal to $u,v$. An irreducible [root system](root-system.md) containing this triple bond must be the rank-two [G2 root system](g2-root-system.md).
