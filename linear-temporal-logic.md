# Linear temporal logic

↑ **Parent:** [Temporal logic](temporal-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linear_temporal_logic)

A [temporal logic](temporal-logic.md) interpreted along infinite [paths in a transition system](path-in-a-transition-system.md). At position $i$, $X\alpha$ requires $\alpha$ at $i+1$, $F\alpha$ requires it at some $j\geq i$, and $G\alpha$ requires it at every $j\geq i$. [Strong until](strong-until.md) and [weak until](weak-until.md) express conditions that hold up to a later event. A system satisfies a specification when all relevant initial [paths in a transition system](path-in-a-transition-system.md) satisfy it.
