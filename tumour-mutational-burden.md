# Tumour mutational burden

↑ **Parent:** [Molecular genetics](molecular-genetics-split.md)

The number of somatic [mutations](mutation.md) per defined amount of [tumour](tumour.md) sequence under a specified assay. It is an imperfect proxy for the number of useful immunogenic targets.
