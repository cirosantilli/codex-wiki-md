# Vector field along a curve

↑ **Parent:** [Vector field along a map](vector-field-along-a-map.md)

A vector field along a curve $\gamma:I\to M$ is a smooth [section of a vector bundle](section-of-a-vector-bundle.md) with $V(t)\in T_{\gamma(t)}M$. Its values may differ at distinct times mapping to the same base point. The [covariant derivative along a curve](covariant-derivative-along-a-curve.md) differentiates its time-dependent coefficients using the pulled-back [connection on a vector bundle](connection-vector-bundle.md); it does not require extending it to one ambient vector field.
