# Gaussian free field

↑ **Parent:** [Gaussian random field](gaussian-random-field.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gaussian_free_field)

The Gaussian free field is a centered [Gaussian random field](gaussian-random-field.md) whose covariance is the Green kernel of a Laplace operator. It has discrete versions on graphs and continuum versions as a random generalized function on a domain.
