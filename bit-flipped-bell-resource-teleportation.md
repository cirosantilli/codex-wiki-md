# Bit-flipped Bell resource teleportation

↑ **Parent:** [Quantum teleportation](quantum-teleportation.md)

Distributing one half of $|\Phi^+\rangle$ through a [quantum bit-flip channel](quantum-bit-flip-channel.md) produces $p\Pi_{\Phi^+}+(1-p)\Pi_{\Psi^+}$. Ideal [quantum teleportation](quantum-teleportation.md) with error-free classical correction bits induces the same bit-flip map on the input: conjugating the resource error by any [Pauli gate](pauli-gate.md) correction changes at most its sign. For a pure target the squared [quantum fidelity](fidelity-of-quantum-states.md) is $p+(1-p)|\langle X\rangle|^2$. This describes noise in resource distribution, not a perfect resource supplied by an independent channel.
