# Conditional regression coefficients from a Gaussian precision matrix

↑ **Parent:** [Precision matrix](precision-matrix.md)

In a [Gaussian graphical model](gaussian-graphical-model.md), regressing component $k$ on the others gives the displayed coefficients, residual variance $1/\Omega_{kk}$ and intercept $\mu_k-\mu_{-k}^{\mathsf T}\theta_{-k,k}$. Opposite directions have identical zero patterns and signs because $\Omega$ is symmetric with positive diagonal, but generally unequal coefficient magnitudes.
