# Memory location

↑ **Parent:** [Computer memory](computer-memory-split.md)

An individually addressable place in [computer memory](computer-memory-split.md) holding a value. An abstract memory interface can separate reading and updating existing [memory locations](memory-location.md) from allocating a fresh [memory location](memory-location.md).
