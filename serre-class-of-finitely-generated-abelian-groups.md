# Serre class of finitely generated abelian groups

↑ **Parent:** [Serre class](serre-class.md)

The class of all finitely generated abelian groups has the closure properties needed for the [Hurewicz theorem modulo a Serre class](hurewicz-theorem-modulo-a-serre-class.md). In a [simply connected](simply-connected-space.md) space, degreewise membership of [homotopy groups](homotopy-group.md) and integral [homology](homology-split.md) groups in this class is equivalent.
