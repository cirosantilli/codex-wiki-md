# Completely randomized design

↑ **Parent:** [Design of experiments](design-of-experiments.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Completely_randomized_design)

A [completely randomized design](completely-randomized-design.md) assigns [treatments](treatment.md) directly to available [experimental units](experimental-unit.md) using [complete randomization](complete-randomization.md), without blocking. Fixed group sizes can be enforced. The residual then includes uncontrolled between-unit variation.
