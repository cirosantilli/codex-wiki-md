# Heuristic function

↑ **Parent:** [Search problem](search-problem.md)

A [function](function-split.md) estimating the remaining cost from a state $s$ to a goal in a [search problem](search-problem.md). The estimate is an [admissible heuristic](admissible-heuristic.md) when it never exceeds the true minimum remaining cost. A [consistent heuristic](consistent-heuristic.md) satisfies an additional local inequality along each permitted transition.
