# Resident set

↑ **Parent:** [Virtual memory](virtual-memory-split.md)

The [set](set-split.md) of an [operating-system process](process-computing.md)'s [memory pages](memory-page.md) currently present in main [computer memory](computer-memory.md). A [resident set](resident-set.md) may omit recently used [memory pages](memory-page.md) after [page replacement](page-replacement.md), or retain [memory pages](memory-page.md) that have left the chosen [working set](working-set.md) window.
