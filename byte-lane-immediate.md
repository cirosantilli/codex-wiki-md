# Byte-lane immediate

↑ **Parent:** [Immediate operand](immediate-operand.md)

An [instruction encoding](instruction-encoding.md) that stores an eight-bit byte and a two-bit byte-position selector, expanding them to a 32-bit [machine word](machine-word.md) as $b2^{8j}$ for $0\leq j\leq3$. Four such values can construct any 32-bit constant using [bitwise OR](bitwise-or.md) or addition [modulo](modulo-operation.md) $2^{32}$.
