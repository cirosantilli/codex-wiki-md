# Integer square root

↑ **Parent:** [Square root](square-root.md)

For a [nonnegative integer](natural-number.md) $n$, its [integer square root](integer-square-root.md) is the unique [nonnegative integer](natural-number.md) $r$ satisfying $r^2\le n<(r+1)^2$, equivalently $r=\lfloor\sqrt n\rfloor$. Testing $r^2=n$ decides whether $n$ is a [perfect square](square-number.md) using exact [integer arithmetic](integer-arithmetic.md).
