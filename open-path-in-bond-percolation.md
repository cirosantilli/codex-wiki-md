# Open path in bond percolation

↑ **Parent:** [Bond percolation](bond-percolation-split.md)

A path in the underlying graph all of whose [edges](edge-of-a-graph.md) are open. Connectivity of [open paths](open-path-in-bond-percolation.md) determines the [percolation clusters](percolation-cluster.md). A [ray in a graph](ray-in-a-graph.md) with all [edges](edge-of-a-graph.md) open is an infinite [ray in a graph](ray-in-a-graph.md).
