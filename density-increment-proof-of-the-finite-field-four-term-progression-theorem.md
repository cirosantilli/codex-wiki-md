# Density-increment proof of the finite-field four-term progression theorem

↑ **Parent:** [Inverse theorem for the Gowers U3 norm over a finite field](inverse-theorem-for-the-gowers-u3-norm-over-a-finite-field.md)

If a dense set has too few four-term arithmetic progressions, its balanced function has large $U^3$ norm. A [Frequency graph extracted from a large Gowers U3 norm](frequency-graph-extracted-from-a-large-gowers-u3-norm.md), followed by the [Balog-Szemerédi-Gowers theorem](balog-szemeredi-gowers-theorem.md) and a Freiman theorem, yields correlation with a quadratic phase. Restricting to a suitable level set gives a density increment, and iteration proves the [Finite-field Szemerédi theorem for four-term arithmetic progressions](finite-field-szemeredi-theorem-for-four-term-arithmetic-progressions.md).
