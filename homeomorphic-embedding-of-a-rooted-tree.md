# Homeomorphic embedding of a rooted tree

↑ **Parent:** [Rooted tree](rooted-tree.md)

For finite [rooted trees](rooted-tree.md) in the ancestor [partial order](partially-ordered-set.md), a [rooted-tree homeomorphic embedding](homeomorphic-embedding-of-a-rooted-tree.md) is an injective vertex map preserving [lowest common ancestors](lowest-common-ancestor.md): $h(u\wedge v)=h(u)\wedge h(v)$. The image of the source root need not be the host root. Edge paths and branching are preserved, while paths may be subdivided in the larger tree.
