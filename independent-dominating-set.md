# Independent dominating set

↑ **Parent:** [Independent set (graph theory)](independent-set-graph-theory.md)

An [independent dominating set](independent-dominating-set.md) is simultaneously an [independent set](independent-set-graph-theory.md) and a [dominating set](dominating-set.md). Equivalently, it is an [independent set](independent-set-graph-theory.md) maximal under inclusion: an outside [vertex](vertex-graph-theory.md) can be added while preserving independence exactly when it has no neighbour in the selected [set](set-split.md). On a [triangle in a graph](triangle-in-a-graph.md), any singleton is an [independent dominating set](independent-dominating-set.md) but no [independent vertex cover](independent-vertex-cover.md) exists. Independence and domination are directly expressible in [first-order logic](first-order-logic.md) when a fixed bound on the number of selected [vertices](vertex-graph-theory.md) is given.
