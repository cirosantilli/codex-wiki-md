# First-class constraint

↑ **Parent:** [Constraint (mechanics)](constraint-mechanics.md)

A first-class constraint has [Poisson brackets](poisson-bracket.md) with all constraints that vanish on the constraint surface. For a regular constrained [Hamiltonian](hamiltonian.md) system, first-class constraints generate [gauge transformations](gauge-transformation.md); each independent constraint and its gauge direction remove one [canonical pair](canonical-pair.md).
