# Gaussian-prior Poisson log-effect conditional

↑ **Parent:** [Log-linear model](log-linear-model.md)

For $c>0$ and a centered [normal distribution](normal-distribution.md) prior, this conditional [log-posterior](log-posterior.md) has second [derivative](derivative.md) $-ce^\alpha-s^{-2}<0$. It is strictly [concave](concave-function.md) but does not belong to a [normal distribution](normal-distribution.md) or [gamma distribution](gamma-distribution.md) family. A [Random-walk Metropolis algorithm](random-walk-metropolis-algorithm.md), or a locally scaled proposal around its unique mode with the full proposal correction, can update it. Gaussian conjugacy is unavailable because the [Poisson distribution](poisson-distribution.md) [likelihood](likelihood-function.md) contains an exponential rate.
