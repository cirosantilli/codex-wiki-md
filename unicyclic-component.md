# Unicyclic component

↑ **Parent:** [Subcritical component bound for a binomial random graph](subcritical-component-bound-for-a-binomial-random-graph.md)

A connected graph is unicyclic when it contains exactly one cycle, equivalently when its numbers of vertices and edges agree.

A [pseudoforest](pseudoforest.md) permits both these components and acyclic [tree](tree-graph-theory.md) components.
