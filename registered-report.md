# Registered report

↑ **Parent:** [Open science](open-science.md)

A publication format involving review of the question and methods before outcomes are known, with in-principle publication acceptance conditional on adequate adherence and reporting. It differs from [preregistration](preregistration.md) alone, which need not involve peer review or publication commitment.[Eligibility features and two-stage workflow](registered-reports-by-center-for-open-science.md)
