# Linear regularization

↑ **Parent:** [Regularization of an inverse problem](regularization-of-an-inverse-problem.md)

A linear regularization uses a family of [bounded linear operators](continuous-linear-operator.md) $R_\alpha$ such that $R_\alpha f\to K^\dagger f$ for each $f\in\mathcal D(K^\dagger)$. A [regularization parameter choice](regularization-parameter-choice.md) must balance approximation error with noise amplification to obtain a [convergent regularization of an inverse problem](convergent-regularization-of-an-inverse-problem.md).
