# Skew-symmetric part of a matrix

↑ **Parent:** [Skew-symmetric matrix](skew-symmetric-matrix.md)

Every real square [matrix](matrix.md) decomposes as $A=S+K$, where $S=(A+A^T)/2$ is its [symmetric part](symmetric-part-of-a-matrix.md) and $K=(A-A^T)/2$ is a [skew-symmetric matrix](skew-symmetric-matrix.md). For a real column vector $x$, $x^TKx$ equals its transpose $x^TK^Tx=-x^TKx$, hence vanishes. Thus a real [quadratic form](quadratic-form-split.md) $x^TAx$ depends only on $S$.
