# Electromagnetic matching for an alpha-Omega interface

↑ **Parent:** [Equal-diffusivity interface dynamo](equal-diffusivity-interface-dynamo.md)

For a planar interface, equal permeability and no singular sheet current make all magnetic components continuous. A nonzero horizontal Fourier wavenumber then gives the first three conditions in the title. [Continuity](continuous-function.md) of the tangential [electric field](electric-field.md) supplies the last: continuous mean velocity cancels its advective contribution, and the retained alpha [mean-field electromotive force](mean-field-electromotive-force.md) is along the toroidal direction, so the other tangential electric component is $-U\partial_xA-\eta\partial_zB$. The given alpha-Omega equations retain only toroidal-to-poloidal alpha generation; adding a full isotropic alpha contribution would alter both the bulk equation and the matching problem.
