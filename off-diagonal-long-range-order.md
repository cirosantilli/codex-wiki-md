# Off-diagonal long-range order

↑ **Parent:** [Order parameter](order-parameter.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Off-diagonal_long-range_order)

For a homogeneous bosonic condensate, the one-body [density matrix](density-matrix-split.md) retains a nonzero long-distance component. More generally, macroscopic occupation is identified by an eigenvalue of that [density matrix](density-matrix-split.md) proportional to particle number. This gives a number-conserving description even when the one-point annihilation-field expectation vanishes. In a paired fermionic system the corresponding macroscopic order belongs to the two-particle [density matrix](density-matrix-split.md), rather than an [electron](electron.md) single-particle condensate.
