# Machine word

↑ **Parent:** [Computer science](computer-science-split.md)

A fixed-size unit of stored information in a computational cost model. Counting [machine words](machine-word.md) separately from [bits](bit.md) makes assumptions about identifier and value sizes explicit: for example, the storage bound for an [adjacency list](adjacency-list.md) assumes each [vertex](vertex-graph-theory.md) identifier fits into a constant number of [machine words](machine-word.md).
