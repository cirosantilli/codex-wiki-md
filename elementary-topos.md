# Elementary topos

↑ **Parent:** [Category theory](category-theory-split.md)

An elementary topos is a category with finite limits, a [cartesian-closed](cartesian-closed-category.md) structure, and a [subobject classifier](subobject-classifier.md). These axioms support an internal intuitionistic higher-order logic.
