# All-ones matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/All-ones_matrix)

The all-ones matrix $J=\mathbf e\mathbf e^T$ has every entry equal to one, where $\mathbf e=(1,\ldots,1)^T$. On $\mathbb R^n$, the matrix $J/n$ is the [orthogonal projection matrix](orthogonal-projection-matrix.md) onto $\operatorname{span}\{\mathbf e\}$.
