# Point mutation

↑ **Parent:** [Mutation](mutation.md)

A [point mutation](point-mutation.md) affects a single [base pair](base-pair.md). Terminology varies: the broad usage includes a one-[base pair](base-pair.md) insertion or deletion as well as a [nucleotide substitution](nucleotide-substitution.md). Describing the actual sequence change avoids this ambiguity.[Definition: a single base pair added, deleted or changed](point-mutation-by-national-human-genome-research-institute.md)
