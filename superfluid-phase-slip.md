# Superfluid phase slip

↑ **Parent:** [Phase winding of a condensate](phase-winding-of-a-condensate.md)

An event changing the [phase winding of a condensate](phase-winding-of-a-condensate.md) around a loop. A continuous nonzero order parameter cannot change its winding integer; a phase-slip path must pass through a locally vanishing amplitude or an equivalent vortex-crossing process. This use concerns a superfluid field, rather than only the relative phase of two classical oscillators.
