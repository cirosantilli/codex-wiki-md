# One-step method

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

A one-step method approximates an [ordinary differential equation](ordinary-differential-equation.md) using the current approximate solution and evaluations within the next step. The function $\Phi$ is its increment function. A [Runge-Kutta method](runge-kutta-method-split.md) may use several intermediate stages while remaining a one-step method: it does not require additional previous solution values as a [linear multistep method](linear-multistep-method-split.md) does. Its [consistency error](normalized-local-truncation-error.md) is the exact-start update defect divided by $h$.
