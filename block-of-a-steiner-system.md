# Block of a Steiner system

↑ **Parent:** [Steiner system](steiner-system.md)

A designated [subset](subset.md) in a [Steiner system](steiner-system.md) is a [Steiner block](block-of-a-steiner-system.md). In a system $S(t,k,v)$, each [Steiner block](block-of-a-steiner-system.md) contains $k$ points and each $t$-point [subset](subset.md) belongs to exactly one [Steiner block](block-of-a-steiner-system.md). For $t=2$, this is the pair-coverage condition used in a [cyclotomic construction of a Steiner 2-design](cyclotomic-construction-of-a-steiner-2-design.md).
