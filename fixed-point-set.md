# Fixed-point set

↑ **Parent:** [Isometry](isometry.md)

The fixed-point set of a map $f:M\to M$ is $M^f=\{x:f(x)=x\}$. For an isometry of a Riemannian manifold, each smooth component of the fixed-point set is totally geodesic.
