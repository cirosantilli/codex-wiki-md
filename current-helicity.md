# Current helicity

↑ **Parent:** [Magnetic helicity](magnetic-helicity.md)

Current helicity correlates a [magnetic field](magnetic-field.md) with its [curl](curl.md), which is proportional to [electric current density](current-density.md). It differs from [magnetic helicity](magnetic-helicity.md), which uses a [magnetic vector potential](magnetic-vector-potential.md). For a solenoidal monochromatic field of wavenumber $k$ in a periodic domain, choose $\mathbf a_b=\nabla\times\mathbf b/k^2$. Then $\nabla\times\mathbf a_b=\mathbf b$ and $H_c=k^2\langle\mathbf a_b\cdot\mathbf b\rangle$.
