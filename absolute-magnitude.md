# Absolute magnitude

↑ **Parent:** [Astronomical magnitude](astronomical-magnitude.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Absolute_magnitude)

Absolute magnitude is the [apparent magnitude](apparent-magnitude.md) that an astronomical source would have at a conventional reference distance. It separates intrinsic luminosity from distance-dependent dimming.
