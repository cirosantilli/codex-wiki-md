# Hamiltonian of an optimal-control problem

↑ **Parent:** [Optimal control](optimal-control.md)

In a normal minimization convention for [optimal control](optimal-control.md), the running cost $L$ and dynamics $\dot x=f$ define $H=L+p\cdot f$. The multiplier $p$ is a [costate](costate.md); this Hamiltonian is a device for variational necessary conditions rather than necessarily a physical energy.
