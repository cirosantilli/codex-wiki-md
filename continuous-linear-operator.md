# Continuous linear operator

↑ **Parent:** [Topological vector space](topological-vector-space-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Continuous_linear_operator)

A continuous linear map is a [linear map](linear-map.md) that is continuous for the topologies on its domain and codomain. Between [normed vector spaces](normed-vector-space.md), continuity is equivalent to boundedness.
