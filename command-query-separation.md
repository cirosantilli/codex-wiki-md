# Command-query separation

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

Command-query separation distinguishes commands that change state from queries that return observations without changing that state. It permits repeated inspection without further updates, but clients may need a protocol connecting updates and subsequent observations. Combining a command and its resulting observation into one [object method](object-method.md) can be convenient for transformation [object interfaces](object-interface.md). Neither organization alone guarantees thread safety.
