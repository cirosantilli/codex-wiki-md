# Statistical invariance principle

↑ **Parent:** [Statistical decision theory](statistical-decision-theory.md)

If sample transformations preserve the model and both hypotheses, the invariance principle restricts attention to tests whose decisions are unchanged by those transformations. Such tests are functions of a [maximal invariant](maximal-invariant.md). In estimation, the analogous requirement is [equivariance](equivariant-map.md), accompanied by an invariant [loss function](loss-function.md) so that risks transform compatibly. The principle respects symmetries; it does not by itself prove optimality among all unrestricted procedures.
