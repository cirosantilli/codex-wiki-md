# Bounded-derivative Burgers flux

↑ **Parent:** [Scalar conservation law](scalar-conservation-law.md)

This $C^1$ flux has $|f'|\le1$ globally and agrees with the [Inviscid Burgers equation](inviscid-burgers-equation.md) flux on $[-1,1]$. It allows Burgers examples to satisfy a global bounded-speed hypothesis. For Riemann data $-1$ to the left and $1$ to the right, both the stationary expansion discontinuity and the fan $u=x/t$ on $|x|<t$, with exterior values $\pm1$, are bounded weak solutions. Only the fan is an [entropy solution](entropy-solution.md).
