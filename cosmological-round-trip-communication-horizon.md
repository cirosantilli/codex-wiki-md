# Cosmological round-trip communication horizon

↑ **Parent:** [Cosmological event horizon](cosmological-event-horizon.md)

A light signal sent from a comoving observer to a comoving reflector at separation $\chi$, and immediately returned, consumes [conformal time](conformal-time.md) $2\chi$. The supremum of the initial physical reflector distances allowing a return is therefore half the [cosmological event horizon](cosmological-event-horizon.md) radius. Equality generally requires infinite return time; finite-time reception requires a strictly smaller distance. For a [cosmological domain wall network](cosmological-domain-wall-network.md) with $a\propto t^2$, the supremum is $t/2=1/H$.
