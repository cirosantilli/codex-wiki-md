# Scalar contraction test for a Cartesian tensor

↑ **Parent:** [Quotient theorem for Cartesian tensors](quotient-theorem-for-cartesian-tensors.md)

If an array specified in each [orthonormal basis](orthonormal-basis.md) has invariant [Frobenius inner product](frobenius-inner-product.md) with every [Cartesian second-rank tensor](cartesian-second-rank-tensor.md), it transforms as such a tensor. For a component change $R$, invariance says $(R^TA\prime R-A):B=0$ for every matrix $B$. Nondegeneracy of the [Frobenius inner product](frobenius-inner-product.md) forces the difference to vanish. Testing every tensor, rather than a single selected tensor, is essential.
