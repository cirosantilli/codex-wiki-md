# Internet

↑ **Parent:** [Computer network](computer-network-split.md)

The [Internet](internet.md) interconnects independently operated [computer networks](computer-network-split.md) using the [Internet Protocol](internet-protocol.md) suite. Its common inter-network interface supports diverse underlying networks and applications; individual services can still depend on centrally controlled providers.
