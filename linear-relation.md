# Linear relation

↑ **Parent:** [Linear dependence](linear-dependence.md)

A linear relation among [vectors](vector.md) $v_1,\ldots,v_n$ is a coefficient tuple $(a_1,\ldots,a_n)$ satisfying $\sum_i a_iv_i=0$. It is nontrivial if at least one coefficient is nonzero. For the [matrix](matrix.md) with these vectors as columns, the space of relations is its [kernel](kernel-of-a-linear-map.md). The vectors are [linearly independent](linear-independence.md) exactly when this kernel is zero. An invertible change of coordinates preserves every relation, since $S\sum_i a_iv_i=0$ if and only if $\sum_i a_iv_i=0$.
