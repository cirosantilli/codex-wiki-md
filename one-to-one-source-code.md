# One-to-one source code

↑ **Parent:** [Information theory](information-theory-split.md)

A one-to-one source code is an [injective function](injective-function.md) from source symbols to finite codewords. Unlike a [prefix code](prefix-code.md), it need not permit instantaneous decoding of concatenated codewords.
