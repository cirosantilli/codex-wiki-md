# Thietanium ion

↑ **Parent:** [Sulfonium ion](sulfonium-ion.md)

A four-membered cyclic [sulfonium ion](sulfonium-ion.md) containing [sulfur](sulfur.md) and three [carbons](carbon.md). A bridged version with equivalent methylene paths can allow nucleophilic opening to restore either configuration at an initially stereogenic [carbon](carbon.md).
