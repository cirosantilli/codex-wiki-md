# Primitive recursive function in intension

↑ **Parent:** [Primitive recursive syntax and arity checking](primitive-recursive-syntax-and-arity-checking.md)

A valid finite construction expression from the [initial functions of recursion theory](initial-function-of-recursion-theory.md) by [function composition in recursion theory](function-composition-in-recursion-theory.md) and [primitive recursion](primitive-recursion.md). Its extension is a [primitive recursive function](primitive-recursive-function.md). The construction grammar supplies both a decidable syntax and a total computable interpreter, but no uniformly primitive recursive interpreter for all valid codes.
