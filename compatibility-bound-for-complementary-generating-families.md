# Compatibility bound for complementary generating families

↑ **Parent:** [Generating family for a uniform set family](generating-family-for-a-uniform-set-family.md)

Let $n>2r-t$ and let $G,H$ generate respectively a [t-intersecting family](t-intersecting-family.md) of $r$-sets and its complement family. If their union had size at most $n-r+t-1$, contain it in a set $T$ of that size. Since $|T|\geq r,n-r$, extend $G,H$ within $T$ to an $r$-set $A$ and an $(n-r)$-set $B$. Both $A$ and $B^c$ belong to the original family, but $|A\cap B^c|=|A\cup B|-|B|\leq t-1$. This contradiction proves the bound.
