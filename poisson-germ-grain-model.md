# Poisson germ-grain model

↑ **Parent:** [Poisson point process](poisson-point-process.md)

A [Poisson germ-grain model](poisson-germ-grain-model.md) assigns a measurable region to each point of a [Poisson point process](poisson-point-process.md) and takes the union of those regions. A location remains uncovered exactly when no Poisson point has a region containing it, so its coverage [probability](probability.md) is determined by the intensity of the corresponding set of germs and marks.
