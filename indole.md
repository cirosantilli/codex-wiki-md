# Indole

↑ **Parent:** [Heterocyclic compound](heterocyclic-compound.md)

A fused benzene–pyrrole heteroaromatic ring system. Electrophilic substitution normally favours C3; when that position is occupied, C2 substitution can retain the pyrrolic [nitrogen](nitrogen.md)–hydrogen bond.
