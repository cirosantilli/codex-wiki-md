# Core of the miners game

↑ **Parent:** [Core (game theory)](core-game-theory.md)

For $r\geq2$, the [core](core-game-theory.md) is zero when $n<r$, the nonnegative unit simplex when $n=r$, the single allocation $x_i=1/r$ when $n\geq2r$ is divisible by $r$, and empty for all other $n\geq r$. To prove the obstruction, every $r$-person [coalition](coalition-game-theory.md) requires payoff at least one. Summing these constraints counts each player $\binom{n-1}{r-1}$ times and gives $r\lfloor n/r\rfloor/n\geq1$, impossible when $r\nmid n$. For a divisible $n$, all such coalition sums must equal one. Comparing coalitions with the same $r-1$ members makes all individual payoffs equal when $n>r$. The uniform allocation satisfies every coalition constraint because $|S|/r\geq\lfloor|S|/r\rfloor$. At $n=r$ all proper coalition values are zero, giving the whole simplex instead.
