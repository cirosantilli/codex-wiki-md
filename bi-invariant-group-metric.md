# Bi-invariant group metric

↑ **Parent:** [Left-invariant group metric](left-invariant-group-metric.md)

A group distance is bi-invariant when both left and right translations are [isometries](isometry.md). [Conjugation](conjugation.md) then fixes the [identity element](identity-element.md) and is an [isometry](isometry.md), so each [metric](metric.md) ball there is invariant under every inner automorphism. A compatible [bi-invariant group metric](bi-invariant-group-metric.md) therefore requires arbitrarily small conjugation-invariant [neighbourhoods](neighbourhood-mathematics.md). This concerns a distance function, not merely a [bi-invariant Riemannian metric](bi-invariant-riemannian-metric.md) tensor.
