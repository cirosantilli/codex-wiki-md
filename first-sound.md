# First sound

↑ **Parent:** [Acoustics](acoustics.md)

An ordinary [acoustic wave](acoustic-wave.md) involving a [pressure](pressure-split.md) and [density](density.md) oscillation in local thermodynamic equilibrium. In a [Fermi liquid](fermi-liquid-split.md), this hydrodynamic response requires collisions fast compared with the oscillation period; [zero sound](zero-sound.md) instead describes a collisionless collective mode.
