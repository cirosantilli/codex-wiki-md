<h1 id="folner-set">Følner set</h1>

↑ **Parent:** [Amenable graph](amenable-graph.md)

A finite nonempty vertex set in an [amenable graph](amenable-graph.md) is a Følner set with tolerance $\varepsilon$ if its external boundary has size at most $\varepsilon$ times its volume. A graph [Følner sequence](folner-sequence.md) consists of such sets with tolerances tending to zero. For a bounded-degree [graph](graph-split.md), every fixed-thickness boundary layer also has negligible relative volume along this sequence.
