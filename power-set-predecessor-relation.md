# Power-set-predecessor relation

↑ **Parent:** [Well-founded relation](well-founded-relation.md)

This [well-founded relation](well-founded-relation.md) is well-founded without the [axiom of choice](axiom-of-choice.md) or [Axiom of foundation](axiom-of-regularity.md). If a nonempty set $A$ lacked a minimal member, put $b=\bigcap A$. For each $y\in A$, some $x\in A$ has $\mathcal P(x)\subseteq y$, and $b\subseteq x$ gives $\mathcal P(b)\subseteq y$. Hence $\mathcal P(b)\subseteq b$. The [Cantor diagonal argument](cantor-diagonal-argument.md) applied to $d=\{u\in b:u\notin u\}$ contradicts this inclusion.
