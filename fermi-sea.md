# Fermi sea

↑ **Parent:** [Fermi energy](fermi-energy.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fermi_sea)

The Fermi sea is the zero-temperature many-fermion state in which every one-particle state below the [Fermi energy](fermi-energy.md) is occupied and every state above it is empty.
