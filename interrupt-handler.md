# Interrupt handler

↑ **Parent:** [Interrupt](interrupt.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Interrupt_handler)

Code entered to handle an [interrupt](interrupt.md). It identifies and acknowledges relevant device state and arranges service, possibly deferring work. The [Linux kernel](linux-kernel.md)'s generic flow layer and [device driver](device-driver.md) callback have distinct responsibilities. [Linux kernel documentation, generic IRQ handling: interrupt control flow and default flow implementations](https://docs.kernel.org/core-api/genericirq.html)
