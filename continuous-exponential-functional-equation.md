# Continuous exponential functional equation

↑ **Parent:** [Functional equation](functional-equation.md)

A continuous real [function](function-split.md) satisfying $g(x+y)=g(x)g(y)$ is either identically zero or $g(x)=e^{cx}$ for a real constant $c$. If it is nonzero somewhere, $g(0)=1$ and $g(x)g(-x)=1$, so it never vanishes. The identity $g(x)=g(x/2)^2$ then makes it everywhere positive. Its real logarithm is a continuous [additive function](additive-function.md), hence linear by [additive function continuous at one point is linear](additive-function-continuous-at-one-point-is-linear.md). Exponentiating proves the classification, and each listed [function](function-split.md) satisfies the equation.
