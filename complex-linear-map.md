# Complex-linear map

↑ **Parent:** [Linear map](linear-map.md)

A real-linear map between [complex vector spaces](complex-vector-space.md) that commutes with multiplication by $i$. On $\mathbb C$, its real matrix is $\begin{pmatrix}a&-b\\b&a\end{pmatrix}$, representing multiplication by $a+ib$. On $\mathbb C$, such a map with real [determinant](determinant.md) one is a rotation. In higher complex dimension, determinant one does not force the map to be a [unitary operator](unitary-operator.md).
