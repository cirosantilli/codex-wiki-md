# Measure

↑ **Parent:** [Measure theory](measure-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Measure)

On a [measurable space](measurable-space.md) $(X,\mathcal F)$, a measure is a [function](function-split.md) $\mu:\mathcal F\to[0,\infty]$ with $\mu(\varnothing)=0$ and [countable additivity](countable-additivity.md): for pairwise disjoint [measurable sets](measurable-set.md) $A_n$,

$$
\mu\left(\bigcup_{n=1}^{\infty}A_n\right)=\sum_{n=1}^{\infty}\mu(A_n).
$$

Infinite size is permitted. Nonnegativity implies that if [measurable sets](measurable-set.md) satisfy $A\subseteq B$, then $\mu(A)\leq\mu(B)$: decompose $B$ into $A$ and $B\setminus A$. For overlapping [measurable sets](measurable-set.md), use [countable subadditivity](countable-subadditivity-of-a-measure.md) rather than adding their full sizes twice.

For example, [counting measure](counting-measure.md) gives $\mu(\{a,b,c\})=3$, while a [Dirac measure](dirac-measure.md) $\delta_a$ gives that same [set](set-split.md) size $1$ if it contains $a$. Under [Lebesgue measure](lebesgue-measure.md), $[0,1/4]\cup[3/4,1]$ has size $1/4+1/4=1/2$. These are all [measures](measure-split.md), but they answer different questions: how many objects, whether a distinguished object is present, or how much length is occupied.
