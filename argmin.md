# Argmin

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

The set of minimizers of an objective:

$$
\operatorname*{arg\,min}_{x\in S}f(x)=\{x\in S:f(x)\le f(y)\text{ for every }y\in S\}.
$$

It is a set of inputs, whereas the [minimum](minimum-of-a-subset-of-a-total-order.md) is an objective value. The [argmin](argmin.md) can be empty if an [infimum](infimum.md) is not attained, a singleton, or a larger set.
