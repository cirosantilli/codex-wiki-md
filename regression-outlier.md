# Regression outlier

↑ **Parent:** [Regression diagnostics](regression-diagnostics.md)

A [regression outlier](regression-outlier.md) has a response unusually far from its fitted conditional mean. A [standardized regression residual](standardized-regression-residual.md) adjusts for [regression leverage](regression-leverage.md); an externally studentized residual also estimates noise [variance](variance-split.md) with the observation deleted. Selecting the largest residual among many observations changes its reference distribution. An outlier need not be an [influential observation](influential-observation.md), and unusual valid data should not be discarded solely for being unusual.
