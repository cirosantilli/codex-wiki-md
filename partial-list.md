# Partial list

↑ **Parent:** [Lazy list](lazy-list.md)

A [list](list-abstract-data-type.md) whose spine or elements may contain [bottom values](bottom-value.md). The displayed value has a known finite spine prefix and an undefined tail. An entirely undefined list exposes no outer constructor, while `[]` exposes a terminating empty list. These distinctions matter to [strict functions](strict-function.md) and to the [fold factorisation criterion](fold-factorisation-criterion.md).
