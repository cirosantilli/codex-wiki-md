# Monotone set function

↑ **Parent:** [Set function](set-function.md)

A real-valued [set function](set-function.md) is monotone, in the nondecreasing convention, when enlarging its input [subset](subset.md) cannot decrease its value. Equivalently, each [marginal increment](marginal-increment-of-a-set-function.md) $\Delta_x f(S)$ is nonnegative. This follows by adding elements individually; the converse follows by considering $S\subseteq S\cup\{x\}$. A [normalised set function](normalised-set-function.md) with this property is a [nonnegative function](nonnegative-function.md).
