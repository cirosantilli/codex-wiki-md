# Scalar clipping

↑ **Parent:** [Continuous map](continuous-map.md)

The [continuous map](continuous-map.md) projecting a real number onto the [closed interval](closed-real-interval.md) $[a,b]$, with $a\le b$. It equals $a$ below the interval, equals the input inside it, and equals $b$ above it. It is nondecreasing and has [Lipschitz constant](lipschitz-constant.md) one.
