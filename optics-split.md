# Optics

↑ **Parent:** [Branches of physics](branches-of-physics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Optics)

Optics studies [light](light.md), its propagation, and instruments for forming images and measuring [optical spectra](optical-spectrum.md).

The central question is how [light](light.md) carries information from a source to an observer. A useful description must explain both where the [light](light.md) goes and how its distribution changes. In [geometrical optics](geometrical-optics.md), [light rays](light-ray.md) locate paths and images; in [physical optics](physical-optics.md), an [electromagnetic wave](electromagnetic-wave.md) has a [wave amplitude](wave-amplitude.md) and a [wave phase](phase-waves.md), so overlapping contributions can produce [wave interference](interference-wave-propagation.md) and [diffraction](diffraction.md). These descriptions address different levels of detail within the same subject. [OpenStax: The propagation of light](https://openstax.org/books/university-physics-volume-3/pages/1-1-the-propagation-of-light).

An image is especially interesting because a single object point emits [light](light.md) in many directions. An [optical lens](lens-optics.md) redirects part of that spreading bundle toward a corresponding image point; repeating this construction over the object preserves spatial information. Simply gathering more [light](light.md) is insufficient: [light rays](light-ray.md) from distinct object points must arrive at distinct locations. This is why an [optical camera](optical-camera.md) needs both an [optical lens](lens-optics.md) and a correctly positioned receiving surface. The [thin lens](thin-lens.md) example below makes that correspondence quantitative. [OpenStax: Images formed by refraction](https://openstax.org/books/university-physics-volume-3/pages/2-3-images-formed-by-refraction).
