# Magnetic tweezers

↑ **Parent:** [Magnetic dipole](magnetic-dipole.md)

A generic instrument for [force](force-split.md) and [torque](torque.md) uses a magnetically responsive bead in a controlled [magnetic field](magnetic-field-split.md), with optical tracking. Translational [force](force-split.md) requires a field gradient. Permanent or anisotropic moments can feel orienting [torque](torque.md); an isotropic induced moment parallel to the field has no such [torque](torque.md). This definition concerns the physical instrument, without biological applications.
