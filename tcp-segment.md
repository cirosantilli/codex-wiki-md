# TCP segment

↑ **Parent:** [Transmission Control Protocol](transmission-control-protocol.md)

A [TCP segment](tcp-segment.md) contains a [TCP](transmission-control-protocol.md) header and zero or more data [bytes](byte.md). The header carries sequencing, [acknowledgement](acknowledgement.md) and [receive window](receive-window.md) information.
