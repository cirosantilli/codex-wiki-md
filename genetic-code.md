# Genetic code

↑ **Parent:** [Translation (biology)](translation-biology.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Genetic_code)

The [genetic code](genetic-code.md) assigns [RNA](ribonucleic-acid.md) [codons](codon.md) to [amino acids](amino-acid.md) or termination signals. Four possible [nucleobases](nucleotide-base.md) at each of three positions give $4^3=64$ [codons](codon.md). In the standard [genetic code](genetic-code.md), 61 specify [amino acids](amino-acid.md) and three are [stop codons](stop-codon.md); several [codons](codon.md) can specify the same [amino acid](amino-acid.md). Variants exist, so state which [genetic code](genetic-code.md) is being used. See [Clark, Douglas and Choi: genetic code assignments and variants](https://openstax.org/books/biology-2e/pages/15-1-the-genetic-code).
