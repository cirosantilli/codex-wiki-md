# Zero set of a continuous function

↑ **Parent:** [Continuous function](continuous-function.md)

For a [continuous function](continuous-function.md) $f:X\to\mathbb R$, its zero set is $f^{-1}(\{0\})$. It is closed and is a [G-delta set](g-delta-set.md), since $f^{-1}(0)=\bigcap_{n\geq1}f^{-1}((-1/n,1/n))$. Replacing $f$ by $|f|/(1+|f|)$ gives the same zero set with values in $[0,1]$. In a [normal topological space](normal-space.md), every closed [G-delta set](g-delta-set.md) has this form.
