# Vector R-symmetry

↑ **Parent:** [R-symmetry](r-symmetry.md)

In two-dimensional N=(2,2) supersymmetry, vector R-symmetry rotates $\theta^+$ and $\theta^-$ with the same phase. A chiral superspace measure has vector R-charge minus two.
