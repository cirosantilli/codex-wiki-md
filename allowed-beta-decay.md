# Allowed beta decay

↑ **Parent:** [Beta decay transition](beta-decay-transition.md)

A [beta decay transition](beta-decay-transition.md) whose leading lepton orbital term has $l=0$. [Fermi transitions](fermi-transition.md) allow $\Delta J=0$ and [Gamow-Teller transitions](gamow-teller-transition.md) allow $\Delta J=0,1$, excluding a Gamow-Teller $0\to0$ transition. Both preserve nuclear [parity](parity.md). Allowed describes the selection rules; cancellations in the nuclear matrix element can still make an allowed transition slow.
