# Lagrangian displacement (symplectic geometry)

↑ **Parent:** [Lagrangian submanifold](lagrangian-submanifold.md)

A Lagrangian $L\subset M$ is displaceable by a class of isotopies when some isotopy $\phi_t$ in that class satisfies $\phi_1(L)\cap L=\varnothing$.
