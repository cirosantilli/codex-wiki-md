# Shortest-seek-time-first disk scheduling

↑ **Parent:** [Disk scheduling](disk-scheduling.md)

Serve the pending request whose track is nearest to the current head position, with an explicit tie rule when necessary. This minimizes the next [seek distance](seek-distance.md), rather than the total distance of every future request; a continuing stream of nearby requests can starve a distant request.
