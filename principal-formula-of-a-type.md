# Principal formula of a type

↑ **Parent:** [Partial type](partial-type.md)

A [principal formula of a type](principal-formula-of-a-type.md) is a [logical formula](logical-formula.md) [first-order consistent](first-order-consistency.md) with the base [first-order theory](first-order-theory.md) that, modulo that [first-order theory](first-order-theory.md), implies every [logical formula](logical-formula.md) of the [partial type](partial-type.md). For a [complete type](complete-type.md) it isolates a single point of the [type space](type-space.md). A realized finite-tuple [partial type](partial-type.md) in a finite [first-order structure](first-order-structure.md) has such a [logical formula](logical-formula.md) by conjoining one distinguishing [logical formula](logical-formula.md) for each competing [tuple](finite-tuple.md) with a different [partial type](partial-type.md).
