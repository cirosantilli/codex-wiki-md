# P-adic number

↑ **Parent:** [Non-Archimedean analysis](non-archimedean-analysis.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/P-adic_number)

A $p$-adic number is an element of the completion $\mathbb Q_p$ of the [rational numbers](rational-number.md) with respect to the $p$-adic absolute value.
