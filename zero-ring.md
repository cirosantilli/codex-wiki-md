# Zero ring

↑ **Parent:** [Ring](ring.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Zero_ring)

The ring with a single element, which is both its additive and multiplicative identity. If a unital [ring](ring.md) has $0=1$, then every element $r$ equals $r1=r0=0$, so it is this ring. Under the usual definition it is excluded from [integral domains](integral-domain.md) and [fields](field.md). The [quotient ring](quotient-ring.md) $\mathbb Z/(1)$ is an example.
