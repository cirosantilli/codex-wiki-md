# Thermometer calibration

↑ **Parent:** [Thermometer](thermometer.md)

[Thermometer](thermometer.md) calibration compares an instrument's response with assigned reference [temperatures](temperature.md) under specified conditions. In a proposed two-reference procedure, thermalize the sensing part at $T_0$ and $T_1$, record responses $X_0$ and $X_1$, and, only if a linear response is justified over that interval, use

$$
T(X)=T_0+(T_1-T_0)\frac{X-X_0}{X_1-X_0}.
$$

Additional reference [temperatures](temperature.md) test curvature; returning to the first reference tests drift. A [gas thermometer](gas-thermometer.md) instead obtains its response from an [equation of state](equation-of-state.md), with a reference and corrections for its apparatus. In either case, uncertainty in the reference propagates to the inferred [temperature](temperature.md). Calibration determines the response relation; it cannot by itself remove the finite-sample disturbance or incomplete [thermal equilibrium](thermal-equilibrium.md) described in [thermometer](thermometer.md). A reference established on a practical scale can also differ slightly from true [thermodynamic temperature](thermodynamic-temperature.md); the BIPM distinguishes the International Temperature Scale of 1990 readings from their thermodynamic counterparts.[section 2.3.1: practical and thermodynamic temperature](the-international-system-of-units-si-ninth-edition-si-brochure.md)
