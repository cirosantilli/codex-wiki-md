# Complementarity-determining region

↑ **Parent:** [Antibody variable region](antibody-variable-region.md)

A [complementarity-determining region](complementarity-determining-region.md) is a variable-region segment contributing to an antibody binding site. Transfer of these regions can transfer specificity, but framework residues also influence conformation and affinity.
