# Squeezed coherent state

↑ **Parent:** [Quantum harmonic oscillator](quantum-harmonic-oscillator-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Squeezed_coherent_state)

A [squeezed coherent state](squeezed-coherent-state.md) is obtained from the vacuum by a squeeze operator and a displacement operator. Its quadrature variances can differ while saturating the uncertainty product. With zero displacement it is a [squeezed vacuum state](squeezed-vacuum-state.md).
