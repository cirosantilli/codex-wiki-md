# Chromatic number of the half-density binomial random graph

↑ **Parent:** [Binomial random graph](binomial-random-graph.md)

For the [binomial random graph](binomial-random-graph.md) $G(n,1/2)$, the [chromatic number](chromatic-number.md) is $(1+o(1))n/(2\log_2n)$ [with high probability](with-high-probability.md). A [first moment method](first-moment-method.md) bounds the [independence number](independence-number.md) above. [Edge-disjoint clique packing](edge-disjoint-clique-packing.md) in the [complement graph](complement-graph.md), followed by an [edge-exposure martingale](edge-exposure-martingale.md) and a [union bound](boole-s-inequality.md) over moderately large [vertex](vertex-graph-theory.md) sets, supplies [independent sets](independent-set-graph-theory.md) for [greedy colouring by removing independent sets](greedy-colouring-by-removing-independent-sets.md).
