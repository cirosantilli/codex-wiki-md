# Generalized eigenvalue problem

↑ **Parent:** [Operator theory](linear-operator-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generalized_eigenvalue_problem)

A generalized eigenvalue problem asks for a nonzero vector $v$ and scalar $\lambda$ satisfying $Av=\lambda Bv$. When $B$ is invertible, it is equivalent to the ordinary [eigenvalue](eigenvalue.md) problem $B^{-1}Av=\lambda v$.
