# Segmentation interface curvature balance

↑ **Parent:** [Piecewise-constant Mumford–Shah problem](piecewise-constant-mumford-shah-problem.md)

When grey values are fixed but region labels vary, a smooth interface satisfies $\beta\kappa=(c_j-g)^2-(c_i-g)^2$. The [curvature](curvature.md) uses the normal pointing out of region $i$, positive on an outward-oriented circle. It balances the change in data cost against the first variation of interface length. Fixing a full spatial [image signal](image-signal.md) instead fixes its jumps and leaves no such boundary-relocation freedom.
