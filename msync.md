# msync

↑ **Parent:** [Memory-mapped file synchronization](memory-mapped-file-synchronization.md)

A mapping-range synchronization interface used by [memory-mapped file synchronization](memory-mapped-file-synchronization.md). Its `MS_SYNC` mode concerns completed updates to a [backing file](backing-file.md); it does not merge [private file mapping](private-file-mapping.md) changes into that [file](computer-file.md) or coordinate competing readers and writers.
