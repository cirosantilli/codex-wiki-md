# List zip

↑ **Parent:** [List (abstract data type)](list-abstract-data-type.md)

Combine corresponding entries of two [lists](list-abstract-data-type.md) into a [list](list-abstract-data-type.md) of [tuples](finite-tuple.md). The usual finite-list operation stops when either input ends. A [lazy evaluation](lazy-evaluation.md) implementation can produce entries from infinite [lists](list-abstract-data-type.md), but its exact strictness depends on the order of [pattern matching](pattern-matching.md) in the definition.
