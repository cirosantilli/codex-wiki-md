# Orbital angular velocity

↑ **Parent:** [Orbital period](orbital-period.md)

For a [circular orbit](circular-orbit.md), the angular rate about the central body equals $2\pi$ divided by its [orbital period](orbital-period.md). Matching it to planetary spin is necessary for a [planet-stationary orbit](planet-stationary-orbit.md), which additionally requires a prograde equatorial circular geometry.
