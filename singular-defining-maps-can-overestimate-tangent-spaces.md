# Singular defining maps can overestimate tangent spaces

↑ **Parent:** [Tangent space](tangent-space.md)

If the zero set of a differentiable [function](function-split.md) $g$ is a [submanifold](submanifold.md), the [chain rule](chain-rule.md) always places its [tangent space](tangent-space.md) inside $\ker Dg_a$. Equality follows from the full-rank hypotheses of the [regular level set theorem](regular-level-set-theorem.md), but may fail for a singular defining function even when the zero set itself is smooth. For $g:\mathbb R\to\mathbb R$, $g(x)=x^2$, the zero set is the single point $\{0\}$. Its [tangent space](tangent-space.md) is zero, while $Dg_0=0$ has kernel $\mathbb R$. One should therefore check the [constraint qualification](constraint-qualification.md) before using the kernel formula.
