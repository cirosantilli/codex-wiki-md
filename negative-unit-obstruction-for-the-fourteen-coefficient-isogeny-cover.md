# Negative unit obstruction for the fourteen-coefficient isogeny cover

↑ **Parent:** [Quartic covering in a two-isogeny descent](quartic-covering-in-a-two-isogeny-descent.md)

This [quartic covering in a two-isogeny descent](quartic-covering-in-a-two-isogeny-descent.md) has no solution with coprime integers $U,V$ not both zero. If precisely one is odd, the right side is $3$ modulo four. If both are odd, their fourth powers are one modulo sixteen and $14U^2V^2=14$ modulo sixteen, so the right side is twelve modulo sixteen. Neither residue is a square. Coprimality excludes the remaining parity case. Consequently the negative unit [square class](square-class.md) is absent from the [two-torsion square-class homomorphism](two-torsion-square-class-homomorphism.md) for $Y^2=X^3+14X^2+X$.
