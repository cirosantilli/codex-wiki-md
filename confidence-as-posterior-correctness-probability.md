# Confidence as posterior correctness probability

↑ **Parent:** [Retrospective confidence](retrospective-confidence.md)

A normative [Bayesian inference](bayesian-statistics-split.md) model of [retrospective confidence](retrospective-confidence.md). For two exhaustive alternatives with equal [prior probabilities](prior-probability.md), let $L=\log[p(E\mid H_1)/p(E\mid H_0)]$ be the [log-likelihood ratio](log-likelihood-ratio.md). [Bayes' theorem](bayes-theorem.md) gives posterior odds $e^L$. Choosing the alternative with the larger posterior yields $P(\text{correct}\mid E)=(1+e^{-|L|})^{-1}$. Unequal priors add prior log odds; choosing a different action changes which posterior probability is appropriate. This calculation does not establish that an observer knows the true likelihoods.
