# Proximal operator of a support function

↑ **Parent:** [Moreau decomposition](moreau-decomposition.md)

For a nonempty closed convex set $C$, the [Moreau decomposition](moreau-decomposition.md) and $\sigma_C^*=\iota_C$ give $\operatorname{prox}_{t\sigma_C}(y)=y-t\Pi_C(y/t)$.
