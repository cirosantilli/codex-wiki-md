# Highest-weight vector

↑ **Parent:** [Weight vector](weight-vector.md)

A highest-weight vector is a nonzero [weight vector](weight-vector.md) annihilated by every positive-root [raising operator](raising-operator.md). The module it generates is a [highest-weight representation](highest-weight-representation.md).
