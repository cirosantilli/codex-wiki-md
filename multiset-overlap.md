# Multiset overlap

↑ **Parent:** [Multiset](multiset.md)

The common multiplicity of two [multisets](multiset.md), summing the smaller multiplicity of each value. To return an order-preserving overlap of two finite [lists](list-abstract-data-type.md), scan the first list and consume one equal item from the second whenever available. Each token can be consumed at most once, so the resulting [subsequence](subsequence.md) has maximum possible length among those that occur in a permutation of the second list.
