# Base (chemistry)

↑ **Parent:** [Acid-base chemistry](acid-base-chemistry-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Base_(chemistry))

A [chemical base](base-chemistry.md) can accept a [proton](proton.md), using an available [electron pair](electron-pair.md) to form a [covalent bond](covalent-bond-split.md); more generally it can donate an [electron pair](electron-pair.md) to form a [covalent bond](covalent-bond-split.md) with another species. See [IUPAC Gold Book, base](https://goldbook.iupac.org/terms/view/B00601).
