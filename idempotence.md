# Idempotence

↑ **Parent:** [Binary operation](binary-operation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Idempotence)

For a [binary operation](binary-operation.md), idempotence means repeating an input does not change it: $x\ast x=x$. An associative commutative idempotent operation defines a [join](least-upper-bound-in-a-partially-ordered-set.md) order by $x\le y\iff x\ast y=y$.
