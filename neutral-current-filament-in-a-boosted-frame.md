# Neutral current filament in a boosted frame

↑ **Parent:** [Boosted uniform line charge](boosted-uniform-line-charge.md)

For an ideal infinite filament with zero [line charge](line-charge.md) [density](density.md) and current $I$ in a laboratory frame, the line-integrated [four-current](four-current.md) is $(0,I)$ in temporal/axial components. An axial boost of [speed](speed.md) $u$ gives the title [density](density.md) and current. The laboratory [magnetic field](magnetic-field-split.md) $\mu_0I\widehat{\boldsymbol\varphi}/(2\pi r)$ therefore becomes both an [electric field](electric-field-split.md) from $\lambda'$ and a [magnetic field](magnetic-field-split.md) from $I'$. [Charge neutrality](charge-neutrality.md) is frame-dependent for a current-carrying system. A model built from oppositely charged moving and resting populations makes this result explicit; the charge of each fixed material particle set remains invariant.
