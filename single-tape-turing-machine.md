# Single-tape Turing machine

↑ **Parent:** [Turing machine](turing-machine.md)

A [Turing machine](turing-machine.md) with one read-write tape. Every [multitape Turing machine](multitape-turing-machine.md) can be simulated by a [single-tape Turing machine](single-tape-turing-machine.md), using delimited tape portions and marked head positions. The simulation preserves the accepted [formal language](formal-language.md) and whether a computation halts, while possibly increasing [time complexity](time-complexity.md).
