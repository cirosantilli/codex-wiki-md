# Bell number

↑ **Parent:** [Stirling numbers of the second kind](stirling-numbers-of-the-second-kind.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bell_number)

The [Bell number](bell-number.md) $B_n$ counts all [set partitions](set-partition.md) of an $n$-element [finite set](finite-set.md), with no restriction on the number of [blocks of a set partition](block-of-a-set-partition.md). Summing the [Stirling numbers of the second kind](stirling-numbers-of-the-second-kind.md) gives $B_n=\sum_{k=0}^n S(n,k)$. The first five values, for $n=0,1,2,3,4$, are $1,1,2,5,15$. In particular, $B_4=1+7+6+1=15$. [Grassl and Levin, More Discrete Mathematics via Graph Theory, definition 3.1.2: Bell numbers](https://discrete.openmathbooks.org/more/mdm/sec_adv-partitions.html)
