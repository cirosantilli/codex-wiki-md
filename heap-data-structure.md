# Heap data structure

↑ **Parent:** [Data structure](data-structure-split.md)

A tree-based [data structure](data-structure-split.md) that orders each parent relative to its children so that an extremal value is available at the root. In a [max-heap](max-heap.md), every parent is at least as large as its children. Heap implementations provide one way to realize a [priority queue](priority-queue.md); the abstract queue and its implementing structure are distinct concepts.
