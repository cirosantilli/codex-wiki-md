# Organelle

↑ **Parent:** [Biological cell](biological-cell.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Organelle)

An [organelle](organelle.md) is a specialized subcellular structure. Usage varies over whether non-membrane-bounded structures such as [ribosomes](ribosome.md) count as [organelles](organelle.md), so explicitly say membrane-bounded [organelles](organelle.md) when comparing [eukaryotic](eukaryote.md) compartmentalization with [prokaryotic](prokaryote.md) organization. [Mitochondria](mitochondria.md) and [chloroplasts](chloroplast.md) are membrane-bounded examples. See [OpenStax Microbiology, 3.4: cellular compartments](https://openstax.org/books/microbiology/pages/3-4-unique-characteristics-of-eukaryotic-cells).
