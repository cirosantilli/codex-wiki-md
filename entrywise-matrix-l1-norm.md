# Entrywise matrix L1 norm

↑ **Parent:** [Matrix](matrix.md)

For a real [matrix](matrix.md) $M$, the entrywise L1 norm is $\sum_{r,s}|M_{rs}|$, the [L1 norm](l1-norm.md) of its vector of entries. It is the usual penalty in the all-entry convention for the [Graphical Lasso](graphical-lasso.md).
