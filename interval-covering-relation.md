# Interval covering relation

↑ **Parent:** [Interval map](interval-map.md)

For [closed intervals](closed-real-interval.md) $J$ and $K$, write $J\longrightarrow K$ under $F$ when $F(J)\supseteq K$. The [intermediate value theorem](intermediate-value-theorem.md) implies that there is a closed subinterval $L\subseteq J$ with $F(L)=K$.
