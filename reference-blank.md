# Reference blank

↑ **Parent:** [Beer-Lambert measurement controls](beer-lambert-measurement-controls.md)

A [reference blank](reference-blank.md) is the comparison sample used to establish the background response in a measurement. For [absorbance](absorbance.md), it contains matching [solvent](solvent.md) and other assay ingredients without the target absorbing [chemical species](chemical-species.md); it sets the reference [radiant power](radiant-flux.md) $P_0$ under matching [cuvette](cuvette.md) and [wavelength](wavelength.md) conditions.
