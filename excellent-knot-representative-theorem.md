# Excellent knot representative theorem

↑ **Parent:** [Excellent three-manifold](excellent-three-manifold.md)

In a compact connected orientable [three-manifold](3-manifold.md) with no spherical boundary components, every embedded [knot](knot.md) is homotopic to a [knot](knot.md) with an [excellent three-manifold](excellent-three-manifold.md) as exterior. In particular this can preserve the generator class in $S^1\times S^2$, or the [winding number of a satellite pattern](winding-number-of-a-satellite-pattern.md) one class in a [solid torus](solid-torus.md). Homotopy here is weaker than [isotopy](isotopy.md).
