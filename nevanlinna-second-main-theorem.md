# Nevanlinna second main theorem

↑ **Parent:** [Nevanlinna theory](nevanlinna-theory.md)

For distinct fixed target values and a nonconstant [meromorphic function](meromorphic-function.md), the truncated second main theorem has the displayed form, with $S_f=O(\log^+T_f+\log r)$ outside a set of finite linear measure. The [truncated Nevanlinna counting function](truncated-nevanlinna-counting-function.md) retains only one unit at each preimage. For finite-order functions the error is $O(\log r)$; for transcendental functions it is $o(T_f)$ along the nonexceptional radii.
