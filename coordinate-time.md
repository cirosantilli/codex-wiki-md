# Coordinate time

↑ **Parent:** [Time in physics](time-in-physics.md)

[Coordinate time](coordinate-time.md) labels events in a chosen spacetime chart. It is distinct from [proper time](proper-time.md), which is measured by a [clock](clock.md) along its timelike path. For a stationary observer in a static [metric](metric.md) with signature $(+---)$, the rate is $d\tau=\sqrt{g_{tt}}\,dt$ in units with light speed one. Different stationary observers can therefore accumulate different [proper times](proper-time.md) during the same coordinate-time interval.
