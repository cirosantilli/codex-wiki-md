# Basis matrix

↑ **Parent:** [Basis](basis.md)

A [matrix](matrix.md) whose columns are the [coordinate vectors](coordinate-vector.md) of an ordered [basis](basis.md) in a fixed reference [basis](basis.md). It is an [invertible matrix](invertible-matrix.md), and multiplication by it converts [coordinates](coordinate-linear-algebra.md) in the column [basis](basis.md) to the reference [coordinates](coordinate-linear-algebra.md): $v=B[v]_B$. For a real [inner product space](inner-product-space.md) with orthonormal reference [basis](basis.md), its [Gram matrix](gram-matrix.md) is $B^TB$, and its [reciprocal basis](reciprocal-basis.md) has [basis matrix](basis-matrix.md) $B^{-T}$.
