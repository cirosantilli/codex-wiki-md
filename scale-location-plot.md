# Scale-location plot

↑ **Parent:** [Residual-versus-fitted plot](residual-versus-fitted-plot.md)

A scale-location plot compares the square root of the absolute [standardized regression residual](standardized-regression-residual.md) with the [fitted values](fitted-values.md). Systematic changes in level or spread suggest [heteroscedasticity](heteroscedastic.md). It assesses the error scale, while a [residual-versus-fitted plot](residual-versus-fitted-plot.md) primarily reveals mean patterns as well as changing spread.
