# Universal forgery

↑ **Parent:** [Digital signature](digital-signature.md)

The ability to produce a valid [digital signature](digital-signature.md) for an arbitrary specified target message. Under a [chosen-message signature attack](chosen-message-signature-attack.md), the target must not have been submitted to the signing oracle.
