# Type-I phase matching

↑ **Parent:** [Phase matching](phase-matching.md)

In a common birefringent down-conversion arrangement, the two daughter [photons](photon.md) have the same polarization class, ordinarily both ordinary or both extraordinary relative to the crystal. The pump has a suitable different index for [phase matching](phase-matching.md). This classification alone does not establish polarization entanglement.
