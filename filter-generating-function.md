# Filter generating function

↑ **Parent:** [Linear filter of a stationary time series](linear-filter-of-a-stationary-time-series.md)

For absolutely summable linear-filter coefficients, the generating function is the displayed [Laurent series](laurent-series.md), absolutely convergent on the [unit circle](complex-unit-circle.md). If the filter is one-sided, it is a [power series](power-series.md) analytic inside the [unit disk](unit-disk.md). A two-sided filter need not have a nonempty larger annulus of convergence. Substituting the [backshift operator](backshift-operator.md) gives the formal notation $Y=A(B)X$.
