# Colimit-preserving functor

↑ **Parent:** [Functor](functor.md)

Relative to a specified class of diagram shapes, a functor preserves colimits when it takes each existing [colimit](colimit.md) cocone of those shapes to a [colimit](colimit.md) cocone. A [left adjoint](adjoint-functors.md) preserves all existing colimits, including large ones when their universal properties are meaningful. Small-colimit preservation alone does not imply preservation of a class-indexed colimit.
