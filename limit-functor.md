# Limit functor

↑ **Parent:** [Categorical limit](categorical-limit.md)

With chosen $J$-shaped [categorical limits](categorical-limit.md), the limit functor sends each [diagram in a category](diagram-category-theory.md) to its limit object. A [natural transformation](natural-transformation.md) induces the unique morphism compatible with the limit-cone projections. It is a [right adjoint](adjoint-functors.md) to the [constant diagram functor](constant-diagram-functor.md), so it preserves existing [categorical limits](categorical-limit.md).
