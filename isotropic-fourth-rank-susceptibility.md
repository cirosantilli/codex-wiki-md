# Isotropic fourth-rank susceptibility

↑ **Parent:** [Nonlinear-susceptibility tensor symmetry](nonlinear-susceptibility-tensor-symmetry.md)

An isotropic fourth-rank polar [tensor](tensor.md) has the displayed form. If its three input slots are fully interchangeable at the same relevant [frequency](frequency.md) arguments, then $a=b=c$, giving $\chi_{xxxx}=3\chi_{xxyy}$. For mixed-sign or unequal [frequencies](frequency.md), intrinsic permutation exchanges the arguments too; it need not make all coefficients at one fixed ordering equal.
