# Empirical adequacy

↑ **Parent:** [Constructive empiricism](constructive-empiricism.md)

A theory is empirically adequate when it correctly represents the observable phenomena, including those not yet observed. Agreement with the data already collected is therefore insufficient to establish [empirical adequacy](empirical-adequacy.md).
