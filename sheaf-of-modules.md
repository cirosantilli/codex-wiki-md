# Sheaf of modules

↑ **Parent:** [Ringed space](ringed-space-split.md)

For a [ringed space](ringed-space-split.md) $(X,\mathcal O_X)$, a sheaf of $\mathcal O_X$-modules is a sheaf $\mathcal F$ such that every $\mathcal F(U)$ is an $\mathcal O_X(U)$-module and restriction maps preserve scalar multiplication.

The underlying object is a [Sheaf (mathematics)](sheaf-mathematics.md) with compatible local module actions.
