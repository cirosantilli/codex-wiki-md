# Gradient of a Sobolev function vanishes on a level set

↑ **Parent:** [Sobolev chain rule](sobolev-chain-rule.md)

If $u\in W^{1,2}_{\mathrm{loc}}$, then $Du=0$ [almost everywhere](almost-everywhere.md) on every [level set](level-set.md) $\{u=t\}$. Choose smooth truncations $\Phi_\varepsilon(s)$ with $|\Phi_\varepsilon|\leq2\varepsilon$, derivative one near zero, bounded derivative, and derivative zero outside $(-2\varepsilon,2\varepsilon)$. The [Sobolev chain rule](sobolev-chain-rule.md) gives $D\Phi_\varepsilon(u-t)\to\mathbf1_{\{u=t\}}Du$ in local $L^2$ by [dominated convergence theorem](dominated-convergence-theorem.md), while $\Phi_\varepsilon(u-t)\to0$. The limiting [weak derivative](weak-derivative.md) is therefore zero.
