# Initial-boundary value problem

↑ **Parent:** [Initial and boundary data for evolution equations](initial-and-boundary-data-for-evolution-equations.md)

An initial-boundary value problem specifies a [partial differential equation](partial-differential-equation-split.md), [initial conditions](initial-condition.md), and [boundary conditions](boundary-condition.md). For example, the half-line [wave equation](wave-equation-split.md) $u_{tt}=c^2u_{xx}$ requires an initial displacement and initial [velocity](velocity.md) for $x\geq0$ together with an endpoint condition such as $u(0,t)=0$ for $t>0$. Its meaning also depends on the chosen solution class: a [classical solution](classical-solution.md) satisfies the equation pointwise, while a [weak solution](weak-solution.md) satisfies an integrated form. These data must obey the compatibility conditions needed by the chosen regularity.
