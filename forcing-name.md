# Forcing name

↑ **Parent:** [Forcing](forcing-split.md)

A forcing name is a recursively built set of pairs $(\sigma,p)$, where $\sigma$ is a lower-rank forcing name and $p$ is a forcing condition. Ground-model names are interpreted using a [generic filter](generic-filter.md) to form the [generic extension](generic-extension.md).
