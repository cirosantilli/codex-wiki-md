# Kernel for nonparametric regression

↑ **Parent:** [Local polynomial regression](local-polynomial-regression.md)

A nonnegative [regression kernel](kernel-for-nonparametric-regression.md) supplies weights $K((x_i-x)/h)$ in a local [weighted least squares](weighted-least-squares.md) fit. Unlike a [probability density function](probability-density-function.md), its integral need not equal one, because rescaling every weight does not change the fitted coefficients.
