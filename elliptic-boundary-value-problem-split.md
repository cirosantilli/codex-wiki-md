# Elliptic boundary value problem

↑ **Parent:** [Partial differential equation](partial-differential-equation-split.md)

An elliptic boundary value problem couples an elliptic differential equation in a domain to [boundary conditions](boundary-condition.md). Its [weak formulation](weak-formulation.md) is often an equation for a [bounded bilinear form](bounded-bilinear-form.md) on a [Sobolev space](sobolev-space-split.md).
