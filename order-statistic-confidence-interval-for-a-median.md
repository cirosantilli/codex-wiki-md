# Order-statistic confidence interval for a median

↑ **Parent:** [Confidence interval](confidence-interval.md)

For a sample of size $n$ from a [continuous probability distribution](continuous-probability-distribution-split.md), this interval covers the [median](median.md) $F^{-1}(1/2)$ with probability $1-2\sum_{r=0}^{j-1}\binom nr2^{-n}$, for $1\leq j<n/2$. Count observations below the [median](median.md): their number has the [binomial distribution](binomial-distribution.md) with parameters $n,1/2$. No strict increase of the [distribution function](cumulative-distribution-function.md) is needed.
