# Avialae

↑ **Parent:** [Theropod dinosaur](theropod-dinosaur.md)

A name used for a more restricted avian-lineage [clade](clade.md) than [Panaves](panaves.md). Definitions have included a branch-based bird-versus-deinonychosaur rule and an apomorphy-based flight rule; the definition must be specified in comparative work.
