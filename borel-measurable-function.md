# Borel measurable function

↑ **Parent:** [Measurable function](measurable-function.md)

A function into a topological space is Borel measurable when the inverse image of every [Borel set](borel-set.md) is measurable. Equivalently, it is measurable when the target carries its Borel sigma-algebra.
