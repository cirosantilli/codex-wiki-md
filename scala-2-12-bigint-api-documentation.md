<h1 id="scala-2-12-bigint-api-documentation">Scala 2.12 BigInt API documentation</h1>

↑ **Parent:** [Computer science bibliography](computer-science-bibliography-split.md)

Official archived documentation: [https://www.scala-lang.org/api/2.12.8/scala/math/BigInt.html](https://www.scala-lang.org/api/2.12.8/scala/math/BigInt.html)

Relevant locators: remainder `%`, `gcd`, `isValidInt` and `toInt`. [Scala](scala.md)'s `BigInt` provides [arbitrary-precision integer arithmetic](arbitrary-precision-integer-arithmetic.md); representability must be checked before conversion to a fixed-width [integer](integer-split.md) because narrowing conversion need not preserve the exact value. The archived API corroborates the operations used in the solution without claiming a particular installed Oxford course library version.
