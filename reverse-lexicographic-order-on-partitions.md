# Reverse lexicographic order on partitions

↑ **Parent:** [Partition of an integer](partition-of-an-integer.md)

Pad partitions with trailing zeros. In the descending-dictionary convention used for symmetric-function reverse lexicographic ordering, the partition with the larger first differing part precedes the other. This is the reverse of increasing [dictionary order on integer partitions](dictionary-order-on-integer-partitions.md), and is a total order. It is distinct from comparing the last differing part in a [monomial](monomial.md) reverse-lexicographic order.
