# Typing context

↑ **Parent:** [Typing judgment](typing-judgment.md)

A [typing context](typing-context.md) records the types assumed for available program names. In $\Gamma=\{x:\mathrm{int},y:\mathrm{int}\}$, looking up either name yields `int`. Checking a [lambda abstraction](lambda-abstraction.md) extends the [typing context](typing-context.md) with its argument's type for the body. In the [Hindley-Milner type system](hindley-milner-type-system.md), a [typing context](typing-context.md) can also hold [type schemes](type-scheme.md) for names introduced by [let polymorphism](let-polymorphism.md).
