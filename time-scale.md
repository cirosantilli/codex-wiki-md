# Time scale

↑ **Parent:** [Mathematical physics](mathematical-physics-split.md)

A [time scale](time-scale.md) is a characteristic duration over which a specified variable or process changes appreciably. Comparing [time scales](time-scale.md) helps choose a dimensionless time and identify a [singular perturbation](singular-perturbation-split.md). An exponential relaxation $x-x_*=A e^{-t/\tau}$ has relaxation [time constant](time-constant.md) $\tau$; a nonlinear process can have several distinct [time scales](time-scale.md).
