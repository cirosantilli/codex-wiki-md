# Elementary transvection matrix

↑ **Parent:** [Transvection](transvection.md)

This [matrix](matrix.md) adds $t$ times coordinate $j$ to coordinate $i$. Left multiplication performs the corresponding row addition. Such matrices generate the [special linear group over a finite field](special-linear-group-over-a-finite-field.md): row elimination also realizes signed interchanges and compensating diagonal scalings using products of these matrices.
