# Planar isotropic stellar distribution function

↑ **Parent:** [Galactic distribution function](galactic-distribution-function.md)

For a stationary [collisionless stellar system](collisionless-stellar-system.md) confined to a plane, [velocity](velocity.md) isotropy makes the [galactic distribution function](galactic-distribution-function.md) depend on [speed](speed.md) through $u=v^2/2$. The [Collisionless Boltzmann equation](collisionless-boltzmann-equation.md) implies $\nabla_x f=f_u\nabla_x\Phi$, hence $f=F(E)$ with [specific orbital energy](specific-orbital-energy.md) $E=u+\Phi$. This conclusion requires stationarity as well as isotropy.
