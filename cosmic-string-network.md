# Cosmic string network

↑ **Parent:** [Barotropic equation of state](barotropic-equation-of-state.md)

An isotropic network of long cosmic strings has average equation-of-state parameter $w=-1/3$ and energy density proportional to $a^{-2}$.

The equation of state averages the stress of a [cosmic string](cosmic-string.md) over an isotropic network; it is not the definition of the individual defect.
