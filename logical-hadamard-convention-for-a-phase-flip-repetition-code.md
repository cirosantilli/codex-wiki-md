# Logical Hadamard convention for a phase-flip repetition code

↑ **Parent:** [Phase-flip repetition code](phase-flip-repetition-code.md)

The codewords $|+++\rangle,|---\rangle$ have residual logical [Pauli X gate](pauli-x-gate.md) after an uncorrectable two- or three-site phase error. Precede their encoding by a logical [Hadamard gate](hadamard-gate.md) and follow decoding by its inverse. Since $HXH=Z$, the same error now acts as a logical [Pauli Z gate](pauli-z-gate.md). Explicitly the encoded coefficients are $(\alpha+\beta)/\sqrt2$ and $(\alpha-\beta)/\sqrt2$ for an input $\alpha|0\rangle+\beta|1\rangle$. This convention matters when translating physical phase errors into a claimed decoded phase-error channel.
