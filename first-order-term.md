# First-order term

↑ **Parent:** [First-order language](first-order-language.md)

A first-order term is built recursively from variables and constant symbols by applying function symbols to existing terms. Evaluation in a [first-order structure](first-order-structure.md) follows the same recursion. An [atomic formula](atomic-formula.md) applies a relation to terms, or asserts their [logical equality](logical-equality.md).
