# Category of partial functions

↑ **Parent:** [Category of sets](category-of-sets.md)

The category $\mathbf{Part}$ has [sets](set-split.md) as objects and [partial functions](partial-function.md) as morphisms. Composition is defined where both successive functions are defined. The nowhere-defined map is a [zero morphism](zero-morphism.md), and the empty set is its sole actual [zero object](zero-object.md). Adjoining a tagged basepoint turns a partial function into a total basepoint-preserving function, giving an [equivalence of categories](equivalence-of-categories.md) with the [category of pointed sets](category-of-pointed-sets.md).
