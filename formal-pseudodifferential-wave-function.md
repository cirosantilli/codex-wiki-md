# Formal pseudodifferential wave function

↑ **Parent:** [Formal pseudodifferential operator](formal-pseudodifferential-operator.md)

Treat $k$ as a formal spectral parameter near infinity. If $P=\sum_{j\geq0}g_j\partial^{\alpha-j}$, the [formal pseudodifferential composition rule](formal-pseudodifferential-composition-rule.md) gives $Pw=k^{\alpha+\beta}e^{kx}\sum_{s\geq0}k^{-s}\sum_{i+j+r=s}g_j\binom{\alpha-j}{r}w_i^{(r)}$. Each [coefficient](coefficient.md) contains finitely many terms. This describes a formal module action, not a claim that the infinite series converges at finite $k$.
