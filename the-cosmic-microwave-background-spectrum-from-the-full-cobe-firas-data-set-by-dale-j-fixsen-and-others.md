A primary analysis of the [cosmic microwave background](cosmic-microwave-background-split.md) spectrum using the [FIRAS](far-infrared-absolute-spectrophotometer.md) absolute-reference comparison, with limits on departures from a blackbody. The paper's reported [temperature](temperature-split.md) is historical; an exam's supplied rounded [temperature](temperature-split.md) should not be silently replaced by it.
