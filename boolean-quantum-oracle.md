# Boolean quantum oracle

↑ **Parent:** [Quantum theory](quantum-theory-split.md)

For a Boolean function $f$, its standard oracle acts by

$$
U_f|x\rangle|y\rangle=|x\rangle|y\mathbin\oplus f(x)\rangle.
$$
