# Compactness bound for partition regularity

↑ **Parent:** [Partition regular matrix](partition-regular-matrix.md)

If a [rational matrix](rational-matrix.md) is a [partition regular matrix](partition-regular-matrix.md), then for each fixed number of colors $k$ some finite [integer interval](integer-interval.md) $[T]$ already forces a [monochromatic](monochromatic-set.md) positive solution. Otherwise the solution-free [finite colorings](finite-coloring.md) of successive intervals form a finitely branching [tree](tree-graph-theory.md) with every level nonempty. The [König infinity lemma](konig-s-lemma.md) gives an infinite branch, contradicting partition regularity. More generally, this argument applies to any family of configurations each using finitely many [positive integers](positive-integer.md).
