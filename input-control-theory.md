# Input (control theory)

↑ **Parent:** [Plant (control theory)](plant-control-theory.md)

A [plant input](input-control-theory.md) is a [signal](signal.md) supplied to the [controlled plant](plant-control-theory.md). The chosen [plant input](input-control-theory.md) is its [control input](control-input.md); other influences can enter as [control disturbances](control-disturbance.md). This use concerns a [dynamical system](dynamical-system.md), rather than the [input](input-computer-science.md) of a computation.
