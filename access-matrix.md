# Access matrix

↑ **Parent:** [Operating system](operating-system.md)

An authorization table with subjects or protection domains as rows, objects as columns, and sets of allowed operations as entries. An [access control list](access-control-list.md) stores an object column; a capability list stores a subject row. This representation is not a numerical linear map and has no ordinary floating-point matrix inverse.
