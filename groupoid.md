# Groupoid

↑ **Parent:** [Category](category-split.md)

A groupoid is a [category](category-split.md) in which every [morphism](morphism.md) is invertible. A group is a groupoid with one object, while an [equivalence relation](equivalence-relation.md) defines a groupoid with exactly one arrow between any related pair of objects. Every [functor](functor.md) sends invertible arrows to invertible arrows.
