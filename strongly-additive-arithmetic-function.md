# Strongly additive arithmetic function

↑ **Parent:** [Additive function (number theory)](additive-function-number-theory.md)

A [strongly additive arithmetic function](strongly-additive-arithmetic-function.md) satisfies $f(p^k)=f(p)$ for every [prime](prime-number.md) $p$ and $k\ge1$, so $f(n)=\sum_{p\mid n}f(p)$. The [prime omega function](prime-omega-function.md) is an example.
