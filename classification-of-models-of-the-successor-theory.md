# Classification of models of the successor theory

↑ **Parent:** [Theory of successor](theory-of-successor.md)

In a model of the axioms for the [theory of successor](theory-of-successor.md), repeatedly taking successor and predecessor partitions the domain into components. [Injectivity](injective-function.md) and the predecessor axiom leave only the zero-generated one-sided chain and two-sided chains; the no-cycle axioms exclude finite components. Choosing one origin in each remaining component gives the displayed structure.

These axioms have [quantifier elimination](quantifier-elimination.md). To eliminate one [existential quantification](existential-quantification.md), put its quantifier-free matrix in [disjunctive normal form](disjunctive-normal-form.md). In a conjunction, an equality between a successor iterate of the bound variable and a parameter term fixes at most one candidate, by [injectivity](injective-function.md). Existence of the finitely many necessary predecessors excludes only finitely many initial zero iterates; the other equalities and inequalities then translate to conditions on the parameters by cancellation of successor iterates. If there is no such fixing equality, only finitely many candidates are excluded, so some point on the infinite zero chain works. Equalities between two different iterates of the same variable are false by absence of cycles. Thus the existential formula reduces to a quantifier-free formula.

Every closed quantifier-free sentence is decided by the distinct zero iterates, proving completeness. A one-variable formula over the empty set is a Boolean combination of finitely many equalities $x=s^n(0)$, modulo this theory. All points in added integer chains therefore realize the same nonisolated [complete type](complete-type.md) over the empty set. At an [uncountable](uncountable-set.md) [cardinal](cardinal-number-split.md) $\kappa$ a model has exactly $\kappa$ integer components, proving categoricity there. A [countable](countable-set.md) model with infinitely many integer components is an [omega-saturated model](omega-saturated-model.md) because finite parameters involve only finitely many components, leaving a fresh one for every new-component type.
