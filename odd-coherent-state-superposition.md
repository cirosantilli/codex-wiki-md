# Odd coherent-state superposition

↑ **Parent:** [Schrödinger cat state](schrodinger-cat-state.md)

The difference $N_-(|\alpha\rangle-|-\alpha\rangle)$ contains only odd [photon numbers](photon-number.md) and tends to a one-photon state as $\alpha\to0$. Exactly at zero amplitude the unnormalized difference vanishes; the normalized limiting state is obtained only by taking a limit.
