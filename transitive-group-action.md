# Transitive group action

↑ **Parent:** [Group action](group-action.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Transitive_group_action)

A [group action](group-action.md) on a set $X$ is transitive when every two points lie in the same [orbit of a group action](orbit-of-a-group-action.md), equivalently when for all $x,y\in X$ there is a group element $g$ with $gx=y$.
