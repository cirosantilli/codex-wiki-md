# Matrix congruence

↑ **Parent:** [Quadratic form](quadratic-form.md)

Two [symmetric matrices](symmetric-matrix.md) are congruent when $C=P^TAP$ for an [invertible matrix](invertible-matrix.md) $P$. This is the transformation of a [quadratic form](quadratic-form.md) under an invertible linear change of coordinates. It differs from [matrix similarity](matrix-similarity.md), which uses $P^{-1}AP$. [Completing the square](completing-the-square.md) diagonalizes a real [quadratic form](quadratic-form.md) by [matrix congruence](matrix-congruence.md).
