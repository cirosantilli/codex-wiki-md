# Continuity of parameter integrals on compact rectangles

↑ **Parent:** [Dominated convergence theorem](dominated-convergence-theorem.md)

If $f$ is jointly continuous on a compact rectangle $J\times[a,b]$, then the displayed parameter [integral](integral-split.md) is continuous on $J$. For $t_n\to t$, pointwise [continuity](continuous-function.md) gives $f(t_n,x)\to f(t,x)$. The [extreme value theorem](extreme-value-theorem.md) bounds $|f|$ by a constant $M$ on the rectangle, and $M$ is integrable on the finite [interval](interval-mathematics.md) $[a,b]$. The [dominated convergence theorem](dominated-convergence-theorem.md) gives $F(t_n)\to F(t)$.

The same conclusion holds on an unbounded parameter [interval](interval-mathematics.md) if $f$ is jointly continuous there: use a compact rectangle around each fixed parameter value. A global bound over the whole parameter range is unnecessary.
