# Dense-brush packing limit

↑ **Parent:** [Polymer brush](polymer-brush.md)

A dense uniform [polymer brush](polymer-brush.md) with $\phi\simeq1$ must have height $H\simeq Nv_0s$ by [polymer-brush volume fraction](polymer-brush-volume-fraction.md). The contour bound $H\leq Na$ therefore requires $s\leq a/v_0$. If $v_0=a^3$, the limit is $sa^2\leq1$; beyond it the putative incompressible branch demands chains longer than their [polymer contour length](polymer-contour-length.md). This is a failure of that microscopic packing model. A [Kuhn length](kuhn-length.md) does not alone determine $v_0$.
