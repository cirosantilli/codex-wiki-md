# Generator polynomial of a cyclic code

↑ **Parent:** [Cyclic code](cyclic-code.md)

The unique monic divisor $g(X)$ of $X^n-1$ generating a cyclic code is its generator polynomial. The code has dimension $n-\deg g$.
