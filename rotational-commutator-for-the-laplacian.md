# Rotational commutator for the Laplacian

↑ **Parent:** [Laplace operator](laplace-operator.md)

The infinitesimal rotation $R_{ij}=x_i\partial_j-x_j\partial_i$ commutes with the [Laplacian](laplacian.md): the extra terms $2\partial_i\partial_j$ cancel. It is tangent to every sphere, so it preserves zero Dirichlet traces on spherical shells. If $\Delta u=f$ and $f$ is radial, uniqueness applied to $R_{ij}u$ forces all these rotation [derivatives](derivative.md) to vanish, hence $u$ is radial.
