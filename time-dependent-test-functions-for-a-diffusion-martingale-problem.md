# Time-dependent test functions for a diffusion martingale problem

↑ **Parent:** [Diffusion martingale problem](diffusion-martingale-problem.md)

For an [L-diffusion](diffusion-martingale-problem.md) with bounded coefficients and $f\in C_b^{1,2}$, $M^f$ is a continuous [martingale](martingale-split.md). Freeze the time argument along a deterministic partition, apply the spatial [martingale problem](martingale-problem.md) on each interval, and pass to the limit by the [dominated convergence theorem](dominated-convergence-theorem.md). The same proof works if the absolute drift coefficients and the trace of the diffusivity have integrable time integrals along the path on every finite horizon. Local hypotheses alone give a [local martingale](local-martingale.md) conclusion.
