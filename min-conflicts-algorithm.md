# Min-conflicts algorithm

↑ **Parent:** [Hill climbing](hill-climbing.md)

A repair method for a [constraint satisfaction problem](constraint-satisfaction-problem.md): choose a currently conflicted, movable variable, and assign a permitted value minimizing its number of violated constraints with the other variables held fixed. Tie handling can permit sideways moves. For the [queens completion problem](queens-completion-problem.md), keep prescribed rows fixed, select a conflicted unfixed row, and choose a column minimizing attacks. Never interpret failure to improve as proof that no solution exists.
