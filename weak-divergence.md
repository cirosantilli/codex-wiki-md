# Weak divergence

↑ **Parent:** [Divergence](divergence.md)

The [divergence](divergence.md) defined through [weak derivatives](weak-derivative.md): pair a locally integrable [vector field](vector-field.md) $J$ with a smooth compactly supported [test function](test-function.md) $\varphi$ using the displayed integration-by-parts identity. A piecewise smooth field can have a surface contribution where its normal component jumps. Thus zero classical [divergence](divergence.md) on each side does not imply zero weak divergence across the interface.
