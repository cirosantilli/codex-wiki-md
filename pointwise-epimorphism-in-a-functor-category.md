# Pointwise epimorphism in a functor category

↑ **Parent:** [Functor category](functor-category.md)

A natural transformation in a set-valued [functor category](functor-category.md) is an [epimorphism](epimorphism.md) exactly when every component is a [surjective function](surjective-function.md). More generally, limits and colimits in a functor category are computed pointwise whenever they exist in the codomain.
