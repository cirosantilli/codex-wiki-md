# Co-immunoprecipitation

↑ **Parent:** [Biophysical measurement](biophysical-measurement.md)

[co-immunoprecipitation](co-immunoprecipitation.md) captures a [protein](protein-split.md) using an [antibody](antibody.md) and tests which other components remain associated. Reciprocal capture, input abundance and negative controls help interpret the result; coprecipitation need not imply direct contact.
