# Volume flux per unit width

↑ **Parent:** [Volumetric flow rate](volumetric-flow-rate.md)

For a flow invariant in one horizontal direction, the [volume flux](volumetric-flow-rate.md) per unit width is the [velocity](velocity.md) integrated across the flow depth. It has dimensions of area per unit time.
