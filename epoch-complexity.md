# Epoch complexity

↑ **Parent:** [Gradient descent](gradient-descent-split.md)

The number of [optimization epochs](optimization-epoch.md) needed to meet a stated accuracy criterion. Comparisons must specify the work counted by an [optimization epoch](optimization-epoch.md), the accuracy measure, and whether a random method is controlled in [expectation](expected-value-split.md) or with a stated [probability](probability.md). Counting coordinate [partial derivatives](partial-derivative.md) is useful for comparing [randomized block coordinate descent](randomized-block-coordinate-descent.md) with [gradient descent](gradient-descent-split.md), but need not match elapsed computation time.
