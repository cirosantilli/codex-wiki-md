# Prototype pattern

↑ **Parent:** [Creational pattern](creational-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Prototype_pattern)

Expose a cloning operation through a common [object interface](object-interface.md) and create new objects by asking a configured prototype for a copy. Concrete prototypes implement the copy operation; the client need not name their concrete [software classes](class-programming.md). This is useful when creation depends on runtime configuration or expensive reusable initial state. The contract must specify whether nested mutable data requires a [deep copy](deep-copy.md); copying only outer fields can preserve unintended [reference aliasing](reference-aliasing.md).
