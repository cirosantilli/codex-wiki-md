# Perfect set property

↑ **Parent:** [Descriptive set theory](descriptive-set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Perfect_set_property)

A subset of a Polish space has the perfect set property when it is countable or contains a nonempty perfect subset. Every uncountable [analytic set](analytic-set.md) contains a perfect subset and consequently has cardinality $2^{\aleph_0}$.
