# Finite-kernel quotient quasi-isometry

↑ **Parent:** [Quasi-isometry](quasi-isometry.md)

If a finitely generated group $G$ maps surjectively to $H$ with finite kernel, the quotient map is a [quasi-isometry](quasi-isometry.md). After lifting a finite generating set of $H$, the only possible extra length lies in the finite kernel and is therefore uniformly bounded.
