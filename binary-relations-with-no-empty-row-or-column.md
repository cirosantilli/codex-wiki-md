# Binary relations with no empty row or column

↑ **Parent:** [Binary relation](binary-relation.md)

Represent a [binary relation](binary-relation.md) on an $n$-element [finite set](finite-set.md) by its zero-one incidence [matrix](matrix.md). If no column may be empty, each column has $2^n-1$ choices. Apply the [inclusion-exclusion principle](inclusion-exclusion-principle.md) to empty rows: fixing $k$ empty rows leaves $(2^{n-k}-1)^n$ allowed matrices. Summing over those row sets with alternating signs yields the displayed count.
