# Gaussian random variable in a Banach space

↑ **Parent:** [Gaussian measure](gaussian-measure.md)

A random variable $X$ in a real [separable Banach space](separable-banach-space.md) $B$ is Gaussian when $\ell(X)$ has a [normal distribution](normal-distribution.md) for every [continuous linear functional](continuous-linear-functional.md) $\ell\in B^*$. It is centered when all these [expected values](expected-value.md) vanish. Its [probability law](probability-distribution.md) is a [Gaussian measure](gaussian-measure.md). Degenerate [normal distributions](normal-distribution.md) are allowed.
