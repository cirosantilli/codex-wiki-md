# Residual set

↑ **Parent:** [Baire category theorem](baire-category-theorem.md)

A set containing a countable intersection of open dense subsets. The intersection itself is also called a residual set. In a [Baire space](baire-space.md) it is dense. This topological notion of genericity does not by itself assert full measure.
