# Square-root reaction problem with nested boundary layers

↑ **Parent:** [Matched asymptotic expansion](matched-asymptotic-expansion.md)

For fixed $k>0$ and endpoint values $y(0)=0$, $y(1)=1$, the [outer solution](outer-expansion.md) is $y\sim\varepsilon^2k^2$. The left [boundary layer](boundary-layer.md) has width $\varepsilon$. At the right, a layer of width $\sqrt\varepsilon$ carries the order-one rise, and a translated layer of width $\varepsilon$ connects its inner edge to the small plateau. The [dominant balance](dominant-balance.md) depends on both amplitude and derivative scale; using the same scale at both ends loses a necessary match.
