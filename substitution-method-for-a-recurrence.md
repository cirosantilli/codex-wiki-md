# Substitution method for a recurrence

↑ **Parent:** [Recurrence relation](recurrence-relation.md)

Prove a proposed bound by [mathematical induction](mathematical-induction.md), substituting the [inductive hypothesis](induction-hypothesis.md) for smaller arguments into the [recurrence relation](recurrence-relation.md). Choose its constants so the resulting inequality implies the proposed bound at the current argument, and verify all base cases. A leading-order guess may need an additional lower-order term to make the induction close. The [entropy potential for a divide-and-conquer recurrence](entropy-potential-for-a-divide-and-conquer-recurrence.md) is an example using a linear correction to an $n\log n$ bound.
