# Propositional variable

↑ **Parent:** [Propositional logic](propositional-logic.md)

A propositional variable is an atomic symbol assigned a [truth value](truth-value.md) by a [Boolean valuation](boolean-valuation.md). A [propositional formula](propositional-formula.md) is built from these symbols by [logical connectives](logical-connective.md). The variables carry no quantifiers over individuals; their values may be chosen independently.
