# Nonadjacent dependency learning

↑ **Parent:** [Statistical language learning](statistical-language-learning.md)

[Learning](learning.md) a relation between elements separated by intervening material. In an artificial $aXb$ system, increasing variability in $X$ can help expose the stable $a$–$b$ relation. Such a relation need not be hierarchical [syntax](syntax.md).[Psychological Science 13, 431–436; three-element artificial-language strings, middle-element variability and nonadjacent dependencies](variability-and-detection-of-invariant-structure-by-rebecca-l-gomez.md)
