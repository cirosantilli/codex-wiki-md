# Gamma function

↑ **Parent:** [Complex analysis](complex-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Gamma_function)

$\Gamma(z)=\int_0^\infty t^{z-1}e^{-t}\,dt$ for $\Re z>0$, and $\Gamma(z+1)=z\Gamma(z)$ gives meromorphic continuation.
