# Configuration-space path integral

↑ **Parent:** [Path integral](path-integral.md)

A [configuration-space path integral](configuration-space-path-integral.md) integrates histories of the coordinates with weight $e^{iS}$. Fixed endpoint conditions specify a transition amplitude. For a quadratic kinetic energy it follows by Gaussian momentum integration from the [phase-space path integral](phase-space-path-integral.md). Time-slicing fixes the normalization, and a regulator gives meaning to the otherwise formal [functional measure](functional-measure.md).
