# Core (game theory)

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Core_(game_theory))

The [core](core-game-theory.md) consists of efficient payoff vectors for which each [coalition](coalition-game-theory.md) receives at least its own attainable value. Thus no [coalition](coalition-game-theory.md) can improve every member's payoff by leaving. It is a [convex set](convex-set.md) defined by linear constraints, but can be empty. Every [convex cooperative game](convex-cooperative-game.md) has a nonempty [core](core-game-theory.md) because each [marginal contribution vector](marginal-contribution-vector.md) belongs to it.
