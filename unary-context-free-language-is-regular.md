# Unary context-free language is regular

↑ **Parent:** [Context-free language](context-free-language.md)

Every [context-free language](context-free-language.md) over a one-symbol alphabet is a [regular language](regular-language.md). Equivalently, the set of word lengths of a unary context-free language is ultimately periodic. This follows, for example, from the one-dimensional case of Parikh's theorem.
