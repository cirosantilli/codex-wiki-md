# Envelope crossover in core accretion

↑ **Parent:** [Runaway gas accretion](runaway-gas-accretion.md)

The epoch when the gaseous envelope [mass](mass.md) becomes comparable with the solid core [mass](mass.md). Envelope self-[gravity](gravity.md) then changes structure and can accelerate [gas](gas.md) capture through cooling and contraction. Crossover is a useful stage in classical models, rather than a universal core [mass](mass.md) independent of [opacity](opacity.md) and accretion history.
