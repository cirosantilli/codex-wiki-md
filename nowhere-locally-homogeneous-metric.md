# Nowhere locally homogeneous metric

↑ **Parent:** [Riemannian metric](riemannian-metric.md)

A smooth [Riemannian metric](riemannian-metric.md) with no nonidentity [local isometry](local-isometry.md) between open subsets. Equivalently distinct nonempty open subsets never have isometric induced metrics. This strong local rigidity is also called bumpy in some spectral-geometry treatments; it is distinct from the closed-geodesic nondegeneracy convention for bumpy metrics.
