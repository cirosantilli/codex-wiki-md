# Indegree

↑ **Parent:** [Combinatorics](combinatorics-split.md)

The [indegree](indegree.md) $d^-(v)$ of a [vertex](vertex-graph-theory.md) $v$ is the number of [directed edges](directed-edge.md) entering it, counting repeated [directed edges](directed-edge.md) separately if permitted. In the toy [Directed acyclic graph](directed-acyclic-graph.md), the initial [indegrees](indegree.md) of $A,B,C,D,E$ are $0,0,1,2,2$. In [Kahn's algorithm](kahn-s-algorithm.md), these counts are updated to describe only the remaining [directed graph](directed-graph.md), so [indegree](indegree.md) zero means that no unfinished predecessor remains. [Sedgewick and Wayne, Digraph: definition of indegree](https://raw.githubusercontent.com/kevin-wayne/algs4/master/src/main/java/edu/princeton/cs/algs4/Digraph.java)
