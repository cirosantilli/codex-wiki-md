# Null-gradient affine-geodesic identity

↑ **Parent:** [Null geodesic congruence](null-geodesic-congruence.md)

If $k_a=\nabla_aS$ is a null gradient, symmetry of the Hessian gives $k^a\nabla_ak_b=k^a\nabla_bk_a=\tfrac12\nabla_b(k^2)=0$. Its integral curves are therefore affinely parametrized [null geodesics](null-geodesic.md), rather than merely null curves with a nonaffinity term.
