# Beads task

↑ **Parent:** [Jumping to conclusions](jumping-to-conclusions.md)

An information-sampling task in which observations from a source are used to infer which source generated them. Decisions about when to stop sampling can investigate reasoning tendencies, with comprehension and task incentives affecting interpretation.
