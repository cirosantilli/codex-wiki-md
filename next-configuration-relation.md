# Next-configuration relation

↑ **Parent:** [Instantaneous description of a Turing machine](instantaneous-description-of-a-turing-machine.md)

For a [Turing machine](turing-machine.md), the one-step [binary relation](binary-relation.md) between [Turing machine configurations](instantaneous-description-of-a-turing-machine.md) specified by its [Turing machine instructions](instruction-of-a-turing-machine.md). Its [reflexive transitive closure](reflexive-transitive-closure.md) $\vdash_M^*$ describes any finite number of computation steps, including zero.
