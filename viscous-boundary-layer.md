# Viscous boundary layer

↑ **Parent:** [Viscous fluid flow](viscous-fluid-flow-split.md)

A viscous boundary layer is a [boundary layer](boundary-layer.md) next to a surface in which viscosity remains important even when the outer flow has a large [Reynolds number](reynolds-number.md). It reconciles the outer inviscid velocity with the [no-slip boundary condition](no-slip-boundary-condition.md).
