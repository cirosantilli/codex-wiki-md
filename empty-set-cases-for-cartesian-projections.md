# Empty-set cases for Cartesian projections

↑ **Parent:** [Projection map](projection-map.md)

For a coordinate [projection map](projection-map.md) onto $X_i$, write $X_j$ for the other factor. The map is [surjective](surjective-function.md) exactly when $X_i$ is empty or $X_j$ is nonempty. It is [injective](injective-function.md) exactly when $X_i$ is empty or $X_j$ has at most one element. In particular, a [surjection](surjective-function.md) onto an empty [Cartesian product](cartesian-product.md) need not induce a [surjection](surjective-function.md) onto a nonempty factor.
