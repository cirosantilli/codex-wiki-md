# Cache miss rate

↑ **Parent:** [Cache miss](cache-miss.md)

The fraction of $R>0$ [memory references](memory-reference.md) yielding [cache misses](cache-miss.md), with $M$ their count: $m=M/R$. When each reference is classified as exactly one [cache hit](cache-hit.md) or [cache miss](cache-miss.md), $h+m=1$; the two-slot [fully associative cache](fully-associative-cache.md) example has $m=7/12$.
