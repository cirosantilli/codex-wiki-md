# String suffix

↑ **Parent:** [String](string.md)

A [string suffix](string-suffix.md) consists of all characters from some position to the end of a [string](string.md). For example, TAC has suffixes TAC, AC, C and the empty [string](string.md). Sorting these in [lexicographic order](lexicographic-order.md) groups all suffixes beginning with a given query into one interval.
