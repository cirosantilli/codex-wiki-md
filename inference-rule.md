# Inference rule

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)

An [inference rule](inference-rule.md) licenses a conclusion from specified premises, possibly with side conditions. A [derived inference rule](derived-inference-rule.md) is justified by a [logical derivation](logical-derivation.md) using the primitive [inference rules](inference-rule.md); using it subsequently abbreviates that [logical derivation](logical-derivation.md).
