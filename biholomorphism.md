# Biholomorphism

↑ **Parent:** [Holomorphic map](holomorphic-map.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Biholomorphism)

A biholomorphism is a bijective [holomorphic map](holomorphic-map.md) whose inverse is holomorphic. A degree-one nonconstant holomorphic map between compact connected Riemann surfaces is a biholomorphism.
