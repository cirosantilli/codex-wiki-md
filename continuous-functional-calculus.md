# Continuous functional calculus

↑ **Parent:** [C-star algebra](c-star-algebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Continuous_functional_calculus)

For a [Normal element of a C-star algebra](normal-element-of-a-c-star-algebra.md) $a$ in a unital [C-star algebra](c-star-algebra.md), the [Commutative Gelfand--Naimark theorem](commutative-gelfand-naimark-theorem.md) identifies $C(\sigma(a))$ isometrically with the closed unital algebra generated by $a$ and $a^*$. The coordinate function maps to $a$, defining $f(a)$ for every continuous $f$ on the [spectrum of an element](spectrum-of-an-element.md).
