# Angular momentum of a radial function times a linear polynomial

↑ **Parent:** [Orbital angular momentum](orbital-angular-momentum.md)

Orbital [angular momentum operators](angular-momentum-operator.md) annihilate a radial multiplier $H(r)$. Their squared sum sends every degree-one homogeneous [polynomial](polynomial-split.md) to $2\hbar^2$ times that polynomial, so a nonzero normalizable state $H(r)(\mathbf a\cdot\mathbf x)$ has angular momentum quantum number $l=1$. With real $H$ and real coefficients, its third-component [expected value](expected-value.md) is zero by angular symmetry, though it need not be an eigenstate of that component.
