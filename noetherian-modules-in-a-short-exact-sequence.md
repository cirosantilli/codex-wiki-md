# Noetherian modules in a short exact sequence

↑ **Parent:** [Noetherian module](noetherian-module.md)

For a [short exact sequence](short-exact-sequence.md) $0\to N\to M\to M/N\to0$, $M$ is a [Noetherian module](noetherian-module.md) exactly when both the other terms are [Noetherian modules](noetherian-module.md). For the extension direction, an ascending chain $M_i$ has eventually constant intersections $M_i\cap N$ and images $(M_i+N)/N$. Equality of both forces equality of consecutive $M_i$: subtract an element with the same image and then use the common intersection.
