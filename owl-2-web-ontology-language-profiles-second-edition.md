# OWL 2 Web Ontology Language Profiles (Second Edition)

↑ **Parent:** [Computer science bibliography](computer-science-bibliography-split.md)

[https://www.w3.org/TR/2012/REC-owl2-profiles-20121211/](https://www.w3.org/TR/2012/REC-owl2-profiles-20121211/)

The profile grammar distinguishes positions where existential and universal restrictions are allowed. Section 4 supplies the [RL description logic](rl-description-logic.md) restrictions and Section 5 gives complexity tables. The EL profile here includes bottom and disjointness; its satisfiability result should not be confused with the trivial satisfiability of [EL](el.md) without bottom.
