# Base-station magnetometer

↑ **Parent:** [Magnetic survey](magnetic-survey.md)

A stationary [magnetometer](magnetometer.md) recording time variation of the background [magnetic field](magnetic-field-split.md) while a moving instrument measures spatial variation. Subtracting the synchronized base changes reduces temporal contamination.
