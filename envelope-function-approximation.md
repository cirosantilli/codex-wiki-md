# Envelope function approximation

↑ **Parent:** [Quantum well](quantum-well.md)

A [semiconductor](semiconductor-split.md) state is approximated by a slowly varying envelope multiplying a cell-periodic Bloch function from a selected band. [effective masses](band-effective-mass.md) govern the envelope equation. Interband optical [matrix elements](matrix-element.md) then factor approximately into a cell-scale [momentum](momentum-split.md) [matrix element](matrix-element.md) and an envelope overlap; abrupt interfaces, band mixing and nonparabolicity limit the separation.
