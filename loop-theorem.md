# Loop theorem

↑ **Parent:** [3-manifold](3-manifold.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Loop_theorem)

If a boundary surface inclusion has noninjective [fundamental group](fundamental-group.md) map, there is a [compression disk](compression-disk.md) whose boundary represents a nontrivial element of that kernel. More generally the boundary can be required to avoid a prescribed normal subgroup if a singular disk with that property exists.
