# Lambda abstraction

↑ **Parent:** [Lambda term](lambda-term.md)

A lambda abstraction $\lambda x.t$ binds the variable $x$ in the [lambda term](lambda-term.md) $t$. In the [simply typed lambda calculus](simply-typed-lambda-calculus.md), if $t:B$ under $x:A$, the abstraction has type $A\to B$; this is the [implication introduction rule](implication-introduction-rule.md) under the [Curry-Howard correspondence](curry-howard-correspondence.md).
