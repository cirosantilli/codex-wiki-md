# Best-bound search

↑ **Parent:** [Branch and bound](branch-and-bound.md)

For minimization, [best-bound search](best-bound-search.md) expands the active [branch and bound](branch-and-bound.md) node with smallest [lower bound](lower-bound-in-a-partially-ordered-set.md). A feasible completed assignment supplies an incumbent upper bound. Nodes with lower bound at least that incumbent can be discarded when only one optimum is needed. Search ends with an optimality certificate when no active node can improve the incumbent.
