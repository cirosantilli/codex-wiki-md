# Equivalence class representative

↑ **Parent:** [Equivalence class](equivalence-class.md)

An equivalence class representative is any [set element](element-of-a-set.md) belonging to that [equivalence class](equivalence-class.md). In the finite modulo-three example, either $0$, $3$ or $6$ represents $\{0,3,6\}$. Changing the [equivalence class representative](equivalence-class-representative.md) changes its name but preserves the [equivalence class](equivalence-class.md) itself. Choosing $0,1,2$ gives one [representative of an equivalence class](equivalence-class-representative.md) from each class; the [quotient set](quotient-set.md) consists of the three whole [sets](set-split.md).
