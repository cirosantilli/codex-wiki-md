# Smooth cutoff function

↑ **Parent:** [Smooth function](smooth-function.md)

A smooth cutoff function is a smooth function used to localize an argument, typically equal to one on one region and zero outside a slightly larger region. Such functions can be built from [bump functions](bump-function.md) and smooth [partitions of unity](partition-of-unity.md).
