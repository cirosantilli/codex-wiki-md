# Matrix exponential respects similarity

↑ **Parent:** [Matrix exponential](matrix-exponential.md)

For an invertible [matrix](matrix.md) $P$, induction gives $(PAP^{-1})^k=PA^kP^{-1}$, including $k=0$. The [power series](power-series.md) for the [matrix exponential](matrix-exponential.md) is absolutely convergent in every [matrix norm](matrix-norm.md), so multiplication by the fixed matrices $P,P^{-1}$ can be taken through the sum. This proves the displayed identity without any [diagonalizability](diagonalizable-matrix.md) assumption. In particular, if $A=PDP^{-1}$ with $D$ diagonal, then $e^A=P\operatorname{diag}(e^{D_{11}},\ldots,e^{D_{nn}})P^{-1}$.
