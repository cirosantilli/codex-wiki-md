# Reentrant event handler

↑ **Parent:** [Event-driven programming](event-driven-programming.md)

A handler invoked again before a previous invocation has completed, for example through a synchronous notification caused by its own display update. A guarded refresh can suppress unintended recursive commits. Such a flag does not replace the need for a coherent state [invariant](invariant-mathematics.md) and an explicit rule deciding which edit is authoritative.
