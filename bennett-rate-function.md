# Bennett rate function

↑ **Parent:** [Bennett inequality](bennett-inequality.md)

The [Bennett rate function](bennett-rate-function.md) has [Taylor expansion](taylor-expansion.md) $\phi(u)=u^2/2-u^3/6+O(u^4)$ near zero. It is the optimized exponent in the [Chernoff bound](chernoff-bound.md) based on the [moment-generating function](moment-generating-function.md) estimate for the [Bennett inequality](bennett-inequality.md).
