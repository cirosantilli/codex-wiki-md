# Infinite-model property of a serial strict partial order

↑ **Parent:** [Strict partial order](strict-partial-order.md)

A [strict partial order](strict-partial-order.md) that is a [serial relation](serial-relation.md) has no finite nonempty [first-order model](model-of-a-first-order-theory.md). If the domain had $N$ elements, seriality would produce a chain of $N+1$ successive elements. The [pigeonhole principle](pigeonhole-principle.md) supplies a repeated element, and transitivity along the resulting cycle contradicts irreflexivity. An infinite example is the usual strict order on the [natural numbers](natural-number.md): every element has its successor. The nonempty-domain convention is essential; the displayed universal conditions hold vacuously on an empty domain if such domains are permitted.
