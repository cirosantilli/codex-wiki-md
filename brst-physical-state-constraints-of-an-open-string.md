# BRST physical-state constraints of an open string

↑ **Parent:** [BRST operator](brst-operator.md)

For a matter state tensored with the [ghost oscillator vacuum](ghost-oscillator-vacuum.md), the [BRST charge](brst-charge.md) produces the independent ghost states $c_0|0\rangle$ and $c_{-m}|0\rangle$ with coefficients $(L_0-1)|\Psi\rangle$ and $L_m|\Psi\rangle$. Thus BRST closure is equivalent to $(L_0-1)|\Psi\rangle=0$ and $L_{m>0}|\Psi\rangle=0$ in this sector. It reproduces [old covariant string quantization](old-covariant-string-quantization.md) and the [open bosonic string mass spectrum](open-bosonic-string-mass-spectrum.md).
