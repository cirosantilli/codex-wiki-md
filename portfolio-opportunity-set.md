# Portfolio opportunity set

↑ **Parent:** [Modern portfolio theory](modern-portfolio-theory.md)

The set of attainable return [standard deviations](standard-deviation.md) and [expected returns](expected-return.md) for budget-feasible risky [investment portfolios](investment-portfolio.md). Negative weights are allowed when [short selling](short-finance.md) is permitted. With positive definite [covariance matrix](covariance-matrix.md) and nonconstant means, the minimum-risk boundary is a hyperbola in standard-deviation/mean coordinates; its upper branch is the [mean-variance efficient frontier](efficient-frontier.md). Adding a risk-free asset changes the budget constraint on risky holdings and produces a different attainable set.
