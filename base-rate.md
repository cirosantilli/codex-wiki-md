# Base rate

↑ **Parent:** [Prior probability](prior-probability.md)

A class prevalence applicable before considering the current case-specific evidence. Under random sampling from the relevant reference population, it sets the prior class [probability](probability.md) used in [Bayes' theorem](bayes-theorem.md).
