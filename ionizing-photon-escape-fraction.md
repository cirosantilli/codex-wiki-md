# Ionizing photon escape fraction

↑ **Parent:** [Hydrogen-ionizing photon production rate](hydrogen-ionizing-photon-production-rate.md)

The ionizing photon escape fraction is the fraction of photons capable of [photoionization](photoionization.md) that leave their source environment. Only these escaping photons contribute to ionizing distant [intergalactic medium](intergalactic-medium.md). Its value can depend on frequency, source geometry, and time.
