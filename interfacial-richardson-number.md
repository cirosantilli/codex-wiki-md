# Interfacial Richardson number

↑ **Parent:** [Richardson number](richardson-number.md)

A local ratio of stabilizing buoyancy to shear across an interface of thickness $\delta$, using [reduced gravity](reduced-gravity-split.md) jump $g'$ and characteristic velocity $u$. The dimensionless value is $\mathrm{Ri}_i=g'\delta/u^2$. It is distinct from a whole-layer bulk [Richardson number](richardson-number.md) based on the total mixed depth. Local [entrainment](fluid-entrainment.md) laws use this ratio when the transition thickness and velocity characterize the turbulence-producing region.
