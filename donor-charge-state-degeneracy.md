# Donor charge-state degeneracy

↑ **Parent:** [Donor impurity](donor-impurity.md)

Let an isolated [donor impurity](donor-impurity.md) admit an empty ionized state with statistical weight $g_0$ and a singly occupied neutral state with statistical weight $g_1$, with double occupation excluded. Its [grand canonical ensemble](grand-canonical-ensemble.md) weights are $g_0$ and $g_1e^{-\beta(\epsilon_D-\mu)}$, so $r=g_1/g_0$ multiplies the occupied-to-empty ratio. A nondegenerate empty state and two allowed [electron spin](electron-spin.md) orientations give $r=2$; a simplified single-state occupation model uses $r=1$. With negligible [electron holes](electron-hole.md) and uncompensated [donor impurities](donor-impurity.md), [charge neutrality](charge-neutrality.md) and nondegenerate conduction occupation imply $n^2/(N_D-n)=(N_c/r)e^{-E_i/(k_BT)}$, where $E_i$ is the donor binding [energy](energy-split.md) and $N_c$ the [effective density of states](effective-density-of-states.md).
