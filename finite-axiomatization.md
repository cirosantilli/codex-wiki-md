# Finite axiomatization

↑ **Parent:** [Finite axiomatizability](finite-axiomatizability.md)

A [finite axiomatization](finite-axiomatization.md) of a class of structures is a finite set of [first-order sentences](first-order-sentence.md) whose [first-order models](model-of-a-first-order-theory.md) are exactly that class. The existence of such a set is [finite axiomatizability](finite-axiomatizability.md).
