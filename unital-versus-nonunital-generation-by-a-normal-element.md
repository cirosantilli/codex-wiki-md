# Unital versus nonunital generation by a normal element

↑ **Parent:** [Normal element of a C-star algebra](normal-element-of-a-c-star-algebra.md)

The unital [continuous functional calculus](continuous-functional-calculus.md) has image $C^*(1,x)$, the [norm](norm.md) closure of star polynomials including constants. The smallest closed star subalgebra $C^*(x)$ need not contain the ambient identity: for $x=0$ it is zero. In a nonunital algebra, apply the unital calculus in the [C-star unitization](unitization-of-a-c-star-algebra.md) and retain functions vanishing at zero to recover $C^*(x)$ inside the original algebra.
