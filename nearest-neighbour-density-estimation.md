# Nearest neighbour density estimation

↑ **Parent:** [Density estimation](density-estimation.md)

In one dimension, a [nearest neighbour density estimator](nearest-neighbour-density-estimation.md) is $\widehat f_{(k)}(x)=k/[2(n+1)\rho_{(k)}(x)]$. It uses the [nearest neighbour distance](nearest-neighbour-distance.md) to select an interval containing a fixed number of observations. The factor $n+1$ corresponds to the exact [expected value](expected-value.md) of the associated [uniform order statistic](uniform-order-statistic.md).
