# Operating system

↑ **Parent:** [Computer science](computer-science-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Operating_system)

An [operating system](operating-system-split.md) manages the resources that let programs run and cooperate. [Operating-system processes](process-computing.md) organize running work, [virtual memory](virtual-memory-split.md) supplies protected [address spaces](address-space.md), and a [file system](file-system-split.md) supplies named [files](computer-file.md) that can outlive the [operating-system process](process-computing.md) that created them. The [operating-system kernel](kernel-operating-system.md) enforces the core mechanisms; [system calls](system-call.md) let programs request its services. Separating these responsibilities makes it possible to share a [file](computer-file.md) while keeping the participating [operating-system processes](process-computing.md)' [address spaces](address-space.md) isolated. [Arpaci-Dusseau and Arpaci-Dusseau, OSTEP chapter 39, introduction: processes, address spaces and persistent storage](https://pages.cs.wisc.edu/~remzi/OSTEP/file-intro.pdf)

A concrete example makes the separation useful: two [operating-system processes](process-computing.md) can each use [file descriptor](file-descriptor.md) `3`, yet refer to different [files](computer-file.md); two different names can instead refer to the same [file](computer-file.md) through [hard links](hard-link.md). Neither a name nor a small [integer](integer-split.md) identifies an object without its context. [Virtual memory](virtual-memory-split.md) has a related distinction: the same [virtual address](virtual-address.md) in different [address spaces](address-space.md) can designate different [physical addresses](physical-address.md).

[Unix](unix.md) provides an influential example of this design. In their July 1974 paper, Dennis M. Ritchie and Ken Thompson date its earliest version to approximately 1969–70 and describe [operating-system processes](process-computing.md), a hierarchical [file system](file-system-split.md), and [inodes](inode.md) separating [directory entries](directory-entry.md) from [file metadata](file-metadata.md). This is a documented historical example, rather than a claim that every [operating system](operating-system-split.md) uses [Unix](unix.md) conventions. [Ritchie and Thompson, The UNIX Time-Sharing System, Communications of the ACM 17(7), 1974, sections 1, 3 and 4](https://www.cs.cmu.edu/~15712/papers/ritchie74.pdf)
