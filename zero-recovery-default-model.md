# Zero-recovery default model

↑ **Parent:** [Defaultable stock](defaultable-stock.md)

For an independent [exponential distribution](exponential-distribution.md) [default time](default-time.md) of rate $\lambda$ and a continuous nonnegative [martingale](martingale-split.md) $S$, this process is a [martingale](martingale-split.md). The compensating pre-default factor $e^{\lambda t}$ balances the survival probability $e^{-\lambda t}$. The strict survival inequality gives a [càdlàg](cadlag.md) price process.
