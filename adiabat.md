# Adiabat

↑ **Parent:** [Adiabatic process](adiabatic-process.md)

An [adiabat](adiabat.md) is a curve representing a quasistatic adiabatic change. In a reversible description it is also a curve of constant [entropy](entropy-split.md). For an [ideal gas](ideal-gas-split.md) with constant heat-capacity ratio $\gamma$, it obeys $pV^\gamma=\mathrm{constant}$. A general irreversible [adiabatic process](adiabatic-process.md) need not follow this equilibrium-state curve and can produce [entropy](entropy-split.md).
