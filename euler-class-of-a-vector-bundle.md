# Euler class of a vector bundle

↑ **Parent:** [Thom class](thom-class.md)

The Euler class of an oriented rank-$d$ vector bundle is the pullback $e(E)=s^*u_E\in H^d(B;R)$ of its [Thom class](thom-class.md) along the zero section. Over $\mathbb F_2$ it equals the top Stiefel-Whitney class.
