# Hypergraph colouring

↑ **Parent:** [Hypergraph](hypergraph-split.md)

A proper [hypergraph colouring](hypergraph-colouring.md) assigns colours to the [vertices of a hypergraph](vertex-of-a-hypergraph.md) so that no [hypergraph edge](edge-of-a-hypergraph.md) is [monochromatic](monochromatic-set.md). Each [colour class](colour-class.md) is a [hypergraph independent set](hypergraph-independent-set.md). This is often called weak colouring, to distinguish it from requiring every pair of vertices in each [edge](edge-of-a-graph.md) to have different colours.
