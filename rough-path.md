# Rough path

↑ **Parent:** [Analysis](analysis-split.md)

A rough path augments a path with compatible higher-order iterated-integral data. The extra data records effects, such as signed area, that are not continuously determined by the first-level path in the uniform topology. A [rough differential equation](rough-differential-equation.md) uses this enhancement to recover a continuous solution map for irregular drivers.
