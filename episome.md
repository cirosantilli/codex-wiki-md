# Episome

↑ **Parent:** [Genome](genome.md)

A genetic element maintained separately from host [chromosomes](chromosome.md) in an episomal state. Copying, [nuclear retention](nuclear-retention.md) and partition between daughter [biological cells](biological-cell-split.md) are separate requirements for stable maintenance.
