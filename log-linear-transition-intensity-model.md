# Log-linear transition intensity model

↑ **Parent:** [Transition intensity](transition-intensity.md)

A positive [transition intensity](transition-intensity.md) can be modeled as $q_{rs}(t\mid z)=\exp(\theta_0+\theta^Tz(t))$. A unit increase in a fixed [covariate](covariate.md) multiplies the intensity by $e^{\theta_j}$. A changing [covariate](covariate.md) generally gives a time-dependent [generator matrix](generator-matrix.md).
