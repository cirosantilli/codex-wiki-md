# Even-weight subcode of a binary linear code

↑ **Parent:** [Binary linear code](binary-linear-code.md)

For a [binary linear code](binary-linear-code.md) $C$, the [linear functional](linear-functional.md) $\sigma(x)=\sum_jx_j$ records [Hamming weight](hamming-weight.md) modulo two. Its [kernel of a linear map](kernel-of-a-linear-map.md) is the even-weight subcode. If $\sigma|_C$ vanishes, this is all of $C$; otherwise [rank-nullity theorem](rank-nullity-theorem.md) gives [dimension](dimension-vector-space.md) $\dim C-1$. This also proves closure under addition without treating ordinary integer weight as a linear function.
