# Hippocampal episodic memory model

↑ **Parent:** [Hippocampus](hippocampus.md)

A circuit-level hypothesis combining sparse input coding and [pattern separation](pattern-separation.md) in the [dentate gyrus](dentate-gyrus.md), recurrent [autoassociation](autoassociative-memory.md) in [hippocampal CA3](hippocampal-ca3.md), and learned [pattern association](heteroassociative-memory.md) through [hippocampal](hippocampus.md) outputs. It explains a route from an incomplete cue to reinstated event content. Context, event order, interference and changing cortical dependence remain requirements beyond a simple fixed-point memory.
