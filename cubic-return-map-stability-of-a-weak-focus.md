# Cubic return-map stability of a weak focus

↑ **Parent:** [Poincaré map](poincare-map.md)

If a planar equilibrium with purely imaginary linear [eigenvalues](eigenvalue.md) has radial return map $r\mapsto r+\kappa r^3+O(r^4)$, then $\kappa<0$ gives nonlinear attraction and $\kappa>0$ gives repulsion. Vanishing linear decay therefore does not imply a centre.
