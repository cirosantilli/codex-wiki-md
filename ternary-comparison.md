# Ternary comparison

↑ **Parent:** [Comparison model](comparison-model.md)

A single comparison returning one of three outcomes: less than, equal to, or greater than. A [comparison model](comparison-model.md) may count this as one operation even when a programming language expresses the outcomes using multiple Boolean tests. [Binary search](binary-search.md) on ordered keys uses one such comparison per inspected position.
