# Timing calibration for acoustic speed measurements

↑ **Parent:** [Acoustic time-of-flight speed measurement](acoustic-time-of-flight-speed-measurement.md)

[Timing calibration for acoustic speed measurements](timing-calibration-for-acoustic-speed-measurements.md) separates travel delay from the offset $\tau_0$ between acquisition channels and checks the clock defining the [sampling rate](sampling-rate.md). A constant offset changes the intercept of a delay-versus-distance [linear regression](linear-regression-split.md); a clock-scale error changes the inferred [speed of sound](speed-of-sound.md) itself.
