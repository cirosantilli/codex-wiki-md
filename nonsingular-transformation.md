# Nonsingular transformation

↑ **Parent:** [Ergodic theory](ergodic-theory.md)

A measurable transformation $T:X\to X$ is nonsingular with respect to $\mu$ when $\mu(T^{-1}N)=0$ for every $\mu$-null set $N$, equivalently when the [pushforward measure](pushforward-measure.md) $T_*\mu$ is [absolutely continuous](absolute-continuity-of-measures.md) with respect to $\mu$.
