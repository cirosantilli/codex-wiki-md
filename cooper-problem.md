# Cooper problem

↑ **Parent:** [Cooper pair](cooper-pair.md)

Two added [electrons](electron.md) move above a frozen filled [Fermi sea](fermi-sea.md) and attract within a thin [energy](energy-split.md) shell. The Pauli-blocked continuum has a logarithmic pair susceptibility, so an arbitrarily weak net attractive constant interaction produces a state below the two-particle threshold at zero [temperature](temperature-split.md). This two-added-particle result is not by itself a full many-electron superconducting state.
