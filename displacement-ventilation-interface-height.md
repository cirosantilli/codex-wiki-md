# Displacement-ventilation interface height

↑ **Parent:** [Displacement ventilation](displacement-ventilation.md)

At steady state, the displacement-ventilation interface lies where the total plume [volume flux](volumetric-flow-rate.md) equals the imposed ventilation flux. For one triangular-profile [wall line plume](wall-line-plume.md) with kinematic [buoyancy flux](buoyancy-flux.md) $B_0$, entrainment coefficient $\alpha$, and ventilation flux $A$ per unit span,

$$
h=\left(\frac{2}{3\alpha}\right)^{2/3}\frac{A}{B_0^{1/3}}.
$$
