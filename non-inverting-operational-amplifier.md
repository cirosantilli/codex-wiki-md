# Non-inverting operational amplifier

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

An operational-amplifier configuration applying the signal to the non-inverting input and returning a fraction of output to the inverting input. In stable unsaturated ideal operation, zero input current and equal input voltages give the displayed [voltage gain](voltage-gain.md). The feedback [resistor](resistor.md) $R_f$ connects output to the inverting input and $R_g$ connects that input to the reference [wavefunction node](wavefunction-node.md).
