# Disjunction property of intuitionistic propositional logic

↑ **Parent:** [Intuitionistic propositional logic](intuitionistic-propositional-logic.md)

The disjunction property says that if $\vdash_{\mathrm{IPC}}A\vee B$, then $\vdash_{\mathrm{IPC}}A$ or $\vdash_{\mathrm{IPC}}B$.

This is the disjunction part of [disjunction and existence properties](disjunction-and-existence-properties.md), specialized to [Intuitionistic propositional logic](intuitionistic-propositional-logic.md).
