# Option rho

↑ **Parent:** [Black-Scholes parameter sensitivities](black-scholes-parameter-sensitivities.md)

The derivative of a claim price with respect to the [interest rate](interest-rate.md), holding the payoff and other model parameters fixed. For a dividend-free [Black-Scholes model](black-scholes-model.md) with remaining time $\tau$, it is $\tau(xp_x-p)$, so its sign is opposite the bank-account value in the [replicating strategy](replicating-strategy.md).
