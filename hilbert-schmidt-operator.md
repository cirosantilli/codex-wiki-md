# Hilbert-Schmidt operator

↑ **Parent:** [Compact operator](compact-operator-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hilbert–Schmidt_operator)

A bounded [linear operator](linear-operator.md) on a [Hilbert space](hilbert-space-split.md) is Hilbert-Schmidt when $\sum_n\|Te_n\|^2<\infty$ for one, equivalently every, [orthonormal basis](orthonormal-basis.md). Every Hilbert-Schmidt operator is a [compact operator](compact-operator-split.md).
