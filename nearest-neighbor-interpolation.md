# Nearest-neighbor interpolation

↑ **Parent:** [Image processing](image-processing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nearest-neighbor_interpolation)

[Nearest-neighbor interpolation](nearest-neighbor-interpolation.md) assigns each requested location the value of its nearest available sample, with a specified convention for ties. In [lossy block averaging](lossy-block-averaging.md), samples are placed at block centres and each is copied into its four original [pixel](pixel.md) positions. This enlarges the [raster image](raster-graphics.md) without recovering discarded detail.
