# Normal order of an arithmetic function

↑ **Parent:** [Analytic number theory](analytic-number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Normal_order_of_an_arithmetic_function)

A positive function $g(n)$ is a normal order of an [arithmetic function](arithmetic-function.md) $f(n)$ when, for every $\epsilon>0$, all but $o(x)$ integers $n\leq x$ satisfy $|f(n)-g(n)|<\epsilon g(n)$.
