# Clustering coefficient

↑ **Parent:** [Graph theory](graph-theory-split.md)

For a [vertex](vertex-graph-theory.md) with $k_i\geq2$ neighbours in a [simple graph](simple-graph.md), its local [clustering coefficient](clustering-coefficient.md) is $C_i=e_i/\binom{k_i}{2}$, where $e_i$ counts [edges](edge-of-a-graph.md) among those neighbours. It is the fraction of possible neighbour-neighbour edges that are present. A common network summary averages these local coefficients, setting them to zero for degrees below two; this differs from weighting by the number of neighbour pairs.
