# Quantile endpoint at probability one

↑ **Parent:** [Quantile function](quantile-function.md)

The [quantile function](quantile-function.md) is finite at every probability strictly between zero and one, but need not be finite at one. For any unbounded-above [normal distribution](normal-distribution.md), $F(x)<1$ for every real $x$, so its generalized inverse at one is $+\infty$. [Inverse transform sampling](inverse-transform-sampling.md) still produces a real random variable almost surely because a continuous [uniform distribution](continuous-uniform-distribution.md) puts zero mass at that endpoint. A real-valued implementation may discard endpoint draws or assign an arbitrary finite value there without changing the sampled law.
