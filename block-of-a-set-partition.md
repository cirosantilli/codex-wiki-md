# Block of a set partition

↑ **Parent:** [Set partition](set-partition.md)

A [block of a set partition](block-of-a-set-partition.md) is one of its nonempty [subsets](subset.md). Distinct [blocks of a set partition](block-of-a-set-partition.md) have empty [intersection](set-intersection.md), and their [union](set-union.md) is the original [set](set-split.md). For $\pi=\{\{1,3\},\{2\}\}$, the [blocks of a set partition](block-of-a-set-partition.md) are $\{1,3\}$ and the [singleton set](singleton-mathematics.md) $\{2\}$. The indices in a written list of [blocks of a set partition](block-of-a-set-partition.md) do not label or order the [set partition](set-partition.md).
