# Matrix unit

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Matrix_unit)

The matrix unit $E_{ij}$ has entry one in row $i$, column $j$, and zero in every other position. The matrix units form the standard [basis](basis.md) of the [vector space](vector-space-split.md) of matrices of a fixed size.
