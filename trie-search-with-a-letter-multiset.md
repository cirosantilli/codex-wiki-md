# Trie search with a letter multiset

↑ **Parent:** [Trie](trie.md)

Use [backtracking](backtracking.md) through a dictionary [trie](trie.md), decrementing and restoring the available count for each traversed letter. Visit each letter-labelled child once when its count is positive, rather than choosing between indistinguishable occurrences. Every reachable complete word is then produced once, including words using only a subcollection of the original letter [multiset](multiset.md).
