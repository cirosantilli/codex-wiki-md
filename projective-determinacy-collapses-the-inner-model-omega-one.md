# Projective determinacy collapses the inner-model omega-one

↑ **Parent:** [Projectively well-ordered inner model](projectively-well-ordered-inner-model.md)

If $M$ is projectively well-ordered and [projective determinacy](projective-determinacy.md) holds, then $\omega_1^M$ is countable in the ambient universe. Otherwise, selecting with the projective well-order the least $M$-code for each countable ordinal produces an uncountable projective set of unique well-order codes. It has no perfect subset by the [boundedness theorem for well-order codes](boundedness-theorem-for-well-order-codes.md), contradicting the [perfect set property](perfect-set-property.md) implied by projective determinacy.
