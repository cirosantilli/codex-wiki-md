# Circle metric

↑ **Parent:** [Circle group](circle-group.md)

The quotient metric of circumference one uses the shorter distance around the circle: $\|x\|=\min_{m\in\mathbb Z}|\widetilde x-m|$. It also measures separation across the identified endpoints. This is the metric used by [circular spacing](circular-spacing.md) in the [analytic large sieve inequality](exponential-sum-large-sieve.md).
