# Event counter

↑ **Parent:** [Interrupt](interrupt.md)

An [event counter](event-counter.md) records a number of observed events, unlike a [single-bit event latch](single-bit-event-latch.md) which records only whether any event occurred. A software [event counter](event-counter.md) shared with an [interrupt handler](interrupt-handler.md) needs atomic updates or a suitable [critical section](critical-section.md). Its finite capacity imposes a maximum backlog unless overflow is handled explicitly.
