# Binary Golay code

↑ **Parent:** [Perfect code](perfect-code.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Binary_Golay_code)

The length-$23$ [binary Golay code](binary-golay-code.md) is the [cyclic code](cyclic-code.md) over $\mathbb F_2$ generated by

$$
g(X)=1+X+X^5+X^6+X^7+X^9+X^{11}.
$$

It has [dimension](dimension-vector-space.md) $12$, [minimum Hamming distance](minimum-distance-of-a-code.md) $7$, and its radius-$3$ [Hamming balls](hamming-ball.md) partition $\mathbb F_2^{23}$. Its [parity extension](parity-extension.md) has length $24$, [dimension](dimension-vector-space.md) $12$, and [minimum Hamming distance](minimum-distance-of-a-code.md) $8$.
