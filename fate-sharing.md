# Fate-sharing

↑ **Parent:** [Internet architecture](internet-architecture.md)

[Fate-sharing](fate-sharing.md) places state needed by a communicating [endpoint](communication-endpoint.md) with that [endpoint](communication-endpoint.md), so that failure of an unrelated forwarding component need not erase the state of an ongoing exchange. This can help communication recover after a route change when a path becomes available again. It does not mean every [router](router.md) lacks state or that communication can survive loss of all paths.[§4: survivability and placement of essential connection state](the-design-philosophy-of-the-darpa-internet-protocols-by-david-d-clark.md)
