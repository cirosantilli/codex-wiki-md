# Codeword length

↑ **Parent:** [Codeword](codeword.md)

The codeword length is the number of alphabet symbols in a [codeword](codeword.md). For a binary word it counts bits; in a [prefix code](prefix-code.md), it is the depth of the corresponding leaf in the code tree.
