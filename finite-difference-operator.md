# Finite difference operator

↑ **Parent:** [Finite difference method](finite-difference-method.md)

A finite difference operator maps grid values to weighted combinations of nearby grid values. Scaled [finite differences](finite-difference-split.md) approximate [derivatives](derivative.md); their weights and grid spacing determine the [order of a numerical method](order-of-a-numerical-method.md).
