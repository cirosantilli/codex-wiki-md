# Congestion window

↑ **Parent:** [Congestion control](congestion-control.md)

A [congestion window](congestion-window.md) bounds a sender's outstanding data according to [congestion control](congestion-control.md). In [TCP](transmission-control-protocol.md) it is local sender state, distinct from the advertised [receive window](receive-window.md).
