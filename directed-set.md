# Directed set

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Directed_set)

A directed set is a nonempty [preorder](preorder.md) in which every finite subset has an upper bound. It provides an index set in which any finite collection of stages has a common later stage.
