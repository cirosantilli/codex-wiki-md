# Sufficient adjustment set

↑ **Parent:** [Backdoor adjustment set](backdoor-adjustment-set.md)

A sufficient adjustment set is a collection of pretreatment variables for which treatment and every relevant [potential outcome](potential-outcome.md) are conditionally independent. Adjustment for that set identifies the corresponding causal contrast under consistency and positivity.
