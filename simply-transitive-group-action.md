# Simply transitive group action

↑ **Parent:** [Transitive group action](transitive-group-action.md)

A [group action](group-action.md) is simply transitive when exactly one element sends any chosen point to any other. Equivalently it is both a [transitive group action](transitive-group-action.md) and a [free group action](free-group-action.md). Choosing a base point identifies the space with the acting [group](group-split.md); a different base point changes that identification by translation.
