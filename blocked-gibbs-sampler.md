# Blocked Gibbs sampler

↑ **Parent:** [Gibbs sampler](gibbs-sampler.md)

A [blocked Gibbs sampler](blocked-gibbs-sampler.md) draws groups of coordinates jointly from their [full conditional distributions](full-conditional-distribution.md). Each update preserves the [joint probability distribution](joint-probability-distribution.md); dependence between blocks can still cause a long [mixing time](mixing-time-of-a-markov-chain.md).
