# Square root of the SWAP gate

↑ **Parent:** [SWAP gate](swap-gate.md)

For two spin-one-half [qubits](qubit.md), the [SWAP gate](swap-gate.md) acts as one on the triplet sector and minus one on the singlet sector. The displayed unitary squares to SWAP. An isotropic [exchange interaction](exchange-interaction.md) with integrated angle $\pi/2$ implements it up to a common phase. There are other square-root branches; a pulse decomposition must use the declared branch consistently.
