# Transverse mass

↑ **Parent:** [Missing transverse momentum](missing-transverse-momentum.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Transverse_mass)

For a two-body [W boson](w-boson.md) decay into a [charged lepton](charged-lepton.md) $\ell$ and a [neutrino](neutrino.md), neglect both daughter [masses](mass.md) and use [natural units](natural-units.md) $c=1$. Let $\Delta\phi$ be the angle between the daughter [transverse momenta](transverse-momentum.md). Identifying the [missing transverse momentum](missing-transverse-momentum.md) with the [neutrino](neutrino.md)'s gives

$$
m_T^2=2p_{T\ell}p_T^{\rm miss}(1-\cos\Delta\phi).
$$

This observable uses no $p_{z\nu}$. The 1983 [UA1 experiment](ua1-experiment.md) paper already used [transverse mass](transverse-mass.md) as a lower bound on parent [mass](mass.md), before making additional decay-model assumptions for a mass estimate.[Section 10, pp.113–114, Figs.8–10: bound versus model-dependent mass fit](experimental-observation-of-isolated-large-transverse-energy-electrons-with-associated-missing-energy-at-sqrt-s-540-gev-by-g-arnison.md)

The bound follows directly from the [energy–momentum relation](energy-momentum-relation.md). For each massless daughter write its [four-momentum](four-momentum.md), using [rapidity](rapidity.md) $y$ and azimuth $\phi$, as

$$
p^\mu=(p_T\cosh y,\ p_T\cos\phi,\ p_T\sin\phi,\ p_T\sinh y).
$$

Using the [Minkowski inner product](minkowski-inner-product.md) with positive time sign, $p^2=E^2-|\mathbf p|^2$, the two daughter [four-momenta](four-momentum.md) give the true parent [invariant mass](invariant-mass.md) $M$:

$$
M^2=2p_{T\ell}p_{T\nu}\bigl[\cosh(y_\ell-y_\nu)-\cos\Delta\phi\bigr],\qquad
M^2-m_T^2=2p_{T\ell}p_{T\nu}\bigl[\cosh(y_\ell-y_\nu)-1\bigr]\geq0.
$$

Since $\cosh u\geq1$, **$m_T\leq M$**, with equality at equal daughter [rapidities](rapidity.md) when both [transverse momenta](transverse-momentum.md) are nonzero. Thus the unmeasured longitudinal information can enlarge the true [invariant mass](invariant-mass.md), but cannot lower it below this ideal [transverse mass](transverse-mass.md).

For an original example, stipulate $p_{T\ell}=p_{T\nu}=40\,\mathrm{GeV}$ and $\Delta\phi=\pi$. Then $m_T=80\,\mathrm{GeV}$. Equal [rapidities](rapidity.md) give $M=80\,\mathrm{GeV}$; choosing $y_\ell-y_\nu=1$ with exactly the same transverse readout gives $M=80\cosh(1/2)\simeq90.210\,\mathrm{GeV}$. One measured transverse configuration therefore permits different true parent [masses](mass.md).
