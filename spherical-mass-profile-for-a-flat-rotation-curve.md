# Spherical mass profile for a flat rotation curve

↑ **Parent:** [Flat galaxy rotation curve](flat-galaxy-rotation-curve.md)

In a spherically dominated [Newtonian gravitational field](newtonian-gravitational-field.md), the [circular orbit](circular-orbit.md) speed satisfies $v_c^2=GM(<r)/r$. A flat [galaxy rotation curve](galaxy-rotation-curve.md) therefore implies $M(<r)=v_0^2r/G$. Differentiating the enclosed mass gives $\rho=(4\pi r^2)^{-1}dM/dr$, yielding the inverse-square density profile. This is a halo-region approximation, not a mass inversion for a flattened stellar disk. A flat curve extending to infinite radius would imply infinite mass, so a real halo profile must eventually change or truncate.
