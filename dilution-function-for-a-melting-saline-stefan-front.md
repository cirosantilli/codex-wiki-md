# Dilution function for a melting saline Stefan front

↑ **Parent:** [Saline Stefan problem](saline-stefan-problem.md)

For stationary liquid below a salt-free solid and an upward [melting](melting.md) interface $a(t)=2A\sqrt{Dt}$, the [complementary error function](complementary-error-function.md) salt profile and flux balance $D C_z(a)=-\dot a C_i$ give the displayed concentration ratio. For $A>0$ it lies below one. At large $A$ it behaves as $e^{-A^2}/(2\sqrt\pi A)$.
