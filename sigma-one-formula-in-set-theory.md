# Sigma-one formula in set theory

↑ **Parent:** [Lévy hierarchy](levy-hierarchy.md)

A [first-order formula](first-order-formula.md) is syntactically $\Sigma_1$ when it is an unbounded existential quantifier block followed by a [bounded formula in set theory](bounded-formula-in-set-theory.md). Equivalence provable in a specified theory gives the corresponding modulo-theory notion. Existential witnesses show upward absoluteness between [transitive models](transitive-model.md) containing the parameters.
