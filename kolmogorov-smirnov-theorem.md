# Kolmogorov-Smirnov theorem

↑ **Parent:** [Statistical inference](statistical-inference-split.md)

For an empirical distribution function based on an independent sample from a continuous distribution $F$,

$$
\sqrt n\sup_x|\widehat F_n(x)-F(x)|
\xrightarrow{d}\sup_{0\leq t\leq1}|B(t)|,
$$

where $B$ is a [Brownian bridge](brownian-bridge.md).

This limit calibrates the [Kolmogorov-Smirnov test](kolmogorov-smirnov-test.md); the test compares an empirical distribution with its null distribution using the supremum discrepancy.
