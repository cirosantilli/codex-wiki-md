# Gaussian chain

↑ **Parent:** [Biopolymer mechanics](biopolymer-mechanics.md)

An ideal [Gaussian chain](gaussian-chain.md) is a [polymer](polymer.md) model whose independent segment vectors have zero mean and isotropic [Gaussian distribution](normal-distribution.md). If $\langle|\mathbf r|^2\rangle=b^2$, each Cartesian [variance](variance-split.md) is $b^2/3$, so a displacement across $\ell$ links has density $(3/(2\pi\ell b^2))^{3/2}\exp[-3R^2/(2\ell b^2)]$ and [characteristic function](characteristic-function.md) $\exp[-k^2b^2\ell/6]$. The continuous-contour version uses the same [characteristic function](characteristic-function.md) for any contour separation. It is the large-scale limit of a [freely jointed chain](ideal-chain.md), while allowing unbounded Gaussian segment lengths and omitting interactions between distant parts of the chain.
