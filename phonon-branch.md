# Phonon branch

↑ **Parent:** [Phonon dispersion relation](phonon-dispersion-relation.md)

A continuous family of [normal modes](normal-mode.md) labelled by the [wavevector](wavevector.md) and a branch index $s$. For $r$ [chemical atoms](atom-physics.md) per three-dimensional [primitive unit cell](primitive-unit-cell.md), the [dynamical matrix](dynamical-matrix.md) has $3r$ [eigenvalues](eigenvalue.md), giving $3r$ branches: three [acoustic phonon branches](acoustic-phonon-branch.md) and $3r-3$ [optical phonon branches](optical-phonon-branch.md) for a mechanically stable ordinary [crystal structure](crystal-structure.md).
