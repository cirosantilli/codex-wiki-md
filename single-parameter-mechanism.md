# Single-parameter mechanism

↑ **Parent:** [Mechanism design](mechanism-design.md)

In a single-parameter mechanism, player $i$ has one private scalar value $v_i$, receives an allocation amount $x_i$, and has [quasilinear utility](quasilinear-utility.md) $v_i x_i-p_i$. The allocation-payment relation is governed by [incentive compatibility](incentive-compatibility.md) and the [interim payment identity](interim-payment-identity.md).
