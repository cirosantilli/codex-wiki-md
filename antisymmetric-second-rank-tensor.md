# Antisymmetric second-rank tensor

↑ **Parent:** [Tensor](tensor.md)

A second-rank Cartesian tensor is antisymmetric when its components form a [skew-symmetric matrix](skew-symmetric-matrix.md), $T_{ij}=-T_{ji}$. Orthogonal coordinate changes preserve this property because $T'=RTR^T$ implies $(T')^T=RT^TR^T=-T'$.
