# Nondecreasing function

↑ **Parent:** [Monotonic function](monotonic-function.md)

A nondecreasing [function](function-split.md) never decreases when its argument increases. Flat intervals are allowed, unlike for a [strictly increasing function](strictly-increasing-function.md). Nondecreasing allocation functions permit [critical-value payments](critical-value-payment.md) in [single-parameter mechanisms](single-parameter-mechanism.md).
