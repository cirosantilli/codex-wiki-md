# Two-qubit product-state determinant criterion

↑ **Parent:** [Product state](product-state.md)

Write a two-qubit pure state as $\sum_{i,j=0}^1c_{ij}|ij\rangle$ and form its coefficient matrix $C=(c_{ij})$. The state is a [product state](product-state.md) exactly when $C$ has rank one, equivalently when

$$
c_{00}c_{11}=c_{01}c_{10}.
$$
