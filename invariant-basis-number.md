# Invariant basis number

↑ **Parent:** [Free module](free-module.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Invariant_basis_number)

A nonzero [ring](ring.md) $R$ has invariant basis number if $R^m\cong R^n$ as [free modules](free-module.md) implies $m=n$ for all positive integers $m,n$. The property is not automatic for arbitrary rings; the commutative-ring case is proved below.
