# Proper-time normalization of an affine parameter

↑ **Parent:** [Affine parameter](affine-parameter.md)

An [affine parameter](affine-parameter.md) on a [timelike geodesic](timelike-geodesic.md) can be scaled to [proper time](proper-time.md). With [metric](metric.md) signature $(+---)$ this fixes the tangent-vector norm to $c^2$. A further constant rescaling preserves the affine [geodesic equation](geodesic-equation.md) but changes that norm; conserved [energy](energy-split.md) and angular-momentum constants must be rescaled consistently. The unit term in a proper-time-normalized radial [energy](energy-split.md) equation is consequently a normalization choice, not a property of every [affine parameter](affine-parameter.md).
