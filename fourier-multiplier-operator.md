# Fourier multiplier operator

↑ **Parent:** [Fourier multiplier](fourier-multiplier.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fourier_multiplier_operator)

A Fourier multiplier operator $T_m$ is defined by $\widehat{T_mf}(\xi)=m(\xi)\widehat f(\xi)$. On $L^2$, a bounded symbol gives a bounded operator by the [Plancherel theorem](plancherel-theorem.md), while an unbounded symbol defines a [closed linear operator](closed-linear-operator.md) on the functions for which $m\widehat f$ remains square-integrable.
