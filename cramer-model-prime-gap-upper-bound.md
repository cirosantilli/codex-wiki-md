<h1 id="cramer-model-prime-gap-upper-bound">Cramér model prime-gap upper bound</h1>

↑ **Parent:** [Cramér model](cramer-model.md)

If $P_n$ are the increasing selected integers in the [Cramér model](cramer-model.md), then [almost surely](almost-sure-convergence.md) $\limsup_n(P_{n+1}-P_n)/(\log P_n)^2\le1$. A zero block of length $(1+\epsilon)(\log k)^2$ after $k$ has summable probability, so the [Borel-Cantelli first lemma](borel-cantelli-first-lemma.md) excludes these blocks eventually.
