# Finite pulse count for a falling Schwarzschild beacon

↑ **Parent:** [Schwarzschild radial fall from rest at a finite radius](schwarzschild-radial-fall-from-rest-at-a-finite-radius.md)

A freely falling source emits [optical pulses](optical-pulse.md) at proper times $\delta+nP$, for integers $n\ge0$. If its horizon-crossing [proper time](proper-time.md) is finite, only pulses beginning before $s_H$ can escape. Their number is the displayed ceiling, for $0\le\delta<P<s_H$. Infinite [Schwarzschild time](schwarzschild-time.md) at crossing does not give infinitely many emitted pulses. The pulse phase $\delta$ fixes both the count and the redshift of the last pulse. If a finite pulse straddles the horizon, its exterior portion has an arbitrarily late, increasingly redshifted received tail.
