# Atomic-orbital nodal plane

↑ **Parent:** [Atomic orbital](atomic-orbital.md)

A plane on which an [atomic orbital](atomic-orbital.md) [wavefunction](wave-function-split.md) vanishes. For a real [p orbital](p-orbital.md) oriented along $x$, it is the plane $x=0$. The [probability density](probability-density.md) also vanishes on that plane.
