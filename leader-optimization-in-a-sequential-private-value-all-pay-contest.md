# Leader optimization in a sequential private-value all-pay contest

↑ **Parent:** [Sequential private-value all-pay contest](sequential-private-value-all-pay-contest.md)

With follower distribution $F$, a leader of value $v$ chooses $b\in\arg\max_{0\leq b\leq1}\{vF(b)-b\}$. If $F$ is a [concave function](concave-function.md), the objective is concave and an interior optimum satisfies $vF'(b)=1$. Endpoint derivatives handle zero or maximal effort. Zero effort guarantees nonnegative payoff, so every optimum satisfies $b\leq vF(b)\leq v$.
