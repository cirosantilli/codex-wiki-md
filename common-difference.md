# Common difference

↑ **Parent:** [Arithmetic progression](arithmetic-progression.md)

The common difference of an [arithmetic progression](arithmetic-progression.md) is the fixed difference between consecutive [sequence terms](sequence-term.md). It gives a [finite difference](finite-difference-split.md) that is independent of position. Checking one adjacent pair finds its value only when the [arithmetic progression](arithmetic-progression.md) property is already known; otherwise, other pairs can disagree. For example, the differences in $7,10,14$ are three and four, so the three entries do not form an [arithmetic progression](arithmetic-progression.md).
