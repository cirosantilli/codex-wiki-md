# Multiplicity function

↑ **Parent:** [Multiset multiplicity](multiset-multiplicity.md)

The [function](function-split.md) mapping each possible element to its [multiset multiplicity](multiset-multiplicity.md). Finite [multisets](multiset.md) correspond to nonnegative functions with finite [support of a multiset](support-of-a-multiset.md). A functional representation can answer queries without supporting enumeration of all elements.
