# Triangular-profile line plume

↑ **Parent:** [Line plume](line-plume.md)

A two-sided [line plume](line-plume.md) whose axial [velocity](velocity.md) and density anomaly both have triangular transverse profiles. For half-width $b$, $\int_{-b}^bf(x/b)^n\,dx=2b/(n+1)$. These profile moments set the different coefficients of stored [mass](mass.md), [momentum](momentum.md), and their fluxes. It differs from a wall plume because both edges entrain ambient fluid.
