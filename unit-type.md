# Unit type

↑ **Parent:** [Data type](data-type.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Unit_type)

A [data type](data-type.md) with exactly one value. In [Haskell](haskell.md), both the [data type](data-type.md) and its sole value are written `()`; it is often the result of a computation whose purpose is an effect.
