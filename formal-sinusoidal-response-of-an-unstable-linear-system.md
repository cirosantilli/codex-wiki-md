# Formal sinusoidal response of an unstable linear system

↑ **Parent:** [Transfer function](transfer-function.md)

Substitution $s=i\omega$ into an algebraic [transfer function](transfer-function.md) can produce finite amplitude and [phase](phase-waves.md) even when the causal system has unstable [poles](pole.md). It then describes a sinusoidal particular solution whose growing homogeneous response is not generically absent. A physically settled [frequency](frequency.md) response requires transient [asymptotic stability](asymptotic-stability.md); for an unstable causal [transfer function](transfer-function.md), its Laplace region of convergence need not include the imaginary axis.
