# Noncommutativity

↑ **Parent:** [Commutativity](commutativity.md)

A [binary operation](binary-operation.md) is noncommutative if some pair of elements fails to commute. Thus reversing their order can change the result. The same operation may still have many [commuting elements](commuting-elements.md).
