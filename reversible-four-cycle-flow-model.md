# Reversible four-cycle flow model

↑ **Parent:** [Flow-level network model](flow-level-network-model.md)

The [proportionally fair allocation on a four-cycle](proportionally-fair-allocation-on-a-four-cycle.md) produces a [reversible Markov chain](reversible-markov-chain.md) with [stationary distribution](stationary-distribution.md) proportional to $\binom{n_1+n_2+n_3+n_4}{n_1+n_3}\prod_r\rho_r^{n_r}$. This is normalizable exactly when every resource's offered load is strictly below capacity, equivalently $\max(\rho_1,\rho_3)+\max(\rho_2,\rho_4)<1$.
