# Facial action coding

↑ **Parent:** [Facial expression](facial-expression.md)

Description of visible facial movements in terms of anatomically informed action components. Coding the movement keeps an observation separate from an inferred [emotion](emotion.md) label; a code by itself does not prove the observer's emotional interpretation.
