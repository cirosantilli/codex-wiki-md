# Microparasite

↑ **Parent:** [Parasite](parasite.md)

A [microparasite](microparasite.md) is typically modelled as multiplying rapidly within a [host](host-biology.md), so infection status rather than the exact organism count is the first between-host state variable. [SIS model](sis-model.md), [SIR model](sir-model.md) and [SEIR model](seir-model.md) descriptions are examples. Additional within-host structure can still be required.
