# Ideal class

↑ **Parent:** [Ideal class group](ideal-class-group.md)

An ideal class is an element of the [ideal class group](ideal-class-group.md), represented by a nonzero [fractional ideal](fractional-ideal.md). Two fractional ideals represent the same class exactly when their quotient is a [principal ideal](principal-ideal.md).
