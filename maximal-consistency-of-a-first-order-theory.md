# Maximal consistency of a first-order theory

↑ **Parent:** [Maximal consistent set of first-order sentences](maximal-consistent-set-of-first-order-sentences.md)

A [first-order consistent](first-order-consistency.md) theory is maximally consistent when it has no proper consistent extension in its fixed language. It decides each [first-order sentence](first-order-sentence.md) or its [negation](negation.md).
