# Alpha-limit set

↑ **Parent:** [Limit set](limit-set.md)

The alpha-limit set of a trajectory consists of the points approached along sequences of times tending to negative infinity. It is the [omega-limit set](omega-limit-set.md) for the time-reversed flow.
