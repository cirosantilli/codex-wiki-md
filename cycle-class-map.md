# Cycle class map

↑ **Parent:** [Chow group](chow-group.md)

For a smooth complex projective [algebraic variety](algebraic-variety.md), the cycle class map sends an [algebraic cycle](algebraic-cycle.md) of codimension $r$ to the [Poincare dual](poincare-dual.md) of its homology class. [Rational equivalence](rational-equivalence.md) gives the same cohomology class, so the map descends to the [Chow group](chow-group.md). It respects [intersection products](intersection-product-of-cartier-divisors.md), pullback and proper pushforward; a cohomological obstruction therefore obstructs the corresponding proposed identity of [Chow classes](chow-class.md).
