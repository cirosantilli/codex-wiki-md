# Transverse electronic mode

↑ **Parent:** [Quasi-one-dimensional quantum transport](quasi-one-dimensional-quantum-transport.md)

A transverse [confinement](confinement.md) [eigenstate](eigenstate.md) that defines a threshold for propagation along a narrow conductor. Above that threshold, its longitudinal dispersion supplies an incident channel from each reservoir. [spin](spin.md) can label separate channels; an unresolved spin-degenerate mode contributes twice the single-spin [spin-resolved conductance quantum](spin-resolved-conductance-quantum.md). This physical use of mode is unrelated to the most probable value of a [probability](probability.md) distribution.
