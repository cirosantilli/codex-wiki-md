# Flow network edge capacity

↑ **Parent:** [Flow network](flow-network.md)

A directed edge capacity is the upper bound $c_{ij}\geq0$ on the feasible nonnegative [flow](flow.md) through that edge. In a [residual network](residual-network.md), its forward residual capacity is $c_{ij}-f_{ij}$ and its backward residual capacity is $f_{ij}$. Increasing every edge capacity need not increase the [maximum flow](maximum-flow-problem.md) by that same amount, because a [cut of a flow network](cut-of-a-flow-network.md) can contain several edges.
