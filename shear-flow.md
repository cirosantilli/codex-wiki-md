# Shear flow

↑ **Parent:** [Fluid mechanics](fluid-mechanics-split.md)

A shear flow has a [velocity field](velocity-field.md) varying across adjacent fluid layers, giving a nonzero [shear rate](shear-rate.md). A parallel example is $\mathbf u=U(z)\mathbf e_x$, with vertical shear $U'$. [Linear shear flow](linear-shear-flow.md) has constant shear, while a [shear layer](shear-layer.md) concentrates the velocity change in a narrow region.
