# Localization of a module

↑ **Parent:** [Localization of a ring](localization-of-a-ring.md)

For a [multiplicative subset](multiplicatively-closed-set.md) $S\subseteq R$ and an $R$-module $M$, the localization $S^{-1}M$ consists of fractions $m/s$, with $m/s=m'/s'$ when some $u\in S$ satisfies $u(s'm-sm')=0$. It is an $S^{-1}R$-module, and the canonical map is $m\mapsto m/1$. If $M$ is finitely generated over a [Noetherian ring](noetherian-ring.md), then $S^{-1}M$ is a [Noetherian module](noetherian-module.md) over $S^{-1}R$.
