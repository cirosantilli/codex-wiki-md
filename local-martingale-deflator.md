# Local martingale deflator

↑ **Parent:** [Martingale deflator](martingale-deflator.md)

A local martingale deflator is a strictly positive process $Y$ such that multiplying each traded asset price by $Y$ produces a [local martingale](local-martingale.md). It can support no-arbitrage arguments even when the deflated prices are not true martingales.
