# Symmetry group

↑ **Parent:** [Group action](group-action-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Symmetry_group)

A symmetry group collects [bijections](bijection.md) of an object to itself that preserve a specified structure in both directions, with [function composition](function-composition.md) as the operation. For a geometric object one may require [Euclidean distances](euclidean-distance.md) to be preserved, giving an [isometry group](isometry-group.md); for a [graph](graph-split.md), one preserves adjacency, giving a [graph automorphism](graph-automorphism.md) [group](group-split.md). For an unstructured [finite set](finite-set.md), every [permutation](permutation.md) is allowed. **The structure to be preserved is part of the definition.**

For a [square](square.md) with its usual geometric structure, the [symmetry group](symmetry-group.md) consists of four [rotations](rotation-mathematics.md) and four [reflections](reflection-mathematics.md). These form the [dihedral group](dihedral-group.md) of [group order](order-of-a-finite-group.md) eight. The existing [group action](group-action-split.md) example shows how its eight elements move the [vertices of a polygon](vertex-of-a-polygon.md); changing the object to its edges or a marked configuration changes the [group action](group-action-split.md) being studied.[§§1–2, Theorem 2.5, printed pp. 1–4: rigid motions, rotations, reflections and dihedral order conventions](dihedral-groups-by-keith-conrad.md)

Specifying the preserved data makes it possible to test a proposed symmetry exactly. After the preserved data are declared, [function composition](function-composition.md), the [identity map](identity-function.md), and [inverse maps](inverse-function.md) automatically preserve them too. [Symmetry transformations](symmetry-transformation.md) therefore form a [group](group-split.md), and questions about equivalent configurations become questions about [group orbits](orbit-group-theory.md), [stabilizer subgroups](stabilizer-subgroup.md), and [group homomorphisms](group-homomorphism.md). This supplies reusable mathematics for comparing many different kinds of objects.
