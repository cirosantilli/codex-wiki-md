# Morse function

↑ **Parent:** [Differential geometry](differential-geometry-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Morse_function)

A Morse function is a smooth real-valued function whose [critical points](critical-point.md) are all nondegenerate. Near a critical point of index $k$, the [Morse lemma](morse-lemma.md) gives coordinates in which the function is a constant minus $k$ squares plus the remaining positive squares.
