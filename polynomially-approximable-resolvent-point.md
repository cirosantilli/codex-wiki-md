# Polynomially approximable resolvent point

↑ **Parent:** [Polynomial Runge theorem](polynomial-runge-theorem.md)

For a closed set $K\subsetneq\mathbb C$, a point $\lambda\notin K$ is a polynomially approximable resolvent point when $z\mapsto(z-\lambda)^{-1}$ is a [uniform limit](uniform-limit.md) on $K$ of complex polynomials.
