# Weak-stiffness string frequency shift

↑ **Parent:** [Dispersion relation](dispersion-relation-split.md)

For the prescribed sine-mode model $\omega=k\sqrt{c_s^2+\alpha k^2}$, positive small stiffness shifts higher harmonics more strongly. Writing $\eta=\alpha k_1^2/c_s^2$ and $k_2=2k_1$ gives $\omega_2/\omega_1=2+3\eta+O(\eta^2)$. At the original fundamental quarter-period, the fundamental displacement changes to first order, but the second-mode [cosine](cosine.md) is at an extremum and changes only to second order. If the quarter-period is redefined with the shifted fundamental [frequency](frequency.md), that fundamental displacement is exactly zero. Comparing profiles requires specifying which clock convention is held fixed.
