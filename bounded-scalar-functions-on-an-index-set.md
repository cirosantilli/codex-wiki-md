# Bounded scalar functions on an index set

↑ **Parent:** [Banach space](banach-space-split.md)

For an arbitrary set $\Gamma$ and scalar field $\mathbb F$, this is the space of bounded functions $u:\Gamma\to\mathbb F$ with the [supremum norm](supremum-norm.md) $\|u\|=\sup_\gamma|u(\gamma)|$. Uniform limits of Cauchy sequences prove it is a [Banach space](banach-space-split.md). For $\Gamma=\mathbb N$ it is the [l-infinity sequence space](l-infinity-sequence-space.md); for the empty index set it is the zero space, with norm zero.
