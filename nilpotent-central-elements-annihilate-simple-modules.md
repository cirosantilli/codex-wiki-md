# Nilpotent central elements annihilate simple modules

↑ **Parent:** [Irreducible module](irreducible-module.md)

For a [simple module](irreducible-module.md) $M$ and a central element $z$ of an [algebra](algebra-split.md) $A$, the [image](image-of-a-function.md) $zM$ is a [submodule](submodule.md). If it is nonzero, it equals $M$, and iterating gives $z^rM=M$ for every $r$. This is impossible when $z$ is nilpotent. Hence $zM=0$. It follows, for example, that the only simple [module](module-mathematics.md) for $k[X]/(X^r)$ is the one-dimensional quotient on which $X$ acts by zero.
