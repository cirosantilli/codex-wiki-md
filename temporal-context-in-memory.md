# Temporal context in memory

↑ **Parent:** [Memory in animals](memory-in-animals.md)

Information about an event's position in an evolving sequence or internal state. Changes in neural activity over time can supply a temporal context, but time covaries with behavior, [expectation](expected-value-split.md) and other variables that require experimental controls.
