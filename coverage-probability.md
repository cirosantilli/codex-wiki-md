# Coverage probability

↑ **Parent:** [Confidence interval](confidence-interval.md)

The repeated-sampling probability that a random [confidence interval](confidence-interval.md) contains the fixed true [statistical parameter](statistical-parameter.md). An exact level-$1-\alpha$ procedure has coverage at least $1-\alpha$ at every admissible parameter; an asymptotic procedure approaches that value as sample size grows. Coverage is not a posterior probability for the realized interval. Higher-order [Edgeworth expansions](edgeworth-series.md) quantify the discrepancy from nominal coverage.
