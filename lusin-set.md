# Lusin set

↑ **Parent:** [Meagre set](meagre-set.md)

A Lusin set is an uncountable [subset](subset.md) $A$ of the [real numbers](real-number.md) such that $A\cap M$ is countable for every [meagre set](meagre-set.md) $M$. Every meagre subset has a meagre $F_\sigma$ cover, so testing those covers suffices. The [Lusin set construction under CH](lusin-set-construction-under-ch.md) gives an example. A Lusin set has no uncountable meagre subset of itself.
