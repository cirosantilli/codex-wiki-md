# Expected codeword length

↑ **Parent:** [Optimal prefix code](optimal-prefix-code.md)

For a source symbol $X$ and a code $c$, the expected codeword length is

$$
L(c)=\mathbb E[|c(X)|]=\sum_xP(X=x)|c(x)|.
$$
