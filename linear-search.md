# Linear search

↑ **Parent:** [Algorithm](algorithm.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linear_search)

Inspect entries one by one until a match is found or all entries have been checked. [Linear search](linear-search.md) needs no ordering assumption; an absent target requires $n$ equality comparisons in a collection of $n$ entries.
