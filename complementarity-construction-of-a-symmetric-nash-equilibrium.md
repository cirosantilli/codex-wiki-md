# Complementarity construction of a symmetric Nash equilibrium

↑ **Parent:** [Nash equilibrium](nash-equilibrium.md)

For a symmetric [bimatrix game](bimatrix-game.md) with payoff matrices $P,P^{\mathsf T}$, any nonzero $x$ satisfying these equations gives the symmetric [Nash equilibrium](nash-equilibrium.md) $(x/\sum_i x_i,x/\sum_i x_i)$. Every positive coordinate attains the same maximal payoff. This one-vector construction differs from a two-vector [Lemke-Howson algorithm](lemke-howson-algorithm.md) path, which can return asymmetric equilibria.
