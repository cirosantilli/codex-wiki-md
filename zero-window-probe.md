# Zero-window probe

↑ **Parent:** [Transmission Control Protocol](transmission-control-protocol.md)

A [zero-window probe](zero-window-probe.md) solicits a current [receive window](receive-window.md) advertisement when a sender has been stopped by a zero window. Repeated probes recover from a lost reopening [acknowledgement](acknowledgement.md).
