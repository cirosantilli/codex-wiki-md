# Finite global generation on a quasi-compact scheme

↑ **Parent:** [Globally generated line bundle](globally-generated-line-bundle.md)

A [globally generated line bundle](globally-generated-line-bundle.md) on a [quasi-compact](compact-space.md) scheme is generated by finitely many [global sections](global-section.md). Each point has a section generating on an open neighbourhood, and quasi-compactness gives a finite subcover. This supplies a map into a fixed finite-dimensional [projective space](projective-space-split.md) associated with that line bundle.
