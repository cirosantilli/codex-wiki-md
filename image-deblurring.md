# Image deblurring

↑ **Parent:** [Inverse problem](inverse-problem-split.md)

Image deblurring reconstructs a sharper image from observations described by a blur model. In the linear model, a [matrix](matrix.md) or [linear operator](linear-operator.md) mixes values of the unknown image; [measurement noise](measurement-noise.md) perturbs the observed result. The [inverse problem](inverse-problem-split.md) must therefore recover attenuated distinctions while controlling amplification of [measurement noise](measurement-noise.md), as the two-pixel example illustrates.
