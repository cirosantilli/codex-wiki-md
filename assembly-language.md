# Assembly language

↑ **Parent:** [Programming language](programming-language-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Assembly_language)

A [programming language](programming-language-split.md) expressing machine instructions through symbolic operation names, [processor registers](processor-register.md), labels and data directives. A concrete program must respect its instruction set's operand restrictions and the platform's [calling convention](calling-convention.md).
