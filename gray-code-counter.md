# Gray-code counter

↑ **Parent:** [Digital counter](digital-counter.md)

A [digital counter](digital-counter.md) following a [Gray code](gray-code.md), so adjacent output states differ in exactly one [bit](bit.md). The two-[bit](bit.md) cycle $00,01,11,10$ is implemented by [D flip-flops](d-flip-flop.md) with next-state functions $G^+=H$, $H^+=\neg G$.
