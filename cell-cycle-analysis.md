# Cell cycle analysis

↑ **Parent:** [Cell cycle](cell-cycle-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cell_cycle_analysis)

[Cell cycle analysis](cell-cycle-analysis.md) assigns evidence to stages of the [cell cycle](cell-cycle-split.md). A [flow cytometric DNA-content assay](flow-cytometric-dna-content-assay.md) measures accumulated nuclear [DNA](deoxyribonucleic-acid.md), whereas [DNA pulse labeling](dna-pulse-labeling.md) detects synthesis over an exposure window. Agreement between these readouts is useful because an amount and a synthesis event answer different questions.
