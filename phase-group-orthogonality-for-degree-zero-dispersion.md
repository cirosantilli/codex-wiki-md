# Phase-group orthogonality for degree-zero dispersion

↑ **Parent:** [Phase velocity and group velocity](phase-velocity-and-group-velocity.md)

If a differentiable [dispersion relation](dispersion-relation.md) $\omega(\mathbf k)$ is homogeneous of degree zero at nonzero $\mathbf k$, the [Euler homogeneous function theorem](euler-theorem-for-homogeneous-functions.md) gives $\mathbf k\cdot\nabla_{\mathbf k}\omega=0$. Therefore [phase velocity](phase-velocity.md) $\omega\mathbf k/k^2$ is orthogonal to [group velocity](group-velocity.md) $\nabla_{\mathbf k}\omega$. The result applies exactly to limiting [inertial waves](inertial-wave.md); finite compressibility can alter the dispersion.
