# Capability (computer security)

↑ **Parent:** [Access matrix](access-matrix.md)

An unforgeable reference carrying authority to perform specified operations on an object. In [seL4](sel4.md), the [operating-system kernel](kernel-operating-system.md) stores [security capabilities](capability-computer-security.md) in protected slots; an [integer](integer-split.md) naming a slot is not itself freely forgeable authority. Guessing another [operating-system process](process-computing.md)'s slot number does not give access to its [security capability](capability-computer-security.md).
