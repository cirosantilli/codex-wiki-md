# Voxel

↑ **Parent:** [Neuroscientific methods](neuroscientific-methods.md)

A volume element in an imaging measurement. In [functional magnetic resonance imaging](functional-magnetic-resonance-imaging.md), one [voxel](voxel.md) aggregates an indirect signal over many cells, so a shared response at [voxel](voxel.md) or region scale need not imply the same active neuronal population.
