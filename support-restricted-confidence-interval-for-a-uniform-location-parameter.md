# Support-restricted confidence interval for a uniform location parameter

↑ **Parent:** [Confidence interval](confidence-interval.md)

For two independent observations uniform on $[\theta-a,\theta+a]$, the displayed interval of possible parameter values contains the true parameter almost surely. Intersecting any [confidence interval](confidence-interval.md) with it preserves that interval's coverage, while excluding values inconsistent with the observations. The [order statistics](order-statistic.md) interval $[U_{(1)},U_{(2)}]$ has coverage $1/2$, since the observations straddle $\theta$ with probability $1/2$. If their separation exceeds $a$, the entire interval of possible parameters lies between the observations; this explains why the nominal one-half procedure can be unnecessarily wide on that event.
