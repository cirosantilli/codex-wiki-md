# Cache coherence

↑ **Parent:** [Cache (computing)](cache-computing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cache_coherence)

Consistency requirements for cached copies of the same memory location, including agreement on its writes. [Cache coherence](cache-coherence.md) does not itself impose [sequential consistency](sequential-consistency.md) across different locations.
