# Modulus of a complex self-power

↑ **Parent:** [Complex exponentiation](complex-exponentiation.md)

For $z\ne0$, every logarithmic value is $\log|z|+i(\arg z+2\pi k)$ with integer $k$. Multiplying by $z$ and taking the real part proves the displayed formula for the [modulus](modulus.md) of each value of [complex exponentiation](complex-exponentiation.md). For nonreal $z$, these values form a geometric progression with nonunit positive ratio $e^{-2\pi\operatorname{Im}z}$. For real nonzero $z$, changing the logarithm branch changes only the phase and leaves the modulus fixed. A fixed initial argument changes only the indexing of the set of values.
