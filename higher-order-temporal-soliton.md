# Higher-order temporal soliton

↑ **Parent:** [Temporal optical soliton](temporal-optical-soliton.md)

An integer-order sech initial pulse in the ideal focusing cubic fibre equation has periodic shape evolution involving compression and recombination. It does not preserve a single fixed profile like a [fundamental temporal bright soliton](fundamental-temporal-bright-soliton.md). Arbitrary noninteger-order initial pulses can contain radiation as well as [solitons](soliton.md).
