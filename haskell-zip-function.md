# Haskell zip function

↑ **Parent:** [Haskell](haskell.md)

The [function](function-split.md) `zip :: [a] -> [b] -> [(a,b)]` pairs corresponding list positions, stopping when either input ends. Pairing a finite [list](list-abstract-data-type.md) with `[0..]` attaches its zero-based indices without constructing an infinite result. With the unbounded `Integer` index type this avoids index overflow for arbitrarily long finite inputs.
