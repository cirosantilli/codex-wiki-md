# Incomplete-trio transmission-selection bias

↑ **Parent:** [Transmission disequilibrium test](transmission-disequilibrium-test.md)

If one parent is [heterozygous](heterozygosity.md) and the other parent's [genotype](genotype.md) is missing, a homozygous child reveals the observed parent's transmitted [allele](allele.md), whereas a heterozygous child need not. Selecting only revealed transmissions can therefore bias the [transmission disequilibrium test](transmission-disequilibrium-test.md). For allele-1 frequency $p$ under random mating and fair transmission, the probabilities of an allele-1 or allele-2 homozygous child from an observed heterozygous parent are $p/2$ and $(1-p)/2$. Among selected homozygous children, the observed allele-1 transmission probability is $p$, not generally $1/2$. A complete-trio analysis avoids this reconstruction rule; methods retaining missing-parent families need an explicit [likelihood function](likelihood-function.md) or a valid conditional adjustment. [Family-based association tests using genotype data with uncertainty](https://pmc.ncbi.nlm.nih.gov/articles/PMC3297829/) discusses this bias.
