# Projective state exclusion

↑ **Parent:** [Quantum state exclusion](quantum-state-exclusion.md)

For $d$ labelled [pure states](pure-state.md) in dimension $d$, an [orthonormal basis](orthonormal-basis.md) $\{|b_j\rangle\}_{j=0}^{d-1}$ supplies error-free [projective state exclusion](projective-state-exclusion.md) when $\langle b_j|\psi_j\rangle=0$ for every $j$. The [Born rule](born-rule.md) gives zero [probability](probability.md) to reporting $j$ on input $\psi_j$; orthonormal-basis completeness ensures that an outcome is always obtained. Conversely, zero error for this labelled [basic measurement](basic-measurement.md) forces precisely those zero overlaps. The matrix of transition [probabilities](probability.md) is therefore a matrix of column [probability distributions](probability-distribution-split.md) with zero diagonal.
