# State function

↑ **Parent:** [Thermodynamics](thermodynamics-split.md)

A state function depends on the current equilibrium state, rather than the path used to reach it. [Internal energy](internal-energy.md) and [entropy](entropy.md) are state functions; transferred [heat](heat.md) and [work](work.md) depend on the process.
