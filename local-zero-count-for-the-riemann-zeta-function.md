# Local zero count for the Riemann zeta function

↑ **Parent:** [Riemann–von Mangoldt formula](riemann-von-mangoldt-formula.md)

The number of [Nontrivial zeros of the Riemann zeta function](nontrivial-zero-of-the-riemann-zeta-function.md) in a height interval of length one is $O(\log(|t|+3))$, including multiplicity and either endpoint. Subtract the [Riemann–von Mangoldt formula](riemann-von-mangoldt-formula.md) at the endpoints and use conjugation at negative heights. Summing these counts with reciprocal-height weights gives $\sum_{|\Im\rho|\le T}1/|\rho|\ll\log^2(T+3)$.
