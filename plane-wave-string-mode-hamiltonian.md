# Plane-wave string mode Hamiltonian

↑ **Parent:** [String sigma model in an isotropic plane wave](string-sigma-model-in-an-isotropic-plane-wave.md)

Expand every transverse [closed string](closed-string.md) coordinate in a real orthonormal [Fourier basis](fourier-basis.md) of the spatial circle. The [canonical momenta](canonical-momentum.md) are $p_{Ia}=T\dot q_{Ia}$, and spatial orthogonality reduces the field [Hamiltonian](hamiltonian.md) to the displayed independent [harmonic oscillators](simple-harmonic-motion.md). Canonical quantization gives $\omega_a(a_{Ia}^\dagger a_{Ia}+1/2)$ for each nonzero-frequency mode; a zero-frequency mode retains the free particle term $p_{Ia}^2/(2T)$. The formal [zero-point energy](zero-point-energy.md) requires a regulator; it is not automatically the massless flat-background intercept. Opposite travelling-wave oscillator combinations diagonalize the translation generator and satisfy [closed-string level matching](closed-string-level-matching.md).
