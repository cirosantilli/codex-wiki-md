# Horizon-scaling cosmic string network

↑ **Parent:** [Cosmic string](cosmic-string.md)

A network whose characteristic long-string separation grows with the horizon scale can lose [energy](energy-split.md) into loops and [radiation](radiation.md). Its density can scale as $\mu/t^2$ in natural units. This is distinct from the $a^{-2}$ dilution of an ideal frozen noninteracting string network.
