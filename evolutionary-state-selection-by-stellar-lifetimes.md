# Evolutionary-state selection by stellar lifetimes

↑ **Parent:** [Stellar population](stellar-population.md)

Given a birth-mass distribution and age distribution, an evolutionary state occupies the mass-age set where its starting lifetime has elapsed and its ending lifetime has not. The state number fraction is the [probability](probability.md) measure of this set. [Initial mass function](initial-mass-function.md) tail coordinates and the [probability integral transform](probability-integral-transform.md) can turn these weighted regions into simple geometric areas.
