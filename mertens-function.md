# Mertens function

↑ **Parent:** [Möbius function](mobius-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Mertens_function)

The Mertens function is the summatory [Möbius function](mobius-function.md)

$$
M(x)=\sum_{n\leq x}\mu(n).
$$
