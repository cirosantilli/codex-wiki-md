# Phase object

↑ **Parent:** [Phase-contrast microscopy](phase-contrast-microscopy.md)

A specimen whose leading optical effect is a spatially varying [phase](phase-waves.md), rather than [absorption](absorption-electromagnetic-radiation.md). A thin specimen with [refractive index](refractive-index.md) $n_s$ in a medium of [refractive index](refractive-index.md) $n_m$ has, in a straight-path approximation,

$$
\phi(x,y)=\frac{2\pi}{\lambda}\int\bigl(n_s(x,y,z)-n_m\bigr)\,dz.
$$

Here $\lambda$ is the vacuum [wavelength](wavelength.md); the integral is an [optical path length](optical-path-length.md) difference. For the chosen values $\lambda=550\,\mathrm{nm}$, thickness $1\,\mathrm{\mu m}$ and $n_s-n_m=0.005$, the [phase](phase-waves.md) is $\pi/55\simeq0.0571$ radians. This calculation does not identify thickness separately from [refractive index](refractive-index.md) contrast.[Formulas 2–4, optical path difference and phase shift](introduction-to-phase-contrast-microscopy-by-nikon-instruments-inc.md)
