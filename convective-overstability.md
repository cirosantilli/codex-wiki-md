# Convective overstability

↑ **Parent:** [Keplerian shearing sheet](keplerian-shearing-sheet.md)

An adverse radial [specific entropy](specific-entropy.md) gradient can drive an oscillatory instability through the finite lag supplied by [thermal conduction](thermal-conduction.md) or relaxation. This differs from a [viscous-convective instability](viscous-convective-instability.md), in which viscosity changes rotational stabilization.
