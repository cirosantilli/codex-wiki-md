# Box plot

↑ **Parent:** [Descriptive statistics](descriptive-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Box_plot)

A [box plot](box-plot.md) displays a median and interquartile interval, with whiskers and separately marked points according to a stated rule. Common whiskers extend to the most extreme observations within 1.5 interquartile ranges of the box. It compares location, spread and unusually distant observations across groups; whiskers need not represent the full range.
