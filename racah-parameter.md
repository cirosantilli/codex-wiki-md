# Racah parameter

↑ **Parent:** [Ligand field](ligand-field.md)

A parameter in a compact description of intra-atomic [electron](electron.md) repulsion within a configuration. $B$ and $C$ control relative d-shell multiplet energies; $B$ is not the [octahedral splitting](octahedral-splitting.md) or a [rotational constant](rotational-constant.md).
