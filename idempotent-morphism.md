# Idempotent morphism

↑ **Parent:** [Category](category-split.md)

An endomorphism $e:A\to A$ is idempotent when $e^2=e$. It splits when $e=ir$ for maps $r:A\to B$, $i:B\to A$ satisfying $ri=1_B$.
