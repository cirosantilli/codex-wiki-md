# Subtraction

↑ **Parent:** [Arithmetic](arithmetic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Subtraction)

Subtraction adds the [additive inverse](additive-inverse.md): $a-b=a+(-b)$. On the [number line](number-line.md), $2-3=-1$ is a shift three units left from $2$. Reversing the two inputs changes the sign: $3-2=1$, so [subtraction](subtraction.md) is generally not [commutative](commutativity.md). Solving $x+3=2$ gives the same answer $x=-1$ by adding $-3$ to both sides; the operation preserves equality while undoing the added amount.
