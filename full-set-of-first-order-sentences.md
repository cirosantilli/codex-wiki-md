# Full set of first-order sentences

↑ **Parent:** [Henkin witness property](henkin-witness-property.md)

A [full set of first-order sentences](full-set-of-first-order-sentences.md) has existential witnesses among names in its own [first-order language](first-order-language.md): if it proves an [existential sentence](existential-sentence.md), it proves some closed-term instance of the matrix. For a deductively closed [set](set-split.md) this may be stated by membership of the [first-order sentences](first-order-sentence.md). In a function-free [first-order language](first-order-language.md) the witness is a [constant symbol](constant-symbol.md). A [first-order consistent](first-order-consistency.md) complete full [first-order theory](first-order-theory.md) has a canonical [term model](term-model.md).
