# Magnetic unit cell

↑ **Parent:** [Crystal](crystal.md)

A magnetic unit cell repeats the ordered magnetic moments as well as the atomic positions. It can exceed the chemical [primitive unit cell](primitive-unit-cell.md) when translations interchange oppositely ordered [magnetic sublattices](magnetic-sublattice.md). For a simple-cubic Néel pattern $(-1)^{n_x+n_y+n_z}$, translations preserving the sum's parity form an FCC lattice with conventional parameter twice the chemical spacing and a two-spin primitive basis.
