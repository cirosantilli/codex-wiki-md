# Boone-Higman theorem

↑ **Parent:** [Word problem for groups](word-problem-for-groups.md)

A finitely generated [group](group-split.md) $G$ has a soluble [word problem for a group](word-problem-for-groups.md) if and only if there are a [simple group](simple-group.md) $S$ and a [finitely presented group](finitely-presented-group.md) $P$ with embeddings $G\hookrightarrow S\hookrightarrow P$. The theorem does not require $S$ itself to be finitely presented. In particular, a finitely generated subgroup of a finitely presented simple group has soluble word problem. The primary statement is Theorem I of [An algebraic characterization of groups with soluble word problem](https://www.cambridge.org/core/journals/journal-of-the-australian-mathematical-society/article/an-algebraic-characterization-of-groups-with-soluble-word-problem1/748FFD937CEA3727E812C8CDB9CC59B9).
