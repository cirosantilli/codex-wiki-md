# Mirror plane

↑ **Parent:** [Reflection symmetry](reflection-symmetry.md)

A plane through which reflection leaves an object unchanged. In a molecular skeleton, sites exchanged by a symmetry preserving all substituent identities can be chemically equivalent in an achiral [NMR spectroscopy](nuclear-magnetic-resonance-split.md) experiment.
