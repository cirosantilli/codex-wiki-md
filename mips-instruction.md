# MIPS instruction

↑ **Parent:** [MIPS architecture](mips-architecture.md)

An instruction in the [MIPS architecture](mips-architecture.md), with a specified binary encoding and architectural effect. Educational datapaths often simplify details such as [branch delay slots](branch-delay-slot.md); instruction behavior in a particular circuit must follow that circuit's stated specification. [MIPS R-type instructions](mips-r-type-instruction.md) use register and function fields; [MIPS I-type instructions](mips-i-type-instruction.md) use an immediate field as well as register fields.
