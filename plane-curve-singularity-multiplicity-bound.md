# Plane curve singularity multiplicity bound

↑ **Parent:** [Genus-degree formula](genus-degree-formula.md)

Blow up each distinct singular point of an [integral projective curve](integral-projective-curve.md) in the [projective plane](projective-plane.md) once. The [arithmetic genus drop under a point blowup](arithmetic-genus-drop-under-a-point-blowup.md) and the [genus-degree formula](genus-degree-formula.md) give arithmetic genus $(d-1)(d-2)/2-\sum_Pm_P(m_P-1)/2$ for the strict transform. Its [arithmetic genus](arithmetic-genus.md) is nonnegative, proving the bound in every characteristic. Infinitely near singularities need not have been resolved.
