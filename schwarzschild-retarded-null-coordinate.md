# Schwarzschild retarded null coordinate

↑ **Parent:** [Null coordinate](null-coordinate.md)

In the exterior of [Schwarzschild spacetime](schwarzschild-spacetime.md), $dr_*/dr=(1-2M/r)^{-1}$. Outgoing [radial null geodesics](radial-null-geodesic.md) therefore have constant $u=t-r_*$. At fixed receiver radius $R$, their arrival Schwarzschild time is $u+r_*(R)$, so differences in $u$ give arrival-time differences. A static receiver's [proper time](proper-time.md) includes the factor $\sqrt{1-2M/R}$.
