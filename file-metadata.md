# File metadata

↑ **Parent:** [Computer file](computer-file.md)

Information describing a [file](computer-file.md), such as type, owner, access permissions, size, timestamps and [hard link](hard-link.md) count. In the toy layout, the [inode](inode.md) carries these attributes; the [directory entries](directory-entry.md) carry the names. The distinction matters because renaming a [file](computer-file.md) need not copy its contents.
