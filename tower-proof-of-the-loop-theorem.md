# Tower proof of the loop theorem

↑ **Parent:** [Loop theorem](loop-theorem.md)

Start with a singular [disk](disk-mathematics.md) whose [boundary](boundary-of-a-set.md) represents a prescribed nontrivial class in a [boundary](boundary-of-a-set.md) subsurface. Repeatedly lift it through double [covering spaces](covering-space.md) of regular neighbourhoods of its image. The number of distinct image [simplexes](simplex.md) strictly increases and is bounded by the number of domain [simplexes](simplex.md), so the tower ends. At the top, vanishing first mod-two [homology](homology-split.md) forces every [boundary](boundary-of-a-set.md) component to be a [sphere](sphere.md). An embedded [disk](disk-mathematics.md) can then be constructed and projected down the tower. Resolving double curves preserves a [boundary](boundary-of-a-set.md) class outside a chosen [normal subgroup](normal-subgroup.md), giving an embedded compression [disk](disk-mathematics.md) at the bottom.
