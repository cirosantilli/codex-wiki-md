# Identical-particle factor in a final-state phase-space integral

↑ **Parent:** [Lorentz-invariant phase-space measure](lorentz-invariant-phase-space-measure.md)

When the full [Lorentz-invariant phase-space measure](lorentz-invariant-phase-space-measure.md) treats $n$ identical final particles as labeled, each physical final configuration is counted $n!$ times. The unlabelled [relativistic scattering cross-section](relativistic-scattering-cross-section.md) therefore includes $1/n!$. For two identical scalars, this divides the full-angle result by two; equivalently, integrate over a region containing only one representative of each exchanged pair.
