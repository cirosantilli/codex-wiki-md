# Coding level of the constructible hierarchy

↑ **Parent:** [Constructible hierarchy](constructible-hierarchy.md)

A level $L_\lambda$ is a coding level when $\lambda$ is a [limit ordinal](limit-ordinal.md), the representation of every [well-order code](well-order-code.md) in $L_\lambda$ is below $\lambda$, and every [ordinal](ordinal.md) below $\lambda$ has a well-order code in $L_\lambda$.
