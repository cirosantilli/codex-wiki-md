# Transverse magnetic focusing

↑ **Parent:** [Two-dimensional electron gas](two-dimensional-electron-gas.md)

A [magnetic field](magnetic-field-split.md) curves ballistic carrier trajectories between an injector and a collector. For openings separated along a specular edge by $L$, peaks occur near $L=2jr_c$ with $r_c=\hbar k_F/(e|B|)$, giving $|B_j|=2j\hbar k_F/(eL)$. Field polarity and carrier sign select the connection direction. [Electron phase coherence](electron-phase-coherence.md) can produce fine structure but is not required for the basic semiclassical focusing geometry.
