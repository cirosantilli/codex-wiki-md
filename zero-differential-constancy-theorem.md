# Zero-differential constancy theorem

↑ **Parent:** [Differential of a smooth map](differential-of-a-smooth-map.md)

A [smooth map](smooth-map-between-manifolds.md) between [smooth manifolds](smooth-manifold.md) with zero differential is locally constant: each target coordinate function has zero [derivatives](derivative.md) on a sufficiently small source coordinate ball. Integration along straight segments proves constancy there. Its fibers are open and closed, so a [connected](connected-space.md) source makes the map constant globally.
