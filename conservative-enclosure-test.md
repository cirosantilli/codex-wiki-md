# Conservative enclosure test

↑ **Parent:** [Bounding volume](bounding-volume.md)

A [conservative enclosure test](conservative-enclosure-test.md) may retain disjoint objects as candidates, but must never reject a true [set intersection](set-intersection.md). Increasing an enclosure can add candidates while preserving this implication.
