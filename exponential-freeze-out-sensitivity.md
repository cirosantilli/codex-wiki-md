# Exponential freeze-out sensitivity

↑ **Parent:** [Cosmological particle freeze-out](cosmological-particle-freeze-out.md)

In a supplied equilibrium-cutoff model with $P=mc^2/(k_BT_f)$, present [number density](number-density.md) can contain $P^{3/2}e^{-P}$. The logarithmic derivative is $3/(2P)-1$, making small changes in a large [cosmological particle freeze-out](cosmological-particle-freeze-out.md) parameter important for the inferred abundance.
