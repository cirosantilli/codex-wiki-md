# Agglomerative hierarchical clustering

↑ **Parent:** [Cluster analysis](cluster-analysis.md)

Start with singleton clusters and repeatedly merge the two clusters with the smallest chosen intercluster dissimilarity. [Single-linkage clustering](single-linkage-clustering.md) uses the smallest cross-pair distance; [complete-linkage clustering](complete-linkage-clustering.md) uses the largest. Merge heights and sensitivity to ties help assess a proposed number of groups.
