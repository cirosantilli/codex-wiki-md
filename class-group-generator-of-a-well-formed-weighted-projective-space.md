# Class-group generator of a well-formed weighted projective space

↑ **Parent:** [Well-formed weighted projective space](well-formed-weighted-projective-space.md)

The [toric divisor class sequence](toric-divisor-class-sequence.md) identifies the [divisor class group](divisor-class-group.md) with $\mathbb Z$ via $(a_i)\mapsto\sum q_ia_i$. Choose integers $a_i$ with $\sum q_ia_i=1$; then $D=\sum a_iF_i$ represents its positive generator $H$. This is an ample [Q-Cartier divisor](q-cartier-divisor.md): for $\ell=\operatorname{lcm}(q_i)$ the local Cartier data of $\ell D$ on the chart omitting ray $j$ is $m_j=(\ell/q_j)e_j-\ell(a_i)$, which satisfies the strict [toric ampleness criterion](toric-ampleness-criterion.md). The generator need not itself be a [Cartier divisor](cartier-divisor-split.md); for example the positive generator on $\mathbb P(1,1,2)$ has Cartier index two.
