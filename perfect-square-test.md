# Perfect square test

↑ **Parent:** [Square number](square-number.md)

For a [nonnegative integer](natural-number.md) $n$, compute its [integer square root](integer-square-root.md) $r=\lfloor\sqrt n\rfloor$ and accept exactly when $r^2=n$. An approximate [square root](square-root.md) must be corrected with exact [integer](integer-split.md) comparisons before this equality is tested. This procedure distinguishes a squareness test from merely approximating a [square root](square-root.md).
