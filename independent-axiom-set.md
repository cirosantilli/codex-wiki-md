# Independent axiom set

↑ **Parent:** [Axiom set](axiom-set.md)

For an [independent axiom set](independent-axiom-set.md), [semantic entailment](semantic-entailment.md) of any one axiom from the remaining [axioms](axiom.md) fails. By the completeness theorem, this is equivalent to no member being formally derivable from the others in a complete calculus. To establish independence it suffices to give, for each axiom, a [first-order structure](first-order-structure.md) satisfying all the other [axioms](axiom.md) and failing that one.
