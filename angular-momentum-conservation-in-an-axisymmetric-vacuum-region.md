# Angular momentum conservation in an axisymmetric vacuum region

↑ **Parent:** [Komar angular momentum](komar-angular-momentum.md)

For an axial [Killing vector](killing-vector-field.md) $\xi$ and zero [cosmological constant](cosmological-constant.md), set $F^{ab}=\nabla^b\xi^a$. The [Killing equation](killing-equation.md) and [Ricci identity](curvature-commutator-on-a-covariant-tensor.md) give $\nabla_bF^{ab}=-R^a{}_b\xi^b$. In a vacuum region this vanishes, so [Stokes theorem](stokes-theorem.md) makes the [Komar angular momentum](komar-angular-momentum.md) equal on homologous enclosing surfaces. The region may contain [gravitational waves](gravitational-wave.md) with nonzero Weyl curvature: Ricci flatness, rather than complete flatness, is what removes the flux. This proves absence of axial angular-momentum transport by exactly axisymmetric gravitational radiation, without assuming that a radiating spacetime is stationary.
