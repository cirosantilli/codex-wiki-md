# Prompt neutron generation time

↑ **Parent:** [Point kinetics model](point-kinetics-model.md)

The effective time associated with successive prompt fission generations in a specified [point kinetics model](point-kinetics-model.md). It is distinct from a macroscopic population growth period, which also depends on [reactor reactivity](reactivity-nuclear-engineering.md) and [delayed neutrons](delayed-neutron.md).
