# Maximum independent set

↑ **Parent:** [Independent set (graph theory)](independent-set-graph-theory.md)

An [independent set](independent-set-graph-theory.md) with the largest possible [cardinality](cardinality.md) in the given finite [graph](graph-split.md). Its size is the [independence number](independence-number.md). This differs from a [maximal independent set](maximal-independent-set.md), which only cannot be enlarged by adding vertices: another independent set can still be larger.
