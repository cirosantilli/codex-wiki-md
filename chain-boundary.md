# Chain boundary

↑ **Parent:** [Chain complex](chain-complex.md)

An element of a [chain group](chain-group.md) is a boundary when it is the image of a higher-degree element under the [boundary operator](boundary-operator.md). Since $\partial^2=0$, every boundary is a [chain cycle](chain-cycle.md). Thus $H_n(C)=Z_n(C)/B_n(C)$, and a [chain cycle](chain-cycle.md) represents zero in [homology](homology-split.md) exactly when it is a boundary.
