# List header

↑ **Parent:** [Linked list node](linked-list-node.md)

A permanent dummy node marking a list boundary, often also storing metadata. In a header-based [circular linked list](circular-linked-list.md), emptiness is represented by the header pointing to itself, so insertion and deletion at the ends use the same splice operations as interior changes. The header payload need not denote an ordinary data entry.
