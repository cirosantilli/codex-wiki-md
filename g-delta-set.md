# G-delta set

↑ **Parent:** [Topological space](topological-space.md)

A G-delta set is a countable intersection of open subsets of a topological space. In a complete [metric](metric.md) space these are precisely the [topologically complete](topological-completeness.md) subspaces, by the [G-delta criterion for topological completeness](g-delta-criterion-for-topological-completeness.md).
