# Smooth plane conic

↑ **Parent:** [Projective plane curve](projective-plane-curve.md)

A smooth complex degree-two [projective plane curve](projective-plane-curve.md) is a projective linear image of the degree-two [Veronese map](veronese-map.md) and is diffeomorphic to a [sphere](sphere.md). Its class in $\mathbb{CP}^2$ is twice the class of a projective line. Its [self-intersection number](self-intersection-number.md) is four, so its oriented [normal bundle](normal-bundle.md) has [Euler class](euler-class-of-a-vector-bundle.md) evaluating to four.
