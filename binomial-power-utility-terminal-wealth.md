# Binomial power-utility terminal wealth

↑ **Parent:** [Complete-market terminal utility optimizer](complete-market-terminal-utility-optimizer.md)

In a complete $n$-period [binomial market](discrete-time-binomial-market.md) with riskless gross return $R$, pricing density $Z$ and [utility function](utility-function-split.md) $U(x)=\gamma x^{1/\gamma}$, put $\eta=\gamma/(\gamma-1)$. The optimal terminal payoff is $X^*=R^nw_0Z^{-\eta}/\mathbb E[Z^{1-\eta}]$. Its marginal utility is proportional to $Z$; the supporting-line inequality for the strictly concave [utility function](utility-function-split.md) proves optimality using the pricing [budget constraint](budget-constraint.md).
