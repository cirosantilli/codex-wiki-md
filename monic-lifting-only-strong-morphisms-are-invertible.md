# Monic lifting-only strong morphisms are invertible

↑ **Parent:** [Left lifting property against monomorphisms](left-lifting-property-against-monomorphisms.md)

If $e:X\to Y$ is a [monomorphism](monomorphism.md) and has the [left lifting property against monomorphisms](left-lifting-property-against-monomorphisms.md), apply its property to the square with both vertical arrows $e$ and both horizontal arrows identities. The filler is a two-sided inverse, so $e$ is an [isomorphism](isomorphism.md).
