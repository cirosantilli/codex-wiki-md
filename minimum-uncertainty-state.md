# Minimum uncertainty state

↑ **Parent:** [Robertson uncertainty principle](robertson-uncertainty-principle.md)

A state saturating the uncertainty bound for a specified pair of [quantum observables](observable.md). The ground state of the [quantum harmonic oscillator](quantum-harmonic-oscillator-split.md) satisfies $\Delta x\Delta p=\hbar/2$. Saturation is a property of the state and the chosen observables.
