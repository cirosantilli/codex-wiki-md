# Data portability

↑ **Parent:** [Distributed system](distributed-system.md)

[Data portability](data-portability.md) permits moving useful application data between implementations or providers. An export format alone need not reproduce a provider's interfaces, credentials or service behaviour, so portability and service interoperability are distinct design questions.
