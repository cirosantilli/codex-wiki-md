# B2 root system

↑ **Parent:** [Special orthogonal Lie algebra](special-orthogonal-lie-algebra.md)

The $B_2$ root system consists of $\pm\varepsilon_1$, $\pm\varepsilon_2$, and $\pm\varepsilon_1\pm\varepsilon_2$. Its vector representation has weights $\varepsilon_1,\varepsilon_2,0,-\varepsilon_2,-\varepsilon_1$.
