# Suslin hypothesis

↑ **Parent:** [Suslin line](suslin-line.md)

The assertion that there is no [Suslin line](suslin-line.md), equivalently that every complete dense linear order without endpoints satisfying the interval countable chain condition is separable. A [Suslin tree](suslin-tree.md) gives a counterexample.
