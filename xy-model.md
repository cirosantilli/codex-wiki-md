# XY model

↑ **Parent:** [Classical O(n) lattice model](classical-o-n-lattice-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/XY_model)

The XY model is the infinite-state limit of the [clock model](clock-model.md): each spin is a [unit vector](unit-vector.md) with a continuous angle and the global symmetry is $O(2)$.
