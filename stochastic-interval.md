# Stochastic interval

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

For a [stopping time](stopping-time.md) $T$, the stochastic interval $[0,T)$ means the subset $\{(\omega,t):0\leq t<T(\omega)\}$ of sample-time space. Its endpoint varies with the sample. A [locally defined stochastic process](locally-defined-stochastic-process.md) on it has no prescribed value at the endpoint. This notation is distinct from an ordinary deterministic interval.
