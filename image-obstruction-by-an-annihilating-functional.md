# Image obstruction by an annihilating functional

↑ **Parent:** [Image of a linear map](image-of-a-linear-map.md)

If a [linear functional](linear-functional.md) $\ell$ vanishes on the [image of a linear map](image-of-a-linear-map.md) $T$ but $\ell(b)\ne0$, the equation $Tx=b$ has no solution. In Euclidean coordinates, a vector $n$ with $n^TA=0$ provides such an obstruction whenever $n^Tb\ne0$. In finite dimensions these annihilating functionals exactly characterize membership in the image: $b\in\operatorname{im}A$ precisely when it is orthogonal to every vector in $\ker A^T$.
