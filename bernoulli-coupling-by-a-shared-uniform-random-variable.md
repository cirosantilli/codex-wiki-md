# Bernoulli coupling by a shared uniform random variable

↑ **Parent:** [Coupling](coupling.md)

For $r,s\in[0,1]$ and a [random variable](random-variable-split.md) $U$ with the [uniform distribution](continuous-uniform-distribution.md) on $[0,1]$, set $B_r=\mathbb1_{\{U\leq r\}}$ and $B_s=\mathbb1_{\{U\leq s\}}$. Each has the corresponding [Bernoulli distribution](bernoulli-distribution.md), and $\mathbb P(B_r\ne B_s)=|r-s|$, because disagreement occurs precisely between the two thresholds. This is a [maximal coupling](maximal-coupling.md) of the two laws.
