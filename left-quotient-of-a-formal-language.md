# Left quotient of a formal language

↑ **Parent:** [Formal language theory](formal-language-theory.md)

For a [word](string.md) $u$ and a [formal language](formal-language.md) $L$, the left quotient $u^{-1}L=\{w:uw\in L\}$ is the possible continuation language after the prefix $u$. Two prefixes have the same left quotient exactly when they are [Myhill-Nerode equivalent](myhill-nerode-equivalence.md). For a [regular language](regular-language.md) only finitely many distinct left quotients occur.
