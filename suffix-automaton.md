# Suffix automaton

↑ **Parent:** [Data structure](data-structure-split.md)

A suffix automaton is a finite automaton recognizing all suffixes of a fixed [string](string.md). With every reachable state accepting, it recognizes all substrings; its number of states and transitions is linear in the original string length for a fixed finite alphabet.
