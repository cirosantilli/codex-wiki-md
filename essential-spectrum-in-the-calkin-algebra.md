# Essential spectrum in the Calkin algebra

↑ **Parent:** [Essential spectrum of a closed operator](essential-spectrum-of-a-closed-operator.md)

For a [bounded linear operator](continuous-linear-operator.md) on an infinite-dimensional complex [Hilbert space](hilbert-space-split.md), define the essential spectrum by failure of the [Fredholm](fredholm-operator.md) property for $T-\lambda I$. The [Atkinson theorem](atkinson-theorem.md) identifies it with the spectrum in the [Calkin algebra](calkin-algebra.md), hence it is compact and nonempty. On a finite-dimensional [Hilbert space](hilbert-space-split.md) it is empty. For a bounded real diagonal operator on a separable infinite-dimensional space it equals the subsequential cluster set of the diagonal entries, including values of infinite multiplicity.
