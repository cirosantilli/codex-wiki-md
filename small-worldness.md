# Small-worldness

↑ **Parent:** [Graph theory](graph-theory-split.md)

[Small-worldness](small-worldness.md) compares a network's clustering and average shortest-path length to reference values through $\sigma=(C/C_{\rm rand})/(L/L_{\rm rand})$. The common $\sigma>1$ classification is a ratio-based convention rather than a significance test; random-reference variability must be assessed separately.[New measures of small-world-ness, Definition 2](network-%E2%80%98small-world-ness%E2%80%99-a-quantitative-method-for-determining-canonical-network-equivalence-by-mark-d-humphries-and-others.md)
