# Symplectic vector bundle

↑ **Parent:** [Vector bundle](vector-bundle.md)

A symplectic vector bundle has a smooth fiberwise [symplectic form](symplectic-form.md), making each fiber a [symplectic vector space](symplectic-vector-space.md). Its structure group reduces to the [symplectic group](symplectic-group.md). A [symplectic normal bundle](symplectic-normal-bundle.md) is an important example.
