# Midpoint test for a closed set

↑ **Parent:** [Convex set](convex-set-split.md)

Checking only [midpoints](midpoint.md) is not enough for an arbitrary [subset](subset.md) of a real [vector space](vector-space-split.md). The [rational numbers](rational-number.md) contain the [midpoint](midpoint.md) of every pair of [rational numbers](rational-number.md), but the [line segment](line-segment.md) from $0$ to $1$ also contains [irrational numbers](irrational-number.md). For instance $\sqrt2/2$ lies on that [line segment](line-segment.md) and is not rational. This shows why the definition quantifies over every real $t\in[0,1]$.

There is a useful additional hypothesis: a [closed subset](closed-set.md) $C\subseteq\mathbb R^d$ containing the [midpoint](midpoint.md) of every pair of its points is a convex set. Repeated bisection includes all points $(1-t)x+ty$ with [dyadic rational](dyadic-rational.md) $t\in[0,1]$. These coefficients approach every real $t\in[0,1]$; being a [closed subset](closed-set.md) then includes each [limit](limit-of-a-function.md). This is a short proof outline, and the [rational numbers](rational-number.md) example identifies precisely why a [closed subset](closed-set.md) was required.
