# Quantum oracle

↑ **Parent:** [Quantum query complexity](quantum-query-complexity.md)

A [quantum oracle](quantum-oracle.md) supplies coherent access to a function through a specified [unitary operator](unitary-operator.md). For a function with [binary string](binary-string.md) output, the standard construction retains the input and adds the output into an answer [quantum register](quantum-register.md) by bitwise [exclusive or](exclusive-or.md). This operation is its own inverse, even when the function is not [injective](injective-function.md). A [Boolean quantum oracle](boolean-quantum-oracle.md) is the single-output-bit case; [Simon's algorithm](simon-s-algorithm.md) uses several answer [qubits](qubit.md). Other encodings, such as a [modular-addition quantum oracle](modular-addition-quantum-oracle.md) or a [phase gate](phase-gate.md) encoding, require their own explicit query conventions.
