# Smooth continuation criterion for semilinear wave equations

↑ **Parent:** [Semilinear wave equation](semilinear-wave-equation.md)

For a smooth [semilinear wave equation](semilinear-wave-equation.md) whose nonlinearity is a smooth function of the solution and its first derivatives, local [Sobolev space](sobolev-space-split.md) theory gives a continuation criterion: a finite maximal existence time requires divergence of a sufficiently high solution norm. A bounded base norm $H^{s+1}\times H^s$, with $s>n/2$, allows restarting local existence. Higher regularity persists by differentiated [energy estimates](energy-estimate.md). Precise norms can be weakened for particular nonlinearities.
