# Spherical current-dipole logarithmic kernel

↑ **Parent:** [Sarvas formula](sarvas-formula.md)

For $r>b$ and $P=|\mathbf r-\mathbf r_0|$, the displayed kernel satisfies $\phi=\int_r^\infty ds/[s|s\widehat{\mathbf r}-\mathbf r_0|]$. The limit at $b=0$ is $1/r$. Differentiating along $\mathbf Q\times\mathbf r_0$, which preserves $b$, gives $(\mathbf Q\times\mathbf r_0)\cdot\nabla_{\mathbf r_0}\phi=(\mathbf Q\times\mathbf r_0)\cdot\mathbf r/F$. Thus it generates the normalized [magnetic scalar potential](magnetic-scalar-potential.md) in the [Sarvas formula](sarvas-formula.md).
