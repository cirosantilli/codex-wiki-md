# Jones-component ratio sensitivity

↑ **Parent:** [Jones vector](jones-vector.md)

For a differentiable [Jones vector](jones-vector.md) with $J_x(0)\ne0$, the ratio $r=J_y/J_x$ fixes [polarization](polarization-waves.md) independently of common [amplitude](wave-amplitude.md) and [phase](phase-waves.md). The title quotient derivative tests first-order [polarization](polarization-waves.md) sensitivity. If $\mathbf J'(0)=a\mathbf J(0)$ for a complex scalar $a$, then $r'(0)=0$. For a lossless normalized output, differentiation of $\mathbf J^\dagger\mathbf J=1$ makes $\operatorname{Re}a=0$, so this change is a common [phase](phase-waves.md). A vanishing component requires the complementary ratio or a basis-independent [polarization](polarization-waves.md) coordinate instead.
