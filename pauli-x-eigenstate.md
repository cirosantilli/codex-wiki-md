# Pauli X eigenstate

↑ **Parent:** [Quantum mechanics](quantum-mechanics-split.md)

The Pauli $X$ eigenstates are $(|0\rangle\pm|1\rangle)/\sqrt2$ with eigenvalues $\pm1$.

These are the eigenvectors of one [Pauli matrix](pauli-matrices.md), not an alternative name for the whole matrix family.
