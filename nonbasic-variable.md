# Nonbasic variable

↑ **Parent:** [Simplex basis](simplex-basis.md)

A [nonbasic variable](nonbasic-variable.md) corresponds to a column outside the current [simplex basis](simplex-basis.md). In standard nonnegative [linear programming](linear-programming-split.md), it is set to zero at the basic solution. With explicit finite bounds, it is normally fixed at one of its bounds.
