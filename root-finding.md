# Root finding

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

Find a value $x$ satisfying $f(x)=0$ for a given function. Methods include the [bisection method](bisection-method.md), which retains a bracket around a root, and derivative-based iteration. Finding a root numerically is distinct from the root as a mathematical object.
