# System call

↑ **Parent:** [Kernel (operating system)](kernel-operating-system.md)

A request from a program for an [operating-system kernel](kernel-operating-system.md) service. In the [Unix](unix.md) examples here, opening, reading, linking and unlinking [files](computer-file.md) request controlled changes or access to [operating system](operating-system-split.md) resources. The [operating-system kernel](kernel-operating-system.md) checks the request and performs the permitted operation; an interface specified by [POSIX](posix.md) does not by itself dictate every internal implementation detail.
