# Boundedly complete statistic

↑ **Parent:** [Complete statistic](complete-statistic.md)

Bounded completeness requires the defining implication for a [complete statistic](complete-statistic.md) only for bounded measurable functions. Completeness implies it, but the converse need not hold. If a [sufficient statistic](sufficient-statistic.md) $T$ gives a parameter-independent event probability $c$ and the conditional probability $S(T)$ of that event is nonconstant, then $S-c$ is a bounded zero-mean obstruction to bounded completeness.
