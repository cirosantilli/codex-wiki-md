# Current-perpendicular-to-plane magnetoresistance

↑ **Parent:** [Giant magnetoresistance](giant-magnetoresistance.md)

The measuring [electric current](electric-current.md) crosses the layer planes. This geometry motivates the serial-layer paths in the [two-current resistor model](two-current-resistor-model.md). A quantitative material calculation can also require interface [electrical resistances](electrical-resistance.md), [spin relaxation](spin-relaxation.md) and [spin accumulation](spin-accumulation.md); the circuit below intentionally isolates a smaller set of assumptions.
