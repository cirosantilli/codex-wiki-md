# QMA error reduction

↑ **Parent:** [QMA](qma.md)

Starting from completeness $2/3$ and soundness $1/3$, run an odd number $r$ of parallel copies and take majority. The [QMA parallel repetition with entangled witnesses](qma-parallel-repetition-with-entangled-witnesses.md) argument proves soundness for arbitrary repeated witnesses. Exponential [Markov's inequality](markov-inequality.md) gives majority error at most $(2\sqrt2/3)^r$. Hence $O(\log(1/\epsilon))$ copies suffice for error $\epsilon$, with polynomial overhead when the target error is inverse-polynomial or exponentially small in input length.
