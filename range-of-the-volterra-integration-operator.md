# Range of the Volterra integration operator

↑ **Parent:** [Volterra operator](volterra-operator.md)

For $Ku(y)=\int_0^y u(x)\,dx$ on the [Hilbert space](hilbert-space-split.md) $L^2(0,1)$, every image has a [weak derivative](weak-derivative.md) $f'=u$ and zero trace at zero. Conversely every such [Sobolev space](sobolev-space-split.md) element is this integral of its [weak derivative](weak-derivative.md). The range is dense because it contains smooth functions supported in $(0,1)$, but it is not closed: a step function can be approximated in $L^2$ by continuous ramps and is not itself in $H^1$. The [Moore–Penrose inverse of an operator](moore-penrose-inverse-of-an-operator.md) has this range as its domain and differentiates there.
