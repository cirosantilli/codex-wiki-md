# Exponential shift rule for differential operators

↑ **Parent:** [Linear differential operator](linear-differential-operator.md)

For a constant $a$ and a [polynomial](polynomial-split.md) $P$, the [product rule](product-rule.md) gives $D(e^{ax}v)=e^{ax}(D+a)v$. Iteration and [linearity](linearity.md) prove the displayed identity. In particular $(D-a)^m(e^{ax}v)=e^{ax}v^{(m)}$, which reduces a repeated-root constant-coefficient [linear ordinary differential equation](linear-ordinary-differential-equation-split.md) to repeated [integration](integral-split.md).
