# L2 Lagrange point

↑ **Parent:** [Collinear Lagrange point](collinear-lagrange-point.md)

The collinear [Lagrange point](lagrange-point.md) beyond the smaller primary, away from the larger one, is $L_2$. For a small mass ratio it lies approximately one [Hill radius](hill-radius.md) from the secondary and has a growing linear mode.
