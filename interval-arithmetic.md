# Interval arithmetic

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Interval_arithmetic)

[Interval arithmetic](interval-arithmetic.md) computes enclosing intervals rather than single floating-point values. Exclusion and validated root tests on recursively subdivided boxes can support exhaustive implicit-curve tracing and certified geometric error bounds.
