# Lazy evaluation

↑ **Parent:** [Programming language semantics](programming-language-semantics.md)

Evaluation delayed until a result is demanded, with sharing of the delayed computation's result. A [lazy list](lazy-list.md) can expose a constructor before computing its tail; this permits productive infinite structures and [lazy feedback streams](lazy-feedback-stream.md). A non-strict language can implement its semantics this way without making every [function](function-split.md) non-strict.
