# Sinc function

↑ **Parent:** [Fourier transform](fourier-transform-split.md)

The unnormalized sinc is $\operatorname{sinc}(x)=\sin x/x$, extended by value one at zero. The normalized form is $\sin(\pi x)/(\pi x)$. It is the inverse [Fourier transform](fourier-transform-split.md) of a frequency interval indicator, so it describes ideal low-pass filtering and the [Shannon scaling function](shannon-scaling-function.md).
