# Small-signal model

↑ **Parent:** [Operating point](operating-point.md)

A first-order [Taylor expansion](taylor-expansion.md) of an [electrical circuit](electrical-circuit-split.md)'s response about an [operating point](operating-point.md). It describes small changes in [electric potential difference](electric-potential-difference.md) and [electric current](electric-current.md); the neglected higher-order terms limit the useful [signal](signal.md) range.
