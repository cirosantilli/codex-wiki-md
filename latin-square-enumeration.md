# Latin square enumeration

↑ **Parent:** [Latin square](latin-square.md)

Enumerating every [Latin square](latin-square.md) of a specified order, without identifying row, column or symbol [permutations](permutation.md) as the same output. Arbitrary square generation visits $n^{n^2}$ candidates. Restricting every row to a [permutation](permutation.md) reduces this to $(n!)^n$ candidates. Both counts follow by independent choices for positions or rows; neither count is the number of valid [Latin squares](latin-square.md).
