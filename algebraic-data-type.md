# Algebraic data type

↑ **Parent:** [Type system](type-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algebraic_data_type)

A type whose values are described by named [data constructors](data-constructor.md) with specified fields. For example, `data Tree a = One a | Two (Tree a) (Tree a)` describes a [leaf-labelled binary tree](leaf-labelled-binary-tree.md). Its two alternatives are distinguished by [pattern matching](pattern-matching.md); the recursive fields give a [recursive type](recursive-type.md).
