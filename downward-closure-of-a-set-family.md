# Downward closure of a set family

↑ **Parent:** [Down-set](down-set.md)

For a [set family](set-family.md) $\mathcal A\subseteq\mathcal P([n])$, its downward closure is $\downarrow\mathcal A=\{S:\text{some }A\in\mathcal A\text{ has }S\subseteq A\}$. It is the smallest [down-set](down-set.md) containing $\mathcal A$, just as the [upward closure of a set family](upward-closure-of-a-set-family.md) is the smallest [up-set](up-set.md) containing it. The two closures allow [Harris' inequality](harris-inequality.md) to control sizes of a [cross-Sperner family](cross-sperner-family.md) pair.
