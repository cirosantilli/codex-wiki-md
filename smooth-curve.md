# Smooth curve

↑ **Parent:** [Differential geometry](differential-geometry-split.md)

A smooth curve is a smooth map from an interval into a manifold or Euclidean space.

A curve may be described by a [parametric equation](parametric-equation.md); smoothness requires its coordinate functions to be differentiable to all orders.
