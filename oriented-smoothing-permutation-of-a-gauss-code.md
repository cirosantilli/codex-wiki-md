# Oriented smoothing permutation of a Gauss code

↑ **Parent:** [Gauss code](gauss-code.md)

Number the $2n$ visits along an oriented [knot diagram](knot-diagram.md), and let $\tau$ exchange the two visits to each crossing. At an [oriented smoothing](oriented-smoothing.md), an incoming strand follows the outgoing strand of the other visit. Thus the cycles of the displayed [permutation](permutation.md) are exactly the [Seifert circles](seifert-circle.md). Their count $s$ gives the [Seifert algorithm](seifert-algorithm.md) genus $(1-s+n)/2$ without requiring a separate drawing of the smoothed diagram.
