# Injectivity of a module map is detected at maximal localizations

↑ **Parent:** [Exactness of localization](exactness-of-localization.md)

For a [module homomorphism](module-homomorphism.md) $f:M\to N$ over a [commutative ring](commutative-ring.md) $A$, $f$ is [injective](injective-function.md) if and only if every $f_{\mathfrak m}$ is [injective](injective-function.md), with $\mathfrak m$ ranging over [maximal ideals](maximal-ideal.md). In a [localization of a module](localization-of-a-module.md), $x/s$ maps to zero exactly when some denominator $t$ satisfies $tf(x)=0$. If $f$ is [injective](injective-function.md) this gives $tx=0$, so the original fraction is zero. In general it identifies $\ker(f_{\mathfrak m})$ with $(\ker f)_{\mathfrak m}$. A nonzero element of $\ker f$ has a proper [annihilator](annihilator-ring-theory.md), contained in some [maximal ideal](maximal-ideal.md); it remains nonzero in that [localization](localization-of-a-ring.md). Thus vanishing of all localized kernels forces $\ker f=0$. No finiteness or [Noetherian](noetherian-ring.md) assumption is required.
