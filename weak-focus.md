# Weak focus

↑ **Parent:** [Nonhyperbolic equilibrium](nonhyperbolic-equilibrium.md)

A weak focus is an isolated planar [equilibrium point](equilibrium-point-of-a-dynamical-system.md) with nonzero imaginary [eigenvalues](eigenvalue.md) and nearby trajectories that spiral toward or away from it because of nonlinear terms. Its [linearization](linearization.md) is a [center equilibrium](center-equilibrium.md), so linear analysis alone does not settle stability. The first nonzero radial drift in its [Poincaré return map](poincare-map.md) decides the direction.

For example, if the radial return map is $P(r)=r+\kappa r^{2m+1}+O(r^{2m+2})$ with $\kappa\ne0$, sufficiently small positive $r$ decreases under successive returns when $\kappa<0$ and increases when $\kappa>0$. The first case gives [asymptotic stability](asymptotic-stability.md); the second gives instability. Equivalently, if a positive local function $W=r^2+O(r^3)$ satisfies $\dot W=c r^{2m+2}+O(r^{2m+3})$ and the angular velocity stays positive, then the sign of $c$ settles the same question. A quadratic planar system can have its cubic radial drift vanish and still have a nonzero fifth-order radial drift.
