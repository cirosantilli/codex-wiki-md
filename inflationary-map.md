# Inflationary map

↑ **Parent:** [Order-preserving function](order-preserving-function.md)

An inflationary map on a [partially ordered set](partially-ordered-set.md) satisfies $x\le f(x)$ for every $x$. This condition is distinct from being [order-preserving](order-preserving-function.md).
