# One-point correlation function

↑ **Parent:** [Correlation function](correlation-function.md)

The [correlation function](correlation-function.md) with a single field insertion is its [expectation value](expectation-value.md). In a translation-invariant vacuum it is independent of position. A [tadpole subtraction](tadpole-subtraction.md) chooses a linear [counterterm](counterterm.md), or shifts the expansion point of the field, so that this expectation is zero. This removes attached [tadpole diagrams](tadpole-diagram.md) from higher connected [correlation functions](correlation-function.md) without discarding the physical need to renormalize the chosen vacuum.
