# Completely invariant set of a rational map

↑ **Parent:** [Complex dynamics](complex-dynamics-split.md)

A subset $E$ is completely invariant for a rational map if $R(E)=E=R^{-1}(E)$. This asserts invariance in both directions, including every preimage, rather than just invariance of one chosen inverse branch. For a nonconstant sphere map, the two inclusions $R(E)\subseteq E$ and $R^{-1}(E)\subseteq E$ already imply the equalities, because the map is surjective. The [Fatou set](fatou-set.md) and [Julia set](julia-set.md) are completely invariant. A [Fatou component](fatou-component.md) need not itself be completely invariant even though the union of all components is.
