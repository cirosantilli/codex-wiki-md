# Cumulative alpha-decay event density

↑ **Parent:** [Direct-impact amorphization model](direct-impact-amorphization-model.md)

The number of [alpha decay](alpha-decay.md) events per material volume accumulated over time. For constant [alpha-decay event rate density](alpha-decay-event-rate-density.md) $R$, $D=Rt$; otherwise $D(t)=\int_0^t R(s)\,ds$. Multiplying by a damaged volume per event gives a dimensionless overlap parameter.
