# Unit-cost model

↑ **Parent:** [Time complexity](time-complexity.md)

A computation-cost convention assigning constant cost to specified primitive operations. For exact unbounded [integer](integer-split.md) arithmetic this can differ substantially from [bit complexity](bit-complexity.md): a multiplication of increasingly large values is one primitive operation but requires more bit operations. State which convention is used when estimating an [algorithm](algorithm-split.md)'s running time.
