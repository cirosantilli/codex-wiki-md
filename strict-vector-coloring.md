# Strict vector coloring

↑ **Parent:** [Vector coloring](vector-coloring.md)

A strict vector $k$-coloring requires equality $\langle v_i,v_j\rangle=-1/(k-1)$ on every [edge](edge-of-a-graph.md). The least admissible $k$ is the [complement theta number](complement-theta-number.md) for a [graph](graph-split.md) with an edge. Allowing merely an inequality defines the potentially smaller vector chromatic number.
