# Shell-model prediction for yttrium-91 beta decay

↑ **Parent:** [Unique forbidden beta decay](unique-forbidden-beta-decay.md)

Using the orbital order after 28 supplied in the simple shell model, [proton](proton.md) counts 32 and 38 fill $2p_{3/2}$ and $1f_{5/2}$, so the odd 39th [proton](proton.md) occupies $2p_{1/2}$. With paired valence [neutrons](neutron-split.md) this gives a $1/2^-$ yttrium-91 ground-state prediction. The daughter has paired 40 [protons](proton.md) and one [neutron](neutron-split.md) beyond the 50-neutron closure in $2d_{5/2}$, giving $5/2^+$. The inferred ground-state beta transition is therefore first-forbidden unique. This is a stated paired-shell model deduction; an endpoint diagram alone does not determine the [spin](spin.md) assignment or an evaluated [isotope](isotope.md) [mass](mass.md).
