# Axiom schema of collection

↑ **Parent:** [Axiom schema of replacement](axiom-schema-of-replacement.md)

For each formula, if every member of a domain set has a witness, a set contains witnesses for all those members. It permits extra members and does not require unique witnesses. For [hereditarily countable sets](hereditarily-countable-set.md), use ambient [axiom of choice](axiom-of-choice.md) to select one internal witness for each member of the countable domain, and use [countable-subset closure](countable-subset-closure.md) to keep the resulting witness set internal.
