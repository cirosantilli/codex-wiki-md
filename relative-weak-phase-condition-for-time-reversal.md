# Relative weak phase condition for time reversal

↑ **Parent:** [T-symmetry](t-symmetry.md)

If a [Fermi interaction](fermi-interaction.md) contains vector and axial operators with the same [time-reversal symmetry](t-symmetry.md) component signs, [antiunitarity](antiunitary-operator.md) conjugates their coupling constants without exchanging the two operators. After removing a common field phase, invariance requires $g_A/g_V$ real when $g_V\ne0$. Equivalently $\operatorname{Im}(g_Ag_V^*)=0$. Fixed intrinsic phases can additionally constrain the common phase; the relative condition is independent of that choice. Adding a Hermitian-conjugate interaction guarantees a [Hermitian operator](hermitian-operator.md) Hamiltonian, but does not guarantee [time-reversal symmetry](t-symmetry.md).
