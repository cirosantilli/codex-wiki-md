# C-star isomorphism

↑ **Parent:** [C-star homomorphism](c-star-homomorphism.md)

A C-star isomorphism is a bijective [C-star homomorphism](c-star-homomorphism.md): a complex-linear multiplicative map preserving the [involution](involution.md). Between unital [C-star algebras](c-star-algebra.md) it automatically preserves the unit. It preserves the [Banach algebra spectrum](spectrum-of-an-element.md), since it preserves invertibility in both directions. Applying the [C-star identity](c-star-identity.md) and the spectral [norm](norm.md) formula to $a^*a$ gives $\|\Phi(a)\|^2=\|\Phi(a^*a)\|=\|a^*a\|=\|a\|^2$, so it is automatically isometric.
