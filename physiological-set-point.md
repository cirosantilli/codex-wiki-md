# Physiological set point

↑ **Parent:** [Homeostasis](homeostasis.md)

A [physiological set point](physiological-set-point.md) is a reference around which regulation is organized, analogous to a [reference signal](reference-signal.md). An observed average is not automatically a separately encoded target. A range of acceptable values and different response thresholds can be more informative than a single exact number. [Negative feedback](negative-feedback.md) describes a causal sign; neither perfect constancy nor complete restoration follows from that sign alone.

For [core body temperature](core-body-temperature.md), [circadian rhythms](circadian-rhythm.md) and [fever](fever.md) can change the defended level. Thus a response toward the current [physiological set point](physiological-set-point.md) need not restore yesterday's [temperature](temperature.md). A drifting target and imperfect tracking of a fixed target are different explanations for a changing readout.
