# Harmonic-oscillator electric polarizability

↑ **Parent:** [Electric polarizability](electric-polarizability.md)

A bound charge in a harmonic restoring potential has induced [electric dipole moment](electric-dipole-moment.md) $d=(q^2/k)E$. Completing the square proves this for every static field within the strictly harmonic model. First-order [nondegenerate perturbation theory](nondegenerate-perturbation-theory.md) gives the same coefficient because the [position operator](position-operator.md) connects the unperturbed [ground state](ground-state.md) only to the first excited state. This exact response coefficient does not make its two-state [wavefunction](wave-function-split.md) approximation exact.
