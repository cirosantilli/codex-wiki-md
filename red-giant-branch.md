# Red giant branch

↑ **Parent:** [Stellar evolution](stellar-evolution.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Red_giant_branch)

The phase of [stellar evolution](stellar-evolution.md) in which hydrogen-shell [nuclear fusion](nuclear-fusion.md) surrounds an inert helium core and the envelope expands and cools. Low-mass [stars](star.md) climb toward helium ignition with growing core mass and [luminosity](luminosity.md); their cores become supported by [electron degeneracy pressure](electron-degeneracy-pressure.md). A [red giant](red-giant.md) is a broader observational category and need not be on this particular evolutionary branch.
