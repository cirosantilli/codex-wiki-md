# Density functional theory

↑ **Parent:** [Quantum chemistry](quantum-chemistry.md)

A framework describing electronic ground-state properties using the [electron density](electron-density.md). Practical approximations require an exchange-correlation functional; this does not mean that explicit [electrons](electron.md) have been replaced by a classical atom-only force field.
