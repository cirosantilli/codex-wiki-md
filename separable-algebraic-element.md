# Separable algebraic element

↑ **Parent:** [Separable extension](separable-extension.md)

An algebraic element $x$ over $K$ is separable when its [minimal polynomial](minimal-polynomial.md) over $K$ has no repeated root in a splitting field. For an irreducible polynomial $m_x$, this is equivalent to $m_x'\ne0$, because then $\gcd(m_x,m_x')=1$.
