# Axisymmetric compressible shearing-sheet waves

↑ **Parent:** [Shearing sheet](shearing-sheet.md)

In an unstratified [Keplerian shearing sheet](keplerian-shearing-sheet.md) with [sound speed](speed-of-sound.md) $c$, the four linear velocity-density equations yield $\omega^4-(\Omega^2+c^2k^2)\omega^2+\Omega^2c^2k_z^2=0$. The lower-frequency branch approaches the [inertial wave](inertial-wave.md) relation $\omega^2=\Omega^2k_z^2/k^2$ for $ck\gg\Omega$; the upper branch is predominantly acoustic.
