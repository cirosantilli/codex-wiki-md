# Endoplasmic reticulum exit site

↑ **Parent:** [Endoplasmic reticulum](endoplasmic-reticulum.md)

An [endoplasmic reticulum exit site](endoplasmic-reticulum-exit-site.md) is a region organizing export machinery and cargo departure from the ER. Local coat assembly, cargo concentration and membrane supply can be coordinated there.
