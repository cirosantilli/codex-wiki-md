# Box-constrained TV-L1 denoising

↑ **Parent:** [Total variation denoising](total-variation-denoising.md)

This finite-image [convex optimization](convex-optimization-split.md) model combines robust [L1 norm](l1-norm.md) fidelity with [discrete isotropic total variation](discrete-isotropic-total-variation.md) and pixel-range constraints. An exact [second-order cone program](second-order-cone-programming.md) uses two orthant fidelity slacks per pixel, two box slacks per pixel and a three-dimensional [Lorentz cone](second-order-cone.md) for each gradient magnitude. The product canonical barrier has parameter $6n$ for $n$ pixels.
