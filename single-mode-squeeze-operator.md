# Single-mode squeeze operator

↑ **Parent:** [Creation and annihilation operators](creation-and-annihilation-operators.md)

For a real squeezing parameter $\gamma$, the single-mode squeeze operator is

$$
S(\gamma)=\exp\left[-\frac\gamma2\left(A^{\dagger2}-A^2\right)\right].
$$

Its exponent is [skew-adjoint](skew-adjoint-generator.md), so $S(\gamma)$ is a [unitary operator](unitary-operator.md), and it implements the [Bogoliubov transformation](bogoliubov-transformation.md)

$$
S^\dagger AS=A\cosh\gamma-A^\dagger\sinh\gamma.
$$
