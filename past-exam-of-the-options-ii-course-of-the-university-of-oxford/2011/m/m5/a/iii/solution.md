<h1 id="m/m5/a/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

For a [Markov chain](../../../../../../markov-chain-split.md) started at state $i$, let $\tau_i^+=\inf\{n\geq1:X_n=i\}$ denote the first positive return time, using time $0$ for the starting state. A [recurrent state](../../../../../../recurrent-state.md) has $P_i(\tau_i^+<\infty)=1$; a [transient state](../../../../../../transient-state.md) has return [probability](../../../../../../probability.md) strictly less than $1$. An [absorbing state](../../../../../../absorbing-state.md) satisfies $P_{ii}=1$, so the chain remains there forever after arrival and it is necessarily a [recurrent state](../../../../../../recurrent-state.md).
