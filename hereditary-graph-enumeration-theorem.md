# Hereditary graph enumeration theorem

↑ **Parent:** [Colouring number of a hereditary graph property](colouring-number-of-a-hereditary-graph-property.md)

For a proper hereditary [graph](graph-split.md) property with unbounded orders, the colouring number determines the leading labelled speed. The lower bound comes from one contained [clique-independent partition class](clique-independent-partition-class.md). For the upper bound, forbid one induced [graph](graph-split.md) from each next-size partition type and use the [induced regularity template lemma](induced-regularity-template-lemma.md). Its intermediate-pair [graph](graph-split.md) is clique-free, and sparse or almost-complete pairs have negligible entropy. Bounded-order properties have colouring number zero and are outside this formula.
