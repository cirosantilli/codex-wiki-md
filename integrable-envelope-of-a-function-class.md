# Integrable envelope of a function class

↑ **Parent:** [Bracketing of a function class](bracketing-of-a-function-class.md)

A measurable function $M$ is an [integrable envelope of a function class](integrable-envelope-of-a-function-class.md) for a class $\mathcal H$ under a probability law $P$ if $|h(x)|\le M(x)$ for every $h\in\mathcal H$ and $PM<\infty$. Such an envelope permits the [dominated convergence theorem](dominated-convergence-theorem.md) to control shrinking [function brackets](bracketing-of-a-function-class.md).
