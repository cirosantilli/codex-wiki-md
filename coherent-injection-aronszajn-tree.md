# Coherent-injection Aronszajn tree

↑ **Parent:** [Aronszajn tree](aronszajn-tree.md)

Given [coherent coinfinite injections into omega](coherent-coinfinite-injections-into-omega.md), use all restrictions $e_\alpha\upharpoonright\beta$, where $\beta\le\alpha<\omega_1$, ordered by proper extension. Every level is countable because its nodes differ finitely from a fixed [function](function-split.md) on a countable domain. An uncountable [chain in a partial order](chain-in-a-partial-order.md) would have unbounded domain heights, and its union would inject $\omega_1$ into $\omega$, which is impossible.
