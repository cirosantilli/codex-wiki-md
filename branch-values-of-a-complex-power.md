# Branch values of a complex power

↑ **Parent:** [Complex exponentiation](complex-exponentiation.md)

For $w\ne0$, different [complex logarithm](complex-logarithm.md) values differ by $2\pi ik$. Applying the [exponential function](exponential-function.md) gives the displayed multivalued power. Selecting a single logarithm branch gives one value. When $z=i$, successive branch values differ by the positive factor $e^{-2\pi}$ and lie on one ray of fixed argument $\ln|w|$. If this factor is not one, the nonzero values accumulate at zero in one direction of the integer index.
