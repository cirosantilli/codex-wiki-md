# Finite type CW approximation

↑ **Parent:** [CW approximation](cw-approximation.md)

For simply connected $X$ with finitely generated integral [homology](homology-split.md) in every degree, the [Hurewicz theorem modulo a Serre class](hurewicz-theorem-modulo-a-serre-class.md) gives finitely generated [homotopy groups](homotopy-group.md). Realize finite generating sets of successive relative [homotopy groups](homotopy-group.md) by attaching finitely many cells at each stage. The resulting weak equivalence has finitely many cells in each dimension.
