# Swap

↑ **Parent:** [Array (data structure)](array-data-structure.md)

Exchange two stored values while preserving all others. For an [array](array-data-structure.md), a temporary value implements `x := a[i]; a[i] := a[j]; a[j] := x`. For distinct indices this uses two element reads and two element writes. The operation is an [involution](involution.md), and its [permutation](permutation.md) is a [transposition](transposition-permutation.md).
