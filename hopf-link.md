# Hopf link

↑ **Parent:** [Link](link.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hopf_link)

The Hopf link consists of two [unknots](unknot.md) with [linking number](linking-number.md) $\pm1$. Each component is a [meridian of a knot](meridian-of-a-knot.md) of the other.
