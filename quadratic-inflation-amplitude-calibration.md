# Quadratic-inflation amplitude calibration

↑ **Parent:** [Quadratic-potential slow-roll solution](quadratic-potential-slow-roll-solution.md)

For a quadratic potential with the end set by $\epsilon_V=1$, a mode leaving $N$ e-folds earlier has $\phi_*^2=(4N+2)M_{\rm pl}^2$. Its curvature amplitude is $(m/M_{\rm pl})^2(2N+1)^2/(24\pi^2)$. Thus the scalar amplitude fixes the [inflaton](inflaton.md) mass while the tilt and tensor ratio depend only on the exit e-fold count at this order.
