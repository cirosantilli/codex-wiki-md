# Lebesgue null set

↑ **Parent:** [Null set](null-set.md)

A Lebesgue null set has zero [Lebesgue measure](lebesgue-measure.md). Since [Lebesgue measure](lebesgue-measure.md) is complete, every [subset](subset.md) of one is also measurable and null. The [Cantor set](cantor-set.md) is an [uncountable](uncountable-set.md) example with positive [Hausdorff dimension](hausdorff-dimension.md); the [rational numbers](rational-number.md) form a [countable](countable-set.md), [dense](dense-set.md) example with [Hausdorff dimension](hausdorff-dimension.md) zero. Being null does not imply being empty or having finitely many points.
