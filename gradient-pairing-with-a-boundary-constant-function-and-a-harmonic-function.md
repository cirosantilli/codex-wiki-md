# Gradient pairing with a boundary-constant function and a harmonic function

↑ **Parent:** [Green's first identity](green-s-first-identity.md)

If $f$ is constant on the boundary and $g$ is a regular [harmonic function](harmonic-function.md) throughout a volume, the [divergence theorem](divergence-theorem.md) applied to $f\nabla g$ gives $\int_V\nabla f\cdot\nabla g=\int_{\partial V}f\partial_ng$. The constant boundary value factors out; a second application of the divergence theorem makes the remaining flux $\int_V\Delta g=0$. This requires enough regularity to use [Green's first identity](green-s-first-identity.md) over the entire volume.
