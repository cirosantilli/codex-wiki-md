# Hoare triple

↑ **Parent:** [Hoare logic](hoare-logic.md)

A [partial correctness](partial-correctness.md) claim connecting a [precondition](precondition.md) $P$, a program $C$ and a [postcondition](postcondition.md) $Q$: every terminating execution begun with $P$ ends with $Q$. State separately whether [total correctness](total-correctness.md) is intended.
