# Double dual module

↑ **Parent:** [Dual module](dual-module.md)

The double dual module is $M^{**}=\operatorname{Hom}_R(M^*,R)$. The [evaluation homomorphism](evaluation-homomorphism.md) sends $m\in M$ to the functional $f\mapsto f(m)$.
