# Principal component analysis on a correlation matrix

↑ **Parent:** [Principal component analysis](principal-component-analysis.md)

For positive marginal [variances](variance-split.md), standardizing each variable to [variance](variance-split.md) one converts covariance-based [PCA](principal-component-analysis.md) on $Z$ into correlation-based PCA on $X$. This makes the analysis insensitive to the original measurement units but changes the optimization criterion. Standardization gives small-variance variables the same marginal weight as large-variance variables; it is a modelling choice, not an automatic improvement.
