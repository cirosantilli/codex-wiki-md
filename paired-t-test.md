# Paired t-test

↑ **Parent:** [Student's t-test](student-s-t-test.md)

A one-sample [Student t-test](student-s-t-test.md) on independent pairs' differences $d_i$. It tests a specified mean difference $d_0$, using the [standard deviation](standard-deviation.md) of those differences rather than treating both measurements in a pair as independent. Exact small-sample inference assumes normally distributed differences.
