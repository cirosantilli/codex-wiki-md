# Invariant set of a measure-preserving transformation

↑ **Parent:** [Invariant sigma-algebra](invariant-sigma-algebra.md)

A measurable set $A$ satisfying $T^{-1}A=A$, or equality modulo null sets in the measure-theoretic convention. These sets form a $\sigma$-algebra, and an [ergodic measure-preserving transformation](ergodicity.md) gives each invariant set probability zero or one.
