# Polynomial space

↑ **Parent:** [Space complexity](space-complexity.md)

An algorithm uses polynomial space if its working memory is bounded by a fixed polynomial in the input length. Exponentially many possibilities can still be searched when each candidate and the search counter need polynomial space and storage is reused. The decision problems with deterministic polynomial-space algorithms form [PSPACE](pspace.md).
