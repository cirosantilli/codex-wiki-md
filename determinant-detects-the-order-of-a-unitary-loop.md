# Determinant detects the order of a unitary loop

↑ **Parent:** [Unitary group](unitary-group.md)

The determinant $U(n)\to S^1$ sends a unitary loop to a circle-valued loop. A nonzero determinant winding number proves that the original loop class has infinite order.
