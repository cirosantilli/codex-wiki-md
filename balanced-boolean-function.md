# Balanced Boolean function

↑ **Parent:** [Boolean function](boolean-function.md)

A [Boolean function](boolean-function.md) on a finite nonempty domain is balanced when it is zero on exactly half the inputs and one on the other half. For a one-[bit](bit.md) domain, the balanced functions are $f(x)=x$ and $f(x)=1⊕x$, while the remaining two functions are [constant functions](constant-function.md). The [Deutsch algorithm](deutsch-algorithm.md) distinguishes these two classes with one [Boolean quantum oracle](boolean-quantum-oracle.md) query in the absence of noise.
