# Incidence matrix of a set system

↑ **Parent:** [Set family](set-family.md)

For a finite ground [set](set-split.md) and an indexed [set family](set-family.md), this zero-one [matrix](matrix.md) records membership of points in members. The diagonal entries of $B^TB$ are member sizes, and its off-diagonal entries count pairwise [intersections](set-intersection.md). For the [Fano plane](fano-plane.md), either point-line orientation gives the identity $B^TB=2I+J$, since every point lies on three lines and each distinct point pair lies on one line.
