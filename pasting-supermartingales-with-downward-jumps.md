# Pasting supermartingales with downward jumps

↑ **Parent:** [Supermartingale](supermartingale.md)

If two [supermartingales](supermartingale.md) satisfy $X_N^1\geq X_N^2$ on the event that the [stopping time](stopping-time.md) $N$ is finite, the displayed pasted [adapted process](adapted-process.md) is a [supermartingale](supermartingale.md). On $\{N>n\}$ its next value is at most $X_{n+1}^1$, because a possible switch at $n+1$ only decreases it. On $\{N\leq n\}$ it follows the second [supermartingale](supermartingale.md). Conditioning these inequalities proves the assertion. Finite repeated pastings inherit the same property, allowing a multiplicative trading construction for [upcrossings](upcrossing.md).
