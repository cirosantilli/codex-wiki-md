# Null recurrent Markov chain

↑ **Parent:** [Recurrent Markov chain](recurrent-markov-chain.md)

An [irreducible Markov chain](irreducible-markov-chain.md) is null recurrent when every state is a [null recurrent state](null-recurrent-state.md): it returns to that state [almost surely](almost-sure-convergence.md), but its [mean recurrence time](mean-recurrence-time.md) is infinite. Such a countable-state chain has no [stationary distribution](stationary-distribution.md).
