# Modalized occurrence

↑ **Parent:** [Modal logic](modal-logic.md)

An occurrence of a propositional variable in a modal formula is modalized if it lies within the scope of a box operator. A variable occurs modalized in a formula when all its occurrences do. For example $p$ is modalized in $\Box p\to q$, while $q$ is not. Fixed-point and uniqueness theorems for [Gödel-Löb logic](godel-lob-logic.md) impose this syntactic condition on the variable being solved for.
