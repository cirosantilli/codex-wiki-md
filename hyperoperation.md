# Hyperoperation

↑ **Parent:** [Exponentiation](exponentiation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hyperoperation)

The [hyperoperation](hyperoperation.md) hierarchy successively iterates basic arithmetic operations. In the usual indexing, successor is followed by [addition](addition.md), [multiplication](multiplication.md), [exponentiation](exponentiation.md) and their higher iterates. A sequence beginning with addition shifts this index by one. Each fixed rank is a [primitive recursive function](primitive-recursive-function.md); this does not imply that the evaluator taking the rank as an additional variable is [primitive recursive](primitive-recursive-function.md).
