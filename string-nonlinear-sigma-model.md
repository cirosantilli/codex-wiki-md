# String nonlinear sigma model

↑ **Parent:** [Polyakov action](polyakov-action.md)

The string nonlinear sigma model couples the worldsheet embedding fields to target-space backgrounds such as a metric, a [Kalb–Ramond field](kalb-ramond-field.md) and a [dilaton](dilaton.md). Quantum Weyl invariance requires its beta functions to vanish.
