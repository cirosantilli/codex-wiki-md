# Lattice path

↑ **Parent:** [Combinatorics](combinatorics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lattice_path)

A lattice path is a sequence of points in an integer lattice whose consecutive differences belong to a prescribed finite set of steps.

For instance, a [north-east lattice path](north-east-lattice-path.md) uses only unit steps east or north in the [integer lattice](integer-lattice.md) $\mathbb Z^2$. Restricting the allowed steps makes the counting question precise: the endpoint fixes how many of each step must occur, but their order remains free. [Pascal's rule](pascal-s-rule.md) counts these [lattice paths](lattice-path.md) by their last step; the same [binomial coefficient](binomial-coefficient-split.md) counts selections of step positions.
