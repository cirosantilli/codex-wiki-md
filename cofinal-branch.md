# Cofinal branch

↑ **Parent:** [Set-theoretic tree](set-theoretic-tree.md)

A maximal chain with nodes at unbounded heights in a [set-theoretic tree](set-theoretic-tree.md). Taking predecessor closure gives one node at each level below the tree height.
