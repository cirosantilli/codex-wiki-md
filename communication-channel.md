# Communication channel

↑ **Parent:** [Information theory](information-theory-split.md)

A communication channel describes how transmitted inputs become received outputs. In a probabilistic model, [conditional probabilities](conditional-probability.md) specify which outputs each input can produce. A [discrete memoryless channel](discrete-memoryless-channel.md) uses the same finite transition law independently on successive symbols; [channel capacity](channel-capacity.md) quantifies its optimal reliable transmission rate.
