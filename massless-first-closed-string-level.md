# Massless first closed-string level

↑ **Parent:** [Bosonic string mass spectrum](bosonic-string-mass-spectrum.md)

In the critical [bosonic string theory](bosonic-string-theory.md), the states $\alpha_{-1}^i\widetilde\alpha_{-1}^j|0;p\rangle$ have $M^2=0$. Their coefficient matrix decomposes into a symmetric trace-free tensor, an antisymmetric tensor, and a scalar trace, representing the [graviton](graviton.md), [Kalb–Ramond field](kalb-ramond-field.md), and [dilaton](dilaton.md). Their transverse [particle polarization](particle-polarization.md) counts add to $(D-2)^2$. The [normal-ordering constant of a string](normal-ordering-constant-of-a-string.md) is one.
