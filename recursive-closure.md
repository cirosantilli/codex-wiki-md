# Recursive closure

↑ **Parent:** [Closure (computer programming)](closure-computer-programming.md)

A [programming closure](closure-computer-programming.md) whose defining [semantic environment](semantic-environment.md) contains a binding for that same [programming closure](closure-computer-programming.md). In a host with [lazy evaluation](lazy-evaluation.md), this can be represented by a recursive data definition without first running the function's body.
