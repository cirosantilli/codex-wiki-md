# Induced subgraph game

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

A [transferable utility game](transferable-utility-game.md) represented by a weighted [undirected graph](undirected-graph.md), with one player per [graph vertex](vertex-graph-theory.md). A [coalition](coalition-game-theory.md) receives the sum of weights of the [graph edges](edge-of-a-graph.md) in its [induced subgraph](induced-subgraph.md); absent edges have weight zero. Singleton and empty [coalitions](coalition-game-theory.md) have value zero. This is a representation of a [transferable utility game](transferable-utility-game.md), distinct from a graphical description of local [payoffs](payoff.md) in a [normal-form game](normal-form-game.md).
