# Finite symmetric difference

↑ **Parent:** [Symmetric difference](symmetric-difference.md)

Two [sets](set-split.md) differ by finite symmetric difference when only finitely many points belong to exactly one of them. This is an [equivalence relation](equivalence-relation.md), since $A\mathbin\triangle C\subseteq(A\mathbin\triangle B)\cup(B\mathbin\triangle C)$.
