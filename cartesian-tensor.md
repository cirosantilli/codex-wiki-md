# Cartesian tensor

↑ **Parent:** [Tensor](tensor.md)

A Cartesian tensor has components in each [orthonormal basis](orthonormal-basis.md) of a [Euclidean space](euclidean-norm.md), related by the displayed rule under an orthogonal component change $R$. Each index contributes one transformation matrix. The Euclidean inner product identifies upper and lower indices in orthonormal coordinates, so the distinction between covariant and contravariant components does not change this rule. An [isotropic tensor](isotropic-tensor.md) has unchanged components under all proper [rotations](rotation-mathematics.md); requiring invariance under reflections as well excludes the ordinary odd-parity cases. A [Cartesian second-rank tensor](cartesian-second-rank-tensor.md) is the matrix case, with transformation $T'=RTR^T$.
