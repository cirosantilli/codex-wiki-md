# Magic Shrinking Machine memory task

↑ **Parent:** [Autobiographical memory](autobiographical-memory.md)

[Children](child.md) experience a distinctive apparatus that appears to produce smaller versions of toys, and later receive verbal recall, recognition or reenactment tests. Measuring vocabulary at the original event helps separate retained content from what the [child](child.md) can later express verbally.[Psychological Science 13, 225–231; Magic Shrinking Machine, verbal and nonverbal tests](breaking-the-barrier-children-fail-to-translate-their-preverbal-memories-into-language-by-gabrielle-simcock-and-harlene-hayne.md)
