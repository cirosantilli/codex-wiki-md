# Tiny object

↑ **Parent:** [Cartesian closed category](cartesian-closed-category.md)

An object $A$ of a [Cartesian closed category](cartesian-closed-category.md) is tiny when exponentiation $(-)^A$ itself has a right adjoint.

The extra adjunction defining a tiny object should not be confused with the filtered-colimit condition for a [compact object (mathematics)](compact-object-mathematics.md).
