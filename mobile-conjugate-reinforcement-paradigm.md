# Mobile conjugate reinforcement paradigm

↑ **Parent:** [Operant conditioning](operant-conditioning.md)

A ribbon links an [infant](infant.md)’s ankle to a mobile so kicking produces visible movement. Baseline kicking and a later nonreinforced test permit assessment of a learned contingency. A reminder moving the familiar mobile can reactivate later performance; the crucial control asks whether reminder exposure alone teaches the response.[Science 208, 1159–1161; mobile conditioning, reminder and retention experiments](reactivation-of-infant-memory-by-carolyn-rovee-collier-and-others.md)
