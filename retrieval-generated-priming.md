# Retrieval-generated priming

↑ **Parent:** [Stimulus priming](stimulus-priming.md)

In the [SOP model](sop-model.md), an associated cue or context activates elements of an expected event into secondary activation before that event occurs. It is conceptually distinct from residual activation caused by recent presentation of the event itself.
