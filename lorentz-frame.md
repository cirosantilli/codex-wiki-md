# Lorentz frame

↑ **Parent:** [Normal coordinates](normal-coordinates.md)

A [Lorentz frame](lorentz-frame.md) at a spacetime event is an orthonormal tangent basis with metric $\operatorname{diag}(-1,1,1,1)$. Future-oriented frames are related by proper orthochronous [Lorentz transformations](lorentz-transformation.md). Any such basis can be realized at the event by [normal coordinates](normal-coordinates.md).
