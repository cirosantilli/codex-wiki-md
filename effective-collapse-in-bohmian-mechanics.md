# Effective collapse in Bohmian mechanics

↑ **Parent:** [Conditional wave function](conditional-wave-function.md)

If total-wave branches become disjoint in the relevant environment configuration variables and the actual environment lies within one branch, the subsystem's [conditional wave function](conditional-wave-function.md) is proportional to that branch's subsystem factor. Persistent separation makes its autonomous use an effective description. No term of the universal [wave function](wave-function-split.md) has literally been deleted. Possible recombination prevents treating every temporary packet separation as irreversible collapse.[sections 2.2–2.3](quantum-equilibrium-and-the-role-of-operators-as-observables-in-quantum-theory-by-detlef-durr-and-others.md)
