# Static closed cosmic-string universe

↑ **Parent:** [Cosmic string network](cosmic-string-network.md)

A closed universe containing only a [cosmic string network](cosmic-string-network.md) can remain static. Its [Friedmann acceleration equation](friedmann-acceleration-equation.md) vanishes identically because $P_s=-\rho_s/3$, and its [Friedmann equation](friedmann-equations.md) requires $\rho_s a^2=3K/(8\pi G)$. Once this conserved normalization is tuned, every positive radius gives a static solution. The usual Hubble-normalized [cosmological density parameter](cosmological-density-parameter.md) is undefined at a static epoch.
