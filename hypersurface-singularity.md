# Hypersurface singularity

↑ **Parent:** [Singular point of an algebraic variety](singular-point-of-an-algebraic-variety.md)

A point on $F=0$ where all first partial derivatives vanish. For a reduced hypersurface this is the [Jacobian criterion](jacobian-criterion.md); a nondegenerate quadratic leading part defines an [ordinary double point](ordinary-double-point.md).
