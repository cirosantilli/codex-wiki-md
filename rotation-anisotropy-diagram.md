# Rotation-anisotropy diagram

↑ **Parent:** [Oblate isotropic rotator](oblate-isotropic-rotator.md)

A rotation-anisotropy diagram compares ordered rotation divided by [velocity dispersion](velocity-dispersion.md) with a [galaxy](galaxy-split.md)'s flattening. An [oblate isotropic rotator](oblate-isotropic-rotator.md) provides a reference curve. Falling below it can indicate anisotropic random support, but inclination, measurement apertures, and the definition of rotation change the interpretation. Intrinsic axis ratios and projected ellipticities are different observables.
