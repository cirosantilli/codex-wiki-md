# Left closed monoidal category

↑ **Parent:** [Monoidal category](monoidal-category.md)

Using the convention $-\otimes M\dashv[M,-]$, every tensoring-on-the-right functor has a right [adjoint functor](adjoint-functors.md). Evaluation is $[M,N]\otimes M\to N$. Naming left and right closure varies in the literature, so the adjunction fixes the convention.
