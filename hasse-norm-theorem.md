# Hasse norm theorem

↑ **Parent:** [Class field theory](class-field-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hasse_norm_theorem)

For a cyclic extension of [number fields](number-field.md), an element of the base field is a global [field norm](field-norm.md) exactly when it is a norm at every finite and infinite completion. The [splitting criterion for a cyclic algebra](splitting-criterion-for-a-cyclic-algebra.md) encodes the norm obstruction as a [Brauer group](brauer-group.md) class. The [Albert-Brauer-Hasse-Noether theorem](albert-brauer-hasse-noether-theorem.md) makes a class that splits at every completion split globally, giving the result. Cyclicity is essential; arbitrary noncyclic extensions can have additional local-global norm obstructions.
