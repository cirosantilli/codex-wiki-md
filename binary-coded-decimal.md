# Binary-coded decimal

↑ **Parent:** [Digital electronics](digital-electronics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Binary-coded_decimal)

Represent a decimal number by coding each [decimal digit](decimal-digit.md) separately as four [bits](bit.md) of weights $8,4,2,1$. The codes 10–15 are unused for one digit; a [Boolean circuit](boolean-circuit.md) must specify whether these combinations produce a defined result or are [don't-care conditions](don-t-care-term.md).
