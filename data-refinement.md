# Data refinement

↑ **Parent:** [Abstract data type](abstract-data-type.md)

Implementation of an abstract state and operations using a more concrete representation, justified by a [coupling invariant](coupling-invariant.md). For example, an insertion-history [list](list-abstract-data-type.md) may be implemented by a [sorted array](sorted-array.md) when clients observe only occurrence counts and [order statistics](order-statistic.md). The observable behavior, rather than insertion order internally, must agree.
