<h1 id="herbrand-s-theorem">Herbrand's theorem</h1>

↑ **Parent:** [Herbrand model](herbrand-model.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Herbrand's_theorem)

A set of universally quantified equality-free [first-order clauses](first-order-clause.md) is unsatisfiable if and only if some finite set of its ground instances is propositionally unsatisfiable. Equivalently, such a set is satisfiable if and only if it has a [Herbrand model](herbrand-model.md). General [first-order sentences](first-order-sentence.md) can first undergo [Skolemization](skolemization.md). A fresh constant is added if needed to make the [Herbrand universe](herbrand-universe.md) nonempty; [first-order equality](logical-equality.md) requires its corresponding equality treatment.
