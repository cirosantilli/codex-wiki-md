# System temperature

↑ **Parent:** [Radio astronomy](radio-astronomy.md)

The equivalent input noise [temperature](temperature-split.md) of the antenna-plus-receiver system is defined by available noise [power](power.md) $P_n=k_BT_{\rm sys}\Delta\nu$ in one matched [polarization of waves](polarization-waves.md) mode. It includes receiver noise and the appropriate sky and instrumental contributions. It is not generally the physical [temperature](temperature-split.md) of a single component.
