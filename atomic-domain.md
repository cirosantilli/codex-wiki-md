# Atomic domain

↑ **Parent:** [Integral domain](integral-domain.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Atomic_domain)

An atomic domain is an [integral domain](integral-domain.md) in which every nonzero nonunit is a finite product of [irreducible elements](irreducible-element.md). Every [unique factorization domain](unique-factorization-domain.md) is atomic, but atomicity alone does not imply uniqueness.
