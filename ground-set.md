# Ground set

↑ **Parent:** [Independence system](independence-system.md)

The [ground set](ground-set.md) is the [set](set-split.md) of labelled elements available for selection. An [independence system](independence-system.md) specifies which [subsets](subset.md) of this [ground set](ground-set.md) are admissible; in a [linear matroid](linear-matroid.md) the labels index [vectors](vector.md), whereas in a [graphic matroid](graphic-matroid.md) they index [edges](edge-of-a-graph.md).
