# Seasonal difference operator

↑ **Parent:** [Differencing](differencing.md)

For an integer period $S$, $\Delta_SX_t=X_t-X_{t-S}$ uses the [backshift operator](backshift-operator.md) as $1-B^S$. It annihilates a deterministic period-$S$ mean. If $X_t=m_t+\varepsilon_t$ with $m_{t+S}=m_t$ and [strong white noise](strong-white-noise.md), the result is the stationary moving average $\varepsilon_t-\varepsilon_{t-S}$.
