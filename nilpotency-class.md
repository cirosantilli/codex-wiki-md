# Nilpotency class

↑ **Parent:** [Nilpotent group](nilpotent-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nilpotency_class)

The nilpotency class of a [nilpotent group](nilpotent-group.md) $G$ is the least nonnegative integer $s$ for which $\gamma_{s+1}(G)=\{1\}$ in the [lower central series](lower-central-series.md). Thus nontrivial [abelian groups](abelian-group.md) have class one.
