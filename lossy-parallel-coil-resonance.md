# Lossy parallel coil resonance

↑ **Parent:** [Electrical impedance](electrical-impedance.md)

A [series circuit](series-circuit.md) comprising [electrical resistance](electrical-resistance.md) $R>0$ and [inductance](inductance.md) $L>0$, placed in a [parallel circuit](parallel-circuit.md) with [capacitance](capacitance.md) $C>0$, has [electrical admittance](electrical-admittance.md) $Y=(R+i\omega L)^{-1}+i\omega C$. Vanishing [imaginary part](imaginary-part.md) at nonzero [angular frequency](angular-frequency.md) gives the displayed condition, requiring $L>R^2C$. It defines zero voltage-current [phase difference](phase-difference.md), which need not coincide exactly with the maximum of impedance magnitude when loss is present. At this frequency the [electrical impedance](electrical-impedance.md) is real and equals $L/(RC)$.
