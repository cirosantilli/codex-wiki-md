# Scientific underdetermination

↑ **Parent:** [Philosophy of science](philosophy-of-science.md)

An evidential situation in which rival scientific accounts remain compatible with the relevant evidence. Agreement with the observations so far is weaker than [empirical equivalence](empirical-equivalence.md) across all possible observations in a stated domain.
