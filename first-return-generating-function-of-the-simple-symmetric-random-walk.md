# First-return generating function of the simple symmetric random walk

↑ **Parent:** [Simple symmetric random walk](simple-symmetric-random-walk.md)

For the [simple symmetric random walk](simple-symmetric-random-walk.md) on $\mathbb Z$, the [renewal equation](renewal-equation.md) relates first-return and return [probability generating functions](probability-generating-function.md). The central-binomial return series is $U(s)=(1-s^2)^{-1/2}$, giving $F(s)=1-U(s)^{-1}$. Its value tends to one at $s=1$, but its derivative diverges there: the walk has [null recurrent states](null-recurrent-state.md).
