# Finite additivity of a set function

↑ **Parent:** [Set function](set-function.md)

A real-valued [set function](set-function.md) on an algebra of sets is finitely additive if it has the displayed property for disjoint pairs. It follows that $F(\varnothing)=0$. On a finite ambient [set](set-split.md), induction gives $F(A)=\sum_{x\in A}F(\{x\})$, so arbitrary signed singleton weights describe all such functions. Summing the pointwise [indicator function](indicator-function.md) identity for the [inclusion-exclusion principle](inclusion-exclusion-principle.md) against these weights proves the same formula for $F$.
