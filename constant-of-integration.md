# Constant of integration

↑ **Parent:** [Antiderivative](antiderivative.md)

If $F'=f$ on a connected interval, every other antiderivative is $F+C$ for a constant $C$. Indeed $(G-F)'=0$, so the [mean value theorem](mean-value-theorem.md) makes $G-F$ constant. A boundary condition fixes $C$. For example $T'=-B/r^2$ integrates to $T=B/r+C$, and $T(R_s)=T_s$ gives $C=T_s-B/R_s$. Discarding an integration constant therefore needs an actual boundary condition or an approximation showing that its effect is small.
