# C integer division

↑ **Parent:** [Integer division](integer-division.md)

For representable integer quotients with nonzero divisor, [C integer division](c-integer-division.md) discards the fractional part towards zero and defines the remainder by $a=bq+r$. Thus a nonzero remainder has the dividend's sign. For example, $-13=5(-2)+(-3)$, so division by five returns quotient $-2$ and remainder $-3$. This convention differs from division rounded down, which would return quotient $-3$ and nonnegative remainder $2$. Division by zero and an unrepresentable quotient are excluded.[section 6.5.5 paragraphs 5–6](c11-committee-draft-n1570.md)
