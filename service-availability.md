# Service availability

↑ **Parent:** [Fault tolerance](fault-tolerance.md)

For an observation period of duration $T>0$, let $T_{\mathrm{up}}$ be the total time during which a service meets a specified condition. Its measured [service availability](service-availability.md) is $A=T_{\mathrm{up}}/T$. The condition must say which operation can be performed: accepting a new user and serving an already admitted user can have different dependencies. A [mandatory service dependency](mandatory-service-dependency.md) can reduce [service availability](service-availability.md) even when all data copies remain intact.
