# Linear innovation process

↑ **Parent:** [Innovation process](innovation-process.md)

For a square-integrable [time series](time-series-split.md), let $\mathcal H_{t-1}$ be the closed linear span of its past. The innovation $\varepsilon_t=X_t-\operatorname{proj}_{\mathcal H_{t-1}}X_t$ is orthogonal to every past linear observation. A causal invertible [autoregressive moving-average model](autoregressive-moving-average-model.md) is driven by these innovations, which are [weak white noise](weak-white-noise.md) for a [weakly stationary process](weakly-stationary-process.md).
