# Wilson factorial congruence modulo a triangular number

↑ **Parent:** [Wilson's theorem](wilson-s-theorem.md)

For an odd [prime number](prime-number.md) $p$, put $m=(p-1)/2$. Both $(p-1)!$ and $p-1$ are divisible by $m$. By [Wilson's theorem](wilson-s-theorem.md), they are also congruent modulo $p$, because each is $-1$ modulo $p$. The [coprime integers](coprime-integers.md) $m,p$ therefore both divide their difference, giving the displayed [integer congruence](integer-congruence.md). This combines the prime-modulus factorial identity with an elementary divisibility constraint.
