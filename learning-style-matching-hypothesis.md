# Learning-style matching hypothesis

↑ **Parent:** [Learning styles](learning-styles.md)

The hypothesis that matching instructional format to a learner's assessed style improves [learning](learning.md) relative to mismatching. It requires an appropriate preference-by-format comparison, not merely a preference questionnaire or a format main effect.
