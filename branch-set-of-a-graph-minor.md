# Branch set of a graph minor

↑ **Parent:** [Graph minor](graph-minor.md)

A branch set is a nonempty set of [vertices](vertex-graph-theory.md) inducing a [connected graph](connected-graph.md) used to represent one [vertex](vertex-graph-theory.md) of a [graph minor](graph-minor.md). A $K_t$ [graph minor](graph-minor.md) is equivalent to $t$ disjoint branch sets with at least one [edge](edge-of-a-graph.md) between every pair. Connectedness allows each set to be reduced to a single [vertex](vertex-graph-theory.md) by [edge contractions](edge-contraction.md).
