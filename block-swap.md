# Block swap

↑ **Parent:** [Swap](swap.md)

Exchange two equally long disjoint segments of an [array](array-data-structure.md), preserving the order within each segment. Applying one [swap](swap.md) at each corresponding offset exchanges length-$n$ blocks in $n$ swaps and constant auxiliary storage. Disjointness ensures that an earlier swap does not overwrite an original value needed by a later pair.
