# Grassmann variable

↑ **Parent:** [Grassmann algebra](grassmann-algebra.md)

A Grassmann variable is an odd generator $\theta$ of a [Grassmann algebra](grassmann-algebra.md). In characteristic zero it obeys $\theta^2=0$, so functions of finitely many Grassmann variables have finite Taylor expansions.
