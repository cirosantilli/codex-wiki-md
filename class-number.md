# Class number

↑ **Parent:** [Ideal class group](ideal-class-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Class_number)

The class number of a number field is the order $h_K=|\operatorname{Cl}(K)|$ of its [ideal class group](ideal-class-group.md).
