# Skorokhod reflection map on the half-line

↑ **Parent:** [Skorokhod problem](skorokhod-problem.md)

For a [continuous](continuous-function.md) driving path with $g(0)\ge0$, the running supremum supplies the minimal nondecreasing regulator keeping the path nonnegative. It increases only at a new negative running minimum, where the reflected path is zero. Any regulator satisfying the [Skorokhod problem](skorokhod-problem.md) constraints must coincide with it. On a finite time interval, $\|\Gamma(g)-\Gamma(h)\|_\infty\le2\|g-h\|_\infty$, so the map is continuous and transfers a [functional central limit theorem](donsker-s-theorem.md) to reflected workloads.
