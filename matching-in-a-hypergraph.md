# Matching in a hypergraph

↑ **Parent:** [Hypergraph](hypergraph-split.md)

A [matching in a hypergraph](matching-in-a-hypergraph.md) is a family of pairwise vertex-disjoint [hypergraph edges](edge-of-a-hypergraph.md). A perfect [matching in a hypergraph](matching-in-a-hypergraph.md) covers every vertex; an almost-perfect [matching in a hypergraph](matching-in-a-hypergraph.md) leaves a small proportion uncovered. In a proper edge colouring, each colour class is a [matching in a hypergraph](matching-in-a-hypergraph.md).
