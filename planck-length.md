# Planck length

↑ **Parent:** [Planck mass](planck-mass.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Planck_length)

The Planck length is $\ell_P=\sqrt{\hbar G/c^3}$. Together with the [Planck mass](planck-mass.md) $m_P=\sqrt{\hbar c/G}$ it satisfies $Gm_P/c^2=\ell_P$.
