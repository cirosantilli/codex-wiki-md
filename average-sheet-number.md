# Average sheet number

↑ **Parent:** [Ahlfors covering surface theory](ahlfors-covering-surface-theory.md)

For a [holomorphic map](holomorphic-map.md) between metric [Riemann surfaces](riemann-surfaces.md), the average sheet number is the pulled-back source area divided by the target area. The [area formula](area-formula-geometric-measure-theory.md) identifies it with the average number of preimages counted with [multiplicity](multiplicity-mathematics.md). The same definition over a target region $D$ gives $S_D=A_f(f^{-1}D)/A(D)$.
