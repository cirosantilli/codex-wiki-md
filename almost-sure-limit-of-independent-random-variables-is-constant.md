# Almost-sure limit of independent random variables is constant

↑ **Parent:** [Complete convergence of random variables](complete-convergence-of-random-variables.md)

If [independent random variables](independent-random-variables.md) $X_n$ converge almost surely to a finite $X$, then $\limsup_nX_n$ is measurable for the [tail sigma-algebra](tail-sigma-algebra.md). The [Kolmogorov zero-one law](kolmogorov-s-zero-one-law.md) forces every rational threshold event for that limit to have probability zero or one. A real-valued [probability distribution](probability-distribution-split.md) with this property is a point mass, so $X$ is almost surely constant. Consequently the [Second Borel-Cantelli lemma](borel-cantelli-second-lemma.md) upgrades almost sure convergence of independent sequences to [complete convergence](complete-convergence-of-random-variables.md).
