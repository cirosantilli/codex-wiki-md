# Conservativity of set products on totally supported families

↑ **Parent:** [Power of sets as a capital regular category](power-of-sets-as-a-capital-regular-category.md)

If some $f_i$ is not injective, extend two distinct equal-image elements to tuples using common choices at all other coordinates; the product is not injective. If some $f_i$ is not surjective, extend a missing target element to a tuple; the product is not surjective. The [axiom of choice](axiom-of-choice.md) supplies these extensions. Thus the set-product [functor](functor.md) reflects [isomorphisms](isomorphism.md) between families whose coordinates are all nonempty.
