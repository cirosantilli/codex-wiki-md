# Coefficient matrix

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

For a [linear system](system-of-linear-equations.md) $\sum_j a_{ij}x_j=b_i$, the coefficient matrix $A$ contains the coefficients of the unknowns, with one row per equation and one column per unknown. The system becomes $A\mathbf x=\mathbf b$. The [augmented matrix](augmented-matrix.md) $[A\mid\mathbf b]$ additionally includes the right-hand-side column; that column is not part of $A$.
