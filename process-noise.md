# Process noise

↑ **Parent:** [State estimation](state-estimation.md)

[Process noise](process-noise.md) is the random contribution to a state transition in a [state-space model](state-space-model-time-series.md). It represents uncertainty in how the state evolves. [Measurement noise](measurement-noise.md) instead affects the observed value of the state. In the [local-level state-space model](local-level-state-space-model.md) $x_t=x_{t-1}+w_t$, $y_t=x_t+v_t$, the first disturbance changes the state itself; the second changes its measurement.
