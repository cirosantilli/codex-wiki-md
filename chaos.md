# Chaos

↑ **Parent:** [Dynamical systems](dynamical-systems-split.md)

[Chaos](chaos.md) describes sustained irregular dynamics with sensitive dependence in a deterministic system. The precise convention matters. [Devaney chaos](devaney-chaos.md) requires [topological transitivity](topological-transitivity.md), dense [periodic orbits](periodic-orbit.md) and sensitive dependence on an [invariant set](invariant-set-of-a-measure-preserving-transformation.md). A common operational flow description asks for bounded nonperiodic long-term motion with sensitive dependence. These formulations are useful in different settings and are not universally equivalent. A positive largest [Lyapunov exponent](lyapunov-exponent.md) is a numerical diagnostic of exponential separation, not by itself a proof of every topological definition.
