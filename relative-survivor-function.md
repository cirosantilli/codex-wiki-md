# Relative survivor function

↑ **Parent:** [Relative survival](relative-survival.md)

Under the additive [hazard function](hazard-function.md) model $h^{(i)}=h_B^{(i)}+h_E$, the [survivor function](survival-function.md) factorization gives $F_E=F^{(i)}/F_B^{(i)}$, independently of $i$. If the [excess hazard](excess-hazard.md) is nonnegative, this has a survival-probability interpretation for a hypothetical process with just that hazard. If [excess hazards](excess-hazard.md) are negative, [relative survival](relative-survival.md) can exceed one and is a comparison ratio rather than an ordinary [survivor function](survival-function.md).
