# Balanced two-mode fermion antibunching

↑ **Parent:** [Pauli exclusion principle](pauli-exclusion-principle.md)

One identical [fermion](fermion.md) in each of two input modes remains one in each output after a lossless two-mode unitary transformation. The fully occupied two-mode state transforms by the [determinant](determinant.md) phase. Pauli exclusion prevents double occupation of either specified mode.
