# Capacity miss

↑ **Parent:** [Cache miss](cache-miss.md)

A repeated [cache block](cache-line.md) access that misses even in the comparison [fully associative cache](fully-associative-cache.md) of the same capacity and [cache line](cache-line.md) size using [LRU replacement](lru-replacement.md). In the [memory cache](cache-computing.md) example these are reads 6, 7 and 11. The replacement assumption matters to this classification.
