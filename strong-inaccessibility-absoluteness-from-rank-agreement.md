# Strong-inaccessibility absoluteness from rank agreement

↑ **Parent:** [Set-theoretic absoluteness](set-theoretic-absoluteness.md)

If transitive models of enough set theory contain the same $V_{\alpha+1}$, then they agree on whether $\alpha$ is a [strongly inaccessible cardinal](strongly-inaccessible-cardinal.md). They have the same subsets and functions on every ordinal below $\alpha$, so they agree on [cardinality](cardinal-number.md), [regularity](regular-cardinal.md), and the [strong limit cardinal](strong-limit-cardinal.md) property.
