# Set shattering

↑ **Parent:** [Trace of a set family](trace-of-a-set-family.md)

A [set family](set-family.md) shatters $Z$ when every subset of $Z$ occurs as a [trace of a set family](trace-of-a-set-family.md). The largest finite shattered-set size is its [VC dimension](vc-dimension.md). The [Sauer-Shelah lemma](sauer-shelah-lemma.md) bounds the number of traces when no set of a given size is shattered.
