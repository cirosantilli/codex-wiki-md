# Metal cluster

↑ **Parent:** [Coordination chemistry](coordination-chemistry.md)

A [metal cluster](metal-cluster.md) contains several connected [metal](metal.md) centers. A triangular three-[metal cluster](metal-cluster.md) can support three edge [metal-metal bonds](metal-metal-bond.md); early-[metal](metal.md) clusters often have stable counts below the [18-electron rule](18-electron-rule.md).
