# Transverse spin order in a number eigenstate

↑ **Parent:** [Long-range order](long-range-order.md)

For a [two-species uniform boson number state](two-species-uniform-boson-number-state.md), set $S_i^+=a_i^\dagger b_i$. A single [spin ladder operator](spin-ladder-operator.md) changes the species [occupation numbers](occupation-number.md), so its [expectation value](expectation-value.md) vanishes. At distinct sites, $\langle S_i^+S_j^-\rangle=n_An_B/L^2$, proving the displayed transverse [two-point correlation function](two-point-correlation-function.md). For $n_A/L,n_B/L$ tending to nonzero constants, this [correlation function](correlation-function.md) has a nonzero large-distance limit despite the global [U(1)](circle-group.md) [symmetry](symmetry-physics.md). This diagnoses [long-range order](long-range-order.md) in the auxiliary state; its interpretation as a state of fixed physical [spins](spin.md) still requires the [Schwinger boson constraint](local-spin-constraint-in-the-schwinger-boson-representation.md).
