<h1 id="painleve-determinateness-theorem">Painlevé determinateness theorem</h1>

↑ **Parent:** [Complex ordinary differential equation](complex-ordinary-differential-equation.md)

For a first-order [ordinary differential equation](ordinary-differential-equation.md) rational in the dependent variable, with coefficients [meromorphic](meromorphic-function.md) on the chosen independent-variable surface, [analytic continuation](analytic-continuation.md) along an arc ending outside the fixed exceptional set has a definite limit in the [Riemann sphere](riemann-sphere.md). Its movable singularities are [poles](pole.md) or [algebraic branch points](algebraic-branch-point.md). To see the limiting assertion, the cluster set of a continuous lifted arc is connected and compact. Any cluster value where the vector field is [holomorphic](complex-differentiability-at-a-point.md) permits uniform local continuation by the [Picard-Lindelöf theorem](picard-lindelof-theorem.md). Otherwise the cluster set lies in finitely many coefficient poles, so it is a singleton. At a pole of the vector field, the inverse equation is [holomorphic](complex-differentiability-at-a-point.md); its solution has a finite-order critical point, giving a convergent root expansion. The reciprocal dependent variable handles infinity. Points where both reduced numerator and denominator vanish belong to the fixed exceptional set and are excluded from this argument.
