# Identity element

↑ **Parent:** [Group](group-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Identity_element)

An identity element $e$ satisfies $eg=ge=g$ for every element $g$ of a [group](group-split.md).
