# Normal-form game

↑ **Parent:** [Game theory](game-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Normal-form_game)

A normal-form game specifies each player's strategy set and their payoff for every strategy profile. In a finite two-player game these data form a [bimatrix game](bimatrix-game.md); if the two payoffs always sum to zero, one [payoff matrix](payoff-matrix.md) describes the [matrix game](matrix-game.md). The representation specifies choices and incentives, without a temporal order of observed moves.
