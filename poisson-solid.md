# Poisson solid

↑ **Parent:** [Lamé parameter](lame-parameter.md)

An isotropic [linear elasticity](linear-elasticity.md) material with equal positive [Lamé parameters](lame-parameter.md) has [Poisson's ratio](poisson-s-ratio.md) $1/4$ and the displayed compressional/shear speed ratio. This simplifying model fixes the relative amplitudes in the [tensile-crack radiation pattern](tensile-crack-radiation-pattern.md); it does not describe every stable isotropic solid.
