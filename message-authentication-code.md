# Message authentication code

↑ **Parent:** [Message authentication](message-authentication.md)

A keyed function producing a tag that a holder of the shared secret can verify. Its [message authentication](message-authentication.md) security requires that valid tags for new messages cannot be forged under the allowed adversarial queries. Unlike a [digital signature](digital-signature.md), verification is not inherently public and the verifier also knows a key capable of making tags.
