# Schwarz conjugation of a spectral function

↑ **Parent:** [Complex conjugation](complex-conjugation.md)

This operation reflects a [holomorphic function](holomorphic-function.md) across the real axis while preserving holomorphic dependence on the new argument. A transform of real data with real kernel coefficients satisfies $F^\sharp=F$. In a polygonal [global relation](global-relation-for-a-linear-boundary-value-problem.md), complex rotation factors are conjugated as well; an explicit prefactor $i$ changes sign.
