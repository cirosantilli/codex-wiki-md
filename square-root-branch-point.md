# Square-root branch point

↑ **Parent:** [Algebraic branch point](algebraic-branch-point.md)

A square-root [branch point](branch-point.md) has [ramification index](ramification-index.md) $2$: one circuit switches local branches and two restore the original branch. Both zero and infinity are square-root [branch points](branch-point.md) of $z^{-1/2}$, since the coordinate $u=1/z$ changes the latter local expression to $u^{1/2}$. A finite limiting value at a [branch point](branch-point.md) does not imply a [removable singularity](removable-singularity.md).
