# Credible interval

↑ **Parent:** [Bayesian statistics](bayesian-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Credible_interval)

A credible interval is an interval whose [posterior probability](posterior-probability.md) equals a prescribed level. Conditional on the observed data and the Bayesian model, the unknown parameter lies in the interval with that probability.
