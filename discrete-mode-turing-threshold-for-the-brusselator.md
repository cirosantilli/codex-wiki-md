# Discrete-mode Turing threshold for the Brusselator

↑ **Parent:** [Turing threshold of the Brusselator](turing-threshold-of-the-brusselator.md)

On a specified finite domain, only its boundary-compatible wavenumbers can grow. Solve the [Brusselator](brusselator.md) mode determinant for its neutral value of $b$ and minimize over those nonzero modes. Minimizing over all continuous $k$ instead gives the usual threshold and $k_c^2=a/\sqrt{D_uD_v}$. The finite-mode minimum must still precede the homogeneous threshold to describe a [Turing instability](turing-instability.md).
