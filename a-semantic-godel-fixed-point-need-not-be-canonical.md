<h1 id="a-semantic-godel-fixed-point-need-not-be-canonical">A semantic Gödel fixed point need not be canonical</h1>

↑ **Parent:** [Gödel sentence](godel-sentence.md)

Assuming PA is [consistent](consistent-first-order-theory.md), the [theory](first-order-theory.md) $S=\operatorname{PA}+\neg\operatorname{Con}_{\operatorname{PA}}$ is [consistent](consistent-first-order-theory.md) by second incompleteness. Its false [axiom](axiom.md) $G=\neg\operatorname{Con}_{\operatorname{PA}}$ is provable, so the standard semantic biconditional $G\leftrightarrow\neg\operatorname{Pr}_S(\ulcorner G\urcorner)$ is true with both sides false. Thus a true biconditional alone does not make an arbitrary sentence a true canonical [Gödel sentence](godel-sentence.md). A canonical [Pi-1](pi-1-formula.md) construction adds the necessary syntactic or sound-base information. Truth, internal equivalence and canonical construction must be distinguished.
