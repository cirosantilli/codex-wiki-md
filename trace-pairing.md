# Trace pairing

↑ **Parent:** [Field trace](field-trace.md)

For a finite field extension $L/K$, the trace pairing is the [bilinear form](bilinear-form.md)

$$
(x,y)\longmapsto\operatorname{Tr}_{L/K}(xy).
$$

It is nondegenerate exactly when $L/K$ is separable.
