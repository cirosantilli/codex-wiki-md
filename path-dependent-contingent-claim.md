# Path-dependent contingent claim

↑ **Parent:** [Contingent claim](contingent-claim.md)

A [contingent claim](contingent-claim.md) whose payoff depends on the underlying price history, rather than only its terminal price. [Asian options](asian-option.md) use averages, [barrier options](barrier-option.md) use whether a threshold has been crossed, and [lookback options](lookback-option.md) use running extrema. In the [Black-Scholes model](black-scholes-model.md), the Brownian [Martingale representation theorem](martingale-representation-theorem.md) still gives a [replicating strategy](replicating-strategy.md); its [portfolio wealth](portfolio-wealth.md) need not be a function of the current stock price alone. Adding a running integral or extremum can give a finite-dimensional state for pricing.
