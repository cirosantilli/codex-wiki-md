# Checksum

↑ **Parent:** [Error detection and correction](error-detection-and-correction.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Checksum)

A [checksum](checksum.md) is a value calculated from data to expose some forms of corruption. [Internet Protocol](internet-protocol.md) and transport checks cover specified header and data fields; changing covered fields requires updating their [checksums](checksum.md).
