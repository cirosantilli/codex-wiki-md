# Incoherent feedforward loop

↑ **Parent:** [Signal transduction](signal-transduction.md)

An [incoherent feedforward loop](incoherent-feedforward-loop.md) carries influences from a shared input to a shared output along routes with opposite net signs. In the [signaling adaptation](signaling-adaptation.md) toy, $s$ drives fast $x$ and slow $a$, which contribute with opposite signs to $r=x-a$. Despite the conventional word "loop", those routes do not return the output to an earlier stage: this arrangement is distinct from [negative feedback](negative-feedback.md). Opposing routes alone do not guarantee complete [signaling adaptation](signaling-adaptation.md). [Ma et al., Cell 138 (2009), p. 764: definition of an incoherent feedforward loop](https://cqb.pku.edu.cn/tanglab/pdf/78.pdf)
