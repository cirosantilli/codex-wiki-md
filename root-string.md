# Root string

↑ **Parent:** [Root system](root-system.md)

A root string is the set $S_{\alpha,\beta}=\Phi\cap(\beta+\mathbb Z\alpha)$ for roots $\alpha,\beta$ of a [root system](root-system.md) $\Phi$. For nonproportional roots $\alpha$ and $\beta$ of a reduced crystallographic [root system](root-system.md), the roots of the form $\beta+n\alpha$ form an unbroken [root string](root-string.md) $\beta-p\alpha,\ldots,\beta+q\alpha$, and $p-q=\langle\beta,\alpha^\vee\rangle$. The [root-string theorem](root-string-theorem.md) explains the endpoint relation. If $\beta=\pm\alpha$, zero is missing and this consecutive-string statement does not apply.
