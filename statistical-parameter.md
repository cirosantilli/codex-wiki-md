# Statistical parameter

↑ **Parent:** [Statistical model](statistical-model-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Statistical_parameter)

A [statistical parameter](statistical-parameter.md) indexes a family of [probability distributions](probability-distribution.md) in a [statistical model](statistical-model-split.md). It is fixed in a frequentist sampling model; a [prior distribution](prior-probability.md) makes it random for [Bayesian statistics](bayesian-statistics.md). Different [statistical parameter](statistical-parameter.md) values should produce different observable distributions when [identifiability](identifiability.md) is claimed.
