# 2-complex

↑ **Parent:** [CW complex](cw-complex.md)

A two-dimensional [CW complex](cw-complex.md) has cells only in dimensions zero, one and two. In a combinatorial two-complex the two-cells are polygons attached by combinatorial edge paths. Its [1-skeleton](1-skeleton.md) carries the path metric assigning length one to each edge. Compact combinatorial complexes have finitely many cells, so their cell-boundary lengths have a finite maximum.
