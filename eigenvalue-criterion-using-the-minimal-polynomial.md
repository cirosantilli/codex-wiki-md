# Eigenvalue criterion using the minimal polynomial

↑ **Parent:** [Minimal polynomial](minimal-polynomial.md)

For a [linear operator](linear-operator.md) on a [finite-dimensional vector space](finite-dimensional-vector-space.md), an [eigenvector](eigenvector.md) gives $m_T(T)v=m_T(\lambda)v=0$, proving the forward implication from eigenvalue to root. Conversely write $m_T(X)=(X-\lambda)q(X)$. If $T-\lambda I$ were invertible, the equation $(T-\lambda I)q(T)=0$ would imply $q(T)=0$, contradicting minimal degree. Thus $T-\lambda I$ has a nonzero [kernel of a linear map](kernel-of-a-linear-map-split.md). The equivalence concerns roots in the scalar field; roots in an extension describe eigenvalues after extending scalars.
