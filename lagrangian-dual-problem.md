# Lagrangian dual problem

↑ **Parent:** [Linear programming duality](linear-programming-duality.md)

For a minimization problem with inequalities $g_i(x)\leq0$, the [Lagrangian](lagrangian.md) is $L(x,\lambda)=f(x)+\sum_i\lambda_i g_i(x)$ with $\lambda_i\geq0$. The Lagrangian dual maximizes the concave dual function $q(\lambda)=\inf_xL(x,\lambda)$.
