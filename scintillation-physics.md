# Scintillation (physics)

↑ **Parent:** [Physics](physics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Scintillation_(physics))

A brief flash of [light](light.md) produced when an energetic [particle](particle-physics.md) deposits [energy](energy-split.md) in a material. Counting resolved flashes can count individual incident [particles](particle-physics.md); this differs from [atmospheric scintillation](scintillation-astronomy.md).
