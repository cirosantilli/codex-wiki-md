# Off-plane razor-thin Poisson kernel

↑ **Parent:** [Razor-thin disk Poisson kernel](razor-thin-disk-poisson-kernel.md)

For $k>0$, horizontal [Fourier transform](fourier-transform.md) gives $(\partial_z^2-k^2)\widetilde\Phi=4\pi G\widetilde\Sigma\delta(z)$. Decay and [continuity](continuous-function.md) give an exponential on each side; its derivative jump fixes the coefficient. The uniform mode needs a separate linear vertical solution and a potential reference.
