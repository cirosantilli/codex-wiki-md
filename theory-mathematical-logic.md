# Theory (mathematical logic)

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Theory_(mathematical_logic))

A [theory](theory-mathematical-logic.md) is a set of sentences in a formal language, sometimes understood to be closed under deduction. A [first-order theory](first-order-theory.md) uses a first-order language; consistency and completeness are separate properties of a theory.
