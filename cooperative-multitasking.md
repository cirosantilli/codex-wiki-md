# Cooperative multitasking

↑ **Parent:** [Coroutine](coroutine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cooperative_multitasking)

Tasks transfer control at explicit suspension points. A [FIFO queue](fifo-queue.md) of runnable [continuations](continuation-computer-science.md) implements [round-robin scheduling](round-robin-scheduling.md); a task that never transfers control can prevent others from running.
