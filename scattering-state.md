# Scattering state

↑ **Parent:** [Quantum scattering](quantum-scattering-split.md)

A [scattering state](scattering-state.md) is a state used to describe [quantum scattering](quantum-scattering-split.md). Its asymptotic incoming and outgoing components determine a [scattering amplitude](scattering-amplitude.md).
