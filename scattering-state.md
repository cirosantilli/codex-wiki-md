# Scattering state

↑ **Parent:** [Quantum scattering](quantum-scattering.md)

A [scattering state](scattering-state.md) is a state used to describe [quantum scattering](quantum-scattering.md). Its asymptotic incoming and outgoing components determine a [scattering amplitude](scattering-amplitude.md).
