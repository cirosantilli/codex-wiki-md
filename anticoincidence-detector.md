# Anticoincidence detector

↑ **Parent:** [Particle detector](particle-detector.md)

An [anticoincidence detector](anticoincidence-detector.md) vetoes a candidate event when another detector fires during the specified coincidence interval, helping reject penetrating [charged particles](charged-particle.md).
