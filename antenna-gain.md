# Antenna gain

↑ **Parent:** [Antenna (radio)](antenna-radio.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Antenna_gain)

[Antenna gain](antenna-gain.md) compares the far-field [energy flux](energy-flux.md) in a specified direction with the flux that an isotropic radiator would produce using the same input [power](power.md). Thus $S_r=GP_{\rm in}/(4\pi r^2)$. Gain includes radiation efficiency; it must be distinguished from a voltage or current [amplifier](amplifier.md) gain and from directivity when losses matter.
