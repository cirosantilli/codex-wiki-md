# Size-exclusion chromatography

↑ **Parent:** [Chemistry](chemistry-split.md)

[Size-exclusion chromatography](size-exclusion-chromatography.md) separates dissolved [molecules](molecule.md) using porous columns. Elution depends on molecular size in the chosen [solvent](solvent.md); calibration supplies an estimate of [molar mass](molar-mass.md). A trace calibrated with another [polymer](polymer.md) does not automatically give absolute [molar masses](molar-mass.md) or a number-count [probability distribution](probability-distribution.md).
