# Descendant in a rooted tree

↑ **Parent:** [Rooted tree](rooted-tree.md)

A [vertex](vertex-graph-theory.md) reachable from a specified [vertex](vertex-graph-theory.md) by following child edges in a [rooted tree](rooted-tree.md). Allowing the length-zero [graph path](path-in-a-graph.md) includes the starting vertex; a proper descendant excludes it. The [subtree](subtree.md) at a vertex consists of that vertex and its descendants. State the properness convention when using strict discovery-time inequalities.
