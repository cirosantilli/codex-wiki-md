# Open file table

↑ **Parent:** [Open file description](open-file-description.md)

The logical system-wide collection of [open file descriptions](open-file-description.md). Each description represents an opening, including access mode, current [file offset](file-offset.md) and a reference to the underlying [file](computer-file.md). Independent opens of the same [file](computer-file.md) normally create different descriptions, whereas descriptor duplication can make multiple [file descriptors](file-descriptor.md) share one description. A table is an abstract organization here, not a requirement that all entries occupy one fixed array.
