# Torsion-free module

↑ **Parent:** [Module theory](module-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Torsion-free_module)

A module $M$ over an integral domain $R$ is torsion-free when $rm=0$ with $0\ne r\in R$ implies $m=0$.
