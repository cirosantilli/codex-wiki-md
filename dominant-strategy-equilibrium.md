# Dominant-strategy equilibrium

↑ **Parent:** [Dominant strategy](dominant-strategy.md)

A [strategy profile](strategy-profile.md) in which each player uses a [dominant strategy](dominant-strategy.md). Every such profile is a [Nash equilibrium](nash-equilibrium.md), since each prescribed choice is a [best response](best-response.md) to the actual opposing choices in particular. The converse fails: a [Nash equilibrium](nash-equilibrium.md) only requires a [best response](best-response.md) to those actual choices. With the weak convention for [dominant strategy](dominant-strategy.md), ties are allowed; a [strictly dominant strategy](strictly-dominant-strategy.md) requires strict improvement over every alternative against every opposing profile.
