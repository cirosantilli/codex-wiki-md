# Jacobi curvature operator

↑ **Parent:** [Jacobi field](jacobi-field.md)

For the [Riemann curvature tensor](riemann-curvature-tensor.md) convention $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$, define $\mathcal R_X(v)=R(v,X)X$. Curvature pair interchange makes this operator self-adjoint. If $v\perp X$, then $\langle\mathcal R_Xv,v\rangle=K(v,X)|v|^2|X|^2$. The [Jacobi field](jacobi-field.md) equation is $D_t^2J+\mathcal R_{\dot\gamma}J=0$. The operator $v\mapsto R(X,v)X$ is $-\mathcal R_X$ and is likewise self-adjoint; this sign distinction matters when testing curvature inequalities.
