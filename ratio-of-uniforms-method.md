# Ratio-of-uniforms method

↑ **Parent:** [Rejection sampling](rejection-sampling.md)

For a nonnegative integrable function $h$ with integral $Z$, its ratio-of-uniforms region has area $Z/2$. A uniform point in the region transforms under $v=ux$ with [Jacobian determinant](jacobian-determinant.md) $u$; integrating $2u/Z$ over $0<u\le\sqrt{h(x)}$ gives density $h(x)/Z$. A rectangle containing the region gives a practical [rejection sampling](rejection-sampling.md) algorithm using only uniform random variables, with acceptance $Z/(2\operatorname{area}(B))$.
