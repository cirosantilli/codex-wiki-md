# Closed-string scattering amplitude

↑ **Parent:** [Polyakov path integral](polyakov-path-integral.md)

A closed-string [scattering amplitude](scattering-amplitude.md) is a worldsheet correlation function of external [string vertex operators](string-vertex-operator.md), integrated over their unfixed positions and [worldsheet moduli](worldsheet-moduli.md), with the necessary [worldsheet ghost fields](worldsheet-ghost-field.md).
