# Local minimizer

↑ **Parent:** [Local minimum](local-minimum.md)

A [local minimizer](local-minimizer.md) is a point $x_*$ of the [domain of a function](domain-of-a-function.md) at which that [function](function-split.md) attains a [local minimum](local-minimum.md): some [neighbourhood](neighbourhood-mathematics.md) $U$ of $x_*$ satisfies $f(x_*)\leq f(x)$ for all $x\in D\cap U$. The point and the attained value are different objects. Every [global minimizer](global-minimizer.md) is a [local minimizer](local-minimizer.md), but the converse need not hold.
