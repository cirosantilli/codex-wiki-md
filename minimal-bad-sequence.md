# Minimal bad sequence

↑ **Parent:** [Bad sequence](bad-sequence.md)

A minimal bad sequence chooses each successive object of least possible natural-number size among choices that admit an infinite bad continuation of the already fixed prefix. Replacing its next object by a strictly smaller one cannot leave a [bad sequence](bad-sequence.md). This contradiction principle proves [Higman lemma](higman-s-lemma.md) and the [labelled version of Kruskal's tree theorem](labelled-version-of-kruskal-s-tree-theorem.md).
