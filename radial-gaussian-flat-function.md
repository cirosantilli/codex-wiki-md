# Radial Gaussian flat function

↑ **Parent:** [Flat function](flat-function.md)

In any finite-dimensional [Euclidean space](euclidean-norm.md), this extension is a [smooth function](smooth-function.md) and all its [partial derivatives](partial-derivative.md) at the origin vanish. Away from zero, repeated [differentiation](differentiation.md) gives finite sums of coordinate [polynomials](polynomial-split.md) divided by powers of $|x|$, multiplied by $e^{-1/|x|^2}$. Every such term is bounded in absolute value by $C|x|^{-N}e^{-1/|x|^2}$ near zero. Since [Gaussian decay dominates every power](gaussian-decay-dominates-every-power.md), this bound tends to zero faster than any prescribed positive power of $|x|$. Induction using difference quotients then proves smoothness and zero [derivatives](derivative.md) of every order at zero.

The origin is nevertheless a strict [global minimum](global-minimum.md), because $F(x)>0$ for $x\ne0$. All its [Taylor series](taylor-series.md) coefficients vanish, so the function is not [real analytic](real-analytic-function.md) at zero. Adding a constant preserves the stationary minimum but changes the zeroth-order value. An expression written only for $x\ne0$ has no stationary point at the excluded origin until an extension is specified.
