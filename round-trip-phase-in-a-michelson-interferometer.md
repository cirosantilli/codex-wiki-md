# Round-trip phase in a Michelson interferometer

↑ **Parent:** [Michelson interferometer](michelson-interferometer.md)

A one-way arm-length difference $\delta$ gives optical path difference $2\delta$ and phase difference $2k\delta$. An ideal constructive output port has [intensity](intensity-physics.md) $I=I_{\rm in}[1+\cos(2k\delta)]/2$. The other output is complementary.
