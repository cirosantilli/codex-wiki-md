# Vertex link in a polygonal schema

↑ **Parent:** [Polygonal schema](polygonal-schema.md)

Replace each corner of a [polygonal schema](polygonal-schema.md) by a small [closed interval](closed-real-interval.md) cutting across that corner. The endpoint identifications induced by paired polygon edges glue these [intervals](interval-mathematics.md) into a [graph](graph-split.md) at each vertex [equivalence class](equivalence-class.md). This is its vertex link. A [circle](circle.md) link gives a [disc](topological-disc.md) [neighbourhood](neighbourhood-mathematics.md); a [closed interval](closed-real-interval.md) link gives a half-[disc](topological-disc.md) [neighbourhood](neighbourhood-mathematics.md) in a [surface with boundary](surface-with-boundary.md).

For a complete pairing of the sides of a single polygon, every link endpoint is paired exactly once. In each vertex [equivalence class](equivalence-class.md) the link [graph](graph-split.md) is [connected](connected-space.md), since the corner endpoint identifications generate precisely that class, and all its vertices have degree two. It is therefore a [circle](circle.md). For partial pairings, a [connected](connected-space.md) link can instead be a [closed interval](closed-real-interval.md) when it has two unpaired endpoints. Counting free polygon edges alone does not count [boundary components of a surface](boundary-component-of-a-surface.md); their endpoints must first be identified.
