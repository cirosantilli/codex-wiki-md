# Cue height for immediate rolling

↑ **Parent:** [Impulse-driven slipping-to-rolling transition of a sphere](impulse-driven-slipping-to-rolling-transition-of-a-sphere.md)

For the ideal uniform solid sphere with negligible table [impulse](impulse.md) during the cue strike, immediate rolling requires $u_0=a\Omega_0$, hence the horizontal cue line lies $2a/5$ above the centre. A different inertia distribution changes this height.
