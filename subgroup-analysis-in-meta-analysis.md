# Subgroup analysis in meta-analysis

↑ **Parent:** [Meta-analysis](meta-analysis.md)

Divide studies by a specified characteristic and estimate an effect in each subgroup, then test the difference using an [independent subgroup contrast in meta-analysis](independent-subgroup-contrast-in-meta-analysis.md) or an appropriate interaction model. The test of a between-group difference is distinct from separate tests against no effect within each group. Exploratory splits can be affected by [multiple testing](multiple-hypothesis-testing.md) and by [confounding](confounding.md) between study characteristics.
