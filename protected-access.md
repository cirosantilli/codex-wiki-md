# Protected access

↑ **Parent:** [Encapsulation in object-oriented programming](encapsulation-in-object-oriented-programming.md)

Protected access permits designated subclass code to use a member while excluding ordinary clients. The precise receiver and scope restrictions depend on the language; it should not be confused with public access to every instance's representation. Access control helps protect [representation invariants](representation-invariant.md) but does not ensure that authorized subclass code maintains them.
