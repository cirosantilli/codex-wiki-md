# Cell-cycle age density

↑ **Parent:** [Age-structured population equation](age-structured-population-equation.md)

A [cell-cycle age density](cell-cycle-age-density.md) counts [biological cells](biological-cell-split.md) per unit time spent in one specified phase of the [cell cycle](cell-cycle-split.md). Its integral over phase age is the population in that phase. Phase age resets on entry into the next phase, so it differs from chronological age since birth. A phase-exit [hazard function](hazard-function.md) supplies loss from the phase and incoming [flux](flux.md) to the next phase.
