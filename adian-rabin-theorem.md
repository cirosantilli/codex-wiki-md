<h1 id="adian-rabin-theorem">Adian–Rabin theorem</h1>

↑ **Parent:** [Markov property of finitely presented groups](markov-property-of-finitely-presented-groups.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Adian–Rabin_theorem)

No [Markov property of finitely presented groups](markov-property-of-finitely-presented-groups.md) is decidable by an algorithm taking an arbitrary [finite group presentation](finite-group-presentation.md) as input. The proof reduces the [word problem for a group](word-problem-for-groups.md) to property recognition using an effective construction which collapses when an input word is trivial and embeds the input group when it is nontrivial.
