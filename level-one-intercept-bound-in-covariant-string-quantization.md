# Level-one intercept bound in covariant string quantization

↑ **Parent:** [Old covariant string quantization](old-covariant-string-quantization.md)

A polarization obeys $p\cdot\epsilon=0$ and $p^2=(a-1)/\alpha'$. If $a>1$, spacelike momentum allows a negative-norm timelike polarization. Thus ghost absence requires $a\leq1$. At $a=1$ the [null string state](null-string-state.md) identification $\epsilon\sim\epsilon+\lambda p$ leaves $D-2$ polarizations.
