# Infinitesimal left-action sign convention

↑ **Parent:** [Fundamental vector field](fundamental-vector-field.md)

For a smooth left [Lie group action](lie-group-action.md), define the [fundamental vector field](fundamental-vector-field.md) by $X^\#(p)=\left.\frac d{ds}\right|_0\exp(sX)\cdot p$. With the [Lie bracket of vector fields](lie-bracket-of-vector-fields.md) $[U,V]f=U(Vf)-V(Uf)$, this map is an anti-homomorphism. The map $X\mapsto v_X=-X^\#$ is a [Lie algebra representation](lie-algebra-representation.md). A right action with the positive exponential has the opposite homomorphism convention, so specifying action side and bracket convention prevents a sign ambiguity.
