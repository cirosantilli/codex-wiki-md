# Wave scattering at a planar interface

↑ **Parent:** [Helmholtz equation](helmholtz-equation.md)

Wave scattering at a planar interface separates an incident [plane wave](plane-wave.md) into reflected and transmitted plane waves. Translation invariance parallel to the interface conserves the tangential component of the wavevector.
