# Recurrent visual processing

↑ **Parent:** [Ventral visual stream](ventral-visual-stream.md)

Visual computation in which activity feeds back within or between processing stages, allowing later representations to depend on earlier internal states. Time-resolved object-recognition measurements constrain this contribution more strongly than a static accuracy score, although a delay alone does not identify one circuit.[Introduction and Results; Nature Neuroscience 22, pp. 974–983: challenge images and IT population response timing](evidence-that-recurrent-circuits-are-critical-to-the-ventral-stream-s-execution-of-core-object-recognition-behavior-by-kohitij-kar-and-others.md)
