# Soundness theorem for propositional logic

↑ **Parent:** [Propositional logic](propositional-logic.md)

If $\Gamma\vdash t$, every valuation that satisfies all formulae in $\Gamma$ also satisfies $t$.

This is [soundness](soundness.md) for the propositional proof system and valuation semantics.
