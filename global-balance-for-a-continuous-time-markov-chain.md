# Global balance for a continuous-time Markov chain

↑ **Parent:** [Continuous-time Markov chain](continuous-time-markov-chain.md)

Global balance equates total stationary incoming and outgoing [transition intensities](transition-intensity.md) at each state. [Detailed balance for a continuous-time Markov chain](detailed-balance-for-a-continuous-time-markov-chain.md) is sufficient but stronger: it equates each pair separately.
