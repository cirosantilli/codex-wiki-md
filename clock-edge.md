# Clock edge

↑ **Parent:** [Computer science](computer-science-split.md)

A designated transition of a clock signal at which a [synchronous sequential circuit](synchronous-sequential-circuit.md) updates its stored [bits](bit.md). Next-state functions use the state immediately before the edge, and all stored [bits](bit.md) update together. This convention is essential when composing circuits: a combinational output computed from the old state can be sampled at that edge, while an additional stored output introduces another cycle of delay.
