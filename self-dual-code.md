# Self-dual code

↑ **Parent:** [Dual code](dual-code.md)

A [linear code](linear-code.md) is self-dual when it equals its [dual code](dual-code.md) under the standard [dot product](dot-product.md). For a length-$2k$ code with a rank-$k$ [generator matrix](generator-matrix.md) $G$, this is equivalent to $GG^T=0$: orthogonality gives inclusion in the [dual code](dual-code.md), and equal [dimensions](dimension-vector-space.md) give equality. Over $\mathbb F_2$, a [generator matrix](generator-matrix.md) $(I\mid A)$ therefore generates a self-dual code exactly when $AA^T=I$.
