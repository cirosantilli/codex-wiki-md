# Hilbert matrix

↑ **Parent:** [Matrix](matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hilbert_matrix)

A real [symmetric matrix](symmetric-matrix.md) whose entries are the moments $H_{ij}=\int_0^1x^{i-1}x^{j-1}dx$. Thus it is the [Gram matrix](gram-matrix.md) of the monomials in the real [L2 inner product](l2-inner-product.md) on $[0,1]$. For a nonzero real coefficient vector $v$, $v^THv=\int_0^1(\sum_i v_ix^{i-1})^2dx>0$, so every finite Hilbert matrix is [positive-definite](positive-definite-bilinear-form.md). The moment description connects these matrices with polynomial approximation and with the [shifted Hilbert quadratic-form bound](shifted-hilbert-quadratic-form-bound.md).
