# Setup time

↑ **Parent:** [Setup and hold time](setup-and-hold-time.md)

The minimum interval before an active [clock edge](clock-edge.md) during which the data input of a [flip-flop](flip-flop.md) must remain stable for specified operation. It constrains the latest arrival of new data at the receiving [flip-flop](flip-flop.md).
