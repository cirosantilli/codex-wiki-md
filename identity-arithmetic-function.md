# Identity arithmetic function

↑ **Parent:** [Dirichlet convolution](dirichlet-convolution.md)

The identity arithmetic function is $\operatorname{id}(n)=n$. The identity $\operatorname{id}=\mathbf 1*\varphi$ is equivalent to $\sum_{d\mid n}\varphi(d)=n$.
