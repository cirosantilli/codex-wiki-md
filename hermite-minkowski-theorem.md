<h1 id="hermite-minkowski-theorem">Hermite–Minkowski theorem</h1>

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)

For fixed degree and bounded absolute discriminant, there are only finitely many number fields up to isomorphism. In particular, only finitely many extensions of bounded degree can be unramified outside a fixed finite set of primes when their ramification exponents are bounded.
