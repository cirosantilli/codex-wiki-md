# Monotone coordinate excludes periodic orbits

↑ **Parent:** [Periodic orbit](periodic-orbit.md)

If one coordinate of every nonstationary trajectory is strictly monotone, the system has no [periodic orbit](periodic-orbit.md): a periodic coordinate must return to its initial value. Any trajectory on which that coordinate is constant must be checked separately.
