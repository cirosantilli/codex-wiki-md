# Least-favourable null configuration

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test.md)

A least-favourable configuration maximizes a test procedure’s [Type I error](type-i-and-type-ii-errors.md) probability over allowed [null hypothesis](null-hypothesis.md) parameters. For one-sided normal comparisons with a fixed [covariance matrix](covariance-matrix.md), coupling by common centered variables shows monotonicity in the means. For the [familywise error rate](familywise-error-rate.md), mixed true and false null configurations must also be checked.
