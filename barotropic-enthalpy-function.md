# Barotropic enthalpy function

↑ **Parent:** [Barotropic fluid](barotropic-fluid.md)

This [barotropic pressure potential](barotropic-enthalpy-function.md) obeys $\nabla h=\nabla p/\rho$ for a [barotropic fluid](barotropic-fluid.md). It gives the [pressure](pressure.md) contribution to a steady [Bernoulli equation](bernoulli-equation.md). In isentropic thermodynamics it agrees with [specific enthalpy](specific-enthalpy.md) up to a constant; for an externally maintained isothermal ideal gas it is $c_s^2\log\rho$ and is not the constant thermodynamic enthalpy at fixed temperature.
