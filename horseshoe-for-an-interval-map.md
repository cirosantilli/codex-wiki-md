# Horseshoe for an interval map

↑ **Parent:** [Glendinning chaos](glendinning-chaos.md)

An [interval map](interval-map.md) $F:I\to I$ has a horseshoe when there are an [open interval](open-interval.md) $J\subseteq I$ and disjoint [open intervals](open-interval.md) $K_0,K_1\subseteq J$ such that

$$
F(K_0)=F(K_1)=J.
$$

Iterating inverse branches produces full two-symbol itinerary dynamics.
