# Ghost zero-mode pairing

↑ **Parent:** [Ghost oscillator vacuum](ghost-oscillator-vacuum.md)

With Hermitian $b_0,c_0$ and $\{b_0,c_0\}=1$, a ket annihilated by $b_0$ has zero bare full-ghost norm. Nonzero amplitudes need [FP ghost](faddeev-popov-ghost.md) zero-mode saturation. Low-level [Virasoro descendant](virasoro-descendant.md) calculations can instead normalize the highest-weight coefficient and compute $L_nL_{-n}|\Omega\rangle$ algebraically. Such normalized contravariant coefficients are not positive-definite Hilbert norms. The pairing convention must be stated before using [FP ghost](faddeev-popov-ghost.md) descendants in a norm argument.
