# Unsigned interpretation of a bit string

↑ **Parent:** [Binary number](binary-number.md)

For an $n$-[bit](bit.md) [binary string](binary-string.md) $A=a_{n-1}\cdots a_0$, the [unsigned interpretation](unsigned-interpretation-of-a-bit-string.md) assigns positive positional weights $2^i$ to its [bits](bit.md). Its values range from zero to $2^n-1$. The same stored [bits](bit.md) have [two's complement](two-s-complement.md) value $\operatorname{bin}(A)-a_{n-1}2^n$, so interpreting a [machine word](machine-word.md) is a separate choice from storing its [bits](bit.md).
