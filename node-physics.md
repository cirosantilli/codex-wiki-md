# Node (physics)

↑ **Parent:** [Normal mode](normal-mode.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Node_(physics))

A node is a point where a [standing wave](standing-wave.md) has minimum [amplitude](wave-amplitude.md). For an ideal standing [normal mode](normal-mode.md), its [eigenfunction](eigenfunction.md) vanishes there at all times.
