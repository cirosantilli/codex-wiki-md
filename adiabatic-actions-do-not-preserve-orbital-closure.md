# Adiabatic actions do not preserve orbital closure

↑ **Parent:** [Adiabatic invariance of an orbital action](adiabatic-invariance-of-an-orbital-action.md)

[Adiabatic invariance of an orbital action](adiabatic-invariance-of-an-orbital-action.md) preserves action values during slow regular changes, but frequencies $\partial H/\partial J_i$ can vary. Closure requires rational frequency ratios, which need not persist. A slowly added harmonic component in a [Kepler orbit](kepler-orbit.md) potential produces generic apsidal precession.
