# Residue class

↑ **Parent:** [Modular congruence](modular-congruence.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Residue_class)

The residue class $[a]_m$ consists of all [integers](integer.md) congruent to $a$ modulo $m$.
