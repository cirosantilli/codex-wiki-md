# Connect-the-dots interval map

↑ **Parent:** [Interval map](interval-map.md)

For prescribed values $F(x_i)$ at ordered points $x_0<\cdots<x_n$, the connect-the-dots interval map is the unique [piecewise linear function](piecewise-linear-function.md) obtained by linear interpolation between consecutive data points.
