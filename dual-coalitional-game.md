# Dual coalitional game

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

Duality assigns a [coalition](coalition-game-theory.md) the grand-coalition value less the value of its complement. For a normalized [transferable utility game](transferable-utility-game.md), the dual is normalized and taking the dual twice recovers the original game. A player's dual [marginal contribution](marginal-contribution.md) at predecessor set $S$ equals its original contribution at the complementary predecessor set in $N\setminus\{i\}$. This preserves the [Shapley value](shapley-value.md).
