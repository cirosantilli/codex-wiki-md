# Keisler extension property

↑ **Parent:** [Strongly inaccessible cardinal](strongly-inaccessible-cardinal.md)

An inaccessible cardinal $\kappa$ has the Keisler extension property when there is a proper [transitive set](transitive-set.md) $X\supsetneq V_\kappa$ for which

$$
(V_\kappa,\in)\prec(X,\in).
$$

Such a $\kappa$ is not the least inaccessible cardinal: $X$ regards $\kappa$ as inaccessible, [elementarity](elementary-substructure.md) reflects the existence of an inaccessible into $V_\kappa$, and [strong-inaccessibility absoluteness from rank agreement](strong-inaccessibility-absoluteness-from-rank-agreement.md) makes the resulting witness genuinely inaccessible below $\kappa$.
