# Kernel regression

↑ **Parent:** [Nonparametric regression](nonparametric-regression.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kernel_regression)

[Kernel regression](kernel-regression.md) estimates a regression function using localized kernel weights rather than a fixed finite-dimensional functional form. The [Nadaraya–Watson estimator](nadaraya-watson-estimator.md) is the local-constant version; [local polynomial regression](local-polynomial-regression.md) improves its local approximation by fitting a polynomial.
