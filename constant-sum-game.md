# Constant-sum game

↑ **Parent:** [Zero-sum game](zero-sum-game.md)

In a two-player [constant-sum game](constant-sum-game.md), the [sum](sum.md) of the two [payoffs](payoff.md) is the same constant $K$ at every [strategy profile](strategy-profile.md). Replacing each player's [payoff](payoff.md) by $u_i-K/2$ gives a [zero-sum game](zero-sum-game.md) without changing [best responses](best-response.md) or [Nash equilibria](nash-equilibrium.md). If both players can guarantee $K/2$, then any [Nash equilibrium](nash-equilibrium.md) gives each that value. An equilibrium in [pure strategies](pure-strategy.md) must use [pure strategies](pure-strategy.md) with that guarantee: otherwise the opponent could improve on $K/2$ by a [unilateral deviation](unilateral-deviation.md).
