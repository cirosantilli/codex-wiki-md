# Affine function

↑ **Parent:** [Linear function](linear-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Affine_function)

An affine function on a real or complex [vector space](vector-space-split.md) has the form $x\mapsto Lx+b$, where $L$ is a [linear map](linear-map.md) and $b$ is constant. Its derivative is the constant map $L$. It is linear exactly when $b=0$.
