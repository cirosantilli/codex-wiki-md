# Group-like element

↑ **Parent:** [Coalgebra](coalgebra.md)

An element of a [coalgebra](coalgebra.md) satisfying the displayed identities. A [group-like element](group-like-element.md) in a [Hopf algebra](hopf-algebra.md) is invertible with inverse its [antipode](antipode.md) image.
