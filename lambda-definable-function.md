# Lambda-definable function

↑ **Parent:** [Church numeral](church-numeral.md)

A function $g:\mathbb N^k\to\mathbb N$ is lambda-definable when some [combinator](combinator.md) $G$ satisfies

$$
G c_{n_1}\cdots c_{n_k}\equiv_\beta c_{g(n_1,\ldots,n_k)}
$$

for every tuple of natural numbers.
