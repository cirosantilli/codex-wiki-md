# Next-state function

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

A function mapping the current [automaton state](automaton-state.md) and input to the state entered at the next update. In a [Moore machine](moore-machine.md), a separate output function depends only on the current state; in a [Mealy machine](mealy-machine.md), it may also depend on the current input.
