# Schauder theorem for compact operators

↑ **Parent:** [Compact operator](compact-operator-split.md)

A bounded operator $T:X\to Y$ between [Banach spaces](banach-space-split.md) is compact if and only if its [dual map of bounded linear operator](transpose-of-a-bounded-linear-operator.md) $T^*:Y^*\to X^*$ is compact.
