# Topological mixing

↑ **Parent:** [Topological transitivity](topological-transitivity.md)

A continuous [map](discrete-dynamical-system-split.md) $F:X\to X$ is [topologically mixing](topological-mixing.md) if for every pair of nonempty open sets $U,V$ there is an [integer](integer-split.md) $N$ such that $F^n(U)\cap V\ne\varnothing$ for every $n\ge N$. This is stronger than [topological transitivity](topological-transitivity.md), which asks only for some hitting time. For the full [tent map](tent-map.md), each sufficiently small dyadic branch interval is mapped onto the whole space by an iterate, proving [mixing](topological-mixing.md).
