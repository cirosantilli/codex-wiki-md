# Lumped thermal model

↑ **Parent:** [Heat](heat-split.md)

A finite-dimensional energy-balance model assigning one representative [temperature](temperature-split.md) and [heat capacity](heat-capacity.md) to each region. [Thermal resistances](thermal-resistance.md) represent the energy exchange between regions; internal spatial gradients are not resolved.
