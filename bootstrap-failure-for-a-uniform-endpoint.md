# Bootstrap failure for a uniform endpoint

↑ **Parent:** [Bootstrapping (statistics)](bootstrapping-statistics.md)

For a continuous [uniform distribution](continuous-uniform-distribution.md) on $[0,\theta]$, the scaled maximum gap $n(\theta-X_{(n)})/\theta$ tends to a unit-rate [exponential distribution](exponential-distribution.md). An ordinary [bootstrap sample](bootstrap-sample.md) includes the unique observed maximum with probability $1-(1-1/n)^n\to1-e^{-1}$. The bootstrap maximum gap therefore retains an atom at zero, whereas the target limit is continuous. This proves failure of the ordinary empirical bootstrap for this endpoint functional; consistency of the endpoint estimate alone does not justify resampling its extreme-value limit.
