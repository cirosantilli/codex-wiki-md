# Finite-buffer workload map

↑ **Parent:** [Workload of a queue](workload-of-a-queue.md)

With lookback net input $z(s)=a(-s,0]-Cs$, the stable finite-buffer workload is $\sup_{t\geq0}\min(\sup_{0\leq s\leq t}z(s),B+\inf_{0\leq s\leq t}z(s))$. Since $z(0)=0$, it lies between zero and B, and is at most the infinite-buffer [supremum](supremum.md) $q(a)=\sup_{s\geq0}z(s)$. For a constant-rate burst which builds exactly x work from an empty queue, no upper reflection occurs when $x\leq B$ and both workloads equal x.
