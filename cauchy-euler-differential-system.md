# Cauchy-Euler differential system

↑ **Parent:** [Linear system of differential equations](linear-system-of-differential-equations.md)

An [eigenvector](eigenvector.md) of $A$ with [eigenvalue](eigenvalue.md) $\lambda$ gives a homogeneous solution $t^\lambda\mathbf v$ for $t>0$. If $A$ is diagonalizable, these powers form a fundamental system. A constant vector forcing has a particular solution $t(I-A)^{-1}\mathbf b$ when $1$ is not an [eigenvalue](eigenvalue.md). At a resonant [eigenvalue](eigenvalue.md) or a nontrivial Jordan block, logarithmic factors in $t$ can occur, equivalently by changing time to $\log t$ and solving a constant-coefficient linear system.
