# Agarose

↑ **Parent:** [Polysaccharide](polysaccharide.md)

A [polysaccharide](polysaccharide.md) that forms a porous gel on cooling from solution. In [agarose gel electrophoresis](agarose-gel-electrophoresis.md), the [agarose](agarose.md) network provides a size-dependent obstacle to [DNA](deoxyribonucleic-acid.md) migration in an [electric field](electric-field-split.md).
