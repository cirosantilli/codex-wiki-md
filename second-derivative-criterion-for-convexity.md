# Second-derivative criterion for convexity

↑ **Parent:** [Convex function](convex-function.md)

A twice-differentiable [real-valued function](real-valued-function.md) on an open [interval](interval-mathematics.md) is [convex](convex-function.md) if and only if its [second derivative](second-derivative.md) is nonnegative everywhere. If $f''\ge0$, the [mean value theorem](mean-value-theorem.md) makes $f'$ nondecreasing, which implies the supporting-line and chord inequalities for [convexity](convex-function.md). Conversely, the slopes of a [convex function](convex-function.md) are ordered; where the [second derivative](second-derivative.md) exists, this gives $f''\ge0$. Strict positivity of $f''$ is sufficient for [strict convexity](strictly-convex-function.md), but is not necessary: $f(x)=x^4$ is [strictly convex](strictly-convex-function.md) despite $f''(0)=0$.
