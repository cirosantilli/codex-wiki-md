# Data compatibility with the regularizer domain

↑ **Parent:** [Variational regularization](variational-regularization.md)

Exact fitting in the small-parameter limit requires data that can be approximated by forward images of elements in the regulariser's [effective domain](effective-domain.md). Membership merely in the [operator range](range-of-a-bounded-linear-operator.md) is insufficient when an extended-real regulariser imposes a hard constraint.
