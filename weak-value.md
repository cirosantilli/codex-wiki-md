# Weak value

↑ **Parent:** [Weak measurement](weak-measurement.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Weak_value)

For preselected $|i\rangle$ and nonorthogonal postselected $|f\rangle$, the displayed transition-amplitude ratio controls the first-order conditional pointer response to a [von Neumann measurement interaction](von-neumann-measurement-interaction.md). It can be complex or outside an observable's eigenvalue range. Expanding $\langle f|\exp(-igA\otimes p/\hbar)|i\rangle$ to first order gives $\langle f|i\rangle[1-igA_wp/\hbar]$, proving that interpretation within the expansion's validity regime.[1988 primary proposal: weak values in a preselected and postselected spin ensemble](weak-values-by-yakir-aharonov-david-z-albert-and-lev-vaidman.md)
