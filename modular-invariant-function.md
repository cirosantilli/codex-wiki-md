# Modular-invariant function

↑ **Parent:** [Modular group](modular-group.md)

A function on the [complex upper half-plane](upper-half-plane-complex-analysis.md) is modular invariant if it is unchanged by the fractional-linear action of the [modular group](modular-group.md). This does not imply holomorphicity: a [nonholomorphic Eisenstein series](nonholomorphic-eisenstein-series.md) is modular invariant, whereas a [modular function](modular-function-split.md) additionally satisfies meromorphicity and cusp conditions.
