# Pointwise approximation by uniformly continuous functions

↑ **Parent:** [Uniform continuity](uniform-continuity.md)

Every continuous $f:\mathbb R\to\mathbb R$ can be approximated with [pointwise convergence](pointwise-convergence.md) by [uniformly continuous](uniform-continuity.md) functions. Set $c_n(x)=\max(-n,\min(x,n))$ and $f_n=f\circ c_n$. The map $c_n$ is [Lipschitz continuous](lipschitz-continuity.md) with constant one and $f|_{[-n,n]}$ is [uniformly continuous](uniform-continuity.md) by the [Heine-Cantor theorem](heine-cantor-theorem.md), so $f_n$ is [uniformly continuous](uniform-continuity.md) on the whole line. On every fixed bounded interval, $f_n=f$ eventually.
