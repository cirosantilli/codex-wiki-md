# Bit stuffing

↑ **Parent:** [Framing](framing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bit_stuffing)

[Bit stuffing](bit-stuffing.md) inserts extra [bits](bit.md) according to an agreed rule, for example after five consecutive ones, so that a reserved [frame delimiter](frame-delimiter.md) cannot occur inside encoded contents. The receiver reverses the insertion rule.
