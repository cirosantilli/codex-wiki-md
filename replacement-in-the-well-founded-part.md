# Replacement in the well-founded part

↑ **Parent:** [Rank bounding for sets in the cumulative hierarchy](rank-bounding-for-sets-in-the-cumulative-hierarchy.md)

Without assuming [foundation](axiom-of-regularity.md), the [class in set theory](class-set-theory.md) formed by the [cumulative hierarchy](cumulative-hierarchy.md) satisfies [replacement](axiom-schema-of-replacement.md). Relativize a functional [logical formula](logical-formula.md) to that definable [class in set theory](class-set-theory.md) and use ambient [replacement](axiom-schema-of-replacement.md) to collect its range. Every output belongs to the hierarchy [class in set theory](class-set-theory.md), and the rank-bounding result places the range [set](set-split.md) itself in that [class in set theory](class-set-theory.md).
