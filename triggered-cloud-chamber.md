# Triggered cloud chamber

↑ **Parent:** [Expansion cloud chamber](expansion-cloud-chamber.md)

A [triggered cloud chamber](triggered-cloud-chamber.md) expands in response to an event indicated by other detectors, rather than hoping that a particle arrives during a randomly chosen sensitive interval. The [ionization](ionization.md) trail is produced before expansion. The apparatus must respond while the ions remain sufficiently localized to make a useful photograph.
