# Generating set of a module

↑ **Parent:** [Module (mathematics)](module-mathematics.md)

A subset $S$ of a [module](module-mathematics.md) $M$ generates $M$ when every element of $M$ is a finite sum $\sum_{s\in S}r_ss$, with coefficients in the scalar [ring](ring.md). The existence of a finite such subset defines a [finitely generated module](finitely-generated-module.md).
