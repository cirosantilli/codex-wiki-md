# Conditional execution

↑ **Parent:** [Machine instruction](machine-instruction.md)

An instruction changes architectural state only if a specified predicate holds. With [register renaming](register-renaming.md), a false conditional write must preserve the preceding logical destination value and satisfy younger consumers of that version.
