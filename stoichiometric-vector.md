# Stoichiometric vector

↑ **Parent:** [Chemical reaction network](chemical-reaction-network.md)

The stoichiometric vector of reaction $r$ records its net change in each [chemical species](chemical-species.md). If the copy-number state is $x$, firing the reaction changes it to $x+\nu_r$.
