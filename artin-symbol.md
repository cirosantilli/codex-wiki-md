# Artin symbol

↑ **Parent:** [Class field theory](class-field-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Artin_symbol)

For an unramified prime $\mathfrak p$ in an abelian extension $L/K$, the Artin symbol is the unique Galois element acting on residue fields by $x\mapsto x^{N\mathfrak p}$.
