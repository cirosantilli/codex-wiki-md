# Unreduced Jones polynomial

↑ **Parent:** [Jones polynomial](jones-polynomial.md)

Use the [Kauffman bracket](kauffman-bracket.md) assigning the empty diagram value $1$ and a disjoint circle factor $-A^2-A^{-2}$. Correct by the [writhe of a link diagram](writhe-of-a-link-diagram.md) and substitute $t=A^{-4}$. Relative to the [Jones polynomial](jones-polynomial.md) normalized to be $1$ on the [unknot](unknot.md), this unreduced invariant has an additional factor $-(t^{1/2}+t^{-1/2})$. For a nonempty $l$-component [link](link.md), its value at $t=1$ is $(-2)^l$.
