# Binary block code

↑ **Parent:** [Block code](block-code.md)

A binary $[n,m,d]$ code is a set of $m$ distinct words in $\mathbb F_2^n$ whose minimum pairwise [Hamming distance](hamming-distance.md) is $d$. Here $n$ is the block length and $m$ is the number of codewords.
