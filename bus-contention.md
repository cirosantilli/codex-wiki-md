# Bus contention

↑ **Parent:** [Bus arbitration](bus-arbitration.md)

Here, competition between pending initiators for the same [shared computer bus](shared-computer-bus.md) resource. Correct [bus arbitration](bus-arbitration.md) converts this competition into waiting. Simultaneously driving incompatible values on the same electrical lines is a different, erroneous kind of [bus contention](bus-contention.md); multiple pending requests need not cause it.
