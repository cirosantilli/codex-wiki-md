# Code encoding

↑ **Parent:** [Coding theory](coding-theory-split.md)

Code encoding maps messages injectively to [codewords](codeword.md). For a dimension-$k$ [linear code](linear-code.md) with [generator matrix](generator-matrix.md) $G$, the standard encoder maps $m\in\mathbb F_q^k$ to $mG$. The redundancy makes error detection and recovery possible; for a [Reed-Solomon code](reed-solomon-error-correction.md), encoding can instead evaluate a message [polynomial](polynomial-split.md) at the chosen field elements.
