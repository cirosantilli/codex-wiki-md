# Distance from a point to a line

↑ **Parent:** [Euclidean distance](euclidean-distance.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Distance_from_a_point_to_a_line)

For a line $Ax+By+C=0$ with $A^2+B^2>0$, its [unit normal](unit-normal.md) is $(A,B)/\sqrt{A^2+B^2}$. Choose any point on the line and project the displacement to $(x_0,y_0)$ onto this normal. The absolute value of that projection gives the title formula. This is the shortest [Euclidean distance](euclidean-distance.md), because any displacement to a different point on the line has the same normal component and an additional orthogonal tangential component.
