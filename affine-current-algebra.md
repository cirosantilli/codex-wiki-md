# Affine current algebra

↑ **Parent:** [Lie algebra](lie-algebra-split.md)

The affine current algebra is the one-dimensional central extension of the [loop algebra](loop-algebra.md) of a finite-dimensional [Lie algebra](lie-algebra-split.md), with central element acting as the level $k$. A restricted module has $J_n v=0$ for all sufficiently large $n$ for each vector $v$; this makes the [Sugawara construction](sugawara-construction.md) finite on each vector after [normal ordering](normal-ordering.md). In a compact unitary positive-energy representation, the nontrivial integrable levels are positive integers in the standard basic normalization.
