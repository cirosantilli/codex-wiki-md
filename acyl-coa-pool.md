# Acyl-CoA pool

↑ **Parent:** [Metabolic pathway](metabolic-pathway.md)

The [acyl-CoA pool](acyl-coa-pool.md) is the set of acyl groups carried by coenzyme A in a specified compartment and condition. Carrier-bound intermediates must be distinguished from the same acyl chains esterified in membrane or storage lipids.
