# Input bias current

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

An [input bias current](input-bias-current.md) is a direct-current component drawn by an input terminal of a real [operational amplifier](operational-amplifier.md). Through a source resistance it produces a voltage error, and through the feedback [capacitor](capacitor.md) of an [op amp integrator](op-amp-integrator.md) it can produce an output ramp. Its magnitude and sign depend on the amplifier technology and operating conditions.
