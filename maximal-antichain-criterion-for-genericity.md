# Maximal-antichain criterion for genericity

↑ **Parent:** [Generic filter](generic-filter.md)

A filter is generic over its ground model exactly when it meets each ground-model maximal [forcing antichain](forcing-antichain.md) in one point. Extensions of a maximal antichain form a dense set, while any ground dense set contains an antichain maximal in the whole [forcing](forcing-split.md). Directedness permits at most one antichain member in a filter.
