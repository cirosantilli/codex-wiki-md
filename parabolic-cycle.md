# Parabolic cycle

↑ **Parent:** [Complex dynamics](complex-dynamics-split.md)

A parabolic cycle is a special kind of [periodic point](periodic-point.md) orbit.

A parabolic cycle is a periodic orbit whose multiplier is a root of unity; an iterate then has multiplier one and attracting petals.
