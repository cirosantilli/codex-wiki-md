# Bounded differences property

↑ **Parent:** [Concentration inequality](concentration-inequality.md)

A [function](function-split.md) $f(x_1,\ldots,x_n)$ has bounded differences with constants $c_i$ when changing only $x_i$ changes its value by at most $c_i$.
