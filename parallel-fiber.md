# Parallel fiber

↑ **Parent:** [Axon](axon.md)

A branch of a cerebellar granule-cell axon that forms [synapses](synapse.md) on [Purkinje cells](purkinje-cell.md) and other cerebellar [neurons](neuron-split.md). Expanded granule-cell activity supplies a diverse input basis in cerebellar adaptive-filter models.
