# Parity computation by CNOT gates

↑ **Parent:** [Parity bit](parity-bit.md)

Apply one [CNOT gate](controlled-not-gate.md) from each input [qubit](qubit.md) to the same target. Their actions commute because controls remain unchanged and each contribution is added modulo two. This reversible circuit computes the [parity bit](parity-bit.md) with exactly one [two-qubit gate](two-qubit-gate.md) per input, and its inverse is the same circuit. Unlike measuring the inputs to compute parity classically, the unitary preserves [quantum superposition](quantum-superposition.md) and can be uncomputed after phase application.
