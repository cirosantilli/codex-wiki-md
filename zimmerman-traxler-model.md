# Zimmerman-Traxler model

↑ **Parent:** [Aldol reaction](aldol-reaction.md)

A six-membered chair-like transition-state model for an aldol-type bond-forming step. It predicts relative [stereochemistry](stereochemistry-split.md) by comparing substituent placement and nonbonded interactions, but must be adapted to the actual [enamine](enamine.md) or metal-enolate catalyst.
