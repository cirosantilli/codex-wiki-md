# Compact isospectral sets of closed surfaces

↑ **Parent:** [Isospectral manifolds](isospectral-manifolds.md)

For a fixed [closed](closed-set.md) orientable [Riemannian surface](riemannian-surface.md), the smooth metrics with a specified scalar [Laplace-Beltrami operator](laplace-beltrami-operator.md) spectrum form a [compact](compact-space.md) set modulo [diffeomorphisms](diffeomorphism.md), in the smooth topology. This is a [compactness](compact-space.md) assertion, not uniqueness or finiteness of the number of [Riemannian isometry](riemannian-isometry.md) classes. It restricts geometric degeneration within an isospectral set and uses more information than the leading [heat invariants](heat-invariants.md) alone. The theorem was established in [the 1988 compactness paper](https://doi.org/10.1016/0022-1236(88)90071-7).
