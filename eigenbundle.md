# Eigenbundle

↑ **Parent:** [Vector bundle](vector-bundle.md)

For a smooth complex [vector bundle](vector-bundle.md) endomorphism $A$ and a smooth eigenvalue function $\lambda$, a kernel of constant rank is a smooth vector subbundle, called its eigenbundle. Without a constant-rank hypothesis these kernels need not form a [vector bundle](vector-bundle.md).
