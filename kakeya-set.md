# Kakeya set

↑ **Parent:** [Incidence geometry](incidence-geometry.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kakeya_set)

A bounded subset of $\mathbb R^n$ is a [Kakeya set](kakeya-set.md) if it contains a unit line segment in every direction. Segment positions may vary with direction. Such a set need not have positive [Lebesgue measure](lebesgue-measure.md); the dimension problem concerns its [Minkowski dimension](box-counting-dimension.md) or other notions of dimension.
