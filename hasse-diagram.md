# Hasse diagram

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hasse_diagram)

A [Hasse diagram](hasse-diagram.md) draws a finite [partially ordered set](partially-ordered-set.md) using one point for each element and an upward line from $x$ to $y$ for each [cover relation](covering-relation.md) $x\prec y$. It omits reflexive loops and comparisons already implied by paths. Line crossings are not additional elements. In a finite [partially ordered set](partially-ordered-set.md), following upward paths recovers exactly the original comparisons. The diagram is named after [Helmut Hasse](helmut-hasse.md).
