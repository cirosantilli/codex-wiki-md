# List edge coloring

↑ **Parent:** [Edge coloring](edge-coloring.md)

Each [edge](edge-of-a-graph.md) has a list of allowed colors; a list edge coloring chooses an allowed color on each edge, giving different colors to incident edges. The [list-chromatic index](list-chromatic-index.md) is the uniform list-size threshold guaranteeing success.
