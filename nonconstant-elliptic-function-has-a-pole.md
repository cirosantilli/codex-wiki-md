# Nonconstant elliptic function has a pole

↑ **Parent:** [Elliptic function](elliptic-function.md)

If an [elliptic function](elliptic-function.md) had no [poles](pole.md), it would be [entire](entire-function.md). It is bounded on the closure of a [fundamental parallelogram](fundamental-parallelogram-of-a-period-lattice.md), and periodicity then makes it bounded on the whole [complex plane](complex-plane.md). The [Liouville theorem](liouville-theorem.md) would make it constant. Thus every nonconstant elliptic function has a pole.
