# Network simplex algorithm

↑ **Parent:** [Minimum-cost flow problem](minimum-cost-flow-problem.md)

The network simplex algorithm specializes the [simplex algorithm](simplex-algorithm.md) to network flows. A basis is represented by a spanning tree with nonbasic flows at their bounds; potentials give [reduced costs](reduced-cost.md), and entering arcs produce cycle pivots. [Degeneracy in linear programming](degeneracy-in-linear-programming.md) is particularly common in assignment instances.
