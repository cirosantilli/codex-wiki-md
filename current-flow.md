# Current flow

↑ **Parent:** [Electrical network](electrical-network.md)

A current flow is an antisymmetric function on oriented edges satisfying Kirchhoff's node law away from its sources and sinks. For conductance $c(x,y)$ and voltage $u$, [Ohm's law](ohm-s-law.md) gives $i(x,y)=c(x,y)(u(x)-u(y))$.
