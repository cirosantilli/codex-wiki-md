# Conditional-vector product-state criterion

↑ **Parent:** [Product state](product-state.md)

A nonzero bipartite [pure state](pure-state.md) is a [product state](product-state.md) if and only if all its [partial inner products](partial-inner-product.md) on the first subsystem lie in a common one-dimensional [vector subspace](vector-subspace.md) of the second. For a product $|a\rangle\otimes|b\rangle$, every contraction equals $\langle u|a\rangle|b\rangle$. Conversely, contract against each [vector](vector.md) of an [orthonormal basis](orthonormal-basis.md) to write $|\Psi\rangle=\sum_i|i\rangle\otimes|\chi_i\rangle$. If $|\chi_i\rangle=c_i|b\rangle$ for a common nonzero $|b\rangle$, then $|\Psi\rangle=(\sum_ic_i|i\rangle)\otimes|b\rangle$. Zero conditional [vectors](vector.md) are allowed. A nontrivial [linear dependence](linear-dependence.md) relation requires multipliers not both zero; allowing both multipliers to vanish would give no test at all.
