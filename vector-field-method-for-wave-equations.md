# Vector field method for wave equations

↑ **Parent:** [Wave equation](wave-equation-split.md)

The vector field method commutes a [wave equation](wave-equation-split.md) with spacetime symmetry generators, estimates the resulting [commuted wave energies](commuted-wave-energy.md), and converts weighted [L2 norms](l2-norm.md) to pointwise decay using a [Klainerman-Sobolev inequality](klainerman-sobolev-inequality.md). The [commutation vector fields for the wave equation](commutation-vector-field-for-the-wave-equation.md) include translations, rotations, [Lorentz boost vector fields](lorentz-boost-vector-field.md) and the [scaling vector field](scaling-vector-field.md). It is useful for [almost global existence for wave equations](almost-global-existence-for-wave-equations.md) and for small-data global existence under the [classical null condition for wave equations](classical-null-condition-for-wave-equations.md).
