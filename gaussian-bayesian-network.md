# Gaussian Bayesian network

↑ **Parent:** [Bayesian network](bayesian-network.md)

A Gaussian Bayesian network specifies a linear normal conditional model at each node of a [Bayesian network](bayesian-network.md): $X_j\mid X_{\operatorname{pa}(j)}\sim N(\alpha_j+\gamma_j^TX_{\operatorname{pa}(j)},\sigma_j^2)$. [Independent](independent-random-variables.md) local errors and an acyclic ordering generate a joint [multivariate normal distribution](multivariate-normal-distribution.md). Positive conditional [variances](variance-split.md) give a nonsingular joint [multivariate normal distribution](multivariate-normal-distribution.md). The graph constrains [regression coefficients](regression-coefficient.md) and hence [conditional independence](conditional-independence.md).
