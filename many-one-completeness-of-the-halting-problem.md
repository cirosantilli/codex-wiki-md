# Many-one completeness of the halting problem

↑ **Parent:** [Diagonal halting set](diagonal-halting-set.md)

Every [recursively enumerable set](recursively-enumerable-set.md) many-one reduces to the [diagonal halting set](diagonal-halting-set.md). If a program halts exactly on $X$, the [S-m-n theorem](smn-theorem.md) produces from $x$ an index $g(x)$ for a unary program that ignores its input and performs that computation on $x$. Then

$$
x\in X\Longleftrightarrow g(x)\in K.
$$

Conversely, a computable preimage of a recursively enumerable set is recursively enumerable.
