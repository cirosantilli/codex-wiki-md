# Busy waiting

↑ **Parent:** [Central processing unit](central-processing-unit.md)

[Busy waiting](busy-waiting.md) repeatedly tests a condition while keeping the processor occupied. A delay based only on instruction counts also depends on instruction timing and time spent handling [interrupts](interrupt.md). Polling a [hardware timer](hardware-timer.md) avoids that calibration dependence but still occupies the processor.
