# Liability-threshold model

↑ **Parent:** [Psychiatric genetics](psychiatric-genetics.md)

A model in which a binary diagnostic outcome occurs when an underlying continuous liability exceeds a threshold. Genetic and environmental components can influence liability. Estimating liability-scale [heritability](heritability.md) requires assumptions about [prevalence](prevalence.md), ascertainment and the liability distribution; crude diagnostic concordance is not a continuous-trait [correlation](pearson-correlation-coefficient.md).
