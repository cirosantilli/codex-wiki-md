# Weyl group of a rank-two root system

↑ **Parent:** [Classification of rank-two root systems](classification-of-rank-two-root-systems.md)

The two simple reflections generate a [dihedral group](dihedral-group.md). For $A_1\times A_1$, $A_2$, $B_2$, and $G_2$, the rotation has order $2,3,4,6$, so the Weyl groups have orders $4,6,8,12$ respectively.
