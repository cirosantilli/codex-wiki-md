# Fokker-Planck drift vector

↑ **Parent:** [Fokker-Planck equation](fokker-planck-equation.md)

The drift vector is the expected infinitesimal displacement per unit time. For jumps $r$ with rates $W(x,r)$, it is $A_i(x)=\sum_r r_iW(x,r)$. It is the first jump moment entering the [Fokker-Planck equation](fokker-planck-equation.md).
