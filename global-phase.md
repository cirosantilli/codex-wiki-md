# Global phase

↑ **Parent:** [Quantum phase](quantum-phase.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Global_phase)

A global phase multiplies an entire [quantum state](quantum-state.md) by one complex number of [modulus](modulus.md) one. It does not change any measurement probability, unlike a relative phase between components.
