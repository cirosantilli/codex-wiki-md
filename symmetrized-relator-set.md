# Symmetrized relator set

↑ **Parent:** [Group presentation](group-presentation.md)

A set of [relator](relator.md) words is symmetrized if it includes their inverses and cyclic permutations. Symmetrizing a finite set remains finite, preserves each [relator](relator.md)'s length and presents the same group. It permits a matching [relator](relator.md) segment to be taken anywhere on either orientation of a cell boundary.
