# Standard gravitational parameter

↑ **Parent:** [Newtonian gravitational field](newtonian-gravitational-field.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Standard_gravitational_parameter)

The product $\mu=GM$ of the [gravitational constant](gravitational-constant.md) and a central [mass](mass.md). In the exact relative [two-body problem](two-body-problem.md), the central parameter is $G(M_1+M_2)$. The appropriate conservative parameter can change when inverse-square [radiation pressure](radiation-pressure.md) is included in a dust [Kepler orbit](kepler-orbit.md).
