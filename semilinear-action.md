# Semilinear action

↑ **Parent:** [Galois descent of vector spaces](galois-descent-of-vector-spaces.md)

For an extension $L/K$ with [Galois group](galois-group.md) $G$, a [semilinear action](semilinear-action.md) on an $L$-space is an additive group action satisfying $\sigma(av)=\sigma(a)\sigma(v)$. Scalar coefficients are transformed along with vectors. Invariants form a $K$-space, and [Galois descent of vector spaces](galois-descent-of-vector-spaces.md) reconstructs the original space from it.
