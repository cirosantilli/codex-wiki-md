# Rank query

↑ **Parent:** [Data structure](data-structure-split.md)

A character [rank query](rank-query.md) asks how many occurrences of character $c$ appear in the first $r$ positions of a sequence. A [prefix sum](prefix-sum.md) array answers a single-character version in constant time after linear preprocessing; a [wavelet tree](wavelet-tree.md) supports many characters more compactly.
