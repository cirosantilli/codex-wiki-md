# Inverse Hessian relation for a connected two-point function

↑ **Parent:** [Connected correlation function](connected-correlation-function.md)

In the [scalar-field source Legendre transform](scalar-field-source-legendre-transform.md), differentiating $h=\delta\Gamma/\delta m$ with respect to the source and using $G=\delta m/\delta h$ yields this inverse-kernel relation. For a scalar quartic [Landau-Ginzburg theory](landau-ginzburg-theory.md), $\Gamma_{\rm L}^{(2)}=-\nabla^2+r_0+u_0m^2/2$, so the connected response is the Green kernel of that operator. A one-momentum representation requires a translationally invariant background.
