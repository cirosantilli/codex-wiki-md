# Sample path

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

For a [stochastic process](stochastic-process-split.md) $X_t$ and a fixed sample outcome $\omega$, its [sample path](sample-path.md) is the function $t\mapsto X_t(\omega)$. Statements about continuous, [càdlàg](cadlag.md) or [Hölder continuous function](holder-condition.md) [sample paths](sample-path.md) concern these functions simultaneously in time; they differ from assertions made only at each fixed deterministic time. A probability-one path property can be checked using countable dense times when the appropriate continuity is available.
