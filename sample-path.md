# Sample path

↑ **Parent:** [Stochastic process](stochastic-process-split.md)

For a [stochastic process](stochastic-process-split.md) $X_t$ and a fixed [sample space](sample-space.md) outcome $\omega$, its sample path is the [function](function-split.md) $t\mapsto X_t(\omega)$. One row of observed fair bits, one trajectory of a [random walk](random-walk-split.md), or one staircase of [Poisson process](poisson-process-split.md) arrival counts is a [sample path](sample-path.md). Fixing $t$ instead gives a [random variable](random-variable-split.md) ranging across possible histories. The same two-variable object $X_t(\omega)$ therefore describes both observations across outcomes and evolution within an outcome.

Statements about [continuous](continuous-function.md), [càdlàg](cadlag.md) or [Hölder continuous function](holder-condition.md) [sample paths](sample-path.md) concern these [functions](function-split.md) simultaneously in time. They differ from assertions made at each fixed time separately. For example, take $U$ with a [uniform distribution](continuous-uniform-distribution.md) on $[0,1]$ and set $X_t=\mathbf1_{\{t=U\}}$. For every fixed $t$, $X_t=0$ [almost surely](almost-sure-convergence.md), but every [sample path](sample-path.md) has a single spike. Thus this process is a [modification of a stochastic process](modification-of-a-stochastic-process.md) that is identically zero, while the two are not [indistinguishable stochastic processes](indistinguishability-of-stochastic-processes.md). [Continuity](continuous-function.md) of both sets of [sample paths](sample-path.md) rules out this discrepancy: equality at a countable dense set then implies equality everywhere. This is why path regularity is an additional part of constructing a continuous-time model.
