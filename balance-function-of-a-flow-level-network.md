# Balance function of a flow-level network

↑ **Parent:** [Flow-level network model](flow-level-network-model.md)

A positive balance function $\Phi$ expresses each active route's aggregate service as this ratio. With independent Poisson arrivals and exponential document sizes, [detailed balance](detailed-balance.md) yields stationary weights $\Phi(n)\prod_r\rho_r^{n_r}$, provided their sum is finite.
