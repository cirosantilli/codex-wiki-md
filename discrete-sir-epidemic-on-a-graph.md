# Discrete SIR epidemic on a graph

↑ **Parent:** [SIR model](sir-model.md)

In this discrete-time [SIR model](sir-model.md), each infected [vertex](vertex-graph-theory.md) is infectious for one step, can infect each susceptible [neighbour](neighbour-of-a-vertex.md) with probability $\beta$, and is then permanently removed. The [adjacency matrix of a graph](adjacency-matrix.md) describes the possible transmissions. If the initial removed set is empty, eventual removal and ever becoming infected are the same event.
