# Inductive-statistical model

↑ **Parent:** [Covering-law model](covering-law-model.md)

A form of [scientific explanation](scientific-explanation.md) using statistical laws and high [conditional probability](conditional-probability.md), relative to appropriate available information. A low-probability event can nevertheless have a [mechanistic explanation](mechanistic-explanation.md), so high [probability](probability.md) is not an uncontested necessary condition for explanation.
