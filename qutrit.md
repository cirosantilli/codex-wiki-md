# Qutrit

↑ **Parent:** [Quantum state](quantum-state.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Qutrit)

A qutrit is a three-dimensional [quantum system](quantum-system.md), with pure states $\alpha|0\rangle+\beta|1\rangle+\gamma|2\rangle$ satisfying $|\alpha|^2+|\beta|^2+|\gamma|^2=1$. A [qubit](qubit.md)-qutrit state is a bipartite state on $\mathbb C^2\otimes\mathbb C^3$.
