# Ballot reflection injection

↑ **Parent:** [Shifted set family](shifted-set-family.md)

For a member of a [shifted set family](shifted-set-family.md) that is an [intersecting family](intersecting-family.md), find the first prefix with more selected than unselected positions. Reflect membership in that prefix. The result has one fewer element and lies in the [lower shadow](lower-shadow.md); the first prefix with more unselected positions gives the inverse. This injection proves the [intersecting shadow lemma](intersecting-shadow-lemma.md).
