# Semidefinite programming

↑ **Parent:** [Convex optimization](convex-optimization-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Semidefinite_programming)

A semidefinite program optimizes a [linear function](linear-function.md) subject to equalities between [affine functions](affine-function.md) and [positive semidefinite matrix](positive-semidefinite-matrix.md) inequalities. It generalizes [linear programming](linear-programming.md): a diagonal [matrix](matrix.md) is a [positive semidefinite matrix](positive-semidefinite-matrix.md) exactly when its diagonal entries are nonnegative. [Matrix trace](matrix-trace.md) expresses the objective as $\langle C,X\rangle=\operatorname{tr}(CX)$ for real [symmetric matrices](symmetric-matrix.md).
