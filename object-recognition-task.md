# Object recognition task

↑ **Parent:** [Recognition memory](recognition-memory.md)

A task assessing prior occurrence of an object. In spontaneous exploration versions, a preference for a novel over a familiar object is informative only with sufficient exploration and controls for sensory ability, motivation, spatial cues and pre-existing object preferences.
