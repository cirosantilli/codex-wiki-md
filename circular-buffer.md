# Circular buffer

↑ **Parent:** [Data structure](data-structure.md)

A [circular buffer](circular-buffer.md) uses a fixed-capacity [array](array-data-structure.md) with indices that wrap through [modular arithmetic](modular-arithmetic.md). A front index and an occupied count can represent a [FIFO queue](fifo-queue.md) without shifting entries after removal. The [representation independence](representation-independence.md) example specifies a rejecting full-buffer policy; overwriting the oldest entry would define different behavior.
