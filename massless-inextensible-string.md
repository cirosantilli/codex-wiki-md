# Massless inextensible string

↑ **Parent:** [Tension](tension.md)

An ideal string of negligible [mass](mass.md) and fixed length, transmitting [tension](tension.md) when taut. In an ideal guide with no [friction](friction.md), the [tension](tension.md) magnitude is the same on both sides: otherwise the [force](force-split.md) balance on an arbitrarily short massless segment would fail. Its fixed length gives a [mechanical constraint](constraint-mechanics.md) relating the endpoint [velocities](velocity.md). The two endpoint [tension](tension.md) [powers](power.md) sum to zero when the guide is stationary; the string can transfer [energy](energy-split.md) between connected particles without adding net [energy](energy-split.md).
