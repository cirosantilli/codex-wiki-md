# Cofinite set

↑ **Parent:** [Cofinite filter](cofinite-filter.md)

A subset $E$ of a [set](set-split.md) $X$ is cofinite in $X$ when its complement $X\setminus E$ is a [finite set](finite-set.md). For infinite $X$, the cofinite subsets form the [cofinite filter](cofinite-filter.md). A [nonprincipal ultrafilter](nonprincipal-ultrafilter.md) on $\mathbb N$ contains every cofinite subset: it contains no singleton, hence no [finite set](finite-set.md), and decides between each [set](set-split.md) and its complement.
