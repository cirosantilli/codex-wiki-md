# Beyond-all-orders boundary-value sensitivity

↑ **Parent:** [Singular perturbation](singular-perturbation.md)

A homogeneous mode can be order one inside an interval and exponentially small at an endpoint. Adjusting an endpoint value beyond all algebraic orders can then change the interior solution by order one. In the [nested layers at an essential singular endpoint](nested-layers-at-an-essential-singular-endpoint.md) example, the mode $\exp(-x/\epsilon-2\epsilon^2/x)$ has this behavior: prescribed exact endpoint values give a unique solution for each fixed positive $\epsilon$, but leading asymptotic endpoint data do not select a unique bounded family.
