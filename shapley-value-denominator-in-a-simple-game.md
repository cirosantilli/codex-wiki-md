# Shapley value denominator in a simple game

↑ **Parent:** [Shapley value](shapley-value.md)

In an $n$-player [simple cooperative game](simple-cooperative-game.md), every [marginal contribution](marginal-contribution.md) along a player [permutation](permutation.md) is zero or one. The [Shapley value](shapley-value.md) is its average over the $n!$ equally likely [permutations](permutation.md). Thus $n!\phi_i(v)$ counts the orders in which player $i$ changes a losing [coalition](coalition-game-theory.md) into a winning one and is an [integer](integer-split.md). In lowest terms, the coordinate's denominator divides $n!$. This is a necessary constraint on a proposed [Shapley value](shapley-value.md) vector, not a sufficient one.
