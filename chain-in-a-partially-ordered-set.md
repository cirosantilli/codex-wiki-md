# Chain in a partially ordered set

↑ **Parent:** [Partially ordered set](partially-ordered-set.md)

A chain in a [partially ordered set](partially-ordered-set.md) is a subset in which every two elements are comparable.

The order induced on this subset is a [total order](total-order.md).
