# Finite-field Kakeya set

↑ **Parent:** [Vector space over a finite field](vector-space-over-a-finite-field.md)

A subset of $\mathbb F_q^n$ is a finite-field Kakeya set when it contains an [affine line in a vector space](affine-line-in-a-vector-space.md) in every one-dimensional direction. The line position may depend on the direction. The [polynomial method in combinatorics](polynomial-method-in-combinatorics.md) yields the [finite-field Kakeya polynomial bound](finite-field-kakeya-polynomial-bound.md) on its [cardinality](cardinality.md).
