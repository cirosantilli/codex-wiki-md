# Double pole

↑ **Parent:** [Pole](pole.md)

A double pole is a [pole](pole.md) of order two. If $f(z)=g(z)/(z-a)^2$ with $g$ holomorphic near $a$, then $\operatorname{Res}_{z=a}f=g'(a)$.
