# Neumann boundary-value problem

↑ **Parent:** [Boundary value problem](boundary-value-problem-split.md)

A [boundary value problem](boundary-value-problem-split.md) with prescribed outward [normal derivative](normal-derivative.md), or the associated weighted flux, on the boundary. Its boundary data are [Neumann boundary data](neumann-boundary-data.md). For an elliptic divergence-form operator without a zeroth-order term, integration over the domain imposes a compatibility condition between total source and boundary flux. A connected domain generally leaves a constant undetermined, fixed by a mean or reference value.
