# Covariant Yoneda embedding

↑ **Parent:** [Yoneda embedding](yoneda-embedding.md)

The covariant version of the [Yoneda embedding](yoneda-embedding.md) sends an object to its outgoing [representable functor](representable-functor.md). Precomposition reverses arrows. The [Yoneda lemma](yoneda-lemma.md) gives $\operatorname{Nat}(Y(A),Y(B))\cong\mathcal C(B,A)$, so it is [full and faithful](full-and-faithful-functor.md). It carries existing [colimits](colimit.md) in $\mathcal C$ to pointwise [categorical limits](categorical-limit.md).
