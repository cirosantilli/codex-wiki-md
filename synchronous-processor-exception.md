# Synchronous processor exception

↑ **Parent:** [Operating system](operating-system-split.md)

A processor event attributable to instruction execution, such as a [page fault](page-fault.md) during a memory access or a divide exception on [x86](x86.md). This causal connection distinguishes it from the asynchronous device [interrupts](interrupt.md) discussed here. It also differs from a programming language's [exception handling](exception-handling.md), which specifies how program-level exceptions propagate. [Linux kernel documentation, Kernel Entries: architecturally defined exceptions](https://docs.kernel.org/arch/x86/entry_64.html)
