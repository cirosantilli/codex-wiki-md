# Pure state

↑ **Parent:** [Quantum theory](quantum-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pure_state)

A pure quantum state is represented by a unit vector $|\psi\rangle$ up to global phase, or equivalently by the rank-one [density operator](density-matrix-split.md) $|\psi\rangle\langle\psi|$.
