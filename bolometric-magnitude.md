# Bolometric magnitude

↑ **Parent:** [Luminosity](luminosity.md)

A logarithmic [luminosity](luminosity.md) or measured [radiative flux](radiative-flux.md) scale using radiation integrated over all wavelengths, in contrast to a measurement in one observing band. [Absolute magnitude](absolute-magnitude.md) uses the flux the object would have at ten [parsecs](parsec.md); [apparent magnitude](apparent-magnitude.md) uses its measured flux. Neglecting extinction, $m_{\rm bol}-M_{\rm bol}=5\log_{10}(d/10\,\mathrm{pc})$.
