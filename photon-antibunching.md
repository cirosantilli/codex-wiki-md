# Photon antibunching

↑ **Parent:** [Photon statistics](photon-statistics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Photon_antibunching)

[Photon antibunching](photon-antibunching.md) means suppression of close pairs compared with pairs at some later delay: $g^{(2)}(0)<g^{(2)}(\tau)$ for some $\tau$. If correlations decay to the independent-count reference, $g^{(2)}(0)<1$ is a sufficient signature. It violates the classical intensity bounds in [photon bunching](photon-bunching.md). For the specified single-mode number measurement, [second-order optical coherence](second-order-optical-coherence.md) also shows that $g^{(2)}(0)<1$ is equivalent to $\operatorname{Var}N<\mu$. This variance criterion concerns that mode or gate; it must not be applied unchanged to arbitrarily long integrated counting intervals.
