# Splay tree

↑ **Parent:** [Binary search tree](binary-search-tree.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Splay_tree)

A [splay tree](splay-tree.md) is a [binary search tree](binary-search-tree.md) whose access operations use [splaying](splaying.md) to move a selected key to the root through [tree rotations](tree-rotation.md). It stores no explicit balance or height information. A single access can take linear time, while the standard operations have logarithmic [amortized time complexity](amortized-time-complexity.md). The distinction matters: [amortized analysis](amortized-analysis.md) bounds the total cost of an operation sequence, not the worst cost of every individual operation.[Author-hosted abstract: representation, operations and amortized logarithmic bound](self-adjusting-binary-search-trees-by-daniel-sleator-and-robert-tarjan.md)
