# Inverse demand function

↑ **Parent:** [Elastic-demand Wardrop equilibrium](elastic-demand-wardrop-equilibrium.md)

A strictly decreasing demand function has a decreasing inverse on its range. The utility primitive $\int P_s(u)\,du$ is a [concave function](concave-function.md). A positive interior reference value avoids assuming that an improper integral from zero is finite.
