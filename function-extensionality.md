# Function extensionality

↑ **Parent:** [Function](function-split.md)

For two mathematical [functions](function-split.md) $f,g:A\to B$ with the same domain and codomain, equality is equivalent to equality of their values at every argument. In the set-theoretic representation, their [graphs of functions](graph-of-a-function.md) then contain exactly the same ordered pairs. This permits a function identity to be proved by fixing an arbitrary argument and proving the resulting value equality.
