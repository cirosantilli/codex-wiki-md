# List (abstract data type)

↑ **Parent:** [Data structure](data-structure-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/List_(abstract_data_type))

A [list](list-abstract-data-type.md) is an ordered collection in which entries may repeat. Removing duplicates would discard information about both multiplicity and, depending on the representation, order. A [linked list](linked-list.md) and an [array](array-data-structure.md) are different ways to implement list operations.
