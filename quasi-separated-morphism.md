# Quasi-separated morphism

↑ **Parent:** [Morphism of schemes](morphism-of-schemes.md)

A [morphism of schemes](morphism-of-schemes.md) $f:X\to S$ is quasi-separated if its [diagonal morphism](diagonal-morphism.md) $X\to X\times_SX$ is a [quasi-compact morphism](quasi-compact-morphism.md). Every [separated morphism](separated-morphism.md) has this property since a [closed immersion](closed-immersion.md) is a [quasi-compact morphism](quasi-compact-morphism.md). This compactness condition is needed when uniqueness in the [valuative criterion](valuative-criterion.md) is used to deduce [separatedness](separated-morphism.md) for arbitrary [schemes](scheme.md).
