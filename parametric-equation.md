# Parametric equation

↑ **Parent:** [Geometry and topology](geometry-and-topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Parametric_equation)

A [parametric equation](parametric-equation.md) expresses coordinates as [functions](function-split.md) of one or more independent parameters. For example, $x=\cos t$, $y=\sin t$ describes a [circle](circle.md); multiple parameters describe surfaces. A [smooth curve](smooth-curve.md) is a differentiable single-parameter realization. A [reparametrization](reparametrization.md) changes the parameter without changing the geometric image.
