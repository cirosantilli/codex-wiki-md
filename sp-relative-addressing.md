# SP-relative addressing

↑ **Parent:** [Addressing mode](addressing-mode.md)

[SP-relative addressing](sp-relative-addressing.md) adds an encoded displacement to the [stack pointer](stack-pointer.md). Scaling an [immediate operand](immediate-operand.md) by a power of two reaches farther with the same field width but restricts the address grid. An eight-bit nonnegative field scaled by four reaches $0,4,\ldots,1020$, whereas scaling it by sixteen reaches $0,16,\ldots,4080$; it does not provide every intervening byte address.
