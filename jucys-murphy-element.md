<h1 id="jucys-murphy-element">Jucys–Murphy element</h1>

↑ **Parent:** [Gelfand–Tsetlin algebra](gelfand-tsetlin-algebra.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Jucys–Murphy_element)

In the [group algebra](group-algebra.md) $\mathbb C S_n$, set

$$
X_1=0,\qquad X_r=\sum_{j<r}(j\ r).
$$

These elements commute: for each triple $a<i<j$, the only overlapping contributions cancel as $[(a\ i),(i\ j)+(a\ j)]=0$. They generate the [Gelfand–Tsetlin algebra](gelfand-tsetlin-algebra.md), and on a [standard Young tableau](standard-young-tableau.md) vector $X_r$ acts by the [Content of a Young-diagram cell](content-of-a-young-diagram-cell.md) containing $r$.
