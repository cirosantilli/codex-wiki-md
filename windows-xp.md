# Windows XP

↑ **Parent:** [Operating system](operating-system.md)

A member of the Windows NT operating-system family. Executive services such as object, memory and input-output management execute in privileged kernel mode. Its object-level [access control lists](access-control-list.md) and subject tokens permit finer authorization policies than traditional owner-group-other file permissions.
