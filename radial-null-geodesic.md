# Radial null geodesic

↑ **Parent:** [Null geodesic](null-geodesic.md)

A [radial null geodesic](radial-null-geodesic.md) in a spherically symmetric [spacetime](spacetime.md) has zero [angular momentum](angular-momentum.md) and fixed angular coordinates. Its projection is a null curve of the two-dimensional radial [Lorentzian metric](lorentzian-metric.md).
