# Generating set of a group

↑ **Parent:** [Group](group-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generating_set_of_a_group)

A subset $S$ of a [group](group-split.md) $G$ is a generating set when every element of $G$ is a finite product of elements of $S$ and their inverses, equivalently when the [subgroup](subgroup.md) $\langle S\rangle$ generated by $S$ equals $G$.
