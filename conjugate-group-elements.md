# Conjugate group elements

↑ **Parent:** [Conjugation](conjugation.md)

Two group elements $x$ and $y$ are conjugate when $y=gxg^{-1}$ for some group element $g$, equivalently when they belong to the same [conjugacy class](conjugacy-class.md). Conjugate elements have the same [order of a group element](order-of-a-group-element.md).
