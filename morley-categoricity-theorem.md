# Morley categoricity theorem

↑ **Parent:** [Categorical theory](categorical-theory.md)

This theorem is the uncountable categoricity theorem for a [categorical theory](categorical-theory.md). If a countable first-order theory is categorical in one uncountable cardinal, then it is categorical in every uncountable cardinal.
