# Matrix-game optimization problem

↑ **Parent:** [Matrix game](matrix-game.md)

The row player solves

$$
\max_{p,v}v
\quad\text{subject to}\quad
A^Tp\geq ve,quad e^Tp=1,quad p\geq0.
$$
