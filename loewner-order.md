# Loewner order

↑ **Parent:** [Positive semidefinite matrix](positive-semidefinite-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Loewner_order)

The Loewner order on [Hermitian matrices](hermitian-operator.md) is defined by $A\preceq B$ when $B-A$ is a [positive semidefinite matrix](positive-semidefinite-matrix.md).
