# Affine algebraic curve

↑ **Parent:** [Algebraic curve](algebraic-curve.md)

An affine algebraic curve is an [affine variety](affine-algebraic-set.md) of [Krull dimension](krull-dimension.md) one. An irreducible affine curve has a finitely generated one-dimensional domain as its [coordinate ring](coordinate-ring.md). Quotienting this ring by a nonzero element gives a zero-dimensional [Noetherian ring](noetherian-ring.md), hence an [Artinian ring](artinian-ring.md). Consequently a nonzero regular function has finitely many zeros. No nonsingularity assumption is part of the definition.
