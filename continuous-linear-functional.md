# Continuous linear functional

↑ **Parent:** [Continuous linear operator](continuous-linear-operator.md)

A continuous linear functional is a continuous linear map from a [topological vector space](topological-vector-space-split.md) to its scalar field. The collection of all such functionals is the [continuous dual space](continuous-dual-space-split.md).
