# Partial type

↑ **Parent:** [First-order theory](first-order-theory.md)

A partial type over a [first-order theory](first-order-theory.md) $T$ is a set of [first-order formulas](first-order-formula.md) in a fixed finite tuple of variables which is jointly consistent with $T$. A tuple realizes it when it satisfies every formula in the set. A [complete type](complete-type.md) additionally decides every formula in those variables.
