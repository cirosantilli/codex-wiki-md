# Arithmetical provability predicate

↑ **Parent:** [Gödel numbering](godel-numbering.md)

For an effectively axiomatized [arithmetic](arithmetic-split.md) theory, a [arithmetical provability predicate](arithmetical-provability-predicate.md) expresses that a [formal proof](formal-proof.md) of the sentence with a specified code exists. If axioms are only enumerated, proof certificates also record finite stages at which their axioms appear. The resulting predicate is arithmetically expressible.
