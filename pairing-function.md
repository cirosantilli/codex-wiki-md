# Pairing function

↑ **Parent:** [Computability theory](computability-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pairing_function)

A pairing function is a computable bijection from $\mathbb N_0^2$ to $\mathbb N_0$ whose inverse coordinate functions are also computable. Iterating it gives computable encodings of every fixed finite tuple of nonnegative integers.
