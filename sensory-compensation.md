# Sensory compensation

↑ **Parent:** [Crossmodal plasticity](crossmodal-plasticity.md)

Adaptation supporting task performance when sensory input is reduced. Practice, altered [attention](attention.md), use of alternative cues and changes in neural recruitment can interact. Improvement in one task can coexist with limitations in another.
