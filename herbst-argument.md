# Herbst argument

↑ **Parent:** [Modified logarithmic Sobolev inequality](modified-logarithmic-sobolev-inequality.md)

The Herbst argument integrates a logarithmic Sobolev bound on $\lambda H'(\lambda)-H(\lambda)$ to control the centered cumulant-generating function $H$, then applies a [Chernoff bound](chernoff-bound.md) to obtain concentration.
