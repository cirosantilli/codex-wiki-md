# Infinite path through a binary tree

↑ **Parent:** [Binary tree of finite strings](binary-tree-of-finite-strings.md)

An infinite path is a binary [function](function-split.md) all of whose finite prefixes belong to the tree. Its path space $[T]$ is closed in [Cantor space](cantor-space.md), since failure is witnessed by one finite prefix outside $T$.
