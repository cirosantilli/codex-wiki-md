# Static type

↑ **Parent:** [Type system](type-system.md)

The type assigned to a program expression during type checking. It controls which members and overloads are available at that expression. A reference with a broad [static type](static-type.md) can designate an object with a narrower [runtime type](runtime-type.md); that does not expose additional overloads through the broad reference.
