# Squared bound from comparison at values

↑ **Parent:** [Value in a lattice-ordered group](value-in-a-lattice-ordered-group.md)

Let $p,q,x\geq1$ in a [lattice-ordered group](lattice-ordered-group.md). Under the displayed hypothesis, suppose $d=(xq^{-2}p^{-2})\vee1>1$ and choose a value $P$ of $d$. If $x\in P$, then $1\leq d\leq x$ contradicts its omission. Otherwise extend $P$ to a value $V$ of $x$. The right-coset test is $Vu\leq Vv\iff(uv^{-1})\vee1\in V$. If $p\notin V$, put $c=(xq^{-2}p^{-1})\vee1\in V$. Then $(pc^{-1})\vee1\notin V$, while its inverse positive part is $(cp^{-1})\vee1=d$. These parts have [meet](greatest-lower-bound-in-a-partially-ordered-set.md) one, so primeness of $P$ forces $d\in P$. If $p\in V$, put $c=(xq^{-1})\vee1\in V$ and $t=p^2q\notin V$; the disjoint pair $(tc^{-1})\vee1$ and $(ct^{-1})\vee1=d$ gives the same contradiction. No normality assumption is used in this separation argument.
