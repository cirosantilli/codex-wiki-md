# Paired forcing name

↑ **Parent:** [Forcing name](forcing-name.md)

For the condition-first [forcing name](forcing-name.md) convention, pair every condition with each of two names $\tau,\tau'$. Under any nonempty [generic filter](generic-filter.md), the [evaluation of a forcing name](evaluation-of-a-forcing-name.md) is then $\{\tau_G,\tau'_G\}$, the unordered pair of the two values. Equal values give a singleton. With the name-first convention, reverse the two components of each syntactic pair.
