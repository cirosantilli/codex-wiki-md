# B-spline

↑ **Parent:** [Spline approximation](spline-approximation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/B-spline)

A B-spline is a compactly supported piecewise polynomial basis function determined by consecutive knots.
