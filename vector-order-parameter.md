# Vector order parameter

↑ **Parent:** [Order parameter](order-parameter.md)

A vector order parameter has several components transforming together as a [vector](vector.md) under spatial rotations. A [polar order parameter](polar-order-parameter.md) is an example. Its [functional derivative](functional-derivative.md) $\delta F/\delta\mathbf p$ has one component for each component of the [order parameter](order-parameter.md).
