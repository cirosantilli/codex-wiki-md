# Golden-section search

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

An [optimization](mathematical-optimization-split.md) [algorithm](algorithm-split.md) that brackets an extremum of a unimodal [function](function-split.md) on an [interval](interval-mathematics.md). Two interior probes divide the bracket in the golden ratio; after discarding one side, one probe can be reused, so each subsequent contraction needs only one new [function](function-split.md) evaluation.
