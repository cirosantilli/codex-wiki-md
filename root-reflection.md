# Root reflection

↑ **Parent:** [Root system](root-system.md)

For a nonzero vector $\alpha$ in a [Euclidean normed vector space](euclidean-norm.md), the root reflection is

$$
s_\alpha(v)=v-\frac{2(v,\alpha)}{(\alpha,\alpha)}\alpha.
$$

It fixes the hyperplane perpendicular to $\alpha$ and sends $\alpha$ to $-\alpha$.
