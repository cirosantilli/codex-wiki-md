# Knaster forcing preserves Suslin trees

↑ **Parent:** [Knaster forcing](knaster-forcing.md)

If $T$ is a normal splitting [Suslin tree](suslin-tree.md) and $P$ is Knaster, then $P\times T$ is [CCC](countable-chain-condition-for-forcing.md), so $P$ forces that the ground tree is still [CCC](countable-chain-condition-for-forcing.md) Countable levels and splitting persist. A new [cofinal branch](cofinal-branch.md) would give an uncountable antichain by splitting, so none is added. This permits adding many Cohen reals while retaining a Suslin tree, and distinguishes Knaster preservation from an unjustified preservation claim for every [CCC](countable-chain-condition-for-forcing.md) [forcing](forcing-split.md).
