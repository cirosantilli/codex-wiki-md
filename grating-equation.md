# Grating equation

↑ **Parent:** [Diffraction grating](diffraction-grating.md)

For a reflection [diffraction grating](diffraction-grating.md) with both ray directions measured on the same side of its normal, adjacent grooves have path difference $d(\sin\alpha+\sin\beta)$. [Constructive interference](constructive-interference.md) requires this to be an integer multiple $m\lambda$. Signed-angle conventions can turn the sum into a difference; the physical path difference is unchanged.
