# Lambda quotation

↑ **Parent:** [Gödel numbering](godel-numbering.md)

For an effective [Gödel numbering](godel-numbering.md) $M\mapsto\#M$, the quotation $d(M)=c_{\#M}$ is a [Church numeral](church-numeral.md) coding the syntax of $M$. It is not a code of a [beta equivalence](beta-equivalence.md) class. The operations taking syntax codes to the code of an application, or to the code of the numeral itself, are [total computable functions](total-computable-function.md) and hence [lambda-definable functions](lambda-definable-function.md).
