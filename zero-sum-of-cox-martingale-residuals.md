# Zero sum of Cox martingale residuals

↑ **Parent:** [Martingale residual](martingale-residual.md)

When a [Cox proportional-hazards model](cox-proportional-hazards-model.md) uses the [Breslow estimator](breslow-estimator.md), the sum of fitted [martingale residuals](martingale-residual.md) is zero. Each estimated [baseline hazard](baseline-hazard.md) jump redistributes one observed event across its [risk set](risk-set.md), so summing cumulative fitted intensities equals summing observed event counts. The identity holds for any finite regression coefficient used consistently in both calculations.
