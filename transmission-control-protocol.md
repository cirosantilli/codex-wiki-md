# Transmission Control Protocol

↑ **Parent:** [Transport protocol](transport-protocol.md)

[Transmission Control Protocol](transmission-control-protocol.md) provides a reliable ordered byte-stream service between its [endpoints](communication-endpoint.md), using sequencing, acknowledgements and retransmission. Receipt by that transport does not establish that a receiving application has durably stored the data or completed a user operation.[§§1.5 and 2.6: operation and reliable communication](transmission-control-protocol-rfc-793.md)
