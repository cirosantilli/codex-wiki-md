# Meromorphic function as a holomorphic map to the Riemann sphere

↑ **Parent:** [Meromorphic function](meromorphic-function.md)

A meromorphic function on a [Riemann surface](riemann-surfaces.md) is equivalently a holomorphic map to the [Riemann sphere](riemann-sphere.md), with every pole mapped to infinity. Composition with a rational self-map of the sphere is again such a holomorphic map.
