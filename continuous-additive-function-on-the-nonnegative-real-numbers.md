# Continuous additive function on the nonnegative real numbers

↑ **Parent:** [Additive function](additive-function.md)

If $f:[0,\infty)\to\mathbb R$ is [continuous](continuous-function.md) and is an [additive function](additive-function.md), then $f(t)=tf(1)$. Additivity proves this first for nonnegative [rational numbers](rational-number.md); because $f$ is [continuous](continuous-function.md), the identity extends to every nonnegative [real number](real-number.md).
