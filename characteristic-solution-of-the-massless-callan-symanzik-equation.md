# Characteristic solution of the massless Callan-Symanzik equation

↑ **Parent:** [Callan-Symanzik equation](callan-symanzik-equation.md)

For fixed external momenta, the massless [Callan-Symanzik equation](callan-symanzik-equation.md) is $(\mu\partial_\mu+\beta(\lambda)\partial_\lambda+n\gamma_\phi)G_n=0$. Choose a [running coupling](running-coupling.md) satisfying $d\lambda/d\log\mu=\beta(\lambda)$ and $\lambda(\mu_0)=\lambda_0$. The [chain rule](chain-rule.md) reduces the equation along this curve to $dG_n/d\log\mu=-n\gamma_\phi G_n$, whose integrating factor gives the displayed solution. The reference [correlation function](correlation-function.md) at $\mu_0$ supplies boundary data; the [renormalization group](renormalization-group.md) alone does not determine these data.

If $\beta=b\lambda^2$, then $\lambda(\mu)=\lambda_0/[1-b\lambda_0\log(\mu/\mu_0)]$. If in addition the [anomalous dimension](anomalous-dimension.md) is $\gamma_\phi=c\lambda^2$, the integral in the exponent is $(c/b)(\lambda(\mu)-\lambda_0)$. These formulas use the stipulated truncated [renormalization group](renormalization-group.md) functions and apply on a branch on which the running solution remains defined.
