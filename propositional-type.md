# Propositional type

↑ **Parent:** [Propositional theory](propositional-theory.md)

A [propositional type](propositional-type.md) is a collection of [propositional formulas](propositional-formula.md) to be jointly realized by a [Boolean valuation](boolean-valuation.md). A valuation realizes it when every member is true and omits it when some member is false. For propositional omission arguments, the collection need not itself be consistent.
