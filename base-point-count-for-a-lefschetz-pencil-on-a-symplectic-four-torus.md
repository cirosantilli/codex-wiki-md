# Base-point count for a Lefschetz pencil on a symplectic four-torus

↑ **Parent:** [Lefschetz pencil](lefschetz-pencil.md)

The standard four-[torus](torus.md) has trivial complex tangent bundle, so its [symplectic canonical class](symplectic-canonical-class.md) is zero. The [symplectic adjunction formula](symplectic-adjunction-formula.md) gives $F^2=2g-2$ for a smooth genus-$g$ fiber of a symplectic [Lefschetz pencil](lefschetz-pencil.md). Two generic fibers meet once positively at each base point and nowhere else, giving the displayed count.
