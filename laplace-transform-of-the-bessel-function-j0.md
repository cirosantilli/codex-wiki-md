# Laplace transform of the Bessel function J0

↑ **Parent:** [Laplace transform](laplace-transform.md)

For real $p>0$, the [Laplace transform](laplace-transform.md) $G$ of the order-zero [Bessel function of the first kind](bessel-function-of-the-first-kind.md) satisfies $(1+p^2)G'+pG=0$. This follows by transforming $xJ_0''+J_0'+xJ_0=0$, using $\mathcal L[xg]=-\partial_p\mathcal L[g]$ and $J_0(0)=1$, $J_0'(0)=0$. Thus $G=C/\sqrt{1+p^2}$; the [initial value theorem for Laplace transforms](initial-value-theorem-for-laplace-transforms.md) gives $pG(p)\to1$ and fixes $C=1$.
