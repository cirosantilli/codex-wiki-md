# Standard Prelude

↑ **Parent:** [Haskell](haskell.md)

The automatically available standard module of [Haskell](haskell.md), supplying basic types, classes and operations such as [list folds](list-fold.md), arithmetic and [list comprehension](list-comprehension.md) support. A program can explicitly hide an imported name when providing an alternative definition. The reference definitions specify behavior, rather than requiring a particular implementation strategy.[Chapter 9, introductory paragraphs and module Prelude exports](haskell-2010-language-report.md)
