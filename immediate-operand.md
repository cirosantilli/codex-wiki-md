# Immediate operand

↑ **Parent:** [Addressing mode](addressing-mode.md)

An [immediate operand](immediate-operand.md) is a value encoded in an instruction rather than fetched from a [processor register](processor-register.md) or a separate memory location. Its width and interpretation limit the available values; scaling an encoded field can trade address granularity for displacement range.
