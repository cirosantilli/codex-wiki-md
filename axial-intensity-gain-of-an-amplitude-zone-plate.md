# Axial intensity gain of an amplitude zone plate

↑ **Parent:** [Zone plate](zone-plate.md)

For uniform coherent plane-wave illumination, an ideal binary amplitude [zone plate](zone-plate.md) transmits alternate [Fresnel half-period zones](fresnel-half-period-zone.md). If $N_o$ complete odd zones are open, every one contributes approximately twice the unobstructed axial [complex amplitude](complex-amplitude.md), in the same phase, and $I_f/I_0\simeq4N_o^2$. This is a local [light intensity](light-intensity.md) gain relative to removing the plate and outer stop. It differs from comparison with a finite clear [aperture](aperture.md): an [aperture](aperture.md) containing an odd integer number of half-period zones has axial [intensity](intensity-physics.md) $4I_0$, giving plate-to-aperture ratio $N_o^2$. Neither gain is a total [power](power.md) efficiency.
