# Small difference set forces a three-term arithmetic progression

↑ **Parent:** [Freiman-Ruzsa theorem](freiman-ruzsa-theorem.md)

For every $C$ there is $N(C)$ such that a set $A\subseteq\mathbb Z$ with $|A|\geq N(C)$ and $|A-A|\leq C|A|$ contains a nontrivial three-term [arithmetic progression](arithmetic-progression.md). The [Freiman-Ruzsa theorem](freiman-ruzsa-theorem.md) places $A$ densely in a bounded-rank coset progression, where the [Szemerédi theorem in a bounded-rank coset progression](szemeredi-theorem-in-a-bounded-rank-coset-progression.md) applies.
