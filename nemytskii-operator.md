# Nemytskii operator

↑ **Parent:** [Functional analysis](functional-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nemytskii_operator)

The [Nemytskii operator](nemytskii-operator.md) associated with a scalar function $f$ applies $f$ pointwise to a function. The domain and target [function spaces](function-space.md) must be specified; an arbitrary continuous $f$ need not preserve them. On a finite-measure domain, a bounded continuous $f:\mathbb R\to\mathbb R$ defines a continuous map $N_f:L^2\to L^2$ with $\|N_f(u)\|_2\leq\|f\|_\infty|\Omega|^{1/2}$. To prove continuity, extract an almost-everywhere convergent further subsequence from every $L^2$-convergent subsequence and apply the [dominated convergence theorem](dominated-convergence-theorem.md) to $|f(u_j)-f(u)|^2$. This forces convergence of the entire image sequence in $L^2$.
