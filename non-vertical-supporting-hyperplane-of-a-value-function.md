# Non-vertical supporting hyperplane of a value function

↑ **Parent:** [Value function](value-function.md)

At a point where $\phi(b)$ is finite, this is an affine plane supporting the [epigraph](epigraph.md) from below: $\phi(u)\geq\phi(b)+\lambda^T(u-b)$ for every $u$. A nonzero coefficient of the vertical coordinate permits normalization to the displayed graph form. For a constrained [value function](value-function.md), the slope is exactly an attained multiplier in the [Strong Lagrangian property](strong-lagrangian-property.md). When the [value function](value-function.md) is differentiable at an interior point of its finite domain, a supporting slope equals its [gradient](gradient.md): apply the supporting inequality along both positive and negative multiples of each coordinate direction and take limits.
