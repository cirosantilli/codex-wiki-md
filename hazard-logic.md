# Hazard (logic)

↑ **Parent:** [Combinational logic](combinational-logic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hazard_(logic))

A transient output error caused by timing differences in a [Boolean circuit](boolean-circuit.md). A static hazard temporarily changes an output that should remain constant; a dynamic hazard introduces extra transitions when the output should change once. A steady-state [truth table](truth-table.md) cannot detect these timing effects. [Consensus theorem](consensus-theorem.md) terms can remove single-input static hazards in a [sum of products](disjunctive-normal-form.md), while simultaneous input changes may still produce other hazards.
