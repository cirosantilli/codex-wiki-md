# State monad transformer

↑ **Parent:** [Monad transformer](monad-transformer.md)

A [state monad](state-monad.md) layered over a base [computational monad](computational-monad.md). An unsuccessful base computation may return no final [program state](program-state.md); this matters when combining it with an [exception monad transformer](exception-monad-transformer.md).
