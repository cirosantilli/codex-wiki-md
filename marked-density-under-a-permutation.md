# Marked density under a permutation

↑ **Parent:** [Grover's algorithm](grover-s-algorithm.md)

For a [permutation](permutation.md) $f$ of an $N$-element set and a known marked output subset of size $K$, exactly $K$ inputs have marked outputs. The [uniform quantum superposition](uniform-quantum-superposition.md) thus has good probability $K/N$, independent of which permutation the oracle represents. This allows a known-angle [amplitude amplification](amplitude-amplification.md) schedule without counting unknown preimages.
