# Complementary error function

↑ **Parent:** [Error function](error-function.md)

The complementary [error function](error-function.md) avoids subtracting a quantity close to one when describing a small [Gaussian integral](gaussian-integral.md) tail. For real $x>0$, $\operatorname{erfc}x=(2/\sqrt\pi)\int_x^\infty e^{-t^2}\,dt$; [analytic continuation](analytic-continuation.md) defines it for complex arguments.
