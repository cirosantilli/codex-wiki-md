# Fiducial self-shielding in a xenon detector

↑ **Parent:** [Dual-phase xenon detector](dual-phase-xenon-detector.md)

Selecting an inner [fiducial volume](fiducial-volume.md) reduces externally produced [radiation](radiation.md) because outer [xenon](xenon.md) attenuates it before it reaches the selected target. This trades target [mass](mass.md) for reduced background. It does not remove uniformly distributed internal radioactivity or every neutron recoil, so purification, veto information and [calibration](calibration-differential-geometry.md) remain important.
