# Bell-LaPadula model

↑ **Parent:** [Access control](access-control.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bell–LaPadula_model)

A classification-based [information confidentiality](information-confidentiality.md) model restricting subject accesses to prevent forbidden information flow. The [simple security property](simple-security-property.md) restricts reading above clearance; the [Bell-LaPadula star property](bell-lapadula-star-property.md) restricts information flow through current reads and writes. It is not a complete [data integrity](data-integrity.md) policy.
