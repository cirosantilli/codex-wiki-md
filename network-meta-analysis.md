# Network meta-analysis

↑ **Parent:** [Meta-analysis](meta-analysis.md)

A network meta-analysis jointly compares several treatments using a [graph](graph-split.md) of direct [randomized controlled trials](randomized-controlled-trial.md) and [indirect treatment comparisons](indirect-treatment-comparison.md). If effects are measured relative to a reference treatment, consistency means $\delta_{ij}=\delta_{i0}-\delta_{j0}$. A connected [graph](graph-split.md) identifies all relative effects under that model. [Transitivity in network meta-analysis](transitivity-in-network-meta-analysis.md) is the substantive comparability assumption supporting these relations; inconsistency can be assessed when the network has loops.
