# Function in intension

↑ **Parent:** [Computability theory](computability-theory.md)

A function in intension is a finite program or formal construction description. Its associated [function in extension](function-in-extension.md) is the partial or total input-output map it denotes. A [Gödel number](godel-number.md) records the description rather than identifying all descriptions with the same extension.
