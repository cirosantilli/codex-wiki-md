# Spectral Green function of a regular Sturm-Liouville problem

↑ **Parent:** [Sturm-Liouville eigenfunction expansion](sturm-liouville-eigenfunction-expansion.md)

Normalize the real [eigenfunctions](eigenfunction.md) using $\int r y_my_n=\delta_{mn}$. For $\mu$ outside the [spectrum](spectrum-functional-analysis.md), applying the operator to the displayed [Green function](green-s-function.md) expansion gives $r(x)\sum_n y_n(x)y_n(\xi)=\delta(x-\xi)$ by weighted completeness. This is the kernel with respect to ordinary source integration $d\xi$; using the weighted measure would change its normalization.
