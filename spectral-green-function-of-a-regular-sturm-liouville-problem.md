# Spectral Green function of a regular Sturm-Liouville problem

↑ **Parent:** [Sturm-Liouville eigenfunction expansion](sturm-liouville-eigenfunction-expansion.md)

Write $\mathcal A y=-(py')'+qy$ and $\mathcal A y_n=\lambda_n r y_n$, where $r$ is the positive weight. Normalize the real [eigenfunctions](eigenfunction.md) using $\int r y_my_n=\delta_{mn}$. For $\mu$ outside the [spectrum](spectrum-functional-analysis.md), applying $\mathcal A-\mu r$ to the displayed [Green function](green-s-function-split.md) expansion gives $r(x)\sum_n y_n(x)y_n(\xi)=\delta(x-\xi)$ by weighted completeness. This is the kernel with respect to ordinary source integration $d\xi$; using the weighted measure would change its normalization.
