# Digital root

↑ **Parent:** [Numerical digit](numerical-digit.md)

Repeatedly sum the [numerical digits](numerical-digit.md) of a [nonnegative integer](natural-number.md) in base $b$ until a single [numerical digit](numerical-digit.md) remains. For $n>0$, the result is $1+((n-1)\bmod(b-1))$, while the result for zero is zero. This follows because $b\equiv1\pmod{b-1}$, so summing [numerical digits](numerical-digit.md) preserves the [integer congruence](integer-congruence.md) class [modulo](modulo-operation.md) $b-1$.
