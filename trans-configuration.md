# Trans configuration

↑ **Parent:** [Stereochemistry](stereochemistry-split.md)

A [trans configuration](trans-configuration.md) places the specified substituents on opposite sides of a restricted structural element. For comparable fatty-acyl chains, trans unsaturation usually permits closer packing than cis unsaturation.
