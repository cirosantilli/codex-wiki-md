# Integer matrix

↑ **Parent:** [Matrix](matrix.md)

An integer matrix is a [matrix](matrix.md) whose entries are [integers](integer-split.md). Sums and products of compatible [integer matrices](integer-matrix.md) remain [integer matrices](integer-matrix.md), but a nonsingular square [integer matrix](integer-matrix.md) can have a nonintegral [inverse matrix](matrix-inverse-split.md). The [unimodular matrix](unimodular-matrix.md) condition characterizes exactly when that [inverse matrix](matrix-inverse-split.md) also has integer entries.
