# Inverse branch

↑ **Parent:** [Inverse function](inverse-function.md)

An inverse branch of a [function](function-split.md) $f$ on a set $J$ is an [inverse function](inverse-function.md) $g:J\to I$ of a bijective restriction $f|_I:I\to J$. Different restrictions can give different branches on the same $J$. Their [function compositions](function-composition.md) describe successive preimages and [itinerary cylinders](itinerary-cylinder.md) in an [interval map](interval-map.md).
