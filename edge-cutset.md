# Edge cutset

↑ **Parent:** [Cut (graph theory)](cut-graph-theory.md)

An edge cutset separating two vertices is a set of edges whose removal leaves no [path in a graph](path-in-a-graph.md) between those vertices. For a vertex set containing exactly one of the two vertices, its [edge boundary](edge-boundary-in-a-graph.md) is such a cutset.
