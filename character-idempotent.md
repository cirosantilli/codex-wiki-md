# Character idempotent

↑ **Parent:** [Group algebra](group-algebra.md)

If the order of a finite abelian group $\Delta$ is invertible in the coefficient ring and all its character values belong to that ring, its character idempotents are orthogonal and sum to one. They decompose any [module](module-mathematics.md) into character components. In a cyclotomic tower with odd $p$, the [Teichmüller character](teichmuller-character.md) provides these components integrally over $\mathbb Z_p$.
