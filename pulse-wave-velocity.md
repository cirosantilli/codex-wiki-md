# Pulse wave velocity

↑ **Parent:** [Arterial pulse](arterial-pulse.md)

The propagation speed inferred from an effective path distance and the travel-time difference of corresponding features in two arterial waveforms. Path definition, synchronized timing and reflections matter; a pulse peak need not track an unchanged waveform.[Pressure-waveform acquisition and transit-time estimation](2024-recommendations-for-validation-of-noninvasive-arterial-pulse-wave-velocity-measurement-devices.md)
