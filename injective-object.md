# Injective object

↑ **Parent:** [Category theory](category-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Injective_object)

An object $I$ is injective when every morphism $A\to I$ extends across every [monomorphism](monomorphism.md) $A\hookrightarrow B$ to a morphism $B\to I$. This is the categorical extension property of an [injective module](injective-module.md) or an [injective sheaf](injective-sheaf.md); it is dual to the lifting property of a [projective object in a category](projective-object.md).
