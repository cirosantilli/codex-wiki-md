# Coordination game

↑ **Parent:** [Bimatrix game](bimatrix-game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Coordination_game)

A [coordination game](coordination-game.md) rewards compatible choices. Players can have a common interest in coordinating while having different preferred coordinated outcomes, so their interests need not be opposite as in a [zero-sum game](zero-sum-game.md).
