# Net quark flavor number

↑ **Parent:** [Quark flavor](quark-flavor.md)

The number of [quarks](quark.md) of [quark flavor](quark-flavor.md) $f$ minus the number of corresponding [antiquarks](antiquark.md). The [strong interaction](strong-interaction.md) and [electromagnetic interaction](electromagnetic-interaction.md) conserve each such difference even when they create or annihilate pairs. [Weak charged currents](charged-current.md) can change these differences. For the strange [quark](quark.md), [strangeness](strangeness.md) is $S=-F_s$.
