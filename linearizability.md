# Linearizability

↑ **Parent:** [Synchronization (computing)](synchronization-computing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linearizability)

A concurrent object behaves as if its operations took effect at individual instants between invocation and response, respecting nonoverlapping operations' real-time order. A read overlapping a replacement can return the old version while remaining [linearizable](linearizability.md).
