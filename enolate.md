# Enolate

↑ **Parent:** [Chemical substance](chemical-substance-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Enolate)

An [enolate](enolate.md) is the conjugate base formed by removing an alpha proton from a suitable carbonyl compound. Oxygen-centred and carbon-centred resonance contributors help explain its ability to react at either site.
