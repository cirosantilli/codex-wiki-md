# Private field in Java

↑ **Parent:** [Java (programming language)](java-programming-language.md)

A field declared `private` is hidden from ordinary external source-level access. Library methods can enforce invariants and change the representation without exposing storage to clients. Returning a mutable internal object can still undermine this [encapsulation in object-oriented programming](encapsulation-in-object-oriented-programming.md).
