# Dyadic source matched to a complete prefix code

↑ **Parent:** [Entropy lower bound for prefix codes](entropy-lower-bound-for-prefix-codes.md)

For a complete binary [prefix code](prefix-code.md) with lengths $\ell_i$, the [Kraft inequality](kraft-mcmillan-inequality.md) is an equality: $\sum_i2^{-\ell_i}=1$. Put $q_i=2^{-\ell_i}$. The difference between [expected codeword length](expected-codeword-length.md) and [Shannon entropy](information-entropy-split.md) is

$$
\overline\ell-H(p)=\sum_i p_i\log_2\frac{p_i}{q_i}.
$$

The [Kullback-Leibler divergence](kullback-leibler-divergence.md) is nonnegative and vanishes exactly when $p=q$. Hence a complete code is entropy-tight exactly for its dyadic matching source. For example, lengths $(1,2,2)$ match probabilities $(1/2,1/4,1/4)$. Being an [optimal prefix code](optimal-prefix-code.md) among symbol-by-symbol codes is a weaker condition and does not imply this equality.
