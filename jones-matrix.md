# Jones matrix

↑ **Parent:** [Jones calculus](jones-calculus.md)

A [Jones matrix](jones-matrix.md) is a complex two-by-two linear transformation of a [Jones vector](jones-vector.md) through a deterministic nondepolarizing optical element. Successive elements multiply in reverse reading order. An ideal linear [polarizer](polarizer.md) along a real transverse [unit vector](unit-vector.md) $\mathbf a$ has matrix $\mathbf a\mathbf a^{\mathsf T}$. A common nonzero scalar phase does not change the output [polarization of waves](polarization-waves.md).
