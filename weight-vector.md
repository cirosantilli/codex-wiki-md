# Weight vector

↑ **Parent:** [Highest-weight representation](highest-weight-representation.md)

A vector $v$ has weight $\mu\in\mathfrak t^*$ when $h v=\mu(h)v$ for every $h$ in the Cartan subalgebra.

A [Weight](weight-representation-theory.md) is the eigenvalue functional; a weight vector is a nonzero vector carrying it.
