# Universal arrow from an object to a functor

↑ **Parent:** [Comma category](comma-category.md)

A universal arrow from $B$ to $F:\mathcal C\to\mathcal D$ is an [initial object](initial-object.md) $(A,\eta_B:B\to F(A))$ of $(B\downarrow F)$. The functor $F$ has a left adjoint exactly when such a universal arrow exists for every $B$; the universal property makes the chosen objects functorial.
