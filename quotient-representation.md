# Quotient representation

↑ **Parent:** [Subrepresentation](subrepresentation.md)

For a [subrepresentation](subrepresentation.md) $W\subseteq V$, the [quotient vector space](quotient-vector-space.md) $V/W$ inherits the action. For a [Lie algebra representation](lie-algebra-representation.md), the formula is $x(v+W)=xv+W$, well-defined because $W$ is invariant.
