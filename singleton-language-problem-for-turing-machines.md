# Singleton-language problem for Turing machines

↑ **Parent:** [Computability theory](computability-theory-split.md)

It is undecidable whether a [Turing machine](turing-machine.md) recognizes a [formal language](formal-language.md) containing exactly one [word](string.md). Reduce the [halting problem](halting-problem.md) by a [Turing machine](turing-machine.md) that rejects every nonempty input and, on the [empty word](empty-word.md), simulates a fixed computation and accepts if that computation halts. Its recognized [formal language](formal-language.md) is a [singleton](singleton-mathematics.md) exactly when the fixed computation halts.
