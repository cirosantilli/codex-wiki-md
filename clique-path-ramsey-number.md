# Clique-path Ramsey number

↑ **Parent:** [Off-diagonal graph Ramsey number](off-diagonal-graph-ramsey-number.md)

If $P_t$ denotes a path of length $t$, then

$$
r(K_s,P_t)=(s-1)t+1
$$

for $s\geq2$ and $t\geq1$.
