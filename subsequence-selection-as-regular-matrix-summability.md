# Subsequence selection as regular matrix summability

↑ **Parent:** [Regular matrix summability method](regular-matrix-summability-method.md)

Selecting a subsequence is a [regular matrix summability method](regular-matrix-summability-method.md): every row has one entry equal to one, every fixed column eventually vanishes, and all row sums equal one. Every [bounded sequence](bounded-sequence.md) of real or complex numbers has a [convergent subsequence](convergent-subsequence.md) by the [Bolzano-Weierstrass theorem](bolzano-weierstrass-theorem.md), so each bounded sequence is summable by some sequence-dependent regular method. The order of the quantifiers matters: no single regular matrix sums all bounded sequences.
