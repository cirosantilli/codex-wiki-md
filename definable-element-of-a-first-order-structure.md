# Definable element of a first-order structure

↑ **Parent:** [Model of a first-order theory](model-of-a-first-order-theory.md)

An element $a$ of a structure $M$ is definable without parameters when some [first-order formula](first-order-formula.md) $\varphi(x)$ uniquely identifies it:

$$
M\models\forall x\,(x=a\leftrightarrow\varphi(x)).
$$
