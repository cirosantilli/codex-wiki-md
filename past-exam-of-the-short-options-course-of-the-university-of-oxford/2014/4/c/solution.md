<h1 id="4/c/solution">Solution</h1>

↑ **Parent:** [C](../c.md)

The [regular level set theorem](../../../../regular-level-set-theorem.md) says that a $C^1$ map $f:\mathbb R^n\to\mathbb R^m$ with [surjective](../../../../surjective-function.md) derivative at every point of $f^{-1}(0)$ has a zero set that is an embedded $C^1$ [submanifold](../../../../submanifold.md) of dimension $n-m$. At each point $a$ of that zero set,

$$
\boxed{T_a(f^{-1}(0))=\ker Df_a.}
$$

For a smooth map the [submanifold](../../../../submanifold.md) is smooth. The full-rank hypothesis is essential for this kernel description when using a particular defining map.
