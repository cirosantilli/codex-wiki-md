# Return level

↑ **Parent:** [Return period](return-period.md)

A $T$-year return level has annual exceedance probability $1/T$ under the assumed stationary model. It is the corresponding [quantile](quantile-function.md) of annual maxima. Daily exceedance probabilities must be converted to annual event probabilities before using the annual [return period](return-period.md) definition.
