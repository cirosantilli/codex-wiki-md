# Classical communication

↑ **Parent:** [Quantum information theory](quantum-information-theory-split.md)

Classical communication transmits a distinguishable classical record, such as measurement bits, between parties. In [quantum teleportation](quantum-teleportation.md) it tells the receiver which local correction to apply. [Quantum no-signalling](quantum-no-signalling.md) prevents shared [entanglement](entangled-state.md) alone from transmitting the record. A classical message cannot propagate across a spacelike separation in a relativistic protocol.
