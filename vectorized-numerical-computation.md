# Vectorized numerical computation

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

[Vectorized numerical computation](vectorized-numerical-computation.md) applies numerical operations to entire arrays of values instead of explicitly iterating over scalar entries. For a [power series](power-series.md), constructing a [vector](vector.md) of term indices, evaluating all corresponding terms and summing that [vector](vector.md) is a vectorized evaluation. A loop over bounded blocks can control memory while preserving vectorized computation within each block.
