# Balanced number

↑ **Parent:** [Numerical digit](numerical-digit.md)

A [positive integer](positive-integer.md) whose first $\lceil k/2\rceil$ decimal [numerical digits](numerical-digit.md) have the same sum as its last $\lceil k/2\rceil$ digits, where $k$ is the number of digits. For odd $k$, the shared middle digit cancels from the equality. Counts and value sums can therefore be assembled from two half-length [digit dynamic programming](digit-dynamic-programming.md) tables indexed by [base-p digit sum](base-p-digit-sum.md).
