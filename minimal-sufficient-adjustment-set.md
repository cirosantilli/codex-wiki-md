# Minimal sufficient adjustment set

↑ **Parent:** [Sufficient adjustment set](sufficient-adjustment-set.md)

A minimal sufficient adjustment set is a [sufficient adjustment set](sufficient-adjustment-set.md) none of whose proper subsets is sufficient. Minimality is by set inclusion and does not imply minimum cardinality or uniqueness.
