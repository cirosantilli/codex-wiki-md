# Vertex set

↑ **Parent:** [Graph](graph-split.md)

The vertex set is the underlying [set](set-split.md) $V$ of a [graph](graph-split.md) or [hypergraph](hypergraph-split.md). In a hypergraph, its hyperedges are subsets of this set; in a simple graph, edges are two-element subsets.
