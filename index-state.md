# Index state

↑ **Parent:** [Relative state of a bipartite vector](relative-state-of-a-bipartite-vector.md)

An index state is a chosen orthonormal basis vector in the indexing subsystem of a [relative state](relative-state-of-a-bipartite-vector.md) decomposition. It labels the corresponding partial inner product; it need not be an eigenvector of the subsystem's [reduced density matrix](reduced-density-matrix.md).
