# Structural pattern

↑ **Parent:** [Software design pattern](software-design-pattern.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Structural_pattern)

A [software design pattern](software-design-pattern.md) organizing composition of classes and objects into larger structures. The [decorator pattern](decorator-pattern.md) wraps a component behind the same [object interface](object-interface.md), delegating existing work and adding one responsibility. Wrappers can be nested without declaring a new class for each combination.
