# Complex-valued function

↑ **Parent:** [Function](function-split.md)

A function taking values in the complex numbers can be written uniquely as $f=u+iv$ with real-valued functions $u,v$. Its [Lebesgue integral](lebesgue-integral.md) is defined by integrating these components when $|f|$ is integrable. Multiplication by a complex exponential of modulus one leaves this integrability unchanged.
