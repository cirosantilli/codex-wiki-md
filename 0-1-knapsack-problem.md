# 0-1 knapsack problem

↑ **Parent:** [Knapsack problem](knapsack-problem.md)

This binary [integer program](integer-programming.md) selects each item at most once. Exact optimization is [NP-hard](np-hardness.md); the [fractional knapsack problem](fractional-knapsack-problem.md) gives an upper bound and supports a [half-approximation algorithm for knapsack](half-approximation-algorithm-for-knapsack.md).
