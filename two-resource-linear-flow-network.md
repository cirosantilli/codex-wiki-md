# Two-resource linear flow network

↑ **Parent:** [Linear flow network](linear-flow-network.md)

A [two-resource linear flow network](two-resource-linear-flow-network.md) has one local route on each of two resources and one through route using both. With unit capacities and [proportional fairness](proportional-fairness.md), its exponential-document [flow-level network model](flow-level-network-model.md) has the [stationary law of a two-resource linear flow network](stationary-law-of-a-two-resource-linear-flow-network.md). The local counts are independent in equilibrium despite their dependence on the shared through-route count.
