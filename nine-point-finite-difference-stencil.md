# Nine-point finite-difference stencil

↑ **Parent:** [Finite difference method](finite-difference-method.md)

A nine-point finite-difference stencil on a square grid couples a central value to its four axial neighbours and four diagonal neighbours. Ordering the grid by columns produces a block tridiagonal matrix whose diagonal and off-diagonal blocks are [symmetric tridiagonal Toeplitz matrices](symmetric-tridiagonal-toeplitz-matrix.md).
