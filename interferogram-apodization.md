# Interferogram apodization

↑ **Parent:** [Fourier transform spectroscopy](fourier-transform-spectroscopy.md)

Multiplying a finite [interferogram](interferogram.md) by a smooth window reduces sharp-edge artifacts. In the recovered [radiation spectrum](radiation-spectrum.md) this convolves the true [spectral density](spectral-density-of-a-stationary-process.md) with the window's [Fourier transform](fourier-transform-split.md). Smoother windows generally lower sidelobes while broadening the main lobe, so a resolution figure must specify the window and criterion. Apodization does not recover unmeasured long-delay information.[chapter 14, printed pp.57–62, and chapter 15: sidelobe/resolution tradeoff](introduction-to-fourier-transform-spectroscopy-by-julius-cohen.md)
