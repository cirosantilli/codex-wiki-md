# Sentinel node

↑ **Parent:** [Linked list](linked-list.md)

A sentinel is a permanently present [linked list node](linked-list-node.md) that is excluded from the represented data. A header sentinel provides a predecessor even for the first real element, allowing uniform link updates. Its datum has no abstract meaning and must not be counted by the [abstraction function](abstraction-function.md). A [representation invariant](representation-invariant.md) should keep the sentinel outside its own finite acyclic successor chain.
