# Isometric embedding

↑ **Parent:** [Isometry](isometry.md)

An isometric embedding $f:X\to Y$ between [metric spaces](metric-space.md) is an [injective function](injective-function.md) satisfying $d_Y(f(x),f(x'))=d_X(x,x')$ for all $x,x'\in X$.
