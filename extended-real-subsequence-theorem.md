# Extended real subsequence theorem

↑ **Parent:** [Bolzano-Weierstrass theorem](bolzano-weierstrass-theorem.md)

Every real [sequence](sequence.md) has a [subsequence](subsequence.md) converging to an [extended real number](extended-real-number-line.md). A bounded sequence has a real convergent subsequence by the [Bolzano-Weierstrass theorem](bolzano-weierstrass-theorem.md). If it is unbounded above, every tail is unbounded above, so choose increasing indices $n_j$ with $a_{n_j}>j$. These terms tend to positive infinity. If it is unbounded below, use $a_{n_j}<-j$.
