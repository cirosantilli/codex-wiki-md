# Hackenbush stalk

↑ **Parent:** [Hackenbush](hackenbush.md)

A [Hackenbush](hackenbush.md) position whose graph is a single path attached to the ground at one endpoint. Finite red-blue stalks have [dyadic rational](dyadic-rational.md) game values; the initial monochromatic run determines the integer part and subsequent colors determine successive binary fractions.
