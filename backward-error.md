# Backward error

↑ **Parent:** [Numerical analysis](numerical-analysis-split.md)

A [backward error](backward-error.md) measures a perturbation $\delta d$ of the input data for which the computed result is an exact solution of the perturbed problem. Specify which data may change and which [norm](norm.md) measures the perturbation. For a [linear system](system-of-linear-equations.md) $A\widehat{x}=b$, holding $A$ fixed gives $\delta b=A\widehat{x}-b$, the negative [linear-system residual](linear-system-residual.md). The corresponding [forward error](forward-error.md) also depends on the [condition number](condition-number.md).
