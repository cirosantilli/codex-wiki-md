# Euler formula for normal curvature

↑ **Parent:** [Normal curvature](normal-curvature.md)

If a unit tangent makes angle $\theta$ with the first principal direction, the [normal curvature](normal-curvature.md) is $\kappa_n=\kappa_1\cos^2\theta+\kappa_2\sin^2\theta$. This follows by diagonalizing the [second fundamental form](second-fundamental-form-split.md) relative to the [first fundamental form](first-fundamental-form.md). When the [Gaussian curvature](gaussian-curvature.md) is nonnegative, $|\kappa_n|\leq2|H|$.
