# Closed-testing control of the familywise error rate

↑ **Parent:** [Closed testing procedure](closed-testing-procedure.md)

If any true elementary hypothesis is rejected by a [closed testing procedure](closed-testing-procedure.md), then the intersection of all true null hypotheses must also be rejected. Its local test has level $\alpha$, so the [familywise error rate](familywise-error-rate.md) is at most $\alpha$ under arbitrary dependence.
