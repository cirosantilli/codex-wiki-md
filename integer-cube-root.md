# Integer cube root

↑ **Parent:** [Cube root](cube-root.md)

The integer cube root of a nonnegative integer $n$ is $\lfloor\sqrt[3]{n}\rfloor$, the unique integer $r$ satisfying $r^3\le n<(r+1)^3$. It can be computed by [binary search](binary-search.md) using integer cube comparisons.
