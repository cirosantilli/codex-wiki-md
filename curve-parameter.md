# Curve parameter

↑ **Parent:** [Smooth curve](smooth-curve.md)

A curve parameter labels the points visited by a [parametric curve](parametric-curve.md) $\gamma(t)$. Choosing time as the parameter determines its [velocity](velocity.md); an [arc-length parametrization](arc-length-parametrization.md) instead measures accumulated [arc length](arc-length.md). A regular monotone [reparametrization](reparametrization.md) changes the labels and speed while preserving the route and its [arc length](arc-length.md).
