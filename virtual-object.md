# Virtual object

↑ **Parent:** [Thin lens](thin-lens.md)

For an optical element, a [virtual object](virtual-object.md) is a point toward which incident rays already converge, so they would meet beyond the element if it were removed. It is distinct from a [virtual image](virtual-image.md), which is an apparent origin of outgoing rays. In the real-is-positive thin-lens convention, a [virtual object](virtual-object.md) beyond the lens has $u<0$, and $1/u+1/v=1/f$. Thus $u\to-\infty$ gives a [real image](real-image.md) in the rear focal plane of a converging lens.
