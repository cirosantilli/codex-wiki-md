# Squarefree Hilbert number

↑ **Parent:** [Hilbert number](hilbert-number.md)

In the multiplicative set of [Hilbert numbers](hilbert-number.md), a squarefree Hilbert number is one divisible by no square $h^2$ of a [Hilbert number](hilbert-number.md) $h>1$. This is weaker than being a [squarefree integer](square-free-integer.md): $9$ is a squarefree Hilbert number because its square divisor $9=3^2$ has $3$ outside the [Hilbert numbers](hilbert-number.md).
