# Inverse error function

↑ **Parent:** [Error function](error-function.md)

Because the real [error function](error-function.md) is [strictly increasing](strictly-increasing-function.md) from $-1$ to $1$, its real [inverse function](inverse-function.md) maps $(-1,1)$ onto the [real line](real-line.md). For $0<q<1$, the [standard normal quantile](standard-normal-quantile.md) is therefore

$$
\Phi^{-1}(q)=\sqrt2\,\operatorname{erf}^{-1}(2q-1).
$$

More generally, the $q$-[quantile](quantile-function.md) of a [normal distribution](normal-distribution.md) with [expected value](expected-value-split.md) $\mu$ and positive [standard deviation](standard-deviation.md) $\sigma$ is $\mu+\sigma\sqrt2\,\operatorname{erf}^{-1}(2q-1)$. This reverses the area calculation: instead of asking how much [probability](probability.md) lies below an endpoint, a [quantile](quantile-function.md) asks which endpoint encloses a specified [probability](probability.md). The domain restriction matters; $q=0$ and $q=1$ correspond to infinite endpoints, rather than finite real values of the [inverse error function](inverse-error-function.md).
