# Continuous embedding

↑ **Parent:** [Functional analysis](functional-analysis-split.md)

For [normed vector spaces](normed-vector-space-split.md) of functions on the same domain, a continuous embedding is an injective inclusion $X\subset Y$ satisfying $\|u\|_Y\leq C\|u\|_X$.
