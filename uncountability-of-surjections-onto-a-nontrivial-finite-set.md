# Uncountability of surjections onto a nontrivial finite set

↑ **Parent:** [Uncountable set](uncountable-set.md)

If $B$ is a [countably infinite set](countably-infinite-set.md) and $A$ is a [finite set](finite-set.md) with at least two elements, the set of [surjective functions](surjective-function.md) $B\to A$ is uncountable. Fix finitely many values to cover $A$, then encode an arbitrary infinite [binary sequence](bitstream.md) using two values of $A$ on the remaining inputs.
