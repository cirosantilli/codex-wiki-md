# Symplectic linear map

↑ **Parent:** [Symplectic vector space](symplectic-vector-space.md)

A [linear map](linear-map.md) $A:(V,\omega_V)\to(W,\omega_W)$ is symplectic when it pulls back the target [symplectic form](symplectic-form.md) to the source form. [Nondegenerate bilinear form](nondegenerate-bilinear-form.md) makes such a map [injective](injective-function.md). In equal finite dimensions it is an [isomorphism](isomorphism.md). The automorphisms form the [symplectic group](symplectic-group.md) and preserve the [symplectic orientation](symplectic-orientation.md) on the ambient space and on every [symplectic subspace](symplectic-subspace.md).
