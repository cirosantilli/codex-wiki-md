# Lagrangian boundary condition

↑ **Parent:** [Pseudoholomorphic curve](pseudoholomorphic-curve.md)

A Lagrangian boundary condition for a [J-holomorphic curve](pseudoholomorphic-curve.md) requires specified boundary components of the source to map into specified [Lagrangian submanifolds](lagrangian-submanifold.md). For the strip, this is $u(s,0)\in L_0$ and $u(s,1)\in L_1$. For a [compatible almost complex structure](compatible-almost-complex-structure.md) these target submanifolds are totally real. The condition accompanies the interior equation $u_s+Ju_t=0$.
