# Point evaluation functional

↑ **Parent:** [Continuous linear functional](continuous-linear-functional.md)

For a function space on a set $X$ and a point $x\in X$, the point evaluation functional is $\delta_x(f)=f(x)$. It is bounded on $C(X)$ with the [supremum norm](supremum-norm.md).
