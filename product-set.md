# Product set

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)

The product set of two sets of real numbers is $A\cdot B=\{ab:a\in A,b\in B\}$. It is a multiplicative counterpart of a [sumset](sumset.md), not the [Cartesian product](cartesian-product.md) $A\times B$.
