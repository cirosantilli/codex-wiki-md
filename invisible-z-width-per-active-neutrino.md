# Invisible Z width per active neutrino

↑ **Parent:** [Z boson](z-boson.md)

For equally coupled light active [neutrinos](neutrino.md), the total invisible width is the sum of the single-species widths. A three-flavor invisible width near $501$ MeV corresponds to about $167$ MeV per species. It must not be assigned to each additional neutrino separately.
