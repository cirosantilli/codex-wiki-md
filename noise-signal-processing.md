# Noise (signal processing)

↑ **Parent:** [Signal](signal.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Noise_(signal_processing))

Noise is unwanted variation in a [signal](signal.md). Whether a component is unwanted depends on the measurement task: suppressing fast variation helps only when that variation is expendable. [White noise](white-noise.md) provides one mathematical model; it does not describe every source of disturbance. A [linear filter](linear-filter.md) may reduce some [noise](noise-signal-processing.md) while also altering the desired [signal](signal.md).
