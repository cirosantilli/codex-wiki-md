# In-order pipeline

↑ **Parent:** [Instruction pipelining](instruction-pipelining.md)

An [instruction pipelining](instruction-pipelining.md) organization in which instructions advance through execution in program order. Different instructions can occupy different stages simultaneously, and [register forwarding](register-forwarding.md) can remove some [data hazards](data-hazard.md).
