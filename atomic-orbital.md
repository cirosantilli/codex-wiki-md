# Atomic orbital

↑ **Parent:** [Quantum chemistry](quantum-chemistry.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Atomic_orbital)

An atomic orbital is a one-[Electron](electron.md) spatial [wavefunction](wave-function.md) used to describe an [Electron](electron.md)'s state in a [chemical atom](atom-physics.md). For a one-electron [hydrogen atom](hydrogen-atom.md), orbitals can be exact [energy eigenstates](energy-eigenstate.md); descriptions of many-electron atoms instead use an orbital approximation. A normalized atomic orbital has $\int|\phi|^2\,d^3\mathbf r=1$, and the [Born rule](born-rule.md) gives the position [probability density](probability-density.md) $|\phi|^2$. It is a function extending through space, not a prescribed classical orbit. [Flowers et al., Chemistry 2e, 6.3: atomic orbitals and the wavefunction description](https://openstax.org/books/chemistry-2e/pages/6-3-development-of-quantum-theory)

The [linear combination of atomic orbitals](linear-combination-of-atomic-orbitals.md) combines these single-centre functions to approximate a [molecular orbital](molecular-orbital.md). The [orbital overlap](orbital-overlap.md) measures their [inner product](inner-product.md), and their relative [quantum phase](quantum-phase.md) controls the [interference](interference-wave-propagation.md) shown in [molecular orbital theory](molecular-orbital-theory.md).
