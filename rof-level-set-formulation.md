# ROF level-set formulation

↑ **Parent:** [Total variation denoising](total-variation-denoising.md)

The scalar [ROF denoising](total-variation-denoising.md) [minimizer](global-minimizer.md) has perimeter-plus-forcing minimizing [superlevel sets](superlevel-set.md) at almost every height. Conversely any finite-energy function with that property minimizes the full energy. The [signed layer-cake identity for quadratic fidelity](signed-layer-cake-identity-for-quadratic-fidelity.md) and [coarea formula for BV functions](coarea-formula-for-bv-functions.md) prove sufficiency. To prove necessity, construct nested minimizing sets using [comparison of perimeter minimizers with ordered forcing](comparison-of-perimeter-minimizers-with-ordered-forcing.md), reconstruct a function from rational levels, clip to establish energy bounds, and use uniqueness from [strict convexity](strictly-convex-function.md) of the squared fidelity.
