# Traceless matrix

↑ **Parent:** [Matrix trace](matrix-trace.md)

A traceless matrix is a square [matrix](matrix.md) whose [trace](matrix-trace.md) is zero. Such [matrices](matrix.md) form the [kernel](kernel-of-a-linear-map.md) of the trace [linear functional](linear-functional.md).
