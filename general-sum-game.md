# General-sum game

↑ **Parent:** [Game theory](game-theory-split.md)

A [game](game.md) whose players' [utilities](utility.md) are specified separately, without assuming a fixed sum. Improving one player's [utility](utility.md) need not worsen another's. A finite [perfect-information game](perfect-information-game.md) can be solved by [backward induction](backward-induction.md) using entire [utility](utility.md) tuples and each moving player's own coordinate, as in [max-n search](max-n-search.md).
