# Free-block list

↑ **Parent:** [File system](file-system-split.md)

A representation of currently unallocated [disk block numbers](disk-block-number.md), maintained as a list or linked groups of available numbers. Allocation removes a number; deallocation returns it after ownership is relinquished. Reserved structures and blocks still owned by an unnamed but open [file](computer-file.md) are unavailable. A [block allocation bitmap](block-allocation-bitmap.md) is an alternative representation of the same allocation state.
