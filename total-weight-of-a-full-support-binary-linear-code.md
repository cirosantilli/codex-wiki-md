# Total weight of a full-support binary linear code

↑ **Parent:** [Binary linear code](binary-linear-code.md)

A length-$n$, dimension-$k$ [binary linear code](binary-linear-code.md) has full support when no coordinate vanishes on every [codeword](codeword.md), equivalently when the union of the [supports of a vector](support-of-a-vector.md) of all codewords covers every coordinate. Every coordinate is then a nonzero [linear functional](linear-functional.md) on the message [vector space](vector-space-split.md) $\mathbb F_2^k$. Translation by a [vector](vector.md) on which it is one pairs the zero and one fibers, so exactly $2^{k-1}$ [codewords](codeword.md) contribute one in that coordinate. Summing these contributions proves the formula. If there are $r$ nonzero columns in a full-rank [generator matrix](generator-matrix.md), the same argument gives $r2^{k-1}$ instead.
