<h1 id="3/a/iii/solution">Solution</h1>

↑ **Parent:** [Iii](../iii.md)

For an [irreducible Markov chain](../../../../../irreducible-markov-chain.md) on a countable [state space](../../../../../state-space.md), **the set has either zero or one element**. By [uniqueness of stationary distributions for an irreducible countable chain](../../../../../uniqueness-of-stationary-distributions-for-an-irreducible-countable-chain.md), a stationary probability distribution exists exactly in the [positive recurrent](../../../../../positive-recurrent-markov-chain.md) case, and then

$$
\pi_i=\frac1{\mathbb E_iT_i^+}
$$

for the [first return time](../../../../../first-return-time.md) $T_i^+$. The right-hand side fixes every entry, proving uniqueness.

For a finite state space, existence is guaranteed, so there is **exactly one**. A countably infinite state space can have none: the [simple symmetric random walk](../../../../../simple-symmetric-random-walk.md) on the integers is irreducible and null recurrent. Periodicity does not affect this existence-and-uniqueness statement.
