# Oscilloscope

↑ **Parent:** [Acoustic wavelength measurement](acoustic-wavelength-measurement.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Oscilloscope)

An [oscilloscope](oscilloscope.md) displays an electrical [signal](signal.md) versus time. In an [acoustic wavelength measurement](acoustic-wavelength-measurement.md), the [microphone](microphone.md) trace supplies the tone's [frequency](frequency.md) and oscillation [amplitude](wave-amplitude.md) as the detector changes position.
