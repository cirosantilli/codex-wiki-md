# Factor analysis

↑ **Parent:** [Latent variable](latent-variable-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Factor_analysis)

Factor analysis writes an observation as $Y=\Lambda Z+\xi$, where the low-dimensional [latent variable](latent-variable-split.md) $Z$ describes shared variation. In the isotropic Gaussian model $Z\sim N(0,I)$ and $\xi\sim N(0,\sigma^2I)$ independently, the observation has covariance $\Lambda\Lambda^T+\sigma^2I$.
