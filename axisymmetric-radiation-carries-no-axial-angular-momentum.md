# Axisymmetric radiation carries no axial angular momentum

↑ **Parent:** [Gravitational wave](gravitational-wave.md)

An exact axial [Killing vector field](killing-vector-field.md) makes [Komar angular momentum](komar-angular-momentum.md) independent of the surrounding vacuum surface. Therefore [gravitational waves](gravitational-wave.md) in a configuration with exact [axisymmetry](axisymmetric-vector-field.md) carry no net [angular momentum](angular-momentum.md) about that symmetry axis, although they can carry [energy](energy.md). This is specific to axial [angular momentum](angular-momentum.md); it is not an absence of radiation.
