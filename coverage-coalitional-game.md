# Coverage coalitional game

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

Players hold finite sets of resources, and their coalition value is the number of distinct resources they collectively cover. The value is generally subadditive rather than superadditive: overlapping resources are counted only once. It is a [superadditive coalitional game](superadditive-coalitional-game.md) exactly when the players' resource sets are pairwise disjoint.
