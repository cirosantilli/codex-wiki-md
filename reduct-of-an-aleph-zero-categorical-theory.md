# Reduct of an aleph-zero-categorical theory

↑ **Parent:** [Ryll-Nardzewski theorem](ryll-nardzewski-theorem.md)

Every reduct of an aleph-zero-categorical theory to a sublanguage is aleph-zero-categorical. There can only be fewer formulas in each arity, so the finite-formula characterization in the [Ryll-Nardzewski theorem](ryll-nardzewski-theorem.md) is preserved.
