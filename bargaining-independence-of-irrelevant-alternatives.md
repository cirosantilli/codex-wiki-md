# Bargaining independence of irrelevant alternatives

↑ **Parent:** [Nash bargaining problem](nash-bargaining-problem.md)

If an admissible smaller feasible set with the same [disagreement point](disagreement-point.md) contains the original chosen vector, deleting the other outcomes must leave the choice unchanged. The [Nash bargaining solution](nash-bargaining-solution.md) satisfies this axiom because its unique product maximizer remains feasible.
