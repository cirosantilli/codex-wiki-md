# Reachability in control theory

↑ **Parent:** [Control theory](control-theory-split.md)

A target is reachable from an initial state if an admissible [control input](control-input.md) drives the dynamical system between them in some permitted time. The reachable set depends on the controls and any time or state constraints. This is a dynamical notion, distinct from graph [reachability](reachability-in-a-graph.md).
