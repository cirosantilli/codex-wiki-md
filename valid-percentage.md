# Valid percentage

↑ **Parent:** [Frequency table](frequency-table.md)

A percentage whose denominator excludes observations missing the variable being summarized. It can differ from a percentage calculated over the complete dataset's [sample size](sample-size.md). Valid percentages for two different variables need not use the same observations.
