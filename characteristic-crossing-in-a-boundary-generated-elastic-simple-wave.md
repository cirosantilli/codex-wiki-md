# Characteristic crossing in a boundary-generated elastic simple wave

↑ **Parent:** [Elastic wave](elastic-wave.md)

In a right-going [simple wave](simple-wave.md), the state emitted at boundary time $s$ travels along $X=c_b(s)(t-s)$. The mapping from emission time to position first becomes singular when $\dot c_b(t-s)-c_b=0$, giving the displayed shock time and position $X=c_b^2/\dot c_b$. A smooth increase of [traction](traction.md) produces steepening only if it increases the propagation speed. This describes the first gradient singularity; continuation as a [shock wave](shock-wave.md) needs admissible jump conditions.
