# vOICe

↑ **Parent:** [Sensory substitution system](sensory-substitution-system.md)

A camera-to-sound sensory-substitution system developed by [Peter B. L. Meijer](peter-b-l-meijer.md). Its column scan encodes vertical position by [frequency](frequency.md), horizontal position by scan timing and image brightness by [amplitude](wave-amplitude.md). Later implementations add other cues; properties of one version should not be attributed to every prototype.
