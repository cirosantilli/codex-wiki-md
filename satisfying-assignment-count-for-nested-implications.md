# Satisfying-assignment count for nested implications

↑ **Parent:** [Logical implication](logical-implication.md)

For distinct propositional variables, eliminate each right-associated [logical implication](logical-implication.md) to obtain $\neg A_n\lor\cdots\lor\neg A_2\lor A_1$. Exactly one [Boolean valuation](boolean-valuation.md) falsifies all these disjuncts: $A_1=0$ and $A_2=\cdots=A_n=1$. Of the $2^n$ assignments, the other $2^n-1$ are [satisfying assignments](satisfying-assignment.md). Left-associated implication chains have a different meaning and need not have the same count.
