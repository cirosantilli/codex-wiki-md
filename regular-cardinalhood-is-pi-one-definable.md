# Regular cardinalhood is Pi-one definable

↑ **Parent:** [Pi-one formula modulo ZF](pi-one-formula-modulo-zf.md)

An infinite [cardinal number](cardinal-number.md) $\kappa$ is a [regular cardinal](regular-cardinal.md) if every function from an ordinal $\delta<\kappa$ into $\kappa$ has bounded range. Write this as $\forall f\,\forall\delta\in\kappa\,(\operatorname{Map}(f,\delta,\kappa)\Rightarrow\exists\beta\in\kappa\,\forall\xi\in\delta\ f(\xi)<\beta)$. The graph predicates are [bounded formulas in set theory](bounded-formula-in-set-theory.md), and [cardinalhood is Pi-one definable](cardinalhood-is-pi-one-definable.md), so adding infinite cardinalhood yields a [Pi-one formula modulo ZF](pi-one-formula-modulo-zf.md).
