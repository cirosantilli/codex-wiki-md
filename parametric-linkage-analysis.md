# Parametric linkage analysis

↑ **Parent:** [Genetic linkage](genetic-linkage.md)

Parametric linkage analysis forms a [pedigree likelihood](pedigree-likelihood.md) from a specified disease model, including [penetrance](penetrance.md), [allele](allele.md) frequencies and [recessive inheritance](recessive-inheritance.md) or another transmission model. It estimates or tests the [recombination fraction](recombination-fraction.md) between a disease locus and a [genetic marker](genetic-marker.md).
