# Mutation count on a neutral coalescent tree

↑ **Parent:** [Kingman's coalescent](kingman-s-coalescent.md)

In [Kingman's coalescent](kingman-s-coalescent.md), the epoch with $j$ ancestral lineages lasts $T_j\sim\operatorname{Exp}(\binom j2)$, independently across epochs. If each lineage carries an independent [Poisson process](poisson-process.md) of [mutations](mutation.md) with rate $\theta/2$, its epoch mutation count satisfies $Y_j\mid T_j\sim\operatorname{Poisson}(j\theta T_j/2)$. The total mutation count is $S=\sum_{j=2}^nY_j$. Under the [infinite sites mutation model](infinite-sites-mutation-model.md), this also counts [segregating sites](segregating-site.md); without that assumption it still counts mutation events, which need not correspond one-to-one to observed polymorphisms.
