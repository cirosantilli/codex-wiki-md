# Ray in a graph

↑ **Parent:** [Path in a graph](path-in-a-graph.md)

A [graph ray](ray-in-a-graph.md) is an infinite [sequence](sequence.md) $v_0,v_1,\ldots$ of distinct [graph vertices](vertex-graph-theory.md) with an [edge](edge-of-a-graph.md) between consecutive [graph vertices](vertex-graph-theory.md). Every infinite connected [locally finite graph](locally-finite-graph.md) contains a [graph ray](ray-in-a-graph.md) from each [graph vertex](vertex-graph-theory.md), by the [König infinity lemma](konig-s-lemma.md) applied to its finite self-avoiding [graph paths](path-in-a-graph.md). An open [graph ray](ray-in-a-graph.md) witnesses an infinite [percolation cluster](percolation-cluster.md).
