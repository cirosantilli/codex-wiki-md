# Pseudorandom number

↑ **Parent:** [Pseudorandom number generator](pseudorandom-number-generator.md)

A pseudorandom number is an output of a deterministic algorithm chosen to imitate samples from a specified [probability](probability.md) law. For example, a [linear congruential generator](linear-congruential-generator.md) returns fractions $S_i/M$ on a finite grid in $[0,1)$. Their intended [uniform distribution](continuous-uniform-distribution.md) is an approximation, and their serial dependence must be assessed separately from the generator's period.
