# Weak radiative hyperon decay

↑ **Parent:** [Weak interaction](weak-interaction.md)

A [hyperon](hyperon.md) decay that changes [quark flavour](quark-flavor.md) while emitting a [photon](photon.md). An example is $\Xi^0\to\Lambda\gamma$, which changes [strangeness](strangeness.md) and cannot be purely electromagnetic. Its amplitude can contain short-distance loops and long-distance hadronic contributions. [photon](photon.md) attachments to a weak quark-exchange graph must be completed consistently with electromagnetic gauge invariance. A [quark](quark.md) topology identifies allowed flavour flow but does not by itself calculate a reliable hadronic rate.
