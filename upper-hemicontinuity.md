# Upper hemicontinuity

↑ **Parent:** [Set-valued mapping](set-valued-mapping.md)

A [set-valued mapping](set-valued-mapping.md) $F$ is upper hemicontinuous at $x$ when every open set containing $F(x)$ also contains $F(x')$ for all nearby $x'$. With values in a fixed [compact](compact-space.md) space, a closed [graph of a set-valued mapping](graph-of-a-set-valued-mapping.md) implies [upper hemicontinuity](upper-hemicontinuity.md): a violating sequence has a convergent subsequence of outputs whose limit lies in the limiting value.
