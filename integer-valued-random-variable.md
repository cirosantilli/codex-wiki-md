# Integer-valued random variable

↑ **Parent:** [Discrete random variable](discrete-random-variable.md)

A [random variable](random-variable-split.md) whose values lie in the [integers](integer-split.md) with [probability](probability.md) one. Its [probability mass function](probability-mass-function.md) is $p(j)=\mathbb P(X=j)$ for $j\in\mathbb Z$. If it is nonnegative, its [probability generating function](probability-generating-function.md) is $G(s)=\sum_{j\ge0}p(j)s^j$ wherever this [expectation](expected-value-split.md) is finite.
