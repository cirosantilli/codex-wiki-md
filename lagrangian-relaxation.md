# Lagrangian relaxation

↑ **Parent:** [Lagrangian dual problem](lagrangian-dual-problem.md)

A Lagrangian relaxation moves selected constraints into the objective with appropriately signed [Lagrange multipliers](lagrange-multiplier.md). Maximizing the relaxed objective over a larger easy set gives an upper bound for a constrained maximization problem. Optimizing that bound need not solve the original integer problem.
