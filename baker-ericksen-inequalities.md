# Baker-Ericksen inequalities

↑ **Parent:** [Material isotropy](material-isotropy.md)

For a smooth objective isotropic [hyperelastic material](hyperelastic-material.md), the strict Baker-Ericksen inequalities require larger distinct [principal stretches](principal-stretch.md) to have larger [principal stresses](principal-stress.md). For $W=\Phi(v_1,v_2,v_3)$ and $J=v_1v_2v_3$, $\sigma_i=J^{-1}v_i\Phi_i$. The strict convention implies every stress-free state has equal stretches: if $v_i\ne v_j$ but both stresses are zero, the displayed product would vanish. Thus a [natural state of a hyperelastic material](natural-state-of-a-hyperelastic-material.md) has $F=vQ$, $v>0$, $Q\in SO(3)$. A weak non-strict inequality alone does not imply this rigidity.
