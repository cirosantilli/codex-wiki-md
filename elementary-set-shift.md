# Elementary set shift

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)

For $i<j$, replace a member $A$ containing $j$ but not $i$ by $(A\setminus\{j\})\cup\{i\}$ only when the replacement is absent. An [elementary set shift](elementary-set-shift.md) preserves family size and the [intersecting family](intersecting-family.md) property. The inclusion $\partial(S_{ij}\mathcal F)\subseteq S_{ij}(\partial\mathcal F)$ shows that it cannot increase the [lower shadow](lower-shadow.md).
