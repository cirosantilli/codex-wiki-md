# Short-interval Perron bound for the second Chebyshev function

↑ **Parent:** [Truncated Perron formula](truncated-perron-formula.md)

For $c=1+1/\log x$, $1\le y\le x$ and $2\le T\le x$, apply the [truncated Perron formula](truncated-perron-formula.md) with [Von Mangoldt function](von-mangoldt-function.md) coefficients at both endpoints on the same vertical line. The difference kernel is $((x+y)^s-x^s)/s=\int_x^{x+y}u^{s-1}\,du$, of modulus $O(y)$. The usual near-integer error bound contributes $O(x\log^2x/T)$. The [logarithmic derivative](logarithmic-derivative.md) on this line is finite because of the [Euler product](euler-product.md).
