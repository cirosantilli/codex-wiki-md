# Q-Cartier divisor

↑ **Parent:** [Weil divisor](weil-divisor.md)

A [Weil divisor](weil-divisor.md) is Q-Cartier if some positive integer multiple is a [Cartier divisor](cartier-divisor-split.md). Its Cartier index is the smallest such integer. It is ample in the Q-Cartier sense when such a multiple is an [ample Cartier divisor](ample-cartier-divisor.md). This need not make the original divisor itself Cartier.
