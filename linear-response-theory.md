# Linear response theory

↑ **Parent:** [Statistical physics](statistical-physics-split.md)

[Linear response theory](linear-response-theory.md) describes a system's small change in an observable to first order in an applied perturbation. The approximation requires a stated reference state and a range of sufficiently small perturbations.
