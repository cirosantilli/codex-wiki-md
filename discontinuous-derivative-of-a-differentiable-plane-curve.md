# Discontinuous derivative of a differentiable plane curve

↑ **Parent:** [Differentiability](differentiability.md)

Set $f(0)=0$. The difference quotient has [Euclidean norm](euclidean-norm.md) $|t|$, so $f'(0)=0$. For $t\ne0$, differentiation gives $\|f'(t)\|^2=1+4t^2$. Thus this [differentiable](differentiable-function.md) curve has a [derivative](derivative.md) discontinuous at zero, despite each scalar component satisfying the usual one-dimensional derivative properties.
