# Adapter pattern

↑ **Parent:** [Software design pattern](software-design-pattern.md)

An adapter presents an [object interface](object-interface.md) expected by clients while delegating to a component with a different [object interface](object-interface.md). Correct adaptation preserves the meaning and order of operations, not merely [object method](object-method.md) names. Adapting a combined update-and-result operation to separate update and query operations requires storing the last result and specifying its initial value. An adapter should not perform a hidden dummy update just to manufacture that initial observation.
