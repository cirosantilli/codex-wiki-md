# Complementary-layer bound for biased measure

↑ **Parent:** [Self-dual set family](self-dual-set-family.md)

Suppose a [self-dual set family](self-dual-set-family.md) has level proportions $a_j\le j/n$ for $j<n/2$. Subtract the binomial identity $p=\sum_j\binom nj(j/n)p^j(1-p)^{n-j}$ from its [biased measure of a set family](biased-measure-of-a-set-family.md) and pair levels $j,n-j$. The difference is

$$
\mu_p(\mathcal F)-p=\sum_{j<n/2}\binom nj(j/n-a_j)[p^{n-j}(1-p)^j-p^j(1-p)^{n-j}].
$$

Every term is nonnegative for $p\ge1/2$. A self-dual [intersecting family](intersecting-family.md) has the required level bounds by the [Erdős-Ko-Rado theorem](erdos-ko-rado-theorem.md).
