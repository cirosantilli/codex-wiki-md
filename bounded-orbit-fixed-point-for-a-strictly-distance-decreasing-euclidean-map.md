# Bounded-orbit fixed point for a strictly distance-decreasing Euclidean map

↑ **Parent:** [Strict distance decrease on a compact metric space](strict-distance-decrease-on-a-compact-metric-space.md)

For a strictly distance-decreasing map of a finite-dimensional [Euclidean space](euclidean-norm.md), one bounded forward [orbit](orbit-dynamical-system.md) suffices for existence of a [fixed point](fixed-point.md). Its closure is compact by the [Heine-Borel theorem](heine-borel-theorem.md) and invariant by continuity, so [strict distance decrease on a compact metric space](strict-distance-decrease-on-a-compact-metric-space.md) applies. Strict distance decrease gives uniqueness throughout the whole space, not merely the orbit closure.
