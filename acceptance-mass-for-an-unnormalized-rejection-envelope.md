# Acceptance mass for an unnormalized rejection envelope

↑ **Parent:** [Rejection sampling](rejection-sampling.md)

If $f\geq0$, $C=\int f\in(0,\infty)$ and $f(x)\leq Mg(x)$ for a proposal [probability density function](probability-density-function.md) $g$, accept a proposal $Y$ when an [independent](independent-random-variables.md) [uniform distribution](continuous-uniform-distribution.md) value is at most $f(Y)/(Mg(Y))$. Integrating the joint acceptance [probability density function](probability-density-function.md) gives $p_{\rm acc}=C/M$ and conditional accepted [probability density function](probability-density-function.md) $f/C$. For $n$ [independent](independent-random-variables.md) proposals the accepted count has [binomial distribution](binomial-distribution.md) with parameters $n,C/M$.
