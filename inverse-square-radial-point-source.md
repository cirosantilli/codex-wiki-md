# Inverse-square radial point source

↑ **Parent:** [Distributional divergence](distributional-divergence.md)

The inverse-square [radial vector field](radial-vector-field.md) has zero ordinary [divergence](divergence.md) at every nonzero radius but flux $4\pi$ through every centred sphere. It is locally integrable in three dimensions. For a smooth compactly supported test function $\eta$, integrate by parts outside a ball of radius $\epsilon$. The inward-oriented inner boundary gives $-\int \mathbf F\cdot\nabla\eta=\int_{S^2}\eta(\epsilon\hat{\mathbf r})d\Omega$, which tends to $4\pi\eta(0)$. This proves the displayed [distributional divergence](distributional-divergence.md), with the three-dimensional [Dirac delta function](dirac-delta-function.md) representing the point source.
