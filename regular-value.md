# Regular value

↑ **Parent:** [Differential geometry](differential-geometry-split.md)

A value is regular when the derivative is surjective at every point of its preimage.

Every value of a [submersion](submersion.md) is regular, but a map can have some regular values without being a submersion everywhere.
