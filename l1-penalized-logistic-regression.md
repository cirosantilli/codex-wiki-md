# L1-penalized logistic regression

↑ **Parent:** [Logistic regression](logistic-regression.md)

L1-penalized logistic regression minimizes empirical [logistic loss](logistic-loss.md) plus $\lambda\lVert\beta\rVert_1$. Its subgradient optimality conditions set each logistic score coordinate equal to $-\lambda z_j$, where $z_j=\operatorname{sgn}(\beta_j)$ off zero and $z_j\in[-1,1]$ at zero.
