# Pancyclic graph

↑ **Parent:** [Cycle graph](cycle-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pancyclic_graph)

An $n$-vertex graph is pancyclic when it contains $C_\ell$ for every $3\leq\ell\leq n$.
