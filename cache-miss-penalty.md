# Cache miss penalty

↑ **Parent:** [Cache miss](cache-miss.md)

The additional [memory access latency](memory-access-latency.md) charged for a [cache miss](cache-miss.md) beyond a common lookup time in the [average memory access time](average-memory-access-time.md) model. It includes obtaining the requested [cache block](cache-line.md) and making the read complete; this model excludes extra costs from writes and overlapping requests.
