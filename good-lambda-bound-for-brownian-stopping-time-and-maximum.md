# Good-lambda bound for Brownian stopping time and maximum

↑ **Parent:** [Burkholder-Davis-Gundy inequalities](burkholder-davis-gundy-inequalities.md)

For [Brownian motion](brownian-motion-split.md) started at zero, condition at time $\lambda^2$. If the stopping time exceeds $\beta^2\lambda^2$ while the running absolute maximum stays below $\delta\lambda$, the path must remain in a fixed interval for another $(\beta^2-1)\lambda^2$ time units. Its expected exit time from this interval is at most $\delta^2\lambda^2$. [Markov's inequality](markov-s-inequality.md) yields the displayed bound. Integrating it against $d\Phi$ for a function of [moderate growth](moderate-growth.md), then absorbing the small tail term, proves $\mathbb E\Phi(\sqrt\tau)\leq C_\Phi\mathbb E\Phi(B_\tau^*)$.
