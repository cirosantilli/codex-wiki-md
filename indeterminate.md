# Indeterminate

↑ **Parent:** [Polynomial](polynomial-split.md)

An indeterminate is a formal symbol used to construct a [polynomial](polynomial-split.md). Choosing an input later defines a [polynomial function](polynomial-function.md); the symbol itself is not a fixed member of the coefficient [ring](ring.md).
