# Prefix-dropping iterator

↑ **Parent:** [Iterator](iterator.md)

Discard input values until the first one satisfying a [predicate](predicate.md), then return that value and every remaining value without testing the predicate again. A [demand-driven filtering iterator](demand-driven-filtering-iterator.md) instead keeps testing and can discard later values too. A buffered first match must survive repeated availability tests and [iterator snapshots](iterator-snapshot.md). A flag distinguishes the initial seeking phase from the already-positioned remainder.
