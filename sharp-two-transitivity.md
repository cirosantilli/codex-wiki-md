# Sharp two-transitivity

↑ **Parent:** [Sharp t-transitivity](sharp-t-transitivity.md)

A [group action](group-action.md) is sharply two-transitive when exactly one element sends each ordered distinct pair to each other ordered distinct pair. The [affine group over a finite field](affine-group-over-a-finite-field.md) provides an example: solve $ax+b=u$ and $ay+b=v$ uniquely, giving $a=(v-u)/(y-x)$.
