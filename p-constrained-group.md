# p-constrained group

↑ **Parent:** [P-core of a finite group](p-core-of-a-finite-group.md)

Put $\overline G=G/O_{p'}(G)$ using the [p-prime core of a finite group](p-prime-core-of-a-finite-group.md). A finite [group](group-split.md) is p-constrained if $C_{\overline G}(O_p(\overline G))\le O_p(\overline G)$. If $O_{p'}(G)=1$, the [p-core of a finite group](p-core-of-a-finite-group.md) has its centralizer contained in itself. Then [block idempotents centralize a normal p-subgroup](block-idempotents-centralize-a-normal-p-subgroup.md) places every block idempotent in $kO_p(G)$, a [local ring](local-ring.md), so $kG$ has only the [principal block](principal-block.md).
