# Paradoxical group action

↑ **Parent:** [Amenable group](amenable-group.md)

A $G$-set $X$ is paradoxical when it contains two disjoint subsets each $G$-equidecomposable with $X$. An invariant finitely additive probability measure rules out such a decomposition, because it would assign each copy the full measure of $X$.
