# AND rule for nodewise graph selection

↑ **Parent:** [Nodewise regression](nodewise-regression.md)

The intersection rule retains an edge only when both directions of [nodewise regression](nodewise-regression.md) select it. It is more conservative than the [OR rule for nodewise graph selection](or-rule-for-nodewise-graph-selection.md); the distinction matters because separate finite-sample fits can disagree.
