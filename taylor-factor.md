# Taylor factor

↑ **Parent:** [Critical resolved shear stress](critical-resolved-shear-stress.md)

The ratio $M=\sigma/\tau_c$ connecting a macroscopic tensile flow [stress](stress.md) to a reference [critical resolved shear stress](critical-resolved-shear-stress.md) in a specified polycrystal model. Texture, slip families and compatibility assumptions matter. An order-three factor is a conventional estimate for randomly oriented cubic grains, distinct from the factor two for a perfectly oriented single [slip system](slip-system.md).
