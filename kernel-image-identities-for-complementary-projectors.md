# Kernel-image identities for complementary projectors

↑ **Parent:** [Projection (linear algebra)](projection-linear-algebra.md)

For an [idempotent](idempotent.md) [linear map](linear-map.md) $P$, $I-P$ is also [idempotent](idempotent.md) and

$$
\ker P=\operatorname{im}(I-P),\qquad \ker(I-P)=\operatorname{im}P.
$$

For the first identity, $P(I-P)=0$ proves one inclusion. If $Pv=0$, then $v=(I-P)v$, proving the reverse inclusion. Apply the same argument to $I-P$ for the second identity. Consequently the ambient [vector space](vector-space-split.md) is the [direct sum](direct-sum.md) of the image and [kernel of a linear map](kernel-of-a-linear-map-split.md) of $P$. [Orthogonality](orthogonal-vectors.md) is not required; it is a separate property of an [orthogonal projection](orthogonal-projection.md).
