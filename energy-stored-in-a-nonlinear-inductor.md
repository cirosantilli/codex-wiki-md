# Energy stored in a nonlinear inductor

↑ **Parent:** [Inductor](inductor.md)

For a reversible device with flux linkage $\Psi$, electrical power is $I\dot\Psi$, so stored energy changes by $dU=I\,d\Psi$. This reduces to $U=LI^2/2$ only for a fixed linear [inductance](inductance.md). [Hysteresis](hysteresis.md) makes energy path dependent and introduces loss.
