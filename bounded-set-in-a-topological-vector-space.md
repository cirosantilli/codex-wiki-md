# Bounded set in a topological vector space

↑ **Parent:** [Topological vector space](topological-vector-space-split.md)

A subset $B$ of a [topological vector space](topological-vector-space-split.md) is bounded when every neighborhood $U$ of zero absorbs it: $B\subseteq tU$ for all sufficiently large positive $t$. In a [locally convex space](locally-convex-space.md) defined by [seminorms](seminorm.md) $p_\lambda$, this is equivalent to $\sup_{x\in B}p_\lambda(x)<\infty$ for every $\lambda$. In particular, a bounded subset of the [Schwartz space](schwartz-space.md) has a uniform bound for every Schwartz seminorm; it need not have uniformly bounded supports.
