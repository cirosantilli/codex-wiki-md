# SOP model

↑ **Parent:** [Classical conditioning](classical-conditioning.md)

A model associated with [Allan R. Wagner](allan-r-wagner.md) in which stimulus elements occupy an inactive state $I$, primary activation $A_1$, or secondary activation $A_2$. External presentation recruits inactive elements into $A_1$; activity then passes through $A_2$ to inactivity. Learned associates can recruit elements into $A_2$. These are functional states, not established neuronal or [receptor](receptor-biochemistry.md) identities.
