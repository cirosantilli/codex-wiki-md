# Database precedence graph

↑ **Parent:** [Conflict-serializable database schedule](conflict-serializable-database-schedule.md)

A [directed graph](directed-graph.md) with a vertex for each [database transaction](database-transaction.md) and an edge from the earlier to the later participant in each conflicting pair of operations. A [database schedule](database-schedule.md) is a [conflict-serializable database schedule](conflict-serializable-database-schedule.md) exactly when this [directed graph](directed-graph.md) has no directed cycle.
