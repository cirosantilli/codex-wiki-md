# Supermodular set function

↑ **Parent:** [Set function](set-function.md)

A real-valued [set function](set-function.md) is supermodular if it satisfies the displayed inequality. Its negative is a [submodular set function](submodular-set-function.md). Equivalently, the gain from adding an element cannot decrease as the set grows. This is the defining property of a [convex cooperative game](convex-cooperative-game.md), and makes [coalition](coalition-game-theory.md) marginal allocations lie in the [core of a cooperative game](core-game-theory.md).
