# Link isotopy

↑ **Parent:** [Link](link.md)

A link isotopy is an [isotopy](isotopy.md) of the ambient three-sphere carrying one link to another. It preserves the number and individual knot types of the components.

Here [ambient isotopy](ambient-isotopy.md) is applied to the embedded [link](link.md) inside the three-sphere.
