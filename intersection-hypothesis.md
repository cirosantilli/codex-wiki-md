# Intersection hypothesis

↑ **Parent:** [Multiple hypothesis testing](multiple-hypothesis-testing.md)

For a nonempty finite index set $I$, this hypothesis asserts that every member $H_i$ is true simultaneously. A valid local test must have its stated size under every parameter satisfying the entire intersection. The [Bonferroni correction](bonferroni-correction.md) within $I$ always supplies such a test from valid elementary [p-values](p-value.md).
