# Least-squares existence criterion

↑ **Parent:** [Least-squares solution of a linear inverse problem](least-squares-solution-of-a-linear-inverse-problem.md)

For a [bounded linear operator](continuous-linear-operator.md) $K:U\to V$ between [Hilbert spaces](hilbert-space-split.md), a [least-squares solution](least-squares-solution-of-a-linear-inverse-problem.md) for $f$ exists exactly when $P_{\overline{\mathcal R(K)}}f\in\mathcal R(K)$, equivalently $f\in\mathcal R(K)\oplus\mathcal R(K)^\perp$. Indeed the [orthogonal projection](orthogonal-projection.md) onto the closure uniquely minimizes distance to that closed space, and it can be realized by $Ku$ exactly under this condition. Thus all data admit [least-squares solutions](least-squares-solution-of-a-linear-inverse-problem.md) exactly when the range is closed.
