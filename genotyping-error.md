# Genotyping error

↑ **Parent:** [Genotype](genotype.md)

A [genotyping error](genotyping-error.md) is an incorrect observed [allele](allele.md) or [genotype](genotype.md) call. A probabilistic observation model replaces the deterministic [genetic marker](genetic-marker.md) factor by $P(X=x\mid G=g)$, allowing nonzero [probability](probability.md) of an observed call inconsistent with the latent [genotype](genotype.md). Such error can bias family transmission tests and linkage [likelihoods](likelihood-function.md).
