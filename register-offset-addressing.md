# Register-offset addressing

↑ **Parent:** [Memory address](memory-address.md)

An [assembly language](assembly-language.md) memory operand whose effective address is the sum of a base [processor register](processor-register.md) and an offset [processor register](processor-register.md). A byte-load table lookup uses the index directly as a byte offset; wider entries require an appropriate scale. The effective address is formed from the old register values before the destination register is overwritten.
