# Galois cohomology of an elliptic curve

↑ **Parent:** [Elliptic curve](elliptic-curve.md)

For an [elliptic curve](elliptic-curve.md) $E/K$, regard $E(K^{\rm sep})$ as a discrete [Galois module](galois-module.md) for the [absolute Galois group](absolute-galois-group.md) $G_K$. Its continuous [Galois cohomology](galois-cohomology.md) has $H^0(K,E)=E(K)$; $H^1(K,E)$ classifies torsors under $E$. For an integer $n$ invertible in $K$, the [Kummer exact sequence of an elliptic curve](kummer-exact-sequence-of-an-elliptic-curve.md) gives $0\to E(K)/nE(K)\to H^1(K,E[n])\to H^1(K,E)[n]\to0$. If $[n]Q=P$, the first map sends $P$ to $\sigma\mapsto\sigma Q-Q$. Changing $Q$ changes the cocycle by a coboundary; this class vanishes exactly when $P$ has a division point over $K$.
