# Zinc blende structure

↑ **Parent:** [Crystal structure](crystal-structure.md)

The binary diamond-related structure with two interpenetrating face-centred cubic sublattices displaced by a quarter of a body diagonal. Each site has four tetrahedrally arranged neighbours of the other species. [Gallium phosphide](gallium-phosphide.md) is an example; this structure name is distinct from the mineral [sphalerite](sphalerite.md).
