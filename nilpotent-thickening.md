# Nilpotent thickening

↑ **Parent:** [Closed immersion](closed-immersion.md)

A nilpotent thickening is a [closed immersion](closed-immersion.md) defined by a nilpotent [ideal sheaf of a closed subscheme](ideal-sheaf-of-a-closed-subscheme.md). Its underlying topological map is a [homeomorphism](homeomorphism.md), because every [prime ideal](prime-ideal.md) contains every [nilpotent element](nilpotent.md). For example, quotienting the [dual numbers](dual-number.md) by $(\varepsilon)$ changes the [structure sheaf](structure-sheaf-of-a-scheme.md) without changing the single point of the spectrum.
