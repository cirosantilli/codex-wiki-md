# Edge-exposure martingale

↑ **Parent:** [Conditional-expectation martingale](conditional-expectation-martingale.md)

Expose the independent [edge](edge-of-a-graph.md) indicators of a [binomial random graph](binomial-random-graph.md) in a fixed order, and set $M_i=\mathbb E[Z\mid\text{the first }i\text{ indicators}]$ for an integrable statistic $Z$. This is a [martingale](martingale-split.md) from $\mathbb EZ$ to $Z$. If changing one [edge](edge-of-a-graph.md) changes $Z$ by at most $c$, coupling the unexposed indicators gives $|M_i-M_{i-1}|\leq c$, permitting the [Azuma-Hoeffding inequality](azuma-s-inequality.md).
