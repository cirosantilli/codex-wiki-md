# DMA address

↑ **Parent:** [Direct memory access](direct-memory-access.md)

An address supplied to a device for [DMA](direct-memory-access.md), in the device's address system. The [Linux kernel](linux-kernel.md)'s mapping interface returns this separately from the [CPU](central-processing-unit.md)'s [virtual address](virtual-address.md); an [IOMMU](input-output-memory-management-unit.md) can translate it to a [physical address](physical-address.md). [Linux kernel documentation, Dynamic DMA mapping Guide: CPU and DMA addresses](https://docs.kernel.org/core-api/dma-api-howto.html)
