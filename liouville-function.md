# Liouville function

↑ **Parent:** [Arithmetic function](arithmetic-function-split.md)

The Liouville function is $\lambda(n)=(-1)^{\Omega(n)}$, where $\Omega(n)$ is the [total number of prime factors](total-number-of-prime-factors.md) counted with multiplicity. It is a [completely multiplicative function](completely-multiplicative-function.md): multiplication adds prime-factor multiplicities, so $\lambda(ab)=\lambda(a)\lambda(b)$.
