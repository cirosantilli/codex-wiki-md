# Ideal class group of Q of square root 229

↑ **Parent:** [Ideal class group](ideal-class-group.md)

Put $\omega=(1+\sqrt{229})/2$, $P=(3,\omega)$ and $Q=(5,\omega-4)$. The [Minkowski bound for ideal classes](minkowski-s-bound.md) is $\sqrt{229}/2<8$, so the [ideal class group](ideal-class-group.md) is generated by primes above three and five; two and seven are inert. The [prime ideal factorizations](prime-ideal-factorization.md) $(6+\omega)=PQ$ and $(15+2\omega)=P^3$ reduce it to a cyclic group of order dividing three. It is not trivial: the unit $\epsilon=(15+\sqrt{229})/2$ has [field norm](field-norm.md) minus one. If an algebraic integer had norm of absolute value three, multiplying by a power of this unit would make both real absolute values at most $\sqrt{3\epsilon}$. For $a=x+y\omega$, this bounds $|y|\sqrt{229}=|a-a'|\leq2\sqrt{3\epsilon}<\sqrt{229}$, forcing $y=0$, which cannot have norm of absolute value three.
