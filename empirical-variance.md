# Empirical variance

↑ **Parent:** [Sample variance](sample-variance.md)

The [empirical variance](empirical-variance.md) is the [variance](variance-split.md) of the [empirical distribution](type-information-theory.md), which puts [probability](probability.md) $1/n$ on each observation. It uses divisor $n$, whereas the usual [sample variance](sample-variance.md) uses divisor $n-1$. For [independent and identically distributed random variables](independent-and-identically-distributed-random-variables.md) with finite second [moment](moment.md), [jackknife bias correction](jackknife-bias-correction.md) converts the [empirical variance](empirical-variance.md) into the [unbiased estimator](unbiased-estimator.md) $s_n^2$ exactly.
