# Cycle detection

↑ **Parent:** [Algorithm](algorithm-split.md)

Determine whether repeated deterministic updates revisit a state, and optionally find the preperiod and cycle length. Recording all visited states uses memory proportional to the visited orbit. [Floyd's cycle-finding algorithm](floyd-s-cycle-finding-algorithm.md) detects repetition with constant extra memory.
