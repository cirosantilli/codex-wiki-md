# Stiffness matrix

↑ **Parent:** [Finite element method](finite-element-method.md)

The stiffness matrix represents a variational [bilinear form](bilinear-form.md) $a$ in a [finite element](finite-element.md) basis. A symmetric [coercive bilinear form](coercive-bilinear-form.md) gives a [positive-definite matrix](positive-definite-matrix.md). Local support of the [piecewise-linear hat functions](piecewise-linear-hat-function.md) produces a sparse [matrix](matrix.md), allowing efficient numerical solution.
