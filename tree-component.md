# Tree component

↑ **Parent:** [Component (graph theory)](component-graph-theory.md)

A tree component is a [graph component](component-graph-theory.md) whose induced [graph](graph-split.md) is a [tree](tree-graph-theory.md). A [tree component](tree-component.md) with $j$ [vertices](vertex-graph-theory.md) has exactly $j-1$ [edges](edge-of-a-graph.md).
