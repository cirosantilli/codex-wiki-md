# Dual Boolean function

↑ **Parent:** [Boolean circuit](boolean-circuit.md)

The dual of a Boolean function $f$ is $f^*(x)=\neg f(\neg x)$. Swapping AND with OR and zero with one in a monotone circuit for $f$ produces a circuit for $f^*$ by [De Morgan's laws](de-morgan-s-laws.md).
