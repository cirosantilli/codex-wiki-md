# Locally integrable function

↑ **Parent:** [Test function](test-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Locally_integrable_function)

A function is locally integrable when its absolute value has finite integral over every compact subset of its domain. It defines a regular [distribution](distribution-mathematical-analysis.md) by integration against test functions.
