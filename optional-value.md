# Optional value

↑ **Parent:** [Data structure](data-structure-split.md)

A value that is either absent or contains one payload. In [Haskell](haskell.md), `Maybe a` uses `Nothing` for absence and `Just x` for presence. These alternatives distinguish an absent element from a present payload that may itself be undefined.
