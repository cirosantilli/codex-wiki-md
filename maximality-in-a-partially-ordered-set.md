# Maximality in a partially ordered set

↑ **Parent:** [Maximal element of a partially ordered set](maximal-element-of-a-partially-ordered-set.md)

An element is maximal when there is no strictly greater element of the [partially ordered set](partially-ordered-set.md). This is different from being a greatest element, which must dominate every other element.
