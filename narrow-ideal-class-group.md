# Narrow ideal class group

↑ **Parent:** [Ideal class group](ideal-class-group.md)

The narrow ideal class group of a [number field](number-field.md) is the group of nonzero [fractional ideals](fractional-ideal.md) modulo [principal fractional ideals](principal-fractional-ideal.md) generated by [totally positive](totally-positive-element-of-a-number-field.md) elements. It is the [ray class group](ray-class-group.md) for the modulus consisting of all real [Archimedean places](archimedean-place.md) and trivial finite part. The forgetful map to the ordinary [ideal class group](ideal-class-group.md) is surjective, with [kernel](kernel-of-a-linear-map.md) $\{\pm1\}^{r_1}/\operatorname{sgn}(\mathcal O_K^\times)$ under the [unit signature map](unit-signature-map.md).
