# Top-bottom decisiveness lemma

↑ **Parent:** [Gibbard-Satterthwaite theorem](gibbard-satterthwaite-theorem.md)

For two agents and a [strategyproof](strategyproofness.md) [social choice function](social-choice-function.md), if an alternative is selected when one agent ranks it first and the other ranks it last, it is selected whenever the first agent ranks it first, whatever the other agent reports. Changing the first agent's order preserves its attainable top choice; changing the second agent's order cannot offer it an improvement over a selected bottom alternative.
