# Maximum entropy distribution on a finite set

↑ **Parent:** [Information entropy](information-entropy.md)

Among [probability distributions](probability-distribution.md) on a finite set of $m$ elements, the [uniform distribution](continuous-uniform-distribution.md) uniquely maximizes [information entropy](information-entropy.md), attaining $\log m$.
