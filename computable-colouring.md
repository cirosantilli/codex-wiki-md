# Computable colouring

↑ **Parent:** [Homogeneous set for a colouring](homogeneous-set-for-a-colouring.md)

A colouring is computable when an [algorithm](algorithm.md) sorts the finite input subset, computes its colour and terminates. Its colour classes are uniformly [computable sets](computable-set.md). The distinction between existence of an infinite [homogeneous set for a colouring](homogeneous-set-for-a-colouring.md) and effective construction of one is a basic phenomenon in [computability theory](computability-theory.md).
