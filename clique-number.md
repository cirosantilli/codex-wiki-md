# Clique number

↑ **Parent:** [Clique (graph theory)](clique-graph-theory.md)

The maximum number of vertices in a [clique](clique-graph-theory.md) of a [graph](graph-split.md). If the graph contains $K_k$ and no $K_{k+1}$, its clique number is exactly $k$, since every larger [clique](clique-graph-theory.md) contains a $(k+1)$-[clique](clique-graph-theory.md).
