# Dark port

↑ **Parent:** [Mach-Zehnder interferometer](mach-zehnder-interferometer.md)

An output port whose ideal [probability amplitude](probability-amplitude.md) vanishes by [destructive interference](destructive-interference.md) for a specified coherent input and calibration. Changing a relative [wave phase](phase-waves.md), losing [quantum coherence](quantum-coherence-in-a-specified-basis.md) or changing the input can brighten it.
