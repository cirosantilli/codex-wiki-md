# Linear horizontal distribution on a vector bundle

↑ **Parent:** [Horizontal subspace of a vector bundle connection](horizontal-subspace-of-a-vector-bundle-connection.md)

In a local trivialization, a vector-bundle connection with matrix $A$ defines the displayed complement of the vertical tangent space. The frame-change law makes these complements independent of the trivialization. Their dependence on the fiber coordinate is linear; an arbitrary horizontal complement need not satisfy this condition and need not define a [connection on a vector bundle](connection-vector-bundle.md). Horizontal lifts satisfy the ordinary differential equation defining [parallel transport](parallel-transport.md).
