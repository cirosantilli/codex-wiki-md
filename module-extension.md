# Module extension

↑ **Parent:** [Short exact sequence](short-exact-sequence.md)

A short exact sequence with specified kernel module $A$ and quotient module $C$. Its equivalence class is determined by the degree-one [Ext functor](ext-functor.md); equivalence must preserve both end modules.
