# Well-order code

↑ **Parent:** [Constructible hierarchy](constructible-hierarchy.md)

A well-order code is a [binary relation](binary-relation.md) $R\subseteq\omega\times\omega$ for which $(\omega,R)$ is a [well-order](well-order.md). Its representation is the unique [countable ordinal](countable-ordinal.md) isomorphic to $(\omega,R)$.
