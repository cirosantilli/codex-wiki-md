# Hall-plateau voltmeter calibration

↑ **Parent:** [Quantum Hall effect](quantum-hall-effect.md)

For an integer [quantum Hall effect](quantum-hall-effect.md) plateau with index $p$ carrying a known current $I$, the true transverse voltage is $IR_K/p$. If an offset-corrected instrument displays $D_p$, its gain in volts per displayed unit is $\lambda=IR_K/(pD_p)$. Independent current and displayed-height errors add in relative quadrature. The Hall-bar width cancels; it enters an electric-field calibration instead. A missing plateau height or an unidentified absolute plateau index prevents a unique numerical gain.
