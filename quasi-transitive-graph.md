# Quasi-transitive graph

↑ **Parent:** [Graph automorphism](graph-automorphism.md)

A [graph](graph-split.md) is quasi-transitive if some group of [graph automorphisms](graph-automorphism.md) has finitely many vertex orbits. This is also called a graph of finite type. A [connected graph](connected-graph.md) that is infinite and a [locally finite graph](locally-finite-graph.md) then has uniformly bounded degrees. Every orbit is infinite: a finite invariant orbit would have finite neighborhoods, and finitely many orbit types would put the entire graph in one such neighborhood. This permits finite sets to be moved arbitrarily far apart by [graph automorphisms](graph-automorphism.md).
