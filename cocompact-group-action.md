# Cocompact group action

↑ **Parent:** [Geometric group theory](geometric-group-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cocompact_group_action)

A group action on a space is cocompact when its quotient is compact, equivalently when some compact set has translates covering the space.
