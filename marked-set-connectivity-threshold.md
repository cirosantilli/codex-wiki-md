# Marked-set connectivity threshold

↑ **Parent:** [Uniform random graph process](uniform-random-graph-process.md)

For a fixed set $L$ of $\lfloor\sqrt n\rfloor$ [vertices](vertex-graph-theory.md), let $\tau_L$ be the first step at which they all belong to one [graph component](component-graph-theory.md). In the [uniform random graph process](uniform-random-graph-process.md), $\tau_L$ lies between $n(\log n-\omega)/4$ and $n(\log n+\omega)/4$ [with high probability](with-high-probability.md) for every $\omega\to\infty$. Below that scale the marked [isolated vertex](isolated-vertex.md) count has divergent [expected value](expected-value.md) and small relative [variance](variance-split.md). Above it the [logarithmic-regime giant component](logarithmic-regime-giant-component.md) misses $o(\sqrt n)$ [vertices](vertex-graph-theory.md); [exchangeability](exchangeable-random-variables.md) and a [union bound](boole-s-inequality.md) show that none are marked. The label coupling then transfers the two assertions to the process.
