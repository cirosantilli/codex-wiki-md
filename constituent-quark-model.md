# Constituent-quark model

↑ **Parent:** [Quark model](quark-model.md)

The [constituent-quark model](constituent-quark-model.md) describes a low-energy [hadron](hadron.md) using effective massive [quarks](quark.md) and phenomenological interactions. Its [constituent quark masses](constituent-quark-mass.md) include strong-interaction dressing and differ from short-distance running [quark masses](quark-mass.md).
