# Parametrized post-Newtonian formalism

↑ **Parent:** [General relativity](general-relativity-split.md)

The [parametrized post-Newtonian formalism](parametrized-post-newtonian-formalism.md) expresses a weak-field [metric tensor](metric-tensor.md) using phenomenological parameters so that different gravitational theories can be compared with the same observations. Its spatial-curvature parameter $\gamma_{\rm PPN}$ is one in [general relativity](general-relativity-split.md); it is distinct from the kinematic [Lorentz factor](lorentz-factor.md).
