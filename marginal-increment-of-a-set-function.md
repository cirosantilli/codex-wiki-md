# Marginal increment of a set function

↑ **Parent:** [Set function](set-function.md)

The [marginal increment](marginal-increment-of-a-set-function.md) measures how much a [set function](set-function.md) changes when one new element is added. Usually $x\notin S$ is required; if $x\in S$, the displayed difference is zero. The [marginal increments](marginal-increment-of-a-set-function.md) of a [modular set function](modular-set-function.md) depend only on $x$. The [marginal increments](marginal-increment-of-a-set-function.md) of a [submodular set function](submodular-set-function.md) can only decrease as the input [subset](subset.md) grows without acquiring $x$.
