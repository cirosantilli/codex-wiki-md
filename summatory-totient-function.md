# Summatory totient function

↑ **Parent:** [Euler totient function](euler-totient-function.md)

The summatory totient function is $\Phi(x)=\sum_{n\le x}\varphi(n)$. It counts the [coprime](coprime-integers.md) [ordered pairs](ordered-pair.md) $(a,b)$ with $1\le a\le b\le x$. The identity $\sum_{d\mid n}\varphi(d)=n$ yields $\sum_{j=1}^{x}\Phi(\lfloor x/j\rfloor)=x(x+1)/2$ for a positive [integer](integer-split.md) $x$.
