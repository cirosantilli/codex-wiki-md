# Topological invariant

↑ **Parent:** [Topology](topology-split.md)

A topological invariant is a property or mathematical object preserved by [homeomorphisms](homeomorphism.md) of [topological spaces](topological-space.md). [Connectedness](connected-space.md) and [compactness](compact-space.md) are examples. The [fundamental group](fundamental-group.md) is an invariant up to [group isomorphism](group-isomorphism.md); it is also preserved up to [isomorphism](isomorphism.md) by [homotopy equivalence](homotopy-equivalence.md), a stronger invariance property which does not hold for every topological invariant.
