# Krylov subspace method

↑ **Parent:** [Numerical linear algebra](numerical-linear-algebra-split.md)

A [Krylov subspace method](krylov-subspace-method.md) seeks approximations in spaces generated by repeated matrix applications to a starting vector. For a linear system with starting point $x_0$ and residual $r_0=b-Ax_0$, the affine search space is $x_0+K_k(A,r_0)$. Choosing an optimality or orthogonality condition within it gives different algorithms. The [conjugate gradient method](conjugate-gradient-method.md) minimizes the [energy norm](energy-norm.md) of the error for a [symmetric positive-definite matrix](symmetric-positive-definite-matrix.md); other methods use residual minimization or different projections. The growth of the [Krylov subspace](krylov-subspace.md) can stop early when an invariant subspace is reached.
