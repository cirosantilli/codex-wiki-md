# Weak definability of a numerical function

↑ **Parent:** [Arithmetical provability predicate](arithmetical-provability-predicate.md)

A [logical formula](logical-formula.md) weakly defines a total numerical [function](function-split.md) in a [first-order theory](first-order-theory.md) when, at every standard input [tuple](finite-tuple.md), it proves the graph instance with the correct standard output and refutes graph instances with every incorrect standard output. This is numeralwise representation of the graph; it does not yet assert uniqueness against nonstandard outputs inside a [first-order model](model-of-a-first-order-theory.md).
