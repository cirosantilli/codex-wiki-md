# Polarization state

↑ **Parent:** [Photon polarization](photon-polarization.md)

The [quantum state](quantum-state.md) associated with the two transverse polarization degrees of freedom of a photon in a specified propagation mode. In a horizontal-vertical basis, a pure state is $\alpha|H\rangle+\beta|V\rangle$ with $|\alpha|^2+|\beta|^2=1$; a [density matrix](density-matrix-split.md) also describes mixtures. Linear polarizers test real combinations of these basis states, while phase-sensitive elements allow elliptical and circular polarization measurements.
