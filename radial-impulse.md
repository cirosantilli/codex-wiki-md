# Radial impulse

↑ **Parent:** [Impulse](impulse.md)

An [impulse](impulse.md) directed along the position vector relative to a specified origin. Its [angular impulse](angular-impulse.md) vanishes because $\Delta\mathbf J=\mathbf r\times\Delta\mathbf p=0$. It can nevertheless change [kinetic energy](kinetic-energy.md); if an initially circular [Kepler orbit](kepler-orbit.md) receives radial [velocity](velocity.md) $w$, the added specific [orbital energy](orbital-energy.md) is $w^2/2$.
