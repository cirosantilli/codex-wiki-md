# Standard concentration

↑ **Parent:** [Standard state](standard-state.md)

The reference concentration $c^\circ$ used to make concentration activities dimensionless. Changing this reference changes the numerical dimensionless [equilibrium constant](equilibrium-constant.md) when the reaction changes the total number of solute or gas molecules.
