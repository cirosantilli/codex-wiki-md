# Radiative mass loss at fixed luminosity

↑ **Parent:** [Astrophysics](astrophysics-split.md)

For [luminosity](luminosity.md) $L$, [mass-energy equivalence](mass-energy-equivalence.md) gives $|\dot M|=L/c^2$. Holding $L$ constant gives a time $t=fMc^2/L$ to radiate a mass fraction $f$. A [blackbody](blackbody.md) estimate uses the [Stefan–Boltzmann law](stefan-boltzmann-law.md), $L=4\pi R^2\sigma T^4$. This is a radiative-energy estimate, not a model of a star's evolving nuclear fuel or mass loss in a wind.
