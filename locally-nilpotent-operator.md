# Locally nilpotent operator

↑ **Parent:** [Linear operator](linear-operator.md)

A linear operator $T$ is locally nilpotent if for each vector $v$ there is an integer $m(v)$ such that $T^{m(v)}v=0$. In finite dimension this is equivalent to being a [nilpotent operator](nilpotent-linear-map.md). Differentiation on the [polynomial ring](polynomial-ring.md) is locally nilpotent in characteristic zero but has no uniform nilpotence exponent.
