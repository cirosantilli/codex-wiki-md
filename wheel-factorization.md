# Wheel factorization

↑ **Parent:** [Number-theoretic sieve](number-theoretic-sieve.md)

Choose a modulus $W$ that is a product of small [primes](prime-number-split.md). Every [prime](prime-number-split.md) not dividing $W$ must be [coprime](coprime-integers.md) to $W$, so a search can restrict candidates to the corresponding [residue classes](residue-class.md) modulo $W$. For several [linear polynomials](linear-polynomial.md), discard each [residue class](residue-class.md) in which any required value is divisible by a selected [prime](prime-number-split.md). The surviving [residue classes](residue-class.md) can be combined using the [Chinese remainder theorem](chinese-remainder-theorem.md).
