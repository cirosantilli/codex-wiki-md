# Conditional photon-number bias

↑ **Parent:** [Photon subtraction](photon-subtraction.md)

A subtraction event weights initial occupation $n$ by $n$ before removing one [photon](photon.md). Thus its conditional output mean is $\langle N(N-1)\rangle/\mu$, giving the displayed identity for $\mu>0$. If the initial [variance](variance-split.md) exceeds its mean, this biased selection can offset the removed [photon](photon.md). The unconditional ensemble includes unsuccessful events and has a different [energy](energy-split.md) balance.
