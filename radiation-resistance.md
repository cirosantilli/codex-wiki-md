# Radiation resistance

↑ **Parent:** [Antenna (radio)](antenna-radio.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Radiation_resistance)

[Radiation resistance](radiation-resistance.md) represents emitted electromagnetic [power](power.md) as a real input resistance of an [antenna](antenna-radio.md). It does not describe conversion to heat inside the conductor. If peak current amplitude is used, $P_{\rm rad}=|I_0|^2R_{\rm rad}/2$. Real ohmic loss adds a separate resistance and lowers radiation efficiency. For an ideal short uniform-current element of length $d$, the [Hertzian dipole](hertzian-dipole.md) gives $R_{\rm rad}=80\pi^2(d/\lambda)^2$ in ohms, using the usual vacuum impedance approximation $120\pi\,\Omega$.
