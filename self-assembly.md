# Self-assembly

↑ **Parent:** [Nanotechnology](nanotechnology.md)

Organization of interacting building blocks into a structure through their own dynamics under specified environmental conditions. A useful description states the components, interactions, environment and reversible transport/rearrangement mechanisms. A favourable [thermodynamic equilibrium](thermodynamic-equilibrium.md) structure can still fail to form if aggregation or glassy arrest prevents defect correction.
