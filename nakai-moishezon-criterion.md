<h1 id="nakai-moishezon-criterion">Nakai–Moishezon criterion</h1>

↑ **Parent:** [Ample Cartier divisor](ample-cartier-divisor.md)

An integral [Cartier divisor](cartier-divisor-split.md) $D$ on a [projective scheme](projective-scheme.md) is [ample](ample-line-bundle.md) if and only if $D^{\dim Y}\cdot Y>0$ for every positive-dimensional integral closed [subvariety](closed-subvariety.md) $Y$. Testing only curves is sufficient in dimension one, but not in higher dimensions.
