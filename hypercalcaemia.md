# Hypercalcaemia

↑ **Parent:** [Serum calcium](serum-calcium.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hypercalcaemia)

Hypercalcaemia is an abnormally elevated [serum calcium](serum-calcium.md) concentration. A diagnosis in medical records depends on testing and diagnostic practice, which can introduce [selection bias](selection-bias.md) into an [observational study](observational-study.md).
