# String sigma model in an isotropic plane wave

↑ **Parent:** [String sigma model in a spacetime metric](string-sigma-model-in-a-spacetime-metric.md)

In [conformal gauge](conformal-gauge.md) and [light-cone gauge in string theory](light-cone-gauge-in-string-theory.md) $X^+=\kappa\tau$, the transverse part of the [string sigma model in a spacetime metric](string-sigma-model-in-a-spacetime-metric.md) reduces to

$$
S_\perp=\frac T2\int d\tau d\sigma\,\left(\dot X^I\dot X^I-X'^IX'^I-m^2\kappa^2X^IX^I\right).
$$

The omitted longitudinal term is a total time derivative. Each transverse coordinate obeys a massive [wave equation](wave-equation-split.md). If the spatial period is $L$, the longitudinal momentum is $p^+=T\kappa L$ in this normalization. Keeping the gauge slope explicit prevents missing a factor of $p^+$ when changing conventions.
