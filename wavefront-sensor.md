# Wavefront sensor

↑ **Parent:** [Adaptive optics](adaptive-optics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Wavefront_sensor)

A wavefront sensor measures information from which a [wavefront error](wavefront-error.md) can be reconstructed. For example, a [Shack–Hartmann wavefront sensor](shack-hartmann-wavefront-sensor.md) measures local wavefront slopes using lenslets.
