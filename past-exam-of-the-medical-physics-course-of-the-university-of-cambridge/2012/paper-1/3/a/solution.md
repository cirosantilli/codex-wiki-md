Generic [image registration](../../../../../image-registration.md) estimates a coordinate transformation aligning corresponding features in two images. A rigid transform permits translation and rotation, an affine transform additionally permits linear deformation, and a nonrigid model permits spatially varying displacement. The transformation class expresses assumptions about what changes between the acquisitions.

One can minimize a discrepancy between $I_1(T(\mathbf x))$ and $I_2(\mathbf x)$, using interpolated image values and an explicit [optimization](../../../../../mathematical-optimization-split.md) procedure. Squared intensity differences suit some comparable acquisitions; [mutual information](../../../../../mutual-information.md) can compare statistical dependence when image contrasts differ. Landmarks, feature descriptors or additional geometric constraints provide other information. Smoothness or other [regularization](../../../../../regularization.md) controls overly flexible transformations. A favorable objective value does not by itself prove correct feature correspondence.
