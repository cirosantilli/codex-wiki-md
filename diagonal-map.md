# Diagonal map

↑ **Parent:** [Product topology](product-topology.md)

The diagonal map sends $x$ to $(x,x)$. It is an embedding of a [topological space](topological-space.md) onto its diagonal subset, because either coordinate projection is its inverse on the image. For a closed oriented [manifold](topological-manifold.md), that subset has a [fundamental class](fundamental-class.md), whose [Poincare dual](poincare-dual.md) is the [cohomology class of the diagonal](cohomology-class-of-the-diagonal.md).
