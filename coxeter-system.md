# Coxeter system

↑ **Parent:** [Coxeter group](coxeter-group.md)

A Coxeter system $(W,I,M)$ records a [Coxeter group](coxeter-group.md) $W$, its set $I$ of simple generators, and its [Coxeter matrix](coxeter-matrix.md) $M=(m_{ij})$.
