# Finitely generated upper set

↑ **Parent:** [Upper set](upper-set.md)

An [upper set](upper-set.md) generated by a finite [set](set-split.md) $A$ is represented by the [minimal elements](minimal-element-of-a-partially-ordered-set.md) of $A$. Removing a nonminimal generator preserves the upward closure. If each pair has a [least upper bound](least-upper-bound-in-a-partially-ordered-set.md), then $\uparrow A\cap\uparrow B=\uparrow\{a\vee b:a\in A,b\in B\}$, so finite generators support [intersection](set-intersection.md) without enumerating the potentially infinite represented [sets](set-split.md).
