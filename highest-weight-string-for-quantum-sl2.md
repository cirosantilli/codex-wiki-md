# Highest-weight string for quantum sl2

↑ **Parent:** [Quantum enveloping algebra of sl2](quantum-enveloping-algebra-of-sl2.md)

If $Ev=0$ and $Kv=\lambda v$, induction using the defining commutator gives the displayed identity. When $q$ is not a [root of unity](root-of-unity.md), a finite string of length $n+1$ in a [simple module](irreducible-module.md) has $\lambda=\epsilon q^n$, $\epsilon=\pm1$. Its distinct $K$ [eigenvalues](eigenvalue.md) make the string vectors independent, and the nonzero raising coefficients prove simplicity.
