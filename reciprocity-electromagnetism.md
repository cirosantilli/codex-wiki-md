# Reciprocity (electromagnetism)

↑ **Parent:** [Electromagnetism](electromagnetism-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reciprocity_(electromagnetism))

[Electromagnetic reciprocity](reciprocity-electromagnetism.md) relates the response obtained after exchanging source and receiver in a linear reciprocal medium. For suitably normalized ports it gives a symmetric scattering matrix. It does not require zero reflection. A magnetically biased [Faraday effect](faraday-effect.md) provides an important optical example in which reciprocity can fail.
