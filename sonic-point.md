# Sonic point

↑ **Parent:** [Compressible flow](compressible-flow-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sonic_point)

A sonic point is a point at which the flow speed equals the local [sound speed](speed-of-sound.md), so the [Mach number](mach-number.md) is one.
