# Zero flavour triality of a light-quark hadron

↑ **Parent:** [Flavor symmetry](flavor-symmetry.md)

For a [colour singlet](colour-singlet.md) [hadron](hadron.md) built entirely from [up quarks](up-quark.md), [down quarks](down-quark.md), [strange quarks](strange-quark.md), [antiquarks](antiquark.md) and [gluons](gluon.md), the net number of quarks is a multiple of three. The central [SU(3)](su-3-group.md) colour element multiplies the state by $\omega^{n_q-n_{\bar q}}$, while a singlet must be unchanged. The central flavour element supplies the same phase because all three light flavours form the fundamental representation. Every resulting flavour multiplet therefore has zero [SU(3) triality](triality-su-3.md). [Heavy quarks](heavy-quark.md) are singlets of light-flavour SU(3), so hadrons containing them do not obey this argument. The zero-triality restriction allows higher light-quark multiplets as well as the familiar singlet, octet and decuplet.
