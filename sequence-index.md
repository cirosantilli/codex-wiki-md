# Sequence index

↑ **Parent:** [Sequence](sequence.md)

A [sequence index](sequence-index.md) labels a position in a [sequence](sequence.md); the [sequence term](sequence-term.md) at that position is its value. For a finite [sequence](sequence.md) of length $n$, one possible [index set](index-set.md) is $\{1,\ldots,n\}$; a zero-based convention instead uses $\{0,\ldots,n-1\}$. Equal [sequence terms](sequence-term.md) can have different [sequence indices](sequence-index.md).
