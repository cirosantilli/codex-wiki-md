# Hamming code weight enumerator

↑ **Parent:** [Hamming code](hamming-code.md)

Here $N=2^l-1$, $m=2^{l-1}$ and the [weight enumerator](weight-enumerator.md) convention is $W_C(s,t)=\sum_{c\in C}s^{\operatorname{wt}(c)}t^{N-\operatorname{wt}(c)}$. The [dual code](dual-code.md) is the [binary simplex code](binary-simplex-code.md), with enumerator $t^N+(2^l-1)s^m t^{m-1}$. The [MacWilliams identity](macwilliams-identity.md) gives the formula. For $l=3$, the ordinary enumerator $W_C(z,1)$ is $1+7z^3+7z^4+z^7$; for $l=1$, the degenerate one-word code has enumerator $t$.
