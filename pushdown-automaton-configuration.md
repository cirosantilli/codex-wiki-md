# Pushdown automaton configuration

↑ **Parent:** [Pushdown automaton](pushdown-automaton.md)

The control state $q$, unread input [word](string.md) $w$, and [stack](stack-data-structure.md) contents $\alpha$ of a [pushdown automaton](pushdown-automaton.md). A fixed convention must say which end of $\alpha$ is the top. With the top on the left, replacing top $X$ by $\gamma$ changes $X\beta$ into $\gamma\beta$.
