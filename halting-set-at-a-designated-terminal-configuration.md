# Halting set at a designated terminal configuration

↑ **Parent:** [Modular machine](modular-machine.md)

For a [modular machine](modular-machine.md) whose $(0,0)$ is terminal, $H_0(\mathcal M)$ is the set of configurations whose forward computation reaches exactly $(0,0)$, including the zero-step computation there. It may differ from the set of configurations stopping at any terminal configuration. Determinism makes membership invariant along each instruction edge.
