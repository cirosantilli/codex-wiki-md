# Eigenfunction

↑ **Parent:** [Eigenvalue](eigenvalue.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Eigenfunction)

An eigenfunction is a nonzero function $f$ satisfying $Lf=\lambda f$ for a linear operator $L$ and scalar [eigenvalue](eigenvalue.md) $\lambda$.
