# Chebyshev function in an arithmetic progression

↑ **Parent:** [Analytic number theory](analytic-number-theory-split.md)

For $(a,q)=1$,

$$
\psi(x;q,a)
=\sum_{\substack{n\leq x\\n\equiv a\pmod q}}\Lambda(n).
$$

The [Orthogonality of Dirichlet characters](orthogonality-of-dirichlet-characters.md) expresses it in terms of character-twisted [Von Mangoldt functions](von-mangoldt-function.md).
