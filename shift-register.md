# Shift register

↑ **Parent:** [Digital register](digital-register.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Shift_register)

A chain of [digital registers](digital-register.md) that transfers each stored value to the next stage at a [clock edge](clock-edge.md). A serial-in parallel-out [shift register](shift-register.md) exposes the stored history simultaneously. With the current input and $k-1$ delayed samples, [combinational logic](combinational-logic.md) can evaluate a [function](function-split.md) of the latest $k$ samples.
