# Finite-set criterion for percolation sharpness

↑ **Parent:** [Exponential decay of subcritical percolation](exponential-decay-of-subcritical-percolation.md)

For a finite vertex set $S$ containing the origin, this quantity is the expected number of potentially open exit edges reached from the origin within $S$. If $\varphi_p(S)<1$, the [BK inequality](van-den-berg-kesten-inequality.md) applied to the first exit of a long open [self-avoiding walk](self-avoiding-walk.md) gives a contraction at the scale of $S$ and hence exponential connection decay. The threshold $\widetilde p_c=\sup\{p:\varphi_p(S)<1\text{ for some finite }S\ni0\}$ equals the [percolation critical probability](percolation-critical-probability.md) by the pivotal-edge differential inequality in [sharpness of the percolation transition](sharpness-of-the-percolation-transition.md).
