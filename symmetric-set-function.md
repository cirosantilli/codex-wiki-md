# Symmetric set function

↑ **Parent:** [Set function](set-function.md)

A [set function](set-function.md) on the [power set](power-set.md) of a [ground set](ground-set.md) $V$ is symmetric when complementary [subsets](subset.md) have equal values. A [hypergraph cut function](hypergraph-cut-function.md) has this property because swapping the two sides changes no crossing [hyperedge](hyperedge.md). If a [symmetric set function](symmetric-set-function.md) is also a [monotone set function](monotone-set-function.md), it is constant: $f(\varnothing)\leq f(S)\leq f(V)=f(\varnothing)$.
