# Beta function

↑ **Parent:** [Gamma function](gamma-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Beta_function)

For $\operatorname{Re}p,\operatorname{Re}q>0$, Euler's beta function is

$$
B(p,q)=\int_0^1t^{q-1}(1-t)^{p-1}\,dt.
$$
