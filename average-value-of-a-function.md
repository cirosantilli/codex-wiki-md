# Average value of a function

↑ **Parent:** [Integral](integral.md)

For an [integrable function](lebesgue-integrable-function.md) on an [interval](interval-mathematics.md) $I$ of positive finite length, its average value is the [integral](integral.md) divided by that length:

$$
\overline f_I=\frac1{|I|}\int_I f(x)\,dx.
$$

If $f$ is constant on equal-length subintervals, this is their values' [arithmetic mean](arithmetic-mean.md); unequal lengths require a [weighted mean](weighted-arithmetic-mean.md). For example, values $2$ and $6$ on two equal halves give average value $4$, whereas value $2$ on the first quarter and $6$ on the remaining three quarters give $5$. The [integral](integral.md) measures total contribution; the [average value of a function](average-value-of-a-function.md) divides out the interval length.

For the [function](function-split.md) $f(x)=2x$ on $[0,1]$, the [average value of a function](average-value-of-a-function.md) is $\int_0^1 2x\,dx=1$. Replacing it by the constant $1$ preserves its [integral](integral.md) on this interval. This is why the [Haar projection](haar-projection.md) uses [cell averages](average-value-of-a-function.md) to obtain a coarser description while retaining each cell's total contribution.
