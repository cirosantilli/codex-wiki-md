# Timer interrupt

↑ **Parent:** [Interrupt](interrupt.md)

An [interrupt](interrupt.md) requested by a [hardware timer](hardware-timer.md), for example when a free-running [digital counter](digital-counter.md) reaches a programmed comparison value. Scheduling the next deadline permits other work or sleep between timed state transitions.
