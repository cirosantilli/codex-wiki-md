# Brent cycle-finding algorithm

↑ **Parent:** [Cycle detection](cycle-detection.md)

A constant-memory [algorithm](algorithm-split.md) for detecting the eventual cycle in a sequence generated by repeated [function](function-split.md) evaluation. It holds a checkpoint fixed while a second pointer advances, doubling the checkpoint interval when exhausted; a second pass locates the start of the cycle.
