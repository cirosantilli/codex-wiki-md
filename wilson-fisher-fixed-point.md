# Wilson-Fisher fixed point

↑ **Parent:** [Renormalization group](renormalization-group.md)

Below four dimensions, the scalar quartic theory has an interacting Wilson-Fisher fixed point that controls the Ising universality class.

This is a particular [fixed point](fixed-point.md) of the [renormalization group](renormalization-group.md), governing the long-distance behavior of a [critical phenomenon](critical-phenomenon-split.md).
