# Forward-invariant set

↑ **Parent:** [Dynamical system](dynamical-system.md)

A subset of a [dynamical system](dynamical-system.md) is [forward invariant](forward-invariant-set.md) if every forward iterate, or every forward-time trajectory beginning in the set, stays in it. For a [map](discrete-dynamical-system-split.md) $F$, this means $F(S)\subseteq S$. It does not require backward invariance or equality $F(S)=S$. Such sets give useful positivity and boundedness guarantees.
