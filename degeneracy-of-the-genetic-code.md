# Degeneracy of the genetic code

↑ **Parent:** [Genetic code](genetic-code.md)

[Degeneracy of the genetic code](degeneracy-of-the-genetic-code.md) means that distinct [codons](codon.md) can specify the same [amino acid](amino-acid.md). For example, UUU and UUC both specify [phenylalanine](phenylalanine.md) in the standard [genetic code](genetic-code.md).[§15.1, Figure 15.4 and paragraph defining degeneracy](biology-2e-by-mary-ann-clark-and-others.md) In the original AUG GCU UUC UGA example, changing UUC to UUU preserves the predicted [amino acid](amino-acid.md) order. This illustrates redundancy of assignment, not equality of every possible effect on [gene expression](gene-expression.md).

[Degeneracy of the genetic code](degeneracy-of-the-genetic-code.md) differs from ambiguity: multiple inputs share one output, whereas an ambiguous assignment would give a single [codon](codon.md) more than one meaning in the same specified decoding context. The standard [genetic code](genetic-code.md) table has one listed assignment per triplet. Alternative [genetic codes](genetic-code.md), including those used in some [mitochondria](mitochondria.md), and engineered decoding contexts must be specified separately; the standard table is not a universal statement about all [organelles](organelle.md) or synthetic systems.
