# Stochastic block model

↑ **Parent:** [Logistic regression](logistic-regression.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stochastic_block_model)

A stochastic block model assigns each [vertex of a graph](vertex-graph-theory.md) to a class and, conditional on those classes, makes distinct [edges](edge-of-a-graph.md) [independent random variables](independent-random-variables.md) whose probabilities depend only on the classes of their endpoints.
