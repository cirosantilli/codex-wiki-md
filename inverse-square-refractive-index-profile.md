# Inverse-square refractive-index profile

↑ **Parent:** [Refractive index](refractive-index.md)

A [transverse electric polarization](transverse-electric-polarization.md) with constant permeability and conserved transverse wavenumber $k_0\sin\theta_0$ satisfies $e''+[\beta^2-(\nu^2-1/4)/(z-z_0)^2]e=0$, with $\beta^2=k_0^2(a^2-\sin^2\theta_0)$ and $\nu^2=1/4+k_0^2b^2$. Substitution $e=\sqrt{|z-z_0|}Z_\nu(\beta|z-z_0|)$ reduces it to the [Bessel equation](bessel-differential-equation.md). The profile is singular at $z_0$, so each side requires its own boundary conditions.
