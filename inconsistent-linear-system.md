# Inconsistent linear system

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

A [linear system](system-of-linear-equations.md) is inconsistent when it has no solution. In [Gaussian elimination](gaussian-elimination.md), a row $0=c$ with $c\ne0$ proves inconsistency. Equivalently the [matrix rank](matrix-rank.md) of the augmented [matrix](matrix.md) is greater than the [matrix rank](matrix-rank.md) of the coefficient [matrix](matrix.md).
