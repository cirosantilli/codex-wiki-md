# Eikonal function

↑ **Parent:** [Geometrical optics](geometrical-optics-split.md)

The rapidly varying real phase of a short-[wavelength](wavelength.md) field written $a(\mathbf r,t)e^{iS(\mathbf r,t)}$. Its derivatives define the local [wavevector](wavevector.md) $\mathbf k=\nabla S$ and [angular frequency](angular-frequency.md) $\omega=-\partial_t S$. The [WKB approximation](wkb-approximation.md) assumes that $a$ and background parameters vary little across one [wavelength](wavelength.md).
