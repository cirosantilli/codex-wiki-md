# Contour plot

↑ **Parent:** [Level curve](level-curve.md)

A [contour plot](contour-plot.md) displays several [level curves](level-curve.md) of a real-valued [function](function-split.md) of two variables, usually with labels indicating their values. It represents a surface's height on a flat page. Closely spaced [level curves](level-curve.md) indicate a large change per unit distance only when the gaps between their labeled values are comparable.
