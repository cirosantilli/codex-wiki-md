# Disjoint-set find operation

↑ **Parent:** [Disjoint-set data structure](disjoint-set-data-structure.md)

The [disjoint-set find operation](disjoint-set-find-operation.md) returns the [disjoint-set representative](disjoint-set-representative.md) of a stored [set element](element-of-a-set.md) $x$. It preserves the [partition of a set](partition-of-a-set.md). With [path compression](path-compression.md), it can change internal pointers while answering the same membership question. Inputs outside the stored [set](set-split.md) require a specified error policy; they are not silently inserted here.
