# Static Lindhard dielectric function

↑ **Parent:** [Dielectric function](dielectric-function.md)

The static independent-electron density response of a uniform three-dimensional, two-spin [Fermi gas](fermi-gas.md), combined with self-consistent [Poisson equation](poisson-s-equation.md) screening, gives the displayed [dielectric function](dielectric-function.md). For bare electron mass and vacuum background, $\kappa^2=m_ee^2k_F/(\epsilon_0\pi^2\hbar^2)$ and

$$
F(x)=\frac12+\frac{1-x^2}{4x}\ln\left|\frac{1+x}{1-x}\right|.
$$

Here $F(0)=1$, $F(1)=1/2$ by continuous extension, and $F(x)\sim1/(3x^2)$ at large $x$. A host dielectric background and [band effective mass](band-effective-mass.md) require replacing the vacuum parameters appropriately. This nonlocal response contains [Friedel oscillations](friedel-oscillations.md), which its long-wavelength [Thomas-Fermi screening](thomas-fermi-screening.md) limit misses.
