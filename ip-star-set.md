# IP-star set

↑ **Parent:** [IP set](ip-set.md)

An IP-star set meets every [IP set](ip-set.md). Equivalently, its complement is not an [IP set](ip-set.md): a disjoint IP set is precisely an IP subset of the complement. This is a condition on all infinite [finite-sums sets](finite-sums-set.md), not merely on a single generating sequence.
