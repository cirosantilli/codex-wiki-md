# Conforming finite element space

↑ **Parent:** [Finite element method](finite-element-method.md)

A conforming finite element space is a finite-dimensional [vector subspace](vector-subspace.md) of the solution's variational space $V$. For a second-order problem with homogeneous [Dirichlet boundary conditions](dirichlet-boundary-condition.md), continuous piecewise-polynomial functions vanishing on the boundary form such a subspace of the [zero-boundary Sobolev space](zero-boundary-sobolev-space.md) $H_0^1(\Omega)$. Conformity allows exact [Galerkin orthogonality](galerkin-orthogonality.md) and the [Céa lemma](cea-s-lemma.md).
