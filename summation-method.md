# Summation method

↑ **Parent:** [Series (mathematics)](series-mathematics.md)

A rule for assigning a value to some [series](series-mathematics.md) through a specified limiting operation. It must say which [series](series-mathematics.md) belong to its domain; different rules can have different domains. A [regular summation method](regular-summation-method.md) agrees with ordinary [summation](summation.md) for every [convergent series](convergent-series.md).
