# Mass-equivalent cosmological critical density

↑ **Parent:** [Critical density](critical-density.md)

The mass-density convention for the cosmological [critical density](critical-density.md). If $u$ denotes [energy](energy-split.md) per unit volume, $\rho=u/c^2$ and $u_{\rm crit}=3c^2H^2/(8\pi G)$. Both conventions give the same dimensionless density parameter when numerator and denominator use consistent units. This distinction avoids inserting an extra $c^2$ into a [Friedmann equation](friedmann-equations.md) written in terms of mass-equivalent density.
