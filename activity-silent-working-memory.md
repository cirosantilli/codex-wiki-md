# Activity-silent working memory

↑ **Parent:** [Working memory](working-memory.md)

Retention through task-dependent network states without an uninterrupted, readily measurable content-specific activity pattern. Candidate mechanisms include temporary changes in synaptic efficacy. An absent decoding result is insufficient to establish silence, and perturbation-induced reactivation does not uniquely identify the underlying mechanism.
