# Orientable genus

↑ **Parent:** [Classification theorem for surfaces](classification-theorem-for-surfaces.md)

For a closed connected [orientable surface](orientable-surface.md), its orientable genus is the number of [torus](torus.md) summands in its [connected sum](connected-sum-of-oriented-manifolds.md) classification, with the [two-sphere](two-sphere.md) assigned genus zero. The [Euler characteristic](euler-characteristic.md) is $2-2g$, so it determines this number within the orientable family.
