# Propositional theory

↑ **Parent:** [Propositional logic](propositional-logic.md)

A [propositional theory](propositional-theory.md) is a set of [propositional formulas](propositional-formula.md), sometimes identified with its deductive closure. It is a [consistent set of formulae](consistent-set-of-formulae.md) when contradiction is not derivable from it. The [completeness theorem for propositional logic](completeness-theorem-for-propositional-logic.md) identifies consistency with existence of a satisfying [Boolean valuation](boolean-valuation.md).
