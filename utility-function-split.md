# Utility function

↑ **Parent:** [Mathematical finance](mathematical-finance-split.md)

In expected-utility portfolio choice, an increasing utility function prefers greater wealth, while concavity models aversion to risk.

A [utility function](utility-function-split.md) assigns numerical values to outcomes consistently with preference comparisons. It represents [utility](utility.md); the representation and the preference concept are distinct.
