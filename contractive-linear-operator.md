# Contractive linear operator

↑ **Parent:** [Continuous linear operator](continuous-linear-operator.md)

A bounded [linear operator](linear-operator.md) between normed spaces is contractive if its operator norm is at most one. This norm property is distinct from a strict [contraction mapping](contraction-mapping.md), whose Lipschitz constant must be less than one.
