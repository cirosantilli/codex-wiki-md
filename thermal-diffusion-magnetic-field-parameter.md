# Thermal-diffusion magnetic-field parameter

↑ **Parent:** [Chandrasekhar number](chandrasekhar-number.md)

With [thermal diffusivity](thermal-diffusivity.md) $\kappa$ and [magnetic diffusivity](magnetic-diffusivity.md) $\eta$, the standard [Chandrasekhar number](chandrasekhar-number.md) uses $\nu\eta$ in its denominator. A thermal-diffusion alternative uses $\nu\kappa$ and is $\zeta=\eta/\kappa$ times the standard parameter. In thermal-time [magnetoconvection](magnetoconvection.md) equations, the linear magnetic-force coefficient is $\sigma Q_\kappa=\sigma\zeta Q_{\mathrm{Ch}}$. Specifying the convention prevents a missing diffusivity factor in a dispersion relation.
