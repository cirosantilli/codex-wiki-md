# Alternating path in a matching

↑ **Parent:** [Matching (graph theory)](matching-graph-theory-split.md)

An [alternating path in a matching](alternating-path-in-a-matching.md) $M$ is a [graph path](path-in-a-graph.md) whose successive [edges](edge-of-a-graph.md) alternate between membership in $M$ and membership outside $M$. Here [graph paths](path-in-a-graph.md) have no repeated [vertices](vertex-graph-theory.md). Alternation alone does not make a [graph path](path-in-a-graph.md) an [augmenting path in a matching](augmenting-path-in-a-matching.md): its endpoints must both be [unmatched vertices in a matching](unmatched-vertex-in-a-matching.md). For example, relative to $M=\{(2,3),(4,5)\}$ in the six-[vertex](vertex-graph-theory.md) [path graph](path-graph.md), $2,3,4,5$ alternates but has matched endpoints; toggling just those three [edges](edge-of-a-graph.md) loses one selected [edge](edge-of-a-graph.md).
