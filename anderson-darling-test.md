<h1 id="anderson-darling-test">Anderson–Darling test</h1>

↑ **Parent:** [Empirical distribution function](empirical-distribution-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Anderson–Darling_test)

The test rejects for large values of this tail-weighted empirical discrepancy. For a specified continuous null, its standard limiting statistic is $\int_0^1B^0(u)^2/[u(1-u)]du$, using a [Brownian bridge](brownian-bridge.md). The reciprocal [variance](variance-split.md) weight gives tail deviations more influence than the [Cramér–von Mises criterion](cramer-von-mises-criterion.md). If null parameters are estimated, fitting must be included when computing or simulating its reference law.
