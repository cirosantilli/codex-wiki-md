# Conditional error principle

↑ **Parent:** [Group sequential design](group-sequential-design.md)

The conditional error principle permits adaptation of a testing design if, conditional on the observed interim information, the modified future rule's [Type I error](type-i-and-type-ii-errors.md) does not exceed the original rule's conditional future rejection probability. Averaging then preserves the original unconditional error bound. For a completed single-look test that has not rejected, there is no future conditional error budget under that original design.
