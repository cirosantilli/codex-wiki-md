# Jones unknot detection problem

↑ **Parent:** [Jones polynomial](jones-polynomial.md)

This asks whether the [Jones polynomial](jones-polynomial.md) equal to one characterizes the [unknot](unknot.md) among [knots](knot.md). A zero [breadth of a Laurent polynomial](breadth-of-a-laurent-polynomial.md) makes $V_K$ a [monomial](monomial.md); the identities $V_K(1)=1$ and $V'_K(1)=0$ then force that monomial to be one. Thus using Jones breadth as a strictly positive complexity for nontrivial [knots](knot.md) requires this detection property. To prove the [derivative](derivative.md) identity, differentiate the [Jones polynomial skein relation](jones-polynomial-skein-relation.md) at one for a crossing change in a [knot](knot.md). Both crossed diagrams have value one, while the smoothed two-component [link](link.md) has value minus two by [Jones polynomial evaluation at one](jones-polynomial-evaluation-at-one.md), so $V'_{K_+}(1)=V'_{K_-}(1)$. Crossing changes reduce to the [unknot](unknot.md), whose [derivative](derivative.md) is zero. The corresponding [Alexander polynomial](alexander-polynomial.md) detection property is false, as nontrivial untwisted [Whitehead doubles](whitehead-double.md) demonstrate. The Jones question is discussed in [research on closed four-strand braids](https://arxiv.org/abs/2402.02553).
