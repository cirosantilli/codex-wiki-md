# Universal quantum gate set

↑ **Parent:** [Quantum circuit](quantum-circuit-split.md)

A universal quantum gate set can approximate every finite-qubit [unitary operator](unitary-operator.md) arbitrarily accurately using finite circuits over the set.

Universality is a property of a set of [quantum logic gates](quantum-logic-gate.md): finite circuits from the set approximate arbitrary unitary transformations.
