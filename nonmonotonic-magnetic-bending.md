# Nonmonotonic magnetic bending

↑ **Parent:** [Magnetic bending in an incompressible disk](magnetic-bending-in-an-incompressible-disk.md)

For nonzero imposed surface inclination, [magnetic bending in an incompressible disk](magnetic-bending-in-an-incompressible-disk.md) is nonmonotonic when $KH>\pi/2$: the first maximum of $|B_x|$ occurs at $z=\pi/(2K)<H$, followed by a decrease. This is exactly the [finite-thickness magnetorotational instability criterion](finite-thickness-magnetorotational-instability-criterion.md) for the same slab. The zero-inclination equilibrium can still be unstable, so nonmonotonic bending is a property of the forced profile, rather than a condition on every possible unstable equilibrium.
