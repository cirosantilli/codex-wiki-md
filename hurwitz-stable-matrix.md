# Hurwitz stable matrix

↑ **Parent:** [Asymptotic stability](asymptotic-stability.md)

A Hurwitz stable matrix has all eigenvalues strictly in the open left half-plane. For $\dot x=Ax$, this is equivalent to $e^{At}x\to0$ for every initial vector. [Jordan blocks](jordan-block.md) contribute polynomial factors times $e^{\lambda t}$, which decay exactly when their eigenvalues have negative real part. Translating an affine equilibrium reduces its attractivity to this same condition.
