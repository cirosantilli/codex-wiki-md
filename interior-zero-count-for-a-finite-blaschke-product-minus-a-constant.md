# Interior zero count for a finite Blaschke product minus a constant

↑ **Parent:** [Blaschke product](blaschke-product.md)

A finite [Blaschke product](blaschke-product.md) is holomorphic across the unit circle and has modulus one there. For a constant $a$ with $|a|<1$, [Rouché's theorem](rouche-s-theorem.md) makes $B-a$ and $B$ have the same number of interior zeros, counting [multiplicity](multiplicity-mathematics.md). Each factor contributes its prescribed zero; the poles are outside the closed disk.
