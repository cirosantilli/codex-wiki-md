# Kauffman state of a knot diagram

↑ **Parent:** [Alexander matrix](alexander-matrix.md)

For a reduced knot diagram with two adjacent starred regions, a Kauffman state chooses one corner at every crossing so that every unstarred region contains exactly one chosen corner. Terms in a determinant expansion of a Dehn-presentation [Alexander matrix](alexander-matrix.md) correspond bijectively to these states.
