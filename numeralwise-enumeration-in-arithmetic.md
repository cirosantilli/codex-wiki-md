# Numeralwise enumeration in arithmetic

↑ **Parent:** [Arithmetical provability predicate](arithmetical-provability-predicate.md)

A two-variable formula enumerates a [set](set-split.md) $A$ in a [theory](first-order-theory.md) $S$ when membership supplies a standard [numeral](numeral.md) stage whose instance is provable, while nonmembership makes every standard-stage instance refutable. The notion contains these proof obligations, not merely a syntactic complexity restriction on the formula. With [bounded completeness](bounded-completeness-of-an-arithmetic-theory.md), a bounded formula whose existential closure defines a [computably enumerable set](recursively-enumerable-set.md) provides such an enumerator.[Incompleteness Theorems, section3, definition of enumeration in a proof system](https://people.cs.uchicago.edu/~razborov/teaching/files/godel.pdf)
