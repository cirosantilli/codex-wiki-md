# Diameter bound for a fixed-density binomial random graph

↑ **Parent:** [Missing common-neighbour count in a binomial random graph](missing-common-neighbour-count-in-a-binomial-random-graph.md)

For fixed $0<p<1$, the [missing common-neighbour count in a binomial random graph](missing-common-neighbour-count-in-a-binomial-random-graph.md) has [expectation](expected-value.md) tending to zero. The [Markov inequality](markov-inequality.md) therefore shows that every pair has a [common neighbour](common-neighbour.md) with probability tending to one. On that event every [graph distance](distance-graph-theory.md) is at most two, so the [graph](graph-split.md) is [connected](connected-space.md) and its [graph diameter](graph-diameter.md) is at most two.
