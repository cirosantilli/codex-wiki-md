# Hindley-Milner type system

↑ **Parent:** [Type system](type-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hindley–Milner_type_system)

The pure [Hindley-Milner type system](hindley-milner-type-system.md) combines [function types](function-type.md), [type inference](type-inference.md) and [let polymorphism](let-polymorphism.md). It solves constraints by [type unification](type-unification.md) and generalizes eligible [type variables](type-variable.md) at `let` bindings. Robin Milner's 1978 paper presents [Algorithm W](algorithm-w.md) and proves its soundness for the paper's language; it also acknowledges Roger Hindley's earlier work on finding general types. [Milner, A Theory of Type Polymorphism in Programming (1978), introduction and sections 3.5, 4.1–4.2](https://www.pure.ed.ac.uk/ws/files/15143545/1_s2.0_0022000078900144_main.pdf)
