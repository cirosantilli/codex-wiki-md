# Cut types over the named rational order

↑ **Parent:** [Type space](type-space.md)

For each irrational real cut $r$, the displayed comparisons with named rationals are finitely satisfiable. [Quantifier elimination](quantifier-elimination.md) for dense linear orders makes them determine a [complete type](complete-type.md), omitted by the named rational structure itself. Different cuts give different types, so there are continuum many. An [omega-saturated model](omega-saturated-model.md) must realize all of them and cannot be [countable](countable-set.md), although the named rational structure is [countable](countable-set.md), atomic and prime.
