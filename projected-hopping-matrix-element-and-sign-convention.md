# Projected hopping matrix element and sign convention

↑ **Parent:** [Hopping integral](hopping-integral.md)

If a tight-binding [Hamiltonian](hamiltonian.md) is written with coefficient $-t_{ij}$ multiplying $c_i^\dagger c_j$, projecting the one-electron [Hamiltonian](hamiltonian.md) gives the displayed relation. An alternative convention defines the coefficient itself as the [hopping integral](hopping-integral.md) and has no leading minus. [Orthogonality](orthogonal-vectors.md) removes constant scalar potentials from off-diagonal matrix elements, but does not remove a spatially varying potential. Orbital rephasing changes both matrix elements together and cannot repair an algebraic mismatch between these two conventions in a fixed basis.
