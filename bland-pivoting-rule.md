# Bland pivoting rule

↑ **Parent:** [Simplex method](simplex-method.md)

For a maximization [simplex dictionary](simplex-dictionary.md), choose the smallest-index nonbasic variable with positive reduced cost to enter. Among basic variables attaining the minimum feasible ratio, choose the smallest-index one to leave. This fixed index rule prevents cycling, including in degenerate pivots whose step length is zero. It need not minimize the number of pivots on a particular instance.
