# Valence-only proton and neutron structure-function moments

↑ **Parent:** [Quark number sum rule](quark-number-sum-rule.md)

With only up/down valence quarks and no antiquarks, the [quark number sum rule](quark-number-sum-rule.md) and leading [parton model](parton-model.md) expression give the charge-squared number moment $\int F_2(x)dx/x=\sum_fQ_f^2N_f$. The squared charges are $4/9$ for up and $1/9$ for down, so the [proton](proton.md) has $8/9+1/9=1$ and the [neutron](neutron.md) has $4/9+2/9=2/3$. Restricting the flavour list to up/down does not itself remove antiquarks; the no-sea assumption is essential for these individual moments.
