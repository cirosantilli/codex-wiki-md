# Clathrin

↑ **Parent:** [Protein](protein-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Clathrin)

[Clathrin](clathrin.md) assembles a scaffold around selected membrane buds. Cargo recognition generally depends on associated adaptors, so the scaffold alone neither selects every cargo nor specifies every destination.
