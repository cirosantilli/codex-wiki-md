# Message-passing channel

↑ **Parent:** [Message passing](message-passing.md)

A communication object with an output port used to send values and an input port used to receive them. Its contract specifies ordering, capacity, sharing and closure. In [synchronous message passing](synchronous-message-passing.md), a send completes through a matching receive; a buffered [message-passing channel](message-passing-channel.md) can retain accepted values until a receiver is ready.
