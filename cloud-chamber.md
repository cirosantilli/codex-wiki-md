# Cloud chamber

↑ **Parent:** [Particle detector](particle-detector.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cloud_chamber)

A [cloud chamber](cloud-chamber.md) contains [supersaturated vapor](supersaturated-vapor.md). [Ionization](ionization.md) along a [charged particle](charged-particle.md)'s path supplies sites for [nucleation](nucleation.md); the resulting [liquid](liquid.md) drops scatter [light](light.md) and reveal the trail. The observed objects are drops, not magnified [particles](particle-physics.md). Its beauty is that a spatially distributed microscopic interaction becomes a visible geometrical record.

Two ways of making [supersaturated vapor](supersaturated-vapor.md) must be distinguished. An [expansion cloud chamber](expansion-cloud-chamber.md) rapidly increases the [volume](volume-thermodynamics.md) of moist [gas](gas.md), producing a temporary sensitive interval through cooling by [adiabatic expansion](adiabatic-expansion.md). A [diffusion cloud chamber](diffusion-cloud-chamber.md) maintains a cold base and a warmer [vapor](vapor.md) supply, producing a continuously replenished sensitive layer through [diffusion](diffusion.md) and a [temperature gradient](temperature-gradient.md).
