# Torsion-freeness from one nonidentity conjugacy class

↑ **Parent:** [Conjugacy class](conjugacy-class.md)

If an infinite [group](group-split.md) has a single nonidentity [conjugacy class](conjugacy-class.md), it is a [torsion-free group](torsion-free-group.md). Otherwise every nonidentity element has the same finite order $n$. Powers show $n$ is prime. For $n\geq3$, choose $xgx^{-1}=g^2$; then $x^n=1$ gives $g=g^{2^n}$, impossible by [Fermat's little theorem](fermat-little-theorem.md). For $n=2$, the group has exponent two and is abelian, so every conjugacy class is a singleton and the hypothesis would force the group to have only two elements. Infinitude excludes this final case.
