# Chapman cycle

↑ **Parent:** [Odd oxygen](odd-oxygen.md)

A basic oxygen–ozone mechanism combining oxygen photodissociation, three-body ozone formation, ozone photodissociation and $\mathrm O+\mathrm O_3\to2\mathrm O_2$. The last reaction removes two units of [odd oxygen](odd-oxygen.md); a catalytic cycle can add another loss pathway.
