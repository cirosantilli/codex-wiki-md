# Local factor of an Artin L-function

↑ **Parent:** [Artin L-function](artin-l-function.md)

Only the [inertia group](inertia-group.md) invariants enter an [Artin L-function](artin-l-function.md) local factor. A [Frobenius automorphism](frobenius-automorphism.md) lift acts unambiguously on this subspace, since other lifts differ by inertia. For an unramified one-dimensional [group representation](group-representation.md), the factor is $(1-\chi(\operatorname{Frob}_{\mathfrak p})(N\mathfrak p)^{-s})^{-1}$; for a ramified one-dimensional [group representation](group-representation.md), the invariant subspace is zero and the factor is one. This explains the zero values used at conductor primes by quadratic [Dirichlet characters](dirichlet-character.md).
