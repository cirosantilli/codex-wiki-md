# Phase convention for complex amplitudes

↑ **Parent:** [Complex amplitude](complex-amplitude.md)

Reference [wave phases](phase-waves.md) label [complex amplitudes](complex-amplitude.md) without changing measured [powers](power.md). If $\mathbf b=S\mathbf a$, choose [diagonal matrices](diagonal-matrix.md) $D_{\rm in},D_{\rm out}$ whose entries have [modulus](modulus.md) one, and set $\mathbf a^{\prime}=D_{\rm in}\mathbf a$, $\mathbf b^{\prime}=D_{\rm out}\mathbf b$. Then $S^{\prime}=D_{\rm out}SD_{\rm in}^{-1}$ and each component has unchanged squared [modulus](modulus.md). For a [beam splitter scattering matrix](beam-splitter-scattering-matrix.md), transforming $S$ without transforming input [complex amplitudes](complex-amplitude.md) changes the stated physical input.
