# Contango

↑ **Parent:** [Futures pricing](futures-pricing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Contango)

A [futures contract](futures-contract.md) delivery quote above the current spot price for the maturity considered; a rising quoted curve across maturities is also described as contango. This compares delivery prices rather than the current zero value of a newly settled contract.
