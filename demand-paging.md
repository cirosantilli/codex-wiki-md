# Demand paging

↑ **Parent:** [Paging](paging.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Demand_paging)

Making a [memory page](memory-page.md) resident when it is first accessed, using a [page fault](page-fault.md) to request the work. It can involve loading stored contents or allocating newly initialized contents.
