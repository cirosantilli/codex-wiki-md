# Event horizon inside an Oppenheimer-Snyder cloud

↑ **Parent:** [Oppenheimer-Snyder model](oppenheimer-snyder-model.md)

Radial outgoing [null geodesics](null-geodesic.md) in the interior of [Oppenheimer-Snyder collapse](oppenheimer-snyder-model.md) obey $d\chi/d\eta=1$. Trace the ray crossing the boundary at $(\eta_H,\chi_0)$ backward: it starts at the centre at $\eta=\eta_H-\chi_0$. This ray is the [event horizon](event-horizon.md); it can exist inside the cloud before the surface crosses $R=2M$. An [event horizon](event-horizon.md) is determined by global escape to [future null infinity](future-null-infinity.md), rather than by a local stopwatch signal.
