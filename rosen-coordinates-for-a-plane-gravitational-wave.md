# Rosen coordinates for a plane gravitational wave

↑ **Parent:** [Plane-fronted gravitational wave](plane-fronted-gravitational-wave.md)

Rosen coordinates put a plane wave into the transverse-metric form

$$
ds^2=-du\,dv+g_{AB}(u)dx^A dx^B.
$$

For diagonal $g_{AB}=\operatorname{diag}(f^2,g^2)$, the only potentially nonzero [Ricci tensor](ricci-tensor.md) component is $R_{uu}=-f''/f-g''/g$.
