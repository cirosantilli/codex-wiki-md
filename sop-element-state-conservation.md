# SOP element-state conservation

↑ **Parent:** [SOP model](sop-model.md)

Represent a three-state [probability distribution](probability-distribution-split.md) by occupancy fractions $\boldsymbol p=(p_I,p_1,p_2)$ in $I,A_1,A_2$. A nonnegative transfer $f_{ij}\leq p_i$ subtracts the same amount from donor $i$ that it adds to recipient $j$. The total therefore remains $p_I+p_1+p_2=1$. If all simultaneous outflows from a state sum to at most its old occupancy, each occupancy remains nonnegative. This elementary conservation argument makes a proposed numerical realization checkable; it does not identify the states with biological compartments.
