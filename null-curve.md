# Null curve

↑ **Parent:** [Minkowski metric](minkowski-metric.md)

A null curve has tangent $u$ satisfying $g(u,u)=0$. It represents the possible spacetime path of a light signal.

Its nonzero tangent is a [null vector](null-vector.md) at every regular point; this distinguishes the curve from a single null direction.
