# Duty cycle

↑ **Parent:** [Electrical circuit](electrical-circuit-split.md)

The fraction of an operating cycle spent in a specified active state. For two constant-current states, average current is $\bar I=DI_a+(1-D)I_s$; wake-up transients require an additional [energy](energy-split.md) term.
