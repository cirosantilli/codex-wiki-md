# Finite directed set has a greatest element

↑ **Parent:** [Directed set](directed-set.md)

In a finite nonempty [directed set](directed-set.md), repeatedly take an internal common [upper bound](upper-bound-in-a-partially-ordered-set.md) of the element reached so far and the next element. The final member is above every element of the [directed set](directed-set.md) and is therefore its [greatest element](greatest-element.md) and [least upper bound](least-upper-bound-in-a-partially-ordered-set.md).
