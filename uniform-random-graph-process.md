# Uniform random graph process

↑ **Parent:** [Erdős-Rényi model](erdos-renyi-model.md)

Start with the empty [graph](graph-split.md) and reveal the [edges](edge-of-a-graph.md) of the [complete graph](complete-graph.md) in a uniformly random order. After $m$ steps its edge set is a uniform $m$-element subset. Independent uniform edge labels couple this process with all [binomial random graphs](binomial-random-graph.md): $G(n,p)=G_{n,M(p)}$, where $M(p)$ has a [binomial distribution](binomial-distribution.md) with parameters $\binom n2,p$. For a [monotone graph property](monotone-graph-property.md), concentration of $M(p)$ transfers a threshold estimate between edge probability and edge count.
