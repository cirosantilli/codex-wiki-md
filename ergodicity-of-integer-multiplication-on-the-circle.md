# Ergodicity of integer multiplication on the circle

↑ **Parent:** [Integer multiplication map on the circle](integer-multiplication-map-on-the-circle.md)

The [integer multiplication map on the circle](integer-multiplication-map-on-the-circle.md) is an [ergodic transformation](ergodicity.md) for [Lebesgue measure](lebesgue-measure.md). In the [Fourier basis](fourier-basis.md), an invariant function has coefficients $c_j=0$ when $K$ does not divide $j$, and $c_j=c_{j/K}$ otherwise. Every nonzero index eventually reduces to the first case, so only the constant coefficient remains.
