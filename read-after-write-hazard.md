# Read-after-write hazard

↑ **Parent:** [Data hazard](data-hazard.md)

A younger instruction needs a value produced by an older instruction before the ordinary writeback/read path would deliver it. [Register forwarding](register-forwarding.md) or a [pipeline stall](pipeline-stall.md) can enforce the true dependence.
