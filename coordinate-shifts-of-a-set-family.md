# Coordinate shifts of a set family

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)

For distinct coordinates $i,j$, replace a member containing $j$ but not $i$ by its partner with $j$ exchanged for $i$, provided that partner is absent. This [set family](set-family.md) operation preserves [cardinality](cardinality.md). Repeating shifts with $i<j$ terminates because every change decreases $\sum_{A\in\mathcal F}\sum_{a\in A}a$. Its effect on shadows is described by [coordinate-shift shadow containment](coordinate-shift-shadow-containment.md).
