# Euclidean Ramsey set

↑ **Parent:** [Ramsey theory](ramsey-theory-split.md)

A finite set $X\subseteq\mathbb R^d$ is Euclidean Ramsey when, for every number of colors, some finite-dimensional [Euclidean space](euclidean-norm.md) has the property that every coloring of it contains a monochromatic [isometric copy](isometry.md) of $X$.
