# Distinct witnesses from incompatible unary predicates

↑ **Parent:** [Unary predicate type](unary-predicate-type.md)

The displayed [first-order sentence](first-order-sentence.md) requires a domain with at least $2^k$ elements without using [logical equality](logical-equality.md). Distinct patterns disagree on some predicate, so a single element cannot witness both. Conversely, a domain consisting of the $2^k$ [binary strings](binary-string.md) of length $k$, with $P_i$ selecting strings whose $i$th [bit](bit.md) is one, realizes every pattern. More generally, requiring any $m$ distinct [unary predicate types](unary-predicate-type.md) forces at least $m$ distinct elements.
