# DONUT

↑ **Parent:** [Tau neutrino](tau-neutrino.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/DONUT)

A Fermilab experiment that directly observed [tau neutrino](tau-neutrino.md) [charged current](charged-current.md) interactions using nuclear emulsion and a prompt [neutrino beam](neutrino-beam.md) from an $800\,\mathrm{GeV}$ [proton](proton.md) dump. [Ds meson](ds-meson.md) decays and the subsequent [tau lepton](tau-particle.md) decays supply the main tau-flavour component.
