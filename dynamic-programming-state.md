# Dynamic programming state

↑ **Parent:** [Dynamic programming](dynamic-programming.md)

A [dynamic programming state](dynamic-programming-state.md) is an element of a [state space](state-space.md) that summarizes all information needed for a remaining [mathematical optimization](mathematical-optimization-split.md) problem. Histories can share a [value function](value-function.md) entry only when their allowed continuations and future rewards agree, or have the same conditional laws in a [stochastic control](stochastic-control.md) problem. Time or the remaining item index may be part of the summary. If past decisions still affect feasibility or rewards, enlarge the [dynamic programming state](dynamic-programming-state.md); forgetting those effects invalidates the [Bellman equation](bellman-equation.md).
