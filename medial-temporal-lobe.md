# Medial temporal lobe

↑ **Parent:** [Brain](brain.md)

A set of anatomically related structures including the [hippocampus](hippocampus.md), [entorhinal cortex](entorhinal-cortex.md) and [perirhinal cortex](perirhinal-cortex.md). Membership in the same anatomical region does not imply identical cognitive function.
