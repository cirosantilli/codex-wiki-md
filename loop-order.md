# Loop order

↑ **Parent:** [Feynman diagram](feynman-diagram.md)

The loop order of a connected [Feynman diagram](feynman-diagram.md) is the number $L=I-V+1$ of independent momentum cycles, where $I$ is the number of internal lines and $V$ the number of vertices. Each loop introduces an unconstrained momentum integral.
