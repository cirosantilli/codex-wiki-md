# Sensory recruitment

↑ **Parent:** [Working memory](working-memory.md)

The hypothesis that sensory systems contribute representations used during retention, reusing feature-sensitive processing rather than requiring all memory content to reside in a separate abstract store. A decodable sensory pattern supports this idea without uniquely locating its maintenance mechanism.
