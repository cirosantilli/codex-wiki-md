# Unipotent algebraic group

↑ **Parent:** [Unipotent](unipotent.md)

A [unipotent algebraic group](unipotent-algebraic-group.md) is built from [unipotent](unipotent.md) elements. A unipotent algebraic group is an affine algebraic group all of whose elements are unipotent. The [Kolchin theorem](kolchin-theorem.md) embeds it into an upper unitriangular group.
