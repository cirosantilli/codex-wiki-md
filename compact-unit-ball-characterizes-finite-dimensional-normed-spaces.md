# Compact unit ball characterizes finite-dimensional normed spaces

↑ **Parent:** [Riesz's lemma](riesz-s-lemma.md)

A normed vector space has compact closed unit ball if and only if it is finite-dimensional. In an infinite-dimensional space, repeated application of [Riesz lemma](riesz-s-lemma.md) produces unit vectors separated pairwise by a fixed positive distance, contradicting sequential compactness.
