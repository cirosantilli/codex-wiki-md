# Transitive set

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Transitive_set)

A set $X$ is transitive when every element of an element of $X$ is itself an element of $X$.
