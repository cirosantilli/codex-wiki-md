# Unit-width box kernel

↑ **Parent:** [Uniform smoothing kernel](uniform-smoothing-kernel.md)

The unit-width centred box kernel is $K(u)=\mathbf1_{[-1/2,1/2]}(u)$. It has integral one and squared $L^2$ norm one. Its rescaling $K_h(u)=h^{-1}K(u/h)$ averages a function on intervals of length $h$. It is obtained from the [uniform smoothing kernel](uniform-smoothing-kernel.md) with support $[-1,1]$ by rescaling, and is useful in both [kernel density estimation](kernel-density-estimation.md) and [local polynomial regression](local-polynomial-regression.md).
