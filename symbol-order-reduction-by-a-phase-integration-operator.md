# Symbol order reduction by a phase integration operator

↑ **Parent:** [Oscillatory integral](oscillatory-integral.md)

For a homogeneous [phase function](phase-function.md), let $q=|\nabla_x\Phi|^2+|\theta|^2|\nabla_\theta\Phi|^2$ and $L=(iq)^{-1}(\nabla_x\Phi\cdot\nabla_x+|\theta|^2\nabla_\theta\Phi\cdot\nabla_\theta)$. Then $Le^{i\Phi}=e^{i\Phi}$. The [formal transpose of a differential operator](formal-transpose-of-a-differential-operator.md) $L^t$ lowers the [symbol class](symbol-class.md) order by one: the $x$ coefficients have order $-1$, while the order-zero frequency coefficients accompany a frequency derivative.
