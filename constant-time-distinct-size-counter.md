# Constant-time distinct-size counter

↑ **Parent:** [Array multiset](array-multiset.md)

Maintain a counter equal to the number of positive count-[array](array-data-structure.md) entries. Increment it only when an [addition](addition.md) changes zero to one; decrement it only when a removal changes one to zero. Other count changes leave the support unchanged. Initialization at zero and these cases prove the [representation invariant](representation-invariant.md) by [induction](mathematical-induction.md) over completed operations, giving a constant-time distinct-size query.
