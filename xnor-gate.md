# XNOR gate

↑ **Parent:** [Logic gate](logic-gate.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/XNOR_gate)

A two-input [logic gate](logic-gate.md) whose output is one exactly when its two input [bits](bit.md) agree. Its [Boolean function](boolean-function.md) is $(a\land b)\lor(\neg a\land\neg b)$, equivalently $(a\lor\neg b)\land(\neg a\lor b)$. This follows by considering the two cases in which inputs are equal. It implements [logical equivalence](logical-equivalence.md) of the input truth values.
