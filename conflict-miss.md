# Conflict miss

↑ **Parent:** [Cache miss](cache-miss.md)

A repeated [cache block](cache-line.md) access that misses in a restricted design but hits in the comparison [fully associative cache](fully-associative-cache.md) of the same capacity and [cache line](cache-line.md) size using [LRU replacement](lru-replacement.md). Read 4 of the [direct-mapped cache](direct-mapped-cache.md) comparison under [cache miss](cache-miss.md) isolates this effect while another [cache slot](cache-slot.md) is unused.
