# Nested partial unary operation category

↑ **Parent:** [Category](category-split.md)

An object of $\mathcal C_n$ is a set with a finite list of [partial unary operations](partial-unary-operation.md). The first is total; the domain of each later operation consists exactly of the defined [fixed points](fixed-point.md) of the immediately preceding operation. Morphisms preserve every defined operation. Take $\mathcal C_0$ to be the [Category of sets](category-of-sets.md). This tower gives examples of arbitrary finite [monadic length](monadic-length.md) even though its long free–forgetful composites induce the same first [monad](monad.md).
