# Enzyme conservation

↑ **Parent:** [Enzyme kinetics](enzyme-kinetics.md)

When each [chemical reaction](chemical-reaction-split.md) only changes the state of one [enzyme](enzyme-split.md) molecule, summing all enzyme-state [concentrations](concentration.md) gives a conserved total. For sequential complexes satisfying $\dot C_0=-R_1$, $\dot C_i=R_i-R_{i+1}$, $\dot C_n=R_n$, the sum telescopes to zero. Bound [substrate](substrate-biochemistry.md) must be included separately in [substrate](substrate-biochemistry.md) [mass conservation](mass-conservation.md).
