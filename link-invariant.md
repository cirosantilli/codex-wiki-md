# Link invariant

↑ **Parent:** [Link](link.md)

A [link](link.md) invariant assigns the same value to [links](link.md) related by [link isotopy](link-isotopy.md). The [Jones polynomial](jones-polynomial.md) applies to oriented [links](link.md), while its bracket precursor retains a framing dependence. An invariant need not distinguish all [link](link.md) types.
