# Quinone

↑ **Parent:** [Chemical compound](chemical-compound.md)

A [quinone](quinone.md) has an oxidized conjugated carbonyl system that can participate in redox chemistry. Some added quinones intercept electrons in photosynthetic preparations, potentially creating routes absent from unmodified cells.
