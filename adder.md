# Adder

↑ **Parent:** [Combinational logic](combinational-logic.md)

A [Boolean circuit](boolean-circuit.md) computing the [sum](sum.md) of [binary representations](binary-number.md), possibly including input and output [carry](carry-arithmetic.md) [bits](bit.md). Its delay depends on how carries are propagated; specifying an [adder](adder.md) does not by itself imply constant [circuit depth](depth-of-a-boolean-circuit.md) as the input width grows.
