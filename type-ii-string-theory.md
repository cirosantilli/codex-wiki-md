# Type II string theory

↑ **Parent:** [String theory](string-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Type_II_string_theory)

Type II superstring theory is a ten-dimensional closed oriented superstring theory with spacetime supersymmetry and no tachyon. Its massive closed-string levels have squared masses separated by $4/\alpha'$.
