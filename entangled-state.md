# Entangled state

↑ **Parent:** [Reduced density matrix](reduced-density-matrix.md)

A bipartite [density operator](density-matrix.md) is entangled when it is not a [separable quantum state](separable-quantum-state.md). For a pure state, this is equivalent to not being a [product state](product-state.md), or to either [reduced density matrix](reduced-density-matrix.md) having rank greater than one.
