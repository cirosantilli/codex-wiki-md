# Cache prefetching

↑ **Parent:** [Cache hierarchy](cache-hierarchy.md)

Fetching a [cache line](cache-line.md) before a demand access requires it, to overlap transfer [latency](latency-engineering.md) with useful work. A [software prefetch](software-prefetch.md) is one way to request this; unnecessary requests can cause [cache pollution](cache-pollution.md).
