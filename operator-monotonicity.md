# Operator monotonicity

↑ **Parent:** [Monotone operator](monotone-operator.md)

For a real [Banach space](banach-space-split.md) $X$, a map $A:X\to X^*$ has [operator monotonicity](operator-monotonicity.md) when $\langle A(u)-A(v),u-v\rangle\geq0$ for all $u,v\in X$. This is the [monotone operator](monotone-operator.md) property, with the pairing between $X$ and its [continuous dual space](continuous-dual-space-split.md) $X^*$. In a [Hilbert space](hilbert-space-split.md) one can identify that pairing with the [inner product](inner-product-split.md).
