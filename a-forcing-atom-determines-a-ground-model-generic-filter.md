# A forcing atom determines a ground-model generic filter

↑ **Parent:** [Forcing atom](forcing-atom.md)

For a [forcing atom](forcing-atom.md) $p$ in a ground-model [forcing](forcing-split.md) order, $G_p$ is a ground-model [generic filter](generic-filter.md). It contains $p$ and is upward closed. For $q,r\in G_p$, choose $q'\leq p,q$ and $r'\leq p,r$. The atom property gives $s\leq q',r'$, so $s\in G_p$ is a common strengthening of $q,r$. Thus $G_p$ is a [filter in an ordered set](filter-mathematics.md). Every [dense subset of a forcing order](dense-subset-of-a-forcing-order.md) has some $d\leq p$, and $d\in G_p$. The defining compatibility predicate is bounded to the ground-model [set](set-split.md) of conditions, so [axiom schema of separation](axiom-schema-of-specification.md) forms $G_p$ inside the ground model. For a nonminimal atom, this filter can strictly contain the [principal filter](principal-filter-in-an-ordered-set.md) above $p$.
