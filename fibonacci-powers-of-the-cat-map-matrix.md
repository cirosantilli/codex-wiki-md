# Fibonacci powers of the cat-map matrix

↑ **Parent:** [Cat map](cat-map.md)

With [Fibonacci](fibonacci-number.md) indexing $F_0=F_1=1$, powers of $A=\begin{pmatrix}2&1\\1&1\end{pmatrix}$ satisfy $A^n=\begin{pmatrix}F_{2n}&F_{2n-1}\\F_{2n-1}&F_{2n-2}\end{pmatrix}$ for $n\ge1$. The base case is immediate. Multiplication by $A$ advances each entry by the two-index [Fibonacci recurrence](fibonacci-number.md), proving the identity by induction.
