# Function oracle

↑ **Parent:** [Oracle machine](oracle-machine.md)

A [function oracle](function-oracle.md) supplies access to an unknown [function](function-split.md) $f$: given an allowed input $x$, one query returns $f(x)$. [Query complexity](query-complexity.md) counts these accesses separately from known local computation. A classical query receives one definite answer; a [quantum oracle](quantum-oracle.md) specifies coherent access through a [unitary operator](unitary-operator.md), allowing inputs in [quantum superposition](quantum-superposition.md). The distinction is part of the access model, not a change to the mathematical function.

A [Boolean quantum oracle](boolean-quantum-oracle.md) preserves $x$ and adds a one-[bit](bit.md) value $f(x)$ into an answer [qubit](qubit.md) by [exclusive or](exclusive-or.md). On known [computational-basis states](computational-basis-state.md), its output determines the same value as a classical [function oracle](function-oracle.md) query.
