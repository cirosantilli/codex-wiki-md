# Kronecker substitution

↑ **Parent:** [Polynomial multiplication](polynomial-multiplication.md)

Kronecker substitution encodes a [polynomial](polynomial-split.md) with bounded [nonnegative integer](natural-number.md) coefficients as one large [integer](integer-split.md) by evaluating it at a sufficiently large base. Integer multiplication then gives the polynomial product, provided the base exceeds every output coefficient so carries cannot mix coefficients.
