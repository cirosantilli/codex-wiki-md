# Semilinear Poisson contraction threshold

↑ **Parent:** [Contraction mapping theorem](contraction-mapping-theorem.md)

For a globally [Lipschitz](lipschitz-continuity.md) nonlinearity of constant $\epsilon$, the map taking $v$ to the [zero-Dirichlet](dirichlet-boundary-condition.md) Poisson solution with load $f(v)$ is a contraction in the [gradient norm](sobolev-norm.md) if the displayed inequality holds. [Poincaré](poincare-inequality.md) gives the factor $C_P$ from the Sobolev input to $L^2$, and testing the linear [Poisson equation](poisson-s-equation.md) gives another factor $C_P$ back to the [gradient norm](sobolev-norm.md). The condition yields a unique [weak solution](weak-solution.md) without requiring $f(0)=0$. With the optimal [Poincaré](poincare-inequality.md) constant it reads $\epsilon<\lambda_1$.
