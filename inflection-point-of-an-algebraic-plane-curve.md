# Inflection point of an algebraic plane curve

↑ **Parent:** [Intersection multiplicity](intersection-multiplicity.md)

A smooth point of an algebraic plane curve is a flex if its tangent line has [intersection multiplicity](intersection-multiplicity.md) at least three there. This definition also applies to smooth points of a singular curve.
