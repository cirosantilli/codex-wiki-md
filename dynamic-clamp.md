# Dynamic clamp

↑ **Parent:** [Computational neuroscience](computational-neuroscience.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dynamic_clamp)

A [dynamic clamp](dynamic-clamp.md) measures a real neuron's voltage, updates a conductance model in real time and injects the resulting current, for example $I=g(t)(E-V)$. It implements a virtual conductance without holding the voltage fixed. It can add artificial synapses, couple real neurons into a hybrid network or test how a voltage-dependent conductance affects excitability. Sampling delay and the injection site limit fidelity to spatially distributed biological channels.
