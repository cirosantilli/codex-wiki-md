# Exponent bound for a binomial power equation

↑ **Parent:** [Baker lower bound for a homogeneous linear form in logarithms](baker-lower-bound-for-a-homogeneous-linear-form-in-logarithms.md)

For fixed positive $a,b$ and fixed nonzero $c$, with $x\ne y$, put $Y=\max(x,y)$ and take $\Lambda=\log(a/b)+n\log(x/y)$, swapping the variables and coefficients if necessary. The equation gives $\log|\Lambda|\leq-n\log Y+O(1)$ when the larger-variable power is sufficiently large. A two-logarithm lower bound gives $\log|\Lambda|\geq-C(a,b)\log Y\log(2n)$. Hence $n\leq C\log(2n)+O(1)$, so $n$ is bounded. The cases $x=y$ and a bounded larger-variable power are elementary. For each remaining exponent, the [Thue theorem](thue-theorem.md) for a binomial form supplies finitely many pairs. The constant-power exception $x=y=1$, $a-b=c$, must be removed.
