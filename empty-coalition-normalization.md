# Empty-coalition normalization

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

The usual convention that the empty [coalition](coalition-game-theory.md) creates no value. It makes the sum of a [marginal contribution vector](marginal-contribution-vector.md) equal $v(N)$ by a [telescoping sum](telescoping-sum.md). Without it, that sum is $v(N)-v(\varnothing)$, so the vector need not satisfy efficiency in the [core of a cooperative game](core-game-theory.md). The constant function $v(T)=1$ is [supermodular](supermodular-set-function.md) but gives a zero marginal vector and fails efficiency for a nonempty player set.
