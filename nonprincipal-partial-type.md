# Nonprincipal partial type

↑ **Parent:** [Partial type](partial-type.md)

A [partial type](partial-type.md) is nonprincipal when it is not a [principal partial type](principal-partial-type.md). Equivalently, for every formula $\theta(\mathbf x)$ consistent with $T$, some $\psi\in p$ makes $\theta\land\neg\psi$ consistent with $T$. This is the exact extension property needed in the [Henkin construction](henkin-construction.md) proving the [omitting types theorem](omitting-types-theorem.md).
