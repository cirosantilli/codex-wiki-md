# Equatorial deformation radius

↑ **Parent:** [Deformation radius](deformation-radius.md)

For an equatorial [beta plane](beta-plane.md) and a [shallow water](shallow-water-approximation.md) wave speed $c$, the natural meridional trapping scale is $R_{\rm eq}=\sqrt{c/\beta}$. A decaying [equatorial Kelvin wave](equatorial-kelvin-wave.md) has $\eta\propto e^{-y^2/(2R_{\rm eq}^2)}$. An envelope written $e^{-y^2/L^2}$ instead uses $L=\sqrt2R_{\rm eq}$; stating the exponent convention prevents a factor-of-two error in the meridional [Cauchy momentum equation](cauchy-momentum-equation.md).
