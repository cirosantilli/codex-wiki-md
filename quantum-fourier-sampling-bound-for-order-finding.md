# Quantum Fourier sampling bound for order finding

↑ **Parent:** [Quantum order finding](quantum-order-finding.md)

In [quantum order finding](quantum-order-finding.md), a phase $s/r$ produces amplitude $Q^{-1}\sum_{x=0}^{Q-1}e^{2\pi ix(s/r-j/Q)}$ after an inverse [quantum Fourier transform](quantum-fourier-transform.md). Its nearest grid point has probability at least $4/\pi^2$, by bounding the sine ratio of this [finite geometric Fourier amplitude](finite-geometric-fourier-amplitude.md). The initial modular orbit state is an equal-weight superposition of the $r$ phase eigenstates, so the phase label is uniform.
