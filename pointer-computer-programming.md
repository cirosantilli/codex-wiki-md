# Pointer (computer programming)

↑ **Parent:** [Computer memory](computer-memory-split.md)

A [pointer](pointer-computer-programming.md) is a value designating a location in a program's memory model, or a special value such as a [null pointer](null-pointer.md) that designates no object. A node in a pointer-linked [binary tree](binary-tree.md) stores [pointers](pointer-computer-programming.md) to its two children. Representation, size, alignment and the validity of dereferencing depend on the [programming language](programming-language-split.md) and target; 32-bit [AAPCS32](aapcs32.md) data [pointers](pointer-computer-programming.md) occupy four bytes.
