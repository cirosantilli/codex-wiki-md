# Euler class of an oriented odd-rank vector bundle is two-torsion

↑ **Parent:** [Euler class of a vector bundle](euler-class-of-a-vector-bundle.md)

For an oriented vector bundle $E$ of odd rank, multiplication by $-1$ on each fiber identifies $E$ with the oppositely oriented bundle. Naturality and reversal of the [Thom class](thom-class.md) give

$$
e(E)=e(E^{\mathrm{op}})=-e(E),
$$

so $2e(E)=0$.
