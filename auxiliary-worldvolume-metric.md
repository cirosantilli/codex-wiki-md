# Auxiliary worldvolume metric

↑ **Parent:** [Worldvolume](worldvolume.md)

An auxiliary worldvolume metric is an independent metric introduced in a [brane](brane.md) action, distinct from the [induced worldvolume metric](induced-worldvolume-metric.md). Its algebraic equation can eliminate it. For the [Polyakov action](polyakov-action.md) of a string, it is determined only up to a [Weyl transformation](weyl-transformation.md).
