<h1 id="erdos-gallai-path-edge-bound">Erdős-Gallai path edge bound</h1>

↑ **Parent:** [Path in a graph](path-in-a-graph.md)

An $n$-vertex graph containing no path of length $t$ has at most $(t-1)n/2$ edges.

This path-length bound is a different result from the [Erdős-Gallai theorem](erdos-gallai-theorem.md) on degree sequences.
