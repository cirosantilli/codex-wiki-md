# Variational inequality

↑ **Parent:** [Mathematical optimization](mathematical-optimization-split.md)

For a feasible set $K$ and a vector field $F$, a [variational inequality](variational-inequality.md) asks for $x^*\in K$ satisfying the displayed inequality for every feasible $x$. If $K$ is convex and $F$ is the gradient of a differentiable [convex function](convex-function.md), it is the necessary and sufficient first-order condition for minimizing that function. It also describes [Wardrop equilibria](wardrop-equilibrium.md) when no scalar objective has the route-cost vector as its gradient.
