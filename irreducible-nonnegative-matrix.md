# Irreducible nonnegative matrix

↑ **Parent:** [Nonnegative matrix](nonnegative-matrix.md)

A square [nonnegative matrix](nonnegative-matrix.md) $A$ is irreducible if for each pair $(i,j)$ there is an integer $k\geq0$ with $(A^k)_{ij}>0$. This says that every index can reach every other through positive entries. The [Perron–Frobenius theorem](perron-frobenius-theorem.md) then gives a positive leading [eigenvector](eigenvector.md) and an algebraically [simple eigenvalue](simple-eigenvalue.md). Irreducibility alone permits other [eigenvalues](eigenvalue.md) of the same [modulus](modulus.md): the cyclic permutation [matrix](matrix.md) $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ has [eigenvalues](eigenvalue.md) $1,-1$.
