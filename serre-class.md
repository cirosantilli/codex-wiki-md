# Serre class

↑ **Parent:** [Abelian group](abelian-group.md)

A class of abelian groups closed under isomorphisms, subgroups, quotients and extensions. For the homotopical Serre-class theorems one also uses tensor/Tor closure and [homology](homology-split.md) closure for Eilenberg–MacLane spaces. A homomorphism is an isomorphism modulo the class when its kernel and cokernel lie in the class.
