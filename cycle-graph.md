# Cycle graph

↑ **Parent:** [Cycle in a graph](cycle-in-a-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cycle_graph)

The cycle graph $C_n$ has vertices $v_1,\ldots,v_n$ and edges $v_iv_{i+1}$, with indices read cyclically.
