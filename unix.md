# Unix

↑ **Parent:** [Operating system](operating-system-split.md)

An operating-system family with process, file and pipe abstractions. The traditional discretionary file-permission model separates owner, group and other users and read, write and execute rights. Individual Unix systems can add richer [access control lists](access-control-list.md) and other protection mechanisms.
