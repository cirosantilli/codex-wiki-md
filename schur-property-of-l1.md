# Schur property of l1

↑ **Parent:** [Gliding hump argument](gliding-hump-argument.md)

The [l-p sequence space](l-p-sequence-space.md) $\ell^1$ has the [Schur property](schur-property.md). If a weakly null sequence stayed bounded below in norm, coordinatewise convergence and summability would select disjoint blocks containing almost all of successive terms. A sequence in $\ell^\infty$ matching their signs on those blocks would pair uniformly positively with a subsequence, contradicting [weak convergence](weak-convergence.md) through the [duality of l1 and l infinity](duality-of-l1-and-l-infinity.md).
