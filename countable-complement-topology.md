# Countable complement topology

↑ **Parent:** [Topology](topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Countable_complement_topology)

The open sets are the empty set and subsets whose complement is countable. On an uncountable set, any two nonempty open sets intersect, so the space is not [Hausdorff](hausdorff-space.md). On a countable underlying set this topology is discrete. The [compact subsets of a cocountable space](compact-subsets-of-a-cocountable-space.md) are finite, regardless of the cardinality of the underlying set.
