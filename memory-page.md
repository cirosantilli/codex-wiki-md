# Memory page

↑ **Parent:** [Paging](paging.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Page_(computer_memory))

A contiguous unit of an [address space](address-space.md) used for [paging](paging.md). In the example, virtual page `0x12` consists of [virtual addresses](virtual-address.md) `0x1200` through `0x12ff`.
