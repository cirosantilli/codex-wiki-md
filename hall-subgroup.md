# Hall subgroup

↑ **Parent:** [Subgroup](subgroup.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hall_subgroup)

A Hall subgroup has order coprime to its index. For a set of primes $\pi$, a Hall $\pi$-subgroup has order using only primes of $\pi$ and index using only primes outside $\pi$. Thus its order contains the full prime-power contributions belonging to $\pi$. A [Sylow subgroup](sylow-subgroup.md) is the single-prime instance. [Hall subgroup existence in soluble groups](hall-subgroup-existence-in-soluble-groups.md) generalizes Sylow existence to every prime set.
