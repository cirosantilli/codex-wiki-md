# Edge loop

↑ **Parent:** [Edge path](edge-path.md)

An [edge loop](edge-loop.md) in a [simplicial complex](simplicial-complex.md) is an [edge path](edge-path.md) whose first and last vertices are the same chosen base vertex. Consecutive repeated vertices are allowed as stationary steps. Its [geometric realization](geometric-realization-of-a-simplicial-complex.md) is a piecewise linear based loop in the realization of the complex.
