<h1 id="pretentious-distance-between-one-and-the-mobius-function">Pretentious distance between one and the Möbius function</h1>

↑ **Parent:** [Pretentious distance](pretentious-distance.md)

Because $\mu(p)=-1$, the squared [pretentious distance](pretentious-distance.md) from one to the [Möbius function](mobius-function.md) is twice the reciprocal-prime sum. The [Mertens second theorem](mertens-second-theorem.md) therefore gives $D(1,\mu;X)^2=2\log\log X+2B_1+o(1)$. In particular the distance diverges, illustrating that a multiplicative function can be far from the constant function even though both have unit-modulus [prime](prime-number.md) values.
