# One-consistency

↑ **Parent:** [Soundness of an arithmetic theory](soundness-of-an-arithmetic-theory.md)

An [arithmetic](arithmetic-split.md) theory is one-consistent if it does not prove $\exists x\,\delta(x)$ while proving every $\neg\delta(\overline n)$, for a [bounded arithmetic formula](arithmetic-bounded-formula.md) $\delta$ and all standard [natural numbers](natural-number.md) $n$. If the theory proves all true bounded sentences, this is equivalent to [Sigma-1 soundness](sigma-1-soundness.md): a false existential theorem has every standard instance refuted by bounded completeness; conversely a true witness and its provable [negation](negation.md) contradict the assumption of a [consistent first-order theory](consistent-first-order-theory.md).
