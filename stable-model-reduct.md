# Stable model reduct

↑ **Parent:** [Stable model semantics](stable-model-semantics.md)

Ground the rules, delete every rule having a negative body atom true in the candidate $I$, and remove all remaining negative premises. The result is a positive program whose [least Herbrand model](least-herbrand-model.md) is compared with $I$.
