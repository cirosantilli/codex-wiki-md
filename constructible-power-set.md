# Constructible power set

↑ **Parent:** [Constructible universe](constructible-universe.md)

For $A\in L$, its constructible power set is

$$
\mathcal P^L(A)=\{X\in L:X\subseteq A\}=\mathcal P(A)\cap L.
$$

Unlike the single-stage [definable power set](definable-power-set-split.md) $\mathcal D(A)$, it includes subsets of $A$ appearing arbitrarily late in the [constructible hierarchy](constructible-hierarchy.md).
