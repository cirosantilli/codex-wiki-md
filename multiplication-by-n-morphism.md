# Multiplication-by-n morphism

↑ **Parent:** [Group scheme](group-scheme.md)

For a commutative [group scheme](group-scheme.md) $G$, the multiplication-by-$n$ morphism $[n]_G:G\to G$ adds a point to itself $n$ times. On an [abelian variety](abelian-variety-split.md), it is surjective for every nonzero integer $n$.
