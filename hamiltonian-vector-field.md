# Hamiltonian vector field

↑ **Parent:** [Symplectic manifold](symplectic-manifold.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Hamiltonian_vector_field)

For a smooth function $H_t:M\to\mathbb R$, the Hamiltonian vector field is defined by $\iota_{X_{H_t}}\omega=-dH_t$, with the sign depending on convention.
