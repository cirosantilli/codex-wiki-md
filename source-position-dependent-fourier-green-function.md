# Source-position-dependent Fourier Green function

↑ **Parent:** [Green's function](green-s-function-split.md)

A static but spatially inhomogeneous linear operator has time [translation](translation-geometry.md) [symmetry](symmetry-physics.md) without spatial [translation](translation-geometry.md) [symmetry](symmetry-physics.md). At fixed [source](source-quantum-field-theory.md) position $\mathbf r'$, one may still [Fourier transform](fourier-transform-split.md) its [Green function](green-s-function-split.md) in $\mathbf x=\mathbf r-\mathbf r'$. The coefficient retains $\mathbf r'$ as a parameter. A multiplication by $V(\mathbf r)$ becomes a [convolution](convolution.md) with $V_{\mathbf r'}(\mathbf q)=e^{i\mathbf q\cdot\mathbf r'}\widetilde V(\mathbf q)$, not a spatially diagonal multiplier unless $V$ is constant. Suppressing the source-position subscript is only a notational convention.
