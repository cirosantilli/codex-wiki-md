# ABCD optical path generating function

↑ **Parent:** [Ray transfer matrix analysis](ray-transfer-matrix-analysis.md)

For forward paraxial slopes and a lossless same-index optical system with $AD-BC=1$ and $B\ne0$, [Fermat's principle](fermat-principle.md) gives endpoint derivatives $\partial_xl=-\theta$ and $\partial_{x'}l=\theta'$. Substituting $\theta=(x'-Ax)/B$ and $\theta'=(Dx'-x)/B$ and integrating proves the displayed optical path. Free space has $B=L>0$ and increases path length by $(x'-x)^2/(2L)$, fixing the sign. Its quadratic [phase](phase-waves.md) generates the associated [linear canonical transform](linear-canonical-transformation.md); $B=0$ is a separate imaging limit.
