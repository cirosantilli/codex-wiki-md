# Wave period

↑ **Parent:** [Wave](wave.md)

A wave period is the time for a monochromatic [wave](wave.md) to complete one oscillation. For angular [frequency](frequency.md) $\omega$, it is $2\pi/|\omega|$. In cascade order-of-magnitude estimates the factor $2\pi$ is normally suppressed, giving a linear interaction time of order $|\omega|^{-1}$.
