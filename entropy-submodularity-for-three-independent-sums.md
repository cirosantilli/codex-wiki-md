# Entropy submodularity for three independent sums

↑ **Parent:** [Information theory](information-theory-split.md)

For independent finitely supported random variables $X,Y,Z$ in a [finite additive group](finite-additive-group.md),

$$
H(X+Y+Z)+H(Y)\leq H(X+Y)+H(Y+Z).
$$

This is the [data processing inequality for mutual information](data-processing-inequality.md) applied to the [Markov chain](markov-chain.md) $X\to X+Y\to X+Y+Z$.
