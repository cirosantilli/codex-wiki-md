# Nonnegative superharmonic function for a Markov chain

↑ **Parent:** [Markov chain](markov-chain.md)

For a [transition matrix](stochastic-matrix.md) $P$, a finite-valued function on its state space is nonnegative superharmonic when $g\ge Pg\ge0$. Thus $g\ge0$ and its expected value cannot increase after one step. Replacing transitions on a target set by identity rows preserves $g\ge\widetilde Pg$. Iterating this inequality gives $g\ge\widetilde P^{\,n}g$, a useful bound for [hitting probabilities](hitting-probability.md) without a separate optional-stopping theorem.
