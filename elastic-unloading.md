# Elastic unloading

↑ **Parent:** [Plasticity (physics)](plasticity-physics.md)

Reduction of an applied load with purely elastic [strain](strain.md) increments while accumulated plastic [strain](strain.md) is fixed. The [superposition principle](superposition-principle.md) applies to the increment, so the current [stress](stress.md) equals the previous [stress](stress.md) plus the [linear elasticity](linear-elasticity.md) response to the load change. The resulting [stress](stress.md) must still satisfy the [yield surface](yield-surface.md) constraint; [reverse yielding](reverse-yielding.md) ends the purely elastic stage.
