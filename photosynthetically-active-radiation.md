# Photosynthetically active radiation

↑ **Parent:** [Photosynthesis](photosynthesis.md)

Radiation in the approximate 400–700 nm interval conventionally counted for [photosynthesis](photosynthesis.md). Organisms differ in spectral use, so equal integrated light does not imply equal biological utility.
