# Left translation of a group function

↑ **Parent:** [Fourier analysis on a finite group](fourier-analysis-on-a-finite-group.md)

For a scalar function on a [group](group-split.md), left translation by $a$ is $(L_af)(x)=f(a^{-1}x)$. With the positive-representation convention for [Fourier analysis on a finite group](fourier-analysis-on-a-finite-group.md), $\widehat{L_af}(\rho)=\rho(a)\widehat f(\rho)$.
