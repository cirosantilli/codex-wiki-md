# Cyclotomic unit index formula

↑ **Parent:** [Cyclotomic unit](cyclotomic-unit.md)

For a real cyclotomic field of odd prime-power conductor, the index of its cyclotomic-unit group has the same p-part as its ideal class number. The [analytic class number formula](analytic-class-number-formula.md) compares the regulator of all units with the explicit cyclotomic-unit regulator. The equality here is stated at the p-part level, so harmless prime-to-p normalization factors do not affect it.
