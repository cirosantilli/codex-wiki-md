# Row-column bound for the matrix 2-norm

↑ **Parent:** [Induced matrix norm](induced-matrix-norm.md)

For each row, the weighted [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) gives $|(Bx)_i|^2\leq(\sum_j|b_{ij}|)(\sum_j|b_{ij}||x_j|^2)$. Summing over rows bounds the result by the maximum absolute row sum times the maximum absolute column sum times $\|x\|_2^2$. Taking square roots and the supremum proves the displayed [induced matrix norm](induced-matrix-norm.md) inequality. It gives a Euclidean estimate directly from entries without computing [singular values](singular-value.md).
