# Matrix-valued Gowers U2 quantity

↑ **Parent:** [Non-abelian additive combinatorics](non-abelian-additive-combinatorics.md)

For $f:G\to M_n(\mathbb C)$ on a [finite group](finite-group.md), use uniform [expectation](expected-value.md) over the solutions of $xy^{-1}zw^{-1}=e$ and the ordinary, unnormalized [trace](matrix-trace.md) to define the displayed fourth-order quantity. If $T_\rho$ is its [matrix Fourier block](matrix-fourier-block.md), this quantity equals $\sum_\rho d_\rho\operatorname{Tr}((T_\rho T_\rho^*)^2)$, so it is real and nonnegative. For a scalar function on an [abelian group](abelian-group.md), it reduces to the usual fourth power of the [Gowers uniformity norm](gowers-uniformity-norm.md) of order two. The unnormalized [trace](matrix-trace.md) means a unitary matrix-valued function can have fourth-order quantity as large as $n$.
