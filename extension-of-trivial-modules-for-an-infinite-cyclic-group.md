# Extension of trivial modules for an infinite cyclic group

↑ **Parent:** [Module extension](module-extension.md)

With trivial action on both end modules, an extension has underlying abelian group $\mathbb Z^r\oplus\mathbb Z^s$ and generator action $\left(\begin{smallmatrix}I&T\\0&I\end{smallmatrix}\right)$. The integer matrix $T$ is invariant under equivalences fixing the ends. The one-element [projective resolution](projective-resolution.md) with differential $z-1$ computes the same classification over the [group ring](group-ring.md).
