# Modularity of mind

↑ **Parent:** [Cognitive psychology](cognitive-psychology.md)

Theoretical accounts in which some processing systems have specialised functions or restricted informational access. Claims about input selectivity, representations, [learning](learning.md) algorithms, developmental origins and mature processing architecture should be distinguished: evidence against one does not automatically settle the others.
