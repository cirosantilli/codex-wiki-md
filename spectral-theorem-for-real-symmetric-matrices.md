# Spectral theorem for real symmetric matrices

↑ **Parent:** [Symmetric matrix](symmetric-matrix.md)

Every real symmetric matrix has an [orthonormal basis](orthonormal-basis.md) of real eigenvectors. Equivalently, it admits an orthogonal diagonalization $A=O^TDO$ with $D$ real diagonal and $O$ an [orthogonal matrix](orthogonal-matrix.md).

This is the finite-dimensional real-symmetric case of the [spectral theorem](spectral-theorem.md).
