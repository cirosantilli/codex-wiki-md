# Closed walk

↑ **Parent:** [Walk in a graph](walk-in-a-graph.md)

A [walk in a graph](walk-in-a-graph.md) whose first and last vertices agree. An [Euclidean travelling salesman tour](euclidean-travelling-salesman-tour.md) can be estimated by first constructing a closed walk visiting all locations and then using the [triangle inequality](triangle-inequality.md) to shortcut repeated visits.
