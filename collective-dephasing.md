# Collective dephasing

↑ **Parent:** [Dephasing channel](dephasing-channel.md)

Correlated [dephasing](dephasing-channel.md) caused by the same fluctuating $z$ rotation on all [qubits](qubit.md). Averaging $U_\phi\rho U_\phi^\dagger$ over the unknown angle suppresses [quantum coherence](quantum-coherence-in-a-specified-basis.md) between sectors with different total $Z$ [eigenvalues](eigenvalue.md). Within one eigenspace, however, every state acquires the same [global phase](global-phase.md), so its [density matrix](density-matrix-split.md) is preserved. Such an eigenspace is a [decoherence-free subspace](decoherence-free-subspace.md) for this noise model. The assumption concerns the shared rotation; independent local phase noise generally destroys this protection.
