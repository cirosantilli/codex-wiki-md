# Deterministic space complexity class

↑ **Parent:** [Space complexity](space-complexity.md)

Languages decidable by deterministic [Turing machines](turing-machine.md) using $O(s(n))$ work-tape cells with a read-only input. Input-head addresses take $O(\log n)$ bits, while the input itself is not charged to work space. The definition does not require the bound to be computed by the deciding machine.
