# Norm maximum principle for a Banach-space-valued holomorphic function

↑ **Parent:** [Banach-space-valued holomorphic function](banach-space-valued-holomorphic-function.md)

For a [compact](compact-space.md) set $K$ in the domain, a norming [bounded linear functional](continuous-linear-functional.md) at $f(z)$ reduces the assertion to the scalar [maximum modulus principle](maximum-modulus-principle.md). If $z$ lies inside $K$, use its [connected](connected-space.md) component of the [interior](interior-topology.md); that component's [boundary](boundary-of-a-set.md) lies in $\partial K$. If $z\in\partial K$, the inequality is immediate. No smoothness or connectedness assumption on $K$ is required.
