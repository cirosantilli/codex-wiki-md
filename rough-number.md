# Rough number

↑ **Parent:** [Sieve theory](sieve-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Rough_number)

A $z$-rough integer has no [prime factor](prime-factor.md) below $z$; $1$ is included. Some authors instead exclude [prime factors](prime-factor.md) at most $z$, so the endpoint convention should be stated.
