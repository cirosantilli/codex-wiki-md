# Zariski-open set

↑ **Parent:** [Algebraic geometry](algebraic-geometry-split.md)

A Zariski-open set is the complement of a [Zariski-closed set](zariski-closed-set.md). A [distinguished affine open](distinguished-open-set.md) has the form $D(f)=\{x:f(x)\ne0\}$.
