# Bipartite block-constant positive semidefinite matrix

↑ **Parent:** [Positive semidefinite matrix](positive-semidefinite-matrix.md)

For positive block sizes, the real [matrix](matrix.md) $\begin{pmatrix}aJ&bJ\\bJ&aJ\end{pmatrix}$ is a [positive semidefinite matrix](positive-semidefinite-matrix.md) exactly when $a\geq|b|$. For test-vector block sums $s,t$, its [quadratic form](quadratic-form.md) is $(a+b)(s+t)^2/2+(a-b)(s-t)^2/2$. This proves sufficiency; testing $s=\pm t$ proves necessity. Zero sums in both blocks describe part of its [kernel](kernel-of-a-linear-map.md).
