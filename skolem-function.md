# Skolem function

↑ **Parent:** [Skolem hull](skolem-hull.md)

For each existential [first-order formula](first-order-formula.md) $\exists y\,\varphi(y,\mathbf x)$ in a structure, a [Skolem function](skolem-function.md) selects a witness when one exists, with an arbitrary default when none exists. An expansion containing these [functions](function-split.md) satisfies

$$
\forall\mathbf x\bigl(\exists y\,\varphi(y,\mathbf x)\to\varphi(f_\varphi(\mathbf x),\mathbf x)\bigr).
$$

A subset closed under all such [functions](function-split.md) is elementary in the original language by the [Tarski-Vaught test](tarski-vaught-test.md). Simultaneously choosing these [functions](function-split.md) is performed in the ordinary classical metatheory with choice.
