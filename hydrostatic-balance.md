# Hydrostatic balance

↑ **Parent:** [Hydrostatic approximation](hydrostatic-approximation.md)

Vertical [pressure gradient](pressure-gradient.md) balances gravitational force per unit volume. Subtracting the resting hydrostatic state and using [kinematic pressure](kinematic-pressure.md) gives $p'_z=b'$ for a [Boussinesq approximation](boussinesq-approximation.md) buoyancy anomaly. The approximation neglects vertical [acceleration](acceleration.md); this diagnostic relation is what couples [buoyancy perturbation](buoyancy-perturbation.md) to the vertical pressure profile.
