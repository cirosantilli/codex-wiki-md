# Seismic parameter

↑ **Parent:** [Seismology](seismology.md)

The [adiabatic bulk modulus](adiabatic-bulk-modulus.md) divided by [density](density.md), $\Phi=K_S/\rho=\alpha^2-4\beta^2/3$ for an [isotropic](isotropy.md) solid. It has units of squared [speed](speed.md) and is a key input to the Adams-Williamson [density](density.md) relation.
