# Null reference

↑ **Parent:** [Memory reference](memory-reference.md)

A null reference denotes the absence of an ordinary referenced [software object](software-object.md). In null-terminated [linked lists](linked-list.md) it marks the end of a chain. A search can return it to signal absence, but the caller must check before selecting data members. [Short-circuit evaluation](short-circuit-evaluation.md) can make a combined nonnull-and-property guard safe.
