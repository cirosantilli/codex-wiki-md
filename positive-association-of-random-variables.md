# Positive association of random variables

↑ **Parent:** [Probability theory](probability-theory-split.md)

A random vector $X$ is positively associated if $\operatorname{Cov}(f(X),g(X))\geq0$ for every pair of coordinatewise nondecreasing bounded functions $f,g$. The same inequality holds when both are nonincreasing, by negating them. Repeatedly applying it to products of nonnegative increasing indicators gives $\mathbb P(\bigcap_iE_i)\geq\prod_i\mathbb P(E_i)$ for increasing events; the same is true for decreasing events. Thus associated rejection indicators have [familywise error rate](familywise-error-rate.md) no greater than [independent](independent-random-variables.md) indicators with the same marginals. Pairwise positive [correlation coefficients](pearson-correlation-coefficient.md) alone do not give this stronger property. The classical definition is in [Esary, Proschan and Walkup (1967)](https://www.stat.cmu.edu/~brian/720/week02/esary-proschan-walkup-1967.pdf).
