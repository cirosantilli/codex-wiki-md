# Costate

↑ **Parent:** [Optimal control](optimal-control.md)

An adjoint variable enforcing the state dynamics in [optimal control](optimal-control.md). In the normal minimization convention it satisfies $\dot p=-H_x$ for the [Hamiltonian of an optimal-control problem](hamiltonian-of-an-optimal-control-problem.md), with terminal conditions determined by the endpoint constraints.
