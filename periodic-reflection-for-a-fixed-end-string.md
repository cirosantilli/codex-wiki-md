# Periodic reflection for a fixed-end string

↑ **Parent:** [Wave equation on a string](wave-equation-on-a-string.md)

Zero values at both endpoints of a length-$L$ string allow the [D'Alembert formula](d-alembert-s-formula.md) to be written with opposite travelling waves and a $2L$-periodic profile. This represents reflection with sign reversal at each fixed endpoint. For positive-time boundary conditions, periodicity concerns the arguments visited by the string solution; unused profile values can be defined by periodic extension.
