# Cognitive reappraisal

↑ **Parent:** [Emotion regulation](emotion-regulation.md)

Changing the interpreted meaning of an event in a way that changes its emotional implications. An experiment that alters interpretation can support a causal role for [cognitive appraisal](cognitive-appraisal.md); it does not by itself show that appraisal is necessary for every [emotion](emotion.md).
