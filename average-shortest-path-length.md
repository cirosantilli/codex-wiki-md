# Average shortest path length

↑ **Parent:** [Distance (graph theory)](distance-graph-theory.md)

The [average shortest path length](average-shortest-path-length.md) averages [graph distances](distance-graph-theory.md) over distinct ordered pairs of [vertices](vertex-graph-theory.md). A nodal value averages distances from one specified [vertex](vertex-graph-theory.md) to all others. Disconnected pairs require a separate convention.
