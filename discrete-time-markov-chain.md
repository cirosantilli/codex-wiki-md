# Discrete-time Markov chain

↑ **Parent:** [Markov chain](markov-chain.md)

A time-homogeneous discrete-time [Markov chain](markov-chain.md) has transitions at [integer](integer.md) times with the displayed conditional [probabilities](probability.md) and a row-stochastic [transition probability matrix](transition-semigroup-of-a-continuous-time-markov-chain.md) $P$. A [probability](probability.md) row vector $\pi$ is a [stationary distribution](stationary-distribution.md) when $\pi P=\pi$. It is [reversible](reversible-markov-chain.md) when $\pi_iP_{ij}=\pi_jP_{ji}$; multiplying these equations along a finite path proves equality of its forward and reversed stationary path [probabilities](probability.md).
