# Value function

↑ **Parent:** [Dynamic programming](dynamic-programming.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Value_function)

A [value function](value-function.md) assigns each [dynamic programming state](dynamic-programming-state.md) and time the best [objective function](objective-function.md) value attainable over the remaining decisions. It is a score, whereas a [control policy](control-policy.md) specifies the actions producing that score. In the [0-1 knapsack problem](0-1-knapsack-problem.md) above, $V_3(5)=7$ is the score, and choosing the items of weights $2$ and $3$ attains it. In sequential [mathematical optimization](mathematical-optimization-split.md), the [Bellman equation](bellman-equation.md) computes a [value function](value-function.md) by comparing immediate reward plus continuation value. Use a [supremum](supremum.md) or [infimum](infimum.md) when the best score need not be attained by any admissible [control policy](control-policy.md).
