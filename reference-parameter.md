# Reference parameter

↑ **Parent:** [Parameter passing](parameter-passing.md)

A parameter that designates the caller's actual storage, rather than a complete copied value. Read-only algorithms may use [reference parameters](reference-parameter.md) to avoid copying, while their correctness arguments still prohibit writes. The `VAR` convention used in [Oberon](oberon-programming-language.md) exam pseudocode has this purpose.
