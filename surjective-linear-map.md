# Surjective linear map

↑ **Parent:** [Linear map](linear-map.md)

A linear map $T:V\to W$ is surjective when its [image](image-and-preimage-of-a-function.md) is all of $W$. For finite-dimensional spaces this is equivalent to $\operatorname{rank}T=\dim W$.
