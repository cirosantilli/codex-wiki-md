# Uniform conditional L2 norm

↑ **Parent:** [Conditional L2 norm](conditional-l2-norm.md)

The essential supremum over the base of the [conditional L2 norm](conditional-l2-norm.md). It may be infinite for a globally square-integrable function. For probability fibers, $\|f\|_2\leq\|f\|_{2,\infty\mid Y}$; the uniform norm controls all fibers outside a null set rather than only their average.
