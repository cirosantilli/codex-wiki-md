# Metric travelling salesman problem

↑ **Parent:** [Travelling salesman problem](travelling-salesman-problem.md)

This is the [travelling salesman problem](travelling-salesman-problem.md) on a complete graph with nonnegative symmetric distances satisfying the [triangle inequality](triangle-inequality.md). Repeated visits can be shortcut without increasing cost. Assigning distance one to edges of an input graph and two to its nonedges creates a metric instance with a tour of cost at most the number of vertices exactly when the graph has a [Hamiltonian cycle](hamilton-cycle.md). Thus the metric problem remains [NP-hard](np-hardness.md).
