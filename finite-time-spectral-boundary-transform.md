# Finite-time spectral boundary transform

↑ **Parent:** [Global relation for a linear boundary value problem](global-relation-for-a-linear-boundary-value-problem.md)

A boundary trace transformed over a finite time interval using the [dispersion relation](dispersion-relation.md) of a linear [partial differential equation](partial-differential-equation-split.md). For integrable trace data and a polynomial dispersion function, it is an [entire function](entire-function.md) of the complex [spectral parameter](spectral-parameter.md). Its growth depends on $\operatorname{Re}\omega(k)$; multiplying by $e^{-\omega(k)t}$ changes the integrand to the causal factor $e^{-\omega(k)(t-s)}$.
