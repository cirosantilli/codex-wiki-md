# Finite bad-sequence tree

↑ **Parent:** [Well-quasi-ordering](well-quasi-ordering.md)

Given a size bound with finitely many possible objects at each position, put finite bad [sequences](sequence.md) in a tree ordered by extension. The tree is finitely branching. Arbitrarily long bad [sequences](sequence.md) would give an infinite bad [sequence](sequence.md) by [König infinity lemma](konig-s-lemma.md). This compactness argument converts an infinite [well-quasi-ordering](well-quasi-ordering.md) theorem into a uniform finite length bound.
