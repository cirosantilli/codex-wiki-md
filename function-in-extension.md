# Function in extension

↑ **Parent:** [Function in intension](function-in-intension.md)

A function in extension is a [function](function-split.md) specified by its domain and the value at each input in that domain. Distinct [functions in intension](function-in-intension.md) can have this same extension. Properties of the extension of an arbitrary program are semantic properties, to which [Rice theorem](rice-s-theorem.md) applies when the property is nontrivial.
