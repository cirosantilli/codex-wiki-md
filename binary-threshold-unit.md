# Binary threshold unit

↑ **Parent:** [Neural network](neural-network.md)

A [binary threshold unit](binary-threshold-unit.md) outputs one when its weighted input reaches its threshold and zero otherwise. Its hard threshold is not differentiable, so ordinary [backpropagation](backpropagation.md) cannot directly train the exact threshold model. Smooth [activation functions](activation-function.md) can approximate its computation.
