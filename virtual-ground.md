# Virtual ground

↑ **Parent:** [Electrical circuit](electrical-circuit-split.md)

A circuit node held close to zero [electric potential](electric-potential.md) by active feedback, without being directly connected to the reference conductor. In an ideal linear [operational amplifier](operational-amplifier.md) with its non-inverting input grounded and stable negative feedback, $V_-=V_+=0$ while neither input draws [electric current](electric-current.md). External branch currents meeting the inverting node therefore obey [Kirchhoff's current law](kirchhoff-node-law.md) without flowing into the amplifier input. Equality of the input potentials fails when the output saturates or the feedback ceases to enforce linear operation.
