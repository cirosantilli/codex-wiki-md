# P-adic columns lemma

↑ **Parent:** [Columns property](columns-property.md)

The necessity direction in [Rado's theorem](rado-s-theorem.md) colors an integer using initial data from a [P-adic valuation](p-adic-valuation.md). Applying partition regularity and grouping the coordinates of a monochromatic solution by valuation yields the blocks in the [columns property](columns-property.md); reduction modulo successively higher powers of $p$ supplies the required linear dependences.
