# Two-dimensional Flory approximation

↑ **Parent:** [Flory approximation](flory-approximation.md)

For a planar [polymer](polymer-split.md) with $N$ segments of length $\ell$, approximate its coil [free energy](thermodynamic-free-energy.md) by $F/(k_BT)\sim R^2/(N\ell^2)+v_2N^2/R^2$. The first term is the entropic stretching cost of an [ideal chain](ideal-chain.md), while $v_2$ is an excluded-area coefficient. Minimizing gives $R^4\sim v_2\ell^2N^3$ and size exponent $\nu=3/4$. For $v_2\sim\ell^2$, this becomes $R\sim\ell N^{3/4}$. A parameter multiplying $N^2/R^2$ must carry area units; using an unsquared segment length there would be dimensionally inconsistent.
