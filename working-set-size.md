# Working set size

↑ **Parent:** [Working set](working-set.md)

The number of distinct [memory pages](memory-page.md) in a [working set](working-set.md), measured by its [cardinality](cardinality.md). It depends on both the current [memory reference](memory-reference.md) index $t$ and the declared window $\Delta$, not just on the [resident set](resident-set.md) capacity.
