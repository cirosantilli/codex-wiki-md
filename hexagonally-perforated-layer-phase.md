# Hexagonally perforated layer phase

↑ **Parent:** [Microphase separation](microphase-separation.md)

A domain structure resembling lamellae pierced by an ordered array of perforations. It is distinct from an unperforated lamellar phase and from a [double gyroid](double-gyroid.md).
