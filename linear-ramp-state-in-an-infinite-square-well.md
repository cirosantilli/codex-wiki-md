# Linear ramp state in an infinite square well

↑ **Parent:** [Infinite square well](infinite-square-well.md)

The normalized [wavefunction](wave-function-split.md) $\psi(x)=\sqrt3x/L^{3/2}$ on $(0,L)$ has sine coefficients $c_n=(-1)^{n+1}\sqrt6/(n\pi)$. Its [ground-state probability](ground-state-probability.md) is $6/\pi^2$, while its [position probability](position-probability.md) in $(0,L/3)$ is $1/27$. The constant values of $E_n|c_n|^2$ make its [energy expectation](energy-expectation.md) divergent. It is a valid [Hilbert space](hilbert-space-split.md) vector but fails the finite-energy Dirichlet boundary-trace condition.
