# C-relevant pair of random variables

↑ **Parent:** [Entropic Ruzsa distance](entropic-ruzsa-distance.md)

A pair $(U,V)$ is $C$-relevant to $(X,Y)$ when

$$
d_R(U;X)+d_R(V;Y)\leq C d_R(X;Y).
$$
