# Analytic class number formula

↑ **Parent:** [Dedekind zeta function](dedekind-zeta-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Analytic_class_number_formula)

For a number field of signature $(r_1,r_2)$, roots-of-unity count $w_K$, regulator $R_K$, class number $h_K$, and discriminant $d_K$,

$$
\operatorname*{Res}_{s=1}\zeta_K(s)
=\frac{2^{r_1}(2\pi)^{r_2}h_KR_K}{w_K\sqrt{|d_K|}}.
$$
