# Codeword

↑ **Parent:** [Coding theory](coding-theory-split.md)

A [codeword](codeword.md) is a member of the specified set of words used to encode messages. For a [linear code](linear-code.md) specified by a [parity-check matrix](parity-check-matrix.md) $H$, the [codewords](codeword.md) are precisely the vectors satisfying $Hc=0$. The [minimum distance](minimum-distance-of-a-code.md) between distinct codewords controls error correction.
