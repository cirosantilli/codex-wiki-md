# Transportation problem

↑ **Parent:** [Linear programming duality](linear-programming-duality.md)

The transportation problem minimizes linear shipping cost while matching prescribed row supplies and column demands.

This is the finite discrete [optimal transport](optimal-transport.md) problem with prescribed supply and demand marginals.
