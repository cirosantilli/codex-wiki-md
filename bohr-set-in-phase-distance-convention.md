# Bohr set in phase-distance convention

↑ **Parent:** [Bohr set](bohr-set.md)

A [Bohr set](bohr-set.md) defined by distance of each character phase to the nearest integer. For $0\leq\epsilon\leq1/2$, it corresponds to the chord-distance radius $2\sin(\pi\epsilon)$. Numerical radius constants depend on the convention. In a group of prime order and with $d=|R|\geq1$, simultaneous torus approximation yields a nonzero element when $\epsilon>N^{-1/d}$ and an [arithmetic progression](arithmetic-progression.md) of length at least $\min(N,\lceil\epsilon N^{1/d}\rceil)$.
