# Linear recurrence matrix

↑ **Parent:** [Linear recurrence relation](linear-recurrence-relation.md)

A linear recurrence matrix advances a vector of quantities by a fixed [linear map](linear-map.md): $v_{n+1}=Mv_n$, hence $v_n=M^n v_0$. It can encode several simultaneous [linear recurrences](linear-recurrence-relation.md) and need not satisfy the normalization required of a [Markov chain](markov-chain-split.md) [transition matrix](stochastic-matrix.md).
