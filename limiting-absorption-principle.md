# Limiting absorption principle

↑ **Parent:** [Radiation condition](radiation-condition.md)

Select outgoing waves as a limit of a problem with weak absorption. With time convention $e^{-i\omega t}$ use $\operatorname{Im}\omega>0$; with $e^{i\omega t}$ use $\operatorname{Im}\omega<0$. The resulting [Green function](green-s-function.md) and transform-contour prescriptions determine which [poles](pole.md) represent incoming or outgoing waves. This is especially useful when real-axis singularities obscure a [Wiener-Hopf factorization](wiener-hopf-factorization.md).
