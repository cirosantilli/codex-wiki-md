# Conditional spin measurement of identical fermions

↑ **Parent:** [Indistinguishable particles](indistinguishable-particles.md)

A [measurement](measurement.md) addressing a spatial mode can prepare an opposite-spin product in the mode description without violating fermionic antisymmetry. For [orthogonal](orthogonal-vectors.md) orbitals $\phi_a,\phi_b$, the conditional mode state with [spin](spin.md) up in $a$ and [spin](spin.md) down in $b$ corresponds to the antisymmetric particle-coordinate state $[\phi_a(1)\phi_b(2)|\uparrow\downarrow\rangle-\phi_b(1)\phi_a(2)|\downarrow\uparrow\rangle]/\sqrt2$. Exchange of mode [spin](spin.md) factors is different from full exchange of the [identical particles](indistinguishable-particles.md). Only the latter must remain antisymmetric.
