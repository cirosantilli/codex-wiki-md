# Digital register

↑ **Parent:** [Sequential logic](sequential-logic.md)

A fixed-width collection of [flip-flops](flip-flop.md) storing a [binary representation](binary-number.md). A synchronous load-enabled [digital register](digital-register.md) captures all its input [bits](bit.md) on the active [clock edge](clock-edge.md) when load is asserted and otherwise retains its old value. One [multiplexer](multiplexer.md) before each [D flip-flop](d-flip-flop.md) can select new data or feedback from its old output. A [processor register](processor-register.md) is a particular use inside a processor; temporary state in a standalone [binary multiplier](binary-multiplier.md) is another.
