# Iwasawa module

↑ **Parent:** [Iwasawa theory](iwasawa-theory.md)

An Iwasawa module is a [module](module-mathematics.md) over an [Iwasawa algebra](iwasawa-algebra.md). In arithmetic towers it usually comes from a norm inverse limit of units or class groups, or from a [compact Galois module](compact-galois-module.md) for a maximal abelian pro-$p$ extension. Specify which extension is allowed to ramify: the [p-ramified Iwasawa module](p-ramified-iwasawa-module.md) and the [unramified Iwasawa module](unramified-iwasawa-module.md) have different ranks.
