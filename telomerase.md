# Telomerase

↑ **Parent:** [Enzyme](enzyme-split.md)

A reverse-transcriptase-containing enzyme that extends telomeric [DNA](deoxyribonucleic-acid.md) using an associated [RNA](ribonucleic-acid.md) template, contributing to chromosome-end maintenance in many [eukaryotes](eukaryote.md).
