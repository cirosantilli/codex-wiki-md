# Sonification

↑ **Parent:** [Acoustics](acoustics.md)

Representation of data through sound. In an image encoder, [frequency](frequency.md), [amplitude](wave-amplitude.md), time and spatial auditory cues can label different image properties. Assigning several independent quantities to one auditory dimension can lose information unless the code supplies a way to separate them.
