# Axiom of constructibility

↑ **Parent:** [Constructible universe](constructible-universe.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Axiom_of_constructibility)

Every [set](set-split.md) belongs to some level of the [constructible hierarchy](constructible-hierarchy.md). The assertion is $\forall x\,\exists\alpha\,(x\in L_\alpha)$, not that each set is definable without parameters. The [constructible universe theorem](constructible-universe-theorem.md) supplies a relative-consistency model of this assertion from [ZFC](zermelo-fraenkel-set-theory-with-choice.md).
