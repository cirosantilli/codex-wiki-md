# Input-output memory management unit

↑ **Parent:** [Computer bus](computer-bus.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Input–output_memory_management_unit)

Hardware translating device [DMA addresses](dma-address.md) to [physical addresses](physical-address.md), with access restrictions used for device isolation. Availability, configuration and isolation boundaries depend on the platform; merely having an [IOMMU](input-output-memory-management-unit.md) does not establish complete isolation. [Linux kernel documentation, VFIO: IOMMUs, device topology and isolation groups](https://docs.kernel.org/driver-api/vfio.html)
