# Constant segment of an array

↑ **Parent:** [Array (data structure)](array-data-structure.md)

A contiguous segment whose elements all have the same value. Its longest suffix after scanning a new element extends the previous constant suffix when the adjacent values agree, and otherwise starts again with length one. Keeping the largest suffix length seen gives a [linear time](linear-time.md) longest-segment scan.
