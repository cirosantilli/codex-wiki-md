# Crown graph

↑ **Parent:** [Bipartite graph](bipartite-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Crown_graph)

A crown graph is a [complete bipartite graph](complete-bipartite-graph.md) with a perfect matching removed. For $n\geq2$ it has [chromatic number](chromatic-number.md) two, but [greedy coloring](greedy-coloring.md) in the order $a_1,b_1,a_2,b_2,\ldots,a_n,b_n$ uses $n$ colors: the matched pair gets the same new color, and every subsequent pair sees all earlier colors.
