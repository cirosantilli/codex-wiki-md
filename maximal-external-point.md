# Maximal external point

↑ **Parent:** [Product order](product-order.md)

A maximal external point of a finite set has no other point strictly larger in every coordinate. This weak nondominance differs from a [maximal element](maximal-element-of-a-partially-ordered-set.md) in the [product order](product-order.md) when coordinate ties exist: for example $(1,0)$ passes the weak test against $(1,1)$ but is not maximal in the product order. In an independent continuous-coordinate random sample, ties have probability zero, so the two notions coincide almost surely.
