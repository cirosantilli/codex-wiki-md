# Wave map

↑ **Parent:** [Semilinear wave equation](semilinear-wave-equation.md)

A wave map is a [harmonic map](harmonic-map.md) with Lorentzian domain: a critical point of the action obtained by contracting the pullback target metric with the domain [Lorentzian metric](lorentzian-metric.md). For target [sphere](sphere.md) $S^2$ in Euclidean space and $\Box=-\partial_t^2+\Delta$, its extrinsic equation is $\Box\phi=\phi(|\phi_t|^2-|\nabla\phi|^2)$, subject to $|\phi|=1$. The derivative contractions are [null forms for wave equations](null-form-for-wave-equations.md). [Wave map Cauchy data](wave-map-cauchy-data.md) must include a tangent initial velocity.
