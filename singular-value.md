# Singular value

↑ **Parent:** [Singular value decomposition](singular-value-decomposition.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Singular_value)

The singular values of a [matrix](matrix.md) $A$ are the nonnegative [square roots](square-root.md) of the [eigenvalues](eigenvalue.md) of $A^*A$.
