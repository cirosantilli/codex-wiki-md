# Assignment in a first-order structure

↑ **Parent:** [First-order structure](first-order-structure.md)

An [assignment in a first-order structure](assignment-in-a-first-order-structure.md) chooses a domain element for each variable. It determines the value of every [first-order term](first-order-term.md) and the truth of every [first-order formula](first-order-formula.md), once the interpretations of symbols are fixed. A [first-order sentence](first-order-sentence.md) has no [free variables](free-variable.md), so its truth is independent of the [assignment in a first-order structure](assignment-in-a-first-order-structure.md). Quantification changes the value assigned to the [bound variable](bound-variable.md) while retaining the other values.
