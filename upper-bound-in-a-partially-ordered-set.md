# Upper bound in a partially ordered set

↑ **Parent:** [Upper and lower bounds](upper-and-lower-bounds.md)

An upper bound of a subset $A$ of a [partially ordered set](partially-ordered-set.md) is an element $u$ satisfying $a\leq u$ for every $a\in A$.
