# Type I X-ray burst

↑ **Parent:** [X-ray binary](x-ray-binary.md)

A Type I X-ray burst is a transient [thermonuclear runaway](thermonuclear-runaway.md) in accreted [hydrogen](hydrogen.md) or [helium](helium.md) on a [neutron star](neutron-star.md) surface. It rises rapidly and cools after the fuel burns. A [black hole](black-hole.md) has no material surface on which the same accumulated surface-fuel event can occur. This is distinct from an accretion-powered X-ray pulse or an accretion instability.
