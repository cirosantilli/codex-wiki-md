# Coupled angular-momentum state count

↑ **Parent:** [Addition of angular momentum](addition-of-angular-momentum.md)

Coupling orbital [angular momentum](angular-momentum.md) $L>0$ to [spin one-half](spin-one-half.md) produces $J=L\pm1/2$. The [dimensions](dimension-vector-space.md) add as $(2L+2)+2L=2(2L+1)$. A change between coupled and product [bases](basis.md) changes labels, not the [dimension](dimension-vector-space.md) of the [Hilbert space](hilbert-space-split.md).
