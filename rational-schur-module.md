# Rational Schur module

↑ **Parent:** [Rational representation of the general linear group](rational-representation-of-the-general-linear-group.md)

For a dominant integer tuple $\lambda$, choose $k=\max(0,-\lambda_m)$ and define $D_\lambda=\det^{-k}\otimes D_{\lambda+k(1,\ldots,1)}$, using the [polynomial](polynomial-split.md) [Schur module](schur-module.md) on the right. The [alternant character formula for the general linear group](alternant-character-formula-for-the-general-linear-group.md) shows that a larger admissible shift yields the same irreducible representation.
