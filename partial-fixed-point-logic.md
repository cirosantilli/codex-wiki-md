# Partial fixed-point logic

↑ **Parent:** [Finite model theory](finite-model-theory.md)

Extend [first-order logic](first-order-logic.md) by iterating definable relation operators from the empty relation. If iteration reaches a fixed point, use that relation; if it enters a nontrivial cycle, the partial fixed point is the empty relation. For a fixed arity on a finite universe, a relation requires polynomially many bits and there are exponentially many states, so iteration is evaluable in [PSPACE](pspace.md). On finite ordered structures this logic captures PSPACE.
