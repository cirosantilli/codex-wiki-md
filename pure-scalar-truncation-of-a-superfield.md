# Pure-scalar truncation of a superfield

↑ **Parent:** [Scalar superfield transformation](scalar-superfield-transformation.md)

A function $S(x,\theta,\bar\theta)=\phi(x)$ is an allowed special configuration of an unconstrained [superfield](superfield.md). The subspace where all other components remain zero is not invariant: $\delta S=(i\theta\sigma^\mu\bar\epsilon-i\epsilon\sigma^\mu\bar\theta)\partial_\mu\phi$ produces components depending on [Grassmann variables](grassmann-variable.md) whenever $\phi$ is nonconstant. Thus an isolated spacetime [scalar field](scalar-field.md) is not closed under [supersymmetry](supersymmetry-split.md). A constant gauge-singlet value is a trivial invariant exception.
