# Entire-function domination by another entire function

↑ **Parent:** [Liouville theorem](liouville-theorem.md)

Let $f,g$ be [entire functions](entire-function.md), with $g$ not identically [zero](zero-of-a-function.md). If $|f(z)|\leq C|g(z)|$ everywhere, then $f/g$ is bounded and [holomorphic](holomorphic-function-split.md) away from the isolated [zeros](zero-of-a-function.md) of $g$. The [removable singularity](removable-singularity.md) extends it across each [zero](zero-of-a-function.md), giving a bounded [entire function](entire-function.md). [Liouville's theorem](liouville-theorem.md) makes it constant, so $f=cg$ with $|c|\leq C$. If $g$ is identically [zero](zero-of-a-function.md) the inequality forces $f=0$. For example, domination by $|\cos z|$ forces a constant multiple of $\cos z$.
