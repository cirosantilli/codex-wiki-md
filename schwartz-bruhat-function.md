# Schwartz-Bruhat function

↑ **Parent:** [Schwartz-Bruhat space](schwartz-bruhat-space.md)

A Schwartz-Bruhat function on a non-Archimedean [local field](local-field.md) is a locally constant, compactly supported complex-valued function, or an element of the [Schwartz-Bruhat space](schwartz-bruhat-space.md). A sufficiently small open additive subgroup leaves it invariant under translation, and only finitely many cosets meet its support.
