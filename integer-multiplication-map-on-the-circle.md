# Integer multiplication map on the circle

↑ **Parent:** [Measure-preserving transformation](measure-preserving-transformation.md)

For an integer $K\geq2$, multiplication by $K$ on the [circle group](circle-group.md) preserves normalized [Lebesgue measure](lebesgue-measure.md). Each inverse image consists of $K$ branches, each scaling lengths by $1/K$.
