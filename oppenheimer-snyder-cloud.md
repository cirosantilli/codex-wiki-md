# Oppenheimer-Snyder cloud

↑ **Parent:** [Oppenheimer-Snyder model](oppenheimer-snyder-model.md)

The comoving dust ball $0\le\chi\le\chi_0<\pi/2$ in the [Oppenheimer-Snyder model](oppenheimer-snyder-model.md) is an Oppenheimer-Snyder cloud. Its [pressureless matter](pressureless-matter.md) has uniform [density](density.md) on each constant-[proper time](proper-time.md) slice and reaches a simultaneous final singularity in the ideal homogeneous model.
