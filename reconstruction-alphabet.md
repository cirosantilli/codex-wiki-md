# Reconstruction alphabet

↑ **Parent:** [Distortion measure (information theory)](distortion-measure-information-theory.md)

The [reconstruction alphabet](reconstruction-alphabet.md) is the set of values that the [decoder](channel-decoder.md) may output. It need not equal the source [alphabet](alphabet.md). A restricted [reconstruction alphabet](reconstruction-alphabet.md) can prevent zero [expected distortion](expected-distortion.md), even if the representation is allowed arbitrarily many [bits](bit.md).
