# Contravariant vector

↑ **Parent:** [Tensor](tensor.md)

A [contravariant vector](contravariant-vector.md) has coordinate components obeying the displayed transformation law. A [tangent vector](tangent-vector-split.md) to a parametrized curve provides the basic example: the [chain rule](chain-rule.md) transforms $dx^a/ds$ in precisely this way. Pairing it with a [covector](covector.md) produces a coordinate-independent [scalar](scalar.md). Conversely, if an array pairs invariantly with every [contravariant vector](contravariant-vector.md), coefficient comparison forces the [covector](covector.md) transformation law for that array.
