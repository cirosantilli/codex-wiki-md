# Contraction property of closed subsets characterizes completeness

↑ **Parent:** [Contraction mapping theorem](contraction-mapping-theorem.md)

A [metric space](metric-space.md) is [complete](completeness.md) if and only if every [contraction mapping](contraction-mapping.md) of every nonempty [closed subset](closed-set.md) into itself has a [fixed point](fixed-point.md). For the converse, a nonconvergent [Cauchy sequence](cauchy-sequence.md) contains a rapidly approaching subsequence whose point set is closed and whose shift is a contraction without a fixed point. Requiring the property only on the whole space is a different, weaker condition.
