# Homotopy class

↑ **Parent:** [Homotopy](homotopy.md)

An equivalence class of [continuous maps](continuous-map.md) under [homotopy](homotopy.md), with any endpoint or boundary restrictions specified. Unbased loop classes are free homotopy classes; periods of a [closed differential form](closed-differential-form.md) are constant on such classes.
