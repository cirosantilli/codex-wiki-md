# Newton iteration for modular inversion

↑ **Parent:** [Modular multiplicative inverse](modular-multiplicative-inverse.md)

If $ax\equiv1\pmod m$, the update $x'=x(2-ax)$ satisfies $ax'\equiv1\pmod{m^2}$ because $1-ax'=(1-ax)^2$. For odd $a$, starting with $x=1$ [modulo](modulo-operation.md) $2$ and repeatedly doubling the number of correct bits computes its inverse [modulo](modulo-operation.md) a [power of two](power-of-two.md).
