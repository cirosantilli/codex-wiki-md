# Modular set function

↑ **Parent:** [Set function](set-function.md)

On a finite [ground set](ground-set.md), a [modular set function](modular-set-function.md) is a [set function](set-function.md) satisfying the displayed equality for every pair of [subsets](subset.md). Equivalently,

$$
h(S)=c+\sum_{x\in S}a_x,
\qquad c=h(\varnothing),\quad a_x=h(\{x\})-h(\varnothing).
$$

To prove this representation, apply the equality to disjoint $S$ and $\{x\}$: $h(S+x)-h(S)=h(\{x\})-h(\varnothing)$. Add these fixed [marginal increments](marginal-increment-of-a-set-function.md) along any ordering of $S$. Conversely, the contributions of each element and of the constant cancel in the displayed identity. Thus a [modular set function](modular-set-function.md) need not be a [normalised set function](normalised-set-function.md); its normalised instances are precisely the real-valued [set functions](set-function.md) with [finite additivity](finite-additivity-of-a-set-function.md) on a finite [power set](power-set.md). Adding or subtracting a [modular set function](modular-set-function.md) preserves [submodularity](submodular-set-function.md).
