# Optical waveguide

↑ **Parent:** [Electromagnetic waveguide](electromagnetic-waveguide.md)

An [optical waveguide](optical-waveguide.md) confines an optical [normal mode](normal-mode.md) transversely while permitting longitudinal propagation. A higher-[refractive index](refractive-index.md) layer between lower-index layers provides a simple dielectric realization. In a [double heterostructure laser](double-heterostructure-laser.md), overlap of the guided field with the carrier-rich active layer improves useful [optical gain](optical-gain.md).
