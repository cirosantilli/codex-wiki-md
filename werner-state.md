# Werner state

↑ **Parent:** [Quantum information theory](quantum-information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Werner_state)

A [Werner state](werner-state.md) is a bipartite [density operator](density-matrix.md) invariant under $U\otimes U$ for every local [unitary operator](unitary-operator.md) $U$. An [isotropic quantum state](isotropic-quantum-state.md) instead has invariance under $U\otimes\overline U$; these are different families.
