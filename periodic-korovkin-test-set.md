# Periodic Korovkin test set

↑ **Parent:** [Compact Korovkin test space](compact-korovkin-test-space.md)

For $2\pi$-periodic [continuous functions](continuous-function.md), convergence of [positive linear operators on continuous functions](positive-linear-operator-on-continuous-functions.md) to the identity on $1,\sin x,\cos x$ implies [uniform convergence](uniform-convergence.md) on every function. Indeed $1-\cos(t-x)$ is nonnegative and has just one zero on the circle, so the [compact Korovkin test space](compact-korovkin-test-space.md) criterion applies.
