# Modal logic K4

↑ **Parent:** [Modal logic](modal-logic.md)

[Modal logic K4](modal-logic-k4.md) extends the [normal modal distribution axiom](normal-modal-distribution-axiom.md) and [necessitation rule](necessitation-rule.md) by [positive introspection](positive-introspection.md) $\Box A\to\Box\Box A$. Its [Kripke semantics](kripke-semantics.md) uses transitive accessibility relations. The fixed point $B=\Box(\Box X\to X)$ satisfies $\Box(B\to\Box X)\to(B\to\Box X)$ in this logic.
