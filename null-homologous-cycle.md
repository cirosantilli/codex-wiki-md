# Null-homologous cycle

↑ **Parent:** [Homology (mathematics)](homology-split.md)

An element of a [cycle module](cycle-module.md) is null-homologous when it represents zero in [homology](homology-split.md), equivalently when it lies in the image of the [boundary operator](boundary-operator.md). A closed submanifold bounding a submanifold one dimension higher is null-homologous.
