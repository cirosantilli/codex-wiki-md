# Equivariant estimator

↑ **Parent:** [Transformation model](transformation-model.md)

An estimator respects the [group action](group-action.md) if the displayed identity holds. If it takes values in the transformation [group](group-split.md) itself, normalization $T(y)^{-1}y$ is a [maximal invariant](maximal-invariant.md): equivariance proves invariance, and equality of normalized samples reconstructs the transformation between them. For estimates in a homogeneous parameter space with a nontrivial stabilizer, normalization is defined only modulo that stabilizer; quotienting the remaining action is essential.
