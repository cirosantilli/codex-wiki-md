# Horseshoe from two closed covering walks

↑ **Parent:** [Horseshoe for an interval map](horseshoe-for-an-interval-map.md)

If a [directed covering graph of an interval map](directed-covering-graph-of-an-interval-map.md) has two distinct closed walks of the same length $n$, based at the same interval and with different first edges, successive use of the [interval covering relation](interval-covering-relation.md) produces two subintervals with disjoint interiors that $F^n$ maps across the base interval. Hence $F^n$ has a [horseshoe for an interval map](horseshoe-for-an-interval-map.md).
