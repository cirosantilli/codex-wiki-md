# Interval discrepancy

↑ **Parent:** [Equidistributed sequence](equidistributed-sequence.md)

Interval discrepancy measures the difference between empirical counts and the expected count for normalized [Lebesgue measure](lebesgue-measure.md). Convolving an enlarged interval [indicator function](indicator-function.md) with a narrow unit-integral [indicator function](indicator-function.md) gives a continuous majorant. Its [Fourier coefficients](fourier-coefficient.md) decay as $O(1/(\delta k^2))$, converting the count into a constant term, finite exponential sums and a controlled absolute tail.
