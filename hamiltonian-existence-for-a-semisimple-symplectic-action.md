# Hamiltonian existence for a semisimple symplectic action

↑ **Parent:** [Weakly Hamiltonian action](weakly-hamiltonian-action.md)

For a symplectic left [Lie group action](lie-group-action.md), use actual fundamental fields $\xi_P$ and $\iota_{X_f}\omega=df$. They satisfy $[\xi_P,\eta_P]=-[\xi,\eta]_P$. [Cartan's magic formula](cartan-s-magic-formula.md) then gives $\iota_{[\xi,\eta]_P}\omega=d[\omega(\xi_P,\eta_P)]$. Thus every commutator generator has a globally exact contraction. A [semisimple Lie algebra](semisimple-lie-algebra-split.md) is perfect, so every generator has a global Hamiltonian. The separate [semisimple moment-map equivariance](semisimple-moment-map-equivariance.md) result removes the constant two-cocycle obstruction and gives an equivariant [moment map](moment-map.md) for a connected group.
