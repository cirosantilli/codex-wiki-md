# Relative error

↑ **Parent:** [Approximation error](approximation-error.md)

For a nonzero reference value $x$, the relative error is the [absolute error](absolute-error.md) divided by the reference's [absolute value](absolute-value.md):

$$
\frac{|x_{\mathrm{approx}}-x|}{|x|}.
$$

It is [dimensionless](dimensionless-quantity.md) and expresses the size of the error compared with the quantity being approximated. Approximating $1/3$ by $0.33$ has [absolute error](absolute-error.md) $1/300$ and [relative error](relative-error.md) $1/100=1\%$. The definition is unavailable when the reference is zero; use an [absolute error](absolute-error.md) or a separately stated scale in that case.
