# Signed relative error

↑ **Parent:** [Relative error](relative-error.md)

The signed relative error is $\varepsilon=(x_{\mathrm{approx}}-x)/x$ for a nonzero reference $x$. Its [absolute value](absolute-value.md) is the [relative error](relative-error.md). For a positive reference, a negative [signed relative error](signed-relative-error.md) means underestimation, and a positive one means overestimation. For a negative reference that interpretation reverses, so retain the displayed definition when interpreting its sign.
