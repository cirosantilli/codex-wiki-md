# Propositional consistency

↑ **Parent:** [Consistent set of formulae](consistent-set-of-formulae.md)

A collection of [propositional formulas](propositional-formula.md) is consistent if it does not derive a [contradiction](contradiction.md). Equivalently, in a standard classical calculus, it does not derive both a [logical formula](logical-formula.md) and its [negation](negation.md).
