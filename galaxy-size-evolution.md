# Galaxy size evolution

↑ **Parent:** [Galaxy evolution](galaxy-evolution.md)

The observed size distribution of [galaxies](galaxy-split.md) changes with epoch at a given [galaxy stellar mass](galaxy-stellar-mass.md). Growth of an individual object and changes in which objects enter a selected sample both contribute. [Minor galaxy mergers](minor-galaxy-merger.md) can deposit stars at large radii, increasing size while adding relatively little mass; stellar mass loss and dissipative evolution provide other mechanisms.
