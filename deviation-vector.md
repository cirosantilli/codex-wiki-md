# Deviation vector

↑ **Parent:** [Geodesic variation](geodesic-variation.md)

For a [geodesic variation](geodesic-variation.md) $F(s,\tau)$, the [deviation vector](deviation-vector.md) $S=F_*\partial_s$ describes infinitesimal separation at equal parameter values. With $T=F_*\partial_\tau$, commuting parameter derivatives give $[S,T]=0$. A [torsion-free connection](torsion-free-connection.md) then gives $\nabla_TS=\nabla_ST$. For an affinely parametrized variation, [geodesic deviation](geodesic-deviation.md) states $\nabla_T^2S=R(T,S)T$ with the convention $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$.
