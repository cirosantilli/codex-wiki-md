# Hermitizing matrix

↑ **Parent:** [Gamma matrices](gamma-matrices.md)

A [Hermitizing matrix](hermitizing-matrix.md) for a set of [gamma matrices](gamma-matrices.md) is an invertible [Hermitian matrix](hermitian-operator.md) $H$ satisfying $\gamma^{a\dagger}=H\gamma^aH^{-1}$. Equivalently, each $H\gamma^a$ is Hermitian. It defines a covariant adjoint $\bar\psi=\psi^\dagger H$. If $\gamma'^a=M\gamma^aM^{-1}$, then $H'=M^{-\dagger}HM^{-1}$ has the same property. In a standard Lorentzian [Dirac basis](dirac-representation-of-the-gamma-matrices.md), $H=\gamma^0$ is a conventional choice.
