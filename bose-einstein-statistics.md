# Bose-Einstein statistics

↑ **Parent:** [Quantum ideal-gas statistics](quantum-ideal-gas-statistics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bose–Einstein_statistics)

[Bose-Einstein statistics](bose-einstein-statistics.md) describes identical noninteracting [bosons](boson.md) in equilibrium. Any occupation number is allowed in a one-particle state; the resulting [Bose-Einstein distribution](bose-einstein-distribution.md) is $n(E)=[e^{\beta(E-\mu)}-1]^{-1}$.
