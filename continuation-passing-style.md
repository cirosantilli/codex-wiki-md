# Continuation-passing style

↑ **Parent:** [Continuation (computer science)](continuation-computer-science.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Continuation-passing_style)

Pass the remaining computation explicitly as a [continuation](continuation-computer-science.md). Returning a value means invoking that [continuation](continuation-computer-science.md); a different control destination can be selected by invoking a different [continuation](continuation-computer-science.md).
