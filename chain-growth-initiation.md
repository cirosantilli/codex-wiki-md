# Chain-growth initiation

↑ **Parent:** [Chain-growth polymerization](chain-growth-polymerization.md)

[Chain-growth initiation](chain-growth-initiation.md) creates a chain capable of [chain-growth propagation](chain-growth-propagation.md). Write

$$
I^*+M\longrightarrow P_1^*.
$$

This schematic includes the first incorporated [monomeric unit](monomeric-unit.md); any preceding production of $I^*$ is a separate step. If $C$ counts [polymer](polymer-split.md) [molecules](molecule-split.md), $A$ counts polymer-bound [polymerization-active sites](polymerization-active-site.md), and $S$ counts incorporated [monomeric units](monomeric-unit.md), this event changes $(C,A,S)$ by $(1,1,1)$. The free $I^*$ was excluded from $A$, so this does not assert creation of reactivity from nothing. An initiator feed amount need not equal the number of successful chains: the efficiency of forming productive chains and the number of initiating species per initiator matter. [McMurry, §31.1, initiating species and the first reactive intermediate](organic-chemistry-by-john-mcmurry/31-1-chain-growth-polymers.md)
