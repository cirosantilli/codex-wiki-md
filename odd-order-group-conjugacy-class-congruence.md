# Odd-order group conjugacy-class congruence

↑ **Parent:** [Frobenius-Schur indicator](frobenius-schur-indicator.md)

An odd-order [finite group](finite-group.md) has only odd irreducible degrees, by [irreducible character degree divides the group order](irreducible-character-degree-divides-the-group-order.md). Its nontrivial characters occur in distinct conjugate pairs, by the [Frobenius-Schur indicator](frobenius-schur-indicator.md). Therefore $|G|-k(G)=\sum_\chi(\chi(1)^2-1)$ is a sum of pairs $2(d^2-1)$ with $d$ odd. Since $d^2\equiv1\pmod8$, each pair is divisible by sixteen. Here $k(G)$ is the number of [conjugacy classes](conjugacy-class.md).
