# Power-set closure of better-quasi-orderings

↑ **Parent:** [Better-quasi-ordering](better-quasi-ordering.md)

If $Q$ is a [better-quasi-ordering](better-quasi-ordering.md), its full [power set](power-set.md) is better-quasi-ordered by the [Hoare domination preorder](hoare-domination-preorder.md). A bad continuous array of subsets would allow a choice of $q_X\in A_X$ not below any member of $A_{X^-}$, where $X^-$ deletes the least element. Choose this witness as a fixed function of the two locally constant subsets. Then $X\mapsto q_X$ is a bad [continuous array in better-quasi-order theory](continuous-array-in-better-quasi-order-theory.md) into $Q$, a contradiction. Empty source subsets cannot occur in a bad array because they precede every subset.
