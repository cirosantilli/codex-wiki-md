# IP hourglass

↑ **Parent:** [Internet architecture](internet-architecture.md)

The [IP hourglass](ip-hourglass.md) describes a common narrow inter-network layer supporting many applications above it and many network technologies below it. Keeping that interface general limits the need for every application developer and link provider to coordinate separate application-specific changes.[§§2.1–2.4: common internetwork protocol and independence from underlying media](architectural-principles-of-the-internet-rfc-1958.md)
