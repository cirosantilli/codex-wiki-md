# Nat (unit)

↑ **Parent:** [Information theory](information-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nat_(unit))

The unit for [information content](information-content.md) or [information entropy](information-entropy.md) computed with [natural logarithms](natural-logarithm.md). Converting to [bits](bit.md) divides the numerical value by $\log2$, so $1\,\mathrm{nat}=(1/\log2)\,\mathrm{bits}$.
