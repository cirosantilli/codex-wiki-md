# True state dependence

↑ **Parent:** [Conditional logistic model for longitudinal binary data](conditional-logistic-model-for-longitudinal-binary-data.md)

A previous outcome may affect a subsequent outcome after controlling both measured [covariates](covariate.md) and persistent [unobserved heterogeneity](unobserved-heterogeneity.md). This is true state dependence. An observed lagged-outcome association alone does not establish it, because omitted individual propensities can create apparent persistence.
