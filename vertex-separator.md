# Vertex separator

↑ **Parent:** [Menger theorem](menger-theorem.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Vertex_separator)

An $x$-$y$ vertex separator is a set of vertices, excluding $x$ and $y$, whose deletion leaves no path from $x$ to $y$.
