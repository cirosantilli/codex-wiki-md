# Cooperative game theory

↑ **Parent:** [Game theory](game-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cooperative_game_theory)

Cooperative game theory studies what groups of players can achieve together and how their joint value can be allocated. A [transferable utility game](transferable-utility-game.md) assigns a real value to each [coalition](coalition-game-theory.md). The [core of a cooperative game](core-game-theory.md) asks which allocations no [coalition](coalition-game-theory.md) can improve upon; the [Shapley value](shapley-value.md) averages [marginal contributions](marginal-contribution.md) across player orderings.
