# Shortened code

↑ **Parent:** [Linear code](linear-code.md)

Shortening a code at one coordinate first retains only words with a chosen symbol there and then applies [puncturing](puncturing-coding-theory.md) at that coordinate. The minimum distance cannot decrease. In a binary code one coordinate-symbol fibre contains at least half of the words.
