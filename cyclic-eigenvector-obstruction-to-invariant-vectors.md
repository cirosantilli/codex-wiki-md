# Cyclic eigenvector obstruction to invariant vectors

↑ **Parent:** [Cyclic vector for a group representation](cyclic-vector-for-a-group-representation.md)

In a [unitary representation](unitary-representation.md) of a [finite group](finite-group.md), if a cyclic vector $v$ satisfies $\rho(g)v=av$ for some $a\ne1$, then there are no invariant vectors. Indeed the averaging [orthogonal projection](orthogonal-projection.md) $P=|G|^{-1}\sum_h\rho(h)$ satisfies $P\rho(g)=P$, so $Pv=aPv=0$. All translates of $v$ also project to zero, and they span the representation.
