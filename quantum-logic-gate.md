# Quantum logic gate

↑ **Parent:** [Quantum circuit](quantum-circuit-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantum_logic_gate)

A unitary operation on a fixed number of [qubits](qubit.md) used as a component of a [quantum circuit](quantum-circuit-split.md). Examples include the [Hadamard gate](hadamard-gate.md) and [Controlled-Z gate](controlled-z-gate.md). Measurements are described separately by [measurement in quantum mechanics](quantum-measurement-split.md); a gate is a reversible operation on its full input state.
