# Set basis problem

↑ **Parent:** [Set family](set-family.md)

The [set basis problem](set-basis-problem.md) asks whether a finite [set family](set-family.md) $\mathcal F\subseteq2^U$ can be generated by [unions](set-union.md) of at most $k$ basis [subsets](subset.md) of $U$. The basis [sets](set-split.md) need not belong to $\mathcal F$, and the empty [union](set-union.md) is allowed. For example, the three pairwise two-element [subsets](subset.md) of $\{1,2,3\}$ have the singleton basis $\{\{1\},\{2\},\{3\}\}$, although none of its members is an input [set](set-split.md).

There are at most $2^k$ distinct [unions](set-union.md) of $k$ basis [sets](set-split.md), so any yes-instance has $|\mathcal F|\leq2^k$, after duplicate input [sets](set-split.md) are discarded. Retain one representative of each class of [incidence equivalence in a set family](incidence-equivalence-in-a-set-family.md). There are at most $2^{|\mathcal F|}\leq2^{2^k}$ representatives, because an element is described by its membership bits across $\mathcal F$. The equivalence-preserving deletion proof in [incidence equivalence in a set family](incidence-equivalence-in-a-set-family.md) shows that this is a [kernelization](kernelization.md). Relabel the representatives and store the reduced incidence [matrix](matrix.md); its length is bounded by a computable [function](function-split.md) of $k$. To solve the reduced instance with $q$ elements, enumerate all $2^{kq}$ ordered lists of $k$ basis [subsets](subset.md), padding smaller bases by empty [sets](set-split.md). For each input [set](set-split.md) $B$, take the [union](set-union.md) of all proposed basis [sets](set-split.md) contained in $B$: it equals $B$ exactly when some allowable [union](set-union.md) represents $B$. This finite search proves [fixed-parameter tractability](fixed-parameter-tractability.md).
