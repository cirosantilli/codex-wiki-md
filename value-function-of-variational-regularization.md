# Value function of variational regularization

↑ **Parent:** [Variational regularization](variational-regularization.md)

For a nonnegative regulariser $J$, the optimal objective value is non-decreasing and [concave](concave-function.md) in the positive regularization parameter. If $J(0)=0$ and $D(0)<\infty$, comparison with zero makes it finite and a [locally Lipschitz function](locally-lipschitz-function.md) away from parameter zero.
