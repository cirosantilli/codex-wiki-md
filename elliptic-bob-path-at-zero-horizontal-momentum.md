# Elliptic bob path at zero horizontal momentum

↑ **Parent:** [Pendulum with a freely sliding support](pendulum-with-a-freely-sliding-support.md)

Zero horizontal [momentum](momentum-split.md) fixes the horizontal [centre of mass](center-of-mass.md). The bob coordinates become $X=X_c+lm_1\sin\phi/(m_1+m_2)$ and $Y=-l\cos\phi$. Eliminating the angle gives an [ellipse](ellipse.md); an ordinary [oscillation](oscillation.md) traverses only its permitted arc. The support counter-moves, so the bob's path differs from the circle about a fixed pivot.
