# Propositional variable elimination

↑ **Parent:** [Propositional formula](propositional-formula.md)

The displayed identity follows by testing the two possible truth values of $p$. Existentially forgetting $p$ gives $A[p:=\top]\vee A[p:=\bot]$. Repeating this operation produces a [propositional formula](propositional-formula.md) on a specified remaining vocabulary. Logical truth constants are needed if that vocabulary is empty.
