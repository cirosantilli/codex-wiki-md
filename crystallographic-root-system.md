# Crystallographic root system

↑ **Parent:** [Root system](root-system.md)

A finite [root system](root-system.md) in a real [inner product space](inner-product-space.md) is crystallographic when every [Cartan integer](cartan-integer.md) $2(\beta,\alpha)/(\alpha,\alpha)$ is an integer. The roots of a complex [semisimple Lie algebra](semisimple-lie-algebra-split.md) satisfy this because each number is a weight of its [sl2 subalgebra associated with a root](sl2-subalgebra-associated-with-a-root.md). Reducedness is a separate axiom; the [root-space reducedness lemma](root-space-reducedness-lemma.md) establishes it for these Lie-algebra roots.
