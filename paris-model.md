# Paris model

↑ **Parent:** [Definable element of a first-order structure](definable-element-of-a-first-order-structure.md)

A Paris model of a complete extension $T$ of [ZFC](zermelo-fraenkel-set-theory-with-choice.md) is a set model $M\models T$ in which every internal [ordinal](ordinal.md) is a [definable element of a first-order structure](definable-element-of-a-first-order-structure.md) without parameters.
