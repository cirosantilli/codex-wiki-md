# Axisymmetric geostrophic mode

↑ **Parent:** [Shearing sheet](shearing-sheet.md)

A stationary [mass density](density.md) disturbance can be balanced by a changed azimuthal [velocity](velocity.md) in a [shearing sheet](shearing-sheet.md). The [continuity](continuous-function.md) and azimuthal equations give zero [radial velocity](radial-velocity.md), while the radial equation balances [Coriolis force](coriolis-force.md) against [pressure](pressure.md) and gravity. This mode is separate from the density-wave pair in the [softened Toomre dispersion relation](softened-toomre-dispersion-relation.md) and is lost if one divides every equation by frequency.
