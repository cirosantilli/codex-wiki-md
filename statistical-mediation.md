# Statistical mediation

↑ **Parent:** [Regression analysis](regression-analysis.md)

A statistical description in which an association between an explanatory variable and an outcome is decomposed using an intermediate variable. Such a fitted relation is not automatically a causal pathway; [causal mediation](causal-mediation.md) requires additional identification assumptions and an appropriate design.
