# Mammillary body

↑ **Parent:** [Hypothalamus](hypothalamus.md)

A paired hypothalamic structure with hippocampal and brainstem inputs and outputs to the [anterior thalamic nuclei](anterior-thalamic-nuclei.md). It can contribute actively to memory processing rather than merely relay hippocampal output.
