# Symmetry coordinate

↑ **Parent:** [Molecular symmetry](molecular-symmetry.md)

A linear combination of atomic displacements adapted to an [irreducible representation](irreducible-representation.md) of a [molecular point group](molecular-point-group.md). [Symmetry coordinates](symmetry-coordinate.md) reduce the [dynamical matrix](dynamical-matrix.md) into independent symmetry blocks; several coordinates in the same block can still mix.
