# Newton system

↑ **Parent:** [Newton's method in optimization](newton-s-method-in-optimization.md)

The linear system defining one step of [Newton's method](newton-s-method-in-optimization.md) for $F(x)=0$ is the displayed first-order correction equation. A nonsingular [Jacobian matrix](jacobian-matrix.md) gives a unique [Newton correction](newton-correction.md). For an unconstrained stationary-point problem $F=\nabla f$, the system uses the [Hessian matrix](hessian-matrix.md) in place of $DF$.
