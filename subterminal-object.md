# Subterminal object

↑ **Parent:** [Terminal object](terminal-object.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Subterminal_object)

An object $S$ is subterminal when its unique morphism $S\to1$ to the [terminal object](terminal-object.md) is a [monomorphism](monomorphism.md). Equivalently, every object has at most one morphism to $S$. Subterminal objects form the preorder $\operatorname{Sub}(1)$.
