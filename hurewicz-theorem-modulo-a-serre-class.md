# Hurewicz theorem modulo a Serre class

↑ **Parent:** [Hurewicz theorem](hurewicz-theorem.md)

For a [simply connected](simply-connected-space.md) space, if lower [homotopy groups](homotopy-group.md) lie in an admissible [Serre class](serre-class.md), the Hurewicz map in the next degree is an isomorphism modulo that class, and the lower [homology](homology-split.md) groups lie in the class. This applies to finitely generated groups and to finite groups supported at prescribed primes.
