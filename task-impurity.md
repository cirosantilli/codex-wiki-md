# Task impurity

↑ **Parent:** [Construct validity](construct-validity.md)

A task intended to measure one cognitive process also requires other processes, such as [perception](perception.md), [language comprehension](language-comprehension.md) or producing a response. Impaired performance therefore does not identify the intended process uniquely. Matched control conditions and converging tasks with different incidental demands help constrain the explanation.
