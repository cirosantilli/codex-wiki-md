# T gate

↑ **Parent:** [Phase gate](phase-gate.md)

The [phase gate](phase-gate.md) with angle $\pi/4$. It rotates the [Bloch vector](bloch-vector.md) by $\pi/4$ around $z$, and $T^2=S$. It is not a [Clifford gate](clifford-gate.md): it takes the positive $X$ eigenstate to a state with vector $(1/\sqrt2,1/\sqrt2,0)$, outside the [stabilizer octahedron](stabilizer-octahedron.md).
