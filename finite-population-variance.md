# Finite population variance

↑ **Parent:** [Probability sampling](probability-sampling.md)

For $N>1$, the [finite population variance](finite-population-variance.md) measures spread about the [finite population mean](finite-population-mean.md). Survey-sampling formulas commonly use denominator $N-1$; the denominator-$N$ version is $\sigma_N^2=(N-1)S^2/N$. The normalization must be specified when using a [finite population correction](finite-population-correction.md).
