# Scalar matrix

↑ **Parent:** [Diagonal matrix](diagonal-matrix.md)

A [scalar matrix](scalar-matrix.md) is a scalar multiple of the identity [matrix](matrix.md), equivalently a [diagonal matrix](diagonal-matrix.md) with all diagonal entries equal. It commutes with every square [matrix](matrix.md) of the same size. In $GL_n(F)$, the nonzero [scalar matrices](scalar-matrix.md) form the central [subgroup](subgroup.md) removed to define the [projective linear group](projective-linear-group.md).
