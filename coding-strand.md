# Coding strand

↑ **Parent:** [Transcription (biology)](transcription-biology.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Coding_strand)

For a specified [transcription](transcription-biology.md) unit, the [coding strand](coding-strand.md) is the [DNA](deoxyribonucleic-acid.md) strand matching the initial [RNA](ribonucleic-acid.md) product in the $5'\to3'$ direction, with T in place of U. The opposite [DNA](deoxyribonucleic-acid.md) strand is the template. The name does not imply that every transcribed [gene](gene.md) encodes a [protein](protein.md). See [Clark, Douglas and Choi: coding and template strands](https://openstax.org/books/biology-2e/pages/15-2-prokaryotic-transcription).
