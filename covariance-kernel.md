# Covariance kernel

↑ **Parent:** [Covariance operator](covariance-operator.md)

When a [covariance operator](covariance-operator.md) on a function space is an [integral operator](integral-operator.md), its covariance kernel satisfies $(C_Xf)(s)=\int c_X(s,t)f(t)dt$. For a centered process, $c_X(s,t)=\mathbb E[X(s)X(t)]$ whenever point evaluation is meaningful.
