# Dimension bound for a commutative Euclidean normed algebra

↑ **Parent:** [Normed algebra](normed-algebra.md)

A finite-dimensional [commutative](commutativity.md) real algebra with a Euclidean multiplicative [norm](norm.md) has dimension at most two. [Automatic real bilinearity from a multiplicative norm](automatic-real-bilinearity-from-a-multiplicative-norm.md) supplies bilinearity if it was not part of the initial description. On its [unit sphere](unit-sphere.md), squaring has derivative $v\mapsto2xv$, injective because there are no [zero divisors](zero-divisor.md). The only equal squares are antipodal pairs, so the map induces an injective [immersion](immersion.md) $\mathbb{RP}^{n-1}\to S^{n-1}$. [Compactness](compact-space.md) and the [inverse function theorem](inverse-function-theorem.md) make it a [diffeomorphism](diffeomorphism.md) when $n\geq2$. For $n\geq3$, the [fundamental groups](fundamental-group.md) $\mathbb Z/2$ and zero contradict this. The real and complex number algebras attain dimensions one and two.
