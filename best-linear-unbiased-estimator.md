# Best linear unbiased estimator

↑ **Parent:** [Linear unbiased estimator](linear-unbiased-estimator.md)

A best linear unbiased estimator minimizes [covariance](covariance.md) among linear estimators unbiased for the same target. In $Y=X\beta+\varepsilon$, assume $\mathbb E\varepsilon=0$, $X$ is a full-column-rank [design matrix](design-matrix.md) and the known [covariance matrix](covariance-matrix.md) $\Sigma$ is a [positive-definite matrix](positive-definite-matrix.md). The [best linear unbiased estimator](best-linear-unbiased-estimator.md) of the coefficient vector is $(X^T\Sigma^{-1}X)^{-1}X^T\Sigma^{-1}Y$. A spatial trend estimate excludes the correlated residual prediction included in [universal kriging](universal-kriging.md).
