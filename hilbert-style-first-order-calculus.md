# Hilbert-style first-order calculus

↑ **Parent:** [First-order logic](first-order-logic.md)

A Hilbert-style calculus specifies axiom schemes and a small collection of inference rules, typically implication elimination and universal [generalization](universal-generalization-rule.md). Equality and [quantifier](quantifier.md) schemes include substitution and free-variable side conditions. Proofs are finite syntactic derivations; validity is separately defined using structures and assignments. A context-sensitive presentation restricts [generalization](universal-generalization-rule.md) by its actual undischarged assumptions.
