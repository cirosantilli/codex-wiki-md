# Bounded model checking

↑ **Parent:** [Model checking](model-checking.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bounded_model_checking)

A [formal verification](formal-verification.md) method that encodes a bounded execution and a violated specification as a [Boolean satisfiability problem](boolean-satisfiability-problem.md). A [satisfying assignment](satisfying-assignment.md) yields a [counterexample](counterexample.md). For infinite-path properties, a [lasso path](lasso-path.md) can finitely represent a repeated execution. Failure to find a [counterexample](counterexample.md) at one finite bound alone does not prove an unbounded property.[§§2–4, bounded encodings; §5, bounds](symbolic-model-checking-without-bdds-by-armin-biere-and-others.md)
