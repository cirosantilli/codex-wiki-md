# Open string

↑ **Parent:** [Bosonic string theory](bosonic-string-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Open_string)

An open string has a worldsheet with boundary. Its endpoint conditions may be [Neumann boundary conditions](neumann-boundary-condition.md), [Dirichlet boundary conditions](dirichlet-boundary-condition.md), or mixtures selected independently in target-space directions.
