# Centralizing HNN extension detects subgroup membership

↑ **Parent:** [HNN extension](hnn-extension.md)

In the [HNN extension](hnn-extension.md) $\langle P,t\mid t^{-1}\ell t=\ell\ (\ell\in L)\rangle$, the displayed equivalence follows from [Britton's lemma](britton-s-lemma.md). If $p\in L$, the word collapses by the defining isomorphism; otherwise it has stable letters and no pinch, so it is nonidentity. When $P$ is finitely presented and $L$ is finitely generated, imposing commutation with the finitely many subgroup generators gives a finite presentation. An undecidable membership problem for $L$ then becomes an undecidable [word problem for a group](word-problem-for-groups.md) in the extension.
