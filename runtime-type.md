# Runtime type

↑ **Parent:** [Type system](type-system.md)

The concrete type of a value or allocated object during execution. For ordinary instance methods in [object-oriented programming](object-oriented-programming.md), [dynamic dispatch](dynamic-dispatch.md) uses the receiver's [runtime type](runtime-type.md) after a signature has been selected. The runtime type of an argument does not in general restart compile-time [method overloading](method-overloading.md).
