# Set inclusion

↑ **Parent:** [Subset](subset.md)

[Set inclusion](set-inclusion.md) $C\subseteq D$ means that every [set element](element-of-a-set.md) of the [set](set-split.md) $C$ also belongs to the [set](set-split.md) $D$. Strict [set inclusion](set-inclusion.md) additionally requires $C\ne D$. A [maximal clique](maximal-clique.md) cannot grow through strict [set inclusion](set-inclusion.md), while a [maximum clique](maximum-clique.md) maximizes [cardinality](cardinality.md).
