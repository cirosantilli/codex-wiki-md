# User Datagram Protocol

↑ **Parent:** [Transport protocol](transport-protocol.md)

[User Datagram Protocol](user-datagram-protocol.md) supplies a datagram transport interface without built-in reliable ordered-stream delivery. An application or another [protocol](communication-protocol.md) can add recovery over that interface, as the pre-2020 [QUIC](quic.md) design illustrates.
