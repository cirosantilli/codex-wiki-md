# Transition system

↑ **Parent:** [Formal verification](formal-verification.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Transition_system)

A model consisting of a [set](set-split.md) $S$ of [states](state-computer-science.md), a [transition relation](transition-relation.md) $\to\subseteq S\times S$, initial [states](state-computer-science.md) $I\subseteq S$, a [set](set-split.md) $AP$ of [atomic propositions](atomic-proposition.md), and a label [function](function-split.md) $L:S\to2^{AP}$ identifying which [atomic propositions](atomic-proposition.md) hold at each [state](state-computer-science.md). A [path in a transition system](path-in-a-transition-system.md) follows permitted transitions. Some definitions omit labels or initial conditions; specify the convention used in each application.
