# Neofunctionalization

↑ **Parent:** [Molecular genetics](molecular-genetics-split.md)

Acquisition of a new function by a [gene](gene.md) copy, classically following [gene duplication](gene-duplication.md). The other copy can retain an ancestral function while changes accumulate in the retained duplicate.
