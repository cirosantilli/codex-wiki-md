# Second-order relation variable

↑ **Parent:** [Second-order logic](second-order-logic.md)

A [second-order relation variable](second-order-relation-variable.md) of arity $k\ge1$ can be assigned a [subset](subset.md) of the $k$-fold [Cartesian product](cartesian-product.md) $D^k$; its application $R(x_1,\ldots,x_k)$ is true exactly when the [tuple](finite-tuple.md) $(x_1,\ldots,x_k)$ belongs to that [subset](subset.md). Arity is the number of arguments, so a unary [second-order relation variable](second-order-relation-variable.md) is a predicate on individual objects. For a [finite set](finite-set.md) $D$ of [cardinality](cardinality.md) $n$, there are $n^k$ possible [tuples](finite-tuple.md) and $2^{n^k}$ possible relations under [full semantics for second-order logic](full-semantics-for-second-order-logic.md). A relation is encoded by $n^k$ membership bits once the objects have been numbered; the number of possible witnesses can be exponential even when each witness has a short encoding.
