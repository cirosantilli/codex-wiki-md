# Uniform stability of a learning algorithm

↑ **Parent:** [Stability (learning theory)](stability-learning-theory.md)

This is a uniform version of [Stability](stability-learning-theory.md) for learning algorithms. A learning algorithm has uniform stability $\beta$ for a loss when replacing one training example changes the loss at every test example by at most $\beta$.
