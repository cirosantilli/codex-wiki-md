# Probabilistic programming

↑ **Parent:** [Programming language](programming-language-split.md)

[Probabilistic programming](probabilistic-programming.md) expresses a [probability model](probability-model.md) as an executable program with random choices and observations. Executing the generative part induces a [probability distribution](probability-distribution-split.md); observations then restrict or weight executions, and inference computes the resulting [conditional distribution](conditional-distribution.md). Program syntax and inference algorithm are separate choices: the same model can be evaluated by [rejection sampling](rejection-sampling.md), [importance sampling](importance-sampling.md) or [Markov chain Monte Carlo](markov-chain-monte-carlo.md).
