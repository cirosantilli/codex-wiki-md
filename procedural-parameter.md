# Procedural parameter

↑ **Parent:** [Procedure type](procedure-type.md)

A procedure passed as an argument to another procedure. For a nested procedure under [lexical scope](lexical-scope.md), the argument must preserve both its code and its defining environment, for example as a [programming closure](closure-computer-programming.md).
