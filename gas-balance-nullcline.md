# Gas-balance nullcline

↑ **Parent:** [Galactic gas regulator](galactic-gas-regulator.md)

In a system where gas and stellar masses both evolve, the locus $\dot M_g=0$ gives the instantaneous [gas-balance nullcline](gas-balance-nullcline.md). Motion along the other state variables generally changes the [equilibrium](equilibrium-point-of-a-dynamical-system.md) reservoir, so the [nullcline](nullcline.md) is not itself an exact constant-gas trajectory.
