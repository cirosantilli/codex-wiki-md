# Projection (mathematics)

↑ **Parent:** [Function](function-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Projection_(mathematics))

A [projection](projection-mathematics.md) is a [function](function-split.md) that fixes the points in its image: applying it twice has the same effect as applying it once. A coordinate projection can be represented this way when its target is identified with a retract; a [linear projection](projection-linear-algebra.md) additionally respects the vector-space operations.
