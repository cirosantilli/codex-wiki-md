# Balanced scales for a thermocapillary film

↑ **Parent:** [Thermocapillary thin-film equation](thermocapillary-thin-film-equation.md)

Write the surface tension as $\gamma_s=\gamma_0+Bh$, where $B>0$. The [thermocapillary thin-film equation](thermocapillary-thin-film-equation.md) has flux $\gamma_0h^3h_{xxx}/(3\mu)+Bh^2h_x/(2\mu)$. Balancing both terms at thickness scale $h_*$ gives aspect ratio $\epsilon^2=3Bh_*/(2\gamma_0)$ and time scale $4\mu\gamma_0/(3B^2h_*)$. The fractional surface-tension variation is $Bh_*/\gamma_0=2\epsilon^2/3$, so using constant tension in the leading [capillary pressure](capillary-pressure.md) term is consistent with the balanced long-wave limit.
