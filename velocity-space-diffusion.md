# Velocity-space diffusion

↑ **Parent:** [Quasilinear diffusion](quasilinear-diffusion.md)

Random changes of particle [velocity](velocity.md) described by a [diffusion equation](diffusion-equation-split.md) in [velocity space](velocity-space.md). For constant $D$, $\langle(\Delta v)^2\rangle=2D\Delta t$. With zero boundary flux it conserves number. For a number-normalized one-dimensional distribution, its [kinetic energy](kinetic-energy.md) production is $d\mathcal K/dt=-m\int vD(v)f'(v)\,dv$, which reduces to $mnD$ for constant $D$. Variable $D$ must remain inside the derivative.
