# Parallel transport preserves a fibre metric

↑ **Parent:** [Metric connection](metric-connection.md)

For a [metric connection](metric-connection.md) on a [vector bundle](vector-bundle.md), the [covariant derivative along a curve](covariant-derivative-along-a-curve.md) satisfies $(d/dt)\langle u,v\rangle=\langle D_tu,v\rangle+\langle u,D_tv\rangle$. If both sections are parallel, the right side vanishes. Thus [parallel transport](parallel-transport.md) preserves the fibre [inner product](inner-product.md), not merely vector lengths, and is a linear isometry between the endpoint fibres.
