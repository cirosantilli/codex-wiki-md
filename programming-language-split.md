# Programming language

↑ **Parent:** [Computer science](computer-science-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Programming_language)

A [programming language](programming-language-split.md) specifies how programs are written and what their execution means. Its [type system](type-system.md) describes which operations may be combined; an [abstract syntax tree](abstract-syntax-tree.md) records the structure on which these rules act. The examples under [type system](type-system.md) use a small teaching language with [integers](integer-split.md), Boolean values and [function types](function-type.md).
