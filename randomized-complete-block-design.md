# Randomized complete block design

↑ **Parent:** [Block design](block-design.md)

A [randomized complete block design](randomized-complete-block-design.md) places every [treatment](treatment.md) in every block, with a common replication pattern, and uses independent within-block [randomization](randomization.md). The usual basic version has one occurrence of each [treatment](treatment.md) per block; equal repeated occurrences give a replicated complete-block version. Such equal-proportion designs are [orthogonal block designs](orthogonal-block-design.md).
