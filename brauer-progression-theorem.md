# Brauer progression theorem

↑ **Parent:** [Van der Waerden theorem](van-der-waerden-theorem.md)

For [positive integers](positive-integer.md) $k,s,\ell$, some $N$ ensures that every $k$-color [finite coloring](finite-coloring.md) of $[N]$ contains a [monochromatic](monochromatic-set.md) set

$$
\{sd,a,a+d,\ldots,a+(\ell-1)d\},\qquad a,d>0.
$$

It follows from the [Van der Waerden theorem](van-der-waerden-theorem.md) by [mathematical induction](mathematical-induction.md) on the number of colors. If $M$ is a bound for $k-1$ colors, take a long one-color [arithmetic progression](arithmetic-progression.md) of length $(\ell-1)M+1$ and step $d$. Either one of $sd,2sd,\ldots,Msd$ has its color, giving the result immediately, or these multiples use only $k-1$ colors. Pull back their [finite coloring](finite-coloring.md) to $[M]$ and use [mathematical induction](mathematical-induction.md), then multiply the resulting configuration by $sd$. Enlarge the ambient finite [integer interval](integer-interval.md) to include all these multiples. The cases $k=1$ and $\ell=1$ are immediate. The parameter $s$ makes this useful for positive [monochromatic](monochromatic-set.md) solutions of a [partition regular equation](partition-regular-equation.md) with arbitrary [integer](integer.md) coefficients.
