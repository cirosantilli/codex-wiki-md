# Prefix function

↑ **Parent:** [String-searching algorithm](string-searching-algorithm.md)

For a string $s$, the value $\pi_i$ is the length of the longest proper prefix of $s_0\cdots s_i$ that is also its suffix. Repeatedly following these lengths lists all proper [borders of a string](border-of-a-string.md); this is the failure-link information used by the [Knuth-Morris-Pratt algorithm](knuth-morris-pratt-algorithm.md).
