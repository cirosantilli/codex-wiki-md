# Second-preimage resistance

↑ **Parent:** [Cryptographic hash function](cryptographic-hash-function.md)

Given a particular input $x$, finding a different input $x'$ with the same digest should be computationally infeasible. [Preimage resistance](preimage-resistance.md) asks for any input matching a given digest; [collision resistance](collision-resistance.md) allows choosing both colliding inputs. These are different security requirements.
