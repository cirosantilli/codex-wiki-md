# Measurement error and observed heritability

↑ **Parent:** [Heritability](heritability.md)

If observed variation is true-score variation $V_T$ plus independent [measurement error](measurement-error.md) $V_\epsilon$, and genetic [variance](variance-split.md) $V_G$ is part of $V_T$, then $h^2_{\mathrm{obs}}=V_G/(V_T+V_\epsilon)$. Writing [measurement reliability](measurement-reliability.md) as $q=V_T/(V_T+V_\epsilon)$ gives the displayed identity. Removing independent error can raise the [heritability](heritability.md) estimate without changing the genetic contribution to the true score. The result requires this measurement model; it does not identify [measurement reliability](measurement-reliability.md) by dividing arbitrary estimates from different longitudinal models.
