# Principal square root in a commutative Banach algebra

↑ **Parent:** [Holomorphic functional calculus](holomorphic-functional-calculus.md)

If the [spectrum of an element](spectrum-of-an-element.md) $x$ lies in the open right half-plane, [holomorphic functional calculus](holomorphic-functional-calculus.md) gives the displayed square root with spectrum in that half-plane. It is unique there. Two such roots $y,v$ have character values equal to the unique scalar square root with positive real part. Every [character of an algebra](character-of-an-algebra.md) is therefore nonzero on $y+v$, so the character description of the spectrum makes $y+v$ invertible. From $(y-v)(y+v)=0$ one obtains $y=v$. Equal character values alone do not prove equality in a possibly nonsemisimple algebra.
