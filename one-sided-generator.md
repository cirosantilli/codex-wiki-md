# One-sided generator

↑ **Parent:** [Generating measurable partition](generating-measurable-partition.md)

A one-sided generator is a [measurable partition](measurable-partition.md) $\xi$ with $\sigma(\bigvee_{j\ge0}T^{-j}\xi)=\mathcal B$ modulo null sets. Equivalently, every measurable set can be approximated in measure by unions of atoms of finite forward-name blocks. A one-sided coordinate partition generates a one-sided [Bernoulli shift](bernoulli-shift.md); for a nontrivial base distribution, it does not generate the two-sided version, whose negative coordinates are independent of the nonnegative ones.
