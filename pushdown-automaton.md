# Pushdown automaton

↑ **Parent:** [Formal language theory](formal-language-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pushdown_automaton)

A finite control equipped with an unbounded [stack](stack-data-structure.md). A move reads one input symbol or the [empty word](empty-word.md), examines the top [stack](stack-data-structure.md) symbol, changes control state and replaces that top by a finite [word](string.md) over the [stack alphabet](stack-alphabet.md). Nondeterministic choices give finitely many possible moves. With [acceptance by final state](acceptance-by-final-state.md) and the entire input consumed, [pushdown automata](pushdown-automaton.md) recognize exactly the [context-free languages](context-free-language.md).
