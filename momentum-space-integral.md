# Momentum-space integral

↑ **Parent:** [Momentum space](momentum-space.md)

An [integral](integral-split.md) over [momentum space](momentum-space.md). For example, state counting in $d$ spatial dimensions uses a measure proportional to $d^dp/(2\pi\hbar)^d$, whereas a relativistic [Feynman integral](feynman-integral.md) commonly uses $d^dp/(2\pi)^d$ in [natural units](natural-units.md). The convention and any regulator must be specified. Independent [loop momenta](loop-momentum.md) supply separate integration variables in a loop [Feynman diagram](feynman-diagram.md); [ultraviolet divergences](ultraviolet-divergence.md) and [infrared divergences](infrared-divergence.md) can require different regularizations.
