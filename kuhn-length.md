# Kuhn length

↑ **Parent:** [Worm-like chain](worm-like-chain.md)

The [Kuhn length](kuhn-length.md) is the link length of an equivalent long [ideal chain](ideal-chain.md) with the same contour length and mean squared end-to-end distance. A three-dimensional [worm-like chain](worm-like-chain.md) satisfies $\langle R^2\rangle\sim2l_pL$ for $L\gg l_p$, hence $b_K=2l_p$.
