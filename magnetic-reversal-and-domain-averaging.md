# Magnetic reversal and domain averaging

↑ **Parent:** [Saturated isotropic magnetostrictive strain](saturated-isotropic-magnetostrictive-strain.md)

A full $180^\circ$ reversal leaves [saturated isotropic magnetostrictive strain](saturated-isotropic-magnetostrictive-strain.md) unchanged. A $90^\circ$ rotation generally changes it. In the simplest unconstrained orientation average over [magnetic domains](magnetic-domain.md), replace $m_i m_j$ by $\langle m_i m_j\rangle$, not by $\langle m_i\rangle\langle m_j\rangle$. Equal populations pointing along $+z$ and $-z$ have zero net [magnetization](magnetization.md) but the same preferred [strain](strain.md) as a single domain along $z$. An isotropic orientation distribution instead has $\langle m_i m_j\rangle=\delta_{ij}/3$ and zero average preferred [strain](strain.md). Elastic compatibility between real [magnetic domains](magnetic-domain.md) can modify the macroscopic response.

Reversing an applied [magnetic field](magnetic-field-split.md) does not guarantee that all microscopic orientations retrace the same path. [Hysteresis](hysteresis.md), [magnetic domain-wall pinning](magnetic-domain-wall-pinning.md), and changes in domain populations can alter the measured curve. The reversal identity concerns the same pair of magnetic states with opposite local [magnetization](magnetization.md); it is not a universal prediction that an arbitrary experimental sweep is a single-valued even function of applied [magnetic field](magnetic-field-split.md).
