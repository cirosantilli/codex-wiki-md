# Plasma parameter

↑ **Parent:** [Plasma (physics)](plasma-physics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Plasma_parameter)

The number of electrons in a [Debye sphere](debye-sphere.md), here $N_D=(4\pi/3)n_e\lambda_D^3$. A large value characterizes weak fluctuations and weak coupling in the ordinary collective-screening regime.
