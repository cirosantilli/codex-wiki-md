# Odd map between spheres

↑ **Parent:** [Antipodal map](antipodal-map.md)

An odd map between [spheres](sphere.md) is a [continuous map](continuous-map.md) $f:S^n\to S^m$ satisfying $f(-x)=-f(x)$. Thus it is equivariant for the two [antipodal maps](antipodal-map.md). It descends to a [continuous map](continuous-map.md) of [Real projective spaces](real-projective-space.md).
