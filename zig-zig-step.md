# Zig-zig step

↑ **Parent:** [Splaying](splaying.md)

When a node and its parent are both left children, first apply a right [tree rotation](tree-rotation.md) to the grandparent, moving the parent upward, and then another right [tree rotation](tree-rotation.md) moving the selected node upward. Use the left-right mirror image when both are right children. The order of these two [tree rotations](tree-rotation.md) distinguishes the operation from repeatedly rotating only the selected node.
