# Credit-linked note

↑ **Parent:** [Credit derivative](credit-derivative.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Credit-linked_note)

A funded note whose coupons or principal depend on specified credit events of a reference entity or [portfolio](investment-portfolio.md). In a simple structure, the investor supplies principal and receives enhanced coupon for economically selling credit protection; a reference [default](credit-default.md) reduces principal repayment. The investor may also face the note issuer's own [credit risk](credit-risk.md). This is not automatically the same exposure as directly holding the reference borrower's bond.
