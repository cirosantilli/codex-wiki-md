# Old covariant string quantization

↑ **Parent:** [Covariant quantization of the bosonic string](covariant-quantization-of-the-bosonic-string.md)

Old covariant quantization retains all target-space [string oscillators](string-oscillator.md) and imposes $(L_0-a)|\psi\rangle=0$ and $L_n|\psi\rangle=0$ for $n>0$. Negative-mode constraints are adjoints, not further annihilation conditions. Quotienting physical [null string states](null-string-state.md) removes redundant polarizations.
