# Resistivity tensor

↑ **Parent:** [Electrical resistivity](electrical-resistivity.md)

The [resistivity tensor](resistivity-tensor.md) is the matrix relating [electric field](electric-field-split.md) to [current density](current-density.md) in linear local transport. It is the [matrix inverse](matrix-inverse-split.md) of the [conductivity tensor](conductivity-tensor.md), not the componentwise reciprocal. A Hall response produces antisymmetric off-diagonal components. In a multicarrier system, the conductivities add because each species sees the same electric field; invert only after summing the species' conductivity tensors.
