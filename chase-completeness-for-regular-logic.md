# Chase completeness for regular logic

↑ **Parent:** [Regular theory](regular-theory.md)

Classically, a [regular formula](regular-formula.md) sequent that is not provable has a set-valued countermodel, with empty sorts allowed. Start with the finite diagram of its antecedent, successively adjoin witnesses to the existential consequences of each axiom, and identify elements when equality axioms require it. Every new fact about the original parameters has a finite derivation, so the nonderivable consequent remains false. The filtered union of this witness construction is a model. The conservativity property of this chase construction is studied in [Forssell and Lumsdaine's paper](https://arxiv.org/abs/1604.03851).
