# Singleton object

↑ **Parent:** [Software object](software-object.md)

A named [software object](software-object.md) instantiated once in the scope of its definition. A top-level [Scala](scala.md) `object` can implement the [singleton pattern](singleton-pattern.md). Nested object definitions can have different instances for different enclosing instances, so the relevant scope matters.
