# Simply laced root system

↑ **Parent:** [Dynkin diagram](dynkin-diagram.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Simply_laced_root_system)

An irreducible root system is simply laced when all roots have the same length, equivalently when its [Dynkin diagram](dynkin-diagram.md) has only single edges. This is also equivalent to

$$
\langle\alpha,\beta^\vee\rangle\in\{0,\pm1\}
$$

whenever $\alpha\ne\pm\beta$.
