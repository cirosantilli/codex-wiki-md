# Causal state filtering

↑ **Parent:** [State estimation](state-estimation.md)

[Causal state filtering](causal-state-filtering.md) estimates the current state of a [dynamical system](dynamical-system.md) from observations up to the current time. Under [quadratic loss](squared-error-loss.md), the [conditional expectation](conditional-expectation.md) is an optimal estimate. A [Kalman filter](kalman-filter.md) obtains this estimate recursively for a linear [Gaussian](normal-distribution.md) [state-space model](state-space-model-time-series.md), without using future observations.
