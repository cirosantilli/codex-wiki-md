# Carbinolamine

↑ **Parent:** [Chemical substance](chemical-substance-split.md)

A carbinolamine has an [amino group](amino-group.md) and a [hydroxy group](hydroxy-group.md) on the same [carbon](carbon.md). It can occur between [carbonyl group](carbonyl-group.md) addition and [iminium ion](iminium.md) formation.
