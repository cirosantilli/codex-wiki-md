# Action schema

↑ **Parent:** [STRIPS](strips.md)

A parameterized action definition with typed parameters, [preconditions](precondition.md), add effects and delete effects. Replacing its parameters by type-correct objects yields a [ground action](ground-action.md). Type restrictions and static inequalities can remove invalid instantiations before the action is considered by a [search algorithm](search-algorithm.md) or [SATPlan](satplan.md).
