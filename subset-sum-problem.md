# Subset sum problem

↑ **Parent:** [NP-completeness](np-completeness.md)

Given finitely encoded nonnegative integers $s_i$ and target $t$, the subset sum problem asks whether some subset sums to $t$. Taking equal item weights and profits reduces it to testing whether a [0-1 knapsack problem](0-1-knapsack-problem.md) with capacity $t$ attains value $t$.
