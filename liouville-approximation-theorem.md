# Liouville approximation theorem

↑ **Parent:** [Diophantine approximation](diophantine-approximation.md)

If an irrational algebraic number has degree $d$, then $|\alpha-p/q|>C(\alpha)q^{-d}$. Approximations of arbitrarily larger polynomial order therefore prove that a [Liouville number](liouville-number.md) is transcendental.
