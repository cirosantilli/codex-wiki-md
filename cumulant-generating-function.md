# Cumulant-generating function

↑ **Parent:** [Moment-generating function](moment-generating-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cumulant-generating_function)

The cumulant-generating function is $\psi_X(\theta)=\log\mathbb E e^{\theta X}$, interpreted as an extended-real [convex function](convex-function.md) where the exponential moment may be infinite.
