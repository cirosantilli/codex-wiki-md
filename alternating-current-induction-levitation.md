# Alternating-current induction levitation

↑ **Parent:** [Mutual inductance](mutual-inductance.md)

A resistive loop with [self-inductance](self-inductance.md) $L_r$ coupled by [mutual inductance](mutual-inductance.md) $M(z)$ to an imposed [alternating current](alternating-current.md) obeys $L_r\dot I_r+RI_r=-M\dot I_s$. For $I_s=I_0\cos\omega t$, averaging the magnetic [force](force-split.md) $I_sI_rM'(z)$ gives $-I_0^2\omega^2ML_rM'/[2(R^2+\omega^2L_r^2)]$. It is repulsive where $MM'<0$. The [self-inductance](self-inductance.md) supplies the current component opposite to the source current; a purely resistive, zero-inductance loop has zero average force in this model.
