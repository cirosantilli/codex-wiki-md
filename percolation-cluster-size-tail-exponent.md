# Percolation cluster-size tail exponent

↑ **Parent:** [Percolation critical exponents](percolation-critical-exponents.md)

The exponent $\delta$ describes the tail of the critical cluster seen from a specified [vertex of a graph](vertex-graph-theory.md). If the expected number of size-$s$ clusters per site scales as $s^{-\tau}$, weighting by cluster size gives $1/\delta=\tau-2$ when these scaling laws hold.
