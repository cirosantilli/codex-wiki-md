# Survival data

↑ **Parent:** [Survival analysis](survival-analysis-split.md)

[Survival data](survival-data.md) describe the time $T$ from a specified origin to an event, together with [covariates](covariate.md) and the observation mechanism. Under [right censoring](right-censoring.md), the observed exit time is $Y=\min(T,C)$ and the event indicator is $\delta=\mathbf1_{\{T\le C\}}$. With [left truncation](left-truncation.md), an entry time $E$ is also recorded and subjects are observed only if $T>E$. Recording the time origin, entry, exit and event indicator is essential for constructing valid [risk sets](risk-set.md).
