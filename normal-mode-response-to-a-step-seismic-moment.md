# Normal-mode response to a step seismic moment

↑ **Parent:** [Seismic moment tensor](seismic-moment-tensor.md)

For mass-normalized [normal modes](normal-mode.md), an instantaneous step in a point [seismic moment tensor](seismic-moment-tensor.md) excites mode $\alpha$ with $C_\alpha=\mathbf M:\mathbf e_\alpha^*(\mathbf x_s)$ and $\tau=t-t_s$. Convolving the causal oscillator [Green's function](green-s-function-split.md) with the step gives $a_\alpha=C_\alpha[1-\cos(\omega_\alpha\tau)]H(\tau)/\omega_\alpha^2$. The expression contains a static response and undamped oscillations; attenuation requires an extension of the conservative model.
