# Zero flag

↑ **Parent:** [Processor condition flag](processor-condition-flag.md)

A [processor condition flag](processor-condition-flag.md) set when the relevant result is zero. A loop that decrements its remaining count and immediately branches on nonzero uses this flag as its termination test. A preceding logical shift's zero result is a different condition.
