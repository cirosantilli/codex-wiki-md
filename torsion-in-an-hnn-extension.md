# Torsion in an HNN extension

↑ **Parent:** [HNN extension](hnn-extension.md)

Every finite-order element of an [HNN extension](hnn-extension.md) is conjugate to a finite-order element of its base. Choose a conjugate minimizing the number of [stable letters](stable-letter.md). If this number is positive, no pinch is possible either internally or across the end-to-start join, since a boundary pinch would allow a conjugation shortening it. Every positive power is then reduced with positive stable-letter length, and [Britton's lemma](britton-s-lemma.md) makes it nonidentity. In particular, an HNN extension of a [torsion-free group](torsion-free-group.md) is torsion-free.
