# System noise temperature

↑ **Parent:** [Noise temperature](noise-temperature.md)

The [system noise temperature](system-noise-temperature.md) includes all noise contributions referred to a specified receiver input. In a simple additive model with negligible intervening losses, $T_{\rm sys}=T_A+T_r$, where $T_A$ is the [antenna temperature](antenna-temperature.md) and $T_r$ the [receiver noise temperature](receiver-noise-temperature.md).
