# Separate continuity

↑ **Parent:** [Continuous map](continuous-map.md)

A [function](function-split.md) of several variables is [separately continuous](separate-continuity.md) when it is [continuous](continuous-function.md) in each variable with the others fixed. This is weaker than joint [continuity](continuous-function.md) in the [product topology](product-topology.md). [Functions](function-split.md) with narrow rectangular supports provide useful examples distinguishing [convergence](convergence.md) in [topologies](topology-split.md) generated by [separate continuity](separate-continuity.md) from Euclidean [convergence](convergence.md).
