# Direct image from an open restriction

↑ **Parent:** [Direct image sheaf](direct-image-sheaf.md)

For an open inclusion $j:U\hookrightarrow X$, this [sheaf](sheaf-mathematics.md) has sections $\mathcal F(V\cap U)$ on an open set $V$. Restriction defines $\mathcal F\to{}_U\mathcal F$. Its [stalks](stalk-of-a-sheaf.md) outside $U$ may be nonzero, so it differs from [extension by zero](extension-by-zero.md).
