# Ordinal rank of a Goodstein term

↑ **Parent:** [Goodstein sequence](goodstein-sequence.md)

Replacing every base occurrence by omega in a [hereditary base representation](hereditary-base-representation.md) gives a [Cantor normal form](cantor-normal-form.md) below [epsilon zero](epsilon-zero.md). Hereditary base change preserves this [ordinal](ordinal.md) expression, and subtraction of one lowers it strictly. The [ordinal](ordinal.md) is a termination measure even when the natural-number value increases.
