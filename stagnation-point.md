# Stagnation point

↑ **Parent:** [Fluid mechanics](fluid-mechanics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Stagnation_point)

A stagnation point of a fluid flow is a point at which the [velocity field](velocity-field.md) vanishes. For a two-dimensional [streamfunction](streamfunction-in-polar-coordinates.md), it is a critical point satisfying both first spatial derivatives of the streamfunction equal to zero.
