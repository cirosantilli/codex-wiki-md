# Covariant quantization of the bosonic string

↑ **Parent:** [Bosonic string theory](bosonic-string-theory.md)

Covariant quantization keeps target-spacetime Lorentz covariance manifest, imposes canonical commutation relations on every embedding coordinate and removes unphysical states with the [Virasoro constraints](virasoro-constraint.md).
