# Piola identity

↑ **Parent:** [Deformation gradient](deformation-gradient.md)

For a twice continuously differentiable [deformation map](deformation-map.md), each row of its [cofactor matrix](cofactor-matrix.md) has zero [divergence](divergence.md) in reference coordinates. In three dimensions write $(\operatorname{cof}Dy)_{iA}=\frac12\varepsilon_{ijk}\varepsilon_{ABC}y_{j,B}y_{k,C}$. Applying $\partial_A$ gives terms in which a symmetric pair of second [partial derivatives](partial-derivative.md) contracts with an antisymmetric [Levi-Civita symbol](levi-civita-symbol.md), so each term vanishes. This identity is the cancellation that makes the [Piola-Kirchhoff stress tensor](piola-kirchhoff-stress-tensors.md) transform force balance correctly between configurations.
