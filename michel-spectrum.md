# Michel spectrum

↑ **Parent:** [Muon decay](muon-decay.md)

For an unpolarized parent [charged lepton](charged-lepton.md) undergoing a three-body leptonic [V-A interaction](v-a-interaction.md) decay, neglecting daughter [masses](mass.md) and radiative corrections, the normalized charged-daughter [energy](energy-split.md) distribution in the parent rest frame is $f(x)=2x^2(3-2x)$, where $x=2E_\ell^*/m_{\rm parent}$ lies in $[0,1]$. Direct integration gives $\int_0^1f(x)\,dx=1$ and $\int_0^1xf(x)\,dx=7/10$. A specified parent [spin](spin.md) orientation also produces angular terms, so this one-variable law alone does not describe polarized samples.
