# Lava estimator

↑ **Parent:** [Lasso](lasso.md)

The Lava estimator minimizes $\|Y-X(\delta+\beta)\|_2^2/(2n)+\lambda_1\|\delta\|_1+\lambda_2\|\beta\|_2^2$. It combines a component selected by [Lasso](lasso.md) with a component shrunk by [ridge regression](ridge-regression.md). Profiling the latter yields a transformed [Lasso](lasso.md) problem; this is not the same coefficient penalty as [elastic net regularization](elastic-net-regularization.md).
