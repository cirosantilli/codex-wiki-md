# Reduced residue system

↑ **Parent:** [Modular congruence](modular-congruence.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reduced_residue_system)

For a positive modulus $n$, a reduced residue system contains exactly one representative of each [residue class](residue-class.md) coprime to $n$. Its size is the [Euler totient function](euler-totient-function.md) $\varphi(n)$. Multiplication by any [unit modulo n](unit-modulo-n.md) permutes these classes, which proves the [Fermat-Euler theorem](euler-s-theorem.md) after multiplying and cancelling their unit product.
