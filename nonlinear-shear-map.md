# Nonlinear shear map

↑ **Parent:** [Area-preserving map](area-preserving-map.md)

This triangular planar map has diagonal [Jacobian matrix](jacobian-matrix.md) entries one and [determinant](determinant.md) one, for [differentiable](differentiable-function.md) $f$. Its inverse subtracts $f(v)$, so it is an [area-preserving map](area-preserving-map.md). The analogous vertical map $(u,v)\mapsto(u,v+g(u))$ has the same property. Their composition preserves area even when the shifts are nonlinear, as in the logarithmic [area-preserving seasonal predator-prey map](area-preserving-seasonal-predator-prey-map.md).
