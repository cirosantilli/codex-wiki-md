# Helium-3 B phase

↑ **Parent:** [Helium-3 pair order parameter](helium-3-pair-order-parameter.md)

Take a proper [rotation matrix](rotation-matrix.md) $R$ with [real number](real-number.md) entries. Then $\mathbf d_B=\Delta R\widehat{\mathbf k}$ has

$$
|\mathbf d_B|^2=\Delta^2\widehat{\mathbf k}^{\,T}R^TR\widehat{\mathbf k}=\Delta^2.
$$

This odd linear orbital model has an isotropic gap magnitude. Isotropic gap magnitude does not require s-wave pairing: the spin components can rotate together with the orbital direction. Nor does the magnitude fix the relative spin-orbit orientation represented by $R$.

For both displayed models, $\mathbf d\times\mathbf d^*=0$. The triplet gap [matrix](matrix.md) $\widehat\Delta=(\mathbf d\cdot\boldsymbol\sigma)i\sigma_y$, written with [Pauli matrices](pauli-matrices.md), satisfies

$$
\widehat\Delta\widehat\Delta^\dagger
=(\mathbf d\cdot\mathbf d^*)I+i(\mathbf d\times\mathbf d^*)\cdot\boldsymbol\sigma
=|\mathbf d|^2 I.
$$

Thus these models give the same gap magnitude for the two [spin](spin.md) branches. That last simplification would fail for a general complex triplet vector with a nonzero cross product. The displayed angular curves illustrate these specified matrices; they are not a microscopic derivation of the phase diagram.
