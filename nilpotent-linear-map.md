↑ **Parent:** [Operator theory](linear-operator-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Nilpotent_linear_map)

A [linear map](linear-map.md) $T:V\to V$ is nilpotent if $T^k=0$ for some [positive integer](positive-integer.md) $k$.
