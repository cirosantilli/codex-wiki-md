# Linear and second-order response of the differential pom-pom model

↑ **Parent:** [Differential pom-pom model](differential-pom-pom-model.md)

Linearizing the [differential pom-pom model](differential-pom-pom-model.md) about its relaxed state leaves no first-order stretch perturbation in [incompressible flow](incompressible-flow.md). Its anisotropic orientation obeys $\dot a+a/\tau_1=A_1$, producing the displayed [relaxation modulus](relaxation-modulus.md). In a slow-flow expansion, $A=I+\tau_1A_1+\tau_1^2(2A_1^2-A_2)+O(3)$. Trace normalization and the first stretch correction affect only isotropic [stress](stress.md) at this order, giving the displayed [second-order fluid](second-order-fluid.md) coefficients. Linear small-amplitude response allows arbitrary frequency, whereas this local second-order expansion also requires slow time dependence.
