# Berggren tree

↑ **Parent:** [Pythagorean triple](pythagorean-triple.md)

A rooted ternary tree that generates every primitive [Pythagorean triple](pythagorean-triple.md) from $(3,4,5)$ by three fixed linear transformations. Keeping a consistent leg convention gives each primitive triple once; multiplying its sides then supplies all nonprimitive triples.
