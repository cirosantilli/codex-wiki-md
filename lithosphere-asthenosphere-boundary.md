# Lithosphere-asthenosphere boundary

↑ **Parent:** [Lithosphere](lithosphere.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Lithosphere–asthenosphere_boundary)

The transition between strong [lithosphere](lithosphere.md) and weak [asthenosphere](asthenosphere.md). A thermal definition uses the [temperature](temperature-split.md) structure; a mechanical definition uses long-term strength or [viscosity](dynamic-viscosity-split.md); a seismic definition uses wave properties. These depths need not coincide. Neither the [Moho](mohorovicic-discontinuity.md) nor every sharp upper-mantle reflector is necessarily a [lithosphere-asthenosphere boundary](lithosphere-asthenosphere-boundary.md).
