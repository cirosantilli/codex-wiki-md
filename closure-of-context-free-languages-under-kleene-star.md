# Closure of context-free languages under Kleene star

↑ **Parent:** [Context-free language](context-free-language.md)

If a [context-free grammar](context-free-grammar.md) for $L$ has start symbol $S$, adjoining a new start symbol $S_0$ and productions $S_0\to\epsilon\mid SS_0$ gives a context-free grammar for the [Kleene star](kleene-star.md) $L^*$.
