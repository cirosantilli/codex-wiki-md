# Cycle class

↑ **Parent:** [Cycle class map](cycle-class-map.md)

The cycle class of an [algebraic cycle](algebraic-cycle.md) is its image under the [cycle class map](cycle-class-map.md). For a codimension-$r$ cycle on a smooth complex projective variety, it belongs to $H^{2r}(X,\mathbb Z)$ and is the [Poincare dual](poincare-dual.md) of its fundamental homology class. The map factors through the [Chow group](chow-group.md), but a [Chow class](chow-class.md) retains finer information than its cohomological cycle class.
