# Affine solution space

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

If a [linear system](system-of-linear-equations.md) $Ax=b$ has one solution $x_0$, every other solution differs from it by an element of the [null space](kernel-of-a-linear-map-split.md): $Ax=b$ is equivalent to $A(x-x_0)=0$. Its solution set is therefore the displayed [affine subspace](affine-subspace.md), of dimension equal to the [nullity](nullity-of-a-linear-map.md). If the system is inconsistent, the solution set is empty, rather than a translate of the kernel.
