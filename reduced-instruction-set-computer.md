# Reduced instruction set computer

↑ **Parent:** [Computer science](computer-science-split.md)

A processor design using a relatively regular instruction repertoire and explicit restrictions on operand forms. Immediate constants may have limited encodings, so extracting low [bits](bit.md) with two [bit shifts](bit-shift.md) can avoid constructing a large [bit mask](bit-mask.md) in a temporary [processor register](processor-register.md). The benefit depends on the actual instruction set. A compact example appears in the [Thumb 16-bit instruction set quick reference by Arm](thumb-16-bit-instruction-set-quick-reference-by-arm.md), whose logical [bitwise AND](bitwise-and.md) instruction uses a [processor register](processor-register.md) operand while shifts accept small immediate counts.
