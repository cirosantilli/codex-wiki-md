# C programming language

↑ **Parent:** [Programming language](programming-language-split.md)

A systems [programming language](programming-language-split.md) supporting explicit memory access, [arrays](array-data-structure.md), and implementation-dependent integer widths. Signed [integer overflow](integer-overflow.md) is not generally specified as modular arithmetic; correctness arguments must state the relevant range assumptions.
