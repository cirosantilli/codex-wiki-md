# Fragment redistribution function

↑ **Parent:** [Collisional cascade](collisional-cascade.md)

This function specifies the fraction of disrupted mass assigned to each fragment size interval. A self-similar law depends on fragment-to-parent size ratios, rather than an absolute size. In logarithmic bins its translation invariance gives the constant processed [mass flux](mass-flux.md) of the interior steady [collisional cascade](collisional-cascade.md). In a removal-dominated interval, it instead sets the fragment source spectrum.
