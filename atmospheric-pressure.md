# Atmospheric pressure

↑ **Parent:** [Pressure](pressure-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Atmospheric_pressure)

[Atmospheric pressure](atmospheric-pressure.md) often provides the reference for a [gauge pressure](gauge-pressure.md) measurement: $p_g=p_{\rm abs}-p_{\rm atm}$. The absolute [pressure](pressure-split.md) is measured relative to an ideal [vacuum](vacuum.md), whereas zero [gauge pressure](gauge-pressure.md) means equality to the chosen reference. The actual [atmospheric pressure](atmospheric-pressure.md) can vary; it must be specified when converting between these descriptions. [OpenStax: atmospheric, gauge and absolute pressure](university-physics-volume-1-by-william-moebs-and-others.md).
