# Piecewise continuous function

↑ **Parent:** [Analysis](analysis-split.md)

A [function](function-split.md) is piecewise continuous on a finite [interval](interval-mathematics.md) if it is [continuous](continuous-function.md) between finitely many breakpoints and has finite [one-sided limits](one-sided-limit.md) at those points and at the endpoints. On $[0,\infty)$, require this on every finite [interval](interval-mathematics.md). A [Heaviside step function](heaviside-step-function.md) is an example; a [function](function-split.md) with an infinite blow-up at an interior point is not. This condition guarantees local [integrability](integrability.md) while allowing jumps in an input.
