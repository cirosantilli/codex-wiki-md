# Last nonzero digit coloring

↑ **Parent:** [P-adic columns lemma](p-adic-columns-lemma.md)

For a [prime number](prime-number.md) $p$, write a positive integer as $x=p^{v_p(x)}u$ with $p\nmid u$. Its last nonzero base-$p$ digit is $u\bmod p$, an element of $\{1,\ldots,p-1\}$. Assigning this digit as the color gives the last nonzero digit coloring used in the necessity proof of [Rado's theorem](rado-s-theorem.md).
