# Metric tensor

↑ **Parent:** [General relativity](general-relativity-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Metric_tensor)

A metric tensor is a [nondegenerate](nondegenerate-bilinear-form.md) symmetric [covariant tensor](covariant-tensor.md) that defines squared line elements by $ds^2=g_{\mu\nu}dx^\mu dx^\nu$.
