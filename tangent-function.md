# Tangent function

↑ **Parent:** [Trigonometric function](trigonometric-function.md)

A [trigonometric function](trigonometric-function.md) defined where $\cos x\ne0$. It has real [simple poles](simple-pole.md) at $(n+1/2)\pi$, and $\tan((n+1/2)\pi+\delta)=-\cot\delta$. This local pole identity generates the [large roots near tangent poles](large-roots-near-tangent-poles.md).
