# Dictionary intersection

↑ **Parent:** [Binary search tree](binary-search-tree.md)

For partial maps $D_1,D_2$, retain exactly entries $(k,v)$ for which both maps define the same value $v$ at $k$. Merely sharing a key is insufficient. Traverse one [binary search tree](binary-search-tree.md), look up each key in the other, and insert only equal-value matches into the result.
