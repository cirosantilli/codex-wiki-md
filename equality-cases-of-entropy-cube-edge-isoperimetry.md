# Equality cases of entropy cube edge-isoperimetry

↑ **Parent:** [Entropy proof of cube edge-isoperimetry](entropy-proof-of-cube-edge-isoperimetry.md)

For a nonempty subset of a [hypercube graph](hypercube-graph.md), split it into sections of sizes $a,b$. The proof of the entropy edge bound uses $H_2(t)\ge2t$, $t=\min(a,b)/(a+b)$. Strict concavity makes equality possible only at $t=0$ or $t=1/2$. In the first case one section is empty; in the second the sections coincide, since all possible crossing [edges](edge-of-a-graph.md) must be present. Induction forces a [coordinate subcube](face-of-the-boolean-hypercube.md). Conversely every [coordinate subcube](face-of-the-boolean-hypercube.md) has the displayed edge count. At size $2^{n-1}$ these are exactly the two halves determined by fixing one coordinate.
