# CheW

↑ **Parent:** [Chemotaxis feedback proteins](chemotaxis-feedback-proteins.md)

[CheW](chew.md) is a coupling protein linking chemotaxis receptor arrays to CheA-associated signalling complexes. Removing it from a reconstituted system can test its functional requirement, while a physical-interface assay addresses direct contacts.
