# Integer linear combination

↑ **Parent:** [Linear combination](linear-combination.md)

An integer linear combination is a [linear combination](linear-combination.md) whose coefficients are [integers](integer-split.md). The [lattice basis](basis-of-a-toric-lattice.md) definition uses unique [integer linear combinations](integer-linear-combination.md), rather than arbitrary real coefficients. For example, $(1,0)$ is a real [linear combination](linear-combination.md) of $(2,0)$ but is not an [integer linear combination](integer-linear-combination.md) of that single [vector](vector.md).
