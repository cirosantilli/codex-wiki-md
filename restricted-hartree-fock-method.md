# Restricted Hartree-Fock method

↑ **Parent:** [Hartree-Fock method](hartree-fock-method.md)

A Hartree-Fock ansatz in which opposite-spin [electrons](electron.md) in a doubly occupied orbital share the same spatial function. The closed-shell [determinant](determinant.md) is spin-pure but can dissociate incorrectly when a bond requires several [determinants](determinant.md).
