# Carry flag

↑ **Parent:** [Processor register](processor-register.md)

A processor status [bit](bit.md) recording [arithmetic carry](carry-arithmetic.md). For unsigned addition of $n$-bit inputs, $X+Y=Z+2^nC$, where $Z$ is the stored result. In the [ARM architecture family](arm-architecture-family.md), subtraction instead uses $X-Y=Z-2^n(1-C)$, so a set [arithmetic carry](carry-arithmetic.md) means no borrow. This convention must be checked for the target instruction set; it is not a signed-overflow test.
