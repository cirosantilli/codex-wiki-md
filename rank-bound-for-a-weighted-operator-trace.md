# Rank bound for a weighted operator trace

↑ **Parent:** [Hilbert-Schmidt inner product](hilbert-schmidt-inner-product.md)

If $\rho$ is a [density operator](density-matrix.md) with decreasing [eigenvalues](eigenvalue.md) $\lambda_j$ and $T$ has [matrix rank](matrix-rank.md) at most $k$, let $\Pi$ project onto the image of $T$. The [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) for the [Hilbert-Schmidt inner product](hilbert-schmidt-inner-product.md) gives

$$
|\operatorname{Tr}(\rho T)|^2\leq\operatorname{Tr}(\rho\Pi)\operatorname{Tr}(\rho T^\dagger T).
$$

The [Hermitian effect variational principle](hermitian-effect-variational-principle.md) bounds $\operatorname{Tr}(\rho\Pi)$ by $\sum_{j<k}\lambda_j$, proving the claimed estimate without assuming $\rho$ is invertible.
