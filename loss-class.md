# Loss class

↑ **Parent:** [Empirical risk minimization](empirical-risk-minimization.md)

Given a [hypothesis class](concept-class.md) $\mathcal H$ and a [loss function](loss-function.md) $\ell$, its loss class is the [function class](function-class.md)

$$
\mathcal F=\{z\mapsto\ell(h,z):h\in\mathcal H\}.
$$

It lets properties of a learning problem be studied through the random fluctuations of the losses themselves.
