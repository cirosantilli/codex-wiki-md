# Pure function

↑ **Parent:** [Functional programming](functional-programming.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Pure_function)

A procedure whose result depends only on its explicit argument values and which has no observable [side effects](side-effect-computer-science.md). For terminating calls with reusable results, this makes the value condition of the [memoization cache contract](memoization-cache-contract.md) particularly simple.
