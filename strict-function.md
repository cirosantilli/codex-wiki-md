# Strict function

↑ **Parent:** [Functional programming](functional-programming.md)

A [function](function-split.md) is strict in an argument if replacing that argument by the [bottom value](bottom-value.md) makes the result bottom. This semantic property does not prescribe evaluation order: a function that always diverges is strict without inspecting its argument. Strictness of a structured argument also does not mean evaluation of every component.[§6.2, Strict Evaluation](haskell-2010-language-report.md)
