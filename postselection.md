# Postselection

↑ **Parent:** [Quantum measurement](quantum-measurement-split.md)

Postselection conditions a [quantum measurement](quantum-measurement-split.md) on a specified outcome. If its branch acts by a [linear operator](linear-operator.md) $K$ on a normalized input $|b\rangle$, its [probability](probability.md) is $\|K|b\rangle\|^2$, and its normalized output is $K|b\rangle/\|K|b\rangle\|$. This conditional state is defined only when the probability is nonzero. Physically unsuccessful trials are discarded; postselection is not a deterministic implementation of the nonlinear normalization map.
