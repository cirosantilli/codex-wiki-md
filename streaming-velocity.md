# Streaming velocity

↑ **Parent:** [Galactic distribution function](galactic-distribution-function.md)

The streaming [velocity](velocity.md) is the local mean stellar [velocity](velocity.md) obtained by averaging with the [galactic distribution function](galactic-distribution-function.md). In an axisymmetric disk it usually denotes $\langle v_\phi\rangle$. It differs from the [circular speed](circular-speed.md), which is set by the [force](force.md) field, and from the [velocity dispersion](velocity-dispersion.md), which measures fluctuations about the mean.
