# Squeezed bispectrum configuration

↑ **Parent:** [Primordial bispectrum](primordial-bispectrum.md)

A [primordial bispectrum](primordial-bispectrum.md) is squeezed when one external [Fourier mode](fourier-mode.md) has much smaller [wavenumber](wavenumber.md) than the other two. Momentum conservation then makes the two short wavevectors almost opposite. This configuration measures the response of short-scale correlations to a long perturbation.
