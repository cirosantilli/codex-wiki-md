# Symbol rate

↑ **Parent:** [Computer network](computer-network-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Symbol_rate)

The [symbol rate](symbol-rate.md), measured in baud, counts signal elements per second. Its relation to [bit rate](bit-rate.md) depends on the representation and on which signal element is counted as a symbol.
