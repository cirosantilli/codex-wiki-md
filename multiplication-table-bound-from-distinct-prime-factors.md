# Multiplication table bound from distinct prime factors

↑ **Parent:** [Multiplication table problem](multiplication-table-problem.md)

Concentration of the [prime omega function](prime-omega-function.md) near $\log\log N$, together with $\omega(ab)=\omega(a)+\omega(b)-\omega(\gcd(a,b))$ and the bounded mean of $\omega(\gcd(a,b))$, gives $M(N)\ll N^2/\log\log N$. This elementary argument uses only distinct [prime factors](prime-factor.md).
