# Squeezed one-photon state

↑ **Parent:** [Squeezed vacuum state](squeezed-vacuum-state.md)

[photon addition](photon-addition.md) to an [optical squeezed vacuum](optical-squeezed-vacuum.md) gives $a^\dagger S|0\rangle=\cosh r\,S|1\rangle$; subtraction gives $aS|0\rangle=-\sinh r\,S|1\rangle$. After successful-event normalization these are the same state up to phase, with mean occupation $1+3\sinh^2r$ and odd [photon](photon.md) parity. At zero squeezing subtraction never succeeds; the normalized limiting state is not an output at that exact parameter value.
