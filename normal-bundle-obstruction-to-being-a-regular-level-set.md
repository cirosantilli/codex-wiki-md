# Normal-bundle obstruction to being a regular level set

↑ **Parent:** [Embedded submanifold](embedded-submanifold.md)

If an embedded codimension-$k$ submanifold $X\subset M$ is $f^{-1}(y)$ for a [regular value](regular-value.md) $y$ of a smooth map $f:M\to\mathbb R^k$, then $df$ identifies its [normal bundle](normal-bundle.md) with the trivial bundle $X\times\mathbb R^k$. A submanifold with nontrivial normal bundle therefore cannot be such a regular level set. The core circle of the [Möbius band](mobius-band.md) is a codimension-one example.
