# CPU burst

↑ **Parent:** [Process scheduling](process-scheduling.md)

An interval of useful [CPU](central-processing-unit.md) execution needed before a task finishes or must wait, for example for [input-output](input-output.md). A real [operating-system process](process-computing.md) can need many [CPU bursts](cpu-burst.md); the example under [process scheduling](process-scheduling.md) assigns each task just one [CPU burst](cpu-burst.md), possibly split across several turns by [round-robin scheduling](round-robin-scheduling.md).
