# Finite-interval Airy global relation

↑ **Parent:** [Global relation for a linear boundary value problem](global-relation-for-a-linear-boundary-value-problem.md)

For the [Airy equation](airy-equation.md) $q_t+q_{xxx}=0$ on $0<x<L$, define $F_j=\int_0^t e^{-ik^3s}\partial_x^jq(0,s)ds$ and $G_j$ analogously at $L$. Set $\mathcal F=k^2F_0-ikF_1-F_2$ and $\mathcal G=k^2G_0-ikG_1-G_2$. Integrating the [local relation](local-relation.md) with flux $-q_{xx}-ikq_x+k^2q$ proves the displayed [global relation](global-relation-for-a-linear-boundary-value-problem.md). The [dispersion relation](dispersion-relation.md) is invariant under multiplication of $k$ by a cube root of unity; the resulting three equations determine the three missing boundary transforms for data $q(0,t),q(L,t),q_x(L,t)$.
