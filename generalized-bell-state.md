# Generalized Bell state

↑ **Parent:** [Generalized Bell basis](generalized-bell-basis.md)

A generalized Bell state is one member of a [generalized Bell basis](generalized-bell-basis.md). Its [reduced density matrices](reduced-density-matrix.md) are both $I/n$, so it is a [maximally entangled state](maximally-entangled-state.md). For $n=2$ these are the four [Bell states](bell-state-split.md).
