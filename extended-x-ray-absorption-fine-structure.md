# Extended X-ray absorption fine structure

↑ **Parent:** [X-ray absorption fine structure](x-ray-absorption-fine-structure.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Extended_X-ray_absorption_fine_structure)

Oscillatory absorption above a core-ionization edge caused by [interference](interference-wave-propagation.md) between outgoing and neighbor-scattered [photoelectron](photoelectron.md) waves. It probes local coordination, distances and disorder. The high-energy shell expansion is distinct from the more complicated near-edge regime; phase corrections are required before interpreting Fourier-transform peaks as bond lengths.
