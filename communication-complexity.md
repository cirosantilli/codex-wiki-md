# Communication complexity

↑ **Parent:** [Computational complexity theory](computational-complexity-theory.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Communication_complexity)

Communication complexity studies how much information distributed parties must exchange to compute a function of their separately held inputs. Local computation is free; the resource being counted is communicated bits or qubits, with the allowed shared randomness, [quantum entanglement](entangled-state.md) or other correlations specified separately. For a [Boolean function](boolean-function.md) $f(x,y)$, a one-way exact protocol has the receiver output $f$ correctly for every input after a single message. [One-bit computation using Popescu–Rohrlich boxes](one-bit-computation-using-popescu-rohrlich-boxes.md) shows that this resource measure changes drastically if ideal superquantum boxes are available.
