# Fourier separation of interval cutoffs

↑ **Parent:** [Bilinear sum](bilinear-sum.md)

If $I_m$ is an integer interval inside $[1,N]$, discrete [Fourier inversion](fourier-inversion-theorem.md) gives the displayed identity. The [exponential geometric sum bound](exponential-geometric-sum-bound.md) gives a common envelope $H_N(\theta)\ll\min(N,\|\theta\|^{-1})$, whose integral is $O(\log(2N))$. At each frequency, $\widehat{1_{I_m}}(\theta)/H_N(\theta)$ is a bounded coefficient depending only on $m$, while $e(n\theta)$ depends only on $n$. A uniform bounded-coefficient [Type II sum](type-ii-sum.md) estimate therefore survives an $m$-dependent interval cutoff at a cost of one logarithm. This is particularly useful for the condition $mn\le N$.
