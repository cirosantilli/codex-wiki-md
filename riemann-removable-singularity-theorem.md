# Riemann removable singularity theorem

↑ **Parent:** [Removable singularity](removable-singularity.md)

A holomorphic function bounded on a punctured neighbourhood extends holomorphically across the puncture.

This criterion characterizes a [removable singularity](removable-singularity.md) of a holomorphic function; the criterion is a theorem about the singularity type.
