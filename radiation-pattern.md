# Radiation pattern

↑ **Parent:** [Electromagnetic radiation](electromagnetic-radiation-split.md)

A radiation pattern specifies emitted [power](power.md) per [solid angle](solid-angle.md) as a function of direction. For a slowly moving point [electric charge](electric-charge-split.md) with [acceleration](acceleration.md) $\mathbf a$, $dP/d\Omega=q^2|\mathbf n\times\mathbf a|^2/(16\pi^2\epsilon_0c^3)$. Its [integral](integral-split.md) over directions is the [Larmor formula](larmor-formula.md); its fore-aft symmetry implies zero net radiated [three-momentum](three-momentum.md) in the instantaneous rest [inertial frame](inertial-frame.md). Directional detector [power](power.md) includes the distinction between source emission time and arrival time.
