# Global Markov property for a directed acyclic graph

↑ **Parent:** [Directed acyclic graph factorization](directed-acyclic-graph-factorization.md)

A distribution has the global Markov property for a [Directed acyclic graph](directed-acyclic-graph.md) when every [D-separation](d-separation.md) of vertex sets by a conditioning set implies the corresponding [conditional independence](conditional-independence.md) of their random variables.
