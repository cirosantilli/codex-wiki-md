# Vacuous truth

↑ **Parent:** [Logical implication](logical-implication.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Vacuous_truth)

A [logical implication](logical-implication.md) holds whenever its premise is false. For [partial correctness](partial-correctness.md), an execution that never terminates supplies no final state violating the [postcondition](postcondition.md).
