# Purity decouples a subsystem from its purification

↑ **Parent:** [Purification of a density operator](purification-of-a-density-operator.md)

If subsystem $S$ has [pure state](pure-state.md) $|u\rangle\langle u|$ in a normalized joint pure vector $|\Omega\rangle_{SE}$, then $|\Omega\rangle_{SE}=|u\rangle_S\otimes|e\rangle_E$. Indeed, for an [orthonormal basis](orthonormal-basis.md) $\{v_j\}$ of $u^\perp$, each squared norm $\|(\langle v_j|\otimes I)|\Omega\rangle\|^2=\langle v_j|\rho_S|v_j\rangle$ is zero. Therefore the joint vector has no component outside $\mathbb Cu\otimes\mathcal H_E$. In particular, if Alice and Bob share a known pure [entangled state](entangled-state.md), an adversary holding a purifying system has no correlations with it. This does not make every pure bipartite state useful for key distribution: a pure [product state](product-state.md) has no shared random correlations.
