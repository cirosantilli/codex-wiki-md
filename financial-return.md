# Financial return

↑ **Parent:** [Mathematical finance](mathematical-finance-split.md)

For initial asset value $V_0>0$, final value $V_1$, and intervening cash distribution $D$, the net [financial return](financial-return.md) is $(V_1-V_0+D)/V_0$. Its gross return is $1+R=(V_1+D)/V_0$. In a one-period [portfolio](investment-portfolio.md) with initial-value weights $w_i$ summing to one, the net return is $\sum_iw_iR_i$. The [expected return](expected-return.md) is its [expected value](expected-value.md); a realized return need not equal it.
