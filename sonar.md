# Sonar

↑ **Parent:** [Acoustics](acoustics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sonar)

Sonar uses sound propagation and reflected signals to detect objects or measure distances. Upward-looking sonar can record [sea-ice draft](sea-ice-draft.md) along a moving platform's track; beam width, return selection and processing affect the inferred profile.
