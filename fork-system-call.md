# Fork (system call)

↑ **Parent:** [System call](system-call.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fork_(system_call))

A [system call](system-call.md) creating a child [operating-system process](process-computing.md) from a parent. The [Linux kernel](linux-kernel.md) documents [copy-on-write](copy-on-write.md) for ordinary inherited private [memory pages](memory-page.md), with separate [address spaces](address-space.md) but shared [open file descriptions](open-file-description.md) for inherited [file descriptors](file-descriptor.md). [fork(2) — Linux manual page](fork-2-linux-manual-page.md)
