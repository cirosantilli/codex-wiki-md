# Definable function

↑ **Parent:** [Definable set](definable-set.md)

A [function](function-split.md) $f:M^n\to M$ is a [definable function](definable-function.md) if its [graph of a function](graph-of-a-function.md) is a [definable set](definable-set.md). Equivalently, a [first-order formula](first-order-formula.md) $\theta(\mathbf x,y)$ defines exactly the pairs with $y=f(\mathbf x)$. Totality and uniqueness mean $M\models\forall\mathbf x\exists!y\,\theta(\mathbf x,y)$. The same definition with restricted domains gives definable partial functions. A function need not be a symbol of the language to be definable; the graph can be specified through the existing relations and operations.
