# Dark count

↑ **Parent:** [Single-photon detector](single-photon-detector.md)

A registered detector event occurring without an incident signal [photon](photon.md). For a [single-photon avalanche diode](single-photon-avalanche-diode.md), internally generated carriers can trigger the same avalanche as an absorbed [photon](photon.md). The dark-count rate $r_{\rm dark}$ is the mean number of these events per unit [time](time-in-physics.md) under specified operating conditions. Such events can contaminate [coincidence counting](coincidence-counting.md) and increase the [quantum bit error rate](quantum-bit-error-rate.md) in [quantum key distribution](quantum-key-distribution.md).
