# Psychotherapy

↑ **Parent:** [Clinical psychology](clinical-psychology.md)

Clinical intervention using psychological methods to address [distress](distress.md), impairment or a specified psychological difficulty. Treatment packages can include several techniques; demonstrating benefit from the package does not establish the necessity of each.
