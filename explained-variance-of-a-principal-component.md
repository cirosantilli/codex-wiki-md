# Explained variance of a principal component

↑ **Parent:** [Principal component analysis](principal-component-analysis.md)

A [population principal component](population-principal-component.md) explains the displayed fraction of total [variance](variance-split.md). The first $q$ components explain $\sum_{j\le q}\lambda_j/\sum_j\lambda_j$. Comparing covariance and correlation analyses requires different denominators: the original [variance](variance-split.md) sum for the former and the number of nonconstant standardized variables for the latter.
