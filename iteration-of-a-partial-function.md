# Iteration of a partial function

↑ **Parent:** [Iterated function](iterated-function.md)

For a [partial function](partial-function.md) $f:D\to X$ with $D\subseteq X$, its $n$th [iterated function](iterated-function.md) is defined only when each intermediate application is defined. Put $D_0=X$, $f^0=\operatorname{id}_X$, and use the displayed recursion for the [domain of a function](domain-of-a-function.md). Simplifying an algebraic expression for $f^n$ does not restore points excluded by an intermediate application. For example, $f(x)=1/x$ has $f^2(x)=x$ on $\mathbb R\setminus\{0\}$; the simplified expression $x$ has a larger natural [domain of a function](domain-of-a-function.md).
