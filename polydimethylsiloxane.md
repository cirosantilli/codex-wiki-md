# Polydimethylsiloxane

↑ **Parent:** [Silicone](silicone.md)

A flexible [silicone](silicone.md) [polymer](polymer-split.md) that can form an [elastomer](elastomer.md) when lightly crosslinked. The network's recoverable deformation provides an example of [rubber elasticity](rubber-elasticity.md).
