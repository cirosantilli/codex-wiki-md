# Weight lattice

↑ **Parent:** [Root system](root-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Weight_lattice)

The weight lattice is the set of vectors $\lambda$ for which $\langle\lambda,\alpha^\vee\rangle$ is an integer for every root $\alpha$.
