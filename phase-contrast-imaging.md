# Phase-contrast imaging

↑ **Parent:** [Physical optics](physical-optics-split.md)

[Phase-contrast imaging](phase-contrast-imaging.md) converts spatial phase changes of light into intensity differences by interference with a reference field. In an off-resonant atomic cloud, the optical phase carries information about column density. Weak probing can support repeated measurements with reduced absorption, although destructiveness still depends on detuning and probe strength.
