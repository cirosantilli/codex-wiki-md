# Alternant orthogonality on a unitary torus

↑ **Parent:** [Weyl character formula](weyl-character-formula.md)

For strictly decreasing integer tuples $\kappa,\eta$, let $A_\kappa(z)=\det(z_i^{\kappa_j})$ on the diagonal [maximal torus](maximal-torus.md) of the [unitary group](unitary-group.md). Expanding both [determinants](determinant.md), [Fourier orthogonality](fourier-orthogonality.md) makes the integral zero unless the exponent tuples have the same permutation orbit. Strict decreasing order makes that equivalent to $\kappa=\eta$; the $n!$ matching permutation terms then each contribute one. An alternating [Laurent polynomial](laurent-polynomial.md) is a finite linear combination of these alternants. For an [irreducible character](irreducible-character.md) $\chi_\lambda$, its highest monomial gives coefficient one for $A_{\lambda+\delta}$ in $\chi_\lambda A_\delta$, with $\delta=(n-1,\ldots,0)$. The [Weyl integration formula](weyl-integration-formula.md) and [Schur orthogonality relations](schur-orthogonality-relations.md) force the sum of squared coefficients to be one, so all other coefficients vanish. This proves the unitary [Weyl character formula](weyl-character-formula.md) directly.
