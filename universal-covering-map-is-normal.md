# Universal covering map is normal

↑ **Parent:** [Normal covering map](normal-covering-map.md)

A universal covering has simply connected total space, so its associated subgroup of the base fundamental group is trivial. The trivial subgroup is normal; hence every universal covering map is a [normal covering map](normal-covering-map.md).
