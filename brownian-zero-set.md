# Brownian zero set

↑ **Parent:** [Brownian motion](brownian-motion-split.md)

The zero set $\{t\geq0:B_t=0\}$ of one-dimensional [Brownian motion](brownian-motion-split.md) is almost surely closed, uncountable, and has zero [Lebesgue measure](lebesgue-measure.md). The last fact follows from [Tonelli theorem](tonelli-theorem.md) because $\mathbb P(B_t=0)=0$ for every $t>0$.
