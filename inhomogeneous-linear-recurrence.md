# Inhomogeneous linear recurrence

↑ **Parent:** [Linear recurrence relation](linear-recurrence-relation.md)

An [inhomogeneous linear recurrence](inhomogeneous-linear-recurrence.md) has a prescribed forcing sequence $g_n$ rather than zero on the right. The difference of two solutions satisfies the associated homogeneous [linear recurrence relation](linear-recurrence-relation.md), so every solution is a particular solution plus a homogeneous solution.
