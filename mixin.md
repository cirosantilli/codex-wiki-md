# Mixin

↑ **Parent:** [Object-oriented programming](object-oriented-programming.md)

Reusable behavior composed into a host [class in object-oriented programming](class-programming.md), often through a [trait](trait.md). [Scala](scala.md) allows one superclass and several mixed-in traits. Required abstract members let a mixin depend on host capabilities without fixing one concrete superclass; member conflicts and `super` calls are resolved using the language's linearization rules.
