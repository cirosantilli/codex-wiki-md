# Heartbeat discrimination task

↑ **Parent:** [Interoceptive accuracy](interoceptive-accuracy.md)

A task requiring judgments about the relation between external events and recorded heartbeats. Sensory timing and task calibration matter; it is not interchangeable with heartbeat counting.
