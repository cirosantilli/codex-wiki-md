# Harshad number

↑ **Parent:** [Number theory](number-theory-split.md)

A Harshad number in base $b\ge2$ is a [positive integer](positive-integer.md) divisible by its [base-p digit sum](base-p-digit-sum.md) in that base. In base ten, $18$ is a Harshad number because $1+8=9$ divides $18$. It is strong when the quotient by its [base-p digit sum](base-p-digit-sum.md) is [prime](prime-number-split.md), and right-truncatable when every nonempty prefix is a Harshad number.
