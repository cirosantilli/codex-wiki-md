# Core rigidity in a constant-sum cooperative game

↑ **Parent:** [Constant-sum cooperative game](constant-sum-cooperative-game.md)

For a [core](core-game-theory.md) allocation $x$, the inequalities for $S$ and its complement, together with efficiency, give $x(S)\ge v(S)$ and $x(S)=v(N)-x(N\setminus S)\le v(N)-v(N\setminus S)=v(S)$. Thus equality holds for every [coalition](coalition-game-theory.md); singletons force $x_i=v(\{i\})$ and all other values must be their sums. Conversely, if the [characteristic function of a coalitional game](characteristic-function-of-a-coalitional-game.md) is additive, that unique allocation satisfies every [core](core-game-theory.md) inequality with equality. Hence a [constant-sum cooperative game](constant-sum-cooperative-game.md) has either an empty [core](core-game-theory.md) or this one-point [core](core-game-theory.md).
