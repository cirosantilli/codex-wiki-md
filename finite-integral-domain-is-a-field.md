# Finite integral domain is a field

↑ **Parent:** [Integral domain](integral-domain.md)

Multiplication by a nonzero element of an [integral domain](integral-domain.md) is injective. If the ring is finite, that map is surjective, so its image contains one and the multiplier has a multiplicative inverse. Hence every nonzero element is invertible and the ring is a [field](field.md).
