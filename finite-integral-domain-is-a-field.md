# Finite integral domain is a field

↑ **Parent:** [Integral domain](integral-domain.md)

Multiplication by a nonzero element $a$ of an [integral domain](integral-domain.md) is [injective](injective-function.md), by [multiplicative cancellation](multiplicative-cancellation-in-an-integral-domain.md). When the domain is finite, this self-map is [surjective](surjective-function.md), so some element $b$ satisfies $ab=1$. Commutativity gives $ba=1$, so every nonzero element has a [multiplicative inverse](multiplicative-inverse.md) and the domain is a [field](field.md).

Even when the domain convention does not initially assume an [identity element](identity-element.md), finiteness produces one. Surjectivity supplies $e$ with $ae=a$; then $a(ex-x)=0$ forces $ex=x$ for every $x$. Commutativity makes $e$ a two-sided identity, after which the inverse argument applies.
