# Partial wave

↑ **Parent:** [Quantum scattering](quantum-scattering.md)

A partial wave is a component of a scattering state with definite [orbital angular momentum](orbital-angular-momentum.md). A [central potential](central-potential.md) preserves each angular-momentum channel, so the scattering problem decomposes into independent partial waves.
