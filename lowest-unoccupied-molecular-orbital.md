# Lowest unoccupied molecular orbital

↑ **Parent:** [Molecular orbital](molecular-orbital.md)

The lowest-energy unoccupied orbital of a specified reference [electron configuration](electron-configuration.md). In a fixed-orbital approximation, adding one electron occupies this orbital; orbital relaxation and electron correlation can alter that picture.
