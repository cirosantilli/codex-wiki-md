# Analog-to-digital converter

↑ **Parent:** [Electrical engineering](electrical-engineering-split.md)

An [analog-to-digital converter](analog-to-digital-converter.md) produces a discrete numerical code from an input voltage. Its specifications include input range, resolution, conversion rate, [input impedance](input-impedance.md), offset, gain error and nonlinearity. A uniform $b$-[bit](bit.md) converter covering voltage span $V_{\mathrm{span}}$ has nominal spacing $q\simeq V_{\mathrm{span}}/2^b$. The [uniform-quantization error bound](uniform-quantization-error-bound.md) applies to rounding inside the range, while clipping is a different error. Sampling and [quantization](quantization-signal-processing.md) are separate operations: neither sufficient sampling rate nor a large bit count alone guarantees accurate reconstruction.
