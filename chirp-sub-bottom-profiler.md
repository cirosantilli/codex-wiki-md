# Chirp sub-bottom profiler

↑ **Parent:** [Seismic source](seismic-source.md)

A shallow marine acoustic profiling system transmitting a swept-frequency pulse and using matched processing to resolve interfaces below the seabed. Fine [vertical seismic resolution](vertical-seismic-resolution.md) must be balanced against penetration and [seismic attenuation](seismic-attenuation.md).
