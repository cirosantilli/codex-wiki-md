# Tree-level connected matter five-point function

↑ **Parent:** [Standard perturbation theory density kernel](standard-perturbation-theory-density-kernel.md)

For Gaussian initial conditions, the tree-level connected matter five-point function has perturbative-order partitions

$$
4+1+1+1+1,
\qquad 3+2+1+1+1,
\qquad 2+2+2+1+1.
$$

They correspond respectively to a four-valent star, an $F_3$--$F_2$ tree, and a chain of three $F_2$ vertices. Every topology contains four linear power spectra.
