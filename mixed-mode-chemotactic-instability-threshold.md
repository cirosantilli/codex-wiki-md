# Mixed-mode chemotactic instability threshold

↑ **Parent:** [Chemotactic instability on a rectangular domain](chemotactic-instability-on-a-rectangular-domain.md)

When $\alpha=\kappa=\eta=1$, the [instability](lyapunov-stability.md) threshold of a spatial mode with squared [wave number](wavenumber.md) $s$ is $\beta=s+2+1/s$. On a rectangle $L_1=1$, $L_2=1/2$, modes varying in both coordinates have $s\ge5\pi^2$. Since the threshold increases for $s>1$, the first such mode is $(n,m)=(1,1)$, at $\beta_{crit}=5\pi^2+2+(5\pi^2)^{-1}$. At equality it is neutral; strict [instability](lyapunov-stability.md) begins above this value.
