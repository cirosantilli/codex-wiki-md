# Minimal dynamical system

↑ **Parent:** [Topological dynamics](topological-dynamics.md)

A nonempty topological [dynamical system](dynamical-system.md) $(Y,T)$ on a [compact Hausdorff space](compact-hausdorff-space.md) is minimal if it has no proper nonempty closed forward-invariant [subset](subset.md). Equivalently, every forward [orbit](orbit-dynamical-system.md) is dense in $Y$, because an [orbit closure](orbit-closure.md) is closed and forward invariant. Minimality implies $T(Y)=Y$.
