# Oriented tree

↑ **Parent:** [Tree (graph theory)](tree-graph-theory.md)

An oriented tree is an orientation of every edge of an undirected [tree](tree-graph-theory.md). Its arrows need not all point towards, or away from, any one root. It is acyclic as a [directed graph](directed-graph.md), but different orientations can have different embedding behaviour in [tournaments](tournament-graph-theory.md).
