# Block sensitivity

↑ **Parent:** [Boolean function](boolean-function.md)

For an input $x$, count the largest family of pairwise disjoint nonempty sets of coordinates such that flipping each set individually changes the [Boolean function](boolean-function.md) value. Maximizing over inputs gives block sensitivity. Sensitive sets need not be contiguous and need not consist of single bits. The standard bounded-error [quantum query complexity](quantum-query-complexity.md) lower bound is $\Omega(\sqrt{\operatorname{bs}(f)})$. A certificate for $f(x)$ meets every sensitive set, so its size bounds their disjoint count.
