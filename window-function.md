# Window function

↑ **Parent:** [Fourier transform](fourier-transform.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Window_function)

A window function is a [function](function-split.md) that vanishes outside a chosen finite [interval](interval-mathematics.md); multiplying an input by it selects and weights that part of the history before a [Fourier transform](fourier-transform.md). The rectangular window $w_T$ is the [indicator function](indicator-function.md) of $[0,T]$. Applied to the weighted [causal extension by zero](causal-extension-by-zero.md) of an input, it produces the finite-history [integral](integral.md) $\int_0^T e^{-st}f(t)\,dt$ used to approximate a [Laplace transform](laplace-transform.md).
