# Natural frequencies in probabilistic reasoning

↑ **Parent:** [Probabilistic reasoning](probabilistic-reasoning.md)

Counts preserving how cases from a common population fall into nested classes and evidence subsets. [Bayesian inference](bayesian-statistics-split.md) can then use a ratio of joint counts, $n(H\cap E)/n(E)$. For uniform sampling from those cases, [conditional probability](conditional-probability.md) is the number satisfying both class and evidence divided by the number satisfying the evidence, so the ratio follows directly without reconstructing separately normalized rates. Separately normalizing each class to the same artificial denominator does not preserve the original prevalence automatically.
