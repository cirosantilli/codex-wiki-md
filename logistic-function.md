# Logistic function

↑ **Parent:** [Sigmoid function](sigmoid-function.md)

The standard logistic function maps a [log odds](log-odds.md) $z$ to probability $1/(1+e^{-z})$. More generally, its translated and scaled form is $L/(1+e^{-k(x-x_0)})$.
