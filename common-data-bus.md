# Common data bus

↑ **Parent:** [Out-of-order execution](out-of-order-execution.md)

A shared path carrying tagged results or completion information to waiting [reservation stations](reservation-station.md), the [register file](register-file.md) or a [reorder buffer](reorder-buffer.md). A tag identifies the particular producer, not merely the destination's logical name.
