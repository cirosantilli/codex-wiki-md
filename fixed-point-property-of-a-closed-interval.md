# Fixed-point property of a closed interval

↑ **Parent:** [Fixed-point property](fixed-point-property.md)

For continuous $f:[0,1]\to[0,1]$, the function $f(x)-x$ is nonnegative at zero and nonpositive at one, so the [intermediate value theorem](intermediate-value-theorem.md) gives a fixed point.
