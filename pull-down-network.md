# Pull-down network

↑ **Parent:** [CMOS](cmos.md)

A [pull-down network](pull-down-network.md) connects a logic output to the low supply rail when its conducting condition holds. In static complementary [CMOS](cmos.md), it is built from [NMOS transistors](nmos-transistor.md); its conducting condition is the [negation](negation.md) of the desired output [Boolean function](boolean-function.md).
