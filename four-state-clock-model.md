# Four-state clock model

↑ **Parent:** [Clock model](clock-model.md)

The four-state clock model permits the four angles $0,\pi/2,\pi,3\pi/2$. Its finite [discrete symmetry](discrete-symmetry.md) allows finite-temperature long-range order above one spatial dimension.
