# Variance bound for a weakly self-bounding function

↑ **Parent:** [Weakly self-bounding function](weakly-self-bounding-function.md)

For a weakly self-bounding function $Z=f(X_1,\ldots,X_n)$ of [independent random variables](independent-random-variables.md), the coordinatewise variance inequality gives

$$
\operatorname{Var}(Z)\leq\mathbb E\sum_i(Z-Z_i)^2\leq\mathbb EZ,
$$

where $Z_i=f_i(X^{(i)})$.
