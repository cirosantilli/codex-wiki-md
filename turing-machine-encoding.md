# Turing machine encoding

↑ **Parent:** [Turing machine](turing-machine.md)

A finite [string](string.md) describing a [Turing machine](turing-machine.md)'s states, [alphabets](alphabet.md), transition rules and designated initial and halting states. Standard encodings have a [decidable language](recursive-language.md) of valid descriptions. A syntactic property of an encoding need not be an [extensional property of programs](extensional-property-of-programs.md); for example, adding an unreachable state changes state count without changing the accepted [formal language](formal-language.md).
