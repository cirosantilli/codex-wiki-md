# Page table entry

↑ **Parent:** [Page table](page-table.md)

One record in a [page table](page-table.md), holding a [page frame](page-frame.md) number or a next-level table reference together with architecture-dependent flags. Effective permissions in a [multi-level page table](multi-level-page-table.md) can depend on several entries, not just the final one.
