# Match state

↑ **Parent:** [Hidden Markov model](hidden-markov-model.md)

A [match state](match-state.md) in a [profile hidden Markov model](profile-hidden-markov-model.md) emits one aligned character at a particular profile position whenever it is visited. “Match” names its alignment role, not a requirement to emit one deterministic character or to match another sequence exactly.
