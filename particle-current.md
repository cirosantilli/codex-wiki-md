# Particle current

↑ **Parent:** [Particle number](particle-number.md)

The rate at which particles cross an oriented surface, measured as particle count per unit time. If a local [continuity equation](continuity-equation.md) has number density $n$ and current density $\mathbf j_N$, then $\partial_t n+\nabla\cdot\mathbf j_N=0$ and $J_N=\int_S\mathbf j_N\cdot d\mathbf S$. In a closed two-reservoir system, a left-to-right [particle current](particle-current.md) is $-dN_L/dt=dN_R/dt$. Neutral particles carry this current without an associated [electric current](electric-current.md).
