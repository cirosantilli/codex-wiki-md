# Cycle index

↑ **Parent:** [Burnside's lemma](burnside-s-lemma.md)

For a [permutation group](permutation-group.md), $c_r(g)$ is the number of length-$r$ cycles of $g$. The cycle index records the average cycle structure. On coloring a finite underlying set, a coloring fixed by $g$ is constant on each cycle. Replacing $t_r$ by the [power-sum symmetric polynomial](power-sum-symmetric-polynomial.md) $p_r(x)$ therefore gives the [pattern inventory](pattern-inventory.md) by the [weighted Burnside lemma](weighted-burnside-lemma.md).
