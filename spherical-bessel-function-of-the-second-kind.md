# Spherical Bessel function of the second kind

↑ **Parent:** [Bessel function of the second kind](bessel-function-of-the-second-kind.md)

The spherical second-kind function is $n_\ell(z)=\sqrt{\pi/(2z)}Y_{\ell+1/2}(z)$. Together with the first-kind [Spherical Bessel function](spherical-bessel-function.md), it spans the radial free-wave solutions; $n_\ell(z)\sim-\cos(z-\ell\pi/2)/z$ at large positive $z$.
