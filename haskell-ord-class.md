# Haskell Ord class

↑ **Parent:** [Haskell type class](haskell-type-class.md)

The [Haskell](haskell.md) class providing ordering operations, including `compare`. A comparison-based [sorting algorithm](sorting-algorithm.md) requires the associated constraint to inspect the order of arbitrary keys. Its correctness additionally assumes that the supplied operations obey the intended ordering laws.
