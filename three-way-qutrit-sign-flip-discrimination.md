# Three-way qutrit sign-flip discrimination

↑ **Parent:** [Quantum channel discrimination](quantum-channel-discrimination.md)

For the three [qutrit](qutrit.md) [unitary operators](unitary-operator.md) $U_j=I-2|j\rangle\langle j|$, prepare $|s\rangle=(|0\rangle+|1\rangle+|2\rangle)/\sqrt3$, query once, apply the known [inversion about the mean](inversion-about-the-mean.md) $D=2|s\rangle\langle s|-I$, and use a [computational-basis measurement](quantum-measurement-in-the-computational-basis.md) to guess $j$. Since $D^2=I$, the processing is a [unitary transformation](unitary-operator.md). Direct multiplication gives $DU_j|s\rangle=(5|j\rangle-\sum_{k\ne j}|k\rangle)/(3\sqrt3)$, establishing success [probability](probability.md) $25/27$ for each label. This calculation establishes the achieved [probability](probability.md), without requiring an optimality claim.
