# Ackermann function

↑ **Parent:** [Computable function](computable-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ackermann_function)

One convention for the [Ackermann function](ackermann-function.md) on [nonnegative integers](natural-number.md) is

$$
A(0,n)=n+1,\quad A(m+1,0)=A(m,1),\quad A(m+1,n+1)=A(m,A(m+1,n)).
$$

Its two-argument recursion defines a [computable function](computable-function.md); fixing the convention matters when defining an [inverse Ackermann function](inverse-ackermann-function.md).
