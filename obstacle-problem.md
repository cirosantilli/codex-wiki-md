# Obstacle problem

↑ **Parent:** [Partial differential equation](partial-differential-equation-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Obstacle_problem)

An obstacle constraint requires a solution to lie above a given function. In an [optimal stopping](optimal-stopping.md) problem, the value dominates the payoff, satisfies a generator equation where continuation is optimal, and a generator inequality where stopping is optimal. The complementary conditions can be expressed as a maximum equal to zero.
