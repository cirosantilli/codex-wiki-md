# Almost sure event

↑ **Parent:** [Probability space](probability-space.md)

An almost sure event is a measurable event of probability one. Countable intersections of such events still have probability one, allowing a conclusion to hold simultaneously for countably many parameter choices. Further deterministic reasoning may then extend it to uncountably many parameters, as in [Brownian Hölder regularity](brownian-holder-regularity.md) or [nowhere monotonicity of Brownian motion](nowhere-monotonicity-of-brownian-motion.md). An uncountable intersection need not preserve probability one without such additional reasoning.
