# Recursive triple colouring with no computable infinite homogeneous set

↑ **Parent:** [Computability theory](computability-theory.md)

Let $K_s$ be increasing finite stage approximations to a noncomputable [computably enumerable set](recursively-enumerable-set.md) $K$. For $x<y<z$, colour the triple zero exactly when $K_y\cap[0,x]=K_z\cap[0,x]$. An infinite homogeneous set has colour zero, since each bounded approximation eventually stabilizes. Its first two elements above any requested bound recover the final approximation at that bound, so the homogeneous set computes $K$. Thus no infinite homogeneous set is [computable](computable-set.md). This illustrates the difference between a [Ramsey's theorem](ramsey-s-theorem.md) existence result and an effective construction.
