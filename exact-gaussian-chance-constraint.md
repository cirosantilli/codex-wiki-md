# Exact Gaussian chance constraint

↑ **Parent:** [Chance constraint](chance-constraint.md)

For $X\sim N(m,v)$ with $v>0$ and $0<\varepsilon<1$, $P(X\geq C)\leq\varepsilon$ is equivalent to the displayed [chance constraint](chance-constraint.md), because the [standard normal distribution function](standard-normal-distribution-function.md) is continuous and strictly increasing. The coefficient is a [standard normal quantile](standard-normal-quantile.md), which can be negative. If $v=0$, equality is an atom and the exact condition becomes $C>m$ instead.
