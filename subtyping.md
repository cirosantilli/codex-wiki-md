# Subtyping

↑ **Parent:** [Type system](type-system.md)

A relationship in which values of one type can be used wherever values of a broader type are required, subject to the language's compatibility rules. In nominal [object-oriented programming](object-oriented-programming.md), extending a class or implementing a trait establishes relevant subtype relationships. [Type variance](type-variance.md) describes how these relationships lift through parameterized types.
