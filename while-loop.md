# While loop

↑ **Parent:** [Imperative programming](imperative-programming.md)

A while loop tests a Boolean condition before each iteration and repeats its body while that condition is true. A [loop invariant](loop-invariant.md) is established initially and preserved by every iteration; a [loop variant](loop-variant.md) decreases in a well-founded order to prove [algorithm termination](algorithm-termination.md). The invariant together with the false exit guard establishes the [postcondition](postcondition.md).
