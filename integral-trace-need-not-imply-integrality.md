# Integral trace need not imply integrality

↑ **Parent:** [Field trace](field-trace.md)

In $L=\mathbb Q_p(\theta)$ with $\theta^2=p$, the [Eisenstein polynomial](eisenstein-polynomial.md) $X^2-p$ gives $v_L(\theta)=1$ and $v_L(p)=2$. The element $x=\theta/p$ has [field trace](field-trace.md) zero, but [valuation](valuation.md) $-1$, so is not in the [valuation ring](valuation-ring.md). Cancellation in a [field trace](field-trace.md) contrasts with the multiplicative test in [unit norm detects units in a local extension](unit-norm-detects-units-in-a-local-extension.md).
