# Degree-sum sufficient statistic for an additive logistic network model

↑ **Parent:** [Additive class-effect logistic network model](additive-class-effect-logistic-network-model.md)

For independent binary edges with log odds $\beta_{z_i}+\beta_{z_j}+\beta_0\mathbf1_{\{z_i=z_j\}}$, the natural statistics are the sum of the [vertex degrees](degree-graph-theory.md) in each class and the total number of within-class edges. They form a [minimal sufficient statistic](minimal-sufficient-statistic.md) whenever the natural parameter space contains an open subset of $\mathbb R^{C+1}$.
