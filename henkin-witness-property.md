# Henkin witness property

↑ **Parent:** [Henkin construction](henkin-construction.md)

A theory in a language with constants has the Henkin witness property when every existential sentence $\exists x\,\phi(x)$ belonging to it has an instance $\phi(c)$ belonging to it for some constant $c$. This property proves the existential step of the [truth lemma for a Henkin term model](truth-lemma-for-a-henkin-term-model.md).
