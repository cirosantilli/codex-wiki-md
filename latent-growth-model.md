# Latent growth model

↑ **Parent:** [Latent variable](latent-variable-split.md)

A longitudinal model in which unobserved intercepts, slopes or other trajectory parameters describe [individual differences](individual-differences.md) in change. The displayed linear example allows people to vary in both initial level and slope; actual trajectories need not be linear.
