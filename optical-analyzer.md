# Optical analyzer

↑ **Parent:** [Polarizer](polarizer.md)

A polarizing element used to examine the polarization of incident [light](light.md). Rotation converts that polarization information into an intensity variation, described by [Malus's law](malus-s-law.md) for an incident linearly polarized beam and an ideal linear analyser.
