# Residual standard error

↑ **Parent:** [Residual estimate of Gaussian noise variance](residual-estimate-of-gaussian-noise-variance.md)

In a full-rank [normal linear model](normal-linear-model.md) with $n$ observations and $p$ mean coefficients, the residual standard error estimates the common error standard deviation. Its square is the [unbiased estimator](unbiased-estimator.md) $\operatorname{RSS}/(n-p)$; the square root itself is not generally unbiased. It measures unexplained response variation, whereas a regression coefficient's [standard error](standard-error.md) measures uncertainty in that coefficient.
