# Maximum cardinality matching

↑ **Parent:** [Matching (graph theory)](matching-graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Maximum_cardinality_matching)

A [maximum cardinality matching](maximum-cardinality-matching.md) is a [matching in a graph](matching-graph-theory-split.md) with as many [edges](edge-of-a-graph.md) as any [matching in a graph](matching-graph-theory-split.md) of the same [graph](graph-split.md). It has [cardinality](cardinality.md) $\nu(G)$, the [matching number](matching-number.md), and need not be unique or be a [perfect matching](perfect-matching.md). For example, any single [edge](edge-of-a-graph.md) of a [triangle in a graph](triangle-in-a-graph.md) is a [maximum cardinality matching](maximum-cardinality-matching.md), but leaves one [vertex](vertex-graph-theory.md) unmatched. [Berge's theorem](berge-s-theorem.md) characterizes these optima by the absence of an [augmenting path in a matching](augmenting-path-in-a-matching.md).
