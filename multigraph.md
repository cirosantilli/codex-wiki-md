# Multigraph

↑ **Parent:** [Graph](graph-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Multigraph)

A multigraph permits distinct [edges](edge-of-a-graph.md) with the same pair of endpoints. Whether loops are also allowed is a convention that must be specified for a particular result. Counting edges with multiplicity differs from counting adjacent vertices.
