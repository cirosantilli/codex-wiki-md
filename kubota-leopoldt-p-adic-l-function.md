# Kubota-Leopoldt p-adic L-function

↑ **Parent:** [p-adic L-function](p-adic-l-function.md)

For an even [Dirichlet character](dirichlet-character.md) $\chi$, the Kubota-Leopoldt function interpolates generalized Bernoulli values with the relevant Euler factor and [Teichmüller character](teichmuller-character.md) adjustment. If $\chi\ne1$, it can be encoded by an integral power series. For $u=1+p$, the $p$-ramified convention is $g_\chi(u^{1-s}-1)=L_p(\chi,s)$. The trivial character requires separate treatment of the pole.
