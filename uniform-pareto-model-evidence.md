# Uniform-Pareto model evidence

↑ **Parent:** [Uniform-Pareto conjugacy](uniform-pareto-conjugacy.md)

For positive observations and $m=\max(\beta,\max_jy_j)$, the [Bayesian model evidence](bayesian-model-evidence.md) follows by integrating the [uniform distribution](continuous-uniform-distribution.md) likelihood against a [Pareto distribution](pareto-distribution.md) prior. For independent groups with shared fixed [hyperparameters](hyperparameter.md), these evidences multiply. The resulting [hyperparameter](hyperparameter.md) log likelihood is $I\log\alpha-\sum_i\log(\alpha+n_i)-\alpha\sum_i\log(m_i/\beta)$ up to a constant.
