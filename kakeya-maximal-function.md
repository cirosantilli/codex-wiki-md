# Kakeya maximal function

↑ **Parent:** [Kakeya inequality](kakeya-inequality.md)

For a direction $e$, the [Kakeya maximal function](kakeya-maximal-function.md) is the supremum over translations of normalized averages of $|f|$ over unit-length [Kakeya tubes](kakeya-tube.md) in direction $e$. It measures how large a function can be on at least one thin tube in each direction. Normalizing by tube volume is essential when comparing different thicknesses.
