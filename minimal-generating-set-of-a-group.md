# Minimal generating set of a group

↑ **Parent:** [Generating set of a group](generating-set-of-a-group.md)

A [generating set of a group](generating-set-of-a-group.md) from which no element can be deleted. This is inclusion-minimal, rather than necessarily having least cardinality. For finite p-groups, the [Burnside basis theorem](burnside-basis-theorem.md) makes all such sets have the same size.
