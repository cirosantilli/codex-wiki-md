# Visual oddity task

↑ **Parent:** [Perception](perception.md)

A task requiring selection of the different item among simultaneously displayed alternatives. Manipulating whether simple features or object-level conjunctions distinguish the odd item tests the representation required. Simultaneous presentation reduces long retention demands but does not eliminate all [working memory](working-memory.md) or learned task rules.
