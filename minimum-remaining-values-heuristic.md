# Minimum remaining values heuristic

↑ **Parent:** [Constraint satisfaction problem](constraint-satisfaction-problem.md)

Choose an unassigned variable with the fewest currently legal values. No legal values detects failure immediately; exactly one legal value forces a choice. This ordering can reduce the [search tree](search-tree.md) without changing the set of solutions.
