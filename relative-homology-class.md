# Relative homology class

↑ **Parent:** [Relative homology](relative-homology.md)

A relative homology class is represented by a [singular chain](singular-chain.md) whose boundary lies in $A$. Two representatives give the same class when their difference is a [boundary operator](boundary-operator.md) image plus a chain in $A$. Thus a path with endpoints in $A$ can represent a class even when its endpoints are different.
