# Absoluteness of constructible levels

↑ **Parent:** [Constructible hierarchy](constructible-hierarchy.md)

For a [transitive model](transitive-model.md) $M$ of [ZFC](zermelo-fraenkel-set-theory-with-choice.md) and $\alpha\in M\cap\operatorname{Ord}$, the internally computed [constructible hierarchy](constructible-hierarchy.md) agrees with the ambient level: $L_\alpha^M=L_\alpha$. Satisfaction for a fixed set structure is computed from the same finite formulas and the same domain in both universes. [Transfinite recursion](transfinite-recursion.md) then proves agreement at successors and limits. If $\theta=M\cap\operatorname{Ord}$, it follows that $L_\theta\subseteq M$.
