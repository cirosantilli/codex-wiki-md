# Uniform hypergraph

↑ **Parent:** [Hypergraph](hypergraph-split.md)

A hypergraph is $r$-uniform if each hyperedge has exactly $r$ vertices. Ordinary simple [graphs](graph-split.md) are 2-uniform hypergraphs. Its average [hypergraph vertex degree](hypergraph-vertex-degree.md) is $r|E|/|V|$.
