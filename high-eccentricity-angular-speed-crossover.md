# High-eccentricity angular-speed crossover

↑ **Parent:** [Specific angular momentum](specific-angular-momentum.md)

For a nearly radial [Kepler orbit](kepler-orbit.md) with [pericentre](periapsis.md) $q$, [specific angular momentum](specific-angular-momentum.md) is $h\simeq\sqrt{2GMq}$. Relative to a circular reference orbit of radius $a_p$ and [mean motion](mean-motion.md) $n_p$, the instantaneous azimuthal rate changes from faster to slower at $r_x=\sqrt{h/n_p}\simeq a_p(2q/a_p)^{1/4}$. In a [rotating reference frame](rotating-reference-frame.md) the polar angle has a turning point at this radius. The [true anomaly](true-anomaly.md) there differs from $\pi$ by approximately $2\sqrt{q/r_x}$.
