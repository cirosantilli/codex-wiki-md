# Linear programming optimality certificate

↑ **Parent:** [Weak duality](weak-duality.md)

For the [linear program](linear-programming.md) maximizing $c^Tx$ with $Ax\le b$, $x\ge0$, a vector $y\ge0$ with $A^Ty\ge c$ proves $c^Tx\le y^Tb$ for every feasible $x$. If a feasible $x$ attains that bound, it is optimal. This is [weak duality](weak-duality.md) written as a directly checkable certificate; adding nonnegative multiples of constraints suffices to verify it. The equivalent reversed-inequality certificate applies to a minimization program.
