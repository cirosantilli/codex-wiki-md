# Axial chromatic aberration

↑ **Parent:** [Chromatic aberration](chromatic-aberration.md)

[Axial chromatic aberration](axial-chromatic-aberration.md), also called [longitudinal chromatic aberration](axial-chromatic-aberration.md), is colour-dependent focus position along the [optical axis](optical-axis.md). For incident [light rays](light-ray.md) parallel to the [optical axis](optical-axis.md), it appears as a changing [focal length](focal-length.md). The [chromatic aberration](chromatic-aberration.md) diagram isolates this effect using an ideal [thin lens](thin-lens.md) at each colour.
