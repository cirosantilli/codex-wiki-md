# GaAs four-band model

↑ **Parent:** [Gallium arsenide](gallium-arsenide.md)

A zone-centre effective-mass description retaining the s-like [conduction band](conduction-band.md), heavy-hole and light-hole branches of the p-like $j=3/2$ valence manifold, and the spin-orbit-split $j=1/2$ valence branch. Each named branch includes [spin](spin.md) multiplicity; four bands does not mean four individual quantum states.
