# Squared distance to a convex set

↑ **Parent:** [Moreau envelope](moreau-envelope.md)

For a nonempty closed convex set $C$, the squared-distance function is the [Moreau envelope](moreau-envelope.md) of its [indicator functional of a constraint set](indicator-functional-of-a-constraint-set.md). It is convex and differentiable with

$$
\nabla d_C(x)=x-P_Cx,
$$

and this gradient is one-Lipschitz.
