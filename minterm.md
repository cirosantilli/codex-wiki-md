# Minterm

↑ **Parent:** [Propositional formula](propositional-formula.md)

A conjunction containing each of a specified finite collection of [Boolean variables](boolean-variable.md) exactly once, either positively or negated. It is satisfied by exactly one [Boolean valuation](boolean-valuation.md) of those variables. The [minterms](minterm.md) for all valuations are mutually exclusive and collectively exhaustive, so they can encode an arbitrary finite table of values.
