# Periodic solution

↑ **Parent:** [Ordinary differential equation](ordinary-differential-equation.md)

A solution with a period $T>0$. A nonconstant periodic solution of an autonomous system traces a [periodic orbit](periodic-orbit.md); constant equilibria are also periodic functions, so they must be excluded when asserting absence of periodic orbits.
