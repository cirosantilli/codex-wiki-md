# Lagrangian function in constrained optimization

↑ **Parent:** [Lagrangian](lagrangian.md)

For an objective $f(x)$ with equality constraints $g_i(x)=0$, the Lagrangian function is

$$
L(x,\lambda)=f(x)+\sum_i\lambda_i g_i(x).
$$
