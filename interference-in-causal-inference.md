# Interference in causal inference

↑ **Parent:** [Causal inference](causal-inference-split.md)

Interference occurs when one unit's treatment changes another unit's [potential outcome](potential-outcome.md). It violates the usual assumption that each unit's potential outcomes depend only on that unit's own treatment.
