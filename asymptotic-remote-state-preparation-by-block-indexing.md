# Asymptotic remote state preparation by block indexing

↑ **Parent:** [Remote state preparation](remote-state-preparation.md)

Prepare independent candidate blocks by [one-bit heralding of a remote state preparation block](one-bit-heralding-of-a-remote-state-preparation-block.md), but send only the first successful block's index. Success eventually occurs with [probability](probability.md) one; a [prefix code for a rare geometric success](prefix-code-for-a-rare-geometric-success.md) uses at most $n+e/(e-1)$ expected [bits](bit.md) per block. The expected [singlet state](singlet-state.md) consumption is $n2^n$. Alternatively, limiting the number of trials to $n2^n$ gives failure [probability](probability.md) at most $e^{-n}$ and a fixed message length $n+\log_2n+O(1)$. Both versions approach one classical [bit](bit.md) per remotely prepared [qubit](qubit.md) in their respective expected-length or high-success senses.
