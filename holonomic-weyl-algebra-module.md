# Holonomic Weyl algebra module

↑ **Parent:** [Bernstein growth dimension of a Weyl algebra module](bernstein-growth-dimension-of-a-weyl-algebra-module.md)

A nonzero finitely generated [Weyl algebra](weyl-algebra.md) module over $A_n(\mathbb C)$ is holonomic when it attains the lower bound in the [Bernstein inequality for Weyl algebra modules](bernstein-inequality-for-weyl-algebra-modules.md). The zero module is also conventionally called holonomic. Nonzero subquotients of a holonomic module remain holonomic. Additivity and integrality of the leading Hilbert-polynomial multiplicity then bound the number of nonzero factors in any submodule chain, giving finite composition length.
