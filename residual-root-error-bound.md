# Residual root error bound

↑ **Parent:** [Root finding](root-finding.md)

Suppose $f$ is continuous on an [interval](interval-mathematics.md), differentiable in its interior, and $|f'|\geq m>0$ throughout the interior. If $x_*$ is a [root](root-of-a-root-system.md) in the [interval](interval-mathematics.md) and $\widehat x$ is another point in it, the [mean value theorem](mean-value-theorem.md) gives $f(\widehat x)-f(x_*)=f'(\xi)(\widehat x-x_*)$ for an intermediate point $\xi$. Taking absolute values proves the stated bound from the [residual of a root equation](residual-of-a-root-equation.md). This converts an observed residual into a stopping certificate, provided the evaluation error in that residual is also controlled.
