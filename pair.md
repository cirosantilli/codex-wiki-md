# Pair

↑ **Parent:** [Set](set-split.md)

A pair is a collection of two objects. An ordered pair records which object is first, whereas an unordered pair does not.

An [ordered pair](ordered-pair.md) is a pair with distinguished first and second positions; an unordered pair does not record those positions.
