# Ramond level operator

↑ **Parent:** [Ramond sector](ramond-sector.md)

For integer transverse string modes, $N_R=\sum_{k>0}(\alpha_{-k}\cdot\alpha_k+k d_{-k}\cdot d_k)$ with vacuum-annihilating normal ordering. Each nonzero-mode creation operator raises the level by $k$; fermionic zero modes commute with it. The open-string mass condition is $M^2=2\pi TN_R$, with zero Ramond intercept.
