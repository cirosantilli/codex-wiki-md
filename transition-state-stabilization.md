# Transition state stabilization

↑ **Parent:** [Catalysis](catalysis.md)

[Transition state stabilization](transition-state-stabilization.md) lowers an activation barrier when a catalytic environment stabilizes the reacting configuration more than the starting bound state. Stronger ground-state binding alone does not demonstrate [catalysis](catalysis.md).
