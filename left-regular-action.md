# Left regular action

↑ **Parent:** [Group action](group-action.md)

The left regular action of a [group](group-split.md) on its own underlying set is left multiplication. It is faithful, because an element fixing the identity is itself the identity. For a finite group it gives the [permutation representation](permutation-representation.md) used in [Cayley theorem](cayley-s-theorem.md).
