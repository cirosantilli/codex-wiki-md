# Automatic differentiation

↑ **Parent:** [Derivative](derivative.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Automatic_differentiation)

[Automatic differentiation](automatic-differentiation.md) evaluates derivatives of a computational graph using the [chain rule](chain-rule.md). Reverse mode is [backpropagation](backpropagation.md) and is useful for [reparameterization gradients](reparameterization-gradient.md) through simulated trajectories.
