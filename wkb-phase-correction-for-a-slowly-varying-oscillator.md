# WKB phase correction for a slowly varying oscillator

↑ **Parent:** [WKB approximation for a slowly varying oscillator](wkb-approximation-for-a-slowly-varying-oscillator.md)

For smooth $K=|k|>0$ and fixed amplitude flux, use $\sigma=K+\epsilon^2\sigma_1+\cdots$ and $A_0\propto K^{-1/2}$. The [exact amplitude-phase equation](exact-amplitude-phase-equation.md) gives $\sigma_1=A_0''/(2KA_0)$, which is the displayed formula. The first phase correction is order $\epsilon^2$ in the local wavenumber, hence order $\epsilon$ in its integrated exponential phase.
