# Morphism in a category

↑ **Parent:** [Category](category-split.md)

A [categorical morphism](morphism-in-a-category.md) is an arrow with a specified source and target in a [category](category-split.md). An arrow $f:A\to B$ composes with $g:B\to C$ to give $gf:A\to C$. Composition is associative, and every object has an identity arrow acting as a unit. A [functor](functor.md) preserves the sources, targets, identities and compositions of these arrows. In a [locally small category](locally-small-category.md), the arrows between fixed objects form a [hom-set](hom-set.md).
