# Entity subtype

↑ **Parent:** [Entity-relationship model](entity-relationship-model.md)

An entity type whose instances inherit the identifier, [database attributes](database-attribute.md) and relationships of a more general entity type. A total disjoint specialization requires every parent instance to belong to exactly one listed subtype.
