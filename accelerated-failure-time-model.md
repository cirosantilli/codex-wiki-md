# Accelerated failure time model

↑ **Parent:** [Survival analysis](survival-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Accelerated_failure_time_model)

An accelerated failure time model changes the time scale of a common event-time distribution. In a log-location-scale representation, $T_z=e^{\mu(z)}e^{\sigma X}$ with common $X$ and positive scale $\sigma$. An additive change in $\mu(z)$ multiplies all time [quantiles](quantile-function.md) by the same factor. A larger time multiplier indicates longer survival, whereas a larger [hazard multiplier](hazard-multiplier.md) in a [proportional hazards model](proportional-hazards-model.md) indicates faster failure.
