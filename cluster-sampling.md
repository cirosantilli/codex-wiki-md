# Cluster sampling

↑ **Parent:** [Probability sampling](probability-sampling.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cluster_sampling)

Cluster sampling chooses groups of observational units, such as production days, rather than dispersed individual units. Testing every unit in a selected group is a one-stage cluster sample. Positive within-cluster [intraclass correlation](intraclass-correlation-coefficient.md) reduces the information supplied by a fixed number of sampled units, although collecting clustered observations can be cheaper.
