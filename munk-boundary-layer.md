# Munk boundary layer

↑ **Parent:** [Western boundary current](western-boundary-current.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Munk_boundary_layer)

A Munk boundary layer closes a [Sverdrup balance](sverdrup-balance.md) interior using lateral viscosity. At a zonal wall, balancing $\beta\psi_x$ with $\nu\nabla^4\psi$ gives the width $(\nu/\beta)^{1/3}$.
