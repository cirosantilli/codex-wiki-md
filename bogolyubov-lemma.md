# Bogolyubov lemma

↑ **Parent:** [Additive combinatorics](additive-combinatorics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bogolyubov_lemma)

If $A$ has positive density in a finite abelian group, then $A+A-A-A$ contains a structured neighbourhood of zero. In a finite-dimensional vector space this neighbourhood can be taken to be a large [vector subspace](vector-subspace.md); in a cyclic group it can be taken to be a [Bohr set](bohr-set.md).
