# Relative hyperplane line bundle

↑ **Parent:** [Relative tautological line bundle](relative-tautological-line-bundle.md)

Dualize the [relative tautological line bundle](relative-tautological-line-bundle.md) to obtain the positive relative hyperplane [line bundle](line-bundle.md). It restricts to $\mathcal O(1)$ on each projective fibre. This sign depends on the convention that projectivization parametrizes lines; fixing the convention avoids confusing it with the tautological line itself.
