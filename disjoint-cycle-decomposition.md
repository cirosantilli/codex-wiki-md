# Disjoint cycle decomposition

↑ **Parent:** [Permutation cycle](permutation-cycle.md)

A [disjoint cycle decomposition](disjoint-cycle-decomposition.md) writes a [permutation](permutation.md) as a product of [disjoint permutation cycles](disjoint-permutation-cycles.md). Repeatedly apply the [permutation](permutation.md) to a point until it returns to that point; these successive points form one [cycle](permutation-cycle.md). Repeat on points not yet used. Finiteness and injectivity ensure that each process returns to its starting point. This partitions the underlying finite set into [cycles](permutation-cycle.md). The decomposition is unique up to reordering the [cycles](permutation-cycle.md), cyclically rotating the entries within each [cycle](permutation-cycle.md), and optionally omitting fixed-point one-cycles. Include the one-cycles when specifying [cycle type](cycle-type.md).
