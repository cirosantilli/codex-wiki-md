# Null condition

↑ **Parent:** [Null vector](null-vector.md)

The null condition for a nonzero vector $k$ in a [Lorentzian metric](lorentzian-metric.md) is $g(k,k)=0$. Applied to the tangent of a curve it makes the curve a [null curve](null-curve.md). Nullity alone does not imply the [geodesic equation](geodesic-equation.md); an additional zero or tangent-parallel covariant acceleration is required.
