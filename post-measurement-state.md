# Post-measurement state

↑ **Parent:** [Lüders rule](luders-rule.md)

The post-measurement state is the conditional quantum state after a specified measurement outcome. For a [projective measurement](projective-measurement.md), it is given by the [Lüders rule](luders-rule.md).
