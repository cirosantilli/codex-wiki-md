# Response dumping

↑ **Parent:** [Psychophysics](psychophysics.md)

Assigning a perceptual contribution to an available response scale because a more appropriate scale is absent or unclear. An odor contribution rated only on a sweetness scale could therefore affect the score without establishing a separate gustatory sensation. Providing multiple scales and independent discrimination tests can help test this possible explanation; their results should not be presumed in advance.
