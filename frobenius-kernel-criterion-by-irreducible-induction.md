# Frobenius kernel criterion by irreducible induction

↑ **Parent:** [Frobenius kernel](frobenius-kernel.md)

For $1<N\triangleleft G$ proper, the displayed condition is equivalent to $N$ being a [Frobenius kernel](frobenius-kernel.md). For a normal subgroup the induction norm is $|I_G(\varphi):N|$. Trivial inertia for each nonprincipal character and [Brauer's permutation lemma](brauer-s-permutation-lemma.md) imply that every element outside $N$ has trivial centralizer in $N$. This forces $N$ to be a normal Hall subgroup; a complement is then fixed-point-free on $N$.
