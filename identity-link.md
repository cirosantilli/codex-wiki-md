# Identity link

↑ **Parent:** [Link function](link-function.md)

The identity [link function](link-function.md) equates the response mean with the [linear predictor](linear-predictor.md). In a [generalized linear model](generalized-linear-model.md) it gives $\mu_i=x_i^T\beta$. It is the [canonical link function](canonical-link-function.md) for the [normal distribution](normal-distribution.md). For response families whose means must remain positive or between zero and one, using the identity link requires corresponding restrictions on the [linear predictor](linear-predictor.md).
