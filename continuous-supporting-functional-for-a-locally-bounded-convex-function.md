# Continuous supporting functional for a locally bounded convex function

↑ **Parent:** [Subgradient](subgradient.md)

A real [convex function](convex-function.md) locally bounded on an open [convex set](convex-set.md) has a continuous supporting [linear functional](linear-functional.md) at every interior point. Apply the dominated [Hahn-Banach theorem](hahn-banach-theorem.md) to its sublinear [directional derivative](directional-derivative.md) $p_x$ to obtain $l\leq p_x$. Increasing secant slopes imply $p_x(z)\leq f(x+z)-f(x)$ whenever the endpoint is in the domain. A local [Lipschitz continuity](lipschitz-continuity.md) bound gives both $l(y)\leq L\|y\|$ and $-l(y)=l(-y)\leq L\|y\|$, proving continuity.
