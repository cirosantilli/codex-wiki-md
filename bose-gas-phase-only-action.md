# Bose-gas phase-only action

↑ **Parent:** [Quadratic density-phase action](quadratic-density-phase-action.md)

In the smooth zero-winding long-wave sector, integrate the density [Gaussian integral](gaussian-integral.md) by completing $g(\delta\rho+i\partial_\tau\phi/g)^2/2$. Its field-independent normalization leaves the displayed action. The real-frequency pole is $\omega^2=g\rho_0 k^2/m$, so the [phonon](phonon.md) speed is $\sqrt{g\rho_0/m}$. Keeping density [gradients](gradient.md) yields $\omega^2=g\rho_0k^2/m+k^4/(4m^2)$, matching the [Bogoliubov spectrum](bogoliubov-quasiparticle-dispersion.md).
