# Associative array

↑ **Parent:** [Data structure](data-structure-split.md)

A collection associating keys with values and supporting lookup by key. Unlike an ordered [list](list-abstract-data-type.md) of guarded alternatives, a simple map does not directly represent sequentially evaluated, potentially repeated label expressions with first-match behavior.
