# Boolean variable

↑ **Parent:** [Boolean formula](boolean-formula.md)

A [Boolean variable](boolean-variable.md) takes one of two [truth values](truth-value.md), false or true, encoded as zero or one. It is an input to a [Boolean formula](boolean-formula.md); a [Boolean literal](boolean-literal.md) uses the [Boolean variable](boolean-variable.md) either positively or with [logical negation](negation.md). A [Boolean valuation](boolean-valuation.md) assigns one [truth value](truth-value.md) to each distinct [Boolean variable](boolean-variable.md), so three distinct [Boolean variables](boolean-variable.md) give eight possible complete assignments regardless of how often each appears.
