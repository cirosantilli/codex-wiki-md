# Boolean variable

↑ **Parent:** [Boolean formula](boolean-formula.md)

A Boolean variable takes one of two truth values. It is an input to a [Boolean formula](boolean-formula.md); a [Boolean literal](boolean-literal.md) uses the variable either positively or negated.
