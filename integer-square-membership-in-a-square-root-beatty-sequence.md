# Integer-square membership in a square-root Beatty sequence

↑ **Parent:** [Beatty sequence](beatty-sequence.md)

For positive integers $i,k,r$, the [floor function](floor-function.md) condition $i=\lfloor k\sqrt r\rfloor$ is equivalent to the displayed integer inequalities. Since $r\geq1$, a witness satisfies $k\leq i$. Finding the least $k\geq1$ with $rk^2\geq i^2$ and checking the strict upper bound therefore decides membership by [binary search](binary-search.md). Scanning successive $i$ values with a persistent increasing witness index instead enumerates all values below a bound in [linear time](linear-time.md) arithmetic-operation count. Exact integer comparison avoids floating-point errors near an integer boundary.
