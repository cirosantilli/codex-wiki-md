# Edwards-Anderson order parameter

↑ **Parent:** [Spin glass](spin-glass.md)

The [Edwards-Anderson order parameter](edwards-anderson-order-parameter.md) measures squared local [spin magnetization](spin-magnetization.md) within a selected equilibrium state $\alpha$. Squaring prevents opposite local orientations from cancelling. The state selection and limits matter: the full finite, zero-field [canonical ensemble](canonical-ensemble-split.md) has $\langle s_i\rangle=0$ by [spin inversion symmetry](spin-inversion-symmetry.md), so substituting that average would miss broken-state order.[p. 1, replica and squared-local-moment order parameter; finite-system state selection is distinguished explicitly here](50-years-of-spin-glass-theory-by-david-sherrington-and-scott-kirkpatrick.md)
