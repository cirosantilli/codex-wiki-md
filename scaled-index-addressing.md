# Scaled index addressing

↑ **Parent:** [Addressing mode](addressing-mode.md)

[Scaled index addressing](scaled-index-addressing.md) forms a memory address $B+sI$ from a base $B$ and index $I$. For element size $s=2^k$, a [barrel shifter](barrel-shifter.md) forms the displacement by a [left bit shift](left-bit-shift.md) before the [arithmetic logic unit](arithmetic-logic-unit.md) adds the base. This directly implements [array](array-data-structure.md) indexing without a separate multiplication instruction.
