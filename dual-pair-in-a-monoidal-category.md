# Dual pair in a monoidal category

↑ **Parent:** [Monoidal category](monoidal-category.md)

Objects $X,Y$ with an [evaluation morphism](evaluation-morphism.md) $e:X\otimes Y\to I$ and a [coevaluation morphism](coevaluation-morphism.md) $n:I\to Y\otimes X$ satisfying both [snake identities](snake-identity.md). These are categorical duality data, distinct from the locally convex [dual pair](dual-pair.md).
