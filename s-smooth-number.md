# S-smooth number

↑ **Parent:** [Smooth number](smooth-number.md)

For a finite set $S$ of [primes](prime-number.md), an [integer](integer.md) is $S$-smooth when every prime dividing it belongs to $S$. Bounding the [largest prime factor](largest-prime-factor.md) is equivalent to restricting the integer to be $S$-smooth for a suitable finite $S$.
