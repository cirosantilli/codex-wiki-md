# String data type

↑ **Parent:** [Programming language](programming-language-split.md)

A type representing a finite sequence of characters or other specified text units. Its indexing and encoding conventions depend on the language. Immutable [strings](string.md) can be shared safely by a saved snapshot because later replacement of a variable does not mutate the saved string's contents.
