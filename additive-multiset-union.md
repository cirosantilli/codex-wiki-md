# Additive multiset union

↑ **Parent:** [Multiset](multiset.md)

The operation adding [multiset multiplicities](multiset-multiplicity.md) pointwise. Its result retains all occurrences from both operands. Some sources use the name multiset union instead for pointwise maximum, so a contract should state which operation is meant.
