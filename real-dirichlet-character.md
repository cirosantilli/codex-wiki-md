# Real Dirichlet character

↑ **Parent:** [Dirichlet character](dirichlet-character.md)

A real Dirichlet character takes values in $\{0,1,-1\}$. Its restriction to the unit group has order at most two; if it is nonprincipal, the order is exactly two. A real nonprincipal [primitive Dirichlet character](primitive-dirichlet-character.md) is the character to which a possible [Siegel zero](siegel-zero.md) belongs.
