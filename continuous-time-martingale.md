# Continuous-time martingale

↑ **Parent:** [Martingale](martingale-split.md)

An adapted integrable process $(M_t)_{t\geq0}$ is a continuous-time martingale when $\mathbb E[M_t\mid\mathcal F_s]=M_s$ for every $s\leq t$.
