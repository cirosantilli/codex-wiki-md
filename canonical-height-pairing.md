# Canonical height pairing

↑ **Parent:** [Canonical height of an elliptic curve](canonical-height-of-an-elliptic-curve.md)

The canonical height pairing is $\langle P,Q\rangle=(\widehat h(P+Q)-\widehat h(P)-\widehat h(Q))/2$. The [height parallelogram identity](height-parallelogram-identity.md) makes it bilinear. It descends through torsion and is positive definite on the free part of the [Mordell-Weil group](mordell-weil-group.md). The [Cauchy-Schwarz inequality](cauchy-schwarz-inequality.md) gives $\widehat h(P-Q)\leq2\widehat h(P)+2\widehat h(Q)$, useful for height descent.
