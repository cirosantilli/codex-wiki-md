# Indicator random variable

↑ **Parent:** [Expected value](expected-value-split.md)

An [indicator random variable](indicator-random-variable.md) is the [indicator function](indicator-function.md) of an [event](event.md) $A$ in a [probability space](probability-space-split.md): $\mathbf1_A$ is one when $A$ occurs and zero otherwise. It has a [Bernoulli distribution](bernoulli-distribution.md) with parameter $p=\mathbb P(A)$, so $\mathbb E[\mathbf1_A]=p$ and $\operatorname{Var}(\mathbf1_A)=p(1-p)$. Even an [event](event.md) described without numbers becomes a numerical [random variable](random-variable-split.md) in this way.

For a finite collection of [events](event.md), their [indicator random variables](indicator-random-variable.md) add up to the number that occur. [Linearity of expectation](linearity-of-expectation.md) therefore turns an average count into a sum of [probabilities](probability.md), without requiring [independence](independent-random-variables.md). The [fixed point count of a uniform random permutation](fixed-point-count-of-a-uniform-random-permutation.md) provides an example where the indicators are [dependent random variables](statistical-dependence.md).
