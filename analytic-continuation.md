# Analytic continuation

↑ **Parent:** [Holomorphic function](holomorphic-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Analytic_continuation)

An analytic continuation extends a [holomorphic function](holomorphic-function.md) through overlapping connected open sets while preserving its values on their overlap. Continuation along different paths can produce different germs when the domain contains [branch points](branch-point.md).
