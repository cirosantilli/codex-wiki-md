# Coboundary

↑ **Parent:** [Boundary module](boundary-module.md)

An element in the image of the preceding differential of a [cochain complex](cochain-complex.md). Every [coboundary](coboundary.md) is a [cocycle](cocycle.md), since consecutive differentials compose to zero.
