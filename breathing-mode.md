# Breathing mode

↑ **Parent:** [Normal mode](normal-mode.md)

A breathing mode is a collective [normal mode](normal-mode.md) in which a structure expands and contracts radially while preserving its overall symmetry. For a uniform scaling pattern, the [displacement](displacement.md) of point $i$ is proportional to its position relative to the [center of mass](center-of-mass.md), as displayed above. In a central [spring](spring.md) framework this pattern is a [normal mode](normal-mode.md) only when applying the [stiffness matrix](stiffness-matrix.md) returns a multiple of the same pattern with the appropriate [mass matrix](mass-matrix.md); radial motion alone does not establish an [eigenvector](eigenvector.md).
