# Normal-order beta reduction

↑ **Parent:** [Beta reduction](beta-reduction.md)

Normal-order beta reduction contracts the leftmost outermost [beta-redex](beta-redex.md). If a [lambda term](lambda-term.md) has a [beta-normal form](beta-normal-form.md), this strategy reaches it. It is useful for implementing [Church Boolean](church-boolean.md) conditionals because an unused branch can be discarded before it is evaluated.
