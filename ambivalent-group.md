# Ambivalent group

↑ **Parent:** [Finite group](finite-group.md)

A finite group is ambivalent when every element is conjugate to its inverse. Since every complex character satisfies $\chi(g^{-1})=\overline{\chi(g)}$, an ambivalent group has real values for every [irreducible character](irreducible-character.md). Conversely, if every irreducible value is real, [irreducible characters separate conjugacy classes](irreducible-characters-separate-conjugacy-classes.md) and force every $g$ to be conjugate to $g^{-1}$.
