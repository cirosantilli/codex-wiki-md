# Set identity

↑ **Parent:** [Set](set-split.md)

An equality between [sets](set-split.md) expressed in terms of arbitrary input [sets](set-split.md) that holds for every allowed choice of those inputs. A [double inclusion proof](double-inclusion-proof.md) proves a [set identity](set-identity.md) by proving both [set inclusions](set-inclusion.md). Membership equivalences give another proof: the expressions are equal if and only if each element belongs to either both or neither.
