# Stable causality

↑ **Parent:** [Causal hierarchy](causal-hierarchy.md)

A spacetime is stably causal when its light cones can be widened slightly without creating a [closed timelike curve](closed-timelike-curve.md). Equivalently, it admits a continuous time function strictly increasing along every future-directed causal curve.
