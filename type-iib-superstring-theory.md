# Type IIB superstring theory

↑ **Parent:** [Type II string theory](type-ii-string-theory.md)

A closed [superstring theory](superstring-theory.md) whose left and right Ramond projections have the same ten-dimensional chirality. It has 32 real supercharges and is chiral. Its low-energy fields form [type IIB supergravity](type-iib-supergravity.md). Circle [T-duality](t-duality.md) exchanges this theory with [type IIA superstring theory](type-iia-superstring-theory.md).
