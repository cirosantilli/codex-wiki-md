# Order (group theory)

↑ **Parent:** [Group theory](group-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Order_(group_theory))

In [group theory](group-theory-split.md), order can mean the cardinality of a [group](group-split.md) or the least positive $n$ for which a [group element](group-element.md) $g$ satisfies $g^n=e$. If no such $n$ exists, the element has infinite order. For a [finite group](finite-group.md), [Lagrange's theorem](lagrange-s-theorem.md) implies that each element order divides the group order.
