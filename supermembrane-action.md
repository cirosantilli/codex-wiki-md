# Supermembrane action

↑ **Parent:** [Supermembranes](supermembranes.md)

The first term uses the [induced worldvolume metric](induced-worldvolume-metric.md) from the [supervielbein](supervielbein.md); the second is the [Wess-Zumino brane coupling](wess-zumino-brane-coupling.md) to the super-three-form. Its fermionic dependence is retained before bosonic truncation. The relative charge magnitude equals the [brane tension](brane-tension.md), while $q=\pm1$ sets the orientation and matching [kappa symmetry projector](kappa-symmetry-projector.md) sign. In an on-shell eleven-dimensional supergravity superspace, this action has [kappa symmetry](kappa-symmetry.md).
