# Phase oracle

↑ **Parent:** [Quantum oracle](quantum-oracle.md)

A phase oracle encodes a [Boolean function](boolean-function.md) in the signs of [computational basis](computational-basis.md) states. Its diagonal entries have [modulus](modulus.md) one, so it is a [unitary operator](unitary-operator.md). The usual convention $O_f$ changes the sign when $f(x)=1$. A complemented convention $U_f|x\rangle=(-1)^{f(x)\oplus1}|x\rangle$ instead changes the sign when $f(x)=0$, with $U_f=-O_f$; $\oplus$ denotes [exclusive or](exclusive-or.md). The two conventions differ by a [global phase](global-phase.md) when used without coherent control, but the [global phase of a controlled quantum gate](global-phase-of-a-controlled-quantum-gate.md) makes that difference observable when the [quantum oracle](quantum-oracle.md) is controlled.
