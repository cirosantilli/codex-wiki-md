# Modified Helmholtz adjoint plane wave

↑ **Parent:** [Modified Helmholtz equation](modified-helmholtz-equation.md)

For $k>0$, a nonzero [spectral parameter for a linear boundary value problem](spectral-parameter-for-a-linear-boundary-value-problem.md) gives

$$
v_\lambda=\exp[ik(\lambda z-\overline z/\lambda)/2]=e^{Ax+By},\quad A=ik(\lambda-\lambda^{-1})/2,\quad B=-k(\lambda+\lambda^{-1})/2.
$$

The identity $A^2+B^2=k^2$ proves that this solves the [modified Helmholtz equation](modified-helmholtz-equation.md). The reciprocal companion is $v_{1/\lambda}=\overline{v_{\overline\lambda}}$.
