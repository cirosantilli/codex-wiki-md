# Riemannian holonomy group

↑ **Parent:** [Holonomy](holonomy.md)

For a connected [Riemannian manifold](riemannian-manifold.md), the full holonomy group consists of [parallel transport](parallel-transport.md) maps around all piecewise smooth loops based at $p$. Metric compatibility makes them orthogonal. Basepoint changes conjugate this group by parallel transport. This is full holonomy, not just the subgroup using contractible loops.
