# Uniform quantization error

↑ **Parent:** [Analog-to-digital converter](analog-to-digital-converter.md)

[rounding](rounding.md) an unclipped [voltage](voltage.md) to equally spaced levels of separation $\Delta$ leaves error in $[-\Delta/2,\Delta/2]$. If the fractional position within a conversion interval is uniformly distributed, direct integration gives zero mean and [expectation value](expectation-value.md) $\langle\epsilon^2\rangle=\Delta^2/12$. This is a [statistical model](statistical-model-split.md) for the error, not a claim that the converter adds independent white [noise](noise-signal-processing.md) for every possible input.
