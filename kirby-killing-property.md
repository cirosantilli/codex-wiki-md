# Kirby killing property

↑ **Parent:** [Normalized Kirby color](normalized-kirby-color.md)

In a [modular tensor category](modular-tensor-category.md), a loop with the [normalized Kirby color](normalized-kirby-color.md) encircling a charge-$x$ strand projects onto the [vacuum anyon](vacuum-anyon.md) charge and multiplies it by $\mathcal D$. Indeed, the encircling scalar is $\mathcal D^{-1}\sum_a d_aS_{ax}/S_{1x}$, which equals $\mathcal D\delta_{x1}$ by [unitary matrix](unitary-matrix.md) orthogonality for the [modular S-matrix](modular-s-matrix.md).
