# Nonincreasing function

↑ **Parent:** [Monotonic function](monotonic-function.md)

A [real-valued function](real-valued-function.md) $f:D\to\mathbb R$ is a [nonincreasing function](nonincreasing-function.md) if every pair $x<y$ in its [domain of a function](domain-of-a-function.md) satisfies $f(x)\geq f(y)$. Equal outputs and flat [intervals](interval-mathematics.md) are allowed. For example, $f(x)=-\min(1,\max(0,x))$ is a [nonincreasing function](nonincreasing-function.md), with a falling segment between two flat portions. Requiring $f(x)>f(y)$ instead gives a [strictly decreasing function](strictly-decreasing-function.md). Negating a [nondecreasing function](nondecreasing-function.md) gives a [nonincreasing function](nonincreasing-function.md).

A [nonincreasing](nonincreasing-function.md) [sequence](sequence.md) of [natural numbers](natural-number.md) has finitely many strict drops, so it is eventually constant. This differs from a [strictly decreasing](strictly-decreasing-function.md) [sequence](sequence.md), which cannot continue indefinitely within the [natural numbers](natural-number.md).
