**[Subtype polymorphism](../../../../../subtype-polymorphism.md)** lets a reference with a common supertype denote values of different implementing classes. A call through that reference uses [dynamic dispatch](../../../../../dynamic-dispatch.md) to select the concrete implementation.

**[Parametric polymorphism](../../../../../parametric-polymorphism.md)** defines an operation or data structure using [type parameters](../../../../../type-parameter.md), such as a collection with an element-type parameter. Instantiations retain type information while reusing one generic definition.

**[Ad hoc polymorphism](../../../../../ad-hoc-polymorphism.md)**, commonly expressed by [method overloading](../../../../../method-overloading.md), gives several implementations the same name but different parameter signatures. The compiler selects a suitable overload using the available static types. This selection differs from later [dynamic dispatch](../../../../../dynamic-dispatch.md) on the receiver of a selected [instance method](../../../../../object-method.md). A programming language can support all three in one program.
