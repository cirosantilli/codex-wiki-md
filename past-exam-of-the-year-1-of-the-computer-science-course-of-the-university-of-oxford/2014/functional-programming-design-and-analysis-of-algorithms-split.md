# Functional programming, design and analysis of algorithms

↑ **Parent:** [2014](split.md)

The solutions use the original 17 June 2014 preliminary examination, code `4208`.[original scan, pp. 2–8](../../functional-programming-design-and-analysis-of-algorithms-examination-paper-by-the-university-of-oxford-2014.md) [Haskell](../../haskell.md) definitions use separate question namespaces; names suffixed `F` or `U` distinguish alternative implementations. For Question 4, use `import Prelude hiding (foldr, (++), concat, flip)` when compiling the definitions together. Unless an infinite input is discussed explicitly, inputs are finite and total. Arithmetic operation counts do not include the growing bit costs of exact [integers](../../integer-split.md).[Chapter 9, Standard Prelude; §3.1, undefined values](../../haskell-2010-language-report.md)
