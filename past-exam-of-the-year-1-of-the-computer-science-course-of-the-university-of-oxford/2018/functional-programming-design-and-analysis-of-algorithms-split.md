# Functional programming, design and analysis of algorithms

↑ **Parent:** [2018](split.md)

This is the 12 June 2018 preliminary examination. Questions 1–4 concern [functional programming](../../functional-programming.md); Questions 5–8 concern [algorithm design](../../algorithm-design.md) and [analysis of algorithms](../../analysis-of-algorithms.md). Every printed option is answered here. The complete nine-page native paper is preserved in the [Oxford examination release](https://www.whatdotheyknow.com/request/past_exam_papers_for_1st_year_of/response/1398416/attach/2/Fakour%20Zip%20Final%201.zip?cookie_passthrough=1), member `a10097w1.pdf`; the damaged duplicate rendition is not the source used here.

The [Haskell](../../haskell.md) definitions below use finite total inputs unless [lazy evaluation](../../lazy-evaluation.md), [strict functions](../../strict-function.md) or infinite [lazy lists](../../lazy-list.md) are being discussed. Separate questions use separate namespaces: in particular their `One` constructors are unrelated, and the list-conversion function `abs` in Question 3 is distinct from the numeric [Standard Prelude](../../standard-prelude.md) function. Treat alternative definitions of the same function separately. In a module for Question 2, use `import Prelude hiding (zip, zipWith)`; in one for Question 3, use `import Prelude hiding (abs, reverse, (++))`. Other questions retain the [Standard Prelude](../../standard-prelude.md) operations they use.[§5.6.2: explicitly hiding redefined Prelude names](../../haskell-2010-language-report.md) Costs count constructor, comparison and ordinary arithmetic operations; integer bit costs and evaluating arbitrary element values are separate.
