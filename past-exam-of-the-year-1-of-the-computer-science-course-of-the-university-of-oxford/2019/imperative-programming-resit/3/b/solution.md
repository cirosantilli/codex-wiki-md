The [linked list node](../../../../../linked-list-node.md) needs mutable fields for changing a stored number and rearranging links:
```
class Node(var name: String, var number: String, var next: Node)
```
The implementation will keep its real [linked list nodes](../../../../../linked-list-node.md) private to the `Book` object and will not return [linked list node](../../../../../linked-list-node.md) references to clients.
