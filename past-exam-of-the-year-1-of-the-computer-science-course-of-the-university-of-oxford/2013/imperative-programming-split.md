# Imperative programming

↑ **Parent:** [2013](split.md)

Solutions to all eight questions of the 12 June 2013 paper. The [Scala](../../scala.md) code uses the paper's Scala 2 conventions. Arithmetic is exact unless a machine type is explicitly discussed; in particular, Question 1 permits ignoring [integer overflow](../../integer-overflow.md). Each code block extends the implementation introduced in its question, unless it supplies a complete replacement.[Cover and printed pp. 2–11, Questions 1–8](../../imperative-programming-examination-paper-by-the-university-of-oxford-2013.md)
