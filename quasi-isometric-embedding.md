# Quasi-isometric embedding

↑ **Parent:** [Quasi-isometry](quasi-isometry.md)

A quasi-isometric embedding satisfies the two-sided coarse distance inequality in the definition of [quasi-isometry](quasi-isometry.md), without requiring its image to be coarsely dense.
