# Fluorescence from a uniformly moving cloud

↑ **Parent:** [Fluorescence](fluorescence-split.md)

For a compact cloud passing a stationary source at distance $L$, put $r(t)=\sqrt{L^2+v^2t^2}$ and $s=vt/r$. Incoming and returning rays have opposite [Doppler factors](doppler-factor.md). Source return time is $t_R=t+r/c$. If $q=f_0/f<1$, line-centre excitation is possible above $\beta=(1-q^2)/(1+q^2)$ and occurs at closest approach when $\beta=\sqrt{1-q^2}$. In a weak, optically thin, isotropic [spontaneous emission](spontaneous-emission.md) model, the excited population obeys $\dot N_*=P_{\rm abs}-N_*/(\gamma\tau)$ and the received bolometric intensity scales as $D_{\rm out}^4N_*/(\tau r^2)$. Finite lifetime and line width smear the pulse and its frequency chirp; geometry and source strength are needed for an absolute prediction.
