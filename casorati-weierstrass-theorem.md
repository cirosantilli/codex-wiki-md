# Casorati-Weierstrass theorem

↑ **Parent:** [Essential singularity](essential-singularity.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Casorati–Weierstrass_theorem)

Near an isolated [essential singularity](essential-singularity.md), a [holomorphic function](holomorphic-function.md) has dense image in the complex plane. If it avoided a disk about $w$, then $1/(f-w)$ would be bounded and extend across the singularity by the [Riemann removable singularity theorem](riemann-removable-singularity-theorem.md). If its extended value is nonzero, $f$ extends holomorphically; if zero, its finite-order zero makes $f$ a pole. Either contradicts an essential singularity.
