# Sublinear operator

↑ **Parent:** [Functional analysis](functional-analysis-split.md)

A nonnegative function-valued operator $S$ is sublinear if $S(f+g)\leq S(f)+S(g)$ and $S(cf)=|c|S(f)$ [almost everywhere](almost-everywhere.md). This pointwise domination notion includes maximal [one-sided interval averaging operators](one-sided-interval-averaging-operator.md) and differs from requiring an ordinary [linear map](linear-map.md).
