# Thiocyanate-mediated thiirane inversion

↑ **Parent:** [Thiirane](thiirane.md)

Sequential ring opening, five-membered cyclic imidodithiocarbonate formation, cleavage and reclosure can exchange the [thiirane](thiirane.md) [sulfur](sulfur.md) with the [thiocyanate](thiocyanate.md) [sulfur](sulfur.md). Backside substitution at both ring [carbons](carbon.md) reverses the [thiirane](thiirane.md) face while leaving remote stereocentres intact.
