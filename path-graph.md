# Path graph

↑ **Parent:** [Path in a graph](path-in-a-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Path_graph)

A path graph $P_n$ has $n$ vertices in a single chain and $n-1$ edges. Its endpoint [graph distance](distance-graph-theory.md) is $n-1$ and, with unit resistances, its endpoint [effective resistance](effective-resistance.md) is also $n-1$.
