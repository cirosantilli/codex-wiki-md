# First-event versus recurrent-event baseline stratification

↑ **Parent:** [Stratified Cox model](stratified-cox-model.md)

Separate first-event episodes from all later episodes with a stratum indicator. A [Stratified Cox model](stratified-cox-model.md) permits one [baseline hazard](baseline-hazard.md) for first events and another for recurrent events while retaining a common treatment coefficient. Later episodes can share their baseline; stratifying each recurrence number separately is a stronger model than the first-versus-later distinction alone.
