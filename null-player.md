# Null player

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

A [null player](null-player.md) has zero [marginal contribution](marginal-contribution.md) to every [coalition](coalition-game-theory.md). The axiom for a [null player](null-player.md) requires allocating that player zero. This is the zero-marginal convention used here.
