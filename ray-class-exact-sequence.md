# Ray class exact sequence

↑ **Parent:** [Ray class group](ray-class-group.md)

For a finite modulus $\mathfrak m$, there is an exact sequence

$$
\mathcal O_K^\times\longrightarrow
(\mathcal O_K/\mathfrak m)^\times\longrightarrow
\operatorname{Cl}_{\mathfrak m}(K)\longrightarrow
\operatorname{Cl}(K)\longrightarrow1.
$$

With real places in the modulus, the residue-unit term and the unit map also record the required signs.
