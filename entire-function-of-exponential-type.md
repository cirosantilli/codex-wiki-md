# Entire function of exponential type

↑ **Parent:** [Entire function](entire-function.md)

An [entire function](entire-function.md) is of exponential type if constants $A,B>0$ give the displayed bound everywhere. A genus-zero [canonical product](canonical-product.md) with $\sum_n|a_n|^{-1}<\infty$ obeys $|\prod_n(1-z/a_n)|\le\exp(|z|\sum_n|a_n|^{-1})$, since $1+u\le e^u$ for $u\ge0$.
