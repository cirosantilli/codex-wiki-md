# Cluster weight in the random-cluster model

↑ **Parent:** [Random-cluster model](random-cluster-model.md)

The multiplicative factor $q$ assigned to each [connected component of a graph](component-graph-theory.md) in a finite [random-cluster measure](random-cluster-model.md). At fixed [edge](edge-of-a-graph.md) [probability](probability.md), the weight of a configuration with $k$ components includes $q^k$. For $q=1$ this reduces to independent [bond percolation](bond-percolation-split.md); increasing $q$ at fixed $p$, for $q\ge1$, suppresses [increasing events](increasing-event.md) by [random-cluster weight monotonicity](random-cluster-weight-monotonicity.md).
