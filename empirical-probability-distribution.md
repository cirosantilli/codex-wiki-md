# Empirical probability distribution

↑ **Parent:** [Finite probability distribution](finite-probability-distribution.md)

For a nonempty finite sample, assign each distinct observed value its relative frequency. The observed values form the finite positive-mass support; the counts sum to the sample size, so the [probabilities](probability.md) sum to one. Repeated observations increase the same outcome's mass rather than adding repeated support entries.
