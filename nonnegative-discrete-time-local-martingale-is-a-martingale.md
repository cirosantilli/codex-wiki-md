# Nonnegative discrete-time local martingale is a martingale

↑ **Parent:** [Integrable discrete-time local martingale is a martingale](integrable-discrete-time-local-martingale-is-a-martingale.md)

The [Fatou lemma](fatou-s-lemma.md) makes every time value of a nonnegative discrete-time [local martingale](local-martingale.md) integrable, assuming the usual integrable initial value. The integrable discrete-time result then makes it a true [martingale](martingale-split.md).
