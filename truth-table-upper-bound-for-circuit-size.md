# Truth-table upper bound for circuit size

↑ **Parent:** [Circuit size class](circuit-size-class.md)

OR together one minterm for each accepted length-$n$ input. Each minterm is an AND of the appropriate [Boolean literals](boolean-literal.md). There are at most $2^n$ minterms, and their negated input wires can be shared, giving $O(n2^n)$ bounded-fan-in gates. This is a nonuniform existence statement, not an algorithm for determining an [undecidable](undecidable-decision-problem.md) truth table.
