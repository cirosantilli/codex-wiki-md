# Decision node

↑ **Parent:** [Binary decision diagram](binary-decision-diagram.md)

An internal [vertex](vertex-graph-theory.md) that tests a condition and selects an outgoing branch. In a [binary decision diagram](binary-decision-diagram.md), a [decision node](decision-node.md) tests a [Boolean variable](boolean-variable.md) and has one zero arrow and one one arrow.
