# Continuation (computer science)

↑ **Parent:** [Programming language semantics](programming-language-semantics.md)

A representation of the rest of a computation. In [continuation-passing style](continuation-passing-style.md), a computation receives a [function](function-split.md) telling it how to use its result. An explicit [computer memory](computer-memory-split.md) argument can be supplied when the [continuation](continuation-computer-science.md) is invoked, so capturing control need not capture a snapshot of [computer memory](computer-memory-split.md).
