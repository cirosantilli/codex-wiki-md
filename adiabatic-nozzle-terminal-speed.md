# Adiabatic nozzle terminal speed

↑ **Parent:** [Isentropic nozzle flow](isentropic-nozzle-flow.md)

For a lossless [polytropic flow](polytropic-flow.md) with $\gamma>1$, negligible [gravity](gravity.md) and a sonic throat, the [Bernoulli function](bernoulli-function.md) is $u^2/2+c_s^2/(\gamma-1)=(\gamma+1)c_*^2/[2(\gamma-1)]$. On an expanding supersonic branch for which $\rho\to0$, the [specific enthalpy](specific-enthalpy.md) vanishes and the limiting [velocity](velocity.md) is the displayed value. If area grows as $Cr^2$, [mass conservation](mass-conservation.md) further gives $\rho\sim\dot M/(Cu_\infty r^2)$. A subsonic pressure-confined branch need not have this asymptotic behavior.
