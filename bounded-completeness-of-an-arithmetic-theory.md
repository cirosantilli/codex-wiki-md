# Bounded completeness of an arithmetic theory

↑ **Parent:** [First-order theory](first-order-theory.md)

An [arithmetic theory](first-order-theory.md) is [bounded-complete](bounded-completeness-of-an-arithmetic-theory.md) if it proves every true closed formula with only bounded [quantifiers](quantifier.md). It then proves every true [Sigma-1](sigma-1-formula.md) sentence by choosing a standard witness. If it is also [consistent](consistent-first-order-theory.md), it cannot prove a false [Pi-1](pi-1-formula.md) sentence: a standard bounded counterexample supplies a provable [contradiction](contradiction.md) to that universal theorem. This arithmetic condition is distinct from [bounded completeness](bounded-completeness-of-an-arithmetic-theory.md) of a statistical [model](model-of-a-first-order-theory.md) or family.
