# Column-major order

↑ **Parent:** [Array (data structure)](array-data-structure.md)

Storage of a multidimensional [array](array-data-structure.md) with the first index varying fastest in consecutive positions. In a two-dimensional [array](array-data-structure.md), each column is contiguous. Traversing a [row-major](row-major-order.md) [array](array-data-structure.md) by columns does not change its storage into [column-major order](column-major-order.md).
