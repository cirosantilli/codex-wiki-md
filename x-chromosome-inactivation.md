# X-chromosome inactivation

↑ **Parent:** [Gene expression](gene-expression.md)

Silencing of much of one X chromosome in a cell lineage. In a heterozygous [retina](retina.md) it can create a mosaic of cells expressing different X-linked [opsin](opsin.md) variants. That mosaic provides potential spectral diversity but does not by itself establish [tetrachromacy](tetrachromacy.md).
