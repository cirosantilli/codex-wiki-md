# Axiom of power set

↑ **Parent:** [Set theory](set-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Axiom_of_power_set)

For every set $x$ there is a set $\mathcal P(x)$ whose members are exactly the subsets of $x$.
