# Modulo operation

↑ **Parent:** [Modular arithmetic](modular-arithmetic-split.md)

For an [integer](integer-split.md) $a$ and a positive [integer modulus](modulus-in-modular-arithmetic.md) $m$, the modulo operation returns the unique [least nonnegative residue](least-nonnegative-residue.md) $r$ satisfying $a=qm+r$ for an [integer](integer-split.md) $q$ and $0\leq r<m$. Equivalently, $r=a-m\lfloor a/m\rfloor$. For example, $-3\bmod5=2$. Some programming languages instead use a remainder with the sign of the dividend, so their negative-input convention must be checked before identifying an operator with this mathematical definition.
