# Projectile

↑ **Parent:** [Projectile motion](projectile-motion.md)

An object launched into motion whose subsequent trajectory is determined by external forces. The ideal elementary [projectile motion](projectile-motion.md) model retains uniform [gravity](gravity.md) and neglects [air resistance](air-resistance.md).
