# Limit superior of sets

↑ **Parent:** [Set-theoretic limit](set-theoretic-limit.md)

Membership means that for every index $N$ there is a later $n\geq N$ with $x\in E_n$, equivalently membership for infinitely many indices. If $\sum_n\mu(E_n)<\infty$, [countable subadditivity](countable-subadditivity-of-a-measure.md) gives $\mu(\limsup E_n)\leq\sum_{n\geq N}\mu(E_n)\to0$. This is the measure form of the first [Borel-Cantelli lemma](borel-cantelli-lemmas.md), and requires no independence assumption.
