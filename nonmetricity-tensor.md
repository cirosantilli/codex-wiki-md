# Nonmetricity tensor

↑ **Parent:** [Affine connection](affine-connection.md)

Given a [metric tensor](metric-tensor.md) and an [affine connection](affine-connection.md), $N_{ab c}=\nabla_cg_{ab}$ measures failure of [metric compatibility](metric-compatibility.md). It is symmetric in $a,b$. Some authors instead define nonmetricity as $-\nabla g$, so formulas must specify the sign. Together with the [torsion tensor](torsion-tensor.md), it determines the difference from the [Levi-Civita connection](levi-civita-connection.md).
