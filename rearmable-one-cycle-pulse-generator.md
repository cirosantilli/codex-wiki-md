# Rearmable one-cycle pulse generator

↑ **Parent:** [Moore machine](moore-machine.md)

A [synchronous sequential circuit](synchronous-sequential-circuit.md) can use three states: armed, pulse, and waiting. Only the pulse state has output one. A reset input rearms the circuit, including when it arrives during the pulse cycle; this permits pulses on alternate [clock cycles](clock-cycle.md) while each pulse still lasts exactly one cycle.
