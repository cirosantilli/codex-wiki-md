# Single-level grand partition function in the dilute limit

↑ **Parent:** [Grand canonical partition function](grand-canonical-partition-function.md)

For a single [one-particle state](one-particle-state.md) with $x_k\ll1$, the empty and singly occupied contributions dominate. A [fermion](fermion.md) state gives $\Xi_k=1+x_k$, a [boson](boson.md) state gives $(1-x_k)^{-1}$, and [Maxwell–Boltzmann statistics](maxwell-boltzmann-statistics.md) give $e^{x_k}$. Thus all have the same leading dilute response, $\ln\Xi_k=x_k+O(x_k^2)$. This approximation does not impose an exclusion principle on classical particles.
