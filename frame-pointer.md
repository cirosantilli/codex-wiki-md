# Frame pointer

↑ **Parent:** [Stack frame](stack-frame.md)

A [processor register](processor-register.md) or equivalent value designating a stable reference location within the current [stack frame](stack-frame.md). Parameters, local variables and saved links can be accessed at fixed offsets from the [frame pointer](frame-pointer.md) even if the evaluation [stack](stack-data-structure.md) changes height.
