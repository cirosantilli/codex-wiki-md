# Binary phase representation of a Pauli string

↑ **Parent:** [Pauli group](pauli-group.md)

Store a [Pauli group](pauli-group.md) element with binary exponents $a_j,b_j$ and a phase exponent $s$ modulo four. This ordered $XZ$ convention uses $2n+2$ bits for $n$ [qubits](qubit.md). Since $XZ=-iY$, phase factors are essential when converting to Hermitian [Pauli operators](pauli-operator.md) and evaluating measurement probabilities.
