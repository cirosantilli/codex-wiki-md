# Subformula

↑ **Parent:** [Propositional formula](propositional-formula.md)

A [subformula](subformula.md) is a constituent [propositional formula](propositional-formula.md) in a formula's recursive construction, including the whole formula itself. For an atomic variable the only [subformula](subformula.md) is itself; for $\neg A$, add $\neg A$ to the [subformulas](subformula.md) of $A$; for a binary connective, add the combined formula to the union of the two operands' [subformulas](subformula.md). The set of distinct [subformulas](subformula.md) can have smaller cardinality than the number of occurrences in the [abstract syntax tree](abstract-syntax-tree.md) when the same expression appears more than once.
