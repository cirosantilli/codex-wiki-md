# Contraction property under equivalent metrics

↑ **Parent:** [Contraction mapping](contraction-mapping.md)

The same self-map can be a [contraction mapping](contraction-mapping.md) for one metric but not for a [bilipschitz equivalent](bilipschitz-equivalence.md) metric. On three points with distances $d'(x,y)=d'(x,z)=2$, $d'(y,z)=1$, the map $f(x)=y$, $f(y)=f(z)=z$ has Lipschitz constant $1/2$. For the [discrete metric](discrete-metric.md), its Lipschitz constant is one. The metrics satisfy $d\le d'\le2d$, so they preserve topology and completeness but not the strict numerical contraction condition. A [contraction mapping theorem](contraction-mapping-theorem.md) fixed-point proof therefore needs the specified metric and its contraction constant.
