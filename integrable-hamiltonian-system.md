# Integrable Hamiltonian system

↑ **Parent:** [Hamiltonian mechanics](hamiltonian-mechanics.md)

Liouville integrability means having $n$ almost-everywhere independent first integrals in mutual Poisson involution.

For a Hamiltonian phase space of dimension $2n$, Liouville integrability means $n$ functionally independent conserved quantities with pairwise vanishing [Poisson brackets](poisson-bracket.md). This is the Hamiltonian specialization of [integrable systems](integrable-systems-split.md).
