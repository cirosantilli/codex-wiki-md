# Half-angle boost aberration of a null spinor

↑ **Parent:** [Relativistic aberration](relativistic-aberration.md)

The [spinor](spinor.md) boost $\operatorname{diag}(e^{\kappa/2},e^{-\kappa/2})$ changes the component-magnitude ratio by $e^{-\kappa}$. The associated active positive-$z$ [Lorentz boost](lorentz-boost.md) therefore changes the polar half-angle as displayed and leaves [azimuth](azimuth.md) unchanged. Its null-vector [time](time-in-physics.md) scale changes by $\cosh\kappa+\sinh\kappa\cos\theta$, which must be retained separately when normalizing a [spinor](spinor.md) to encode direction.
