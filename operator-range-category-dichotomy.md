# Operator range category dichotomy

↑ **Parent:** [Open mapping theorem (functional analysis)](open-mapping-theorem-functional-analysis.md)

A [bounded linear operator](continuous-linear-operator.md) $T:X\to Y$ from a [Banach space](banach-space-split.md) to a [normed space](normed-vector-space-split.md) either maps onto $Y$ or has [meagre set](meagre-set.md) image in $Y$. To prove this, write $T(X)=\bigcup_{n\geq1}T(n\overline B_X)$. If every $\overline{T(n\overline B_X)}$ has empty [interior](interior-topology.md), each term is a [nowhere dense set](nowhere-dense-set.md). Otherwise scaling and [geometric correction for approximate surjectivity](geometric-correction-for-approximate-surjectivity.md) place a [ball](ball-mathematics.md) about zero inside $T(\overline B_X)$; the [vector subspace](vector-subspace.md) $T(X)$ then equals $Y$. In particular a nonclosed operator image is a [meagre set](meagre-set.md). A proper closed operator image is also a [meagre set](meagre-set.md), so the closed/meagre alternatives need not be exclusive.
