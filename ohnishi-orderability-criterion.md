# Ohnishi orderability criterion

↑ **Parent:** [Linearly ordered group](linearly-ordered-group.md)

A [group](group-split.md) admits a two-sided invariant [total order](total-order.md) exactly when every finite list of nonidentity elements can be signed so that the conjugation-invariant [semigroup](semigroup.md) generated by the signed elements excludes the identity. A [compactness theorem](compactness-theorem.md) argument supplies a compatible global sign assignment. Omitting the conjugates changes the criterion to a different orderability problem.
