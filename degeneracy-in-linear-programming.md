# Degeneracy in linear programming

↑ **Parent:** [Basic feasible solution](basic-feasible-solution.md)

A [basic feasible solution](basic-feasible-solution.md) is degenerate when one or more of its basic variables is zero. A [simplex algorithm](simplex-algorithm.md) pivot may then change the basis without moving the feasible point or changing the objective. Assignment networks force many zero-flow basic tree arcs.
