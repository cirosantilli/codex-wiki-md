# Spin-reflection ambiguity in a gamma cascade

↑ **Parent:** [Missing gamma lines and matrix-element hindrance](missing-gamma-lines-and-matrix-element-hindrance.md)

If a cascade determines only absolute [spin](spin.md) differences relative to a known reference [spin](spin.md), reflection of all inferred [spins](spin.md) around that reference can preserve the same multipole pattern. Nonnegative-spin constraints, independently known [spins](spin.md), angular correlations or [polarization](polarization-waves.md) measurements may break the ambiguity. A set of line energies and lowest-multipole labels need not do so.
