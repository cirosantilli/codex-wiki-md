# Wave-action transport for a variable-speed wave

↑ **Parent:** [Eikonal equation for a variable-speed wave](eikonal-equation-for-a-variable-speed-wave.md)

The first-order imaginary balance of the [wave equation](wave-equation-split.md) in [geometrical optics](geometrical-optics.md) gives $\partial_T(\omega A^2)+\nabla\cdot(c^2\mathbf k A^2)=0$ for a real leading [amplitude](wave-amplitude.md). The action density $\omega A^2$ travels with the [group velocity](group-velocity.md) $c^2\mathbf k/\omega$. For a complex [amplitude](wave-amplitude.md) replace $A^2$ by $|A|^2$.
