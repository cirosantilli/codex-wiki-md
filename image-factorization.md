# Image factorization

↑ **Parent:** [Subobject](subobject.md)

An image of $f:A\to B$ is the least [subobject](subobject.md) $m:I\hookrightarrow B$ through which $f$ factors. In a [category](category-split.md) with [pullback in a category](pullback-category-theory.md) constructions this gives a [strong epimorphism](strong-epimorphism.md)–[monomorphism](monomorphism.md) factorization $f=me$: pull back any mono in a lifting square for $e$ to $I$; minimality of the image forces the resulting mono to be invertible, producing a diagonal. Conversely, the lifting property of the strong part proves minimality. No stability under pullback is asserted; that is an additional property in a [regular category](regular-category.md).
