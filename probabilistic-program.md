# Probabilistic program

↑ **Parent:** [Probabilistic programming](probabilistic-programming.md)

A [probabilistic program](probabilistic-program.md) maps elementary random choices to outputs and observation weights. Its mathematical meaning can be specified by the [pushforward measure](pushforward-measure.md) on outputs, normalized after conditioning when the observation has finite positive mass. Different random-choice spaces can implement the same output law.
