# Minmax payoff

↑ **Parent:** [Repeated game](repeated-game.md)

The lowest [expected payoff](expected-payoff.md) to which a player's opponents can hold that player when the player chooses a [best response](best-response.md). The opponents' permitted randomization and correlation conventions should be specified for games with several opponents. In a two-player finite game, this equals the player's maximum guaranteed [expected payoff](expected-payoff.md) by the [minimax theorem](minimax-theorem.md) applied to that player's payoff matrix. This equality does not make the original two-player game a [zero-sum game](zero-sum-game.md).
