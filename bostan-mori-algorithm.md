# Bostan-Mori algorithm

↑ **Parent:** [Algorithm](algorithm-split.md)

The Bostan-Mori algorithm extracts a distant coefficient from a [rational generating function](rational-generating-function.md) $P(x)/Q(x)$ by multiplying both by $Q(-x)$. The new denominator is even; retaining the appropriate even or odd numerator coefficients halves the coefficient index at each step.
