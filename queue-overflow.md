# Queue overflow

↑ **Parent:** [Queue (queueing theory)](queue-queueing-theory.md)

An arrival exceeds the available service and storage capacity, causing work to be lost or blocked. For a [bufferless queue](bufferless-queue.md) with capacity $c$ per slot, overflow means input work strictly greater than $c$. Stationary [queue workload](workload-of-a-queue.md) tails in an infinite-buffer comparison model are often used to estimate finite-buffer overflow probabilities.
