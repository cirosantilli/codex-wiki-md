# Pointwise alpha-prescription obstruction in a radiation-supported layer

↑ **Parent:** [Alpha disk](alpha-disk.md)

In the exact constant-[opacity](opacity.md), pure-[radiation pressure](radiation-pressure.md) diffusion model, [dynamic viscosity](dynamic-viscosity.md) is height-independent. Imposing an additional exact pointwise relation $\mu\propto p(z)$ forces constant pressure, incompatible with nonzero vertical [hydrostatic equilibrium](hydrostatic-equilibrium.md) away from the midplane. The characteristic-pressure [alpha disk](alpha-disk.md) prescription can still be used for order-of-magnitude scalings; it is not an exact simultaneous vertical solution.
