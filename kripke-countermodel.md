# Kripke countermodel

↑ **Parent:** [Kripke forcing relation](kripke-forcing-relation.md)

A Kripke countermodel to a formula $A$ is a [Kripke model for intuitionistic propositional logic](kripke-model-for-intuitionistic-propositional-logic.md) containing a world $w$ such that $w\nVdash A$.
