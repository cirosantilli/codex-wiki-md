# Polynomial evaluation

↑ **Parent:** [Polynomial](polynomial-split.md)

[Polynomial evaluation](polynomial-evaluation.md) replaces the [indeterminate](indeterminate.md) of a [polynomial](polynomial-split.md) by an input value. For a fixed [scalar](scalar.md) $a$, the rule $E_a:p\mapsto p(a)$ is a [linear functional](linear-functional.md) on a [vector space](vector-space-split.md) of [polynomials](polynomial-split.md), because evaluating a [linear combination](linear-combination.md) gives the same [linear combination](linear-combination.md) of the values. For $p(t)=1+2t+3t^2$, evaluation at zero gives one and evaluation at two gives seventeen. [Polynomial interpolation](polynomial-interpolation.md) uses these measurements to reconstruct a [polynomial](polynomial-split.md) subject to a [polynomial degree](degree-of-a-polynomial.md) bound.
