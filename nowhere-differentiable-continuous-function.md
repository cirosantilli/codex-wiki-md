# Nowhere differentiable continuous function

↑ **Parent:** [Baire category theorem](baire-category-theorem.md)

A nowhere differentiable continuous function is continuous at every point and has no finite derivative anywhere. A Baire-category argument shows that such functions form a dense subset of $C([0,1])$ in the [uniform norm](supremum-norm.md).
