# Completion of a valued field

↑ **Parent:** [Absolute value (algebra)](absolute-value-algebra.md)

The metric completion of a [field](field.md) for an [absolute value on a field](absolute-value-algebra.md) is formed from Cauchy sequences modulo sequences tending to zero. Addition and multiplication extend continuously, and every nonzero completed element is invertible, so the result remains a [field](field.md). The [absolute value on a field](absolute-value-algebra.md) extends uniquely. A place of a [number field](number-field.md) determines the corresponding completion $K_v$.
