# Irrefutable pattern

↑ **Parent:** [Pattern matching](pattern-matching.md)

A pattern that does not force its matched value merely to establish the match. A [Haskell](haskell.md) pattern written with `~` can defer evaluation of a recursive pair until one component is demanded. This can preserve [productivity](stream-productivity.md) in definitions involving [lazy evaluation](lazy-evaluation.md). It does not make every later use of the components terminate.
