# Spirodienone

↑ **Parent:** [Spiro compound](spiro-compound.md)

A spirocyclic framework containing a dienone ring. An acid-promoted [dienone-phenol rearrangement](dienone-phenol-rearrangement.md) can convert a suitably substituted spiro framework into fused-ring connectivity.
