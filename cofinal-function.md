# Cofinal function

↑ **Parent:** [Cofinality](cofinality.md)

A function $f:\beta\to\alpha$ between ordinals is cofinal when its range is unbounded in $\alpha$: for every $\gamma<\alpha$ some $\xi<\beta$ satisfies $\gamma\leq f(\xi)$.
