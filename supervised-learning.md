# Supervised learning

↑ **Parent:** [Statistical learning](statistical-learning-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Supervised_learning)

Supervised learning fits a prediction rule from [training data](training-data.md) containing both inputs and associated target responses. [Regression analysis](regression-analysis.md) predicts numerical responses; [classification in statistical learning](classification-in-statistical-learning.md) predicts class labels. A [loss function](loss-function.md) specifies which prediction errors matter, and [generalization](generalization-in-statistical-learning.md) concerns performance beyond the observations used to fit the rule.
