# Matrix similarity

↑ **Parent:** [Linear algebra](linear-algebra-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Matrix_similarity)

Square matrices $A$ and $B$ are similar when $B=P^{-1}AP$ for some invertible matrix $P$. They represent the same linear operator in different bases and therefore have the same [Jordan normal form](jordan-normal-form.md).
