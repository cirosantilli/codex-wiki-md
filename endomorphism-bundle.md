# Endomorphism bundle

↑ **Parent:** [Vector bundle](vector-bundle.md)

The [vector bundle](vector-bundle.md) whose fibre at $p$ consists of linear maps $E_p\to E_p$. If a [local frame](frame-of-a-vector-bundle.md) changes by $e'=eg$, the coefficient matrix of an [endomorphism](endomorphism.md) changes by $T'=g^{-1}Tg$, giving smooth fibre-linear transitions. For a [line bundle](line-bundle.md) this bundle is canonically the trivial scalar bundle, because every fibre endomorphism is scalar multiplication. A [connection on a vector bundle](connection-vector-bundle.md) induces the [endomorphism bundle connection](endomorphism-bundle-connection.md).
