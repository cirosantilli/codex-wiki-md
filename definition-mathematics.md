# Definition (mathematics)

↑ **Parent:** [Mathematical logic](mathematical-logic-split.md)

A mathematical definition fixes the meaning of a term or symbol using previously specified concepts. A definition by a [universal property](universal-property.md) can still require a [mathematical proof](mathematical-proof.md) that an object with that property exists. For example, the definition of a [product in a category](product-category-theory.md) specifies its mapping behavior, while existence is a further question about that [category](category-split.md).
