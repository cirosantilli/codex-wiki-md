# Spin configuration

↑ **Parent:** [Spin model](spin-model-split.md)

A [spin configuration](spin-configuration.md) specifies the [spin](spin.md) variable at every site of a [spin model](spin-model-split.md). For $N$ [Ising spins](ising-spin-variable.md), it is a member of $\{-1,1\}^N$.
