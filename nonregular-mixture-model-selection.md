# Nonregular mixture model selection

↑ **Parent:** [Model selection](model-selection.md)

Testing the number of components in a [finite mixture model](finite-mixture-model.md) is nonregular: absent components have zero weights on the parameter boundary and their means or other parameters are unidentified. The usual chi-squared limit for a [likelihood-ratio test](likelihood-ratio-test.md) therefore need not apply. Information criteria are useful working comparisons, while parametric bootstrap and predictive [cross-validation](cross-validation.md) can provide more appropriate evidence. Neither a mixture fit nor a selected component count proves genuine latent populations.
