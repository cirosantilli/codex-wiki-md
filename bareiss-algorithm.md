# Bareiss algorithm

↑ **Parent:** [Gaussian elimination](gaussian-elimination.md)

A fraction-free elimination [algorithm](algorithm-split.md) for exact [determinants](determinant.md). At each stage it divides a cross-multiplied update by the preceding pivot; the determinantal identities underlying the method make this division exact when its pivot assumptions hold. Pivoting handles zero pivots.
