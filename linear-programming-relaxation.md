# Linear programming relaxation

↑ **Parent:** [Linear programming](linear-programming-split.md)

Remove the integrality requirements from an [integer program](integer-programming.md) while retaining its [linear inequalities](linear-inequality.md) and variable bounds. Every original [feasible point](feasible-point.md) remains feasible. Thus the relaxed optimum is an upper bound for a maximization problem and a lower bound for a minimization problem. An optimal relaxed [feasible point](feasible-point.md) need not have integer coordinates. Variable bounds that were implied only by an informal declaration such as binary must be made explicit before removing integrality.
