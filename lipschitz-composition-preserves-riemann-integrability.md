# Lipschitz composition preserves Riemann integrability

↑ **Parent:** [Riemann integrability criterion](riemann-integrability-criterion.md)

If $f$ is [Riemann integrable](riemann-integrable-function.md) and $g$ is Lipschitz on an interval containing the range of $f$, then $g\circ f$ is [Riemann integrable](riemann-integrable-function.md). With Lipschitz constant $K$, the oscillation on each partition cell satisfies $\operatorname{osc}(g\circ f)\leq K\operatorname{osc}(f)$, and hence the gap between [Darboux sums](darboux-sum.md) is multiplied by at most $K$. A continuously differentiable $g$ is Lipschitz on each closed bounded interval by the [mean value theorem](mean-value-theorem.md) and the [extreme value theorem](extreme-value-theorem.md) applied to $g'$.
