# Hereditary graph property

↑ **Parent:** [Graph property](graph-property.md)

A hereditary [graph](graph-split.md) property is closed under taking [induced subgraphs](induced-subgraph.md). It can be described by forbidden induced [graphs](graph-split.md). Unlike subgraph closure, this condition allows [edges](edge-of-a-graph.md) to be essential to membership. Its [colouring number of a hereditary graph property](colouring-number-of-a-hereditary-graph-property.md) governs its quadratic enumeration rate.
