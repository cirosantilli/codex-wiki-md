# Input impedance

↑ **Parent:** [Electrical impedance](electrical-impedance.md)

[Input impedance](input-impedance.md) is the ratio of a small applied input-voltage [phasor](phasor.md) to the resulting input-current [phasor](phasor.md), with the output termination and operating point specified. A finite [input impedance](input-impedance.md) loads a voltage source. For an [ideal operational amplifier](ideal-operational-amplifier.md) the [input impedance](input-impedance.md) is infinite, so neither input terminal draws current.
