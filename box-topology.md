# Box topology

↑ **Parent:** [Product topology](product-topology.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Box_topology)

The box topology on $\prod_{i\in I}X_i$ has a [basis of a topology](basis-of-a-topology.md) consisting of all [Cartesian products](cartesian-product.md) $\prod_iU_i$ with every $U_i$ an [open set](open-set.md) in $X_i$; infinitely many coordinates may be restricted. It contains the [product topology](product-topology.md) and agrees with it for finite $I$.[Lecture 12, Exercise 12.1.2(1)-(2), printed page 43: box basis, comparison with the product topology, and finite-factor equality](18-901-fall-2024-lecture-notes.md)

For copies of the usual [real line](real-line.md), the [box topology](box-topology.md) is strictly finer when $I=\mathbb N$. The box $W=\prod_{j\geq1}(-1/2,1/2)$ is not an [open set](open-set.md) in the [product topology](product-topology.md): a basic [cylinder set](cylinder-set.md) containing zero leaves some coordinate $j$ unrestricted, so it contains $e_j\notin W$. This is a construction for every finite coordinate set, not evidence from testing a finite prefix.
