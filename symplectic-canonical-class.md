# Symplectic canonical class

↑ **Parent:** [First Chern class](first-chern-class.md)

The symplectic canonical class is the negative [First Chern class](first-chern-class.md) of the tangent bundle for a [compatible almost complex structure](compatible-almost-complex-structure.md). The [contractibility of compatible almost complex structures](contractibility-of-compatible-almost-complex-structures.md) makes it independent of that choice. It is the class appearing in the [symplectic adjunction formula](symplectic-adjunction-formula.md).
