# Hom-set detection of categorical limits

↑ **Parent:** [Categorical limit](categorical-limit.md)

A [categorical cone](cone-over-a-diagram.md) $L\to E_i$ is a [categorical limit](categorical-limit.md) precisely when $\mathcal C(C,L)\to\lim_i\mathcal C(C,E_i)$ is a [bijection](bijection.md) for every object $C$. This is exactly the [universal property](universal-property.md) expressed as a test on [hom-sets](hom-set.md). Consequently a [functor](functor.md) preserves existing [categorical limits](categorical-limit.md) if every composite with a covariant [representable functor](representable-functor.md) does.
