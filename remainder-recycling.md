# Remainder recycling

↑ **Parent:** [Random number generation](random-number-generation.md)

A [random number generation](random-number-generation.md) technique that retains the unused equally likely outcomes after a rejected trial in [rejection sampling](rejection-sampling.md). Instead of discarding those outcomes, it uses their [conditional probability](conditional-probability.md) to obtain a new [uniform distribution on a finite set](discrete-uniform-distribution.md) for the input state of the next trial.
