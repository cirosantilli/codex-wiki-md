# Quasipolynomial

↑ **Parent:** [Hilbert function](hilbert-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quasipolynomial)

A quasipolynomial is a function $f:\mathbb Z\to\mathbb C$ for which there are [polynomials](polynomial-split.md) $P_0,\ldots,P_{m-1}$ such that $f(n)=P_r(n)$ whenever $n\equiv r\pmod m$. The least possible positive $m$ is its period.
