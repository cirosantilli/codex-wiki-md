# Monodromy matrix

↑ **Parent:** [Lax pair](lax-pair.md)

For periodic $U(x,t,\lambda)$ with period $L$, solve $W_x=UW$, $W(0)=I$. The monodromy matrix is $w=W(L)$. If $U,V$ satisfy the [zero-curvature condition](zero-curvature-condition.md) and are periodic, then $W_t=VW-WV(0)$, hence $w_t=[V(0),w]$. The [matrix trace](matrix-trace.md) of each power of $w$ is a [first integral](first-integral.md).
