# Application programming interface

↑ **Parent:** [Software module](software-module.md)

An [application programming interface](application-programming-interface.md) defines the operations available to client code and their promised behavior, including [inputs](input-computer-science.md), [outputs](output-computing.md) and failure cases. For a [FIFO queue](fifo-queue.md), operation names alone do not specify what happens on an empty or full queue. An [API](application-programming-interface.md) should state those cases before clients depend on them.
