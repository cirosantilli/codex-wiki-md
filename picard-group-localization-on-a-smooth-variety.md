# Picard-group localization on a smooth variety

↑ **Parent:** [Picard group](picard-group.md)

For a smooth integral [variety](algebraic-variety.md), every [Weil divisor](weil-divisor.md) is a [Cartier divisor](cartier-divisor-split.md), so the [Picard group](picard-group.md) equals the [divisor class group](divisor-class-group.md). If $U$ is obtained by removing irreducible [Weil divisors](weil-divisor.md) $D_j$, the [localization sequence for the divisor class group](localization-sequence-for-the-divisor-class-group.md) gives the displayed [exact sequence](exact-sequence.md). A rational trivialization of a [line bundle](line-bundle.md) on $U$ has divisor supported on the removed divisors, describing the [kernel](kernel-of-a-linear-map.md) concretely.
