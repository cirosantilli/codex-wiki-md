# Chordal graph

↑ **Parent:** [Graph theory](graph-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Chordal_graph)

A chordal graph is an undirected [graph](graph-split.md) in which every cycle of length at least four has a chord. Its structure allows exact [junction tree](junction-tree.md) calculations using its [maximal cliques](maximal-clique.md).
