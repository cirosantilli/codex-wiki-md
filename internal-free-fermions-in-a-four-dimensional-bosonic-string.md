# Internal free fermions in a four-dimensional bosonic string

↑ **Parent:** [Bosonic string theory](bosonic-string-theory.md)

Keeping the ordinary reparameterization [bc ghost system](bc-system.md), four embedding bosons require 44 additional real chiral fermions in each chirality to cancel the [worldsheet Weyl anomaly](worldsheet-weyl-anomaly.md). These are internal matter fields, not an assumed locally supersymmetric RNS construction. Their bilinear currents generate the chiral $\mathfrak{so}(44)$ current algebra, with $\binom{44}{2}=946$ currents. A full closed fermionic model also requires consistent spin-structure and modular projections; the central-charge count alone does not determine these choices.
