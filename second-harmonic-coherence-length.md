# Second-harmonic coherence length

↑ **Parent:** [Phase matching in second-harmonic generation](phase-matching-in-second-harmonic-generation.md)

The length over which the harmonic and its quadratic source accumulate a relative [wave phase](phase-waves.md) of $\pi$. For nonzero [second-harmonic phase mismatch](second-harmonic-phase-mismatch.md), $L_c=\pi/|\Delta k|$; the first output zero of the uniform undepleted model occurs at $2L_c$. This is a propagation mismatch length, distinct from the pump's [optical coherence length](optical-coherence-length.md). It diverges as perfect [phase matching](phase-matching.md) is approached.
