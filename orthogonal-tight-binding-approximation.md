# Orthogonal tight-binding approximation

↑ **Parent:** [Tight binding](tight-binding.md)

In the [orthogonal tight-binding approximation](orthogonal-tight-binding-approximation.md), localized basis states satisfy $\langle i|j\rangle=\delta_{ij}$ while the [Hamiltonian](hamiltonian.md) retains nonzero [hopping integrals](hopping-integral.md). These are independent matrix elements: orthogonal states need not have vanishing Hamiltonian coupling. One can construct localized orthonormal orbitals from overlapping atomic orbitals; truncating the resulting Hamiltonian to nearest neighbours is a further approximation. An overlap matrix must instead be retained for raw nonorthogonal orbitals.
