# Convex perturbation function

↑ **Parent:** [Strong duality](strong-duality.md)

A jointly proper [convex function](convex-function.md) $f(x,z)$ represents an optimization problem at perturbation $z=0$ and a family of nearby problems at other $z$. Its primal value function is $p(z)=\inf_x f(x,z)$. Relaxing an inequality by $z$ gives the example $f(x,z)=J(x)+\delta_{(-\infty,0]}(r(x)-\sigma-z)$, using an [indicator functional](indicator-functional-of-a-constraint-set.md). The resulting [convex perturbation duality](convex-perturbation-duality.md) expresses multipliers as supporting [subgradients](subgradient.md) of the value function.
