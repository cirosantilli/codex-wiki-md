# Capillary parameter for a falling film

↑ **Parent:** [Falling film flow](falling-film-flow.md)

For downslope length scale $L$, film thickness scale $h_0$ and surface [velocity](velocity.md) scale $U_0=\rho gh_0^2\sin\alpha/(2\mu)$, this normalization makes the capillary part of the [Benney equation](benney-equation.md) flux $\varepsilon S h^3h_{xxx}$. The dimensionless capillary [pressure](pressure-split.md) is $-3S h_{xx}/2$. Keeping $S=O(1)$ specifies a distinguished [long-wave approximation](long-wave-approximation.md) in which [surface tension](surface-tension-split.md) remains relevant.
