# Memory reference

↑ **Parent:** [Computer memory](computer-memory.md)

An access to a location in [computer memory](computer-memory.md), such as an instruction fetch, a read or a write. A page-level reference [sequence](sequence.md) records the corresponding [memory page](memory-page.md) for each access, retaining repetitions and order.
