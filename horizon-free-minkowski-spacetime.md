# Horizon-free Minkowski spacetime

↑ **Parent:** [Event horizon](event-horizon.md)

Every event in complete [Minkowski spacetime](minkowski-spacetime.md) emits a future-directed [null geodesic](null-geodesic.md) ending on [future null infinity](future-null-infinity.md). Therefore its black-hole region $M\setminus J^-(\mathcal I^+)$ is empty and there is no intrinsic event horizon. The null edges of the [Minkowski conformal compactification](minkowski-conformal-compactification.md) represent infinity, not hidden regions inside the physical spacetime. An accelerated observer can instead have an observer-dependent [Rindler horizon](rindler-horizon.md).
