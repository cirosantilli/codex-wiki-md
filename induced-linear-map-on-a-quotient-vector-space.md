# Induced linear map on a quotient vector space

↑ **Parent:** [Quotient vector space](quotient-vector-space.md)

For a [linear map](linear-map.md) $T:V\to V$ and an [invariant subspace](invariant-subspace.md) $U$, the rule $\overline T(v+U)=T(v)+U$ defines a [linear map](linear-map.md) on the [quotient vector space](quotient-vector-space.md) $V/U$. Indeed, two representatives differ by an element of $U$, so their images also differ by an element of $U$. Conversely, this rule is well-defined only if $T(U)\subseteq U$, by comparing every $u\in U$ with zero.
