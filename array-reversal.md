# Array reversal

↑ **Parent:** [Array (data structure)](array-data-structure.md)

Reverse the order of entries in an [array](array-data-structure.md) segment by exchanging its outermost unprocessed pair and moving inward. This takes linear time and constant [auxiliary space](auxiliary-space.md). Reversing two adjacent blocks separately and then reversing their union rotates the blocks while restoring each block's internal order.
