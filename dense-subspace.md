# Dense subspace

↑ **Parent:** [Topological vector space](topological-vector-space-split.md)

A dense subspace of a [topological vector space](topological-vector-space-split.md) $X$ is a [linear subspace](vector-subspace.md) $D$ whose closure is all of $X$. It permits continuous operators to be determined or extended from values on $D$. For a normed space, every vector in $X$ is a limit of vectors from $D$.
