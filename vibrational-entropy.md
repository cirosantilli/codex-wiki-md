# Vibrational entropy

↑ **Parent:** [Vibrational partition function](vibrational-partition-function.md)

The harmonic-oscillator [entropy](entropy-split.md) contribution for one vibrational coordinate, with $x=\theta_{\rm vib}/T$. Contributions from independent [normal modes](normal-mode.md) add, with one term for each component of a degenerate mode. A temperature-independent [zero-point energy](zero-point-energy.md) does not change this [entropy](entropy-split.md).
