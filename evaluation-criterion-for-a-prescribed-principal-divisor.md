# Evaluation criterion for a prescribed principal divisor

↑ **Parent:** [Riemann-Roch space](riemann-roch-space.md)

Let $P=p_1+\cdots+p_k$ and $Q=q_1+\cdots+q_k$ be disjoint sums of distinct points on a [smooth projective curve](smooth-projective-curve.md). A nonzero function with [principal divisor](principal-divisor-on-an-algebraic-curve.md) $P-Q$ exists exactly when $L(Q-P)\ne0$: a nonzero member makes $(f)+Q-P$ an [effective divisor](effective-cartier-divisor.md) of degree zero, forcing equality. Evaluation $f\mapsto(f(p_1),\ldots,f(p_k))$ on $L(Q)$ has [kernel of a linear map](kernel-of-a-linear-map-split.md) $L(Q-P)$.

If $\ell(Q)=k$, a choice of [basis](basis.md) $f_1,\ldots,f_k$ turns the criterion into $\det(f_j(p_i))=0$. This determinant is not identically zero. Starting with $L(Q)$, repeatedly choose a point where some nonzero function in the current space does not vanish; evaluation then lowers the [dimension](dimension-vector-space.md) of that space by one. After $k$ choices the joint kernel is zero. Thus a generic tuple of points gives an invertible evaluation matrix, and no function with divisor $P-Q$. On a [genus one curve](genus-one-curve.md), [Riemann-Roch theorem](riemann-roch-theorem.md) gives $\ell(Q)=k$, so this obstruction applies for every $k>0$.
