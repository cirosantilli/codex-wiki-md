# Strict buffer

↑ **Parent:** [Message-passing channel](message-passing-channel.md)

A process with finite positive capacity whose output [sequence](sequence.md) is a prefix of its input [sequence](sequence.md) and whose input-output length discrepancy never exceeds that capacity. While active, it offers input whenever non-full and output whenever nonempty; upstream closure drains retained data, while downstream closure cancels delivery.
