# Credible set

↑ **Parent:** [Bayesian statistics](bayesian-statistics-split.md)

A [credible set](credible-set.md) is a measurable set of parameter values containing specified [posterior probability](posterior-probability.md). At credibility level $1-\alpha$, it satisfies $\int_C\pi(\theta\mid x)d\theta=1-\alpha$ for a continuous posterior. A [credible interval](credible-interval.md) is a credible set that is an interval. Equal-tailed and highest-density choices add selection rules; the posterior-mass requirement alone does not make the set unique. Its probability statement is conditional on the observed data and prior model, whereas a frequentist [confidence interval](confidence-interval.md) is interpreted through repeated-sample coverage.
