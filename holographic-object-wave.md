# Holographic object wave

↑ **Parent:** [Holography](holography.md)

A [holographic object wave](holographic-object-wave.md) is the object-dependent field arriving at the recording surface, including the propagation from the object. Its [complex amplitude](complex-amplitude.md) generally differs from the transmission function at the object itself. Distinguishing these two planes is essential when refocusing a [hologram](hologram.md).
