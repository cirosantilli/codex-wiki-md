# Phase-sensitive detection

↑ **Parent:** [Lock-in amplifier](lock-in-amplifier.md)

[phase-sensitive detection](phase-sensitive-detection.md) correlates an input with a synchronized reference and filters the product. Sinusoidal quadrature references recover both [signal](signal.md) [amplitude](wave-amplitude.md) and relative phase. Narrow detection [bandwidth](bandwidth-signal-processing.md) rejects incoherent [noise](noise-signal-processing.md) but cannot reject a background coherent at the same [frequency](frequency.md); changing the integration [time](time-in-physics.md) also changes settling and tracking speed.[printed pp.3-1–3-3](model-sr830-dsp-lock-in-amplifier-manual-by-stanford-research-systems.md)
