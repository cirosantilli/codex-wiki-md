# Projective object

↑ **Parent:** [Category](category-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Projective_object)

An object $P$ is projective when every morphism $P\to B$ lifts through every [epimorphism](epimorphism.md) $A\twoheadrightarrow B$. Equivalently, the functor $\mathcal C(P,-)$ preserves epimorphisms.
