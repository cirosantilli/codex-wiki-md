# Dense set

↑ **Parent:** [Topology](topology-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dense_set)

A subset is dense when every nonempty [open set](open-set.md) meets it, equivalently when its closure is the whole ambient space.
