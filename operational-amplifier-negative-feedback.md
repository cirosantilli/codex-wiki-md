# Operational-amplifier negative feedback

↑ **Parent:** [Operational amplifier](operational-amplifier.md)

Return a fraction of the output to the inverting input so that it opposes the input difference. Large stable [loop gain](loop-gain.md) makes the [closed-loop gain](closed-loop-gain.md) depend mainly on the external feedback ratio rather than the uncertain [open-loop gain](open-loop-gain.md). Frequency-dependent phase lag can destabilize the loop; saturation and finite [slew rate](slew-rate.md) also limit the approximation.[Chapter 3, §§3.2.2–3.2.4](operational-amplifier-negative-feedback-by-analog-devices.md)
