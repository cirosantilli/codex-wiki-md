# Bandwidth (signal processing)

↑ **Parent:** [Signal processing](signal-processing.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bandwidth_(signal_processing))

The [bandwidth](bandwidth-signal-processing.md) is the width of a specified [frequency](frequency.md) interval, $\Delta\nu=\nu_h-\nu_l$. Its meaning depends on how the interval is selected: a [signal bandwidth](signal-bandwidth.md) and an [effective noise bandwidth](effective-noise-bandwidth.md) can differ even for the same receiving system.
