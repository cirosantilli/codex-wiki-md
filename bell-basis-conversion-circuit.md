# Bell-basis conversion circuit

↑ **Parent:** [Bell basis](bell-basis.md)

Apply a [Hadamard gate](hadamard-gate.md) to the first qubit, then a [controlled-NOT gate](controlled-not-gate.md) from the first to the second. This maps a [computational-basis state](computational-basis-state.md) $|ij\rangle$ to the [Bell state](bell-state-split.md) with phase bit $i$ and parity bit $j$. Its inverse uses the same gates in reverse order because each gate is self-inverse but they do not commute. Applying the forward sequence twice is not generally a decoding operation.
