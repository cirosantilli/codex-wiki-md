# State encoding

↑ **Parent:** [Finite-state machine](finite-state-machine.md)

An injective assignment of abstract [finite-state machine](finite-state-machine.md) states to stored [bit](bit.md) patterns. $m$ distinct states require at least $\lceil\log_2m\rceil$ binary storage elements. Encodings with unused patterns can simplify [Boolean functions](boolean-function.md) through [don't-care conditions](don-t-care-term.md), but the implemented next-state equations determine what those unused patterns actually do.
