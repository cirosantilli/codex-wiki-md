# Size of a statistical test

↑ **Parent:** [Statistical hypothesis test](statistical-hypothesis-test.md)

The size of a test is the supremum, over distributions in its [null hypothesis](null-hypothesis.md), of its rejection probability. For a simple null it is just the null rejection probability; a level-$\alpha$ test has size at most $\alpha$.
