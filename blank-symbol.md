# Blank symbol

↑ **Parent:** [Turing machine](turing-machine.md)

A designated tape [alphabet](alphabet.md) symbol occupying unused cells of a [Turing machine](turing-machine.md). It is excluded from the input [alphabet](alphabet.md), so a finite input [word](string.md) occupies a finite region of an otherwise blank tape.
