↑ **Parent:** [C](../c.md)

A collection of [logical connectives](../../../../../logical-connective.md) is adequate, or has [functional completeness](../../../../../functional-completeness.md), if every [Boolean function](../../../../../boolean-function.md) of finitely many [propositional variables](../../../../../propositional-variable.md) can be expressed by a formula using those connectives and variables, with the usual convention for nullary truth constants stated if those are included.

An adequate example is $\boxed{\{\neg,\to\}}$. An inadequate example is $\boxed{\{\to\}}$: formulas using [logical implication](../../../../../logical-implication.md) alone preserve truth when every input is true, so cannot express [negation](../../../../../negation.md). These examples concern truth functions, rather than mere syntactic formation of formulas.
