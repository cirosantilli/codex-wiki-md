↑ **Parent:** [I](../i.md)

A [consistent set of formulae](../../../../../../consistent-set-of-formulae.md), restricted here to sentences, does not derive a contradiction in the chosen classical deductive system. Equivalently there is no sentence $\theta$ for which both $\Sigma\vdash\theta$ and $\Sigma\vdash\neg\theta$ hold. By explosion, an inconsistent set derives every sentence; a consistent set does not.

This is a syntactic condition about finite derivations, rather than a definition in terms of models.
