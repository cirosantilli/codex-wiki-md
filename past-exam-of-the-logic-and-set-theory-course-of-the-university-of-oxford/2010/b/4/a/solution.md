<h1 id="b/4/a/solution">Solution</h1>

↑ **Parent:** [A](../a.md)

**True in ZF.** For a set $A$, the singleton map injects $A$ into its [power set](../../../../../power-set.md). No map $f:A\to\mathcal P(A)$ is onto: the diagonal set

$$
D=\{a\in A:a\notin f(a)\}
$$

differs from $f(a)$ at the element $a$ for every $a$. Thus there is no [bijection](../../../../../bijection.md) between $A$ and its [power set](../../../../../power-set.md). The [injection](../../../../../injective-function.md) together with this failure proves $\boxed{\kappa<2^\kappa}$.

If strict comparison is formulated as [injection](../../../../../injective-function.md) in one direction but not the other, the [Cantor-Schröder-Bernstein theorem](../../../../../cantor-schroder-bernstein-theorem.md), which requires no choice, excludes an [injection](../../../../../injective-function.md) of the [power set](../../../../../power-set.md) back into $A$. This is [Cantor's theorem](../../../../../cantor-s-theorem.md) in a choice-free form.
