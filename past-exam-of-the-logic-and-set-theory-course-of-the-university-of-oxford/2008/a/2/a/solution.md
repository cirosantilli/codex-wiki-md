A collection of [logical connectives](../../../../../logical-connective.md) is functionally complete, or adequate, if every [Boolean function](../../../../../boolean-function.md) of finitely many [propositional variables](../../../../../propositional-variable.md) is represented by a [logical formula](../../../../../logical-formula.md) using only those [logical connectives](../../../../../logical-connective.md). More explicitly, for every $n\geq1$ and every $F:\{0,1\}^n\to\{0,1\}$ there is a [logical formula](../../../../../logical-formula.md) $\theta(p_1,\ldots,p_n)$ whose [truth value](../../../../../truth-value.md) under each [Boolean valuation](../../../../../boolean-valuation.md) is $F(v(p_1),\ldots,v(p_n))$. [Constant functions](../../../../../constant-function.md) with Boolean values may use an otherwise irrelevant [logical variable](../../../../../logical-variable.md), for example $p\to p$ for truth and $\neg(p\to p)$ for falsity.
