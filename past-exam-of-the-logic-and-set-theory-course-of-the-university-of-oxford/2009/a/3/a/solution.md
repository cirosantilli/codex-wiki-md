<h1 id="a/3/a/solution">Solution</h1>

↑ **Parent:** [A](../a.md)

Adequacy here means [functional completeness](../../../../../functional-completeness.md): every Boolean truth function of finitely many positive-arity propositional inputs can be expressed by a formula using the available connectives. It is an expressive-power claim, distinct from the completeness theorem relating derivability and [semantic entailment](../../../../../semantic-entailment.md).

[Negation](../../../../../negation.md) and implication define [conjunction](../../../../../conjunction-astronomy.md) and disjunction by

$$
p\land q\equiv\neg(p\to\neg q),\qquad p\lor q\equiv\neg p\to q.
$$

Given any [truth table](../../../../../truth-table.md), for each input row where its output is true form the [minterm](../../../../../minterm.md) containing each input positively or negatively according to that row. The disjunction of these [minterms](../../../../../minterm.md) is true on exactly the required rows: a [disjunctive normal form](../../../../../disjunctive-normal-form.md). Replacing its conjunctions and disjunctions by the displayed definitions gives a formula using only $\neg,\to$.

The constantly true and constantly false functions are represented by $p\to p$ and $\neg(p\to p)$, using a dummy input if needed. Thus the empty or full [truth table](../../../../../truth-table.md) also causes no difficulty. If one insists on genuinely nullary formulas with no variables at all, a separate truth constant is needed; ordinary propositional adequacy allows the constant truth functions to be expressed with irrelevant input variables.
