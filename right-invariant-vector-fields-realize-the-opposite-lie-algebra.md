# Right-invariant vector fields realize the opposite Lie algebra

↑ **Parent:** [Right-invariant vector field](right-invariant-vector-field.md)

For a [Matrix Lie group](matrix-lie-group.md), the [right-invariant vector field](right-invariant-vector-field.md) is $r_\xi(g)=\xi g$. Differentiating these ambient matrix-valued functions in the definition of the [Lie bracket of vector fields](lie-bracket-of-vector-fields.md) gives $[r_\xi,r_\eta](g)=(\eta\xi-\xi\eta)g$. Thus $\xi\mapsto r_\xi$ is an antihomomorphism, and $\xi\mapsto-r_\xi$ is a homomorphism. In contrast, $\xi\mapsto l_\xi$ for [left-invariant vector fields](left-invariant-vector-field.md) is a homomorphism.
