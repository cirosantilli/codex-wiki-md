# Knot insertion

↑ **Parent:** [B-spline](b-spline.md)

[Knot insertion](knot-insertion.md) refines the [spline knot sequence](spline-knot-sequence.md) and changes the control points without changing the represented [B-spline](b-spline.md). Repeated insertion exposes local [Bézier curves](bezier-curve.md) and provides subdivision-based evaluation.
