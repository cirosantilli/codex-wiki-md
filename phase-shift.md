# Phase shift

↑ **Parent:** [Phase (waves)](phase-waves.md)

A [phase shift](phase-shift.md) is a change in an oscillation's [wave phase](phase-waves.md), specified modulo $2\pi$. It can arise from propagation, reflection or an imposed response. With the time convention $e^{-i\omega t}$, a delay $\tau$ multiplies the [complex amplitude](complex-amplitude.md) by $e^{i\omega\tau}$. A sign reversal is a $\pi$ [phase shift](phase-shift.md).
