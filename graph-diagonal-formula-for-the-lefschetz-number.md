# Graph-diagonal formula for the Lefschetz number

↑ **Parent:** [Cohomology class of the diagonal](cohomology-class-of-the-diagonal.md)

For the graph map $(1,f):M\to M\times M$, the [cohomology class of the diagonal](cohomology-class-of-the-diagonal.md) satisfies

$$
\left\langle(1,f)^*\varepsilon_\Delta,[M]\right\rangle
=\sum_p(-1)^p\operatorname{tr}\left(f^*:H^p(M;\mathbb Q)\to H^p(M;\mathbb Q)\right).
$$

If $f$ is fixed-point-free, its graph misses the diagonal, so the pullback vanishes. This proves the [Lefschetz fixed-point theorem](lefschetz-fixed-point-theorem.md) for closed oriented manifolds.
