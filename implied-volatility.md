# Implied volatility

↑ **Parent:** [Mathematical finance](mathematical-finance-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Implied_volatility)

Implied volatility is the volatility input of an option-pricing model that reproduces an observed option price. [Black-Scholes implied volatility](black-scholes-implied-volatility.md) specializes this inversion to the [Black-Scholes model](black-scholes-model.md).
