# Real character and real conjugacy class counting theorem

↑ **Parent:** [Character table](character-table.md)

For a [finite group](finite-group.md), the number of [irreducible characters](irreducible-character.md) which are [real-valued characters](real-valued-character.md) equals the number of [real conjugacy classes](real-conjugacy-class.md). On the [complex vector space](complex-vector-space.md) of [class functions](class-function.md), the [linear operator](linear-operator.md) $Tf(g)=f(g^{-1})$ permutes the [basis](basis.md) of class indicators by inversion and the [basis](basis.md) of [irreducible characters](irreducible-character.md) by pointwise [complex conjugation](complex-conjugation.md), using the [character inversion identity](character-inversion-identity.md). The [trace](matrix-trace.md) of a [basis](basis.md) permutation is its number of fixed members. Equality of the [trace](matrix-trace.md) in the two [bases](basis.md) proves the theorem. The [linear operator](linear-operator.md) $T$ is complex-linear; pointwise [complex conjugation](complex-conjugation.md) on arbitrary [class functions](class-function.md) is not.
