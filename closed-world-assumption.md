# Closed-world assumption

↑ **Parent:** [First-order logic](first-order-logic.md)

The convention that ground facts not present in the current representation are false. In a basic [STRIPS](strips.md) state, listing the true facts therefore determines a complete interpretation for its ground facts. This convention differs from a knowledge base in which an absent assertion is simply unknown.
