# Locality of weak differentiability

↑ **Parent:** [Weak derivative](weak-derivative.md)

A locally integrable function has [weak derivatives](weak-derivative.md) on an open set exactly when it has them near every point. Local derivatives agree almost everywhere on overlaps because they define the same [distributional derivative](distributional-derivative.md). A countable local cover therefore gives globally defined, locally integrable derivative functions. A smooth [partition of unity](partition-of-unity.md) subordinate to the cover splits each compactly supported [test function](test-function.md); summing the local integration identities yields the global weak-derivative identity.
