# Logical connective

↑ **Parent:** [Proposition](proposition.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Logical_connective)

A [logical connective](logical-connective.md) forms a compound [proposition](proposition.md) from component [propositions](proposition.md); [logical truth](logical-truth.md) and [logical falsity](logical-falsity.md) are the zero-input cases. [Logical negation](negation.md) has one input, while [logical conjunction](logical-conjunction.md), [logical disjunction](logical-disjunction.md), and [logical implication](logical-implication.md) each have two. In [classical propositional logic](classical-propositional-logic.md), these [logical connectives](logical-connective.md) are truth-functional: their output value is determined by their input values, as listed in a [truth table](truth-table.md). This does not characterize every kind of [logical connective](logical-connective.md) in every logic. See [forall x: Calgary, section 10.1](https://forallx.openlogicproject.org/html/Ch10.html).
