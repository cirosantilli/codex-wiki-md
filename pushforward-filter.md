# Pushforward filter

↑ **Parent:** [Filter (set theory)](filter-set-theory.md)

For a [function](function-split.md) $f:X\to Y$, the pushforward of a [filter on a set](filter-set-theory.md) $X$ consists of the [subsets](subset.md) $B\subseteq Y$ with $f^{-1}(B)\in\mathcal F$. [Preimages](preimage.md) preserve inclusions and finite [intersections](set-intersection.md), so this is a proper filter. Equivalently it is generated by $f(A)$ for $A\in\mathcal F$. Because preimages preserve complements too, the pushforward of an [ultrafilter](ultrafilter.md) is an [ultrafilter](ultrafilter.md).
