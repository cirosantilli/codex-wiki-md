<h1 id="chromatic-polynomial-determines-a-turan-graph">Chromatic polynomial determines a Turán graph</h1>

↑ **Parent:** [Chromatic polynomial](chromatic-polynomial.md)

If a simple graph has the same [chromatic polynomial](chromatic-polynomial.md) as the [Turán graph](turan-graph.md) $T_r(n)$, it has the same number of vertices and edges, and the same [chromatic number](chromatic-number.md) $r$. It is therefore $K_{r+1}$-free and attains equality in [Turán's theorem](turan-s-theorem.md). The equality case forces it to be isomorphic to $T_r(n)$.
