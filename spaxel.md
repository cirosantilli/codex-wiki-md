# Spaxel

↑ **Parent:** [Integral field spectrograph](integral-field-spectrograph.md)

A [spaxel](spaxel.md) is one spatial sampling element in a [spectral data cube](spectral-data-cube.md). For a square field of angular side $\beta$ sampled at angular side $\theta$, the number of [spaxels](spaxel.md) is $(\beta/\theta)^2$, before edge rounding.
