# Number state

↑ **Parent:** [Number operator](number-operator.md)

A number state is a normalized [eigenstate](eigenstate.md) of the [number operator](number-operator.md):

$$
N|n\rangle=n|n\rangle,
\qquad n\in\mathbb Z_{\geq0}.
$$

For a single [quantum harmonic oscillator](quantum-harmonic-oscillator-split.md), it is also an [energy eigenstate](energy-eigenstate.md) with energy $\hbar\omega(n+1/2)$.
