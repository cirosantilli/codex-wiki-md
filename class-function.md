# Class function

↑ **Parent:** [Representation theory](representation-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Class_function)

A class function on a [group](group-split.md) is a function constant on every [conjugacy class](conjugacy-class.md). Equivalently, $f(hgh^{-1})=f(g)$ for all group elements $g,h$.
