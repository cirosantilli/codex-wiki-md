# Manchester code

↑ **Parent:** [Line code](line-code.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Manchester_code)

[Manchester encoding](manchester-code.md) represents each data [bit](bit.md) by two opposite half-bit levels. The compulsory midpoint transition supports [clock recovery](clock-recovery.md).
