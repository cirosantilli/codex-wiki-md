# Dual code

↑ **Parent:** [Linear code](linear-code.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dual_code)

The dual code $C^\perp$ consists of the words orthogonal to every word of $C$ under the standard dot product. A [parity-check matrix](parity-check-matrix.md) for $C$ is a [generator matrix](generator-matrix.md) for $C^\perp$.
