# Void probability functional

↑ **Parent:** [Point process](point-process.md)

The void [probability](probability.md) functional assigns to a measurable set the [probability](probability.md) that it contains no atom of a random point [measure](measure.md). For a [Poisson random measure](poisson-random-measure.md) of intensity $\mu$, it is $e^{-\mu(A)}$. The [exponential void probabilities characterize a Poisson random measure](exponential-void-probabilities-characterize-a-poisson-random-measure.md) result uses simplicity; doubling every atom of a Poisson [measure](measure.md) preserves void [probabilities](probability.md) but changes count distributions.
