# Determinantal point process

↑ **Parent:** [Point process](point-process.md)

A point process is determinantal with kernel $K$ relative to a specified reference measure if every [correlation function of a point process](correlation-function-of-a-point-process.md) is the indicated [determinant](determinant.md). A rank-$m$ [finite-rank projection kernel](finite-rank-projection-kernel.md) gives an exactly $m$-point process, whose symmetric joint density is $\det[K(x_i,x_j)]/m!$.
