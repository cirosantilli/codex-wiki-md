# Subcategory

↑ **Parent:** [Category](category-split.md)

A subcategory $\mathcal S$ of a [category](category-split.md) $\mathcal C$ specifies some objects and some [morphisms](morphism.md) between them, containing their identities and closed under composition. It is full if it contains every ambient morphism between its selected objects. A [skeleton of a category](skeleton-of-a-category.md) is a full subcategory containing one object from each isomorphism class.
