# Odd cross-intersection bound

↑ **Parent:** [Extremal set theory](extremal-set-theory-split.md)

Appending a coordinate one to each [indicator vector](indicator-vector.md) changes every odd cross-intersection dot product into an even one in $\mathbb F_2^{n+1}$. The argument for the [even cross-intersection bound](even-cross-intersection-bound.md) then gives the displayed bound. It is a valid bound without a claim that it is sharp.
