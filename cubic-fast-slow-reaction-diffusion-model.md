# Cubic fast-slow reaction-diffusion model

↑ **Parent:** [Reaction–diffusion system](reaction-diffusion-system.md)

This nondimensional two-variable [reaction–diffusion system](reaction-diffusion-system.md) combines a fast cubic local response with slow negative feedback. With $D>0$, $0<\alpha<1$, $\beta>0$ and $\varepsilon\ll1$, its spatially uniform rest state at $I=0$ is linearly stable: the Jacobian has [trace](matrix-trace.md) $-\alpha-\varepsilon\beta$ and [determinant](determinant.md) $\varepsilon(1+\alpha\beta)$. For suitable parameters a finite perturbation can nevertheless cause a large excursion followed by recovery. Frozen recovery gives a [bistable cubic reaction-diffusion equation](bistable-cubic-reaction-diffusion-equation.md); the full coupled travelling-wave boundary-value problem determines whether front pairs form a pulse. This is a generic excitable-medium formulation of the [FitzHugh-Nagumo model](fitzhugh-nagumo-model.md), without assigning any biological variable or application.
