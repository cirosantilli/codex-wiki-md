# NaN

↑ **Parent:** [Floating-point arithmetic](floating-point-arithmetic-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/NaN)

A special [floating-point arithmetic](floating-point-arithmetic-split.md) value representing an undefined or unrepresentable numerical result. A displayed [NaN](nan.md) is not a numerical zero and is not a valid [p-value](p-value.md).
