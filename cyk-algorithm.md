# CYK algorithm

↑ **Parent:** [Chomsky normal form](chomsky-normal-form.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/CYK_algorithm)

The CYK algorithm decides membership in a [context-free language](context-free-language.md) given by a grammar in [Chomsky normal form](chomsky-normal-form.md). It records, for every substring, the nonterminals that derive that substring and combines adjacent substrings using binary productions. For a word of length $n$ and a fixed grammar, it runs in $O(n^3)$ time.
