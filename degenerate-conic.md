# Degenerate conic

↑ **Parent:** [Conic section](conic-section.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Degenerate_conic)

For $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$, the homogeneous quadratic coefficient matrix is

$$
Q=\begin{pmatrix}A&B/2&D/2\\B/2&C&E/2\\D/2&E/2&F\end{pmatrix}.
$$

The conic is degenerate when $Q$ is a [singular matrix](singular-matrix.md). Examples over the [real numbers](real-number.md) include the point $x^2+y^2=0$, the repeated line $y^2=0$, and the two [straight lines](straight-line.md) in $xy=0$. The real solution set alone need not reveal the algebraic distinction: $x^2+y^2=-1$ has no real points, but its matrix is nonsingular. This determinant test is different from the [conic type discriminant](conic-type-discriminant.md), which only uses the quadratic part in $x,y$.
