# Continuous array in better-quasi-order theory

↑ **Parent:** [Better-quasi-ordering](better-quasi-ordering.md)

A continuous array takes infinite subsets of an infinite $A\subseteq\omega$, in the [ordinary topology on infinite subsets](ordinary-topology-on-infinite-subsets.md), to a discrete [preorder](preorder.md) $Q$. It is bad if $F(X)\not\leq F(X\setminus\{\min X\})$ for every infinite $X$. A [barrier in better-quasi-order theory](barrier-in-better-quasi-order-theory.md) array induces such a continuous array by evaluating its unique barrier initial segment. The continuous-array and barrier formulations of [better-quasi-ordering](better-quasi-ordering.md) are equivalent, using refinement of fronts to barriers in the reverse direction.
