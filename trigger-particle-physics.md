# Trigger (particle physics)

↑ **Parent:** [Particle detector](particle-detector.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Trigger_(particle_physics))

A [detector trigger](trigger-particle-physics.md) decides which candidate events cause a readout or recording. It can concentrate a limited recording capacity on rare interactions, but the accepted events then form a selected sample. A [coincidence circuit](coincidence-circuit.md) uses a timing relation between several detectors; the [Blackett-Occhialini triggered cloud-chamber experiment](blackett-occhialini-triggered-cloud-chamber-experiment.md) made that relation operate an entire camera-and-expansion sequence.
