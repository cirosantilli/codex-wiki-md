# Spectral resolution element

↑ **Parent:** [Spectrograph](spectrograph.md)

A [spectral resolution element](spectral-resolution-element.md) is a spectral interval at the adopted instrumental resolution. At [spectral resolving power](spectral-resolving-power.md) $R$, its width is $\Delta\lambda=\lambda/R$. The number of [photodetector](photodetector.md) [detector pixels](optical-detector-pixel.md) sampling it is distinct from $R$.
