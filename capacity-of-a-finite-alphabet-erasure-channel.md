# Capacity of a finite-alphabet erasure channel

↑ **Parent:** [Finite-alphabet erasure channel](finite-alphabet-erasure-channel.md)

For a [finite-alphabet erasure channel](finite-alphabet-erasure-channel.md) with $k$ input symbols, $I(X;Y)=(1-f)H(X)$. Maximizing [Shannon entropy](information-entropy.md) at the uniform input gives [channel capacity](channel-capacity.md) $C=(1-f)\log_2k$ bits per use, by the [Shannon second coding theorem](noisy-channel-coding-theorem.md).
