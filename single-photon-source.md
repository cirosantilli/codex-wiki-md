# Single-photon source

↑ **Parent:** [Photon](photon.md)

A [single-photon source](single-photon-source.md) prepares light with strongly suppressed simultaneous two-[photon](photon.md) emission. One useful implementation repeatedly excites one discrete emitter and collects a selected radiative transition. [Photon antibunching](photon-antibunching.md), measured through the zero-delay second-order correlation $g^{(2)}(0)$, tests the multiphoton suppression; a weak coherent beam retains Poissonian number fluctuations. Collection efficiency and multiphoton probability are distinct properties.
