# ARM architecture family

↑ **Parent:** [Instruction set architecture](instruction-set-architecture.md)

A family of processor architectures with several execution states and instruction encodings. The 32-[bit](bit.md) instruction sets include the compact [Thumb instruction set](thumb-instruction-set.md); the 32-[bit](bit.md) [AAPCS32](aapcs32.md) [calling convention](calling-convention.md) specifies interoperation at subroutine boundaries.
