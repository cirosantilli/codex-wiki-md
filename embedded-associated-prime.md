# Embedded associated prime

↑ **Parent:** [Associated prime of a module](associated-prime-of-a-module.md)

An [associated prime of a module](associated-prime-of-a-module.md) $R/I$ is embedded when it is not minimal over $I$. For example, in $k[x,y]/(x^2,xy)$ the nonzero class of $x$ has [annihilator](annihilator-ring-theory.md) $(x,y)$, while the unique minimal prime is $(x)$. Embedded primes record [annihilators](annihilator-ring-theory.md) which are invisible if one retains only the reduced irreducible components.
