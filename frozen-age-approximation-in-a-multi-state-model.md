# Frozen-age approximation in a multi-state model

↑ **Parent:** [Irreversible three-state disease model](irreversible-three-state-disease-model.md)

A frozen-age approximation holds an age covariate constant at the start of each observation interval, allowing homogeneous [transition probabilities](transition-probability.md) to enter a [panel-observed multi-state likelihood](panel-observed-multi-state-likelihood.md). It approximates a model with continuously changing age. Reciprocal rate calibration of mean waiting times is exact for a fixed-age [exponential distribution](exponential-distribution.md), but not for a continuously ageing [Gompertz distribution](gompertz-distribution.md).
