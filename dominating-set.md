# Dominating set

↑ **Parent:** [Graph theory](graph-theory-split.md)

A [dominating set](dominating-set.md) $D$ of a [graph](graph-split.md) is a [vertex](vertex-graph-theory.md) [subset](subset.md) such that every unselected [vertex](vertex-graph-theory.md) has a neighbour in $D$. Equivalently every [vertex](vertex-graph-theory.md) lies in $D$ or is adjacent to an element of $D$. This condition differs from [vertex cover](vertex-cover.md), which requires every [edge](edge-of-a-graph.md) to have an endpoint in the selected [set](set-split.md).
