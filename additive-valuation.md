# Additive valuation

↑ **Parent:** [Game theory](game-theory-split.md)

A bundle-value [function](function-split.md) for which an agent's value for a [set](set-split.md) of items is the [sum](sum.md) of its item values. Different agents may assign different values to the same item. With nonnegative item values, a bundle containing no positively valued item has value zero. The formula excludes interactions such as a pair of items being valuable only when held together.
