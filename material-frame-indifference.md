# Material frame indifference

↑ **Parent:** [Constitutive equation](constitutive-equation.md)

A [constitutive equation](constitutive-equation.md) is frame indifferent when a superposed rigid spatial rotation changes its outputs by their tensor transformation rules. For an elastic [Cauchy stress tensor](cauchy-stress-tensor.md), this requires $\sigma(QF)=Q\sigma(F)Q^T$. It differs from [material isotropy](material-isotropy.md), which rotates reference material directions.
