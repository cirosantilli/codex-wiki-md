# Stochastic control

↑ **Parent:** [Optimal control](optimal-control.md)

A [stochastic control](stochastic-control.md) problem chooses an admissible [control input](control-input.md) using information available in a [filtration](filtration-probability-theory.md) to optimize an expected objective for a random dynamical system. [Dynamic programming](dynamic-programming.md) often characterizes its [value function](value-function.md) through a [Hamilton-Jacobi-Bellman equation](hamilton-jacobi-bellman-equation.md).
