# Search frontier

↑ **Parent:** [Search tree](search-tree.md)

The generated but unexpanded [search nodes](search-node.md) maintained by a [search algorithm](search-algorithm.md). [Best-first search](best-first-search.md) selects the next expansion from this frontier using a [priority queue](priority-queue.md) or an equivalent ordering operation. A lower-bound argument about a frontier node on an optimal path is central to [A-star search](a-star-search.md) correctness.
