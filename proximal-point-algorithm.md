# Proximal point algorithm

↑ **Parent:** [Monotone operator](monotone-operator.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Proximal_point_algorithm)

The proximal point algorithm seeks a zero of a [monotone operator](monotone-operator.md) $F$ by repeatedly applying its resolvent:

$$
w_{k+1}=(I+\lambda F)^{-1}w_k.
$$

For $F=\partial f$, this is iteration of a [proximal operator](proximal-operator.md).
