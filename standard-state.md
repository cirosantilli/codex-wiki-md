# Standard state

↑ **Parent:** [Chemical equilibrium](chemical-equilibrium.md)

A standard state is a specified reference state used to define a species' standard [chemical potential](chemical-potential-split.md) $\mu_i^\circ$. The reference convention, including [temperature](temperature-split.md), must be consistent when calculating [thermodynamic activities](thermodynamic-activity.md), [reaction quotients](reaction-quotient.md), and [equilibrium constants](equilibrium-constant.md).
