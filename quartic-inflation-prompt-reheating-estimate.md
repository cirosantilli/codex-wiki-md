# Quartic-inflation prompt-reheating estimate

↑ **Parent:** [Reheating temperature](reheating-temperature.md)

For a quartic [inflaton](inflaton.md) potential, an endpoint field of order the unreduced [Planck mass](planck-mass.md) leaves density of order $\lambda M_P^4$. If prompt, efficient [reheating](reheating.md) converts it to equilibrium radiation, $\rho=(\pi^2/30)g_*T_R^4$ gives the displayed scaling. With the potential-only endpoint estimate $\phi_e=M_P/\sqrt\pi$, the coefficient is $[15/(2\pi^4)]^{1/4}$. End-of-inflation [kinetic energy](kinetic-energy.md) changes that coefficient by order one, and delayed transfer or incomplete thermalization requires a reheating model rather than the potential alone.
