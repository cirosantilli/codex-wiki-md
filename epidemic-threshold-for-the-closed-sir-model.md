# Epidemic threshold for the closed SIR model

↑ **Parent:** [SIR model](sir-model.md)

The deterministic [SIR model](sir-model.md) with initial susceptible count $S_0$ grows initially exactly when $\beta S_0>\gamma$. Its [basic reproduction number](basic-reproduction-number.md) is $\beta S_0/\gamma$ under unnormalized [mass-action infection](mass-action-infection.md). If that ratio is at most one, decreasing $S$ prevents later infectious growth.
