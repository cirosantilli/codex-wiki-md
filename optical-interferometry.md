# Optical interferometry

↑ **Parent:** [Interferometry](interferometry.md)

Measurement using interfering [light](light.md) fields. A [phase difference](phase-difference.md) changes the detected [intensity](intensity-physics.md), allowing measurements of displacement, [optical path length](optical-path-length.md) or a spectrum. The [round-trip phase in a Michelson interferometer](round-trip-phase-in-a-michelson-interferometer.md) gives one explicit path-to-phase calibration; [Fourier transform spectroscopy](fourier-transform-spectroscopy.md) recovers spectral information from an interferogram.
