# Equivalent width

↑ **Parent:** [Radiative transfer](radiative-transfer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Equivalent_width)

An absorption [equivalent width](equivalent-width.md) is $W_\lambda=\int[1-I_\lambda/I_\lambda^0]d\lambda$, the [wavelength](wavelength.md) width of a completely black interval that removes the same continuum-normalized area. For a narrow [spectral line profile](spectral-line-profile.md), small [optical depth](optical-depth.md) and negligible [stimulated emission](stimulated-emission.md), the energy-density convention for [Einstein coefficients](einstein-coefficients.md) gives $W_\lambda=hB_{12}N_1/\nu_{12}$. This follows by replacing $1-e^{-\tau_\nu}$ by $\tau_\nu$ and using $|d\lambda/d\nu|=c/\nu^2$. At [redshift](redshift.md) $z$, the observed and rest-frame values satisfy $W_{\rm obs}=(1+z)W_{\rm rest}$.
