# Digital signature

↑ **Parent:** [Cryptography](cryptography.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Digital_signature)

A public-verification [message authentication](message-authentication.md) scheme with key generation, signing using a [private key](private-key.md), and verification using the corresponding [public key](public-key.md). Signing an appropriate digest binds the signature to the message; [encryption](encryption.md) alone does not provide this authenticity.
