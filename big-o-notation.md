# Big O notation

↑ **Parent:** [Real analysis](real-analysis-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Big_O_notation)

The relation $f(x)=O(g(x))$ near a limit point means that $|f(x)|\leq C|g(x)|$ there for some constant $C$.
