# Potential event time

↑ **Parent:** [Kaplan–Meier estimator](kaplan-meier-estimator.md)

A potential event time is a support point permitted in the discrete event-time distribution used to derive the [Kaplan–Meier estimator](kaplan-meier-estimator.md) by [maximum likelihood estimation](maximum-likelihood-estimation.md). The support must include every observed exact event time. Additional points with a nonempty [risk set](risk-set.md) but no observed event receive zero fitted event mass.
