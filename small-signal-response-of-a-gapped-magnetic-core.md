# Small-signal response of a gapped magnetic core

↑ **Parent:** [Magnetic reluctance](magnetic-reluctance.md)

For a uniform core of path length $\ell$, a narrow air gap $d$, and $n$ winding turns, [Ampère's circuital law](ampere-s-circuital-law.md) gives $nI=\ell H_{\rm core}+dB/\mu_0$ when leakage and fringing are negligible. If a reversible branch has differential [magnetic permeability](permeability-electromagnetism.md) $\mu_{\rm core}=dB/dH$, linearization gives $dB/dI=\kappa$. An offset in the operating branch changes the bias field, not this differential formula. For $B=B_m\tanh(H/H_m)$ at the origin, $\mu_{\rm core}=B_m/H_m$.
