# Lorentzian line shape

↑ **Parent:** [Spectral line](spectral-line.md)

A [spectral line](spectral-line.md) profile with the shape of a [Cauchy distribution](cauchy-distribution.md). In the displayed peak-normalized convention, $\nu$ is [frequency](frequency.md), $\nu_0$ is the line centre, and $\gamma>0$ is the half width at half maximum: $L(\nu_0\pm\gamma)=1/2$, so the full width is $2\gamma$. The normalization used for a [probability density function](probability-density-function.md) differs from this unit-peak convention.
