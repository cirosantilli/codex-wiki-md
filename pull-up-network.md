# Pull-up network

↑ **Parent:** [CMOS](cmos.md)

A [pull-up network](pull-up-network.md) connects a logic output to the high supply rail when its conducting condition holds. In static complementary [CMOS](cmos.md), it is built from [PMOS transistors](pmos-transistor.md) and paired with a complementary [pull-down network](pull-down-network.md).
