# Comoving number density

↑ **Parent:** [Comoving volume](comoving-volume.md)

[Comoving number density](comoving-number-density.md) is object count per [comoving volume](comoving-volume.md). With scale factor normalized to unity today, proper density is $n_p=a^{-3}n_c$. A conserved population moving with homogeneous expansion has constant $n_c$ despite declining proper density. Formation, mergers or changing sample selection can make $n_c$ evolve.
