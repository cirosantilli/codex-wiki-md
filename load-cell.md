# Load cell

↑ **Parent:** [Scientific instrument](scientific-instrument.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Load_cell)

A [load cell](load-cell.md) is a calibrated device for measuring [force](force-split.md). In a [tensile modulus experiment](tensile-modulus-experiment.md) its output supplies the axial load used to calculate [engineering stress](engineering-stress.md).
