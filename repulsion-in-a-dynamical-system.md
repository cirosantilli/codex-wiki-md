# Repulsion in a dynamical system

↑ **Parent:** [Dynamical system](dynamical-system.md)

[Repulsion in a dynamical system](repulsion-in-a-dynamical-system.md) describes nearby trajectories moving away from an invariant state or set in forward time. For a scalar [discrete dynamical system](discrete-dynamical-system-split.md), a fixed-point multiplier with modulus greater than one gives local repulsion.
