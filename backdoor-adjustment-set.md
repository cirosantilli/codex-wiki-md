# Backdoor adjustment set

↑ **Parent:** [Backdoor path](backdoor-path.md)

A backdoor adjustment set contains no descendant of the exposure and blocks every [backdoor path](backdoor-path.md) from the exposure to the outcome. Averaging the conditional outcome distribution over such a set identifies the total causal effect.
