# Instruction selection

↑ **Parent:** [Compiler](compiler.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Instruction_selection)

Choosing target-machine instructions to implement an [intermediate representation](intermediate-representation.md). A memory operand using [register-offset addressing](register-offset-addressing.md) can cover both an address [addition](addition.md) and a load or store; computing the full address into a [temporary variable](temporary-variable.md) can prevent that covering and add an unnecessary instruction.
