<h1 id="kac-s-lemma">Kac's lemma</h1>

↑ **Parent:** [Probability and statistics](probability-and-statistics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kac's_lemma)

For an irreducible positive recurrent [Markov chain](markov-chain.md) with [stationary distribution](stationary-distribution.md) $\pi$, the expected return time to state $i$ is $1/\pi_i$. More generally, expected occupation rewards in a return cycle equal their stationary rate times the expected cycle length.
