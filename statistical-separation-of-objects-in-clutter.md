# Statistical separation of objects in clutter

↑ **Parent:** [Competitive learning](competitive-learning.md)

Independently varying companions can make an individual object’s features more consistently related than the features of any particular multi-object conjunction. Competitive networks can exploit this difference to learn separate object representations without being shown each object in isolation. The result depends on the training distribution; a fixed co-occurring group can instead be learned as a conjunction.[Abstract; Network 18, pp. 161–187, changing object repertoire and [trace learning](trace-learning.md) with multiple objects](invariant-object-recognition-with-trace-learning-and-multiple-stimuli-present-during-training-by-simon-m-stringer-and-others.md)[Abstract; [Neural networks](neural-network.md) 21, pp. 888–903, competitive networks and rotating 3D objects](learning-transform-invariant-object-recognition-in-the-visual-system-with-multiple-stimuli-present-during-training-by-simon-m-stringer-and-others.md)
