# Triangularity of an inverse matrix

↑ **Parent:** [Triangular matrix](triangular-matrix.md)

An invertible [lower triangular matrix](lower-triangular-matrix.md) has a lower triangular [matrix inverse](matrix-inverse-split.md). To see this, solve $Ax=e_j$ for column $j$ of the inverse. The nonzero diagonal and [forward substitution](forward-substitution.md) force $x_i=0$ for $i<j$. Applying the result to the transpose proves the upper-triangular case as well. Invertibility is essential; a singular triangular matrix has no ordinary matrix inverse.
