# Periodic Poisson compatibility

↑ **Parent:** [Poisson's equation](poisson-s-equation.md)

On a periodic domain, integrating $\Delta\Phi=f$ gives $\int f=0$ because boundary fluxes cancel. On a periodic grid the row sum of the [discrete Laplacian](discrete-laplacian.md) is zero, so $\sum_j f_j=0$ is necessary. The constant [gravitational potential](newtonian-potential-of-a-point-mass.md) remains an arbitrary gauge.
