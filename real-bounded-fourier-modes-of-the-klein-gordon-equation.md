# Real bounded Fourier modes of the Klein-Gordon equation

↑ **Parent:** [Klein-Gordon equation](klein-gordon-equation.md)

With inverse-time convention $e^{i\omega t}$, the half-line [Klein-Gordon equation](klein-gordon-equation.md) $\sigma_{tt}-\sigma_{rr}+\mu^2\sigma=0$ has spatial [normal modes](normal-mode.md) $Ae^{ikr}+Be^{-ikr}$, where $k=\sqrt{\omega^2-\mu^2}>0$ above threshold and $k=i\sqrt{\mu^2-\omega^2}$ below it. For the branch even in $\omega$, reality above threshold requires $A(\omega)=B(-\omega)^*$. Below threshold boundedness eliminates $B$, and reality requires $A(\omega)=A(-\omega)^*$. At threshold the spatial [differential equation](differential-equation-split.md) instead has the [basis](basis.md) $1,r$; boundedness retains only the constant mode. A spectral [integral](integral-split.md) with ordinary [integrable functions](lebesgue-integrable-function.md) as amplitudes ignores the isolated threshold points, while [distribution](distribution-mathematical-analysis.md) amplitudes can represent the surviving monochromatic constant-spatial modes.
