# Aggregate molecular fraction versus aggregate number fraction

↑ **Parent:** [Mass-action model of micellization](mass-action-model-of-micellization.md)

If $x_\alpha$ counts [amphiphile](amphiphile.md) molecules belonging to aggregates of size $\alpha$, the corresponding dimensionless aggregate count is $n_\alpha=x_\alpha/\alpha$. Its ideal translational [chemical potential](chemical-potential-split.md) contains $\ln n_\alpha$. Confusing these two distributions drops a factor of $\alpha$ and changes both normalization and the chemical-potential interpretation.
