# Hard-wall and soft-turning-point WKB quantization

↑ **Parent:** [WKB quantization condition](wkb-quantization-condition.md)

A [Dirichlet boundary condition](dirichlet-boundary-condition.md) at a hard endpoint and a single smooth [classical turning point](classical-turning-point.md) give the leading [WKB quantization condition](wkb-quantization-condition.md) $\int_0^{x_{\rm t}}k(x)\,dx=(n+3/4)\pi$, with $n=0,1,\ldots$. The phase differs from the two-soft-turning-point condition because the hard wall imposes an exact [wavefunction](wave-function-split.md) zero rather than an [Airy function](airy-function.md) connection phase. The [WKB validity condition](wkb-validity-condition.md) is still checked in the interior.
