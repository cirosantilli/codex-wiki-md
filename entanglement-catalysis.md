# Entanglement catalysis

↑ **Parent:** [Local operations and classical communication](local-operations-and-classical-communication.md)

An auxiliary entangled [pure state](pure-state.md) can enable an otherwise forbidden deterministic bipartite [LOCC](local-operations-and-classical-communication.md) transformation while being returned exactly and uncorrelated with the output. [Nielsen's pure-state conversion theorem](nielsen-s-pure-state-conversion-theorem.md) reduces this to the displayed [majorization](majorization.md) condition on sorted squared [Schmidt coefficients](schmidt-coefficient.md). It does not follow from a scalar comparison of [entanglement entropies](entanglement-entropy.md): tensoring changes which products occupy the largest cumulative-weight sums. An exact returned catalyst can be reused; merely restoring its marginal while allowing correlations is a different resource task.[Introduction and explicit two-qubit catalyst example](entanglement-assisted-local-manipulation-of-pure-quantum-states-by-daniel-jonathan-and-martin-b-plenio.md)
