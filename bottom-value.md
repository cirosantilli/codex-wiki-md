# Bottom value

↑ **Parent:** [Programming language semantics](programming-language-semantics.md)

An undefined or nonterminating computation in the denotational account of [Haskell](haskell.md). A structured value may contain [bottom values](bottom-value.md) while retaining a defined outer constructor: `undefined : []` is distinguishable from an entirely undefined [list](list-abstract-data-type.md).[§3.1, Errors](haskell-2010-language-report.md)
