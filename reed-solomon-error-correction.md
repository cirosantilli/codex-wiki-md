# Reed-Solomon error correction

↑ **Parent:** [Linear code](linear-code.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Reed–Solomon_error_correction)

For distinct elements $a_1,\ldots,a_n$ of a [finite field](finite-field.md), a Reed-Solomon code consists of the evaluation vectors $(f(a_1),\ldots,f(a_n))$ of [polynomials](polynomial-split.md) with degree less than $k$. It has [dimension](dimension-vector-space.md) $k$ and [minimum Hamming distance](minimum-distance-of-a-code.md) $n-k+1$, so it is a [maximum distance separable code](maximum-distance-separable-code.md). A nonzero polynomial has at most its degree many distinct [polynomial roots](root-of-a-polynomial.md). [Primitive cyclic Reed-Solomon codes](primitive-cyclic-reed-solomon-code.md) use all nonzero field elements, ordered as powers of a [primitive root of unity](primitive-root-of-unity.md); arbitrary evaluation sets need not give a [cyclic code](cyclic-code.md).
