# Source term in a partial differential equation

↑ **Parent:** [Initial and boundary data for evolution equations](initial-and-boundary-data-for-evolution-equations.md)

A prescribed [PDE source term](source-term-in-a-partial-differential-equation.md) changes the [heat equation](heat-equation.md) to $u_t=D u_{xx}+f(x,t)$, or the [transport equation](transport-equation-split.md) to $u_t+c u_x=f(x,t)$. If $u$ is a [temperature](temperature-split.md), $f$ has units of temperature per time. The formulas below assume $f=0$; a nonzero [PDE source term](source-term-in-a-partial-differential-equation.md) can change the spatial average even with [periodic boundary conditions](periodic-boundary-conditions.md).
