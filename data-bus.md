# Data bus

↑ **Parent:** [Shared computer bus](shared-computer-bus.md)

The [computer bus](computer-bus.md) path carrying payload. A write sends data from the initiator to the target; a read returns data from the target. Owning the request path does not mean driving the [data bus](data-bus.md) in both directions.[CS152 lecture 21, slide 24: initiator commands, data in either direction](cs152-computer-architecture-and-engineering-fall-1999/lecture-21-buses-and-i-and-o.md)
