# Category of matrices valued in a frame

↑ **Parent:** [Complete Heyting algebra](complete-heyting-algebra.md)

For a [frame](complete-heyting-algebra.md) $L$, an $L$-valued matrix $f:A\rightsquigarrow B$ is a function $A\times B\to L$. Composition is matrix multiplication with join as addition and meet as multiplication.
