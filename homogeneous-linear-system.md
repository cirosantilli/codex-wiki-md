# Homogeneous linear system

↑ **Parent:** [System of linear equations](system-of-linear-equations.md)

A [linear system](system-of-linear-equations.md) is homogeneous when its forcing is zero. Its solution set is the [kernel of a linear map](kernel-of-a-linear-map-split.md), a [vector subspace](vector-subspace.md). If $Ax=b$ has a particular solution $x_0$, all its solutions are $x_0+\ker A$: subtracting the particular solution leaves a [homogeneous linear system](homogeneous-linear-system.md). The [rank-nullity theorem](rank-nullity-theorem.md) gives the dimension of this freedom.
