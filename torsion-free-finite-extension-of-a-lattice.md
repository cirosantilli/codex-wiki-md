# Torsion-free finite extension of a lattice

↑ **Parent:** [Group extension](group-extension.md)

For a specified [finite group](finite-group.md) action on $A=\mathbb Z^n$, extensions are classified by $e\in H^2(Q,A)$. For an element $q$ of prime order $p$, a lift $g$ satisfies $g^p=a\in A^q$; changing the lift changes $a$ by $N_qv=(1+q+\cdots+q^{p-1})v$. Thus the extension is torsion-free precisely when every restriction to a prime-order cyclic subgroup is nonzero in $A^q/N_qA$. Any finite-order element has a prime-order power, so this tests all torsion. An arbitrary finite quotient must not be confused with faithful holonomy on a maximal translation lattice.
