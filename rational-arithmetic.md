# Rational arithmetic

↑ **Parent:** [Fraction](fraction.md)

Exact arithmetic on [rational numbers](rational-number.md) represented by [integer](integer-split.md) numerators and nonzero [integer](integer-split.md) denominators. Common factors can be removed with the [greatest common divisor](greatest-common-divisor.md). Exact [rational arithmetic](rational-arithmetic.md) avoids rounding error when deciding equality or integrality.
