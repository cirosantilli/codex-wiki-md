# Bernoulli string

↑ **Parent:** [Bernoulli distribution](bernoulli-distribution.md)

A Bernoulli string is a finite sequence of independent binary digits, each taking value one with a specified [probability](probability.md). Unless stated otherwise, all positions use the same probability.
