# Topological generator

↑ **Parent:** [Topological generating set](topological-generating-set.md)

An element of a [topological generating set](topological-generating-set.md) of a [topological group](topological-group-split.md). A finite tuple consists of topological generators when the abstract [subgroup](subgroup.md) it generates is dense in the group; it need not equal that abstract subgroup.
