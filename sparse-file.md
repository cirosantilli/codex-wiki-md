# Sparse file

↑ **Parent:** [Computer file](computer-file.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Sparse_file)

A [computer file](computer-file.md) whose logically zero-filled regions need not occupy physical [file data blocks](file-data-block.md). The [file offset](file-offset.md) and byte length describe the logical content independently of the blocks actually allocated.
