<h1 id="minkowski-s-theorem">Minkowski's theorem</h1>

↑ **Parent:** [Algebraic number theory](algebraic-number-theory-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Minkowski's_theorem)

If $\Lambda\subset\mathbb R^n$ is a full lattice and a measurable convex centrally symmetric set $C$ has volume greater than $2^n\operatorname{covol}(\Lambda)$, then $C$ contains a nonzero lattice point.
