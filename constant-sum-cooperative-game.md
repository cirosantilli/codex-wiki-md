# Constant-sum cooperative game

↑ **Parent:** [Transferable utility game](transferable-utility-game.md)

A [transferable utility game](transferable-utility-game.md) satisfying the displayed equality for every [coalition](coalition-game-theory.md). This forces $v(\varnothing)=0$. It does not by itself guarantee a nonempty [core](core-game-theory.md): [core rigidity in a constant-sum cooperative game](core-rigidity-in-a-constant-sum-cooperative-game.md) shows that nonemptiness requires the [characteristic function of a coalitional game](characteristic-function-of-a-coalitional-game.md) to be additive.
