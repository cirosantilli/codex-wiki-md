# Lambda definition of the successor function

↑ **Parent:** [Lambda-definable function](lambda-definable-function.md)

The [successor function](successor-function.md) is lambda-defined on [Church numerals](church-numeral.md) by

$$
\operatorname{Succ}=\lambda n.\lambda f.\lambda x.f(nfx),
$$

because $\operatorname{Succ}\,c_n\equiv_\beta c_{n+1}$.
