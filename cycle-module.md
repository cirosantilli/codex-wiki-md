# Cycle module

↑ **Parent:** [Cochain complex](cochain-complex.md)

The submodule of cocycles in degree $q$. A projective [boundary module](boundary-module.md) $B^{q+1}$ makes $0\to Z^q\to P^q\to B^{q+1}\to0$ split when $P^q$ is projective, so $Z^q$ is then also projective.
