# Abstraction heuristic

↑ **Parent:** [Relaxation heuristic](relaxation-heuristic.md)

Map original states to simpler abstract states, include every projected original transition at no greater cost, and map original goals to abstract goals. An original goal-reaching [graph path](path-in-a-graph.md) then projects to an abstract goal-reaching walk, so the exact abstract distance is an [admissible heuristic](admissible-heuristic.md). A [pattern database](pattern-database.md) stores such distances for repeated lookup.
