# Dynamical symmetry

↑ **Parent:** [Symmetry (physics)](symmetry-physics.md)

A transformation taking solutions of a specified set of dynamical equations into solutions, with the theory's fixed background data held fixed. For a [Lagrangian](lagrangian.md), invariance of the [action](action.md) up to a boundary term is a useful sufficient criterion. Symmetry of the equations does not imply that every individual solution has that symmetry: initial data and boundary conditions can select a direction or state of motion.
