# Half adder

↑ **Parent:** [Adder](adder.md)

A [combinational logic](combinational-logic.md) circuit adding two input [bits](bit.md) $a,b$ to a sum [bit](bit.md) $s=a\oplus b$ and [carry](carry-arithmetic.md) [bit](bit.md) $c=a\land b$. An [exclusive or](exclusive-or.md) gate and an [AND gate](and-gate.md) implement it. The identity $a+b=(a\oplus b)+2(a\land b)$ follows by checking the four input pairs. A [half adder](half-adder.md) has no input carry, so adding three equally weighted [bits](bit.md) needs a different circuit or multiple stages.
